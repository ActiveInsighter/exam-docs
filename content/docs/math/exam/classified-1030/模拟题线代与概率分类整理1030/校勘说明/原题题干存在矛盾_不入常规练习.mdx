# 已核查但不收录的原题：李林六套卷第六套第6题

- 原题 ID：`lilin-2027-s6-q06`
- 暂拟归档：线性代数·第二章第二节 逆矩阵／第四章第二节 相似对角化（**待校勘，不计入正式题数**）
