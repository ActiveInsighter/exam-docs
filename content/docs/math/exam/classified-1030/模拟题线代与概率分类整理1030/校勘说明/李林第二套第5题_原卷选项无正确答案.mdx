# 李林六套卷·第二套·第5题：原卷选项无法对应正确参数

- 来源：[李林六套卷·第二套](https://exam.any1.tech/docs/math/exam/s-cf996fa8/lilin-02/)
- 原题 ID：`lilin-2027-s2-q05`
- 归类候选：线性代数/第三章 向量与线性方程组/第一节 向量的线性表出
- **结论：不计入常规训练题数；原卷 A～D 四项无正确答案。** 其网页整理版已加第五选项E，该选项不是原始选项。

题设要求 $\beta=(a,1,1)^T$ 被三向量 $\alpha_1=(b,0,1)^T,\alpha_2=(1,b,-1)^T,\alpha_3=(1,0,b)^T$ 线性表出且表示不唯一。令 $M=(\alpha_1,\alpha_2,\alpha_3)$，则 $|M|=b(b^2-1)$，故 $b\in\{-1,0,1\}$。$b=0$ 因第二行全0而右端第二坐标为1，不相容。$b=1$ 时得 $a=3$；$b=-1$ 时得 $a=-1$。

因此正确参数应为 $(a,b)=(3,1)$ 或 $(-1,-1)$。原卷 A $(-2,1)$、B $(-2,-1)$、C $(2,1)$、D $(2,-1)$ 均不符。**应校对原始纸质题面，不可改选A～D。**
