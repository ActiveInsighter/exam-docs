# 1.3 条件概率与独立性

## 小题

<ExamQuestion>

1. **【1989-1-2 分】** 甲, 乙两人独立的对同一目标射击一次, 其命中率分别为0.6 和0.5, 现已知目标被命中, 则它是甲射中的概率是

<ExamSolution>

<ExamAnswer>$ \frac34$。</ExamAnswer>

<ExamExplanation>
设甲、乙命中事件分别为 $A,B$，则 $ P(A\cup B)=1-(1-0.6)(1-0.5)=0.8$，故 $ P(A\mid A\cup B)=0.6/0.8=3/4$。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

2. **【2017-1-4 分】** 设 $A,B$ 为随机事件.若 $ 0<P(A)<1$, $ 0<P(B)<1$, 则 $ P(A|B)>P(A|\bar{B})$ 的充分必要条件是( )

<ExamChoices>
<ExamOption>A. $ P(B|A)>P(B|\bar{A})$</ExamOption>
<ExamOption>B. $ P(B|A)<P(B|\bar{A})$</ExamOption>
<ExamOption>C. $ P(\bar{B}|A)>P(B|\bar{A})$</ExamOption>
<ExamOption>D. $ P(\bar{B}|A)<P(B|\bar{A})$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>A。</ExamAnswer>

<ExamExplanation>
由全概率公式，$P(A)$ 是 $P(A\mid B)$ 与 $P(A\mid\bar B)$ 的加权平均；所给不等式等价于 $A,B$ 正相关，也等价于 $ P(B\mid A)>P(B\mid\bar A)$。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

3. **【2021-13-5 分】** 设 $A,B$ 为随机事件, 且 $ 0<P(B)<1$, 下列命题中为假命题的是( )

<ExamChoices>
<ExamOption>A. 若 $ P(A|B)=P(A)$, 则 $ P(A|\bar{B})=P(A)$</ExamOption>
<ExamOption>B. 若 $ P(A|B)>P(A)$, 则 $ P(\bar{A}|\bar{B})>P(\bar{A})$</ExamOption>
<ExamOption>C. 若 $ P(A|B)>P(A|\bar{B})$, 则 $ P(A|B)>P(A)$</ExamOption>
<ExamOption>D. 若 $ P(A|A \cup B)>P(\bar{A}|A \cup B)$, 则 $ P(A)>P(B)$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>D。</ExamAnswer>

<ExamExplanation>
A、B、C 三项均可由全概率公式直接推出。D 的前提等价于 $P(A)>P(\bar A B)$，而 $P(B)=P(AB)+P(\bar A B)$，其中还包含交集部分 $P(AB)$，因此不能推出 $P(A)>P(B)$，故 D 为假命题。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

4. **【2000-4-3 分】** 设 $A,B,C$ 三个事件两两相互独立, 则 $A,B,C$ 相互独立的充分必要条件是( ).

<ExamChoices>
<ExamOption>A. $A$ 与 $BC$ 独立</ExamOption>
<ExamOption>B. $ AB$ 与 $ A \cup C$ 独立</ExamOption>
<ExamOption>C. $ AB$ 与 $ AC$ 独立</ExamOption>
<ExamOption>D. $ A \cup B$ 与 $ A \cup C$ 独立</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>A。</ExamAnswer>

<ExamExplanation>
已知两两独立后，三事件相互独立只差条件 $ P(ABC)=P(A)P(B)P(C)$。这恰好等价于 $A$ 与事件 $BC$ 独立。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

5. **【2003-3-4 分】** 将一枚硬币独立地掷两次, 引进事件:
$ A_1=\{\text{掷第一次出现正面}\}$,
$ A_2=\{\text{掷第二次出现正面}\}$,
$ A_3=\{\text{正、反面各出现一次}\}$,
$ A_4=\{\text{正面出现两次}\}$,
则事件( )

<ExamChoices>
<ExamOption>A. $ A_1$, $ A_2$, $ A_3$ 相互独立</ExamOption>
<ExamOption>B. $ A_2$, $ A_3$, $ A_4$ 相互独立</ExamOption>
<ExamOption>C. $ A_1$, $ A_2$, $ A_3$ 两两独立</ExamOption>
<ExamOption>D. $ A_2$, $ A_3$, $ A_4$ 两两独立</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>C。</ExamAnswer>

<ExamExplanation>
$A_1,A_2,A_3$ 的概率均为 $1/2$，任意两者交集概率均为 $1/4$，故两两独立；但三者交集为空而概率乘积为 $1/8$，所以不相互独立。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

6. **【2017-3-4 分】** 设 $A,B,C$ 为三个随机事件, 且 $A$ 与 $C$ 相互独立, $B$ 与 $C$ 相互独立, 则 $A \cup B$ 与 $C$ 相互独立的充分必要条件是( )

<ExamChoices>
<ExamOption>A. $A$ 与 $B$ 相互独立</ExamOption>
<ExamOption>B. $A$ 与 $B$ 互不相容</ExamOption>
<ExamOption>C. $AB$ 与 $C$ 相互独立</ExamOption>
<ExamOption>D. $AB$ 与 $C$ 互不相容</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>C。</ExamAnswer>

<ExamExplanation>
利用容斥公式，$ P((A\cup B)C)=P(AC)+P(BC)-P(ABC)$。已知 $A,C$ 与 $B,C$ 独立后，$A\cup B$ 与 $C$ 独立当且仅当 $ P(ABC)=P(AB)P(C)$，即 $AB$ 与 $C$ 独立。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

7. **【张宇1000题·概率论与数理统计·第1章·基础部分第4题】** 一平面质点从原点出发，每次走一个单位，只有向上、向右两种走法，且向上走的概率为$p(0<p<1)$，现质点走到了点$(3,2)$，则这5步按照：右，上，右，上，右的方式走的概率为( )
<ExamChoices>
<ExamOption>A. $\frac{3}{20}$</ExamOption>
<ExamOption>B. $\frac{1}{13}$</ExamOption>
<ExamOption>C. $\frac{1}{20}$</ExamOption>
<ExamOption>D. $\frac{1}{10}$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>D</ExamAnswer>

<ExamExplanation>
到达$ (3,2)$意味着5步中恰有3步向右、2步向上。任一满足该条件的具体路径概率均为
$ (1-p)^3p^2$，因此在“已经到达$ (3,2)$”这一条件下，所有$ \binom52=10$条路径等可能。
故指定路径的条件概率为
$ \frac1{\binom52}=\frac1{10}$。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

## 大题

<ExamQuestion>

1. **【2002-4-8 分】** 设 $A,B$ 是任意二事件, 其中 $A$ 的概率不等于0 和1, 证明, $ P(B|A)=P(B|\bar{A})$ 是事件 $A$ 与 $B$ 独立的充分必要条件.

<ExamSolution>

<ExamAnswer>结论成立。</ExamAnswer>

<ExamExplanation>
若 $ P(B\mid A)=P(B\mid\bar A)=r$，由全概率公式 $ P(B)=rP(A)+rP(\bar A)=r$，于是 $ P(AB)=P(A)P(B)$，$A,B$ 独立。反之，若 $A,B$ 独立，则 $ P(B\mid A)=P(B)$；又 $A$ 与 $B$ 独立也推出 $\bar A$ 与 $B$ 独立，所以 $ P(B\mid\bar A)=P(B)$。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>
