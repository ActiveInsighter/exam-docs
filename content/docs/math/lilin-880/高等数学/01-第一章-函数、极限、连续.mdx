# 第一章 函数、极限、连续

## 基础题

### 选择题

<ExamQuestion>

1. 函数 $f(x) = |x\sin x|e^{\cos x}, x \in (-\infty, +\infty)$, 是 ( ).
<ExamChoices>
<ExamOption>A. 单调函数 \quad</ExamOption>
<ExamOption>B. 周期函数 \quad</ExamOption>
<ExamOption>C. 偶函数 \quad</ExamOption>
<ExamOption>D. 有界函数</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>C</ExamAnswer>

<ExamExplanation>
**解析：** 对任意 $x\in\mathbb R$，

$$f(-x)=|(-x)\sin(-x)|e^{\cos(-x)}=|x\sin x|e^{\cos x}=f(x),$$

故 $f(x)$ 为偶函数。

另外，取 $x_k=\frac{\pi}{2}+2k\pi$，则 $f(x_k)=|x_k|\to+\infty$，所以 $f(x)$ 无界，也不可能是周期函数；又 $f(0)=0$、$f\left(\frac{\pi}{2}\right)=\frac{\pi}{2}$、$f(\pi)=0$，故 $f(x)$ 也不是单调函数。因此选 C。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

2. 设函数 $f(x) = \cos(\sin x), g(x) = \sin(\cos x)$, 则当 $x \in \left(0, \frac{\pi}{2}\right)$ 时, ( ).
<ExamChoices>
<ExamOption>A. $f(x)$ 单调增加, $g(x)$ 单调减少 \quad</ExamOption>
<ExamOption>B. $f(x)$ 单调减少, $g(x)$ 单调增加</ExamOption>
<ExamOption>C. $f(x)$ 与 $g(x)$ 都单调增加 \quad</ExamOption>
<ExamOption>D. $f(x)$ 与 $g(x)$ 都单调减少</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>D</ExamAnswer>

<ExamExplanation>
**解析：** 在区间 $\left(0, \frac{\pi}{2}\right)$ 内，$\sin x$ 单调增加，$\cos x$ 单调减少，任取 $x_1, x_2 \in \left(0, \frac{\pi}{2}\right)$，且 $x_1 < x_2$，则 $\sin x_1 < \sin x_2$，故 $\cos(\sin x_1) > \cos(\sin x_2)$，所以函数 $f(x)$ 单调减少。又 $\cos x_1 > \cos x_2$，则 $\sin(\cos x_1) > \sin(\cos x_2)$，故函数 $g(x)$ 单调减少，选项 D 正确。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

3. 设函数 $f(x) = \sqrt{1 + x + x^2} - \sqrt{1 - x + x^2}$, 则 ( ).
<ExamChoices>
<ExamOption>A. $f(x)$ 为偶函数 \quad</ExamOption>
<ExamOption>B. $f(x)$ 为奇函数 \quad</ExamOption>
<ExamOption>C. $f(x)$ 为无界函数 \quad</ExamOption>
<ExamOption>D. $\lim_{x \to -\infty} f(x) = 1$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>B</ExamAnswer>

<ExamExplanation>
**解析：** 先判断奇偶性：

$$f(-x)=\sqrt{1-x+x^2}-\sqrt{1+x+x^2}=-f(x),$$

故 $f(x)$ 为奇函数，B 正确。

再有

$$f(x)=\frac{2x}{\sqrt{x^2+x+1}+\sqrt{x^2-x+1}},$$

因此

$$\lim_{x\to+\infty}f(x)=1,\qquad \lim_{x\to-\infty}f(x)=-1.$$

因此 D 错误；又 $f(x)$ 在 $x\to\pm\infty$ 时均趋于有限值，且在有限区间上连续，所以 $f(x)$ 有界，C 也错误。因此选 B。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

4. 设当 $x \to +\infty$ 时, $f(x), g(x)$ 都是无穷大, 则当 $x \to +\infty$ 时, 下列结论中正确的是 ( ).
<ExamChoices>
<ExamOption>A. $f(x) - g(x)$ 是无穷小 \quad</ExamOption>
<ExamOption>B. $f(x) + g(x)$ 是无穷大</ExamOption>
<ExamOption>C. $\frac{g(x)}{f(x)} \to 1$ \quad</ExamOption>
<ExamOption>D. $\frac{f(x) + g(x)}{f(x)g(x)}$ 是无穷小</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>D</ExamAnswer>

<ExamExplanation>
**解析：** 由题可得

$$\lim_{x \to +\infty} \frac{f(x) + g(x)}{f(x)g(x)} = \lim_{x \to +\infty} \left(\frac{1}{g(x)} + \frac{1}{f(x)}\right) = 0.$$

故 $\frac{f(x) + g(x)}{f(x)g(x)}$ 是无穷小，选项 D 正确。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

5. 当 $x \to 0$ 时, $\frac{1}{x^2}\sin\frac{1}{x}$ 是 ( ).
<ExamChoices>
<ExamOption>A. 无穷大 \quad</ExamOption>
<ExamOption>B. 无穷小 \quad</ExamOption>
<ExamOption>C. 有界但非无穷小 \quad</ExamOption>
<ExamOption>D. 无界但非无穷小</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>D</ExamAnswer>

<ExamExplanation>
**解析：** 当 $x \to 0$ 时，$\frac{1}{x^2} \to +\infty, \sin\frac{1}{x}$ 在 $-1$ 和 $1$ 之间振荡，且重复函数值为零，故可排除选项 A 和 B。

取 $x_n = \dfrac{1}{2n\pi + \dfrac{\pi}{2}} (n = 1, 2, \cdots)$, 则当 $x_n \to 0$ 时, $f(x_n) = \left(2n + \dfrac{1}{2}\right)^2 \cdot \pi^2 \to \infty$, 故 $\dfrac{1}{x^2}\sin\dfrac{1}{x} (x \to 0)$ 不是无穷小, 也不是有界量.

令 $y_n = \dfrac{1}{n\pi} (n = 1, 2, \cdots)$, 当 $y_n \to 0$ 时, $f(y_n) = 0$, 故当 $x \to 0$ 时, $\dfrac{1}{x^2}\sin\dfrac{1}{x}$ 不是无穷大. 选项 D 正确.
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

有 $1-a=0, a+b=0$, 故 $a=1, b=-1$, 选项 C 正确.

$$(x-\sin x)\tan x \sim \dfrac{x^4}{6}.$$
由已知, $4>n$ 且 $n>2$, 故 $n=3$, 选项 B 正确.

8. 当 $x\to 0$ 时，$\mathrm{e}^x-\frac{1+ax^2}{1+bx}$ 与 $x^3$ 是同阶无穷小，则 $(\quad)$.
<ExamChoices>
<ExamOption>A. $a=\frac{1}{2}, b=1$ \quad</ExamOption>
<ExamOption>B. $a=-\frac{1}{2}, b=1$ \quad</ExamOption>
<ExamOption>C. $a=\frac{1}{2}, b=-1$ \quad</ExamOption>
<ExamOption>D. $a=-\frac{1}{2}, b=-1$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>D</ExamAnswer>

<ExamExplanation>
**解析：** 依题设, 有
$$\lim_{x\to 0}\dfrac{e^x - \dfrac{1+ax^2}{1+bx}}{x^3} = \lim_{x\to 0}\dfrac{e^x(1+bx)-(1+ax^2)}{(1+bx)x^3} = \lim_{x\to 0}\dfrac{e^x(1+bx)-(1+ax^2)}{x^3} \neq 0,$$
故
$$\lim_{x\to 0}\dfrac{\left[1+x+\dfrac{1}{2}x^2+\dfrac{1}{6}x^3+o(x^3)\right](1+bx)-(1+ax^2)}{x^3}$$
$$=\lim_{x\to 0}\dfrac{(1+b)x + \left(\dfrac{1}{2}+b-a\right)x^2 + \left(\dfrac{1}{6}+\dfrac{1}{2}b\right)x^3 + \dfrac{1}{6}bx^4}{x^3} \neq 0.$$
所以 $1+b=0, \dfrac{1}{2}+b-a=0, \dfrac{1}{6}+\dfrac{1}{2}b \neq 0.$

解得 $a=-\dfrac{1}{2}, b=-1$. 选项 D 正确.
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

9. 设 $f(x)=\ln^2 x, g(x)=x, h(x)=\mathrm{e}^{\frac{x}{2}}(x>1)$，则当 $x$ 充分大时，$(\quad)$.
<ExamChoices>
<ExamOption>A. $f(x)<g(x)<h(x)$ \quad</ExamOption>
<ExamOption>B. $g(x)<h(x)<f(x)$</ExamOption>
<ExamOption>C. $h(x)<g(x)<f(x)$ \quad</ExamOption>
<ExamOption>D. $g(x)<f(x)<h(x)$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>A</ExamAnswer>

<ExamExplanation>
**解析：** 由于
$$\lim_{x\to+\infty}\dfrac{f(x)}{g(x)} = \lim_{x\to+\infty}\dfrac{\ln^2 x}{x} = 2\lim_{x\to+\infty}\dfrac{\ln x}{x} = 2\lim_{x\to+\infty}\dfrac{1}{x} = 0 < 1,$$
故当 $x$ 充分大时, $g(x) = x > 0, \dfrac{f(x)}{g(x)} < 1$, 即 $f(x) < g(x)$. 又
$$\lim_{x\to+\infty}\dfrac{h(x)}{g(x)} = \lim_{x\to+\infty}\dfrac{e^{\frac{x}{2}}}{x} = \lim_{x\to+\infty}\dfrac{1}{2}\cdot e^{\frac{x}{2}} = +\infty > 1,$$
故当 $x$ 充分大时, $g(x) = x > 0, \dfrac{h(x)}{g(x)} > 1$, 即 $h(x) > g(x)$. 选项 A 正确.
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

10. 设 $\lim_{n\to\infty}a_n$ 与 $\lim_{n\to\infty}b_n$ 均不存在，则下列选项中正确的是 $(\quad)$.
<ExamChoices>
<ExamOption>A. 若 $\lim_{n\to\infty}(a_n+b_n)$ 不存在，则 $\lim_{n\to\infty}(a_n-b_n)$ 必不存在</ExamOption>
<ExamOption>B. 若 $\lim_{n\to\infty}(a_n+b_n)$ 不存在，则 $\lim_{n\to\infty}(a_n-b_n)$ 必存在</ExamOption>

<ExamSolution>

</ExamExplanation>

</ExamSolution>

11. 函数 $f(x)=\frac{2+\mathrm{e}^{\frac{1}{x}}}{1+\mathrm{e}^{\frac{2}{x}}}+\frac{\sin x}{|x|}$ 在 $x=0$ 处为 $(\quad)$.
<ExamChoices>
<ExamOption>A. 可去间断点 \quad</ExamOption>
<ExamOption>B. 跳跃间断点 \quad</ExamOption>
<ExamOption>C. 无穷间断点 \quad</ExamOption>
<ExamOption>D. 振荡间断点</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>A</ExamAnswer>

<ExamExplanation>
**解析：** $f(x)$ 在 $x = 0$ 处间断，考虑间断点处的左、右极限。
$$\lim_{x \to 0^-} \left( \frac{2 + e^{\frac{1}{x}}}{1 + e^{\frac{2}{x}}} + \frac{\sin x}{|x|} \right) = \lim_{x \to 0^-} \left( \frac{2 + e^{\frac{1}{x}}}{1 + e^{\frac{2}{x}}} - \frac{\sin x}{x} \right) = 2 - 1 = 1,$$
$$\lim_{x \to 0^+} \left( \frac{2 + e^{\frac{1}{x}}}{1 + e^{\frac{2}{x}}} + \frac{\sin x}{|x|} \right) = \lim_{x \to 0^+} \left( \frac{2 + e^{\frac{1}{x}}}{1 + e^{\frac{2}{x}}} + \frac{\sin x}{x} \right)$$
$$= \lim_{x \to 0^+} \left( \frac{2e^{-\frac{2}{x}} + e^{-\frac{1}{x}}}{e^{-\frac{2}{x}} + 1} + \frac{\sin x}{x} \right) = 0 + 1 = 1,$$
故 $x = 0$ 是 $f(x)$ 的可去间断点，选项 A 正确。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

12. $f(x)=\frac{(x^2-x)|x+1|\mathrm{e}^{-\frac{1}{x}}}{\int_1^x t^2\sin t\mathrm{d}t} (x\in[-\pi,\pi])$ 的第一类间断点的个数为 $(\quad)$.
<ExamChoices>
<ExamOption>A. $0$ \quad</ExamOption>
<ExamOption>B. $1$ \quad</ExamOption>
<ExamOption>C. $2$ \quad</ExamOption>
<ExamOption>D. $3$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>C</ExamAnswer>

<ExamExplanation>
**解析：** 令

$$F(x)=\int_1^x t^2\sin t\,\mathrm{d}t.$$

由于 $t^2\sin t$ 为奇函数，$F(1)=0$，且

$$F(-1)=\int_1^{-1}t^2\sin t\,\mathrm{d}t=-\int_{-1}^1t^2\sin t\,\mathrm{d}t=0,$$

再结合因子 $e^{-1/x}$，可知需要考察的间断点为 $x=0,\pm1$。

当 $x\to0^+$ 时，$e^{-1/x}\to0$，故 $f(x)\to0$；当 $x\to0^-$ 时，$e^{-1/x}\to+\infty$，而 $F(x)\to F(0)\neq0$，从而 $|f(x)|\to\infty$。因此 $x=0$ 为第二类间断点。

当 $x\to1$ 时，由洛必达法则，

$$\lim_{x\to1}f(x) =\frac{2}{e}\lim_{x\to1}\frac{x-1}{F(x)} =\frac{2}{e}\lim_{x\to1}\frac{1}{x^2\sin x} =\frac{2}{e\sin1},$$

故 $x=1$ 为可去间断点。

当 $x\to-1$ 时，记 $h=x+1$。由

$$F(x)=F'(-1)h+o(h)=-\sin1\,h+o(h),$$

且

$$x(x-1)|x+1|e^{-1/x}=2e|h|+o(|h|),$$

可得

$$\lim_{x\to-1^-}f(x)=\frac{2e}{\sin1},\qquad \lim_{x\to-1^+}f(x)=-\frac{2e}{\sin1}.$$

左右极限均存在且有限但不相等，所以 $x=-1$ 为跳跃间断点。综上，第一类间断点共有 $2$ 个，选 C。
</ExamExplanation>

</ExamSolution>

<ExamSolution>

<ExamAnswer>$P \leqslant 2$</ExamAnswer>

<ExamExplanation>

3. $\lim_{x \to 0} \frac{e^{x^2} - e^{2 - 2\cos x}}{e^{x^4} - 1} =$ _________.

<ExamSolution>

<ExamAnswer>$\frac{1}{12}$</ExamAnswer>

<ExamExplanation>
**解析：** 当 $x \to 0$ 时, 有 $e^{x^4} - 1 \sim x^4$, 故

$$\begin{aligned} \text{原式} &= \lim_{x \to 0} \frac{e^{x^2} - e^{2 - 2\cos x}}{x^4} = \lim_{x \to 0} e^{2 - 2\cos x} \cdot \frac{e^{x^2 - 2 + 2\cos x} - 1}{x^4} \\ &= \lim_{x \to 0} \frac{x^2 - 2 + 2\cos x}{x^4} = \lim_{x \to 0} \frac{2x - 2\sin x}{4x^3} \\ &= \frac{1}{2} \lim_{x \to 0} \frac{1 - \cos x}{3x^2} = \frac{1}{6} \lim_{x \to 0} \frac{\frac{1}{2}x^2}{x^2} = \frac{1}{12}. \end{aligned}$$

</ExamExplanation>

1. 设函数 $f(x)$ 满足 $af(x) + bf\left(\frac{1}{x}\right) = \frac{c}{x}$, 其中 $a$、 $b$、 $c$ 均为常数, 且 $|a| \neq |b|$, 求 $f(x)$ 的表达式, 并证明 $f(x)$ 是奇函数.

<ExamSolution>

<ExamAnswer>$f(x)=\dfrac{c}{a^2-b^2}\left(\dfrac{a}{x}-bx\right)$，且 $f(x)$ 为奇函数。</ExamAnswer>

<ExamExplanation>
**解析：** 由已知得,
$$af(x) + bf\left(\frac{1}{x}\right) = \frac{c}{x}, \quad \text{①}$$
在 ① 式中用 $\frac{1}{x}$ 代替 $x$, 得
$$af\left(\frac{1}{x}\right) + bf(x) = cx. \quad \text{②}$$
再由 ① $\times a -$ ② $\times b$, 得 $(a^2 - b^2)f(x) = \frac{ac}{x} - bcx$, 由 $|a| \neq |b|$, 故
$$f(x) = \frac{c}{a^2 - b^2} \left(\frac{a}{x} - bx\right).$$
而
$$f(-x) = \frac{c}{a^2 - b^2} \left(-\frac{a}{x} + bx\right) = -f(x),$$
所以 $f(x)$ 是奇函数.
</ExamExplanation>

</ExamSolution>

<ExamQuestion>

2. 求下列极限:

$(I) \lim_{x \to \infty} \frac{x^2 - x \sin x}{x^2 + x \sin \frac{1}{x}}$;

$(II) \lim_{x \to +\infty} \left(\frac{a^{\frac{1}{x}} + b^{\frac{1}{x}} + c^{\frac{1}{x}}}{3}\right)^x \quad (a, b, c \text{为正数})$;

$(III) \lim_{x \to 0} \frac{\ln(\sin^2 x + e^x) - x}{\ln(e^{2x} - x^2) - 2x}$;

$(IV) \lim_{x \to 0} \frac{(1 + x)^{\frac{3}{x}} - e^3}{x}$;

$(V) \lim_{x \to 0} \frac{e^{\tan x} - e^x}{x^3}$;

$(VI) \lim_{x \to 0} \cot x \left(\frac{1}{\sin x} - \frac{1}{x}\right)$;

$(VII) \lim_{x \to 0} (1 - x^2)^{\frac{1}{1-\sqrt{1-x^2}}}$;

$(VIII) \lim_{x \to 0^+} x^{\sin x}$.

<ExamSolution>

<ExamAnswer>$(I)\ 1$；$(II)\ (abc)^{1/3}$；$(III)\ -1$；$(IV)\ -\dfrac32e^3$；$(V)\ \dfrac13$；$(VI)\ \dfrac16$；$(VII)\ e^{-2}$；$(VIII)\ 1$。</ExamAnswer>

<ExamExplanation>
**解析：**

$(I)$

$$\frac{x^2-x\sin x}{x^2+x\sin\frac1x} =\frac{1-\frac{\sin x}{x}}{1+\frac1x\sin\frac1x}\to1.$$

$(II)$ 设

$$L=\lim_{x\to+\infty}\left(\frac{a^{1/x}+b^{1/x}+c^{1/x}}3\right)^x.$$

取对数，并用 $a^{1/x}=e^{(\ln a)/x}=1+\frac{\ln a}{x}+o(1/x)$，得

$$\ln L=\lim_{x\to+\infty}x\ln\left(1+\frac{\ln a+\ln b+\ln c}{3x}+o\!\left(\frac1x\right)\right) =\frac{\ln(abc)}3.$$

故

$$L=(abc)^{1/3}.$$

$(III)$

$$\frac{\ln(\sin^2x+e^x)-x}{\ln(e^{2x}-x^2)-2x} =\frac{\ln\left(1+e^{-x}\sin^2x\right)} {\ln\left(1-e^{-2x}x^2\right)} \to -1.$$

$(IV)$ 令

$$u(x)=\frac{3\ln(1+x)}x-3=-\frac32x+o(x),$$

则

$(\text{II})$ 令 $F(x) = f\left(x + \frac{1}{n}\right) - f(x), x \in \left[0, \frac{n-1}{n}\right]$, 则
$$F(0) + F\left(\frac{1}{n}\right) + \dots + F\left(\frac{n-1}{n}\right) = f(1) - f(0) = 0.$$
若 $F(0) = F\left(\frac{1}{n}\right) = \dots = F\left(\frac{n-1}{n}\right) = 0$, 即
$$f\left(0 + \frac{1}{n}\right) - f(0) = f\left(\frac{2}{n}\right) - f\left(\frac{1}{n}\right) = \dots = f(1) - f\left(\frac{n-1}{n}\right) = 0,$$
所证结论显然成立；
若存在 $k\in\{1,2,\ldots,n-1\}$ 使 $F\left(\frac{k}{n}\right)=0$，则直接取 $\xi=\frac{k}{n}$。否则，若 $F(0)=0$，则其余 $n-1$ 个离散值之和仍为 $0$；若 $F(0)\neq0$，则全部离散值之和为 $0$。在这两种情况下，除非已经出现内部零点，否则这些离散值中必同时出现正值和负值。由于 $F$ 连续，介值定理保证存在

$$\xi\in\left(0,\frac{n-1}{n}\right)\subset(0,1)$$

使 $F(\xi)=0$，即

$$f(\xi)=f\left(\xi+\frac1n\right).$$
</ExamExplanation>

</ExamSolution>

12. (I) 设 $\lim_{x\to 0}\frac{\ln\left[1+\frac{f(x)}{\sin x}\right]}{a^x-1}=\frac{1}{2}\,(a>0, a\neq 1)$, 求 $\lim_{x\to 0}\frac{f(x)}{x^2}$;

$$\lim_{x\to0}\frac{\ln\left(1+\frac{f(x)}{\sin x}\right)}{a^x-1}=\frac12,$$

$$a^x-1=x\ln a+o(x),$$

$$\ln\left(1+\frac{f(x)}{\sin x}\right)=\frac12x\ln a+o(x).$$

1. 设 $x_0 \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$, 数列 $\{x_n\}$ 满足 $x_{n+1}=\frac{1}{2}(x_n+\arctan x_n)\,(n=0,1,2,\cdots)$.

(I) 证明: $\lim_{n\to\infty}x_n$ 存在, 并求其值;

(II) 求 $\lim_{n\to\infty}\frac{(1+x_n)^{\frac{1}{x_n}}-(1+2x_n)^{\frac{1}{2x_n}}}{2x_{n+1}-x_n}$.

<ExamSolution>

<ExamAnswer>$(I)\ 0$；$(II)\ \dfrac e2$。</ExamAnswer>

<ExamExplanation>
**证明：** (I) 由 $x_0 \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right), \arctan x_0 \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$, 知
$$x_1 = \frac{1}{2}(x_0 + \arctan x_0) \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right).$$

假设 $x_n \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$, 则
$$x_{n+1} = \frac{1}{2}(x_n + \arctan x_n) \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right).$$

由数学归纳法, 知 $\{x_n\}$ 有界.
记 $f(x) = \frac{1}{2}(x + \arctan x)$, 则 $x_{n+1} = f(x_n), f'(x) = \frac{1}{2}\left(1 + \frac{1}{1+x^2}\right) > 0$. 由拉格朗日中值定理, 有
$$x_{n+1} - x_n = f(x_n) - f(x_{n-1}) = f'(\xi_n)(x_n - x_{n-1}),$$
故 $x_{n+1} - x_n$ 与 $x_n - x_{n-1}$ 同号.
当 $x_1 > x_0$ 时, $\{x_n\}$ 单调递增; 当 $x_1 < x_0$ 时, $\{x_n\}$ 单调递减. 由单调有界准则, 知 $\lim_{n \to \infty} x_n$ 存在, 记 $\lim_{n \to \infty} x_n = a$, 则在 $x_{n+1} = \frac{1}{2}(x_n + \arctan x_n)$ 两边同时取极限 $(n \to \infty)$, 有 $a = \frac{1}{2}(a + \arctan a)$, 即 $a = \arctan a$, 得 $a = 0$, 从而 $\lim_{n \to \infty} x_n = 0$.

**解析：** (II) 若 $x_0=0$，则 $x_n\equiv0$，题中比值本身无定义；因此本问应在 $x_0\ne0$ 的情形下理解。由已知 $2x_{n+1}-x_n=\arctan x_n$，且此时 $x_n\to0$，则

$$\begin{aligned} \lim_{n \to \infty} \frac{(1+x_n)^{\frac{1}{x_n}}-(1+2x_n)^{\frac{1}{2x_n}}}{\arctan x_n} &=\lim_{x\to0}\frac{(1+x)^{\frac1x}-(1+2x)^{\frac1{2x}}}{\arctan x}\\ &=\lim_{x\to0}\frac{e^{\frac{\ln(1+x)}x}-e^{\frac{\ln(1+2x)}{2x}}}{\arctan x}. \end{aligned}$$

由拉格朗日中值定理, 有
$$e^{\frac{\ln(1+x)}{x}} - e^{\frac{\ln(1+2x)}{2x}} = e^\xi \left[\frac{\ln(1+x)}{x} - \frac{\ln(1+2x)}{2x}\right],$$
其中 $\xi$ 介于 $\frac{\ln(1+x)}{x}$ 与 $\frac{\ln(1+2x)}{2x}$ 之间.
又 $\lim_{x \to 0} \frac{\ln(1+x)}{x} = \lim_{x \to 0} \frac{\ln(1+2x)}{2x} = 1$, 故 $\lim_{x \to 0} e^\xi = e$.

因此

$$\begin{aligned} \text{原式} &=\lim_{x\to0}e^{\xi} \frac{\frac{\ln(1+x)}x-\frac{\ln(1+2x)}{2x}}{x}\cdot\frac{x}{\arctan x}\\ &=\frac e2\lim_{x\to0}\frac{2\ln(1+x)-\ln(1+2x)}{x^2}\\ &=\frac e2. \end{aligned}$$

2. (I) 设 $f(x)$ 是 $[0, +\infty)$ 上单调减少且非负的连续函数. 证明:

$f(k+1)\leqslant \int_k^{k+1}f(x)\mathrm{d}x\leqslant f(k)\,(k=1,2,\cdots)$;

(II) 证明: $\ln(1+n)\leqslant 1+\frac{1}{2}+\cdots+\frac{1}{n}\leqslant 1+\ln n$, 并求极限 $\lim_{n\to\infty}\frac{1+\frac{1}{2}+\cdots+\frac{1}{n}}{\ln n}$.

<ExamSolution>

<ExamAnswer>不等式成立，且 $\displaystyle\lim_{n\to\infty}\dfrac{1+\frac12+\cdots+\frac1n}{\ln n}=1$。</ExamAnswer>

<ExamExplanation>
**证明：** (I) 由 $f(x)$ 单调减少且非负连续, 可知当 $x \in [k, k+1]$ 时,
$$f(k+1) \leqslant f(x) \leqslant f(k),$$
故
$$\int_k^{k+1} f(k+1) \, \mathrm{d}x \leqslant \int_k^{k+1} f(x) \, \mathrm{d}x \leqslant \int_k^{k+1} f(k) \, \mathrm{d}x,$$

即 $f(k+1)\leqslant\int_{k}^{k+1}f(x)\mathrm{d}x\leqslant f(k)$。

($\text{II}$) 若取 $f(x)=\frac{1}{x}(x>0)$，显然 $f(x)$ 单调减少且非负，则由 ($\text{I}$) 知
$$\frac{1}{n+1}\leqslant\int_{n}^{n+1}\frac{1}{x}\mathrm{d}x\leqslant\frac{1}{n},$$

故
$$\int_{1}^{n+1}\frac{1}{x}\mathrm{d}x=\int_{1}^{2}\frac{1}{x}\mathrm{d}x+\int_{2}^{3}\frac{1}{x}\mathrm{d}x+\cdots+\int_{n}^{n+1}\frac{1}{x}\mathrm{d}x\leqslant 1+\frac{1}{2}+\cdots+\frac{1}{n},$$
$$1+\int_{1}^{n}\frac{1}{x}\mathrm{d}x=1+\int_{1}^{2}\frac{1}{x}\mathrm{d}x+\int_{2}^{3}\frac{1}{x}\mathrm{d}x+\cdots+\int_{n-1}^{n}\frac{1}{x}\mathrm{d}x\geqslant 1+\frac{1}{2}+\cdots+\frac{1}{n}.$$

又因为
$$\int_{1}^{n+1}\frac{1}{x}\mathrm{d}x=\ln x\Big|_{1}^{n+1}=\ln(1+n),$$
$$\int_{1}^{n}\frac{1}{x}\mathrm{d}x=\ln x\Big|_{1}^{n}=\ln n,$$

所以
$$\ln(1+n)\leqslant 1+\frac{1}{2}+\cdots+\frac{1}{n}\leqslant 1+\ln n.$$ ①

由 ① 式可知
$$\frac{\ln(1+n)}{\ln n}\leqslant\frac{1+\dfrac{1}{2}+\cdots+\dfrac{1}{n}}{\ln n}\leqslant\frac{1+\ln n}{\ln n},$$

又由于
$$\lim_{n\to\infty}\frac{1+\ln n}{\ln n}=\lim_{n\to\infty}\frac{1}{\ln n}+1=1,$$
$$\lim_{n\to\infty}\frac{\ln(1+n)}{\ln n}=\lim_{x\to+\infty}\frac{\ln(1+x)}{\ln x}\underset{\text{法则}}{\overset{\text{洛必达}}{=}}\lim_{x\to+\infty}\frac{\dfrac{1}{1+x}}{\dfrac{1}{x}}=1,$$

故由夹逼准则,可知
$$\lim_{n\to\infty}\frac{1+\dfrac{1}{2}+\cdots+\dfrac{1}{n}}{\ln n}=1.$$
</ExamExplanation>

</ExamSolution>
