# 第十六章 随机事件及其概率

## 本章方法速记

- 先把事件关系翻译成集合运算，再使用概率加法公式。
- 条件概率、乘法公式、全概率公式与 Bayes 公式是计算主线。
- 独立性要用乘法定义验证，互斥与独立不能混淆。
- 重复试验优先识别二项模型，复杂分组可用对立事件简化。

## 基础题

### 一、选择题

<ExamQuestion>

1. 设当事件 $A$ 与 $B$ 同时发生时，事件 $C$ 必发生，则 $(\quad)$.

<ExamChoices>
<ExamOption>A. $P(C) = P(AB)$</ExamOption>
<ExamOption>B. $P(C) = P(A \cup B)$</ExamOption>
<ExamOption>C. $P(C) \leqslant P(A) + P(B) - 1$</ExamOption>
<ExamOption>D. $P(C) \geqslant P(A) + P(B) - 1$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>D</ExamAnswer>

<ExamExplanation>
依题设，$AB \subset C$, 故
$1 \ge P(A \cup B) = P(A) + P(B) - P(AB) \ge P(A) + P(B) - P(C)$,
即 $P(C) \ge P(A) + P(B) - 1$. 故选 D.
仅由 $AB \subset C$ 不能推出 $P(C) = P(AB)$ 和 $P(C) = P(A \cup B)$.
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

2. 对任意两个事件 $A$ 和 $B$，若 $P(AB) = 0$，则 $(\quad)$.

<ExamChoices>
<ExamOption>A. $P(A)P(B) = 0$</ExamOption>
<ExamOption>B. $P(A-B) = P(A)$</ExamOption>
<ExamOption>C. $\overline{AB} = \varnothing$</ExamOption>
<ExamOption>D. $AB = \varnothing$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>B</ExamAnswer>

<ExamExplanation>
由 $P(AB) = 0$, 得 $P(A - B) = P(A) - P(AB) = P(A)$. 故选 B.
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

3. 设 $P(A) > 0, P(B) > 0, P(A \mid B) = P(A)$，则下列选项中不正确的是 $(\quad)$.

<ExamChoices>
<ExamOption>A. $A$ 与 $B$ 互不相容</ExamOption>
<ExamOption>B. $A$ 与 $B$ 相容</ExamOption>
<ExamOption>C. $P(B \mid A) = P(B)$</ExamOption>
<ExamOption>D. $P(\overline{A} \mid \overline{B}) = P(\overline{A})$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>A</ExamAnswer>

<ExamExplanation>
由 $P(A \mid B) = P(A)$ 知, $A, B$ 相互独立, 故选项 C 正确, $\bar{A}$ 与 $\bar{B}$ 也相互独立, 选项 D 正确.
因 $P(A) > 0, P(B) > 0$, 且 $A, B$ 相互独立, 知 $A, B$ 必不互不相容, 即相容, 故选项 B 正确. 故选 A.

**知识点与技巧：** ①若 $P(A) > 0, P(B) > 0$, 则当 $A, B$ 独立时, 有 $AB \neq \varnothing$, 即 $A, B$ 相容. 当 $AB = \varnothing$ 时, 有 $A$ 与 $B$ 不独立(见《2027 考研数学概率论与数理统计辅导讲义》).
简单地说, 在 $P(A) > 0, P(B) > 0$ 的条件下, $A, B$ 相互独立与 $A, B$ 互不相容不能同时成立.
②若 $A, B$ 相互独立且其概率均大于零, 则
$$
\begin{aligned}
P(B \mid A) &= P(B) \iff P(\bar{B} \mid A) = P(\bar{B}) \\
&\iff P(\bar{A} \mid B) = P(\bar{A}) \\
&\iff P(\bar{A} \mid \bar{B}) = P(\bar{A}).
\end{aligned}
$$
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

4. 设 $A, B, C$ 是三个相互独立的随机事件，且 $0 < P(C) < 1$，则下列四对事件中不相互独立的是 $(\quad)$.

<ExamChoices>
<ExamOption>A. $\overline{A \cup B}$ 与 $C$</ExamOption>
<ExamOption>B. $\overline{AC}$ 与 $\overline{C}$</ExamOption>
<ExamOption>C. $\overline{A-B}$ 与 $\overline{C}$</ExamOption>
<ExamOption>D. $\overline{AB}$ 与 $\overline{C}$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>B</ExamAnswer>

<ExamExplanation>
由 $A, B, C$ 相互独立, 知 $AB$ 与 $\bar{C}$ 相互独立, $A \cup B$ 与 $C$ 相互独立, $\overline{A-B}$ 与 $\bar{C}$ 相互独立, 故排除选项 A, C, D. 选项 B 正确.

**知识点与技巧：** 事件 $A, B, C$ 相互独立,“不重叠分组, 各自运算后仍独立”(见《2027 考研数学概率论与数理统计辅导讲义》).
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

5. 设 $0 < P(A) < 1, 0 < P(B) < 1$ 且 $P(A \mid B) + P(\overline{A} \mid \overline{B}) = 1$，则 $(\quad)$.

<ExamChoices>
<ExamOption>A. $A$ 与 $B$ 互不相容</ExamOption>
<ExamOption>B. $A$ 与 $B$ 相互独立</ExamOption>
<ExamOption>C. $A$ 与 $B$ 对立</ExamOption>
<ExamOption>D. $A$ 与 $B$ 不相互独立</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>B</ExamAnswer>

<ExamExplanation>
由 $1 - P(\bar{A} \mid \bar{B}) = P(A \mid \bar{B})$, 知 $P(A \mid \bar{B}) = P(A \mid \bar{B})$, 即
$$
\frac{P(A\bar{B})}{P(\bar{B})} = \frac{P(\overline{AB})}{P(\bar{B})} = \frac{P(A) - P(AB)}{1 - P(B)},
$$
故可得 $P(AB) = P(A)P(B)$, 即 $A, B$ 相互独立. 故选 B.
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

6. 设 $A, B$ 为任意两个事件，且 $A \subset B, P(B) > 0$，则下列选项中正确的是 $(\quad)$.

<ExamChoices>
<ExamOption>A. $P(A) < P(A \mid B)$</ExamOption>
<ExamOption>B. $P(A) \leqslant P(A \mid B)$</ExamOption>
<ExamOption>C. $P(A) > P(A \mid B)$</ExamOption>
<ExamOption>D. $P(A) \geqslant P(A \mid B)$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>B</ExamAnswer>

<ExamExplanation>
由 $A \subset B$, 得 $AB = A, P(B) \leqslant 1$, 故
$$
P(A \mid B) = \frac{P(AB)}{P(B)} = \frac{P(A)}{P(B)} \geqslant P(A),
$$
选项 B 正确.
当 $P(B) = 1$ 时, 选项 A 不正确; 当 $P(B) < 1$ 时, 选项 C 和 D 不正确.
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

7. 设 $A, B$ 是两个随机事件，且 $0 < P(A) < 1, P(B) > 0, P(B \mid A) = P(B \mid \overline{A})$，则下列选项中正确的是 $(\quad)$.

<ExamChoices>
<ExamOption>A. $P(A \mid B) = P(\overline{A} \mid B)$</ExamOption>
<ExamOption>B. $P(A \mid B) \neq P(\overline{A} \mid B)$</ExamOption>
<ExamOption>C. $P(AB) = P(A)P(B)$</ExamOption>
<ExamOption>D. $P(AB) \neq P(A)P(B)$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>C</ExamAnswer>

<ExamExplanation>
由 $P(B \mid A) = P(B \mid \bar{A})$, 得 $\frac{P(AB)}{P(A)} = \frac{P(B\bar{A})}{P(\bar{A})} = \frac{P(B) - P(AB)}{1 - P(A)}$, 故 $P(AB) = P(A)P(B)$,
选项C正确.
此时,$A,B$ 相互独立, 所以
$$P(A \mid B) = P(A), P(\bar{A} \mid B) = P(\bar{A}).$$
由于 $0 < P(A) < 1$, 所以选项A和B不一定成立.
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

### 二、填空题

<ExamQuestion>

1. 设 $P(A \mid B) = P(B \mid A) = \frac{1}{2}, P(A) = \frac{1}{3}$，则 $P(A \cup B) = $ _______.

<ExamSolution>

<ExamAnswer>$\frac{1}{2}$</ExamAnswer>

<ExamExplanation>
由已知, 得 $P(AB) = P(A)P(B \mid A) = \frac{1}{3} \times \frac{1}{2} = \frac{1}{6}$. 又 $P(AB) = P(B)P(A \mid B)$, 知 $P(B) = \frac{1}{3}$, 故
$$P(A \cup B) = P(A) + P(B) - P(AB) = \frac{1}{3} + \frac{1}{3} - \frac{1}{6} = \frac{1}{2}.$$
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

2. 设事件 $A, B, C$ 满足 $P(A) = P(B) = P(C) = \frac{1}{4}, P(AB) = P(BC) = 0, P(AC) = \frac{1}{8}$，则 $A, B, C$ 三个事件中至少出现一个的概率为 _______.

<ExamSolution>

<ExamAnswer>$\frac{5}{8}$</ExamAnswer>

<ExamExplanation>
由 $ABC \subset AB$, 知 $P(ABC) \leqslant P(AB) = 0$, 所以 $P(ABC) = 0$, 故所求概率为
$$
\begin{aligned}
P(A \cup B \cup C) &= P(A) + P(B) + P(C) - P(AB) - P(AC) - P(BC) + P(ABC) \\
&= \frac{1}{4} + \frac{1}{4} + \frac{1}{4} - 0 - \frac{1}{8} - 0 + 0 = \frac{5}{8}.
\end{aligned}
$$
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

3. 设 $P(A) = 0.1, P(B \mid A) = 0.9, P(B \mid \bar{A}) = 0.2$，则 $P(A \mid B) = $ _______.

<ExamSolution>

<ExamAnswer>$\frac{1}{3}$</ExamAnswer>

<ExamExplanation>
由条件概率公式, 有 $P(A \mid B) = \frac{P(AB)}{P(B)} = \frac{P(A)P(B \mid A)}{P(B)}$. 又
$$
\begin{aligned}
P(B) &= P(AB \cup \bar{A}B) = P(AB) + P(\bar{A}B) = P(A)P(B \mid A) + P(\bar{A})P(B \mid \bar{A}) \\
&= 0.1 \times 0.9 + (1 - 0.1) \times 0.2 = 0.27,
\end{aligned}
$$
故 $P(A \mid B) = \frac{1}{3}$.

**知识点与技巧：** $B = \Omega \cdot B = (A + \bar{A})B = AB + \bar{A}B$, $\Omega$ 表示全集, 且 $AB$ 与 $\bar{A}B$ 互不相容.
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

4. 设 $A, B$ 为随机事件，且 $P(\bar{A}) = 0.3, P(B) = 0.4, P(A - B) = 0.5$，则 $P(B \mid A \cup \bar{B}) = $ _______.

<ExamSolution>

<ExamAnswer>$\frac{1}{4}$</ExamAnswer>

<ExamExplanation>
由条件概率公式, 有
$$
\begin{aligned}
P(B \mid A \cup \bar{B}) &= \frac{P(B \cap (A \cup \bar{B}))}{P(A \cup \bar{B})} = \frac{P((AB) \cup (B\bar{B}))}{P(A \cup \bar{B})} \\
&= \frac{P(AB)}{P(A \cup \bar{B})} = \frac{P(A) - P(A\bar{B})}{P(A) + P(\bar{B}) - P(A\bar{B})} \\
&= \frac{P(A) - P(A - B)}{P(A) + P(\bar{B}) - P(A - B)} = \frac{0.2}{0.8} = \frac{1}{4}.
\end{aligned}
$$
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

5. 在区间 $(0, 1)$ 内任取两个数 $x, y$，则 $xy \le \frac{2}{9}$ 的概率为 _______.

<ExamSolution>

<ExamAnswer>$\frac{2}{9}\left(1 + \ln\frac{9}{2}\right)$</ExamAnswer>

<ExamExplanation>
设事件
$$
\begin{aligned}
A &= \left\{(x, y) \mid xy \leqslant \frac{2}{9}, 0 < x < 1, 0 < y < 1\right\}, \\
D &= \{(x, y) \mid 0 < x < 1, 0 < y < 1\},
\end{aligned}
$$

则事件 $A$ 的样本位于区域 $D_1$ 中, 如图 16-1 阴影部分所示, 由几何概型公式得
$$P(A)=\frac{S_{D_1}}{S_D}=\frac{2}{9}\times 1+\int_{\frac{2}{9}}^{1}\frac{2}{9x}\mathrm{d}x=\frac{2}{9}\left(1+\ln\frac{9}{2}\right).$$
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

6. 某人向同一目标独立重复射击，每次射击命中目标的概率为 $p (0 < p < 1)$，则此人第 $6$ 次射击恰好第 $2$ 次命中目标的概率为 _______.

### 三、解答题

<ExamQuestion>

1. 设事件 $A, B$ 相互独立，$A, C$ 互不相容，且 $P(A) = 0.4, P(B) = 0.3, P(C) = 0.4, P(B \mid C) = 0.2$，求下列概率：$(I) P(A \cup B)$； $(II) P(C \mid A \cup B)$； $(III) P(AB \mid \bar{C})$。

<ExamSolution>

<ExamAnswer>见解析</ExamAnswer>

<ExamExplanation>
$(\mathrm{I})\ P(A\cup B)=P(A)+P(B)-P(AB)=P(A)+P(B)-P(A)P(B)$
$$=0.4+0.3-0.4\times 0.3=0.58.$$

$(\mathrm{II}) \quad P(C\mid A\cup B)=\frac{P[C(A\cup B)]}{P(A\cup B)}=\frac{P(BC)}{P(A\cup B)}$
$$=\frac{P(C)P(B\mid C)}{P(A\cup B)}=\frac{0.4\times 0.2}{0.58}\approx 0.138.$$

$(\mathrm{III}) \quad P(AB\mid\bar{C})=\frac{P(A B \bar{C})}{P(\bar{C})}=\frac{P(AB)}{1-P(C)}$
$$=\frac{P(A)P(B)}{1-P(C)}=\frac{0.4\times 0.3}{1-0.4}=0.2.$$
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

2. 对某一目标依次进行了三次独立的射击，设第一、第二、第三次射击命中的概率分别为 $0.4, 0.5$ 和 $0.7$，求：
$(I)$ 三次射击中恰好有一次命中的概率；
$(II)$ 三次射击中至少有一次命中的概率。

<ExamSolution>

<ExamAnswer>见解析</ExamAnswer>

<ExamExplanation>
设 $A_i=\{\text{第 } i \text{ 次命中}\} (i=1,2,3)$, $B$ 为恰有一次命中, $C$ 为至少有一次命中, 则 $B=A_1\bar{A}_2\bar{A}_3\cup\bar{A}_1A_2\bar{A}_3\cup\bar{A}_1\bar{A}_2A_3$, $C=A_1\cup A_2\cup A_3$.

$(\mathrm{I})$ 由已知, $A_1, A_2, A_3$ 相互独立且互不相容, 故
$$P(B)=P(A_1\bar{A}_2\bar{A}_3)+P(\bar{A}_1A_2\bar{A}_3)+P(\bar{A}_1\bar{A}_2A_3)$$
$$=P(A_1)P(\bar{A}_2)P(\bar{A}_3)+P(\bar{A}_1)P(A_2)P(\bar{A}_3)+P(\bar{A}_1)P(\bar{A}_2)P(A_3)$$
$$=0.4\times 0.5\times 0.3+0.6\times 0.5\times 0.3+0.6\times 0.5\times 0.7=0.36.$$

$(\mathrm{II}) \quad P(C)=P(A_1\cup A_2\cup A_3)=1-P(\overline{A_1\cup A_2\cup A_3})=1-P(\bar{A}_1\bar{A}_2\bar{A}_3)$
$$=1-P(\bar{A}_1)P(\bar{A}_2)P(\bar{A}_3)=1-0.6\times 0.5\times 0.3=0.91.$$
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

1. 设某人毫无准备地参加一项测验，其中有 5 道是非题，他随机地选择“是”或“非”，则该人至少答对 1 题的概率为（ ）。

<ExamChoices>

<ExamOption>B. $\frac{1}{32}$</ExamOption>
<ExamOption>C. $\frac{5}{32}$</ExamOption>

</ExamChoices>

<ExamSolution>

<ExamAnswer>D</ExamAnswer>

<ExamExplanation>

$$P\left(\bigcup_{i=1}^5 A_i\right)=1-P\left(\bigcap_{i=1}^5 \bar{A}_i\right)=1-\prod_{i=1}^5 P(\bar{A}_i)=1-\left(\frac{1}{2}\right)^5=\frac{31}{32}.$$

选项 D 正确。
</ExamExplanation>

2. 有一根长为 $L$ 的木棒，将其任意折成三段，记事件 $A = \{\text{中间一段为三段中的最长者}\}$, 则 $P(A) = (\quad)$.

<ExamChoices>
<ExamOption>A. $\frac{1}{2}$</ExamOption>

<ExamOption>C. $\frac{1}{4}$</ExamOption>

$$\Omega=\{(x,y)\mid 0\leqslant x\leqslant L, 0\leqslant y\leqslant L, 0\leqslant x+y\leqslant L\}.$$

事件 $A$ 相应的子区域 $\Omega_1$ 应满足 $0<x<L-x-y, 0<y<L-x-y$, 即
$$\Omega_1=\left\{(x,y)\mid 0<y<L-2x, 0<y<\frac{1}{2}(L-x)\right\}.$$

如图 16-2 所示, 可知 $\Omega$ 的面积为 $\frac{1}{2}L^2$, $\Omega_1$ 的面积为 $\frac{1}{6}L^2$, 故
$$P(A)=\frac{\frac{1}{6}L^2}{\frac{1}{2}L^2}=\frac{1}{3}.$$

$\frac{1}{3}$.选项 B 正确。
</ExamExplanation>

</ExamSolution>

### 二、填空题

<ExamQuestion>

1. 设甲、乙两人独立地对同一目标射击一次，其命中率分别为 $0.5$ 和 $0.4$，已知目标被命中，则它是乙射中的概率为 $\underline{\quad\quad\quad\quad}$。

<ExamSolution>

<ExamAnswer>$\frac{4}{7}$</ExamAnswer>

<ExamExplanation>
设 $A = \{\text{甲射击一次命中目标}\}, B = \{\text{乙射击一次命中目标}\}$,由已知,得所求概率为 $P(B \mid A \cup B) = \frac{P(B(A \cup B))}{P(A \cup B)} = \frac{P(B)}{P(A \cup B)}$,其中 $A \cup B$ 表示目标被命中.又
$$P(A \cup B) = P(A) + P(B) - P(AB) = P(A) + P(B) - P(A)P(B)$$
$$= 0.5 + 0.4 - 0.5 \times 0.4 = 0.7,$$
故 $P(B \mid A \cup B) = \frac{0.4}{0.7} = \frac{4}{7}$.
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

2. 设 $A,B$ 是两个随机事件，$0 < P(B) < 1, AB = \overline{AB}$，则 $P(\bar{A}|B) + P(A|\bar{B}) = \underline{\quad\quad\quad\quad}$。

<ExamSolution>

<ExamAnswer>$2$</ExamAnswer>

<ExamExplanation>
由 $AB = \overline{A}\overline{B}$,知 $(AB)(\overline{A}\overline{B}) = A\bar{A}B\bar{B} = \varnothing$,而 $(AB)(\overline{A}\overline{B}) = AB = \overline{A}\overline{B}$,所以 $\overline{A}\overline{B} = \varnothing$.又由对偶律 $\overline{A}\overline{B} = \overline{A \cup B} = \varnothing$,故 $A \cup B = \Omega$ ($\Omega$ 表示全集),从而 $A$ 与 $B$ 为对立事件(因 $AB = \varnothing$),于是 $A = \overline{B}, \overline{A} = B$,故 $P(\overline{A} \mid B) + P(A \mid \overline{B}) = 2$.
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

3. 设进行一系列独立试验，每次试验成功的概率均为 $p$，则在试验成功 $2$ 次之前已经失败 $3$ 次的概率为 $\underline{\quad\quad\quad\quad}$。

<ExamSolution>

<ExamAnswer>$4p^2(1 - p)^3$</ExamAnswer>

<ExamExplanation>

$$P(B_3) = C_4^3 p(1 - p)^3 = 4p(1 - p)^3, P(A_5) = p,$$
故
$$P(A) = P(A_5 B_3) = P(A_5) \cdot P(B_3) = 4p^2(1 - p)^3.$$

<ExamSolution>

<ExamAnswer>$\frac{2}{15}$</ExamAnswer>

$$P(A_1) = C_n^1 p q^{n-1} + C_n^3 p^3 q^{n-3} + C_n^5 p^5 q^{n-5} + \cdots,$$

$$P(A_2) - P(A_1) = (q - p)^n = (1 - 2p)^n,$$
两式相减,得所求概率为 $P(A_1) = \frac{1}{2}[1 - (1 - 2p)^n]$.

1. 设甲盒中有 4 个红球和 2 个白球，乙盒中有 2 个红球和 4 个白球，掷一枚均匀的硬币，若正面出现，则从甲盒中任取一球，若反面出现，则从乙盒中任取一球，设每次取出的球观看颜色后放回原盒中.

($I$) 若前两次都取得红球，求第三次也取得红球的概率；

($II$) 若前两次都取得红球,求红球都来自甲盒的概率.

<ExamSolution>

<ExamAnswer>见解析</ExamAnswer>

<ExamExplanation>
(I) 设 $A_i = \{\text{第 } i \text{ 次取得红球}\} (i = 1, 2, 3), B_j = \{\text{第 } j \text{ 次掷硬币出现正面}\} (j = 1, 2, 3)$.
依题设,易知 $B_j$ 为第 $j$ 次从甲盒中取球.将“掷一次硬币,再由硬币出现的结果从相应的盒中取出”看作一次试验,则每次试验都是重复的,且相互独立,所以它的结果 $A_1, A_2, A_3$ 是相互独立的,且
$$P(A_i) = P(A_1), i = 1, 2, 3,$$
故所求概率为 $P(A_3 \mid A_1 A_2) = P(A_3) = P(A_1)$.
又由全概率公式,得
$$P(A_1) = P(B_1)P(A_1 \mid B_1) + P(\overline{B_1})P(A_1 \mid \overline{B_1})$$
$$= \frac{1}{2} \times \frac{4}{6} + \frac{1}{2} \times \frac{2}{6} = \frac{1}{2},$$

故 $P(A_3 \mid A_1 A_2) = \frac{1}{2}$。

$(\text{II})$ 由于两次试验是独立重复的，所以 $A_1 B_1$ 与 $A_2 B_2$ 是相互独立的，且
$$P(A_2 B_2) = P(A_1 B_1) = P(B_1)P(A_1 \mid B_1) = \frac{1}{2} \times \frac{4}{6} = \frac{1}{3}.$$

由条件概率公式得
$$P(B_1 B_2 \mid A_1 A_2) = \frac{P(A_1 A_2 B_1 B_2)}{P(A_1 A_2)} = \frac{P(A_1 B_1)P(A_2 B_2)}{P(A_1)P(A_2)} = \frac{\left(\frac{1}{3}\right)^2}{\left(\frac{1}{2}\right)^2} = \frac{4}{9}.$$
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

2. 设一批产品中有 $15\%$ 的次品，进行独立重复抽样检验，若抽取 20 个样品，则抽出的 20 个样品中，可能性最大的次品数是多少？并求其概率.

<ExamSolution>

<ExamAnswer>见解析</ExamAnswer>

<ExamExplanation>
设 $X = \{\text{抽取 } 20 \text{ 个样品中的次品数}\}$，则 $X \sim B(20, 0.15)$。所求问题是，当 $k$ 为多少时，$P\{X = k\} = C_{20}^k \times 0.15^k \times (1 - 0.15)^{20-k} (k = 0, 1, \cdots, 20)$ 最大。

设当 $k = k_0$ 时，$P\{x = k\}$ 最大，则有
$$P\{X = k_0\} \geqslant P\{X = k_0 - 1\}, \quad P\{X = k_0\} \geqslant P\{X = k_0 + 1\},$$

考虑任意两项的比值，
$$\frac{P\{X = k\}}{P\{X = k - 1\}} = \frac{C_{20}^k \times 0.15^k \times 0.85^{20-k}}{C_{20}^{k-1} \times 0.15^{k-1} \times 0.85^{20-k+1}} = \frac{(20 - k + 1) \times 0.15}{0.85 \times k},$$

则 $P\{X = k\} \geqslant P\{X = k - 1\}$，当且仅当 $k \leqslant (20 + 1) \times 0.15 = 3.15$。

同理，$P\{X = k\} \geqslant P\{X = k + 1\}$，当且仅当 $k \geqslant (20 + 1) \times 0.15 - 1 = 2.15$，故当 $P\{X = k\}$ 最大时，$k = 3$，且 $P\{X = 3\} = C_{20}^3 \times 0.15^3 \times 0.85^{17} \approx 0.242 8$。

**知识点与技巧：** 本题是求二项分布中最大可能目标数，一般结论是：若 $X \sim B(n, p)$，如果 $(n+1)p$ 不是整数，则当 $k = [(n+1)p]$（向下取整）时，$P\{X = k\}$ 取得最大值；如果 $(n+1)p$ 是整数，则当 $k = (n+1)p$ 或 $k = (n+1)p-1$ 时，$P\{X = k\}$ 取得最大值。如本题，$[(20+1) \times 0.15] = [3.15] = 3$。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>
