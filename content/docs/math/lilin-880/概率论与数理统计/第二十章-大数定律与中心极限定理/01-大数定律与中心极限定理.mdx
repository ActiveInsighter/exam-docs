# 第二十章 大数定律与中心极限定理

## 本章方法速记

- 大数定律处理样本平均的概率收敛，中心极限定理处理标准化和的近似分布。
- 独立同分布且方差有限时，优先使用经典 CLT 标准化。
- 二项分布在参数较大时可用正态近似，注意均值和方差。
- 题目问“概率趋于”与“近似概率”时要区分 LLN 与 CLT。

## 基础题

### 一、选择题

<ExamQuestion>

1. 设 $X_1, X_2, \cdots, X_n$ 是总体 $X$ 的简单随机样本，且 $E(X^k) = a_k, k=1, 2, 3, 4$，根据中心极限定理，当 $n$ 充分大时，$Y_n = \frac{1}{n} \sum_{i=1}^{n} X_i^2$ 近似服从（ ）。

<ExamChoices>
<ExamOption>A. $N\left(a_2, \frac{a_4-a_2^2}{n}\right)$</ExamOption>
<ExamOption>B. $N(a_2, a_4-a_2^2)$</ExamOption>
<ExamOption>C. $N\left(a_1, \frac{a_4-a_2^2}{n}\right)$</ExamOption>
<ExamOption>D. $N(a_2, a_2^2)$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>A</ExamAnswer>

<ExamExplanation>
由已知,得 $X_1, X_2, \cdots, X_n$ 独立同分布,故 $X_1^2, X_2^2, \cdots, X_n^2$ 也独立同分布.又
$$E(X_1^2) = a_2,$$
得
$$D(X_1^2) = E(X_1^4) - [E(X_1^2)]^2 = a_4 - a_2^2.$$
根据独立同分布的中心极限定理,可知
$$Z_n \overset{\text{记}}{=} \frac{\sum\limits_{i=1}^n X_i^2 - n a_2}{\sqrt{n(a_4 - a_2^2)}} = \frac{\frac{1}{n}\sum\limits_{i=1}^n X_i^2 - a_2}{\sqrt{\frac{1}{n}(a_4 - a_2^2)}} = \frac{Y_n - a_2}{\sqrt{\frac{1}{n}(a_4 - a_2^2)}}$$
的极限分布为标准正态分布,故当 $n$ 充分大时, $Z_n$ 近似服从标准正态分布,所以 $Y_n$ 服从 $N\left(a_2, \frac{a_4 - a_2^2}{n}\right)$.
故选 A.
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

2. 设随机变量 $X_1, X_2, \cdots, X_n$ 相互独立，记 $Y_n = X_1 + X_2 + \cdots + X_n$，根据列维-林德伯格中心极限定理，$Y_n$ 近似服从正态分布（$n$ 充分大），则只要 $X_1, X_2, \cdots, X_n$（ ）。

<ExamChoices>
<ExamOption>A. 服从同一离散型分布</ExamOption>
<ExamOption>B. 服从同一连续型分布</ExamOption>
<ExamOption>C. 服从同一指数分布</ExamOption>
<ExamOption>D. 具有相同的期望与方差</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>C</ExamAnswer>

<ExamExplanation>
列维-林德伯格中心极限定理的条件是 $X_1, X_2, \cdots, X_n$ 独立同分布,且期望与方差均存在.
满足选项 A 和 B 的随机变量的期望或方差不一定存在,故排除选项 A 和 B.
对于选项 D,有相同的期望与方差未必有相同的分布,故排除选项 D.
只有选项 C 正确,指数分布的期望与方差均存在.故选 C.
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

3. 设 $X_1, X_2, \cdots, X_n$ 是独立同分布的随机变量序列，且 $E(X_i^2) < +\infty$，则对任意 $\varepsilon$ 有（ ）。

<ExamChoices>
<ExamOption>A. $\lim_{n\to\infty} P\left\{\left|\frac{1}{n}\sum_{i=1}^n X_i^2\right| < \varepsilon\right\} = 0$</ExamOption>
<ExamOption>B. $\lim_{n\to\infty} P\left\{\left|\frac{1}{n}\sum_{i=1}^n X_i^2 - E(X_i^2)\right| < \varepsilon\right\} = 0$</ExamOption>
<ExamOption>C. $\lim_{n\to\infty} P\left\{\left|\frac{1}{n}\sum_{i=1}^n X_i^2 - E(X_i^2)\right| < \varepsilon\right\} = 1$</ExamOption>
<ExamOption>D. $\lim_{n\to\infty} P\left\{\left|\frac{1}{n}\sum_{i=1}^n X_i^2\right| \ge \varepsilon\right\} = 0$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>C</ExamAnswer>

<ExamExplanation>
依题设,可知 $X_1^2, X_2^2, \cdots, X_n^2$ 独立同分布,根据辛钦大数定律
$$\lim_{n\to\infty} P\left\{\left|\frac{1}{n}\sum_{i=1}^n X_i^2 - E(X_i^2)\right| < \varepsilon\right\} = 1,$$
即样本的二阶原点矩依概率收敛于随机变量的二阶原点矩.故选 C.
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

### 二、填空题

<ExamQuestion>

1. 设随机变量 $X_i$ 服从二项分布 $B(1, 0.2), i=1, 2, \cdots, 10$，且 $X_1, X_2, \cdots, X_{10}$ 相互独立，则根据切比雪夫不等式，有 $P\left\{6 < \sum_{i=1}^{10} X_i < 16\right\} \geqslant$ ______ 。

<ExamSolution>

<ExamAnswer>$0.648$</ExamAnswer>

<ExamExplanation>
由 $X_1, X_2, \cdots, X_{10}$ 相互独立,及 $X_i \sim B(i, 0.2)$,可知 $\sum_{i=1}^{10} X_i \sim B(55, 0.2)$,所以
$$E\left(\sum_{i=1}^{10} X_i\right) = 11, \quad D\left(\sum_{i=1}^{10} X_i\right) = 8.8,$$
故
$$P\left\{6 < \sum_{i=1}^{10} X_i < 16\right\} = P\left\{\left|\sum_{i=1}^{10} X_i - 11\right| < 5\right\} \ge 1 - \frac{8.8}{5^2} = 0.648.$$
**知识点与技巧：** ① 在独立的条件下,二项分布具有可加性,即 $X \sim B(m, p), Y \sim B(n, p)$,且 $X$ 与 $Y$ 相互独立,则 $X+Y \sim B(m+n, p)$.
② 切比雪夫不等式: $$P\{|X - EX| < \varepsilon\} \ge 1 - \frac{DX}{\varepsilon^2}.$$
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

2. 设 $X$ 与 $Y$ 满足：$EX = -2, EY = 2, DX = 1, DY = 4, \rho_{XY} = -\frac{1}{2}$，则根据切比雪夫不等式，有 $P\{|X+Y| \ge 6\} \leqslant$ ______ 。

<ExamSolution>

<ExamAnswer>$\frac{1}{12}$</ExamAnswer>

<ExamExplanation>
$$E(X + Y) = EX + EY = -2 + 2 = 0,$$
$$D(X + Y) = DX + DY + 2\rho_{XY}\sqrt{DX \cdot DY}$$

$$= 1 + 4 - 2 \times \frac{1}{2} \times 2 = 3,$$

故

$$P\{ | X + Y - 0 | \geqslant 6 \} \leqslant \frac{3}{36} = \frac{1}{12}.$$
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

3. 设 $X$ 在区间 $[-1, b]$ 上服从均匀分布，由切比雪夫不等式有 $P\{|X-1| < \varepsilon\} \ge \frac{2}{3}$，则 $b=$ ______ ， $\varepsilon =$ ______ 。

<ExamSolution>

<ExamAnswer>$3, 2.$</ExamAnswer>

<ExamExplanation>
由已知, 有 $\mathrm{EX} = \frac{b-1}{2}, \mathrm{DX} = \frac{(b+1)^2}{12}.$ 又 $P\{ | X - \mathrm{EX} | < \varepsilon \} \ge 1 - \frac{\mathrm{DX}}{\varepsilon^2}.$

而已知

$$P\{ | X - 1 | < \varepsilon \} \ge \frac{2}{3},$$

故 $\mathrm{EX} = 1 = \frac{b-1}{2}$, 得 $b = 3, \mathrm{DX} = \frac{16}{12} = \frac{4}{3}$, 所以 $1 - \frac{\mathrm{DX}}{\varepsilon^2} = \frac{2}{3}$, 故 $\varepsilon = 2.$
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

4. 设随机变量 $X_1, X_2, \cdots, X_n$ 相互独立，且均服从 $B\left(1, \frac{1}{2}\right)$。若存在常数 $k$，使得
$$\lim_{n\to\infty} P\left\{\frac{k\sum_{i=1}^n (X_{2i}-X_{2i-1})}{\sqrt{n}} \leqslant x\right\} = \Phi(x),$$
其中 $\Phi(x)$ 为 $N(0, 1)$ 的分布函数，则 $k=$ _________。

<ExamSolution>

<ExamAnswer>$\sqrt{2}.$</ExamAnswer>

<ExamExplanation>
记

$$Y_i = X_{2i} - X_{2i-1} \quad (i = 1, 2, \cdots).$$

由已知, 得 $X_i \sim \begin{pmatrix} 0 & 1 \\ \frac{1}{2} & \frac{1}{2} \end{pmatrix}$ 且相互独立, 知 $Y_i (i = 1, 2, \cdots)$ 也相互独立且服从同一分布, 故

$$Y_i = X_{2i} - X_{2i-1} \sim \begin{pmatrix} -1 & 0 & 1 \\ \frac{1}{4} & \frac{1}{2} & \frac{1}{4} \end{pmatrix},$$

$$\mathrm{EY}_i = 0, \quad \mathrm{DY}_i = \mathrm{DX}_{2i} + \mathrm{DX}_{2i-1} = \frac{1}{4} + \frac{1}{4} = \frac{1}{2},$$

由独立同分布的中心极限定理, 有

$$\lim_{n\to\infty} P\left\{ \frac{\sum\limits_{i=1}^n Y_i - E\left(\sum\limits_{i=1}^n Y_i\right)}{\sqrt{D\left(\sum\limits_{i=1}^n Y_i\right)}} \leqslant x \right\} = \lim_{n\to\infty} P\left\{ \frac{\sum\limits_{i=1}^n Y_i}{\sqrt{\frac{n}{2}}} \leqslant x \right\}$$

$$= \lim_{n\to\infty} P\left\{ \frac{\sqrt{2}\sum\limits_{i=1}^n (X_{2i} - X_{2i-1})}{\sqrt{n}} \leqslant x \right\} = \Phi(x).$$

所以, $k = \sqrt{2}.$
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

### 三、解答题

<ExamQuestion>

1. 设一条生产线的合格率为 $0.8$，要使一批产品的合格率在 $76\%$ 与 $84\%$ 之间的概率不小于 $90\%$，可这批产品至少要生产多少件？

<ExamSolution>

<ExamAnswer>见解析</ExamAnswer>

<ExamExplanation>
解法 1：** 设至少要生产 $m$ 件产品, 记随机变量 $X$ 为 $m$ 件产品中合格品的件数, 则依题设, $X \sim B(m, 0.8)$, 现要确定 $m$, 使之满足 $P\left\{ 0.76 < \frac{X}{m} < 0.84 \right\} \ge 0.90$, 利用切比雪夫不等式, 得

$$P\left\{ 0.76 < \frac{X}{m} < 0.84 \right\} = P\{ | X - 0.8m | < 0.04m \}$$

$$\ge 1 - \frac{0.8m \times 0.2}{(0.04m)^2} = 1 - \frac{100}{m} \ge 0.90,$$

故 $m \ge 1000$, 即至少要生产 $1000$ 件才能满足要求.

**解法 2：** 利用棣莫弗 - 拉普拉斯定理估计 $m$ 的值. 当 $n$ 比较大时, $X$ 近似服从正态分布 $N(0.8m, 0.16m)$, 故

$$P\left\{ 0.76 < \frac{X}{m} < 0.84 \right\} = P\left\{ \frac{X - 0.8m}{0.4\sqrt{m}} < \frac{0.04m}{0.4\sqrt{m}} \right\}$$

$$\approx 2\Phi(0.1\sqrt{m}) - 1 \ge 0.90.$$

查正态分布表可得, $0.1\sqrt{m} \ge 1.65$, 解得 $m \ge 272.25$, 故 $m$ 至少为 $273$.

**知识点与技巧：** 比较解法 1 与解法 2, 可知中心极限定理比切比雪夫不等式要精确。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

2. 设随机变量序列 $X_1, X_2, \cdots, X_n$ 独立，$X_i$ 的分布律为

| $X_i$ | $-ia$ | $0$ | $ia$ |
| :---: | :---: | :---: | :---: |
| $p$ | $\frac{1}{2i^2}$ | $1-\frac{1}{i^2}$ | $\frac{1}{2i^2}$ |

其中 $i=1,2, \cdots, n$，利用大数定律证明：$\lim_{n\to\infty} P\left\{\left|\frac{1}{n}\sum_{i=1}^n X_i\right| \geqslant \varepsilon\right\} = 0$。

<ExamSolution>

<ExamAnswer>见解析</ExamAnswer>

<ExamExplanation>
先验证满足大数定律的条件,
由已知
$$EX_i = 0, E(X_i^2) = \frac{2i^2 a^2 \times 1}{2i^2} = a^2,$$
所以
$$E\left(\frac{1}{n}\sum_{i=1}^n X_i\right) = \frac{1}{n}\sum_{i=1}^n EX_i = 0,$$
$$D\left(\frac{1}{n}\sum_{i=1}^n X_i\right) = \frac{1}{n^2}\sum_{i=1}^n DX_i = \frac{a^2}{n},$$
满足切比雪夫大数定律条件, 故
$$\lim_{n\to\infty} P\left\{\left|\frac{1}{n}\sum_{i=1}^n X_i - 0\right| < \varepsilon\right\} = 1,$$
即
$$\lim_{n\to\infty} P\left\{\left|\frac{1}{n}\sum_{i=1}^n X_i\right| \ge \varepsilon\right\} = 0.$$
</ExamExplanation>

</ExamSolution>

</ExamQuestion>
