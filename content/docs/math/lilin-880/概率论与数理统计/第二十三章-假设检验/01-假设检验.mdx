# 第二十三章 假设检验

## 本章方法速记

- 先明确原假设 $H_0$、备择假设 $H_1$ 与显著性水平 $\alpha$。
- 拒绝域由统计量在 $H_0$ 下的分布决定，单双侧检验临界值不同。
- “不拒绝 $H_0$”不等于“证明 $H_0$ 正确”。
- 正态总体均值/方差检验要根据方差已知与否选择 $Z$、$t$ 或 $\chi^2$ 统计量。

## 基础题

### 一、选择题

<ExamQuestion>

1. 在假设检验中，检验水平 $\alpha$ 的意义是 $(\quad)$.

<ExamChoices>
<ExamOption>A. 原假设 $H_0$ 成立，经检验 $H_0$ 被拒绝的概率</ExamOption>
<ExamOption>B. 原假设 $H_0$ 成立，经检验 $H_0$ 不能被拒绝的概率</ExamOption>
<ExamOption>C. 原假设 $H_0$ 不成立，经检验 $H_0$ 被拒绝的概率</ExamOption>
<ExamOption>D. 原假设 $H_0$ 不成立，经检验 $H_0$ 不能被拒绝的概率</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>A</ExamAnswer>

<ExamExplanation>
由 $P\{\text{拒绝 } H_0 \mid H_0 \text{ 为真}\} = \alpha$，知选项 A 正确。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

2. 设 $X_1, X_2, \cdots, X_n$ 为来自总体 $X \sim N(\mu, 1)$ 的简单随机样本，$\overline{X}$ 为样本均值，对于假设检验 $H_0: \mu = \mu_0$，若取拒绝域 $R_\alpha = \left\{ \overline{X} > \mu_0 + \frac{1.96}{\sqrt{n}} \right\}$，$\Phi(x)$ 为 $N(0, 1)$ 的分布函数，则该检验犯第一类错误的概率 $\alpha$ 为 $(\quad)$.

<ExamChoices>
<ExamOption>A. $1 - \Phi(0.04)$</ExamOption>
<ExamOption>B. $1 - \Phi(0.05)$</ExamOption>
<ExamOption>C. $1 - \Phi(1.96)$</ExamOption>
<ExamOption>D. $1 - \Phi(1)$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>C</ExamAnswer>

<ExamExplanation>
由已知，得犯第一类错误的概率，即
$$\alpha = P\{\text{否定 } H_0 \mid H_0 \text{ 为真}\} = P\left\{\left. \overline{X} > \mu_0 + \frac{1.96}{\sqrt{n}} \right| \mu = \mu_0 \right\}.$$

当 $\mu = \mu_0$ 成立时，总体 $X \sim N(\mu_0, 1)$，$\overline{X} \sim N\left(\mu_0, \frac{1}{n}\right)$。

故
$$\alpha = P\left\{\overline{X} > \mu_0 + \frac{1.96}{\sqrt{n}}\right\} = 1 - P\left\{\frac{\overline{X} - \mu_0}{\sqrt{\frac{1}{n}}} \leqslant 1.96\right\} = 1 - \Phi(1.96).$$

选项 C 正确。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

### 二、填空题

<ExamQuestion>

1. 设总体 $X \sim N(\mu, \sigma^2)$，$(X_1, X_2, \cdots, X_n)$ 为 $X$ 的简单随机样本，其中 $\mu, \sigma^2$ 未知，$\overline{X} = \frac{1}{n} \sum_{i=1}^{n} X_i$，$Q^2 = \sum_{i=1}^{n} (X_i - \overline{X})^2$，则假设 $H_0: \mu = 0$ 的 $t$ 检验统计量 $T = \underline{\quad\quad\quad\quad}$．

<ExamSolution>

<ExamAnswer>$\frac{\overline{X}\sqrt{n}(n - 1)}{Q}$</ExamAnswer>

<ExamExplanation>
当 $H_0$ 成立时，有 $\dfrac{\overline{X} - 0}{\sigma/\sqrt{n}} \sim N(0, 1)$，而 $\dfrac{(n - 1)S^2}{\sigma^2} \sim \chi^2(n - 1)$，

即 $\dfrac{Q^2}{\sigma^2} \sim \chi^2(n - 1)$，且相互独立，故 $T = \dfrac{\dfrac{\overline{X}}{\sigma/\sqrt{n}}}{\sqrt{\dfrac{Q^2}{\sigma^2(n - 1)}}} = \frac{\overline{X}\sqrt{n}(n - 1)}{Q} \sim t(n - 1)$。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

2. 设 $X_1, X_2, \cdots, X_n$ 为来自总体 $X \sim N(\mu, \sigma^2)$ 的简单随机样本，$\sigma^2$ 未知，$\overline{X}$ 为样本均值，$S^2$ 为样本方差，检验水平为 $\alpha$，则 $H_0: \mu \geqslant \mu_0$，$H_1: \mu < \mu_0$ 的拒绝域为 $\underline{\quad\quad\quad\quad}$．

<ExamSolution>

<ExamAnswer>$R_\alpha = \left\{ \frac{\overline{X} - \mu_0}{\dfrac{S}{\sqrt{n}}} < -t_\alpha(n - 1) \right\}$</ExamAnswer>

<ExamExplanation>
方差 $\sigma^2$ 未知，检验均值 $\mu$，应用 $t$ 检验法，因 $H_1$ 是单边的，故是单边检验。

在 $H_0$ 成立的条件下，$T = \dfrac{\overline{X} - \mu_0}{\dfrac{S}{\sqrt{n}}} \sim t(n - 1)$。

对于给定的检验水平 $\alpha$，使 $P\{T < -t_\alpha(n - 1)\} = \alpha$，故拒绝域为
$$R_\alpha = \{T < -t_\alpha(n - 1)\} = \left\{ \frac{\overline{X} - \mu_0}{\dfrac{S}{\sqrt{n}}} < -t_\alpha(n - 1) \right\}.$$
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

### 三、解答题

<ExamQuestion>

1. 设在一批圆木中随机抽取 $100$ 根，测其小头直径，得到样本平均值为 $\overline{x} = 11.2\text{cm}$，已知标准差 $\sigma = 2.6\text{cm}$，问在显著性检验水平 $\alpha = 0.05$ 下，该批圆木小头平均直径能否认为是在 $12\text{cm}$ 以上？（已知 $\Phi(1.645) = 0.95$）

<ExamSolution>

<ExamAnswer>见解析</ExamAnswer>

<ExamExplanation>
此题已知方差 $\sigma^2 = 2.6^2$，检验假设 $H_0: \mu \geqslant \mu_0 = 12$，$H_1: \mu < \mu_0 = 12$。

选用统计量 $U = \dfrac{\overline{X} - \mu_0}{\sigma / \sqrt{n}}$，将 $\overline{x} = 11.2, \mu_0 = 12, \sigma = 2.6, n = 100$
代入计算，得 $U = -3.08$，而 $\alpha = 0.05$，故 $\Phi(U_0) = 1 - \alpha = 0.95$，所以 $U_0 = 1.645$，从而
$-U_0 = -1.645, U = -3.08 < -1.645$，
故拒绝 $H_0$，即不能认为小头平均直径在 $12\text{ cm}$ 以上。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

2. 设某生产线生产袋装产品，正常情况下每袋 $1\text{ kg}$，标准差不超过 $15\text{ g}$，且每袋重量服从正态分布. 现检查机器生产情况，从中任取 $10$ 袋，测得其均值为 $\bar{x} = 998\text{ g}$，样本均方差为 $S = 30$，在显著性水平 $\alpha = 0.05$ 下，问机器生产是否正常?(已知 $\chi_{0.05}^2(9) = 16.919$)

<ExamSolution>

<ExamAnswer>见解析</ExamAnswer>

<ExamExplanation>
设 $H_0: \sigma^2 \leqslant 15^2, H_1: \sigma^2 > 15^2$，统计量为 $\chi^2 = \dfrac{(n - 1)S^2}{\sigma_0^2} \sim \chi^2(n - 1)$，
当 $\alpha = 0.05, \chi_{0.05}^2(9) = 16.919$ 时，拒绝域为 $ [16.919, +\infty)$。
又由于 $\dfrac{(n - 1)S^2}{\sigma_0^2} = \dfrac{9 \times 30^2}{15^2} = 36$，且 $36 \in [16.919, +\infty)$，故 $H_0$ 被拒绝，即机器生产不正常。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>
