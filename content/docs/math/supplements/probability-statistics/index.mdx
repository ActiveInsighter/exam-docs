概率统计最容易混淆的不是单个公式，而是随机事件、随机变量、分布、总体、样本、统计量和抽样分布等概念所处的层级。本组讲义专门用整体框架把这些概念串起来。

## 文档

1. [概率论与数理统计总览](./01-overview)：先建立概率论和数理统计各自研究什么、为什么需要抽样与推断的整体认识。
2. [概率论与数理统计知识链](./02-concept-chain)：按“随机现象 → 概率模型 → 随机变量 → 分布 → 总体 → 样本 → 统计量 → 抽样分布 → 统计推断”串联核心概念。

## 主教材入口

需要按随机事件、一维/二维随机变量、数字特征、极限定理、统计基础与参数估计等考研章节复习时，回到[概率论与数理统计核心知识](../../knowledge/probability-statistics/)。
