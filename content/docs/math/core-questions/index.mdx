# 考研核心题目

科目下的章名与顺序和数学真题一致，章内保留核心题目的细分专题。题目包含真题、补充练习和标注来源的变式题。每道题保留题干、选项、答案与解析，可先作答，再展开解析核对思路。

- [高等数学](/docs/math/core-questions/01-b69fd298)：9 个模块、47 个专题，共 1800 道题。
- [线性代数](/docs/math/core-questions/02-1c0ed78f)：5 章、29 个专题，共 649 道题。
- [概率论与数理统计](/docs/math/core-questions/03-611e560f)：5 章、29 个专题，共 570 道题。

高等数学沿用数学真题的 9 个模块；线性代数和概率统计各分为 5 章。核心题目覆盖更多细分练习专题，因此章内专题数量与数学真题不完全相同。
