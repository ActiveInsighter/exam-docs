# 1.3 条件概率与独立性

## 小题

1. **【1989-1-2 分】** 甲, 乙两人独立的对同一目标射击一次, 其命中率分别为0.6 和0.5, 现已知目标被命中, 则它是甲射中的概率是

<details>
<summary>查看答案与解析</summary>

**答案：** $\displaystyle \dfrac34$。

**解析：** 设甲、乙命中事件分别为 $A,B$，则 $\displaystyle P(A\cup B)=1-(1-0.6)(1-0.5)=0.8$，故 $\displaystyle P(A\mid A\cup B)=0.6/0.8=3/4$。

</details>

---

2. **【1993-5-3 分】** 设10 件产品有4 件不合格品, 从中任取两件, 已知所取两件产品中有一件是不合格品, 则另一件也是不合格品的概率为

<details>
<summary>查看答案与解析</summary>

**答案：** $\displaystyle \dfrac15$。

**解析：** “至少有一件不合格”的组合数为 $\displaystyle \binom{10}{2}-\binom62=30$，其中两件均不合格的组合数为 $\binom42=6$，故条件概率为 $6/30=1/5$。

</details>

---

3. **【1994-5-3 分】** 假设一批产品中一, 二, 三等品各占60%, 30%, 10%, 从中随意取出一件, 结果不是三等品, 则取到的是一等品的概率为

<details>
<summary>查看答案与解析</summary>

**答案：** $\displaystyle \dfrac23$。

**解析：** 在“不是三等品”的条件下，一等品与二等品的比例为 $60\%:30\%$，故概率为 $\displaystyle 0.6/(0.6+0.3)=2/3$。

</details>

4. **【1996-4-3 分】** 已知 $\displaystyle 0<P(B)<1$, $\displaystyle P[(A_1+A_2)|B]=P(A_1|B)+P(A_2|B)$, 则下列选项成立的是( ).

<div className="choice-options">
<div className="choice-option-row">A. $\displaystyle P[(A_1+A_2)|\bar{B}]=P(A_1|\bar{B})+P(A_2|\bar{B})$ &emsp;&emsp; B. $\displaystyle P(A_1B+A_2B)=P(A_1B)+P(A_2B)$</div>
<div className="choice-option-row">C. $\displaystyle P(A_1+A_2)=P(A_1|B)+P(A_2|B)$ &emsp;&emsp; D. $\displaystyle P(B)=P(A_1)P(B|A_1)+P(A_2)P(B|A_2)$</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** B。

**解析：** 题设条件说明在条件 $B$ 下，$A_1$ 与 $A_2$ 的交集概率为0，即 $\displaystyle P(A_1A_2B)=0$，所以 $A_1B$ 与 $A_2B$ 互不相容，从而选项 B 成立。

</details>

5. **【1996-5-3 分】** 设 A, B 为任意两个事件, 且 $\displaystyle A \subset B$, $\displaystyle P(B)>0$, 则下列选项必然成立的是( ).

<div className="choice-options">
<div className="choice-option-row">A. $\displaystyle P(A)<P(A|B)$ &emsp;&emsp; B. $\displaystyle P(A) \leq P(A|B)$</div>
<div className="choice-option-row">C. $\displaystyle P(A)>P(A|B)$ &emsp;&emsp; D. $\displaystyle P(A) \geq P(A|B)$</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** B。

**解析：** 因 $A\subset B$，$\displaystyle P(A\mid B)=P(A)/P(B)$。又 $0<P(B)\le1$，故 $\displaystyle P(A\mid B)\ge P(A)$。

</details>

6. **【2012-13-4 分】** 设 A, B, C 是随机事件, A 与 C 互不相容, $\displaystyle P(AB)=\dfrac{1}{2}$, $\displaystyle P(C)=\dfrac{1}{3}$ 则 $\displaystyle P(AB|\bar{C})=$

<details>
<summary>查看答案与解析</summary>

**答案：** $\displaystyle \dfrac34$。

**解析：** 由于 $A$ 与 $C$ 互不相容，$AB\subset A$ 也与 $C$ 互不相容，故 $\displaystyle P(AB\mid\bar C)=P(AB)/P(\bar C)=(1/2)/(2/3)=3/4$。

</details>

7. **【2016-3-4 分】** 设 A, B 为两个随机事件, 且 $\displaystyle 0<P(A)<1$, $\displaystyle 0<P(B)<1$, 如果 $\displaystyle P(A|B)=1$, 则( )

<div className="choice-options">
<div className="choice-option-row">A. $\displaystyle P(\bar{B}|\bar{A})=1$ &emsp;&emsp; B. $\displaystyle P(A|\bar{B})=0$ &emsp;&emsp; C. $\displaystyle P(A \cup B)=0$ &emsp;&emsp; D. $\displaystyle P(B|A)=1$</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** A。

**解析：** $\displaystyle P(A\mid B)=1$ 表明 $B\subset A$（按概率意义），取补得 $\bar A\subset\bar B$，所以 $\displaystyle P(\bar B\mid\bar A)=1$。

</details>

8. **【2017-1-4 分】** 设 A, B 为随机事件.若 $\displaystyle 0<P(A)<1$, $\displaystyle 0<P(B)<1$, 则 $\displaystyle P(A|B)>P(A|\bar{B})$ 的充分必要条件是( )

<div className="choice-options">
<div className="choice-option-row">A. $\displaystyle P(B|A)>P(B|\bar{A})$ &emsp;&emsp; B. $\displaystyle P(B|A)<P(B|\bar{A})$</div>
<div className="choice-option-row">C. $\displaystyle P(\bar{B}|A)>P(B|\bar{A})$ &emsp;&emsp; D. $\displaystyle P(\bar{B}|A)<P(B|\bar{A})$</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** A。

**解析：** 由全概率公式，$P(A)$ 是 $P(A\mid B)$ 与 $P(A\mid\bar B)$ 的加权平均；所给不等式等价于 A、B 正相关，也等价于 $\displaystyle P(B\mid A)>P(B\mid\bar A)$。

</details>

9. **【2021-13-5 分】** 设 A, B 为随机事件, 且 $\displaystyle 0<P(B)<1$, 下列命题中为假命题的是( )

<div className="choice-options">
<div className="choice-option-row">A. 若 $\displaystyle P(A|B)=P(A)$, 则 $\displaystyle P(A|\bar{B})=P(A)$</div>
<div className="choice-option-row">B. 若 $\displaystyle P(A|B)>P(A)$, 则 $\displaystyle P(\bar{A}|\bar{B})>P(\bar{A})$</div>
<div className="choice-option-row">C. 若 $\displaystyle P(A|B)>P(A|\bar{B})$, 则 $\displaystyle P(A|B)>P(A)$</div>
<div className="choice-option-row">D. 若 $\displaystyle P(A|A \cup B)>P(\bar{A}|A \cup B)$, 则 $\displaystyle P(A)>P(B)$</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** D。

**解析：** A、B、C 三项均可由全概率公式直接推出。D 的前提只说明在 $A\cup B$ 内 $A$ 的概率大于 $\bar A$ 的概率，并不能推出 $P(A)>P(B)$，故 D 为假命题。

</details>

10. **【1994-45-3 分】** 设 $\displaystyle 0<P(A)<1$, $\displaystyle 0<P(B)<1$, $\displaystyle P(A|B)+P(\bar{A}|\bar{B})=1$, 则( ).

<div className="choice-options">
<div className="choice-option-row">A. 事件 A 和 B 互不相容 &emsp;&emsp; B. 事件 A 和 B 互相对立</div>
<div className="choice-option-row">C. 事件 A 和 B 互不独立 &emsp;&emsp; D. 事件 A 和 B 相互独立</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** D。

**解析：** $\displaystyle P(A\mid B)+P(\bar A\mid\bar B)=1$ 等价于 $\displaystyle P(A\mid B)=P(A\mid\bar B)$，由 $0<P(B)<1$ 可知 A 与 B 独立。

</details>

11. **【1998-1-3 分】** 设 A, B 是随机事件, 且 $\displaystyle 0<P(A)<1$, $\displaystyle P(B)>0$, $\displaystyle P(B|A)=P(B|\bar{A})$, 则必有( ).

<div className="choice-options">
<div className="choice-option-row">A. $\displaystyle P(A|B)=P(\bar{A}|B)$ &emsp;&emsp; B. $\displaystyle P(A|B) \neq P(\bar{A}|B)$</div>
<div className="choice-option-row">C. $\displaystyle P(AB)=P(A)P(B)$ &emsp;&emsp; D. $\displaystyle P(AB) \neq P(A)P(B)$</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** C。

**解析：** 由全概率公式，$\displaystyle P(B)=P(B\mid A)P(A)+P(B\mid\bar A)P(\bar A)$。两条件概率相等时均等于 $P(B)$，从而 $\displaystyle P(AB)=P(A)P(B)$。

</details>

12. **【2000-4-3 分】** 设 A, B, C 三个事件两两相互独立, 则 A, B, C 相互独立的充分必要条件是( ).

<div className="choice-options">
<div className="choice-option-row">A. A 与 $\displaystyle BC$ 独立 &emsp;&emsp; B. $\displaystyle AB$ 与 $\displaystyle A \cup C$ 独立</div>
<div className="choice-option-row">C. $\displaystyle AB$ 与 $\displaystyle AC$ 独立 &emsp;&emsp; D. $\displaystyle A \cup B$ 与 $\displaystyle A \cup C$ 独立</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** A。

**解析：** 已知两两独立后，三事件相互独立只差条件 $\displaystyle P(ABC)=P(A)P(B)P(C)$。这恰好等价于 A 与事件 $BC$ 独立。

</details>

13. **【2003-3-4 分】** 将一枚硬币独立地掷两次, 引进事件:
$\displaystyle A_1=\{\text{掷第一次出现正面}\}$,
$\displaystyle A_2=\{\text{掷第二次出现正面}\}$,
$\displaystyle A_3=\{\text{正、反面各出现一次}\}$,
$\displaystyle A_4=\{\text{正面出现两次}\}$,
则事件( )

<div className="choice-options">
<div className="choice-option-row">A. $\displaystyle A_1$, $\displaystyle A_2$, $\displaystyle A_3$ 相互独立 &emsp;&emsp; B. $\displaystyle A_2$, $\displaystyle A_3$, $\displaystyle A_4$ 相互独立</div>
<div className="choice-option-row">C. $\displaystyle A_1$, $\displaystyle A_2$, $\displaystyle A_3$ 两两独立 &emsp;&emsp; D. $\displaystyle A_2$, $\displaystyle A_3$, $\displaystyle A_4$ 两两独立</div>

<details>
<summary>查看答案与解析</summary>

14. **【2003-4-4 分】** 对于任意二事件 A 和 B, ( ).

<div className="choice-options">
<div className="choice-option-row">A. 若 $\displaystyle AB \neq \varnothing$, 则 A, B 一定独立 &emsp;&emsp; B. 若 $\displaystyle AB \neq \varnothing$, 则 A, B 有可能独立</div>
<div className="choice-option-row">C. 若 $\displaystyle AB=\varnothing$, 则 A, B 一定独立 &emsp;&emsp; D. 若 $\displaystyle AB=\varnothing$, 则 A, B 一定不独立</div>

<details>
<summary>查看答案与解析</summary>

**答案：** B。

15. **【2017-3-4 分】** 设 A, B, C 为三个随机事件, 且 A 与 C 相互独立, B 与 C 相互独立, 则 $\displaystyle A \cup B$ 与 C 相互独立的充分必要条件是( )

<div className="choice-options">
<div className="choice-option-row">A. A 与 B 相互独立 &emsp;&emsp; B. A 与 B 互不相容</div>
<div className="choice-option-row">C. $\displaystyle AB$ 与 C 相互独立 &emsp;&emsp; D. $\displaystyle AB$ 与 C 互不相容</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** C。

**解析：** 利用容斥公式，$\displaystyle P((A\cup B)C)=P(AC)+P(BC)-P(ABC)$。已知 A、C 与 B、C 独立后，$A\cup B$ 与 C 独立当且仅当 $\displaystyle P(ABC)=P(AB)P(C)$，即 $AB$ 与 C 独立。

</details>

## 大题

1. **【2002-4-8 分】** 设 A, B 是任意二事件, 其中 A 的概率不等于0 和1, 证明, $\displaystyle P(B|A)=P(B|\bar{A})$ 是事件 A 与 B 独立的充分必要条件.

<details>
<summary>查看答案与解析</summary>

**答案：** 结论成立。

**解析：** 若 $\displaystyle P(B\mid A)=P(B\mid\bar A)=r$，由全概率公式 $\displaystyle P(B)=rP(A)+rP(\bar A)=r$，于是 $\displaystyle P(AB)=P(A)P(B)$，A、B 独立。反之，若 A、B 独立，则 $\displaystyle P(B\mid A)=P(B)$；又 A 与 B 独立也推出 $\bar A$ 与 B 独立，所以 $\displaystyle P(B\mid\bar A)=P(B)$。

</details>
