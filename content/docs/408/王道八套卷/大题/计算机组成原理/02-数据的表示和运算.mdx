# 计算机组成原理 · 第2章 数据的表示和运算

## 第2套试卷 · 第43题

<Question id="wd408-2027-s02-q43" type="essay" number={43} tags="来源:王道8套卷第2套, 考点:8位无符号数加减法, 考点:进位与借位, 考点:CF与ZF标志" points={12}>

某计算机的字长为 **8 位**。$x$ 和 $y$ 均为**无符号整数**，$x=68$、$y=80$，分别存于寄存器 A、B。加/减法结果仅保留 8 位，且减法由加法器完成补码形式的 $x+(\sim y)+1$。各问结果尽量用十六进制表示。

1. 寄存器 A、B 中的内容分别是什么？
2. 将 $x+y$ 的结果存入寄存器 C。写出 C 的内容、结果是否能正确表示、最高位进位 $C_{out}$，以及 $\mathrm{ZF}$、$\mathrm{CF}$ 的值。
3. 将 $x-y$ 的结果存入寄存器 D。写出 D 的内容、结果是否能正确表示、最高位进位 $C_{out}$，以及 $\mathrm{ZF}$、$\mathrm{CF}$ 的值。
4. 对无符号数，加法与减法中 $C_{out}$ 分别表示什么？与 $\mathrm{CF}$ 的关系是什么？
5. 无符号数常用于哪些场景？为什么不能用**有符号溢出标志 OF**来判断无符号运算的越界？

<Solution>

### 参考答案

**（1）寄存器内容。**

$$
68_{10}=01000100_2=\boxed{0x44},\qquad
80_{10}=01010000_2=\boxed{0x50}.
$$

所以 $A=\mathrm{0x44}$，$B=\mathrm{0x50}$。

**（2）计算 $x+y$。**

$$
\begin{aligned}
\mathrm{0x44}+\mathrm{0x50}
&=\mathrm{0x94}=148_{10},\\
0100\,0100+0101\,0000&=1001\,0100.
\end{aligned}
$$

无符号 8 位范围为 $0\sim255$，$148$ 在范围内，故 **C 中为 $\mathrm{0x94}$，结果正确且未发生无符号进位越界**。求和没有第 9 位进位：$C_{out}=0$。结果非 0，故 $\mathrm{ZF}=0$；无符号加法的 $\mathrm{CF}=C_{out}=0$。

**（3）计算 $x-y$。** 数学意义上的差是 $68-80=-12$，**不能用无符号 8 位整数表示这个负数**。硬件保留低 8 位：

$$
\begin{aligned}
\sim\mathrm{0x50}&=\mathrm{0xAF},\\
\mathrm{0x44}+\mathrm{0xAF}+1
&=\mathrm{0xF4}=244_{10}.
\end{aligned}
$$

所以 D 的位模式为 $\boxed{\mathrm{0xF4}}$（相当于 $-12\bmod256$），但它**不是 $-12$ 的合法无符号表示**，发生了**无符号减法借位/下溢**。加法器并未产生第 9 位进位：$C_{out}=0$。结果非零，故 $\mathrm{ZF}=0$；按“$\mathrm{CF}=1$ 表示减法借位”的常用标志语义，$\mathrm{CF}=1-C_{out}=1$。

**（4）$C_{out}$ 与 CF：**

| 运算 | $C_{out}$ 的含义 | 常用 CF 设置规则 |
| --- | --- | --- |
| 无符号加法 $x+y$ | 第 8 位之外的**进位**，1 表示数学和超出 255 | $\mathrm{CF}=C_{out}$ |
| 由补码加法器实现的无符号减法 $x+(\sim y)+1$ | $C_{out}=1$ 表示**未借位**；$0$ 表示发生借位 | $\mathrm{CF}=\neg C_{out}$（1 表示借位） |

这正是为何不能对减法直接写成 $\mathrm{CF}=C_{out}$。**注意：**这是题目给出的加法器实现及通常 x86 风格的 CF（减法借位标志）约定；有的教学模型直接以末位进位表示“无借位”，须先核对使用的是哪种标志定义。

**（5）无符号数的应用与溢出判断。** 无符号数适合**计数、长度、容量、下标、地址偏移、位掩码等非负量**，能在相同位数下覆盖更大的非负范围。无符号加减法**同样可能超出表示范围**，并非“无需判断越界”；只是不该依据判定**有符号**溢出的 $\mathrm{OF}$ 去判断：无符号**加法溢出看 CF 进位**，**减法下溢看 CF 借位**。例如本题 $0x44+0x50$ 若按有符号数理解会超出 $[-128,127]$，但按无符号理解 $148$ 完全合法。

**结果汇总：**

| 运算 | 低 8 位 | 数学结果在无符号范围内？ | $C_{out}$ | ZF | CF |
| --- | --- | --- | ---: | ---: | ---: |
| $68+80$ | $0x94$ | 是 | 0 | 0 | 0 |
| $68-80$ | $0xF4$ | 否（借位） | 0 | 0 | 1 |

</Solution>

</Question>

## 第4套试卷 · 第43题

<Question id="wd408-2027-s04-q43" type="essay" number={43} tags="来源:王道8套卷第4套, 考点:补码减法及CF-OF-ZF-SF, 考点:IEEE754单精度浮点数, 考点:小端字节序" points={11}>

某 32 位计算机以**小端方式**存储数据，`int` 为 32 位有符号补码整数，`float` 为 IEEE 754 **32 位单精度**浮点数。以下 C 语言程序片段中，初始有 `a[5] = 0x7FFFFFFF`、`b[5] = 0xFFFFFFFF`：

```c
int i, a[10], b[10];
float x = -15.25f;
for (i = 0; i < 10; i++)
    if (b[i] < a[i])
        b[i] = 1;
    else
        b[i] = 0;
```

1. 假设有符号比较 `b[i] < a[i]` 在该机上通过 `b[i] - a[i]` 及标志位实现。求 $i=5$ 时减法结果及 $\mathrm{CF}$、$\mathrm{OF}$、$\mathrm{ZF}$、$\mathrm{SF}$ 的值（规定减法的 CF=1 表示产生**无符号借位**）。
2. 执行该次循环后 `b[5]` 的值是多少？说明为何不能只检查 SF 就断定两个有符号整数的大小。
3. `x` 的首地址为 `0x12345670`。求地址 `0x12345670` 至 `0x12345673` 四个字节的内容。

<Solution>

### 参考答案

**（1）减法与标志位。** `b[5] = 0xFFFFFFFF` 是补码 $-1$，`a[5] = 0x7FFFFFFF` 是补码 $2^{31}-1=2147483647$，故

$$
\begin{aligned}
b[5]-a[5]
&=-1-2147483647\\
&=-2147483648\\
&=\boxed{\mathrm{0x80000000}}.
\end{aligned}
$$

由此逐个判断：

- **CF=0：** 若作为无符号数，$\mathrm{0xFFFFFFFF}>\mathrm{0x7FFFFFFF}$，执行减法无需借位。
- **OF=0：** 有符号数学结果恰好等于 32 位最小值 $-2^{31}$，可以精确表示，故**未发生有符号溢出**。
- **ZF=0：** 结果为 `0x80000000`，不是 0。
- **SF=1：** 结果最高位（符号位）为 1。

所以依次为 $\boxed{(\mathrm{CF},\mathrm{OF},\mathrm{ZF},\mathrm{SF})=(0,0,0,1)}$。

**（2）比较结果。** 条件 `b[5] < a[5]` 为真，因为 $-1<2147483647$，故循环体执行 `b[5] = 1`，结果为 $\boxed{1}$，即 32 位位模式 `0x00000001`。

对**有符号**比较，不能只看减法结果的 SF：一旦发生有符号溢出，结果符号可能被翻转，判断小于应使用 **$\mathrm{SF}\oplus\mathrm{OF}$**（并结合有符号条件码规则）；本题 OF=0，因此 SF=1 恰好对应条件为真。CF 描述的是**无符号借位**，不能代替有符号大小比较。

**（3）浮点编码与小端存储。** 先将 $15.25$ 转为二进制：

$$
15.25_{10}=1111.01_2=1.11101_2\times2^3.
$$

于是 IEEE 754 单精度的字段为：

- 符号位 $s=1$（负数）。
- 指数字段 $E=3+127=130=10000010_2$。
- 尾数字段为小数点后的 `11101` 再补 18 个 0，总计 23 位，即 `11101000000000000000000`。

合并得到

$$
1\quad10000010\quad11101000000000000000000
=\boxed{\mathrm{0xC1740000}}.
$$

**小端存储时低有效字节放在低地址**，所以：

| 内存地址 | 存储的 1 字节内容 |
| --- | --- |
| `0x12345670` | **`0x00`** |
| `0x12345671` | **`0x00`** |
| `0x12345672` | **`0x74`** |
| `0x12345673` | **`0xC1`** |

**核对方法：** 按地址从低到高读出的字节序列为 `00 00 74 C1`，按 32 位**数值位模式**从高到低书写则是 `C1 74 00 00`。切勿把“数值的十六进制书写顺序”直接当成“小端内存的字节顺序”。

</Solution>

</Question>
