## 第4套试卷 · 第41题

<Question id="wd408-2027-s04-q41" type="essay" number={41} tags="来源:王道8套卷第4套, 考点:小根堆, 考点:实时最小值删除与插入, 考点:堆调整复杂度" points={10}>

集合 $S$ 中已有一批元素，系统每隔 $1\,\mathrm{s}$ 接收一个新元素。每次接收新元素**之前**，必须输出并删除当前 $S$ 中的最小元素。

1. 选择合适的数据结构，设计算法，使每次删除最小元素、接收新元素的操作尽可能高效。
2. 初始 $S=\{59,31,29,18,78,26,48,10,65,35\}$，其后依次接收 $39$、$12$。给出建立结构以及两轮“删除最小值、插入新值”的过程。

<Solution>

### 参考答案

**（1）采用顺序存储的小根堆（最小堆），而不是每次对整个集合重新排序。** 小根堆中每个结点的值不大于其孩子，因此堆顶始终是当前最小值。

- 初始化：用自底向上建堆，时间 $O(n)$。
- 接收每个新元素前：输出堆顶；用末尾元素替换根，缩小堆长度并向下筛选，时间 $O(\log n)$。
- 接收新元素后：放在数组末尾并向上筛选，时间 $O(\log n)$。

因此每轮时间为 $O(\log n)$、取最小值本身为 $O(1)$，附加空间为 $O(1)$（不计存放 $n$ 个元素的堆数组）。

**C 语言算法（从 0 开始下标；调用前保证堆数组容量足够，删除时堆非空）：**

```c
#include <stddef.h>

// 自顶向下修复以 i 为根的子堆。
static void siftDown(int a[], size_t n, size_t i) {
    while (2 * i + 1 < n) {
        size_t c = 2 * i + 1;
        if (c + 1 < n && a[c + 1] < a[c]) ++c;
        if (a[i] <= a[c]) break;
        int t = a[i]; a[i] = a[c]; a[c] = t;
        i = c;
    }
}

void buildMinHeap(int a[], size_t n) {
    for (size_t i = n / 2; i > 0; --i)
        siftDown(a, n, i - 1);
}

// 删除并返回原堆顶。调用前 *n > 0。
int removeMin(int a[], size_t *n) {
    int result = a[0];
    --(*n);
    if (*n > 0) {
        a[0] = a[*n];
        siftDown(a, *n, 0);
    }
    return result;
}

// 插入后堆大小加 1，调用前预留至少一个空闲位置。
void insertMinHeap(int a[], size_t *n, int value) {
    size_t i = (*n)++;
    a[i] = value;
    while (i > 0) {
        size_t p = (i - 1) / 2;
        if (a[p] <= a[i]) break;
        int t = a[p]; a[p] = a[i]; a[i] = t;
        i = p;
    }
}
```

**（2）以数组层序展示一种确定的执行过程**（建堆从最后一个非叶结点开始，向下筛选时选择较小孩子）：

初始按题目给定顺序存入数组，经自底向上建小根堆：

$$
[10,18,26,31,35,29,48,59,65,78].
$$

**第 1 轮（下一条新元素为 39）：**

- 新元素到达**之前**，输出并删除堆顶 **10**。末尾 $78$ 替根后向下筛选，得到 $[18,31,26,59,35,29,48,78,65]$。
- 插入 $39$ 并向上筛选，得到 $[18,31,26,59,35,29,48,78,65,39]$。

**第 2 轮（下一条新元素为 12）：**

- 先输出并删除堆顶 **18**，向下筛选得到 $[26,31,29,59,35,39,48,78,65]$。
- 插入 $12$ 并向上筛选，得到 $[12,26,29,59,31,39,48,78,65,35]$。

故两次输出顺序为 **10、18**。两轮结束后若再次需要输出最小值，则堆顶为 **12**。堆的内部数组表示通常不唯一；只要所有堆序关系正确、弹出的最小值顺序一致，即为有效答案。

**易错点：**必须遵守“**先删除，再接收**”，不能在第一次输出 10 前插入 39，也不能在第二次输出 18 前插入 12。

</Solution>

</Question>

## 第6套试卷 · 第41题

<Question id="wd408-2027-s06-q41" type="essay" number={41} tags="来源:王道8套卷第6套, 考点:外部排序, 考点:初始归并段, 考点:4路最佳归并树, 考点:虚段与I/O" points={11}>

外存中有 $n$ 条记录，每条记录恰好占一个磁盘块；内存一次能容纳 $k$ 条记录，且 $n\gg k$。先用内部排序生成初始归并段，再进行 **4 路归并**（假设归并时具备满足缓冲区要求的内存空间）。

1. 每次最多读入 $k$ 条记录进行内部排序，会生成多少个初始归并段？
2. 这种初始归并段的生成方法有什么局限？如何优化？
3. 若已经生成 $8$ 个初始归并段，长度依次为 $12,25,39,61,19,42,33,49$（单位：磁盘块），构造 **4 路最佳归并树**，写出归并顺序及其总磁盘 I/O 次数。约定每次读或写一个磁盘块记为一次 I/O，计入**归并阶段**的读、写，不重复计入初始归并段生成阶段的 I/O。

<Solution>

### 参考答案

**（1）初始归并段个数**为

$$
\boxed{r=\left\lceil\frac{n}{k}\right\rceil}.
$$

前 $r-1$ 段最多各有 $k$ 条，最后一段长度为 $n-(r-1)k$；当 $n$ 是 $k$ 的整数倍时恰为 $n/k$ 段。

**（2）局限与优化。** 将外存数据机械地每 $k$ 条分为一组并独立内部排序，只得到长度至多 $k$ 的初始归并段。归并段可能较多，所需归并趟数和磁盘 I/O 开销偏大。

可采用**置换—选择排序（replacement selection）**：用内存中的最小堆维护当前可写出的记录，按序输出当前段；新读入的记录若不小于本段刚输出的关键字，则仍参与当前段，否则冻结到下一段。这可以生成**长于 $k$** 的归并段；输入关键字独立且近似随机时，平均初始段长通常约为 $2k$，但并非对任意输入都保证达到 $2k$。还可在归并阶段使用败者树与更大的块缓冲区降低比较和实际 I/O 开销。

**（3）4 路最佳归并树与磁盘 I/O。** 将长度排序得到

$$
12,19,25,33,39,42,49,61,\qquad N=280.
$$

4 路严格归并树的叶结点数应满足 $\left(n_0-1\right)\bmod(4-1)=0$。现有 $8$ 段，$(8-1)\bmod3=1$，因此须补充 **2 个权值为 0 的虚段**，变为 $10$ 个叶结点。每次合并当前权值最小的 4 个结点：

| 合并轮次 | 选取的 4 个结点（权值） | 归并后的结点权值 |
| --- | --- | ---: |
| 1 | $0,0,12,19$ | $31$ |
| 2 | $25,31,33,39$ | $128$ |
| 3 | $42,49,61,128$ | $280$ |

最佳归并树（内部结点括号内为该结点的总记录数，`0` 为不占实际磁盘块的虚段）：

```text
                    [280]
          /        /      \          \
        42        49      61        [128]
                                  /   |    \      \
                                25   [31]   33     39
                                    / | \ \
                                   0  0 12 19
```

每个内部结点代表一次归并，需将对应数据各读入一次、写出一次：

$$
\begin{aligned}
I/O_{\text{读}} &= 31+128+280=439,\\
I/O_{\text{写}} &= 31+128+280=439,\\
I/O_{\text{归并总计}} &=2\times439=\boxed{878\text{ 次}}.
\end{aligned}
$$

也可以按每条记录在最佳归并树中的加权路径长度来算，结果同样为 $439$ 个记录块的“读量”加 $439$ 个记录块的“写量”。**虚段权值为 0，不产生磁盘 I/O。**

**统计口径：**上述 $878$ 次仅指题目要求的归并阶段。若另要求把“初始归并段生成”时读取、写出全部 $280$ 块也算进去，则还需要 $2\times280=560$ 次，合为 $1438$ 次；本题按题干约定回答 **878 次**。

</Solution>

</Question>

## 第7套试卷 · 第41题

<Question id="wd408-2027-s07-q41" type="essay" number={41} tags="来源:王道8套卷第7套, 考点:大根堆, 考点:完全二叉树顺序存储, 考点:自底向上建堆" points={10}>

输入关键字序列 $15,10,24,47,37,68,50$，建立大根堆：

1. 堆通常采用顺序存储还是链式存储？说明其逻辑结构与存储结构的关系。
2. 用 C 或 C++ 给出堆的数据结构定义。
3. 按**输入顺序存放在数组中**，采用自底向上的建堆算法，逐步展示各次筛选结果，并画出最终大根堆。

<Solution>

### 参考答案

**（1）堆的存储。** 堆的**逻辑结构**是一棵满足堆序关系的完全二叉树；由于完全二叉树按层序存储几乎无结构空间浪费，堆**通常使用顺序存储（数组）**，而不是每个结点另设指针的链式存储。不能把“树形逻辑结构”误解为“必须链式存储”。

**（2）C 语言数据结构及孩子下标。** 采用从 0 开始的数组下标：

```c
#define MAX_HEAP_SIZE 1024

typedef struct {
    int key[MAX_HEAP_SIZE];
    int size;  // 堆中当前元素数量
} MaxHeap;

// 下标 i 的左孩子 2*i+1、右孩子 2*i+2（若下标 < size）。
// i > 0 时双亲下标为 (i-1)/2。
// 大根堆满足每个有效孩子 key[child] <= key[parent]。
```

**（3）自底向上调整。** 初始层序数组为

$$
[15,10,24,47,37,68,50].
$$

共有 7 个结点，最后一个非叶结点的**0 基下标**为 $\lfloor 7/2\rfloor-1=2$，因此依次对 $i=2,1,0$ 向下筛选，遇到两个孩子时选择较大的孩子交换：

| 操作 | 本次结果（层序数组） |
| --- | --- |
| 初始 | $[15,10,24,47,37,68,50]$ |
| 对 $i=2$ 筛选：$24\leftrightarrow68$ | $[15,10,68,47,37,24,50]$ |
| 对 $i=1$ 筛选：$10\leftrightarrow47$ | $[15,47,68,10,37,24,50]$ |
| 对 $i=0$ 筛选：先 $15\leftrightarrow68$，再 $15\leftrightarrow50$ | $[68,47,50,10,37,24,15]$ |

最终大根堆：

```text
             68
           /    \
         47      50
        /  \    /  \
      10   37  24   15
```

检验：$68\ge47,50$，$47\ge10,37$，$50\ge24,15$，满足大根堆性质。建堆复杂度为 **$O(n)$**，不是把每个元素依次插入空堆时的 $O(n\log n)$ 上界。不同建堆实现可能形成不同的合法堆，本题明确采用自底向上法，因而给出上述确定过程。

</Solution>

</Question>
