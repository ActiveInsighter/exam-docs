## 第1套试卷 · 第41题

<Question id="wd408-2027-s01-q41" type="essay" number={41} tags="来源:王道8套卷第1套, 考点:强连通分量与顶点度及最小生成树" points={10}>

某有向图 $G$ 的邻接矩阵如下，顶点按 $0,1,2,3,4$ 编号，矩阵的非零元素表示存在相应有向边，数值表示边权。

$$
A=\begin{bmatrix}
0&3&1&3&5\\
3&0&1&2&4\\
1&1&0&1&1\\
3&2&1&0&1\\
5&4&1&1&0
\end{bmatrix}
$$

1. 图 $G$ 有多少个强连通分量？
2. 对下列函数 `f()`，说明其功能，并计算 `f(&G, 3)` 的返回值。

```c
int f(MGraph *G, int i) {
    int d = 0, j;
    for (j = 0; j < G->n; j++) {
        if (G->edges[i][j]) d++;
        if (G->edges[j][i]) d++;
    }
    return d;
}
```

3. 若将 $G$ 视为**无向带权图**，从节省时间开销的角度应采用哪种算法求最小生成树？求其权值之和。

<Solution>

### 参考答案

**（1）强连通分量数为 $1$。**

该矩阵的所有非对角元素都非 0，即任意两个不同顶点之间均存在**双向的有向边**，当然彼此可达。因此全部 5 个顶点属于**同一个强连通分量**。不要把“强连通分量”误认为每个顶点单独一个。

**（2）`f()` 计算顶点 $i$ 的出度与入度之和。**

- `G->edges[i][j]` 为非零时，表示存在 $i\to j$，出度加 1。
- `G->edges[j][i]` 为非零时，表示存在 $j\to i$，入度加 1。

所以函数返回 $d^+(i)+d^-(i)$。对 $i=3$（下标从 0 开始），第 3 行除对角线外共有 4 个非零数，第 3 列同样有 4 个，返回 $4+4=\boxed{8}$。

提示：若存在自环，该函数也会将其分别计入入度和出度，这是有向图“总度”的常用定义；本题对角线为 0，不涉及自环。

**（3）采用 Prim（普里姆）算法，最小生成树总权值为 $\boxed{4}$。**

这是一个有 5 个顶点、10 条无向边的**稠密图**。对邻接矩阵的典型实现，Prim 算法复杂度为 $O(V^2)$，而用排序实现的 Kruskal 算法通常为 $O(E\log E)$。在稠密图上通常优先选 Prim。

最小生成树可以直接取以下四条边（用顶点下标表示）：

$$
(2,0):1,\quad(2,1):1,\quad(2,3):1,\quad(2,4):1.
$$

它们连接了全部 5 个顶点，没有环，权值总和为 $1+1+1+1=4$。任意生成树都包含 4 条边，且本图每条边的权值不小于 1，所以其总权值至少为 4；上述构造达到了下界，因而**必为最小生成树**。

**易错点**：第（2）问不能把邻接矩阵中的数值直接相加当作“度”；度只看边是否存在。第（3）问 Prim 是算法选择，权值必须根据实际的边权计算。

</Solution>

</Question>

## 第3套试卷 · 第41题

<Question id="wd408-2027-s03-q41" type="essay" number={41} tags="来源:王道8套卷第3套, 考点:拓扑排序与AOE网络及关键路径及Dijkstra最短路" points={10}>

给定如图所示的带权有向无环图，顶点为 $V_1,\ldots,V_8$，边上的数字表示活动持续时间（也作为计算最短路的边权）。

![8 个顶点的带权有向无环图](/images/27王道8套卷1025/p033-1.svg)

1. 写出图的邻接矩阵（顶点依次为 $V_1,\ldots,V_8$）。
2. 写出**所有**拓扑排序序列。
3. 将图视为 AOE 网络，以 $V_1$ 为源、$V_8$ 为汇，求所有**事件**和**活动**的最早/最晚允许发生时刻，并给出全部关键路径。
4. 以 $V_1$ 为起点，求到各顶点的最短距离及一条对应最短路径。

<Solution>

### 参考答案

**（1）邻接矩阵**。顶点顺序为 $V_1,V_2,\ldots,V_8$。因为所有边权都是正数，此处约定：**有边填权值、无边填 $\infty$、主对角线填 0**（若使用 0 表示无边的存储约定也可以，但应明确说明）。

$$
A=\begin{bmatrix}
0&2&3&\infty&\infty&\infty&\infty&\infty\\
\infty&0&\infty&5&\infty&\infty&\infty&\infty\\
\infty&\infty&0&3&10&\infty&\infty&\infty\\
\infty&\infty&\infty&0&\infty&4&\infty&\infty\\
\infty&\infty&\infty&\infty&0&\infty&3&\infty\\
\infty&\infty&\infty&\infty&2&0&\infty&6\\
\infty&\infty&\infty&\infty&\infty&\infty&0&1\\
\infty&\infty&\infty&\infty&\infty&\infty&\infty&0
\end{bmatrix}.
$$

根据图可列出全部 10 条有向边：$1\to2(2)$、$1\to3(3)$、$2\to4(5)$、$3\to4(3)$、$3\to5(10)$、$4\to6(4)$、$6\to5(2)$、$6\to8(6)$、$5\to7(3)$、$7\to8(1)$，逐项检查矩阵即可。

**（2）所有拓扑序列：恰好 2 种。**

1. $V_1,V_2,V_3,V_4,V_6,V_5,V_7,V_8$；
2. $V_1,V_3,V_2,V_4,V_6,V_5,V_7,V_8$。

理由：$V_1$ 必须最先；$V_2$ 与 $V_3$ 之间无依赖，可以互换；随后 $V_4$ 必须在两者之后，且 $V_6\prec V_5\prec V_7\prec V_8$，所以只有 2 种。

**（3）AOE 网络的事件最早/最晚发生时刻。**

以 $ve(1)=0$ 为起点，顺拓扑序采用“取前驱最大值”计算最早时刻；以工程总工期 $ve(8)=17$ 为终点，逆拓扑序采用“取后继最小值”计算最晚时刻。

$$
ve(j)=\max_{(i,j)\in E}\{ve(i)+w_{ij}\},\qquad
vl(i)=\min_{(i,j)\in E}\{vl(j)-w_{ij}\}.
$$

| 事件 | $V_1$ | $V_2$ | $V_3$ | $V_4$ | $V_5$ | $V_6$ | $V_7$ | $V_8$ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 最早 $ve$ | 0 | 2 | 3 | 7 | 13 | 11 | 16 | 17 |
| 最晚 $vl$ | 0 | 2 | 3 | 7 | 13 | 11 | 16 | 17 |

所有**事件**均满足 $ve=vl$，但不能据此认为所有活动均是关键活动。

对活动 $i\to j$，其最早开始时刻 $e(i,j)=ve(i)$，最晚开始时刻 $l(i,j)=vl(j)-w_{ij}$，时间余量为 $l-e$：

| 活动（持续时间） | 最早开始 $e$ | 最晚开始 $l$ | 余量 $l-e$ |
| --- | ---: | ---: | ---: |
| $V_1\to V_2\ (2)$ | 0 | 0 | 0 |
| $V_1\to V_3\ (3)$ | 0 | 0 | 0 |
| $V_2\to V_4\ (5)$ | 2 | 2 | 0 |
| $V_3\to V_4\ (3)$ | 3 | 4 | **1** |
| $V_3\to V_5\ (10)$ | 3 | 3 | 0 |
| $V_4\to V_6\ (4)$ | 7 | 7 | 0 |
| $V_6\to V_5\ (2)$ | 11 | 11 | 0 |
| $V_6\to V_8\ (6)$ | 11 | 11 | 0 |
| $V_5\to V_7\ (3)$ | 13 | 13 | 0 |
| $V_7\to V_8\ (1)$ | 16 | 16 | 0 |

工程总工期为 $\boxed{17}$。**全部 3 条关键路径**（每条长度均为 17）为：

- $V_1\to V_3\to V_5\to V_7\to V_8$：$3+10+3+1=17$；
- $V_1\to V_2\to V_4\to V_6\to V_8$：$2+5+4+6=17$；
- $V_1\to V_2\to V_4\to V_6\to V_5\to V_7\to V_8$：$2+5+4+2+3+1=17$。

**仅**活动 $V_3\to V_4$ 的时间余量为 1，其余均为关键活动。

**（4）单源最短路径**。各边权非负，可用 Dijkstra 算法。与 AOE 的**最长工期**不同，最短路径松弛更新取最小值。计算结果如下：

| 终点 | 最短距离 | 一条最短路径 |
| --- | ---: | --- |
| $V_1$ | 0 | $V_1$ |
| $V_2$ | 2 | $V_1\to V_2$ |
| $V_3$ | 3 | $V_1\to V_3$ |
| $V_4$ | 6 | $V_1\to V_3\to V_4$ |
| $V_5$ | 12 | $V_1\to V_3\to V_4\to V_6\to V_5$ |
| $V_6$ | 10 | $V_1\to V_3\to V_4\to V_6$ |
| $V_7$ | 15 | $V_1\to V_3\to V_4\to V_6\to V_5\to V_7$ |
| $V_8$ | **16** | $V_1\to V_3\to V_4\to V_6\to V_8$ |

**核查关键区别：**$V_1\to V_8$ 的最短距离是 16，而项目关键路径长为 17；两者分别是在同一张图上做**最小**与**最大**路径权重计算，不能混淆。

</Solution>

</Question>

## 第6套试卷 · 第42题

<Question id="wd408-2027-s06-q42" type="essay" number={42} tags="来源:王道8套卷第6套, 考点:邻接表与有向图入度计算" points={12}>

假设**无权有向图**采用邻接表存储，顶点以整数 $0,1,\ldots,n-1$ 编号。回答：

1. 给出图 $G$ 的邻接表存储结构定义（C 语言）。
2. 基于此结构设计算法，求给定顶点 $v$ 的**入度**，给出设计思想、C 或 C++ 代码与复杂度。

<Solution>

### 参考答案

**（1）邻接表定义**。一个顶点表元素保存顶点编号和指向其第一条**出边**的指针；每个边表结点保存该出边的终点编号及下一条边的指针。

```c
#include <stddef.h>
#define MAXV 100

typedef struct ArcNode {
    int adjvex;                 // 弧的终点编号
    struct ArcNode *nextarc;   // 同一顶点的下一条出弧
} ArcNode;

typedef struct VNode {
    int data;                   // 顶点编号：0..n-1
    ArcNode *firstarc;         // 该顶点的第一条出弧
} VNode;

typedef struct ALGraph {
    VNode vertices[MAXV];
    int n, e;                  // 顶点数、有向边数
} ALGraph;
```

**（2）设计思想**。邻接表通常沿顶点 $u$ 的出边链保存 $u\to w$，因此某个顶点的入边并不集中在它自己的链表内。遍历**全部顶点**的出边链，每遇到一条终点编号为 $v$ 的边，就把计数器加 1。

```c
// 若 v 非法则返回 -1；合法时返回该顶点的入度。
int inDegree(const ALGraph *G, int v) {
    if (G == NULL || v < 0 || v >= G->n) return -1;

    int count = 0;
    for (int u = 0; u < G->n; ++u) {
        for (const ArcNode *p = G->vertices[u].firstarc;
             p != NULL; p = p->nextarc) {
            if (p->adjvex == v) ++count;
        }
    }
    return count;
}
```

**复杂度**：设 $V$ 为顶点数、$E$ 为有向边数。外层遍历 $V$ 个顶点，内层对全部链表合计恰好检查 $E$ 个边表结点，因此**时间复杂度为 $O(V+E)$**，额外空间为 $O(1)$。

**验证**：若出边依次为 $0\to2$、$1\to2$、$2\to3$，则顶点 2 的入度为 2（来源分别是 0、1），出度为 1；仅统计 `vertices[2].firstarc` 会求成**出度**而不是入度。

**拓展**：如需频繁查询全部顶点入度，可在建图时同步维护 `indegree[]`，使单次查询达到 $O(1)$，但这需要额外 $O(V)$ 空间及插删边时维护数据。若允许自环，自环对对应顶点入度贡献 1；允许重边时每条边分别计数。

</Solution>

</Question>
