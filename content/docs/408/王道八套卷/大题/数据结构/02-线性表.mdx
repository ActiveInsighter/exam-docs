## 第2套试卷 · 第42题

<Question id="wd408-2027-s02-q42" type="essay" number={42} tags="来源:王道8套卷第2套, 考点:高位在前单链表加法与栈" points={12}>

给定两个非空单链表，分别表示两个非负整数。链表的头结点对应数字的最高位，每个结点存储一位数字（0～9）。要求将这两个数相加，返回一个**新的单链表**表示其和。假设除数字 0 本身外，两个数均无前导 0，链表长度范围为 $[1,100]$，结点值域为 $[0,9]$。

单链表结点定义如下：

```c
struct ListNode {
    int val;
    struct ListNode *next;
};
```

示例 1：输入 $L1=[7,2,4,3]$，$L2=[5,6,4]$；输出 $[7,8,0,7]$，因为 $7243+564=7807$。

示例 2：输入 $L1=[2,4,3]$，$L2=[5,6,4]$；输出 $[8,0,7]$，因为 $243+564=807$。

回答下列问题：

1. 给出算法的基本设计思想。
2. 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
3. 分析所设计算法的时间复杂度和空间复杂度。

<Solution>

### 参考答案

**（1）设计思想：栈实现从最低位开始相加。**

链表的结点从**最高位指向最低位**，不能像普通从低位开始存储的链表那样直接同步相加。分别顺序扫描两个链表，将各位数字依次压入两个栈；此后从栈顶弹出数字，即按照个位、十位、百位……的顺序计算。

维护进位 `carry`。每次求出 `sum = x + y + carry`，个位数字 `sum % 10` 创建为一个新结点，并采用**头插法**接入结果链表；进位更新为 `sum / 10`。当两个栈均空且进位为 0 时结束。这样既能正确处理长度不等和最高位产生进位的情况，又不会修改原输入链表。

**（2）C 语言实现：**链表长度不超过 100，两个定长数组足以实现栈。

```c
#include <stdlib.h>

typedef struct ListNode {
    int val;
    struct ListNode *next;
} ListNode;

ListNode *addLists(const ListNode *L1, const ListNode *L2) {
    int a[100], b[100];
    int na = 0, nb = 0;

    for (const ListNode *p = L1; p != NULL; p = p->next)
        a[na++] = p->val;  // 最高位先入栈，最低位位于栈顶
    for (const ListNode *p = L2; p != NULL; p = p->next)
        b[nb++] = p->val;

    int carry = 0;
    ListNode *head = NULL;
    while (na > 0 || nb > 0 || carry != 0) {
        int x = (na > 0) ? a[--na] : 0;
        int y = (nb > 0) ? b[--nb] : 0;
        int sum = x + y + carry;
        carry = sum / 10;

        ListNode *s = (ListNode *)malloc(sizeof(ListNode));
        if (s == NULL) {
            // 分配失败时释放已经产生的结果，避免内存泄漏。
            while (head != NULL) {
                ListNode *next = head->next;
                free(head);
                head = next;
            }
            return NULL;
        }
        s->val = sum % 10;
        s->next = head;
        head = s;
    }
    return head;
}
```

**（3）复杂度：**设两链表长度分别为 $m,n$。两次扫描与逐位相加的总次数为 $O(m+n)$，故**时间复杂度为 $O(m+n)$**。两个数字栈使用 $O(m+n)$ 的辅助空间；新链表最多含 $\max(m,n)+1$ 个结点，若计入输出占用空间，也是 $O(m+n)$。

**验算：**$[7,2,4,3]+[5,6,4]$ 由低位依次产生 $7,0,8,7$，头插后得到 $[7,8,0,7]$。对于 $[9,9]+[1]$，循环末尾的 `carry` 还会生成最左边的 1，得到 $[1,0,0]$。输入链表始终未改动。

**易错点：**不能按链表当前的高位先计算并立即生成结果；十进制加法的进位来自低位。

</Solution>

</Question>

## 第3套试卷 · 第42题

<Question id="wd408-2027-s03-q42" type="essay" number={42} tags="来源:王道8套卷第3套, 考点:滑动窗口与连续子数组计数" points={13}>

给定一个由**正整数**组成的数组 `nums` 和一个整数 $k$，计算并返回所有满足“子数组内元素乘积严格小于 $k$”的**非空连续子数组**的总数。

示例 1：输入 `nums=[10,5,2,6]`，$k=100$；输出 8。满足条件的 8 个子数组为 $[10]$、$[5]$、$[2]$、$[6]$、$[10,5]$、$[5,2]$、$[2,6]$、$[5,2,6]$。注意 $[10,5,2]$ 的乘积为 100，不满足严格小于的条件。

示例 2：输入 `nums=[1,2,3]`，$k=0$；输出 0。

回答下列问题：

1. 给出算法设计思想。
2. 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
3. 分析所设计算法的时间复杂度和空间复杂度。

<Solution>

### 参考答案

**（1）设计思想：双指针滑动窗口。**

由于数组中的每个元素都是**正整数**（至少为 1），当固定右端点并向左缩短区间时，乘积不会增加。故可保持一个窗口 $[left,right]$，其乘积为 `product`：

1. 如果 $k\le 1$，任何非空连续子数组的乘积都至少为 1，应直接返回 0。
2. 否则遍历右端点 `right`，将新元素乘入 `product`。
3. 当 `product >= k` 时，反复除去左端元素并右移 `left`，直到乘积严格小于 $k$。
4. 此时所有**以 `right` 结尾**、起点位于 `left` 到 `right` 的子数组均满足要求，新增数量为 $right-left+1$。对所有右端点求和即可，既不遗漏也不重复计数。

**（2）C 语言实现：**

```c
#include <stddef.h>

long long countSubarrays(const int nums[], int n, int k) {
    if (n <= 0 || k <= 1) return 0;

    int left = 0;
    long long product = 1;
    long long count = 0;

    for (int right = 0; right < n; ++right) {
        product *= nums[right]; // 题设元素为正整数
        while (product >= k) {
            product /= nums[left];
            ++left;
        }
        // 以 right 为终点的合法子数组有 right-left+1 个
        count += right - left + 1;
    }
    return count;
}
```

上面以 `int` 存储 $k$ 和数组元素，以 `long long` 保存乘积与答案。在该整数取值范围内，收缩前的乘积最多约为 $\mathrm{INT\_MAX}^2$，不会超过常见的有符号 64 位整数范围；若题目扩展为任意精度整数，则应另行处理溢出问题。

**（3）复杂度：**右指针单调前进 $n$ 次，左指针在整个算法中最多移动 $n$ 次，所以**时间复杂度为 $O(n)$**；只使用常数个变量，**辅助空间复杂度为 $O(1)$**。

**示例演算：**`[10,5,2,6]`，$k=100$。

| 右端点 `right` | 收缩后的有效窗口 | 新增子数组数 | 累计 |
| --- | --- | ---: | ---: |
| 0 | `[10]` | 1 | 1 |
| 1 | `[10,5]` | 2 | 3 |
| 2 | `[5,2]` | 2 | 5 |
| 3 | `[5,2,6]` | 3 | **8** |

**易错点：**本题是**乘积严格小于**，窗口必须在 `product >= k` 时收缩；正整数条件对滑动窗口的单调性必不可少。如果允许负数或零，不能直接套用本算法。

</Solution>

</Question>

## 第5套试卷 · 第42题

<Question id="wd408-2027-s05-q42" type="essay" number={42} tags="来源:王道8套卷第5套, 考点:按原序号稳定划分与时间空间权衡" points={12}>

已知线性表 $(a_1,a_2,a_3,\cdots,a_n)$ 存放在一维数组 $A$ 中。试设计一个在时间和空间上都尽可能高效的算法，将所有**原奇数号元素**移到所有**原偶数号元素**前面，且不得改变奇数号（或偶数号）元素之间的相对顺序。要求：

1. 给出算法的基本设计思想。
2. 根据设计思想，采用 C、C++ 或 Java 语言描述算法，关键之处给出注释。
3. 说明所设计算法的时间复杂度和空间复杂度。

<Solution>

### 参考答案

**（1）设计思想：借助辅助数组进行稳定划分。**

注意“奇数号、偶数号”指元素在**原线性表中的位置编号**，不是元素数值的奇偶性；采用 C 数组时，原奇数号元素的下标为 `0,2,4,...`，原偶数号元素的下标为 `1,3,5,...`。

先按下标从小到大依次复制全部原奇数号元素到辅助数组，再按下标从小到大复制原偶数号元素，最后整体复制回原数组。这是线性扫描，天然保持两类元素的相对顺序。

**（2）C 语言实现：**

```c
#include <stdlib.h>

// A 为长度 n 的数组；函数返回 1 表示成功，0 表示失败。
int stableReorder(int A[], int n) {
    if (n <= 1) return 1;
    int *tmp = (int *)malloc((size_t)n * sizeof(int));
    if (tmp == NULL) return 0;

    int j = 0;
    for (int i = 0; i < n; i += 2)
        tmp[j++] = A[i];      // 原第 1、3、5、... 个元素
    for (int i = 1; i < n; i += 2)
        tmp[j++] = A[i];      // 原第 2、4、6、... 个元素

    for (int i = 0; i < n; ++i)
        A[i] = tmp[i];
    free(tmp);
    return 1;
}
```

**（3）复杂度：**每个元素最多被扫描和复制常数次，**时间复杂度为 $O(n)$**，达到必须检查/移动全部元素的线性时间下界；辅助数组长为 $n$，**辅助空间复杂度为 $O(n)$**。

例如，原数组 `[10,20,30,40,50,60,70]` 变为 `[10,30,50,70,20,40,60]`。各组内部的次序完全保持。

**补充：时间与额外空间的权衡。**如果要求不分配辅助数组，可以逐个将后面的原奇数号元素插入前面的奇数号区末尾，并将中间偶数号元素整体右移；该直接插入方案保持稳定，额外空间为 $O(1)$，但最坏时间为 $O(n^2)$。本答案采用时间优先的 $O(n)$ 方法；不应把它误报为 $O(1)$ 额外空间。

</Solution>

</Question>

## 第8套试卷 · 第42题

<Question id="wd408-2027-s08-q42" type="essay" number={42} tags="来源:王道8套卷第8套, 考点:快慢指针与原地反转判断回文链表" points={14}>

已知一个长度为 $n$（$n>1$）的单链表，其表头指针为 `L`，结点结构由 `data` 和 `next` 两个域构成，其中 `data` 域为字符型。试设计一个在时间和空间上都尽可能高效的算法，判断该单链表是否**中心对称**（如 `xyx`、`xyyx` 都是中心对称的）。要求：

1. 给出算法的基本设计思想。
2. 根据设计思想，采用 C、C++ 或 Java 语言描述算法，关键之处给出注释。
3. 说明所设计算法的时间复杂度和空间复杂度。

<Solution>

### 参考答案

**（1）设计思想：快慢指针定位中点，原地反转后半段，比较后恢复。**

中心对称等价于链表正序与倒序的字符序列相同。用快指针每次走两步、慢指针每次走一步找到中部：偶数长度直接从中点开始处理后半段；奇数长度跳过正中的一个字符。将后半段**原地反转**，再从头结点与反转后的后半段同步比较。无论是否相同，最后将后半段反转回来并重新连接，以恢复原链表。

**（2）C 语言实现：**下述 `L` 指向首个数据结点，**不含额外头结点**。

```c
#include <stddef.h>

typedef struct Node {
    char data;
    struct Node *next;
} Node;

static Node *reverseList(Node *head) {
    Node *prev = NULL, *curr = head;
    while (curr != NULL) {
        Node *next = curr->next;
        curr->next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}

int isPalindrome(Node *L) {
    if (L == NULL || L->next == NULL) return 1;

    Node *slow = L, *fast = L, *prev = NULL;
    while (fast != NULL && fast->next != NULL) {
        prev = slow;
        slow = slow->next;
        fast = fast->next->next;
    }

    // fast 非空：奇数长度，跳过正中结点 slow。
    // fast 为空：偶数长度，slow 是后半段首结点。
    // link 始终指向后半段入口的 next 指针。
    Node **link = (fast != NULL) ? &slow->next : &prev->next;
    Node *second = reverseList(*link);
    *link = second;

    int equal = 1;
    Node *p = L, *q = second;
    while (q != NULL) {
        if (p->data != q->data) {
            equal = 0;
            break;
        }
        p = p->next;
        q = q->next;
    }

    *link = reverseList(second); // 恢复原链表次序与链接
    return equal;
}
```

**（3）复杂度：**找中点、反转、比较、恢复各最多扫描线性数量的结点，总体**时间复杂度为 $O(n)$**；仅使用有限个指针和整数变量，**辅助空间复杂度为 $O(1)$**。链表最终保持原样。

**边界检验：**`xyx`（奇数长度）只比较两侧的 `x`；`xxyyx` 不是回文序列（首尾 `x` 相同，但第二位 `x` 与倒数第二位 `y` 不同）；题干示例 `xxyyx` 在字符序列意义下并非中心对称，因此应将示例改为 **`xyyyx`**（奇数长度）或 **`xyyx`**（偶数长度）。这不影响题目考察的算法。

**易错点：**奇数长度必须跳过中间结点；直接比较两半而忽略中间会错位。要求最小辅助空间时，无须先把整个链表复制到栈；如题目不允许临时修改结构，则需要额外的 $O(n)$ 空间。

</Solution>

</Question>
