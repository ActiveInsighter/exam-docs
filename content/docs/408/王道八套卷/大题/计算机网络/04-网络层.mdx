# 计算机网络 · 第4章 网络层

本章收录综合应用题 **4** 道，按第 1～8 套试卷顺序排列。

## 第2套试卷 · 第47题

<Question id="wd408-2027-s02-q47" type="essay" number={47} points={9} tags="来源:王道8套卷第2套, 考点:VLSM子网划分, 考点:RIPv2与最短跳数, 考点:路由聚合, 考点:链路故障收敛">

某单位通过 R1～R5 互联部门局域网，并由 R3 接入 Internet。路由器使用支持 CIDR/VLSM 的 **RIPv2** 交换路由信息，路由表已收敛。部门 1、部门 2 分别有 18 台和 25 台联网计算机，连接 R1 的 D1、D2，地址块是 `211.72.32.0/26`；还需给各部门的路由器 LAN 接口分配地址。路由器间各点到点网络都是 `/30`，具体 IP 如图。

![](/images/27王道8套卷1025/p025-1.svg)

1. 为部门 1、部门 2 分配适当的 CIDR 子网，并给出 R1 的 D1 和 D2 的 IP 地址。
2. 给出部门 1 主机的子网掩码和默认网关。
3. 给出 R1 与 R4 到**部门 1、部门 2 和 Internet** 的最少路由表项，分别写出目的网络、掩码、下一跳和出接口。Internet 用缺省路由代表；允许对**相邻且具有相同下一跳**的两个部门网络进行路由聚合。
4. R2 停机后网络重新收敛，说明 RIP 的变化处理，并写出 R1 到 Internet 的新路由。

<Solution>

### 参考答案

**（1）两部门均须分配 `/27` 子网。**

- 部门 1 需 `18` 台主机加 `1` 个网关接口，共 `19` 个可用地址。
- 部门 2 需 `25+1=26` 个可用地址。
- `/28` 只有 $2^4-2=14$ 个可用地址，不满足要求；`/27` 有 $2^5-2=30$ 个可用地址。

因此可按地址递增分配（子网顺序也可交换）：

| 部门 | 地址块 | 可用主机地址 | R1 LAN 接口 |
| --- | --- | --- | --- |
| 部门 1 | `211.72.32.0/27` | `211.72.32.1～211.72.32.30` | **D1：`211.72.32.1/27`** |
| 部门 2 | `211.72.32.32/27` | `211.72.32.33～211.72.32.62` | **D2：`211.72.32.33/27`** |

广播地址分别为 `211.72.32.31` 和 `211.72.32.63`；两个 `/27` 恰好覆盖整个 `211.72.32.0/26`。

**（2）部门 1：** 子网掩码 **`255.255.255.224`**，默认网关 **`211.72.32.1`**。默认网关就是该 LAN 内 R1 的 D1 地址，而不是 R1 某个点到点接口的 IP。

**（3）RIP 按经过的路由器跳数优选下一跳。**

R1 直接连接两个部门 LAN，到 Internet 的较短路径为 `R1→R2→R3`；R4 到两部门的较短路径为 `R4→R5→R1`，可聚合为一个 `/26` 路由；R4 到 Internet 经 `R3` 直达。

**R1 的相关路由表项：**

| 目的网络 | 子网掩码 | 下一跳 IP | 出接口 |
| --- | --- | --- | --- |
| `211.72.32.0` | `255.255.255.224` | 直连 | `D1` |
| `211.72.32.32` | `255.255.255.224` | 直连 | `D2` |
| `0.0.0.0` | `0.0.0.0` | **`211.72.33.6`（R2）** | **`L2`** |

**R4 的相关路由表项：**

| 目的网络 | 子网掩码 | 下一跳 IP | 出接口 |
| --- | --- | --- | --- |
| `211.72.32.0` | `255.255.255.192`（`/26`，聚合） | **`211.72.33.22`（R5）** | **`L10`** |
| `0.0.0.0` | `0.0.0.0` | **`211.72.33.17`（R3）** | **`L9`** |

这里列的是题目限定的目的网络，并未删除路由器实际还需要维护的各点到点网段路由。**RIPv2 不会必然自动把所有不同子网聚合为 `/26`**；表中对 R4 的压缩是根据题设的“尽可能少”采用的等效人工聚合表示。

**（4）R2 故障后的收敛：**

相邻路由器检测到 R2 不可达后，将相关路由视为失效，通过定时／触发更新传播新距离向量，必要时使用路由毒化、毒性逆转和抑制计时减少计数到无穷，最终选取未发生故障的可达路径。

R1 可经 `R1→R5→R4→R3→Internet` 继续访问外网；新的 Internet 缺省路由为：

| 目的网络 | 子网掩码 | 下一跳 IP | 出接口 |
| --- | --- | --- | --- |
| **`0.0.0.0`** | **`0.0.0.0`** | **`211.72.33.2`（R5）** | **`L1`** |

### 易错点

不要将 RIP 的选路“最少跳数”误当最小链路代价；题目只要求两部门网段和 Internet 的表项时，也不要将其他直连 `/30` 误加入答案表。聚合要求**相邻地址块的下一跳／出接口相同**，所以 R4 可将两个 `/27` 合并，而 R1 的两条部门直连路由不能合并。

</Solution>
</Question>

## 第3套试卷 · 第47题

<Question id="wd408-2027-s03-q47" type="essay" number={47} points={9} tags="来源:王道8套卷第3套, 考点:交换与路由区分, 考点:802.11地址3, 考点:子网有效主机数, 考点:CIDR路由聚合">

网络拓扑如图。PC1 使用 `211.73.1.134/28`，PC2 使用 `211.73.1.150/29`，无线终端 M1 使用 `211.73.1.153/29`。图中 `D1～D13` 为**物理接口标记**，不是 IP 地址或 MAC 地址的实际数值。设备 X1 连通 PC2、AP1 和 R1，AP1 为桥接式 IEEE 802.11 AP。

![](/images/27王道8套卷1025/p034-1.svg)

1. X1 应是交换机还是路由器？
2. M1 向 PC2 发单播 IP 数据后，PC2 收到的以太网帧源 MAC 属于哪个设备及接口？PC2 向 M1 返回 IP 数据时，M1 收到的**802.11 下行数据帧的地址 3** 属于哪个设备及接口？
3. 若子网中第一个**可用主机地址**留给默认网关，PC1 所在子网的默认网关 IP 是多少？除 PC1 与网关外还有多少个可分配的可用主机地址？
4. 列出 R1 到图中 PC1、PC2/M1 所在网段及 Internet 的**最少目的路由表项**（目的网络、点分十进制掩码、出接口）。两条相邻下游路由若经同一接口可聚合；图未给出的 X1 与 R1 互连链路的 IP 不要求补造。

<Solution>

### 参考答案

**（1）X1 必须承担三层路由器的角色。**

- PC2：`211.73.1.150/29` 属于 **`211.73.1.144/29`**（主机 `145～150`）。
- M1：`211.73.1.153/29` 属于 **`211.73.1.152/29`**（主机 `153～158`）。

它们属于不同 IP 子网；若仍需经 X1 相互 IP 通信，就必须有三层转发（可由路由器或三层交换机提供），**普通二层交换机单独不能完成**。

**（2）链路层地址每经过一次路由转发就重建：**

- `M1→AP1→X1→PC2`：X1 从连接 PC2 的 **`D5`** 口发出以太网帧，PC2 看到的源 MAC 应是 **X1 的 `D5` 接口 MAC**，而不是 M1 的无线网卡 MAC。
- `PC2→X1→AP1→M1`：X1 在连接 AP1 的 **`D4`** 口生成帧，AP1 桥接成下行 802.11 帧（`From DS=1, To DS=0`）。此时地址 3 为**原始发送方 MAC，即 X1 的 `D4` 接口 MAC**；地址 1 才是 M1 的 MAC，地址 2 是 AP1 的 BSSID。

题图只标了接口代号，没有提供真实 48 位 MAC 值，因此不能编造具体十六进制地址。

**（3）PC1 子网为 `211.73.1.128/28`。**

掩码 `255.255.255.240`，地址范围 `128～143`，网络地址 `211.73.1.128`，广播地址 `211.73.1.143`，可用地址 `129～142` 共 14 个。

- 默认网关：**`211.73.1.129`**。
- PC1 已占用 `211.73.1.134`，网关占用 `.129`，故其余可分配地址数为 **`14−2=12` 个**。

**（4）R1 目的网络路由：**

| 目的网络 | 子网掩码 | 出接口 |
| --- | --- | --- |
| **`211.73.1.128`** | **`255.255.255.240`（/28）** | **`D11`** |
| **`211.73.1.144`** | **`255.255.255.240`（/28）** | **`D10`** |
| **`0.0.0.0`** | **`0.0.0.0`** | **`D9`** |

第二项等于把 PC2 的 `211.73.1.144/29` 和 M1 的 `211.73.1.152/29` **聚合为 `211.73.1.144/28`**，二者都经 X1 与 R1 的 `D10` 路径到达。`D9` 为通向 Internet 的默认出口。图中未明确标注 R1→X1 互连接口的 IP，因此路由表只写确定的出接口，不虚构下一跳 IP。

### 易错点

“同一接入点下的用户”不等于同一 IP 子网：此题中 PC2 与 M1 是**不同 `/29`**。默认网关属于主机所属子网，不能把网络地址 `.128` 直接作为网关。`802.11` 地址 3 不是固定等于无线站自己的 MAC，而是取决于 `To DS`、`From DS` 两标志和转发方向。

</Solution>
</Question>

## 第4套试卷 · 第47题

<Question id="wd408-2027-s04-q47" type="essay" number={47} points={9} tags="来源:王道8套卷第4套, 考点:VLAN广播域, 考点:ARP与默认网关, 考点:NAT与PAT, 考点:DNS故障排查">

局域网拓扑见图。R 是支持 NAT 的路由器，其 E0 为 `192.168.0.1/24`，MAC 为 `00-11-11-11-11-A1`；S 是支持 802.1Q 的交换机，**VLAN10：端口 1、2、5；VLAN20：端口 3、4**；AP 为桥接式无线接入点。H1、H2 分别在端口 1、2，默认网关均为 `192.168.0.1`；AP 接端口 3，DHCP 服务器接端口 4；H3、H4 从 DHCP 获取地址。**本题只讨论 H1 所属 VLAN10 出口上网，不假设图中已经实现 VLAN20 与 VLAN10 间的三层路由。**

![](/images/27王道8套卷1025/p045-1.svg)

1. VLAN10 与 VLAN20 是否同属一个二层广播域？H1 的广播以太网帧能直接传给 H3 吗？
2. H1 在浏览器中输入 `www.s.com`，经 Internet 访问 Web 服务器。说明 DNS 解析需要的条件、H1 ARP 查询的对象、IP 层目的地址与下一跳的关系，以及 H1 初始发出的以太网帧目的 MAC。
3. H1 的私网 IP 报文经 R 做 NAT/PAT 后向 Internet 转发。描述 H1 的二层转发路径、源／目的 IP 在 R 上可能发生的变化，以及 R **外网出口处**的以太网帧目的 MAC 应属于哪个设备。
4. H1 可以 ping 通 `192.168.0.1`，且浏览器已经得到 Web 服务器公网 IP，但 HTTP 请求总超时。假设 R 的接口与默认路由工作正常、NAT 功能已启用，**但尚未验证 NAT 转换／过滤规则**。候选故障为：① NAT/PAT 或过滤规则错误；② H1 默认网关填错；③ DNS 服务器地址错误。选最有针对性的故障项并解释。

<Solution>

### 参考答案

**（1）不是同一广播域，H1 的二层广播不能直接到达 H3。**

VLAN10 只在 S 的 `1、2、5` 端口传递该 VLAN 的广播；AP、H3 属于 VLAN20 的二层路径（端口 3）。即使图示两个 VLAN 的主机使用相似或相同的 `192.168.0.0/24` 地址，**IP 前缀相同不会合并两个 VLAN 的二层广播域**。

**（2）H1 访问 Web 的主机侧流程：**

1. 浏览器若尚不知道 `www.s.com` 对应公网 IP，则通过系统 DNS 解析取得 Web 服务器 IP；**若存在有效的本地 DNS 缓存则可以不再发起 DNS 网络查询**。
2. 目的 IP 不是 `192.168.0.0/24` 内的直连地址，H1 按自己的掩码 `255.255.255.0` 和路由表决定使用**默认网关 `192.168.0.1`**。IP 分组目的地址仍是 **Web 服务器公网 IP**，并不会被替换成网关 IP。
3. H1 在 VLAN10 内查询默认网关 `192.168.0.1` 的 MAC（ARP 缓存已有时可省略广播查询）。ARP 应答给出 **`00-11-11-11-11-A1`**。
4. H1 构造以太网帧，源 MAC 为自身 **`00-11-11-11-11-01`**，目的 MAC 为 **R 的 E0：`00-11-11-11-11-A1`**；帧承载的 IP 数据报仍以 Web 服务器公网 IP 为目的。
5. 使用 TCP 连接、HTTP 交换数据；若为 HTTPS，还需在 TCP 上进行 TLS 握手，但这与默认网关的 ARP 对象无关。

**（3）链路与 NAT：**

- LAN 二层路径：**H1 → S 端口 1 → S 端口 5 → R 的 E0**。S 按 VLAN10 的 MAC 转发表转发帧，不修改 IP 地址。
- R 处理 IP 分组时执行 NAT（常用 PAT），一般把 **源私网 IP `192.168.0.11`**（以及有需要时的源端口）转换为 R 的公网出口 IP（及映射端口），**目的 IP 仍为 Web 服务器的公网地址**。返回流量依映射反向转换。
- R 向外网发送时重新封装下一跳链路帧：若出口为以太网，**目的 MAC 是该条外网链路上“下一跳路由器”的 MAC**，而不是远端 Web 服务器的 MAC 或 R 自己 E0 的 MAC；若外网出口使用 PPP 等无 MAC 帧格式，则**不存在以太网目的 MAC 字段**。原图并未说明 R 的外网二层技术，不能无条件写出某个具体 MAC。

**（4）最有针对性的是** **① NAT／转发过滤规则错误**。

已能 ping 到 `192.168.0.1`，说明 H1 的本地到网关路径与配置在常规前提下可用，② 与症状不符；域名已经被成功解析，③ 也无法解释解析成功后的 HTTP 数据持续超时。NAT/PAT 映射不生效或过滤规则阻断 HTTP 流量，都可能让请求发不出或回包无法返回。

**校订说明：** 原转写的第 4 问同时写“R 的 NAT 功能及路由均正确”和“选 NAT 规则错误”，条件冲突；此处将“功能已启用”与“规则已验证正确”分开。此外，图把两个 VLAN 的若干主机均标为 `192.168.0.0/24`，且只画出 R 接在 VLAN10 的一个 E0 端口，**不足以推断 VLAN 间路由已配置**。如果实际要求跨 VLAN 通信，需额外正确设计三层 VLAN 接口／网关及不冲突的 IP 子网；不影响本题 H1 到 Internet 的分析。

</Solution>
</Question>

## 第5套试卷 · 第47题

<Question id="wd408-2027-s05-q47" type="essay" number={47} points={9} tags="来源:王道8套卷第5套, 考点:变长子网掩码VLSM, 考点:PPP点到点地址, 考点:路由汇总, 考点:ARP次数">

某企业内网分配地址块 `160.10.10.0/24`，经核心路由器 R1 和外部路由器 R2 接入 Internet。部门 1、2、3 有计算机 **112、60、29** 台，且每个部门还要为 R1 的 LAN 网关接口预留一个可用 IP，部门 1 包含可被公网访问的 Web 服务器。三个部门采用以太网交换机 S1～S3，R1 与 R2 通过 **PPP** 点到点链路互连。部门 1～3 按地址从低到高分配子网，尽量节约空间；图示 R1 的 WAN1 地址为 `198.10.10.18/30`。

![](/images/27王道8套卷1025/p054-1.svg)

1. 为 3 个部门划分地址块（CIDR），并给出部门 1 一个合理的默认网关 IP。
2. R2 的 WAN2 在同一 `/30` 链路上，可分配什么 IP？写出计算。
3. 为了让 Internet 能把数据送回企业内网，给出 R2 至少需要的**企业网路由**（可作地址聚合；注明直连 WAN 网络），若其他 Internet 路由未在图中给出，不要求臆造。
4. Internet 主机的请求已到 R2，随后经 R1 转发到部门 1 的 Web 服务器。**R2、R1 和其他设备开始时 ARP 缓存均为空**；在该单向转发路径上需要多少次 ARP 地址解析？不统计对端服务器回包。

<Solution>

### 参考答案

**（1）按主机需求降序进行 VLSM：**

| 部门 | 计算机 + LAN 网关 | 最小掩码 | 子网 | 可用地址数 |
| --- | ---: | --- | --- | ---: |
| 部门 1 | `112+1=113` | `/25` | **`160.10.10.0/25`** | 126 |
| 部门 2 | `60+1=61` | `/26` | **`160.10.10.128/26`** | 62 |
| 部门 3 | `29+1=30` | `/27` | **`160.10.10.192/27`** | 30 |

部门 1 主机范围 `160.10.10.1～126`，默认网关可以取 **`160.10.10.1`**（只需保证与主机不冲突）。部门 2 范围 `.129～.190`，部门 3 范围 `.193～.222`；剩余 `160.10.10.224/27` 未分配，可用于扩展。

**（2）WAN2 = `198.10.10.17/30`。**

`/30` 掩码为 `255.255.255.252`，第四字节每 4 个地址构成子网。`198.10.10.18` 所在网段为：

- 网络地址 `198.10.10.16`；
- 可用主机地址 `.17`、`.18`；
- 广播地址 `.19`。

WAN1 已使用 `.18`，故 R2 WAN2 取 **`.17`**。

**（3）R2 中最关键的是通向内网的聚合路由：**

| 目的网络 | 掩码 | 下一跳／备注 |
| --- | --- | --- |
| **`160.10.10.0`** | **`255.255.255.0`（/24）** | **经 PPP 发往 R1 `198.10.10.18`** |
| `198.10.10.16` | `255.255.255.252`（/30） | **WAN2 的直连点到点链路** |

企业内部的三个子网 `/25 + /26 + /27` 都落入分配给 R1 的整个 `/24`，R2 可只保留一条**通向 R1 的 `/24`**，同时可覆盖暂未分配的末尾 `/27`。R2 若还需要把数据转发到其他 Internet 网段，其相应出口路由／缺省路由取决于图中未给出的外网接口与上游网络，**不能据图给出具体下一跳**。此处只列与本题有关的最少路由项。

**（4）仅需 `1` 次 ARP 解析。**

1. **R2→R1：PPP** 是点到点链路，不使用以太网目的 MAC，故 **`0` 次 ARP**。
2. **R1→Web 服务器：以太网**。R1 已知 Web IP 所在部门 1 直连网段，发送前需以 ARP 求得 **Web 服务器网卡的 MAC**，所以 **`1` 次 ARP**。
3. S1 为二层交换设备，依据 MAC 表转发帧，不再为转发该 IP 分组进行 ARP。

ARP 不会在一个 IP 分组每经过一台交换机时执行一次；同样，本题也不应把 PPP 误当需要 ARP 的以太网。
