<Question id="wd408-2027-s07-q01" type="single" tags="王道8套卷, 第7套, 数据结构, 考点:带头结点单链表的头插法" points={2} number={1}>

一个带头结点的单链表，头指针为 `L`，尾指针 `r` 指向最后一个数据结点。要使结点在链表中的顺序与**逐次插入的顺序相反**，若新结点指针为 `p`，应采用哪组操作？假设链表当前已有至少一个数据结点，且本题只考虑插入新结点所需的指针操作。

<Option>`L->next = p; p->next = L->next;`</Option>
<Option correct>`p->next = L->next; L->next = p;`</Option>
<Option>`L->next = p; r = p;`</Option>
<Option>`p->next = r;`</Option>

<Solution>

**答案：B。** 要让后插入的结点排在先插入结点的前面，应使用**头插法**：先让新结点接上原首元结点，再让头结点指向新结点。

```c
p->next = L->next;  // 保留原链表，p 指向原首元结点
L->next = p;        // 头结点改为指向 p
```

这两句的**次序不能交换**。A 先执行 `L->next=p`，随后 `p->next=L->next` 实际变为 `p->next=p`，出现自环。C 仅修改头指针域和尾指针，既丢失原首元结点的连接，也没有正确设置 `p->next`；D 只修改 `p` 的后继而没有把 `p` 接入现有链表。

**补充：**当原链表为空时，头插后尾指针也应更新为 `p`；题目明确已有数据结点，是为了使四组操作有唯一答案。

</Solution>
</Question>

<Question id="wd408-2027-s07-q02" type="single" tags="王道8套卷, 第7套, 数据结构, 考点:链式栈出栈与栈顶指针" points={2}>

用不带头结点的单链表实现链栈，结点含 `data` 和 `link` 两个域，`top` 指向栈顶。假设栈非空，仅考虑**取得栈顶元素并更新栈顶指针**（原结点空间的释放另行处理），将出栈值保存到 `x` 中，正确的操作为（ ）。

<Option correct>`x = top->data; top = top->link;`</Option>
<Option>`top = top->link; x = top->data;`</Option>
<Option>`x = top; top = top->link;`</Option>
<Option>`x = top->data;`</Option>

<Solution>

**答案：A。** 链栈在链头进行入栈和出栈。出栈时先取得**原栈顶的值**，再令 `top` 指向其后继。

```c
Node *old = top;
x = old->data;
top = old->link;
free(old); // 动态分配结点且需要释放时，再执行这一步
```

- B 先移动 `top`，取到的是下一个结点的数据；若原栈只有一个结点，还会解引用空指针。
- C 把结点指针本身赋给 `x`，不是把数据域赋给 `x`。
- D 没有修改栈顶，未完成出栈。

**易错点：**需要真正销毁动态分配的栈顶结点时，还必须保存原指针并释放；题目选项只考查取值与栈顶更新，不应据此认为两条语句已经完成内存回收。

</Solution>
</Question>

<Question id="wd408-2027-s07-q03" type="single" tags="王道8套卷, 第7套, 数据结构, 考点:栈的合法出栈序列" points={2}>

六个元素按 $6,5,4,3,2,1$ 的次序依次入栈，允许入栈和出栈操作交替进行。下列**不可能**出现的出栈序列是（ ）。

<Option>$5,4,3,6,1,2$</Option>
<Option>$4,5,3,1,2,6$</Option>
<Option correct>$3,4,6,5,2,1$</Option>
<Option>$2,3,4,1,5,6$</Option>

<Solution>

**答案：C。** 栈是后进先出（LIFO），判断一个序列是否可能时，从输入序列按顺序压栈，只有当**目标出栈元素恰好在栈顶**时才可弹出。

考察 C：为弹出 $3$，必须已压入 $6,5,4,3$，依次弹出 $3,4$ 后，栈从底到顶还剩 $6,5$。题目下一项要求弹出 $6$，但此时 **$5$ 压在 $6$ 上方**，无法绕过 $5$ 直接弹出 $6$，因此 C 不合法。

其他三个序列均可通过如下操作实现（“入”后接压入值，“出”后接弹出值）：

- A：入 $6,5$ → 出 $5$ → 入 $4$ → 出 $4$ → 入 $3$ → 出 $3,6$ → 入 $2,1$ → 出 $1,2$。
- B：入 $6,5,4$ → 出 $4,5$ → 入 $3$ → 出 $3$ → 入 $2,1$ → 出 $1,2,6$。
- D：入 $6,5,4,3,2$ → 出 $2,3,4$ → 入 $1$ → 出 $1,5,6$。

**技巧：**不必枚举所有栈操作；只要发现目标元素上方仍压有一个必须以后才能出栈的元素，就可判定不合法。

</Solution>
</Question>

<Question id="wd408-2027-s07-q04" type="single" tags="王道8套卷, 第7套, 数据结构, 考点:KMP算法next数组" points={2}>

模式串 `acaba` 按**从 1 开始编号**的传统 KMP `next` 数组约定：`next[1]=0`，对 $j>1$，`next[j]` 等于前缀 $P[1\ldots j-1]$ 的最长相等真前后缀长度加 $1$。其 `next[1..5]` 为（ ）。

<Option>`01234`</Option>
<Option>`01212`</Option>
<Option correct>`01121`</Option>
<Option>`01230`</Option>

<Solution>

**答案：C。** 题目采用的是**教材传统的一基下标 `next` 定义**，并不是 `nextval`，也不是零基下标的 `lps` 长度表。

| $j$ | 参与计算的前缀 $P[1..j-1]$ | 最长相等真前后缀 | `next[j]` |
| --- | --- | --- | --- |
| 1 | 空 | —（特殊定义） | 0 |
| 2 | `a` | 空，长度 0 | 1 |
| 3 | `ac` | 空，长度 0 | 1 |
| 4 | `aca` | `a`，长度 1 | 2 |
| 5 | `acab` | 空，长度 0 | 1 |

因此从左向右写成 **`0 1 1 2 1`**，即 `01121`。

**易错点：**计算第 $j$ 项时，只考察 $j$ **之前**的子串，而不是包括当前字符的子串；不同教材的 `next`、`nextval`、`lps` 表不能混用。

</Solution>
</Question>

<Question id="wd408-2027-s07-q05" type="single" tags="王道8套卷, 第7套, 数据结构, 考点:二叉树前序与中序遍历" points={2}>

下列二叉树中，**前序遍历序列与中序遍历序列相同**的有（ ）。

Ⅰ. 只有一个根结点的二叉树。

Ⅱ. 根结点没有右孩子的二叉树（左子树可非空）。

Ⅲ. 所有非叶结点均只有左孩子的二叉树。

Ⅳ. 所有非叶结点均只有右孩子的二叉树。

<Option>仅Ⅰ</Option>
<Option>Ⅰ、Ⅱ、Ⅳ</Option>
<Option>Ⅰ、Ⅲ</Option>
<Option correct>Ⅰ、Ⅳ</Option>

<Solution>

**答案：D。** 前序遍历顺序为**根—左—右**，中序遍历为**左—根—右**。要使两种遍历序列一致，每棵非空子树的根都必须在中序遍历时率先出现，这意味着它的**左子树必须为空**。

- **Ⅰ 正确：**单结点树的前序、中序均只输出根。
- **Ⅱ 不一定：**若根有左孩子，中序先访问左孩子，前序却先访问根；不能仅由“无右孩子”保证一致。
- **Ⅲ 错误（多于一个结点时）：**向左延伸的链，前序自上而下，中序自下而上，次序相反。
- **Ⅳ 正确：**只有右孩子的链，每个结点均无左子树，因此前序、中序均依次自根向右访问。

**概括：**对于结点标识互不相同的非空二叉树，前序与中序完全相同，当且仅当**所有结点的左子树均为空**。

</Solution>
</Question>

<Question id="wd408-2027-s07-q06" type="single" tags="王道8套卷, 第7套, 数据结构, 考点:并查集与Kruskal最小生成树" points={2}>

在以下算法中，通常需要使用**并查集**维护顶点连通关系的是（ ）。

<Option>Floyd 算法</Option>
<Option correct>Kruskal 算法</Option>
<Option>Prim 算法</Option>
<Option>Dijkstra 算法</Option>

<Solution>

**答案：B。** Kruskal 算法对无向连通带权图按边权从小到大考虑边。对于候选边 $(u,v)$，需判断其两端是否已经属于同一连通分量：

1. `find(u)` 与 `find(v)` **不同**，说明加边不会形成环，选入生成树并执行 `union(u,v)`。
2. `find(u)` 与 `find(v)` **相同**，说明已经存在连通路径，再加该边会形成环，舍弃。

并查集利用路径压缩和按秩（或按大小）合并，可以高效支持该过程。

Floyd 通过动态规划求各点对最短路径；Prim 通过不断选取连接已选顶点集与未选顶点集的最小权边构造生成树；Dijkstra 逐步确定单源最短路径。它们的标准实现都不**必需**并查集。

</Solution>
</Question>

<Question id="wd408-2027-s07-q07" type="single" tags="王道8套卷, 第7套, 数据结构, 考点:AVL树RR型失衡与单旋转" points={2}>

下图是一棵 AVL（平衡二叉）树，字母仅表示结点而非关键字。在结点 $D$ 的**右子树**插入新结点 $F$，再按 AVL 插入规则恢复平衡。调整后，**平衡因子绝对值为 $1$ 的分支结点**有多少个？（平衡因子定义为左子树高度减右子树高度。）

![](/images/27王道8套卷1025/p064-1.svg)

<Option>0</Option>
<Option correct>1</Option>
<Option>2</Option>
<Option>3</Option>

<Solution>

**答案：B。** 插入前树形为 `A` 的左孩子 `B`、右孩子 `C`；`C` 的左孩子为 `E`，右孩子为 `D`。插入 $F$ 后，$F$ 成为 $D$ 的右孩子：

```text
      A
     / \
    B   C
       / \
      E   D
           \
            F
```

此时根 $A$ 的右子树比左子树高 $2$，新结点位于其**右孩子的右子树**，属于 **RR 型失衡**，对 $A$ 做一次**左旋**：

```text
        C
       / \
      A   D
     / \   \
    B   E   F
```

调整后分支结点为 $A,C,D$：

- $A$ 的左右子树均为一层，平衡因子 $0$。
- $C$ 的左右子树均为两层，平衡因子 $0$。
- $D$ 的左子树为空、右子树是 $F$，平衡因子 $-1$。

因此只有 **$D$ 一个分支结点**的平衡因子绝对值等于 $1$。这里不能把叶结点 $B,E,F$ 算入“分支结点”。

</Solution>
</Question>

<Question id="wd408-2027-s07-q08" type="single" tags="王道8套卷, 第7套, 数据结构, 考点:AVL插入失衡与旋转分类" points={2}>

在 AVL 树中插入一个结点后，设从新结点向根回溯遇到的**最低不平衡结点**为 $a$。已知**插入前**结点 $a$ 的左孩子平衡因子为 $-1$，右孩子平衡因子为 $0$（平衡因子为左高减右高），则下列哪些调整方式**有可能**恢复以 $a$ 为根的子树的平衡？

Ⅰ. 左旋。

Ⅱ. 先左旋后右旋。

Ⅲ. 先右旋后左旋。

Ⅳ. 右旋。

<Option correct>Ⅰ、Ⅲ</Option>
<Option>Ⅱ、Ⅳ</Option>
<Option>Ⅰ、Ⅱ</Option>
<Option>Ⅲ、Ⅳ</Option>

<Solution>

**答案：A（Ⅰ、Ⅲ）。** 关键是“**最低不平衡结点**”，意味着沿插入路径位于 $a$ 以下的结点在需要调整时均未失衡。

- 左孩子原平衡因子为 $-1$（右高）。若在它的右子树继续插入并使其高度上升，该左孩子会先变为 $-2$，不平衡位置就不可能仍以 $a$ 为最低失衡点；若在它的左子树插入使其平衡因子变为 $0$，其高度并不增大，不能因此让 $a$ 新增一级左子树高度而失衡。因此此处不会出现需要对 $a$ 进行 LL / LR 修复的情形。
- 右孩子原平衡因子为 $0$。在其**右子树**插入可以使右孩子变为 $-1$ 而仍平衡，并让原本右重的 $a$ 变为 $-2$：这是 RR 型，对 $a$ **左旋**（Ⅰ）。
- 在其**左子树**插入也可能使右孩子变为 $+1$ 而仍平衡，并让 $a$ 变为 $-2$：这是 RL 型，先对右孩子**右旋**，再对 $a$ **左旋**（Ⅲ）。

所以可能的调整只有Ⅰ和Ⅲ。**注意：**“旋转方式是否可能”要联系插入前的子树平衡因子和“最低不平衡”这一限制，不能只看 $a$ 失衡后高度差的符号。

</Solution>
</Question>

<Question id="wd408-2027-s07-q09" type="single" tags="王道8套卷, 第7套, 数据结构, 考点:折半插入排序比较次数" points={2}>

对数组 $A[1\ldots n]$ 做**升序折半插入排序**。处理第 $i$ 个待插元素 `key` 时，在已排序的 $A[1\ldots i-1]$ 中使用二分查找，初始化 `low=1`、`high=i-1`；当 `low<=high` 时取 `mid=floor((low+high)/2)`，只统计执行条件 `A[mid] > key` 的次数。对于初始序列 $\{6,2,9,1,5\}$，整个排序过程该比较执行了多少次？

<Option correct>7</Option>
<Option>8</Option>
<Option>9</Option>
<Option>10</Option>

<Solution>

**答案：A。** 按题目给出的单条件折半查找，每次循环执行一次 `A[mid] > key`，不额外统计循环判断或移动元素。

| 本趟 `key` | 此前有序部分 | 依次与哪些值比较 | 比较次数 | 插入后序列 |
| --- | --- | --- | --- | --- |
| $2$ | $[6]$ | $6$ | 1 | $[2,6]$ |
| $9$ | $[2,6]$ | $2,6$ | 2 | $[2,6,9]$ |
| $1$ | $[2,6,9]$ | $6,2$ | 2 | $[1,2,6,9]$ |
| $5$ | $[1,2,6,9]$ | $2,6$ | 2 | $[1,2,5,6,9]$ |

故总次数为

$$
1+2+2+2=\boxed{7}.
$$

**易错点：**折半插入排序的元素移动仍可能达到 $O(n^2)$，但决定插入位置的比较次数为 $O(n\log n)$；本题只算明确定义的 `A[mid] > key` 比较，不应把元素移动也计入。

</Solution>
</Question>

<Question id="wd408-2027-s07-q10" type="single" tags="王道8套卷, 第7套, 数据结构, 考点:排序算法运行时间与初始有序度" points={2}>

下列排序算法组合中，**主要比较次数的渐近阶及常规实现的时间复杂度上界，不随输入初始有序程度而改变**的是（ ）。

<Option>直接插入排序与快速排序</Option>
<Option>归并排序与快速排序</Option>
<Option correct>简单选择排序与归并排序</Option>
<Option>直接插入排序与归并排序</Option>

<Solution>

**答案：C。** 简单选择排序第 $i$ 趟都需要在未排序区间寻找最小元素，比较次数固定为

$$
(n-1)+(n-2)+\cdots+1=\frac{n(n-1)}2,
$$

无论输入是否有序，其时间复杂度均为 $\Theta(n^2)$。标准**自顶向下归并排序**总是递归划分并归并，运行时间量级为 $\Theta(n\log n)$，与原始排列的有序程度无关（具体比较次数可能不同）。

直接插入排序对已排序输入可达到 $\Theta(n)$，对逆序输入通常需要 $\Theta(n^2)$；普通快速排序的划分平衡程度与输入及选主元规则有关，可由 $\Theta(n\log n)$ 恶化至 $\Theta(n^2)$。

**注意表述边界：**归并排序**具体的比较次数**可以随数据不同而变化；题目考查的是典型时间复杂度级别，而非所有机器指令执行次数严格相等。

</Solution>
</Question>

<Question id="wd408-2027-s07-q11" type="single" tags="王道8套卷, 第7套, 数据结构, 考点:外部排序多路归并趟数" points={2}>

外部排序开始时有 $29$ 个**初始归并段**，每一趟做 $k$ 路平衡归并，且一趟最多把每 $k$ 个归并段合并成一个。若希望**至多经过 3 趟归并**得到一个有序段，则归并路数 $k$ 至少为（ ）。

<Option>2</Option>
<Option>3</Option>
<Option correct>4</Option>
<Option>5</Option>

<Solution>

**答案：C。** 在每趟最多 $k$ 路归并的条件下，完成全部归并所需趟数为

$$
S=\left\lceil\log_k 29\right\rceil.
$$

若要 $S\le 3$，至少需要 $k^3\ge29$。检查邻近整数：

$$
3^3=27<29,\qquad 4^3=64\ge29.
$$

因此 $k_{\min}=\boxed{4}$。也可用段数变化检验：三路归并最多得到 $29\to10\to4\to2$，三趟后仍剩两段；四路归并则 $29\to8\to2\to1$，正好三趟完成。

**易错点：**初始归并段形成的过程不计入本题所说的 $3$ 趟；“29 条记录”只有在每条记录都作为一个初始归并段时才能直接代入该公式。

</Solution>
</Question>

<Question id="wd408-2027-s07-q12" type="single" tags="王道8套卷, 第7套, 计算机组成原理, 考点:补码与内存字节编址" points={2}>

某 32 位计算机中 `int` 为 **32 位二进制补码整数**，数组声明为：

```c
int buf[4] = {-2, 103, -10, -20};
```

设 `buf` 首地址为 `0x8049320`，按字节编址，问地址 `0x804932a` 中存放的字节是（ ）。

<Option>`0000 0000`</Option>
<Option>`1111 1010`</Option>
<Option>`1111 0101`</Option>
<Option correct>`1111 1111`</Option>

<Solution>

**答案：D。** 目标地址相对数组首地址的偏移为

$$
\mathrm{0x804932a}-\mathrm{0x8049320}=\mathrm{0xA}=10\ \text{B}.
$$

每个 `int` 占 $4\ \text{B}$，因此偏移 $10=2\times4+2$ 对应 `buf[2]`（第三个整型）的**第 3 个字节**，即数值 $-10$ 的一个字节。

32 位补码：

$$
-10=\mathrm{0xFFFFFFF6}.
$$

它的四个字节中，除了最低有效的 `F6` 之外，其余三个均为 `FF`。在常见小端排列下，第 3 个字节为 `FF`；在大端排列下，第 3 个字节也为 `FF`，故本题**无需额外限定字节序**。

$$
\mathrm{FF}_{16}=1111\ 1111_2.
$$

**易错点：**先定位数组元素，再计算元素内字节偏移；不要把地址尾数 `a` 直接当作元素下标。

</Solution>

<Question id="wd408-2027-s07-q21" type="single" tags="王道8套卷, 第7套, 计算机组成原理, 考点:DMA周期挪用与总线带宽" points={2}>

某同步总线时钟周期为 $200\,\mathrm{ns}$，每周期传输 $1\,\mathrm B$。每条指令需访问主存两次（取指令、取操作数各占一个总线周期），无其他开销。磁盘以 DMA **周期挪用**方式向主存连续传送数据，传输速率为 $1\,\mathrm{MB/s}$，每传送 $1\,\mathrm B$ 占用一个总线周期。忽略 DMA 初始化及中断开销。DMA 传送期间，CPU 指令执行速度较无 DMA 时降低（ ）。约定 $1\,\mathrm{MB}=10^6\,\mathrm B$。

<Option correct>$20\%$</Option>
<Option>$25\%$</Option>
<Option>$50\%$</Option>

$$
\frac{2.5-2.0}{2.5}\times100\%=20\%.

仅有两个进程 $P_0$、$P_1$ 可能进入某临界区。共享变量 `turn` 初值为 $1$，各进程分别取 $i=0$ 或 $i=1$，执行以下代码。假设 `turn` 的单次读写是原子的，但整段判断及赋值**不是原子操作**。该算法（ ）。

```text
repeat
    retry: if (turn != 1) turn = i;
    if (turn != i) goto retry;
    turn = 1-i;
    临界区
    turn = 0;
    剩余区
until false;
```

<Option correct>不能保证进程互斥进入临界区，且可能发生饥饿</Option>
<Option>不能保证进程互斥进入临界区，但保证不会发生饥饿</Option>
<Option>能保证进程互斥进入临界区，但可能发生饥饿</Option>
<Option>既保证互斥，也保证不会发生饥饿</Option>

<Solution>

**答案：A。**互斥与有限等待是两个不同性质，必须分别验证。

**（1）互斥被破坏的反例。**初值 `turn=1`。让 $P_1$ 先执行检查：它看到 `turn=1`，通过判断，随后执行 `turn=0` 并进入临界区。此时 $P_0$ 执行：看见 `turn=0`，赋 `turn=0`，通过判断，再赋 `turn=1`，也进入临界区。**两个进程同时在临界区**，所以不满足互斥。

**（2）不能保证有限等待。**令 $P_1$ 不断完成临界区并循环重新尝试；可以安排一种使两个进程都不断得到 CPU 的交错次序：每次 $P_0$ 执行 `if (turn!=1)` 时恰好看到 `turn=1`，于是它不修改 `turn`；紧接着检查 `turn!=0` 时仍为真，继续回到 `retry`。在这期间 $P_1$ 可反复循环并重新设置 `turn=1`，$P_0$ 可能无限次重试，体现**饥饿（无法保证有限等待）**。

**易错点：**一条变量赋值不是原子锁操作；仅靠 `turn` 的检查与普通赋值，不能自动得到互斥或公平性。

</Solution>

<Option>$16\,\mathrm{kb/s}$</Option>

<Solution>

**答案：C。**停止-等待每发送一帧，都要等该帧的确认返回后才能发下一帧。

传播时延（一程）：

$$
t_p=\frac{1000\,\mathrm m}{20\,\mathrm{m/ms}}=50\,\mathrm{ms}.
$$

一个数据帧的发送时延为：

$$
t_t=\frac{100\times8}{2\times10^6}\,\mathrm s=0.4\,\mathrm{ms}.
$$

忽略确认帧发送时延、处理延迟，则每轮完成时间为

$$
T=t_t+2t_p=0.4+100=100.4\,\mathrm{ms}.
$$

有效速率：

$$
R_{\mathrm{eff}}=\frac{800\,\mathrm{bit}}{0.1004\,\mathrm s}\approx7968\,\mathrm{bit/s}\approx8\,\mathrm{kb/s}.
$$

**注意单位：**这里传播速度是 $20\,\mathrm{m/ms}$，而不是 $2\times10^8\,\mathrm{m/s}$。忽略题给单位会造成三个数量级以上的错误。

</Solution>
</Question>

<Question id="wd408-2027-s07-q37" type="single" tags="王道8套卷, 第7套, 计算机网络, 考点:子网掩码与同子网判断" points={2}>

设各主机均使用子网掩码 `255.255.192.0`，并且处于能够直接二层互通的常规 IPv4 局域网中。以下主机中，**不与** `129.23.144.16` **处于同一子网，需经路由器进行三层转发**的是（ ）。

<Option>`129.23.191.21`</Option>
<Option correct>`129.23.127.222`</Option>
<Option>`129.23.130.33`</Option>
<Option>`129.23.148.127`</Option>

<Solution>

**答案：B。**掩码 `255.255.192.0` 即 `/18`，第三个八位组掩码 `192=11000000_2`，每个子网在第三个八位组的跨度是

$$
256-192=64.
$$

因此其第三个八位组的子网范围依次是 $0$–$63$、$64$–$127$、$128$–$191$、$192$–$255$。

`129.23.144.16` 属于 `129.23.128.0/18`，第三个八位组必须落在 **128–191**：A 的 191、C 的 130、D 的 148 均符合；B 的 127 属于 `129.23.64.0/18`。

所以 B 不同子网，按题设需要经路由器转发。**易错点：**`/18` 不是 `/16`，只比较前两个八位组会误判。

<Question id="wd408-2027-s07-q38" type="single" tags="王道8套卷, 第7套, 计算机网络, 考点:IGMPv2成员报告与多播组管理" points={2}>

**按照 IGMPv2 的主机加入多播组过程**，下列说法正确的是（ ）。

<Option>IGMP 能精确获知各局域网每个多播组的成员总数</Option>
<Option>IGMP 在整个因特网范围内逐一管理所有组播接收者</Option>

<Question id="wd408-2027-s07-q39" type="single" tags="王道8套卷, 第7套, 计算机网络, 考点:TCP端口号与四元组连接" points={2}>

关于 TCP 端口和连接，下列说法正确的是（ ）。

Ⅰ. TCP 端口号为 16 位，其取值共有 $65536$ 种。

Ⅱ. 一台主机同一时刻最多只能建立 $65536$ 条 TCP 连接。

Ⅲ. TCP 连接正常释放后，该连接使用的端口号可在满足协议及系统限制后再次使用。

Ⅳ. 一台服务器可使用**同一个本地 TCP 端口**与不同客户端同时建立多条 TCP 连接。

<Option>Ⅰ、Ⅱ</Option>
<Option>Ⅱ、Ⅲ</Option>
<Option>Ⅰ、Ⅱ、Ⅲ、Ⅳ</Option>
<Option correct>Ⅰ、Ⅲ、Ⅳ</Option>

<Solution>

**答案：D。**判断 TCP 连接时，不能把**端口号个数**直接等同于**连接条数**。

- Ⅰ 正确：TCP 首部源端口、目的端口字段均为 16 位，端口号范围 `0`–`65535`，共 $2^{16}=65536$ 种。并非所有编号都可供普通应用任意绑定。

- Ⅲ 正确：连接释放后端口可复用，但可能需受到 `TIME_WAIT`、地址绑定策略等条件约束。
- Ⅳ 正确：例如 Web 服务器监听 TCP 443，并可同时服务多台客户端；每条连接的远端地址或远端端口不同。

所以选择**Ⅰ、Ⅲ、Ⅳ**。

</Solution>

<Question id="wd408-2027-s07-q40" type="single" tags="王道8套卷, 第7套, 计算机网络, 考点:FTP访问过程中的IP、ARP、DHCP与ICMP" points={2}>

某计算机刚接入校园**IPv4 以太网**，按题设采用 **DHCP 自动获取 IP 配置**，并通过 **ARP 动态解析缺省网关的 MAC 地址**；随后用 `ftp` 连接校园网外的文件服务器 `202.38.70.25`。假设网络畅通、没有额外诊断或差错报告报文。在上述过程中，**可能完全不需要使用**的是（ ）。

<Option>IP</Option>
<Option correct>ICMP</Option>
<Option>ARP</Option>
<Option>DHCP</Option>

<Solution>

**答案：B。**逐项辨析网络初始化及 FTP 建连所需的协议：

- **IP：**服务器给定了 IPv4 地址，FTP 基于 TCP/IP 传输，IP 必然参与。
- **DHCP：**题目明确通过 DHCP 自动获取地址、掩码、网关等配置，必然使用。
- **ARP：**题目明确在以太网中动态解析网关 MAC 地址，必然使用。
- **ICMP：**主要用于网络差错报告、诊断等；网络工作正常且不主动执行 `ping`、`traceroute` 等操作时，FTP 访问过程可以完全没有 ICMP 报文。

因此选 **ICMP**。

**原题歧义校订：**若未限定 DHCP 动态配置，主机也可能使用静态 IP；若网关 MAC 地址已经由缓存或静态邻居表确定，也可能不再执行 ARP。因此原题“可能未用到”存在多个可选项，本题补全 DHCP、ARP 的使用前提以确保单选唯一。

</Solution>
</Question>
