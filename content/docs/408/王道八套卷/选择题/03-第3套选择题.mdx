<Question id="wd408-2027-s03-q01" type="single" tags="来源:王道8套卷第3套, 考点:Floyd算法及循环次数" points={2} number={1}>

设有一个包含 $n=6$ 个顶点的带权有向图，图中允许存在负权边，但不存在负权环。使用 Floyd 算法求解任意两个顶点间的最短路径，算法的三重循环伪代码如下所示：

```text
for k=1 to n
    for i=1 to n
        for j=1 to n
            if d[i][k]+d[k][j]<d[i][j] then
                d[i][j]=d[i][k]+d[k][j]
```

其中 $d$ 为距离矩阵。若不考虑矩阵初始化与赋值操作的执行代价，仅统计上述伪代码中 `if` 语句条件判断的执行总次数，则该次数为（ ）。

<Option>180</Option>

<Option correct>216</Option>

<Option>240</Option>

<Option>360</Option>

<Solution>

**答案：B（216 次）。** 三重循环的取值范围都是 $1$ 到 $n$；题目统计的是 `if` 条件被判断的次数，而不是条件成立或距离被更新的次数。故

$$
N=n\times n\times n=6^3=216.
$$

负权边、不存在负权环只关系到 Floyd 求最短路的适用性，不影响三个固定循环的迭代次数。即使某次判断为假，仍算一次条件判断。时间复杂度为 $\Theta(n^3)$。

</Solution>

</Question>

<Question id="wd408-2027-s03-q02" type="single" tags="来源:王道8套卷第3套, 考点:循环链表队列与入队出队时间复杂度" points={2}>

假设链式队列 $Q$ 采用不带头结点的循环单链表存储，并且只设队尾指针 `rear`，若队列中有 $n$ 个结点，则出队和进队操作的时间复杂度分别为（ ）。

<Option correct>$O(1), O(1)$</Option>

<Option>$O(1), O(n)$</Option>

<Option>$O(n), O(1)$</Option>

<Option>$O(n), O(n)$</Option>

<Solution>

**答案：A。** 不带头结点的循环单链表只保留尾指针 `rear` 时，**队头是 `rear->next`**（非空队列）。

- **入队：**新结点接入 `rear` 之后，再让 `rear` 指向新结点；涉及常数次指针修改，$O(1)$。
- **出队：**直接删除 `rear->next` 指向的队头，更新 `rear->next`；若原来只有一个结点，删除后置 `rear=NULL`；均为 $O(1)$。

注意这里必须利用循环链表的首尾相接关系；若只有非循环单链表的尾指针，出队就不能这样直接定位表头。

</Solution>

</Question>

<Question id="wd408-2027-s03-q04" type="single" tags="来源:王道8套卷第3套, 考点:顺序存储和三叉链表空间比较" points={2}>

<Option correct>$d < 12n/(k - n)$</Option>

<Option>$d > 12n/(k - n)$</Option>

<Option>$d < 12n/(k + n)$</Option>

<Option>$d > 12n/(k + n)$</Option>

<Solution>

**答案：A。** 三叉链表中，每个结点含数据域以及指向双亲、左孩子、右孩子的 3 个 4B 指针域，合计每结点 $d+12$ 字节。$n$ 个结点需

$$

$$

</Solution>

<Option>$35/12$</Option>

<Option>$31/12$</Option>

<Option correct>$37/12$</Option>

<Option>$39/12$</Option>

<Solution>

**答案：C（$37/12$）。** 成功查找的平均查找长度（ASL）是各个元素成功比较次数的加权平均。概率相等时，等于折半判定树全部结点层数之和除以元素个数。

| :---: | :---: | :---: | :---: | :---: |
| A | 2 | 1 | 30% | 30% |

| C | 4 | 1.5 | 20% | 50% |

\mathrm{CPI}_{\mathrm{avg}}=\sum_i p_i\,\mathrm{CPI}_i.
$$

$$
\begin{aligned}
\mathrm{CPI}_{M1,C1}&=0.3\cdot2+0.5\cdot3+0.2\cdot4=2.9,\\
\mathrm{CPI}_{M2,C1}&=0.3\cdot1+0.5\cdot2+0.2\cdot1.5=1.6.
\end{aligned}

\begin{aligned}

$$
\frac{S_{M2}}{S_{M1}}=\frac{T_{M1}}{T_{M2}}=\frac{3.2/800}{1.45/400}=\frac{1.6}{1.45}\approx1.10.
$$

因此选择 $(1.1,1.1)$。**不能只看时钟频率**，也不能先把各类 CPI 简单平均。

</Solution>

- **D 错：**差错**检测**不等于差错**恢复**；PPP 没有内置普遍的 ACK/ARQ 重传机制。

与 HDLC 的可靠传输工作模式区分：不要因为 PPP 有 FCS，就推断它一定有确认重传。

</Solution>

R1 和 R2 是同一自治系统内使用 RIP 的相邻路由器。R1 当前路由表和 R2 向 R1 通告的距离向量如下。假设表中“距离”表示 RIP 跳数，直接相连网络距离为 $0$。R1 根据来自 R2 的报文更新相应路由表项，按网络 $10.0.0.0$、$20.0.0.0$、$30.0.0.0$ 的顺序，更新后的距离依次为（ ）。

**表 1：R1 当前路由表**

| 目的网络 | 距离 | 下一跳 |
| :---: | :---: | :---: |
| 10.0.0.0 | 0 | 直接 |
| 20.0.0.0 | 7 | R2 |
| 30.0.0.0 | 4 | R2 |

**表 2：R2 的距离向量通告**

| 目的网络 | 距离 |
| :---: | :---: |
| 10.0.0.0 | 3 |
| 20.0.0.0 | 4 |
| 30.0.0.0 | 3 |

<Option>$0,4,3$</Option>

| :---: | :---: | :---: | :---: |
| 10.0.0.0 | 0 / 直连 | $3+1=4$ | 保留直连的 **0** |
| 20.0.0.0 | 7 / R2 | $4+1=5$ | 同一下一跳 R2，更新为 **5** |
| 30.0.0.0 | 4 / R2 | $3+1=4$ | 同一下一跳 R2，更新为 **4** |

<Question id="wd408-2027-s03-q39" type="single" tags="来源:王道8套卷第3套, 考点:字节序号空间数据速率与分组最大生存时间" points={2}>

一种类似 TCP 的可靠**字节流**传输协议，链路数据速率为 $2.5\mathrm{\ Gb/s}$，其中 $1\mathrm{\ G}=2^{30}$，每个**字节**占用一个序号。假定 PDU 最大生存时间为 $51.2\mathrm{\ s}$，并采用**恰在生存期届满时旧 PDU 已失效、可复用其序号**的理想化边界约定。为了避免在旧 PDU 仍存活时重复使用字节序号，该协议首部序号字段的最小长度为（ ）。

<Option>$64\mathrm{\ bit}$</Option>
<Option>$37\mathrm{\ bit}$</Option>
<Option correct>$34\mathrm{\ bit}$</Option>
<Option>$32\mathrm{\ bit}$</Option>

<Solution>

**解析：**选择 C（$34\mathrm{\ bit}$）。这是一道**速率—生存时间—序号空间**关系题；协议按**字节**编号，务必先把 bit/s 转换为 B/s。

$$
\begin{aligned}
R_{\mathrm{bytes}}&=\frac{2.5\times2^{30}}8\mathrm{\ B/s},\\
N&=R_{\mathrm{bytes}}\cdot51.2
=\frac{2.5\times51.2}{8}\times2^{30}\\
&=16\times2^{30}=2^{34}\text{ 个字节}.
\end{aligned}
$$

$n$ 位序号有 $2^n$ 种不同取值；依题干明确的**生存期届满即失效**的理想化边界，要求 $2^n\ge2^{34}$，故

$$
\boxed{n_{\min}=34}.
$$

- **37 位**是把 $2.5\mathrm{\ Gb/s}$ 当成“每位数据分配一个序号”直接计算的结果；本题是**字节流序号**，因此不选 37。
- **工程注意：**实际协议不能仅凭此等式断定安全，还需考虑序号窗口大小、乱序、计时误差和安全余量；若额外规定复用必须严格晚于最大生存时间而不允许等号，则需要大于 $2^{34}$ 的序号空间（至少 35 位）。原题没有明确临界等号的处理，本版已补充条件，使 34 位成为唯一可判定的答案。

</Solution>

<Question id="wd408-2027-s03-q40" type="single" tags="来源:王道8套卷第3套, 考点:DNS域名解析缓存递归迭代与传输协议" points={2}>

关于 DNS（域名系统）的说法中，**正确**的是（ ）。

<Option>如果整个互联网的 DNS 服务都不可用，即使知道目标主机 IP 地址，也无法向它发送 IP 数据报</Option>
<Option correct>DNS 解析过程中广泛使用高速缓存，可减少重复查询、缩短解析时间，并减轻上级和根域名服务器负荷</Option>
<Option>DNS 只能基于 TCP 传输，目的是提供可靠交付</Option>
<Option>查询到某个权威域名服务器后，如果它不能直接给出最终答案，DNS 必须立即判定整个查询失败</Option>

<Solution>

**解析：**选择 B。DNS 是将域名解析为 IP 地址等资源记录的**分布式、层次化命名系统**。递归解析器、域名服务器通常维护受 TTL 限制的缓存，减少重复查询带来的网络开销与根服务器压力。

- **A 错：**若已经知道对方 IP 地址，在有可用路由与网络连接的情况下，依然可以按 IP 地址通信；DNS 不是 IP 数据报传输的必要前置环节。
- **B 对：**缓存可保存近期获取的 DNS 资源记录，降低解析时延和上级查询次数，需遵守 TTL。
- **C 错：**DNS 通常使用 **UDP 53** 进行查询，也可使用 **TCP 53**（如响应较大、区域传送等），不是“只能 TCP”。
- **D 错：**服务器可能返回转介信息或相应 DNS 响应代码，解析器可继续向其他授权服务器查询；不能简单认为“没有直接给出最终答案”就一定整体失败。此外权威域名服务器通常负责其管辖区内的数据，不必替递归解析器完成全部迭代查询。

**关联考点：**递归与迭代查询、DNS 缓存 TTL、权威服务器和根服务器的区别，以及 DNS 的 UDP/TCP 传输。

</Solution>
