<Question id="wd408-2027-s01-q01" type="single" tags="来源:王道8套卷第1套, 考点:算法的特性" points={2} number={1}>

在下列选项中，不属于算法的主要特征的是（ ）。

<Option>有穷性 &emsp;&emsp;</Option>

<Option>可行性 &emsp;&emsp;</Option>

<Option>确定性 &emsp;&emsp;</Option>

<Option correct>可读性</Option>

<Solution>

**答案依据**：算法应满足五项基本特性：有穷性、确定性、可行性、输入（允许零个输入）和输出（至少一个输出）。

- A 有穷性：必须在有限步骤后终止；属于基本特性。
- B 可行性：每一步操作应能在有限时间内有效执行；属于基本特性。
- C 确定性：相同条件下每一步操作含义明确；属于基本特性。
- D 可读性：属于算法设计追求的优良性质，**不是算法的必要特性**。

</Solution>

</Question>

<Question id="wd408-2027-s01-q02" type="single" tags="来源:王道8套卷第1套, 考点:时间复杂度与循环计数" points={2}>

设 $n$ 是描述问题规模的正整数，则下列程序段的时间复杂度是（ ）。

```c
for (i=1; i<=n; i++) {
    for (j=2*i; j<=n; j++) {
        y+=i*j;
    }
}
```

<Option>$O(n)$ &emsp;&emsp;</Option>

<Option correct>$O(n^2)$ &emsp;&emsp;</Option>

<Option>$O(n \log_2 n)$ &emsp;&emsp;</Option>

<Option>$O(\log_2 n)$</Option>

<Solution>

**解析**：固定外层 $i$ 后，内层从 $j=2i$ 到 $n$，仅当 $2i\le n$ 时执行，次数为 $n-2i+1$。因此总执行次数为

$$
T(n)=\sum_{i=1}^{\lfloor n/2\rfloor}(n-2i+1).
$$

设 $m=\lfloor n/2\rfloor$，有

$$
T(n)=m(n+1)-m(m+1)=m(n-m)=\Theta(n^2).
$$

外层后半段虽然不执行内层，但外层本身的 $O(n)$ 开销不会改变二次阶。因此选 B。易错点：不能把本题内层写成每次倍增的循环；这里是 **起始值** $2i$，而不是令 $j$ 逐次乘 2。

</Solution>

</Question>

在有 6 个结点的二叉树中，结点编号为 1, 2, 3, 4, 5, 6，其中叶结点的编号为 2, 5, 6。该二叉树的先序遍历结果为 1, 4, 3, 2, 5, 6，则遍历结果 1, 4, 6, 3, 5, 2 可能采用的是（ ）。

<Option>先序遍历算法 &emsp;&emsp;</Option>

<Option>中序遍历算法 &emsp;&emsp;</Option>

<Option correct>层次遍历算法</Option>

<Question id="wd408-2027-s01-q04" type="single" tags="来源:王道8套卷第1套, 考点:树与二叉树转换, 考点:卡特兰数" points={2}>

当有 7 个结点的树转换为二叉树后，总共可能有（ ）种不同的形态。

<Option correct>132 &emsp;&emsp;</Option>

<Option>154 &emsp;&emsp;</Option>

<Option>429 &emsp;&emsp;</Option>

<Option>无法确定</Option>

<Solution>

**解析**：采用孩子—兄弟表示法把一棵普通树转换成二叉树时，原树的根没有右兄弟，因此转换所得的二叉树**根结点的右孩子必为空**。

对于包含 $n$ 个结点的有序树，其形态数等于包含 $n-1$ 个结点的二叉树形态数，即卡特兰数

$$
C_{n-1}=\frac{1}{n}\binom{2n-2}{n-1}.
$$

取 $n=7$：

$$
C_6=\frac{1}{7}\binom{12}{6}=\frac{924}{7}=132.
$$

故选 A。**易混点**：任意 7 结点二叉树有 $C_7=429$ 种；本题要求由一棵 7 结点的树转换而来，必须附加“根无右孩子”的限制。

</Solution>

</Question>

<Question id="wd408-2027-s01-q05" type="single" tags="来源:王道8套卷第1套, 考点:哈夫曼编码与前缀码" points={2}>

在一次哈夫曼编码的过程中，若要求编码的长度小于或等于 4，假设现已对两个字符编码为 0 和 10，则最多还可对（ ）个字符进行编码。

<Option>3 &emsp;&emsp;</Option>

<Option correct>4 &emsp;&emsp;</Option>

<Option>5 &emsp;&emsp;</Option>

<Option>6</Option>

<Solution>

**解析**：哈夫曼编码属于前缀编码，任何字符的码字不能是另一码字的前缀。既然已分配码字 `0` 和 `10`，那么其余码字都不能以 `0` 或 `10` 开头，只能以 `11` 开头。

码长不超过 4 时，前缀 `11` 后还可接最多 2 位，共可取以下 **4 个互不为前缀的码字**：`1100`、`1101`、`1110`、`1111`。

因此最多还能编码 4 个字符，选 B。也可用 Kraft 等式验证：已分配码字权重为 $2^{-1}+2^{-2}=3/4$；每个长 4 码字占 $1/16$，至多再容纳 $(1/4)/(1/16)=4$ 个。

</Solution>

</Question>

<Question id="wd408-2027-s01-q06" type="single" tags="来源:王道8套卷第1套, 考点:强连通图的边数" points={2}>

对有 $n$ 个顶点的强连通图，若采用邻接矩阵存储，则其邻接矩阵中至少有（ ）个非零元素。

<Option>$n - 1$ &emsp;&emsp;</Option>

<Option correct>$n$ &emsp;&emsp;</Option>

<Option>$2n - 2$ &emsp;&emsp;</Option>

<Option>$2n$</Option>

<Solution>

**解析**：对至少有 2 个顶点的有向强连通图，从任一顶点都必须能到达其他顶点，因此每个顶点的**出度至少为 1**（入度也至少为 1）。

由有向图出度之和等于弧数得

$$
|E|=\sum_{v\in V}\deg^+(v)\ge n.
$$

下界可以达到：把 $n$ 个顶点连成一条有向环，每个顶点的入度、出度均为 1，全图强连通，恰好有 $n$ 条弧。邻接矩阵中每条弧对应一个非零元素，故选 B。

**注意**：这里按通常考题约定讨论 $n\ge 2$ 的简单有向图；单顶点图的边界情况应另行规定。

</Solution>

</Question>

<Question id="wd408-2027-s01-q07" type="single" tags="来源:王道8套卷第1套, 考点:强连通分量与缩点图" points={2}>

下列关于有向图 $G$ 的强连通分量特性的叙述中，正确的是（ ）。

<Option>假设图 $G$ 中有两个不同的强连通分量 $C$ 和 $C'$，顶点 $u, v \in C$，顶点 $u', v' \in C'$，若存在一条从 $u$ 到 $u'$ 的路径，则可能存在一条从 $v'$ 到 $v$ 的路径</Option>

<Option>在图 $G$ 中加入一条新的有向边，若该边的两个顶点都处于同一个强连通分量中，则可能会增加图 $G$ 的强连通分量数量</Option>

<Option>在图 $G$ 中加入一条新的有向边，若该边的两个顶点 $A$ 和 $A'$ 分别处于不同的强连通分量中，且 $A$ 和 $A'$ 之间原先没有路径，则添加后可能会增加图 $G$ 的强连通分量数量</Option>

<Option correct>在图 $G$ 中加入一条新的有向边，若该边的两个顶点 $A$ 和 $A'$ 分别处于不同的强连通分量中，且 $A$ 和 $A'$ 之间原先有一条路径，则添加后可能会减少图 $G$ 的强连通分量数量</Option>

<Solution>

**解析**：把每个强连通分量缩成一个点后得到的**缩点图一定是有向无环图（DAG）**。

- A 错：如果从 $C$ 能到 $C'$，又从 $C'$ 能回到 $C$，两个分量之间互相可达，原本就应属于同一个强连通分量，与“不同”矛盾。
- B 错：同一分量内新增边不会破坏原有可达性，更不可能把已有分量拆开。
- C 错：新增有向边只会**增加**可达路径，不会把原本互相可达的顶点分开，所以强连通分量的数量不可能增加。
- D 对：若缩点图原有路径 $C\to\cdots\to C'$，再新增反向边 $C'\to C$，形成有向环，环上的原有分量会合并，**分量数量可能减少**。

关键词是“**可能**”：并非跨分量新增的每条边都会触发合并，必须形成回路。

</Solution>

</Question>

<Question id="wd408-2027-s01-q08" type="single" tags="来源:王道8套卷第1套, 考点:二叉排序树的先序序列" points={2}>

在下列选项中，（ ）不可能构成任何二叉排序树的前序遍历序列。

<Option>4, 2, 3, 5, 6, 7</Option>

<Option>4, 3, 2, 7, 6, 5</Option>

<Option>6, 5, 4, 2, 3, 7</Option>

<Option correct>6, 5, 3, 4, 2, 7</Option>

<Solution>

**解析**：二叉排序树的先序遍历遵循“根—左子树—右子树”：在某个结点 $x$ 的先序片段中，必须先连续出现小于 $x$ 的左子树结点，然后才可以出现大于 $x$ 的右子树结点；一旦进入右子树，就不能再出现属于该结点左子树的值。

- A：根为 4，左子树序列 `2,3`、右子树序列 `5,6,7`，成立。
- B：根 4，左子树 `3,2`，右子树 `7,6,5`，成立。
- C：根 6，左子树 `5,4,2,3`，右子树 `7`；其中结点 2 的右孩子可为 3，成立。
- D：根 6 的左子树以 5 为根，进一步子树以 3 为根；片段 `3,4,2` 中，4 已属于 3 的右子树，之后却出现 $2\lt3$，违背先序遍历的左右子树顺序。

因此 D 不可能。

</Solution>

</Question>

<Question id="wd408-2027-s01-q10" type="single" tags="来源:王道8套卷第1套, 考点:B树与B+树" points={2}>

I. B 树的结点可以同时存储关键字和数据，而 B+ 树的非叶结点仅可以存储关键字  
II. B+ 树的叶结点之间存在指针链接，这有利于进行范围查询  
III. 在相同的磁盘 I/O 条件下，B+ 树通常比 B 树更适用于数据库索引  
IV. B 树在进行插入和删除操作时，可能需要合并或分裂结点以保持其平衡性

<Question id="wd408-2027-s01-q12" type="single" tags="来源:王道8套卷第1套, 考点:CPI与CPU性能分析" points={2}>

假定执行一条指令 $I$ 需要 20 个时钟周期，该指令在程序中出现的频率为 10%，其他所有指令的平均 CPI 为 5，则 CPU 执行指令 $I$ 所用的时间占整个 CPU 时间的比例是多少？（ ）如果对硬件进行改进能使指令 $I$ 的执行时间缩短为 10 个时钟周期，但同时会使 CPU 时钟周期延长 10%，那么是否值得采取这种改进措施？（ ）

<Option correct>30.77%，值得</Option>

<Option>15.39%，值得</Option>

<Option>30.77%，不值得</Option>

<Option>15.39%，不值得</Option>

<Solution>

**解析**：设原时钟周期为 $T$，总指令数为 $N$。优化前平均 CPI：

$$
\overline{\mathrm{CPI}}=0.1\times20+0.9\times5=6.5.
$$

指令 $I$ 的执行时间占比为

$$
\frac{0.1N\times20T}{6.5NT}=\frac{2}{6.5}\approx30.77\%.
$$

优化后，$I$ 的 CPI 变为 10，而时钟周期变为 $1.1T$，其他指令的 CPI 仍按题意取 5。于是总执行时间为

$$
T_{\mathrm{new}}=N(0.1\times10+0.9\times5)\times1.1T
=6.05NT.
$$

原时间为 $6.5NT$，且 $6.05NT\lt6.5NT$，因此**值得改进**。实际加速比约为 $6.5/6.05\approx1.0744$。所以选 A。

</Solution>

</Question>

<Question id="wd408-2027-s01-q13" type="single" tags="来源:王道8套卷第1套, 考点:无符号运算与类型转换" points={2}>

下面是一个用来计算数组 $a$ 中各元素之和的程序，当参数 $\text{len}$ 为 0 时，返回值应该是 0，但在执行时发生了存储器访问异常。请问程序应如何修改？（ ）

```c
float sum_elements(float a[], unsigned len) {
    int i;
    float result = 0;
    for (i = 0; i <= len - 1; i++)
        result += a[i];
    return result;
}
```

<Option>将变量 $\text{result}$ 定义为 $\text{double}$ 型</Option>

<Option>将变量 $\text{result}$ 定义为 $\text{int}$ 型</Option>

<Option correct>将变量 $\text{len}$ 定义为 $\text{int}$ 型</Option>

<Option>将数组 $a$ 定义为 $\text{int}$ 型</Option>

<Solution>

**解析**：问题不是浮点累加精度，而是 **无符号整数减法的下溢**。

`len` 为 `unsigned`。当 `len = 0` 时，表达式 `len - 1` 按无符号算术计算，回绕成 `UINT_MAX`。判断 `i <= len - 1` 时，`i` 也会按通常算术转换参与无符号比较，因此循环会错误进入，继续读取 `a[0]` 等元素，可能导致越界访问异常。

选 C 后，`len` 为有符号 `int`，在 `len = 0` 时 `len - 1 = -1`，首次判定 `0 <= -1` 为假，函数返回初始化的 0。

**工程实践**：更稳妥的写法是保留无符号 `len`，改用 `for (unsigned i = 0; i < len; ++i)`，既避免下溢又直观；但此法不在四个选项中，故本题选 C。

</Solution>

</Question>

<Question id="wd408-2027-s01-q14" type="single" tags="来源:王道8套卷第1套, 考点:IEEE754单精度与舍入" points={2}>

$$

它恰好位于两个相邻的单精度可表示数之间：

$$
2-2^{-23}\quad\text{与}\quad2.
$$

两端到精确和的距离均为 $2^{-24}$，属于**恰好中点**。按“就近舍入到偶数”规则，舍入至尾数最低有效位为 0 的候选值：前者的尾数末位为 1（奇），而 $2=(1.000\ldots000)_2\times2^1$ 的尾数末位为 0（偶）。

**转写校订**：原文 $x$ 的数字串与括号内“23 位全为 1”相互矛盾。本次将 $x$ 统一成 23 位尾数字段，并整理各选项的尾数位数，符合“操作数均可精确表示”的题设。

<Option>104 ms</Option>

<Question id="wd408-2027-s01-q34" type="single" tags="来源:王道8套卷第1套, 考点:香农公式, 考点:传播时延与带宽时延积" points={2}>

$$

数据链路层采用 SR 协议传输数据，使用 $4\text{ bit}$ 给帧编号，接收窗口的尺寸取值为 5，发送窗口的尺寸取最大值，发送窗口内的起始序号为 0，数据帧的初始序号为 0。假设发送方已发送了 0~6 号数据帧，现已收到 1、3、5 号帧的确认，而 0、2、4 号数据帧依次超时，则此时发送方最多能发送的数据帧数量为（ ）。

<Option>8</Option>

<Option correct>7</Option>

<Option>5</Option>

<Option>4</Option>

<Solution>

**解析**：SR 协议的收发窗口需使序号回绕后仍能区分新旧帧。设序号位数 $m=4$，序号空间为 $2^4=16$，接收窗口 $W_R=5$，则题目采用的**一般窗口约束**是

$$
W_T+W_R\le 2^m.
$$

因此最大发送窗口

$$
W_T^{\max}=16-5=11.
$$

当前窗口起始序号为 0，所以窗口覆盖 **0—10 号帧**。已发出 0—6 号帧，但 0 号尚未获确认，发送窗口不能整体右移。

3. 本题问“此时最多能发送的数据帧数量”（包括超时重传），所以 $4+3=\boxed{7}$ 帧，选 **B**。

**易错点**：如果题目只问“最多还能首次发送多少个**新**帧”，答案才是 4；本题将超时重传也算进发送数量。另有教材常用对称窗口设置 $W_T=W_R\le2^{m-1}$，但本题明确给出非对称的 $W_R=5$ 并要求发送窗口取最大值，应使用 $W_T+W_R\le2^m$。

<Question id="wd408-2027-s01-q36" type="single" tags="来源:王道8套卷第1套, 考点:IPv4分片与重组标识" points={2}>

某应用程序发送一个 UDP 数据报，在网络层把 IP 数据报划分为 4 个报片发送出去，结果前两个报片丢失，后两个报片正确到达目的站。过段时间后，应用程序重传该 UDP 数据报，网络层仍将其划分为 4 个报片来传送，结果这次前两个报片正确到达目的站，而后两个报片丢失。假定目的站第一次收到的后两个报片仍保存在目的站的缓存中，则下列说法中，正确的是（）。

<Option>因 UDP 不保证可靠传输，故目的站能够将两次传输的 4 个报片组装成 IP 数据报</Option>

<Option>因 IP 不保证可靠传输，故目的站能够将两次传输的 4 个报片组装成 IP 数据报</Option>

<Option correct>因首部标识字段不同，故目的站不能将两次传输的 4 个数据报片组装成 IP 数据报</Option>

<Option>因首部源 IP 地址不同，故目的站不能将两次传输的 4 个数据报片组装成 IP 数据报</Option>

<Solution>

**解析**：IPv4 的分片重组由**目的主机的网络层**进行，不能把来自不同 IP 数据报的报片任意拼接。报片归属于哪个原始 IP 数据报，通常结合<strong>源 IP、目的 IP、上层协议号及 IPv4 Identification（标识）</strong>等信息来区分。

- A、B 错：UDP/IP 是否提供可靠传输，不会改变分片重组时需识别**相同原始 IP 数据报**的要求。
- **C 正确**：不同 Identification 的报片不属于同一重组单元。
- D 错：应用程序在同一源主机重传时，源 IP 地址通常不变，不能据此解释。

**补充**：实际 IPv4 标识可能回绕或复用；本题按标准教学场景中两次发送标识不同处理，且分片缓存有超时机制。

</Solution>

<Question id="wd408-2027-s01-q37" type="single" tags="来源:王道8套卷第1套, 考点:ARP广播, 考点:以太网集线器与交换机转发" points={2}>

某网络的拓扑结构如图所示，假设交换机当前已学习到了主机 E 的 MAC 地址，主机 A 向主机 E 发送 ARP 请求报文，主机 E 收到后，向主机 A 发送 ARP 响应报文，则能收到 ARP 请求报文和 ARP 响应报文的主机数量分别是（）。

![](/images/27王道8套卷1025/p009-1.svg)

<Option correct>5, 3</Option>

<Option>5, 1</Option>

<Option>3, 5</Option>

<Option>1, 1</Option>

<Solution>

**解析**：图中 A、B、C 接在**集线器**一侧，D、E、F 接在**交换机**一侧，两设备相连；共 6 台主机。

**① ARP 请求**。A 要查 E 的 MAC 地址，发送目的 MAC 为广播地址 `FF:FF:FF:FF:FF:FF` 的 ARP 请求。集线器会向除入端口外的所有端口复制信号，交换机也会泛洪广播帧。因此除发送者 A 外，**B、C、D、E、F 共 5 台主机**能收到请求。

**② ARP 应答**。E 获得 A 的 MAC 地址后，向 A **单播**回复。交换机已经根据 A 的请求帧学习到 A 位于连接集线器的端口，因此只把响应转发向集线器，不发往 D、F 或其他交换机端口。集线器不识别 MAC 地址，会在除输入端口以外的各端口重复信号，使 **A、B、C 共 3 台主机**收到应答的以太网帧（只有 A 是预期接收者，其他网卡可丢弃非本机帧）。

故为 **5、3**，选 A。

**易错点**：即使 E 的 MAC 地址在交换机表中已知，**ARP 请求仍是广播帧**；而单播响应一旦到达集线器，集线器仍会物理层复制给 B、C。

</Solution>

<Question id="wd408-2027-s01-q38" type="single" tags="来源:王道8套卷第1套, 考点:TCP排序与IPv4数据报分片重组" points={2}>

在基于 TCP/IP 模型的分组交换网络中，每个分组都可能走不同的路径，所以在分组到达目的主机后应该重新排序。又由于不同类型的物理网络的 MTU 不同，因此一个分组在传输的过程中也可能需要分段，这些分段在到达目的主机后也必须重组。对于分组的排序和分段的重组，下列说法中正确的是（）。

<Option>排序和重组工作都由网络层完成</Option>

<Option>排序和重组工作都由传输层完成</Option>

<Option>排序工作由网络层完成，而重组工作由传输层完成</Option>

<Option correct>排序工作由传输层完成，而重组工作由网络层完成</Option>

<Solution>

**解析**：题干中的两个动作发生在**不同层次**：

1. **分组排序：传输层（TCP）**。不同 IP 数据报可能走不同路径、乱序到达；TCP 利用字节序号与接收缓存把数据恢复成顺序字节流。IPv4 本身不保证到达顺序，UDP 也不提供排序。
2. **IP 分片重组：网络层（IPv4）**。IP 数据报因 MTU 限制而被分片后，由目的主机 IPv4 层根据标识、片偏移和 MF 等字段重组，然后再交付传输层。

因此“排序由传输层完成，分片重组由网络层完成”，选 D。

**辨析**：TCP 还会把应用字节流拆成报文段并在接收端按序交付，这属于 TCP 自己的机制；不要把**TCP 分段**与**IPv4 分片**混为一谈。IPv6 的路由器不能像 IPv4 路由器那样中途分片，仍不改变本题层次区分。

</Solution>

</Question>

<Question id="wd408-2027-s01-q39" type="single" tags="来源:王道8套卷第1套, 考点:TCP重传, 考点:持续, 考点:时间等待与保活计时器" points={2}>

在以下关于 TCP 中各种计时器的描述中，错误的是（）。

<Option>超时计时器用于控制报文段的重传时机</Option>

<Option correct>持续计时器用于防止接收长报文分片造成的死锁</Option>

<Option>时间等待计时器用于保证 TCP 连接释放的可靠性</Option>

<Option>保活计时器用于检测长期空闲的 TCP 连接是否仍然有效</Option>

<Solution>

**解析**：TCP 中几类典型定时器的职责不同：

- **A 正确**：**重传计时器**（RTO）用于判断报文段是否已等待确认过久，超时后启动重传。
- **B 错误**：**持续计时器**（persist timer）是为了防止**零窗口通告**造成的死锁——例如接收方窗口重新打开的通知丢失，发送方仍以为不能发送。计时器触发窗口探测，而非处理“接收长报文分片”。

- **D 正确**：**保活计时器**用于空闲连接的存活性探测，其行为通常需要由实现或应用配置启用。

所以选 B。**易错点：**“持续”不是“持续发送”或“分片重组”，其关键词是**零窗口探测**。

</Solution>

<Question id="wd408-2027-s01-q40" type="single" tags="来源:王道8套卷第1套, 考点:HTTP持久连接, 考点:请求响应与状态码" points={2}>

下列关于 HTTP 的说法中，正确的是（ ）。

Ⅰ. 当用户点击某个包含1个文本文件和3张图片的网页时，如果 HTTP 使用持续连接，那么只需发送1个请求报文就能收到4个响应报文

Ⅱ. 可以使用同一个 HTTP/1.1 持续连接传输对 x.com/1.html 和 x.com/2.html 的请求和响应

Ⅲ. 当 HTTP 使用非持续连接时，一个 TCP 报文段也可装入两个不同的请求报文

Ⅳ. 响应报文中的实体主体部分永远不会是空的

<Option>Ⅰ、Ⅱ</Option>

<Option correct>仅 Ⅱ</Option>

<Option>Ⅲ、Ⅳ</Option>

<Option>Ⅱ、Ⅳ</Option>

<Solution>

**解析**：HTTP/1.1 的持续连接允许在**同一条 TCP 连接**上顺序处理多个 HTTP 请求/响应，但它不会把多个网页资源自动合并成“一次请求返回多个响应”。

- **Ⅰ 错误**：文本和 3 张图片是多个独立资源，常规 HTTP/1.1 浏览器至少要发起对应的 4 次资源请求；持续连接减少 TCP 建连次数，不减少到只要 1 个 HTTP 请求。
- **Ⅱ 正确**：两个 URL 同属 `x.com` 主机，满足连接复用条件时，HTTP/1.1 的同一条持续连接可以先后传输 `/1.html`、`/2.html` 的请求和响应。
- **Ⅲ 错误（按非持续 HTTP/1.0 教学模型）**：非持续连接通常一条 TCP 连接仅承载一个 HTTP 请求及其响应；不能把两个独立请求写在同一条非持续连接的数据流里。本选项把“TCP 报文段是字节流承载单元”误当成“必然可以在一个非持续连接内复用多个请求”。
- **Ⅳ 错误**：例如 `204 No Content`、`304 Not Modified` 和 `HEAD` 请求的响应可以没有消息体。

所以仅Ⅱ正确，选 B。

**补充**：现代 HTTP/2、HTTP/3 可以复用多个并发请求，部分 HTTP 扩展允许推送或特殊批处理；这不改变题目对**传统 HTTP/1.1 持续/非持续连接**的考查。

</Solution>
