# 第 1 章 操作系统概述

## 1.1 操作系统的发展历程

<Question id="408-af0ed0-001" type="single" tags="来源:2009考研408">

单处理机系统中, 可并行的是（ ）。 I. 进程与进程 II. 处理机与设备 III. 处理机与通道 IV. 设备与设备

<Option>仅 I、 II 和 III</Option>
<Option>仅 I、 II 和 IV</Option>
<Option>仅 I、 III 和 IV</Option>
<Option correct>II、III、IV</Option>

<Solution>

**【解析】** 在单处理机系统中，因为只有一个物理 CPU 核心，所以同一时刻只能执行一个进程的指令，不能并行执行多个进程，只能实现并发执行。处理机与设备、通道之间，设备与设备之间都是并行工作的。故选 D。

**【点评】** 概念题。考查“并行”和“并发”的概念。本题也有快速解题的小技巧（又快又准）：单处理机系统中，进程和进程之间只能并发、不能并行执行，Ⅰ错误，可快速排除 A、B、C，选 D。

</Solution>

</Question>

<Question id="408-af0ed0-002" type="single" tags="来源:2016考研408">

下列关于批处理系统的叙述中, 正确的是（ ）。 I. 批处理系统允许多个用户与计算机直接交互 II. 批处理系统分为单道批处理系统和多道批处理系统 III. 中断技术使得多道批处理系统的 I/O 设备可与 CPU 并行工作

<Option correct>仅 II、 III</Option>
<Option>仅 II</Option>
<Option>仅 I、 II</Option>
<Option>I、 III</Option>

<Solution>

**【解析】** I 错误 ×：批处理系统的特点恰恰是用户不与计算机直接交互——用户把作业交给操作员，由系统成批自动处理，作业运行期间用户无法干预。能与计算机直接交互的是分时系统。

II 正确 ✓：批处理系统按内存中可容纳的作业道数分为单道批处理系统和多道批处理系统；

III 正确 ✓：多道批处理系统正是利用中断技术和通道技术，使 I/O 设备与 CPU 并行工作，从而在 I/O 期间切换运行其他作业，提高 CPU 利用率。故选 A。

<Callout title="提示">

批处理系统主要出现在 20 世纪 50 年代中后期到 60 年代，是操作系统发展的第一个阶段。批处理系统中，用户将作业提交给操作员，这个操作员指的是机房里专职操作计算机的工作人员——是“人”，不是程序或系统软件。在批处理系统时代，计算机是昂贵的大型机，用户不能直接接触计算机，也没有终端、键盘可以直接交互。

</Callout>

**【点评】** 冷门考点。本题其实是考查操作系统的发展历程，批处理系统这种已经被时代淘汰的过时技术，很多考生可能忽略了这个考点，但这是“来时路”！

</Solution>

</Question>

<Question id="408-af0ed0-003" type="single" tags="来源:2017考研408">

与单道程序系统相比, 多道程序系统的优点是（ ）。 I. CPU 利用率高 II. 系统开销小 III. 系统吞吐量大 IV. I/O 设备利用率高

<Option>仅 I、 III</Option>
<Option>仅 I、 IV</Option>
<Option>仅 II、 III</Option>
<Option correct>I、 III、 IV</Option>

<Solution>

**【解析】** ① Ⅰ正确 ✓：多道程序让 CPU 在一个作业等待 I/O 时，转而执行另一个就绪作业，把原本空转的时间利用起来，提高了 CPU 的利用率。

② Ⅱ错误 ×：多道程序需进程调度、上下文切换、内存保护、同步互斥等机制，系统开销更大。

③ Ⅲ正确 ✓：多道程序单位时间完成的作业增多，系统吞吐量大。

④ Ⅳ正确 ✓：多道程序并发使用不同设备，I/O 设备利用率高。

综上，Ⅰ、Ⅱ、Ⅳ正确，故选 D。

{/* 原书此处将Ⅲ误写为Ⅱ，答案表与选项D及前文分析一致。 */}

**【点评】** 概念题。本题容易想当然认为多道程序“效率高 = 开销小”。多道程序提高的是 CPU 利用率与吞吐量，付出的代价是管理成本与进程切换开销。

</Solution>

</Question>

<Question id="408-af0ed0-004" type="single" tags="来源:2018考研408">

下列关于多任务操作系统的叙述中, 正确的是（ ）。 I. 具有并发和并行的特点 II. 需要实现对共享资源的保护 III. 需要运行在多 CPU 的硬件平台上

<Option>仅 I</Option>
<Option>仅 II</Option>
<Option correct>仅 I、 II</Option>
<Option>I、 II、 III</Option>

<Solution>

**【解析】** Ⅰ 正确 ✓：多任务操作系统允许多个程序同时驻留内存并宏观上“同时”运行。并发（concurrency）指多个任务在同一时间段内交替推进，这是多任务系统的本质特征；在多核/多 CPU 环境下还可以实现并行（parallelism），即多个任务在同一时刻真正同时执行。多任务操作系统在设计上同时具备并发与并行的特点。

Ⅱ 正确 ✓：多个任务共享内存、设备、文件等资源，若不加保护，一个任务的错误可能破坏其他任务甚至系统本身。因此多任务 OS 必须通过互斥、访问控制、存储保护等机制实现对共享资源的保护。

Ⅲ 错误 ×：多任务操作系统只要求支持并发，单 CPU 通过时间片轮转等分时技术即可实现多任务（早期的单核 PC 机上的 Windows/Linux 皆是如此），并非必须运行在多 CPU 硬件平台上。

综上，仅Ⅰ、Ⅱ正确，故选 C。

**【点评】** 概念题。考查操作系统的基本概念：并发与并行的区别、多任务系统的特征。

</Solution>

</Question>

## 1.2 操作系统的运行环境

<Question id="408-af0ed0-006" type="single" number={1} tags="来源:2010考研408">

下列选项中, 操作系统提供给应用程序的接口是（ ）。

<Option correct>系统调用</Option>
<Option>中断</Option>
<Option>库函数</Option>
<Option>原语</Option>

<Solution>

**【解析】** ① A 正确 ✓：系统调用（通过 trap 指令实现）是应用程序访问操作系统的接口，是用户程序进入内核态、请求操作系统服务（如文件操作、进程管理、内存分配等）的唯一方式。

② B 错误 ×：中断是硬件或程序向 CPU 发送的信号，用于打断当前执行流程、处理紧急事件（例如：I/O 完成、异常等），它是内核与硬件交互的机制，不是直接提供给应用程序的接口。

③ C 错误 ×：库函数（例如：C 标准库中的 printf 函数、malloc 函数）是对系统调用的封装，运行在用户态，并非操作系统直接提供的接口，通常是编程语言提供的工具函数。

④ D 错误 ×：原语是操作系统内核中不可分割、不可中断的一段程序（例如：同步原语），用于实现内核的基础功能（同步、互斥、进程管理等），不直接暴露给应用程序使用。故选 A。

**【点评】** 概念题。考查操作系统的一些基础概念。

</Solution>

</Question>

<Question id="408-af0ed0-007" type="single" tags="来源:2011考研408">

下列选项中, 在用户态执行的是（ ）。

<Option correct>命令解释程序</Option>
<Option>缺页处理程序</Option>
<Option>进程调度程序</Option>
<Option>时钟中断处理程序</Option>

<Solution>

**【解析】** ① A 选项：命令解释程序运行在用户态，负责接收、解释并执行用户输入的命令（例如，cd、ls 等命令），例如：Windows 中常见的 cmd，Linux/Unix 中常见的 bash，都属于命令解释程序。

② B 选项：缺页处理程序属于操作系统的内存管理模块，是内核态的异常处理程序，发生缺页时由内核接管处理。

③ C 选项：进程调度程序是操作系统内核的核心功能之一，负责 CPU 资源分配，必须在内核态执行。

④ D 选项：时钟中断处理程序属于内核态的中断处理程序，用于维护系统时间、触发时间片轮转等，在内核态执行。故选 A。

</Solution>

<Question id="408-af0ed0-008" type="single" tags="来源:2012考研408">

下列选项中, 不可能在用户态发生的事件是（ ）。

<Option>系统调用</Option>
<Option>外部中断</Option>
<Option correct>进程切换</Option>
<Option>缺页</Option>

<Solution>

**【解析】** 用户态和内核态是操作系统为了安全隔离而划分的两种 CPU 运行级别：

- 用户态：普通应用程序运行的级别，权限受限，无法直接访问硬件资源和执行特权指令。
- 内核态：OS 内核运行的级别，拥有最高权限，可执行所有指令、访问所有硬件资源。

① 系统调用：用户态程序主动触发系统调用（例如，在 x86 架构下，int 指令或 syscall 指令是 x86 架构下最具代表性的两种系统调用触发方式），陷入内核态执行内核代码。② 外部中断：外部设备（例如：键盘、磁盘等）触发的中断，CPU 在用户态时也能响应，响应后会进入内核态处理中断。③ 进程切换：进程切换是操作系统内核的核心特权操作，涉及修改页表、寄存器上下文、调度队列等，只能在内核态触发和执行。④ 缺页：用户态程序访问不在内存中的页面时触发缺页异常，CPU 响应后进入内核态处理。可以在用户态发生。

系统调用、外部中断和缺页等事件都是发生在用户态，在内核态处理。故选 C。

**【点评】** 概念题。注意审题，区分题目中的“发生”和“执行”。

</Solution>

</Question>

<Question id="408-af0ed0-009" type="single" tags="来源:2012考研408">

中断处理和子程序调用都需要压栈以保护现场, 中断处理一定会保存而子程序调用不需要保存其内容的是（ ）。

<Option>程序计数器</Option>
<Option correct>程序状态字寄存器</Option>
<Option>通用数据寄存器</Option>
<Option>通用地址寄存器</Option>

<Solution>

**【解析】** ① 中断处理：由硬件自动响应，必须保存程序运行的完整现场，以便中断返回后能恢复原程序的执行状态。② 子程序调用：由软件主动发起，现场保存由程序员控制，仅需保存必要的寄存器，甚至可以不保存任何寄存器。

- 程序计数器（PC）：中断处理和子程序调用都需要保存 PC（返回地址），否则无法回到调用点继续执行。
- 程序状态字寄存器（PSW）：中断处理时必须由硬件（中断隐指令）自动保存 PSW，因为中断响应会改变 CPU 的状态，返回时需要恢复原状态。子程序调用不会改变 CPU 的核心状态，PSW 通常不需要保存。
- 通用数据寄存器：两者都可以由软件选择是否保存，不是必须的。
- 通用地址寄存器：和通用数据寄存器一样，属于软件可控制的现场，不是必须保存的。

PSW（程序状态字）包含了 CPU 的运行状态（例如：中断允许位、条件码、特权级等），中断响应时硬件会自动将其压栈保存，而子程序调用时不会自动保存。故选 B。

**【点评】** 难题。子程序调用的概念比较生僻，容易误选。

</Solution>

</Question>

<Question id="408-af0ed0-010" type="single" tags="来源:2013考研408">

下列选项中, 会导致用户进程从用户态切换到内核态的操作是（ ）。 I. 整数除以零 II. sin（ ） 函数调用 III. read 系统调用

<Option>仅 I、 II</Option>
<Option correct>仅 I、 III</Option>
<Option>仅 II、 III</Option>
<Option>I、 II 和 III</Option>

<Solution>

**【解析】** ① I. 整数除以零会触发异常，会导致从用户态切换到内核态。② II. sin() 函数调用是标准库函数调用，运行在用户态，不涉及系统资源操作，不会触发内核态切换。③ III. read 系统调用是典型的系统调用，用户进程通过它请求内核读取文件，会主动触发用户态到内核态的切换。故选 B。

**【拓展】** “整数除以零”是异常处理的经典案例，在教材教辅中多有提及。以下为该异常触发后，操作系统的完整处理流程：

① **硬件检测并触发异常：** CPU 在执行除法指令时，检测到除数为 0，立即触发除法错误异常，暂停当前指令执行。② **硬件自动完成用户态到内核态切换：** CPU 通过中断隐指令（是硬件操作）自动保存现场（程序计数器 PC、状态寄存器 PSW 等），并查中断向量表，跳转到操作系统内核的除法错误异常处理程序。③ **内核异常处理：** 内核识别出异常原因是除零错误，向出错进程发送 SIGFPE（浮点异常）信号。④ **进程响应信号：** 异常处理完成后，进程准备从内核态返回用户态时，内核会检查到该进程的待处理 SIGFPE 信号。默认情况下，进程会直接终止运行；若进程提前注册了自定义信号处理函数，则会跳转到用户态执行该函数。

**【提示】** 用户态切换到内核态，有以下三种常见触发方式：

- 系统调用（主动触发）：例如，read/write/open 等。由用户程序执行程序时主动触发陷入内核，请求操作系统提供服务。
- 异常（被动触发）：例如，除零、缺页、地址越界等。进程在用户态执行指令时，意外触发的错误，CPU 检测到错误，强制把控制权交给操作系统内核来处理（被动触发）。
- 外部中断（被动触发）：例如，键盘输入、磁盘 I/O 完成等。外部设备主动发信号打断 CPU，CPU 被迫停下当前进程，切换到内核态处理中断。

异常是 CPU 内部指令执行引发的事件（如除零、缺页），与当前指令强相关；外部中断是 CPU 外部设备引发的事件，与当前指令无关。

从用户态切换到内核态，分为主动触发和被动触发 2 种方式。通俗的讲：

- 主动触发：进程自己“喊”内核来帮忙（系统调用）。
- 被动触发：进程没“喊”，内核/硬件/设备“硬闯进来”接管 CPU（异常、外部中断）。

**【点评】** 概念题。考查用户态和内核态之间的切换，是 408 中的高频考点。

</Solution>

<Question id="408-af0ed0-011" type="single" tags="来源:2014考研408">

下列指令中, 不能在用户态执行的是（ ）。

<Option>trap 指令</Option>
<Option>跳转指令</Option>
<Option>压栈指令</Option>
<Option correct>关中断指令</Option>

<Solution>

**【解析】** A 选项：trap 指令（陷入指令）是一条可在用户态执行的非特权指令，执行后会触发 CPU 异常，自动保存现场、切换 CPU 为内核态，进入内核的系统调用处理程序。

B 选项：跳转指令是最基本的程序控制流指令，属于非特权指令，在用户态和内核态都可以执行。常见的跳转指令如下：

- JMP 指令：直接修改程序计数器，无条件跳转到目标地址执行，不保存返回地址。常用于循环、分支、无条件跳转等场景。
- CALL 指令：先将下一条指令的地址压入栈，再跳转到目标函数处执行，等待跳转的目标函数执行完后，再用 RET 指令弹出栈中地址回到原代码继续执行。常用于调用函数或子程序等场景。
- RET 指令：配合 CALL 指令使用，从栈中弹出之前保存的返回地址，跳转回调用处。

C 选项：压栈指令是最基本的数据操作指令，属于非特权指令，在用户态和内核态都可以执行。例如：PUSH 是常用的压栈指令，将源操作数存入栈顶。

D 选项：关中断指令是特权指令，只能在内核态执行，不能在用户态执行。如果用户程序可以随意关中断，会导致：系统无法响应外部事件；时钟中断被屏蔽、进程调度失效；整个系统陷入死锁或瘫痪。故选 D。

**【提示】** ★ 关于用户态与核心态、特权指令和非特权指令、以及系统调用和 trap 指令的联系和区别，是 408 中的高频考点。相关常见考点的总结，详见竞成写的 2021 年 408 第 23 题的解析，那里用将近一页的篇幅，进行了详尽的总结，强烈建议考生去看看，这里不再重复讲述。

**【点评】** 常规题。2021 年 408 第 23 题和 2026 年 408 第 21 题，跟本题可视为“原题”。

</Solution>

<Question id="408-af0ed0-012" type="single" tags="来源:2015考研408">

处理外部中断时, 应该由操作系统保存的是（ ）。

<Option>程序计数器 (PC) 的内容</Option>
<Option correct>通用寄存器的内容</Option>
<Option>快表 (TLB) 中的内容</Option>
<Option>Cache 中的内容</Option>

<Solution>

**【解析】** 中断发生后，现场的保存由硬件和操作系统共同完成，两者分工明确：

- CPU 在响应中断的瞬间会执行一条“中断隐指令”（它并不是指令系统中程序员可见的指令，而是由硬件自动完成的一组微操作），完成关中断、保存断点（即程序计数器 PC 的值，有的机器还保存程序状态字 PSW）、转向中断处理程序入口三项工作。因此 PC 的保存属于硬件行为，A 选项错误。
- 进入中断处理程序后，由操作系统（即中断服务程序本身）负责保存“中断现场”，主要是被中断程序所使用的通用寄存器组、状态寄存器等，以便中断处理完毕后能恢复原程序的执行，B 选项正确。

至于 TLB 和 Cache，它们的存在对进程完全透明——TLB 只是页表的硬件缓存副本，Cache 只是主存的副本，其内容随时可以由内存重建，不需要、也无法由操作系统保存和恢复，C、D 选项均错误。故选 B。

**【点评】** 常规题。考查中断处理过程。该考点是 408 中的高频考点。

</Solution>

② 系统调用和 trap 指令之间的联系和区别是 408 考试中的易错点和难点，总结如下：

- 所有传统架构（MIPS、RISC-V 等）的系统调用，底层都依靠 trap 类指令完成状态切换，即：系统调用通过 trap 指令来实现。但系统调用 $\ne$ trap 指令：trap 指令是一种通用的异常机制，系统调用只是 trap 指令的应用场景之一。

⑤ 要注意审题区分“发生（触发）”和“执行”：有些指令可在用户态触发，但不能在用户态执行。例如：所有的系统调用、缺页 / 非法指令等异常、硬件中断，都是在用户态发生触发，内核态完成实际处理。

<Question id="408-af0ed0-021" type="single" number={1} tags="来源:2023考研408">

与宏内核操作系统相比, 下列特征中, 微内核操作系统具有的是（ ）。 I. 较好的性能 II. 较高的可靠性 III. 较高的安全性 IV. 较强的可扩展性

<Option>I, III, IV</Option>
<Option correct>II, III, IV</Option>

**【解析】** 选项 II. 较高的可靠性：微内核操作系统将核心功能模块化，将部分操作系统功能移出内核，以减少内核的复杂性和错误的影响范围，从而提高系统的可靠性，由于微内核中只包含最基本的功能，因此可以更容易地对其进行验证和测试，减少错误的概率。选项 III. 较高的安全性：微内核操作系统通过将一些非核心功能移出内核，以降低系统的攻击面，只有核心的、必要的功能位于内核中，而其他的服务和驱动程序则在用户空间运行，减少了恶意代码对内核的直接访问，这有助于提高系统的安全性，并减少潜在的漏洞。选项 IV. 较强的可扩展性：微内核操作系统的设计使得新增功能或服务更容易添加到系统中。由于非核心功能运行在用户空间，可以通过插件或模块的形式进行扩展，而无需对内核进行大规模的修改，这使得微内核操作系统更具有灵活性和可扩展性。微内核操作系统采用模块化设计，将一部分功能移至用户空间，这就需要通过进程间通信（IPC）机制来实现内核与用户空间的交互。这种通信会引入额外的开销，包括上下文切换、数据拷贝等，从而影响系统的性能。所以选项 I 不是微内核操作系统所具有的特点。正确的选项为 II，III，IV，故选 D。

<Option>每个系统调用都有对应的内核服务例程</Option>

**【解析】** 中断或异常发生时，CPU 可能处于内核态也可能处于用户态。例如，若 CPU 在执行用户程序时发生缺页异常，则 CPU 处于用户态；若 CPU 在执行中断服务程序时产生中断嵌套，则 CPU 处于内核态。

**【点评】** 常规题。考查基本概念。

## 1.4 操作系统引导

<Question id="408-af0ed0-025" type="single" number={1} tags="来源:2013考研408">

计算机开机后, 操作系统最终被加载到（ ）。

<Option>BIOS</Option>
<Option>ROM</Option>
<Option>EPROM</Option>
<Option correct>RAM</Option>

<Solution>

**【解析】** 采用传统 BIOS 的计算机启动流程如下：

- 开机后，首先执行 BIOS（存放在 ROM 中），完成硬件自检（POST）。
- BIOS 会从硬盘等启动设备读取引导程序，引导程序再加载操作系统内核。
- 操作系统最终被加载到 RAM（随机存取存储器，也就是我们常说的内存）中才能运行，因为 CPU 只能直接执行内存中的程序指令。

**【提示】** 操作系统的运行依赖于 RAM 提供的高速读写能力，所有进程、数据都需要调入内存才能被处理，这也是内存大小直接影响系统流畅度的核心原因。

C 选项中，EPROM 是可擦除可编程只读存储器，正常工作时只能读、不能写，断电数据不丢失。出厂空白，可专用设备一次性/多次烧录程序/数据。主流场景已经基本被淘汰，被 Flash 替代。这是 2013 年的 408 真题，距今已经十多年。如今的 408 考试中应该不会再考 EPROM 这种被淘汰的技术了，要考也是考 Flash 这种当下主流的。

**【拓展】** BIOS 全称是 Basic Input Output System（基本输入输出系统），它是计算机主板上的固件程序（BIOS 本质上是一套程序代码），也是电脑开机后第一个运行的软件。负责最基础的硬件初始化和启动流程控制。BIOS 核心作用是：

- 硬件自检（POST）：开机瞬间，BIOS 会对 CPU、内存、硬盘、显卡等所有核心硬件进行检测。如果发现问题（比如内存没插好），会通过蜂鸣器报警或屏幕报错提示。
- 硬件初始化：给键盘、鼠标、硬盘控制器等设备设置初始参数，让它们能被后续系统识别和使用。
- 启动引导：按照预设的启动顺序（比如先硬盘、再 U 盘），找到可启动的设备，读取其中的引导扇区，把控制权交给操作系统（如 Windows、Linux），最终让系统加载到 RAM 中运行。
- BIOS 设置界面：开机时按 Del/F2 进入的蓝色界面，就是 BIOS 的设置界面。在这里可以调整启动顺序、硬件频率、电压、日期时间等底层参数。

**【注意】** ★ 传统 BIOS 在如今的新机器、新设计上已经被淘汰，UEFI（统一可扩展固件接口）替代了传统 BIOS，UEFI 本质上是更先进的“升级版 BIOS”。因为这是 2013 年的 408 真题，距今已经十多年。如今的 408 考试中应该不会再考传统 BIOS 这种被淘汰的技术了，要考也是考 UEFI 这种当下主流的。在 Windows 电脑上，按下 Win+R 键，输入 `msinfo32`，在“系统摘要”中，可查看当前 BIOS 模式（应该都是 UEFI）。

**【拓展】** UEFI（Unified Extensible Firmware Interface，统一可扩展固件接口）是传统 BIOS 的现代化替代方案，它本质上是一套定义了操作系统与平台固件之间接口的标准，也是电脑开机后最先运行的程序。UEFI 解决了 BIOS 的容量和安全瓶颈，其完整启动流程简介如下：

1. 上电复位：主板通电，CPU 开始执行 UEFI 固件代码。
2. SEC 安全阶段：初始化 CPU、缓存，搭建临时运行环境。
3. PEI 预初始化：识别并启用内存，完成基础硬件初始化。
4. DXE 驱动执行：加载各类硬件驱动，启动固件服务与设置界面。
5. BDS 启动项选择：按优先级扫描设备，找到系统引导分区。
6. 加载操作系统：运行 EFI 引导程序，校验签名后载入操作系统内核。
7. 运行时阶段：操作系统接管控制权，UEFI 保留后台服务，启动完成。

**【点评】** 冷门考点。本题比较容易猜出来选 D。本题解析的拓展部分，属于操作系统这门课程的常识性内容，还是需要考生掌握的。2021 年 408 第 46 题，着重考查了教材教辅中没有着重介绍的 OS 常识性内容。

</Solution>

</Question>
