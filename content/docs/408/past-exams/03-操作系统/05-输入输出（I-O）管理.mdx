# 第 5 章 输入 / 输出 (I/O) 管理


## 5.1 I/O 管理基础

<Question id="408-8d5396-001" type="single">

【2010】本地用户通过键盘登录系统时, 首先获得键盘输入信息的程序（ ）。

<Option>命令解释程序</Option>
<Option correct>中断处理程序</Option>
<Option>系统调用服务程序</Option>
<Option>用户登录程序</Option>

<Solution>

**【解析】** ① A 选项：命令解释程序运行在用户态，负责接收、解释并执行用户输入的命令（例如，cd、ls 等命令），例如：Windows 中常见的 cmd，Linux/Unix 中常见的 bash，都属于命令解释程序。

② B 选项 ✓：中断处理程序是内核态的底层程序，负责响应硬件中断，键盘按键按下瞬间立即响应。

③ C 选项：系统调用服务程序指操作系统内核中具体执行该系统调用的函数 / 程序。当用户程序触发系统调用后，CPU 会跳转到内核态，执行对应的系统调用服务程序。

④ D 选项：用户登录程序只是使用输入信息，但输入信息首先由中断处理程序获取并放入缓冲区后，用户登录程序才能读取。故选 B。

**【点评】** 概念题。考查操作系统中常见程序的功能。

</Solution>

</Question>

<Question id="408-8d5396-002" type="single">

【2011】用户程序发出磁盘 I/O 请求后, 系统的正确处理流程是（ ）。

<Option>用户程序 → 系统调用处理程序 → 中断处理程序 → 设备驱动程序</Option>
<Option correct>用户程序 → 系统调用处理程序 → 设备驱动程序 → 中断处理程序</Option>
<Option>用户程序 → 设备驱动程序 → 系统调用处理程序 → 中断处理程序</Option>
<Option>用户程序 → 设备驱动程序 → 中断处理程序 → 系统调用处理程序</Option>

<Solution>

**【解析】** ① 用户程序（用户层）：发起磁盘 I/O 请求（例如：read()/write() 系统调用），陷入内核态。

② 系统调用处理程序（设备独立软件）：内核接收请求，验证参数并进行权限检查，将请求转换为内核能识别的 I/O 请求块。

③ 设备驱动程序：驱动程序根据请求，向磁盘控制器发送具体的 I/O 命令（例如：设置寄存器、启动传输），并等待设备完成操作。

④ 中断处理程序：磁盘完成 I/O 操作后，向 CPU 发出中断信号，由中断处理程序响应中断，处理数据、通知内核请求完成，并唤醒等待的用户进程。故选 B。

**【点评】** 本题容易混淆的是：① 中断处理程序的作用是响应设备完成信号，它是在设备操作完成后才被调用的，而不是在设备驱动程序之前。② 用户程序无法直接调用设备驱动程序，必须通过系统调用进入内核态，再由内核调用设备驱动程序。

**【点评】** 常规题。以磁盘 I/O 请求这个实例考查 I/O 软件层次结构。

</Solution>

</Question>

<Question id="408-8d5396-003" type="single">

【2012】操作系统的 I/O 子系统通常由四个层次组成,每一层明确定义了与邻近层次的接口。其合理的层次组织排列顺序是（ ）。

<Option correct>用户级 I/O 软件、设备无关软件、设备驱动程序、中断处理程序</Option>
<Option>用户级 I/O 软件、设备无关软件、中断处理程序、设备驱动程序</Option>
<Option>用户级 I/O 软件、设备驱动程序、设备无关软件、中断处理程序</Option>
<Option>用户级 I/O 软件、中断处理程序、设备无关软件、设备驱动程序</Option>

<Solution>

**【解析】** ① 用户级 I/O 软件位于最上层，作为和用户进程直接交互的接口（例如：库函数、系统调用接口等），负责将用户的 I/O 请求传递给操作系统内核。

② 设备无关软件（也叫设备独立软件）负责实现与硬件无关的通用 I/O 功能，例如：设备命名、设备保护、块设备的缓冲管理、字符设备的通用接口等，为用户层提供统一的系统调用接口，并向下调用设备驱动程序。

③ 设备驱动程序直接与硬件控制器交互，和硬件强相关，通常由硬件厂商开发，负责将上层的通用请求转换为硬件可执行的命令（例如：寄存器操作、启动 I/O 传输等），并处理设备控制器发来的状态信息。

④ 中断处理程序位于最底层，当设备完成 I/O 操作或发生错误时，硬件会触发中断，由中断处理程序负责响应中断、处理设备状态、唤醒等待的进程，完成 I/O 操作的收尾工作。故选 A。

**【点评】** 概念题。记忆性内容。越靠近用户的 I/O 层次越抽象，越靠近硬件的 I/O 层次越具体。本题可看作 2011 年 408 第 26 题的原题。

</Solution>

</Question>

<Question id="408-8d5396-004" type="single">

【2013】用户程序发出磁盘 I/O 请求后, 系统的处理流程是: 用户程序 → 系统调用处理程序 → 设备驱动程序 → 中断处理程序。其中, 计算数据所在磁盘的柱面号、磁头号、扇区号的程序是（ ）。

<Option>用户程序</Option>
<Option>系统调用处理程序</Option>
<Option correct>设备驱动程序</Option>
<Option>中断处理程序</Option>

<Solution>

**【解析】** 这里以使用 read 系统调用，从文件中读取 100B 为例，简要介绍整个流程。

系统调用 `read(fd, buf, 100)` 的功能是：从文件描述符 fd 对应的文件中，读取最多 100 字节数据，到 buf 指向的内存空间。完整过程如下：

| 层级 | 功能 |
| --- | --- |
| 用户程序 | 调用 `read(fd, buf, 100)`，发起磁盘 I/O 请求，进程进入阻塞状态 |
| 系统调用处理程序（设备独立软件） | ① 验证 fd 是否有效，用户是否有读取该文件的权限。② 解析参数：根据文件偏移量，算出要读取数据在文件系统上的逻辑块号（例如：文件的第 3 个逻辑块）。③ 将请求交给磁盘驱动。 |
| 设备驱动程序 | ① 将逻辑块号转换成磁盘物理地址（柱面号、磁头号、扇区号）。② 配置 DMA 控制器，设置数据传输的目标内核地址。③ 向磁盘控制器发送读命令，启动 I/O。 |
| 中断处理程序 | ① 磁盘读完数据后，触发中断，CPU 暂停当前任务。② 检查 I/O 状态，确认传输成功。③ 把内核缓冲区的数据拷贝到 buf 指向的内存空间。④ 唤醒用户进程，read() 函数返回，程序继续执行。 |

**【点评】** 概念题。2011 年 408 第 26 题、2012 年 408 第 26 题、2013 年 408 第 25 题，连续 3 年都考查了 I/O 系统层次结构。建议考生结合竞成写的这 3 题的解析，理解记忆这些概念。

</Solution>

</Question>

<Question id="408-8d5396-005" type="single">

【2017】系统将数据从磁盘读到内存的过程包括以下操作: ① DMA 控制器发出中断请求；②初始化 DMA 控制器并启动磁盘；③从磁盘传输一块数据到内存缓冲区；④执行“DMA 结束”中断服务程序。正确的执行顺序是（ ）。

<Option>③ → ① → ② → ④</Option>
<Option correct>② → ③ → ① → ④</Option>
<Option>② → ① → ③ → ④</Option>
<Option>① → ② → ④ → ③</Option>

<Solution>

**【解析】** DMA 的传送过程主要分为预处理、数据传送和后处理三个阶段。

- 预处理阶段：这是传送前的准备工作，CPU 通过执行指令对 DMA 控制器进行初始化。包括设置数据传送方向、向 DMA 控制器送入内存起始地址、设置传送的字数/数据块长度、设置外设地址等相关参数、启动 DMA 控制器。
- 数据传输阶段（由硬件实现）：当 I/O 设备准备好数据后发出 DMA 请求，CPU 让出总线控制权，DMA 控制器直接在外设与内存之间传送数据。
- 后处理阶段：数据块传送结束后，DMA 控制器向 CPU 发出中断请求，CPU 执行相应的中断服务程序进行收尾工作：校验数据是否正确、决定是否继续传送下一块数据、进行错误处理等。

正确的执行顺序是②→③→①→④，故选 B。

**【点评】** 常规题。本题考查 DMA 方式的工作流程。

</Solution>

</Question>

<Question id="408-8d5396-006" type="single">

【2020】下列与中断相关的操作中,由操作系统完成的是（ ）。 I. 保存被中断程序的中断点 II. 提供中断服务 III. 初始化中断向量表 IV. 保存中断屏蔽字

<Option>仅 I、 II</Option>
<Option>仅 I、 II、 IV</Option>
<Option>仅 III、 IV</Option>
<Option correct>仅 II、 III、 IV</Option>

<Solution>

**【解析】** 中断处理的过程由硬件（中断隐指令）和操作系统（中断处理程序）协作完成。

① 在 CPU 在响应中断后，在指令执行的中断周期中，硬件（中断隐指令）自动完成关中断 → 保存断点 → 中断服务程序寻址等一系列操作。

② 操作系统（中断处理程序）负责保存现场和屏蔽字 → 开中断 → 执行中断服务程序 → 关中断 → 恢复现场和屏蔽字 → 开中断 → 中断返回等操作。中断向量表的初始化通常在操作系统启动阶段完成，与中断处理过程无关。综上，II、III、IV 是由操作系统完成的，故选 D。

**【点评】** 常规题。中断处理过程在408中反复多次考查过，属于必会内容，考生需要熟练掌握。本题解析中列举的是允许多重中断的中断过程的完整步骤，其中每一步的功能和操作细节，考生都要理解记忆。值得一提的是，在2022年408第24题的 A 选项，其实就是将本题的 C 选项再考了一遍；2023年408第24题，更进一步，考了“中断向量表”的具体结构。这提示我们对于408真题中出现过的每个名词概念，考生都有必要做拓展分析，了解其含义和功能。

</Solution>

</Question>

【2023】下列因素中, 设备分配需要考虑的是（ ）。 I. 设备类型 II. 设备的访问权限 III. 设备的占用状态 IV. 逻辑设备与物理设备的映射关系

<Option>I、 II</Option>
<Option>II、 III</Option>
<Option>III、 IV</Option>
<Option correct>I、 II、III、IV</Option>

<Solution>

**【解析】** ① I 正确 √：不同类型的设备有不同的特性和接口，例如：有些设备是可以共享访问的，有些是需要独占使用的。需要根据设备类型进行适当的分配和管理。

## 5.2 设备独立软件

<Question id="408-8d5396-008" type="single" number={1}>

【2009】程序员利用系统调用打开 I/O 设备时, 通常使用的设备标识是（ ）。

<Option correct>逻辑设备名</Option>
<Option>物理设备名</Option>
<Option>主设备号</Option>
<Option>从设备号</Option>

<Solution>

**【解析】** ① 程序员（用户层）通过系统调用（例如：`open()`）打开设备时，通常使用逻辑设备名来标识设备。逻辑设备名通常表现为文件系统路径，例如：`/dev/tty`、`/dev/sda`。逻辑设备名屏蔽底层硬件差异，为程序员提供统一的设备访问接口。故选 A。

② 物理设备名是硬件层面的设备标识，例如：硬件总线地址、设备端口、硬件型号等。物理设备名属于底层硬件细节，对用户层不可见，程序员不能使用。由设备独立软件完成逻辑设备名到物理设备名的转换。

③ 主设备号是内核用于区分设备类型的编号，例如：所有磁盘共享同一个主设备号。设备独立层通过主设备号找到对应的设备驱动程序，是内核内部的标识。

④ 内核用从设备号区分同一类型设备中的具体实例，例如：同一类磁盘中的不同分区。

| 逻辑设备名 | 主设备名 | 从设备号 | 含义 |
| --- | --- | --- | --- |
| /dev/sda | 8 | 0 | 设备文件名为 sda 的整块磁盘 |
| /dev/sda1 | 8 | 1 | 设备文件名为 sda 的磁盘的第 1 个分区 |
| /dev/sda2 | 8 | 2 | 设备文件名为 sda 的磁盘的第 2 个分区 |
| /dev/sdb | 8 | 3 | 设备文件名为 sdb 的整块磁盘 |

<Question id="408-8d5396-009" type="single">

【2011】某文件占 10 个磁盘块,现要把该文件磁盘块逐个读入主存缓冲区,并送用户区进行分析。 假设一个缓冲区与一个磁盘块大小相同, 把一个磁盘块读入缓冲区的时间为 100μs, 将缓冲区的数据传送到用户区的时间是 50μs,CPU 对一块数据进行分析的时间为 50μs。在单缓冲区和双缓冲区结构下, 读入并分析完该文件的时间分别是（ ）。

<Option>1500μs,1000μs</Option>
<Option correct>1550μs,1100μs</Option>
<Option>1550μs,1550μs</Option>
<Option>2000μs,2000μs</Option>

<Solution>

**【解析】** 将一块数据输入到缓冲区的时间为 $T$，操作系统把缓冲区送到用户区的时间为 $M$，CPU 处理该数据的时间为 $C$。① 单缓冲区结构如下图所示。当 CPU 处理前一个磁盘块的数据时，可以将后一个磁盘块的数据读入缓冲区（即：$T$ 和 $C$ 这段时间可并行）。

- 处理第 1 个磁盘块：读入缓冲区（$100\ \mu\mathrm{s}$）+ 从缓冲区传送到用户区（$50\ \mu\mathrm{s}$）+ CPU 分析（$50\ \mu\mathrm{s}$）$=200\ \mu\mathrm{s}$。
- 处理第 2 个磁盘块：在 CPU 分析第 1 个磁盘块的同时，可将第 2 个磁盘块的数据读入缓冲区，可并行 $50\ \mu\mathrm{s}$。处理第 2 个磁盘块的时间为 $(200-50)\ \mu\mathrm{s}=150\ \mu\mathrm{s}$。
- 处理第 3～10 个磁盘块的流程跟处理第 2 个磁盘块完全一致，都是需要 $150\ \mu\mathrm{s}$。

处理 10 个磁盘块总共需要 $200+150\times9=1550\ \mu\mathrm{s}$。

![单缓冲工作示意图](/img/2011-q31-single.svg)

② 双缓冲区结构如下图所示。因为有 2 个缓冲区（缓冲区 1 和缓冲区 2），当前一个磁盘块的数据从缓冲区 1 传送到用户区时，就可以将后一个磁盘块的数据读入缓冲区 2（即：$T$ 和 $M+C$ 这段时间可并行）。

- 处理第 1 个磁盘块：读入缓冲区（$100\ \mu\mathrm{s}$）+ 从缓冲区传送到用户区（$50\ \mu\mathrm{s}$）+ CPU 分析（$50\ \mu\mathrm{s}$）$=200\ \mu\mathrm{s}$。
- 处理第 2 个磁盘块：将第 1 个磁盘块数据从缓冲区 1 送往用户区的同时，就可将第 2 个磁盘块的数据读入缓冲区 2，可并行 $50+50=100\ \mu\mathrm{s}$。处理第 2 个磁盘块的时间为 $(200-100)\ \mu\mathrm{s}=100\ \mu\mathrm{s}$。
- 处理第 3～10 个磁盘块的流程跟处理第 2 个磁盘块完全一致，都是需要 $100\ \mu\mathrm{s}$。

处理 10 个磁盘块总共需要 $200+100\times9=1100\ \mu\mathrm{s}$。故选 B。

![双缓冲工作示意图](/img/2011-q31-double.svg)

**【点评】** 常规题。考查缓冲区的相关计算。此类题型，解题方法固定，考生需要理解整个过程，并加强记忆，从而又快又准的解题。以下公式考生需要熟悉：单缓冲结构和双缓冲结构除第 1 块外，平均处理时间分别为 $\max(C,T)+M$ 和 $\max(T,C+M)$。

</Solution>

<Question id="408-8d5396-010" type="single">

【2013】设系统缓冲区和用户工作区均采用单缓冲, 从外设读入 1 个数据块到系统缓冲区的时间为 100, 从系统缓冲区读入 1 个数据块到用户工作区的时间为 5, 对用户工作区中的 1 个数据块进行分析的时间为 90(如下图所示)。进程从外设读入并分析 2 个数据块的最短时间是（ ）

<Option correct>在一个磁盘上设置多个分区</Option>

<Option>优化文件物理块的分布</Option>

<Question id="408-8d5396-018" type="single">

【2017】下列选项中, 磁盘逻辑格式化程序所做的工作是（ ）。

I. 对磁盘进行分区 II. 建立文件系统的根目录 III. 确定磁盘扇区校验码所占位数 IV. 对保存空闲磁盘块信息的数据结构进行初始化

<Option>仅 II</Option>
<Option correct>仅 II、 IV</Option>
<Option>仅 III、 IV</Option>
<Option>仅 I、 II、 IV</Option>

<Solution>

**【解析】** 磁盘投入使用前需要经过三步处理：物理格式化（低级格式化）→ 磁盘分区 → 逻辑格式化（高级格式化）。三步环环相扣，从“裸盘”逐步变成可存文件的盘。

1. 物理格式化（低级格式化）。这是最底层的处理，一般由厂商在出厂前完成，主要工作是：
   - 划分扇区：在磁盘上划分出一个个扇区，为每个扇区建立物理结构；
   - 建立扇区结构：每个扇区通常由头部、数据区、尾部组成——头部和尾部包含扇区编号、校验码等控制信息，数据区才是真正存放数据的地方；
   - 坏扇区检测与处理：检测出有缺陷的扇区并标记，用备用扇区替换。
2. 磁盘分区。在物理格式化之后，把磁盘划分为一个或多个逻辑上独立的区域（例如：C 盘、D 盘），每个区域可以当作一个独立的磁盘来使用。主要工作是：
   - 分区信息记录在磁盘开头的分区表中（如 MBR 或 GPT）；
   - 每个分区可以安装不同的文件系统，甚至不同的操作系统；
   - 主引导记录（MBR）中也包含引导代码，用于启动时定位并加载活动分区中的操作系统。
3. 逻辑格式化（高级格式化）。针对每个分区进行，目的是创建文件系统，即“做文件系统的初始化”：
   - 建立文件系统的数据结构：如 FAT 表 / inode 表、根目录、空闲空间管理结构（位图或空闲表）等；
   - 为文件分配建立管理机制，此后文件数据才能以“块（簇）”为单位进行存取；
   - 有些系统在这一步还会进一步处理坏块（标记不可用、避免分配给用户文件）。

题目问“逻辑格式化”所做工作，故选Ⅱ、Ⅳ，故选 B。

**【点评】** 概念题。考查低级格式化、磁盘分区、逻辑格式化各自的工作内容。此考点较为冷门，容易忽略。

</Solution>

<Question id="408-8d5396-019" type="single">

【2018】系统总是访问磁盘的某个磁道而不响应对其他磁道的访问请求, 这种现象称为磁臂黏着。下列磁盘调度算法中, 不会导致磁臂粘着的是（ ）。

<Option correct>先来先服务 (FCFS)</Option>
<Option>最短寻道时间优先 (SSTF)</Option>
<Option>扫描算法 (SCAN)</Option>
<Option>循环扫描算法 (CSCAN)</Option>

<Solution>

**【解析】** ① A 正确 ✓：FCFS（先来先服务）算法严格按请求到达的先后顺序服务，任何请求一旦到达，其前面只有有限个请求，必定在有限时间内被服务，不可能发生磁臂黏着。

② B 错误 ×：SSTF（最短寻道时间优先）算法总是选择距当前磁头位置最近的请求。若当前磁道附近不断有新请求到来，远处磁道的请求将无限期等待，会产生磁臂黏着（饥饿）。

③ C 错误 ×：SCAN（也称为电梯算法）算法，磁头按照一个方向持续移动，沿途处理遇到的请求；到达该方向最末端后，反转方向，再反向处理剩余请求。类比于电梯：电梯从 1 楼往上升，每层有人按就停，到顶层后掉头往下，再接下楼层的乘客。磁头在移动方向上选择最近的请求进行响应，若请求持续出现在磁头当前位置附近（已扫过一侧的远端请求），该远端请求要等磁头走到尽头再折返，可使某些请求长时间得不到服务，可能产生黏着。

④ D 错误 ×：CSCAN（循环扫描）磁头只沿一个方向处理请求，到达该方向的末端后，立即快速返回起点（空跑，不处理任何请求），然后重新开始同一方向的扫描。若请求持续集中于某区域，仍可能使个别请求响应被长期拖延，存在黏着可能。

只有 FCFS 算法与磁头位置、请求分布完全无关，公平性最强，故选 A。

**【点评】** 常规题。命题人用“磁臂黏着”这一术语包装“饥饿”概念，考查考生对常见调度算法特性的理解。

</Solution>

<Option>619</Option>
<Option correct>788</Option>
<Option>799</Option>

<Solution>

**【解析】** CSCAN 算法只在一个移动方向上响应磁盘访问请求，回返时不响应请求。首先明确本题在哪个方向上响应磁盘访问请求：题目已说明完成对 200 号磁道的请求后，磁头向磁道号减小的方向移动，故本题中仅在磁头向磁道号减少的方向访问磁盘。磁头访问序列为：200、160、120、110、0、399、300、210，磁头移动距离 $=(200-0)+(399-0)+(399-210)=788$。故选 C。

<Question id="408-8d5396-023" type="essay">

【2010】假设计算机系统采用 CSCAN (循环扫描) 磁盘调度策略, 使用 2KB 的内存空间记录 16384 个磁盘块的空闲状态。
   (1) 请说明在上述条件下如何进行磁盘块空闲状态的管理。
   (2) 设某单面磁盘旋转速度为 6000r/min, 每个磁道有 100 个扇区, 相邻磁道间的平均移动时间为 1ms。若在某时刻, 磁头位于 100 号磁道处, 并沿着磁道号增大的方向移动 (如下图所示), 磁道号请求队列为 50,90,30,120, 对请求队列中的每个磁道需读取 1 个随机分布的扇区, 则读完这 4 个扇区点共需要多少时间？要求给出计算过程。

![5.3 外存管理第 9 题磁盘调度示意图](/img/questions/408/operating-system-5-3-q9.svg)

   (3) 如果将磁盘替换为随机访问的 Flash 半导体存储器 (如 U 盘、 SSD 等), 是否有比 CSCAN 更高效的磁盘调度策略？若有, 给出磁盘调度策略的名称并说明理由；若无, 说明理由。

<Solution>

**【解析】**

(1) 用位示图表示磁盘块的空闲状态。一个二进制位（1bit）表示一个磁盘块是否空闲。总共有 16384 个磁盘块，需要 $16384\times1\text{bit}=2\text{KB}$ 的存储空间，刚好可放在系统提供的内存空间中。

(2) 磁盘读取时间分为 3 部分：寻道时间、旋转延迟时间、传输时间。

① <u>寻道时间</u>：磁头移动到数据所在磁道需要的时间。CSCAN 算法每次在磁头移动方向上，选择与当前磁头最近的磁道作为访问对象。根据 CSCAN 算法，依次访问 120，30，50，90 号磁道，移动的磁道数为 $(120-100)+(120-30)+(50-30)+(90-50)=170$。相邻磁道间平均移动时间为 1ms，则总寻道时间为 $170\times1\text{ms}=170\text{ms}$。

② <u>旋转延迟时间</u>：磁头移动到指定磁道后，扇区移动到磁头下面需要的时间。磁盘转速为 6000 转/分钟，即磁盘一分钟旋转 6000 转，即一秒钟旋转 100 转。磁盘旋转一圈用时 $\frac{1}{100}=0.01\text{s}=10\text{ms}$。平均旋转延迟为磁盘旋转半圈的时间（当公式记忆）。访问 4 个扇区的旋转延迟为 $4\times\frac{1}{2r}=4\times5\text{ms}=20\text{ms}$。

③ <u>传输时间</u>：把数据从磁盘读出，或向磁盘写入数据需要的时间。每个磁道 100 个扇区，磁盘旋转一圈用时 10ms，则每个扇区读取时间为 $10\text{ms}\div100=0.1\text{ms}$。4 个扇区的读取时间为 $0.1\text{ms}\times4=0.4\text{ms}$。

综上，读完这 4 个扇区点共需要 $170+20+0.4=190.4\text{ms}$。

(3) 有更高效的策略。例如，采用先来先服务（FCFS）的磁盘调度策略（或其他更高效的策略），理由如下：Flash 半导体存储器（SSD、U 盘）没有机械部件，不存在磁头移动的寻道时间和盘片旋转的旋转延迟。而且，它支持随机访问，访问任意地址的时间几乎相同，与地址位置无关。所以，CSCAN 这类为减少寻道时间而设计的调度策略不再有意义，甚至会因排序带来额外时间开销。直接按请求顺序处理（FCFS）更高效。

**【点评】** 难题。综合考查磁盘相关计算。第 (1) 小问考“位示图”的概念。第 (2) 考磁盘读取时间。第 (3) 小问是开放性答案，较难回答。

</Solution>

<Question id="408-8d5396-024" type="essay">

【2019】某计算机系统中的磁盘有 300 个柱面, 每个柱面有 10 个磁道, 每个磁道有 200 个扇区, 扇区大小为 512B。文件系统的每个簇包含 2 个扇区。请回答下列问题:
   (1) 磁盘的容量是多少？
   (2) 假设磁头在 85 号柱面上, 此时有 4 个磁盘访问请求, 簇号分别为:100260,60005,101660 和 110560。若采用最短寻道时间优先 (SSTF) 调度算法,则系统访问簇的先后次序是什么?
   (3) 第 100530 簇在磁盘上的物理地址是什么？将簇号转换成磁盘物理地址的过程是由 I/O 系统的什么程序完成的?

<Solution>

**【解析】**

(1) 磁盘容量 = 柱面数×磁道数×扇区数×扇区大小，该磁盘的容量为 $300\times 10\times 200\times 512\mathrm{B}=3\times 10^5\mathrm{KB}$。

(2) 每个柱面共有 $10\times 200=2000$ 个扇区，即 1000 个簇，所以 85 号柱面上是第 85000 号～85999 号簇。根据最短寻道时间优先算法，应选择距离当前磁道最近的磁道访问请求进行访问，系统访问簇的先后次序是 100260，101660，110560，60005。

(3) 已知每个柱面有 10 个磁道，每个磁道有 200 个扇区，每个簇包含 2 个扇区。则每个柱面包含 $10\times 200\div 2=1000$ 个簇。

① 第 100530 簇所在的柱面号为：$\lfloor 100530\div 1000\rfloor=100$。

② 该簇在 100 号柱面的簇号为：$100530\bmod 1000=530$。每个磁道包含 $200\div 2=100$ 个簇。磁头号为：$\lfloor 530\div 100\rfloor=5$，即磁头号为 5。

③ 因为每个簇包含 2 个扇区，则扇区号为：$(530\times 2)\bmod 200=60$。

综上，第 100530 号簇在磁盘上的物理地址为：（柱面号 100，磁头号 5，扇区号 60）。将簇号转换成磁盘物理地址的过程是由 I/O 系统的磁盘驱动程序完成的。

**【提示】** 簇在磁盘上的物理格式为（柱面号，磁头号，扇区号）。

<Question id="408-8d5396-025" type="essay">

【2021】某计算机用硬盘作为启动盘,硬盘第一个扇区存放主引导记录,其中包含磁盘引导程序和分区表。磁盘引导程序用于选择要引导哪个分区的操作系统, 分区表记录硬盘上各分区的位置等描述信息。硬盘被划分成若干个分区, 每个分区的第一个扇区存放分区引导程序, 用于引导该分区中的操作系统。系统采用多阶段引导方式,除了执行磁盘引导程序和分区引导程序外,还需要执行 ROM 中的引导程序。请回答下列问题:
   (1) 系统启动过程中操作系统的初始化程序、分区引导程序、 ROM 中的引导程序、磁盘引导程序的执行顺序是什么?
   (2) 把硬盘制作为启动盘时, 需要完成操作系统的安装、磁盘的物理格式化、逻辑格式化、对磁盘进行分区,执行这 4 个操作的正确顺序是什么?
   (3) 磁盘扇区的划分和文件系统根目录的建立分别是在第 (2) 问的哪个操作中完成的？

<Solution>

**【解析】**

(1) 执行顺序依次是：ROM 中的引导程序 → 磁盘引导程序 → 分区引导程序 → 操作系统的初始化程序。① 系统启动过程中，首先运行 **ROM 中的引导程序**（也就是 BIOS，固化在 ROM 中），负责初始化硬件（设置硬件参数）和硬件加电自检等准备工作。② ROM 引导程序完成初步硬件准备后，会去读取硬盘第一个扇区（主引导记录所在扇区）中的 **磁盘引导程序**，将控制权转交给磁盘引导程序。并解析分区表，选择要引导哪个分区的操作系统。③ 磁盘引导程序选定要引导的分区后，接着执行该分区第一个扇区存放的 **分区引导程序**，并将控制权转交分区引导程序。分区引导程序衔接磁盘引导程序与操作系统内核，初始化分区环境，并加载操作系统内核。④ 分区引导程序执行完毕后，会执行 **操作系统的初始化程序**，完成操作系统的启动，让系统进入用户可操作的状态。

(2) 4 个操作的执行顺序依次是：磁盘的物理格式化 → 对磁盘进行分区 → 逻辑格式化 → 操作系统的安装。① **磁盘的物理格式化**（也叫低级格式化）由磁盘生产厂家在出厂前完成。物理格式化对磁盘划分磁道、扇区等最底层物理结构，并对磁盘表面可能存在的物理坏道进行检测和标记。② **对磁盘进行分区** 是指把一个物理磁盘的存储空间划分成若干个可独立存储的区域，例如：Windows 系统的 C 盘和 D 盘。③ **逻辑格式化**（也叫高级格式化）是指为磁盘分区创建文件系统、设置引导记录、分配目录结构的过程，使得操作系统能够识别和管理磁盘分区中的文件。④ 在已经完成逻辑格式化的分区上 **安装操作系统**。

(3) 由上一问的介绍可知，在磁盘的物理格式化中完成对磁盘扇区的划分，在磁盘的逻辑格式化中建立文件系统根目录。

</Solution>
