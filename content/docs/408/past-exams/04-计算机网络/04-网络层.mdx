# 第 4 章 网络层

## 4.1 网络层的功能 (SDN 基本概念)

<Question id="408-c10df6-001" type="single" tags="来源:2022考研408">

在 SDN 网络体系结构中, SDN 控制器向数据平面的 SDN 交换机下发流表时所使用的接口是（ ）。

<Option>东向接口</Option>
<Option correct>南向接口</Option>
<Option>西向接口</Option>
<Option>北向接口</Option>

<Solution>

**【解析】** SDN 架构以控制器为逻辑中心，通过南向接口与数据平面通信，通过北向接口与应用平面进行通信。东向和西向接口用于连接 SDN 网络中的多个控制器，实现横向扩展和协同工作。故选 B。

**【点评】** 常规题。“SDN 基本概念”是 2022 年 408 大纲中新增内容，在当年的 408 真题中就考到了。这题了解了概念就是送分题，否则就会出错。这提醒考生，对于当年考纲新增内容要重视。

</Solution>

</Question>

## 4.2 IPv4

<Question id="408-c10df6-002" type="single" number={2} tags="来源:2010考研408">

某网络的 IP 地址空间为 192.168.5.0/24, 采用定长子网划分, 子网掩码 255.255.255.248, 则该网络中的最大子网个数、每个子网内的最大可分配地址个数分别是（ ）。

<Option>32,8</Option>
<Option correct>32,6</Option>
<Option>8,32</Option>
<Option>8,30</Option>

<Solution>

**【解析】** 根据地址空间 192.168.5.0/24，可知网络前缀占 24 位。$248=1111\ 1000\mathrm{B}$，子网掩码 255.255.255.248 对应的二进制由 29 个 1 和 3 个 0 组成，可知子网号占 $29-24=5$，最大子网数为 $2^5=32$。IPv4 地址总长 32 位，划分子网后，主机号占 $32-29=3$ 位。2 种特殊的地址不分配：主机号全为 0 表示子网网络地址，主机号全为 1 表示子网广播地址。子网内的最大可分配地址个数为 $2^3-2=6$。

**【点评】** 常规题。本题考查子网划分，是 408 中的高频考点，可跟 2019 年 408 第 37 题对比学习。

</Solution>

</Question>

<Question id="408-c10df6-003" type="single" tags="来源:2010考研408">

路由器 R 因为拥塞丢弃 IP 分组, 则此时 R 可向发出该 IP 分组的源主机发送的 ICMP 报文类型是（ ）。

<Option>路由重定向</Option>
<Option>目的不可达</Option>
<Option correct>源抑制</Option>
<Option>超时</Option>

<Solution>

**【解析】** ICMP 协议是网络层的辅助协议，是对 IP 协议的补充。ICMP 报文封装在 IP 数据报中，分为 ICMP 差错报告报文和 ICMP 询问报文两大类型，分别对应差错报告和主机查询两大功能。ICMP 报文总共有 18 种标准类型，常见的有以下几种（本题选 C）：

① 路由重定向：路由器告诉主机存在更好的路由路径。

② 目的不可达：无法到达目标主机 / 网络 / 端口等。

③ 源抑制：路由器因拥塞丢弃分组时，通知源主机降低发送速率。但最新标准中已经弃用 ICMP 源抑制报文，因为它会增加路由器的额外开销，甚至可能加重拥塞。相关的拥塞控制已经完全由上层协议承担（例如：TCP 协议自带了完善的拥塞控制机制）。

④ 超时：TTL 减为 0 或分片重组超时。

⑤ 回显请求：ping 发送的探测包。

⑥ 回显应答：ping 的回复报文。

⑦ 参数问题：IP 首部出错。

**【提示】** ping 是一个基于 ICMP 协议的常用网络命令，用于网络探测，测试本机与目标主机之间网络是否连通、延迟多少、丢包不丢包。

**【点评】** 冷门考点。考查 ICMP 协议的相关报文。

</Solution>

</Question>

<Question id="408-c10df6-004" type="single" tags="来源:2011考研408">

在子网 192.168.4.0/30 中,能接收到目的地址 192.168.4.3 的 IP 分组的最大主机数量是（ ）

<Option>0</Option>
<Option>1</Option>
<Option correct>2</Option>
<Option>4</Option>

<Solution>

**【解析】** 子网 192.168.4.0/30 中，网络前缀为 30 位，主机号为 $32-30=2$ 位。子网中主机号全为 0（表示子网网络地址）和主机号全为 1（表示子网广播地址）的 IP 地址不分配，所以子网中可分配给网络设备的有效 IP 地址数量为 $2^2-2=2$。

而 IP 地址 192.168.4.3 对应二进制的最后 2 位都是 1，恰好是子网 192.168.4.0/30 的广播地址，在子网中能收到广播的主机数最多为 2 个。故选 C。

**【点评】** 综合题。考查子网划分、广播地址等常见考点，是高频考点但易错。

</Solution>

</Question>

在 TCP/IP 体系结构中, 直接为 ICMP 提供服务的协议是（ ）。

<Option>PPP</Option>
<Option correct>IP</Option>

<Option>TCP</Option>

<Solution>

ARP 协议的功能是（ ）。

<Option correct>根据 IP 地址查询 MAC 地址</Option>
<Option>根据 MAC 地址查询 IP 地址</Option>

<Option>根据 IP 地址查询域名</Option>

<Question id="408-c10df6-007" type="single" tags="来源:2012考研408">

某主机的 IP 地址为 180.80.77.55, 子网掩码为 255.255.252.0。若该主机向其所在子网发送广播分组, 则目的地址可以是（ ）。

<Option>180.80.76.0</Option>
<Option>180.80.76.255</Option>
<Option>180.80.77.255</Option>
<Option correct>180.80.79.255</Option>

<Solution>

**【解析】** 本题其实就是求子网的广播地址。广播地址的主机位全为 1。下面分步求解：

① 第一步：分析子网掩码，确定子网号的位数。将点分十六进制的 IP 地址转化为二进制：

$$
255.255.252.0=\overbrace{1111\ 1111.1111\ 1111.1111\ 11}^{22\text{个}1}00.0000\ 0000
$$

可知子网号占 22 位，主机位占 10 位。

② 第二步：将主机 IP（180.80.77.55）的主机位全部置为 1。即可得到子网的广播地址。故选 D。

$$
\overbrace{\underbrace{1011\ 0100}_{180}.\underbrace{0101\ 0000}_{80}.\underbrace{0100\ 11}_{\text{前6位}=76}}^{22\text{位网络号}}\overbrace{11.\underbrace{1111\ 1111}_{255}}^{10\text{位主机号全为}1}=180.80.79.255
$$

**【提示】** 子网号占 22 位，其实 IP 地址前 2 个字节（前 16 位）不用将十进制还原成二进制，直接将第 3 个字节展开成二进制即可。这里为了方便理解，才进行展开。

**【点评】** 常规题。考查广播地址的计算。

</Solution>

</Question>

<Question id="408-c10df6-008" type="single" tags="来源:2015考研408">

某路由器的路由表如下表所示。若路由器收到一个目的地址为 169.96.40.5 的 IP 分组,

| 目的网络 | 下一跳 | 接口 |
| --- | --- | --- |
| 169.96.40.0/23 | 176.1.1.1 | S1 |
| 169.96.40.0/25 | 176.2.2.2 | S2 |
| 169.96.40.0/27 | 176.3.3.3 | S3 |
| 0.0.0.0/0 | 176.4.4.4 | S4 |

则转发该 IP 分组的接口是（ ）。

<Option>S1</Option>
<Option>S2</Option>
<Option correct>S3</Option>
<Option>S4</Option>

<Solution>

**【解析】** 采用 CIDR 编址，一个目的地址可能同时匹配路由表中的多个表项，路由器必须遵循“最长前缀匹配”原则：在所有匹配的表项中，选择网络前缀最长（掩码中 1 的位数最多）的那一项进行转发。若无匹配的目的网络，则按照默认路由（0.0.0.0/0）转发。

在本题给出的 4 条路由表项中，四条都能和 169.96.40.5 匹配，按最长前缀匹配原则，选择前缀最长的 169.96.40.0/27，从接口 S3 转发。故选 C。

**【提示】** 0.0.0.0/0 表示默认路由：与任何地址都能匹配，但前缀长度为 0，优先级最低，仅在其他表项均不匹配时才使用。

**【点评】** 常规题。考查路由转发中的最长前缀匹配原则。

</Solution>

</Question>

<Option>H1 不能与 H2 进行正常 IP 通信</Option>
<Option>H2 与 H4 均不能访问 Internet</Option>
<Option correct>H1 不能与 H3 进行正常 IP 通信</Option>
<Option>H3 不能与 H4 进行正常 IP 通信</Option>

<Question id="408-c10df6-010" type="single" tags="来源:2016考研408">

如上题图所示,假设连接 R1、 R2 和 R3 之间的点对点链路使用 201.1.3.x/30 地址,当 H3

访问 Web 服务器 S 时, R2 转发出去的封装 HTTP 请求报文的 IP 分组的源 IP 地址和目的 IP 地址分别是（ ）。

<Option>192.168.3.251, 130.18.10.1</Option>
<Option>192.168.3.251, 201.1.3.9</Option>
<Option>201.1.3.8, 130.18.10.1</Option>
<Option correct>201.1.3.10, 130.18.10.1</Option>

<Solution>

**【解析】** ① H3（192.168.3.251）访问 S（130.18.10.1），分组到达 R2（NAT 路由器）的接口 E1，经 NAT 转换后从 R2 的 L0 接口发出：源地址 192.168.3.251（私网地址）必须替换为 R2 的公网出口地址；目的地址始终是 S 的真实地址 130.18.10.1。

② S 在 Internet 方向，须经 R1 到达，故 R2 从连接 R1 的 L0 接口转发。路由器 R1 至 R2 之间链路使用网络地址 201.1.3.x/30：

- 201.1.3.x/30 的网络前缀长度为 30，主机号仅占 2 位，可分配的主机地址只有 $2^2-2=2$ 个（主机号全为 0 和全为 1 的地址不分配），R1 的一个接口已占用 201.1.3.9，故仅剩一个可分配的主机地址 201.1.3.10、分配给 R2 的 L0 接口。

③ 所以，R2 转发出去的 IP 分组：源 IP = 201.1.3.10，目的 IP = 130.18.10.1。故选 D。

<Callout title="提示">

① NAT 维护一张映射表，地址转换是双向的。出方向修改 IP 分组的源 IP，入方向改目的 IP：

- <u>出方向</u>：内网主机发往外网的包，源 IP 是私有地址，路由器把源 IP 换成自己的公网 IP。
- <u>入方向</u>：外网返回的响应包，目的 IP 是路由器公网 IP，路由器查地址转换（映射）表，把目的 IP 换回对应内网主机的私有 IP。

② 主机号全为 0 的地址是子网地址，主机号全为 1 的地址是子网的广播地址，这 2 个地址均不分配给主机使用。

</Callout>

**【点评】** 难题。综合考查 NAT 地址转换和子网 IPv4 地址分配。

</Solution>

<Solution>

**【解法一】** 点分十进制 IP 地址 183.80.72.48，对应的二进制形式为 1011 0111.0101 0000.0100 1000.0011 0000；子网掩码 255.255.192.0 对应的二进制形式为 1111 1111.1111 1111.1100 0000.0000 0000。IP 地址和子网掩码“与”运算结果为 1011 0111.0101 0000.0100 0000.0000 0000（183.80.64.0）。

② II 错误 ×：IPv4 基本首部长度是可变的（但必须是 4 字节的倍数）：包含 20 字节的固定部分（用于传输和路由数据包）和最多 40B 的可选部分。IPv6 基本首部长度固定为 40B。

③ III 正确 √：双协议栈（Dual Stack）是指在同一设备上同时支持 IPv4 和 IPv6 协议栈。设备可以根据需要选择使用 IPv4 和 IPv6 两种协议进行通信。隧道技术（Tunneling）是一种将 IPv6 数据包封装在 IPv4 数据包中进行传输的方法，使得 IPv6 数据可以通过 IPv4 网络进行传输，实现 IPv4 到 IPv6 的过渡。

④ IV 正确 √：Hop-Limit 字段和 TTL 字段的作用都是限制数据报在网络中的传输跳数（即经过的路由器数量）。每经过一个路由器，跳数值就会减少。当跳数值达到 0 时，数据报会被丢弃，并发送一个 ICMP（Internet Control Message Protocol）时间超时报文。故选 D。

**【点评】** 常规题。考查基本概念，记忆性的内容。

</Solution>

</Question>

## 4.4 路由协议

<Question id="408-c10df6-028" type="single" number={24} tags="来源:2010考研408">

某自治系统内采用 RIP 协议, 若该自治系统内的路由器 R1 收到其邻居路由器 R2 的距离矢量, 距离矢量中包含信息 `<net1,16>`, 则能得出的结论是（ ）。

<Option>R2 可以经过 R1 到达 net1,跳数为 17</Option>
<Option>R2 可以到达 net1,跳数为 16</Option>

<Option correct>R1 不能经过 R2 到达 net1</Option>

<Solution>

**【解析】** RIP 协议是一种基于距离矢量的路由协议，它规定最大有效跳数为 15，当跳数达到 16 时，表示该网络不可达。故选 D。

<Question id="408-c10df6-029" type="single" tags="来源:2016考研408">

假设下图中的 R1、 R2、 R3 采用 RIP 交换路由信息, 且均已收敛。若 R3 检测到网络201.1.2.0/25 不可达,并向 R2 通告一次新的距离向量,则 R2 更新后,其到达该网络的距离应是（ ）。

![第 4 章 网络层 4.4 第2题：网络拓扑图，见原 PDF 第40页附近](/img/questions/408/computer-network-4-4-q2.svg)

<Option>2</Option>
<Option correct>3</Option>
<Option>16</Option>
<Option>17</Option>

<Solution>

**【解析】** ① 收敛时各路由器到 201.1.2.0/25 的距离：R3 直连为 1；R2 经 R3 为 2；R1 经 R3 为 2（此处见下文【提示】部分的解释说明）。

② R3 检测到该网不可达，把自己到该网的距离置为 16（不可达），并向邻居通告新向量；

③ R2 收到 R3 的“16”通告：按 RIP 规则，来自当前下一跳的坏消息必须接受，原经 R3 的路由失效（16 即不可达）。但 R2 在此前 R1 的周期性通告中保存有“R1 自称到该网距离为 2”的信息（R1 尚不知道网络已坏，属“过时的好消息”），于是 R2 本次更新，改选经 R1 的路径，距离 = 2 + 1 = 3，故选 B。

<Callout title="提示">

① 在本题给出图中，并未标明路由器 R3 直连网络 201.1.2.0/25，此处这个“隐含”条件，是本题最大的难点之一。其实这里并非本题有问题或者存在争议。题目条件“R3 检测到网络 201.1.2.0/25 不可达”，这里“<u>检测</u>”二字，就说明网络 201.1.2.0/25 直连 R3。

② “检测到某网络不可达”，前提是该网络是该路由器的直连网络。因为非直连网络的不可达，只能通过路由协议间接获悉。为什么非直连网络不能“检测到”？因为路由器对非直连网络的认知完全来自邻居的 RIP 通告：

- 邻居说“能到，距离 n” → 路由器就认为能到
- 邻居连续 180 秒没再通告 → 路由器才判定该路由可能无效
- 再等 120 秒仍无更新 → 彻底删除

在这整个过程中，路由器没有任何主动手段去探测非直连网络是否真的不可达——它既没有接口连在上面，也不会主动发探测包。所以对于非直连网络，路由器是“等不到更新而超时”，而不是“检测到不可达”。

</Callout>

**【点评】** 难题。考查 RIP 协议的慢收敛特性。题目隐含条件的挖掘：R3 <u>直连</u>网络 201.1.2.0/25，是本题的突破口，很多同类真题解析书籍或视频中，在此题上没有讲清楚。

</Solution>

</Question>

## 4.5 网络层设备

<Question id="408-c10df6-034" type="single" number={27} tags="来源:2010考研408">

下列网络设备中, 能够抑制广播风暴的是（ ）。 I. 中继器 II. 集线器 III. 网桥 IV. 路由器

<Option>仅 I 和 II</Option>
<Option>仅 III</Option>
<Option>仅 III 和 IV</Option>
<Option correct>仅 IV</Option>

<Solution>

**【解析】** 先明确 3 个概念。广播风暴指局域网中广播帧被大量复制、转发，占用带宽导致网络瘫痪的现象。冲突域指同一时间只能有一台设备发送数据的网络区域。网络中一台设备发送广播帧，所有能够收到该广播帧的设备共同构成一个广播域。

① 中继器（物理层设备）：仅对信号进行放大再生，会把广播帧转发到所有端口，无法抑制广播风暴。

② 集线器（物理层设备）：本质是多口中继器，所有端口在同一个冲突域和广播域中，会转发所有广播帧，无法抑制广播风暴。

③ 网桥（数据链路层设备）：可以隔离冲突域，但不能隔离广播域，广播帧会被转发到所有端口，无法抑制广播风暴。

④ 路由器（网络层设备）：每个接口属于不同的广播域，默认不转发广播帧，可以有效抑制广播风暴。

**【点评】** 综合题。考查常见网络设备的特点。

</Solution>
