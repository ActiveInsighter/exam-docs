# 第 1 章 计算机网络概述


## 1.1 计算机网络体系结构

<Question id="408-b6a8e0-001" type="single">

【2009】在 OSI 参考模型中, 自下而上第一个提供端到端服务的层次是（ ）。

<Option>数据链路层</Option>
<Option correct>传输层</Option>
<Option>会话层</Option>
<Option>应用层</Option>

<Solution>

**【解析】** 在 OSI 七层模型中：

① 物理层、数据链路层和网络层提供的都是点到点服务；

② 传输层是自下而上第一个提供端到端服务的层次；

③ 会话层、表示层和应用层虽然也提供端到端服务，但它们是在传输层提供的端到端基础之上，为应用进程提供更高级的端到端功能，不是第一个提供端到端服务的层次。故选 B。

**【点评】** 概念题。本题考查 OSI 参考模型中，各层的特点。这里对点对点和端到端服务进行总结补充。点到点服务指直接相连的两个设备之间，提供的直接数据传输服务，只关心“当前一跳”的交付，不关心最终目的地。点到点服务涉及物理层、数据链路层和网络层：

- 物理层：不寻址、不认地址，只负责把比特流从当前节点传到直接相连的下一个节点。
- 数据链路层：以太网帧基于 MAC 地址在同一局域网内两设备间传输。
- 网络层：IP 数据包基于 IP 地址在路由器之间逐跳转发。

端到端服务指在源主机和目的主机的应用进程之间提供的完整数据传输服务。传输层的端到端服务，基于端口号来标识。更通俗的讲，以接力跑来类比，点到点是：我只负责传给相邻的下一位，其他我不管；端到端是：把数据从你这传到对方那，中间所有路我全都负责，从起点管到终点。

</Solution>

</Question>

<Question id="408-b6a8e0-002" type="single">

【2010】下列选项中, 不属于网络体系结构所描述的内容是（ ）。

<Option>网络的层次</Option>
<Option>每层使用的协议</Option>
<Option correct>协议的内部实现细节</Option>
<Option>每层必须完成的功能</Option>

<Solution>

**【解析】** 网络体系结构指的是计算机网络的各层及其协议的集合。它包含了网络的层次、各层使用的协议以及需要完成的功能。网络体系结构只规定“做什么”和“怎么交互”，不规定“具体怎么做”。协议的具体实现细节由具体的硬件 / 软件厂商来实现，不属于体系结构本身要描述的内容。故选 C。

**【点评】** 概念题。本题考查网络体系结构的概念。

</Solution>

</Question>

<Question id="408-b6a8e0-003" type="single">

【2011】TCP/IP 参考模型的网络层提供的是（ ）。

<Option correct>无连接不可靠的数据报服务</Option>
<Option>无连接可靠的数据报服务</Option>
<Option>有连接不可靠的虚电路服务</Option>
<Option>有连接可靠的虚电路服务</Option>

<Solution>

**【解析】** TCP/IP 参考模型中，网络层（IP 层）只提供无连接、不可靠的数据报服务。

- **无连接：** IP 协议在发送数据报前，不需要和对方建立连接。每个 IP 数据报独立路由，不同报文可能走不同路径到达目标。
- **不可靠：** IP 协议本身不保证数据报一定送达、不保证按序到达，也不保证不重复。可靠性（重传、流量控制、顺序控制）由上层的 TCP 协议来保证。
- **数据报服务：** IP 层以数据报（分组）为单位传输，每个数据报都包含完整的源/目的 IP 地址，独立寻址。

OSI 参考模型中网络层既提供面向连接的服务，也提供无连接的服务。故选 A。

**【点评】** 概念题。考查 TCP/IP 参考模型的基本概念。

</Solution>

</Question>

<Question id="408-b6a8e0-004" type="single">

【2013】在 OSI 参考模型中, 下列功能需由应用层的相邻层实现的是（ ）。

<Option>对话管理</Option>
<Option correct>数据格式转换</Option>
<Option>路由选择</Option>
<Option>可靠数据传输</Option>

<Solution>

**【解析】** OSI 七层模型从下到上依次是：① 物理层 → ② 数据链路层 → ③ 网络层 → ④ 传输层 → ⑤ 会话层 → ⑥ 表示层 → ⑦ 应用层。

① 表示层负责数据格式转换、加密/解密、压缩/解压缩，解决不同系统间数据格式差异。

② 会话层在传输层连接之上，负责应用进程之间的对话逻辑控制：会话连接的建立与释放、会话管理与控制、会话同步与恢复、对话单元管理等。

③ 路由选择是网络层的功能，可靠性传输是传输层的功能。应用层的相邻层是表示层，表示层的核心功能是数据格式转换。故选 B。

**【点评】** 概念题。考生需牢记 OSI 模型各层的核心功能，以及 OSI 模型与 TCP/IP 模型的异同点。

</Solution>

</Question>

<Option>表示层</Option>
<Option correct>传输层</Option>

<Question id="408-b6a8e0-006" type="single">

【2016】在 OSI 参考模型中,路由器、交换机 (Switch)、集线器 (Hub) 实现的最高功能层分别是（ ）。

<Option>2,2,1</Option>
<Option>2,2,2</Option>
<Option correct>3,2,1</Option>
<Option>3,2,2</Option>

<Solution>

**【解析】** ① 首先要清楚 OSI 参考模型的层次顺序，从下至上依次为：

1. 物理层、2. 数据链路层、3. 网络层、4. 传输层、5. 会话层、6. 表示层、7. 应用层。

- R1 为路由器，工作在网络层（第 3 层）。其功能是根据 IP 地址转发分组，隔离广播域，进行路由选择。
- Switch 为交换机，工作在数据链路层（第 2 层）。其功能是根据 MAC 地址转发帧，隔离冲突域，同一广播域。
- Hub 为集线器，工作在物理层（第 1 层）。其功能是仅对电信号进行放大和广播转发，不识别任何地址。

综上，R1、Switch、Hub 在 OSI 参考模型中工作的层次分别为 3、2、1，故选 C。

<Callout title="提示">

① 设备工作在第 $n$ 层，指它能识别和处理第 $n$ 层的协议数据单元（首部 / 地址信息），$n$ 是它实现的最高一层。要实现第 $n$ 层的功能，就必须先实现它下面各层的功能：因为高层数据是逐层封装在底层之上的。故工作在第 $n$ 层的设备，实际上实现了 1 到 $n$ 层的全部功能。

</Callout>

**【点评】** 常规题。考查常见网络设备工作的 OSI 层次。

</Solution>

</Question>

<Question id="408-b6a8e0-007" type="single">

【2017】假设 OSI 参考模型的应用层欲发送 400B 的数据 (无拆分), 除物理层和应用层之外,其他各层在封装 PDU 时均引入 20B 的额外开销,则应用层数据传输效率约为（ ）。

<Option correct>80%</Option>
<Option>83%</Option>
<Option>87%</Option>
<Option>91%</Option>

<Solution>

**【解析】** OSI 共 7 层，除去应用层（数据源）和物理层（不封装 PDU 头），还有表示层、会话层、传输层、网络层、数据链路层共 5 层，每层加 20B 额外开销，共 $5\times20\mathrm{B}=100\mathrm{B}$。传输效率 = 应用层数据 ÷ 实际传送总量 = $\frac{400}{400+100}=80\%$。故选 A。

**【点评】** 概念题。考查 OSI 七层模型。要注意物理层只做比特传输，不封装 PDU。

</Solution>

</Question>

<Question id="408-b6a8e0-008" type="single">

【2019】OSI 参考模型的第 5 层 (自下而上) 完成的主要功能是（ ）。

<Option>差错控制</Option>
<Option>路由选择</Option>
<Option correct>会话管理</Option>
<Option>数据表示转换</Option>

<Solution>

**【解析】** OSI 参考模型自下而上分别为：物理层、数据链路层、网络层、传输层、会话层、表示层、应用层。

① A 错误 ×：差错控制是数据链路层、网络层、传输层的功能之一：数据链路层针对“帧”检查“位错”；网络层针对“分组首部”检查“首部位错”（辅助路由）；传输层针对“段 / 数据报”检查“位错”并处理“丢失、乱序”等传输异常。

② B 错误 ×：路由选择是网络层的主要功能。

③ C 正确 ✓：会话层是 OSI 参考模型的第五层，会话层的功能是管理并协调不同主机上各个进程之间的通信会话。

④ D 错误 ×：数据表示转换是表示层的主要功能。故选 C。

**【点评】** 常规题。考查 OSI 参考模型的基本概念，记忆性内容。

</Solution>

<Question id="408-b6a8e0-010" type="single">

【2021】在 TCP/IP 参考模型中, 由传输层相邻的下一层实现的主要功能是（ ）

<Option>对话管理</Option>
<Option correct>路由选择</Option>
<Option>端到端报文段传输</Option>
<Option>结点到结点流量控制</Option>

<Solution>

**【解析】** 在 TCP/IP 参考模型从下至上依次为：① 网络接口层：对应 OSI 模型中的数据链路层和物理层，负责数据在物理网络中传输，处理硬件相关细节。② 网际层：对应 OSI 模型中的网络层，负责数据包的路由和转发，实现主机到主机的通信。③ 传输层：对应 OSI 模型中的传输层，提供端到端的可靠（TCP）或不可靠（UDP）数据传输服务，保障数据可靠性和完整性。④ 应用层：对应 OSI 模型的应用层、表示层和会话层，直接为应用程序提供网络服务。

A 错误：对话管理是应用层功能。B 正确：传输层紧邻的下一层为网际层。C 错误：端到端报文传输是传输层功能。D 错误：结点到结点流量控制是网络接口层（数据链路层）功能。

**【点评】** 常规题。考查 TCP/IP 参考模型的概念。举一反三，考生再回顾下 OSI 模型的概念。另外，端到端指应用程序（进程）之间，点到点通常指主机（IP 地址或 MAC 地址）之间。

</Solution>

</Question>

<Question id="408-b6a8e0-011" type="single">

【2022】在 ISO/OSI 参考模型中, 实现两个相邻结点间流量控制功能的是（ ）。

<Option>物理层</Option>
<Option correct>数据链路层</Option>
<Option>网络层</Option>
<Option>传输层</Option>

<Solution>

**【点评】** 常规题。考 ISO/OSI 参考模型的基本概念。类似的题 408 考过多次，考生需要理解记忆。

</Solution>

</Question>
