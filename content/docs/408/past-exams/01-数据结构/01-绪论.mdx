# 第 1 章 绪论


## 1.1 绪论

<Question id="408-4f5586-001" type="single">

【2011】设 $ n$ 是描述问题规模的非负整数，下面程序片段的时间复杂度是（ ）。

```c
x = 2;
while (x < n / 2)
    x = 2 * x;
```

<Option correct>$ O(\log_2 n)$</Option>
<Option>$ O(n)$</Option>
<Option>$ O(n\log_2 n)$</Option>
<Option>$ O(n^2)$</Option>

<Solution>

**【解析】** 时间复杂度是基本语句执行次数的数量级。本题的基本语句为“`x=2*x`”。若该语句执行第 $t+1$ 次时跳出循环，即 $t$ 取满足条件 $2^{t+1}<n/2$ 的最大值，则 $t=\lceil\log_2 n/2\rceil-1$。该等式与 $\log_2 n$ 同数量级，所以该程序段的时间复杂度为 $O(\log_2 n)$。故选 A。

**【点评】** 常规题。考查时间复杂度计算的常规题目。

</Solution>

</Question>

```c
int fact(int n) {
    if (n <= 1) return 1;

```

<Option>$ O(\log_2 n)$</Option>
<Option correct>$ O(n)$</Option>
<Option>$ O(n\log_2 n)$</Option>

<Solution>

**【解析】** 时间复杂度是基本语句执行次数的数量级。本题基本语句是“`n*fact(n-1)`”，该语句会执行 $n-1$ 次。故时间复杂度为 $O(n)$。故选 B。

**【点评】** 常规题。考查时间复杂度的计算。

</Solution>

<Question id="408-4f5586-003" type="single">

【2014】下列程序段的时间复杂度是（ ）。

```c
count = 0;
for (k = 1; k <= n; k *= 2)
    for (j = 1; j <= n; j++)
        count++;
```

<Option>$ O(\log_2 n)$</Option>
<Option>$ O(n)$</Option>
<Option correct>$ O(n\log_2 n)$</Option>
<Option>$ O(n^2)$</Option>

<Solution>

**【解析】** 外层循环“`for(k = 1; k <= n; k *= 2)`”的执行是 $\lfloor\log_2 n\rfloor$。内存循环“`for(j = 1; j <= n; j++)`”，每次执行 $n$ 次。时间复杂度是基本语句执行次数的数量级。本题的基本语句是“`count++`”，其执行次数为：$n\lfloor\log_2 n\rfloor$。故时间复杂度为 $O(n\log_2 n)$。故选 C。

<Question id="408-4f5586-004" type="single">

【2017】下列函数的时间复杂度是（ ）。

```c
int func(int n) {
    int i = 0, sum = 0;
    while (sum < n) sum += ++i;
    return i;
}
```

<Option>$ O(\log_2 n)$</Option>
<Option correct>$ O(n^{1/2})$</Option>
<Option>$ O(n)$</Option>
<Option>$ O(n\log_2 n)$</Option>

<Solution>

**【解析】** 时间复杂度指基本语句执行次数的数量级。该函数的基本语句是 `sum += ++i`，该基本语句的执行次数受到 while 循环条件 `sum < n` 的制约。

（1）假设语句 `sum += ++i` 共执行了 $t$ 次，当执行到 $t+1$ 次时，`sum ≥ n`。

（2）当语句 `sum += ++i` 执行到第 $t$ 次时，$i=t$，$\mathrm{sum}=1+2+3+\cdots+t=\frac{t(1+t)}{2}$。结合（1）的假设可得，$\mathrm{sum}=\frac{t(1+t)}{2}\ge n$，解得 $t=\left\lceil\frac{\sqrt{8n+1}-1}{2}\right\rceil$，可知 $t$ 与 $\sqrt{8n+1}$（即 $n^{1/2}$）同数量级，所以该程序段的时间复杂度为 $O(n^{1/2})$。故选 B。

**【点评】** 常规题。本题和 2019 年 408 第 1 题相似。如今 408 考试中考时间复杂度时，很少再出现一眼就能看出答案题目了，需要经过一定的推导计算。

</Solution>

</Question>

<Question id="408-4f5586-005" type="single">

【2019】设 $ n$ 是描述问题规模的非负整数，下列程序段的时间复杂度是（ ）。

```c
x = 0;
while (n >= (x + 1) * (x + 1))
    x = x + 1;
```

<Option>$ O(\log_2 n)$</Option>
<Option correct>$ O(n^{1/2})$</Option>
<Option>$ O(n)$</Option>
<Option>$ O(n^2)$</Option>

<Solution>

**【解析】** 时间复杂度指基本语句执行次数的数量级。本题程序段的基本语句是 `x = x+1`，该基本语句的执行次数受到 while 循环条件 `n >= (x+1)*(x+1)` 的制约，可知基本语句最多执行次数不超过 $n^{1/2}$ 次，故时间复杂度为 $O(n^{1/2})$。故选 B。

**【点评】** 常规题。考查时间复杂度的常规题目。关于“时间复杂度”的定义，很多其他教辅讲的较难理解，考生可能对此不清不楚，建议考生查看竞成《数据结构考研复习全书》中的讲解，更好理解。

</Solution>

</Question>

<Question id="408-4f5586-006" type="single">

【2022】下列程序段的时间复杂度是（ ）。

```c
int sum = 0;
for (int i = 1; i < n; i *= 2)
    for (int j = 0; j < i; j++)
        sum++;
```

<Option>$ O(\log_2 n)$</Option>
<Option correct>$ O(n)$</Option>
<Option>$ O(n\log_2 n)$</Option>
<Option>$ O(n^2)$</Option>

<Solution>

**【解析】** 本题的基本语句是“sum++”，时间复杂度是基本语句执行次数的数量级。本题程序是二层循环，外层循环中 $i$ 的值是多少，内层循环中就要执行多少次运算。令 $m=\lfloor\log_2 n\rfloor$，外层循环中 $i$ 的值分别为 $1,2,4,8,\cdots,2^{m-1},2^m$，则基本语句的执行次数为 $1+2+4+8+\cdots+2^{m-1}=2^m-1\approx 2^{\log_2 n}-1$。因为 $2^{\log_2 n}-1$ 与 $2^{\log_2 n}=n$ 数量级相同，所以时间复杂度为 $O(n)$。

{/* 原书列出的外层 i 值与求和上限不完全一致，保留原文；不影响渐近复杂度。 */}

**【点评】** 易错题。本题是常见的时间复杂度计算题，命题人在此题上精心设计了一些坑，具有迷惑性：① 误认为内层循环次数的数量级是 $O(n)$，从而误选 C；② 误认为外层和内层循环次数的数量级都是 $O(n)$，从而误选 D。

</Solution>

<Question id="408-4f5586-007" type="single">

【2023】下列对顺序存储的有序表（长度为 $ n$）实现给定操作的算法中，平均时间复杂度为 $ O(1)$ 的是（ ）。

<Option>查找包含指定值元素的算法</Option>
<Option>插入包含指定值元素的算法</Option>
<Option>删除第 $ i(1\le i\le n)$ 个元素的算法</Option>
<Option correct>获取第 $ i(1\le i\le n)$ 个元素的算法</Option>

<Solution>

**【解析】** ① A 选项 ×：在顺序存储的有序表中，查找指定值元素，可以通过顺序查找，其时间复杂度为 $O(n)$，也可以采用折半查找，时间复杂度为 $O(\log n)$。

② B 选项 ×：在顺序存储的有序表中，插入一个元素可能需要移动其他元素，以便为新元素腾出空间，该操作时间复杂度取决于元素的插入位置，最坏情况下需要移动整个数组，时间复杂度为 $O(n)$。

③ C 选项 ×：在顺序存储的有序表中，删除一个元素后，后面的元素需要向前移动以填补空缺。这个过程的时间复杂度也取决于删除位置，最坏情况下需要移动整个数组，时间复杂度为 $O(n)$。

④ D 选项 √：在顺序存储的有序表中，可以通过数组下标来直接访问数组中的元素，这个操作的时间复杂度为 $O(1)$。故选 D。

**【点评】** 常规题。考查顺序表的基本操作。数组是顺序存储的有序表的一种具体实现，本题可用在有序数组中的各种操作来类比。

</Solution>

</Question>
