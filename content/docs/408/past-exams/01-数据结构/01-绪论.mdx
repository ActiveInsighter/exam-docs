# 第 1 章 绪论


## 1.1 绪论

<ExamQuestion>

1. 【2011】设 $ n$ 是描述问题规模的非负整数，下面程序片段的时间复杂度是（ ）。

```c
x = 2;
while (x < n / 2)
    x = 2 * x;
```

<ExamChoices>
<ExamOption>A. $ O(\log_2 n)$</ExamOption>
<ExamOption>B. $ O(n)$</ExamOption>
<ExamOption>C. $ O(n\log_2 n)$</ExamOption>
<ExamOption>D. $ O(n^2)$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>A</ExamAnswer>

<ExamExplanation>
设循环执行了 $ t$ 次。初始时 $ x=2$，每执行一次循环，$ x$ 扩大为原来的 $ 2$ 倍，因此执行 $ t$ 次后

$$
x=2\cdot 2^t=2^{t+1}.
$$

循环结束时应有 $ 2^{t+1}\ge \frac{n}{2}$，所以

$$
t=\Theta(\log_2 n).
$$

循环体内只有常数次基本操作，故程序的时间复杂度为 $ O(\log_2 n)$。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

2. 【2012】求整数 $ n(n\ge 0)$ 阶乘的算法如下，其时间复杂度是（ ）。

```c
int fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}
```

<ExamChoices>
<ExamOption>A. $ O(\log_2 n)$</ExamOption>
<ExamOption>B. $ O(n)$</ExamOption>
<ExamOption>C. $ O(n\log_2 n)$</ExamOption>
<ExamOption>D. $ O(n^2)$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>B</ExamAnswer>

<ExamExplanation>
当 $ n>1$ 时，函数每次递归都将参数减 $ 1$，直至参数变为 $ 1$。递归调用序列为

$$
n,n-1,n-2,\ldots,1,
$$

共进行 $ n$ 级左右的调用。每一层除递归调用外只进行常数次判断和乘法，因此递推式可写为

$$
T(n)=T(n-1)+O(1).
$$

解得 $ T(n)=O(n)$，故选 B。该算法的递归栈空间复杂度也为 $ O(n)$，但本题只问时间复杂度。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

3. 【2014】下列程序段的时间复杂度是（ ）。

```c
count = 0;
for (k = 1; k <= n; k *= 2)
    for (j = 1; j <= n; j++)
        count++;
```

<ExamChoices>
<ExamOption>A. $ O(\log_2 n)$</ExamOption>
<ExamOption>B. $ O(n)$</ExamOption>
<ExamOption>C. $ O(n\log_2 n)$</ExamOption>
<ExamOption>D. $ O(n^2)$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>C</ExamAnswer>

<ExamExplanation>
外层循环中 $ k$ 依次取

$$
1,2,4,\ldots,2^t,
$$

当 $ 2^t\le n<2^{t+1}$ 时停止，因此外层循环执行次数为 $ \lfloor\log_2 n\rfloor+1=\Theta(\log_2 n)$。

每次外层循环中，内层循环均执行 $ n$ 次，所以总基本操作次数为

$$
n\bigl(\lfloor\log_2 n\rfloor+1\bigr)=\Theta(n\log_2 n).
$$

故时间复杂度为 $ O(n\log_2 n)$。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

4. 【2017】下列函数的时间复杂度是（ ）。

```c
int func(int n) {
    int i = 0, sum = 0;
    while (sum < n) sum += ++i;
    return i;
}
```

<ExamChoices>
<ExamOption>A. $ O(\log_2 n)$</ExamOption>
<ExamOption>B. $ O(n^{1/2})$</ExamOption>
<ExamOption>C. $ O(n)$</ExamOption>
<ExamOption>D. $ O(n\log_2 n)$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>B</ExamAnswer>

<ExamExplanation>
循环第 $ i$ 次执行后，变量 $ sum$ 的值为

$$
1+2+\cdots+i=\frac{i(i+1)}{2}.
$$

循环终止时，$ sum\ge n$，即

$$
\frac{i(i+1)}{2}\ge n.
$$

由此可得 $ i=\Theta(\sqrt n)$。循环体每次只执行常数次操作，所以函数的时间复杂度为

$$
O(\sqrt n)=O(n^{1/2}).
$$
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

5. 【2019】设 $ n$ 是描述问题规模的非负整数，下列程序段的时间复杂度是（ ）。

```c
x = 0;
while (n >= (x + 1) * (x + 1))
    x = x + 1;
```

<ExamChoices>
<ExamOption>A. $ O(\log_2 n)$</ExamOption>
<ExamOption>B. $ O(n^{1/2})$</ExamOption>
<ExamOption>C. $ O(n)$</ExamOption>
<ExamOption>D. $ O(n^2)$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>B</ExamAnswer>

<ExamExplanation>
循环条件等价于

$$
(x+1)^2\le n.
$$

变量 $ x$ 从 $ 0$ 开始，每次增加 $ 1$。循环执行次数约为 $ \lfloor\sqrt n\rfloor$，因此基本操作次数与 $ \sqrt n$ 同阶，即

$$
T(n)=\Theta(\sqrt n).
$$

故时间复杂度为 $ O(n^{1/2})$。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

6. 【2022】下列程序段的时间复杂度是（ ）。

```c
int sum = 0;
for (int i = 1; i < n; i *= 2)
    for (int j = 0; j < i; j++)
        sum++;
```

<ExamChoices>
<ExamOption>A. $ O(\log_2 n)$</ExamOption>
<ExamOption>B. $ O(n)$</ExamOption>
<ExamOption>C. $ O(n\log_2 n)$</ExamOption>
<ExamOption>D. $ O(n^2)$</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>B</ExamAnswer>

<ExamExplanation>
外层循环中，$ i$ 依次取 $ 1,2,4,\ldots,2^k$，其中 $ 2^k<n\le 2^{k+1}$。第 $ r$ 次外层循环中，内层循环执行 $ 2^r$ 次，因此总执行次数为等比数列之和

$$
1+2+4+\cdots+2^k=2^{k+1}-1.
$$

由 $ 2^k<n\le 2^{k+1}$ 可知，该和为 $ \Theta(n)$。因此程序的时间复杂度为 $ O(n)$，而不是把“外层 $ O(\log n)$”与“最大内层 $ O(n)$”直接相乘得到 $ O(n\log n)$。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

7. 【2023】下列对顺序存储的有序表（长度为 $ n$）实现给定操作的算法中，平均时间复杂度为 $ O(1)$ 的是（ ）。

<ExamChoices>
<ExamOption>A. 查找包含指定值元素的算法</ExamOption>
<ExamOption>B. 插入包含指定值元素的算法</ExamOption>
<ExamOption>C. 删除第 $ i(1\le i\le n)$ 个元素的算法</ExamOption>
<ExamOption>D. 获取第 $ i(1\le i\le n)$ 个元素的算法</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>D</ExamAnswer>

<ExamExplanation>
顺序表中的元素存放在一段连续的存储空间中。若首元素地址为 $ LOC(a_1)$，每个元素占用 $ L$ 个存储单元，则第 $ i$ 个元素的地址为

$$
LOC(a_i)=LOC(a_1)+(i-1)L.
$$

因此，只要给出合法下标 $ i$，便可通过地址计算直接访问第 $ i$ 个元素，时间复杂度为 $ O(1)$。

其余选项中：有序顺序表按值查找即使采用折半查找也需 $ O(\log_2 n)$；插入元素通常需要移动后续元素，平均为 $ O(n)$；删除第 $ i$ 个元素也通常需要前移其后的元素，平均为 $ O(n)$。故选 D。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>
