# 第 2 章 线性表

## 2.2 线性表的链式存储

<Question id="408-c52f34-006" type="single" tags="来源:2013考研408">

已知两个长度分别为 $m$ 和 $n$ 的升序链表，若将它们合并为一个长度为 $m+n$ 的降序链表，则最坏情况下的时间复杂度是（ ）。

<Option>$O(n)$</Option>
<Option>$O(mn)$</Option>
<Option>$O(\min(m,n))$</Option>
<Option correct>$O(\max(m,n))$</Option>

<Solution>

**【解析】** 设置一个临时链表，两个升序链表从头开始比较，每次将两链表比较结果较小的、采用头插法插入到临时链表中。当一个链表遍历结束之后，将另一个未遍历完的链表采用头插法插入到临时链表中即可。最终的临时链表即为合并后的降序链表。最坏情况下需要将更长的链表遍历完，时间复杂度为 $O(\max(m,n))$。

**【点评】** 常规题。这类题列举一个实际的例子来找思路和验证，更快更准。例如：链表 $1\to2\to3$ 和链表 $5\to6\to7\to8$。

</Solution>

</Question>

<Question id="408-c52f34-007" type="single" tags="来源:2016考研408">

已知表头元素为 c 的单链表在内存中的存储状态如下表所示。现将 f 存放于 1014H 处并插入到单链表中，若 f 在逻辑上位于 a 和 e 之间，则 a、e、f 的“链接地址”依次是（ ）。

| 地址  | 元素 | 链接地址 |
| ----- | ---- | -------- |
| 1000H | a    | 1010H    |
| 1004H | b    | 100CH    |
| 1008H | c    | 1000H    |
| 100CH | d    | NULL     |
| 1010H | e    | 1004H    |
| 1014H |      |          |

<Option>1010H，1014H，1004H</Option>
<Option>1010H，1004H，1014H</Option>
<Option>1014H，1010H，1004H</Option>
<Option correct>1014H，1004H，1010H</Option>

<Solution>

**【解析】** 根据题目条件，链表初始状态为 $c$(1008H) → $a$(1000H) → $e$(1010H) → $b$(1004H) → $d$(100CH) → NULL。加入 $f$ 之后，由于 $f$ 在逻辑上位于 $a$ 与 $e$ 之间，因此 $a$ 指向 $f$，$f$ 指向 $e$。插入 $f$ 之后的状态为 $c$(1008H) → $a$(1000H) → $f$(1014H) → $e$(1010H) → $b$(1004H) → $d$(100CH) → NULL。题目中的“链接地址”指的是某结点的指针所指的下一个结点的地址，可知 $a$、$e$、$f$ 的链接地址分别为 1014H、1004H、1010H。故选 D。

**【点评】** 常规题。考查链表在内存中的存储，有一定新意，初次遇到容易出错。

</Solution>

</Question>

<Question id="408-c52f34-008" type="single" tags="来源:2016考研408">

已知一个带有表头结点的双向循环链表 L，结点结构为 `|prev|data|next|`，其中，prev 和 next 分别是指向其直接前驱和直接后继结点的指针。现要删除指针 p 所指的结点，正确的语句序列是（ ）。

<Option>`p->next->prev=p->prev; p->prev->next=p->prev; free(p);`</Option>
<Option>`p->next->prev=p->next; p->prev->next=p->next; free(p);`</Option>
<Option>`p->next->prev=p->next; p->prev->next=p->prev; free(p);`</Option>
<Option correct>`p->next->prev=p->prev; p->prev->next=p->next; free(p);`</Option>

<Solution>

**【解析】** 删除 $p$ 指针所指的结点，需要改变 $p$ 的前驱结点的 next 指针和 $p$ 后继结点的 prev 指针，将 `p->prev->next` 指向 `p->next` 结点，`p->next->prev` 指向 `p->prev` 结点。最后释放 $p$ 指针所指的结点的空间。故选 D。

**【点评】** 常规题。考查链表的删除。

</Solution>

</Question>

<Question id="408-c52f34-009" type="single" tags="来源:2021考研408">

已知头指针 h 指向一个带头结点的非空单循环链表，结点结构为 `|data|next|`。其中 next 是指向直接后继结点的指针，p 是尾指针，q 是临时指针。现要删除该链表的第一个元素，正确的语句序列是（ ）。

<Option>`h->next=h->next->next; q=h->next; free(q);`</Option>
<Option>`q=h->next; h->next=h->next->next; free(q);`</Option>
<Option>`q=h->next; h->next=q->next; if(p!=q) p=h; free(q);`</Option>
<Option correct>`q=h->next; h->next=q->next; if(p==q) p=h; free(q);`</Option>

<Solution>

**【解析】** 本题要考虑的特殊情况是：“当链表中只有一个元素时，即要删除的是尾指针 p 指向的结点时”，画图模拟此场景下链表删除，如右图所示：

![链表删除示意图](/img/2021-a01.svg)

在这种情况下，肯定涉及处理尾指针 p，可快速排除 A 和 B。观察选项 C 和 D，唯一的不同就是判断 p 和 q 的关系：这两个选项中 q 都指向了链表的第一个元素（待删除结点），而 p 是尾指针。在上述情况下：① 当 p 和 q 不相等时，说明链表中元素不止一个，删除第一个元素不影响尾指针 p，故 C 错误；② 当 p 和 q 相等时（尾指针指向第一个元素），说明链表中只有一个元素，将其删除后就只剩下头结点，所以要将尾指针指向头结点，故 D 正确。

**【点评】** 常规题。链表删除是常见基础的考点，本题为了增加难度，增加了“非空单循环”这些限制条件。“非空”则要考虑删除前，除头结点外链表只有一个元素的特殊情况。另外，需要留意的是，如本题所示，通常默认头结点仅作为链表的入口，不属于链表中的元素。

</Solution>

</Question>

<Question id="408-c52f34-010" type="single" tags="来源:2023考研408">

现有非空双向链表 L，其结点结构为 `|prev|data|next|`，prev 是指向直接前驱结点的指针，next 是指向后继结点的指针。若要在 L 中指针 p 所指向的结点（非尾结点）之后插入指针 s 指向的新结点，则在执行了语句序列 `s->next=p->next; p->next=s;` 后，下列语句序列中还需要执行的是（ ）。

<Option>`s->next->prev=p; s->prev=p;`</Option>
<Option>`p->next->prev=s; s->prev=p;`</Option>
<Option correct>`s->prev=s->next->prev; s->next->prev=s;`</Option>
<Option>`p->next->prev=s->prev; s->next->prev=p;`</Option>

<Solution>

**【解析】** 本题主要考查双链表的插入操作，这类问题画图模拟可减小出错概率，示意图如右图所示。双链表中插入一个结点，需要处理 4 个指针：因为 `s -> next` 已经赋值为 p 的后继结点，同时 `p->next` 指针已经赋值为 s。所以只需要处理 `s -> prev` 和 `s -> next -> prev`。`s -> prev` 需要指向 p，`s -> next -> prev` 需要指向 s。由于题中已经设置 `s -> next` 等于 `p -> next`，所以 `s -> next -> prev` 等价于 `p -> next -> prev`，也就是 p 本身。故选 C。

<Question id="408-c52f34-011" type="single" tags="来源:2024考研408">

已知带头结点的非空单链表 L 的头指针为 h，结点结构为 `|data|next|`，其中 next 是指向直接后继结点的指针。现有指针 p 和 q，若 p 指向 L 中非首且非尾的任意一个结点，则执行语句序列 `q=p->next; p->next=q->next; q->next=h->next; h->next=q;` 的结果是（ ）。

<Option>在 p 所指结点后插入 q 所指结点</Option>
<Option>在 q 所指结点后插入 p 所指结点</Option>
<Option>将 p 所指结点移动到 L 的头结点之后</Option>
<Option correct>将 q 所指结点移动到 L 的头结点之后</Option>

<Solution>

**【解析】** “`q = p->next;`” 使 q 指向 p 的后继；“`p->next = q->next;`” 使 p 指向 q 的后继（即 p 的后继的后继）；“`q->next = h->next;`” q 指向头指针 h 的后继；“`h->next = q;`” 将头指针 h 指向 q 结点。该语句序列实现将 p 的后继结点插入到头指针 h 之后。故选 D。

**【点评】** 常规题。本题有点绕，没通常的第一题那么简单。但大部分人做出来应该没问题。

</Solution>

</Question>
