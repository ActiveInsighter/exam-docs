# 第 3 章 栈、队列和数组


## 3.1 栈

<Question id="408-db1ecd-001" type="single">

【2009】设栈S 和队列Q 的初始状态均为空, 元素a、b、c、d、e、f 、g 依次进入栈S。若每个元素出栈后立即进入队列Q, 且7 个元素出队的顺序是b、d、c、f 、e、a、g，则栈S 的容量至少是（ ）。

<Option>1</Option>
<Option>2</Option>
<Option correct>3</Option>
<Option>4</Option>

<Solution>

**【解析】** 队列先进先出，则出队顺序对应了出栈顺序。栈 $S$ 的入栈出栈过程为：$a$、$b$ 入栈，$b$ 出栈，$c$、$d$ 入栈，$d$、$c$ 出栈，$e$、$f$ 入栈，$f$、$e$、$a$ 出栈，$g$ 入栈，$g$ 出栈。栈容量最少为 3。

**【点评】** 常规题。考查栈和队列的特点。

</Solution>

</Question>

<Question id="408-db1ecd-002" type="single">

【2010】若元素a,b,c,d,e,f 依次进栈, 允许进栈、退栈操作交替进行, 但不允许连续三次进行退栈操作，则不可能得到的出栈序列是（ ）。

<Option>dcebfa</Option>
<Option>cbdaef</Option>
<Option>bcaefd</Option>
<Option correct>afedcb</Option>

<Solution>

**【解析】** 用 I 表示进栈，O 表示出栈。选项 A 可由 IIIIOOIOOIOO 得到，选项 B 可由 IIIOOIOOIOIO 得到，选项 C 可由 IIOIOOIIOIOO 得到，都满足题意。而选项 D 可由 IOIIIIIOOOOO 得到，但题目要求不允许连续三次退栈操作，选项 D 不符合题意。故选 D。

**【点评】** 常规题。考查入栈和出栈操作。

</Solution>

</Question>

<Question id="408-db1ecd-003" type="single">

【2011】元素a,b,c,d,e 依次进入初始为空的栈中，若元素进栈后可停留、可出栈, 直到所有元素都出栈，则在所有可能的出栈序列中, 以元素d 开头的序列个数是（ ）。

<Option>3</Option>
<Option correct>4</Option>
<Option>5</Option>
<Option>6</Option>

<Solution>

**【解析】** 入栈顺序为 $a,b,c,d,e$，由于第一个出栈元素为 $d$，根据栈后进先出的特点，则说明 $a,b,c$ 已入栈。当 $d$ 出栈后，下一个出栈的元素只能是 $e$ 或 $c$，再分类讨论：① 若下一个出栈元素是 $e$，则出栈序列为 $decba$；② 若下一个出栈元素是 $c$，则再次出栈元素只能是 $e$ 或 $b$：

- 若出栈元素为 $e$，则出栈序列为 $dceba$；
- 若出栈元素为 $b$，则出栈序列为 $dcbea$ 或 $dcbae$；

共有 4 种出栈序列。故选 B。

**【点评】** 常规题。考查出栈入栈操作（后进先出），注意分类讨论不要漏。另外，本题也等价于“将 $e$ 插入到序列 $c,b,a$ 中，共 $\_c\_b\_a\_$ 有 4 个位置可以插入”。

</Solution>

</Question>

<Question id="408-db1ecd-004" type="single">

【2013】一个栈的入栈序列为 $1,2,3,\cdots,n$， 其出栈序列是 $p_1,p_2,p_3,\cdots,p_n$。若 $p_2=3$，则 $p_3$ 可能取值的个数是（ ）。

<Option>n - 3</Option>
<Option>n - 2</Option>
<Option correct>n - 1</Option>
<Option>无法确定</Option>

<Solution>

**【解析】【解法一】** $p_2=3$，根据栈后进先出，$p_1$ 只能为 1 或 2，$p_3$ 可以在 $p_2$ 出栈之后，通过入栈后立刻出栈取到序列中的任意值（3 本身除外）。故 $p_3$ 可能的取值个数为 $n-1$。故选 C。

**【解法二】** 举特例分析，例如：假设 $n=5$，入栈序列为 1,2,3,4,5，出栈序列为 $p_1,3,p_3,p_4,p_5$。3 入栈之后，说明 1 和 2 都已经入过栈，$p_1$ 只能为 1 或 2：① 若 $p_1=1,p_2=3$，说明 1 入栈之后立刻出栈，2 入栈后未出栈，3 入栈后立刻出栈，2 出栈后再入栈其他元素，或者入栈其他元素并立刻出栈，$p_3$ 可以在 $\{2,4,5\}$ 中间取值。② 若 $p_1=2,p_2=3$，说明 2 入栈之后立刻出栈，1 入栈后未出栈，3 入栈后立刻出栈，1 出栈后再入栈其他元素，或者入栈其他元素并立刻出栈，$p_3$ 可以在 $\{1,4,5\}$ 中间取值。故选 C。通过举特例分析的过程，可以逐步明确正确选项。

**【点评】** 常规题。本题有一定思维量，分析起来比较费时间。

</Solution>

</Question>

I. 采用非递归方式重写递归程序时必须使用栈
II. 函数调用时,系统要用栈保存必要的信息
III. 只要确定了入栈次序, 就可确定出栈次序
IV. 栈是一种受限的线性表,允许在其两端进行操作

<Option>仅I</Option>
<Option>仅I、II、III</Option>
<Option correct>仅I、III、IV</Option>
<Option>仅II、III、IV</Option>

<Solution>

**【解析】** ① Ⅰ错误：采用非递归方式重写递归程序时，不是必须使用栈，可以用循环等其他方式。② Ⅱ正确：函数调用时，系统会用栈保存返回地址、参数等必要信息。③ Ⅲ错误：例如，若入栈顺序为 1,2,3，出栈次序不唯一，可以是 3,2,1，也可以是 2,3,1。④ Ⅳ错误：栈只允许在一端进行操作。

【2022】给定有限符号集S, in 和out 均为S 中所有元素的任意排列。对于初始为空的栈ST, 下列叙述中, 正确的是（ ）。

<Option>若in 是ST 的入栈序列，则不能判断out 是否为其可能的出栈序列</Option>
<Option>若out 是ST 的出栈序列，则不能判断in 是否为其可能的入栈序列</Option>

## 3.2 队列

<Question id="408-db1ecd-009" type="single" number={1}>

【2010】某队列允许在其两端进行入队操作, 但仅允许在一端进行出队操作。若元素a、b、c、d、e 依次入此队列后再进行出队操作，则不可能得到的出队序列是（ ）。

<Option>bacde</Option>
<Option>dbace</Option>
<Option correct>dbcae</Option>
<Option>ecbad</Option>

<Solution>

**【解析】** 假设该队列允许从左右两端入队，只允许从左侧出队。

① 选项 A 可由 $a$ 从左端入队、$b$ 从左端入队、$c$ 从右端入队、$d$ 从右端入队、$e$ 从右端入队得到。

② 选项 B 可由 $a$ 从左端入队、$b$ 从左端入队、$c$ 从右端入队、$d$ 从左端入队、$e$ 从右端入队得到。

③ 选项 D 可由 $a$ 从左端入队、$b$ 从左端入队、$c$ 从左端入队、$d$ 从右端入队、$e$ 从左端入队得到。

④ 因为 $a$ 和 $b$ 是前两个入队的元素（队列初始为空），则队列中 $a$、$b$ 应相邻，出队序列中 $a$、$b$ 也应该相邻，而选项 C 出队序列中 $a$、$b$ 中间出现 $c$，不可能得到。故选 C。

**【点评】** 常规题。考查入队和出队操作。

</Solution>

</Question>

<Question id="408-db1ecd-010" type="single">

【2011】已知循环队列存储在一维数组 $ A[0,\cdots,n-1]$ 中, 且队列非空时front 和rear 分别指向队头元素和队尾元素。若初始时队列为空, 且要求第1 个进入队列的元素存储在 $ A[0]$ 处，则初始时 front 和rear 的值分别是（ ）。

<Option>0,0</Option>
<Option correct>0,n - 1</Option>
<Option>n - 1,0</Option>
<Option>n - 1,n - 1</Option>

<Solution>

**【解析】** 队列的进出规则为尾（rear）入头（front）出。① 队列非空时 rear 指向队尾元素。要求第 1 个入队元素存在 $A[0]$ 处，即 `(rear + 1) % n = 0`，解得 $rear=n-1$。② 队列非空时 front 指向队头元素。要求第 1 个入队元素存在 $A[0]$ 处，而入队操作不影响 front 的值，说明 front 初始为 0。故选 B。

**【点评】** 常规题。考查循环队列，比较“绕”，初学者容易出错。

</Solution>

</Question>

<Question id="408-db1ecd-011" type="single">

【2014】循环队列放在一维数组 $ A[0,\cdots,M-1]$ 中, end1 指向队头元素, end2 指向队尾元素的后一个位置。假设队列两端均可进行入队和出队操作, 队列中最多能容纳 $ M-1$ 个元素。初始时为空。下列判断队空和队满的条件中, 正确的是（ ）。

<Option correct>队空: end1 == end2; 队满: end1 == (end2 + 1) mod M;</Option>
<Option>队空: end1 == end2; 队满: end2 == (end1 + 1) mod M;</Option>
<Option>队空: end2 == (end1 + 1) mod M; 队满: end1 == (end2 + 1) mod M;</Option>
<Option>队空: end1 == (end2 + 1) mod M; 队满: end2 == (end1 + 1) mod M;</Option>

<Solution>

**【解析】** end1 指向队头元素，end2 指向队尾元素的后一个元素。队空时队头与队尾指针重合。队满时容纳 $M-1$ 个元素，即空出一个元素用来判断队满，可得当 `end1 == end2 + 1` 时为队满。又因为该队列为循环队列，则需要对 $m$ 进行取余操作。故选 A。

**【点评】** 高频考点。此类题，考生可通过举一个具体的例子、画图辅助判断。一般循环队列初始为空都是设置为尾指针 = 头指针。循环队列判断队空和队满，有几种常见的处理方式，具体内容可以参考竞成《数据结构考研复习全书》相应章节。

</Solution>

(2) 队列初始状态如下左图所示。以 front 为队头，rear 为队尾，队空的条件为 `front == rear`，队满的条件为 `front == rear->next`。

int s(int n) { return (n <= 0) ? 0 : s(n - 1) + n; }
int main（ ） { cout << s(1); }

<Option correct>main（ ） →S 1 →S 0</Option>

<Question id="408-db1ecd-019" type="single">

【2016】设有如下图所示的火车车轨, 入口到出口之间有n 条轨道, 列车的行进方向均为从左至右, 列车可驶入任意一条轨道。现有编号为1~9 的9 列列车, 驶入的次序依次是8、4、2、5、3、 9、1、6、7。若期望驶出的次序依次为1 ∼9，则n 至少是（ ）。

![](/img/questions/408/data-structure-p023-01.svg)

<Option>2</Option>
<Option>3</Option>
<Option correct>4</Option>
<Option>5</Option>

<Solution>

**【解析】** 入队顺序为 8、4、2、5、3、9、1、6、7，要求出队顺序为 1～9。在题目中，一条轨道就是一条队列，“求入口到出口之间至少有几条轨道”的问题可以转化为“求入口到出口之间至少有几条队列”的问题。出队顺序为 1～9，队列先进先出，则**在同一条队列中、先入队的元素必须小于后入队的元素**（这句话是解题的关键）。若 8、4 入同一条队列，则 8 必然在 4 的前面出队，与题目要求不符。则 8 入队第 1 条轨道，4 只能入队第 2 条轨道，4 后面的 2 只能入队第 3 条轨道。为了保证同一队列内元素大小顺序，5 可以入队第 2 条轨道，3 入队第 3 条轨道，9 入队列第 1 条轨道，1 只能入队第 4 条轨道（因为值最小），6、7 依次入队第 2 条轨道。因此 $n$ 至少为 4 可满足题意。故选 C。

**【点评】** 难题。考查队列“先进先出”的特点，涉及多条队列一起考查，有一定难度，比较难分析清楚。

</Solution>

</Question>

## 3.4 数组与压缩存储

<Question id="408-db1ecd-021" type="single" number={1}>

【2016】有一个100 阶的三对角矩阵 M， 其元素 $ m_{i,j}\ (1\le i\le100,1\le j\le100)$ 按行优先次序压缩存入下标从0 开始的一维数组 N 中。元素 $ m_{30,30}$ 在 N 中的下标是（ ）。

<Option>86</Option>
<Option correct>87</Option>
<Option>88</Option>
<Option>89</Option>

<Solution>

**【解析】** 代入三对角矩阵的计算公式“$k=2i+j-3$”（辅导书中一般都有对该结论的推导），可得 $k=2\times30+30-3=87$。

**【点评】** 常规题。考生需要熟悉常见的特殊矩阵压缩存储相关结论，若不熟悉相关结论，考试时可先举特例找规律（比如，本题举 5 阶三对角矩阵）。另外，需要注意题目要求，数组下标是从 0 还是 1 开始。

</Solution>

【2017】适用于压缩存储稀疏矩阵的两种存储结构是（ ）。

<Option correct>三元组表和十字链表</Option>

<Question id="408-db1ecd-024" type="single">

【2020】将一个 $ 10\times10$ 对称矩阵M 的上三角部分的元素 $ m_{i,j}\ (1\le i\le j\le10)$ 按列优先存入C 语言的一维数组 N 中, 元素 $ m_{7,2}$ 在 N 中的下标是（ ）。

<Option>15</Option>
<Option>16</Option>
<Option correct>22</Option>
<Option>23</Option>

<Solution>

**【解析】** ① 因为是对称矩阵，所以 $m_{7,2}=m_{2,7}$。② 因为对称矩阵 $M$ 只存储上三角部分，而 $m_{7,2}$ 位于下三角部分，所以本题等价于求 $m_{2,7}$ 在数组 $N$ 中的下标。③ 按列优先存储上三角部分，第1列有1个元素，第2列有2个元素，…，第6列有6个元素，前6列共有 $1+2+3+4+5+6=21$ 个元素（可动手画图模拟），$m_{2,7}$ 是第7列的第2个元素，所以 $m_{2,7}$ 是数组 $N$ 的 $21+2=23$ 个元素。因为数组下标从0开始，数组中的第23个元素的下标为22。故选 C。

<Question id="408-db1ecd-025" type="single">

【2021】已知二维数组 A 按行优先方法存储, 每个元素占用1 个存储单元，若元素 $ A[0][0]$ 的存储地址为 100，$ A[3][3]$ 的存储地址为 220，则元素 $ A[5][5]$ 的存储地址是（ ）。

<Option>295</Option>
<Option correct>300</Option>
<Option>301</Option>
<Option>306</Option>

<Solution>

**【解析】** ① **【解法一】** `A[3][3]` 的存储地址为 220，则 `A[3][0]` 的存储地址为 $220-3=217$。而 `A[0][0]` 的存储地址为 100，从 `A[0][0]` 到 `A[3][0]` 有三行元素，所以一行有 $(217-100)\div3=39$ 个元素。则 `A[5][0]` 的存储地址为 $100+5\times39=295$。`A[5][0]` 和 `A[5][5]` 之间相隔 5 个元素，故 `A[5][5]` 的存储地址为 $295+5=300$。

② **【解法二】** `A[0][0]`、`A[1][1]`、`A[2][2]`、`A[3][3]`、`A[4][4]`、`A[5][5]` 的存储地址为等差数列（因为每个元素之间相隔的元素个数相同），`A[0][0]` 存储地址为 100，`A[3][3]` 存储地址为 220，求得公差为 40，故 `A[5][5]` 的存储地址为 $220+40\times2=300$。

**【点评】** 常规题。为了避免计算出错，这类题可先在草稿纸上，举个例子类比下。

</Solution>

</Question>
