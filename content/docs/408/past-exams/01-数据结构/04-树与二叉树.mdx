# 第 4 章 树与二叉树


## 4.1 树的基本概念

<Question id="408-67f846-001" type="single">

【2010】在一棵度为4 的树T 中，若有20 个度为4 的结点, 10 个度为3 的结点, 1 个度为2 的结点,10 个度为1 的结点，则树T 的叶结点个数是（ ）。

<Option>41</Option>
<Option correct>82</Option>
<Option>113</Option>
<Option>122</Option>

<Solution>

**【解析】** 设树中度为 $i$ 的结点是 $n_i$，树内结点总数是 $n$。树中的分支数 $=n_1+2\times n_2+3\times n_3+4\times n_4$，树中的结点数 $n=n_0+n_1+n_2+n_3+n_4$。根据树中结点数和分支数之间的关系：树的结点数 = 分支数 + 1。则有 $n_1+2\times n_2+3\times n_3+4\times n_4+1=n_0+n_1+n_2+n_3+n_4$，代入题目数据 $n_4=20,n_3=10,n_2=1,n_1=10$ 可得，$n_0=82$。故选 B。

**【点评】** 常规题。考查结论：树的结点数 = 分支数 + 1，该结论在 408 中经常考到，考生应熟悉。

</Solution>

</Question>

<Question id="408-67f846-002" type="single">

【2022】若三叉树T 中有244 个结点(叶结点的高度为1)，则T 的高度至少是（ ）。

<Option>8</Option>
<Option>7</Option>
<Option correct>6</Option>
<Option>5</Option>

<Solution>

**【解析】** 本题可以用二叉树类比：结点数确定的情况下，完全二叉树高度最小。三叉树也是同理，当含有 244 个结点的三叉树是完全三叉树时，高度最小。高度为 $h$ 的满三叉树的结点数 $=3^0+3^1+3^2+\cdots+3^{h-1}$。当 $h=5$ 时，$3^0+3^1+3^2+3^3+3^4=121$；当 $h=6$ 时，$3^0+3^1+3^2+3^3+3^4+3^5=121+243=364$。而 $121<244<364$，所以当 T 是高度为 6 的完全三叉树时，高度最小。故选 C。

**【点评】** 常规题。此类题在教辅中有类似结论。即使考生此前不知道“完全三叉树”概念，也应该会根据完全二叉树类推。根据熟悉的知识去类推陌生的概念，近些年 408 考试中经常出现。命题人为了加大难度，改成了更为陌生的“三叉树”，如果是二叉树，难度会更一步降低。

</Solution>

## 4.2 二叉树基础

<Question id="408-67f846-003" type="single" number={1}>

【2009】已知一棵完全二叉树的第6 层(设根为第1 层) 有8 个叶结点，则该完全二叉树的结点个数最多是（ ）。

<Option>39</Option>
<Option>52</Option>
<Option correct>111</Option>
<Option>119</Option>

<Solution>

**【解析】** 根结点为第 1 层的完全二叉树的第 $n$ 层最多有 $2^{n-1}$ 个结点，即第 6 层最多有 $2^{6-1}=32$ 个结点。完全二叉树的叶结点只可能出现在最后两层，题目中给出第 6 层有 8 个叶结点，则第 6 层其余位置均为有两个孩子的非叶结点时，总结点数最多。第 6 层除了 8 个叶结点外，还有 24 个非叶结点，第 7 层有 48 个叶结点，此时总结点数为 $1+2+4+8+16+(8+24)+24\times2=111$ 个。故选 C。

**【点评】** 常规题。考查完全二叉树的性质。这是高频考点，必须掌握。

</Solution>

</Question>

<Question id="408-67f846-004" type="single">

【2011】若一棵完全二叉树有768 个结点，则该二叉树中叶结点的个数是（ ）。

<Option>257</Option>
<Option>258</Option>
<Option correct>384</Option>
<Option>385</Option>

<Solution>

**【解析】** 
**【解法一】** 从根结点开始，按从上到下（逐层）、从左往右的顺序，给完全二叉树中的每个结点编号。则完全二叉树父结点和孩子结点之间的编号有如下关系：若孩子结点编号为 $x$，则其父亲结点编号为 $\lfloor x/2\rfloor$。根据上述关系，对含有 768 个结点的完全二叉树进行编号，根结点编号为 1，编号为 768 的结点的父结点编号为 $\lfloor768/2\rfloor=384$。根据完全二叉树的性质，编号从 1～384 的这些结点都是有孩子的，故叶结点个数为 $768-384=384$。故选 C。

**【解法二】** 设二叉树中度为 0、1、2 的结点数分别为 $n_0,n_1,n_2$，二叉树结点总数为 $n$。① 根据二叉树的性质，$n_0=n_2+1,n=2n_2+n_1+1$。② 该完全二叉树有 768 个结点，即 $n=2n_2+n_1+1=768$，则 $2n_2+n_1=767$。767 是奇数，$2n_2$ 是偶数，则 $n_1$ 只能是奇数。③ 又因为在完全二叉树中，度为 1 的结点数只能是 0 或 1，即：$n_1=0$ 或 1。因为 $n_1$ 是奇数，故 $n_1=1$。则 $n_2=(767-1)\div2=383$，$n_0=n_2+1=384$，即叶结点个数为 384。故选 C。

**【点评】** 常规题。考查完全二叉树的特性。解法二比较绕，建议使用解法一。

</Solution>

</Question>

<Question id="408-67f846-006" type="single">

【2018】设一棵非空完全二叉树T 的所有叶结点均位于同一层, 且每个非叶结点都有2 个子结点。若T 有k 个叶结点，则T 的结点总数是（ ）。

<Option correct>$ 2k-1$</Option>
<Option>$ 2^k-1$</Option>
<Option>$ 2^k$</Option>
<Option>$ k^2$</Option>

<Solution>

**【解析】** **【解法一】** 二叉树中度为 2、1、0 的结点分别有 $n_2$、$n_1$、$n_0$ 个，则 $n_0=n_2+1$。该结论挺常见的，需要考生理解记忆。该结论的依据是：二叉树中，分支数 + 1 = 结点数。度为 2 的结点有 2 个分支，度为 1 的结点有 1 个分支，则二叉树中的分支数 = $2\times n_2+n_1$，结点数 = $n_0+n_1+n_2$。代入等式：分支数 + 1 = 结点数，则有 $2\times n_2+n_1+1=n_0+n_1+n_2$，即 $n_0=n_2+1$。本题中 $n_0=k$。因为非叶结点的都有 2 个子结点，则不存在度为 1 的结点，即 $n_1=0$。则 $T$ 的结点总数是 $k-1+k=2k-1$。故选 A。

**【解法二】** 完全二叉树中所有叶结点位于同一层，且每个非叶结点都有两个子结点，所以最后一层是满的，即此树是满二叉树。最后一层（第 $n$ 层）的叶结点个数是 $k=2^{n-1}$，总结点数目是 $2^n-1=2k-1$。故选 A。

**【点评】** 常规题。考查特殊形态的二叉树结点之间的关系。要求考生熟悉基本概念。

</Solution>

</Question>

<Question id="408-67f846-008" type="essay">

【2016】如果一棵非空 $ k(k\ge2)$ 叉树T 中每个非叶结点都有k 个孩子，则称T 为正则k 叉树, 回答下列问题并给出推导过程:

(1) 若T 有m 个非叶结点，则T 中的叶结点有多少个？

(2) 若T 的高度为h(单结点的树h = 1)，则T 的结点数最多为多少个? 最少为多少个?

<Solution>

**【解析】**

(1) 由题意得结点总数 $n=n_0+n_k=n_0+m$。这里的 $n_0$ 指的是度为 0 的结点，也就是叶子结点；$n_k$ 为度为 $k$ 的结点，由题意得到非叶结点的度均为 $k$，所以 $m=n_k$。

根据树的结点总数与度的关系可得边数 $e=n-1=mk$。结点的度就是结点孩子的个数，每个孩子都通过一条边与父结点连接，即结点的度就是该结点连接孩子结点的边数。题目中“每个非叶结点都有 $k$ 个孩子”告诉我们每个结点都有 $k$ 条边来连接孩子结点。又有 $m$ 个非叶节点，所以树有 $mk$ 条边。由上述公式，可得叶结点个数：$n_0=(k-1)m+1$。

{/* 原文“每个结点都有 k 条边”应限于非叶结点，此处保留原文。 */}

(2) ① 结点数最多的情形：除第 $h$ 层外，其余层都是度为 $k$ 的结点，第 $h$ 层都是叶结点，也就是说树是一个满树，对应结点总数是 $(k^h-1)/(k-1)$。

② 结点数最少的情形：除根结点外，第 2 至 $h$ 层的每层结点数均为 $k$，对应的结点总数是 $1+(h-1)k$。

> **【点评】** 常规题。考查树的数学性质。根据二叉树的数学性质，类推到 $k$ 叉树。

</Solution>

<Option>1,2,3,4</Option>
<Option>2,3,4,1</Option>
<Option correct>3,2,4,1</Option>
<Option>4,3,2,1</Option>

**【解析】** 
**【解法一】** 根据二叉树的中序遍历和任何一种其他遍历，可唯一确定一颗二叉树。可根据前序遍历和每个选项的中序遍历确定 4 棵二叉树，再逐一排查哪一棵二叉树的后序遍历与题设不符即可。选项 ABD 对应的二叉树如下图所示。故选 C。

![选项 ABD 对应的二叉树](/img/2011-q05-solution.svg)

**【解法二】** 先序遍历和后序遍历对子树结点的遍历顺序不变，即先遍历左子树结点，再遍历右子树结点。本题所给先序和后序序列完全相反，没有任何两个结点相对位置不变，可知二叉树中无度为 2 的结点，由此可知二叉树的深度为 4。通过先序遍历序列可知，1 为根结点。根据 2 的位置可以分为如下 2 种情况展开讨论：① 2 为 1 的左孩子结点，中序遍历时，先遍历结点 2 及 2 的孩子结点；② 2 为 1 的右孩子结点，中序遍历时，先遍历 1，再遍历 2 及 2 的孩子结点；对于以 2 为根结点的子树来说，也是同理。选项 ABD 都有可能。故选 C。

**【点评】** 常规题。考查二叉树的 3 种遍历算法，建议采用【解法一】通过排除法解题。【解法二】考虑的情况较多，容易漏，反而不如【解法一】稳当。此题难度不大，但做起来费时间。

</Solution>

【2017】设计算法,将给定的表达式树(二叉树) 转换为等价的中缀表达式(通过括号反映操作符的计算次序) 并输出。例如, 当下列两棵表达式树作为输入时, 输出的等价中缀表达式分别为a+b* c* -d 和a*b + - c-d 。二叉树结点定义如下:

```c
typedef struct node {
    char data[10];          // 存储操作数或操作符
    struct node *left;      // 指向左子树
    struct node *right;     // 指向右子树
} BTree;
```

![](/img/questions/408/data-structure-p032-02.svg)

要求:

(1) 给出算法的基本设计思想。

(2) 根据设计思想，采用C 或C++ 语言描述算法，关键之处给出注释。

<Solution>

**【解析】**

(1) 算法思想：表达式树的中序遍历序列加上必要的括号，即为等价的中缀表达式。对二叉树进行中序遍历：访问叶结点时输出操作数；访问分支结点时，在其左右子树的遍历结果之间输出操作符。关键在于括号的添加规则：根结点对应的最外层表达式不加括号；每个非根分支结点所代表的子表达式在输出时用一对括号包裹，以反映其运算优先级。叶结点是操作数，不加括号。这样既能保证运算次序正确，又不会出现多余括号。

(2) 代码如下：

```cpp
void infix(BTree* root,int depth = 1) { //depth = 1，表示从根结点开始递归
    if (root == NULL) {
        return;
    }

    if (root -> left == NULL && root -> right == NULL) {
        cout << root -> data; //对于叶子结点，直接打印，不需要添加括号
    } else { //对子表达式先添加左括号
        if(depth > 1) cout << "("; //depth > 1表示表达式最外层不需要加上括号
        //递归方向：分解为对左子表达式 + 操作符 + 右子表达式的求解
        infix(root -> left, depth + 1);
        //非叶结点都是操作符。加括号的操作仅对子表达式进行，所以直接输出操作符
        cout << root -> data;
        infix(root -> right, depth + 1);
        if(depth > 1) cout << ")";
    }
}
```

<Question id="408-67f846-039" type="essay">

【2014】二叉树的带权路径长度(WPL) 是二叉树中所有叶结点的带权路径长度之和。给定一棵二叉树T，采用二叉链表存储, 其结点结构为 `|left|weight|right|`。其中叶结点的weight 域保存该结点的非负权值。设root 为指向T 的根结点的指针，请设计求T 的WPL 的算法, 要求:

(1) 给出算法的基本设计思想。

(2) 使用C 或C++ 语言, 给出二叉树结点的数据类型定义。

(3) 根据设计思想，采用C 或C++ 语言描述算法，关键之处给出注释。

<Solution>

**【解析】**

(1) 算法的基本设计思想：① 二叉树的带权路径长度（WPL）是树中所有叶结点的带权路径长度之和。叶结点的带权路径长度 = 该叶结点的权值 × 根结点到该叶结点的路径长度（路径上的边数），其中叶结点的权值存储在结点结构体的 weight 成员中。

② 求解时，可通过“任意一种二叉树的遍历算法”（本题采用中序遍历）统计每个叶结点的路径长度：遍历时维护一个变量 h，二叉树每向下一层深度 h 加 1，每回溯一层深度 h 减 1（如果用层序遍历算法则不用回溯）；遇到叶结点时，用其权值 weight 与当前深度 h 相乘并累加到总和 WPL 中。遍历完整棵二叉树即可求得 WPL。

(2) 二叉树结点的数据类型定义如下：

```c
typedef struct BiTNode {
    int weight;
    struct BiTNode *left, *right;
} BiTNode, *BiTree;
```

(3) C 语言算法代码实现如下：

```c
void InOrderCalWPL(BiTNode *T,int h,int *wpl) {
    if(T == NULL) {
        return ; // 空结点，递归直接返回
    }
    InOrderCalWPL(T->left,h+1,wpl); //递归遍历左子树，下层深度+1
    if(T->left == NULL && T->right == NULL) {
        *wpl += T->weight * h; // 计算叶结点的带权路径长度
    }
    InOrderCalWPL(T->right, h+1, wpl); //递归遍历右子树，下层深度+1
}

int GetTreeWPL(BiTree root) { //函数调用入口，输入根指针，返回树的WPL
    int wpl = 0; // 初始化wpl为0
    InOrderCalWPL(root,0,&wpl); // 根结点初始深度为0
    return wpl;
}
```

**【注意】** 在子函数 `InOrderCalWPL()` 中，形参 wpl 必须定义成指针，否则就是错的。或者通过引用传参也行。考生若不熟悉 C 语言函数的形参和实参，或者 C++ 中的引用，建议去看下竞成《数据结构考研复习全书》第 1 章【编程基础】部分（在该章 1.5 小节），该章对 408 考试中所需要的前置的编程基础知识进行了补充介绍，助力考生 0 基础入门 408。

**【解析】**

(1) 适宜用二叉树保存上述具有前缀特性的不等长编码。用二叉树中的叶结点保存字符，字符编码规则为：从根结点开始，左分支路径记为 0，右分支路径记为 1，从根结点到叶结点路径上、由 0 和 1 组成的字符串，即为该叶结点保存字符的编码。

(2) 从左到右依次遍历 0/1 串中的各位。从二叉树的根结点开始，若 0/1 串中的当前位为 0，则查找左子树；若 0/1 串中的当前位为 1，则查找右子树，直到遍历到叶结点，输出叶结点中保存的字符，并从根结点开始重复此过程。直到遍历完整个 0/1 串，则译码完成。此过程中输出的字符串即为 0/1 串表示的字符串。

(3) 这个过程描述很繁杂，这里直接原文摘抄官方给出的参考答案：

二叉树既可用于保存各字符的编码，也可用于检测编码是否具有前缀特性。判定编码是否具有前缀特性的过程，同时也是构建二叉树的过程。初始时，二叉树中仅含有根结点，其左子指针和右子指针均为空。依次读入每个编码 C，建立 / 寻找从根开始对应于该编码的一条路径，过程如下：对每个编码，从左至右扫描 C 的各位，根据 C 当前位（0 或 1）沿结点的指针（左子指针或右子指针）向下移动。当遇到空指针时，创建新结点，让为空的指针指向该新结点并继续移动。沿指针移动过程中，可能遇到三种情况：

① 若遇到了叶结点（非根），则表明不具有前缀特性，返回；

② 若在处理 C 的所有位的过程中，均没有创建新结点，则表明不具有前缀特性，返回；

③ 若处理 C 的最后一个编码位时创建了新结点，则继续验证下一个编码。

若所有编码均通过验证，则编码具有前缀特性。
