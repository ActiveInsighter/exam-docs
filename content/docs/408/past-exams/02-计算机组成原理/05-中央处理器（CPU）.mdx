# 第 5 章 中央处理器 (CPU)


## 5.1 CPU 的功能和基本结构

<Question id="408-605176-001" type="single">

【2010】下列寄存器中, 汇编语言程序员可见的是（ ）。

<Option>存储器地址寄存器(MAR)</Option>
<Option correct>程序计数器(PC)</Option>
<Option>存储器数据寄存(MDR)</Option>
<Option>指令寄存器(IR)</Option>

<Solution>

**【解析】** 对汇编语言程序员可见（也称为“不透明”）的寄存器，指使用汇编语言可以直接编程访问、使用的寄存器。PC 虽然通常由硬件自动递增，但汇编指令中的跳转（JMP）、调用（CALL）、返回（RET）等指令会直接修改 PC 的值，因此它是程序员编程时需要感知和控制的寄存器之一。而 MAR、MDR、IR 都是 CPU 内部的数据通路寄存器，完全由硬件管理，对汇编程序员透明。另外，还有通用寄存器、PSW 对汇编语言程序员是可见的（不透明）。故选 B。

**【点评】** 概念题。首次遇到可能考生会有疑惑，但此类题在教辅中很常见。

</Solution>

</Question>

<Question id="408-605176-002" type="single">

【2016】某计算机主存空间为4GB, 字长为32 位, 按字节编址, 采用32 位字长指令字格式。若指令按字边界对齐存放, 则程序计数器(PC) 和指令寄存器(IR) 的位数至少分别是（ ）。

<Option>30、30</Option>
<Option correct>30、32</Option>
<Option>32、30</Option>
<Option>32、32</Option>

<Solution>

**【解析】** 主存空间为 4GB，按字节编址，共 $4\mathrm G=2^{32}$ 个字节地址。指令字长为 32 位 = 4B，“指令按字边界对齐存放”指的是指令在内存中的起始地址必须是“字长”的整数倍，故指令字地址数量为 $2^{32}\div4=2^{30}$ 个，则 PC 至少 30 位。指令寄存器 IR 存放整条指令，IR 位数取决于指令字长，故 IR 至少 32 位。故选 B。

<Callout title="拓展">

指令按字边界对齐 = 地址是字长的整数倍。若字长为 4B，则指令的起始地址必须是 4 的倍数。地址是 4 的整数倍 $\xLeftrightarrow{\text{等价于}}$ 地址的二进制最低 2 位为 00。因为任何一个整数 $A$ 如果是 4 的倍数，则可以表示为 $A=4\times k=2^2\times k$，将其转为二进制，相当于把 $k$ 的二进制表示“左移 2 位，末尾补 2 个 0”。

</Callout>

**【点评】** 概念题。“指令按字边界对齐存放”，这个概念考生可能首次遇到不知道其具体含义，而导致出错。

</Solution>

</Question>

<Question id="408-605176-003" type="single">

【2019】下列有关处理器时钟脉冲信号的叙述中,错误的是（ ）。

<Option>时钟脉冲信号由机器脉冲源发出的脉冲信号经整形和分频后形成</Option>
<Option>时钟脉冲信号的宽度称为时钟周期,时钟周期的倒数为机器主频</Option>
<Option>时钟周期以相邻状态单元间组合逻辑电路的最大延迟为基准确定</Option>
<Option correct>处理器总是在每来一个时钟脉冲信号时就开始执行一条新的指令</Option>

<Solution>

**【解析】** D 错误：处理器不是每来一个时钟脉冲就开始执行新指令，指令执行需要多个时钟周期（取指、译码、执行等阶段），一个时钟脉冲推进一个周期步骤，而不是启动新指令。其他选项均正确。故选 D。

**【点评】** 常规题。本题关于时钟脉冲信号的描述中，虽然其中 3 个选项的描述比较生僻，教辅书中没有、考生可能也没见过，但 D 选项的错误还是很明显的，这些生僻的名词概念不影响做对题目。

</Solution>

</Question>

<Question id="408-605176-004" type="single">

【2021】下列寄存器中, 汇编语言程序员可见的是（ ）。

I. 指令寄存器
II. 微指令寄存器
III. 基址寄存器
IV. 标志/状态寄存器

<Option>仅I、II</Option>
<Option>仅I、IV</Option>
<Option>仅II、IV</Option>
<Option correct>仅III、IV</Option>

<Solution>

**【解析】** 基址寄存器、标志 / 状态寄存器、程序计数器 PC 和通用寄存器组对汇编语言程序员是可见的，因为汇编语言程序员需要通过通用寄存器组获得数据，通过标志 / 状态寄存器确定条件跳转指令执行与否等，通过基址寄存器和程序计数器编制浮动程序等，故Ⅲ、Ⅳ正确。而 MAR、MDR、IR 等寄存器是 CPU 内部用于存放数据地址、数据内容和指令的寄存器，不需要汇编语言程序员对其进行操作，因此对汇编语言程序员不可见，故Ⅰ错误。微指令寄存器（$\mu\mathrm{IR}$）暂存当前正在执行的微指令，是 CPU 控制单元（CU）中微程序控制器的组成部分，属于 CPU 内部微架构层面的实现细节，对汇编程序员是不可见的，故Ⅱ错误。故选 D。

**【点评】** 常规题。教辅中一般都有类似总结。另外，不可见也叫“透明”。

</Solution>

</Question>

<Question id="408-605176-005" type="single">

【2023】数据通路由组合逻辑元件(操作元件) 和时序逻辑元件(状态元件) 组成。下列给出的元件中, 属于操作元件的是（ ）。

I. 算术逻辑部件(ALU)
II. 程序计数器(PC)
III. 通用寄存器组(GPRs)
IV. 多路选择器(MUX)

<Option>仅I, II</Option>
<Option correct>仅I, IV</Option>
<Option>仅II, III</Option>
<Option>I, II, IV</Option>

<Solution>

**【解析】** 组合逻辑元件是那些仅由组合逻辑电路组成的元件，其输出仅取决于当前的输入，而不受存储器或时钟信号的影响。算术逻辑部件 ALU 和多路选择器 MUX 都属于组合逻辑元件，它们的输出仅由当前输入决定。程序计数器 PC 和通用寄存器是时序逻辑元件，也称为状态元件。它们的输出不仅取决于当前输入，还受存储器或时钟信号的影响，并且具有状态或存储功能。故选 B。

**【提示】** 简单分辨组合逻辑元件和时序逻辑元件的方法：有存储功能的就是时序逻辑元件。

**【点评】** 常规题。考查记忆性内容。

</Solution>

</Question>

## 5.2 指令执行过程

<Question id="408-605176-006" type="single" number={1}>

【2011】假定不采用Cache 和指令预取技术,且机器处于“开中断”状态。在下列有关指令执行的叙述中, 错误的是（ ）。

<Option>每个指令周期中CPU 都至少访问内存一次</Option>
<Option>每个指令周期一定大于或等于一个CPU 时钟周期</Option>
<Option correct>空操作指令的指令周期中任何寄存器的内容都不会被改变</Option>
<Option>当前程序在每条指令执行结束时都可能被外部中断打断</Option>

<Solution>

**【解析】** ① A 正确 √：指令周期包含取指阶段，CPU 必须从内存中取出指令，即使没有访存操作的指令，例如：空操作指令（NOP），也需要取指，因此至少访存一次。

② B 正确 √：指令周期是执行一条指令所需的全部时间，而时钟周期是 CPU 的最小时间单位，单条指令至少需要一个时钟周期（实际中通常需要多个）。

③ C 错误 ×：空操作指令（NOP）在执行时，虽然不改变通用寄存器的值，但程序计数器（PC）会自动自增，以下一条要执行的指令的地址。PC 也是寄存器，因此该说法错误。

④ D 正确 √：题目已说明机器处于“开中断”状态，而中断响应的时机是在每条指令执行结束、下一条指令开始之前，因此每条指令执行结束时都可能响应外部中断。故选 C。

**【点评】** 常规题。考查指令执行的综合概念题。

</Solution>

</Question>

<Question id="408-605176-007" type="single">

【2019】某指令功能为 $ R[r2] \leftarrow R[r1] + M[R[0]]$，其两个源操作数分别采用寄存器、寄存器间接寻址方式。对于下列给定部件, 该指令在取数及执行过程中需要用到的是（ ）。

I. 通用寄存器组(GPRs)
II. 算术逻辑单元(ALU)
III. 存储器(Memory)
IV. 指令译码器(ID)

<Option>仅I、II</Option>
<Option correct>仅I、II、III</Option>
<Option>仅II、III、IV</Option>
<Option>仅I、III、IV</Option>

<Solution>

**【解析】** ① I 正确 ✓：在取数阶段，一个操作数采用寄存器寻址方式（数据存储在寄存器中），需要用到通用寄存器组 (GPRs)。

② I、III 正确 ✓：在取数阶段，一个操作数使用寄存器间接寻址方式（数据地址存储在寄存器中，数据存储在存储器中），需要用到通用寄存器组 (GPRs) 和存储器 (Memory)。

③ II 正确 ✓：在执行阶段，“R[r1]+M[R[r0]]”是两个操作数相加，因此要用到算术逻辑单元 (ALU)。

④ IV 错误 ×：在取数之前，指令译码器需要对指令进行译码，通过译码结果向控制器提供控制信号。而在取数和执行阶段用不到指令译码器。故选 B。

**【点评】** 常规题。本题要注意审题，指令译码器在“译码”阶段要用到，但“取指、取数和执行”阶段都用不到。

</Solution>

</Question>

## 5.3 数据通路的功能和基本结构

<Question id="408-605176-008" type="single" number={1}>

【2016】单周期处理器中所有指令的指令周期为一个时钟周期。下列关于单周期处理器的叙述中,错误的是（ ）。

<Option correct>可以采用单总线结构数据通路</Option>
<Option>处理器时钟频率较低</Option>
<Option>在指令执行过程中控制信号不变</Option>
<Option>每条指令的CPI 为1</Option>

<Solution>

**【解析】** A 错误 ×：单周期处理器每个时钟周期执行一条指令，对于指令“`add R1,R2,R3`”来说，先将寄存器 R2 和 R3 的值相加，再把结果写入寄存器 R1。在执行这条指令时，需要先从寄存器 R2 和 R3 中读取数据，进行运算，再将结果写回寄存器 R1。若采用单总线结构，每个时钟周期只能传送一个数据，无法在一个时钟周期内完成这三个操作，需要多个时钟周期（分时复用总线）才能完成整个指令的执行。

B 正确 ✓：由于所有指令均要在一个时钟周期完成，考虑到比较慢的指令，CPU 时钟周期会较长，时钟频率是时钟周期的倒数，所以 CPU 时钟频率较低。

C 正确 ✓：指令控制信号仅由该指令的操作码译码决定，在单周期处理器中，一条指令在一个时钟周期内完成所有操作，指令本身在该时钟周期内不变，所以控制信号在整个指令执行过程中保持不变。需要控制信号随时间变化的唯一理由是“同一部件在不同的时刻干不同的活”（分时复用），所以多周期处理器中控制信号会变。

D 正确 ✓：CPI 的定义是每条指令的时钟周期数，单周期处理器中所有指令的指令周期为一个时钟周期，即 CPI 为 1。故选 A。

**【点评】** 难题。此题涉及的知识点多，需要推理分析，属于 408 难度较大的一类题。

</Solution>

</Question>

<Question id="408-605176-009" type="single">

【2021】下列关于数据通路的叙述中,错误的是（ ）。

<Option>数据通路包含ALU 等组合逻辑(操作) 元件</Option>
<Option>数据通路包含寄存器等时序逻辑(状态) 元件</Option>
<Option correct>数据通路不包含用于异常事件检测及响应的电路</Option>
<Option>数据通路中的数据流动路径由控制信号进行控制</Option>

<Solution>

**【解析】** 数据通路指的是指令执行过程中数据的传输路径，以及路径上集成的部件（各种逻辑元件、寄存器和运算部件 ALU 等）。在指令执行过程中，数据会流经 ALU、PSW、通用寄存器、异常和中断处理逻辑等部件，故 A、B 正确，C 错误。控制部件通过发出控制信号控制数据通路中的传送操作，控制部件根据指令功能的不同，生成对数据通路的不同控制信号，以保证指令能够正确执行，故 D 正确（但是要注意数据通路不包括控制部件）。故选 C。

**【点评】** 常规题。考查数据通路的概念，数据通路的示意图 408 真题中考过，可通过排除法选 C。

</Solution>

</Question>

<Question id="408-605176-010" type="essay">

【2009】某计算机字长16 位, 采用16 位定长指令字结构, 部分数据通路结构如下图所示。上图中所有控制信号为1 时表示有效、为0 时表示无效。例如控制信号MDRinE 为1 表示允许数据从DB 打入MDR, MDRin 为1 表示允许数据从内总线打入MDR。假设MAR 的输出一直处于使能状态。加法指令“ADD(R1), R0”的功能为(R0) + ((R1)) →(R1), 即将R0 中的数据与R1 的内容所指主存单元的数据相加, 并将结果送入R1 的内容所指主存单元中保存。下表给出了上述指令取指和译码阶段每个节拍(时钟周期) 的功能和有效控制信号,请按表中描述方式用表格列出指令执行阶段每个节拍的功能和有效控制信号。

<img src="/img/questions/408/computer-organization-p065-01.svg" alt="2009年部分数据通路结构图" />

| 时钟 | 功能 | 有效控制信号 |
| --- | --- | --- |
| C1 | MAR ← (PC) | PCout, MARin |
| C2 | MDR ← M(MAR)，PC ← (PC)+1 | MemR, MDRinE, PC+1 |
| C3 | IR ← (MDR) | MDRout, IRin |
| C4 | 指令译码 | 无 |

<Solution>

**【解析】** 本题要求写出加法指令 `ADD (R1),R0`，在指令**执行阶段**每个节拍的功能和有效控制信号。本题答案不唯一，这里先给出参考答案，再进行解析。

**【参考答案一】**

| 时钟 | 功能 | 有效控制信号 |
| --- | --- | --- |
| C5 | MAR←(R1) | R1out, MARin |
| C6 | MDR←M(MAR) | MemR, MDRinE |
| C7 | A←(MDR) | MDRout, Ain |
| C8 | AC←(A)+(R0) | R0out, ADD, ACin |
| C9 | MDR←(AC) | ACout, MDRin |
| C10 | M(MAR)←(MDR) | MDRoutE, MemW |

**【参考答案二】**

| 时钟 | 功能 | 有效控制信号 |
| --- | --- | --- |
| C5 | MAR←(R1) | R1out, MARin |
| C6 | MDR←M(MAR), A←(R0) | MemR, MDRinE, Ain, R0out |
| C7 | AC←(A)+(MDR) | MDRout, Add, ACin |
| C8 | MDR←(AC) | ACout, MDRin |
| C9 | M(MAR)←(MDR) | MDRoutE, MemW |

时钟周期 C1～C4 是取指阶段，主要工作是：根据寄存器 PC 中地址，从主存中读取数据（指令），经过 MDR 送至指令寄存器 IR。

- `C1: MAR←(PC)`。指令地址在 PC 中，将 PC 中指令地址送往地址寄存器 MAR。
- `C2: MDR←M(MAR), PC←(PC)+1`。在这一个时钟周期，同时完成了两项工作：① 根据 MAR 中的地址，从主存中读取数据送往 MDA；② PC 自增，指向下一条指令地址。
- `C3: IR←(MDR)`。此时指令已经暂存在 MDR 中，将其送往 IR。

时钟周期 C4 是指令译码阶段，主要工作是：对当前取出的指令进行分析、解码，识别出指令的操作类型、寻址方式、操作数来源／去向，为后续执行阶段生成对应的控制信号，控制 CPU 完成指令要求的操作。加法指令 `ADD (R1),R0` 的第一个操作数，保存在 R1 的内容（地址）所指主存单元中；第二个操作数保存在寄存器 R0 中；两个操作数相加，结果保存在 R1 的内容（地址）所指主存单元中。

- `C5: MAR←(R1)`。((R1)) 是寄存器间接寻址，需要从 R1 中读取目的地址送入 MAR 中。
- `C6: MDR←M(MAR)`。根据 MAR 中的地址，取出操作数送入 MDR 中。这一步完成后，加法运算所需要的两个操作数，存在寄存器 MDR 和 R0 中。这道题答案有多种，将 MDR 中的内容送入暂存寄存器 A，或 R0 中的内容送入暂存寄存器 A，都可以。在节拍安排上，如【参考答案一】所示，若执行 `MDR←M(MAR)` 时，同时将 R0 中的内容送入暂存寄存器 A（`A←(R0)`），并不会发生总线冲突。
- `C7: A←(MDR)`。将 MDR 中的内容送入暂存寄存器 A。
- `C8: AC←(A)+(R0)`。将两个操作数同时送至 ALU 进行加法操作，将运算结果送入累加寄存器 AC 中。
- `C9: MDR←(AC)`。将运算结果从累加寄存器 AC 中送入 MDR。
- `C10: M(MAR)←(MDR)`。将计算结果送至 MAR 内容（其实是 R1）所指的内存单元。

**【点评】** 难题。考查指令执行过程、数据通路。细节较多。2009 年是首次 408 统考，首次遇到这种题，可能很难拿满分。但教材教辅中，对常见指令的执行过程，都有类似的分析介绍。

</Solution>

</Question>

(6) 为什么二路选择器MUX 的一个输入端是2?

<Solution>

**【解析】**

(1) ① 程序员可见寄存器是指机器语言（汇编语言）程序员可以指定、可编程访问的寄存器：通用寄存器 R0～R3 可作为指令中的操作数地址出现，PC 虽不直接编址但可通过转移类指令隐式修改，均属于程序员可见。

而 IR、MAR、MDR、T 等都是 CPU 内部为实现指令功能而设的工作寄存器，程序员无法访问，属于程序员不可见寄存器。

② 暂存器 T 的作用：单总线结构在同一时刻只能传送一个数据，而 ALU 执行双操作数运算时，A、B 两个输入端必须同时获得两个不同的操作数。解决办法是：先把第一个操作数经内总线送入 T 暂存，再把第二个操作数经内总线直接送到 ALU 的 B 端，此时 T 的输出稳定地接在 A 端，两个操作数便同时就绪，ALU 方可正常工作。如果没有 T，ALU 的 A、B 两端将得到同一个数据（都等于总线上当前的数据），双操作数运算无法实现，数据通路无法工作。

(2) 控制信号的编码位数必须能区分对应功能部件的全部操作种类。

由题目可知，ALU 有 7 种操作，所以操作控制信号 ALUop 至少需要 $\lceil\log_2 7\rceil=3$ 位。

移位寄存器有 3 种操作，所以操作控制信号 SRop 至少需要 $\lceil\log_2 3\rceil=2$ 位。

(3) SRout 控制的部件是三态门，用于控制移位器与总线数据通路的连接 / 断开。CPU 采用单内总线结构，同一时刻只允许一个部件向总线发送数据。当该三态门关闭时，SR 输出为高阻态，不占用总线，防止多个器件同时驱动总线造成信号冲突。

(4) 端口 ①、②、③、⑤、⑧ 必须连接控制部件的输出端（这些部件都需要控制信号）。

(5) 有两条连线。

- 第一条：⑥→⑨。将内总线上的数据引到 MUX 的一个数据输入端（⑨），使总线数据可被 MUX 选通；
- 第二条：⑦→④。这条线用于将 MUX 的输出（⑦）接到 ALU 的 B 输入端（④），并由 MUXop 控制。根据题目给出的 CPU 结构图，当实现普通 ALU 操作时，MUXop = 1，数据直接流入 ALU 的 B 端；当需要完成 PC 自增时，MUXop = 0，2 作为加数实现 $(\mathrm{PC})+2\to(\mathrm{PC})$。

> **【注意】** 在程序计数器（PC）自增时，MUX 输入端的控制信号取决于具体的硬件设计和控制逻辑。在有的机器中，也有可能 MUXop = 1 时，实现 PC 自增。考生要结合具体的题目分析，不可死记硬背。

(6) 每条指令的长度为 16 位 = 2B，按字节编址，所以每条指令占用 2B ÷ 1B = 2 个内存单元。当顺序执行时，下条指令地址为 (PC) + 2。把常数 2 固定接在 MUX 的一个输入端上，就为“(PC) + 2”这一高频微操作提供了硬件捷径，无需再从其他寄存器取常数 2，方便计算下一条顺序指令的地址。

> **【点评】** 常规题。以单总线 CPU 数据通路为载体，全面考查数据通路结构的静态分析（可见寄存器、三态门、控制信号位数、端点属性）与动态理解（暂存器 T 的作用、PC + 2 的实现）。本题是非常经典的一道考查数据通路的综合题，很适合作为一个典型例题理解记忆。近些年 408 中此类题型都和本题形似。

（5）将指令机器码 A040 A103H 展开成二进制，A040 A103H = 101000000100 00001 010 00010 0000011B，指令中低七位 IR[6:0] = 0000011B，第 12 到第 14 位 IR[14:12] = 010，和 lw 指令格式的对应位相等，因此可以判断是 lw 指令。根据 lw 指令的格式，可知该指令的偏移量 imm = IR[31:20] = A04H（高 12 位），用补码表示并符号扩展，得到 32 位机器码为 FFFF FA04H，该指令第 15～19 位 IR[19:15] = 00001 = 01H（寄存器 rs1 的编号），根据指令功能，数据的存储地址 = R[rs1] + imm（符号扩展）= R[01H] + imm（符号扩展）= FFFF A2D0H + FFFF FA04H = FFFF 9CD4H。

**【点评】** 难题。本题计算和思维量大，综合性强，但综合的各个考点都是常见的基本考点。熟练掌握此前真题中的类似考法，这题就应该能做出来。但还是很费时间。

</Solution>

<Question id="408-605176-016" type="single">

【2012】某计算机的控制器采用微程序控制方式,微指令中的操作控制字段采用字段直接编码法, 共有33 个微命令, 构成5 个互斥类, 分别包含7、3、12、5 和6 个微命令, 则操作控制字段至少有（ ）。

<Option>5 位</Option>
<Option>6 位</Option>
<Option correct>15 位</Option>
<Option>33 位</Option>

<Solution>

**【解析】** 字段直接编码法（也叫字段译码法）的规则如下：

- 不能同时有效的微命令构成一个互斥类。每个互斥类使用同一字段进行二进制编码，通过译码器输出控制信号。
- 该字段的每个二进制编码均表示一个微命令。每个字段需要额外预留一个状态表示“不发出任何微命令”。某个互斥类的字段位数 = $\lceil\log_2(\text{该类微命令数}+1)\rceil$（向上取整）。

**【提示】** 字段直接编码法相比直接控制法（每个微命令占 1 位）大幅缩短了微指令长度，是微程序控制中常用的优化手段。

**【点评】** 概念题。这类题本身没难度，但记的不熟的时候，容易和直接控制（编码）法“记混了”导致出错。

- ② 控制相关（控制冒险）：流水线中因指令执行流改变（例如，跳转指令、分支指令、转移指令），导致预取的后续指令无效，引起阻塞。
- ③ 资源冲突（结构冒险）：多条指令同时使用同一硬件资源，导致资源竞争，引起阻塞。

④ 而数据旁路（转发 / 直通技术）是解决数据相关引起阻塞的一种优化手段：它将结果直接转发给后续指令，避免流水线停顿，本身不会引起阻塞。数据旁路（转发）可以解决大部分数据冒险，但无法解决“load-use”类的数据冒险（即访存指令的结果被下一条指令使用），这类情况仍需插入流水线气泡。控制冒险通常通过分支预测、延迟槽等技术缓解，资源冲突则需要通过增加硬件资源来解决。

**【点评】** 概念题。本题主要考查流水线阻塞的原因。

</Solution>

<Solution>

**【解析】**

(1) **【解法一】** $x=-513$，$[x]_{\text{补}}=1111\ 1101\ 1111\ 1111\mathrm{B}$。指令“`SHR R1`”表示算术右移一位。算术右移，低位移出，高位补符号位（负数补 1，正数补 0），得到 $1111\ 1110\ 1111\ 1111=\mathrm{FEFFH}$。执行指令之后 R1 的内容为 FEFFH。

**【解法二】** $x=-513$，$x/2=-257$，$[-257]_{\text{补}}=1111\ 1110\ 1111\ 1111\mathrm{H}=\mathrm{FEFFH}$。

{/* 解法二二进制补码后缀 H 为原书写法。 */}

**【拓展】** ① 整数 $x$ 算术右移 1 位，正数和负数的运算规则有所不同：

- 若 $x$ 是正整数，则和普通除法一样（向零取整），例如：$x=513$，则 $x/2=256$。
- 若 $x$ 是负整数，则向负无穷取整，例如：$x=-513$，则 $x/2=-257$（不是 −256）。

② 逻辑右移和算术右移不同：逻辑右移无论正负，右边移出丢弃，左边补 0。即：逻辑右移当成无符号数整体右移，和除法无关！算术右移，低位移出，高位补符号位（0 正 1 负）。

(2) 5 段流水线，执行第 1 条指令需要 5 个时钟周期，之后每个时钟周期都会执行完 1 条指令。连续 4 条指令进入该流水线，执行完毕需要 $5+(4-1)=8$ 个时钟周期。

**【拓展】** $m$ 段流水线稳定之后（无阻塞的理想情况下），执行 $n$ 条指令需要 $m+(n-1)$ 个时钟周期。

(3) ① I3 与 I1、I2 存在数据相关。I3 必须等 I2 将数据写入寄存器 R2 后（WB 阶段之后），再从寄存器 R2 中读取操作数，所以 I3 的 ID 段（读寄存器）被阻塞。

② I4 的 IF 段被阻塞，是因为 I3 的 ID 段被阻塞，导致 I3 的后一条指令 I4 无法取指而阻塞。

**【拓展】** ① 传统单周期 CPU，只有一个指令寄存器 IR，用于存当前指令。而流水线 CPU 中，为了实现多指令并行执行，每段流水线之间设有独立的暂存寄存器。以 5 段流水线为例，段间寄存器包括 IF/ID、ID/EX、EX/MEM、MEM/WB，这些寄存器不仅暂存指令，还会传递指令的完整上下文（操作数、控制信号、地址信息等），本质上替代了全局 IR 的作用。流水线段间寄存器完整的数据流如下（此部分内容目前教辅书中都没有，考生需重视）：

- IF 阶段：取指令并计算 PC + 4，将指令和 PC + 4 的值送入 IF/ID 寄存器；
- ID 阶段：从 IF/ID 寄存器取出指令，完成译码、读寄存器堆，生成控制信号，将源操作数、目的寄存器号、控制信号等送入 ID/EX 寄存器；
- EX 阶段：从 ID/EX 寄存器取出数据，ALU 完成运算或地址计算，将结果和控制信号送入 EX/MEM 寄存器；
- MEM 阶段：从 EX/MEM 寄存器取出数据，完成内存读写（RISC 架构只有 load / store 指令能读写内存），将访存结果或 ALU 结果送入 MEM/WB 寄存器；
- WB 阶段：从 MEM/WB 寄存器取出数据并写回寄存器堆，完成指令的最后一步。

② 例如：本题中指令 I3 因数据相关无法进入 ID 阶段，停留在 IF/ID 寄存器中不动。下一个时钟周期，在 IF 阶段若要取指令 I4，则新指令无处可存：因为 IF/ID 寄存器还被 I3 占用。

(4) $x=x*2+a$ 可以通过 1 次加法、1 次算术左移，或两次加法来实现，对应的指令序列如下。

```asm
I1   LOAD R1,[x]
I2   LOAD R2,[a]
I3   SHL R1   //或ADD R1,R1
I4   ADD R1,R2
I5   STORE R2,[x]
```

① I3 和 I1 存在数据相关：I1 的 WB 阶段写回寄存器之后，I3 的 ID 阶段才能取数。

② I4 和 I2、I3 存在数据相关：因为 I3 的 ID 阶段被阻塞，所以 I4 的 IF 阶段被阻塞（原因第 (3) 问解释过）。等到 I2 和 I3 的 WB 阶段都写回寄存器之后，I4 的 ID 阶段才能取数。

③ I5 和 I4 存在数据相关：因为 I4 的 ID 阶段被阻塞，所以 I5 的 IF 阶段被阻塞（原因第 (3) 问解释过）。I4 的 WB 阶段写回寄存器之后，I5 的 ID 阶段才能取数。

## 5.7 多处理器基本概念

<Question id="408-605176-041" type="single" number={1}>

【2022】下列关于并行处理技术的叙述中, 不正确的是（ ）。

<Option>多核处理器属于MIMD 结构</Option>
<Option>向量处理器属于SIMD 结构</Option>

**【解析】** ① A 正确 ✓：MIMD (Multiple Instruction stream Multiple Data stream)：多指令流多数据流，即该结构同时有多个指令分别处理不同的数据，这种系统中一定包含有多个计算机或多个处理器，故多核处理器属于 MIMD 结构。

② B 正确 ✓：向量处理机是面向向量型数据的并行计算机，在向量的各分量上执行的运算操作都一般是彼此无关的、各自独立的，属于 SIMD 一类。

③ C 错误 ×：硬件多线程 (hardware multithreading)：当线程发生阻塞时，处理器可切换到另一线程继续运行，单核处理器也可以使用硬件多线程技术。

④ D 正确 ✓：共享地址多处理器 (shared-address multiprocessor)，其特点是硬件为所有的处理器提供单一的物理地址空间，并用锁来同步共享变量。
