# 第 5 章 中央处理器 (CPU)

## 5.1 CPU 的功能和基本结构

<Question id="408-605176-001" type="single" tags="来源:2010考研408">

下列寄存器中, 汇编语言程序员可见的是（ ）。

<Option>存储器地址寄存器(MAR)</Option>
<Option correct>程序计数器(PC)</Option>
<Option>存储器数据寄存(MDR)</Option>
<Option>指令寄存器(IR)</Option>

<Solution>

**【解析】** 对汇编语言程序员可见（也称为“不透明”）的寄存器，指使用汇编语言可以直接编程访问、使用的寄存器。PC 虽然通常由硬件自动递增，但汇编指令中的跳转（JMP）、调用（CALL）、返回（RET）等指令会直接修改 PC 的值，因此它是程序员编程时需要感知和控制的寄存器之一。而 MAR、MDR、IR 都是 CPU 内部的数据通路寄存器，完全由硬件管理，对汇编程序员透明。另外，还有通用寄存器、PSW 对汇编语言程序员是可见的（不透明）。故选 B。

**【点评】** 概念题。首次遇到可能考生会有疑惑，但此类题在教辅中很常见。

</Solution>

</Question>

<Question id="408-605176-002" type="single" tags="来源:2016考研408">

某计算机主存空间为4GB, 字长为32 位, 按字节编址, 采用32 位字长指令字格式。若指令按字边界对齐存放, 则程序计数器(PC) 和指令寄存器(IR) 的位数至少分别是（ ）。

<Option>30、30</Option>
<Option correct>30、32</Option>
<Option>32、30</Option>
<Option>32、32</Option>

<Solution>

**【解析】** 主存空间为 4GB，按字节编址，共 $4\mathrm G=2^{32}$ 个字节地址。指令字长为 32 位 = 4B，“指令按字边界对齐存放”指的是指令在内存中的起始地址必须是“字长”的整数倍，故指令字地址数量为 $2^{32}\div4=2^{30}$ 个，则 PC 至少 30 位。指令寄存器 IR 存放整条指令，IR 位数取决于指令字长，故 IR 至少 32 位。故选 B。

<Callout title="拓展">

指令按字边界对齐 = 地址是字长的整数倍。若字长为 4B，则指令的起始地址必须是 4 的倍数。地址是 4 的整数倍 $\xLeftrightarrow{\text{等价于}}$ 地址的二进制最低 2 位为 00。因为任何一个整数 $A$ 如果是 4 的倍数，则可以表示为 $A=4\times k=2^2\times k$，将其转为二进制，相当于把 $k$ 的二进制表示“左移 2 位，末尾补 2 个 0”。

</Callout>

**【点评】** 概念题。“指令按字边界对齐存放”，这个概念考生可能首次遇到不知道其具体含义，而导致出错。

</Solution>

</Question>

<Question id="408-605176-003" type="single" tags="来源:2019考研408">

下列有关处理器时钟脉冲信号的叙述中,错误的是（ ）。

<Option>时钟脉冲信号由机器脉冲源发出的脉冲信号经整形和分频后形成</Option>
<Option>时钟脉冲信号的宽度称为时钟周期,时钟周期的倒数为机器主频</Option>
<Option>时钟周期以相邻状态单元间组合逻辑电路的最大延迟为基准确定</Option>
<Option correct>处理器总是在每来一个时钟脉冲信号时就开始执行一条新的指令</Option>

<Solution>

**【解析】** D 错误：处理器不是每来一个时钟脉冲就开始执行新指令，指令执行需要多个时钟周期（取指、译码、执行等阶段），一个时钟脉冲推进一个周期步骤，而不是启动新指令。其他选项均正确。故选 D。

**【点评】** 常规题。本题关于时钟脉冲信号的描述中，虽然其中 3 个选项的描述比较生僻，教辅书中没有、考生可能也没见过，但 D 选项的错误还是很明显的，这些生僻的名词概念不影响做对题目。

</Solution>

</Question>

<Question id="408-605176-004" type="single" tags="来源:2021考研408">

下列寄存器中, 汇编语言程序员可见的是（ ）。

I. 指令寄存器
II. 微指令寄存器
III. 基址寄存器
IV. 标志/状态寄存器

<Option>仅I、II</Option>
<Option>仅I、IV</Option>
<Option>仅II、IV</Option>
<Option correct>仅III、IV</Option>

<Solution>

**【解析】** 基址寄存器、标志 / 状态寄存器、程序计数器 PC 和通用寄存器组对汇编语言程序员是可见的，因为汇编语言程序员需要通过通用寄存器组获得数据，通过标志 / 状态寄存器确定条件跳转指令执行与否等，通过基址寄存器和程序计数器编制浮动程序等，故Ⅲ、Ⅳ正确。而 MAR、MDR、IR 等寄存器是 CPU 内部用于存放数据地址、数据内容和指令的寄存器，不需要汇编语言程序员对其进行操作，因此对汇编语言程序员不可见，故Ⅰ错误。微指令寄存器（$\mu\mathrm{IR}$）暂存当前正在执行的微指令，是 CPU 控制单元（CU）中微程序控制器的组成部分，属于 CPU 内部微架构层面的实现细节，对汇编程序员是不可见的，故Ⅱ错误。故选 D。

</Solution>

</Question>

<Question id="408-605176-005" type="single" tags="来源:2023考研408">

数据通路由组合逻辑元件(操作元件) 和时序逻辑元件(状态元件) 组成。下列给出的元件中, 属于操作元件的是（ ）。

I. 算术逻辑部件(ALU)
II. 程序计数器(PC)
III. 通用寄存器组(GPRs)
IV. 多路选择器(MUX)

<Option>仅I, II</Option>
<Option correct>仅I, IV</Option>
<Option>仅II, III</Option>
<Option>I, II, IV</Option>

<Solution>

**【解析】** 组合逻辑元件是那些仅由组合逻辑电路组成的元件，其输出仅取决于当前的输入，而不受存储器或时钟信号的影响。算术逻辑部件 ALU 和多路选择器 MUX 都属于组合逻辑元件，它们的输出仅由当前输入决定。程序计数器 PC 和通用寄存器是时序逻辑元件，也称为状态元件。它们的输出不仅取决于当前输入，还受存储器或时钟信号的影响，并且具有状态或存储功能。故选 B。

**【提示】** 简单分辨组合逻辑元件和时序逻辑元件的方法：有存储功能的就是时序逻辑元件。

**【点评】** 常规题。考查记忆性内容。

</Solution>

</Question>

## 5.2 指令执行过程

<Question id="408-605176-006" type="single" number={6} tags="来源:2011考研408">

假定不采用Cache 和指令预取技术,且机器处于“开中断”状态。在下列有关指令执行的叙述中, 错误的是（ ）。

<Option>每个指令周期中CPU 都至少访问内存一次</Option>
<Option>每个指令周期一定大于或等于一个CPU 时钟周期</Option>
<Option correct>空操作指令的指令周期中任何寄存器的内容都不会被改变</Option>
<Option>当前程序在每条指令执行结束时都可能被外部中断打断</Option>

<Solution>

**【解析】** ① A 正确 √：指令周期包含取指阶段，CPU 必须从内存中取出指令，即使没有访存操作的指令，例如：空操作指令（NOP），也需要取指，因此至少访存一次。

② B 正确 √：指令周期是执行一条指令所需的全部时间，而时钟周期是 CPU 的最小时间单位，单条指令至少需要一个时钟周期（实际中通常需要多个）。

③ C 错误 ×：空操作指令（NOP）在执行时，虽然不改变通用寄存器的值，但程序计数器（PC）会自动自增，以下一条要执行的指令的地址。PC 也是寄存器，因此该说法错误。

④ D 正确 √：题目已说明机器处于“开中断”状态，而中断响应的时机是在每条指令执行结束、下一条指令开始之前，因此每条指令执行结束时都可能响应外部中断。故选 C。

**【点评】** 常规题。考查指令执行的综合概念题。

</Solution>

</Question>

<Question id="408-605176-007" type="single" tags="来源:2019考研408">

某指令功能为 $R[r2] \leftarrow R[r1] + M[R[0]]$，其两个源操作数分别采用寄存器、寄存器间接寻址方式。对于下列给定部件, 该指令在取数及执行过程中需要用到的是（ ）。

I. 通用寄存器组(GPRs)
II. 算术逻辑单元(ALU)
III. 存储器(Memory)
IV. 指令译码器(ID)

<Option>仅I、II</Option>
<Option correct>仅I、II、III</Option>
<Option>仅II、III、IV</Option>
<Option>仅I、III、IV</Option>

<Solution>

**【解析】** ① I 正确 ✓：在取数阶段，一个操作数采用寄存器寻址方式（数据存储在寄存器中），需要用到通用寄存器组 (GPRs)。

② I、III 正确 ✓：在取数阶段，一个操作数使用寄存器间接寻址方式（数据地址存储在寄存器中，数据存储在存储器中），需要用到通用寄存器组 (GPRs) 和存储器 (Memory)。

③ II 正确 ✓：在执行阶段，“R[r1]+M[R[r0]]”是两个操作数相加，因此要用到算术逻辑单元 (ALU)。

④ IV 错误 ×：在取数之前，指令译码器需要对指令进行译码，通过译码结果向控制器提供控制信号。而在取数和执行阶段用不到指令译码器。故选 B。

**【点评】** 常规题。本题要注意审题，指令译码器在“译码”阶段要用到，但“取指、取数和执行”阶段都用不到。

</Solution>

</Question>

## 5.3 数据通路的功能和基本结构

<Question id="408-605176-008" type="single" number={8} tags="来源:2016考研408">

单周期处理器中所有指令的指令周期为一个时钟周期。下列关于单周期处理器的叙述中,错误的是（ ）。

<Option correct>可以采用单总线结构数据通路</Option>
<Option>处理器时钟频率较低</Option>
<Option>在指令执行过程中控制信号不变</Option>
<Option>每条指令的CPI 为1</Option>

<Solution>

**【解析】** A 错误 ×：单周期处理器每个时钟周期执行一条指令，对于指令“`add R1,R2,R3`”来说，先将寄存器 R2 和 R3 的值相加，再把结果写入寄存器 R1。在执行这条指令时，需要先从寄存器 R2 和 R3 中读取数据，进行运算，再将结果写回寄存器 R1。若采用单总线结构，每个时钟周期只能传送一个数据，无法在一个时钟周期内完成这三个操作，需要多个时钟周期（分时复用总线）才能完成整个指令的执行。

B 正确 ✓：由于所有指令均要在一个时钟周期完成，考虑到比较慢的指令，CPU 时钟周期会较长，时钟频率是时钟周期的倒数，所以 CPU 时钟频率较低。

C 正确 ✓：指令控制信号仅由该指令的操作码译码决定，在单周期处理器中，一条指令在一个时钟周期内完成所有操作，指令本身在该时钟周期内不变，所以控制信号在整个指令执行过程中保持不变。需要控制信号随时间变化的唯一理由是“同一部件在不同的时刻干不同的活”（分时复用），所以多周期处理器中控制信号会变。

D 正确 ✓：CPI 的定义是每条指令的时钟周期数，单周期处理器中所有指令的指令周期为一个时钟周期，即 CPI 为 1。故选 A。

**【点评】** 难题。此题涉及的知识点多，需要推理分析，属于 408 难度较大的一类题。

</Solution>

</Question>

<Question id="408-605176-009" type="single" tags="来源:2021考研408">

下列关于数据通路的叙述中,错误的是（ ）。

<Option>数据通路包含ALU 等组合逻辑(操作) 元件</Option>
<Option>数据通路包含寄存器等时序逻辑(状态) 元件</Option>
<Option correct>数据通路不包含用于异常事件检测及响应的电路</Option>
<Option>数据通路中的数据流动路径由控制信号进行控制</Option>

<Solution>

**【解析】** 数据通路指的是指令执行过程中数据的传输路径，以及路径上集成的部件（各种逻辑元件、寄存器和运算部件 ALU 等）。在指令执行过程中，数据会流经 ALU、PSW、通用寄存器、异常和中断处理逻辑等部件，故 A、B 正确，C 错误。控制部件通过发出控制信号控制数据通路中的传送操作，控制部件根据指令功能的不同，生成对数据通路的不同控制信号，以保证指令能够正确执行，故 D 正确（但是要注意数据通路不包括控制部件）。故选 C。

**【点评】** 常规题。考查数据通路的概念，数据通路的示意图 408 真题中考过，可通过排除法选 C。

</Solution>

</Question>

## 5.4 控制器的功能和工作原理

<Question id="408-605176-015" type="single" number={10} tags="来源:2009考研408">

相对于微程序控制器, 硬布线控制器的特点是（ ）。

<Option>指令执行速度慢, 指令功能的修改和扩展容易</Option>
<Option>指令执行速度慢, 指令功能的修改和扩展难</Option>
<Option>指令执行速度快, 指令功能的修改和扩展容易</Option>
<Option correct>指令执行速度快, 指令功能的修改和扩展难</Option>

<Solution>

**【解析】** ①对于微程序控制器，指令需要经过微程序的解释和转换才能执行，相对来说其执行速度较慢，但只需修改微程序即可实现指令功能的修改和扩展。②对于硬布线控制器，指令被编码成电路中的物理连接和逻辑门，直接执行不需要进行额外的解释和转换，因此执行速度更快，但是修改或扩展指令功能需要重新设计电路。综上，故选 D。

**【点评】** 概念题。本题考查硬布线控制器、微程序控制器的特点。

</Solution>

</Question>

<Question id="408-605176-016" type="single" tags="来源:2012考研408">

某计算机的控制器采用微程序控制方式,微指令中的操作控制字段采用字段直接编码法, 共有33 个微命令, 构成5 个互斥类, 分别包含7、3、12、5 和6 个微命令, 则操作控制字段至少有（ ）。

<Option>5 位</Option>
<Option>6 位</Option>
<Option correct>15 位</Option>
<Option>33 位</Option>

<Solution>

**【解析】** 字段直接编码法（也叫字段译码法）的规则如下：

- 不能同时有效的微命令构成一个互斥类。每个互斥类使用同一字段进行二进制编码，通过译码器输出控制信号。
- 该字段的每个二进制编码均表示一个微命令。每个字段需要额外预留一个状态表示“不发出任何微命令”。某个互斥类的字段位数 = $\lceil\log_2(\text{该类微命令数}+1)\rceil$（向上取整）。

题目中 5 个互斥类分别包含 7、3、12、5 和 6 个微命令，所以表示每个互斥类的编码位数分别为：$\lceil\log_2(7+1)\rceil=3$、$\lceil\log_2(3+1)\rceil=2$、$\lceil\log_2(12+1)\rceil=4$、$\lceil\log_2(5+1)\rceil=3$、$\lceil\log_2(6+1)\rceil=3$，共 $3+2+4+3+3=15$ 位。故选 C。

**【提示】** 字段直接编码法相比直接控制法（每个微命令占 1 位）大幅缩短了微指令长度，是微程序控制中常用的优化手段。

**【点评】** 概念题。这类题本身没难度，但记的不熟的时候，容易和直接控制（编码）法“记混了”导致出错。

</Solution>

</Question>

<Question id="408-605176-017" type="single" tags="来源:2014考研408">

某计算机采用微程序控制器, 共有32 条指令, 公共的取指令微程序包含2 条微指令, 各指令对应的微程序平均由4 条微指令组成,采用断定法(下地址字段法) 确定下条微指令地址,则微指令中下地址字段的位数至少是（ ）。

<Option>5</Option>
<Option>6</Option>
<Option correct>8</Option>
<Option>9</Option>

<Solution>

**【解析】** ① 计算微指令总数量：

- 公共取指令微程序包含 2 条微指令。
- 32 条指令，每条对应平均 4 条微指令：$32\times4=128$ 条。

则微指令总数 = $128+2=130$ 条。② 微指令中下地址字段应能对所有微指令进行寻址，下地址字段位数 $n$ 需要满足 $2^n\geq$ 微指令总数。则 $n=\lceil\log_2 130\rceil=8$。故选 C。

**【点评】** 常规题。考查微指令格式。计算时不要漏掉公共的取指微程序。

</Solution>

</Question>

<Question id="408-605176-018" type="single" tags="来源:2017考研408">

下列关于主存储器(MM) 和控制存储器(CS) 的叙述中,错误的是（ ）。

<Option>MM 在CPU 外, CS 在CPU 内</Option>
<Option correct>MM 按地址访问, CS 按内容访问</Option>
<Option>MM 存储指令和数据, CS 存储微指令</Option>
<Option>MM 用RAM 和ROM 实现, CS 用ROM 实现</Option>

<Solution>

**【解析】** ① 主存 MM 在 CPU 外，存放指令和数据，用 RAM / ROM 实现，按地址访问。

② 控制存储器 CS 在 CPU 控制器内，存放微程序（微指令），一般用 ROM 实现，也是按微地址访问，而非按内容访问（按内容访问的是相联存储器）。故 B 错误。

**【点评】** 概念题。“按内容访问”是相联存储器（TLB、Cache）的特征，控制存储器仍按微地址顺序读取，这是本题最易混淆的点。

</Solution>

</Question>

## 5.5 异常和中断机制

<Question id="408-605176-019" type="single" number={14} tags="来源:2009考研408">

下列选项中, 能引起外部中断的事件是（ ）。

<Option correct>键盘输入</Option>
<Option>除数为0</Option>
<Option>浮点运算下溢</Option>
<Option>访存缺页</Option>

<Solution>

<Question id="408-605176-028" type="single" tags="来源:2010考研408">

下列选项中, 不会引起指令流水线阻塞的是（ ）。

<Option correct>数据旁路(转发)</Option>
<Option>数据相关</Option>
<Option>条件转移</Option>
<Option>资源冲突</Option>

<Solution>

**【解析】** 指令流水线的阻塞通常由三类冒险引起：

- ① 数据相关（数据冒险）：指令之间存在数据依赖关系，导致后一条指令无法在流水线中正常执行，会引起阻塞。
- ② 控制相关（控制冒险）：流水线中因指令执行流改变（例如，跳转指令、分支指令、转移指令），导致预取的后续指令无效，引起阻塞。
- ③ 资源冲突（结构冒险）：多条指令同时使用同一硬件资源，导致资源竞争，引起阻塞。

④ 而数据旁路（转发 / 直通技术）是解决数据相关引起阻塞的一种优化手段：它将结果直接转发给后续指令，避免流水线停顿，本身不会引起阻塞。数据旁路（转发）可以解决大部分数据冒险，但无法解决“load-use”类的数据冒险（即访存指令的结果被下一条指令使用），这类情况仍需插入流水线气泡。控制冒险通常通过分支预测、延迟槽等技术缓解，资源冲突则需要通过增加硬件资源来解决。

**【点评】** 概念题。本题主要考查流水线阻塞的原因。

</Solution>

<Option>I、II 和III</Option>

<Solution>

**【解析】** 超标量流水线是指在一个时钟周期内，CPU 可以同时发射多条指令进入流水线执行的技术。它通过在 CPU 内部重复设置多套功能部件（例如：多个 ALU、多个取指单元、多个译码单元），实现指令级并行。

① Ⅰ错误 ×：超标量是通过同时发射多条指令来提升吞吐率，不是改变单段的处理时间。

② Ⅱ正确 ✓：超标量流水线的核心特性就是在一个时钟周期内同时发射多条指令，通过配置多套功能部件，一个时钟周期内可同时发射、执行多条指令，使 CPI 可以小于 1。

③ Ⅲ正确 ✓：超标量处理器可配合动态流水线调度技术（例如：乱序执行、记分牌、Tomasulo 算法等），由硬件动态调整指令执行顺序，解决指令的数据相关问题，进一步挖掘指令级并行性。故选 C。

**【拓展】**

① **动态流水线** 指在同一时间内，多功能流水线中的各段可以按照不同的方式连接，同时执行多种功能的流水线。它允许在同一时间内将不同的功能段连接成不同的功能子集，以完成不同的功能。

② **静态流水线** 指在同一时间内，流水线的各段只能按同一种功能的连接方式工作的流水线。静态流水线在从一种功能切换到另一种功能时，必须等流水线排空（流水线中所有指令全部流出）之后，才能重新按新功能连接各段并流入新的指令。

③ **超流水线** 指把流水线的功能段进一步细分（加深流水级数），以缩短各段处理时间、提高时钟频率，从而在一个时钟周期内能分时发射（流出）多条指令的流水线。

④ 超标量和超流水线既不属于静态流水线，也不属于动态流水线，它们是从不同维度对流水线进行分类的。

**【点评】** 概念题。本题考查超标量流水线的概念。408 考试是抽查，考生应举一反三，练习此题时应同步回顾“超流水线”和“动态流水线”等相关概念。

</Solution>

</Question>

<Question id="408-605176-033" type="single" tags="来源:2017考研408">

下列关于指令流水线数据通路的叙述中，错误的是（ ）。

<Option correct>包含生成控制信号的控制部件</Option>
<Option>包含算术逻辑运算部件（ALU）</Option>
<Option>包含通用寄存器组和取指部件</Option>
<Option>由组合逻辑电路和时序逻辑电路组合而成</Option>

<Solution>

**【解析】** 数据通路是数据在各功能部件之间流动的路径，包括取指部件（程序计数器 PC 和指令寄存器 IR 等）、通用寄存器组、总线 / 多路选择器、流水线段间寄存器、ALU 等，由组合逻辑（ALU、多路选择器 MUX 等）和时序逻辑构成。故 B、C、D 均正确 ✓。A 错误 ×：生成控制信号的控制部件（控制器 CU）不属于数据通路，它与数据通路是 CPU 内部并列的两大组成部分（控制器发出控制信号“指挥”数据通路工作）。故选 A。

<Question id="408-605176-034" type="single" tags="来源:2018考研408">

若某计算机最复杂指令的执行需要完成5 个子功能, 分别由功能部件A∼E 实现, 各功能部件所需时间分别为80ps、50ps、50ps、70ps 和50ps, 采用流水线方式执行指令, 流水段寄存器延时为20ps, 则CPU 时钟周期至少为（ ）。

<Option>60ps</Option>
<Option>70ps</Option>
<Option>80ps</Option>
<Option correct>100ps</Option>

<Solution>

<Question id="408-605176-035" type="single" tags="来源:2019考研408">

在采用“取指、译码/取数、执行、访存、写回”5 段流水线的处理器中, 执行如下指令序列, 其中s0、s1、s2、s3 和t2 表示寄存器编号。

```asm

I4: store s2, 0(t2)    // M[R[t2] + 0] ← R[s2]
```

下列指令对中, 不存在数据冒险的是（ ）。

<Option>I1 和I3</Option>
<Option>I2 和I3</Option>
<Option correct>I2 和I4</Option>

<Question id="408-605176-036" type="single" tags="来源:2020考研408">

下列给出的处理器类型中,理想情况下, CPI 为1 的是（ ）。

I. 单周期CPU
II. 多周期CPU
III. 基本流水线CPU
IV. 超标量流水线CPU

<Option>仅I、II</Option>
<Option correct>仅I、III</Option>
<Option>仅II、IV</Option>
<Option>仅III、IV</Option>

<Solution>

**【解析】** CPI 指 CPU 执行一条指令平均所需要的时钟周期数。① I 正确：单周期 CPU 中每条指令都在一个时钟周期内完成，每条指令的 CPI 为1。② II 错误：在多周期 CPU 中，一条指令的执行需要几个时钟周期，每个时钟周期对应执行过程的一个阶段，故多周期 CPU 的 $\mathrm{CPI}>1$。③ III 正确：对于基本流水线，在理想情况下，其每个时钟周期均流出一条指令，故 CPI=1。④ IV 错误：超标量流水线 CPU 在每个时钟周期内，会并行执行多条流水线，故 $\mathrm{CPI}<1$。故选 B。

<Question id="408-605176-037" type="single" tags="来源:2023考研408">

在采用“取指、译码/取数、执行、访存、写回”5 段流水线的RISC 处理器中, 执行如下指令序列(第一列为指令序号), 其中s0、s1、s2、s3 和t2 表示寄存器编号。

```asm
I1: add s2, s1, s0     // R[s2] ← R[s1] + R[s0]
I2: load s3, 0(s2)     // R[s3] ← M[R[s2] + 0]
I3: beq t2, s1, L1     // if R[t2] = R[s1] jump to L1
I4: addi t2, t2, 20    // R[t2] ← R[t2] + 20
I5: L1: add ...
```

若采用转发(旁路) 技术处理数据冒险, 采用硬件阻塞方式处理控制冒险, 则在I1～I4 执行过程中, 发生流水线阻塞的指令有（ ）。

<Option>仅I3</Option>
<Option>I2、I4</Option>
<Option correct>I3、I4</Option>
<Option>I2、I3、I4</Option>

<Solution>

**【解析】** 旁路技术通过在流水线中引入旁路（Forwarding）路径，将之前指令的结果直接传递给后续需要使用的指令，避免了流水线停顿。具体来说，当检测到数据相关时，旁路技术将结果从执行阶段的功能单元（如算术逻辑单元）直接转发给需要使用该结果的指令，绕过了中间的寄存器阶段。I1 和 I2 存在数据相关，可以通过旁路技术，使得 I2 获取到 I1 执行阶段 R[S2] 的新值，解决数据相关。I2 和 I3 存在数据相关，但是是属于 load-use 类型的数据相关（即取数指令的下一条指令立刻使用取出的数），需要等 I2 的访存阶段结束，I3 才能拿到 R[s3] 的值，所以 I3 需要阻塞，等待 I2 的访存阶段结束。I4 与 I3 存在控制相关，需要等待 I3 执行结束才能判断 I4 是否能够执行，所以 I4 会发生流水线阻塞。故选 C。

<Option>相邻两条指令中的操作数相关可能引起数据冒险</Option>
<Option>在数据相关的指令间插入“气泡”能避免数据冒险</Option>

## 5.7 多处理器基本概念

<Question id="408-605176-041" type="single" number={34} tags="来源:2022考研408">

下列关于并行处理技术的叙述中, 不正确的是（ ）。

<Option>多核处理器属于MIMD 结构</Option>
<Option>向量处理器属于SIMD 结构</Option>
<Option correct>硬件多线程技术只可用于多核处理器</Option>
<Option>SMP 中所有处理器共享单一物理地址空间</Option>

<Solution>

**【解析】** ① A 正确 ✓：MIMD (Multiple Instruction stream Multiple Data stream)：多指令流多数据流，即该结构同时有多个指令分别处理不同的数据，这种系统中一定包含有多个计算机或多个处理器，故多核处理器属于 MIMD 结构。

② B 正确 ✓：向量处理机是面向向量型数据的并行计算机，在向量的各分量上执行的运算操作都一般是彼此无关的、各自独立的，属于 SIMD 一类。

③ C 错误 ×：硬件多线程 (hardware multithreading)：当线程发生阻塞时，处理器可切换到另一线程继续运行，单核处理器也可以使用硬件多线程技术。

④ D 正确 ✓：共享地址多处理器 (shared-address multiprocessor)，其特点是硬件为所有的处理器提供单一的物理地址空间，并用锁来同步共享变量。

**【点评】** 冷门考点。本题考查了一些冷门概念，如果此前了解过这些概念，则是送分题，否则容易出错。

</Solution>
