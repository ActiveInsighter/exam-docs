# 第 2 章 数据的表示和运算


## 2.1 数制与编码

<Question id="408-b24539-001" type="single">

【2013】用海明码对长度为 8 位的数据进行检错和纠错时，若能纠正一位错误，则校验位数至少为（ ）。

<Option>2</Option>
<Option>3</Option>
<Option correct>4</Option>
<Option>5</Option>

<Solution>

**【解析】** 用 $k$ 表示校验位的位数，$n$ 表示数据位的位数，海明码纠正 1 位错的条件是：$2^k\geq k+n+1$。在本题中，$n=8$，代入上述公式得：$2^k-k\geq9\Rightarrow k\geq4$。

**【点评】** 冷门考点。① 在最新的 408 考纲中，计组部分已经删除了涉及“海明码”考点（校验码）的描述。但在 408 考纲的计网部分中“差错控制”的部分有可能会考海明码。而且，在 2025 年 408 第 34 题中，再次考到了海明码，这是 2009～2025 年 408 考试中关于海明码仅有的 2 次考查。② 关于海明码有个经典例题，考生可根据此视频学习：https://b23.tv/xoQT4kA

</Solution>

</Question>

<Question id="408-b24539-002" type="single">

【2018】冯·诺依曼结构计算机中数据采用二进制编码表示，其主要原因是（ ）。

I. 二进制的运算规则简单  
II. 制造两个稳态的物理器件较容易  
III. 便于用逻辑门电路实现算术运算

<Option>仅 I、II</Option>
<Option>仅 I、III</Option>
<Option>仅 II、III</Option>
<Option correct>I、II 和 III</Option>

<Solution>

**【解析】** ① Ⅰ 正确：二进制只有 0 和 1 两个数码，加、减、乘、除的运算规则比十进制简单得多，加法只需 3 条规则（$0+0=0$，$0+1=1$，$1+1=10$），便于硬件实现。

② Ⅱ 正确：电子器件中区分两个稳态（例如：电压高低、电容有无电荷、磁介质的两种磁化方向，分别对应 0 和 1）比区分多个稳态（例如：十进制对应十个稳态）更容易且抗干扰能力强、可靠性高，制造两个稳态的物理器件更容易。

③ Ⅲ 正确：算术运算可以转化为 0、1 之间的逻辑运算，直接由与、或、非等逻辑门电路实现，使运算器结构规整、易于集成。

**【提示】** 稳态（稳定状态），指一个物理器件在不加外界干预的情况下，能够长期稳定保持、且能被可靠区分的工作状态。

**【点评】** 难题。此类题涉及知识面较广、需要根据已有知识区分分析判断，各个选项迷惑性较强，容易错选漏选。

</Solution>

## 2.2 整数表示和运算

<Question id="408-b24539-003" type="single" number={1}>

【2010】假定有 4 个整数用 8 位补码分别表示 $ r_1=\text{FEH}$，$ r_2=\text{F2H}$，$ r_3=\text{90H}$，$ r_4=\text{F8H}$。若将运算结果存放在一个 8 位寄存器中，则下列运算中会发生溢出的是（ ）。

<Option>$ r_1\times r_2$</Option>
<Option correct>$ r_2\times r_3$</Option>
<Option>$ r_1\times r_4$</Option>
<Option>$ r_2\times r_4$</Option>

<Solution>

**【解析】** 8 位补码所能表示的整数范围为 $-128\sim +127$。先将 4 个整数转化为十进制，再判断十进制相乘结果是否在表示范围内。负数补码转化为原码（真值）的方法是：符号位不变，其他各位取反，再加 1。$r_1=\mathrm{FEH}=1111\ 1110\mathrm{B}=-2$，$r_2=\mathrm{F2H}=1111\ 0010\mathrm{B}=-14$，$r_3=\mathrm{90H}=1001\ 0000\mathrm{B}=-112$，$r_4=\mathrm{F8H}=1111\ 1000\mathrm{B}=-8$。

① A 选项 ×：$r_1\times r_2=(-2)\times(-14)=28$，没有溢出。

② B 选项 ✓：$r_2\times r_3=(-14)\times(-112)=1568>127$，发生溢出。

③ C 选项 ×：$r_1\times r_4=(-2)\times(-8)=16$，没有溢出。

④ D 选项 ×：$r_2\times r_4=(-14)\times(-8)=112$，没有溢出。故选 B。

**【点评】** 难题。本题若直接用二进制乘法计算，则会很耗费时间。

</Solution>

</Question>

<Question id="408-b24539-004" type="single">

【2013】某字长为 8 位的计算机中，已知整型变量 $ x$ 和 $ y$ 的机器数分别为 $ [x]_{\text{补}}=11110100$、$ [y]_{\text{补}}=10110000$。若整型变量 $ z=2x+y/2$，则 $ z$ 的机器数为（ ）。

<Option correct>1100 0000</Option>
<Option>0010 0100</Option>
<Option>1010 1010</Option>
<Option>溢出</Option>

<Solution>

**【解析】【解法一】** 补码算术左移一位，等价于乘以 2。补码算术右移一位，等价于除以 2。

① 计算 $2x$（补码算术左移 1 位）：符号位不变，高位丢弃，低位补 0。$[2x]_{\text{补}}=1110\ 1000$。

② 计算 $y/2$（补码算术右移 1 位）：符号位不变，高位补符号位，低位丢弃。$[y/2]_{\text{补}}=1101\ 1000$。

③ $[2x]_{\text{补}}+[y/2]_{\text{补}}=1110\ 1000+1101\ 1000=\underline{1}\ 1100\ 0000$，丢弃最高位进位。故选 A。

| | 运算 | 机器数 |
| --- | --- | --- |
| $[2x]_{\text{补}}$ | | 11101000 |
| $[y/2]_{\text{补}}$ | + | 11011000 |
| 结果 | 1（进位丢弃） | 11000000 |

**【提示】** ① 注意只有补码算术左移一位等价于乘以 2，补码算术右移一位等价于除以 2。该规则对原码、移码不生效，即：原码/移码算术左移（或右移）一位，不等于乘以（或除以）2。② 补码乘法都可以转化为移位和加法运算。例如：$6x=4x+2x$，$4x$ 等价于将 $[x]_{\text{补}}$ 左移 2 位，而 $2x$ 等价于将 $[x]_{\text{补}}$ 左移 1 位，即可通过两次移位运算和一次加法运算实现 $6x$。熟练掌握该方法可以更快的求解补码乘除法。

**【解法二】** 转化成十进制计算。将补码转化成原码：除符号位外，其余各位取反，再加 1。即：

$$
\begin{aligned}
[x]_{\text{补}}=1\ 111\ 0100&\xrightarrow{\text{除符号位外，其余各位取反}}1\ 000\ 1011\xrightarrow{+1}[x]_{\text{原码}}=1\ 000\ 1100=-12\\
[y]_{\text{补}}=1\ 011\ 0000&\xrightarrow{\text{除符号位外，其余各位取反}}1\ 100\ 1111\xrightarrow{+1}[y]_{\text{原码}}=1\ 101\ 0000=-80
\end{aligned}
$$

则 $z=2x+y/2=2\times(-12)+(-80)\div2=-64$，$[z]_{\text{补}}=11000000$。故选 A。

**【点评】** 常规题。考查补码的加减乘除运算。

</Solution>

</Question>

<Question id="408-b24539-006" type="single">

【2015】由 3 个“1”和 5 个“0”组成的 8 位二进制补码，能表示的最小整数是（ ）。

<Option>$ -126$</Option>
<Option correct>$ -125$</Option>
<Option>$ -32$</Option>
<Option>$ -3$</Option>

<Solution>

**【解析】** ① 要使补码表示的整数最小，首先该数必为负数，因此符号位必须为 1。

② 负数补码的数值位“各位取反再加 1”，得到对应真值的绝对值。所以数值位中 1 越靠低位，取反后 0 越靠低位，对应真值的绝对值就越大，对应的负数就越小。

③ 总共 3 个“1”，其中符号位为“1”，再将剩余的 2 个“1”放在最低位，得到对应的补码 = 10000011，$[10000011]_{\text{补码}}\to[11111101]_{\text{原码}}=-125$。故选 B。

**【点评】** 常规题。考查补码的应用。

</Solution>

</Question>

<Question id="408-b24539-007" type="single">

【2018】假定带符号整数采用补码表示，若 int 型变量 $ x$ 和 $ y$ 的机器数分别是 FFFF FFDFH 和 0000 0041H，则 $ x$、$ y$ 的值及 $ x-y$ 的机器数分别是（ ）。

<Option>$ x=-65$，$ y=41$，$ x-y$ 的机器数溢出</Option>
<Option>$ x=-33$，$ y=65$，$ x-y$ 的机器数为 FFFF FF9DH</Option>
<Option correct>$ x=-33$，$ y=65$，$ x-y$ 的机器数为 FFFF FF9EH</Option>
<Option>$ x=-65$，$ y=41$，$ x-y$ 的机器数为 FFFF FF96H</Option>

<Solution>

**【解析】** ① 将负数补码转换成原码的规则为：符号位不变，将数值位取反再加 1。

$[x]_{补码}=\mathrm{FFFF\ FFDFH}=\mathrm{1\ 111\ 1111\ 1111\ 1111\ 1111\ 1111\ 1101\ 1111B}$，除符号位外，其余各位取反得到 1 000 0000 0000 0000 0000 0000 0010 0000，再加 1 得 $[x]_{原码}=\mathrm{1\ 000\ 0000\ 0000\ 0000\ 0000\ 0000\ 0010\ 0001}=-33$。② 正数的补码和原码相同，$[y]_{补码}=\mathrm{0000\ 0041H}=\mathrm{0000\ 0000\ 0000\ 0000\ 0000\ 0000\ 0100\ 0001B}=65$。③ $[x-y]_{补码}=[x]_{补码}+[-y]_{补码}$。$[-y]_{补码}$ 等于将 $[y]_{补码}$ 连同符号位在内，各位取反，再加 1。则 $[-y]_{补码}=\mathrm{1111\ 1111\ 1111\ 1111\ 1111\ 1111\ 1011\ 1111B}=\mathrm{FFFF\ FFBFH}$。

$[x-y]_{补码}=[x]_{补码}+[-y]_{补码}=\mathrm{FFFF\ FFDFH}+\mathrm{FFFF\ FFBFH}=\mathrm{FFFF\ FF9EH}$。计算过程如下：

| | | |
|---|---|---|
| $[x]_{补码}$ | | FFFFFFDF |
| $[-y]_{补码}$ | + | FFFFFFBF |
| 结果 | 1（进位丢弃） | FFFFFF9E |


**【提示】** 求 $x-y$ 的机器数也可以用如下方法：$x-y=-33-65=-98$，$-98$ 的 32 位十六进制补码为 FFFF FF9EH。32 位补码的表示范围为 $-2^{31}\sim2^{31}-1$，求出 $x$ 和 $y$ 的真值之后，可以很明显的看出未发生溢出。

**【点评】** 常规题。考查补码运算、补码和十进制的相互转换，这些内容是备考 408 必须掌握的。

</Solution>

</Question>

<Question id="408-b24539-008" type="single">

【2018】整数 $ x$ 的机器数为 11011000，分别对 $ x$ 进行逻辑右移 1 位和算术右移 1 位操作，得到的机器数分别是（ ）。

<Option>1110 1100，1110 1100</Option>
<Option correct>0110 1100，1110 1100</Option>
<Option>1110 1100，0110 1100</Option>
<Option>0110 1100，0110 1100</Option>

<Solution>

**【解析】** ① 逻辑右移 1 位，最高位补 0，最低位移丢。$1101\ 1000\xrightarrow{逻辑右移1位}0110\ 1100$。

② 算术右移 1 位，最高位补符号位，最低位移丢。$1101\ 1000\xrightarrow{算术右移1位}1110\ 1100$。故选 B。

**【提示】** ① 逻辑移位和算术移位的对比总结如下表所示：

| 操作 | 逻辑移位 | 算术移位 |
|---|---|---|
| 左移 | 右端补 0 | 右端补 0 |
| 右移 | 左端补 0 | 左端填充符号位 |
| 移出的位 | 丢弃 | 丢弃 |

② 逻辑移位视为无符号数操作，移出空位一律补 0。逻辑移位不区分原码、反码、补码，直接把所有二进制位当作普通数值位处理。

- 逻辑左移一位，未溢出时，等价于无符号数 × 2；
- 逻辑右移一位，等价于无符号数 ÷ 2（向下取整）。

对于原码、反码、补码，算术左移一位，只要移位后没有溢出，都等价于有符号数 × 2；但只有补码（以及正数）算术右移一位，等价于有符号数除以 2（向下取整）。

**【点评】** 概念题。考查逻辑移位和算术移位。

</Solution>

</Question>

<Question id="408-b24539-009" type="single">

【2021】已知带符号整数用补码表示，变量 $ x$、$ y$、$ z$ 的机器数分别为 FFFDH、FFDFH、7FFCH，下列结论正确的是（ ）。

<Option>若 $ x$、$ y$ 和 $ z$ 为无符号整数，则 $ z<x<y$</Option>
<Option>若 $ x$、$ y$ 和 $ z$ 为无符号整数，则 $ x<y<z$</Option>
<Option>若 $ x$、$ y$ 和 $ z$ 为带符号整数，则 $ x<y<z$</Option>
<Option correct>若 $ x$、$ y$ 和 $ z$ 为带符号整数，则 $ y<x<z$</Option>

<Solution>

**【解析】** $x=\text{FFFDH}=\text{1111 1111 1111 1101B}$，$y=\text{FFDFH}=\text{1111 1111 1101 1111B}$，$z=\text{7FFCH}=\text{0111 1111 1111 1100B}$。① 若 $x$、$y$ 和 $z$ 均为无符号整数，则 $x>y>z$，故 A 和 B 错误。② 若 $x$、$y$ 和 $z$ 均为带符号整数，补码的最高位是符号位，0 表示正数，1 表示负数，所以 $x$ 和 $y$ 为负数，$z$ 为正数，可得 $z>x$，$z>y$。对于负数，补码转换为原码和原码转换为补码的方法均为“符号位不变，数值位取反再加一”。$x$ 的原码为 1000 0000 0000 0011B，则 $x=-3$；$y$ 的原码为 1000 0000 0010 0001B，则 $y=-33$。所以 $x>y$，可得 $y<x<z$。故选 D。

**【提示】** 本题也可以使用如下结论：当补码符号位相同时，数值位越大，其对应的真值越大（可以参考移码理解）。所以当 $x,y,z$ 为带符号整数时，可得 $y<x$。又因为 $z$ 为正数，可得 $y<x<z$。该结论在竞成 408《计算机组成原理考研复习全书》第 2 章的章末总结中进行了详细说明。

**【点评】** 常规题。整数的表示和运算，补码、原码、有符号和无符号都考到了，涉及的内容都是 408 必须掌握的，有一定综合性。

</Solution>

</Question>

## 2.3 浮点数的表示和运算

<Question id="408-b24539-011" type="single" number={1}>

【2009】浮点数加、减运算过程一般包括对阶、尾数运算、规格化、舍入和判溢出等步骤。设浮点数的阶码和尾数均采用补码表示，且位数分别为 5 位和 7 位（均含 2 位符号位）。若有两个数 $ X=2^7\times \frac{29}{32}$，$ Y=2^5\times \frac{5}{8}$，则用浮点加法计算 $ X+Y$ 的最终结果是（ ）。

<Option>00111 1100010</Option>
<Option>00111 0100010</Option>
<Option>01000 0010001</Option>
<Option correct>发生溢出</Option>

<Solution>

**【解析】**

① 第一步：规格化。将 $X$、$Y$ 表示为规格化浮点数。$X=2^7\times29/32=29\times2^2$，29 = 11101B，$X$ 规格化形式的表示为 $00.11101\times2^7$。$X$ 的规格化尾数 = 00.11101（高 2 位为符号位）、阶码 = 7 = 00111B（高 2 位为符号位）。$Y=2^5\times5/8=5\times2^2$，5 = 101B，$Y$ 规格化形式的表示为 $00.101\times2^5=00.10100\times2^5$（末尾补 0 不影响大小）。$Y$ 的规格化尾数 = 00.10100（高 2 位为符号位）、阶码 = 5 = 00101B（高 2 位为符号位）。

② 第二步：对阶，小阶向大阶对齐。将 $Y$ 的尾数右移 2 位，使得阶码变为 7。$Y=00.10100\times2^5=00.00101\times2^7$。

③ 第三步：尾数相加。$00.11101+00.00101=01.00010$。尾数相加结果符号位为 01，故右规。

④ 第四步：结果规格化。将尾数右移 1 位，阶码加 1，尾数为 00.10001，阶码为 7 + 1 = 8 = 01000B。阶码加 1 变成 8 之后，其实已经可以判断溢出，超出 3 位阶码（除去 2 位符号位后）的最大表示范围了。

⑤ 第五步：舍入处理。本题中无需舍入。

⑥ 第六步：溢出判断和处理。阶码符号位为 01，说明发生溢出。

**【提示】**

① 快速解题技巧：由阶码 5 位、尾数 7 位（均含 2 位符号位）可知，该浮点数可表示的最大数的尾数均为 1（00.11111），阶码均为 1（00 111），对应真值为 $31\times2^7\div2^5=31\times2^2$。直接通过十进制计算 $X+Y=29\times2^2+5\times2^2=34\times2^2>31\times2^2$，超过最大表示范围，显然溢出，故选 D。

② 原码和补码规格化尾数形式是不一样的，相关总结如下表所示。原码的符号位和数值位完全分开，而补码的符号位和数值位是一体的。

| 编码方式 | 规格化形式 | 正数形式 | 负数形式 |
| --- | --- | --- | --- |
| 原码 | 小数点后第一位必须为 1 | 0.1xxxx | 1.1xxxx |
| 补码 | 符号位与最高数值位必须不同 | 0.1xxxx | 1.0xxxx |
| 补码（双符号位） | 双符号位与最高数值位必须不同 | 00.1xxxx | 11.0xxxx |

**【点评】** 常规题。本题考查浮点数加减运算，只要掌握了浮点数加减运算的流程，难度其实不大。可能部分同学放弃了对该考点的学习，从而无从下手。

</Solution>

</Question>

<Question id="408-b24539-012" type="single">

【2011】float 型数据通常用 IEEE 754 单精度浮点数格式表示。若编译器将 float 型变量 $ x$ 分配到一个 32 位浮点寄存器 FR1 中，且 $ x=-8.25$，则 FR1 的内容是（ ）。

<Option correct>C104 0000H</Option>

④ 对于 IV：$d+f$，根据浮点数加减法运算步骤，$f$ 隐式转换为 double 类型（低精度类型转为高精度类型）。再对阶（小阶向大阶对齐），

$$
d+f=1.5\mathrm{e}100+0.\overbrace{000\cdots0}^{96\text{个0}}15678\mathrm{e}100=1.5\overbrace{000\cdots0}^{95\text{个0}}15678\mathrm{e}100
$$

IEEE 754 表示 double 类型，其尾数部分有效位为 53 位（含 1 位隐藏位），尾数部分超过 53 位的部分被截断，所以 $d+f=d$，$(d+f)-d=d-d=0$。故 IV 为假。

② 关于无符号数减法，这里用 2 种方法求解：

- 人类视角：$n$ 位无符号数减法计算公式为 $x-y=(x+(2^n-y))\bmod 2^n$。$x-y=(134+(2^8-246))\bmod 2^8=144\%256=144=10010000\text{B}=90\text{H}$，

## 2.5 运算方法和运算电路

<Question id="408-b24539-032" type="single" number={1}>

【2011】某机器有一个标志寄存器，其中有进位/借位标志 CF、零标志 ZF、符号标志 SF 和溢出标志 OF。条件转移指令 `bgt`（无符号整数比较大于时转移）的转移条件是（ ）。

<Option>$ CF+OF=1$</Option>
<Option>$ \overline{SF+ZF}=1$</Option>
<Option correct>$ \overline{CF+ZF}=1$</Option>
<Option>$ \overline{CF+SF}=1$</Option>

<Solution>

**【解析】** CF、ZF、SF、OF 这 4 个标志位的含义如下表所示。

| 标志位 | 全称 | 含义与触发条件 | 主要用途 |
| --- | --- | --- | --- |
| CF (Carry Flag) | 进位/借位标志 | 无符号数运算中，最高位产生进位（加法）或借位（减法）时，CF=1；否则为 0。 | CF 仅与无符号数运算相关 |
| ZF (Zero Flag) | 零标志 | 运算结果为 0 时，ZF=1；否则为 0。 | 判断结果是否为零、是否相等 |
| SF (Sign Flag) | 符号标志 | 运算结果的最高位（符号位）为 1 时，SF=1（表示负数）；否则为 0（表示正数）。 | 仅用于有符号数的正负判断 |
| OF (Overflow Flag) | 溢出标志 | 有符号数运算中，结果超出可表示范围（溢出）时，OF=1；否则为 0。 | 仅用于有符号数的溢出判断 |

bgt 指令在无符号整数比较大于时转移，判断逻辑为：将 2 个操作数 A 和 B 相减，即 $A-B$ 后，若 $A>B$，则发生转移。要求运算结果为正，则无借位（CF=0），且结果非零（ZF=0），等价于先对 CF 和 ZF 做“或”运算，再将结果取反，最终结果为 1，即：$\overline{\mathrm{CF}+\mathrm{ZF}}=1$。故选 C。

**【提示】** SF、OF 和 CF 标志，会随所有算术运算自动更新。但 SF 和 OF 标志仅对有符号数运算具备逻辑判断意义，对无符号数运算无实际作用，可利用这点快速排除选项 A、B 和 D。CF 标志仅对无符号数运算具备逻辑判断意义，对有符号数运算无实际作用。

**【点评】** 难题。CF、ZF、SF、OF 这 4 个标志位的含义及示例，考生应熟练掌握。在竞成《计算机组成原理复习全书》第 2 章最后一个小节“运算方法和运算电路”部分，也有详细介绍。另外，本题选项中“+”指逻辑或，不是加号。关于常见逻辑运算符，在数字电路、数学逻辑和 C 语言编程代码中，不同场景下符号的写法有差异（经常混用），但都是等价的，这里总结如下。

| 运算名称 | 数字电路 | 数学符号 | C 编程符号 | 运算规则 |
| --- | --- | --- | --- | --- |
| 逻辑非（NOT） | $\overline A$ | $\neg A$ | `!A` | 取反：真变假，假变真 |
| 逻辑与（AND） | $A\cdot B$ | $A\land B$ | `&&` | 全 1 出 1，有 0 出 0 |
| 逻辑或（OR） | $A+B$ | $A\lor B$ | `\|\|` | 有 1 出 1，全 0 出 0 |
| 异或（XOR） | $A\oplus B$ | $A\oplus B$ | `^` | 二进制位不同为 1，相同为 0 |

</Solution>

【2018】减法指令 `sub R1, R2, R3` 的功能为“$ (R1)-(R2)\to R3$”，该指令执行后将生成进位/借位标志 CF 和溢出标志 OF。若 $ (R1)=\text{FFFF FFFFH}$，$ (R2)=\text{FFFF FFF0H}$，则该减法指令执行后，CF 与 OF 分别为（ ）。

<Option correct>$ CF=0,OF=0$</Option>
<Option>$ CF=1,OF=0$</Option>
<Option>$ CF=0,OF=1$</Option>
<Option>$ CF=1,OF=1$</Option>

<Solution>

**【解析】** **【解法一】** (R1) = FFFF FFFFH，(R2) = FFFF FFF0H，(R1) − (R2) = FFFF FFFFH − FFFF FFF0H = 0000 000FH。上述减法过程中，够减、无借位，所以 CF = 0。减法过程中，一直没有任何进位和借位，则结果无溢出，所以 OF = 0。故选 A。

**【解法二】** 因为题目没有说明 (R1) 和 (R2) 中是无符号数还是有符号数，所以视为无符号数还是有符号数均可。

- 把两个数看作 32 位无符号数：(R1) = FFFF FFFFH = $2^{32}-1$，(R2) = FFFF FFF0H = $2^{32}-16$。$2^{32}-1>2^{32}-16$，所以不会产生借位，故 CF = 0。两个正数相减，结果也不会溢出，故 OF = 0。
- 把两个数看作 32 位有符号补码：(R1) = FFFF FFFFH，32 位补码表示 −1。(R2) = FFFF FFF0H，32 位补码表示 −16。$(\mathrm{R1})-(\mathrm{R2})=[\mathrm{R1}]_{补码}+[-\mathrm{R2}]_{补码}$。$[-\mathrm{R2}]_{补码}$ 等于将 $[\mathrm{R2}]_{补码}$ 连同符号位在内，各位取反再加一。$[-\mathrm{R2}]_{补码}=\mathrm{0000\ 0010H}$。

则 (R1) − (R2) = FFFF FFFFH + 0000 0010H，计算过程如下：

```text
  1111 1111 1111 1111 1111 1111 1111 1111
+ 0000 0000 0000 0000 0000 0000 0001 0000
-----------------------------------------
1 0000 0000 0000 0000 0000 0000 0000 1111
```

OF = 最高位进位（即符号位进位）⊕ 次高位进位（即最高数值位进位）= 1 ⊕ 1 = 0。最高位进位为 1，所以 OF = 0（见下文提示部分的解释）。

{/* 原书末句 OF 应为 CF，保留原文。 */}

**【提示】** ALU 执行加减运算时，CF、OF、ZF、SF 等标志是同时、自动产生的，硬件不认识“有符号”还是“无符号”：硬件只看到一串二进制位，按固定的物理规则产生进位 / 借位。虽然 CF 的取值对有符号数运算无意义，但硬件还是会根据如下规则生成 CF 的值：

① 加法运算时，CF 为进位标志，CF = 最高位的进位；

② 减法运算时，CF 为借位标志。将减法转为补码加法，CF = 最高位的进位取反。

**【点评】** 难题。本题考查标志位的生成，题目并未指出是有符号数还是无符号数的减法，需要自行推导。考试时推荐使用解法一，能最快得到正确选项就行。

<Question id="408-b24539-036" type="essay">

【2020】有实现 $ x\times y$ 的两个 C 语言函数如下：

```c
unsigned umul(unsigned x, unsigned y) { return x * y; }
int imul(int x, int y) { return x * y; }
```

假定某计算机 M 中 ALU 只能进行加减运算和逻辑运算。请回答下列问题：

（1）若 M 的指令系统中没有乘法指令，但有加法、减法和位移等指令，则在 M 上也能实现上述两个函数中的乘法运算，为什么？  
（2）若 M 的指令系统中有乘法指令，则基于 ALU、位移器、寄存器以及相应控制逻辑实现乘法指令时，控制逻辑的作用是什么？  
（3）针对以下三种情况：①没有乘法指令；②有使用 ALU 和位移器实现的乘法指令；③有使用阵列乘法器实现的乘法指令。函数 `umul（ ）` 在哪种情况下执行时间最长？哪种情况下执行时间最短？说明理由。  
（4）$ n$ 位整数乘法指令可保存 $ 2n$ 位乘积，当仅取低 $ n$ 位作为乘积时，其结果可能会发生溢出。当 $ n=32$，$ x=2^{31}-1$，$ y=2$ 时，带符号整数乘法指令和无符号整数乘法指令得到的 $ x\times y$ 的 $ 2n$ 位乘积分别是什么？用十六进制表示。此时函数 `umul（ ）` 和 `imul（ ）` 的返回结果是否溢出？对于无符号整数乘法运算，当仅取乘积的低 $ n$ 位作为乘法结果时，如何用 $ 2n$ 位乘积进行溢出判断？

<Solution>

**【解析】**

(1) 乘法运算可以转换为加法运算和移位运算来实现。在计算机中，若没有乘法指令，可以通过多次的加法和移位操作、直到循环次数达到乘数的位数，从而实现乘法指令的功能。

(2) 控制逻辑的作用：控制加法操作和移位操作的次数，并且发出控制信号来执行判断、加法、移位等操作。

(3) 情况①的执行时间最长，情况③的执行时间最短。情况①要用到多条指令的配合来实现乘法运算，每条指令的执行都可能要经过取指、译码、取数、执行和写回这些阶段。因此情况①中要循环执行多条指令，历时多条指令的指令周期，所以其时间最长。情况②和情况③都是使用乘法指令来实现乘法运算，但是乘法指令的实现方式不同。具体来说，情况②使用 ALU、位移器实现，要经过多次加法、移位操作，所以需要多个时钟周期；而使用阵列乘法器实现，通过硬件电路直接输出乘法结果，时间最短。所以情况③执行时间最短，情况②次之，情况①执行时间最长。

(4) ① 这一小问无需知道乘法运算的具体细节，题干已经说明，通过 $n$ 位乘法指令保存 $2n$ 位乘积，若只保存 $n$ 位乘积，则可能会由于截断高 $n$ 位而产生溢出。所以求 $2n$ 位乘积时，可以先将乘积的真值求出来，再扩充至 $2n$ 位机器数即可。

$x\times y=(2^{31}-1)\times2=2^{32}-2$，对应十六进制为 FFFF FFFEH。结果是正数，符号扩展（针对有符号数）或零扩展（针对无符号数）均在高位补 0。所以带符号整数乘法指令和无符号整数乘法指令的 $2n$ 位乘积均为 0000 0000 FFFF FFFEH。

② umul() 和 imul() 的返回值均为截断高 $n$ 位后的末 $n$ 位乘积，为 FFFF FFFEH。$n$ 位乘积解释为无符号数时真值不变，解释为有符号数时发生溢出（因为 FFFF FFFEH 为负数）。所以 umul() 返回结果不溢出，imul() 返回结果溢出。

③ 通过上述分析可知，判断 $n$ 位乘积是否溢出的关键为截断后真值是否发生变化。对于无符号整数乘法运算，当 $2n$ 位乘积的高 $n$ 位全为 0 时，截断高 $n$ 位后真值不发生改变，则结果不溢出，否则溢出。

**【点评】** 难题。主要围绕乘法运算来考查。乘法运算这个考点难度比较大，可能有些考生备考时放弃了对该考点的学习。本题前 3 问还是很常见的，基本属于常识性内容。最后一问比较难理解，难以做对。

</Solution>

</Question>
