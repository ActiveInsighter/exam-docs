# 第 3 章 存储器层次结构

## 3.1 存储器层次结构 (局部性原理)

<Question id="408-2be72e-001" type="single" tags="来源:2017考研408">

某C 语言程序段如下:

```c
for (i = 0; i <= 9; i++) {
    temp = 1;
    for (j = 0; j <= i; j++) temp *= a[j];
    sum += temp;
}
```
   下列关于数组a 的访问局部性的描述中,正确的是（ ）。

<Option correct>时间局部性和空间局部性皆有</Option>
<Option>无时间局部性,有空间局部性</Option>
<Option>有时间局部性,无空间局部性</Option>
<Option>时间局部性和空间局部性皆无</Option>

<Solution>

**【解析】** ① 空间局部性。内层循环 `for(j=0;j<=i;j++) temp *= a[j];` 中，j 从 0 递增到 i，依次访问 a[0]、a[1]、a[2]、…，数组元素在内存中连续存放，访问的是相邻的存储单元，因此具有空间局部性。

② 时间局部性。外层循环 i 从 0 到 9 执行 10 次：i = 0 时访问 a[0]；i = 1 时访问 a[0]、a[1]；i = 2 时访问 a[0]、a[1]、a[2]；…。同一个元素，例如 a[0] 在外层循环中会被反复访问 10 次，a[1] 被访问 9 次，…，即近期访问过的数据很快会再次被访问，因此具有时间局部性。故选 A。

**【提示】** ① 时间局部性指程序中刚被访问过的存储单元，在不久的将来很可能再次被访问，其本质是同一个数据/指令被重复使用。例如：循环结构中的循环变量、循环体内的代码（指令）。

② 空间局部性指程序中刚被访问过的存储单元，其附近（邻近）的存储单元在不久的将来很可能被访问，其访问地址连续或邻近。例如：顺序遍历数组、顺序执行指令。

**【点评】** 概念题。本题考查时间局部性和空间局部性的概念。

</Solution>

</Question>

## 3.2 半导体随机存储器

<Question id="408-2be72e-002" type="single" number={2} tags="来源:2010考研408">

下列有关RAM 和ROM 的叙述中,正确的是（ ）。
I. RAM 是易失性存储器, ROM 是非易失性存储器
II. RAM 和ROM 都采用随机存取方式进行信息访问
III. RAM 和ROM 都可用作Cache
IV. RAM 和ROM 都需要进行刷新

<Option correct>仅I、II</Option>
<Option>仅II、III</Option>
<Option>仅I、II、IV</Option>
<Option>仅II、III、IV</Option>

<Solution>

**【解析】** ① I 正确 ✓：RAM 断电数据会丢失，而 ROM 断电数据不会丢失。

② II 正确 ✓：随机存取的定义是可以按地址直接访问任意存储单元，访问时间与地址无关。尽管部分 ROM 对写入有限制，但 RAM 和 ROM 都支持按地址直接读写。

③ III 错误 ×：Cache 需要频繁读写、速度极快，必须使用可高速读写的 RAM。ROM 只能读不能写（或写入速度极慢），无法满足 Cache 的读写需求，不能用作 Cache。

④ IV 错误 ×：RAM 分为 SRAM 和 DRAM，DRAM 需要定期刷新来保持数据，SRAM 不需要刷新。ROM 不需要刷新，数据可以永久保存。

**【点评】** 概念题。考查 RAM、ROM 的特点，记住了就会。

</Solution>

</Question>

<Question id="408-2be72e-003" type="single" tags="来源:2011考研408">

下列各类存储器中, 不采用随机存取方式的是（ ）。

<Option>EPROM</Option>
<Option correct>CDROM</Option>
<Option>DRAM</Option>
<Option>SRAM</Option>

<Solution>

**【解析】** 随机存取（Random Access）指可直接访问任意地址单元，访问时间与数据位置无关。

① A 选项：EPROM（Erasable Programmable Read-Only Memory），即可擦除可编程只读存储器，属于半导体存储器，支持随机存取。

② B 选项：CDROM（Compact Disc Read-Only Memory），即只读光盘，是一种基于光学存储技术的只读光盘，用户只能读取数据，无法写入、修改或擦除。断电后数据永久保存（非易失性），是早期计算机中最主流的大容量外部存储介质之一（如今已逐步被淘汰）。采用直接存取（半随机）+ 顺序读取的混合方式，不支持真正的随机存取。

③ C 选项：DRAM（Dynamic Random Access Memory），即动态随机存取存储器，断电数据丢失，需要定期刷新。是典型的半导体随机存取存储器（RAM），也是计算机主存（内存条）的主流类型之一。如今笔记本电脑常见的 DDR4 和 DDR5 内存条，都属于 DRAM 的衍生技术。

④ D 选项：SRAM（Static Random Access Memory），即静态随机存取存储器，是一种易失性、高速、随机存取的半导体存储器，是计算机中高速缓存（Cache）的核心载体。故选 B。

**【点评】** 概念题。考查常见的存储器和随机存取的概念。CDROM 较为冷门考点，容易出错。

</Solution>

</Question>

<Question id="408-2be72e-004" type="single" tags="来源:2012考研408">

下列关于闪存(FlashMemory) 的叙述中,错误的是（ ）。

<Option correct>信息可读可写, 并且读、写速度一样快</Option>
<Option>存储元由MOS 管组成,是一种半导体存储器</Option>
<Option>掉电后信息不丢失,是一种非易失性存储器</Option>
<Option>采用随机访问方式,可替代计算机外部存储器</Option>

<Solution>

**【解析】** 闪存是一种非易失性半导体存储器，广泛应用于 SSD、U 盘、手机存储等设备中。闪存支持随机访问（支持直接访问任意地址单元）、读写不对称（读速度远快于写速度，这也是闪存的典型特征）。故选 A。

**【点评】** 概念题。考查冷门考点“闪存”的基本概念。

</Solution>

</Question>

<Question id="408-2be72e-005" type="single" tags="来源:2014考研408">

某容量为256MB 的存储器由若干4M × 8 位的DRAM 芯片构成, 该DRAM 芯片的地址引 脚和数据引脚总数是（ ）。

<Option correct>19</Option>
<Option>22</Option>
<Option>30</Option>
<Option>36</Option>

<Solution>

**【解析】** DRAM 芯片参数：

- 地址引脚：$4\mathrm{M}=2^{22}$，需要 22 位地址寻址。DRAM 芯片的地址线采用分时复用：行地址、列地址分两次送同一组引脚。22 位地址拆成：行 11 位 + 列 11 位。只需要 11 根地址引脚，先送行地址，再送列地址。
- 数据引脚：数据位 8 位，则数据引脚 = 8 根。

地址引脚和数据引脚的总数 = $11+8=19$。故选 A。

**【提示】** ★ ①“某容量为 256MB 的存储器”这句话是干扰信息。② DRAM 芯片的“地址线采用分时复用”，该考点极其生僻，常见教材教辅中都没讲，非科班考生大概率没听说过。但对于科班考生，若本科期间做过类似实验，本题就是送分题。③ DRAM 为了缩小芯片封装体积、降低成本，采用地址复用设计。而 SRAM 无复用、引脚多（有多少位地址就一一对应多少根地址引脚）、成本高。

**【点评】** 冷门考点。考查 DRAM 芯片地址线采用分时复用的特点。本题如果改成“4M×8 位的 SRAM 芯片”，则选 C。

</Solution>

</Question>

<Question id="408-2be72e-006" type="single" tags="来源:2015考研408">

下列存储器中, 在工作期间需要周期性刷新的是（ ）。

<Option>SRAM</Option>
<Option correct>SDRAM</Option>
<Option>ROM</Option>
<Option>FLASH</Option>

<Solution>

**【解析】** ① A 错误 ×：SRAM（静态 RAM）靠触发器（双稳态电路）存储信息，只要不断电，触发器状态就保持稳定。SRAM 的核心特点是“速度快、不需要刷新”，但成本高、集成度低。Cache 和 TLB 通常都用 SRAM 构成。

② B 正确 ✓：SDRAM（同步 DRAM）属于 DRAM（动态 RAM），靠 MOS 管栅极电容上的电荷存储信息。电容会随时间漏电，电荷流失导致信息丢失，因此必须周期性刷新以补充电荷。"SDRAM" 中的 "S" 是 Synchronous（同步），表示其读写操作与系统时钟同步，同步特性不改变其 DRAM 需刷新的本质。

③ C 错误 ×：ROM（只读存储器），信息由制造工艺固化，断电也不丢失，属于非易失存储器，无需刷新。

④ D 错误 ×：FLASH（闪存），基于浮栅结构存储电荷，属于非易失存储器，断电信息不丢失，无需刷新。故选 B。

**【点评】** 概念题。考查常见存储器的基本特性和工作原理。SDRAM 可能大部分考生此前没见过，可基于排除法解题。

</Solution>

</Question>

<Question id="408-2be72e-007" type="single" tags="来源:2018考研408">

假定DRAM 芯片中存储阵列的行数为r、列数为c, 对于一个2K × 1 位的DRAM 芯片, 为保证其地址引脚数最少, 并尽量减少刷新开销, 则r、c 的取值分别是（ ）。

<Option>2048、1</Option>
<Option>64、32</Option>
<Option correct>32、64</Option>
<Option>1、2048</Option>

<Solution>

**【解析】** 对于一个 2K×1 位的 DRAM 芯片，$2\mathrm K=2^{11}=2048$，总共有 2048 个可独立寻址的存储单元，需满足 $r\times c=2048$。根据 DRAM 芯片行列地址分时复用和按行刷新的特性，来分别分析各个选项。

- DRAM 芯片行地址和列地址分时复用同一组地址引脚，地址引脚数 = $\max(\log_2r,\log_2c)$。
- DRAM 芯片按行刷新，刷新开销和行数 $r$ 成正比，行数越少，刷新开销越小。

A 选项：$r=2048,c=1$，$\max(\log_2 2048,\log_2 1)=11$ 根引脚，行数 2048，刷新开销极大。

B 选项：$r=64,c=32$，$\max(\log_2 64,\log_2 32)=\max(6,5)=6$ 根引脚，行数 64。

C 选项：$r=32,c=64$，$\max(\log_2 32,\log_2 64)=\max(5,6)=6$ 根引脚，行数 32。

D 选项：$r=1,c=2048$，$\max(\log_2 1,\log_2 2048)=11$ 根引脚。

B 选项和 C 选项的地址引脚数相同，但 C 选项的行数更小，刷新开销更小。故选 C。

**【点评】** 难题。考查 DRAM 地址复用和按行刷新的特性，要分析题目给出的 4 个选项求解。比较新颖，考生第一次接触时可能无从下手。

</Solution>

</Question>

<Question id="408-2be72e-008" type="single" tags="来源:2022考研408">

某内存条包含8 个8192 × 8192 × 8 位的DRAM 芯片, 按字节编址, 支持突发(burst) 传送 方式,对应存储器总线宽度为64 位,每个DRAM 芯片内有一个行缓冲区(row buffer)。下列关于该内 存条的叙述中, 不正确的是（ ）。

<Option>内存条的容量为512MB</Option>
<Option>采用多模块交叉编址方式</Option>
<Option correct>芯片的地址引脚为26 位</Option>
<Option>芯片内行缓冲有8192 × 8 位</Option>

<Solution>

**【解析】** 由题目中“某内存条包含 8 个 $8192\times8192\times8$ 位的 DRAM 芯片”，可知内存条容量为 $8\times8192\times8192\times8\mathrm{bit}=2^{32}\mathrm{bit}=2^{29}\mathrm{B}=512\mathrm{MB}$，故 A 正确。由“对应存储器总线宽度为 64 位”，$64\mathrm{bit}=8\times8\mathrm{bit}$，一个芯片只能一次性传输 8bit 数据，因此采用 8 体交叉编址方式能实现一次性传输 64bit 的数据，故 B 正确。$8192\times8192=2^{13}\times2^{13}$，DRAM 芯片地址线采用行列地址复用方式，地址引脚为 $26\div2=13$ 位，故 C 错误。行缓冲区占据 DRAM 芯片一行的空间，由题目中“$8192\times8192\times8\mathrm{bit}$”，可得行缓冲区大小为 $8192\times8\mathrm{bit}$，故 D 正确。故选 C。

**【点评】** 常规题。本题全面考查 DRAM。其中，DRAM 采用地址线复用的方式，行地址和列地址分两次传送。该特点在教辅中一般都有总结，竞成的计组中也有着重解释说明。

</Solution>

</Question>

## 3.3 主存储器

<Question id="408-2be72e-009" type="single" number={9} tags="来源:2009考研408">

某计算机主存容量为64KB, 其中ROM 区为4KB, 其余为RAM 区, 按字节编址。现要用 2K × 8 位的ROM 芯片和4K × 4 位的RAM 芯片来设计该存储器, 则需要上述规格的ROM 芯片数和 RAM 芯片数分别是（ ）。

<Option>1、15</Option>
<Option>2、15</Option>
<Option>1、30</Option>
<Option correct>2,30</Option>

<Solution>

**【解析】** 64KB 的空间中 ROM 区为 4KB，故 RAM 区为 60KB。因采用字节编址，故 $2\mathrm{K}\times8$ 位的 ROM 芯片无需位扩展，只需进行字扩展，即 ROM 芯片所需个数为 4K/2K = 2 个。由于 RAM 芯片为 $4\mathrm{K}\times4$ 位，所以需同时进行位扩展与字扩展。1 字节为 8 位，8/4 = 2，故位扩展需 ×2；60K/4K = 15，故字扩展需要 ×15，即 RAM 芯片所需个数为：$1\times2\times15=30$ 个。

**【点评】** 常规题。本题考查主存存储芯片的扩展方式，属于简单的概念题。

</Solution>

</Question>

<Question id="408-2be72e-010" type="single" tags="来源:2010考研408">

假定用若干2K × 4 位的芯片组成一个8K × 8 位的存储器, 则地址0B1FH 所在芯片的最 小地址是（ ）。

<Option>0000H</Option>
<Option>0600H</Option>
<Option>0700H</Option>
<Option correct>0800H</Option>

<Solution>

**【解析】** 组成 $8\mathrm{K}\times8$ 的存储器，需要 $\frac{8\mathrm{K}\times8}{2\mathrm{K}\times4}=8$ 片 $2\mathrm{K}\times4$ 的芯片。进行字位扩展，每 2 片并联形成一组，共 $\frac82=4$ 组。组成的存储器地址长度为 $8\mathrm{K}=2000\mathrm{H}$，从 0 开始编址，则地址范围为 0000H～1FFFH。每组可寻址长度为 $2\mathrm{K}=2^{11}=0800\mathrm{H}$。这 4 组芯片的地址范围为：

| 第一组 | 第二组 | 第三组 | 第四组 |
| --- | --- | --- | --- |
| 0000H～07FFH | 0800H～0FFFH | 1000H～17FFH | 1800H～1FFFH |

$0800\mathrm{H}<0\mathrm{B}1\mathrm{FH}<0\mathrm{FFFH}$，所以地址 0B1FH 所在芯片的最小地址是 0800H。故选 D。

**【点评】** 难题。考查主存芯片扩展、地址计算，综合性较强。首次遇到可能不会做，但如今教辅中一般都有类似例题。

</Solution>

</Question>

<Question id="408-2be72e-011" type="single" tags="来源:2011考研408">

某计算机存储器按字节编址, 主存地址空间大小为64MB, 现用4M × 8 位的RAM 芯片组 成32MB 的主存储器, 则存储器地址寄存器MAR 的位数至少是（ ）。

<Option>22 位</Option>
<Option>23 位</Option>
<Option>25 位</Option>
<Option correct>26 位</Option>

<Solution>

**【解析】** MAR 的位数由主存地址空间的大小决定。主存地址空间为 $64\mathrm{MB}=2^{26}\mathrm{B}$，按字节编址，为了保证能寻址到整个主存地址空间，MAR 至少 26 位。故选 D。

**【点评】** 概念题。本题的难点在于，命题人在此题中精心设计了一些干扰信息：“现用 4M × 8 位的 RAM 芯片组成 32MB 的主存储器”，这些都属于干扰信息。主存物理空间大小是“可扩展”的，例如：笔记本电脑主存物理空间大小是 16GB，加装一个 16GB 的内存条，就可变为 32GB。

</Solution>

</Question>

<Question id="408-2be72e-012" type="single" tags="来源:2015考研408">

某计算机使用4 体交叉编址存储器, 假定在存储器总线上出现的主存地址(十进制) 序列 为8005, 8006, 8007, 8008, 8001, 8002, 8003, 8004, 8000, 则可能发生访存冲突的地址对是（ ）。

<Option>8004 和8008</Option>
<Option>8002 和8007</Option>
<Option>8001 和8008</Option>
<Option correct>8000 和8004</Option>

<Solution>

**【解析】** 低位交叉编址，存储体号 = 主存地址 % 模块数（本题为 4）。先将各地址分配到模块：

| 地址 | 8005 | 8006 | 8007 | 8008 | 8001 | 8002 | 8003 | 8004 | 8000 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 模块号 | 1 | 2 | 3 | 0 | 1 | 2 | 3 | 0 | 0 |

4 体交叉存储器，每隔 1/4 个存储周期启动一个访问，同一模块必须间隔一个完整存储周期才能再次启动。地址 8004 是访问模块 0，地址 8000 也是访问模块 0，连续两次访问模块 0，会发生访存冲突。故选 D。

**【点评】** 常规题。考查多体交叉存储器的访存冲突。

</Solution>

</Question>

<Question id="408-2be72e-013" type="single" tags="来源:2016考研408">

某存储器容量为64KB, 按字节编址, 地址4000H ∼5FFFH 为ROM 区, 其余为RAM 区。 若采用8K × 4 位的SRAM 芯片进行设计, 则需要该芯片的数量是（ ）。

<Option>7</Option>
<Option>8</Option>
<Option correct>14</Option>
<Option>16</Option>

<Solution>

**【解析】** ① ROM 区 4000H～5FFFH 容量 = 5FFFH − 4000H + 1 = 2000H = 8KB。

② RAM 区 = 64KB − 8KB = 56KB。

③ 每片 $8\mathrm K\times4$ 位芯片容量为 4KB（8K × 4bit = 4KB），故需 56KB ÷ 4KB = 14 片。故选 C。

**【点评】** 常规题。本题易错点是：① 地址范围容量计算要“+1”；② $8\mathrm K\times4$ 位是 4KB 不是 8KB（注意位宽是 4 位不是 8 位），需要位扩展和字扩展同时考虑；③ 题目问的是 RAM 芯片数量，不要把 ROM 也算进去。

</Solution>

</Question>

<Question id="408-2be72e-014" type="single" tags="来源:2017考研408">

某计算机主存按字节编址, 由4 个64M × 8 位的DRAM 芯片采用交叉编址方式构成, 并 与宽度为32 位的存储器总线相连, 主存每次最多读写32 位数据。若double 型变量x 的主存地址为 804001AH, 则读取x 需要的存储周期数是（ ）。

<Option>1</Option>
<Option>2</Option>
<Option correct>3</Option>
<Option>4</Option>

<Solution>

## 3.4 外存储器

<Question id="408-2be72e-017" type="single" number={17} tags="来源:2013考研408">

下列选项中, 用于提高RAID 可靠性的措施有（ ）。
I. 磁盘镜像
II. 条带化
III. 奇偶校验
IV. 增加Cache 机制

<Option>仅I、II</Option>
<Option correct>仅I、III</Option>
<Option>仅I、III 和IV</Option>
<Option>仅II、III 和IV</Option>

<Solution>

**【解析】** RAID（Redundant Array of Independent Disks，独立磁盘冗余阵列）是一种将多块物理磁盘组合成一个逻辑单元的磁盘虚拟化技术。其核心目标是在读写性能、可靠性（冗余）和存储利用率三者之间做平衡与取舍。其核心技术是条带化、磁盘镜像和奇偶校验，其简介如下：

- 条带化：将数据分成多个条带分散存储在不同磁盘上，目的是提升读写性能，但不提供冗余。缺点是：任何一块磁盘故障都会导致所有数据丢失，降低了可靠性。
- 磁盘镜像：将数据同时写入两个磁盘，实现数据备份。当其中一块磁盘故障时，另一块仍可正常工作，显著提高了可靠性。
- 奇偶校验：分开存储原始数据和校验数据。当磁盘损坏时，根据剩余数据和校验数据来还原丢失内容，以较低存储空间开销实现磁盘故障容错。低成本的实现磁盘故障容错。

RAID 是磁盘阵列技术总称，这套技术有多种不同实现方案，称为 RAID 级别（RAID Level）。主流常见的 RAID 级别如下：

| RAID 级别 | 核心原理 | 冗余能力 | 性能特点 | 典型应用场景 |
| --- | --- | --- | --- | --- |
| RAID0 | 条带化技术：将数据分块分散写入所有磁盘 | 无冗余，一块盘故障则全阵列数据丢失 | 读写性能最高，完全并行 | 高性能计算、非关键数据临时存储（例如：视频缓存） |
| RAID1 | 磁盘镜像技术：数据同时写入两块磁盘 | 允许 1 块盘故障，数据完整备份 | 读性能提升，写性能与单盘一致 | 系统盘、关键业务数据等对安全性要求极高的场景 |
| RAID5 | 条带化技术 + 分布式奇偶校验技术 | 允许 1 块盘故障，可通过校验重建数据 | 读性能大幅提升，写性能因校验开销略降 | 通用业务场景，兼顾性能、安全与利用率 |
| RAID6 | 条带化技术 + 双奇偶校验技术 | 允许 2 块盘同时故障 | 读性能大幅提升，写性能开销比 RAID5 更高 | 大容量磁盘阵列、数据安全要求更高的场景 |
| RAID 10 | 先做 RAID1 镜像，再做 RAID0 条带化 | 允许每组镜像中各坏 1 块盘 | 读写性能高，冗余能力强 | 数据库、核心业务系统等对性能和可靠性都有极高要求的场景 |

其中，RAID2、RAID3、RAID4 这 3 种已经被彻底淘汰，408 中应该不会考这些被淘汰的技术，所以上表中未介绍。IV 选项中，Cache（高速缓存）作用是缓解速度差，提高读写性能，与可靠性无关。故选 B。

**【点评】** 概念题。RAID 相关考点是冷门考点，考生需要适当留意。

</Solution>

<Question id="408-2be72e-025" type="single" tags="来源:2014考研408">

采用指令Cache 与数据Cache 分离的主要目的是（ ）。

<Option>降低Cache 的缺失损失</Option>
<Option>提高Cache 的命中率</Option>
<Option>降低CPU 平均访存时间</Option>
<Option correct>减少指令流水线资源冲突</Option>

<Solution>

**【解析】** 指令 Cache 与数据 Cache 分离时，在指令流水线中，取指令阶段访问指令 Cache，执行阶段访问数据 Cache。采用两套独立存储、两套独立访问通路，取指令和读写数据可同时并行访问各自 Cache，消除端口争抢，减少流水线资源冲突。

若指令、数据共用同一个 Cache，在指令流水线中，同一时钟周期内取指令和读写数据会争抢唯一的 Cache 访问端口，引发资源冲突、造成流水线停顿。故选 D。

- A 选项：Cache 缺失损失主要取决于主存速度、替换策略等。
- B 选项：Cache 分离后，指令 Cache 和数据 Cache 各自容量减半，反而可能降低命中率。这是分离式设计的一个代价，而非目的。
- C 选项：Cache 分离后可能因命中率下降而增加访存时间。

**【拓展】** ①“冯·诺依曼架构”的核心设计思想是“存储程序”，指令和数据以同等地位存于同一存储器。即：指令和数据共享同一存储空间和总线。其优点是结构简单、成本低、通用性强，其缺点是取指令和访存操作无法并行执行，存在理论层面的访存冲突瓶颈（现代 CPU 通过 Cache 等技术已大幅缓解）。

②“哈佛架构”的核心设计思想是指令和数据分开存储，并且各自拥有独立的存储器（指令存放在程序存储器中，数据存放在数据存储器）和总线。其优点是可同时取指令、读写数据，并行执行（适合流水线），吞吐率高。缺点是硬件复杂度高、不支持程序自我修改（因为“哈佛架构”程序必须预先固化在指令 ROM 中）和动态加载（指程序运行时，才把代码从外存调入内存执行），难以运行现代通用操作系统。

③“改进型哈佛架构”是上述两种架构的折中方案：在 CPU 内部指令 Cache 和数据 Cache 分离，在 CPU 外部指令和数据统一存储。“改进型哈佛架构”兼顾性能与灵活性，是现代 CPU 的事实标准。目前主流的手机 CPU（例如：高通骁龙、联发科、苹果 A 系列和 M 系列）都是采用“改进型哈佛架构”。

**【点评】** 常规题。本题考查“哈佛架构”的设计思想。

</Solution>

<Question id="408-2be72e-029" type="single" tags="来源:2022考研408">

<Option correct>8,20</Option>
<Option>8,23</Option>
<Option>64,20</Option>
<Option>64,23</Option>

<Solution>

**【解析】** ① 按字节编址，主存块大小 64B，可知块内地址为 $\log_2 64=6$ 位。由 Cache 数据区容量 32KB，得到 Cache 块总数为 $32\mathrm{KB}\div64\mathrm{B}=512$ 块。题目中采用 8 路组相联映射方式，因此每 8 个 Cache 块为一组，共有 $512\div8=64$ 个 Cache 组，因此组号为 $\log_2 64=6$ 位。已知主存地址为 32 位，由 Cache 的地址结构知，剩下 $32-6-6=20$ 位均为 Tag 位。

② 在组相联映射中，查找同组内的所有 Cache 块中是否有系统要找的块，为了加快查找速度（并行查找），**比较器个数等于每组的路数**。本题中一组有 8 个块（8 路），所以比较器的个数为 8 个。在访问某物理地址时，根据组号找到某一分组后，再用物理地址的高 20 位与 Cache 行的 Tag 位做比较，若两者相同，则选中此 Cache 行。**比较器的位数等于物理地址中标记（tag）字段的位数**，为 20 位。故选 A。

<Question id="408-2be72e-038" type="single" tags="来源:2015考研408">

假定编译器将赋值语句“x = x + 3;”转换为指令“add xaddr, 3”, 其中xaddr 是x 对应的存储单元地址。若执行该指令的计算机采用页式虚拟存储管理方式,并配有相应的TLB,且Cache 使用直写(Write Through) 方式,则完成该指令功能需要访问主存的次数至少是（ ）。

<Option>0</Option>
<Option correct>1</Option>
<Option>2</Option>
<Option>3</Option>

<Solution>

**【解析】** 指令“`add xaddr,3`”的功能：将 x 对应存储单元处的数据加 3 后，再写回 x 对应的存储单元。执行过程如下：

① 取指：CPU 根据虚拟地址去访存，TLB 命中，完成虚拟地址到物理地址的转换。根据物理地址访存时，Cache 命中，从 Cache 中获取指令内容。若 TLB 和 Cache 均命中，则取指阶段无需访问内存。

② 取数：从主存取出操作数 x。若 x 已在 Cache 中（Cache 命中），则直接从 Cache 读取，不访问主存；题目问“至少”，按 Cache 命中情形考虑，此步访存 0 次。

④ 写回：将运算结果写入 x 对应的存储单元。直写法（Write Through）的特点是：写 Cache 命中的同时必须把数据写入主存，以保证 Cache 与主存内容一致。因此即使写 Cache 命中，也必须访问主存 1 次。

<Question id="408-2be72e-041" type="single" tags="来源:2022考研408">

某计算机主存地址为24 位, 采用分页虚拟存储管理方式, 虚拟地址空间大小为4GB, 页大小为4KB, 按字节编址。某进程的页表部分内容如下表所示。当CPU 访问虚拟地址00082840H 时, 虚实地址转换的结果是（ ）．

| 虚页号 | 实页号（页框号） | 存在位 |
| --- | --- | --- |
| 82 | 024H | 0 |
| ... | ... | ... |
| 129 | 180H | 1 |
| 130 | 018H | 1 |

<Option>得到主存地址024840H</Option>
<Option>得到主存地址180840H</Option>
<Option correct>得到主存地址018840H</Option>
<Option>检测到缺页异常</Option>

<Solution>

**【解析】** 由页大小为 4KB、按字节编址，可得页内地址为低 $\log_2 4096=12$ 位。又因为虚拟地址空间大小为 $4\mathrm{GB}=2^{32}\mathrm{B}$，$\log_2 2^{32}=32$，即虚拟地址有 32 位。虚页号为高 $32-12=20$ 位。当 CPU 访问虚拟地址 0008 2840H 时，高 20 位为 00082H，转换为十进位为 130，因此访问页表里虚页号 130 所在的表项，该表项的实页号位 018H，且存在位为 1，说明存在。因此将实页号 018H 与页内地址 840H 拼接，得到实地址 01 8840H，故选 C。

**【点评】** 常规题。这是一道常见的考查虚实地址转换的题目。但是有坑，很容易误选 D。虚拟地址 0008 2840H，低 12 位为页内地址，高 20 位 00082H 为虚页号。根据 82 去查给出的页表，发现存在位为 0，所以缺页异常，从而选 D。可能考场上很多考生都这样选了 D。其实错的挺冤的。题目页表给出的虚页号末尾没有带 H，开头也没有 0x，所以题目给出的虚页号是十进制。82H 的十进制是 $8\times16+2=130$，要用虚页号 130 去查页表。这题如此设置坑点，我们认为“欠妥”，为了出题而出题。因为在计算机真实执行时肯定不会转化成十进制去查页表的，408 这种选拔性考试应该回归知识本身，考查灵活运用，选 D 的同学应该也是掌握了该考点的。

</Solution>

</Question>

<Question id="408-2be72e-042" type="single" tags="来源:2024考研408">

某计算机按字节编址, 采用页式虚拟存储管理方式, 虚拟地址为32 位, 主存地址为30 位, 页大小为1KB。若TLB 共有32 个表项,采用4 路组相联映射方式,则TLB 表项中标记字段的位数至少是（ ）。

<Option>17</Option>
<Option>18</Option>
<Option correct>19</Option>
<Option>20</Option>

<Solution>

**【解析】** TLB 中标记字段是由页号的高位所组成，即：虚拟地址的高位减去表示组号的位。页大小为 1KB，计算机按字节编址，$1\mathrm{KB}=2^{10}\mathrm{B}$，因此页内偏移为 10 位。由 4 路组相联映射，可得出组数 $=32/4=8=2^3$，故组号为 3 位。则 TLB 表项中标记字段位数至少是：$32-10-3=19$。

**【点评】** 常规题，但有一定创新。即使 “TLB 采用 4 路组相联映射方式” 这个说法此前没听说过，也能类比 Cache 和主存的组相联映射方式做出来。

</Solution>

<Question id="408-2be72e-043" type="single" tags="来源:2024考研408">

下列事件中, 不是在MMU 地址转换过程中检测的是（ ）。

<Option>访问越权</Option>
<Option correct>Cache 缺失</Option>
<Option>页面缺失</Option>
<Option>TLB 缺失</Option>

<Solution>

**【解析】** 在地址转换过程中，如果页内偏移大于一整页，则会出现访问越界。访问越界是指程序试图访问的内存位置超出了其合法或已分配的范围。而访问越权通常发生在权限控制不当的情况下，指的是用户或程序以未经授权的方式访问系统中的资源或执行操作。如果某一页不在主存中，则会出现页面缺失。MMU 地址转换机构采用快表涉及 TLB 访问时也能出现 TLB 缺失的情况。MMU 地址转换是由虚拟地址转换为物理地址的过程，而访问 Cache 是得到物理地址之后，因此不会在 MMU 转换过程中检测到。

**【提示】** 内存管理单元 MMU（Memory Management Unit）的主要功能是虚实地址转换、内存保护和 Cache 等，是一种负责处理中央处理器（CPU）的内存访问请求的计算机硬件。

**【点评】** 常规题。考查基本概念。

</Solution>

</Question>
