# 第 1 章 计算机系统概述

## 1.1 计算机系统层次结构

<Question id="408-4d88ad-001" type="single" tags="来源:2009考研408">

冯·诺伊曼计算机中指令和数据均以二进制形式存放在存储器中，CPU 区分它们的依据是（ ）。

<Option>指令操作码的译码结果</Option>
<Option>指令和数据的寻址方式</Option>
<Option correct>指令周期的不同阶段</Option>
<Option>指令和数据所在的存储单元</Option>

<Solution>

**【解析】** 指令周期可分为取指周期、间址周期、执行周期和中断周期。CPU 在取指周期从存储器中取指令，在执行周期会根据指令的寻址方式，从寄存器 / 存储器 / 立即数中获取操作数进行运算。CPU 能根据指令周期的不同阶段来分辨是指令还是数据。故选 C。

**【点评】** 常规题。考查冯·诺依曼机的基本概念。

</Solution>

<Question id="408-4d88ad-002" type="single" tags="来源:2015考研408">

计算机硬件能够直接执行的是（ ）。  
I. 机器语言程序  
II. 汇编语言程序  
III. 硬件描述语言程序

<Option correct>仅 I</Option>
<Option>仅 I、II</Option>
<Option>仅 I、III</Option>
<Option>I、II 和 III</Option>

<Solution>

**【解析】** ① I. 机器语言程序由二进制指令构成，是计算机硬件唯一可以直接识别、直接执行的语言。例如：机器语言程序代码 `6a 27 58 0f 05 48 97 6a 3c 58 0f 05`，实现的功能是：获取当前进程 PID，并以该 PID 作为状态码退出进程。故选 A。

② II. 汇编语言（Assembly Language）是机器语言的符号化表示。它用人类易记的助记符（例如：MOV、ADD）代替二进制机器指令的操作码，用符号地址（例如：LOOP、DATA）代替物理地址，一条汇编指令通常对应一条机器指令。汇编语言是一种与具体 CPU 架构紧密相关的低级程序设计语言，不同处理器架构（例如：x86、ARM、RISC-V 等）拥有完全不同的汇编指令集，彼此互不通用。汇编语言程序不能被计算机硬件直接执行，必须通过“汇编器”翻译成二进制机器码，才能在 CPU 上运行。

② III. 硬件描述语言（HDL, Hardware Description Language）是一种用于描述数字电路结构和行为的专门语言，它不是传统意义上的“编程语言”，而是“描述语言”：描述的是硬件如何连接、如何工作（本质是用文本“画电路”）。目前行业内最主流的两类基础 HDL 分别是 Verilog 和 VHDL。

**【点评】** 概念题。编程语言有很多种，但计算机硬件能直接执行的只有机器语言。这个考点在 408 中多次考到过。本题列举了“硬件描述语言”这个生僻的语言，类似的考法还有：再列举一个在小众专业领域应用广泛，但考生普遍没听说过的语言作为干扰项，比如 COBOL、Tcl 等。

**【拓展】** 掌握基础的汇编语言语法，对备考 408 是非常重要的。因为 408 中的计组大题，经常给一段 C 语言代码，分析其在计算机中的底层执行过程。通常是默认考生已经学过汇编语言。一个完整可上机执行的入门级汇编语言代码实例如下，考生可对比注释学习：

```asm
; 这段程序的功能是：向屏幕输出一行字符串，随后正常退出程序
section .data        ; 段定义伪指令，用于划分程序的不同内存区域。
    ; msg标记这段数据的内存起始地址；db是数据定义伪指令，按字节分配内存；
    ; 'Hello, Assembly!'是字符串；0Ah指换行符\n，作用是打印完字符串后光标换行。
    msg db 'Hello, Assembly!', 0Ah
    ; len是自定义符号名；equ是等值伪指令，在编译阶段给符号len绑定一个固定数值；
    ; $是汇编器内置的“当前地址计数器”，代表执行到这一行时，当前所处的内存偏移地址。
    len equ $ - msg

section .text        ; 代码段，专门存放程序的执行指令
    ; Linux的链接器默认以_start作为程序的入口地址，必须用global声明。
    ; _start等价于C语言的main函数的入口标识。
    global _start

; _start是程序入口标号，_start是整个程序第一条执行指令的地址。
; 操作系统加载程序后，CPU 会从这个地址开始取指令运行。
_start:
    ; --- write 系统调用：输出字符串 ---
    mov rax, 1        ; 把立即数1存入rax寄存器
    ; 把立即数1存入rdi寄存器。1是 Linux 中“标准输出”的文件描述符，表示向屏幕输出。
    mov rdi, 1
    ; 把字符串的首地址msg存入rsi，告诉内核要输出的数据在内存中的位置。
    mov rsi, msg
    mov rdx, len      ; 把字符串长度len存入rdx，告诉内核“要输出多少个字节”。
    ; 内核根据rax中的调用号，读取对应寄存器的参数，
    ; 执行“向标准输出打印字符串”的操作，完成后返回用户态继续执行下一条指令。
    syscall

    ; --- exit 系统调用：程序退出 ---
    ; 把立即数60存入rax。Linux中，系统调用编号60表示exit（程序退出）。
    mov rax, 60
    ; 把立即数0存入rdi。0表示程序正常退出，非0代表程序异常退出，此值会返回给操作系统。
    mov rdi, 0
    ; 触发 exit 系统调用，程序终止运行，控制权交还给操作系统，不会再执行后续代码。
    syscall
```

一、考生可能会有疑问，为什么上述汇编代码中出现了 2 次 syscall？其实，Linux 中 syscall 是用户态程序进入内核态的唯一入口，具体进入内核态执行什么操作，由触发前 rax 寄存器里的系统调用号决定。

二、建议考生在 linux 上动手运行上述代码，运行步骤如下：

① 第一步：先安装汇编器 nasm（安装命令：`sudo yum install nasm`），将上述代码保存到文件 `hbtest.asm` 中。

② 编译运行命令如下：

```bash
# 1. 汇编为目标文件
nasm -f elf64 hbtest.asm -o hbtest.o
# 2. 链接为可执行文件
ld hbtest.o -o hbtest
# 3. 运行
./hbtest
```

③ 上述代码运行后，会在屏幕显示字符串 "Hello, Assembly!"。

<Question id="408-4d88ad-003" type="single" tags="来源:2016考研408">

将高级语言源程序转换为机器级目标代码文件的程序是（ ）。

<Option>汇编程序</Option>
<Option>链接程序</Option>
<Option correct>编译程序</Option>
<Option>解释程序</Option>

<Solution>

**【解析】** ① 汇编程序将汇编语言源程序翻译成机器语言目标代码。

② 链接程序将编译 / 汇编生成的多个目标代码模块（例如：.obj / .o）和库文件组合起来，解决模块间的相互引用，生成可执行文件（例如：.exe 文件）。链接程序主要完成符号解析和重定位等工作。

- 符号解析：一个模块调用了另一个模块的函数 / 变量，链接器负责找到它们的定义
- 重定位：各模块编译时都假设自己从地址从 0 开始，链接器重新分配实际内存地址。

③ 编译程序将高级语言源程序（C/C++/Java 等）整体翻译成等价的机器级目标代码。

④ 解释程序对高级语言源程序逐句（或逐条）翻译并立即执行，不生成目标代码文件。故选 C。

**【点评】** 概念题。考查编译程序、汇编程序、解释程序、链接程序的基本概念。

</Solution>

## 1.2 计算机性能指标

<Question id="408-4d88ad-008" type="single" number={1} tags="来源:2010考研408">

下列选项中，能缩短程序执行时间的措施是（ ）。  
I. 提高 CPU 时钟频率  
II. 优化数据通路结构  
III. 对程序进行编译优化

<Option>仅 I、II</Option>
<Option>仅 I、III</Option>
<Option>仅 II、III</Option>
<Option correct>I、II、III</Option>

<Solution>

**【解析】** I 正确：CPU 时钟频率越高，CPU 时钟周期越短，完成相同指令所需的时间就越短。

II 正确：数据通路是 CPU 内部指令执行的硬件路径。优化结构（如缩短关键路径、减少流水线阻塞、优化运算单元布局）可以降低单条指令的时钟周期数（CPI），从而提升执行效率、缩短程序运行时间。

III 正确：编译器优化（如常量折叠、循环展开、指令重排、寄存器分配优化）可以减少程序的指令条数、提升指令执行效率，直接减少 CPU 需要执行的总指令数，大幅缩短程序执行时间。

**【点评】** 常规题。考查灵活运用，运用所学进行分析。

</Solution>

<Question id="408-4d88ad-010" type="single" tags="来源:2012考研408">

假定基准程序 A 在某计算机上的运行时间为 $100\text{s}$，其中 $90\text{s}$ 为 CPU 时间，其余为 I/O 时间。若 CPU 速度提高 $50\%$，I/O 速度不变，则运行基准程序 A 所耗费的时间是（ ）。

<Option>$55\text{s}$</Option>
<Option>$60\text{s}$</Option>
<Option>$65\text{s}$</Option>
<Option correct>$70\text{s}$</Option>

<Solution>

**【解析】** ① 程序 A 原运行总时间为 100s，其中 CPU 时间 90s，I/O 时间为 $100-90=10\text{s}$。② CPU 速度提高 50%，则新的 CPU 速度是原来的 1.5 倍，完成相同 CPU 任务所需时间与速度成反比。则 CPU 提速后，运行程序 A 的 CPU 时间为 $\frac{90}{1.5}=60\text{s}$。③ I/O 速度不变，因此 I/O 时间仍为 10s。总时间为 $60+10=70\text{s}$。故选 D。

<Question id="408-4d88ad-012" type="single" tags="来源:2014考研408">

程序 P 在机器 M 上的执行时间是 20 秒，编译优化后，P 执行的指令数减少到原来的 $70\%$，而 CPI 增加到原来的 $1.2$ 倍，则 P 在 M 上的执行时间是（ ）。

<Option>8.4 秒</Option>
<Option>11.7 秒</Option>
<Option>14 秒</Option>
<Option correct>16.8 秒</Option>

<Solution>

**【解析】** CPI 指平均执行一条指令所需的时钟周期数。执行时间 = 指令条数 × CPI × 单个时钟周期时长。设编译优化前的 CPI = $m$，指令条数 = $n$，单个时钟周期时长 = $t$，则执行时间 = $m\times n\times t=20\mathrm{s}$。编译优化后，CPI = $1.2m$，指令条数 = $0.7n$，则执行时间 = $1.2m\times0.7n\times t=0.84mnt=0.84\times20\mathrm{s}=16.8\mathrm{s}$。故选 D。

**【点评】** 常规题。考查计算机的性能指标。本题只要知道了 CPI 的含义，就是一道小学数学题。

</Solution>

<Question id="408-4d88ad-013" type="single" tags="来源:2017考研408">

假定计算机 M1 和 M2 具有相同的指令集体系结构（ISA），主频分别为 $1.5\text{GHz}$ 和 $1.2\text{GHz}$。在 M1 和 M2 上运行某基准程序 P，若平均 CPI 分别为 2 和 1，则程序 P 在 M1 和 M2 上运行时间的比值是（ ）。

<Option>0.4</Option>
<Option>0.625</Option>
<Option correct>1.6</Option>
<Option>2.5</Option>

<Solution>

**【解析】** ① 因为计算机 M1、M2 的 ISA 相同，运行同一个程序 P，所以程序 P 在 M1 和 M2 上的指令数 N 相同。② 时钟周期 = $\frac{1}{\text{主频}}$，程序的运行时间 = 指令数 × CPI × 时钟周期。

③ 则程序 P 在 M1 和 M2 上运行时间的比值 = $\frac{N\times2\times\frac{1}{1.5\mathrm{G}}}{N\times1\times\frac{1}{1.2\mathrm{G}}}=2\times\frac{1.2}{1.5}=\frac{8}{5}=1.6$。故选 C。

**【点评】** 概念题。考查主频、CPI 等常见的计算机性能指标。

</Solution>

<Question id="408-4d88ad-014" type="single" tags="来源:2020考研408">

下列给出的部件中，其位数（宽度）一定与机器字长相同的是（ ）。  
I. ALU  
II. 指令寄存器

<Question id="408-4d88ad-016" type="single" tags="来源:2022考研408">

某计算机主频为 $1\text{GHz}$，程序 P 运行过程中，共执行了 10000 条指令，其中，$80\%$ 的指令执行平均需 1 个时钟周期，$20\%$ 的指令执行平均需要 10 个时钟周期。程序 P 的平均 CPI 和 CPU 执行时间分别是（ ）。

<Option correct>$2.8,\ 28\mu\text{s}$</Option>
<Option>$28,\ 28\mu\text{s}$</Option>
<Option>$2.8,\ 28\text{ms}$</Option>
<Option>$28,\ 28\text{ms}$</Option>

<Solution>

**【解析】** 由题意知，80% 的指令执行平均需要 1 个时钟周期，20% 的指令执行平均需要 10 个时钟周期，得到 $\mathrm{CPI}=80\%\times1+20\%\times10=2.8$，排除 B、D。由于程序 P 一共执行 10000 条指令，计算机主频 1GHz，时钟周期 $=\frac{1}{1\mathrm{GHz}}=10^{-9}\mathrm{s}$。前面得到每条指令的执行平均要 2.8 个时钟周期，即平均执行一条指令需要 $2.8\times10^{-9}\mathrm{s}$。由此得到 CPU 执行时间 $=(10000\times2.8\times10^{-9})\mathrm{s}=28\mu\mathrm{s}$。故选 A。

</Solution>

<Question id="408-4d88ad-017" type="single" tags="来源:2023考研408">
