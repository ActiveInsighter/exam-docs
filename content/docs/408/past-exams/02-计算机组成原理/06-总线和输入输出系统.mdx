# 第 6 章 总线和输入输出系统


## 6.1 总线

<Question id="408-7c4a2e-001" type="single">

【2009】假设某系统总线在一个总线周期中并行传输4B 信息, 一个总线周期占用2 个时钟周期, 总线时钟频率为10MHz, 则总线带宽是（ ）。

<Option>10MB/s</Option>
<Option correct>20MB/s</Option>
<Option>40MB/s</Option>
<Option>80MB/s</Option>

<Solution>

**【解析】** 总线时钟频率：在总线中，用于定时的公共时钟信号的频率。题目中给出总线时钟频率为 10MHz，总线时钟周期是总线时钟频率的倒数：$\frac{1}{10\mathrm{MHz}}=10^{-7}\mathrm{s}$。由题目条件可知，总线周期为 $2\times10^{-7}\mathrm{s}$，故总线带宽 = $\frac{4\mathrm{B}}{2\times10^{-7}\mathrm{s}}=20\mathrm{MB/s}$。

**【点评】** 常规题。计算总线带宽是 408 中的高频考点。408 考试中，经常“捏造”一个场景，添加一些“干扰信息”，再要求计算总线带宽。本题的干扰信息在于题目条件“一个总线周期占用 2 个时钟周期”，这里“2 个时钟周期”指的是“2 个总线时钟周期”。通常，在计算总线带宽的题目中，若仅给出“时钟频率”、未标注 CPU 主频，则默认该频率为总线时钟频率，默认时钟周期为总线时钟周期。若涉及 CPU 时钟，题目必须明确给出两者之间的关系。

</Solution>

</Question>

<Option>PCI、CRT、USB、EISA</Option>
<Option>ISA、CPI、VESA、EISA</Option>
<Option>ISA、SCSI、RAM、MIPS</Option>
<Option correct>ISA、EISA、PCI、PCI-Express</Option>

① A 错误 ×：CRT 是使用阴极射线管的显示器。

② B 错误 ×：ISA 是指令集体系结构，CPI 是平均每条指令的平均时钟周期个数。

③ C 错误 ×：RAM 是半导体随机存储器，MIPS 是每秒执行多少百万条指令数。故选 D。

**【点评】** 概念题。“总线标准”这个考点虽然在最新的 408 纲中已删除，但考生需要了解一些常见名词缩写的含义，例如：ISA、CPI、RAM、MIPS 的含义。

</Solution>

</Question>

<Question id="408-7c4a2e-003" type="single">

【2011】在系统总线的数据线上, 不可能传输的是（ ）。

<Option>指令</Option>
<Option>操作数</Option>
<Option correct>握手(应答) 信号</Option>
<Option>中断类型号</Option>

<Solution>

**【解析】** 系统总线通常分为 3 类：数据总线、地址总线、控制总线，其相关总结如下表所示。

① A 选项：指令本质上也是数据，取指时会通过数据总线传输。

② B 选项：操作数通常是从内存中读/写，直接通过数据总线传输。

③ C 选项：握手（应答）信号这类控制信号属于控制总线的职责，不会出现在数据总线上。

④ D 选项：中断响应时，设备会将中断类型号通过数据总线发送给 CPU。故选 C。

**【拓展】** 中断类型号（Interrupt Type Number），是 x86 架构中用来标识不同中断/异常源的一个 8 位无符号整数，范围 0～255，是中断机制的核心标识。例如：中断类型号为 0，表示除法错误异常。CPU 收到中断请求后，会用中断类型号去查中断向量表，找到对应的中断服务程序的入口地址，从而跳转到正确的处理程序。通俗的说，中断类型号是中断的“身份证号”，用来告诉 CPU “是谁在请求中断”。

| 总线类型 | 传输方向 | 核心作用 | 典型传输内容 |
| --- | --- | --- | --- |
| 数据总线 | 双向 | 传输数据信息，实现 CPU、内存、外设之间的数据交换 | 操作数、中断类型号、指令、设备状态数据 |
| 地址总线 | 单向（CPU → 设备） | 传输内存/IO 设备的地址信息，用来指明数据要访问的目标位置，是单向通道（CPU 发地址） | 内存单元地址、I/O 端口地址 |
| 控制总线 | 单向/双向混合 | 传输控制信号与时序信号，协调各部件的工作节奏与操作，是总线的“指挥系统”，包含单向和双向信号 | 读写信号、握手应答信号、中断请求/响应信号 |

**【点评】** 难题。考查系统总线的概念，考的很细。

</Solution>

</Question>

<Question id="408-7c4a2e-004" type="single">

【2012】某同步总线的时钟频率为100MHz, 宽度为32 位, 地址/ 数据线复用, 每传输一个地址或数据占用一个时钟周期。若该总线支持突发(猝发) 传输方式,则一次“主存写”总线事务传输128 位数据所需要的时间至少是（ ）。

<Option>20ns</Option>
<Option>40ns</Option>
<Option correct>50ns</Option>
<Option>80ns</Option>

<Solution>

**【解析】** 突发（猝发）传输是一种总线/内存优化传输模式，核心是传一次地址，连续传输多笔数据，大幅减少地址/控制信号的开销，提升总线效率。突发传输工作流程如下：

- 地址阶段（仅传 1 次）：主设备（例如：CPU）发送起始地址 + 传输长度，占用 1 个时钟周期。从设备（例如：内存）收到地址后，自动按顺序生成后续数据的地址。
- 数据阶段（连续多笔）：总线不再重复发送地址，仅连续传输数据。每笔数据仅需 1 个时钟周期，地址从设备内部自动递增。
- 事务结束：约定数量的数据传输完成后，总线事务结束。

时钟周期为主频的倒数，由于总线的时钟频率为 100MHz，所以时钟周期 $=\frac{1}{100\text{M}}=10\text{ns}$。总线宽度为 32 位（即每次传 32 位），需传输 128 位数据，数据传输次数为：$\frac{128\text{ bit}}{32\text{ bit/次}}=4$ 次。每次数据传输占用 1 个时钟周期，传数据共占用 4 个时钟周期（40 ns）。传地址需要一个时钟周期 10ns，总共需要 $10\text{ns}+40\text{ns}=50\text{ns}$。

**【提示】** 此题易错点是：地址/数据复用意味着地址和数据不能同时传输，必须分阶段占用总线，所以传地址需要一个时钟周期。容易错选 B。

**【点评】** 易错题。若此前不了解“突发传输”的概念，则此题极易出错。

</Solution>

</Question>

<Question id="408-7c4a2e-005" type="single">

【2012】下列关于USB 总线特性的描述中,错误的是（ ）。

<Option>可实现外设的即插即用和热拔插</Option>
<Option>可通过级联方式连接多台外设</Option>
<Option>是一种通信总线,连接不同外设</Option>
<Option correct>同时可传输2 位数据,数据传输率高</Option>

<Solution>

**【解析】** USB 是一种串行传输（每次仅传输 1 位数据）、即插即用与热插拔、最多接入 127 台外设、不同版本支持不同传输速率、多种传输模式（控制传输、批量传输、中断传输、同步传输）、可总线供电（接口可提供电源）、主机主导通信（所有传输均由主机发起）的通用外设总线。故选 D。

**【提示】** USB 的级联方式指的是通过 USB Hub（集线器）将一台 USB 设备扩展为多个端口，从而连接更多外设的多层扩展方式。

**【点评】** 概念题。考查 USB 总线特性。

</Solution>

<Question id="408-7c4a2e-006" type="single">

【2012】下列选项中，在 I/O 总线的数据线上传输的信息包括（ ）。

I. I/O 接口中的命令字  
II. I/O 接口中的状态字  
III. 中断类型号

<Option>仅 I、II</Option>
<Option>仅 I、III</Option>
<Option>仅 II、III</Option>
<Option correct>I、II、III</Option>

<Solution>

**【解析】** ① I/O 接口中的命令字：CPU 通过数据线向 I/O 接口发送控制命令（如读/写指令、模式配置），命令字是典型的数据线传输信息。② I/O 接口中的状态字：I/O 接口通过数据线向 CPU 反馈设备状态（如忙/闲、错误标志），状态字也由数据线传输。③ 中断类型号：外设向 CPU 发送中断请求时，会通过数据线传输中断类型号，供 CPU 识别中断源并跳转至对应的中断服务程序。故选 D。

**【拓展】** ① 中断类型号（Interrupt Type Number），是 x86 架构中用来标识不同中断/异常源的一个 8 位无符号整数，范围 0～255，是中断机制的核心标识。例如：中断类型号为 0，表示除法错误异常。CPU 收到中断请求后，会用中断类型号去查中断向量表，找到对应的中断服务程序的入口地址，从而跳转到正确的处理程序。通俗的说，中断类型号是中断的“身份证号”，用来告诉 CPU“是谁在请求中断”。

② 所有总线（包括系统总线、I/O 总线等）上的信号都可以按逻辑功能抽象为以下三类：

- 地址信号：指明访问的设备/端口地址，在地址线上传输。
- 数据信号：双向传输的所有数据、命令、状态，在数据线上传输。
- 控制信号：控制读写时序、握手、中断等，在控制线上传输。

但在总线物理实现时，物理上通常并没有独立的三根线，而是通过同一组线路分时复用传输地址、数据、控制信号。

**【点评】** 概念题。本题可以和 2011 年 408 第 20 题对比学习，考的是同类考点。

</Solution>

</Question>

<Question id="408-7c4a2e-008" type="single">

【2014】某同步总线采用数据线和地址线复用方式,其中地址/ 数据线有32 根,总线时钟频率为66MHz, 每个时钟周期传送两次数据(上升沿和下降沿各传送一次数据), 该总线的最大数据传输率(总线带宽) 是（ ）。

<Option>132MBps</Option>
<Option>264MBps</Option>
<Option correct>528MBps</Option>
<Option>1056MBps</Option>

<Solution>

**【解析】** ① 分析单次传输字节数：地址 / 数据线复用，共 32 根，一次可以并行传输 32 位（4B）数据。② 计算每秒数据传输次数：总线时钟频率为 66MHz，表示每秒有 66M 个时钟周期。每个时钟周期传送两次数据，则每秒数据传输次数 = $66\mathrm{M}\times2=132\mathrm{M}$。③ 计算总线带宽：总线带宽 = 每秒数据传输次数 × 单次传输字节数 = $132\mathrm{M}\times4\mathrm{B}=528\mathrm{MB/s}$。故选 C。

**【点评】** 常规题。根据总线带宽的计算公式，按照题目条件一步步计算即可。基于一个陌生的场景，考带宽计算，类似的题在 408 中经常考查。

</Solution>

</Question>

【2014】一次总线事务中, 主设备只需给出一个首地址, 从设备就能从首地址开始的若干连续单元读出或写入多个数据。这种总线事务方式称为（ ）。

<Option>并行传输</Option>
<Option>串行传输</Option>
<Option correct>突发传输</Option>
<Option>同步传输</Option>

<Question id="408-7c4a2e-010" type="single">

【2015】下列有关总线定时的叙述中,错误的是（ ）。

<Option>异步通信方式中, 全互锁协议最慢</Option>
<Option>异步通信方式中, 非互锁协议的可靠性最差</Option>
<Option correct>同步通信方式中, 同步时钟信号可由各设备提供</Option>
<Option>半同步通信方式中,握手信号的采样由同步时钟控制</Option>

<Solution>

**【解析】** ① A 正确 ✓：全互锁协议中，主设备发出请求后必须等从设备应答，从设备应答后主设备还要撤销请求，从设备再撤销应答，四次握手，速度最慢但最可靠。

② B 正确 ✓：非互锁协议中，主设备发出请求后经过一段时间自行撤销，不等待从设备确认，从设备也不知道主设备是否收到应答，握手最简略，速度最快，但双方都无法确认对方状态，可靠性最差。

③ C 错误 ×：同步通信方式的核心特征是所有设备在统一的系统时钟节拍下协调工作，时钟必须由系统（总线）统一提供。若各设备各自提供时钟，时钟频率、相位各不相同，就失去了“同步”的前提，通信将无法正常协调。

④ D 正确 ✓：半同步通信以同步通信为基础（有统一时钟），但增设了 WAIT（等待）握手信号。在时钟边沿采样 WAIT 信号，若从设备未准备好，主设备就插入等待周期。即握手信号的采样由同步时钟控制，兼具同步的简单与异步的灵活。故选 C。

**【点评】** 冷门考点。综合考查四种总线定时方式的核心特征。

</Solution>

</Question>

<Question id="408-7c4a2e-011" type="single">

【2016】下列关于总线设计的叙述中,错误的是（ ）。

<Option correct>并行总线传输比串行总线传输速度快</Option>
<Option>采用信号线复用技术可减少信号线数量</Option>
<Option>采用突发传输方式可提高总线数据传输率</Option>
<Option>采用分离事务通信方式可提高总线利用率</Option>

<Solution>

**【解析】** ① A 错误 ×：并行总线存在时钟偏移、并行导线间串扰等问题，工作频率难以提高。

- 时钟偏移：指同一个时钟信号，到达不同部件（或不同接收端）的时间存在差异。
- 串扰：指相邻导线之间通过电磁耦合产生的信号干扰，即一根导线上的信号跳变，会“串”到旁边的导线上，在原本不该有信号的线上感应出噪声电压。并行总线线多且密，串扰严重，这是它频率做不高、最终被串行总线取代的重要物理原因。

高速串行总线（例如：PCIe、USB、SATA 等）可以做到极高的单线频率，实际传输速度往往超过并行总线。“并行总线比串行总线速度快”不是绝对的。

② B 正确 ✓：地址 / 数据分时复用同一组线可减少引脚数。

③ C 正确 ✓：突发（burst）传输传一次地址，可连续传多个数据，从而提高传输率。

④ D 正确 ✓：分离事务指把一个完整的总线操作拆成独立的、可分离的子事务，例如：将总线操作拆分成“请求—等待—响应”，等待期间释放总线给其他设备，提高总线利用率。故选 A。

**【点评】** 常规题。本题 A 选项的“迷惑性”极强，是“反直觉”题。很容易凭“直觉”认为并行比串行快，从而错选。现代高速总线（例如：PCIe、USB3.0、SATA 等）都是串行，频率提升带来的收益远超并行位宽优势。看到“并行一定比串行快”这种绝对化表述要警惕。

</Solution>

</Question>

<Question id="408-7c4a2e-012" type="single">

【2017】下列关于多总线结构的叙述中,错误的是（ ）。

<Option>靠近CPU 的总线速度较快</Option>
<Option>存储器总线可支持突发传送方式</Option>
<Option>总线之间须通过桥接器相连</Option>
<Option correct>PCI-Express × 16 采用并行传输方式</Option>

<Solution>

**【解析】** ① A 正确 ✓：多总线结构按速度分层，越靠近 CPU 的总线速度越快。CPU 是整个系统速度最快的部件。离 CPU 越近的总线，承载的是 CPU 高频交互的数据；离 CPU 越远，是慢速外设，传输频率低。

② B 正确 ✓：存储器总线支持突发（burst）传送，一次寻址连续传送多个数据。

③ C 正确 ✓：桥接器是多总线结构中连接两条不同总线的接口电路 / 芯片，让速度、协议、位宽不同的总线能够互相通信。采用南北桥架构的桥接器：北桥连接高速部件（例如：内存、显卡（AGP / PCIe）等）；南桥连接低速部件（例如：硬盘（SATA）、USB、网卡、PCI）等。

④ D 错误 ×：PCI-Express（包括 ×16）采用串行差分传输和数据包交换，而非并行传输，“×16”指 16 对串行收发通道，并非 16 位并行总线。故选 D。

**【提示】** 为什么靠近 CPU 的总线速度较快？因为靠近 CPU 的部件通信最频繁、延迟最敏感，必须用高速总线；而高速总线贵且只能短距离连接，外围设备慢、多、杂，用低速总线性价比更高。分层结构是性能与成本权衡下的必然选择。

<Question id="408-7c4a2e-018" type="single">

【2024】某存储器总线的时钟频率为420MHz, 总线宽度为64 位, 每个时钟周期传送2 次数据；其总线事务支持突发传送方式,最多传送8 次数据,第一个时钟周期传送地址和读/ 写命令,从第4 个至第7 个时钟周期连续传送8 次数据。该总线的总线带宽(最大数据传输率) 为（ ）。

<Option>3.84GB/s</Option>
<Option correct>6.72GB/s</Option>
<Option>30.72GB/s</Option>
<Option>53.76GB/s</Option>

<Solution>

**【解析】** **【解法一】** 由于一个时钟周期传送两次数据，因此总线带宽 = 总线时钟频率 × 总线宽度 × 2 = $(420\mathrm{MHz}\times64\mathrm{bit}\times2\div8)\ \mathrm{B}=6.72\mathrm{GB/s}$。

**【解法二】** 根据第 4～7 个时钟周期传送 8 次数据（每次 64 位），即 4 个时钟周期内传送 $8\times8\mathrm{B}=64\mathrm{B}$，得到数据传输率为：$64\mathrm{B}\div(4\times\frac{1}{420\mathrm{M}})=6.72\mathrm{GB/s}$。

- 传地址的同时直接指定本次突发要传多少个数据。
- 从设备根据总线预设的固定突发长度（例如：4 个数据）自动完成传输。
- 通过“结束信号”动态终止传输（无预设长度）。

<Option>I/O 接口中CPU 可访问的寄存器称为I/O 端口</Option>

C 正确：独立编址指主存和 I/O 端口使用两套完全独立、互不干涉的地址空间，主存地址和 I/O 端口地址各自独立编码。CPU 提供专门的 I/O 访问指令（例如：IN / OUT 指令），访存指令无法访问 I/O 端口。独立编址需在硬件上增设专门的 I/O 读写控制信号，和主存读写信号分开。其优点是 I/O 专用指令短小，执行速度更快，且内存与 I/O 控制逻辑互不干扰。其缺点是 CPU 必须额外实现一套 I/O 指令，硬件需要额外译码与控制信号线。

- 地址共享：主存地址和 I/O 端口地址共享同一地址空间。
- 指令共用：CPU 使用普通访存指令（LOAD/STORE、MOV 等）读写 I/O 端口，无需专用 I/O 指令集。
- 简化硬件设计：不需要区分内存与 I/O 的读写控制信号，控制逻辑简单。

其缺点是：I/O 端口占用部分主存地址空间，访存指令长度更长，I/O 操作速度略慢。故选 D。

| $L_4$ | 1 | 1 | 1 | 1 | 1 |
| $L_3$ | 0 | 1 | 0 | 0 | 0 |
| $L_2$ | 0 | 1 | 1 | 1 | 0 |
| $L_1$ | 0 | <u>1</u> | 0 | <u>1</u> | 0 |
| $L_0$ | 0 | 1 | 1 | 1 | 1 |

<Question id="408-7c4a2e-042" type="essay">

【2018】假定计算机的主频为500MHz,CPI 为4。现有设备A 和B, 其数据传输率分别为2MBps和40MBps, 对应I/O 接口中各有一个32 位数据缓冲寄存器。请回答下列问题, 要求给出计算过程。
   (1) 若设备A 采用定时查询I/O 方式, 每次输入/ 输出都至少执行10 条指令。设备A 最多间隔多长时间查询一次才能不丢失数据?CPU 用于设备A 输入/ 输出的时间占CPU 总时间的百分比至少是多少?
   (2) 在中断I/O 方式下, 若每次中断响应和中断处理的总时钟周期数至少为400, 则设备B 能否采用中断I/O 方式? 为什么?
   (3) 若设备B 采用DMA 方式, 每次DMA 传送的数据块大小为1000B, CPU 用于DMA 预处理和后处理的总时钟周期数为500,则CPU 用于设备B 输/ 输出的时间占CPU 总时间的百分比最大是多少?

<Solution>

**【解析】**

(1) 采用定时查询 I/O 方式：① I/O 接口数据缓冲寄存器为 32 位 = 4B。设备 A 数据传输率 2MB/s，填满 4B 缓冲区的时间 = $\frac{4\mathrm{B}}{2\mathrm{MB/s}}=2\mu\mathrm{s}$。若超过 2μs 未查询，缓冲区数据会被新数据覆盖而丢失，因此最多每隔 2μs 必须查询一次。

② 每秒查询次数 = $\frac{1\mathrm{s}}{2\mu\mathrm{s}}=5\times 10^5$ 次。每次查询至少执行 10 条指令，CPI = 4，每条指令需 4 个时钟周期。每秒用于设备 A 的时钟周期数 = $5\times10^5\times10\times4=2\times10^7$。CPU 主频 500MHz，每秒总时钟周期数 = $500\times10^6$。CPU 用于设备 A 的输入/输出时间占比 = $\frac{2\times10^7}{500\times10^6}=4\%$。

(2) ① I/O 接口数据缓冲寄存器为 32 位 = 4B。设备 B 传输率 40MB/s，准备 4B 数据的时间 = $\frac{4\mathrm{B}}{40\mathrm{MB/s}}=2\mu\mathrm{s}$。每次中断响应和处理至少需要 400 个时钟周期，每个时钟周期 = $\frac{1}{500\mathrm{MHz}}\mathrm{s}$，则每次中断响应和处理耗时 = $400\times\frac{1}{500\mathrm{MHz}}=0.8\mu\mathrm{s}$。

{/* 原书此处将 4B/(40MB/s) 误写为 2μs，正确为 0.1μs；下文使用正确数值。 */}

② 由于 $0.8\mu\mathrm{s}>0.1\mu\mathrm{s}$，即中断处理速度跟不上数据到达速度，缓冲区数据会在中断处理期间被覆盖丢失。因此设备 B 不能采用中断 I/O 方式。

(3) 设备 B 数据传输率为 40MBps，DMA 每次传送 1000B，则每秒 DMA 次数 = $\frac{40\mathrm{MB}}{1000\mathrm{B}}=4\times10^4$ 次。每次 DMA 预处理和后处理共需 500 个时钟周期，则每秒 CPU 用于 DMA 的时钟周期数 = $4\times10^4\times500=2\times10^7$。

CPU 用于设备 B 的输入/输出时间占比 = $\frac{2\times10^7}{500\times10^6}=4\%$。

**【点评】** 概念题。考查定时查询、程序中断、DMA 这 3 种 I/O 方式的计算。本题跟 2009 年 408 第 43 题考法类似，考生可对比练习。

</Solution>
