# 第 4 章 网络层

## 4.2 IPv4

<Question id="408-c10df6-023" type="essay" tags="来源:2009考研408">

某网络拓扑如下图所示, 路由器 R1 通过接口 E1、 E2 分别连接局域网 1、局域网 2, 通过接口 L0 连接路由器 R2, 并通过路由器 R2 连接域名服务器与互联网。 R1 的 L0 接口的 IP 地址是 202.118.2.1, R2 的 L0 接口的 IP 地址是 202.118.2.2, L1 接口的 IP 地址是 130.11.120.1, E0 接口的 IP 地址是 202.118.3.1,域名服务器的 IP 地址是 202.118.3.2。

![第 4 章 网络层 4.2 第22题：网络拓扑图，见原 PDF 第36页附近](/img/questions/408/computer-network-4-2-q22.svg)

   (1) 将 IP 地址空间 202.118.1.0/24 划分为 2 个子网, 分别分配给局域网 1、局域网 2, 每个局域网需分配的 IP 地址数不少于 120 个。请给出子网划分结果,并说明理由或给出必要的计算过程。
   (2) 请给出 R1 的路由表, 使其明确包括到局域网 1 的路由、局域网 2 的路由、域名服务器的主机路由和互联网的路由。
   (3) 请采用路由聚合技术, 给出 R2 到局域网 1 和局域网 2 的路由。

<Solution>

**【解析】**

(1) 题目要求划分 2 个子网，每个子网 IP 地址数不少于 120 个。这说明主机号最少 $\lceil\log_2 120\rceil=7$ 位。IP 地址空间 202.118.1.0/24 的网络前缀占 24 位，再借用 1 位主机号划分子网，满足题目要求。子网划分结果如下：

- 子网 1：子网地址为 202.118.1.0/25，子网掩码为 255.255.255.128。
- 子网 2：子网地址为 202.118.1.128/25，子网掩码为 255.255.255.128。

地址分配方案：子网 1 分配给局域网 1，子网 2 分配给局域网 2；或子网 1 分配给局域网 2，子网 2 分配给局域网 1。

(2) ① 局域网 1 和局域网 2 均与 R1 直连，不存在下一跳路由，故下一跳 IP 地址为空。② 域名服务器的 IP 地址是固定 IP（静态 IP），子网掩码为 255.255.255.255（因为只有子网掩码的各位全为 1，和固定 IP 相与结果才不变）。③ 题目没有给出互联网的 IP 地址，则按照默认路由转发。默认路由的目的网络 IP 地址和子网掩码均为 0.0.0.0。R1 连接到互联网和域名服务器需要经过 R2，因此下一跳 IP 地址应为 202.118.2.2，接口为 L0。

若局域网 1 分配得到子网 202.118.1.0/25，局域网 2 分配得到子网 202.118.1.128/25（分配结果可调换），则 R1 的路由表如下表所示。

| 目的网络 IP 地址 | 子网掩码 | 下一跳 IP | 地址接口 |
| --- | --- | --- | --- |
| 202.118.1.0 | 255.255.255.128 | — | E1 |
| 202.118.1.128 | 255.255.255.128 | — | E2 |
| 202.118.3.2 | 255.255.255.255 | 202.118.2.2 | L0 |
| 0.0.0.0 | 0.0.0.0 | 202.118.2.2 | L0 |

(3) 路由聚合实际上就是找到若干个子网的最长公共前缀。局域网 1 和局域网 2 是从划分 IP 地址空间 202.118.1.0/24 中划分出来的，因此路由聚合后目的网络地址为 202.118.1.0，子网掩码为 255.255.255.0。R2 通过 R1 访问这两个局域网，下一跳 IP 地址及接口分别为 202.118.2.1 和 L0。聚合后的路由表项如下：

| 目的网络 IP 地址 | 子网掩码 | 下一跳 IP | 地址接口 |
| --- | --- | --- | --- |
| 202.118.1.0 | 255.255.255.0 | 202.118.2.1 | L0 |

**【点评】** 常规题。本题全面考查了网络层相关的常见考点，这些基础内容是考 408 必须要掌握的。其中，考生需要留意一些常见的特殊路由（域名服务器和互联网等）。

</Solution>

</Question>

<Question id="408-c10df6-024" type="essay" tags="来源:2015考研408">

某网络拓扑如下图所示, 其中路由器内网接口、 DHCP 服务器、 WWW 服务器与主机1 均采用静态 IP 地址配置, 相关地址信息如图中标注; 主机 2~ 主机 N 通过 DHCP 服务器动态获取 IP 地址等配置信息。请回答下列问题。

![第 4 章 网络层 4.2 第23题：网络拓扑图，见原 PDF 第37页附近](/img/questions/408/computer-network-4-2-q23.svg)

   (1) DHCP 服务器可为主机 2~ 主机 N 动态分配 IP 地址的最大范围是什么？主机 2 使用 DHCP 协议获取 IP 地址的过程中,发送的封装 DHCPDiscover 报文的 IP 分组的源 IP 地址和目的 IP 地址分别是什么?
   (2) 若主机 2 的 ARP 表为空, 则该主机访问 Internet 时,发出的第一个以太网帧的目的 MAC 地址是什么? 封装主机 2 发往 Internet 的 IP 分组的以太网帧的目的 MAC 地址是什么?
   (3) 若主机 1 的子网掩码和默认网关分别配置为 255.255.255.0 和 111.123.15.2, 则该主机是否能访问 WWW 服务器? 是否能访问 Internet? 请说明理由。

<Solution>

**【解析】**

(1) DHCP 服务器所在网络为 111.123.15.0/24，除去网络地址 111.123.15.0、已分配的静态地址 111.123.15.1～111.123.15.4 以及广播地址 111.123.15.255，可分配给主机 2～主机 N 的 IP 地址范围是 111.123.15.5～111.123.15.254。

DHCP Discover 报文的 IP 分组的源 IP 地址和目的 IP 地址分别是 0.0.0.0、255.255.255.255。

主机目前没有分配到 IP 地址，所以源 IP 地址为 0.0.0.0；因为主机不知道网络中 DHCP 服务器的 IP 地址是什么，所以广播发送 DHCP Discover 报文，即目的 IP 地址为 255.255.255.255，让本地网络所有主机都能收到该报文，但只有 DHCP 服务器才对此报文做出回应。

(2) 主机 2 发出的第一个以太网帧封装的是 ARP 请求报文，使用 MAC 广播地址 ff-ff-ff-ff-ff-ff。由于是访问 Internet，路由器对 ARP 请求报文做出应答。随后封装主机 2 发往 Internet 的 IP 分组的以太网帧的目的 MAC 地址是路由器的 MAC 地址，即 00-a1-a1-a1-a1-a1。

(3) ① 该主机能访问 WWW 服务器。WWW 服务器与主机 1 在同一子网（111.123.15.0/24），主机 1 通过 ARP 直接获取 WWW 服务器的 MAC 地址，不需要经过网关，因此网关配置错误不影响同子网通信。

② 该主机不能访问 Internet。访问 Internet 需要将 IP 分组发送给默认网关转发，但主机 1 配置的网关 111.123.15.2 是 DHCP 服务器而非路由器，该主机不会将分组转发到外网，因此无法访问 Internet。

**【点评】** 常规题。综合考查 DHCP 工作过程、ARP 协议、MAC 地址封装、子网划分与网关作用，是一道常规的计网综合题，是常见考点的常规考法。

</Solution>

</Question>

<Question id="408-c10df6-025" type="essay" tags="来源:2018考研408">

某公司的网络如下图所示。 IP 地址空间 192.168.1.0/24 被均分给销售部和技术部两个子网, 并已分别为部分主机和路由器接口分配了 IP 地址,销售部子网的 MTU = 1500B,技术部子网的 MTU = 800B。

![第 4 章 网络层 4.2 第24题：网络拓扑图，见原 PDF 第38页附近](/img/questions/408/computer-network-4-2-q24.svg)

请回答下列问题:
   (1) 销售部子网的广播地址是什么？技术部子网的子网地址是什么？若每个主机仅分配一个 IP 地址, 则技术部子网还可连接多少台主机?
   (2) 假设主机 192.168.1.1 向主机 192.168.1.208 发送一个总长度为 1500B 的 IP 分组, IP 分组的头部长度为 20B, 路由器在通过接口 F1 转发该 IP 分组时进行了分片。若分片时尽可能分为最大片,则一个最大 IP 分片封装数据的字节数是多少? 至少需要分为几个分片? 每个分片的片偏移量是多少?

<Solution>

**【解析】**

(1) 192.168.1.0/24 均分给两个部门，需借 1 位主机位作为子网位，每个子网的网络前缀是 25 位：

- 销售部：子网号为 0，网络地址 192.168.1.0，可用主机地址范围 192.168.1.0～192.168.1.127，广播地址 = 主机位全 1 = 192.168.1.127。
- 技术部：子网号为 1，网络地址 192.168.1.128，可用主机地址范围 192.168.1.128～192.168.1.255。

{/* 原书以上两处可用主机地址范围包含网络地址和广播地址，实际可用范围分别为 192.168.1.1～192.168.1.126 和 192.168.1.129～192.168.1.254。 */}

技术部可用主机地址 = 192.168.1.129～192.168.1.254，共 $2^7-2=126$ 个。已分配 IP 地址范围为 192.168.1.129～192.168.1.208，共 $208-129+1=80$ 个；加上路由器接口 F1 占用地址 192.168.1.254，共 81 个。还可连接 $126-81=45$ 台主机。

(2) 原始 IP 分组总长度 1500B，首部 20B，数据部分 = $1500-20=1480\mathrm{B}$。技术部子网 MTU = 800B，每个分片首部 20B，最大数据载荷 = $800-20=780\mathrm{B}$。但分片数据长度必须是 8B 的整数倍（片偏移字段以 8B 为单位），$\lfloor780\div8\rfloor\times8=776\mathrm{B}$。分片数 = $\lceil1480\div776\rceil=2$ 个。两分片的片偏移量分别是 $0\div8=0$、$776\div8=97$。

| 分片 | 数据长度 | 总长度 | 片偏移 | MF 标志 |
| --- | --- | --- | --- | --- |
| 分片 1 | 776B | 796B | 0 | 1 |
| 分片 2 | 704B | 724B | 97 | 0 |

**【易错点】** 分片中封装的是原 IP 数据报的数据部分，不包括原 IP 首部。

**【点评】** 常规题。本题综合考查子网划分和 IP 分片两个计网中的高频考点。难度适中，中规中矩，而且这些考点在此前的 408 中都考过。这些内容也属于备考 408 必须掌握的内容。

</Solution>

</Question>

<Question id="408-c10df6-026" type="essay" tags="来源:2020考研408">

某校园网有两个局域网,通过路由器 R1、 R2 和 R3 互联后接入 Internet, S1 和 S2 为以太网交换机。局域网采用静态 IP 地址配置, 路由器部分接口以及各主机的 IP 地址如下图所示。请回答下列问题:

![第 4 章 网络层 4.2 第25题：网络拓扑图，见原 PDF 第39页附近](/img/questions/408/computer-network-4-2-q25.svg)

   (1) 为使 H2 和 H3 能够访问 Web 服务器 (使用默认端口号), 需要进行什么配置？
   (2) 若 H2 主动访问 Web 服务器时, 将 HTTP 请求报文封装到 IP 数据报 P 中发送, 则 H2 发送的 P 的源 IP 地址和目的 IP 地址分别是什么? 经过 R3 转发后, P 的源 IP 地址和目的 IP 地址分别是什么? 经过 R2 转发后, P 的源 IP 地址和目的 IP 地址分别是什么?

假设 NAT 转换表结构为:

| 外网 IP 地址 | 外网端口号 | 内网 IP 地址 | 内网端口号 |
| -------- | ----- | -------- | ----- |
|          |       |          |       |

<Solution>

**【解析】**

(1) 主机 H2、H3 和 Web 服务器不在同一个局域网中。要使得外部主机能访问内网中的 Web 服务器，必须进行 NAT 配置，在路由器 R2 的 NAT 转换表中配置外网地址到内网地址的映射。Web 服务器使用 HTTP 协议，而 HTTP 协议的默认端口是 80。当路由器 R2 的 80 端口收到请求时，将其转发到内网中的 Web 服务器。路由器 R2 唯一的外网 IP 地址为 203.10.2.2，Web 服务器的内网 IP 地址为 192.168.1.2。路由器 R2 的 NAT 转换表具体配置如下表所示。

| 外网 IP 地址 | 外网端口号 | 内网 IP 地址 | 内网端口号 |
| --- | --- | --- | --- |
| 203.10.2.2 | 80 | 192.168.1.2 | 80 |

(2) R3 与 R2 是 NAT 路由器，对穿越内网外网的 IP 分组进行 IP 地址转换。① H2 发送的数据报 P 使用 192.168.1.2 作为源地址，使用 R2 的外网地址 203.10.2.2 作为目的地址。② 经过 R3 转发后，进入外网，源地址变为 R3 的外网地址 203.10.2.6，目的地址保持 203.10.2.2 不变。③ 经过 R2 转发后，进入 R2 的内网，源地址保持 R3 的外网地址 203.10.2.6 不变，目的地址改为 Web 服务器的内网地址 192.168.1.2。

**【点评】** 常规题。本题考查 NAT 地址转换这个单一考点。一般的在教辅中都有对该考点的介绍，也有类似的练习题。

</Solution>

## 4.4 路由协议

<Question id="408-c10df6-031" number={5} type="essay" tags="来源:2013考研408">

假设 Internet 的两个自治系统构成的网络如下图所示, 自治系统 AS1 由路由器 R1 连接两个子网构成；自治系统 AS2 由路由器 R2、 R3 互联并连接 3 个子网构成。各子网地址、 R2 的接口名、 R1 与 R3 的部分接口 IP 地址如下图所示。 请回答下列问题:

![第 4 章 网络层 4.4 第4题：网络拓扑图，见原 PDF 第41页附近](/img/questions/408/computer-network-4-4-q4.svg)

   (1) 假设路由表结构如下表所示。请利用路由聚合技术, 给出 R2 的路由表, 要求包括到达下图中所有子网的路由,且路由表中的路由项尽可能少。

| 目的网络 | 下一跳 | 接口 |
| --- | --- | --- |

   (2) 若 R2 收到一个目的 IP 地址为 194.17.20.200 的 IP 分组, 则 R2 会通过哪个接口转发该 IP 分组?
   (3) R1 与 R2 之间利用哪个路由协议交换路由信息？该路由协议的报文被封装到哪个协议的分组中进行传输?

<Solution>

**【解析】**

(1) 图中 R2 有三个接口，路由聚合后，R2 的路由表中最少有 3 条表项。

① 子网 153.14.5.0/25 和 153.14.5.128/25 都是通过 R2 的 S0 接口转发，其最长公共前缀为 1001 1001.0000 1110.0000 0101（24 位），可聚合为子网 153.14.5.0/24。

② 子网 194.17.20.0/25 和 194.17.21.0/24 都是通过 R2 的 S1 接口转发，其最长公共前缀为 1100 0010.0001 0001.0001 010（23 位），可聚合为子网 194.17.20.0/23。

③ 子网 194.17.20.128/25 通过 R2 的 E0 接口转发，因为 R2 的 E0 接口只连接了这一个子网，所以无需聚合。

经过路由聚合后，R2 的路由表如下：

| 目的网络 | 下一跳 | 接口 |
| --- | --- | --- |
| 153.14.5.0/24 | 153.14.3.2 | S0 |
| 194.17.20.0/23 | 194.17.24.2 | S1 |
| 194.17.20.128/25 | 直接交付 | E0 |

**【提示】** 路由聚合的基本原则是：① 被聚合子网 IP 地址连续、高位前缀相同，和连接在哪个路由器无关。② 聚合后的路由必须是同一个出接口、同一个下一跳。

(2) 194.17.20.200 可同时匹配 R2 的路由表中、目的网络为 194.17.20.0/23 和 194.17.20.128/25 的两条路由，但依据最长前缀匹配规则（优先选用匹配且子网前缀位数最多的子网），优先选择子网掩码更长的 194.17.20.128/25 条目，故 R2 从 E0 接口转发报文。

(3) R1 和 R2 分属不同自治系统，跨 AS 交互路由须采用 BGP（BGP4）这类外部网关协议。BGP 报文属于应用层协议，依托 TCP 报文封装传输（端口号 179）。

**【提示】** ① BGP 协议是全球唯一通用域间路由协议，是域间路由行业唯一事实标准。据统计，全球 95% 以上跨运营商、跨国流量依靠 BGP 调度，其中骨干 ISP（Internet Service Provider，指电信、联通、移动这类主干运营商）互联全部用 BGP。根据目前的 408 命题趋势，偏好考 BGP 在行业内占核心地位的协议，不考非主流、逐渐被淘汰的技术。

② BGP 是该类路由协议的统称，BGP4 是 BGP 的第 4 版正式标准，目前实际在用的 BGP 协议均为 BGP4。BGP1、BGP2、BGP3 等老旧版本，已经被彻底淘汰。

**【点评】** 常规题。考查路由聚合、最长匹配原则。本题是计算机网络较为经典的大题考法，这种考法相对简单，较早年份的 408 真题频频出现。最近几年的计算机网络大题的难度和灵活性都增加了不少。这种考法在最近年份的 408 真题中，往往只作为一个小题或大题的一个小问。

</Solution>

</Question>

(1) ① OSPF 路由协议通过链路开销计算最短路径来确定下一跳，这是 OSPF 路由协议固有的工作机制。2014 年 408 第 42 题第 (3) 小问已经求出了 R1 到达各子网的最短路径（通过“人工肉眼”也可看出最短路径）。未进行路由聚合之前，R1 的路由表如下：

| 目的网络 | 下一跳 | 接口 |

② 题目“要求包括到达图中子网 `192.1.x.x` 的路由”，4 个子网 192.1.1.0/24、192.1.5.0/24、192.1.6.0/24、192.1.7.0/24 都是 `192.1.x.x` 这种格式。所以，题目意思就是“求路由器 R1 到达图中 4 个子网的路由”。

③ 路由聚合要求地址连续、有共同前缀、下一跳相同。在本题场景下，聚合路由应避免覆盖网络拓扑中不存在的子网；若无法避免，需配合 Null0 防止路由回路。只有 192.1.6.0/24 和 192.1.7.0/24 的下一跳相同，路由聚合成 192.1.6.0/23。可得路由聚合后 R1 的路由表如下：

| 目的网络 | 下一跳 | 接口 |
| --- | --- | --- |

| 192.1.5.0/24 | 10.1.1.10 | L1 |
| 192.1.6.0/23 | 10.1.1.2 | L0 |

**【提示】** 本题可能考生会得到以下常见的错误答案：将 3 个子网 192.1.5.0/24、192.1.6.0/24、192.1.7.0/24 聚合成 192.1.4.0/22，这为何不对呢？因为这样聚合虽然地址连续，但 R1 到达这 3 个子网的下一跳不相同，无法聚合。而且，192.1.4.0/22 包含在本题网络拓扑中并不存在的子网 192.1.4.0/24，会造成路由黑洞问题。

② 该 IP 分组到达路由器 R1 后，通过 L0 接口转发，下一跳是路由器 R2。R2 再转发给 R4，R4 转发给主机 192.1.7.211。该 IP 分组依次经过 R1 → R2 → R4 这 3 个路由，每经过一个路由器 TTL 减 1，所以主机收到该 IP 分组时 TTL = 64 − 3 = 61。

**【提示】** 该 IP 分组路由转发的详细过程如下：

① 第 1 跳：源主机 → R1

- 源主机 192.1.1.130 对比自身网段的子网掩码 255.255.255.0，判断目的地址 192.1.7.211 与自己不在同一网段，所以将 IP 分组发往默认网关 R1。

② 第 2 跳：R1 → R2

- R1 查自身的路由表，目的地址 192.1.7.211 匹配聚合路由 192.1.6.0/23，对应下一跳为 10.1.1.2（R2），出接口为 L0。
- R1 将 IP 分组的 TTL 从 64 减为 63，重新计算首部校验和，从 L0 接口转发给 R2。

③ 第 3 跳：R2 → R4

- R2 收到分组，查自身的路由表，目的 IP 地址 192.1.7.211 的下一跳为 R4。
- R2 将 IP 分组的 TTL 从 63 减为 62，转发给 R4。

④ 第 4 跳：R4 → 目的主机

- R4 收到分组，查路由表，发现目的 IP 地址 192.1.7.211 匹配直连网段 192.1.7.0/24。
- R4 将 IP 分组的 TTL 从 62 减为 61，从连接 192.1.7.0/24 的接口转发给目的主机。

(3) R1 的 LSI 需要增加一条特殊的直连网络，网络前缀 Prefix 为“0.0.0.0/0”，Metric 为 10。

**【提示】** ★ ① 0.0.0.0/0 的掩码长度为 0，意味着它要求匹配的网络前缀位为 0 位（也就是没有任何约束）。任何 IPv4 地址（0.0.0.0～255.255.255.255）和 0.0.0.0 按位与，结果都是 0.0.0.0，所以所有目的 IP 都能匹配上这条路由。

② 全球 Internet 拥有数亿个活跃 IP 地址和数百万条路由前缀。如果路由器要把所有 Internet 路由都记录在本地路由表中，内存和查找开销都是不可接受的。因此，本地网络只保留自己关心的明细路由（直连子网、内部子网等），对于所有外部未知地址统一交给默认路由 0.0.0.0/0 处理，由上游路由器继续转发。

**【点评】** 常规题。综合考查路由聚合、TTL、默认路由等常见考点。本题的主要难点在于计网的大题和数据结构的大题共用一个背景，阅读量较大。从 2009～2026，这 18 年 408 考试中，计网和数据结构综合的题目，仅此考过一次。

</Solution>

<Solution>

**【解析】**

（1）AS4 中路由器可能超过 20 个，而 RIP 限制最大距离为 15 跳，定义距离为 16 表示不可达，不适合大规模网络，因此只能选择 OSPF 协议。

（2）TTL 每经过一个路由器减一，若 TTL 值减少到 0，该分组就会被路由器丢弃。AS3 中任意两个主机间通信经过的路由器数不超过 15 个，为了确保该 IP 分组能被正常接收，因此 TTL 初值至少应该设置为 $15+1=16$。当 TTL 初值等于 16 时，即使最多经过 15 个路由器之后，TTL 最小值为 1，该分组也不会被路由器丢弃。

（3）本题求解过程可以看作无权图求单源最短路径，类似广度优先遍历。注意：“本小问题目假设 AS1 中的路由器同一时刻启动，启动后立即构建并交换初始距离向量”，意思是第 0s 时相邻路由器间开始交换距离向量，并非 30s 后才第一次交换距离向量。

## 4.5 网络层设备

<Question id="408-c10df6-039" number={8} type="essay" tags="来源:2019考研408">

某网络拓扑如下图所示, 其中 R 为路由器, 主机 H1 ~ H4 的 IP 地址配置以及 R 的各接口 IP 地址配置如下图所示。现有若干以太网交换机 (无 VLAN 功能) 和路由器两类网络互连设备可供选择。

![第 4 章 网络层 4.5 第6题：网络拓扑图，见原 PDF 第46页附近](/img/questions/408/computer-network-4-5-q6.svg)

请回答下列问题:
   (1) 设备 1、设备 2 和设备 3 分别应选择什么类型的网络设备？
   (2) 设备 1、设备 2 和设备 3 中, 哪几个设备的接口需要配置 IP 地址? 为对应的接口配置正确的 IP 地址。
   (3) 为确保主机 H1 ~ H4 能够访问 Internet, R 需要提供什么服务？
   (4) 若主机 H3 发送一个目的地址为 192.168.1.127 的 IP 数据报, 网络中哪几个主机会接收该数据报?

<Solution>

**【解析】**

(1) 设备 1、设备 2 和设备 3 分别应选择路由器、以太网交换机、以太网交换机。同一网络设备间的连接使用以太网交换机，根据 H1～H4 的地址和网络前缀长度可得，H1 与 H2 在同一网络（192.168.1.0/26），H3 与 H4 同在另一网络（192.168.1.64/26）。所以，设备 2 和设备 3 是以太网交换机。连接不同网络应使用路由器，H1 与 H2、H3 与 H4 在不同网络，故设备 1 是路由器。此外，还可根据 R 接口地址 192.168.1.253/30，计算出子网有效地址数量是 2，只有当设备 1 是路由器，IP 地址才够分配，从这个角度也可确定设备 1 是路由器。

(2) 仅设备 1 需配置 IP 地址，IF1 地址为 192.168.1.254，IF2 地址为 192.168.1.1，IF3 地址为 192.168.1.65。根据主机 H1～H4 的默认网关地址，可知设备 1（路由器）的 IF2、IF3 接口地址。而通过 R 配置的接口地址 192.168.1.253/30，根据网络前缀长度可知有效地址数量为 2，因此 IF1 使用唯一剩下的 IP 地址 192.168.1.254。

(3) 地址块 192.168.0.0/16 内地址是私有地址，仅拥有私有地址的主机需要通过地址转换才可访问 Internet，所以 R 需要提供 NAT 服务。

(4) 127 = 0111 1111B，64 = 0100 0000B。所以，IP 地址 192.168.1.127 属于 H3 和 H4 所在网络 192.168.1.64/26（前 26 位网络号相同），并且是子网广播地址。由于设备 1 是路由器，它可以隔绝广播域，故只有主机 H4 能收到该数据报。

**【点评】** 常规题。计网综合题。此题的考点和考查形式，在此前 408 中考过多次。
