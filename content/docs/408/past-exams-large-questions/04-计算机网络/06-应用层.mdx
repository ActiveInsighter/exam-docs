## 2011 年第 47 题

综合考点：HTTP、ARP、IP 首部。

<ExamQuestion>

**111. 2011 年第 47 题**

某主机的 MAC 地址为 `00-15-C5-C1-5E-28`，IP 地址为 `10.2.128.100`（私有地址）。题图给出了网络拓扑，以及该主机进行 Web 请求时一个以太网数据帧前 80B 的十六进制内容。

<img src="/img/408/past-exams-large-questions/04-计算机网络/assets/2011-47-figure-001.svg" alt="2011 年第 47 题网络拓扑、以太网帧内容及报文格式" />

1. Web 服务器的 IP 地址是什么？该主机默认网关的 MAC 地址是什么？
2. 该主机在构造图中数据帧时，使用什么协议确定目的 MAC 地址？封装该协议请求报文的以太网帧目的 MAC 地址是什么？
3. 假设 HTTP/1.1 采用持续、非流水线方式，一次请求—响应耗时为一个 RTT，`rfc.html` 页面还引用 5 个 JPEG 小图像。从发出图中的 Web 请求开始，到浏览器收到全部内容，共需多少个 RTT？
4. 该帧封装的 IP 分组经过路由器 R 转发时，需要修改 IP 首部中的哪些字段？

<ExamSolution>

<ExamAnswer>

1. Web 服务器 IP 地址为 `64.170.98.32`；默认网关 MAC 地址为 `00-21-27-21-51-EE`。
2. 使用 ARP；ARP 请求帧的目的 MAC 地址为 `FF-FF-FF-FF-FF-FF`。
3. 共需 $6$ 个 RTT。
4. 本题中应修改：源 IP 地址、TTL、首部校验和。源 IP 地址由 `10.2.128.100` 转换为 `101.12.123.15`，TTL 减 1，并重新计算 IP 首部校验和。

</ExamAnswer>

<ExamExplanation>

### （1）由帧内容确定目的 IP 和默认网关 MAC

以太网首部长度为

$$
6+6+2=14\text{ B}.
$$

IPv4 首部中的目的 IP 地址位于首部第 17～20 字节，因此在以太网帧中从第 31 字节开始。图中对应的 4 个字节为

$$
\texttt{40 AA 62 20}_{16},
$$

换成十进制即

$$
64.170.98.32.
$$

以太网帧最前面的 6B 是**目的 MAC 地址**，图中为 `00-21-27-21-51-EE`。由于 Web 服务器不在本地私有网络内，主机应把帧交给默认网关，因此该目的 MAC 就是默认网关接口的 MAC 地址。

### （2）ARP

主机已知下一跳默认网关的 IP 地址，需要通过 ARP 得到其 MAC 地址。若本机 ARP 缓存中没有对应项，则先广播 ARP 请求，因此以太网目的地址为

$$
\texttt{FF-FF-FF-FF-FF-FF}.
$$

### （3）持续非流水线 HTTP

持续连接只建立一次 TCP 连接；本问从题图中的 Web 请求已经发出开始计时，因此只计算 HTTP 请求—响应 RTT。

- 获取 `rfc.html`：$1$ RTT；
- 页面引用 5 个 JPEG，小图像必须依次请求，每个再用 $1$ RTT。

故总时间为

$$
1+5=\boxed{6\text{ RTT}}.
$$

### （4）路由器转发时的首部变化

路由器 R 同时承担 NAT。源地址 `10.2.128.100` 是私有地址，出 Internet 时被转换为 R 的公网地址 `101.12.123.15`。每经过一个路由器，TTL 还要减 1；因为 IP 首部发生变化，所以必须重新计算首部校验和。

题图中该 IP 分组总长度字段为 `01EFH`，即 495B，小于输出链路 MTU 1500B，因此本题不会发生 IP 分片，总长度、标志和片偏移无需改变。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

## 2021 年第 47 题

<ExamQuestion>

**121. 2021 年第 47 题**

某网络拓扑如下图所示。以太网交换机 S 通过路由器 R 与 Internet 互联。路由器部分接口、本地域名服务器、H1、H2 的 IP 地址和 MAC 地址如图所示。

在 $t_0$ 时刻，H1 的 ARP 表和 S 的交换表均为空。H1 从 $t_0$ 时刻开始使用浏览器通过域名 `www.abc.com` 请求访问 Web 服务器；在 $t_1$ 时刻（$t_1>t_0$），S 第一次收到封装 HTTP 请求报文的以太网帧。假设从 $t_0$ 到 $t_1$ 期间，网络中没有发生任何与此次 Web 访问无关的通信。

<img src="/img/408/past-exams-large-questions/04-计算机网络/assets/2021-47-figure-001.svg" alt="2021 年第 47 题网络拓扑" />

1. 从 $t_0$ 到 $t_1$ 期间，H1 除了 HTTP 之外还运行了哪个应用层协议？从应用层到数据链路层，该应用层协议报文依次通过哪些协议进行封装？
2. 若 S 的交换表表项结构为 `<MAC 地址, 端口>`，则在 $t_1$ 时刻，S 的交换表中有哪些表项？
3. 从 $t_0$ 到 $t_1$ 期间，H2 至少会接收到几个与此次 Web 访问相关的帧？这些帧是什么帧？其目的 MAC 地址是什么？

<ExamSolution>

<ExamAnswer>

1. 还运行 DNS。封装关系为：DNS 报文 $\rightarrow$ UDP 数据报 $\rightarrow$ IP 数据报 $\rightarrow$ 以太网帧。
2. $t_1$ 时刻交换表至少包含：`<00-11-22-33-44-cc, 4>`、`<00-11-22-33-44-bb, 1>`、`<00-11-22-33-44-aa, 2>`。
3. 至少接收到 $2$ 个帧，均为封装 ARP 请求报文的广播以太网帧，目的 MAC 地址均为 `FF-FF-FF-FF-FF-FF`。

</ExamAnswer>

<ExamExplanation>

### （1）DNS 及逐层封装

H1 使用的是域名 `www.abc.com`，在发送 HTTP 请求之前必须先获得该域名对应的 IP 地址，因此还需要运行 **DNS**。

DNS 通常使用 UDP 作为运输层协议，因此从应用层向下的封装关系为

$$
\text{DNS 报文}
\rightarrow
\text{UDP 数据报}
\rightarrow
\text{IP 数据报}
\rightarrow
\text{以太网帧}.
$$

原材料中将最后一层表述为“CSMA/CD 帧”，这里按题图中的以太网交换网络统一表述为“以太网帧”。

### （2）交换表的学习过程

交换机根据**收到帧的源 MAC 地址和入端口**学习表项。

在 $t_0$ 时刻，H1 的 ARP 表为空。H1 首先需要访问本地域名服务器 `192.168.1.126/25`，因此先发送 ARP 请求。S 从端口 4 收到该帧后，学习到

`<00-11-22-33-44-cc, 4>`。

本地域名服务器发送 ARP 应答时，S 从端口 1 收到该帧，于是学习到

`<00-11-22-33-44-bb, 1>`。

DNS 解析完成后，H1 发现 Web 服务器位于 Internet，需要把分组交给默认网关 R。由于 H1 尚不知道 R 的 MAC 地址，因此还会广播 ARP 请求。R 返回 ARP 应答时，S 从端口 2 收到该帧，于是学习到

`<00-11-22-33-44-aa, 2>`。

H2 在此期间没有主动发送帧，因此交换机不会仅因为向 H2 所在端口转发广播帧而学习 H2 的 MAC 地址。

所以在 $t_1$ 时刻，交换表为：

| MAC 地址 | 端口 |
| --- | ---: |
| `00-11-22-33-44-cc` | 4 |
| `00-11-22-33-44-bb` | 1 |
| `00-11-22-33-44-aa` | 2 |

### （3）H2 接收到的广播帧

从 $t_0$ 到 $t_1$，至少出现两次 ARP 广播：

- H1 查询本地域名服务器的 MAC 地址；
- H1 查询默认网关 R 的 MAC 地址。

ARP 请求封装在广播以太网帧中，S 会向除入端口外的其他相关端口转发，因此 H2 至少会收到这两个帧。

二者的目的 MAC 地址均为

$$
\boxed{\texttt{FF-FF-FF-FF-FF-FF}}.
$$

</ExamExplanation>

</ExamSolution>

</ExamQuestion>
