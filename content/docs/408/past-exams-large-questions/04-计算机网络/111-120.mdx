# 408 历年大题整理 · 计算机网络（第 111–120 题）

<ExamQuestion>

**111. 2011 年第 47 题**

某主机的 MAC 地址为 `00-15-C5-C1-5E-28`，IP 地址为 `10.2.128.100`（私有地址）。题图给出了网络拓扑，以及该主机进行 Web 请求时一个以太网数据帧前 80B 的十六进制内容。

<img src="/img/408/past-exams-large-questions/04-计算机网络/assets/2011-47-figure-001.svg" alt="2011 年第 47 题网络拓扑、以太网帧内容及报文格式" />

1. Web 服务器的 IP 地址是什么？该主机默认网关的 MAC 地址是什么？
2. 该主机在构造图中数据帧时，使用什么协议确定目的 MAC 地址？封装该协议请求报文的以太网帧目的 MAC 地址是什么？
3. 假设 HTTP/1.1 采用持续、非流水线方式，一次请求—响应耗时为一个 RTT，`rfc.html` 页面还引用 5 个 JPEG 小图像。从发出图中的 Web 请求开始，到浏览器收到全部内容，共需多少个 RTT？
4. 该帧封装的 IP 分组经过路由器 R 转发时，需要修改 IP 首部中的哪些字段？

<ExamSolution>

<ExamAnswer>

1. Web 服务器 IP 地址为 `64.170.98.32`；默认网关 MAC 地址为 `00-21-27-21-51-EE`。
2. 使用 ARP；ARP 请求帧的目的 MAC 地址为 `FF-FF-FF-FF-FF-FF`。
3. 共需 $6$ 个 RTT。
4. 本题中应修改：源 IP 地址、TTL、首部校验和。源 IP 地址由 `10.2.128.100` 转换为 `101.12.123.15`，TTL 减 1，并重新计算 IP 首部校验和。

</ExamAnswer>

<ExamExplanation>

### （1）由帧内容确定目的 IP 和默认网关 MAC

以太网首部长度为

$$
6+6+2=14\text{ B}.
$$

IPv4 首部中的目的 IP 地址位于首部第 17～20 字节，因此在以太网帧中从第 31 字节开始。图中对应的 4 个字节为

$$
\texttt{40 AA 62 20}_{16},
$$

换成十进制即

$$
64.170.98.32.
$$

以太网帧最前面的 6B 是**目的 MAC 地址**，图中为 `00-21-27-21-51-EE`。由于 Web 服务器不在本地私有网络内，主机应把帧交给默认网关，因此该目的 MAC 就是默认网关接口的 MAC 地址。

### （2）ARP

主机已知下一跳默认网关的 IP 地址，需要通过 ARP 得到其 MAC 地址。若本机 ARP 缓存中没有对应项，则先广播 ARP 请求，因此以太网目的地址为

$$
\texttt{FF-FF-FF-FF-FF-FF}.
$$

### （3）持续非流水线 HTTP

持续连接只建立一次 TCP 连接；本问从题图中的 Web 请求已经发出开始计时，因此只计算 HTTP 请求—响应 RTT。

- 获取 `rfc.html`：$1$ RTT；
- 页面引用 5 个 JPEG，小图像必须依次请求，每个再用 $1$ RTT。

故总时间为

$$
1+5=\boxed{6\text{ RTT}}.
$$

### （4）路由器转发时的首部变化

路由器 R 同时承担 NAT。源地址 `10.2.128.100` 是私有地址，出 Internet 时被转换为 R 的公网地址 `101.12.123.15`。每经过一个路由器，TTL 还要减 1；因为 IP 首部发生变化，所以必须重新计算首部校验和。

题图中该 IP 分组总长度字段为 `01EFH`，即 495B，小于输出链路 MTU 1500B，因此本题不会发生 IP 分片，总长度、标志和片偏移无需改变。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

**112. 2012 年第 47 题**

主机 H 通过快速以太网连接 Internet，IP 地址为 `192.168.0.8`；服务器 S 的 IP 地址为 `211.68.71.80`。H 与 S 使用 TCP 通信时，在 H 上捕获到 5 个 IP 分组，其前 40B 如图所示。

<img src="/img/408/past-exams-large-questions/04-计算机网络/assets/2012-47-figure-001.svg" alt="2012 年第 47 题捕获的 5 个 IP 分组" />

1. 哪几个 IP 分组由 H 发送？哪几个分组完成了 TCP 连接建立过程？哪几个分组通过快速以太网传输时需要填充？
2. 根据这些分组，S 已经收到多少字节应用层数据？
3. 若其中某个由 S 发出的 IP 分组在发送时前 40B 如下图所示，则该分组到达 H 时经过了多少个路由器？

<img src="/img/408/past-exams-large-questions/04-计算机网络/assets/2012-47-figure-002.svg" alt="2012 年第 47 题服务器发出时的 IP 分组内容" />

<ExamSolution>

<ExamAnswer>

1. H 发送的是 1、3、4 号分组；1、2、3 号分组完成 TCP 三次握手；3、5 号分组在以太网上传输时需要填充。
2. S 已收到 $16\text{ B}$ 应用层数据。
3. 共经过 $15$ 个路由器。

</ExamAnswer>

<ExamExplanation>

### （1）判断方向、握手与以太网填充

IPv4 首部的源 IP 地址位于第 13～16 字节。1、3、4 号分组中的源地址均为

$$
\texttt{C0 A8 00 08}=192.168.0.8,
$$

因此它们由 H 发出。

TCP 三次握手可由 SYN、ACK 标志和序号关系判断：

- 1 号：`SYN=1, ACK=0`；
- 2 号：`SYN=1, ACK=1`，确认 1 号；
- 3 号：`ACK=1`，确认 2 号。

所以 1、2、3 号构成连接建立过程。

以太网帧的数据字段最小为 46B。3、5 号 IP 分组总长度字段为 `0028H`，即

$$
40\text{ B}<46\text{ B},
$$

因此封装成以太网帧时需要补齐 6B；其余分组无需填充。

### （2）应用层数据量

连接建立后 H 发送数据的起始序号为

$$
\texttt{846B41C6H}.
$$

5 号分组中 S 返回的确认号为

$$
\texttt{846B41D6H}.
$$

TCP 确认号表示“下一字节序号”，因此 S 已正确收到的数据量为

$$
\texttt{846B41D6H}-\texttt{846B41C6H}
=\texttt{10H}
=\boxed{16\text{ B}}.
$$

### （3）根据 TTL 判断经过的路由器数

先用 IP 首部标识字段判断图中服务器发送的分组与捕获的 5 号分组对应。发送时 TTL 为

$$
\texttt{40H}=64,
$$

H 捕获时 TTL 为

$$
\texttt{31H}=49.
$$

每经过一个路由器 TTL 减 1，因此路由器数为

$$
64-49=\boxed{15}.
$$

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

**113. 2013 年第 47 题**

Internet 中两个自治系统构成的网络如下图所示。AS1 由 R1 连接两个子网；AS2 由 R2、R3 互联并连接 3 个子网。

<img src="/img/408/past-exams-large-questions/04-计算机网络/assets/2013-47-figure-001.svg" alt="2013 年第 47 题自治系统网络拓扑" />

路由表结构如下。

<img src="/img/408/past-exams-large-questions/04-计算机网络/assets/2013-47-figure-002.svg" alt="2013 年第 47 题路由表结构" />

1. 利用路由聚合技术给出 R2 的路由表，要求能够到达图中所有子网，且路由项尽可能少。
2. 若 R2 收到目的 IP 地址为 `194.17.20.200` 的 IP 分组，R2 通过哪个接口转发？
3. R1 与 R2 之间使用什么路由协议交换路由信息？该协议报文封装在哪个运输层协议中传输？

<ExamSolution>

<ExamAnswer>

1. R2 路由表可写为：

| 目的网络 | 下一跳 | 接口 |
| --- | --- | --- |
| `153.14.5.0/24` | `153.14.3.2` | S0 |
| `194.17.20.0/23` | `194.17.24.2` | S1 |
| `194.17.20.128/25` | 直接交付 | E0 |

2. 通过 E0 转发。
3. 使用 BGP（BGP-4）；BGP 报文由 TCP 承载。

</ExamAnswer>

<ExamExplanation>

### （1）路由聚合

AS1 的两个 `/25` 子网

$$
153.14.5.0/25,\qquad153.14.5.128/25
$$

可以聚合为

$$
153.14.5.0/24.
$$

R3 后方的 `194.17.20.0/25` 与 `194.17.21.0/25` 可以由更短前缀

$$
194.17.20.0/23
$$

统一覆盖。该 `/23` 同时也覆盖 R2 直连的 `194.17.20.128/25`，因此还必须在 R2 中保留一条更具体的直连 `/25` 路由。转发时依靠最长前缀匹配即可正确区分。

> 原整理把 `194.17.21.0/25` 误写成了 `/24`，这里已按题图修正。

### （2）最长前缀匹配

目的地址 `194.17.20.200` 同时匹配：

$$
194.17.20.0/23
$$

和

$$
194.17.20.128/25.
$$

`/25` 前缀更长，所以选择 E0 直连路由。

### （3）自治系统之间的路由协议

R1、R2 分属不同自治系统，因此交换域间路由信息应使用 BGP。BGP 是应用层路由协议，使用 TCP 建立可靠连接传送报文。

</ExamExplanation>

</ExamSolution>

**115. 2015 年第 47 题**

某网络拓扑如下图。路由器内网接口、DHCP 服务器、WWW 服务器和主机 1 使用静态 IP 地址；主机 2～主机 N 通过 DHCP 动态获取配置。

<img src="/img/408/past-exams-large-questions/04-计算机网络/assets/2015-47-figure-001.svg" alt="2015 年第 47 题网络拓扑" />

1. DHCP 服务器可动态分配给主机 2～主机 N 的最大 IP 地址范围是什么？主机 2 发送 DHCP Discover 时，封装它的 IP 分组源地址和目的地址分别是什么？
2. 若主机 2 的 ARP 表为空，则它访问 Internet 时发出的第一个以太网帧目的 MAC 地址是什么？真正封装主机 2 发往 Internet 的 IP 分组的以太网帧目的 MAC 地址是什么？
3. 若主机 1 的子网掩码和默认网关分别错误/正确配置为 `255.255.255.0` 和 `111.123.15.2`，主机 1 能否访问 WWW 服务器？能否访问 Internet？说明理由。

<ExamSolution>

<ExamAnswer>

1. 可动态分配的最大范围为 `111.123.15.5`～`111.123.15.254`；DHCP Discover 所在 IP 分组的源地址为 `0.0.0.0`，目的地址为 `255.255.255.255`。
2. 第一个以太网帧是 ARP 请求，目的 MAC 为 `FF-FF-FF-FF-FF-FF`；随后承载发往 Internet 的 IP 分组的以太网帧，目的 MAC 为路由器内网接口 MAC：`00-A1-A1-A1-A1-A1`。
3. 能访问 WWW 服务器；不能访问 Internet。

</ExamAnswer>

<ExamExplanation>

### （1）DHCP 地址范围

该局域网为 `111.123.15.0/24`：

- `.0` 为网络地址；
- `.255` 为广播地址；
- `.1` 已分配给路由器；
- `.2` 已分配给 DHCP 服务器；
- `.3` 已分配给 WWW 服务器；
- `.4` 已分配给主机 1。

因此可供 DHCP 动态分配的最大连续范围是

$$
\boxed{111.123.15.5\sim111.123.15.254}.
$$

主机尚未获得自己的 IP 地址时，DHCP Discover 使用

$$
\text{源 IP}=0.0.0.0,
\qquad
\text{目的 IP}=255.255.255.255.
$$

### （2）ARP 与实际数据帧

主机 2 要访问 Internet，下一跳是默认网关 `111.123.15.1`。ARP 表为空时，必须先广播 ARP 请求，所以第一个帧的目的 MAC 是全 1 广播地址。

得到网关 MAC 后，真正承载 Internet 方向 IP 分组的以太网帧，其目的 MAC 为默认网关接口的

$$
\texttt{00-A1-A1-A1-A1-A1}.
$$

### （3）错误默认网关的影响

WWW 服务器 `111.123.15.3` 与主机 1 `111.123.15.4/24` 同网段，通信不需要经过默认网关，因此仍可访问。

访问 Internet 必须把分组交给真正的路由器 `111.123.15.1`。题设却把默认网关配置为 DHCP 服务器 `111.123.15.2`，该设备不承担路由转发，因此不能正常访问 Internet。

</ExamExplanation>

</ExamSolution>

**116. 2016 年第 41 题**

题图网络中，H3 访问 Web 服务器 S。S 为新 TCP 连接分配 20KB（$K=1024$）接收缓存，最大报文段长度 $MSS=1\text{ KB}$，平均往返时间 $RTT=200\text{ ms}$。H3 建立连接时初始序号为 100，并持续以 MSS 大小发送数据；拥塞窗口初始阈值为 32KB。S 对每个收到的段都立即确认并通告新的接收窗口。连接建立后，S 的接收缓存只有数据写入，没有数据被应用程序取走。

<img src="/img/408/past-exams-large-questions/04-计算机网络/assets/2016-41-figure-001.svg" alt="2016 年第 41 题网络拓扑" />

1. H3 收到的第二次握手 TCP 段中，SYN、ACK 标志位分别是多少？确认号是多少？
2. H3 收到第 8 个确认段时，S 通告的接收窗口是多少？此时 H3 的拥塞窗口和发送窗口分别是多少？
3. 当 H3 的发送窗口变为 0 时，下一个待发送数据段的序号是多少？从发送第 1 个数据段到发送窗口变为 0，平均数据传输速率是多少？忽略报文段发送时延。
4. 若通信已结束，在时刻 $t$ H3 请求断开连接，从 $t$ 起 S 最快经过多长时间释放连接？

<ExamSolution>

<ExamAnswer>

1. `SYN=1`，`ACK=1`，确认号为 `101`。
2. 接收窗口为 $12\text{ KB}$；拥塞窗口为 $9\text{ KB}$；发送窗口为 $9\text{ KB}$。
3. 下一个待发送数据段序号为 $20581$；平均数据传输速率为

$$
\boxed{163.84\text{ kbps}}.
$$

4. 最短为 $300\text{ ms}$。

</ExamAnswer>

<ExamExplanation>

### （1）第二次握手

H3 的初始序号为 100。第一次握手的 SYN 段虽然不携带应用数据，但会占用一个序号，因此 S 返回第二次握手时：

$$
SYN=1,\qquad ACK=1,\qquad ack=100+1=101.
$$

### （2）第 8 个 ACK 到达时的三个窗口

S 的接收缓存最初为 20KB，每收到 1 个 1KB 段就少 1KB 可用空间，且没有应用读取数据。收到 8 个段后：

$$
rwnd=20-8=12\text{ KB}.
$$

慢开始初始拥塞窗口为 1 MSS，即 1KB；每收到一个对新数据的 ACK，$cwnd$ 增加 1 MSS，所以收到 8 个 ACK 后：

$$
cwnd=1+8=9\text{ KB}.
$$

实际发送窗口为

$$
swnd=\min(cwnd,rwnd)=\min(9,12)=\boxed{9\text{ KB}}.
$$

### （3）序号与平均速率

S 最终缓存满 20KB，也就是已经接收

$$
20\times1024=20480\text{ B}
$$

数据。H3 第一个数据字节序号为 101，因此下一个待发送字节序号是

$$
101+20480=\boxed{20581}.
$$

慢开始发送轮次可按 $1,2,4,8,5$ KB 理解，共 5 个 RTT 后 20KB 数据均被确认、接收窗口降为 0，因此历时

$$
5\times200\text{ ms}=1\text{ s}.
$$

平均数据传输速率为

$$
\frac{20\times1024\times8}{1}
=163840\text{ bit/s}
=\boxed{163.84\text{ kbps}}.
$$

原整理中把 `20 KB/s` 错换算成了 `20.48 kbps`，这里已按字节与比特关系修正。

### （4）S 最快释放连接的时间

H3 的 FIN 到达 S 需要约半个 RTT；S 无待发送数据，可立即回复 ACK 并发送自己的 FIN；该 FIN 到达 H3 再用半个 RTT；H3 的最终 ACK 返回 S 又用半个 RTT。因此 S 收到最终 ACK 并释放连接的最短时间为

$$
\frac32 RTT
=1.5\times200\text{ ms}
=\boxed{300\text{ ms}}.
$$

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

**117. 2017 年第 47 题**

甲、乙双方均使用后退 N 帧协议（GBN）进行持续双向数据传输，并始终采用捎带确认。帧长均为 1000B，信道速率为 100Mbps，$RTT=0.96\text{ ms}$。

用 $S_{x,y}$ 表示甲发送的数据帧，用 $R_{x,y}$ 表示甲收到的乙方数据帧，其中 $x$ 为发送序号，$y$ 为确认序号（即希望接收对方的下一帧序号）。发送序号与确认序号字段均为 3bit。$t_0$ 时甲方发送序号与确认序号均为 0，$t_1$ 时甲方仍有足够多数据待发送。

<img src="/img/408/past-exams-large-questions/04-计算机网络/assets/2017-47-figure-001.svg" alt="2017 年第 47 题 GBN 时序图" />

1. 对图 (a)，从 $t_0$ 到 $t_1$，甲方可以断定乙方已经正确接收多少个甲方数据帧？分别是哪几个帧？
2. 对图 (a)，从 $t_1$ 起，在不超时且未收到乙方新数据帧前，甲最多还能发送多少个数据帧？其中第一个和最后一个帧分别是什么？
3. 对图 (b)，从 $t_1$ 起，在不出现新的超时且未收到乙方新数据帧前，甲需要重发多少个数据帧？重发的第一个帧是什么？
4. 甲方可达到的最大信道利用率是多少？

<ExamSolution>

<ExamAnswer>

1. 已正确接收 3 帧：$S_{0,0}$、$S_{1,0}$、$S_{2,0}$。
2. 最多还能发送 5 帧；第一帧为 $S_{5,2}$，最后一帧为 $S_{1,2}$。
3. 需要重发 3 帧；第一帧为 $S_{2,3}$。
4. 最大信道利用率为

$$
\boxed{50\%}.
$$

</ExamAnswer>

<ExamExplanation>

### （1）累计确认

图 (a) 中甲在 $t_1$ 前收到 $R_{1,3}$、$R_{3,3}$，其中确认号 $3$ 表示乙方下一帧期望收到序号 3，也就是已经按序正确收到序号 0、1、2。因此甲可以确认

$$
S_{0,0},\quad S_{1,0},\quad S_{2,0}
$$

这 3 帧已被正确接收。

### （2）图 (a) 中还能继续发多少帧

序号字段 3bit，共有

$$
2^3=8
$$

个序号。GBN 要避免新旧帧混淆，发送窗口最大为

$$
W_T\le2^3-1=7.
$$

`t1` 前，甲已经发送到序号 4；累计 ACK=3 后，尚未确认的是序号 3、4，共占用 2 个窗口位置，因此还可发送

$$
7-2=5
$$

帧。

甲已按序收到乙方的 $R_{0,1}$、$R_{1,3}$，而 $R_{3,3}$ 因缺少序号 2 的帧不能按序接收，因此甲希望乙下一帧发送序号 2，捎带确认号取 2。

接下来的发送序号依次为

$$
5,6,7,0,1,
$$

所以第一帧和最后一帧分别为

$$
\boxed{S_{5,2}},\qquad\boxed{S_{1,2}}.
$$

### （3）图 (b) 中的超时重传

图 (b) 中 $S_{2,0}$ 超时，而 GBN 要从最早未确认帧开始，把它以及随后所有已发送但未确认的帧全部重传。此时未确认的是序号 2、3、4，共 3 帧。

甲已经按序收到乙的序号 0、1、2 三帧，因此下一帧期望序号为 3，重传第一帧应写为

$$
\boxed{S_{2,3}}.
$$

### （4）最大信道利用率

一帧发送时延为

$$
T_d=\frac{1000\times8}{100\times10^6}
=0.08\text{ ms}.
$$

捎带确认帧长度相同，因此

$$
T_a=0.08\text{ ms}.
$$

最大窗口 $N=7$，故最大利用率为

$$
U=\frac{N T_d}{T_d+RTT+T_a}
=\frac{7\times0.08}{0.08+0.96+0.08}
=\boxed{0.5=50\%}.
$$

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

**118. 2018 年第 47 题**

某公司把地址空间 `192.168.1.0/24` 均分给销售部和技术部两个子网。销售部子网 MTU 为 1500B，技术部子网 MTU 为 800B，已有地址分配如下图。

<img src="/img/408/past-exams-large-questions/04-计算机网络/assets/2018-47-figure-001.svg" alt="2018 年第 47 题两个部门子网与 MTU" />

1. 销售部子网的广播地址是什么？技术部子网的网络地址是什么？若每台主机只分配一个 IP 地址，技术部子网还可以再连接多少台主机？
2. 主机 `192.168.1.1` 向 `192.168.1.208` 发送一个总长度 1500B、首部长度 20B 的 IP 分组。路由器经 F1 转发到 MTU=800B 的技术部子网时需要分片。若尽可能采用最大分片，一个最大分片可封装多少字节数据？至少分成几个分片？各分片的片偏移量是多少？

<ExamSolution>

<ExamAnswer>

1. 销售部广播地址为 `192.168.1.127`；技术部网络地址为 `192.168.1.128`；技术部还可连接 45 台主机。
2. 最大分片数据长度为 $776\text{ B}$；至少分为 2 个分片；两个分片的片偏移分别为 $0$ 和 $97$。

</ExamAnswer>

<ExamExplanation>

### （1）两个 `/25` 子网

把 `/24` 均分为两个子网，需要借 1 位主机位，因此得到：

$$
192.168.1.0/25,
\qquad
192.168.1.128/25.
$$

销售部使用前一个子网，所以广播地址为

$$
\boxed{192.168.1.127}.
$$

技术部网络地址为

$$
\boxed{192.168.1.128}.
$$

一个 `/25` 子网共有 128 个地址，可分配给主机/接口的地址数为

$$
128-2=126.
$$

技术部已分配 `192.168.1.129`～`192.168.1.208`，共

$$
208-129+1=80
$$

个地址；路由器 F1 接口还占用 `192.168.1.254`。因此还能分配

$$
126-80-1=\boxed{45}
$$

个地址给主机。

### （2）IP 分片

每个分片都要带 20B IP 首部。MTU 为 800B，因此理论最大数据区为

$$
800-20=780\text{ B}.
$$

除最后一个分片外，数据长度必须是 8B 的整数倍，所以取不超过 780 的最大 8 的整数倍：

$$
\left\lfloor\frac{780}{8}\right\rfloor\times8
=97\times8
=\boxed{776\text{ B}}.
$$

原 IP 分组数据量为

$$
1500-20=1480\text{ B}.
$$

因此两片即可：第一片 776B，第二片

$$
1480-776=704\text{ B}.
$$

片偏移以 8B 为单位，所以：

$$
\text{第 1 片偏移}=0,
$$

$$
\text{第 2 片偏移}=\frac{776}{8}=\boxed{97}.
$$

原整理中的“进行了分配”应为“进行了分片”，这里已修正。

</ExamExplanation>

</ExamSolution>

某网络拓扑如下图。R 为路由器，H1～H4 的 IP 地址和默认网关如图。可供选择的网络互连设备只有“无 VLAN 功能的以太网交换机”和“路由器”。

2. 哪些设备的接口需要配置 IP 地址？为相应接口配置正确的 IP 地址。
3. 为保证 H1～H4 能访问 Internet，R 需要提供什么服务？
4. 若 H3 发送一个目的地址为 `192.168.1.127` 的 IP 数据报，网络中哪些主机会接收该数据报？

<ExamSolution>

<ExamAnswer>

1. 设备 1 为路由器；设备 2、设备 3 为以太网交换机。
2. 只有设备 1 的接口需要配置 IP 地址：
   - IF1：`192.168.1.254/30`；
   - IF2：`192.168.1.1/26`；
   - IF3：`192.168.1.65/26`。
3. R 需要提供 NAT 服务。
4. H4 会接收该数据报。

</ExamAnswer>

<ExamExplanation>

### （1）为什么设备 1 必须是路由器

H1、H2 属于

$$
192.168.1.0/26,
$$

H3、H4 属于

$$
192.168.1.64/26.
$$

两个子网属于不同广播域，必须由三层设备互联，所以设备 1 是路由器。设备 2、3 只需在各自局域网内部转发以太网帧，因此使用二层以太网交换机。

### （2）设备 1 的三个接口地址

IF1 与 R 的 `192.168.1.253/30` 相连。该 `/30` 子网是

$$
192.168.1.252/30,
$$

其中 `.252` 为网络地址、`.255` 为广播地址，可用主机地址只有 `.253`、`.254`。R 已使用 `.253`，因此设备 1 的 IF1 应为

$$
\boxed{192.168.1.254/30}.
$$

H1、H2 默认网关均为 `192.168.1.1`，所以 IF2 为 `192.168.1.1/26`；H3、H4 默认网关均为 `192.168.1.65`，所以 IF3 为 `192.168.1.65/26`。

普通二层交换机用于数据转发的端口不需要配置 IP 地址。

### （3）NAT

H1～H4 使用 `192.168.x.x` 私有地址，不能直接作为 Internet 全局地址使用。R 连接 Internet 时需要进行网络地址转换，因此应提供 NAT 服务。

### （4）定向广播地址

H3 地址为 `192.168.1.66/26`，所在子网为 `192.168.1.64/26`。该子网广播地址为

$$

$$

因此该数据报在 H3 所在广播域内广播，H4 会接收；路由器不会把这种二层广播继续转发到另一个 LAN，所以 H1、H2 不会接收。

**120. 2020 年第 47 题**

某校园网有两个局域网，经 R1、R2、R3 互联后接入 Internet。S1、S2 为以太网交换机。两个局域网都使用 `192.168.1.0/24` 私有地址，R2、R3 开启 NAT，拓扑如下。

<img src="/img/408/past-exams-large-questions/04-计算机网络/assets/2020-47-figure-001.svg" alt="2020 年第 47 题校园网与双 NAT 拓扑" />

NAT 转换表结构如下。

<img src="/img/408/past-exams-large-questions/04-计算机网络/assets/2020-47-figure-002.svg" alt="2020 年第 47 题 NAT 转换表结构" />

1. 为使 H2、H3 能通过 HTTP 默认端口访问 Web 服务器，需要进行什么配置？
2. H2 主动访问 Web 服务器时，将 HTTP 请求封装进 IP 数据报 P。分别给出：H2 发出 P 时、P 经 R3 转发后、P 经 R2 转发后，P 的源 IP 地址和目的 IP 地址。

<ExamSolution>

<ExamAnswer>

1. 在 R2 上配置静态 NAT/NAPT 端口映射：

| 外网 IP 地址 | 外网端口 | 内网 IP 地址 | 内网端口 |
| --- | ---: | --- | ---: |
| `203.10.2.2` | 80 | `192.168.1.2` | 80 |

2. 地址变化如下：

| 位置 | 源 IP 地址 | 目的 IP 地址 |
| --- | --- | --- |
| H2 发出时 | `192.168.1.2` | `203.10.2.2` |
| 经 R3 转发后 | `203.10.2.6` | `203.10.2.2` |
| 经 R2 转发后 | `203.10.2.6` | `192.168.1.2` |

</ExamAnswer>

<ExamExplanation>

### （1）为什么要在 R2 做端口映射

Web 服务器位于 R2 内网，地址为

$$
192.168.1.2:80.
$$

H2、H3 位于 R3 后方，并且两个局域网恰好使用相同的私有网段 `192.168.1.0/24`。外部主机不能直接用服务器私有地址进行跨 NAT 访问，因此需要让 R2 的公网侧地址 `203.10.2.2` 的 HTTP 端口 80 映射到内网服务器 `192.168.1.2:80`。

即：

$$
203.10.2.2:80
\longleftrightarrow
192.168.1.2:80.
$$

### （2）数据报经过两次 NAT 时的地址变化

H2 位于 R3 内网，它访问的是 R2 对外公布的公网地址，因此刚发出时：

$$
\text{源}=192.168.1.2,
\qquad
\text{目的}=203.10.2.2.
$$

P 到达 R3 后，R3 做源 NAT，把私有源地址改为自己的外网接口地址：

$$
\text{源}=203.10.2.6,
\qquad
\text{目的}=203.10.2.2.
$$

P 到达 R2 后，R2 根据静态端口映射做目的 NAT，将目的地址还原为 Web 服务器地址：

$$
\text{源}=203.10.2.6,
\qquad
\text{目的}=192.168.1.2.
$$

这样即使两个局域网内部都存在 `192.168.1.2`，通过各自 NAT 的公网地址仍能区分通信端点。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>
