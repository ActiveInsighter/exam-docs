# 第 3 章 数据链路层

## 3.2 流量控制与可靠传输机制

<Question id="408-7496cf-013" type="essay" tags="来源:2017考研408">

甲乙双方均采用后退 N 帧协议 (GBN) 进行持续的双向数据传输, 且双方始终采用捎带确认, 帧长均为 1000B。 Sx,y 和 Rx,y 分别表示甲方和乙方发送的数据帧, 其中:x 是发送序号； y 是确认序号 (表示希望接收对方的下一帧序号)；数据帧的发送序号和确认序号字段均为 3 比特。信道传输速率为 100Mbps,RTT = 0.96ms。右图给出了甲方发送数据帧和接收数据帧的两种场景, 其中 t0 为初始时刻, 此时甲方的发送和确认序号均为 0, t1 时刻甲方有足够多的数据待发送。请回答下列问题:

![第 3 章 数据链路层 3.2 第11题：图表，见原 PDF 第18页附近](/img/questions/408/computer-network-3-2-q11.svg)

   (1) 对于图 (a), t0 时刻到 t1 时刻期间, 甲方可以断定乙方已正确接收的数据帧数是多少？正确接收的是哪几个帧 (请用 Sx,y 形式给出)?
   (2) 对于图 (a), 从 t1 时刻起, 甲方在不出现超时且未收到乙方新的数据帧之前, 最多还可以发送多少个数据帧？其中第一个帧和最后一个帧分别是哪个 (请用 Sx,y 形式给出)?
   (3) 对于图 (b), 从 t1 时刻起, 甲方在不出现新的超时且未收到乙方新的数据帧之前,需要重发多少个数据帧? 重发的第一个帧是哪个 (请用 Sx,y 形式给出)?
   (4) 甲方可以达到的最大信道利用率是多少？

<Solution>

**【解析】**

(1) $t_0$ 到 $t_1$ 期间，乙方已经接收到了 $S_{0,0}$、$S_{1,0}$、$S_{2,0}$ 共三个数据帧，因此甲方可以确定乙方已经确认接收的数据帧数为 3。在 $t_1$ 之前甲方收到的最后一个乙方发来的帧为 $R_{3,3}$，即乙方希望甲方发送序号为 3 的帧，代表序号为 0～2 的帧已被正确接收。

(2) 从 $t_1$ 时刻起，甲在不出现超时且未收到乙方新的数据帧之前，最多还可以发送的数据帧个数为 5，其中 $S_{5,2}$ 为第一个数据帧，$S_{1,2}$ 为最后一个数据帧。根据发送序号为 3 比特，可以得出窗口大小为 $2^3=8$ 个。在 GBN 协议中，发送窗口最大序号个数为：$8-1=7$，已经发送 $S_{3,0}$ 和 $S_{4,1}$ 2 个数据帧，所以还可以发送 5 个数据帧。此时应该发送的下一帧序号为 5，同时已经收到了接收方的第 1、3 帧，但没收到第 2 帧，所以确认序号为 2，发送的第一帧为 $S_{5,2}$。由于一共可以发送 5 帧，所以发送的最后一帧序号为 $(4+5)\bmod8=1$，最后一帧为 $S_{1,2}$。

(3) 甲方需要重发的数据帧个数为 3，$S_{2,3}$ 为重发的第一个帧。甲方一共发送了序号为 0～4 的 5 个帧，但直到 $t_1$ 只收到了对第 0、1 帧的确认（确认号为 2），所以需要重新发送第 2～4 帧。重发的第一帧序号为 2，由于收到了乙方发来的序号为 2 的帧，所以确认号为 3，故重发的第一个帧为 $S_{2,3}$。

(4) 甲方可以达到的最大信道利用率为 50%。发送一帧的传输时延为 $T_d=1000\times8\mathrm{bit}\div100\mathrm{Mbps}=80\mu\mathrm{s}$。发送窗口为 7，所以在收到第一个确认帧之前可以发送 7 帧，一个发送周期长度为 $2\times T_d+\mathrm{RTT}=1.12\mathrm{ms}$。可以得到最大信道利用率为 $7\times80\mu\mathrm{s}\div1.12\mathrm{ms}=50\%$。

> **【点评】** 难题。本题深入考查 GBN 协议的相关计算：以双向捎带确认的 GBN 场景，综合考查累计确认的含义、发送窗口大小与序号空间关系、超时重传范围、捎带确认下的确认号填写，以及信道利用率公式。
>
> 本题作为本套试卷的最后一题，考场上分配给此题的时间应该不多，题目设置的得分点多，细节多，计算量也较大，给考生做题带来很大的心理压力，很难静下心来分析清楚。

## 3.3 介质访问控制

<Question id="408-7496cf-025" number={1} type="essay" tags="来源:2010考研408">

某局域网采用 CSMA/CD 协议实现介质访问控制, 数据传输速率为 10Mbit/s, 主机甲和主机乙之间的距离为 2km, 信号传播速度为 200000km/s。请回答下列问题, 要求说明理由或写出计算过程。
   (1) 若主机甲和主机乙发送数据时发生冲突, 则从开始发送数据时刻起, 到两台主机均检测到冲突时刻止, 最短需经过多长时间？最长需经过多长时间 (假设主机甲和主机乙发送数据过程中,其他主机不发送数据)?
   (2) 若网络不存在任何冲突与差错, 主机甲总是以标准的最长以太网数据帧 (1518B) 向主机乙发送数据, 主机乙每成功收到一个数据帧后立即向主机甲发送一个 64B 的确认帧, 主机甲收到确认帧后方可发送下一个数据帧。此时主机甲的有效数据传输速率是多少 (不考虑以太网的前导码)？

<Solution>

**【解析】**

(1) 主机甲和乙之间的单向传播时延 $t=2\text{km}\div200000\text{km/s}=10\ \mu\text{s}$。两台主机均检测到冲突，所需的最长时间和最短时间，如下图所示，分别对应两种极端情况：

- <u>最短时间</u>：如下图 (a) 所示，主机甲和主机乙同时开始发送数据，信号在信道正中间发生冲突，冲突信号继续相向传播。当主机甲和乙同时检测到冲突时，最短需经过单向传播时延 $t=10\ \mu\text{s}$。
- <u>最长时间</u>：如下图 (b) 所示，主机甲先发送一个数据帧，当该数据帧即将到达主机乙时，主机乙也开始发送一个数据帧。此时，主机乙将立即检测到冲突。当冲突信号从主机乙传播到主机甲时，主机甲检测到冲突。当两台主机均检测到冲突时，最长需经过 2 倍的单向传播时延 = 20μs。

![两台主机均检测到冲突的最短和最长时间](/img/2010-q47-collision.svg)

(2) 有效数据传输速率 = 有效数据长度 ÷ 数据发送周期。下面分别求有效数据长度和数据发送周期。① <u>求有效数据长度</u>。不考虑前导码的以太网帧的格式如下。

| 6B | 6B | 2B | 46B～1500B | 4B |
| --- | --- | --- | --- | --- |
| 目的地址 | 源地址 | 类型 | 数据部分（IP 数据报） | FCS |

最长以太网数据帧 1518B，去掉帧首部和尾部长度，其有效数据部分 = 1518B - 18B = 1500B。

② <u>求数据发送周期</u>。主机甲和乙数据传输过程的示意图如下所示。

![主机甲和乙数据传输过程](/img/2010-q47-transmission.svg)

主机甲发送一帧的发送时间 $T_d=1518\times8\text{b}\div10\text{Mb/s}=1214.4\ \mu\text{s}$。主机乙发送确认帧的发送时间 $T_a=64\times8\text{b}\div10\text{Mb/s}=51.2\ \mu\text{s}$。往返传播时延 $RTT=2\times2\text{km}\div200000\text{km/s}=20\ \mu\text{s}$。则一个发送周期的总时间 $T=T_d+T_a+RTT=(1214.4+51.2+20)\ \mu\text{s}=1285.6\ \mu\text{s}$。

主机甲的有效数据传输速率 = $\frac{1500\text{B}}{T}=\frac{1500\text{B}}{1285.6\ \mu\text{s}}\approx9.33\text{Mbps}$。

{/* 原书速率算式的分子使用字节，换算为 Mbps 时隐含乘以 8。 */}

**【注意】** 此题易错点为求的是有效数据传输率而非数据传输率，此外考生也需记住以太网帧前导码和帧首部以及帧尾部都不属于有效传输数据。

</Solution>

<Question id="408-7496cf-026" type="essay" tags="来源:2022考研408">

某网络拓扑如下图所示, R 为路由器, S 为以太网交换机, AP 是 802.11 接入点, 路由器的E0 接口和 DHCP 服务器的 IP 地址配置如图中所示； H1 与 H2 属于同一个广播域,但不属于同一个冲突域； H2 和 H3 属于同一个冲突域； H4 和 H5 已经接入网络, 并通过 DHCP 动态获取了 IP 地址。现有路由器、 100BaseT 以太网交换机和 100BaseT 集线器 (Hub) 三类设备各若干台。

![第 3 章 数据链路层 3.3 第13题：网络拓扑图，见原 PDF 第24页附近](/img/questions/408/computer-network-3-3-q13.svg)

请回答下列问题:
   (1) 设备 1 和设备 2 应该分别选择哪类设备？
   (2) 若信号传播速度为 $2\times 10^8\text{m/s}$, 以太网最小帧长为 64B, 信号通过设备 2 时会产生额外的 1.51μs 的时间延迟, 则 H2 与 H3 之间可以相距的最远距离是多少?
   (3) 在 H4 通过 DHCP 动态获取 IP 地址过程中, H4 首先发送了 DHCP 报文 M,M 是哪种 DHCP 报文? 路由器 E0 接口能否收到封装 M 的以太网帧?S 向 DHCP 服务器转发的封装 M 的以太网帧的目的 MAC 地址是什么?
   (4) 若 H4 向 H5 发送一个 IP 分组 P, 则 H5 收到的封装 P 的 802.11 帧的地址 1、地址 2 和地址 3 分别是什么?

<Solution>

**【解析】**

(1) 由于路由器能隔离广播域和冲突域，以太网交换机只能隔离冲突域，集线器既不能隔离广播域也不能隔离冲突域。从题目所给条件来看（在题目给出的三类设备中选择），设备 1 选择 100BaseT 以太网交换机，设备 2 选择 100BaseT 集线器。

(2) 100BaseT 表示数据传输速率为 100Mb/s。传播时延 = 信号在信道上的传播时延 + 信号通过 H2 时产生的 $1.51\mathrm{\mu s}$ 延迟。设相距最远两个站点之间的距离为 $L$。争用期是相距最远两个站点之间的信号传播时延 $\tau$ 的两倍。最小帧长 = 争用期 × 数据传输速率，即 $64\mathrm{B}=2\times\tau\times100\mathrm{Mb/s}$。再将传播时延 $\tau$ 的计算公式，代入上式可得：

$$
64\times8=\left(\frac{L}{2\times10^8}+1.51\times10^{-6}\right)\times2\times100\times10^6
$$

求得最远距离 $L=210\mathrm{m}$。

{/* 原书写“信号通过 H2 时产生的延迟”，题干为“信号通过设备 2 时”产生的延迟。原文保留。 */}

(3) ① 在 H4 通过 DHCP 动态获取 IP 地址的过程中，H4 首先发送了 DISCOVER（发现）报文，所以 M 是 DISCOVER（发现）报文。② 路由器的接口 E0 与 H4 在同一个广播域，DISCOVER（发现）报文以广播形式发出，故路由器接口 E0 能收到 M。③ S 向 DHCP 服务器转发的封装 M 的以太网帧是广播帧，所以目的地址是 FF-FF-FF-FF-FF-FF。

(4) H4 向 H5 发送一个 IP 分组 P，该分组 P 会经过 AP，AP 再将此帧转发给 H5，则 H5 收到的封装 P 的 802.11 帧属于“From AP”的 802.11 帧。根据 802.11 无线数据帧格式，可知地址 1 为接收方 H5 的 MAC 地址 00-11-11-11-11-E1，地址 2 为 AP 的 MAC 地址 00-11-11-11-11-C1，地址 3 为发送方 H4 的 MAC 地址 00-11-11-11-11-D1。

**【提示】** 关于 802.11 帧多种特殊格式的详解，在竞成《计算机网络考研复习全书》无线局域网小节中有介绍。

</Solution>
