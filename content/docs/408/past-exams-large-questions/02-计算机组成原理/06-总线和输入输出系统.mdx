## 2009 年第 43 题

<ExamQuestion>

**37. 2009 年第 43 题**

某计算机的 CPU 主频为 $500\text{ MHz}$，CPI 为 $5$，即执行每条指令平均需要 $5$ 个时钟周期。

某外设的数据传输率为 $0.5\text{ MB/s}$，采用中断方式与主机进行数据传送，以 $32$ 位为一个传输单位。对应的中断服务程序包含 $18$ 条指令，中断服务的其他开销相当于 $2$ 条指令的执行时间。

请回答：

1. 在中断方式下，CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比是多少？
2. 当该外设的数据传输率达到 $5\text{ MB/s}$ 时，改用 DMA 方式传送数据。假定每次 DMA 传送块大小为 $5000\text{ B}$，DMA 预处理和后处理的总开销为 $500$ 个时钟周期。若 DMA 与 CPU 之间没有访存冲突，则 CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比是多少？

<ExamSolution>

<ExamAnswer>

1. 中断方式中，CPU 用于此外设 I/O 的时间占比为 **$2.5\%$**。
2. DMA 方式中，若 DMA 与 CPU 不争用存储器，CPU 的管理时间占比为 **$0.1\%$**。

</ExamAnswer>

<ExamExplanation>

### 一、这类题的核心：占用率 = 每秒 CPU 消耗周期 / 每秒 CPU 可用周期

题目给出主频 $500\,\mathrm{MHz}$，即 CPU 每秒有 $500\times10^6$ 个时钟周期，单周期为 $1/(500\times10^6)=2\,\mathrm{ns}$。CPI=5 是**平均每条指令的周期数**，不能直接当成“每字节开销”；中断服务程序包含 18 条指令，另外还有折合 2 条指令的额外开销。

设每次数据搬运大小为 $B$ 字节、外设速度为 $v$ 字节/秒、每次 CPU 消耗 $c$ 周期、CPU 主频为 $f$ 周期/秒。理想稳定传输时：

$$
N=\frac{v}{B}\quad(\text{次/秒}),\qquad
U=\frac{N\times c}{f}=\frac{vc}{Bf}.
$$

最后再乘 $100\%$ 得百分比。这套公式既适用于每字中断，也适用于 DMA 的**每块 CPU 管理开销**，但 DMA 搬数据的总时间原则上不能当成 CPU 必然忙于复制的时间。

### 二、中断方式：先算每次中断的 CPU 时间，再算每秒中断次数

中断数据单位为 32 bit = 4B。按题目使用十进制 MB，

$$
N_{INT}=\frac{0.5\times10^6\ \mathrm{B/s}}{4\ \mathrm{B/次}}=125000\ \mathrm{次/s}.
$$

每次 CPU 处理开销是

$$
C_{INT}=(18+2)\ \mathrm{条/次}\times5\ \mathrm{周期/条}=100\ \mathrm{周期/次}.
$$

因此每秒 CPU 用于该设备的周期是 $125000\times100=12.5\times10^6$：

$$
U_{INT}=\frac{12.5\times10^6}{500\times10^6}\times100\%=\boxed{2.5\%}.
$$

**检验**：每次服务时间是 $100\times2\,\mathrm{ns}=200\,\mathrm{ns}$；每秒 12.5 万次对应 $0.025\,\mathrm s$，仍为 2.5%。如果忘记“另外 2 条等效指令”，将误算为 $2.25\%$。

### 三、DMA 方式：只计算 CPU 初始化与收尾，不把 DMA 传输量换算为指令数

DMA 每块 5000B，设备新速度是 $5\,\mathrm{MB/s}$，所以

$$
N_{DMA}=\frac{5\times10^6}{5000}=1000\ \mathrm{块/s}.
$$

题设给的是**预处理 + 后处理总开销 500 个时钟周期/块**，不是 500 条指令，因此千万不能再次乘 CPI=5。每秒 CPU 管理成本

$$
C_{DMA}=1000\times500=5\times10^5\ \mathrm{周期/s}.
$$

故

$$
U_{DMA}=\frac{5\times10^5}{500\times10^6}\times100\%=\boxed{0.1\%}.
$$

**为什么传输速率变大，CPU 占用率反而下降？** 中断每搬 4B 都进入一次服务程序，频繁保存现场和运行 ISR；DMA 每搬 5000B 才付一次管理开销，批量摊薄了 CPU 参与成本。DMA 并不意味着数据“瞬时到达”，只是数据实际移动过程主要由 DMA 控制器管理。本题专门说明没有访存冲突，因此无需另加 DMA 偷取周期、总线仲裁导致的 CPU 等待。

### 四、重难点：时间单位、频率和额外开销的三重区分

| 情况 | 正确处理 | 典型错误 |
| --- | --- | --- |
| $500\,\mathrm{MHz}$ | $500\times10^6$ 周期/秒 | 把 500MHz 直接当 500 周期/秒 |
| 32 bit 一单位 | $32/8=4\,\mathrm B$ | 按 32B/次计算 |
| 中断开销“等价 2 条指令” | $(18+2)\times CPI$ | 丢掉等效开销或多乘一次 |
| DMA 开销 500 **周期** | 直接使用 500 | 再乘 CPI=5 |
| 5MB/s | $5\times10^6$ B/s，按题库惯例的十进制 | 无依据改用 $2^{20}$ |
| DMA/CPU 不冲突 | 不计额外总线争用 | 把 DMA 传输的所有时间都算 CPU 忙时 |

### 五、模型变式：什么时候 DMA 不划算？

若按相同设备速率比较 CPU 管理开销，中断每 4B 消耗 100 周期，DMA 每块 500 周期；令块长为 $D$ B，得到

$$
\frac{100}{4}>\frac{500}{D}\iff D>20\ \mathrm B.
$$

也就是说，**仅在此题给定的两种管理成本、且不计总线冲突与缓冲区其他代价时**，块长大于 20B，DMA 的 CPU 参与开销/字节就低于中断。注意原题两小问设备速率不同，直接比较 $2.5\%$ 与 $0.1\%$ 的结论可以展示本题占用变化，但不能拿它当成完全控制变量的“DMA 比中断快 25 倍”普遍定理。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

## 2016 年第 44 题

<ExamQuestion>

**51. 2016 年第 44 题**

假定 CPU 主频为 $50\text{ MHz}$，CPI 为 $4$。设备 D 采用异步串行通信方式向主机传送 7 位 ASCII 字符，通信规程中有 1 位奇校验位和 1 位停止位。从 D 接收启动命令到字符送入 I/O 端口需要 $0.5\text{ ms}$。请回答下列问题，并说明理由。

1. 每传送一个字符，在异步串行通信线上共需传输多少位？在设备 D 持续工作过程中，每秒钟最多可向 I/O 端口送入多少个字符？
2. 设备 D 采用中断方式进行输入/输出，工作过程如下图所示。I/O 端口每收到一个字符申请一次中断，中断响应需 10 个时钟周期，中断服务程序共有 20 条指令，其中第 15 条指令启动 D 工作。若 CPU 需从 D 读取 1000 个字符，则完成这一任务所需时间大约是多少个时钟周期？CPU 用于完成这一任务的时间大约是多少个时钟周期？在中断响应阶段 CPU 进行了哪些操作？

<img src="/img/408/past-exams-large-questions/02-计算机组成原理/assets/2016-44-figure-001.svg" alt="2016 年第 44 题设备 D 与 CPU 中断工作时序" />

<ExamSolution>

<ExamAnswer>

1. 每帧共 **10 bit**（起始 1、数据 7、奇校验 1、停止 1）；设备连续工作时每秒最多向端口提供 **2000 个字符**。
2. 按题设忽略首尾细微差别，任务完成约需 **$2.507\times10^7$ 个 CPU 时钟周期**。若从首次启动开始计时、直到第 1000 次 ISR 全部执行结束，精确计为 **$25\,070\,020$ 周期**；CPU 实际用于中断响应与 ISR 的时间为 **$90\,000$ 周期**。中断响应主要包括中断允许状态处理、保存断点、识别中断源或取得向量并转入 ISR；通用寄存器等额外现场通常由 ISR 软件保存（具体取决于体系结构）。

</ExamAnswer>

<ExamExplanation>

### 一、先拆开三条独立时间线：串行帧、设备工作与 CPU 服务

- **串行帧长度**：异步串行通信无论 ASCII 数据位数多少，都不能漏算起始位；题设给出数据位 7、奇校验 1、停止 1，再加起始位 1，故 $L=1+7+1+1=10\,\mathrm{bit/字符}$。校验位用于差错**检测**（奇数个 1），不是纠错编码。
- **设备自身生产节拍**：收到启动命令后 $0.5\,\mathrm{ms}$ 才送入一个字符；设备连续启动时最大字符率为 $1/(0.5\times10^{-3})=\boxed{2000\,\mathrm{字符/s}}$。没有给出独立的波特率，不能用 $10\,\mathrm{bit}$ 再除一次设备工作时间。
- **CPU 时钟基准**：主频 $50\,\mathrm{MHz}$，每周期 $20\,\mathrm{ns}$，所以设备一次工作折合

$$
C_D=50\times10^6\times0.5\times10^{-3}=\boxed{25\,000\ \text{周期}}.
$$

**考点**：设备等待的 25000 拍属于**墙上时间（经历时间）**，并不表示 CPU 执行了 25000 拍 I/O 指令。在设备工作的同时，CPU 可以执行其他程序。

### 二、按“重新启动设备”切段，才不会把最后 5 条 ISR 指令重复计算

一次中断的 CPU 工作包括：响应 10 拍，ISR 共 $20\times4=80$ 拍，总计 90 拍。但**第 15 条指令**便重新启动设备，因此从前一次设备开始到下一次设备开始，包含的串行路径为

$$
C_{\mathrm{launch}\to\mathrm{launch}}=25\,000+10+15\times4
=\boxed{25\,070\ \text{拍}}.
$$

余下 5 条 ISR 指令在下一次设备运作时即可执行，不应算成两次启动之间的串行等待。图示所对应的时序如下：

| 阶段 | 设备 | CPU 对该设备的动作 | 时间（CPU 拍） |
| --- | --- | --- | ---: |
| A | D 从接令到字符到达 I/O 端口 | 可执行其他工作 | 25000 |
| B | 字符到达并发中断 | 响应并进入 ISR | 10 |
| C | D 尚未被重新启动 | 执行 ISR 前 15 条，在第 15 条重新启动 D | 60 |
| D | 下一字符的生产已经开始 | ISR 余下 5 条并返回 | 20（与下一次设备工作重叠） |

最后一个字符不再需要启动下一次 D，故若把**最后一次 ISR 全部完成**作为任务终点，严谨的周期数为

$$
\begin{aligned}
C_{\mathrm{elapsed}}
&=1000\underbrace{(25\,000+10)}_{\text{每次设备工作及中断响应}}
+999\underbrace{(15\times4)}_{\text{前 999 次触发后续启动}}+20\times4\\
&=\boxed{25\,070\,020\ \text{拍}}.
\end{aligned}
$$

作为考场近似算法，也可以采用 $1000\times25\,070\approx2.507\times10^7$ 拍，差距仅 20 拍。**若“完成任务”定义为最后一个字符刚被硬件放入端口**，则终点还要早于最后一次 ISR；答题时注明采用的终点事件即可。

### 三、CPU 真正用于任务的周期不能用上述经历时间代替

每次中断响应 + 执行全部 ISR 共 $10+20\times4=90$ 拍，处理 1000 个字符累计占用 CPU

$$
C_{\mathrm{CPU,I/O}}=1000\times90=\boxed{90\,000\ \text{拍}},
\qquad t_{\mathrm{CPU,I/O}}=90\,000\times20\,\mathrm{ns}=1.8\,\mathrm{ms}.
$$

整个过程经历约 $0.5014\,\mathrm{s}$，但 CPU 用于该 I/O 的时间只有 $1.8\,\mathrm{ms}$，余下时间可用于其他计算或等待调度。若追问这段任务的平均 CPU 占用率，按包含末次 ISR 的时间约为 $90\,000/25\,070\,020\approx0.359\%$；它不是题目第（2）问直接要求的“CPU 占用周期数”。

### 四、中断响应、ISR 和 DMA 的三层职责要区分

**中断响应硬件**通常在可响应时检查优先级/屏蔽，保存返回断点和必要的处理器状态，取得 ISR 入口并修改 PC 等控制状态；**ISR 软件**通常保存需要的通用寄存器、读取端口、更新缓冲区、向设备发下一次启动命令、恢复现场并中断返回。不能简单说“所有通用寄存器都必由中断响应硬件保存”。DMA 则进一步让大批量实际数据搬运不必逐字符经 CPU 指令完成。

**常见失分点**：漏起始位；把 $0.5\,\mathrm{ms}$ 当作 CPU 服务时间；将 ISR 的 20 条而非前 15 条全部计入启动间隔；忘记最终一次 ISR 的尾部；把总 CPU 周期误当总历时。

</ExamExplanation>

</ExamSolution>

## 2018 年第 43 题

<ExamQuestion>

**55. 2018 年第 43 题**

假定计算机主频为 $500\text{ MHz}$，CPI 为 $4$。现有设备 A 和 B，其数据传输率分别为 $2\text{ MB/s}$ 和 $40\text{ MB/s}$，对应 I/O 接口中各有一个 32 位数据缓冲寄存器。请回答，并给出计算过程。

1. 若设备 A 采用定时查询 I/O 方式，每次输入/输出至少执行 10 条指令。设备 A 最多间隔多长时间查询一次才不会丢失数据？CPU 用于设备 A 输入/输出的时间占 CPU 总时间的百分比至少是多少？
2. 在中断 I/O 方式下，若每次中断响应和中断处理的总时钟周期数至少为 400，则设备 B 能否采用中断 I/O 方式？为什么？
3. 若设备 B 采用 DMA 方式，每次 DMA 传送的数据块大小为 $1000\text{ B}$，CPU 用于 DMA 预处理和后处理的总时钟周期数为 500，则 CPU 用于设备 B 输入/输出的时间占 CPU 总时间的百分比最大是多少？

<ExamSolution>

<ExamAnswer>

1. 32 位端口缓冲可容纳 4B，设备 A 每装满一次需要 **$2\,\mu\mathrm{s}$**，故查询间隔不应超过此值；按题设每次至少 10 条指令，CPU 时间占比**至少 $4\%$**。
2. 设备 B **不能在题设单个 4B 缓冲、每份数据中断一次的条件下可靠运行**：到达间隔 $0.1\,\mu\mathrm{s}$，一次最短响应与处理 $0.8\,\mu\mathrm{s}$，处理能力不足。
3. DMA 预处理与后处理占用率**至多按题设速率计算为 $4\%$**（设备持续以标称最高速率传输时达到该值；题目未计总线争用）。

</ExamAnswer>

<ExamExplanation>

### 一、先把题目统一成“每 4B 一次事件”的速率模型

接口数据缓冲宽度 $32\,\mathrm{bit}=4\,\mathrm B$。若设备不断以 $R$ B/s 到达数据，端口每装入一份 4B 数据的间隔

$$
\Delta t=\frac{4}{R}.
$$

题目按十进制 $1\,\mathrm{MB}=10^6\,\mathrm B$ 处理，时钟 $500\,\mathrm{MHz}$，每拍 $2\,\mathrm{ns}$；CPI=4，故 10 条指令占 40 拍（$80\,\mathrm{ns}$）。**注意缓冲寄存器仅有 4B，并非多深度 FIFO**：尚未取走旧数据前，新一份会造成丢数风险。

### 二、查询方式：最大查询间隔与最小 CPU 占比是一对边界条件

设备 A 数据率 $R_A=2\times10^6\,\mathrm{B/s}$，每隔

$$
\Delta t_A=\frac{4}{2\times10^6}=\boxed{2\,\mu\mathrm s}
$$

端口产生一个新数据单位。稳态下为了不遗漏，**不得比这个间隔更久才读取一次**；若计入任意相位误差、查询抖动和取数时间，实际设计应留裕度，不应把数学等号误认为现实中的充分保证。

最理想情况下每 $2\,\mu\mathrm s$ 执行一次 I/O，每秒至少 $5\times10^5$ 次；每次至少 $10\times4=40$ 拍，所以

$$
U_A\ge\frac{5\times10^5\times40}{500\times10^6}\times100\%
=\boxed{4\%}.
$$

这是**为该设备执行查询和数据传送的 CPU 处理开销下界**，不是说 CPU 必须空转满整个 $2\,\mu\mathrm s$。如果查询循环不断检查状态而不是按最优时间点查询，实际开销可能更高。

### 三、中断方式：先看 CPU 服务率，再判断能否应付数据到达率

设备 B 每生成 4B 仅需

$$
\Delta t_B=\frac{4}{40\times10^6}=\boxed{0.1\,\mu\mathrm s}.
$$

ISR 总开销下界 400 拍，单份服务时间 $400/(500\times10^6)=\boxed{0.8\,\mu\mathrm s}$。可将其等价为：

| 项目 | 数值 |
| --- | ---: |
| 每秒产生的 4B 数据份数 | $40\times10^6/4=10^7$ 次/秒 |
| CPU 最多完成的逐份中断次数 | $500\times10^6/400=1.25\times10^6$ 次/秒 |
| 仅凭逐份中断所需的 CPU 时间占比下界 | $10^7\times400/(500\times10^6)=800\%$ |

需要 $800\%$ 的单 CPU 时间，显然不可行，更何况端口只有一份缓冲。**结论有前提**：若改成 FIFO、合并中断、批量读或 DMA，已不再是“每 4B 一次中断”的原模型，不能沿用此否定结论。

### 四、DMA：分块计算管理成本，而不是把搬运时间归到 CPU

设备 B 每秒数据 $40\times10^6\,\mathrm B$，块长 1000B，按持续标称速率每秒形成 $4\times10^4$ 块，每块 CPU 预/后处理总计 500 拍：

$$
U_{\rm DMA}=\frac{(40\times10^6/1000)\times500}{500\times10^6}\times100\%
=\boxed{4\%}.
$$

注意题目问**最大**占比，是基于设备数据率达到给定上限以及每块处理成本固定；若设备并非持续满速，实际占比会更低。每块在设备侧形成时间是 $1000/(40\times10^6)=25\,\mu\mathrm s$，CPU 处理 500 拍仅 $1\,\mu\mathrm s$，但两者不是顺序相加的全程 CPU 忙时：DMA 控制器可独立搬运，且题目忽略访存争用。

### 五、三个考场万能检验

1. **带宽变事件率**：$\lambda=R/B$，B 是一次端口/中断/批量 DMA 的实际字节数，不能混用。
2. **饱和检测**：若事件间隔小于独占服务时间，单缓冲逐次响应不能持续运行；把 CPU 占比算出大于 $100\%$ 就应立即警觉。
3. **单位检测**：给“指令数”才乘 CPI；直接给“时钟周期数”绝不能再乘 CPI。DMA 省 CPU 时间不等于没有总线占用或没有传输延迟。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

### 原创第 196 题 · 中断与 DMA 的临界块大小和 CPU 时间

<ExamQuestion>

**196. 原创变式（2009-43 模型变化）。** 主频 $1\,\mathrm{GHz}$ 的 CPU 连接一个 $8\,\mathrm{MB/s}$ 设备，数据率按十进制 MB 计算。若采用程序中断方式，每中断一次传 8B，服务程序 30 条指令、CPI=2，附加保存与恢复现场共 20 个时钟周期；若采用 DMA，每块大小 $4096$B，每块预处理和后处理的 CPU 总开销为 2000 个时钟周期，不发生 CPU/DMA 访存冲突。忽略块尾不足一块的影响。

1. 两种方案的 CPU I/O 时间占比分别是多少？
2. 若保持各自每次 CPU 开销不变，只改变 DMA 块大小为 $D$B，求 DMA 的 CPU 占用低于中断占用的**临界块长条件**。
3. 若 DMA 每块另使 CPU 因总线争用损失 40 个周期，对第（1）问 DMA 占比有何影响？
4. 说明 DMA 更省 CPU 时间是否一定意味着该设备 I/O 响应延迟更低。

<ExamSolution>

<ExamAnswer>

1. 中断：$\boxed{8\%}$；DMA：$\boxed{0.390625\%}$。
2. $D>\boxed{200\,\mathrm B}$ 时 DMA 的 CPU 占用更低；等于 200B 时相同。
3. 每块 CPU 周期成本改为 2040，DMA 占比变为 $\boxed{0.3984375\%}$。
4. **不一定**；块大小、等待凑满一块的时间、DMA 初始化、总线争用及设备传输时间影响延迟。

</ExamAnswer>

<ExamExplanation>

中断每次 CPU 开销为

$$
C_{INT}=30\times2+20=80\quad\text{周期/8B}.
$$

$8\times10^6$B/s 的设备每秒中断 $8\times10^6/8=10^6$ 次，因此 CPU 花费 $80\times10^6$ 周期/秒。CPU 每秒拥有 $10^9$ 周期，故 $U_{INT}=80\times10^6/10^9=\boxed{8\%}$。

DMA 每秒搬 $8\times10^6/4096=1953.125$ 块，按题设忽略尾块效应，CPU 开销为

$$
U_{DMA}=\frac{(8\times10^6/4096)\times2000}{10^9}\times100\%=\boxed{0.390625\%}.
$$

这里 CPI=2 只用于**中断的 30 条指令**；DMA 的 2000 已经是时钟周期，不再乘 CPI。若 DMA 发生每块 40 周期额外 CPU 停顿，分子将每块成本改为 $2000+40=2040$，因此 $0.390625\%\times2040/2000=\boxed{0.3984375\%}$。

比较 CPU 每字节开销即可消去设备数据速率与 CPU 主频：

$$
\frac{2000}{D}<\frac{80}{8}=10
\quad\Longleftrightarrow\quad D>200\,\mathrm B.
$$

**注意“省 CPU 时间”与“完成单个请求的延迟”是不同优化目标。** DMA 可降低 CPU 平均占用，但如果必须等待凑够整块数据，小请求反而可能承受批处理等待；若中断能够及时响应每个 8B 数据单位，实时性有时更佳。本题临界点只比较 CPU 周期/字节，不是总响应时间或吞吐极限。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

### 原创第 197 题 · 串口帧长度、重启流水时序与中断实际占用

<ExamQuestion>

**197. 原创变式（2016-44 模型变化）。** CPU 主频为 $80\,\mathrm{MHz}$，CPI=2。设备 D 每次收到启动命令后，要先准备数据 $0.8\,\mathrm{ms}$，然后再通过 $9600\,\mathrm{baud}$ 的异步串行链路发送一帧（按 1 波特传 1 bit 计算）。一帧包括 1 位起始位、8 位数据位、1 位奇校验位和 2 位停止位。该设备不重叠处理多个字符，整个帧传完后向 CPU 发一次中断。中断响应 12 拍，ISR 共 18 条指令，其中第 12 条完成再次启动 D，后面 6 条与 D 下一次工作可以并行。首次启动已在 $t=0$ 时完成，无额外开销，要求接收 $400$ 字符。

1. 每帧共多少 bit？纯链路的最大帧率是多少？本题设备持续重复启动时的最大字符率约为多少？
2. 两次连续启动命令相距至少多少 CPU 拍？
3. 从第一次启动到第 400 次中断服务**全部完成**，经历多少 CPU 拍？
4. CPU 真正用于这 400 个字符中断响应和处理的周期数是多少？解释与第（3）问的区别。

<ExamSolution>

<ExamAnswer>

1. **12 bit/帧**；链路独立上界为 **800 帧/秒**；本题非重叠设备准备+发送的极限吞吐约为 **$487.8$ 字符/秒**。
2. 连续两次启动的最短间距为 **$164\,036$ CPU 拍**。
3. 全程为 **$65\,614\,412$ 拍**，约 $0.82018\,\mathrm s$。
4. CPU 中断处理共 **$19\,200$ 拍**，与约 6561 万拍的设备任务经历时间不可混同。

</ExamAnswer>

<ExamExplanation>

本题同时有三种“速率”：**波特率**只决定串行发送 12bit 的时间；设备的准备时间必须额外相加；**CPU** 中断响应和 ISR 又是另一条可以部分重叠的时间线。

帧位数为 $1+8+1+2=12$ bit，因此线传输每帧 $12/9600=1.25\,\mathrm{ms}$，仅看线路时 $9600/12=800$ 帧/s。但每次启动还需不重叠的 $0.8\,\mathrm{ms}$ 准备：

$$
T_D=0.8+1.25=2.05\,\mathrm{ms},\qquad r_D=1/0.00205\approx487.805\,\mathrm{字符/s}.
$$

设备一轮折合 CPU 拍数 $2.05\times10^{-3}\times80\times10^6=164000$。每次字符到达后中断响应 12 拍，前 12 条 ISR 指令占 $12\times2=24$ 拍后才启动下一轮，故两次启动间隔为 $164000+12+24=\boxed{164036}$ 拍。余下 6 条 ISR 指令占 12 拍，但在设备下一轮准备/传输期间执行，不能再重复累加到每轮启动间隔。

终点是第 400 次**完整 ISR 结束**，因此（第一次启动零开销）

$$
\begin{aligned}
C_{\rm total}
&=400(164000+12)+399(12\times2)+18\times2\\
&=65\,604\,800+9\,576+36=\boxed{65\,614\,412}.
\end{aligned}
$$

CPU 每字符真正做的工作为响应 12 拍与 ISR $18\times2=36$ 拍：

$$
C_{\rm CPU}=400(12+36)=\boxed{19\,200},
\quad t_{\rm CPU}=19\,200/(80\times10^6)=0.24\,\mathrm{ms}.
$$

**四步模型**：先列串口开销位 → 算一次设备工作的时间 → 找出重启指令位置决定跨批串行部分 → 单独统计所有中断的 CPU 实际占用。若把全部 18 条 ISR 都加到两次启动的间隔，就会把与下一次设备工作重叠的 6 条指令重复算入。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

### 原创第 198 题 · 轮询、中断合并与 DMA 的可行性比较

<ExamQuestion>

**198. 原创变式（2018-43 模型变化）。** CPU 为 $800\,\mathrm{MHz}$，CPI=2。设备每秒连续产生 $12.8\,\mathrm{MB}$ 数据（十进制），原始端口为 $64\,\mathrm{bit}$ 寄存器。考虑三种方案：

- **定时查询**：每取 8B 至少执行 16 条指令。
- **合并中断**：接口换成两块可交替使用的 $64\,\mathrm B$ 缓冲区，每填满一块触发一次中断，中断响应和取走该整块数据总开销 600 个 CPU 周期（两缓冲区可同时进行“填入”和“CPU 取走”）。
- **DMA**：每搬 $4096\,\mathrm B$ 产生一次管理事件，CPU 每块预/后处理占用 1000 周期，不计总线冲突。

求：（1）原始端口生成 8B 的时间间隔、按最低查询频率时的 CPU 时间占比；（2）合并中断每秒次数、CPU 占比，以及能否持续接收；（3）DMA 的 CPU 占比；（4）为什么“CPU 占比最低”不等于“单字节延迟最低”。

<ExamSolution>

<ExamAnswer>

1. 每 $8/12.8\times10^6=\boxed{0.625\,\mu\mathrm s}$ 产生 8B；理想定时轮询 CPU 开销 **$6.4\%$**。
2. 每秒 **$200\,000$ 次中断**，CPU 开销 **$15\%$**；由于处理一整块仅 $0.75\,\mu\mathrm s$，小于下一块到达间隔 $5\,\mu\mathrm s$，在题设双缓冲和无其他干扰下**可持续处理**。
3. DMA 的 CPU 管理开销 **$0.390625\%$**。
4. 延迟取决于缓冲积累、事件触发、控制器调度及争用，不能由 CPU 利用率单独推出。

</ExamAnswer>

<ExamExplanation>

先统一吞吐率 $R=12.8\times10^6\,\mathrm{B/s}$。8B 端口到达率为 $R/8=1.6\times10^6$ 次/s，对应间隔 $0.625\,\mu\mathrm s$。轮询每次 $16\times2=32$ 拍，因而

$$
U_{poll}=\frac{(R/8)\times32}{800\times10^6}\times100\%=\boxed{6.4\%}.
$$

合并中断一次聚合 $64/8=8$ 份原始端口数据，故中断率降为 $R/64=200000$ 次/s，聚合间隔 $64/R=5\,\mu\mathrm s$。CPU 每次处理中断耗时 $600/(800\times10^6)=0.75\,\mu\mathrm s$，所以处理比下一整块到达快，**吞吐意义上**双缓冲足以避免因 CPU 处理慢于平均数据产生而堆积（忽略题设之外的调度抖动、填满瞬间交接等延迟）。CPU 占比

$$
U_{int}=\frac{(R/64)\times600}{800\times10^6}\times100\%=\boxed{15\%}.
$$

DMA 每秒约 $(R/4096)=3125$ 块，每块 CPU 占 1000 拍：

$$
U_{DMA}=\frac{3125\times1000}{800\times10^6}\times100\%=\boxed{0.390625\%}.
$$

| 方案 | 单次处理粒度 | 每次 CPU 开销 | 持续满速下 CPU 占比 |
| --- | ---: | ---: | ---: |
| 定时轮询 | 8B | 32 拍 | $6.4\%$ |
| 双缓冲合并中断 | 64B | 600 拍 | $15\%$ |
| DMA | 4096B | 1000 拍 | $0.390625\%$ |

**结论不能过度外推**：本题中断合并后的每块 ISR 开销较高，虽减少中断次数，仍比理想轮询方案消耗更多 CPU；并不是“只要采用中断就一定比轮询省 CPU”。轮询为最少指令数、恰当时间点读取的**理想下界**；真实系统在轮询周期安排、状态检查、系统开销和实时约束上可能更差。DMA 虽最省 CPU，但等 $4096$B 填满需要约 $320\,\mu\mathrm s$，若应用必须等整块交付，首字节的等待延迟就可能明显更长。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>
