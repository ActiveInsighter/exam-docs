# 第 6 章 总线和输入输出系统

## 6.4 I/O 方式

<Question id="408-7c4a2e-040" type="essay" tags="来源:2009考研408">

某计算机的CPU 主频为500MHz, CPI 为5(即执行每条指令平均需5 个时钟周期)。假定某外设的数据传输率为0.5MB/s, 采用中断方式与主机进行数据传送, 以32 位为传输单位, 对应的中断服务程序包含18 条指令,中断服务的其他开销相当于2 条指令的执行时间。请回答下列问题, 要求给出计算过程。
   (1) 在中断方式下, CPU 用于该外设I/O 的时间占整个CPU 时间的百分比是多少？
   (2) 当该外设的数据传输率达到5MB/s 时, 改用DMA 方式传送数据。假定每次DMA 传送块大小为5000B, 且DMA 预处理和后处理的总开销为500 个时钟周期, 则CPU 用于该外设I/O 的时间占整个CPU 时间的百分比是多少?(假设DMA 与CPU 之间没有访存冲突)

<Solution>

**【解析】**

(1) 外设的数据传输率是 0.5MB/s。采用中断进行数据传输时，每次为 32 位（4B）。外设如果想要达到 0.5MB/s 的数据传输率，外设每秒的中断次数为 $0.5\text{MB}/4\text{B}=125000=0.125\text{M}$，CPU 在中断方式下每次用于数据传送的时钟周期为 $(18+2)\times5=100$，则 1s 内用于中断的时间为 $100\times125000=12.5\text{M}$ 个时钟周期。所以 CPU 用于外设 I/O 的时间占整个 CPU 时间的百分比，等于 1s 内用于中断的时间开销 ÷ 整个 CPU 时间 $=12.5\text{M}\div500\text{M}=2.5\%$。

(2) DMA 方式每次传送的大小是 5000B，当数据传输率为 5MB/s 时，每秒 DMA 的次数为 $5\text{MB}\div5000\text{B}=1000$。CPU 每秒用于 DMA 处理的总开销：每次 DMA 总开销 × 每秒 DMA 次数 $=500\times1000=500000=0.5\text{M}$ 个时钟周期。则 CPU 在 DMA 方式下，用于外设的时间占整个 CPU 时间的百分比为 $0.5\text{M}\div500\text{M}=0.1\%$。

**【点评】** 概念题。本题分别考查中断方式、DMA 方式下的计算，比较基础。

</Solution>

</Question>

<Question id="408-7c4a2e-041" type="essay" tags="来源:2016考研408">

假定CPU 主频为50MHz, CPI 为4。设备D 采用异步串行通信方式向主机传送7 位ASCII 字符, 通信规程中有1 位奇校验位和1 位停止位, 从D 接收启动命令到字符送入I/O 端口需要0.5ms。请回答下列问题, 要求说明理由。
   (1) 每传送一个字符, 在异步串行通信线上共需传输多少位？在设备D 持续工作过程中, 每秒钟最多可向I/O 端口送入多少个字符?
   (2) 设备D 采用中断方式进行输入/ 输出, 示意图如下:

<img src="/img/questions/408/computer-organization-p098-01.svg" alt="2024年设备D采用中断方式进行输入输出的示意图" />

   I/O 端口每收到一个字符申请一次中断,中断响应需10 个时钟周期,中断服务程序共有20 条指令,其中第15 条指令启动D 工作。若CPU 需从D 读取1000 个字符,则完成这一任务所需时间大约是多少个时钟周期？CPU 用于完成这一任务的时间大约是多少个时钟周期？在中断响应阶段CPU 进行了哪些操作?

<Solution>

**【解析】**

(1) ① 异步串行通信线上需要传输：起始位（1 位）+ 数据位（7 位）+ 奇偶校验位（1 位）+ 停止位（1 位），总共为 10 位。

② 设备 D 从收到启动命令到字符进入 I/O 端口需 0.5ms，设备 D 持续工作时每隔 0.5ms 就能送出一个字符，故每秒最多送入 $1000\div 0.5=2000$ 个字符。

(2) ① 一个字符传送的时间包含：将字符送到 I/O 端口所需的时间、中断响应时间、中断服务程序执行前的 15 条指令启动设备 D 工作的时间。一个字符的传送时间 = $15\times 4+10+0.5\mathrm{ms}\times 50\mathrm{MHz}=25070$ 个时钟周期。1000 个字符的传送所需时间为 25070000 个时钟周期。

② 由上面可得，中断服务程序共有 20 条指令，CPI 为 4，中断响应为 10 个时钟周期，得到 CPU 用于完成这一任务的时间约为 $1000\times (10+20\times 4)=90000$ 个时钟周期。

③ 在中断响应阶段，CPU 主要进行以下操作：关中断、保存断点和程序状态字（PSW）、识别中断源并转入中断服务程序入口。

> **【点评】** 难题。考查中断方式相关的计算问题。无论是一个字符的传送时间，还是终端服务程序执行时间的计算都比较困难。需要完全读懂题中示意图，理清中断程序的执行过程才能准确算出答案。

</Solution>

</Question>

<Question id="408-7c4a2e-042" type="essay" tags="来源:2018考研408">

假定计算机的主频为500MHz,CPI 为4。现有设备A 和B, 其数据传输率分别为2MBps和40MBps, 对应I/O 接口中各有一个32 位数据缓冲寄存器。请回答下列问题, 要求给出计算过程。
   (1) 若设备A 采用定时查询I/O 方式, 每次输入/ 输出都至少执行10 条指令。设备A 最多间隔多长时间查询一次才能不丢失数据?CPU 用于设备A 输入/ 输出的时间占CPU 总时间的百分比至少是多少?
   (2) 在中断I/O 方式下, 若每次中断响应和中断处理的总时钟周期数至少为400, 则设备B 能否采用中断I/O 方式? 为什么?
   (3) 若设备B 采用DMA 方式, 每次DMA 传送的数据块大小为1000B, CPU 用于DMA 预处理和后处理的总时钟周期数为500,则CPU 用于设备B 输/ 输出的时间占CPU 总时间的百分比最大是多少?

<Solution>

**【解析】**

(1) 采用定时查询 I/O 方式：① I/O 接口数据缓冲寄存器为 32 位 = 4B。设备 A 数据传输率 2MB/s，填满 4B 缓冲区的时间 = $\frac{4\mathrm{B}}{2\mathrm{MB/s}}=2\mu\mathrm{s}$。若超过 2μs 未查询，缓冲区数据会被新数据覆盖而丢失，因此最多每隔 2μs 必须查询一次。

② 每秒查询次数 = $\frac{1\mathrm{s}}{2\mu\mathrm{s}}=5\times 10^5$ 次。每次查询至少执行 10 条指令，CPI = 4，每条指令需 4 个时钟周期。每秒用于设备 A 的时钟周期数 = $5\times10^5\times10\times4=2\times10^7$。CPU 主频 500MHz，每秒总时钟周期数 = $500\times10^6$。CPU 用于设备 A 的输入/输出时间占比 = $\frac{2\times10^7}{500\times10^6}=4\%$。

(2) ① I/O 接口数据缓冲寄存器为 32 位 = 4B。设备 B 传输率 40MB/s，准备 4B 数据的时间 = $\frac{4\mathrm{B}}{40\mathrm{MB/s}}=2\mu\mathrm{s}$。每次中断响应和处理至少需要 400 个时钟周期，每个时钟周期 = $\frac{1}{500\mathrm{MHz}}\mathrm{s}$，则每次中断响应和处理耗时 = $400\times\frac{1}{500\mathrm{MHz}}=0.8\mu\mathrm{s}$。

{/* 原书此处将 4B/(40MB/s) 误写为 2μs，正确为 0.1μs；下文使用正确数值。 */}

② 由于 $0.8\mu\mathrm{s}>0.1\mu\mathrm{s}$，即中断处理速度跟不上数据到达速度，缓冲区数据会在中断处理期间被覆盖丢失。因此设备 B 不能采用中断 I/O 方式。

(3) 设备 B 数据传输率为 40MBps，DMA 每次传送 1000B，则每秒 DMA 次数 = $\frac{40\mathrm{MB}}{1000\mathrm{B}}=4\times10^4$ 次。每次 DMA 预处理和后处理共需 500 个时钟周期，则每秒 CPU 用于 DMA 的时钟周期数 = $4\times10^4\times500=2\times10^7$。

CPU 用于设备 B 的输入/输出时间占比 = $\frac{2\times10^7}{500\times10^6}=4\%$。

**【点评】** 概念题。考查定时查询、程序中断、DMA 这 3 种 I/O 方式的计算。本题跟 2009 年 408 第 43 题考法类似，考生可对比练习。

</Solution>

</Question>
