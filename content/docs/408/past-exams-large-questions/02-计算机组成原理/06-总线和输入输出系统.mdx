## 2009 年第 43 题

<ExamQuestion>

**37. 2009 年第 43 题**

某计算机的 CPU 主频为 $500\text{ MHz}$，CPI 为 $5$，即执行每条指令平均需要 $5$ 个时钟周期。

某外设的数据传输率为 $0.5\text{ MB/s}$，采用中断方式与主机进行数据传送，以 $32$ 位为一个传输单位。对应的中断服务程序包含 $18$ 条指令，中断服务的其他开销相当于 $2$ 条指令的执行时间。

请回答：

1. 在中断方式下，CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比是多少？
2. 当该外设的数据传输率达到 $5\text{ MB/s}$ 时，改用 DMA 方式传送数据。假定每次 DMA 传送块大小为 $5000\text{ B}$，DMA 预处理和后处理的总开销为 $500$ 个时钟周期。若 DMA 与 CPU 之间没有访存冲突，则 CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比是多少？

<ExamSolution>
<ExamAnswer>

1. 中断方式：一次中断占 $100$ 周期，每秒需处理中断 $125000$ 次，每秒占 $12.5\times10^6$ 周期，因此 CPU 用于该设备 I/O 的比例为 **$2.5\%$**。
2. DMA 方式：每秒传送 $1000$ 块，每块 CPU 预处理与后处理合计 $500$ 周期，每秒占 $5\times10^5$ 周期，因此比例为 **$0.1\%$**。

</ExamAnswer>
<ExamExplanation>

1. **中断题用“每秒中断次数 × 每次服务周期数”**，先统一数据单位：32 位 = 4 B；按题目使用十进制 MB，即 $1\text{ MB}=10^6\text{ B}$。平均 CPI=5，服务程序有 18 条指令，另有相当于 2 条指令执行时间的保存恢复等开销，所以一次中断耗时

   $$C_{\mathrm{int}}=(18+2)\times5=100\text{ cycles}.$$

   设备每秒传送 $0.5\times10^6$ B，故每秒中断次数为

   $$N_{\mathrm{int}}=\frac{0.5\times10^6}{4}=125000.$$

   CPU 每秒总计 $500\times10^6$ 周期，因此

   $$\eta_{\mathrm{int}}=\frac{125000\times100}{500\times10^6}\times100\%=\boxed{2.5\%}.$$

   **两个易错点：**① 把 32 位错当作 32 B，会使中断次数少算 8 倍；② 18 条程序指令以外，2 条的等效开销也要乘 CPI，不能只加 2 个周期。计算出的百分比是 CPU 的周期占用率，而不是设备总线利用率，也不是某次中断占全部程序执行时间的比例。
2. **DMA 题用“每秒 DMA 块数 × 每块 CPU 管理周期数”**。此时数据率升至 $5\text{ MB/s}$，块长 $5000$ B：

   $$N_{\mathrm{DMA}}=\frac{5\times10^6}{5000}=1000\text{ blocks/s}.$$

   CPU 用于初始化与结束的周期数为 $1000\times500=5\times10^5$，因此

   $$\eta_{\mathrm{DMA}}=\frac{1000\times500}{500\times10^6}\times100\%=\boxed{0.1\%}.$$

   数据搬运由 DMA 控制器直接在外设与主存间进行，**不能对每个 4 B 再按中断服务程序执行 20 条指令**。题目假定 DMA 与 CPU 无访存冲突，所以无须另计 DMA 窃取存储器总线周期导致的 CPU 停顿；如果有总线竞争，还需区分“CPU 执行控制程序的时间”与“CPU 因访存被阻塞的时间”。

**通用检查：** 利用率无量纲，$\text{次/s}\times\text{cycle/次}\div\text{cycle/s}$；若结果 $>100\%$，说明按该服务方案单核 CPU 无法跟上数据流，不能把它当成真实占用率。中断按传输**单元**计，DMA 按传输**块**计。

</ExamExplanation></ExamSolution>
</ExamQuestion>

<ExamQuestion>

某处理器主频 $400\text{ MHz}$、平均 CPI 为 4。一个持续运行的设备每秒向 CPU 提供 $1\text{ MB}$ 数据，采用中断输入，每 8 B 触发一次中断。每次中断服务程序有 22 条指令，进入、退出中断等开销等效于 3 条指令的执行时间。

1. 每秒产生多少次中断？每次中断消耗多少周期？
2. CPU 每秒用于该设备 I/O 的周期数及占总周期的百分比是多少？
3. 如果把每次中断的传输单元由 8 B 改为 16 B，而其他条件不变，新的 CPU 占用率是多少？假定外设有足够的缓冲能力。

<ExamSolution><ExamAnswer>

1. **125000 次/s，100 周期/次**。
2. **$12.5\times10^6$ 周期/s，占 $3.125\%$**。
3. **$1.5625\%$**。

</ExamAnswer><ExamExplanation>

1. 单元从 32 位改变为 8 B 后，应直接用字节数据率计算：$10^6/8=125000$。每次处理的等效指令数是 $22+3=25$，乘以 CPI=4 得 100 周期。
2. 每秒总周期为 $400\times10^6$，所以 $125000\times100=12.5\times10^6$，占 $12.5/400=0.03125=3.125\%$。
3. 传输单元翻倍，中断频次减半，若每次中断固定开销不变，总 CPU 开销也减半。$10^6/16=62500$ 次/s，占 $62500\times100/(400\times10^6)=1.5625\%$。注意增大每次数据单元要求接口、驱动有相应缓存支持，题设已给定这一前提。

</ExamExplanation></ExamSolution>
</ExamQuestion>

<ExamQuestion>

一台 CPU 主频 $300\text{ MHz}$。某设备持续传输速率为 $12\text{ MB/s}$。若采用中断方式，每收到 4 B 就中断一次，每次响应与服务共需 50 个 CPU 周期。若采用 DMA，每块大小为 4000 B，每块启动及结束共需 CPU 的 200 个周期；假定 DMA 不与 CPU 争用主存。

1. 采用中断方式时，每秒需要处理多少次中断？CPU 占用率是多少？
2. 采用 DMA 时，每秒传送多少块？CPU 的管理开销占用率是多少？
3. 若将 DMA 块长减小为 1000 B，其他条件不变，管理开销占用率变为多少？由此解释批量传输的作用。

<ExamSolution><ExamAnswer>

1. **300 万次/s；占用 $50\%$**。
2. **3000 块/s；占用 $0.2\%$**。
3. **$0.8\%$**；每块固定管理成本使小块传输次数增加，占用率升高。

</ExamAnswer><ExamExplanation>

1. 中断频率 $12\times10^6/4=3\times10^6$ 次/s，周期开销 $3\times10^6\times50=150\times10^6$，除以 $300\times10^6$ 得 0.5。此值仍小于 100%，但实际系统还需考虑中断嵌套、数据缓冲、其他负载及中断响应的时序约束。
2. $12\times10^6/4000=3000$ 块/s，开销 $3000\times200=600000$ 周期/s，占 $600000/(300\times10^6)=0.2\%$。
3. DMA 块长改为 1000 B 后需 12000 块/s，管理开销 $12000\times200=2.4\times10^6$ 周期/s，占 $0.8\%$。每块固定成本较高时，更大块可以摊薄 CPU 开销，但可能增加单次延迟和所需缓冲空间；本题不涉及这些额外资源限制。

</ExamExplanation></ExamSolution>
</ExamQuestion>

## 2016 年第 44 题

<ExamQuestion>

**51. 2016 年第 44 题**

假定 CPU 主频为 $50\text{ MHz}$，CPI 为 $4$。设备 D 采用异步串行通信方式向主机传送 7 位 ASCII 字符，通信规程中有 1 位奇校验位和 1 位停止位。从 D 接收启动命令到字符送入 I/O 端口需要 $0.5\text{ ms}$。请回答下列问题，并说明理由。

1. 每传送一个字符，在异步串行通信线上共需传输多少位？在设备 D 持续工作过程中，每秒钟最多可向 I/O 端口送入多少个字符？
2. 设备 D 采用中断方式进行输入/输出，工作过程如下图所示。I/O 端口每收到一个字符申请一次中断，中断响应需 10 个时钟周期，中断服务程序共有 20 条指令，其中第 15 条指令启动 D 工作。若 CPU 需从 D 读取 1000 个字符，则完成这一任务所需时间大约是多少个时钟周期？CPU 用于完成这一任务的时间大约是多少个时钟周期？在中断响应阶段 CPU 进行了哪些操作？

<img src="/img/408/past-exams-large-questions/02-计算机组成原理/assets/2016-44-figure-001.svg" alt="2016 年第 44 题设备 D 与 CPU 中断工作时序" />

<ExamSolution>
<ExamAnswer>

1. 每个字符在线路上需 **10 位**：1 位起始位、7 位 ASCII 数据位、1 位奇校验位、1 位停止位。每秒最多送至 I/O 端口 **2000 个字符**。
2. 读取 1000 字符，按题设时序完成整个最后一次中断服务，历时约 **$25\,070\,020$ 周期**（近似为 $2.507\times10^7$ 周期）；CPU 实际用于该任务的时间为 **$90\,000$ 周期**。中断响应阶段主要进行中断识别/应答、保存断点和必要状态、转至中断服务程序，典型实现还会关中断或调整中断屏蔽。

</ExamAnswer>
<ExamExplanation>

1. **“字符位数”与“字符产生间隔”分别计算。** 异步串行帧包含 $1+7+1+1=10$ 位，其中起始位是**额外的 1 位**，不能把 ASCII 的起始零误认为 7 位数据之一。题目已规定 D 从启动到一个字符被送入端口需 $0.5\text{ ms}$，若持续按该周期启动，理想最大字符率为

   $$f_D=\frac{1}{0.5\times10^{-3}}=\boxed{2000\text{ 个/s}}.$$

   这里没有给比特率，因此不能再把 10 位乘以某个猜测的每位时间。**若另外提供通信线波特率**，还需比较线路最大帧率与设备工作周期确定瓶颈。
2. **把总历时和 CPU 的忙碌时间分开。** CPU 主频 50 MHz，每秒 $50\times10^6$ 周期，一个周期 20 ns；设备单次工作 $0.5\text{ ms}$ 换算成

   $$C_D=50\times10^6\times0.5\times10^{-3}=25000\text{ cycles}.$$

   每次中断响应要 10 周期，服务程序共 20 条指令、CPI=4，即 80 周期。第 **15 条**指令就再次启动 D，所以相邻两次 D 启动的间隔为

   $$25000+10+15\times4=\boxed{25070\text{ cycles}}.$$

   这里“执行了第 15 条就启动下一个字符”不是“该次 ISR 只需 15 条”，后续 5 条仍需 CPU 执行，只是它们可与设备下一次 $25000$ 周期的工作**重叠**。初次启动后，到第 1000 个字符送入端口共有 1000 段设备工作时间，以及 999 段“中断响应 + 执行前 15 条后再次启动”的时间；最后一个字符到了之后，若要把最后一次中断服务全部执行完，再加上 10 周期响应及 20 条指令：

   $$\begin{aligned}C_{\mathrm{total}}&=1000\times25000+999\times(10+15\times4)+(10+20\times4)\\&=\boxed{25\,070\,020\text{ cycles}}.\end{aligned}$$

   在近似题中也常直接用 $1000\times25070\approx2.507\times10^7$ 周期，差仅 20 个周期（最后一次多执行的 5 条指令）。如果停止计时定义为“最后字符刚进入端口”而非 ISR 完成，则相应时间应减去最后一次的 90 周期；**题意通常按任务完成含最后一次中断处理理解**。

   CPU 真正被中断响应及服务程序占用的时间为

   $$C_{\mathrm{CPU}}=1000\times(10+20\times4)=\boxed{90000\text{ cycles}}.$$

   不能把 D 工作中的 $25000$ 周期也加进 CPU 占用，因为 CPU 可以并行执行其他工作。**中断响应**属于硬件/控制流程：判定中断请求与允许条件、应答、保存 PC/必要现场、装入 ISR 入口；保存哪些寄存器由硬件和软件约定决定，不能武断说所有通用寄存器必由硬件自动保存。

**答题策略：** 先画时序：D 工作 → 中断响应 → ISR 第 1～15 条 → 重启 D → ISR 第 16～20 条（与 D 工作重叠）；总历时沿设备关键路径累加，CPU 时间按所有中断与 ISR 实际执行周期累加，两者使用不同统计口径。

</ExamExplanation></ExamSolution>
</ExamQuestion>

<ExamQuestion>

一个异步串行设备以 **9600 bit/s** 的物理线路速率连续发送字符。每帧包含 1 位起始位、8 位数据位、1 位偶校验位、2 位停止位。其 I/O 端口每接收一帧即向 CPU 申请一次中断。CPU 主频为 50 MHz，处理一次中断（含响应）需要 250 周期。假定无其他开销。

1. 每帧占多少位？线路每秒最多可发送多少个字符？
2. 相邻两帧约间隔多少毫秒？250 个 CPU 周期折合多少微秒？
3. 若设备内部另外规定“产生一个字符至少需要 $0.5\text{ ms}$”，整套系统的字符率上限由哪一因素决定？CPU 能否在下一帧到达前处理完一个中断？

<ExamSolution><ExamAnswer>

1. **12 bit/帧；800 字符/s**。
2. **1.25 ms/帧；5 μs/次中断**。
3. **线路是瓶颈，上限 800 字符/s**；可以处理完，5 μs 小于 1.25 ms。

</ExamAnswer><ExamExplanation>

1. $1+8+1+2=12$ 位，不要把偶校验位是否为 1 与“是否存在校验位”混淆，传输开销固定为 1 位。$9600/12=800$ 帧/s。

3. 设备内部每 0.5 ms 最多产生 2000 字符/s；通信线只能提供 800 字符/s，故取较小值 800。中断处理只用 5 μs，远小于 1250 μs 的帧间隔，所以在当前假设下中断服务能力足以跟上数据，但还应有可用的串行接收缓冲区。

</ExamExplanation></ExamSolution>

一台 CPU 主频 $100\text{ MHz}$、平均 CPI=5。设备从启动至送出一个字符需要 $0.2\text{ ms}$，每字符产生一次中断。中断响应需 8 个周期，ISR 共 12 条指令，其中**第 5 条指令结束时启动下一次设备工作**。初始设备启动时间取为 $t=0$，后续设备工作可以与 ISR 后半段并行，忽略其他任务对响应的延迟。

1. 完成 200 个字符并执行完最后一次 ISR，共需多少周期？写出精确计数公式。
2. CPU 用于这 200 个字符的中断响应和 ISR 的周期总数是多少？
3. 若错误地把每次 ISR 的全部 12 条指令都串行加在设备等待时间上，为什么会高估总历时？

<ExamSolution><ExamAnswer>

1. **$4\,006\,635$ 周期**，即 $200\times20000+199\times(8+5\times5)+(8+12\times5)$。
2. **$13\,600$ 周期**。
3. 因为每次执行完第 5 条已重启设备，ISR 的后 7 条指令与**下一次设备的 20000 周期工作重叠**，不能重复加到关键路径。

</ExamAnswer><ExamExplanation>

1. $100\times10^6\times0.2\times10^{-3}=20000$ 周期/字符。前 199 次接收后先付出 $8+5\times5=33$ 周期才能启动下次接收；最后一次 ISR 完整结束仍需 $8+12\times5=68$ 周期。因此总历时 $4\,000\,000+6567+68=4\,006\,635$ 周期。
2. 每次中断 CPU 都执行全部 12 条指令，耗时 $8+12\times5=68$ 周期；200 次为 $200\times68=13600$ 周期。两者差别来自设备等待期间 CPU 可处理其他程序。
3. 错法 $200\times(20000+68)$ 没考虑“ISR 的后 35 周期可以藏在下一次设备延迟内”，故高估 $199\times35=6965$ 周期。若设备等待短于 35 周期，才需另行检查 ISR 后段是否成为重新响应中断的瓶颈，本例不存在该问题。

## 2018 年第 43 题

<ExamQuestion>

**55. 2018 年第 43 题**

假定计算机主频为 $500\text{ MHz}$，CPI 为 $4$。现有设备 A 和 B，其数据传输率分别为 $2\text{ MB/s}$ 和 $40\text{ MB/s}$，对应 I/O 接口中各有一个 32 位数据缓冲寄存器。请回答，并给出计算过程。

1. 若设备 A 采用定时查询 I/O 方式，每次输入/输出至少执行 10 条指令。设备 A 最多间隔多长时间查询一次才不会丢失数据？CPU 用于设备 A 输入/输出的时间占 CPU 总时间的百分比至少是多少？
2. 在中断 I/O 方式下，若每次中断响应和中断处理的总时钟周期数至少为 400，则设备 B 能否采用中断 I/O 方式？为什么？
3. 若设备 B 采用 DMA 方式，每次 DMA 传送的数据块大小为 $1000\text{ B}$，CPU 用于 DMA 预处理和后处理的总时钟周期数为 500，则 CPU 用于设备 B 输入/输出的时间占 CPU 总时间的百分比最大是多少？

<ExamSolution>
<ExamAnswer>

1. A 的接口缓冲每满一次 4 B 需 $2\,\mu\text{s}$，因此轮询间隔**至多 $2\,\mu\text{s}$**；CPU 至少需占总时间 **$4\%$**。
2. B **不能按每 4 B 中断一次**可靠处理。接口缓冲每 $0.1\,\mu\text{s}$ 被新数据填满，而中断响应与服务至少需 $0.8\,\mu\text{s}$，CPU 跟不上。
3. B 的 DMA 每秒传送 $40000$ 块，管理开销占用 CPU 时间**最多 $4\%$**（按满速传输且每块耗 500 周期计算）。

</ExamAnswer>
<ExamExplanation>

1. **定时查询的核心是缓冲覆盖周期。** 32 位缓冲寄存器一次容纳 $32/8=4\text{ B}$；A 的 $2\text{ MB/s}$ 按十进制为 $2\times10^6\text{ B/s}$，故下一份 4 B 到来的间隔为

   $$T_A=\frac{4}{2\times10^6}\text{ s}=\boxed{2\,\mu\text{s}}.$$

   在接口只有一个缓冲寄存器且新数据会覆盖旧数据的条件下，应在下一份数据到来前读取当前缓冲。因此理想模型的最大轮询间隔为 $2\,\mu\text{s}$；真实系统为容忍抖动一般应更短。每秒最少轮询 $1/T_A=5\times10^5$ 次。一次至少需 10 条指令、CPI=4，即 $40$ 周期，主频 $500\text{ MHz}$，故

   $$\eta_A\ge\frac{5\times10^5\times40}{500\times10^6}=\boxed{4\%}.$$

   **不要误把 CPU 主频 500 MHz 当成设备传输频率，也不要把 32 位看作 32 B。** 这里按每次轮询承担题设的至少 10 条指令计 CPU 的理论最小开销。
2. **单缓冲的中断可行性不能只看“CPU 是否支持中断”。** B 的数据率为 $40\text{ MB/s}$，每 4 B 产生一次可读数据，间隔

   $$T_B=\frac4{40\times10^6}=0.1\,\mu\text{s}.$$

   每次响应和中断处理至少 400 周期，耗时

   $$T_{\mathrm{ISR}}\ge\frac{400}{500\times10^6}=0.8\,\mu\text{s}.$$

   一次中断处理尚未完成时，又有约 $0.8/0.1=8$ 份 4 B 数据产生；32 位单缓冲不足以保存它们，因此以**每缓冲一中断**的数据接收方案不可行。另一种验算：中断频率为 $40\times10^6/4=10^7$ 次/s，至少占 $10^7\times400=4\times10^9$ CPU 周期/s，远大于每秒可用的 $5\times10^8$ 周期。若更改硬件为大 FIFO、批量中断、总线 DMA 等，结论可能改变；本题不允许自加这些条件。
3. **DMA 按块统计 CPU 管理开销，不按 4 B 中断。** 每块 1000 B，满速时

   $$N_{\mathrm{DMA}}=\frac{40\times10^6}{1000}=40000\text{ blocks/s}.$$

   每块 CPU 预处理+后处理占 500 周期，因此

   $$\eta_{\mathrm{DMA}}=\frac{40000\times500}{500\times10^6}=\boxed{4\%}.$$

   题问“最大”按设备 B 持续达到给定最大数据率计算；当实际流量降低时 CPU 管理开销相应降低。这个 $4\%$ **不包括** DMA 抢占主存总线造成的 CPU 等待，因为题设没有给出总线争用参数；若需计算总 CPU 影响，应另外考虑总线带宽和请求仲裁。

**快速比较表：** 轮询看“缓冲填满间隔 + 每次查询指令成本”；中断看“数据到达间隔 vs 一次中断完成时间”；DMA 看“块数/秒 × 每块管理周期”。三种方案的 CPU 占用率都用总可用周期归一化。

</ExamExplanation></ExamSolution>

<ExamQuestion>

某 CPU 主频为 $250\text{ MHz}$，CPI 为 2。设备 A 以 $16\text{ MB/s}$ 持续输入数据，接口只有一个 64 位数据缓冲寄存器。若采用定时轮询，每次读取缓冲至少执行 15 条指令，其他开销不计。

1. 接口一次可容纳多少字节？缓冲被填满的时间间隔是多少微秒？
2. 每秒最少需要有效轮询多少次？CPU 因轮询被占用的时间比例至少是多少？
3. 如果该接口改成连续的双缓冲（两个 64 位缓冲交替使用），能否**不改变 CPU 查询与读取吞吐量**，仅凭双缓冲就无限延长查询间隔？说明理由。

<ExamSolution><ExamAnswer>

1. **8 B，$0.5\,\mu\text{s}$**。
2. **$2\times10^6$ 次/s，至少 $24\%$**。
3. **不能**；双缓冲只提供短暂余量，不会改变长期每秒要搬运的 $16\times10^6$ B。

</ExamAnswer><ExamExplanation>

1. $64\text{ bit}/8=8\text{ B}$，按满速连续到达，填满一份缓冲所用时间为 $8/(16\times10^6)=0.5\times10^{-6}\text{ s}$。
2. 每秒最少搬运 $16\times10^6/8=2\times10^6$ 份缓冲数据，每份至少 15 条指令、CPI=2，即 30 周期，合计 $6\times10^7$ 周期/s。CPU 只有 $2.5\times10^8$ 周期/s，占比 $60/250=24\%$。
3. 双缓冲可在 CPU 读取一块时容纳新到的另一块数据，短时间内降低时序抖动或允许分批读取；但在稳态下 CPU 的平均读取速率必须不低于输入率。若长期轮询吞吐不足，缓冲最终仍溢出，不能用“缓冲翻倍所以频率可以永久减半”替代实际的消费速率分析。

</ExamExplanation></ExamSolution>

<ExamQuestion>

某处理器主频为 $400\text{ MHz}$。设备 B 以 $50\text{ MB/s}$ 持续传送数据，接口有一个 64 位缓冲寄存器。若以每个缓冲的数据申请一次中断，一次中断响应及处理合计需至少 80 个 CPU 周期；若改用 DMA，每次块长 1000 B，CPU 的 DMA 启动和收尾合计需 200 周期。不考虑 DMA 和 CPU 的主存竞争。

1. 接口产生 8 B 数据的时间是多少？一次中断处理至少耗时多少微秒？逐缓冲中断输入是否可行？
2. 采用逐缓冲中断的 CPU 理论周期需求为多少周期/s，是实际周期预算的多少倍？
3. 采用 DMA 时，每秒管理多少块？CPU 占用率为多少？若将 DMA 块长加倍，假设每块管理成本不变，占用率如何变化？

<ExamSolution><ExamAnswer>

1. **$0.16\,\mu\text{s}$、$0.20\,\mu\text{s}$；不可行**，单缓冲会被覆盖。
2. **$5\times10^8$ 周期/s，是 $4\times10^8$ 周期/s 预算的 $1.25$ 倍**。
3. **50000 块/s、$2.5\%$**；块长变为 2000 B 时，**降至 $1.25\%$**。

</ExamAnswer><ExamExplanation>

1. 每份 8 B 到达时间为 $8/(50\times10^6)\text{ s}=0.16\,\mu\text{s}$；80 周期在 400 MHz 时长 $80/(400\times10^6)=0.20\,\mu\text{s}$。即使假定响应时无其他任务，CPU 仍来不及在新数据覆盖前完成每次中断；这里的限制是设备输入速率和单缓冲中断服务能力。
2. 每秒需 $50\times10^6/8=6.25\times10^6$ 次中断，乘以 80 周期为 $5\times10^8$ 周期/s；可用预算仅 $400\times10^6$ 周期/s，需求为 125%，因此无法持续处理全部数据。
3. DMA 为 $50\times10^6/1000=50000$ 次/s，管理周期共 $50000\times200=10^7$，CPU 占比 $10^7/(400\times10^6)=2.5\%$。块长翻倍、每块管理成本固定则块数减半，开销也减半。若改动块长还引入缓存、延迟或内存争用成本，需补充条件再评估。

</ExamExplanation></ExamSolution>
