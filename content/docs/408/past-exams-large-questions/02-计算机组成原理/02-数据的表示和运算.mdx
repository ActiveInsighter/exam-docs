# 第 2 章 数据的表示和运算

## 2.4 C 语言中的类型转换

<Question id="408-b24539-030" type="essay" tags="来源:2011考研408">

假定在一个 8 位字长的计算机中运行如下类 C 程序段：

```c
unsigned int x = 134;
unsigned int y = 246;
int m = x;
int n = y;
unsigned int z1 = x - y;
unsigned int z2 = x + y;
int k1 = m - n;
int k2 = m + n;
```

若编译器将 8 个 8 位寄存器 R1～R8 分别分配给变量 $x$、$y$、$m$、$n$、$z_1$、$z_2$、$k_1$ 和 $k_2$。请回答下列问题（带符号整数用补码表示）：

（1）执行上述程序段后，寄存器 R1、R5 和 R6 的内容分别是什么？用十六进制表示。  
（2）执行上述程序段后，变量 $m$ 和 $k_1$ 的值分别是多少？用十进制表示。  
（3）上述程序段涉及带符号整数加/减、无符号整数加/减运算，这四种运算能否利用同一个加法器及辅助电路实现？简述理由。  
（4）计算机内部如何判断带符号整数加/减运算的结果是否发生溢出？上述程序段中，哪些带符号整数运算语句的执行结果会发生溢出？

<Solution>

**【解析】**

(1) ① 无符号整数 $x=134=10000110\text{B}=86\text{H}$，R1 中存放无符号整数 $x$ 的机器数，故 R1 的内容为 86H。

② 关于无符号数减法，这里用 2 种方法求解：

- 人类视角：$n$ 位无符号数减法计算公式为 $x-y=(x+(2^n-y))\bmod 2^n$。$x-y=(134+(2^8-246))\bmod 2^8=144\%256=144=10010000\text{B}=90\text{H}$，
- 计算机底层实现：计算机硬件只有加法器，没有减法器，用加法器实现所有减法。$x-y=[x-y]_{\text{补}}=[x]_{\text{补}}+[-y]_{\text{补}}$。无符号整数 $y=[y]_{\text{补}}=246=11110110\text{B}$。$[-y]_{\text{补}}$ 可由 $[y]_{\text{补}}$（1111 0110B）连同符号位在内，按位取反，末位加 1 而得。所以 $[-y]_{\text{补}}=00001010$。则 $x-y=1000\ 0110\text{B}+0000\ 1010\text{B}=1001\ 0000\text{B}=90\text{H}$。

R5 中存放无符号数 $x-y$ 的运算结果，故 R5 的内容为 90H。

③ $n$ 位无符号数加法计算公式为 $x+y=(x+y)\bmod 2^n$。在计算机底层中计算规则为：二进制位逐位相加，溢出进位直接舍弃。$x+y=1000\ 0110\text{B}+1111\ 0110\text{B}=(1)0111\ 1100\text{B}=7\text{CH}$（舍弃高位的进位 1），故 R6 的内容为 7CH。

(2) 有符号整数和无符号整数相互转换时，机器数不变，仅改变翻译（解释）方式。① $m$ 的机器数与 $x$ 的机器数相同，均为 86H = 1000 0110B（此为带符号整数的补码），转换成原码为 1111 1010B（除符号位外，各位取反，末位加 1），故 $m=-122$。② $k1$ 的机器数与 $z1$ 的机器数相同，均为 1001 0000B（此为带符号整数的补码），转换成原码为 1111 0000B（除符号位外，各位取反，末位加 1），故 $k1=-112$。

(3) 能。理由如下：① 编码基础：计算机中带符号整数采用补码表示，无符号整数本质就是正数的补码形式（原码）。② 减法统一变加法：无论有符号还是无符号减法，都可以统一转换为加法运算：$A-B=A+[-B]_{\text{补}}=A+(\sim B+1)$。$[-B]_{\text{补}}$ 可由 $[B]_{\text{补}}$ 连同符号位在内，按位取反，末位加 1 而得（即：$\sim B+1$）。③ 共用加法器硬件：以 $n$ 位逐位进位加法器为核心，配合取反控制电路即可实现。

- 加法：在输入端 $A$ 和 $B$，直接相加。
- 减法：对 B 按位取反，通过将“最低位进位输入端置 1”来实现“+1”操作。

④ 带符号整数加/减、无符号整数加/减运算，这四种运算共用加法器得到运算结果，仅溢出/进位标志的判断逻辑不同。运算主体电路完全复用，无需两套独立加法器。

- 无符号数：用进位标志 CF 判断溢出；
- 带符号数：用溢出标志 OF 判断溢出；

所以，现代 CPU 的 ALU 通常只设计一个加法器核心，配合少量控制逻辑，即可处理所有整数加减运算。

(4) 带符号整数加/减运算的溢出判断规则为：加法器完成加法操作时，若最高位的进位（符号位向外的进位）和次高位的进位（数值最高位向符号位的进位）不同，则发生溢出，否则不溢出。执行 $k2=m+n$ 时会发生溢出。因为 $1000\ 0110\text{B}+1111\ 0110\text{B}=(1)\ 0\ 111\ 1100\text{B}$，最高位的进位为 1（括号中的 1），次高位进位为 0，故发生溢出。

**【点评】** 难题。考查计算机中的加减运算、无符号数和有符号数之间的转化，考查灵活运用，限定在 8 位字长的场景下，而不是常见的 32 位字长。本题的考点是 408 中的高频考点，虽然学起来费劲、难理解，但属于备考 408 必须掌握的内容。

</Solution>

</Question>

<Question id="408-b24539-031" type="essay" tags="来源:2017考研408">

已知

$$
f(n)=\sum_{i=0}^{n}2^i=2^{n+1}-1=(11\cdots1)_2,
$$

计算 $f(n)$ 的 C 语言函数 $f_1$ 如下：

```c
int f1(unsigned n) {
    int sum = 1, power = 1;
    for (unsigned i = 0; i <= n - 1; i++) {
        power *= 2;
        sum += power;
    }
    return sum;
}
```

将 $f_1$ 中的 int 都改为 float，可得到计算 $f(n)$ 的另一个函数 $f_2$。假设 unsigned 和 int 型数据都占 32 位，float 采用 IEEE 754 单精度标准。请回答下列问题：

（1）当 $n=0$ 时，$f_1$ 会出现死循环，为什么？若将 $f_1$ 中的变量 $i$ 和 $n$ 都定义为 int 型，则 $f_1$ 是否还会出现死循环？为什么？  
（2）$f_1(23)$ 和 $f_2(23)$ 的返回值是否相等？机器数各是什么？用十六进制表示。  
（3）$f_1(24)$ 和 $f_2(24)$ 的返回值分别为 33554431 和 33554432.0，为什么不相等？  
（4）$f(31)=2^{32}-1$，而 $f_1(31)$ 的返回值却为 $-1$，为什么？若使 $f_1(n)$ 的返回值与 $f(n)$ 相等，则最大的 $n$ 是多少？  
（5）$f_2(127)$ 的机器数为 7F80 0000H，对应的值是什么？若使 $f_2(n)$ 的结果不溢出，则最大的 $n$ 是多少？若使 $f_2(n)$ 的结果精确（无舍入），则最大的 $n$ 是多少？

<Solution>

**【解析】**

(1) ① $i$ 和 $n$ 均为 unsigned 型，循环条件 $i\le n-1$ 是无符号比较。$n=0$ 时，无符号减法 $n-1$ 下溢，机器数为全 1，即 $2^{32}-1$，是 unsigned 可表示的最大值，因此 $i\le 2^{32}-1$ 恒真，死循环。

② 若 $i$、$n$ 都改为 int 型，则不会死循环。此时 $n-1$ 按带符号整数运算得 −1，$i=0$ 时 $0\le-1$ 不成立，循环一次都不执行，正常退出。

(2) f1(23) 与 f2(23) 返回值相等，都等于 $2^{24}-1$。f1(23) 机器数 = 00FF FFFFH，f2(23) 机器数 = 4B7F FFFFH。

根据公式 $f(n)=\sum_{i=0}^{n}2^i=2^{n+1}-1=\overbrace{11\cdots1}^{n+1\text{位}}\mathrm{B}$ 可知，$f(23)=2^{23+1}-1=2^{24}-1=\overbrace{11\cdots1}^{24}$。

- f1(23)：int 型（补码）足以表示 $2^{24}-1$（远小于 int 类型能表示的最大值 $2^{31}-1$），其机器数为：0000 0000 1111 1111 1111 1111 1111 1111 = 00FF FFFFH。
- f2(23)：IEEE 754 单精度浮点数格式：符号位（1 位）+ 阶码（8 位）+ 尾数（23 位）。float 类型尾数有 23 位小数位加 1 位隐含 1，共 24 位有效位，也能精确表示 24 个 1。f2(23) 计算结果的机器数计算过程如下：

  ① 规格化：$2^{24}-1=1.11111111111111111111111\times2^{23}$（23 位尾数全为 1）；

  ② 阶码 $e=23$，偏置值 $E=23+127=150=1001\ 0110\mathrm{B}$；

  ③ 符号位 $S=0$（0 表示正数，1 表示负数）；

  ④ 按 IEEE 754 格式拼接：

$$
  \overbrace{0}^{1\text{位符号位}}\quad\overbrace{1001\ 0110}^{8\text{位阶码}}\quad\overbrace{111\ 1111\ 1111\ 1111\ 1111\ 1111}^{23\text{位尾数}}=\mathrm{4B7F\ FFFFH}。
$$

(3) $f(24)=2^{25}-1$，二进制为 25 个连续 1。int 有 32 位可精确表示；但 float 只有 24 位有效位，第 25 位为 1，按“就近偶数”舍入后进位，使尾数全变为 0、阶码加 1，结果变成 $2^{25}=33554432.0$，比真实值大 1。故不相等。

(4) $f(31)=2^{32}-1$，机器数为 32 个 1。int 型最高位为符号位，全 1 解释为补码 −1，故返回值为 −1。int 型能表示的最大值为 $2^{31}-1$（32 位 int 表示范围为 $[-2^{31},2^{31}-1]$），对应 f30，故使 f1n 与 fn 相等的最大 $n$ 为 30。

(5) ① f2 的机器数 7F80 0000H =

$$
\overbrace{0}^{1\text{位符号位}}\quad\overbrace{1111\ 1111}^{8\text{位阶码}}\quad\overbrace{000\ 0000\ 0000\ 0000\ 0000\ 0000}^{23\text{位尾数}}\mathrm{B}。
$$

在 IEEE 单浮点数标准中，用一个特殊的指数值来表示正无穷和负无穷。阶码全为 1，尾数部分全为 0，表示 $+\infty$。

② 不溢出的最大 $n$：当 $n=126$ 时，$f(126)=2^{127}-1=1.1\cdots1\times2^{126}$，舍入后为 $1.0\times2^{127}$，阶码 254，是单精度最大有限值（当 $n=127$ 时，则舍入到阶码 255 表示 $+\infty$）。故 $n$ 最大为 126。

{/* 原书称阶码 254、尾数全 0 的数是单精度最大有限值；实际最大有限值的尾数全为 1。保留原文。 */}

③ 结果精确（无舍入）的最大 $n$：当 $n=23$ 时 f23 为 24 个 1，恰好 24 位有效位，无需舍入；当 $n=24$ 起需舍入。故最大 $n$ 为 23。

> **【点评】** 难题。以一段 C 语言求和代码为载体，综合考查 unsigned 下溢、补码解释、IEEE 754 单精度的阶码 / 尾数结构、舍入与溢出。是一道“数据表示”的经典综合题。而且，本题有 5 个小问，每一问都有几个得分点，分析起来费时费力。408 考场上时间紧张，考场桑分析这类题会带来很大的心理压力。

</Solution>

</Question>

## 2.5 运算方法和运算电路

<Question id="408-b24539-036" number={3} type="essay" tags="来源:2020考研408">

有实现 $x\times y$ 的两个 C 语言函数如下：

```c
unsigned umul(unsigned x, unsigned y) { return x * y; }
int imul(int x, int y) { return x * y; }
```

假定某计算机 M 中 ALU 只能进行加减运算和逻辑运算。请回答下列问题：

（1）若 M 的指令系统中没有乘法指令，但有加法、减法和位移等指令，则在 M 上也能实现上述两个函数中的乘法运算，为什么？  
（2）若 M 的指令系统中有乘法指令，则基于 ALU、位移器、寄存器以及相应控制逻辑实现乘法指令时，控制逻辑的作用是什么？  
（3）针对以下三种情况：①没有乘法指令；②有使用 ALU 和位移器实现的乘法指令；③有使用阵列乘法器实现的乘法指令。函数 `umul（ ）` 在哪种情况下执行时间最长？哪种情况下执行时间最短？说明理由。  
（4）$n$ 位整数乘法指令可保存 $2n$ 位乘积，当仅取低 $n$ 位作为乘积时，其结果可能会发生溢出。当 $n=32$，$x=2^{31}-1$，$y=2$ 时，带符号整数乘法指令和无符号整数乘法指令得到的 $x\times y$ 的 $2n$ 位乘积分别是什么？用十六进制表示。此时函数 `umul（ ）` 和 `imul（ ）` 的返回结果是否溢出？对于无符号整数乘法运算，当仅取乘积的低 $n$ 位作为乘法结果时，如何用 $2n$ 位乘积进行溢出判断？

<Solution>

**【解析】**

(1) 乘法运算可以转换为加法运算和移位运算来实现。在计算机中，若没有乘法指令，可以通过多次的加法和移位操作、直到循环次数达到乘数的位数，从而实现乘法指令的功能。

(2) 控制逻辑的作用：控制加法操作和移位操作的次数，并且发出控制信号来执行判断、加法、移位等操作。

(3) 情况①的执行时间最长，情况③的执行时间最短。情况①要用到多条指令的配合来实现乘法运算，每条指令的执行都可能要经过取指、译码、取数、执行和写回这些阶段。因此情况①中要循环执行多条指令，历时多条指令的指令周期，所以其时间最长。情况②和情况③都是使用乘法指令来实现乘法运算，但是乘法指令的实现方式不同。具体来说，情况②使用 ALU、位移器实现，要经过多次加法、移位操作，所以需要多个时钟周期；而使用阵列乘法器实现，通过硬件电路直接输出乘法结果，时间最短。所以情况③执行时间最短，情况②次之，情况①执行时间最长。

(4) ① 这一小问无需知道乘法运算的具体细节，题干已经说明，通过 $n$ 位乘法指令保存 $2n$ 位乘积，若只保存 $n$ 位乘积，则可能会由于截断高 $n$ 位而产生溢出。所以求 $2n$ 位乘积时，可以先将乘积的真值求出来，再扩充至 $2n$ 位机器数即可。

$x\times y=(2^{31}-1)\times2=2^{32}-2$，对应十六进制为 FFFF FFFEH。结果是正数，符号扩展（针对有符号数）或零扩展（针对无符号数）均在高位补 0。所以带符号整数乘法指令和无符号整数乘法指令的 $2n$ 位乘积均为 0000 0000 FFFF FFFEH。

② umul() 和 imul() 的返回值均为截断高 $n$ 位后的末 $n$ 位乘积，为 FFFF FFFEH。$n$ 位乘积解释为无符号数时真值不变，解释为有符号数时发生溢出（因为 FFFF FFFEH 为负数）。所以 umul() 返回结果不溢出，imul() 返回结果溢出。

③ 通过上述分析可知，判断 $n$ 位乘积是否溢出的关键为截断后真值是否发生变化。对于无符号整数乘法运算，当 $2n$ 位乘积的高 $n$ 位全为 0 时，截断高 $n$ 位后真值不发生改变，则结果不溢出，否则溢出。

**【点评】** 难题。主要围绕乘法运算来考查。乘法运算这个考点难度比较大，可能有些考生备考时放弃了对该考点的学习。本题前 3 问还是很常见的，基本属于常识性内容。最后一问比较难理解，难以做对。

</Solution>

</Question>
