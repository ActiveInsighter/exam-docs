# 第 5 章 中央处理器 (CPU)

## 5.3 数据通路的功能和基本结构

<Question id="408-605176-010" type="essay" tags="来源:2009考研408">

某计算机字长16 位, 采用16 位定长指令字结构, 部分数据通路结构如下图所示。上图中所有控制信号为1 时表示有效、为0 时表示无效。例如控制信号MDRinE 为1 表示允许数据从DB 打入MDR, MDRin 为1 表示允许数据从内总线打入MDR。假设MAR 的输出一直处于使能状态。加法指令“ADD(R1), R0”的功能为(R0) + ((R1)) →(R1), 即将R0 中的数据与R1 的内容所指主存单元的数据相加, 并将结果送入R1 的内容所指主存单元中保存。下表给出了上述指令取指和译码阶段每个节拍(时钟周期) 的功能和有效控制信号,请按表中描述方式用表格列出指令执行阶段每个节拍的功能和有效控制信号。

<img src="/img/questions/408/computer-organization-p065-01.svg" alt="2009年部分数据通路结构图" />

| 时钟 | 功能 | 有效控制信号 |
| --- | --- | --- |
| C1 | MAR ← (PC) | PCout, MARin |
| C2 | MDR ← M(MAR)，PC ← (PC)+1 | MemR, MDRinE, PC+1 |
| C3 | IR ← (MDR) | MDRout, IRin |
| C4 | 指令译码 | 无 |

<Solution>

**【解析】** 本题要求写出加法指令 `ADD (R1),R0`，在指令**执行阶段**每个节拍的功能和有效控制信号。本题答案不唯一，这里先给出参考答案，再进行解析。

**【参考答案一】**

| 时钟 | 功能 | 有效控制信号 |
| --- | --- | --- |
| C5 | MAR←(R1) | R1out, MARin |
| C6 | MDR←M(MAR) | MemR, MDRinE |
| C7 | A←(MDR) | MDRout, Ain |
| C8 | AC←(A)+(R0) | R0out, ADD, ACin |
| C9 | MDR←(AC) | ACout, MDRin |
| C10 | M(MAR)←(MDR) | MDRoutE, MemW |

**【参考答案二】**

| 时钟 | 功能 | 有效控制信号 |
| --- | --- | --- |
| C5 | MAR←(R1) | R1out, MARin |
| C6 | MDR←M(MAR), A←(R0) | MemR, MDRinE, Ain, R0out |
| C7 | AC←(A)+(MDR) | MDRout, Add, ACin |
| C8 | MDR←(AC) | ACout, MDRin |
| C9 | M(MAR)←(MDR) | MDRoutE, MemW |

时钟周期 C1～C4 是取指阶段，主要工作是：根据寄存器 PC 中地址，从主存中读取数据（指令），经过 MDR 送至指令寄存器 IR。

- `C1: MAR←(PC)`。指令地址在 PC 中，将 PC 中指令地址送往地址寄存器 MAR。
- `C2: MDR←M(MAR), PC←(PC)+1`。在这一个时钟周期，同时完成了两项工作：① 根据 MAR 中的地址，从主存中读取数据送往 MDA；② PC 自增，指向下一条指令地址。
- `C3: IR←(MDR)`。此时指令已经暂存在 MDR 中，将其送往 IR。

时钟周期 C4 是指令译码阶段，主要工作是：对当前取出的指令进行分析、解码，识别出指令的操作类型、寻址方式、操作数来源／去向，为后续执行阶段生成对应的控制信号，控制 CPU 完成指令要求的操作。加法指令 `ADD (R1),R0` 的第一个操作数，保存在 R1 的内容（地址）所指主存单元中；第二个操作数保存在寄存器 R0 中；两个操作数相加，结果保存在 R1 的内容（地址）所指主存单元中。

- `C5: MAR←(R1)`。((R1)) 是寄存器间接寻址，需要从 R1 中读取目的地址送入 MAR 中。
- `C6: MDR←M(MAR)`。根据 MAR 中的地址，取出操作数送入 MDR 中。这一步完成后，加法运算所需要的两个操作数，存在寄存器 MDR 和 R0 中。这道题答案有多种，将 MDR 中的内容送入暂存寄存器 A，或 R0 中的内容送入暂存寄存器 A，都可以。在节拍安排上，如【参考答案一】所示，若执行 `MDR←M(MAR)` 时，同时将 R0 中的内容送入暂存寄存器 A（`A←(R0)`），并不会发生总线冲突。
- `C7: A←(MDR)`。将 MDR 中的内容送入暂存寄存器 A。
- `C8: AC←(A)+(R0)`。将两个操作数同时送至 ALU 进行加法操作，将运算结果送入累加寄存器 AC 中。
- `C9: MDR←(AC)`。将运算结果从累加寄存器 AC 中送入 MDR。
- `C10: M(MAR)←(MDR)`。将计算结果送至 MAR 内容（其实是 R1）所指的内存单元。

**【点评】** 难题。考查指令执行过程、数据通路。细节较多。2009 年是首次 408 统考，首次遇到这种题，可能很难拿满分。但教材教辅中，对常见指令的执行过程，都有类似的分析介绍。

</Solution>

<Question id="408-605176-011" type="essay" tags="来源:2015考研408">

某16 位计算机的主存按字节编码, 存取单位为16 位；采用16 位定长指令字格式；CPU采用单总线结构, 主要部分如下图所示。图中R0~R3 为通用寄存器；T 为暂存器；SR 为移位寄存器, 可实现直送(mov)、左移一位(left) 和右移一位(right)3 种操作, 控制信号为SRop, SR 的输出由信号SRout 控制；ALU 可实现直送A(mova)、A 加B(add)、A 减B(sub)、A 与B(and)、A 或B(or)、非A(not) 和A 加1(inc)7 种操作, 控制信号为ALUop。请回答下列问题:

<img src="/img/questions/408/computer-organization-p067-01.svg" alt="2015年单总线结构CPU主要部分图" />

(1) 图中哪些寄存器是程序员可见的？为何要设置暂存器T？

(2) 控制信号ALUop 和SRop 的位数至少各是多少？

(3) 控制信号SRout 所控制部件的名称或作用是什么？

(4) 端点①∼⑨中, 哪些端点须连接到控制部件的输出端？

(5) 为完善单总线数据通路, 需要在端点①∼⑨中相应的端点之间添加必要的连线。写出连线的起点和终点,以正确表示数据的流动方向。

(6) 为什么二路选择器MUX 的一个输入端是2?

<Solution>

**【解析】**

(1) ① 程序员可见寄存器是指机器语言（汇编语言）程序员可以指定、可编程访问的寄存器：通用寄存器 R0～R3 可作为指令中的操作数地址出现，PC 虽不直接编址但可通过转移类指令隐式修改，均属于程序员可见。

而 IR、MAR、MDR、T 等都是 CPU 内部为实现指令功能而设的工作寄存器，程序员无法访问，属于程序员不可见寄存器。

② 暂存器 T 的作用：单总线结构在同一时刻只能传送一个数据，而 ALU 执行双操作数运算时，A、B 两个输入端必须同时获得两个不同的操作数。解决办法是：先把第一个操作数经内总线送入 T 暂存，再把第二个操作数经内总线直接送到 ALU 的 B 端，此时 T 的输出稳定地接在 A 端，两个操作数便同时就绪，ALU 方可正常工作。如果没有 T，ALU 的 A、B 两端将得到同一个数据（都等于总线上当前的数据），双操作数运算无法实现，数据通路无法工作。

(2) 控制信号的编码位数必须能区分对应功能部件的全部操作种类。

由题目可知，ALU 有 7 种操作，所以操作控制信号 ALUop 至少需要 $\lceil\log_2 7\rceil=3$ 位。

移位寄存器有 3 种操作，所以操作控制信号 SRop 至少需要 $\lceil\log_2 3\rceil=2$ 位。

(3) SRout 控制的部件是三态门，用于控制移位器与总线数据通路的连接 / 断开。CPU 采用单内总线结构，同一时刻只允许一个部件向总线发送数据。当该三态门关闭时，SR 输出为高阻态，不占用总线，防止多个器件同时驱动总线造成信号冲突。

(4) 端口 ①、②、③、⑤、⑧ 必须连接控制部件的输出端（这些部件都需要控制信号）。

(5) 有两条连线。

- 第一条：⑥→⑨。将内总线上的数据引到 MUX 的一个数据输入端（⑨），使总线数据可被 MUX 选通；
- 第二条：⑦→④。这条线用于将 MUX 的输出（⑦）接到 ALU 的 B 输入端（④），并由 MUXop 控制。根据题目给出的 CPU 结构图，当实现普通 ALU 操作时，MUXop = 1，数据直接流入 ALU 的 B 端；当需要完成 PC 自增时，MUXop = 0，2 作为加数实现 $(\mathrm{PC})+2\to(\mathrm{PC})$。

> **【注意】** 在程序计数器（PC）自增时，MUX 输入端的控制信号取决于具体的硬件设计和控制逻辑。在有的机器中，也有可能 MUXop = 1 时，实现 PC 自增。考生要结合具体的题目分析，不可死记硬背。

(6) 每条指令的长度为 16 位 = 2B，按字节编址，所以每条指令占用 2B ÷ 1B = 2 个内存单元。当顺序执行时，下条指令地址为 (PC) + 2。把常数 2 固定接在 MUX 的一个输入端上，就为“(PC) + 2”这一高频微操作提供了硬件捷径，无需再从其他寄存器取常数 2，方便计算下一条顺序指令的地址。

> **【点评】** 常规题。以单总线 CPU 数据通路为载体，全面考查数据通路结构的静态分析（可见寄存器、三态门、控制信号位数、端点属性）与动态理解（暂存器 T 的作用、PC + 2 的实现）。本题是非常经典的一道考查数据通路的综合题，很适合作为一个典型例题理解记忆。近些年 408 中此类题型都和本题形似。

</Solution>

(2) 题目所给的指令的机器代码如下所示：

<Question id="408-605176-013" type="essay" tags="来源:2022考研408">

某CPU 中部分数据通路如下图所示, 其中, GPRs 为通用寄存器组；FR 为标志寄存器, 用于存放ALU 产生的标志信息；带箭头虚线表示控制信号, 如控制信号Read、Write 分别表示主存读、主存写, MDRin 表示内部总线上数据写入MDR, MDRout 表示MDR 的内容送内部总线。请回答下列问题:

<img src="/img/questions/408/computer-organization-p069-01.svg" alt="2022年CPU部分数据通路图" />

(1) 设ALU 的输入端A、B 及输出端F 的最高位分别为A15、B15及F15, FR 中的符号标志和溢出标志分别为SF 和OF, 则SF 的逻辑表达式是什么?A 加B、A 减B 时OF 的逻辑表达式分别是什么? 要求逻辑表达式的输入变量为A15、B15及F15。

(2) 为什么要设置暂存器Y 和Z？

(3) 若GPRs 的输入端rs、rd 分别为所读、写的通用寄存器的编号, 则GPRs 中最多有多少个通用寄存器?rs 和rd 来自图中的哪个寄存器? 已知GPRs 内部有一个地址译码器和一个多路选择器, rd 应连接地址译码器还是多路选择器?

(4) 取指令阶段(不考虑PC 增量操作) 的控制信号序列是什么？若从发出主存读命令到主存读出数据并传送到MDR 共需5 个时钟周期,则取指令阶段至少需要几个时钟周期?

(5) 图中控制信号由什么部件产生？图中哪些寄存器的输出信号会连到该部件的输入端？

<Solution>

**【解析】**

(1) ① 在 FR 中，SF 是符号标志，在最高位。在 ALU 的输出端中，$F_{15}$ 也是最高位，代表运算结果的符号。故 $\mathrm{SF}=F_{15}$。② 当 $A+B$ 时，只有 A 和 B 同号（即 A、B 均为正数或负数）时才可能发生溢出，溢出时符号位 $F_{15}$ 和 A、B 的正负性相反，故 $\mathrm{OF}=A_{15}\cdot B_{15}\cdot\overline{F_{15}}+\overline{A_{15}}\cdot\overline{B_{15}}\cdot F_{15}$。③ 当 $A-B$ 时，只有 A 和 B 异号（即 A 正 B 负或者 A 负 B 正）时才可能发生溢出，溢出时有两种情况：A 为正数、B 为负数、$F_{15}=1$；A 为负数、B 为正数、$F_{15}=0$。故 $\mathrm{OF}=A_{15}\cdot\overline{B_{15}}\cdot\overline{F_{15}}+\overline{A_{15}}\cdot B_{15}\cdot F_{15}$。

**【提示】** 数字电路逻辑表达式中，“·”表示逻辑与运算，当参与运算的逻辑变量都为真（在数字电路中通常用 1 表示）时，运算结果才为真（1）。“+”表示逻辑或运算，只要参与运算的多个逻辑变量（或逻辑表达式）中有一个为真（1），运算结果就为真（1）。

(2) 内部总线只有 1 条，可视为单总线结构。ALU 是运算部件，不具备存储功能。在单总线结构中，一次只能传输一个数据，但 ALU 有 2 个输入端。故设置暂存器 Y 暂存输入到 A 端的数据，防止数据丢失。由于单总线结构在每个时刻只有一个数据有效（输入/输出），该结构中还有其他部件输出数据到总线，故设置暂存器 Z 缓存 ALU 输出的数据。

<Solution>

**【解析】**

(1) **【解法一】** $x=-513$，$[x]_{\text{补}}=1111\ 1101\ 1111\ 1111\mathrm{B}$。指令“`SHR R1`”表示算术右移一位。算术右移，低位移出，高位补符号位（负数补 1，正数补 0），得到 $1111\ 1110\ 1111\ 1111=\mathrm{FEFFH}$。执行指令之后 R1 的内容为 FEFFH。

**【解法二】** $x=-513$，$x/2=-257$，$[-257]_{\text{补}}=1111\ 1110\ 1111\ 1111\mathrm{H}=\mathrm{FEFFH}$。

{/* 解法二二进制补码后缀 H 为原书写法。 */}

**【拓展】** ① 整数 $x$ 算术右移 1 位，正数和负数的运算规则有所不同：

- 若 $x$ 是正整数，则和普通除法一样（向零取整），例如：$x=513$，则 $x/2=256$。
- 若 $x$ 是负整数，则向负无穷取整，例如：$x=-513$，则 $x/2=-257$（不是 −256）。

② 逻辑右移和算术右移不同：逻辑右移无论正负，右边移出丢弃，左边补 0。即：逻辑右移当成无符号数整体右移，和除法无关！算术右移，低位移出，高位补符号位（0 正 1 负）。

(2) 5 段流水线，执行第 1 条指令需要 5 个时钟周期，之后每个时钟周期都会执行完 1 条指令。连续 4 条指令进入该流水线，执行完毕需要 $5+(4-1)=8$ 个时钟周期。

**【拓展】** $m$ 段流水线稳定之后（无阻塞的理想情况下），执行 $n$ 条指令需要 $m+(n-1)$ 个时钟周期。

(3) ① I3 与 I1、I2 存在数据相关。I3 必须等 I2 将数据写入寄存器 R2 后（WB 阶段之后），再从寄存器 R2 中读取操作数，所以 I3 的 ID 段（读寄存器）被阻塞。

② I4 的 IF 段被阻塞，是因为 I3 的 ID 段被阻塞，导致 I3 的后一条指令 I4 无法取指而阻塞。

**【拓展】** ① 传统单周期 CPU，只有一个指令寄存器 IR，用于存当前指令。而流水线 CPU 中，为了实现多指令并行执行，每段流水线之间设有独立的暂存寄存器。以 5 段流水线为例，段间寄存器包括 IF/ID、ID/EX、EX/MEM、MEM/WB，这些寄存器不仅暂存指令，还会传递指令的完整上下文（操作数、控制信号、地址信息等），本质上替代了全局 IR 的作用。流水线段间寄存器完整的数据流如下（此部分内容目前教辅书中都没有，考生需重视）：

- IF 阶段：取指令并计算 PC + 4，将指令和 PC + 4 的值送入 IF/ID 寄存器；
- ID 阶段：从 IF/ID 寄存器取出指令，完成译码、读寄存器堆，生成控制信号，将源操作数、目的寄存器号、控制信号等送入 ID/EX 寄存器；
- EX 阶段：从 ID/EX 寄存器取出数据，ALU 完成运算或地址计算，将结果和控制信号送入 EX/MEM 寄存器；
- MEM 阶段：从 EX/MEM 寄存器取出数据，完成内存读写（RISC 架构只有 load / store 指令能读写内存），将访存结果或 ALU 结果送入 MEM/WB 寄存器；
- WB 阶段：从 MEM/WB 寄存器取出数据并写回寄存器堆，完成指令的最后一步。

② 例如：本题中指令 I3 因数据相关无法进入 ID 阶段，停留在 IF/ID 寄存器中不动。下一个时钟周期，在 IF 阶段若要取指令 I4，则新指令无处可存：因为 IF/ID 寄存器还被 I3 占用。

(4) $x=x*2+a$ 可以通过 1 次加法、1 次算术左移，或两次加法来实现，对应的指令序列如下。


<Solution>

**【解析】**

(1) M 的存储器编址单位是字节。理由：题目规定指令是 32 位定长，即：单条指令占 4 字节。观察表中 6 条指令的地址，相邻指令的地址相差 4（例如：08048104H − 08048100H = 4），说明 1 个地址编号对应 4B ÷ 4 = 1B 存储空间，所以编址单位为字节。

(2) 数组 A 中每个元素占 4B。理由：指令 1 为“`sll R4,R2,2`”，其功能是把循环变量 i（在 R2 中）逻辑左移 2 位（等价于 $i\times4$），将结果存在 R4 中。

指令 2 为“`add R4,R4,R3`”，其功能是把 $i\times4$ 后的结果（在 R4 中）加上数组 A 的首地址（即 A[0]，在 R3 中），即：`A[i]=A[0]+i*4`，将 A[i] 的地址存在 R4 中。

按字节编址，每个数组元素地址对应的偏移量 = $i\times4$，说明每个数组元素占 4 字节 = 32 位。

(3) ① 题目给出的 bne 指令的机器代码为 1446 FFFAH，bne 指令格式为：

| 31～26 | 25～21 | 20～16 | 15～0 |
| --- | --- | --- | --- |
| OP | Rs | Rd | OFFSET |

由 bne 指令格式可知，低 16 位是 OFFSET 的值，所以 OFFSET = FFFAH（补码）= −6。

② 转移目标地址 = $(\mathrm{PC})+4+\mathrm{OFFSET}\times4$。理由：CPU 取 bne 指令时 PC 为指令自身地址，每条指令是 4B，取指结束 PC + 4 指向下一条指令地址；OFFSET 以指令条数为偏移单位，单条指令占 4B，因此偏移量为 $\mathrm{OFFSET}\times4$。

**【提示】** 转移目标地址计算公式推导过程如下：题目给出的表中，编号为 6 这一行对应 bne 指令。① bne 指令地址为 08048114H，按字节编址，指令长度 = 4B，所以 PC 取指后自增 4 指向下一条指令地址。PC + 4 = 08048118H。② bne 采用相对寻址，且目标地址为 `loop(08048100H)`。08048100H − 08048118H = −18H = −24。由于 OFFSET = −6，$-24=(-6)\times4$，说明 OFFSET 是按 4B 偏移的。所以转移目标地址 = $(\mathrm{PC}+4)+\mathrm{OFFSET}\times4$。
