## 2010 年第 44 题

<ExamQuestion>

**40. 2010 年第 44 题**

某计算机的主存地址空间大小为 $256\text{ MB}$，按字节编址。指令 Cache 和数据 Cache 分离，均有 $8$ 个 Cache 行，每个 Cache 行大小为 $64\text{ B}$，数据 Cache 采用直接映射方式。

现有两个功能相同的程序：

```c
// 程序 A
int a[256][256];
...
int sum_array1() {
    int i, j, sum = 0;
    for (i = 0; i < 256; i++)
        for (j = 0; j < 256; j++)
            sum += a[i][j];
    return sum;
}
```

```c
// 程序 B
int a[256][256];
...
int sum_array2() {
    int i, j, sum = 0;
    for (j = 0; j < 256; j++)
        for (i = 0; i < 256; i++)
            sum += a[i][j];
    return sum;
}
```

假定 `int` 用 $32$ 位补码表示，编译时 `i`、`j`、`sum` 均分配在寄存器中，数组 `a` 按行优先存放，首地址为十进制 $320$。

请回答：

1. 若不考虑用于 Cache 一致性维护和替换算法的控制位，数据 Cache 的总容量是多少？
2. 数组元素 `a[0][31]` 和 `a[1][1]` 各自所在主存块对应的 Cache 行号分别是多少？Cache 行号从 $0$ 开始。
3. 程序 A 和程序 B 的数据访问命中率各是多少？哪个程序执行时间更短？

<ExamSolution>
<ExamAnswer>

1. 数据 Cache 总容量为 $532\ \mathrm B$（含数据位、Tag 和有效位，不计题目排除的其他控制位）。
2. `a[0][31]` 映射到第 6 行；`a[1][1]` 映射到第 5 行。
3. 程序 A 的数据访问命中率为 $15/16=93.75\%$；程序 B 为 $0\%$。在题设其余条件相同的情况下，程序 A 更快。

</ExamAnswer>
<ExamExplanation>

1. **由地址空间反推地址格式和 Cache 容量。** 主存按字节编址，$256\ \mathrm{MB}=2^{28}\ \mathrm B$，故主存地址 28 位；Cache 块长 $64=2^6\ \mathrm B$，块内偏移 6 位；直接映射共 $8=2^3$ 行，行号 3 位；Tag $28-6-3=19$ 位。每行有 $64\times8=512$ 数据位，加 19 位 Tag 和 1 位有效位，即 $532$ 位，总计 $8\times532/8=532\ \mathrm B$。**注意两个 532 分别是“每行位数”和“全 Cache 字节数”，量纲不同。** 本题未规定脏位等额外元数据，不应擅自加入。

2. **用字节地址公式求映射。** 行优先存储时，$\operatorname{addr}(a[i][j])=320+4(256i+j)$。`a[0][31]` 的字节地址是 $444$，主存块号 $\lfloor444/64\rfloor=6$，Cache 行号 $6\bmod8=6$。`a[1][1]` 的地址是 $320+4(257)=1348$，块号 $\lfloor1348/64\rfloor=21$，行号 $21\bmod8=5$。这里**行号**与**块号**不是同一字段；映射后的 Tag 来自主存块号中高于 Cache 索引的位。

3. **程序 A：顺序扫描形成空间局部性。** 由于数组首址 $320$ 是 $64$ 的整数倍，每个块正好装 $64/4=16$ 个 `int`，每次装入一个新块发生 1 次缺失，随后 15 次访问命中。数组共有 $256\times256=65536$ 次访问，块数 $65536/16=4096$，冷启动且不重复读取旧块，故缺失 4096 次、命中 $61440$ 次，命中率 $61440/65536=93.75\%$。

4. **程序 B：列扫描产生直接映射冲突。** 内层循环中相邻两次访问相差 $256\times4=1024\ \mathrm B$，折算成块号差 $1024/64=16$，其 Cache 行号差 $16\bmod8=0$，所以同一列的 256 个访问全部映射到**相同一行**，每次都覆盖上一行数据。跨到下一列时虽然回到相同行的另一元素，但先前对应的块早被其余 255 行替换，故每次访问依旧不命中，命中率为 0。不能只说“列访问跨度大”就直接认定 0；必须结合索引冲突和访问顺序证明。

5. **耗时比较及扩展。** 若命中时间为 $t_c$、缺失额外代价为 $t_m$，对同样次数的数组读操作，近似代价 $T\approx N t_c+N(1-h)t_m$；A 的缺失率 $1/16$，B 为 1。因此 A 的主存访问成本显著较低。真实程序还取决于指令调度和预取，但题设的缓存模型下 A 更优。题中已说明 `i、j、sum` 放寄存器，因而无需再为这些变量另计数据 Cache 访问。

6. **答题套路。** 先分地址位（主存地址位数／偏移／索引／标记），再用 `addr = base + (i*列数+j)*元素大小` 算地址，最后判断工作集是否能保留到下一次复用。区分**强制缺失**、**容量缺失**、**冲突缺失**；直接映射索引相同尤其容易导致“相同块内本有 16 个元素，却完全不能命中”的反常结果。

</ExamExplanation>
</ExamSolution>
</ExamQuestion>

<ExamQuestion>

某直接映射数据 Cache 共 8 行，每行 64 B；数组 `b[8][16]` 为 32 位整型，首地址为 0 且行优先存放，数据 Cache 起初为空。程序按列访问：

```c
for (int j=0; j<16; ++j)
    for (int i=0; i<8; ++i)
        use(b[i][j]);
```

1. 每个数组行占多少字节？不同数组行分别映射到哪些 Cache 行？
2. 首列共发生多少次未命中？后续 15 列的访问结果如何？计算整个循环命中率。
3. 如果改成 `b[9][16]` 并以同样顺序访问，初始为空，计算总缺失次数与命中率（其他条件不变）。

<ExamSolution>
<ExamAnswer>

1. 每行 $16\times4=64$ B，8 行分别映射到第 0～7 行。
2. 首列 8 次未命中，以后 $15\times8=120$ 次均命中；命中率 $120/128=93.75\%$。
3. 9 行时，首列 9 次未命中；以后每列第 0 行与第 8 行冲突，各发生 2 次未命中，总计 $9+2\times15=39$ 次；命中率 $(144-39)/144=105/144\approx72.92\%$。

</ExamAnswer>
<ExamExplanation>

1. 每行整好 1 个块，行号与索引一一对应；虽然访问按列进行，8 个主存块能同时留在 8 个 Cache 行中。
2. 第一列载入全体 8 块后，剩余 15 列所需的每个块均已驻留，没有块被挤出；“按列访问一定是 0 命中”是错误的绝对化结论。
3. 第 9 行的块号 8 映射到第 0 行，与第 0 行冲突；按每列“第 0 行先被访问，第 8 行后被访问”的顺序，二者会在每列互相替换。其他 7 行的数据块仍常驻，因此每个后续列只有两次缺失。计算时要把**冷缺失 9 次**与**后续冲突缺失 30 次**分开。

</ExamExplanation>
</ExamSolution>
</ExamQuestion>

<ExamQuestion>

沿用原题 256 MB 主存、64 B 块和 8 个 Cache 行，但把直接映射改成**2 路组相联**，Cache 仍共 8 行，忽略替换策略位。

1. Cache 共有多少组？28 位物理地址的 Tag、组索引、块内偏移分别多少位？
2. 若每行另有一位有效位，Cache 总容量是多少字节？
3. 原题地址 444 与 1348 分别映射到哪个组？它们必然冲突吗？

<ExamSolution>
<ExamAnswer>

1. 共 $8/2=4$ 组；Tag 20 位、组索引 2 位、块内偏移 6 位。
2. 总容量 $8\times(512+20+1)/8=533\ \mathrm B$。
3. 块号分别为 6、21，映射到第 $6\bmod4=2$ 组与第 $21\bmod4=1$ 组；不冲突。

</ExamAnswer>
<ExamExplanation>

1. 组相联地址划分依靠**组数**而不是总行数确定索引位；每组有 2 条路是选择可放置位置，并不额外增加主存地址索引位。
2. 同样 512 B 的数据区，由于索引位少 1 位，Tag 多 1 位，因此比原题直接映射的 532 B 多 1 B 元数据。
3. 只有组号相同的不同块才可能竞争本组路数；即使映射到同组，如果尚有空路，也未必立即替换。判断是否实际冲突还需要访问次序和替换规则。

</ExamExplanation>
</ExamSolution>
</ExamQuestion>

## 2011 年第 44 题

<ExamQuestion>

**42. 2011 年第 44 题**

某计算机存储器按字节编址，虚拟（逻辑）地址空间大小为 16MB，主存（物理）地址空间大小为 1MB，页面大小为 4KB。Cache 采用直接映射方式，共 8 行；主存与 Cache 之间交换的块大小为 32B。

系统运行到某一时刻时，页表和 Cache 的部分内容如下图所示，其中页框号和标记字段均采用十六进制表示。

<img src="/img/408/past-exams-large-questions/02-计算机组成原理/assets/2011-44-figure-001.svg" alt="2011 年第 44 题页表与 Cache 内容" />

请回答：

1. 虚拟地址共有多少位？哪几位是虚页号？物理地址共有多少位？哪几位是页框号（物理页号）？
2. 使用物理地址访问 Cache 时，物理地址应划分成哪些字段？分别有多少位、位于什么位置？
3. 虚拟地址 `001C60H` 所在页面是否在主存中？若在，则对应物理地址是什么？访问该物理地址时 Cache 是否命中？说明理由。
4. 假定配置一个 4 路组相联 TLB，共可存放 8 个页表项，其当前内容如下图。此时虚拟地址 `024BACH` 所在页面是否在主存中？说明理由。

<img src="/img/408/past-exams-large-questions/02-计算机组成原理/assets/2011-44-figure-002.svg" alt="2011 年第 44 题 TLB 内容" />

<ExamSolution>
<ExamAnswer>

1. 虚拟地址长 24 位，虚页号 `VA[23:12]`（12 位）；物理地址长 20 位，页框号 `PA[19:12]`（8 位）。
2. 物理地址字段：Tag `PA[19:8]` 12 位、Cache 行号 `PA[7:5]` 3 位、块内偏移 `PA[4:0]` 5 位。
3. 虚页 `001H` 在主存，物理地址 `04C60H`；访问 Cache 第 3 行，Tag=`04CH`，因当前对应行 Tag 不符而**不命中**。
4. 虚拟地址 `024BACH` 的虚页号 `024H`；TLB 第 0 组存在有效 Tag=`012H`，因此 TLB 命中，页面在主存（对应页框号 `1FH`）。

</ExamAnswer>
<ExamExplanation>

1. **首先把 KB、MB 化为 2 的幂并划分地址。** $16\mathrm{MB}=2^{24}\mathrm B$，虚拟地址 24 位；$1\mathrm{MB}=2^{20}\mathrm B$，物理地址 20 位；页大小 $4\mathrm{KB}=2^{12}\mathrm B$，两者低 12 位页内偏移保持不变。因此 VPN 位宽 $24-12=12$，PPN 位宽 $20-12=8$。所谓“哪几位”应明确编号区间，如 `VA[23:12]`，不能仅答“高位”。

2. **物理寻址的 Cache 字段。** Cache 块为 $32=2^5$ B，故块内地址占 5 位；共 $8=2^3$ 行，直接映射索引占 3 位；物理地址 20 位，剩余 Tag $20-3-5=12$ 位。格式为 `Tag[19:8] | Index[7:5] | Offset[4:0]`。注意分 Cache 字段的是**物理地址**，不是尚未翻译的 24 位虚拟地址；题目已明确采用物理地址访问 Cache。

3. **串联“查页表→得到物理地址→查 Cache”的计算。** `001C60H` 可拆为 `001H | C60H`，VPN=`001H`。读题图页表：对应条目有效位 1、页框号 `04H`，因此物理地址 `04C60H`。Cache 索引为 `PA[7:5]=011B=3`，块内偏移为 `00000B`，Tag=`04CH`。图示 Cache 行 3 当前有效，Tag=`105H`，与 `04CH` 不同，所以 Cache **未命中**。这里出现 Cache 缺失不代表缺页：数据仍可从已驻留的主存页读出并装入 Cache。

4. **4 路组相联 TLB 的组号和 Tag。** 总共 8 项、每组 4 路，故 $8/4=2$ 组，组号 1 位。以 VPN 低一位选组，高 11 位做 TLB Tag。地址 `024BACH` 的末尾 `H` 是十六进制**标记**，不是数码，故 24 位地址按 `024 | BAC` 分开，VPN=`024H`、页内偏移=`BACH`（末尾 H 代表十六进制）。组号 `024H % 2 = 0`，TLB Tag=`024H >> 1 = 012H`。题图中第 0 组存在有效 Tag `012H`，页框号 `1FH`，所以该页面在主存中。**TLB 命中不能推出对应数据已在 Cache 中**，还需单独检查 Cache。

5. **三个层次分别问什么。** 页表/TLB 处理虚拟页号到物理页框号的翻译；页表有效位（或存在位）决定该页是否驻留主存；Cache Tag/有效位决定相应物理主存块是否驻留 Cache。TLB miss 后还可能命中页表，Cache miss 后还可能命中主存，它们不是必然导致缺页异常的同一件事。

6. **做题速算模板。** VPN=`VA >> 12`、页内偏移=`VA & 0xFFF`；物理地址=`(PPN << 12) | offset`；Cache 索引=`(PA >> 5) & 7`、Tag=`PA >> 8`；TLB 组号=`VPN & 1`、TLB Tag=`VPN >> 1`。先算位宽，后移位与取模，再结合题图有效位判断，能避免把各级地址格式混用。

</ExamExplanation>
</ExamSolution>
</ExamQuestion>

<ExamQuestion>

沿用原题地址空间、页大小、物理地址访问直接映射 Cache（8 行、每行 32 B）及 4 路组相联 TLB（8 项）。假设虚页 `002H` 已驻留页框 `7FH`，Cache 第 5 行有效且 Tag=`7F3H`，TLB 第 0 组中有一有效条目 Tag=`001H`、页框=`7FH`。

1. 虚拟地址 `0023A5H` 的 VPN 与页内偏移分别是什么？TLB 应查哪一组、哪个 Tag？是否命中？
2. 该地址翻译后的物理地址是什么？Cache 索引、Tag、块内偏移是多少？是否命中？

<ExamSolution>
<ExamAnswer>

1. VPN=`002H`，页内偏移=`3A5H`；查 TLB 第 0 组、Tag=`001H`，TLB 命中。

3. 修改的是 Cache 中一个块的标识，不是页表存在位；**Cache miss、TLB miss、page fault** 三者应独立判断。

1. 给出这 4 个字节各自的虚拟地址与物理地址。

<ExamSolution>
<ExamAnswer>

1. 两个字节在 `003FFEH、003FFFH`，物理地址 `2AFFEH、2AFFFH`；另两个在 `004000H、004001H`，物理地址 `7B000H、7B001H`。
2. 跨越 2 个虚拟页，需翻译两个页号（可以由相应 TLB 项命中快速完成）。
3. 第二页会触发缺页异常/页面不存在事件，需要由操作系统处理，不能仅按普通 Cache miss 从主存取块继续。

</ExamExplanation>

## 2012 年第 43 题

<ExamQuestion>

**43. 2012 年第 43 题**

假定某计算机的 CPU 主频为 80MHz，CPI 为 4，平均每条指令访存 1.5 次，主存与 Cache 之间交换的块大小为 16B，Cache 命中率为 99%，存储器总线宽度为 32 位。请回答：

1. 该计算机的 MIPS 数是多少？平均每秒 Cache 缺失多少次？不考虑 DMA 传送时，主存带宽至少达到多少才能满足 CPU 的访存要求？
2. 假定 Cache 缺失后访问主存时存在 0.0005% 的缺页率，则 CPU 平均每秒产生多少次缺页异常？若页面大小为 4KB，每次缺页均需访问磁盘，DMA 采用周期挪用方式，磁盘 I/O 接口的数据缓冲寄存器为 32 位，则磁盘 I/O 接口平均每秒至少发出多少次 DMA 请求？
3. CPU 和 DMA 控制器同时请求使用存储器总线时，谁的优先级更高？为什么？
4. 主存采用四体低位交叉存储，每 $1/4$ 个存储周期启动一个存储体。若每个存储体的存储周期为 50ns，则主存能提供的最大带宽是多少？

<ExamSolution>
<ExamAnswer>

1. $20\,\mathrm{MIPS}$；每秒访存 $3.0\times10^7$ 次，Cache 缺失 $3.0\times10^5$ 次；最低主存数据带宽 $4.8\,\mathrm{MB/s}$。
2. 平均缺页 $1.5$ 次/s；每次缺页需 $1024$ 次 32 位 DMA 传送，故至少 $1536$ 次 DMA 请求/s。
3. 在题设周期挪用 DMA 中，一般 DMA 总线请求优先，以防止外设数据丢失；CPU 可暂时等待。
4. 四体低位交叉最短启动间隔 $12.5\,\mathrm{ns}$，理论最大带宽 $320\,\mathrm{MB/s}$。

</ExamAnswer>
<ExamExplanation>

1. **先统一“每秒指令数—访存数—缺失数—字节数”四个层次。** 主频 $f=80\times10^6$ 周期/s，$\mathrm{CPI}=4$，故指令吞吐率为 $f/\mathrm{CPI}=20\times10^6$ 条/s，即 $20\,\mathrm{MIPS}$。访存率为 $20\times10^6\times1.5=3\times10^7$ 次/s。Cache 缺失率为 $1-0.99=0.01$，得 $3\times10^5$ 次缺失/s。按“每次缺失调入 16B 块、忽略脏块写回及其他主存业务”的最小传输量：$3\times10^5\times16=4.8\times10^6\,\mathrm{B/s}$。这里 $\mathrm{MB}=10^6\mathrm B$，不是 $2^{20}\mathrm B$。**不要将 32 位总线宽度直接当作每次 Cache 缺失只读 4B**：它决定每拍可传 4B，完整块仍要传 16B（至少 4 次数据传送）。若存在写回/预取，实际带宽需求可能更高。
2. **小数百分数换算的陷阱。** $0.0005\%=0.0005/100=5\times10^{-6}$，不是 $5\times10^{-4}$。题意指 Cache 缺失后主存访问的条件缺页率，故平均每秒缺页 $3\times10^5\times5\times10^{-6}=1.5$ 次。每次换入 $4\mathrm{KB}=4096\mathrm B$，每次 DMA 请求由 32 位数据缓冲寄存器搬运 $4\mathrm B$，所以 $4096/4=1024$ 次/页，$1.5\times1024=1536$ 次/s。这里计数的是 **DMA 的总线服务请求次数**，不是“磁盘 I/O 操作次数”；后者按每次缺页一个页面传输计算至少为 $1.5$ 次/s。
3. **周期挪用与优先级。** 周期挪用 DMA 在 CPU 和 DMA 都要访问主存时，DMA 取得一个或若干存储器访问周期，随后释放总线；CPU 可能被阻塞。外设速率受数据缓冲容量约束，延误可能导致溢出，而 CPU 通常可以等候。因此常见总线仲裁约定 DMA 优先；具体计算机仍由硬件仲裁策略决定，不能推广成“DMA 永远高于任何 CPU 请求”。注意周期挪用、停止 CPU 访存的成组传送、透明 DMA 三种方式的差别。
4. **存储周期不等于交叉存储的发起间隔。** 每个存储体周期 $T=50\mathrm{ns}$，四体交叉顺序按体号 $0,1,2,3,0,\ldots$ 发起，下次使用同一体需要至少 $4t\ge T$，因此 $t=T/4=12.5\mathrm{ns}$。总线每次提供一个 32 位字 $=4\mathrm B$，理论稳态带宽 $4/(12.5\times10^{-9})=320\times10^6\mathrm{B/s}$。这是**连续顺序访问、地址分布均匀且总线不另成瓶颈**下的最大值；若总线每次传输耗时超过 $12.5\mathrm{ns}$，还应取总线所限带宽。

**考场速记：** $\mathrm{MIPS}=f/(\mathrm{CPI}\times10^6)$；缺失数 $=$ 指令率 $\times$ 每指令访存次数 $\times$ 缺失率；主存最低吞吐 $=$ 缺失数 $\times$ 传入块字节数；DMA 请求数 $=$ 缺页数 $\times$ 页大小 $/$ 单次传送字节数。

</ExamExplanation>
</ExamSolution>

1. Cache 每行中的 Tag、LRU 位各占几位？是否需要修改位？
2. 有如下 C 程序段：

```c
for (k = 0; k < 1024; k++)
    s[k] = 2 * s[k];
```

若数组 `s` 和变量 `k` 均为 `int` 型，`int` 占 4 B，`k` 分配在寄存器中，数组 `s` 在主存中的起始地址为 `008000C0H`，则程序执行过程中访问数组 `s` 的数据 Cache 缺失多少次？
3. 若 CPU 最先进行的访问是读取主存单元 `00010003H` 中的指令，简要说明从指令 Cache 访问该指令的过程，包括 Cache 缺失处理。

<ExamSolution>
<ExamAnswer>

1. 主存地址划分为 **20 位 Tag、6 位组号和 6 位块内偏移**。按每行记录 0～7 的 LRU 次序的实现，每行需 **3 位 LRU 状态**；直写策略不需要修改（脏）位。
2. 数组 `s` 的数据 Cache **缺失 64 次**。
3. `00010003H` 的 Tag 为 `00010H`、组号为 0、块内偏移为 `03H`。Cache 初始为空，必然缺失，应调入主存块 `00010000H`～`0001003FH`，设置 Tag 和有效位、更新 LRU，然后取所需指令。

</ExamAnswer>
<ExamExplanation>

1. **由“容量—块大小—路数”反推地址字段。** 主存块大小为 $64\mathrm B=2^6\mathrm B$，故块内偏移占 6 位。数据区容量 $32\mathrm{KB}$ 包含 $32\times1024/64=512$ 行；8 路组相联共有 $512/8=64=2^6$ 组，故组号占 6 位。32 位地址剩余 $32-6-6=20$ 位为 Tag：

   $$\underbrace{A_{31}\sim A_{12}}_{\text{Tag，20 位}}\;|\;\underbrace{A_{11}\sim A_6}_{\text{组号，6 位}}\;|\;\underbrace{A_5\sim A_0}_{\text{块内偏移，6 位}}.$$

   **LRU 的口径必须说清：** 教材中若用 0～7 的使用次序标记每一行，则每行需 $\lceil\log_2 8\rceil=3$ 位，8 路一组共 24 位；它描述的是指定编码方式，不是所有 LRU 电路的唯一或最小实现。其他硬件方案可能按组编码状态；树形伪 LRU 也不等同精确 LRU。直写（Write Through）对 Cache 中的写入同时更新主存，因此不必保留“与主存不一致”的脏位。**直写与写缺失时是否分配（Write Allocate）是两个独立策略**，不能混同。

2. **读写次数与缺失次数分开计。** `int` 为 4 B，数组占 $1024\times4=4096\mathrm B$。起始地址 `008000C0H` 的最低 6 位为 0，位于块首；每 64 B 块含 16 个元素，恰好涉及 $4096/64=64$ 个连续主存块。每个块第一次读取 `s[k]` 强制缺失一次，随后本块内其他读操作命中；写入发生在读操作之后，因而该元素写入时块已经驻留。64 个块正好访问一次，各有且只有 1 次强制缺失，故 $\boxed{64\text{ 次}}$。即便按“每个元素一次读、一次写”统计 2048 次数组 Cache 访问，缺失次数也不是 2048 次；若要求缺失率则为 $64/2048=3.125\%$。若题目改成纯写循环，才需追问写缺失分配策略。

3. **把地址的低 12 位分成组号和偏移。** `00010003H` 右移 12 位得到 Tag=`00010H`；低 6 位为 `03H`；第 11～6 位为 0。因此先选中**指令 Cache 第 0 组**，并行比较该组 8 路的有效位和 Tag。由于初始全无效，一定缺失；将块首地址按 64B 对齐得到 `00010000H`，取回完整 64B 块，放入无效行，写 Tag=`00010H`，置有效位并更新 LRU；最后由块内偏移 `03H` 定位所需指令字节。若对应指令长度超过当前块末尾，还要进一步考虑跨块取指，本题没有这类附加条件。

**做题检查表：** 区分数据区容量与含 Tag/状态位的总存储量；区分“行数”与“组数”；区分首次访问造成的强制缺失与替换缺失；区分读-改-写与仅写操作；最后用低位掩码验证组号和块内偏移。

</ExamExplanation>

<ExamSolution>
<ExamAnswer>

1. 地址字段为**柱面号（磁道号）**、**磁头号（盘面号）**、**扇区号**，至少分别需要 15、3、9 位。
2. 单扇区的平均访问时间约为 **$9.18\mathrm{ms}$**（寻道、平均旋转等待、一个扇区的传送时间之和）。
3. 假定每次请求传送一个 64 位缓冲区数据，则需 **64 次 DMA 总线请求**；CPU 同时请求主存时，周期挪用 DMA 通常可优先获得总线，以免外设数据覆盖或丢失，CPU 的访存须暂缓。

</ExamAnswer>
<ExamExplanation>

1. **CHS 三元组先数几何结构，再求二进制位宽。** CHS 即 Cylinder–Head–Sector：柱面号定位磁道半径，磁头号选盘面，扇区号选该磁道中的扇区。4 个**双面**盘片共 $4\times2=8$ 个盘面，每个盘面有 20000 条磁道，而所有盘面上同半径的磁道合起来构成一个柱面，因此柱面数为 20000，不是 $20000\times8$。位数取上整：

   $$\begin{aligned}
   b_C&=\lceil\log_2 20000\rceil=15,\\
   b_H&=\lceil\log_2 8\rceil=3,\\
   b_S&=\lceil\log_2 500\rceil=9.
   \end{aligned}$$

   合计至少 27 位描述一个扇区的几何位置。$2^{15}=32768\ge20000$；$2^9=512\ge500$。**盘片数、盘面数、磁道数和柱面数不能直接互换**。若拓展计算容量，用户数据区大小为 $8\times20000\times500\times512=40{,}960{,}000{,}000\mathrm B$（约 40.96 GB，按十进制计），不含格式开销。

   $$T_{avg}=5+4.1667+0.01667\approx\boxed{9.18\mathrm{ms}}.$$

3. **DMA 传输次数按缓冲字长，不按地址字段位宽。** 扇区中可用数据为 $512\mathrm B=4096$ bit，每次 DMA 搬运 $64$ bit 即 8B，所以 $N=4096/64=\boxed{64}$ 次。该答案的前提是题目隐含“缓冲区一次向主存传送一个 64 位数据字，且每次需单独仲裁一次”，若改成突发 DMA、每次占有总线连续传多个字，请求次数要依突发规则重算。

   **周期挪用与中断方式不同：** DMA 控制器获总线后在一个或若干主存周期内直接传输数据，并非让 CPU 逐字执行搬运指令。周期挪用发生竞争时通常授予 DMA 较高优先级，因为 I/O 流数据到达有时限；CPU 随后继续工作。**不意味着 DMA 永久占用总线**，也不意味着 CPU 永远不能访问主存。

1. 数组 `a` 分布在几个页面中？对于数组 `a` 的访问，会发生几次缺页异常？页故障地址各是什么？
2. 不考虑变量 `i` 和 `j`，该程序段对数据的访问是否具有时间局部性？为什么？

```c
for (j = 0; j < 64; j++)
    for (i = 0; i < 24; i++)
        a[i][j] = 10;
```

<ExamSolution>
<ExamAnswer>

1. `a` 占 **2 个 4KB 页面**；共发生 **2 次缺页异常**，首次访问引发缺页的虚拟地址是 `00422000H`、`00423000H`。

3. 块内地址为 $A_4\sim A_0$，组号为 $A_{10}\sim A_5$；`a[1][0]` 虚拟地址是 `00422100H`，对应组号 **8**。

</ExamAnswer>
<ExamExplanation>

1. **分页问题：先把二维数组转换成连续字节区间。** `int` 占 4B，总量 $24\times64\times4=6144\mathrm B$。首地址 `00422000H` 是 4KB 页边界；第一页 `00422000H`～`00422FFFH` 容纳 4096B，对应前 $4096/(64\times4)=16$ 行。第 17 行（`a[16][0]`）首地址 `00423000H` 开始第二页，剩余 $2048$B。只占 2 页，且原来两页都不在主存、此后不换出，所以每页第一次访问各缺页 1 次。

   **区分“页故障地址”与“页表项地址”：** 本题要求的故障访问虚拟地址分别为第一次触发缺页的 `00422000H` 和 `00423000H`，不是物理页框地址；页号可分别写作 `00422H` 和 `00423H`。

2. **时间局部性不等于空间局部性。** 对数组执行 `a[i][j]=10`，每个元素只写一次，不存在短期重复使用同一元素的行为，因此对数组数据没有明显时间局部性。行优先存储时，原循环的内层 `j` 连续变化，地址每次加 4B，表现出明显空间局部性。交换循环后，内层 `i` 变化一次跨过 $64\times4=256$B，直接空间局部性变差，但不能据此断言最终命中率必然下降；命中率还由组相联度及冲突程度决定。

3. **先行、后组、再取位。** Cache 块长 $32\mathrm B=2^5$B，故块内偏移占 5 位；行数 $8\mathrm{KB}/32\mathrm B=256$，4 路组相联得到 64 组，组号需 6 位。地址按 $[Tag]\,|\,[A_{10}:A_5]\,|\,[A_4:A_0]$ 划分。每行数组占 256B，所以 `a[1][0]` 地址为 `00422000H+100H=00422100H`，组号为

   $$\left(\frac{\texttt{00422100H}}{32}\right)\bmod64=\boxed{8}.$$

   若 Cache 用物理地址标记，判断组号本应使用物理地址；但本题组号和块内偏移的最高位为 $A_{10}$，均处于 4KB 页内偏移 $A_{11}\sim A_0$，因此虚实地址的这些位相同，**无需知道物理页框号即可求组号**。

4. **分析两种循环次序时，必须检查 Cache 组竞争。** 数据区总量 $6144$B，按 32B 对齐且首地址也对齐，恰好 192 块。每块 8 个 `int`，总写入 1536 次。**题目给出的 $87.5\%$ 以写分配（Write Allocate）为前提**：首次写入某个尚未驻留的主存块会导致缺失并将该块装入 Cache，后续写该块中另外 7 个元素命中。

   - 原循环：每 8 个连续 `int` 的写入形成“1 缺失 + 7 命中”，共 192 缺失和 $1536-192=1344$ 命中，因此 $1344/1536=87.5\%$。

   **隐藏条件提醒：** 仅说“数据不与其他数据产生 Cache 冲突”并不自动保证数组内部无冲突，必须像上面一样核验每组最多容纳多少活跃块。若机器采用**写不分配**（No Write Allocate）且本程序只有对 `a` 的存储指令，那么缺失写入不装块，每次写都可能缺失，命中率不能沿用 87.5%。考场应遵循原题默认的缺失装块条件，并在严谨推导中写出前提。

3. 单向扫描中的每个块首次写入缺失并被分配，其余本块元素命中；题设无块置换，故 13 次缺失，命中率 $(100-13)/100=87\%$。缺页次数为 2、Cache 缺失次数为 13：**页与块的粒度不同，绝不能互相代替**。

</ExamExplanation>
</ExamSolution>
</ExamQuestion>

## 2025 年第 43 题

<ExamQuestion>

**69. 2025 年第 43 题**

现有 C 语言程序 P 的部分代码如下：

```c
int x, d[2048], i;
...
for (i = 0; i < 2048; i++)
    d[i] = d[i] / x;
...
```

假定运行 P 的计算机 M 字长为 32 位，按字节编址，数据 Cache 的数据区大小为 $32\text{ KB}$，采用 8 路组相联映射，主存块大小为 $64\text{ B}$，Cache 命中时间为 2 个时钟周期，缺失损失为 200 个时钟周期；采用页式虚拟存储管理，页大小为 $4\text{ KB}$。数组 `d` 的起始虚拟地址 $VA_{31}\sim VA_0$ 为 `0180 0020H`。请回答下列问题。

1. 主存地址中的 Cache 组号字段、块内地址字段分别占几位？虚拟地址中哪些位可作为 Cache 索引？
2. `d[100]` 的虚拟地址是多少？`d[100]` 所在主存块对应的 Cache 组号是多少？
3. 假定执行 `for` 语句时对应代码已在 Cache 中，变量 `i` 和 `x` 已装入寄存器，数组 `d` 已调入主存但不在 Cache。`d[0]` 在其所在主存块内的偏移量是多少（用十六进制表示）？执行 `for` 的过程中，访问 `d` 的 Cache 缺失率和数组元素的平均访问时间分别是多少？缺失率用百分比表示并保留两位小数。
4. `d` 分布在几个页中？若代码已在主存而 `d` 不在主存，则执行 `for` 的过程中，访问 `d` 所引起的缺页次数是多少？

<ExamSolution>
<ExamAnswer>

1. Cache 组号占 **6 位**，块内地址占 **6 位**；可用虚拟地址中的 **$VA_{11}\sim VA_6$** 作为组索引。
2. `d[100]` 的虚拟地址为 **`018001B0H`**，Cache 组号为 **6**。
3. `d[0]` 的块内偏移为 **`20H`**。数组访问共 4096 次，其中 129 次缺失，缺失率约为 **$3.15\%$**；平均访问时间约为 **$8.30$ 个时钟周期**。
4. `d` 跨越 **3 个页面**。若执行前数组页均不在主存、执行中没有将其再次换出，则有 **3 次缺页**。

</ExamAnswer>
<ExamExplanation>

1. **地址划分的三步：块、组、页。** 块大小 $64\mathrm B=2^6\mathrm B$，故块内偏移 6 位；Cache 数据区 $32\mathrm{KB}$ 有 $32\times1024/64=512$ 行，8 路组成 $512/8=64=2^6$ 组，故组号 6 位。物理 Cache 访问地址从低到高依次是偏移 $[5:0]$、组号 $[11:6]$、其上为 Tag。4KB 页面有 12 位页内偏移，低 12 位在虚实地址转换中不变，所以 $VA_{11}\sim VA_6$ **可直接用于索引**。这是 VIPT（虚拟索引、物理标记）类题的关键条件：

   $$\text{组号位数}+\text{块内偏移位数}\le\text{页内偏移位数}.$$

   本题 $6+6=12$，刚好满足。注意：**索引可以从虚拟地址取得，不表示 Tag 可以直接取虚拟高位**；Tag 是否命中仍须结合物理地址和有效位判断。

2. `d[100]` 位于首元素后第 100 个 4B 单元，偏移 $100\times4=400=\texttt{190H}$；因此地址为 `01800020H+190H=018001B0H`。块内偏移 $\texttt{1B0H}\bmod\texttt{40H}=\texttt{30H}$；组号 $\lfloor\texttt{1B0H}/\texttt{40H}\rfloor\bmod64=6$。**取组号时应先除以块大小，不能直接把低 6 位误当组号。**

3. **先数覆盖的块，再数全部访问。** `d[0]` 的地址低 6 位是 `20H`（32B），数组总长 $2048\times4=8192$B；从一个块的中间开始，所覆盖的块数为

   $$N_{blocks}=\left\lceil\frac{32+8192}{64}\right\rceil=\boxed{129}.$$

   每轮 `d[i]=d[i]/x` 对数组元素先读一次再写一次；`x` 与 `i` 已在寄存器中，不额外增加对数组的访问，故总数据 Cache 访问次数是 $2048\times2=4096$。每块首次读取缺失一次，随后相应写操作命中。数组虽涉及 129 个块，但它们均匀落入 64 组，每组至多出现 3 个数组块，低于每组 8 路，不产生内部冲突淘汰；所以缺失数是 129。

   $$r_{miss}=\frac{129}{4096}\approx\boxed{3.15\%}.$$

   已知“命中时间 2 周期、**缺失损失**200 周期”，缺失损失是命中时间之外的额外开销，因此

   $$\mathrm{AMAT}=T_{hit}+r_{miss}T_{penalty}=2+\frac{129}{4096}\times200\approx\boxed{8.30\text{ 周期}}.$$

   **概念辨析：** 若题目改称“缺失时总访问耗时 200 周期”，则公式应为 $(1-r)T_{hit}+rT_{miss,total}$，不可额外重复加一次命中时间。本题“缺失损失”一词对应额外惩罚。此处的“平均数组元素访问时间”依原题口径按一次 Cache 读或写访问平均，不是将两次访问合并成一次后重新定义平均。

4. **页数和块数分开算。** 页内偏移为 `020H`=32B，数组长度为 8192B，恰为两整页大小，但首地址不在页边界：第 1 页先容纳 $4096-32=4064$B，余下 $4128$B 需要再跨过一整页并进入第 3 页。因此页数

   $$N_{pages}=\left\lceil\frac{32+8192}{4096}\right\rceil=\boxed{3}.$$

   这三页虚拟页首地址依次为 `01800000H`、`01801000H`、`01802000H`；首次访问对应页内数组位置时各发生一次缺页。**不应将“129 次 Cache 缺失”写成“129 次缺页”。** Cache 行 64B、页面 4096B，两者粒度完全不同。

</ExamExplanation>
</ExamSolution>
</ExamQuestion>

沿用原题的 Cache 参数、页大小、数组元素个数及 `d[i]=d[i]/x` 循环，但将数组首地址改为 **`01800000H`**（64B 块边界且为 4KB 页边界）。仍假设数组在主存中但开始不在 Cache，其他数据不冲突。

1. 数组共占几个主存块和几个页面？
2. 总数组 Cache 访问次数及缺失次数各是多少？缺失率按百分比保留两位小数。

2. 总访问次数仍为 4096 次，缺失 128 次，缺失率 $128/4096=3.125\%\approx3.13\%$。

<ExamQuestion>

某 32 位字节编址计算机采用数据 Cache：$32\mathrm{KB}$ 数据区、8 路组相联、64B 块、直写策略；数组 `int q[1024]` 从 64B 边界开始，原先不在 Cache。忽略其他访问，依次且仅执行一次：

```c
for (i = 0; i < 1024; i++)
    q[i] = 1;
```

分别讨论如下两种**写缺失策略**：甲为写分配，乙为写不分配。

1. 甲方案的 Cache 访问总次数、缺失数、命中率分别是多少？
2. 乙方案的 Cache 访问总次数、缺失数、命中率分别是多少？
3. 两种方案对主存写操作的基本影响是什么？为什么不能直接把原题 `d[i]=d[i]/x` 的缺失率套用到这里？

<ExamSolution>
<ExamAnswer>

1. 甲：1024 次写访问、64 次写缺失，命中率 $(1024-64)/1024=93.75\%$。
2. 乙：1024 次写访问、1024 次写缺失，命中率 **0%**。
3. 两种方案均为直写，每次存储最终都要更新主存；写分配还在写缺失时把相应块调入 Cache，写不分配则绕开 Cache 直接更新主存。原题先读后写，先读已使块驻留，本题只有写，策略差异才直接影响缺失数。

</ExamAnswer>
<ExamExplanation>

1. 每块 64B 可装 16 个 `int`，1024 个整数共 64 块。写分配时首个写失配装入整个块，后续同块 15 次写命中，因此 64 次缺失、960 次命中。
2. 写不分配时每个写缺失都不把块载入 Cache；每个数组元素只写一次，没有此前读访问，所以全程 1024 次写均缺失。
3. “直写/写回”规定**写命中后主存是否同步更新**，“写分配/写不分配”规定**写缺失是否装块**。这两对术语彼此独立；不能只看到“直写”就判断纯写数组的 Cache 缺失数。本问忽略了写缓冲、合并写等实现细节，仅按题设讨论 Cache 命中与缺失。

</ExamExplanation>
