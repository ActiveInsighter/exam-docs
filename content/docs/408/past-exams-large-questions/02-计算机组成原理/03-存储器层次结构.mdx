# 第 3 章 存储器层次结构

## 3.4 外存储器

<Question id="408-2be72e-021" type="essay" tags="来源:2022考研408">

假设某磁盘驱动器中有4 个双面盘片,每个盘面有20000 个磁道,每个磁道有500 个扇区, 每个扇区可记录512 字节的数据, 盘片转速为7200r/m(转/ 分), 平均寻道时间为5ms。请回答下列问 题:
   (1) 每个扇区包含数据及其地址信息, 地址信息分为3 个字段。这3 个字段的名称各是什么？对于该 磁盘,各字段至少占多少位?
   (2) 一个扇区的平均访问时间约为多少？
   (3) 若采用周期挪用DMA 方式进行磁盘与主机之间的数据传送, 磁盘控制器中的数据缓冲区大小为 64 位,则在一个扇区读写过程中, DMA 控制器向CPU 发送了多少次总线请求? 若CPU 检测到DMA 控制器的总线请求信号时也需要访问主存, 则DMA 控制器是否可以获得总线使用权? 为什么?

<Solution>

**【解析】**

(1) ① 三个字段分别为：柱面号（或磁道号）、盘面号（或磁头号）、扇区号。

② 由“每个盘面有 20000 个磁道”，可知该磁盘至少有 20000 个柱面，可得柱面号（磁道号）至少为 $\lceil\log_2 20000\rceil=15$ 位；由“有 4 个双面盘片”，可知该磁盘有 $4\times2=8$ 个盘面，盘面号至少为 $\log_2 8=3$ 位；由“每个磁道都 500 个扇区”，可知扇区号至少为 $\lceil\log_2 500\rceil=9$ 位。

(2) 一个扇区的平均访问时间 = 平均寻道时间 + 平均等待（延迟）时间 + 数据传输时间。

① 题目已说明平均寻道时间为 5ms；

② 平均等待（延迟）时间一般默认为磁盘旋转半周所需的时间。由于磁盘转速为 7200 转/分，因此磁盘旋转一周的时间约为 $60\mathrm{s}/7200\approx8.33\times10^{-3}\mathrm{s}=8.33\mathrm{ms}$。可得平均等待时间 = $8.33\mathrm{ms}\div2\approx4.165\mathrm{ms}$；

③ 数据传输时间（盘片转一个扇区时间，每个磁道 500 个扇区）为 $8.33\mathrm{ms}\div500\approx0.017\mathrm{ms}$。

上述三者相加可得：一个扇区的平均访问时间约为 $5\mathrm{ms}+4.165\mathrm{ms}+0.017\mathrm{ms}\approx9.18\mathrm{ms}$。

(3) ① 在一个扇区读写过程中，每当数据缓冲区的数据充满了，DMA 控制器就要向 CPU 发送一次请求。一个扇区的大小是 512B，缓冲大小 64b = 8B，因此读写一个扇区时向 CPU 发送请求次数 = 扇区大小/缓冲大小 = $512\mathrm{B}\div8\mathrm{B}=64$ 次。

② DMA 控制器的总线使用权优先级高于 CPU，故 DMA 可以获得总线使用权。若磁盘读写的时候 DMA 失去了总线控制权，那么数据缓冲区的数据会发生丢失现象，不能在规定的时间内传输数据。

**【提示】** 周期挪用 DMA 方式是指当 I/O 设备发出 DMA 请求时，会挪用或窃取一个或几个存取周期用于 DMA 接口的数据传送，传送结束后 CPU 仍可以继续访问主存。

**【点评】** 常规题。本题考的都是简单的基础概念。第一问可当作结论记忆了解。第二问在 2013 年 408 第 21 题和 2015 年 408 的第 20 题均考过，教辅书中也有介绍。第三问是常见概念。

</Solution>

</Question>

## 3.5 Cache

<Question id="408-2be72e-031" number={2} type="essay" tags="来源:2010考研408">

某计算机的主存地址空间大小为256MB, 按字节编址。指令Cache 和数据Cache 分离, 均有8 个Cache 行, 每个Cache 行大小为64B, 数据Cache 采用直接映射方式。现有两个功能相同的 程序A 和B, 其伪代码如下所示。假定int 类型数据用32 位补码表示, 程序编译时i, j, sum 的分配在 寄存器中, 数组a 按行优先方式存放, 其首地址为320(十进制数)。 请回答下列问题, 要求说明理由或给出计算过程。
   (1) 若不考虑用于Cache 一致性维护和替换算法的控制位, 则数据Cache 的总容量为多少？
   (2) 数组元素$a[0][31]$和$a[1][1]$各自所在的主存块对应的Cache行号分别是多少（Cache行号从0开始）?
   (3) 程序A 和B 的数据访问命中率各是多少？哪个程序的执行时间更短？ 程序 A：

```c
int a[256][256];
...
int sum_array1（ ）
{
    int i, j, sum = 0;
    for (i = 0; i < 256; i++)
        for (j = 0; j < 256; j++)
            sum += a[i][j];
    return sum;
}
```

   程序 B：

```c
int a[256][256];
...
int sum_array2（ ）
{
    int i, j, sum = 0;
    for (j = 0; j < 256; j++)
        for (i = 0; i < 256; i++)
            sum += a[i][j];
    return sum;
}
```

<Solution>

**【解析】**

(1) ① 一行 Cache 的内容包括辅助位和 Cache 块数据（存储对应的主存块数据）。辅助位包括 Tag 位、有效位、脏位、LRU 标记位等，其中 Tag 位和有效位是任何 Cache 所必需的。题目已说明“不考虑 Cache 一致性维护和替换算法的控制位”，则 Cache 行内容如下表所示。

| 有效位 | 标记位 | Cache 块数据 |
| --- | --- | --- |

② 每个 Cache 块占 64B，有效位为 1bit，接下来求标记位的位数。直接映射的物理地址结构如下表所示。

| 标记 | Cache 块号 | 块内地址 |
| --- | --- | --- |

Cache 行数为 8，则 Cache 块号占 $\log_2 8=3$ 位。主存块和 Cache 块大小相等，均为 64B，则块内地址占 $\log_2 64=6$ 位。主存地址空间为 256MB，按字节编址，则主存地址占 $\log_2\frac{256\text{MB}}{\text{B}}=28$ 位。所以，标记位占 $28-3-6=19$ 位。

③ 物理地址中的标记位数和 Cache 行中的标记位数相等，均为 19 位。综上所述，每一行 Cache 中，有效位为 1bit，标记位为 19bit，Cache 块为 $64\text{B}=64\times8=512\text{bit}$。数据 Cache 有 8 行，则总容量为 $8\times(1+19+512)=532\times8\text{bit}=532\text{B}$。即：数据 Cache 的总容量为 532B。

(2) 第 (1) 问已经求出直接映射的物理地址结构各部分所占位数如下表所示。

| 标记（19 位） | Cache 块号（3 位） | 块内地址（6 位） |
| --- | --- | --- |

① 数组 a 首地址为 320，数组 a 按行优先存储，按字节编址，每个 int 类型数据占 4B，则数组元素 `a[0][31]` 的地址为 $320+4\times31=444=\text{0001 1011 1100B}$，根据物理地址结构可知，Cache 块号为 110B = 6。即：<u>数组元素 `a[0][31]` 所在的主存块对应的 Cache 行号为 6</u>。

② 同理，因为数组 a 按行优先存储，一行有 256 个元素，则数组元素 `a[1][1]` 的地址为 $320+4\times256+4\times1=1348=\text{0101 0100 0100B}$，根据物理地址结构可知，Cache 块号为 101B = 5。即：<u>数组元素 `a[1][1]` 所在的主存块对应的 Cache 行号为 5</u>。

(3) ① **【解法一】** 程序 A 中，数组 a 的访问顺序和存储顺序完全一致，连续访问同一行的元素。访问数组 a 的次数为 $256\times256=2^{16}$。数组 a 占 $\frac{256\times256\times4\text{B}}{64\text{B}}=2^{12}$ 个主存块。访问每个主存块中的第一个元素时，因为该主存块还未调入 Cache，导致 Cache 未命中，将该主存块调入 Cache，随后再访问该主存块中的其他元素时，Cache 均命中。则 Cache 不命中次数为 $2^{12}$，命中次数为 $2^{16}-2^{12}$，Cache 命中率为

$$
\frac{2^{16}-2^{12}}{2^{16}}=1-\frac{1}{16}=\frac{15}{16}=93.75\%。
$$

**【解法二】** 每个 int 类型数组元素占 4B，Cache 行大小为 64B，则一个 Cache 行可存放 $\frac{64\text{B}}{4\text{B}}=16$ 个数组元素。程序 A 中，数组 a 的访问顺序和存储顺序完全一致，连续访问同一行的元素。则每访问 16 个连续元素，仅第 1 个不命中，Cache 不命中后，会将该主存块未调入 Cache（调入相邻的 16 个元素），则后续 15 个均命中，Cache 命中率为 $\frac{15}{16}=93.75\%$。

{/* 原书此处写作“会将该主存块未调入 Cache”，保留原文。 */}

② 数组 a 按行优先方式存放，程序 B 中按列访问数组 a，依次访问 `a[0][0]`、`a[1][0]`、`a[2][0]`、……、`a[255][0]`。程序 B 中，连续访问数组 a 中的 2 个元素，中间间隔 256 个数组元素（例如：`a[0][0]` 和 `a[1][0]` 中间间隔 256 个元素），$256\times4=1024\text{B}$，每个 Cache 行占 64B，$1024\%64=0$，数据 Cache 采用直接映射，说明这 2 个元素映射到同一个 Cache 行。则每次访问都会发生 Cache 冲突失效：新块覆盖旧块，下一次访问同一列的下一个元素时，原块已被替换，必须重新加载。所有访问 Cache 均不命中，Cache 命中率为 0%。

③ 执行程序 A 时，Cache 命中率高；执行程序 B 时，Cache 命中率为 0。所以程序 A 的执行时间更短。

**【点评】** 难题。本题综合性很强，全面考查了 Cache 相关考点，也有一定的计算量，做起来很费时间。

</Solution>

<Question id="408-2be72e-032" type="essay" tags="来源:2012考研408">

假定某计算机的CPU 主频为80MHz,CPI 为4, 平均每条指令访存1.5 次, 主存与Cache 之间交换的块大小为16B, Cache 的命中率为99%,存储器总线宽度为32 位。请回答下列问题:
   (1) 该计算机的MIPS 数是多少？平均每秒Cache 缺失的次数是多少？在不考虑DMA 传送的情况下, 主存带宽至少达到多少才能满足CPU 的访存要求?
   (2) 假定在Cache 缺失的情况下访问主存时, 存在0.0005% 的缺页率, 则CPU 平均每秒产生多少次缺 页异常? 若页面大小为4KB, 每次缺页都需要访问磁盘, 访问磁盘时DMA 传送采用周期挪用方式, 磁 盘I/O 接口的数据缓冲寄存器为32 位, 则磁盘I/O 接口平均每秒发出的DMA 请求次数至少是多少？
   (3)CPU 和DMA 控制器同时要求使用存储器总线时,哪个优先级更高? 为什么?
   (4) 为了提高性能, 主存采用四体低位交叉存储模式, 工作时每1/4 个存储周期启动一个体。若每个 体的存储周期为50ns, 则该主存能提供的最大带宽是多少？

<Solution>

**【解析】**

(1) ① CPU 主频指每秒有多少个时钟周期，CPI 指执行一条指令平均需要多少个时钟周期，MIPS 指每秒执行百万条指令数。CPU 每秒有 80M 个时钟周期，而执行一个指令平均要 4 个时钟周期，故 CPU 平均每秒能执行 $80\mathrm{M}\div 4=20\mathrm{M}$ 条指令，故 MIPS = 20。

② CPU 平均每秒执行 20M 条指令，平均每条指令访存 1.5 次，则 CPU 平均每秒访存 $20\mathrm{M}\times 1.5=30\mathrm{M}$ 次。每次访存先访问 Cache，Cache 命中率为 99%，则 Cache 缺失率为 $1-99\%=1\%$，则平均每秒 Cache 缺失次数为 $30\mathrm{M}\times 1\%=3\times 10^5$ 次。③ 每次 Cache 缺失时，需要从读取 16B 数据写入 Cache，则主存带宽至少为 $3\times 10^5\times 16\mathrm{B}=4.8\mathrm{MB/s}$。

(2) CPU 平均每秒产生的缺页次数为 $3\times 10^5\times 0.0005\%=1.5$ 次。

每页 DMA 请求次数 $=\dfrac{\text{页面大小}}{\text{总线宽度}}=\dfrac{4\mathrm{KB}}{32\mathrm{bit}}=1\mathrm{K}$，每秒 DMA 请求次数 = 每秒缺页次数 × 每页 DMA 请求次数 $=1.5\times 1\mathrm{K}=1.5\times 1024=1536$ 次（注意不是 1500 次，这里 $1\mathrm{K}\ne 1000$）。

(3) DMA 控制器优先级更高。原因：DMA 用于高速外设（例如：磁盘）与主存间的数据传输，若不及时响应，外设数据会丢失（例如：磁盘缓冲区溢出）；而 CPU 访问主存的请求可以等待，不会导致数据永久性丢失。

(4) 每 1/4 个存储周期启动一个体，每个存储体传输 32 位数据，则一个存储周期（50ns）内可传输 $4\times 32\mathrm{bit}=128\mathrm{bit}=16\mathrm{B}$ 数据，带宽 $=\dfrac{16\mathrm{B}}{50\mathrm{ns}}=320\mathrm{MB/s}$。

**【提示】** 需注意单位。K、M 在表示数量、速度时，$1\mathrm{K}=10^3$、$1\mathrm{M}=10^6$。K、M 在表示存储空间大小、文件大小时，$1\mathrm{K}=2^{10}$、$1\mathrm{M}=2^{20}$。

**【点评】** 概念题。① 本题综合考查计组中的基本概念，后一问要用到前一问的结论（后一问在前一问的基础上计算），很容易一步错导致步步错。② 另外，第 (2) 问“假定在 Cache 缺失的情况下访问主存时，存在 0.0005% 的缺页率”，这句话的表述很不严谨，很不妥当：缺页发生在虚实地址转换过程中，Cache 缺失发生在根据物理地址去访问主存的过程中，只可能先发生“缺页”再发生“Cache 缺失”。题目把顺序说反了，会让人感觉莫名其妙。

</Solution>

</Question>

<Question id="408-2be72e-033" type="essay" tags="来源:2013考研408">

某32 位计算机, CPU 主频为800MHz, Cache 命中时的CPI 为4, Cache 块大小为32 字节； 主存采用8 体交叉存储方式, 每个体的存储字长为32 位、存储周期为40ns；存储器总线宽度为32 位,总线时钟频率为200MHz,支持突发传送总线事务。每次读突发传送总线事务的过程包括: 送首地 址和命令、存储器准备数据、传送数据。每次突发传送32 字节, 传送地址或32 位数据均需要一个 总线时钟周期。请回答下列问题, 要求给出理由或计算过程。
   (1)CPU 和总线的时钟周期各为多少? 总线的带宽(即最大数据传输率) 为多少?
   (2)Cache 缺失时, 需要用几个读突发传送总线事务来完成一个主存块的读取？
   (3) 存储器总线完成一次读突发传送总线事务所需的时间是多少？
   (4) 若程序BP 执行过程中, 共执行了100 条指令, 平均每条指令需进行1.2 次访存, Cache 缺失率为 5%, 不考虑替换等开销, 则BP 的CPU 执行时间是多少?

<Solution>

**【解析】**

(1) ① CPU 时钟周期是主频的倒数，CPU 时钟周期 $=\frac1{800\mathrm{MHz}}=1.25\mathrm{ns}$。② 总线时钟周期是总线时钟频率倒数，总线时钟周期 $=\frac1{200\mathrm{MHz}}=5\mathrm{ns}$。③ 存储器总线宽度为 32bit = 4B，即：每个总线时钟周期可传输 4B 数据，则总线带宽 $=4\mathrm{B}\times200\mathrm{MHz}=800\mathrm{MB/s}$。

**【提示】** 总线带宽 = 总线宽度 ÷ 总线时钟周期 = 总线宽度 × 总线时钟频率

(2) 每次突发传送 32B，Cache 块大小为 32B，主存块和 Cache 块大小相等，所以读取一个主存块需要 1 个读突发传送总线事务。

(3) 一次突发总线事务过程包括：

- 送首地址和命令：1 个总线时钟周期 = 5ns
- 存储器准备数据：主存为 8 体交叉存储，存储周期 40ns，每隔 5ns 启动一个存储体，交叉存储器是流水线式并行存储。读取 32B 数据的时间为 $40\mathrm{ns}+(8-1)\times5\mathrm{ns}=75\mathrm{ns}$。

  **【提示】** 4 体交叉存储器读取 6 个存储字长示意图如下图所示。交叉存储器默认是低位交叉。关于交叉存储器的数据存取时间，考生若不熟悉，可再回顾学习一遍，这里限于篇幅，不再重复讲述。

- 传送数据：题目已说明“传送 32 位数据需要一个总线时钟周期（5ns）”，传送 32B 数据需要 8 个总线时钟周期 $=8\times5\mathrm{ns}=40\mathrm{ns}$。读取数据和传送数据可并行。读完第一个存储体之后，读取后续存储体数据的同时、可在总线上传送已读取的上一个存储体的数据，可并行 7 个总线时钟周期（35ns）。

总线完成一次突发传送总线事务需要 $(5+75+40-35)\mathrm{ns}=85\mathrm{ns}$。

![4体交叉存储器读取6个存储字长](/img/2013-a43.svg)

(4) CPU 执行时间 = Cache 命中时的 CPU 执行时间 + Cache 缺失时的额外访存时间。

① 题目中说明“Cache 命中时的 CPI 为 4”：意思是当所有访存都命中 Cache 时（这里已经考虑了 Cache 命中率），平均每条指令的 CPI 是 4。Cache 命中时的执行时间 $=100\times4\times1.25\mathrm{ns}=500\mathrm{ns}$。② Cache 缺失次数 $=100\times1.2\times5\%=6$ 次。题目第 (2) 和 (3) 问已经求出，每次 Cache 缺失访存需要读取一个主存块，需要完成一次突发总线传送，时间为 85ns。则 Cache 缺失时的额外访存时间 $=85\mathrm{ns}\times6=510\mathrm{ns}$。

CPU 执行时间 $=500\mathrm{ns}+510\mathrm{ns}=1010\mathrm{ns}$。

**【点评】** 概念题。本题前两问容易得分，比较简单。第 (3) 问难点在于交叉存储器的读取和数据在总线上的传送可并行。第 (4) 问要用到第 (3) 问的结论，易错点在于利用“Cache 命中时的 CPI 为 4”的结论时，不用再乘以 Cache 命中率 95%，这点极易出错。

</Solution>

<Question id="408-2be72e-034" type="essay" tags="来源:2014考研408">

③ Cache 缺失后，现代主流通用 CPU 都是将缺失的主存块写入 Cache 的同时，将所需数据送往 CPU。在早期 CPU 设计中，查 Cache 标记发现 Cache 缺失后，先读取主存数据块写入 Cache 块，再从 Cache 块中读取所需数据送往 CPU，这个过程（先查 Cache 标记 → 写入 Cache 块 → 从 Cache 块中取数据送 CPU）属于 Cache 的内部读写，不改变外部访问 Cache 的计数，所以这个过程属于“一次访问 Cache”，不是两次访问 Cache，这点很容易混淆。

② Cache 命中判断：根据图中给出的物理地址结构，将物理地址 0040040H 拆分为 Tag（20 位）+ 组索引（3 位）+ 块内偏移（5 位）。0040040H = 0000 0000 0100 0000 0000 0100 0000B，则 Tag = 00400H，组号 = 010B = 2，块内偏移 = 00000B。查图中 Cache 第 2 组：左路 Tag = 00400H 但有效位 = 0（无效）；右路 Tag = 01600H（不匹配）。故 Cache 未命中。

③ ▷ 根据图中给出的虚拟地址结构：

| 虚页号（20 位） | 页内偏移（12 位） |
| --- | --- |

虚拟地址 0007C260H 的页内偏移（后 12 位）= 260H = 0010 0110 0000B。

▷ 根据图中给出的物理地址结构：

| Tag 标记（20 位） | 组号（3 位） | 块内偏移（5 位） |
| --- | --- | --- |

Cache 组号是物理地址的第 6～8 位（块内偏移左边 3 位），而页内偏移在虚实地址转换中保持不变，因此直接取页内偏移的第 6～8 位：011B = 3。该地址所在主存块映射到 Cache 第 3 组。

**【拓展】** 在 2022 年 408 第 16 题考查了 Cache 比较器的个数、位数，其原理和本题出现的 TLB 比较器一致。所以，考生应仔细研究分析历年 408 真题，真的会遇到“原题”。以 TLB 为例，下面是关于比较器的个数结论：

- 直接映射：一个块只能映射到一个 TLB 行，故只需要一个比较器；
- 全相联映射：一个块可以映射到多个 TLB 行，为了加快映射速度，一般采用多个比较器，一个 TLB 行对应一个比较器；
- 组相联映射中需要的比较器个数为 TLB 一组中的行数。

<Question id="408-2be72e-048" type="essay" tags="来源:2021考研408">

假设计算机M 的主存地址为24 位, 按字节编址；采用分页存储管理方式, 虚拟地址为30 位, 页大小为4KB；TLB 采用2 路组相联方式和LRU 替换策略, 共8 组。请回答下列问题:
   (1) 虚拟地址中哪几位表示虚页号？哪几位表示页内地址？
   (2) 已知访问TLB 时虚页号高位部分用作TLB 标记, 低位部分用作TLB 组号, M 的虚拟地址中哪几位是TLB 标记? 哪几位是TLB 组号?
   (3) 假设TLB 初始时为空, 访问的虚页号依次为10,12,16,7,26,4,12 和20, 在此过程中, 哪一个虚页号对应的TLB 表项被替换? 说明理由。
   (4) 若将M 中的虚拟地址位数增加到32 位, 则TLB 表项的位数增加几位？

<Solution>

**【解析】**

(1) 虚拟地址格式为 `虚页号 | 页内地址（页内偏移）`。页大小为 4KB = $2^{12}$B，按字节编址，$\log_2 2^{12}=12$，所以虚拟地址的低 12 位为页内地址，虚拟地址的高 $30-12=18$ 位为虚页号。

(2) 虚页号 = `TLB 标记 | TLB 组号`。TLB 共 8 组，所以虚页号的低 $\log_2 8=3$ 位为 TLB 组号，虚页号高 $18-3=15$ 位为 TLB 标记号。虚拟地址的高 15 位为 TLB 标记，虚拟地址中 TLB 标记的随后 3 位是 TLB 组号。

(3) ① 参照 Cache 组相联映射中 Cache 组号和主存块号之间的映射关系，TLB 中组号与虚页号之间的关系为 TLB 组号 = 虚页号 % TLB 组数。虚页号 10 映射到的 TLB 组号为 10%8 = 2，依此计算，10, 12, 16, 7, 26, 4, 12, 20 映射到的 TLB 组号分别为 2, 4, 0, 7, 2, 4, 4, 4。因为 TLB 为 2 路组相联（一组存放 2 个表项），第 4 组出现的频率大于 2 次，所以只有第 4 组可能存在替换现象。② 访问的虚页号 12, 4, 12, 20 映射到第 4 组。TLB 初始为空，访问虚页号 12, 4 时将对应的表项调入第 4 组，再次访问虚页号 12 时命中。访问虚页号 12 之后，紧接着访问虚页号 20，此时 TLB 第 4 组表项对应的虚页号分别为 12, 4（已被填满）。TLB 采用 LRU（最近最少使用）替换策略，由于 12 刚被访问过，所以虚页号 4 对应的 TLB 表项被替换。

**【提示】** 求解虚页号映射到的 TLB 组号还有一种方法：将题目给出的十进制虚页号转化为二进制，例如：虚页号 10 对应的二进制为 10 = 00 0000 0000 0000 1010B，虚页号的低 3 位为 TLB 组号，则虚页号 10 映射到的 TLB 组号为 010B = 2。这种计算方式比较麻烦费时间，但可能更容易想到。

(4) 虚拟地址由虚页号和页内地址组成，虚拟地址的位数增加而其他参数不变的情况下，只会引发虚页号增加，TLB 表项对应标记 Tag 和物理页号。当虚拟地址增加到 32 位时，每个 TLB 块的 TLB 标记位增加 $32-30=2$ 位，表项位数增加 2 位。

**【点评】** 常规题。第二问的设置欠妥当，居然同一个问题考 2 遍。TLB 采用二路组相联，其解法参照 Cache 组相联方式求解。这个点如果第一次遇到，可能无从下手，但在经典教材中一般都有讲解这种方式，也有类似的练习题。

</Solution>

<Question id="408-2be72e-049" type="essay" tags="来源:2023考研408">

(14 分) 已知计算机M 字长为32 位, 按字节编址, 采用请求调页策略的虚拟存储管理方式,虚拟地址为32 位,页大小为4KB; 数据Cache 采用4 路组相联映射方式,数据区大小为8KB,主存块大小为32B。现有C 语言程序段如下:

```c
int a[24][64];
......
for (i = 0; i < 24; i++)
    for (j = 0; j < 64; j++)
        a[i][j] = 10;
```

已知二维数组a 按行优先存放, 在虚拟地址空间中分配的起始地址为00422000H, sizeof (int) = 4,假定在M 上执行上述程序段之前数组a 不在内存, 且在该程序段执行过程中不会发生页面置换。请回答下列问题:
   (1) 数组a 分布在几个页面中？对于数组a 的访问, 会发生几次缺页异常？页故障地址各是什么？
   (2) 不考虑对变量i 和j, 该程序段的数据访问是否具有时间局部性？为什么？
   (3) 计算机M 的虚拟地址(A31~A0) 中哪几位用作块内地址？哪几位用作Cache 组号? 数组元素a[1][0] 的虚拟地址是多少? 其所在主存块对应的Cache 组号是多少?
   (4) 数组a 总共占多少主存块? 假设上述程序段执行过程中数组a 的访问不会和其他数据发生Cache 访问冲突, 则数组a 的Cache 命中率是多少? 若将循环中i 和j 的次序按如下方式调换,则数组a 的 Cache 命中率又是多少?

```c
for (j = 0; j < 64; j++)
    for (i = 0; i < 24; i++)
        a[i][j] = 10;
```

<Solution>

**【解析】**

（1）① 数组 a 的大小为 24 行 × 64 列，按字节编址，每个元素的大小为 4B（sizeof(int) = 4），则数组 a 所需的存储空间为：$24\times64\times4\mathrm{B}=6\mathrm{KB}$。页面大小为 4KB，故数组 a 需要占用 $6\mathrm{KB}/4\mathrm{KB}=1.5$ 个页面。由于页面是最小单位，因此数组 a 需要占用 2 个页面。② 在访问数组 a 的过程中，每访问一个页面，都需要将该页面加载到内存中，数组 a 占用 2 个页面，所以会出现 2 次缺页。③ 一页可以存放 $4\mathrm{KB}\div4\mathrm{B}=1024$ 个数组元素。第一次缺页发生在访问第一个数组元素（即：a[0][0]）时，第二次缺页发生在访问第二页的第一个元素（即第 1025 个元素）时。第一个元素的虚拟地址 0042 2000H，第 1025 个元素的地址为 0042 2000H + 1024 × 4 = 0042 2000H + 1000H = 0042 3000H。页故障的地址分别为 0042 2000H 和 0042 3000H。

（2）时间局部性是指在一段时间内，如果某个数据被访问，那么在不久的将来该数据很可能再次被访问。因为本题中对数组 a 的每个元素只访问一次，所以没有时间局部性。

**【提示】** 空间局部性指若一个存储位置被访问，则程序在不久的将来可能访问其附近的存储位置。本题对数组 a 的访问体现了空间局部性。访问数组元素 a[0][0] 时，会将 a[0][1]、a[0][2]、a[0][3]、… 等接下来要访问的元素调入内存。

（3）内存块大小为 32B，所以块内地址为 5 位。Cache 数据区一共有 $8\mathrm{KB}/32\mathrm{B}=2^8$ 块，采用 4 路组相联，每 4 块为一组，所以共有 $2^8/2^2=2^6$ 组，所以组号需要 6 位，剩下的 21 位为 Tag 位。所以块内的地址为 A4～A0，Cache 的组号为 A10～A5，a[1][0] 的虚拟地址为 00422000H + 64 × 4 = 00422000H + 100H = 00422100H。对应 Cache 的组号为 001000B = 8。

（4）数组 a 共占 $(24\times64\times4\mathrm{B})/32\mathrm{B}=192$ 块，因为一个内存块为 32B，每个 int 类型占 4B，所以一个内存块包含 8 个 int，则每次访问该内存块的第一个元素会不命中，访问剩下的 7 个元素都会命中，所以命中率为 $7/8=87.5\%$。因为 Cache 的总块数大于 192 块，不管是按照行访问还是按照列访问，都是每次访问内存块的第一个元素不命中，命中率都为 87.5%。

**【点评】** 常规题。本题是偏简单的常规题，题目考法及考查的知识点都是常见的，在往年的 408 考试中都考过类似的。考生至少应该在本题上拿到大部分分数。

</Solution>
