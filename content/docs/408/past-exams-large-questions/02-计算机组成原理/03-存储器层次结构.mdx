## 2010 年第 44 题

<ExamQuestion>

**40. 2010 年第 44 题**

某计算机的主存地址空间大小为 $256\text{ MB}$，按字节编址。指令 Cache 和数据 Cache 分离，均有 $8$ 个 Cache 行，每个 Cache 行大小为 $64\text{ B}$，数据 Cache 采用直接映射方式。

现有两个功能相同的程序：

```c
// 程序 A
int a[256][256];
...
int sum_array1() {
    int i, j, sum = 0;
    for (i = 0; i < 256; i++)
        for (j = 0; j < 256; j++)
            sum += a[i][j];
    return sum;
}
```

```c
// 程序 B
int a[256][256];
...
int sum_array2() {
    int i, j, sum = 0;
    for (j = 0; j < 256; j++)
        for (i = 0; i < 256; i++)
            sum += a[i][j];
    return sum;
}
```

假定 `int` 用 $32$ 位补码表示，编译时 `i`、`j`、`sum` 均分配在寄存器中，数组 `a` 按行优先存放，首地址为十进制 $320$。

请回答：

1. 若不考虑用于 Cache 一致性维护和替换算法的控制位，数据 Cache 的总容量是多少？
2. 数组元素 `a[0][31]` 和 `a[1][1]` 各自所在主存块对应的 Cache 行号分别是多少？Cache 行号从 $0$ 开始。
3. 程序 A 和程序 B 的数据访问命中率各是多少？哪个程序执行时间更短？

<ExamSolution>

<ExamAnswer>

1. 数据 Cache 含数据位、标记位和有效位的总容量为 $532\mathrm B$（其中纯数据区为 $512\mathrm B$）。
2. `a[0][31]` 映射到第 $6$ 行；`a[1][1]` 映射到第 $5$ 行。
3. 程序 A 的 Cache 命中率为 $93.75\%$，程序 B 为 $0\%$。在其余条件相同且主存访问比 Cache 访问慢时，A 通常执行更快。

</ExamAnswer>

<ExamExplanation>

### 一、从地址位数画出直接映射 Cache

按字节编址、主存 $256\mathrm{MB}=2^{28}\mathrm B$，所以物理地址共 **28 位**。数据 Cache 共 8 行（$2^3$），每行 64B（$2^6$）。地址从高位至低位分为：

$$
\underbrace{\mathrm{Tag}}_{19\ \text{位}}\mid
\underbrace{\mathrm{Index}}_{3\ \text{位}}\mid
\underbrace{\mathrm{Offset}}_{6\ \text{位}},\qquad
19+3+6=28.
$$

**容量题不能把“数据区容量”与“总容量”混淆**：数据区 $8\times64=512\mathrm B$；每行存放 19 位 Tag 和 1 位有效位，共 $8\times(19+1)=160$ 位，即 20B；总容量 $512+20=\boxed{532\mathrm B}$。题设只忽略一致性/替换控制位，不等于可以忽略有效位。若题目另外要求脏位，则须根据写策略增计，本题未要求。

<img src="/img/408/past-exams-large-questions/02-计算机组成原理/assets/2010-44-figure-001.svg" alt="直接映射 Cache 行的有效位、标记与数据区" />

### 二、通用三步定位法：元素地址 → 主存块号 → Cache 行号

二维 C 数组按**行优先**存储，元素占 4B，首地址 $A_0=320$。其地址公式为

$$
\operatorname{addr}(a[i][j])=320+4(256i+j).
$$

如果主存块大小 $B=64$ 字节，直接映射行数 $L=8$，那么

$$
\operatorname{block}(x)=\left\lfloor\frac{x}{64}\right\rfloor,
\qquad \operatorname{line}(x)=\operatorname{block}(x)\bmod8,
\qquad \operatorname{tag}(x)=\left\lfloor\frac{\operatorname{block}(x)}8\right\rfloor.
$$

| 数组元素 | 字节地址 | 主存块号 | 行号 | Tag |
| --- | ---: | ---: | ---: | ---: |
| `a[0][31]` | $320+4\times31=444$ | $\lfloor444/64\rfloor=6$ | $6$ | $0$ |
| `a[1][1]` | $320+4\times257=1348$ | $\lfloor1348/64\rfloor=21$ | $21\bmod8=5$ | $2$ |

**注意**：行号不是数组行号；Tag 不参与决定 Cache 行索引，但决定该行中的数据是否来自所求主存块。

<img src="/img/408/past-exams-large-questions/02-计算机组成原理/assets/2010-44-figure-002.svg" alt="数组行优先存储与主存块的映射" />

### 三、程序 A：一块 16 个元素，1 次缺失 + 15 次命中

每个 Cache 块容纳 $64/4=16$ 个 `int`。数组的首地址 320 恰为 64 的整数倍，整张数组连续分布，因此每读到一个新块的第一个元素产生 1 次**强制性缺失**，后续连续 15 次访问都命中。全数组访问 $N=256^2=65536$ 次；共有 $65536/16=4096$ 个主存块。

$$
\text{Miss}_A=4096,\quad
\text{Hit}_A=65536-4096=61440,\quad
H_A=\frac{61440}{65536}=\boxed{93.75\%}.
$$

**易混点**：即便 4096 个主存块大于 Cache 的 8 行，按行单次顺序扫描仍有空间局部性；8 行装不下整个数组并不意味着每个访问都缺失。

### 四、程序 B：跨行步长与冲突缺失

程序 B 内层改变 $i$，相邻元素地址相差一整行

$$
\Delta=256\times4=1024\mathrm B=16\text{ 个主存块}.
$$

两个连续被访问的主存块号相差 16，而 $16\bmod8=0$，因此它们**映射到同一个 Cache 行**，但标记不同。访问另一行时前一块被替换；下一轮外层循环再访问上一列的相邻元素时，缓存中已无该块。

所以每次数组读取都发生直接映射冲突缺失：

$$
\text{Miss}_B=65536,\quad H_B=\boxed{0\%}.
$$

可手写前四步核对：`a[0][0]` 在块 5、行 5；`a[1][0]` 在块 21、行 5；`a[2][0]` 在块 37、行 5；`a[3][0]` 在块 53、行 5，持续反复替换。

### 五、遇到变式先检查这些前提

1. **编址与元素宽度**：按字节编址时先化成字节地址，再做模运算。若有多级数组指针而非连续二维数组，不能直接套行优先公式。
2. **初始位置对齐**：本题 $320\bmod64=0$，否则“每块正好 16 个连续元素”在数组首尾处要单独处理。
3. **Cache 映射与容量**：直接映射是块号对 Cache **行数**取模；组相联是对**组数**取模，不是对总行数。
4. **命中率的分母**：本题只计数据数组的读访问，`i,j,sum` 都在寄存器；不要混入取指 Cache 次数。
5. **运行时间比较**：结论是相同机器模型下 A 的数据 Cache 性能更好；绝对时间还取决于失效代价、流水线等，不能仅用命中率凭空算时钟周期。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

<span className="inline-block rounded border px-2 py-0.5 text-xs text-fd-muted-foreground">原创</span>

二维数组 `int a[4][64]` 按行优先连续存放，数组首地址是 64B 对齐的，`int` 为 4B。先按列遍历：外层 $j=0,\ldots,63$，内层 $i=0,\ldots,3$，每个元素恰好读取一次。Cache 总数据区 512B，主存块为 64B，起初为空，不计指令和其他数据访问。

1. 采用 8 行**直接映射**，求数组访问的 Cache 命中率，并说明连续两行发生的映射。
2. 保持总数据区、块大小不变，改为 **4 路组相联**（共 2 组、每组 4 行），采用 LRU，求命中率。
3. 若将遍历顺序改为按行，以上两种 Cache 的命中率如何变化？总结从时间、空间局部性与冲突角度解释结果。

<ExamSolution>

<ExamAnswer>

直接映射下全部 $256$ 次访问均未命中，命中率 **0%**。4 路组相联下每个主存块首次读取时缺失，共 $4\times4=16$ 次缺失，命中率 $240/256=\boxed{93.75\%}$。如果改为按行遍历，两种组织均为 $93.75\%$。

</ExamAnswer>

<ExamExplanation>

每行 64 个整数，占 $64\times4=256\mathrm B$，即 4 个连续的主存块。对于相同的列 $j$，相邻两数组行的地址步长 256B，即相差 $256/64=4$ 个主存块。

**直接映射**：将各行当前主存块号相对于数组首块写为 $4i+\lfloor j/16\rfloor$；行索引为该块号模 8。固定 $j$ 时，四行的 Cache 行号依次是 $q,q+4,q,q+4$（模 8）。后两次访问驱逐前两次访问的块；下一个列 $j+1$ 仍重复该模式，导致当前同一 16 列区域内每次都冲突未命中，总共 256 次 miss。

**4 路组相联**：共 $512/(4\times64)=2$ 组。四行的块号 $q,4+q,8+q,12+q$ 都具有相同组号 $q\bmod2$，但一个组刚好有 4 路，可以同时保留这四个块；每 16 列换一轮新的四块时发生 4 次强制/容量替换缺失，其余 $4\times(16-1)=60$ 次命中。四轮总 miss 为 $4\times4=16$。

按行遍历时，内层连续读一个块内的 16 个整数，Cache 行或组内冲突在**当前块被用完以后**才发生，故两种设计都具有每块 1 miss、15 hit 的命中率。这就是“局部性 + 映射冲突”两步检查法：先算**块包含多少元素**，再算**重复使用之前是否已经被驱逐**。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

## 2011 年第 44 题

<ExamQuestion>

**42. 2011 年第 44 题**

某计算机存储器按字节编址，虚拟（逻辑）地址空间大小为 16MB，主存（物理）地址空间大小为 1MB，页面大小为 4KB。Cache 采用直接映射方式，共 8 行；主存与 Cache 之间交换的块大小为 32B。

系统运行到某一时刻时，页表和 Cache 的部分内容如下图所示，其中页框号和标记字段均采用十六进制表示。

<img src="/img/408/past-exams-large-questions/02-计算机组成原理/assets/2011-44-figure-001.svg" alt="2011 年第 44 题页表与 Cache 内容" />

请回答：

1. 虚拟地址共有多少位？哪几位是虚页号？物理地址共有多少位？哪几位是页框号（物理页号）？
2. 使用物理地址访问 Cache 时，物理地址应划分成哪些字段？分别有多少位、位于什么位置？
3. 虚拟地址 `001C60H` 所在页面是否在主存中？若在，则对应物理地址是什么？访问该物理地址时 Cache 是否命中？说明理由。
4. 假定配置一个 4 路组相联 TLB，共可存放 8 个页表项，其当前内容如下图。此时虚拟地址 `024BACH` 所在页面是否在主存中？说明理由。

<img src="/img/408/past-exams-large-questions/02-计算机组成原理/assets/2011-44-figure-002.svg" alt="2011 年第 44 题 TLB 内容" />

<ExamSolution>

<ExamAnswer>

1. 虚拟地址长 24 位，高 12 位为 VPN；物理地址长 20 位，高 8 位为 PFN（页框号），两者低 12 位均为页内偏移。
2. Cache 的物理地址分成 `Tag[19:8] (12 位) | 行号[7:5] (3 位) | 块内偏移[4:0] (5 位)`。
3. `001C60H` 所属虚页在内存，转换为 `04C60H`；物理 Cache 第 3 行的有效 Tag 与所求不匹配，因此**未命中**。
4. `024BACH` 查 TLB 第 0 组时 Tag=`012H` 命中、页框号 `1FH`，所以该页在主存中；由该项可知对应物理地址为 `1FBACH`。

</ExamAnswer>

<ExamExplanation>

### 一、先弄清页面与 Cache 块的嵌套关系

本题有**两层不同粒度的地址转换**：虚页（4KB）由页表/TLB 映射到物理页框；物理主存块（32B）由 Cache 行号和标记定位。Cache 不是页表，TLB 也不是 Cache 的数据备份。

$$
16\mathrm{MB}=2^{24}\mathrm B,\quad
1\mathrm{MB}=2^{20}\mathrm B,\quad
4\mathrm{KB}=2^{12}\mathrm B.
$$

由此得虚拟地址 `VPN[23:12] | 页内偏移[11:0]`；物理地址 `PFN[19:12] | 页内偏移[11:0]`。**地址转换不改变页内偏移的 12 位**，只替换高位的页号。页框号有 $20-12=8$ 位，并非 $20$ 位。

直接映射 Cache 的 8 行、32B 块分别需要 3 位行号、5 位块内偏移，所以物理地址划分为

$$
\underbrace{\mathrm{Tag}}_{20-3-5=12\text{ 位}}\mid
\underbrace{\mathrm{行号}}_{3\text{ 位}}\mid
\underbrace{\mathrm{偏移}}_{5\text{ 位}}.
$$

**速算口诀**：先确定编址单位；偏移取块/页大小的 $\log_2$；索引取行数或组数的 $\log_2$；最后从总地址位数中相减得到 Tag。

### 二、`001C60H`：页表检查在前，Cache Tag 比较在后

虚页号 $\operatorname{VPN}=\texttt{001H}$，页内偏移 $\texttt{C60H}$。查题图页表，VPN 001 对应页表项有效，PFN 为 `04H`，故物理地址

$$
(\texttt{04H}\ll12)\,|\,\texttt{C60H}=\boxed{\texttt{04C60H}}.
$$

将物理地址 `04C60H` 按 `12 | 3 | 5` 划分：

$$
\mathrm{Tag}=\texttt{04CH},\qquad
\mathrm{Index}=\left\lfloor\frac{\texttt{04C60H}}{32}\right\rfloor\bmod8=3,\qquad
\mathrm{Offset}=0.
$$

题图中 Cache 第 3 行有效，但 Tag 为 `105H`，与所求 `04CH` 不同，判为 Cache 缺失。**行号相同不代表命中**，还必须有效位为 1 且标记相等。

<img src="/img/408/past-exams-large-questions/02-计算机组成原理/assets/2011-44-figure-001.svg" alt="2011 真题页表和 Cache 当前有效位与标记" />

### 三、`024BACH`：TLB 组号由 VPN 而非整个虚拟地址取模

TLB 有 8 项、4 路组相联：组数 $8/4=2$，组索引占 1 位。虚拟地址 `024BACH` 的 VPN=`024H`，故

$$
\mathrm{TLB\ group}=\texttt{024H}\bmod2=0,\qquad
\mathrm{TLB\ Tag}=\left\lfloor\frac{\texttt{024H}}2\right\rfloor=\texttt{012H}.
$$

由题图第 0 组可见有效项 Tag=`012H`、PFN=`1FH`，因此 **TLB 命中**，意味着该转换对应主存驻留页面。若继续计算，物理地址为 `1F000H + BACH = 1FBACH`；原问只需判断驻留即可。

<img src="/img/408/past-exams-large-questions/02-计算机组成原理/assets/2011-44-figure-002.svg" alt="2011 真题 TLB 的组相联项和标记" />

### 四、形成统一访存决策树

- **TLB 命中**：取出 PFN，形成物理地址，再访问物理 Cache；TLB 命中并不保证 Cache 命中。
- **TLB 缺失**：访问页表，若页表项有效则补入 TLB；这属于 TLB miss，但**不是缺页异常**。
- **页表项无效/不驻留**：进入缺页处理，由 OS 调页，更新页表并按需更新 TLB，再重试指令。
- **物理 Cache 缺失**：在所需物理页面驻留的情况下，从主存装入 Cache 块，必要时替换旧块。

易错点：把 `024BACH` 当作 6 位十六进制时，VPN 取**高 3 个十六进制位**，不是取高 4 位；多路 TLB 的组数是“总项数 ÷ 路数”；不同表的 Tag 位数互不通用；页内偏移不能当作 Cache 块内偏移（12 位与 5 位）。

</ExamExplanation>

</ExamSolution>

<ExamQuestion>

<span className="inline-block rounded border px-2 py-0.5 text-xs text-fd-muted-foreground">原创</span>

某机器按字节编址，虚拟地址 32 位、物理地址 24 位、页大小 4KB。TLB 为 16 项、4 路组相联，使用 VPN 的低位选择组，TLB 项有效；数据 Cache 为**物理地址寻址**的 16KB、2 路组相联，块大小 64B。

给定虚拟地址 `12345678H`，查询 TLB 可得到虚页号 `12345H` 映射到物理页框号 `ABCH`。求：

1. VPN、PFN、页内偏移的位数；TLB 组号和 Tag；
2. 最终物理地址；物理 Cache 的组数、组索引位数、Tag 位数；
3. 本次访问的 Cache 块内偏移、组号、Tag；
4. 能否在 **不查 TLB** 时，只凭页内偏移确定 Cache 组号？给出理由，并说明若同等容量 Cache 改成 4 路组相联，情况是否改变。

<ExamSolution>

<ExamAnswer>

VPN 为 20 位、PFN 为 12 位、页内偏移 12 位；TLB 共 4 组，查第 $1$ 组，TLB Tag=`48D1H`。物理地址为 `ABC678H`；2 路 Cache 共 128 组，7 位组号、11 位 Tag；块内偏移 `38H`，组号为 **25**，Tag=`55EH`。**不能**仅靠页内偏移确定该 2 路 Cache 的全部组号；改为 4 路时共有 64 组，组号 6 位，全部位于页内偏移中，故可以确定。

</ExamAnswer>

<ExamExplanation>

页内偏移位数 $\log_2(4096)=12$，VPN $32-12=20$ 位，PFN $24-12=12$ 位。地址 `12345678H` 按 3 个十六进制位切分为 `12345H | 678H`；TLB 的 $16/4=4$ 组需要 2 个索引位，故组号 $\texttt{12345H}\bmod4=1$，TLB Tag=$\texttt{12345H}\gg2=\texttt{48D1H}$。

PFN 与偏移直接拼接为 `ABC678H`。Cache 共 $16\mathrm{KB}/(2\times64\mathrm B)=128$ 组，故 7 个组索引位、6 个块内偏移位、$24-7-6=11$ 个 Tag 位。进一步计算得

$$
\mathrm{Offset}=\texttt{ABC678H}\bmod64=\texttt{38H},\quad
\mathrm{Group}=\left\lfloor\frac{\texttt{ABC678H}}{64}\right\rfloor\bmod128=25,\quad
\mathrm{Tag}=\left\lfloor\frac{\texttt{ABC678H}}{8192}\right\rfloor=\texttt{55EH}.
$$

由于组号占物理地址位 $[12:6]$，其中第 12 位已经超出 12 位页内偏移 $[11:0]$，必须知道物理页框的最低位；**仅凭虚拟页内偏移不能推出全部 7 位组号**。若改为 4 路，总组数为 64，组号用 $[11:6]$ 六个位，全部在页内偏移内，可不依赖 PFN 得到组号（但是否命中还需要物理 Tag 与有效位）。

> 校验笔记：Cache 组数增加则索引位增加，Tag 位减少；总 Cache 容量一定时，关联度从 2 路提高为 4 路，组数减半，索引位减少 1 位，Tag 位增加 1 位。本题的 2 路 Cache Tag 是 11 位；4 路 Cache Tag 则是 12 位。

</ExamExplanation>

</ExamSolution>

## 2012 年第 43 题

<ExamQuestion>

**43. 2012 年第 43 题**

假定某计算机的 CPU 主频为 80MHz，CPI 为 4，平均每条指令访存 1.5 次，主存与 Cache 之间交换的块大小为 16B，Cache 命中率为 99%，存储器总线宽度为 32 位。请回答：

1. 该计算机的 MIPS 数是多少？平均每秒 Cache 缺失多少次？不考虑 DMA 传送时，主存带宽至少达到多少才能满足 CPU 的访存要求？
2. 假定 Cache 缺失后访问主存时存在 0.0005% 的缺页率，则 CPU 平均每秒产生多少次缺页异常？若页面大小为 4KB，每次缺页均需访问磁盘，DMA 采用周期挪用方式，磁盘 I/O 接口的数据缓冲寄存器为 32 位，则磁盘 I/O 接口平均每秒至少发出多少次 DMA 请求？
3. CPU 和 DMA 控制器同时请求使用存储器总线时，谁的优先级更高？为什么？
4. 主存采用四体低位交叉存储，每 $1/4$ 个存储周期启动一个存储体。若每个存储体的存储周期为 50ns，则主存能提供的最大带宽是多少？

<ExamSolution>

<ExamAnswer>

1. $20\mathrm{MIPS}$；每秒 Cache 缺失 $3\times10^5$ 次；忽略 DMA 时主存最低平均数据吞吐率 $4.8\mathrm{MB/s}$。
2. 每秒平均缺页 $1.5$ 次；按每次 DMA 请求传 32 位计算，DMA 请求速率至少 $1536$ 次/s。
3. 一般由 DMA 请求优先占用存储器总线，避免 I/O 缓冲区积压或丢数据。
4. 若每体每次传 32 位，四体低位交叉连续访问峰值带宽 $320\mathrm{MB/s}$。

</ExamAnswer>

<ExamExplanation>

### 一、先画数量关系链，别把 MIPS 与 MHz 混用

时钟频率 $f=80\mathrm{MHz}$，$\mathrm{CPI}=4$，则理想指令吞吐率

$$
I=\frac{80\times10^6\ \mathrm{cycle/s}}{4\ \mathrm{cycle/instruction}}
=20\times10^6\ \mathrm{instruction/s}=\boxed{20\mathrm{MIPS}}.
$$

平均每条指令访存 $1.5$ 次（按题设将所计访存统一用于缺失率），每秒访存次数

$$
A=I\times1.5=3\times10^7\ \mathrm{access/s}.
$$

缺失率为 $1-0.99=0.01$，每秒缺失

$$
M=A\times0.01=\boxed{3\times10^5\ \mathrm{miss/s}}.
$$

每次未命中从主存读 16B 块，不计写回、预取和 DMA 的额外流量，故最低**平均带宽**

$$
B_{\min}=M\times16\mathrm B=4.8\times10^6\mathrm{B/s}
=\boxed{4.8\mathrm{MB/s}}.
$$

其中 $\mathrm{MB}=10^6\mathrm B$；若答 $\mathrm{MiB/s}$，须按 $2^{20}$ 换算。*平均带宽*可低于瞬时突发带宽，不能把它视为内存固定的峰值能力。

### 二、条件概率与 DMA：写清“0.0005%”的基数

题述缺页率是**已经发生 Cache 缺失后，访问主存时**的条件缺页概率，数值为

$$
0.0005\%=\frac{0.0005}{100}=5\times10^{-6}.
$$

因此每秒平均缺页次数

$$
F=M\times5\times10^{-6}=\boxed{1.5\ \mathrm{fault/s}}.
$$

题目假定一次缺页需由磁盘向主存调入 $4\mathrm{KB}=4096\mathrm B$；DMA 数据寄存器 32 位=4B。一次页面传送包含

$$
N_{\mathrm{DMA/page}}=\frac{4096}{4}=1024
$$

次 32 位传送（此处每次传送与一次请求对应）。每秒至少请求 $1.5\times1024=\boxed{1536\ \mathrm{requests/s}}$。不要将 $4\mathrm{KB}$ 直接除以“总线有 32 位”后忘记乘缺页次数。

严格说，$1.5$ 次/s 是**长期平均**，不代表某 1 秒恰好产生非整数次中断；实际磁盘可能有额外寻道、扇区、页表与设备元数据流量，本题均按简化模型计算。

### 三、DMA 抢总线与四体交叉主存的边界

**DMA 周期挪用**是 DMA 在需要传送一字/一拍时申请并占用存储器总线，CPU 的对应总线周期暂时让出；通常 DMA 优先级更高，因为外设缓冲区不能无限等待。DMA 并非永远优先于所有 CPU 操作，具体仲裁机制以系统规定为准。

四体低位交叉存储采用地址低位选体，使连续**字**分布于不同存储体。每体周期 $T=50\mathrm{ns}$，四体可在理想稳态下每 $T/4=12.5\mathrm{ns}$ 启动一次存储体；每个存储字按 32 位即 4B：

$$
B_{\max}=\frac{4\mathrm B}{12.5\mathrm{ns}}
=\boxed{320\mathrm{MB/s}}.
$$

这个 $320\mathrm{MB/s}$ 是给定存储体与访问排程下的**理想峰值**。不包含总线/控制器瓶颈，因而不应与刚求出的 $4.8\mathrm{MB/s}$ 平均需求作同一概念的替换。

### 四、考场速用公式与易错清单

$$
\begin{aligned}
\text{指令/s}&=\frac f{\mathrm{CPI}},\\
\text{Cache misses/s}&=\frac f{\mathrm{CPI}}\cdot a\cdot (1-h),\\
\text{内存需求 B/s}&=\text{misses/s}\cdot \text{块字节数},\\
\text{DMA 请求/s}&=\text{faults/s}\cdot\frac{\text{页字节数}}{\text{每次 DMA 字节数}}.
\end{aligned}
$$

提醒：百分号先换小数；页大小和块大小是不同层次；位与字节相差 8 倍；把**平均**指标与**峰值**指标分开；如果 CPI 本身已含 Cache 等待惩罚，重新添加缺失时间会重复计算。本题遵循给定的 CPI/访存率简化模型。

</ExamExplanation>

**45. 2013 年第 43 题**

某 32 位计算机的 CPU 主频为 800MHz，Cache 命中时 CPI 为 4，Cache 块大小为 32B。主存采用 8 体交叉存储，每个存储体字长为 32 位、存储周期为 40ns。存储器总线宽度为 32 位，总线时钟频率为 200MHz，支持突发传送。

每次读突发总线事务包括：发送首地址和命令、存储器准备数据、传送数据。发送一个地址或一个 32 位数据均需 1 个总线时钟周期；每次突发传送 32B。请回答：

1. CPU 时钟周期和总线时钟周期各是多少？总线最大数据传输率是多少？
2. Cache 缺失时，需要多少个读突发传送事务才能读入一个主存块？
3. 完成一次读突发传送总线事务需要多长时间？
4. 若程序 BP 共执行 100 条指令，平均每条指令访存 1.2 次，Cache 缺失率为 5%，不考虑替换等其他开销，则 BP 的 CPU 执行时间是多少？

<ExamSolution>

<ExamAnswer>

1. CPU 周期 $1.25\mathrm{ns}$，总线周期 $5\mathrm{ns}$，理论总线最大传输率 $800\mathrm{MB/s}$。
2. 一次未命中只需 **1 个**读突发事务。
3. 一次突发读事务耗时 $85\mathrm{ns}$。
4. 程序 BP 的预计执行时间为 $1010\mathrm{ns}$（$500\mathrm{ns}$ 基础执行 + $510\mathrm{ns}$ 缺失延迟）。

</ExamAnswer>

<ExamExplanation>

### 一、分开计算三个“频率/时间”：CPU、总线、存储体

- CPU 主频 $800\mathrm{MHz}$，$T_{\mathrm{CPU}}=1/(800\times10^6)=1.25\mathrm{ns}$。
- 总线频率 $200\mathrm{MHz}$，$T_{\mathrm{bus}}=5\mathrm{ns}$；总线宽 32 位=4B/拍。
- 存储体周期为 $40\mathrm{ns}$；8 体交叉访问可每 $40/8=5\mathrm{ns}$ 启动新存储体。

因此存储体理想出字间隔与总线传数间隔都是 5ns，二者匹配；总线最大数据率

$$
B=\frac{4\mathrm B}{5\mathrm{ns}}=\boxed{800\mathrm{MB/s}}.
$$

**注意**：存储周期 40ns 不等于每个总线数据拍耗时 40ns。多体交叉通过流水式启动不同存储体，把首字延迟和后续连续出字吞吐率分离。

### 二、一次 Cache 缺失的突发事务时间线

Cache 块 32B，每次读突发恰好 32B，所以需要 $32/32=\boxed{1}$ 个事务；32 位总线共需 $32/4=8$ 个数据拍。

| 阶段 | 计算 | 时长 |
| --- | --- | ---: |
| 发送首地址与命令 | $1\times5\mathrm{ns}$ | $5\mathrm{ns}$ |
| 主存准备第一份数据 | 题给存储体访问周期 | $40\mathrm{ns}$ |
| 8 拍数据突发传输 | $8\times5\mathrm{ns}$ | $40\mathrm{ns}$ |
| **合计** | $5+40+40$ | **$85\mathrm{ns}$** |

这类题的得分点是按题目给定的突发事务模型**把首字等待和数据传送分开记**；既不能把 8 个字都记成各需 40ns，也不能忽略首地址和命令的一个总线周期。若题目明确首字准备与总线阶段可重叠，时间线才应另行改写；本题按先后顺序求和。

### 三、CPI 模型下的缺失惩罚

100 条指令在 Cache 全命中时 $\mathrm{CPI}=4$，基本执行时间

$$
T_0=100\times4\times1.25\mathrm{ns}=500\mathrm{ns}.
$$

总访存次数 $100\times1.2=120$，命中率为 $95\%$，预计缺失 $120\times0.05=6$ 次；每次未命中访问主存需 85ns，附加等待

$$
T_{\mathrm{stall}}=6\times85=510\mathrm{ns}.
$$

总时间

$$
T=T_0+T_{\mathrm{stall}}=500+510=\boxed{1010\mathrm{ns}}.
$$

可进一步算**有效 CPI**作独立核验：$6\times85/1.25=408$ 个额外 CPU 周期，$\mathrm{CPI}_{\mathrm{eff}}=(400+408)/100=8.08$；再乘 $100\times1.25\mathrm{ns}$ 仍为 1010ns。

### 四、什么情况下不能照搬“缺失数 × 85ns”

1. **平均访存次数**含 1.2 这样的非整数，这是整体平均统计；单个指令可能取指和读/写数据多次。
2. **缺失罚时**是额外时间，本题已说明命中时 CPI 4；若题目给的是已经计入失效的实际 CPI，不能重复加。
3. **阻塞还是可重叠**：存在非阻塞 Cache、乱序执行、多笔未完成请求时，纯线性加法可能高估实际 stall；本题的简化模型默认串行处理每次缺失。
4. **有效带宽不等于理想带宽**：单次事务的 85ns 包含命令和首字延迟；$800\mathrm{MB/s}$ 只描述连续数据拍的峰值，不能用 $32\mathrm B/800\mathrm{MB/s}=40\mathrm{ns}$ 替代 85ns。

</ExamExplanation>

3. 指令 4（`add R1,R1,R5`）可能发生带符号溢出；指令 3（`load R5,0(R4)`）可能产生缺页。数组 A 至少磁盘读 **1 次**；数组读取引发的 TLB 查找至少 **1001 次**（按缺页后重新取址访问的题设模型）。

</ExamAnswer>

<ExamExplanation>

### 一、先补齐“承接上一题”的上下文，避免跨章断链

本题沿用 [2014 年第 44 题的 6 条循环指令](/docs/408/past-exams-large-questions/02-ec68095a/05-96cb0d51#question-2014-44) 与其寄存器约定：

```text
1 loop: sll  R4, R2, 2      // 计算下标偏移 4*i
2       add  R4, R4, R3     // 得到 A[i] 的地址
3       load R5, 0(R4)      // 读取 A[i]
4       add  R1, R1, R5     // sum += A[i]
5       add  R2, R2, 1      // i++
6       bne  R2, R6, loop   // 若 i != N，则继续
```

R1 存 `sum`，R2 存 `i`，R3 为数组首地址，R6 存 $N=1000$。初始 $R2=0$，每次循环执行指令 5 加一，然后指令 6 比较，当 $R2=1000$ 时退出，因此结束时 $\boxed{R2=1000}$。指令 6 也在第 1000 轮执行一次，但该次**不跳转**。

### 二、指令 Cache：算“容量”和“实际动态取指数”

Cache 有 16 行、每行 32B，则**数据区**为 $16\times32=512\mathrm B$。若问含 Tag/有效位的总容量，还需物理地址和映射信息，本题仅问数据区，不能把 512B 当成通用的总容量。

P 六条指令均为 32 位（4B），共 $6\times4=24\mathrm B$，从 `08048100H` 开始；该地址为 32B 对齐地址，24B 处于**同一指令 Cache 块**。初始该块不在 Cache，第一条取指缺失，调入整块后其他取指均命中。

程序循环 1000 轮，每轮执行 6 条指令，动态取指共 $6\times1000=6000$ 次，只有第一次失败一次，所以

$$
H_I=\frac{6000-1}{6000}=\boxed{\frac{5999}{6000}\approx99.98\%}.
$$

**题型陷阱**：不能用“6 条静态指令只有 1 次不命中，所以命中率 5/6”作答；命中率分母是**动态取指次数**，而不是源代码中机器指令个数。

### 三、异常判断：算术溢出 vs 缺页 vs Cache 未命中

- `add R1,R1,R5` 把元素加入 32 位累加器，**可能**发生有符号整数溢出；要明确机器模型中溢出是否定义为异常，考试按题给语义回答“指令 4 可能”。
- `load R5,0(R4)` 真正读取尚未驻留的数组 A，其首次加载可能触发**缺页异常**；指令 3 为答案。
- 指令 Cache 未命中通常由硬件/存储层次处理，不应直接和 CPU 执行的缺页异常混为一谈。

### 四、页、Cache 和 TLB：逐次访存计数

所有 1000 个数组元素位于同一虚页，且该页在开始时**未驻留主存**。因此首次取 `A[0]` 时发生缺页，把该页所需的磁盘内容读入后，假定不再被换出，后续 `A[1]`～`A[999]` 都在同一页，故至少 **1 次磁盘读**。题设所有元素又在同一扇区，是简化磁盘 I/O 下界的附加条件。

只数**读取 A 所需的 TLB 查找**：第一次数组读取发生缺页，先有一次转换尝试；缺页服务结束后重启该访存，再查一次 TLB，因而首次访问至少两次；余下 999 次各一次。

$$
N_{\mathrm{TLB,\ data}}=1+1+999=\boxed{1001}.
$$

这里**不包括 6000 次取指、操作系统缺页处理代码及页表访问自身可能引发的其他地址转换**；不同实现的缺页重启/TLB 填入顺序可能出现比该理论下界更多的查询。因此不要把“同一页只产生 1 次缺页”误读为“TLB 只访问 1 次”：TLB 每次转换都可能查询，是否命中是另一回事。

### 五、答题与变式思维

1. 原卷上一题被按知识章移动了，所以先找程序的六指令表；本题已经在解析中恢复必需的程序段。
2. 动态指令数：循环次数 $\times$ 每轮条数；若有提前退出、分支延迟槽、流水线取指预取等，按题给指令模型单独分析。
3. 取指缺失（Cache）≠ TLB miss ≠ 缺页（内存页不驻留），这三个事件会叠加但含义不同。
4. 若数组跨 $k$ 个未驻留页面、没有中途换出，则至少缺页 $k$ 次；在每次缺页均造成访存指令重新查询 TLB 的模型下，$n$ 次数组访问需至少 $n+k$ 次对应 TLB 查询。

</ExamExplanation>

<ExamSolution>

<ExamAnswer>

总动态取指次数 $6\times1000=6000$，指令 Cache 缺失 1 次，命中率 $\boxed{5999/6000\approx99.9833\%}$；最少磁盘调入 2 页、数据 TLB 查询 $1000+2=\boxed{1002}$ 次。一般地，磁盘调页至少 $k$ 次、相同重试假设下数据 TLB 查询至少 $n+k$ 次。TLB 具体命中/未命中数量还取决于 TLB 容量、相联度、初始化状态、替换等。

<ExamExplanation>

### 1. 先锁定两种地址，再辨认图中字段

本题把**虚拟存储**与**Cache**叠在一张图中。高频错误是把 TLB 的 Tag、Cache 的 Tag 与物理页框号视为同一概念。虚拟地址 $32$ 位、物理地址 $24$ 位、页大小 $8\mathrm{KB}=2^{13}\mathrm B$，因此

$$
\begin{aligned}
\text{虚拟地址}&=\underbrace{\mathrm{VPN}}_{19\text{ 位}}\mid\underbrace{\mathrm{PageOffset}}_{13\text{ 位}},\\
\text{物理地址}&=\underbrace{\mathrm{PFN}}_{11\text{ 位}}\mid\underbrace{\mathrm{PageOffset}}_{13\text{ 位}}.
\end{aligned}
$$

图中的 A 为 VPN，B 为全相联 TLB 的 Tag（完整 VPN），C 为 PFN，D 为页内地址：$A=19,B=19,C=11,D=13$。**页内偏移在地址转换中不改变**；但 PFN 不等于 VPN，二者甚至位数不同。

数据 Cache 容量 $64\mathrm{KB}=2^{16}\mathrm B$，块 $64\mathrm B=2^6\mathrm B$，每组 2 路：

$$
\text{组数}=\frac{2^{16}}{2\times2^6}=2^9=512.
$$

物理地址拆分为 $\underbrace{\mathrm{Tag}}_{9\text{ 位}}\mid\underbrace{\mathrm{Group}}_{9\text{ 位}}\mid\underbrace{\mathrm{BlockOffset}}_{6\text{ 位}}$，故 $E=9,F=9,G=6$。**通用口诀**：$b=\log_2B$、$s=\log_2(C/(aB))$、$t=p-s-b$；其中 $B$ 是块字节数、$a$ 为相联路数、$C$ 是**数据区**容量、$p$ 为物理地址位数。

### 2. 从主存块号一次求出组号和 H

地址所在主存块号为 $N=4099$（已按 64B 块编号），所以**无需再除以 64**：

$$
4099=512\times8+3\quad\Rightarrow\quad
\mathrm{Group}=4099\bmod512=\boxed3,
\quad \mathrm{Tag}=\left\lfloor\frac{4099}{512}\right\rfloor=\boxed8.
$$

H 是 9 位 Cache 标记字段，须保留前导零，写作 $\boxed{000001000_2}$。也可反查：块首地址为 $4099\times64=262336=\texttt{400C0H}$；把其低 6 位舍去、再取 9 位组号，得到组 3、Tag 8。不同主存块**可能同组**，因而需要 Tag 区分并依靠有效位判定命中。

### 3. Cache miss、TLB miss、page fault 不是一回事

| 事件 | 主要检查对象 | 常见后续动作 | 是否必然访问外存 |
| --- | --- | --- | --- |
| TLB 未命中 | 快表缺少 VPN→PFN 映射 | 查页表、补 TLB；页不在主存时再缺页 | 否 |
| Cache 未命中 | 目标物理块未在对应组中 | 从下一层 Cache/主存取块 | 否 |
| 缺页 | 页表指示页面不驻留 | 陷入 OS，调页、可能置换并重启访存 | 可能需要慢速外存 |

通常缺页代价最高，既有异常处理又可能发生存储设备 I/O；但若题设采用内存型后备存储或给出具体延时，应服从其模型，不能把相对快慢当作普遍严格定理。

### 4. 为什么两级的写策略可以不同

**直写（Write Through）**：写 Cache 同时写主存，优点是下层数据新、简化脏块处理；缺点是写流量大，可用写缓冲优化。**回写（Write Back）**：先更新上层，仅标脏，替换脏块才写下层，节省写流量，但一致性维护更复杂。

内存页与磁盘/SSD 之间即使修改一个字节也可能牵涉远大于字节的 I/O，故通常采用回写；页表项的 dirty bit 记录其页面修改状态。不要把“**直写**”和“写缺失时**写分配/非写分配**”混为一谈：前者决定何时更新下层，后者决定写未命中时是否装入块，两者是不同维度。

### 5. 迁移技巧

若改为 **4 路组相联**而数据容量、块大小不变，则组数由 512 降为 256，$F=8$、$E=10$；对块 4099，组号变为 $4099\bmod256=3$，Tag 变为 $16$。一旦改变相联度，**组号和标记必须一起重算**。

<img src="/img/408/past-exams-large-questions/02-计算机组成原理/assets/2018-44-figure-001.svg" alt="2018 年第 44 题 TLB、页表和 2 路组相联 Cache 示意图" />

3. Cache 采用什么映射方式？若 Cache 采用 LRU 替换算法和回写（Write Back）策略，则每行中除 Data、Tag 和有效位外，还应有哪些附加位？Cache 总容量是多少？有效位有什么作用？
4. 若 CPU 给出的虚拟地址为 `0008C040H`，对应的物理地址是多少？是否在 Cache 中命中？说明理由。若虚拟地址为 `0007C260H`，则该地址所在主存块映射到的 Cache 组号是多少？

<ExamSolution>

<ExamAnswer>

1. 物理地址共 $28$ 位。
2. TLB 是**全相联**；通常使用 SRAM/CAM 风格高速相联硬件，不是普通 DRAM。
3. Cache 为 **2 路组相联**；回写需要**脏位**，替换需要**LRU 状态位**。按题图每行带 1 位 LRU 标志的口径，总容量为 $4464$ bit，即 $558\mathrm B$；有效位用来判断该行是否含有有效数据。若按两路 LRU **每组仅 1 位**的最小实现，容量为 $4456$ bit，即 $557\mathrm B$，属不同状态记账口径。
4. `0008C040H` 转换为 `0040040H`，Cache 第 2 组**未命中**；`0007C260H` 映射到 Cache 第 $3$ 组。

</ExamAnswer>

<ExamExplanation>

### 1. 三张表各自做什么

TLB 按**虚拟页号**查页框，页表判断**页是否驻留**，Cache 按**物理地址中的块号**查数据。题图页大小为 $4\mathrm{KB}=2^{12}\mathrm B$，页内偏移 12 位；物理页框号 16 位，所以物理地址为 $\boxed{16+12=28\text{ 位}}$。图中另一条验证路径是 Cache 地址的 Tag 20 位、组索引 3 位、块偏移 5 位，合计也为 28 位。

TLB 的各项被并行比较完整虚页标记，因此是全相联；其小容量高速表常采用相联比较电路（CAM 比较单元）和 SRAM 风格存储，**答题写 SRAM**，不应简单等同于主存的 DRAM。TLB 中的有效位只说明**转换项可用**，并不保证数据在 Cache 中。

### 2. 先求几组几路，再算总容量

从题图得 Cache 的**组索引 3 位**、**块内偏移 5 位**：

$$
S=2^3=8\text{ 组},\quad B=2^5=32\mathrm B,\quad a=2\text{ 路},\quad N=Sa=16\text{ 行}.
$$

总数据位 $16\times32\times8=4096$ bit；Tag 共 $16\times20=320$ bit；每行有效位 1、脏位 1，所以各 16 bit。若按题图将 LRU 也按**每行 1 位**编码，则

$$
T=4096+320+16_{\mathrm V}+16_{\mathrm D}+16_{\mathrm{LRU}}=\boxed{4464\text{ bit}=558\mathrm B}.
$$

**模型辨析**：对 2 路组相联而言，若用最精简的真 LRU，每组仅需 1 位来标识最近使用的路，则 LRU 合计 8 bit，得 $4456$ bit（557B）。考试给出按**每行**计状态的表格时，优先使用题图/参考答案对应口径；在工程方案中两种位数不要混算。

有效位 $V=0$ 时 Tag 即使碰巧相同也不能命中；脏位 $D=1$ 时替换该行应先写回下层；LRU 位标记哪个候选行最久未用。先查是否有无效行，通常**不必立即淘汰任何有效行**。

### 3. `0008C040H` 的完整访问路径

4KB 页大小，虚地址按 `VPN | offset` 拆分：

$$
\mathrm{VPN}=\texttt{0008CH},\quad \mathrm{PageOffset}=\texttt{040H}.
$$

由题图 TLB 有效映射，$\mathrm{VPN}=\texttt{0008CH}$ 对应 $\mathrm{PFN}=\texttt{0040H}$，所以物理地址是 $\boxed{\texttt{0040040H}}$。接着按 Cache 地址 `Tag[27:8] | Set[7:5] | Offset[4:0]` 拆解：

$$
\mathrm{Tag}=\texttt{00400H},\qquad
\mathrm{Set}=(\texttt{0040040H}\gg5)\bmod8=2,
\qquad \mathrm{Offset}=0.
$$

Cache 图中第 2 组一路 Tag=`00400H` 但有效位为 0，另一路虽有效但 Tag 不符，故本次**不命中**。遇到“同 Tag 却无效”，仍是 miss，必须把有效位作为命中的**必要条件**。

## 2019 年第 46 题

<ExamQuestion>

**58. 2019 年第 46 题**

承接上一题。若计算机 M 的主存地址为 32 位，采用分页存储管理，页大小为 $4\text{ KB}$：

1. 第 1 行 `push` 指令和第 30 行 `ret` 指令是否在同一页中？说明理由。
2. 若指令 Cache 有 64 行，采用 4 路组相联映射，主存块大小为 $64\text{ B}$，则 32 位主存地址中，哪些位表示块内地址、Cache 组号和 Tag？
3. 读取第 16 行 `call` 指令时，只可能在指令 Cache 的哪一组中命中？说明理由。

<ExamSolution>

<ExamAnswer>

1. **同一虚拟页**：`00401000H` 与 `0040104AH` 的虚页号均为 `00401H`。
2. $[5:0]$ 是块内偏移，$[9:6]$ 是 Cache 组号，$[31:10]$ 是物理地址 Tag（22 位）。
3. 第 16 行 `call` 地址 `00401025H` 的组号为 $0$，所以只可能命中指令 Cache 的**第 0 组**；仅凭地址无法判断这次实际是否命中。

</ExamAnswer>

<ExamExplanation>

### 1. 先定位跨章节引用的指令地址

本题“承接上一题”，引用的是 **2019 年第 45 题（指令系统章）**所给汇编清单。这里只需要其中的三个指令地址，不必重算完整程序：第 1 行 `push` 为 `00401000H`、第 16 行 `call` 为 `00401025H`、第 30 行 `ret` 为 `0040104AH`。可跳至 [指令系统章 2019 年第 45 题](/docs/408/past-exams-large-questions/02-ec68095a/04-418f1dfd#question-2019-45) 对照原程序。地址都是十六进制表示，不是十进制。

分页大小 $4\mathrm{KB}=2^{12}\mathrm B$，因此**同一页判据**为虚拟地址右移 12 位后的虚页号相等：

$$
\texttt{00401000H}\gg12=\texttt{00401H},\qquad
\texttt{0040104AH}\gg12=\texttt{00401H}.
$$

两条指令属于同一**虚拟**页。这里不必知道它们映射到哪个物理页框，不能把“在同一页”误当成“已在指令 Cache”。

### 2. Cache 组数是总行数除以路数

Cache 共有 64 行，4 路组相联，故有 $S=64/4=16=2^4$ 组。主存块 $64\mathrm B=2^6\mathrm B$，块内偏移占 6 位。于是对于**32 位物理地址**：

$$
\underbrace{\mathrm{Tag}}_{32-4-6=22\text{ 位}\;(31{:}10)}\mid
\underbrace{\mathrm{Set}}_{4\text{ 位}\;(9{:}6)}\mid
\underbrace{\mathrm{Offset}}_{6\text{ 位}\;(5{:}0)}.
$$

典型陷阱：**64 是 Cache 总行数，16 才是组数**；把 64 直接用于取模，会错把 4 路组相联当作直接映射。分离 I-Cache 与 D-Cache 时，本题只统计 **I-Cache** 的指令访问，不会因为有数据 Cache 就把组数或容量翻倍。

### 3. 用虚拟页内偏移推出物理组号

第 16 行 `call` 的地址为 `00401025H`，页内偏移 `025H`。组索引位 $[9:6]$ 位于页内偏移 $[11:0]$ 内，虚实地址的这 12 位严格相同，因此

$$
\mathrm{Set}=(\texttt{025H}\gg6)\bmod16
=\left\lfloor\frac{37}{64}\right\rfloor\bmod16
=\boxed0.
$$

即使题干给出的是**虚拟指令地址**，也能算出物理 Cache 的组号；但 **Cache Tag $[31:10]$ 未必能从该虚拟地址高位直接得到**，必须依赖物理页框号。组号仅限定候选位置，不能凭它判定命中。

### 4. 做题模板与变式判断

1. **比较页**：先按页大小切 VPN 与页内偏移；同一 VPN 即同一虚拟页。
2. **地址划分**：组数 $S=\mathrm{CacheLines}/\mathrm{Ways}$，组位数 $\log_2S$，块内位数 $\log_2B$，Tag 用物理位数减去二者。
3. **检查“组位是否落在页内”**：若 $s+b\le p$（$p=\log_2$ 页大小），虚拟地址低 $p$ 位即可推出组号。否则需要实际物理地址。
4. **可定位与命中区分**：能确定第几组不等于已命中；还需要有效位、物理 Tag 和该组实际内容。

按字节编址、`int` 占 4B，一个含 20 个整数的连续数组首地址为 `003CH`（十六进制），与数据 Cache 同处一个地址空间。数据 Cache 只有 **2 行**，直接映射、块 64B，初始为空。程序先从 `a[0]` 读到 `a[19]`，再从 `a[19]` 读回 `a[0]`，只发生这 40 次读、无写和其他干扰。

1. 求该数组覆盖的主存块号及第一轮顺序读的 Cache 缺失次数。
2. 求逆序读的 Cache 缺失次数，以及完整 40 次读的命中率。
3. 若仅将 Cache 改为 **3 行直接映射**、块大小不变，逆序读的缺失次数又是多少？

<ExamSolution>

<ExamAnswer>

数组占用主存块 $0,1,2$；顺序扫缺失 **3 次**。2 行直接映射时逆序扫缺失 **1 次**，40 次总缺失 4 次，命中率 $36/40=\boxed{90\%}$。若为 3 行直接映射，逆序扫缺失 **0 次**。

</ExamAnswer>

<ExamExplanation>

首元素地址 $\texttt{003CH}=60$，末元素（`a[19]`）首字节为 $60+19\times4=136$，最后一个字节地址 $139$。主存块号为 $\lfloor\mathrm{addr}/64\rfloor$，所以覆盖：块 $0$ 的 4B、块 $1$ 的 64B、块 $2$ 的 12B，分别对应第 1、16、3 个整数，共 20 个。

**顺序读**从块 $0\rightarrow1\rightarrow2$，三块均第一次遇到，因此 3 次强制 miss。只有 2 行时映射：块 0→行 0，块 1→行 1，块 2→行 0；结束后 Cache 保存**块 2（行 0）与块 1（行 1）**。逆序访问从块 2 起（命中），接着块 1（命中），最终块 0（因行 0 已被块 2 占用而未命中），因此仅 1 次 miss。

总命中次数 $40-4=36$；注意两轮之间**不清空 Cache**，不能将顺序阶段的 3 次 miss 简单复制成逆序阶段 3 次。若 Cache 变为 3 行，块 $0,1,2$ 分别映射到行 $0,1,2$，第一轮后全部驻留，因此逆序 20 次都命中。

**未对齐通式**：从地址 $A$ 开始连续访问 $L$ 字节，跨越块数为

$$
N_{\mathrm{blocks}}=\left\lfloor\frac{A+L-1}{B}\right\rfloor-\left\lfloor\frac AB\right\rfloor+1.
$$

本题 $A=60,L=80,B=64$，得 $\lfloor139/64\rfloor-\lfloor60/64\rfloor+1=2-0+1=3$。没有这一公式时，常误用 $\lceil80/64\rceil=2$，漏算未对齐导致的额外块。

</ExamExplanation>

## 2020 年第 44 题

<ExamQuestion>

**60. 2020 年第 44 题**

假定主存地址为 32 位，按字节编址。指令 Cache 和数据 Cache 与主存之间均采用 8 路组相联映射、直写（Write Through）策略和 LRU 替换算法，主存块大小为 $64\text{ B}$，两者的数据区容量均为 $32\text{ KB}$。开始时 Cache 均为空。请回答：

1. Cache 每行中的 Tag、LRU 位各占几位？是否需要修改位？
2. 有如下 C 程序段：

```c
for (k = 0; k < 1024; k++)
    s[k] = 2 * s[k];
```

若数组 `s` 和变量 `k` 均为 `int` 型，`int` 占 4 B，`k` 分配在寄存器中，数组 `s` 在主存中的起始地址为 `008000C0H`，则程序执行过程中访问数组 `s` 的数据 Cache 缺失多少次？
3. 若 CPU 最先进行的访问是读取主存单元 `00010003H` 中的指令，简要说明从指令 Cache 访问该指令的过程，包括 Cache 缺失处理。

<ExamSolution>

<ExamAnswer>

1. Tag 为 $20$ 位。题目采用“每行编码 0～7 的 LRU 顺序号”时，每行 LRU 字段为 $3$ 位；直写不需要脏位。**3 位/行是这种编码方案的位数**，不代表所有 8 路 LRU 实现只需 3 位总状态。
2. 数据 Cache **缺失 64 次**。
3. `00010003H`：组号 $0$、Tag=`00010H`、块内偏移 `03H`；首次访问因 Cache 初始为空而 miss，装入主存块 `00010000H`～`0001003FH`，更新有效位与替换状态，再取指。

</ExamAnswer>

<ExamExplanation>

### 1. 容量换算：64B × 8 路 × 64 组

每份 Cache 的数据区容量 $32\mathrm{KB}=2^{15}\mathrm B$，每块 $64\mathrm B=2^6\mathrm B$，故每份 Cache 行数 $2^{15}/2^6=512$，8 路组相联后组数 $512/8=64=2^6$。物理地址 32 位，字段划分：

$$
\underbrace{\mathrm{Tag}}_{20\text{ 位}}\mid
\underbrace{\mathrm{Set}}_{6\text{ 位}}\mid
\underbrace{\mathrm{Offset}}_{6\text{ 位}}.
$$

题设明示 LRU。若每行存一个“最近使用次序排名”$0\sim7$，每行需要 $\log_2 8=3$ 位并在命中/替换时维护组内全部排名。**LRU 与具体编码方式需区分**：精确 LRU 不等于仅以一个全组 3 位寄存器就记录所有 8 路次序（8! 种排列至少需 $\lceil\log_2(8!)\rceil=16$ 位状态）；树形伪 LRU 又是另一算法。本题的**每行 3 位**只对应顺序排名实现。

采用 **Write Through** 直写主存，无“已在 Cache 修改而主存尚未更新”的状态，因此不需要 dirty bit。**写策略≠写分配策略**；本题顺序先读后写，是否写分配不影响下面的读 miss 数。

### 2. 把循环还原为访存序列，再数不重复主存块

循环 `s[k]=2*s[k]` 对每个元素先**读取** `s[k]`，再计算并**写回** `s[k]`；$k$ 常驻寄存器，指令访问被独立的 I-Cache 处理，题问的是**数据 Cache** 缺失。$\mathrm{int}=4\mathrm B$，$1024$ 个整数共

$$
1024\times4=4096\mathrm B,
\quad \text{每块整数}=64/4=16,
\quad \text{连续块数}=4096/64=\boxed{64}.
$$

数组首地址 `008000C0H` 是 64B 对齐地址（低 6 位全为 0）。每个块 16 个元素；第一次读取该块的第一个元素发生 miss 并**整块装入**，本块中余下读取和写回均命中。顺序访问每块一次，不回头访问被替换的旧块，所以 64 个不同块各缺失一次，总 miss **64**。

> 自检：总共有 1024 次读 + 1024 次写。如果把每次读写都统计为数据 Cache 访问，共 2048 次、64 次缺失、1984 次命中，命中率为 $1984/2048=96.875\%$。若题目只统计读请求，命中率则为 $(1024-64)/1024=93.75\%$。**两种分母不同，题目只要求缺失次数，答案一致。**

注意“直写”可能使每个写命中都向主存产生写事务，但这是**下层写流量**，不应误算为 1024 次 Cache miss。如果题目另设写缓冲或 no-write-allocate，应先单独判断缺失写是否装块。

### 3. 首次从指令 Cache 读取 `00010003H` 的操作流程

地址 32 位按 `[31:12] Tag | [11:6] Set | [5:0] Offset` 切分；该指令地址的低 12 位为 `003H`，因而

$$
\mathrm{Tag}=\texttt{00010003H}\gg12=\texttt{00010H},\quad
\mathrm{Set}=(\texttt{00010003H}\gg6)\mathbin{\&}63=0,
\quad\mathrm{Offset}=3.
$$

步骤：① CPU 发起取指，使用**指令 Cache** 第 0 组同时比较 8 路的有效位和 Tag；② 初始全空，故 miss；③ 选空行装入起始字节地址为 `00010000H` 的完整 64B 主存块；④ 设置 Tag=`00010H`、有效位 1、调整 LRU；⑤ 由块内偏移 `03H` 定位起始字节并交由取指单元继续获取指令。若一条指令跨越块边界，还须读取下一个块；本题没有给出该条指令长度，故**不能臆断跨块读取次数**。

**检查重点**：最初访问是取指，不能误当成数据 Cache 的缺失；两份 Cache 参数相同，但存放内容及命中历史彼此独立。

假设计算机 M 的主存地址为 24 位，按字节编址；采用分页存储管理方式，虚拟地址为 30 位，页大小为 $4\text{ KB}$；TLB 采用 2 路组相联方式和 LRU 替换策略，共 8 组。请回答下列问题。

1. 虚拟地址中哪几位表示虚页号？哪几位表示页内地址？
2. 已知访问 TLB 时虚页号高位部分用作 TLB 标记，低位部分用作 TLB 组号，M 的虚拟地址中哪几位是 TLB 标记？哪几位是 TLB 组号？
3. 假设 TLB 初始时为空，访问的虚页号依次为 10、12、16、7、26、4、12 和 20，在此过程中，哪一个虚页号对应的 TLB 表项被替换？说明理由。
4. 若将 M 中的虚拟地址位数增加到 32 位，则 TLB 表项的位数增加几位？

<ExamSolution>

<ExamAnswer>

1. 页内偏移 $A_{11}\sim A_0$（12 位），虚页号 $A_{29}\sim A_{12}$（18 位）。
2. TLB 组索引 $A_{14}\sim A_{12}$（3 位），Tag $A_{29}\sim A_{15}$（15 位）。
3. **VPN = 4** 的 TLB 项在访问 VPN 20 时被替换。
4. 虚拟地址由 30 位增至 32 位且其他参数不变，TLB **每项增加 2 位 Tag**。

</ExamAnswer>

<ExamExplanation>

### 1. 先按页大小分离虚拟地址

$4\mathrm{KB}=2^{12}\mathrm B$，30 位虚拟地址的 12 个低位为页内偏移；其余 $30-12=18$ 个高位为虚页号：

$$
\underbrace{A_{29}\cdots A_{12}}_{18\text{ 位 VPN}}\mid
\underbrace{A_{11}\cdots A_0}_{12\text{ 位页内偏移}}.
$$

主存地址为 24 位，仅影响**物理页框号**的位数 $24-12=12$；不能用主存地址长度 24 位去切虚拟 VPN。这种“虚实位数不同”的题务必画两行地址格式。

### 2. TLB 组号由 VPN 的低位取得

题目明确 TLB **8 组、2 路**，所以共有 16 个表项，但只需 $\log_2 8=3$ 位来编号组。组号来自 VPN 的低 3 位，也就是整条虚拟地址的 $A_{14}\sim A_{12}$；剩余高 15 位作为 Tag：

$$
\mathrm{Set}=\mathrm{VPN}\bmod8,\qquad
\mathrm{Tag}=\left\lfloor\frac{\mathrm{VPN}}8\right\rfloor.
$$

**易错**：2 路表示每组可并存 2 个不同 VPN，不是只有 2 组；不能直接用**整个虚拟地址**对 8 取模，那会把页内偏移误算进组号。

### 3. 手工维护组内 LRU：只有第 4 组需要替换

初始 TLB 为空，序列为 $10,12,16,7,26,4,12,20$。依次求余数：

| 访问 VPN | 10 | 12 | 16 | 7 | 26 | 4 | 12 | 20 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 所属组 | 2 | 4 | 0 | 7 | 2 | 4 | 4 | 4 |
| 结果 | 缺失 | 缺失 | 缺失 | 缺失 | 缺失 | 缺失 | **命中** | **缺失、替换 4** |

第 2 组依次装入 VPN 10、26，两路刚好占满而未发生替换；第 0、7 组分别只装一个表项。第 4 组细化：

| 第 4 组访问 | 访问 12 | 访问 4 | 再访问 12 | 访问 20 |
| --- | --- | --- | --- | --- |
| 最近使用 → 最久未用 | `[12]` | `[4, 12]` | `[12, 4]` | `[20, 12]` |
| 事件 | 装入空路 | 装入空路 | 命中并更新最近使用项 | **淘汰 4** |

故唯一被替换的 VPN 为 $\boxed4$。**LRU 命中也要更新时间戳或次序**，若错误地按 FIFO 不更新，会错淘汰 VPN 12。

这里求的是 **TLB 表项被替换**，不是物理页框被换出；TLB miss 可以由页表填充，无须一定缺页。本题默认访问的页面有有效映射，没有额外页面置换条件。

### 4. 扩大虚拟地址空间后哪些字段增长

从 30 位到 32 位，页内偏移仍 12 位、组号仍 3 位、PFN 仍 12 位。VPN 长度变为 $32-12=20$ 位，Tag 从 $18-3=15$ 位增至 $20-3=17$ 位：

$$
\Delta\mathrm{TLBTag}=17-15=\boxed{2\text{ 位}}.
$$

表项中的 PFN、有效位、替换相关状态等均不因**虚拟地址位宽**增加而自动变长。若题目改的是**物理地址位宽**，则变化通常落到 PFN，而不是 VPN Tag；若改的是**页大小**或 **TLB 组数**，须重算所有切分位数。

### 5. 考场三步法

只画一张表：① `VPN % 组数`；② 按组分别维护最近使用顺序；③ 只有**同一组已满且目标不在组内**才替换。这个流程对 TLB 和组相联 Cache 都成立，但二者 Tag、访问对象、缺失后的处理完全不同。

</ExamExplanation>

1. 求一次访存的平均服务时间（AMAT），分开列出 TLB 与数据层次的开销。
2. 若 L1 命中率提升到 95%，其他参数不变，新 AMAT 是多少？
3. 说明不能把 L2 的 20% 未命中率直接乘在**所有**访问上的原因。

<ExamSolution>

<ExamAnswer>

原 AMAT = $1+0.05\times10+1+0.1(5+0.2\times50)=\boxed{4\mathrm{ns}}$。L1 命中率升至 95% 后为 $1+0.5+1+0.05(5+10)=\boxed{3.25\mathrm{ns}}$。L2 未命中率是以**已发生 L1 未命中**为条件的比例，整体进入主存的概率为 $0.1\times0.2=2\%$，而不是 20%。

</ExamAnswer>

<ExamExplanation>

画概率树（串行）：每次都要先付 TLB 检索 $1$ns，只有 5% 的请求额外付页表走查 10ns；每次都要付 L1 检索 1ns，只有 10% 进一步付 L2 查询 5ns；这 10% 中的 20% 还须付主存 50ns。所以

$$
\begin{aligned}
T_{\mathrm{TLB}}&=1+(1-0.95)\times10=1.5\mathrm{ns},\\
T_{\mathrm{Data}}&=1+(1-0.9)\,[5+(1-0.8)\times50]=2.5\mathrm{ns},\\
\mathrm{AMAT}&=T_{\mathrm{TLB}}+T_{\mathrm{Data}}=\boxed{4\mathrm{ns}}.
\end{aligned}
$$

把 L1 命中率改成 95% 后，只替换 $P(\mathrm{L1Miss})$ 为 $0.05$，得到 $1.5+1+0.05\times15=3.25$ns，节省 $0.75$ns。

## 2022 年第 44 题

<ExamQuestion>

**64. 2022 年第 44 题**

假设某磁盘驱动器中有 4 个双面盘片，每个盘面有 20000 个磁道，每个磁道有 500 个扇区，每个扇区可记录 512 字节的数据，盘片转速为 $7200\text{ rpm}$，平均寻道时间为 $5\text{ ms}$。请回答下列问题。

1. 每个扇区包含数据及地址信息，地址信息分为 3 个字段。这 3 个字段的名称各是什么？对于该磁盘，各字段至少占多少位？
2. 一个扇区的平均访问时间约为多少？
3. 若采用周期挪用 DMA 方式进行磁盘与主机之间的数据传送，磁盘控制器中的数据缓冲区大小为 64 位，则在一个扇区读写过程中，DMA 控制器向 CPU 发送多少次总线请求？若 CPU 检测到 DMA 控制器的总线请求信号时也需要访问主存，则 DMA 控制器是否可以获得总线使用权？为什么？

<ExamSolution>

<ExamAnswer>

1. 采用 **CHS（柱面/磁头/扇区）**地址：柱面号至少 **15 位**、磁头号至少 **3 位**、扇区号至少 **9 位**。
2. 单扇区平均访问时间约 **$9.18\mathrm{ms}$**（寻道 $5\mathrm{ms}$、平均旋转等待 $4.167\mathrm{ms}$、传输 $0.0167\mathrm{ms}$）。
3. 每扇区共需 **64 次** 64 位 DMA 数据传送/总线申请；在题设的**周期挪用**仲裁规则下，DMA 与 CPU 同时要求主存时，通常由 DMA 优先获得使用权。

</ExamAnswer>

<ExamExplanation>

### 一、先统一盘片、盘面、磁头、磁道、柱面五个概念

- **盘片**：有两个可用于存储数据的表面；本题 4 个双面盘片，共 $4\times2=8$ 个盘面。
- **磁头**：与一个盘面对应，选择磁头也就是选择盘面，故磁头号需 $\lceil\log_2 8\rceil=3$ 位。
- **磁道**：单个盘面上的同心圆记录区域；每面 20000 磁道。
- **柱面**：所有盘面上半径相同的磁道组成一个柱面，不是“盘面数乘每面磁道数”。柱面数 $20000$，至少 $\lceil\log_2 20000\rceil=15$ 位。
- **扇区**：磁道的进一步划分；每条磁道 500 个扇区，至少 $\lceil\log_2 500\rceil=9$ 位。

地址字段最小位宽汇总如下：

| CHS 字段 | 可取值个数 | 最少位数 | 理由 |
| --- | ---: | ---: | --- |
| 柱面号 C | 20000 | 15 | $2^{14}<20000\le2^{15}$ |
| 磁头号 H | 8 | 3 | $2^3=8$ |
| 扇区号 S | 500 | 9 | $2^8<500\le2^9$ |

实际硬盘可能使用 LBA 逻辑块编址和区位记录，这里**完全按题设的等扇区数 CHS 模型**计算。若要求盘总用户数据容量，则为 $8\times20000\times500\times512=40,960,000,000\mathrm B$（十进制 $40.96\mathrm{GB}$）；地址字段合计 $27$ 位，可能有无效编码，不能反推容量就是 $2^{27}\times512$ 字节。

### 二、平均访问时间三段不能漏传输

转速 $7200\mathrm{rpm}=120\mathrm{r/s}$，转一圈

$$
T_{\mathrm{rev}}=\frac{60}{7200}\mathrm s=\frac1{120}\mathrm s=8.333\overline3\mathrm{ms}.
$$

随机到达扇区的平均旋转等待时间为半周；在“一个扇区占整道的 $1/500$”的均匀模型下，持续传送一扇区需 $T_{\mathrm{rev}}/500$：

$$
\begin{aligned}
T_{\mathrm{seek}}&=5\mathrm{ms},\\
T_{\mathrm{rot}}&=\frac{T_{\mathrm{rev}}}{2}=4.166\overline6\mathrm{ms},\\
T_{\mathrm{xfer}}&=\frac{T_{\mathrm{rev}}}{500}=0.016\overline6\mathrm{ms},\\
T_{\mathrm{avg}}&=T_{\mathrm{seek}}+T_{\mathrm{rot}}+T_{\mathrm{xfer}}\approx\boxed{9.18\mathrm{ms}}.
\end{aligned}
$$

**高频陷阱**：转速单位是“每分钟转数”，需先除以 60；随机访问的旋转延迟按平均**半圈**，不是一圈；题目要求单个扇区访问，还应计算扇区数据的传输时间。这里忽略控制器处理时间、寻道后稳定时间及扇区间隙，这是考题模型的默认约定。

### 三、DMA 为什么是 64 次而不是 512 次或一次

一个扇区有效数据 $512\mathrm B=4096\mathrm{bit}$，缓冲区大小 64 位 $=8\mathrm B$，则每份待搬运数据大小为 8B：

$$
N_{\mathrm{DMA}}=\frac{512\times8}{64}=\boxed{64\text{ 次}}.
$$

这里将“缓冲区 64 位”按**一次从缓冲区取走 64 位并申请一次总线**解释；如果另一个题设明确了更宽的突发 DMA、DMA 成组传输或独立的总线宽度与 FIFO，必须按**每次实际授予传送的字节数**重新计数，不能机械套用 $64$。

**周期挪用（cycle stealing）**：DMA 在需要访问主存时请求总线并占用必要的存储器总线周期，其间 CPU 的访存可能暂停；题目所指经典优先级模型下 DMA 获优先权，以防设备数据因缓冲区积满而丢失。与另外两种方式比较：

| DMA 工作方式 | 占用总线形式 | CPU 受到的典型影响 |
| --- | --- | --- |
| 停止 CPU 访问 | 一次长批量占用 | CPU 长时间不能访存 |
| 周期挪用 | 每次挪用必要周期 | CPU 被间歇性推迟 |
| DMA 与 CPU 交替 | 双方按约定时隙使用 | 可较规则地并行调度 |

**易错辨析**：DMA 无需 CPU **逐字节执行搬运指令**，但并非“完全不占总线”；DMA 完成整个 I/O 后仍可能通过中断通知 CPU。实际机器的仲裁策略可配置，本题只考经典周期挪用的优先性。

### 四、迁移解法

若改为平均寻道 $4\mathrm{ms}$、$10000\mathrm{rpm}$、每道 $600$ 扇区，只需按

$$
T_{\mathrm{avg}}=T_{\mathrm{seek}}+\frac{30}{\mathrm{rpm}}\times10^3+\frac{60}{\mathrm{rpm}\cdot N_s}\times10^3\quad(\mathrm{ms})
$$

代入（注意 $\mathrm{rpm}$ 以转/分计），得到 $4+3+0.01=7.01\mathrm{ms}$。CHS **位数由可取值个数决定**，与当前转速无关。

</ExamExplanation>

### 一、二维数组按行优先，先写统一地址公式

定义 `a` 为 $24\times64$ 个 4B 整数，基址 $B=\texttt{00422000H}$。`a[i][j]` 的首地址：

$$
\operatorname{Addr}(a[i][j])=B+4(64i+j)=B+256i+4j.
$$

总元素数 $24\times64=1536$；大小 $1536\times4=6144\mathrm B=6\mathrm{KiB}$。页长 $4\mathrm{KiB}=4096\mathrm B$，起始位置正好位于页边界（低 12 位为 0）。因此占 $\lceil6144/4096\rceil=2$ 页。访问开始前两页都不驻留且不置换，第一次访问第 1、2 页分别引发一次缺页：`00422000H` 和 `00423000H`，共两次。区分**缺页发生时的触发访存地址**和页框号；这里题目给出了触发元素首字节地址，恰好都是页首。

若交换循环，先访问 `a[0][0]`，其后按列跨行访问；仍会在首次触及第二页时发生第二次缺页，次数不变，但访问顺序发生变化。

### 二、时间局部性与空间局部性严格区分

**时间局部性**要求近期再次使用同一地址或数据；`a[i][j]=10` 每个元素仅赋值一次，因此就数组元素而言没有重复访问，不能因为处于双重循环就说“有时间局部性”。**空间局部性**要求近期访问相邻地址，按行遍历 $a[i][j],a[i][j+1]$ 地址差 4B，空间局部性好。

按列遍历时 $a[i][j]$ 与 $a[i+1][j]$ 地址差 256B，短期空间局部性较弱；不过之后下一个列号 $j+1$ 会重访**刚才各行的 Cache 块**，这属于**块级重用**，与题目中“数组元素只访问一次”的判断可以同时成立。

### 三、Cache 索引及地址位范围

数据 Cache $8\mathrm{KiB}$，块大小 $32\mathrm B$，4 路组相联。先求行数，再求组数：

$$
L=8192/32=256,\qquad S=256/4=64=2^6.
$$

块内偏移位数 $b=\log_2 32=5$，组索引位数 $s=\log_2 64=6$，故 $A_{4:0}$ 为块内偏移、$A_{10:5}$ 为组号。`a[1][0]` 与首地址相距 256B $=\texttt{100H}$：

$$
\operatorname{Addr}(a[1][0])=\texttt{00422000H}+\texttt{100H}=\boxed{\texttt{00422100H}}.
$$

第 8 组来自 $(\texttt{100H}\gg5)\bmod64=8$。**物理 Cache 的完整 Tag**仍取决于地址转换；但组号位 $[10:5]$ 全在 4KB 页内偏移 $[11:0]$，可直接从虚地址取出。题目没有给物理页框号，故不能凭虚拟地址高位构造完整物理标记。

### 四、按行遍历：每 8 次访问产生 1 次强制缺失

数据长度 $6144\mathrm B$，从 32B 对齐的地址开始，正好占 $6144/32=\boxed{192}$ 个不同的块。一个块含 $32/4=8$ 个整数；按行访问时，每个块首次写入为 miss，另外 7 次写命中：

$$
\text{按行缺失}=192,\quad\text{总访存}=1536,\quad h=\frac{1536-192}{1536}=\boxed{87.5\%}.
$$

这里沿用原题答案的 Cache 缺失统计模型：**写未命中采用写分配**，使一个新块在第一次写时进入 Cache。若另行规定“写未命中不分配”，上述命中率便不能沿用。题目未提供写策略时，题解使用可产生题设预期命中率的写分配模型，并明确该前提。

### 五、按列遍历：先做“每组驻留压力”核验

每行 $64\times4=256\mathrm B$，即 8 个 Cache 块。固定列 $j$（其中 $0\le j<8$）时，24 行所访问的 24 个块，其组号每跨一行加 8（模 64），所以仅落入组 $0,8,16,24,32,40,48,56$；**每组刚好 3 个不同块**。4 路的容量足以容纳这 3 个块，所以前 8 列内不会因同行/异行映射冲突提前被替换。

对 $j=8\sim15$ 等后续每组 8 列重复上述过程，只是组号整体平移 1，仍每组 3 个块。于是 $1536$ 次访问中也恰有 **192 次强制缺失**、1344 次命中：

$$
h=\frac{1344}{1536}=\boxed{87.5\%}.
$$

**考试策略**：遇到循环交换与组相联，绝不能只凭“按列不连续”就判命中率下降；必须按“地址跨度 $\to$ Cache 块号 $\to$ 组号 $\to$ 同时活跃块数 $\to$ 路数”核验。若本题仅将 **4 路改成 2 路而仍保留 8KiB 数据区**，组数同时由 64 增到 128，24 个活跃块在每组最多 2 块，**仍不会产生这类冲突**；若再把容量减至 **4KiB**，则只有 64 组、2 路，每组可能同时需要 3 个块，按列扫描就可能发生冲突缺失。相联度、总容量和组数必须联立分析。

</ExamExplanation>

<span className="inline-block rounded border px-2 py-0.5 text-xs text-fd-muted-foreground">原创</span>

有 `int a[24][64]`，按行优先存放，首地址在 32B 块边界，`sizeof(int)=4`。数据 Cache 数据区为 **8KiB**、块大小 32B、但改成 **2 路组相联**，采用 LRU 替换，初始为空；写未命中时**写分配**，程序中没有其他会干扰 Cache 的数据访问。执行：

```c
for (int j = 0; j < 64; ++j)
    for (int i = 0; i < 24; ++i)
        a[i][j] = 10;
```

1. 求组数、同一列中 24 行对每组的映射块数，说明缓存是否能保存每行此列所在的块。
2. 整个循环对 `a` 的 1536 次写访问共多少次 Cache 缺失？命中率是多少？
3. 若改回 **4 路组相联**，只修改路数，缺失次数及命中率是多少？

<ExamSolution>

<ExamAnswer>

2 路时 **128 组**，每列的 24 块落在 **16 组**、每组 1 或 2 块，能同时保留；故全程 **192 次缺失、命中率 $87.5\%$**。4 路时 **64 组**、每列 24 块落在 8 组，每组 3 块，仍可同时保留，答案同为 **192 次、$87.5\%$**。

</ExamAnswer>

<ExamExplanation>

每行 $64\times4=256$B $=8$ 个 32B 块。2 路 Cache 有 $8192/(32\times2)=128$ 组，连续 24 行同一列的块号依次相差 8。映射组号差 8（模 128），循环周期 $128/\gcd(128,8)=16$，因此 24 行共涉及 16 个组：前 8 个组各遇 2 个不同块，后 8 个组各遇 1 个，**最多 2 个/组**，恰好不超过 2 路。

更精确地，对固定列区间 $8k\le j\le8k+7$，访问的 24 个块就是每行第 $k$ 块，首列把它们装入 Cache；后 7 列再次触及各自的同一块，**均命中**。切换到下一组 8 列时，所有要访问的是新块，同样首列强制未命中，但缓存压力不会使其在当前 8 列内被提前置换。因此总缺失 $24\times(64/8)=\boxed{192}$、命中率 $(1536-192)/1536=87.5\%$。

换成 4 路时 $S=8192/(32\times4)=64$ 组，组号差 8 的周期为 $64/8=8$，24 块恰好每组 3 个，不超过 4 路；命中率仍然相同。这里的**关键陷阱**是“减少相联度必然导致冲突”这一错误推断：须同时考虑**组数变多、相同跨度分散到多少组**。

**扩展追问**：若变为 **直接映射 256 组**，差 8 的周期为 32，24 块映射到不同组，同样不存在这组数据的冲突。因此在本题固定容量、固定数据跨度条件下，3 种相联度都不会改变命中率；不能只根据“列访问”四字断定缓存效率低。

</ExamExplanation>

## 2025 年第 43 题

<ExamQuestion>

**69. 2025 年第 43 题**

现有 C 语言程序 P 的部分代码如下：

```c
int x, d[2048], i;
...
for (i = 0; i < 2048; i++)
    d[i] = d[i] / x;
...
```

假定运行 P 的计算机 M 字长为 32 位，按字节编址，数据 Cache 的数据区大小为 $32\text{ KB}$，采用 8 路组相联映射，主存块大小为 $64\text{ B}$，Cache 命中时间为 2 个时钟周期，缺失损失为 200 个时钟周期；采用页式虚拟存储管理，页大小为 $4\text{ KB}$。数组 `d` 的起始虚拟地址 $VA_{31}\sim VA_0$ 为 `0180 0020H`。请回答下列问题。

1. 主存地址中的 Cache 组号字段、块内地址字段分别占几位？虚拟地址中哪些位可作为 Cache 索引？
2. `d[100]` 的虚拟地址是多少？`d[100]` 所在主存块对应的 Cache 组号是多少？
3. 假定执行 `for` 语句时对应代码已在 Cache 中，变量 `i` 和 `x` 已装入寄存器，数组 `d` 已调入主存但不在 Cache。`d[0]` 在其所在主存块内的偏移量是多少（用十六进制表示）？执行 `for` 的过程中，访问 `d` 的 Cache 缺失率和数组元素的平均访问时间分别是多少？缺失率用百分比表示并保留两位小数。
4. `d` 分布在几个页中？若代码已在主存而 `d` 不在主存，则执行 `for` 的过程中，访问 `d` 所引起的缺页次数是多少？

<ExamSolution>

<ExamAnswer>

1. 块内偏移 **6 位**、Cache 组号 **6 位**；虚拟地址 $VA_{11:6}$ 可直接用于物理组索引。
2. `d[100]` 的虚地址是 `018001B0H`；组号为 **6**。
3. `d[0]` 块内偏移 `20H`；顺序数组读写共 **129 次 Cache 未命中 / 4096 次 Cache 访问**，缺失率 $\boxed{3.15\%}$，平均访问时间 $\boxed{8.30\text{ 个周期}}$。
4. `d` 跨越 **3 个虚拟页**，假定起初这些页均不驻留且之后不换出，共 **3 次缺页**。

</ExamAnswer>

<ExamExplanation>

### 一、组号位和地址转换：一张公式表搞定

数据区 $32\mathrm{KiB}=32768\mathrm B$、块大小 $64\mathrm B$、8 路：

$$
\begin{aligned}
\text{块偏移位数 }b&=\log_2 64=6,\\
\text{Cache 行数 }L&=32768/64=512,\\
\text{组数 }S&=512/8=64=2^6,\\
\text{组索引位数 }s&=6.
\end{aligned}
$$

故物理地址的组位是 $PA_{11:6}$、块内位是 $PA_{5:0}$。页大小 $4\mathrm{KiB}=2^{12}\mathrm B$；因为 $b+s=12$，组索引在页内地址范围内，$VA_{11:6}=PA_{11:6}$。这只允许用虚地址**索引组**，不代表可用虚地址高位代替**物理 Tag** 判命中。若日后增大 Cache 组数导致 $s+b>12$，这种无需译址的组索引关系就不再成立。

### 二、精算地址、块偏移，识别“不对齐起始”的陷阱

`d[100]` 距数组首部 $100\times4=400=\texttt{190H}$：

$$
\operatorname{Addr}(d[100])=\texttt{01800020H}+\texttt{190H}=\boxed{\texttt{018001B0H}}.
$$

组号为 $(\texttt{1B0H}\gg6)\bmod64=6$，即可由地址位 $[11:6]$ 求得。`d[0]` 地址低 6 位为 $\texttt{20H}$，块内偏移是 **32B**，不是 0。第一个 64B 块只容纳数组前 $32/4=8$ 个元素。

### 三、129 次 Cache 缺失从何而来

数组共 $2048\times4=8192$B，恰好为 128 个块的**数据量**，但起始偏移 32B；数组覆盖的半开地址区间是 $[\texttt{01800020H},\texttt{01802020H})$，首块号至末块号一共有

$$
N=\left\lfloor\frac{A+L-1}{64}\right\rfloor-\left\lfloor\frac{A}{64}\right\rfloor+1=\boxed{129}.
$$

Cache 初始化没有 `d`，且此循环单次线性扫描、无其他数据 Cache 干扰，故每个首次遇到的块引发一次未命中。`d[i]=d[i]/x` 的右侧先**读一次** `d[i]`，左侧再**写一次**回同一位置，共 $2048\times2=4096$ 次数据 Cache 访问。读首次 miss 后该块已装入 Cache，紧随的写命中（不需额外计一次 miss）：

$$
r=\frac{129}{4096}\times100\%\approx\boxed{3.15\%}.
$$

**不要先把缺失率四舍五入成 $3.15\%$ 再算平均时间**；保留分数更准确。命中时间为 2 周期，缺失损失为在这 2 周期**之外额外增加**的 200 周期：

$$
\begin{aligned}
\mathrm{AMAT}&=T_h+rT_m\\
&=2+\frac{129}{4096}\times200\\
&=8.298828125\approx\boxed{8.30\text{ 周期}}.
\end{aligned}
$$

若另一个题把“未命中总服务时间”写成 200 周期，则应改为 $(1-r)T_h+r\times200$；本题明确为 **miss penalty 200**，所以是 $T_h+rT_m$。

### 四、按页统计不能用 `总长/页大小` 忽略页首偏移

页内地址是起始虚址的低 12 位，即 $\texttt{020H}=32$B。数据长 $8192$B，相对于首个页面边界占用 $32+8192=8224$B，跨越 3 个 4096B 页：

- 第一页从 `01800020H` 开始；
- 第二页第一次访问地址 `01801000H`；
- 第三页第一次访问地址 `01802000H`（只有尾部 32B 数据落入该页）。

起初 `d` 全部不在主存，每个页第一次触及时各触发 1 次缺页，所以是 **3 次**。**缺页次数、Cache 未命中次数、数组元素数是三个不同尺度**：分别以页、块和元素为计数单位。题目没有要求把操作系统调页期间的访存折入 Cache AMAT，故分别计算，不能把缺页延迟额外塞进 $8.30$ 周期。

### 五、可复用的一页/一块通式

连续覆盖 $L$ 字节，起始地址对齐偏移 $r=A\bmod P$（页长 $P$），页面数为

$$
N_{\mathrm{pages}}=\left\lceil\frac{r+L}{P}\right\rceil.
$$

当起始块偏移为 $q=A\bmod B$（块长 $B$），对应块数为 $N_{\mathrm{blocks}}=\lceil(q+L)/B\rceil$。本题页面 $\lceil(32+8192)/4096\rceil=3$，主存块 $\lceil(32+8192)/64\rceil=129$。条件是数据线性连续且统计了每一个触及的字节，不应对有跨行间隙的数据布局不加调整地套用。

</ExamExplanation>
