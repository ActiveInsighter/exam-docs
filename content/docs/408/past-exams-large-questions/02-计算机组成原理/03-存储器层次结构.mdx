## 2010 年第 44 题

<Question
  id="408-co-large-2010-44"
  type="essay"
  tags="来源:2010考研408, 科目:计算机组成原理, 章节:存储器层次结构, 考点:Cache直接映射, 考点:访问命中率, 难度:综合"
>

某计算机主存按字节编址，主存地址空间大小为 $256\ \mathrm{MB}$。指令 Cache 与数据 Cache 分离，均有 8 个 Cache 行，每行 $64\ \mathrm B$，数据 Cache **直接映射**。不考虑用于 Cache 一致性及替换算法的控制位。

有两个功能相同的程序，使用按**行优先**连续存放的数组 `a`。`int` 占 $32$ 位，数组首地址为**十进制 320**；`i`、`j`、`sum` 均位于寄存器。

```c title="程序 A：按行扫描"
int a[256][256];
int sum_array1(void) {
    int sum = 0;
    for (int i = 0; i < 256; ++i)
        for (int j = 0; j < 256; ++j)
            sum += a[i][j];
    return sum;
}
```

```c title="程序 B：按列扫描"
int a[256][256];
int sum_array2(void) {
    int sum = 0;
    for (int j = 0; j < 256; ++j)
        for (int i = 0; i < 256; ++i)
            sum += a[i][j];
    return sum;
}
```

1. 若计入数据位、标记位和有效位，数据 Cache 的总容量为多少？
2. `a[0][31]` 与 `a[1][1]` 分别映射到哪一 Cache 行？行号从 0 开始。
3. 假定数据 Cache 初始为空，两个程序的数组访问命中率各是多少？哪个更快？

<Solution>

### 参考答案

1. **$532\ \mathrm B$。** 物理地址 28 位，块内偏移 6 位，行索引 3 位，标记 19 位；每行 512 位数据、19 位标记、1 位有效位，所以 $(512+19+1)\times8/8=532\ \mathrm B$。
2. `a[0][31]` 的地址为十进制 $444$，块号 $6$，映射到**行 6**；`a[1][1]` 的地址为十进制 $1348$，块号 $21$，映射到**行 5**。
3. A：$4096$ 次缺失，$61440$ 次命中，**命中率 $93.75\%$**；B：每次数组访问均冲突缺失，**命中率 $0\%$**。在题目设定下**程序 A 更快**。

### 解题过程

<Steps>
  <Step>

  **步骤一：先拆地址字段，再算总容量。**

  $$
  256\ \mathrm{MB}=2^{28}\ \mathrm B,\quad64\ \mathrm B=2^6\ \mathrm B,\quad8=2^3.
  $$


  直接映射物理地址按从高到低分为

  $$
  \underbrace{\text{Tag}}_{28-3-6=19\text{ 位}}\mid
  \underbrace{\text{Index}}_{3\text{ 位}}\mid
  \underbrace{\text{Offset}}_{6\text{ 位}}.
  $$


  数据区容量仅 $8\times64=512\ \mathrm B$，**题目问总容量时还须算元数据**。按“每行 1 个有效位，不计其他控制位”，每行存储 $64\times8+19+1=532$ 位，全部共 $8\times532=4256$ 位，即 $532\ \mathrm B$。

  </Step>
  <Step>

  **步骤二：把 C 语言二维数组下标换成字节地址。**

  行优先存储、每行 256 个 4 B 整数，通式是

  $$
  \operatorname{addr}(a[i][j])=320+4(256i+j).
  $$


  Cache 行号不是数组行号，而是

  $$
  \operatorname{line}(a[i][j])=\left\lfloor\frac{\operatorname{addr}(a[i][j])}{64}\right\rfloor\bmod8.
  $$


  | 数组元素 | 字节地址（十进制） | 主存块号 $\lfloor\text{addr}/64\rfloor$ | Cache 行号 |
  | --- | ---: | ---: | ---: |
  | `a[0][31]` | $320+31\times4=444$ | $6$ | **6** |
  | `a[1][1]` | $320+(256+1)\times4=1348$ | $21$ | **5** |

  **易错校验：**$320$ 是**十进制**，而非 `0x320`；存储是按字节编址，所以数组下标必须乘 $4$。

  </Step>
  <Step>

  **步骤三：分析程序 A 的连续访问与时间局部性。**

  一个块能放 $64/4=16$ 个元素。数组从 $320=5\times64$ 的**块边界**开始，因此每 16 个连续 `int` 恰占一块。程序 A 的内层 `j` 变化是相邻 4 B，第一次触及每个块时缺失，余下 15 个元素都命中。

  $$
  N=256\times256=65536,\quad N_{\rm miss}=\frac{65536}{16}=4096.
  $$


  $$
  h_A=\frac{65536-4096}{65536}=\frac{15}{16}=\boxed{93.75\%}.
  $$


  尽管 Cache 只有 8 行，A 顺序处理每个块后**不再返回旧块**，所以容量很小不会破坏一个块内部的 15 次空间局部性命中。

  </Step>
  <Step>

  **步骤四：分析程序 B 的步长和相同索引冲突。**

  当 `j` 固定、`i` 增加 1 时：

  $$
  \Delta\operatorname{addr}=256\times4=1024\ \mathrm B=16\times64\ \mathrm B.
  $$


  相邻访问的主存块号相差 16，而 Cache 索引只有 8 行：

  $$
  \Delta\operatorname{line}=16\bmod8=0.
  $$


  因此某一列的所有 256 个元素都访问**相同 Cache 行号**，但来自不同主存块；一个块刚被加载就会在下一次访问时被替换。转到下一列时，虽然访问的是同一个主存块内的下一整数，但该块早在上一次列扫描期间被覆盖。故**所有 $65536$ 次数组读取均为缺失**：

  $$
  h_B=0.
  $$


  </Step>
</Steps>

### 关键结论对比

| 特征 | 程序 A | 程序 B |
| --- | --- | --- |
| 内层相邻访问的地址差 | $4\ \mathrm B$ | $1024\ \mathrm B$ |
| 连续访问能否共享同一 Cache 块 | 能，16 个整数一块 | 当前列不能 |
| 全部数组读取次数 | $65536$ | $65536$ |
| 缺失次数 | $4096$ | $65536$ |
| 命中率 | **$93.75\%$** | **$0\%$** |

程序二者的数组运算次数相同；若缺失需额外从主存取数，A 所花的访存代价显著更小。不能机械认为“列访问一定为零命中”——这里得到零命中，是**步长 16 块与 8 行直接映射发生完全冲突**的结果，必须写出这一证据。

<Callout type="info" title="一眼识别直接映射冲突">

设主存块号为 $b$、Cache 共 $L$ 行，则行号为 $b\bmod L$。两次访问若块号差为 $L$ 的倍数且不是同一块，则在直接映射下竞争同一行；若交替访问，两边都会遭遇冲突缺失。

</Callout>

</Solution>
</Question>

### 原创强化题 1｜列优先并非必定 0 命中：8 行与 9 行的对照

<Question
  id="408-co-large-2010-44-ext1"
  type="essay"
  tags="来源:原创强化训练, 科目:计算机组成原理, 章节:存储器层次结构, 考点:直接映射冲突, 考点:命中率, 难度:较难"
>

数据 Cache：**直接映射、8 行、64 B/行**，初始为空。整型为 4 B、数组首地址为 0，行优先存储。执行按列读取：

```c
for (int j = 0; j < 16; ++j)
    for (int i = 0; i < rows; ++i)
        use(b[i][j]);
```

1. 当 `b` 为 `int b[8][16]` 时，求 8 个主存块的映射行、首列缺失次数、总命中率。
2. 当 `b` 为 `int b[9][16]` 时，求全程缺失次数、命中率，并解释与上一问的突变。
3. 若只有第 9 行发生冲突，能否直接据此说“每列只有一次缺失”？指出该推理的遗漏。

<Solution>

### 参考答案

1. 数组每行 $16\times4=64\ \mathrm B$，第 $i$ 行属于主存块 $i$，映射 Cache 行 $i\bmod8$。8 行对应 8 个不同 Cache 行：**首列 8 次缺失，其后全部命中**，命中率 $120/128=93.75\%$。
2. 对 9 行，块 0 与块 8 均映射到 Cache 行 0。首列 **9 次缺失**；其后每列发生**两次**冲突缺失，合计 $9+15\times2=39$ 次。命中率 $(144-39)/144=\boxed{105/144\approx72.92\%}$。
3. 不能。访问次序为每列**先访问第 0 行，最后才访问第 8 行**；这两个块在每一列互相顶替，因此该列会产生两次缺失。

### 解题过程

<Steps>
  <Step>

  **先认清一个数组行恰好占一个主存块。** 不管 `rows=8` 或 `9`，所有 `b[i][j]` 以 `b[i][0]` 所在块为基准，每行的 16 个整数都在同一主存块中。列扫描改变的是**访问块的顺序**，不改变各行的块号。

  </Step>
  <Step>

  **8 行：全部块可同时常驻。** `i=0,...,7` 分别映射 0～7 号 Cache 行。首列完成加载后，没有任何后续访问会驱逐这 8 个块；其后 15 列的 $15\times8=120$ 次访问全部命中。

  </Step>
  <Step>

  **9 行：块 0 与块 8 对冲。** 第一列第 0 行装入块 0；同列最后第 8 行装入块 8，驱逐块 0。第二列首先访问块 0 时缺失并驱逐块 8；该列最后访问块 8 再次缺失。循环 15 个后续列，冲突始终重复，而中间块 1～7 始终常驻。

  </Step>
</Steps>

**结论：**按列访问是否低效，不只由“行优先存储”决定，也取决于**工作集能否同时驻留 Cache**及各块的**索引别名**。

</Solution>
</Question>

### 原创预测题 2｜改为两路组相联，真的能修好列扫描吗？

<Question
  id="408-co-large-2010-44-ext2"
  type="essay"
  tags="来源:原创预测题, 科目:计算机组成原理, 章节:存储器层次结构, 考点:组相联映射, 考点:Cache冲突, 难度:综合"
>

沿用 2010 真题：28 位物理地址、Cache 共 8 行、每行 $64\ \mathrm B$、数组 `a[256][256]`、首地址十进制 320。现将数据 Cache 改为 **2 路组相联**，共 4 组；每行需 1 个有效位，忽略其他控制位，初始为空。

1. 写出地址字段位宽，并计算总容量（含 Tag、有效位）。
2. `a[0][31]` 与 `a[1][1]` 分别映射到哪个组？二者会不会争抢同一组？
3. 仍运行原题的**程序 B（按列访问）**，两路组相联能否把命中率提高到非零？请用步长、组号及替换前复用机会说明，而不是仅凭“相联度变高”作判断。

<Solution>

### 参考答案

1. **4 组**，组索引 2 位、块内偏移 6 位、Tag $28-2-6=20$ 位。总容量 $8\times(512+20+1)/8=\boxed{533\ \mathrm B}$。
2. 两元素主存块号仍分别为 $6$ 与 $21$，组号为 $6\bmod4=2$ 与 $21\bmod4=1$，**属于不同组，不会互相挤占**。
3. **仍为 0 命中率。** 固定列扫描时连续访问的块号相差 16，组号差 $16\bmod4=0$；每个组只有 2 路，却要依次访问该列的 256 个**不同主存块**。等回到下一列再访问其中一个旧块时，它早已被后来的同组块替换。

### 计算过程与推广

- **字段变化：**总行数不变，数据位共 $512\ \mathrm B$；两路组相联把索引位从 3 降为 2，Tag 从 19 增至 20，因此总容量比原直接映射方案增加 $8$ 位，即 **$1\ \mathrm B$**。
- **单点映射：**`a[0][31]` 地址 444、块号 6，进入组 2；`a[1][1]` 地址 1348、块号 21，进入组 1。两路允许**同一组最多两个块共存**，不是任意两个块可以直接选到同一行。
- **整个访问序列：**程序 B 在某固定列依次读 256 行，对应主存块彼此不同，且组号都一样。处理到第三个块时已经超出该组两路容量；直到本列结束，同组还会经历大量不同块。下一列从第一行重新开始，首个块不在组中，仍缺失。即使使用常见 LRU/FIFO，后续访问也会依次淘汰上一列残留的块；这里沿相同顺序扫一遍长于容量的循环工作集，全部缺失。

<Callout type="warn" title="容量结论必须同时分析访问顺序">

组相联能缓解某些直接映射的**二块冲突**，但无法保证消除任意大步长或工作集远超组容量的冲突。本题仍有 256 个轮流争抢同一组的块，远超过 2 路。

</Callout>

</Solution>
</Question>

## 2011 年第 44 题

<Question
  id="408-co-large-2011-44"
  type="essay"
  tags="来源:2011考研408, 科目:计算机组成原理, 章节:存储器层次结构, 考点:地址转换, 考点:TLB与Cache, 难度:综合"
>

某计算机按字节编址，**虚拟地址空间 16 MB**、**物理地址空间 1 MB**、**页大小 4 KB**。物理地址访问的 Cache 采用直接映射，共 8 行，每行 32 B。当前页表、Cache 内容如图。

<img src="/img/408/past-exams-large-questions/02-计算机组成原理/assets/2011-44-figure-001.svg" alt="2011 年第 44 题页表和 Cache 当前条目" />

1. 虚拟地址、物理地址各是多少位？虚页号、物理页框号分别位于哪些地址位？
2. 访问物理地址时，Cache 的 Tag、行号与块内偏移各占多少位、位于哪些地址位？
3. 虚拟地址 `001C60H` 所在页面是否在主存？若在，物理地址为何？访问 Cache 是否命中？
4. 若配置 **4 路组相联 TLB，共 8 项**，其当前内容如下图，判断虚拟地址 `024BACH` 所在页面是否在主存，并说明理由。

<img src="/img/408/past-exams-large-questions/02-计算机组成原理/assets/2011-44-figure-002.svg" alt="2011 年第 44 题四路组相联 TLB 当前内容" />

<Solution>

### 参考答案

1. 虚拟地址为 **24 位**，VPN（虚页号）在 `VA[23:12]`，共 12 位；物理地址为 **20 位**，PPN（页框号）在 `PA[19:12]`，共 8 位；两者低 12 位都是页内偏移。
2. 物理地址 Cache 字段：**Tag=`PA[19:8]`（12 位）｜行号=`PA[7:5]`（3 位）｜块内偏移=`PA[4:0]`（5 位）**。
3. `001C60H` 的 VPN 为 `001H`，根据题图，页表有效，页框号为 `04H`，所以物理地址为 **`04C60H`**；Cache 行号为 **3**、Tag 为 **`04CH`**。题图该行 Tag 为 `105H`，不匹配，故 **Cache 未命中，但不是缺页**。
4. TLB 共有 **2 组**。`024BACH` 的 VPN 为 `024H`，组号 $0$、TLB Tag 为 `012H`；题图第 0 组存在有效的匹配项，页框号为 `1FH`，故**TLB 命中，页面在主存**。

### 解题过程

<Steps>
  <Step>

  **步骤一：固定页内偏移，再计算虚实地址宽度。**

  $$
  16\ \mathrm{MB}=2^{24}\ \mathrm B,\quad1\ \mathrm{MB}=2^{20}\ \mathrm B,\quad4\ \mathrm{KB}=2^{12}\ \mathrm B.
  $$


  因此无论虚拟地址还是物理地址，**低 12 位页内偏移原封不动地保留**。只将高位的 VPN 翻译成 PPN。

  | 项目 | 虚拟地址 VA | 物理地址 PA |
  | --- | --- | --- |
  | 地址总位宽 | 24 | 20 |
  | 页号/页框号 | `[23:12]`，12 位 | `[19:12]`，8 位 |
  | 页内偏移 | `[11:0]`，12 位 | `[11:0]`，12 位 |

  一页覆盖 $4096$ 个字节；**4 KB 页大小与 32 B Cache 块大小不同**，不要用 Cache 块大小来划分页号。

  </Step>
  <Step>

  **步骤二：Cache 分字段用物理地址，而不是 VA。**

  $$
  \text{Offset}=\log_2 32=5\text{ 位},\quad
  \text{Index}=\log_2 8=3\text{ 位},
  $$


  $$
  \text{Tag}=20-5-3=12\text{ 位}.
  $$


  对某个物理地址 `PA`，可直接写成位运算：

  ```c
  unsigned offset = PA & 0x1F;       // PA[4:0]
  unsigned index  = (PA >> 5) & 7;  // PA[7:5]
  unsigned tag    = PA >> 8;        // PA[19:8]
  ```

  Cache 直接映射的**命中**需要同时满足：`valid[index]==1` 且存储的 Tag 与 `tag` 相等；查到某一行不代表必然命中。

  </Step>
  <Step>

  **步骤三：翻译 `001C60H` 并与题图 Cache 条目比对。**

  由于页内偏移是 3 个十六进制位：

  $$
  \texttt{001C60H}=\underbrace{\texttt{001H}}_{VPN}
    \mid\underbrace{\texttt{C60H}}_{\text{页内偏移}}.
    $$


  由题图页表，VPN=`001H` 对应页框 `04H`，存在位有效：

  $$
  \text{PA}=(\texttt{04H}\ll12)\;\vert\;\texttt{C60H}=\boxed{\texttt{04C60H}}.
  $$


  继续拆 Cache：

  $$
  \text{Tag}=\texttt{04C60H}\gg8=\texttt{04CH},
  $$


  $$
  \text{Index}=(\texttt{04C60H}\gg5)\mathbin{\&}7=3,
  \qquad\text{Offset}=\texttt{04C60H}\mathbin{\&}\texttt{1FH}=0.
  $$


  题图 **第 3 行有效，但 Tag 为 `105H`**，与查询的 `04CH` 不同。因此发生的是**Cache 缺失**，可以从对应物理主存块调入；该虚页已驻留，**没有缺页**。

  </Step>
  <Step>

  **步骤四：另用 VPN 来拆 TLB 的组号与标记。**

  四路组相联 TLB 一共存 8 项，所以只有 $8/4=2$ 组；组索引 1 位，TLB Tag 为 VPN 其余 11 位：

  $$
  \text{TLB 组号}=VPN\bmod2,\qquad\text{TLB Tag}=VPN\gg1.
  $$


  `024BACH` 的数值是 `0x024BAC`，不是末尾包含一个十六进制数字 `H`；它的 VPN=`024H`，偏移=`BACH`：

  $$
  \text{组号}=\texttt{024H}\bmod2=0,
  \qquad\text{Tag}=\texttt{024H}\gg1=\texttt{012H}.
  $$


  题图第 0 组存在有效的匹配 Tag `012H`，记录的页框号为 `1FH`。这证明**地址翻译命中 TLB**，页面**在物理主存中**。若还要进一步访问数据，则仍需使用所得物理地址单独查 Cache。

  </Step>
</Steps>

### 三类“未命中”不得混为一谈

| 事件 | 核心检查对象 | 是否直接意味着页面不在主存？ | 后续常见处理 |
| --- | --- | --- | --- |
| TLB miss | VPN 对应的 TLB 项 | **否** | 查页表，必要时装入 TLB |
| Cache miss | 物理块的 Cache 行和 Tag | **否** | 从物理主存取块并装入 Cache |
| Page fault（缺页） | 页表项的存在/有效状态及访问合法性 | **可能** | 转入操作系统异常处理；按原因处理缺页或保护错误 |

<Callout type="warn" title="计数与层次关系">

虚拟地址先通过 TLB/页表获取物理页框号，页内偏移保留；采用物理地址访问的 Cache 再由物理地址定位数据块。**TLB 命中不保证 Cache 命中，Cache 未命中也不必然触发缺页异常。**

</Callout>

</Solution>
</Question>

### 原创强化题 1｜一笔访问，完成 TLB—页表—Cache 全链条计算

<Question
  id="408-co-large-2011-44-ext1"
  type="essay"
  tags="来源:原创强化训练, 科目:计算机组成原理, 章节:存储器层次结构, 考点:TLB组相联, 考点:物理Cache, 难度:综合"
>

沿用原题：24 位 VA、20 位 PA、4 KB 页、8 行直接映射 Cache（每行 32 B）、4 路组相联 8 项 TLB。

现在额外给定：VPN=`002H` 所在页**已驻留**在页框 `7FH`；TLB 第 0 组中有一条有效项，TLB Tag=`001H`、PPN=`7FH`；Cache 第 5 行有效，Cache Tag=`7F3H`。

1. 对虚拟地址 `0023A5H`，计算 VPN、页内偏移、TLB 组号与 Tag，并判断 TLB 是否命中。
2. 写出对应物理地址、Cache 行号、Tag 与块内偏移，判断 Cache 是否命中。
3. 仅将 Cache 第 5 行的 Tag 改为 `7F2H`，其余状态不变。解释 TLB 命中、Cache 命中与页面驻留性各发生了什么变化。

<Solution>

### 参考答案

1. VPN=`002H`，页内偏移=`3A5H`；TLB 第 **0** 组、Tag=`001H`，**命中**。
2. PA=`7F3A5H`；Cache **行 5**、Tag=`7F3H`、偏移=`05H`，**命中**。
3. 修改后 **TLB 仍命中、页面仍在主存，只是 Cache 由于 Tag 不一致而未命中**。

### 地址拆分计算

<Steps>
  <Step>

  先按照 4 KB 页的 12 位偏移分解虚拟地址：

  $$
  \texttt{0023A5H}=\underbrace{\texttt{002H}}_{VPN}\mid
  \underbrace{\texttt{3A5H}}_{\text{偏移}}.
  $$


  组号为 `0x002 & 1 = 0`；TLB Tag 为 `0x002 >> 1 = 0x001`。这正是给出的第 0 组有效项。

  </Step>
  <Step>

  页框替换页号，页内偏移不变：

  $$
  PA=(\texttt{7FH}\ll12)\mid\texttt{3A5H}=\texttt{7F3A5H}.
  $$


  随后 `PA >> 8 = 0x7F3`，`(PA >> 5) & 7 = 5`，`PA & 31 = 5`。Cache 第 5 行有效且 Tag=`7F3H`，两条件同时成立，数据 Cache 命中。

  </Step>
  <Step>

  修改行 Tag 为 `7F2H` 并未修改页表、TLB 或虚实映射，所以不能推导出缺页。它只改变该 Cache 行中被缓存的**物理主存块的身份**；再次访问时不匹配，须从已驻留物理主存获取需要的块。

  </Step>
</Steps>

**计算链条口诀：**`VA → VPN/offset → TLB/页表 → PPN/offset → PA → Cache index/tag/offset`。不要在“得到 PPN”后误把它直接当成 Tag。

</Solution>
</Question>

### 原创预测题 2｜一次 4 字节读跨越两个虚拟页

<Question
  id="408-co-large-2011-44-ext2"
  type="essay"
  tags="来源:原创预测题, 科目:计算机组成原理, 章节:存储器层次结构, 考点:跨页访存, 考点:缺页异常, 难度:拔高"
>

分页系统同原题，页大小 4 KB。CPU 发出一条指令，读取从**虚拟地址 `003FFEH` 起始的连续 4 个字节**。已知 VPN=`003H` 对应 PPN=`2AH`，VPN=`004H` 对应 PPN=`7BH`，两页均存在且可读。

1. 列出四个字节各自的虚拟地址与物理地址；它们在物理主存中是否一定连续？
2. 需要涉及多少个不同 VPN？即使首个 VPN 的 TLB 已命中，第二个 VPN 是否还能免于翻译？
3. 若把 VPN=`004H` 的页表存在位改为 0，导致尚未驻留，发生什么？它与普通 Cache miss 有何区别？若异常处理后补入该页，能否只用第一个页的 PPN 推出后两个字节的地址？

<Solution>

### 参考答案

| 字节序号 | VA | VPN | PPN | PA |
| --- | --- | --- | --- | --- |
| 0 | `003FFEH` | `003H` | `2AH` | `2AFFEH` |
| 1 | `003FFFH` | `003H` | `2AH` | `2AFFFH` |
| 2 | `004000H` | `004H` | `7BH` | `7B000H` |
| 3 | `004001H` | `004H` | `7BH` | `7B001H` |

共跨越 **2 个虚拟页**，需要对两个 VPN 分别建立有效翻译；物理页框不必相邻，因此这四个物理地址**不连续**。若第二页尚未驻留，会触发**缺页异常**，需要由操作系统使该页获得有效映射后才能完成访问；这不是只从已有物理主存块装入 Cache 就能解决的事。

### 解题过程

<Steps>
  <Step>

  一个页面大小为 `1000H` B，VPN=`003H` 的末尾两个字节是 `003FFEH、003FFFH`，下一个字节正好转到 VPN=`004H` 的起始地址 `004000H`。原来连续的逻辑读被拆在两个页框内。

  </Step>
  <Step>

  翻译时只替换高位页号：

  $$
  \text{PA}=(PPN\ll12)\mid(\text{VA}\mathbin{\&}\texttt{FFFH}).
  $$


  前两字节得到 `2AFFEH、2AFFFH`，后两字节得到 `7B000H、7B001H`。不能仅给第一字节算一次 PA，然后连续加 1 得到全部四个物理地址。

  </Step>
  <Step>

  若第二页页表项表明尚未驻留，指令执行中必须转入相应缺页处理；在支持恢复该缺页的系统中，操作系统装入或分配该页并更新相关映射后才能重试/继续。第一个页框号 `2AH` 无法决定第二页将获得哪个页框。

  </Step>
</Steps>

### 考点延伸：是否一定要两次查 TLB？

访问涉及两个**不同 VPN**，就必须得到各自有效的地址转换结果。实际 CPU 可能为两个页分别命中 TLB，也可能对其中一个发生 TLB miss；不能把“两个页”直接等同于“发生两次 TLB miss”，更不能把 TLB miss 当成缺页。

<Callout type="info" title="为什么跨页场景值得练习？">

跨页读写会同时考查页内偏移保留、物理页框不连续、TLB 项粒度和精确异常处理。只记住 `PA=页框+偏移` 的口令，却不检查地址是否越过页面边界，很容易把后半部分错误地映射到前一个页框。

</Callout>

</Solution>
</Question>

## 2012 年第 43 题

<Question
  id="408-co-large-2012-43"
  type="essay"
  tags="来源:2012考研408, 科目:计算机组成原理, 章节:存储器层次结构, 考点:Cache带宽, 考点:DMA与交叉存储, 难度:综合"
>

某计算机的 CPU 主频为 **80 MHz**，CPI 为 **4**，平均每条指令访存 **1.5 次**，Cache 命中率为 **99%**。主存与 Cache 交换的块大小为 **16 B**，存储器数据总线宽度为 **32 位**。

1. 求 MIPS 数、平均每秒 Cache 缺失次数，以及**忽略 DMA 传送**时满足 CPU 访存所需的最低主存带宽。
2. 假定 Cache 缺失后访问主存时的**条件缺页率为 $0.0005\%$**。若页面大小为 4 KB，每次缺页均需访问磁盘，DMA 使用**周期挪用**方式，磁盘 I/O 接口的数据缓冲寄存器宽 32 位，求每秒平均缺页次数与至少需要的 DMA 总线请求次数。
3. CPU 与 DMA 同时请求存储器总线时，通常谁优先？说明原因。
4. 主存采用**四体低位交叉存储**，相邻存储体可按 $1/4$ 个存储周期的间隔启动，每体存储周期 50 ns，求主存理论最大带宽。

<Solution>

### 参考答案

| 问题 | 结果 |
| --- | --- |
| 指令吞吐率 | $20\ \mathrm{MIPS}$ |
| Cache 缺失次数 | $3.0\times10^5$ 次/s |
| 最低主存读入带宽 | $4.8\times10^6\ \mathrm{B/s}=4.8\ \mathrm{MB/s}$ |
| 缺页次数 | $1.5$ 次/s（长期平均值） |
| DMA 总线请求次数 | $1536$ 次/s |
| 周期挪用的通常优先级 | **DMA 优先**，避免外设缓冲区溢出；CPU 暂停一个存储器访问周期 |
| 四体低位交叉存储最大带宽 | $320\ \mathrm{MB/s}$ |

以上带宽均采用 $1\ \mathrm{MB}=10^6\ \mathrm B$；最低主存带宽只计算 **Cache 缺失时把数据块读入 Cache** 的流量，不另计写回、预取、页表访问等开销。

### 解题过程

<Steps>
  <Step>

  **步骤一：建立「指令 → 访存 → Cache 缺失 → 主存数据量」计算链。**

  一秒内 CPU 提供 $80\times10^6$ 个时钟周期，平均每条指令消耗 4 个周期，所以

  $$
  R_{\mathrm{inst}}=\frac{80\times10^6}{4}
  =20\times10^6\ \mathrm{inst/s}=20\ \mathrm{MIPS}.
  $$

  每条指令平均访存 $1.5$ 次：

  $$
  R_{\mathrm{mem}}=20\times10^6\times1.5=3.0\times10^7\ \mathrm{access/s}.
  $$

  Cache 缺失率是 $1-99\%=1\%$：

  $$
  R_{\mathrm{miss}}=3.0\times10^7\times0.01
  =3.0\times10^5\ \mathrm{miss/s}.
  $$

  一次缺失需要读入**整个** 16B 块，故

  $$
  B_{\mathrm{min}}=3.0\times10^5\times16
  =4.8\times10^6\ \mathrm{B/s}.
  $$

  **32 位总线并没有把「一次缺失读入 16B」改为 4B。** 它只说明每次总线数据传送为 4B，装入一个块至少需要 $16/4=4$ 次传送。

  </Step>
  <Step>

  **步骤二：把条件缺页率严格换算为概率。**

  本题的 $0.0005\%$ 是「发生 Cache 缺失之后，访问主存时又触发缺页」的比例：

  $$
  p_{\mathrm{fault}\mid\mathrm{miss}}
  =\frac{0.0005}{100}=5\times10^{-6}.
  $$

  因而平均每秒缺页数为

  $$
  R_{\mathrm{fault}}
  =R_{\mathrm{miss}}p_{\mathrm{fault}\mid\mathrm{miss}}
  =3.0\times10^5\times5\times10^{-6}
  =\boxed{1.5\ \mathrm{次/s}}.
  $$

  结果是长期平均速率，**不是说一秒中实际能发生半次异常**。若把 $0.0005\%$ 误读成 $0.0005$，就会把答案放大 100 倍。

  </Step>
  <Step>

  **步骤三：从一次换页的字节数推导 DMA 请求次数。**

  一页为 $4\ \mathrm{KB}=4096\ \mathrm B$，接口的数据缓冲寄存器为 32 位，即每次向主存传送 $4\ \mathrm B$。

  $$
  N_{\mathrm{DMA/page}}=\frac{4096}{4}=1024.
  $$

  因此平均请求率为

  $$
  R_{\mathrm{DMA}}=1.5\times1024
  =\boxed{1536\ \mathrm{requests/s}}.
  $$

  这是题设**每次 DMA 请求搬运一个缓冲寄存器字**的计数口径；不是说发生了 1536 次磁盘缺页，也不是每请求搬一整个 4KB 页面。

  </Step>
  <Step>

  **步骤四：周期挪用时为什么通常让 DMA 优先？**

  周期挪用 DMA 需要占用一个存储器访问周期，把外设接口的数据送入主存或反向传送。外设若长时间无法清空有限的缓冲区，后续数据可能丢失；CPU 的普通访存通常可以被暂停。故传统总线仲裁中，DMA 与 CPU 同时请求时一般给 DMA 较高优先级。

  这里的 **「优先」并非 DMA 永久占据总线**：一次挪用结束后，CPU 仍可继续访存。也不要把周期挪用与「停止 CPU 访存、成组传送」混为一谈。

  </Step>
  <Step>

  **步骤五：计算四体低位交叉存储的稳态吞吐量。**

  每体从一次访问开始到同一体可再次启动的周期为 $50\ \mathrm{ns}$。四体轮流启动时，稳态相邻字启动间隔最短为

  $$
  \Delta t=\frac{50\ \mathrm{ns}}{4}=12.5\ \mathrm{ns}.
  $$

  每次向存储器总线提供 $32\ \mathrm{bit}=4\ \mathrm B$，所以

  $$
  B_{\max}=\frac{4\ \mathrm B}{12.5\times10^{-9}\ \mathrm s}
  =\boxed{320\times10^6\ \mathrm{B/s}}.
  $$

  此处的 $320\ \mathrm{MB/s}$ 是**连续顺序访问且总线不会另行限速**时的理论峰值；$50\ \mathrm{ns}$ 是同一存储体的恢复周期，不能把它错误地用作交叉存储中每次连续取字的间隔。

  </Step>
</Steps>

### 一眼识别三种不同的「率」

| 比率 | 分子/分母的样本空间 | 本题数值 |
| --- | --- | --- |
| Cache 缺失率 | 缺失访存 / 全部访存 | $0.01$ |
| 条件缺页率 | 缺页 / Cache 缺失引起的主存访问 | $5\times10^{-6}$ |
| DMA 每页请求数 | 页面字节数 / 每次 DMA 数据字节数 | $1024$ 次/页 |

<Callout type="warn" title="本题最容易错的两个单位">

$0.0005\%$ 要再除以 $100$；$4\ \mathrm{KB}$ 按本题页大小是 $4096\ \mathrm B$。同时，**总线字宽**与 **Cache 块长**属于两个不同量，不能交换使用。

</Callout>

</Solution>
</Question>

### 原创强化训练 1：访存瓶颈、有效带宽与条件缺页

<Question
  id="408-co-large-2012-43-ext1"
  type="essay"
  tags="来源:原创强化训练, 科目:计算机组成原理, 章节:存储器层次结构, 考点:访存带宽, 考点:条件概率, 难度:提高"
>

一台计算机 CPU 主频 $120\ \mathrm{MHz}$、CPI 为 3，平均每条指令有 2 次数据 Cache 访问，Cache 缺失率 2%，每次缺失需要从主存装入 32 B。主存数据总线为 64 位、时钟频率 $100\ \mathrm{MHz}$。除正常装块外，每次发生缺失都要替换一行，其中 **25% 的被替换行是脏块**，写回时也传送完整 32 B。假定指令执行速度、缺失率和上述写回比例已经给定，不考虑其他总线业务。

1. 求指令吞吐率、Cache 缺失率对应的每秒缺失次数。
2. 计算主存需要承受的**读入带宽、写回带宽和总数据带宽**。数据总线每拍能传多少字节？完成一次 32B 搬块至少需要多少个数据拍？
3. 理想总线峰值带宽是否足以提供上述总数据量？能否仅据此断定 CPU **不会发生 Cache 缺失停顿**？
4. 若仅对 Cache 缺失后的主存访问统计，缺页率为 $0.001\%$，求每秒平均缺页次数。

<Solution>

### 参考答案

1. $40\ \mathrm{MIPS}$，$1.6\times10^6$ 次 Cache 缺失/s。
2. 读入 **$51.2\ \mathrm{MB/s}$**，脏块写回 **$12.8\ \mathrm{MB/s}$**，总计 **$64\ \mathrm{MB/s}$**；每拍 **8B**，每 32B 块至少 **4 个数据拍**。
3. 峰值 **$800\ \mathrm{MB/s}$**，在平均吞吐上足够，**但不能**推出缺失停顿为零。
4. 平均 **$16$ 次缺页/s**。

### 解题过程

<Steps>
  <Step>

  **从基本吞吐率算出缺失事件率。**

  $$
  R_{\mathrm{inst}}=\frac{120}{3}=40\ \mathrm{MIPS},\quad
  R_{\mathrm{miss}}=40\times10^6\times2\times0.02
  =1.6\times10^6\ \mathrm{/s}.
  $$

  </Step>
  <Step>

  **每一次缺失可能含两种主存流量。**

  读入流量 $=1.6\times10^6\times32=51.2\ \mathrm{MB/s}$。

  按题设每次都要替换一行，其中四分之一需要写回：

  $$
  B_{\mathrm{writeback}}
  =1.6\times10^6\times0.25\times32
  =12.8\ \mathrm{MB/s}.
  $$

  两者相加：$B_{\mathrm{total}}=64\ \mathrm{MB/s}$。原真题的「最低读带宽」没有给出脏块比例，不能擅自把写回计入；**本题**明确给出了，因此必须额外计算。

  </Step>
  <Step>

  **区分吞吐能力和单次延迟。**

  总线每拍 8B、每秒 $10^8$ 拍，因此峰值 $800\ \mathrm{MB/s}$；一块 32B 至少占 4 个数据拍。可见 $64<800$，但总线还有仲裁、地址、等待与争用，单次 Cache 未命中也可能需等待许多拍，造成 CPU 停顿。平均带宽足够只是**必要的吞吐检查**，不是「零延迟」保证。

  </Step>
  <Step>

  **条件缺页率仅乘缺失次数。**

  $$
  0.001\%=10^{-5},\qquad1.6\times10^6\times10^{-5}=16\ \mathrm{次/s}.
  $$


  </Step>
</Steps>

<Callout type="info" title="可迁移的考试方法">

题目若出现脏块写回，应将「缺失导致的块读入」和「替换导致的块写出」分账计算；若出现「在 Cache 缺失的条件下……」，概率必须沿条件事件链逐层相乘。

</Callout>

</Solution>

### 原创强化训练 2：交叉主存与数据总线的双重瓶颈

<Question
  id="408-co-large-2012-43-ext2"
  type="essay"
  tags="来源:原创强化训练, 科目:计算机组成原理, 章节:存储器层次结构, 考点:多体交叉, 考点:总线瓶颈, 难度:提高"
>

一台主存由 **8 个低位交叉存储体**构成；每个存储体每次提供 8 B，存储周期为 $80\ \mathrm{ns}$。主存数据总线每次恰能传输 8 B，但两次总线数据传送的最短间隔为 $15\ \mathrm{ns}$。不计地址阶段和首次数据准备延迟的额外开销。

1. 不考虑总线限制时，连续顺序读取的最短发起间隔、最大数据吞吐率分别是多少？
2. 考虑总线限制，持续顺序访问的理论带宽上限是多少？指出真正的瓶颈。
3. 若访问地址连续且每次读一个 8 B 字，从空闲状态连续访问 **10 个字**，每个存储体的访问启动间隔是否满足 $80\ \mathrm{ns}$ 的约束？
4. 若不是顺序访问，而是始终访问**同一个存储体**，在不考虑其他开销时可达到的最大稳态带宽是多少？

<Solution>

### 参考答案

1. 间隔 **$10\ \mathrm{ns}$**，银行端峰值 **$800\ \mathrm{MB/s}$**。
2. 总线限制为 $8/15\ \mathrm{ns}\approx\mathbf{533.33\ \mathrm{MB/s}}$，**总线**是瓶颈。
3. 可以。相邻访问可按不小于 $15\ \mathrm{ns}$ 间隔发起，访问同一体的两次启动至少间隔 $8\times15=120\ \mathrm{ns}\ge80\ \mathrm{ns}$。
4. 同体每 $80\ \mathrm{ns}$ 至多接受一次访问，最大 **$100\ \mathrm{MB/s}$**。

### 解题过程

<Steps>
  <Step>

  **由存储体恢复周期推导交叉的理论流水节拍。**

  若按体号 $0,1,\dots,7$ 轮流访问，八次轮换后同一体才再次使用，所以

  $$
  \Delta t_{\mathrm{bank}}=\frac{80}{8}=10\ \mathrm{ns},\quad
  B_{\mathrm{bank}}=\frac{8}{10\times10^{-9}}=800\ \mathrm{MB/s}.
  $$


  </Step>
  <Step>

  **总线和存储体两个约束要同时满足。**

  总线要求相邻数据传送间隔不小于 $15\ \mathrm{ns}$，于是实际稳态间隔至少为

  $$
  \Delta t=\max(10,15)=15\ \mathrm{ns}.
  $$


  对连续顺序流，理想可实现的上限为

  $$
  B=\min(800,8/15\mathrm{ns})\ \mathrm{MB/s}
  =\frac{8}{15\times10^{-9}}\approx533.33\ \mathrm{MB/s}.
  $$


  </Step>
  <Step>

  **核验存储体有没有过早被再次访问。**

  第 1、9 个连续字访问同一体，中间经历 8 个最短数据节拍，间隔 $8\times15=120\ \mathrm{ns}$，超过该体的 $80\ \mathrm{ns}$ 恢复周期。因此连续读 10 字在稳态节拍安排上**无需因体冲突额外降速**。这不代表首字延迟为零；题目已要求不另计首字准备开销。

  </Step>
  <Step>

  **考察访存地址分布。**

  所有请求都落在同一存储体时，其他七体即使空闲也不能缩短该体的 $80\ \mathrm{ns}$ 周期，因而 $8/80\ \mathrm{ns}=100\ \mathrm{MB/s}$，并小于总线带宽上限。

  </Step>
</Steps>

<Callout type="warn" title="并行存储体不会无条件把带宽乘以 8">

总线较慢时被总线限制；连续访问若集中在同一体，又会被该存储体自身恢复周期限制。先判断**访问如何映射到体**，再看两种速率上限。

</Callout>

</Solution>
</Question>

## 2013 年第 43 题

<Question
  id="408-co-large-2013-43"
  type="essay"
  tags="来源:2013考研408, 科目:计算机组成原理, 章节:存储器层次结构, 考点:突发传送, 考点:缺失惩罚与CPI, 难度:综合"
>

某 32 位计算机 CPU 主频为 **800 MHz**，Cache 命中条件下 CPI 为 **4**。Cache 块长 32 B；主存由 **8 个低位交叉存储体**组成，每体字长 32 位、存储周期 40 ns；存储器总线数据宽度 **32 位**，总线频率 **200 MHz**，支持突发传送。

一次读突发事务依次经历：**（甲）发送首地址与命令；（乙）主存准备首字数据；（丙）连续发送数据。** 发送一个地址或一个 32 位数据均需 1 个总线时钟周期，三阶段按题设依次完成；每次突发事务传输 **32 B**。

1. 求 CPU 时钟周期、总线时钟周期和总线理想最大数据传输率。
2. 一次 Cache 缺失要读入一个块，需要几次读突发事务？
3. 计算一次读突发事务的总用时。
4. 程序 BP 执行 **100 条指令**，平均每条指令访存 **1.2 次**，Cache 缺失率 **5%**。忽略题目未列出的其他开销，求 BP 的 CPU 执行时间。

<Solution>

### 参考答案

1. CPU 周期 **$1.25\ \mathrm{ns}$**；总线周期 **$5\ \mathrm{ns}$**；理想最大数据传输率 **$800\ \mathrm{MB/s}$**。
2. 每次 Cache 缺失只需 **1 次**读突发事务；该事务内部要传送 **8 个 32 位字**。
3. 一次事务总计 **$5+40+8\times5=85\ \mathrm{ns}$**。
4. 基本执行时间为 $500\ \mathrm{ns}$，平均 6 次缺失造成 $510\ \mathrm{ns}$ 停顿，合计 **$1010\ \mathrm{ns}$**（即 $1.01\ \mathrm{\mu s}$）。

### 解题过程

<Steps>
  <Step>

  **步骤一：频率转换为时钟周期，并单独算总线峰值。**

  $$
  T_{\mathrm{CPU}}=\frac1{800\times10^6}=1.25\ \mathrm{ns},\qquad
  T_{\mathrm{bus}}=\frac1{200\times10^6}=5\ \mathrm{ns}.
  $$

  数据总线宽 32 位 $=4\ \mathrm B$，峰值传输率仅由**数据阶段满负荷连续传送**决定：

  $$
  B_{\max}=4\ \mathrm B\times200\times10^6\ \mathrm{/s}
  =800\ \mathrm{MB/s}.
  $$

  这是总线理论数据拍峰值，并未扣除发地址和主存等待的开销。

  </Step>
  <Step>

  **步骤二：先区分「一次事务」和「事务内的数据拍」。**

  由于 Cache 块长为 $32\ \mathrm B$、一次突发事务也完整传 $32\ \mathrm B$，所以每次缺失只需 1 次读突发事务。

  但是一条 32 位总线一拍仅传 $4\ \mathrm B$，故该事务的数据阶段需要

  $$
  N_{\mathrm{beat}}=\frac{32}{4}=8\ \text{个总线数据拍}.
  $$


  答 8 **次事务**或答 1 **个数据拍**，都属于量纲错误。

  </Step>
  <Step>

  **步骤三：分阶段推导 $85\ \mathrm{ns}$，不可凭峰值带宽反算事务延迟。**

  | 事务阶段 | 含义 | 时间 |
  | --- | --- | ---: |
  | 甲 | 首地址与命令，占 1 个总线周期 | $5\ \mathrm{ns}$ |
  | 乙 | 访问主存，等待首个 32 位字准备好 | $40\ \mathrm{ns}$ |
  | 丙 | 传出 32 B，共 8 个数据拍 | $8\times5=40\ \mathrm{ns}$ |
  | **合计** | 三阶段按本题约定不重叠 | **$85\ \mathrm{ns}$** |

  为什么 8 体交叉有用？每体存储周期是 40ns，但依次访问体 $0$ 至体 $7$ 时，相邻体可每 $40/8=5\ \mathrm{ns}$ 启动一次。因此主存足以**匹配总线每 5ns 一个字**的节拍；交叉技术缩短的是连续发起间隔，**不是将首字访问延迟 40ns 缩为 5ns**。

  <Callout type="info" title="为什么不是 80 ns 或 45 ns？">

  首字准备完成后仍须通过总线送出全部 8 个字，其中**第一个字的总线发送也占一个周期**。按题设阶段模型，不能漏算第一拍，也不能把已经明确分开的「首字准备」和「数据传送」擅自重叠。

  </Callout>

  </Step>
  <Step>

  **步骤四：计算命中条件下的基础运行时间。**

  $$
  T_{\mathrm{base}}=N_{\mathrm{inst}}\times\mathrm{CPI}_{\mathrm{hit}}\times T_{\mathrm{CPU}}
  =100\times4\times1.25=500\ \mathrm{ns}.
  $$

  「命中时 CPI=4」就是不含额外 Cache 缺失停顿的基准，否则追加缺失惩罚会重复计算。

  </Step>
  <Step>

  **步骤五：算期望缺失事件数，再算总停顿。**

  总访存次数的期望为 $100\times1.2=120$，故平均缺失次数

  $$
  N_{\mathrm{miss}}=120\times0.05=6.
  $$


  每次缺失造成一段 $85\ \mathrm{ns}$ 的主存读块延迟，停顿时间 $6\times85=510\ \mathrm{ns}$。所以

  $$
  \boxed{T_{\mathrm{BP}}=500+510=1010\ \mathrm{ns}}.
  $$

  整个计算以题目的**平均访存次数与命中率**作期望估算，不必硬凑实际某一轮具体哪些指令缺失。

  </Step>
</Steps>

### 另一种验算：从有效 CPI 入手

<Callout type="info" title="把缺失延迟换成 CPU 周期验证">

一次缺失相当于 $85/1.25=68$ 个 CPU 周期，平均每条指令 Cache 缺失数为 $1.2\times0.05=0.06$。因此

$$
\mathrm{CPI}_{\mathrm{eff}}=4+0.06\times68=8.08,
$$

总执行时间 $=100\times8.08\times1.25\ \mathrm{ns}=1010\ \mathrm{ns}$，与逐项相加完全一致。

</Callout>

### 重要区分：吞吐与延迟

- **总线峰值 $800\ \mathrm{MB/s}$**：连续数据拍理想情况下，每秒能传多少数据。
- **一次事务 $85\ \mathrm{ns}$**：这 32B 数据从发请求到送完，需要经过地址、等待、传输三个阶段的总时间。
- **有效 CPI $8.08$**：程序计算时间与平均 Cache 停顿共同产生的整体性能指标。

</Solution>
</Question>

### 原创强化训练 1：突发长度、有效带宽与事务启动次数

<Question
  id="408-co-large-2013-43-ext1"
  type="essay"
  tags="来源:原创强化训练, 科目:计算机组成原理, 章节:存储器层次结构, 考点:总线事务时序, 考点:有效带宽, 难度:提高"
>

某计算机总线时钟频率为 **250 MHz**，数据线宽 **64 位**。每次读突发事务固定传送 **64 B**，其三个阶段不可重叠：发首地址用 1 个总线周期、主存准备数据需 $32\ \mathrm{ns}$、每个总线周期传送 1 个 64 位数据字。

1. 求总线周期和仅计算数据拍时的理想峰值带宽。
2. 求一次 64B 事务的**总延迟**和按完整事务计的**有效数据带宽**。
3. 若 Cache 块长改为 **128B**，每次事务仍只能传 64B，且两个读事务不能重叠，则装入一块至少需要几次事务、多长时间？
4. 若有同学直接用 $128\mathrm B/(2000\mathrm{MB/s})$ 计算第 3 问时间，指出错误所在。

<Solution>

### 参考答案

1. **$4\ \mathrm{ns}$**；峰值 **$2000\ \mathrm{MB/s}$**。
2. 一次事务 **$68\ \mathrm{ns}$**；有效带宽约 **$941.18\ \mathrm{MB/s}$**。
3. **2 次事务、$136\ \mathrm{ns}$**。
4. $2000\ \mathrm{MB/s}$ 只计算理想连续数据拍，遗漏每次事务重复发生的地址阶段和 32ns 首字等待。

### 解题过程

<Steps>
  <Step>

  **总线频率与字宽共同决定数据拍吞吐。**

  $$
  T_{\mathrm{bus}}=1/(250\mathrm{MHz})=4\mathrm{ns},\qquad
  B_{\mathrm{peak}}=8\mathrm B/4\mathrm{ns}=2000\mathrm{MB/s}.
  $$


  </Step>
  <Step>

  **把一次突发事务拆成真实耗时。**

  64B 需要 $64/8=8$ 拍，数据阶段耗时 $8\times4=32\mathrm{ns}$。加上地址 $4\mathrm{ns}$、准备 $32\mathrm{ns}$：

  $$
  T_{\mathrm{burst}}=4+32+32=68\mathrm{ns}.
  $$


  完整事务有效带宽不是峰值，而是

  $$
  B_{\mathrm{eff}}=\frac{64}{68\times10^{-9}}\mathrm{B/s}
  \approx941.18\mathrm{MB/s}.
  $$


  </Step>
  <Step>

  **大块需要发起多次完整事务。**

  $$
  N=128/64=2,\qquad T=2\times68=136\mathrm{ns}.
  $$


  即使每次都传满数据，总耗时也含两次首地址与两次主存等待，所以不能把纯数据阶段的吞吐率当作端到端的实际吞吐率。

  </Step>
</Steps>

<Callout type="warn" title="最值公式适用前提">

这里的 $136\ \mathrm{ns}$ **明确依赖题设「事务不可重叠」**。若有多个未完成请求并发、流水化突发或连续行命中等优化，必须另按其时序计算，不能直接把两个事务耗时相加。

</Callout>

</Solution>
</Question>

### 原创强化训练 2：有效 CPI、性能提升与不可缩小的基础时间

<Question
  id="408-co-large-2013-43-ext2"
  type="essay"
  tags="来源:原创强化训练, 科目:计算机组成原理, 章节:存储器层次结构, 考点:有效CPI, 考点:性能加速比, 难度:提高"
>

某处理器主频 **1 GHz**，Cache 全部命中时的基本 CPI 为 2。程序共执行 **1000 条指令**，每条指令平均访存 1.5 次，Cache 缺失率 4%，**每次缺失额外停顿 60ns**；题中 CPI 尚未计入该缺失惩罚。

1. 分别计算基本执行时间、平均缺失次数、缺失造成的总停顿时间、最终程序运行时间。
2. 计算有效 CPI。
3. 通过硬件优化把 Cache 缺失率降为 1%，其他条件不变，新的程序运行时间与有效 CPI 各是多少？
4. 计算加速比，并解释为何缺失率降低为原来的 $1/4$，总执行时间却没有降为原来的 $1/4$。

<Solution>

### 参考答案

1. 基本 **$2000\ \mathrm{ns}$**；缺失 **60 次**；停顿 **$3600\ \mathrm{ns}$**；总计 **$5600\ \mathrm{ns}$**。
2. 有效 **CPI $=5.6$**。
3. 新缺失次数 15，运行时间 **$2900\ \mathrm{ns}$**，有效 **CPI $=2.9$**。
4. 加速比 $5600/2900=\boxed{56/29\approx1.93}$；基本执行时间并不受 Cache 缺失率下降影响。

### 解题过程

<Steps>
  <Step>

  **原系统的运行时间拆为可变项与不可变项。**

  CPU 周期 $1\mathrm{ns}$，基本执行时间 $1000\times2\times1=2000\mathrm{ns}$。访存总数为 $1500$，Cache 缺失 $1500\times0.04=60$ 次，停顿 $60\times60=3600\mathrm{ns}$，故总时间 $5600\mathrm{ns}$。

  </Step>
  <Step>

  **将时间换成平均每条指令的周期数。**

  $$
  \mathrm{CPI}_{\mathrm{eff}}=\frac{5600\mathrm{ns}}{1000\times1\mathrm{ns}}=5.6.
  $$


  也可直接算 $2+1.5\times0.04\times60=5.6$。

  </Step>
  <Step>

  **只改变缺失率，基准时间不变。**

  新缺失 $1500\times0.01=15$ 次，停顿 $15\times60=900\mathrm{ns}$，新总时间 $2000+900=2900\mathrm{ns}$，有效 CPI 为 $2.9$。

  </Step>
  <Step>

  **加速比按运行时间的比值求。**

  $$
  S=\frac{T_{\mathrm{old}}}{T_{\mathrm{new}}}
  =\frac{5600}{2900}=\frac{56}{29}\approx1.93.
  $$


  即使将**缺失停顿部分**缩小为四分之一，也不能对基础计算时间 $2000\mathrm{ns}$ 施加同样倍数缩放。这是理解 Amdahl 定律的关键：优化只作用于一部分开销。

  </Step>
</Steps>

### 答题迁移

$$
T=N\cdot\mathrm{CPI}_{\mathrm{base}}\cdot T_{\mathrm{clk}}
+N\cdot m\cdot r_{\mathrm{miss}}\cdot t_{\mathrm{penalty}}.
$$

只要题目明确缺失惩罚位于基本 CPI **之外**，这条式子就能直接使用；若给的是**已经计入平均停顿的 CPI**，则不能二次追加相同的惩罚。

</Solution>
</Question>

## 2014 年第 45 题

<Question
  id="408-co-large-2014-45"
  type="essay"
  tags="来源:2014考研408, 科目:计算机组成原理, 章节:存储器层次结构, 考点:指令Cache, 考点:缺页与TLB, 难度:综合"
>

沿用 **2014 年第 44 题**的计算机 M 和程序 P。该程序把数组 `A` 的 1000 个元素求和，循环体由如下 **6 条、每条 4B** 的机器指令构成，代码起始地址为 `08048100H`：

| 编号 | 机器指令 | 功能 |
| --- | --- | --- |
| 1 | `loop: sll R4, R2, 2` | $R4\leftarrow4R2$，得到数组下标字节偏移 |
| 2 | `add R4, R4, R3` | $R4\leftarrow R4+R3$，得到 `A[i]` 地址 |
| 3 | `load R5, 0(R4)` | $R5\leftarrow M[R4]$，读取 `A[i]` |
| 4 | `add R1, R1, R5` | $R1\leftarrow R1+R5$，累加元素值 |
| 5 | `add R2, R2, 1` | $R2\leftarrow R2+1$，更新循环下标 |
| 6 | `bne R2, R6, loop` | 下标不等于 $R6$ 时继续下一轮 |

P 开始执行时，`(R1)=(R2)=0`、`(R6)=1000`。计算机采用页式虚拟存储管理，**指令 Cache 与数据 Cache 分离**。程序的机器代码已在主存，但尚未装入指令 Cache；数组 A 尚未调入主存，并且所有数组元素位于**同一页面、磁盘同一扇区**。

请回答：

1. 程序执行完毕时，R2 中的值是多少？
2. 指令 Cache 有 **16 行**、每行 **32 B**。指令 Cache 的**数据区容量**是多少？只考虑 P 的执行，求指令 Cache 命中率。
3. 程序中哪条指令可能引发**算术溢出异常**？哪条指令可能触发**缺页异常**？为了访问整个数组，最少需要从磁盘读取多少次、访问 TLB 多少次？

<Solution>

### 参考答案

1. 执行完后 **$R2=1000$**。
2. 指令 Cache 的**数据区容量是 $512\ \mathrm B$**。P 共取指 $1000\times6=6000$ 次，只有初次载入代码块的 **1 次强制缺失**，因此命中率为

   $$
   \boxed{H_I=\frac{5999}{6000}\approx99.9833\%}.
   $$


3. **第 4 条 `add R1,R1,R5`** 可能因有符号求和超范围发生算术溢出；**第 3 条 `load R5,0(R4)`** 的首次数组读取可能因数据页不驻留而发生缺页。按题设至少需要 **1 次磁盘读取**；若首次发生缺页的 `load` 恢复后**重新执行并再次查询 TLB**，则仅统计访问数组所需的 TLB 查询至少为 **$1001$ 次**。不把其他取指、异常处理和隐含访存计算在这一最小计数中。

### 解题过程

<Steps>
  <Step>

  **步骤一：先复原循环执行次数，避免把最后一轮漏掉。**

  $R2$ 从 0 开始，每轮经第 5 条指令增加 1，**在增加后**由第 6 条 `bne` 将其与 $R6=1000$ 比较。

  | 轮次 | 进入循环时 R2 | 第 5 条指令之后 R2 | 第 6 条指令是否跳回 |
  | --- | ---: | ---: | --- |
  | 第 1 轮 | 0 | 1 | 是 |
  | 第 2 轮 | 1 | 2 | 是 |
  | … | … | … | … |
  | 第 1000 轮 | 999 | **1000** | **否** |

  因此 1000 轮全部执行，每轮均执行第 1 至第 6 条指令；最后一轮虽然不跳转，**`bne` 本身依旧完成一次取指**。

  </Step>
  <Step>

  **步骤二：Cache 数据区容量不包含标记位。**

  共 16 行，每行数据块为 32B：

  $$
  C_{\mathrm{data}}=16\times32=\boxed{512\ \mathrm B}.
  $$


  本问强调**数据区**，而不是含 Tag、有效位等元数据的「总物理容量」，不要套用以前求 Cache 总容量的题型。

  </Step>
  <Step>

  **步骤三：检查代码首地址与块边界。**

  六条指令各 4B，合计 $6\times4=24\ \mathrm B$。它们的起始地址分别为 `08048100H`、`08048104H`、`08048108H`、`0804810CH`、`08048110H`、`08048114H`。

  指令块长度是 $32\ \mathrm B=\texttt{20H}$；起始地址的低 5 位为 0，说明它恰好从一块的边界开始。这 24B 的地址覆盖范围为

  ```text
  08048100H ................ 08048117H
  [ 指令 1  ][ 指令 2 ][ ... ][ 指令 6 ]
  |-------- 同一个 32B Cache 块 --------|
  ```

  **首次取指**：从主存载入包含全部六条指令的这一块，计一次缺失。**其后 5999 次**：都访问同一块，且题设为分离 I-Cache/D-Cache，没有数组数据块驱逐指令块的冲突。

  $$
  N_{\mathrm{fetch}}=6\times1000=6000,\qquad
  H_I=\frac{6000-1}{6000}=\frac{5999}{6000}.
  $$


  仅由「代码大小 24B 小于 32B」**不能**断定只占一块，还必须验证地址对齐；本题已经完成了对齐检查。

  </Step>
  <Step>

  **步骤四：根据指令实际作用辨认两类异常。**

  - 第 4 条 `add R1,R1,R5` 将当前元素加进 `sum`。虽然单个数组元素是合法的 32 位整数，但多次求和**可能**超过有符号 32 位范围，所以该指令可能触发算术溢出异常。
  - 第 3 条 `load` 才真正以 `A[i]` 的虚拟地址读取数据。数组 A 的页面起初不在主存，首次 `load` 需要地址转换、可能触发**缺页异常**；程序随后经缺页处理装入该页后，方能成功读取。
  - 指令 Cache 初次不命中只是 Cache 缺失，**并非指令页缺页**，因为题设代码已在主存。
  - 第 5 条下标递增从 0 至 1000，在题设范围内不会溢出；不应只凭它也是一条 `add` 就选第 5 条作为本题溢出候选。

  </Step>
  <Step>

  **步骤五：磁盘访问次数由「页驻留状态与数据位置」决定。**

  一共访问 1000 个数组元素，但题设特别保证它们同属**一个原本不驻留的页面**，且磁盘中处在**同一个扇区**。因此首次访问导致一次缺页处理，只需从磁盘读取其所在数据一次；该页随后保持驻留，其他 999 次数组读取不再产生缺页。

  最小磁盘读取次数为 $\boxed{1}$。注意这是**本题特殊放置与最少读取口径**；不能脱离「同一页、同一扇区」的条件，把「访问 1000 个元素」机械写为 1000 次磁盘读取。

  </Step>
  <Step>

  **步骤六：区分「成功访问次数」与「异常指令的重启尝试次数」。**

  仅数该循环对数组的 1000 次逻辑读取；在题设教学模型中，首次 `load` 查询 TLB 后因页面不驻留而陷入缺页处理；页面装入后，同一条 `load` **重新执行并再次查询一次 TLB**。

  因此：

  $$
  N_{\mathrm{TLB}}=\underbrace{1}_{\text{首次异常尝试}}
  +\underbrace{1}_{\text{恢复后重试}}
  +\underbrace{999}_{\text{其他元素访问}}
  =\boxed{1001}.
  $$


  这里的计数是**最少的、仅对应数据访问的地址翻译查询次数**，而非 TLB **未命中**次数，也不是整个进程全部指令、异常处理程序访问内存的总次数。不同体系结构的访问重启细节可能不同；本题答案采用缺页后重启访存并重新查 TLB 的约定。

  </Step>
</Steps>

### 关键区别：三种「第一次」

| 事件 | 触发原因 | 对应本题 |
| --- | --- | --- |
| 第一次取指 Cache miss | **指令块**起初不在 I-Cache | 1 次强制缺失 |
| 第一次数据页 Page Fault | 数组所在**页面**起初不在主存 | 最少 1 次磁盘调入 |
| 第一次数据地址 TLB 查询及重启 | 原访问未完成，恢复后需要重新翻译 | 使查询次数从 1000 增为 1001 |

<Callout type="warn" title="题干中的「最少」限制了统计范围">

Cache miss、TLB miss、Page Fault 分别代表**缓存块缺失、翻译缓存项缺失、主存页面未驻留**。它们不能相互替代。尤其是第一次取指虽在 I-Cache 中缺失，但代码早已驻留主存，**不应据此再算一次磁盘读代码**。

</Callout>

</Solution>

### 原创强化训练 1：代码跨 Cache 块的强制缺失

<Question
  id="408-co-large-2014-45-ext1"
  type="essay"
  tags="来源:原创强化训练, 科目:计算机组成原理, 章节:存储器层次结构, 考点:指令对齐, 考点:Cache命中率, 难度:提高"
>

沿用真题中 **6 条各 4B 的循环指令、1000 轮执行**，且同样使用初始为空、行大小为 32B 的**独立指令 Cache**。现在将循环中第 1 条指令的首地址改为 **`08048118H`**；其余指令仍按地址连续存放，执行顺序及循环次数不变。

1. 列出六条指令的起始地址，并指出它们覆盖几个不同的 32B 主存块。
2. 忽略与其他程序的冲突，Cache 容量足以同时容纳这些代码块时，共取指几次？最少发生几次指令 Cache 缺失？求命中率。
3. 若改为**统一 Cache**，且数组访问会反复把这些指令块替换出去，能否直接使用第 2 问命中率？
4. 说明为何比较「程序长度」与「Cache 块长」本身不足以确定访存涉及的块数。

<Solution>

### 参考答案

1. 指令起始地址依次是 `08048118H`、`0804811CH`、`08048120H`、`08048124H`、`08048128H`、`0804812CH`；跨 **2 个块**。
2. **6000 次取指、最少 2 次强制缺失**，命中率 $\boxed{5998/6000\approx99.9667\%}$。
3. **不能。** 若统一 Cache 的数组读操作驱逐了代码块，会增加指令冲突缺失。
4. 即使代码总长 $24\ \mathrm B<32\ \mathrm B$，也可能由于未对齐的首地址而跨越块边界。

### 解题过程

<Steps>
  <Step>

  **逐条写地址，不凭印象判断。**

  本例涉及的字节范围为 `08048118H` 至 `0804812FH`。Cache 块边界按低 5 位划分：

  ```text
  块一：08048100H ~ 0804811FH
        08048118H: 指令 1
        0804811CH: 指令 2

  块二：08048120H ~ 0804813FH
        08048120H: 指令 3
        08048124H: 指令 4
        08048128H: 指令 5
        0804812CH: 指令 6
  ```

  故虽然全部指令合计 24B，**实际跨两个块**。

  </Step>
  <Step>

  **每个不同代码块首次被访问时发生一次强制缺失。**

  程序共执行 $6\times1000=6000$ 条指令的取指。两个代码块第一次各需从主存装入一次；在题设独立 I-Cache、容量充足且无其他驱逐时，余下 5998 次均命中：

  $$
  H=\frac{6000-2}{6000}=\frac{5998}{6000}\approx99.9667\%.
  $$


  </Step>
  <Step>

  **不同 Cache 组织方式下，不能无条件沿用原命中率。**

  分离 I-Cache 时数组数据不会直接占用 I-Cache 行；统一 Cache 时，指令与数据竞争相同的行/组，可能在每轮循环中再次驱逐指令块。因此题设一旦更改为统一 Cache，就必须按数组物理地址、映射与访问先后重新模拟。

  </Step>
</Steps>

<Callout type="info" title="快速判断跨块的通式">

对长度为 $L$ 字节、块长为 $B$、起始地址 $A$ 的连续区间，覆盖块数为

$$
N_{\mathrm{blocks}}=\left\lfloor\frac{(A\bmod B)+L-1}{B}\right\rfloor+1.
$$


本例 $A\bmod32=24$、$L=24$，故 $N=\lfloor47/32\rfloor+1=2$；原真题起始偏移为 0，则 $N=1$。

</Callout>

</Solution>

### 原创强化训练 2：跨页访存、缺页重启与 TLB 查询

<Question
  id="408-co-large-2014-45-ext2"
  type="essay"
  tags="来源:原创强化训练, 科目:计算机组成原理, 章节:存储器层次结构, 考点:跨页访问, 考点:TLB与PageFault, 难度:拔高"
>

某程序使用 `load` 逐个读取数组的 **1000 个 4B 整数**，主存采用**4KB 页面**，两个连续虚页起初都**没有驻留主存**。数组首元素从第一个虚页的**倒数第 100 个字节**（即页内偏移 $4096-100=3996$）开始存放，之后在虚拟地址空间中连续排列；假定数组不会发生未对齐访问，且两个页面随后都不被换出。

磁盘按 512B 扇区读取，每个被调入的页面都必须**完整读取 4KB**，一次只读一个扇区。另约定：首次读取一个不驻留页时，相关 `load` **先进行一次 TLB 查询，触发缺页后由操作系统调页，随后原 `load` 重启并再查询一次 TLB**；除缺页重启之外，一次正常数组读取进行一次 TLB 查询。仅统计这 1000 次数据读取及其重启。

1. 数组中有多少个元素位于第一页、多少个元素位于第二页？是否可能访问第三个虚页？
2. 最少缺页几次？为完成两页的调入至少读取多少个磁盘扇区？
3. 该程序对数组访问至少进行多少次 TLB 查询？注意**查询次数不等于 TLB miss 次数**。
4. 假设两页**已在主存但 TLB 表项尚未缓存**，第 2 问中的缺页结论是否依旧？说明与 TLB miss 的区别。

<Solution>

### 参考答案

1. 第一页含 **25** 个数组元素；第二页含 **975** 个；**不触及第三页**。
2. 共 **2 次缺页**；两页合计 $2\times(4096/512)=\boxed{16}$ 个扇区读取。
3. **$1002$ 次 TLB 查询**（1000 次逻辑读取，加 2 次故障重启额外查询）。
4. 若两页已驻留主存，仅 TLB 记录未缓存，通常会发生 **TLB miss**，可查页表并回填，**不必发生缺页**。

### 解题过程

<Steps>
  <Step>

  **先把数组与页面边界的关系算清。**

  第一页尚有 $100\ \mathrm B$ 连续空间，整数大小 4B，恰容纳 $100/4=25$ 个完整元素。总数组大小为 $1000\times4=4000\ \mathrm B$，余下 $3900\ \mathrm B$，小于第二页的 $4096\ \mathrm B$。因此第二页恰装 $3900/4=975$ 个元素，不需要第三页。

  </Step>
  <Step>

  **每个最初不驻留的页面第一次访问时才触发缺页。**

  初次读取第一页触发一次缺页；第 26 个整数位于第二页，首次读取时再触发一次缺页。其他数据都在这两页中，且题设承诺两页不会换出，故最少 $2$ 次。

  每页完整调入 4096B，需要 $4096/512=8$ 个磁盘扇区，合计 $2\times8=16$ 个扇区。**缺页异常数是 2，并不等于扇区 I/O 数 16。**

  </Step>
  <Step>

  **重启机制使 TLB 查询总数比正常读取次数多。**

  逻辑上有 1000 条 `load`，正常情况下各查询一次 TLB；两条首次触及新页的 `load` 各在首次失败之后又重启一次，分别增加一次查询。因此

  $$
  N_{\mathrm{TLB}}=1000+2=\boxed{1002}.
  $$


  其中绝大多数查询**可以命中 TLB**；本问没有给出 TLB 项数或替换情况，不应该把 $1002$ 解释为 $1002$ 次 TLB 缺失。

  </Step>
  <Step>

  **对比两个「找不到」。**

  TLB miss 只表示快表没有找到有效的页号映射；如果页表记录该页已经驻留且访问权限合法，CPU 可以通过查页表完成翻译并更新 TLB，而不必磁盘调页。Page Fault 则是更深层的页面驻留/访问问题，不能仅凭 TLB 缺失推出。

  </Step>
</Steps>

<Callout type="warn" title="这类题最应写明的计数约定">

本题特意规定缺页后的 `load` 要重启、重新查询 TLB，因此答案是 $1002$。如果另一个体系结构题没有说明这一统计口径，应先辨别它要求的究竟是**逻辑数据访问、地址翻译尝试、TLB miss、还是缺页次数**，不宜套一个固定数值。

</Callout>

</Solution>

## 2016 年第 45 题

<Question
  id="408-co-large-2016-45"
  type="essay"
  tags="来源:2016考研408, 科目:计算机组成原理, 章节:存储器层次结构, 考点:TLB地址字段, 考点:组相联Cache, 难度:综合"
>

某计算机采用**页式虚拟存储管理**，按字节编址，虚拟地址 **32 位**，物理地址 **24 位**，页面大小 **8 KB**；TLB 采用**全相联映射**。Cache 的**数据区容量为 64 KB**，采用 **2 路组相联**，主存块大小 **64 B**。存储访问过程见图。

<img src="/img/408/past-exams-large-questions/02-计算机组成原理/assets/2016-45-figure-001.svg" alt="2016 年第 45 题：TLB、页表及组相联 Cache 地址转换结构（原图）" />

请回答：

1. 图中字段 **A～G** 分别占多少位？TLB 标记字段 B 存放什么信息？
2. 主存**块号**为 $4099$ 的块装入 Cache，应映射到哪一组？对应字段 **H** 的内容是什么？
3. Cache 缺失和缺页相比，哪一种通常耗时更多？为什么？
4. 为什么 Cache 可以采用**直写**（Write Through），而虚拟存储器中修改页面时通常采用**回写**（Write Back）？

<Solution>

### 参考答案

1. **$A=19$、$B=19$、$C=11$、$D=13$、$E=9$、$F=9$、$G=6$ 位。** B 是 **19 位虚页号 VPN**，用于全相联 TLB 的并行匹配。
2. Cache 共 **$512$ 组**；组号 **$3$**，字段 H（物理 Cache Tag）为 **$8=000001000_2$**（9 位）。
3. **通常缺页开销更大。** 典型缺页需操作系统调入外存页面；Cache 缺失一般在主存和 Cache 之间调入块。
4. **下一级写入代价差别极大。** Cache 直写同步更新较快的主存，可以用写缓冲缓解流量；若虚存页面每次修改都同步写外存，代价高昂，故通常只置脏位，换出时回写。

### 详细解析

<Steps>
  <Step>

  **先把「页」的字段算完。**

  页面大小 $8\mathrm{KB}=8192=2^{13}\mathrm B$，故页内偏移为 **13 位**，并且虚实地址转换**不改变页内偏移**。

  $$
  \begin{aligned}
  \text{虚页号宽度} &=32-13=19,\\
  \text{物理页框号宽度} &=24-13=11.
  \end{aligned}
  $$

  因为 TLB **全相联**，它不用另取「TLB 组号」；用整个 VPN 作为匹配标记。因此：$A=19$、$B=19$、$C=11$、$D=13$。全相联**并不意味着** TLB Tag 等于 Cache Tag：前者标识**虚页**，后者标识**物理主存块**。

  </Step>
  <Step>

  **再把 Cache 的组数、索引和标记算完。**

  $64\mathrm{KB}=2^{16}\mathrm B$ 是**数据区**，而非包含元数据的容量。每块 $64\mathrm B=2^6\mathrm B$，共 $2^{16}/2^6=1024$ 个 Cache 行；2 路组相联，每组 2 行，所以

  $$
  N_{\mathrm{set}}=\frac{65536}{2\times64}=512=2^9.
  $$

  则物理地址的低 6 位为块内偏移 $G$，再向上 9 位为组号 $F$，高 $24-9-6=9$ 位为物理标记 $E$：

  | 地址／表项字段 | 构成 | 位宽 |
  | --- | --- | ---: |
  | 虚拟地址 | `VPN[31:13]` + `页内偏移[12:0]` | $19+13$ |
  | 全相联 TLB Tag B | 完整 VPN | $19$ |
  | TLB 输出的 PPN C | 物理页框号 | $11$ |
  | 物理地址 | `PPN[23:13]` + `页内偏移[12:0]` | $11+13$ |
  | 物理 Cache 地址 | `Tag[23:15]` + `Set[14:6]` + `Offset[5:0]` | $9+9+6$ |

  这里 $|$ 仅表示字段相邻拼接；**Cache 按物理地址确定标记**，不能直接把 32 位虚地址的高位拿来比对物理标记。

  </Step>
  <Step>

  **题目给的是主存块号，不是字节地址。**

  块号已去掉 6 位块内偏移，所以可以直接按组数取模：

  $$
  4099=512\times8+3,\qquad
  \begin{cases}
  \mathrm{Set}=4099\bmod512=3,\\
  \mathrm{Tag}=\lfloor4099/512\rfloor=8.
  \end{cases}
  $$

  因 Tag 为 9 位，$8$ 的定宽二进制表示为 $000001000_2$。如果误把 $4099$ 当成**字节地址**再除以 $64$，就会使整道题错位。

  </Step>
  <Step>

  **最后区分两次「不命中」和两种写策略。**

  - **TLB miss**：TLB 中没有该 VPN 的翻译缓存，可能继续访问驻留页的页表项；它**不等于**缺页。
  - **Cache miss**：所需物理主存块未在 Cache，有效的物理地址仍可从主存取数；它也**不等于**缺页。
  - **典型的缺页（非驻留页）**：需异常处理、分配/置换页框、访问外存并更新页表，延迟通常远大于 Cache miss。零填充、写时复制等缺页未必读磁盘，故应强调「通常」。
  - **直写与回写**：直写可在 Cache 命中写入时同时更新主存；虚存的下一层是外存，每写一次就同步外存会造成极大的写放大。因此分页系统通常记录页脏位，在换出时才有条件写回。Cache 本身**也完全可以采用回写**，题目问的是为何两层倾向不同。

  </Step>
</Steps>

<Callout type="warn" title="容易丢分的三处单位与口径">

- **64 KB 是 Cache 数据区容量**，不可直接拿「总容量含 Tag」去求组数。
- **块号 $4099$ 不再除 $64$**；只有给出字节地址时才先右移 6 位。
- 「TLB 全相联」决定**Tag 用整个 VPN**；「2 路 Cache」决定**每组 2 个块**，它们属于不同层级。

</Callout>

</Solution>

### 原创强化训练 1 · VIPT Cache 的组索引安全边界

<Question
  id="408-co-large-2016-45-ext1"
  type="essay"
  tags="来源:原创强化训练, 科目:计算机组成原理, 考点:VIPT同义地址, 考点:Cache相联度, 难度:拔高"
>

沿用原题 **8 KB 页面、64 B Cache 块、64 KB Cache 数据区**。现打算改为 **VIPT（虚拟索引、物理标记）**：TLB 地址翻译与 Cache 选组并行进行，且**不配置额外的同义地址检测/消歧硬件**。

1. 若保持 2 路组相联，页内偏移有多少位可供索引与块内偏移使用？目前 Cache 的索引是否完全处于页内偏移范围？
2. 保持 **2 路、64 B 块**时，满足上述无同义冲突要求的 Cache 数据区最大容量是多少？
3. 保持 **64 KB 容量、64 B 块**时，相联度至少提升到多少路，才能在这类简化 VIPT 设计中保证组号完全由页内偏移决定？写出新的组号位数。

<Solution>

### 参考答案

1. 页内偏移 **13 位**；原配置 512 组需索引 9 位、块偏移 6 位，共 15 位，**超出页内偏移 2 位**。
2. 最大 **$16\mathrm{KB}$**。
3. 至少 **8 路**，此时 $128$ 组、组号 **7 位**，与 6 位偏移相加恰为 13 位。

### 详细解析

<Steps>
  <Step>

  **VIPT 的约束从「不变的位」出发。**

  虚拟地址到物理地址的转换保留页内偏移 $[12:0]$。若索引位全部来自这 13 位，同一物理块的不同虚拟映射（别名）也会落在同一组；若索引深入虚页号，就可能在不同组保存同一个物理块的多个副本。题目不允许增加别名处理硬件，所以要求

  $$
  \log_2 S+\log_2 B\le\log_2 P,
  $$


  其中 $S$ 为组数、$B$ 为块字节数、$P$ 为页字节数。

  </Step>
  <Step>

  **计算安全容量上界。**

  $B=64=2^6$，$P=8192=2^{13}$，因此最多有 $2^{13-6}=128$ 组。对于 2 路配置：

  $$
  C_{\max}=128\times 2\times64=16384\mathrm B=16\mathrm{KB}.
  $$


  该结论亦可写作简便公式：$C_{\max}=P\times\text{路数}$，**只在题设的简化安全 VIPT 前提下**直接使用。

  </Step>
  <Step>

  **固定容量时反求相联度。**

  $64\mathrm{KB}/(64\mathrm B)=1024$ 行，若每组至少允许 8 行，则组数 $1024/8=128$，组号 7 位；$7+6=13$，完全落在页面低 13 位内。4 路时仍有 $256$ 组，需要 $8+6=14$ 位，因此不满足。

  </Step>
</Steps>

<Callout type="info" title="方法迁移">

更大的页大小、较高的相联度、降低 Cache 容量或较小的块大小，都会影响 VIPT 的索引设计；但若系统允许页着色或专门的同义项处理，实际硬件可能使用更灵活的配置，不能把上述不等式说成所有 Cache 的物理定律。

</Callout>

</Solution>
</Question>

### 原创强化训练 2 · 物理地址标记、元数据与替换状态综合设计

<Question
  id="408-co-large-2016-45-ext2"
  type="essay"
  tags="来源:原创预测题, 科目:计算机组成原理, 考点:Cache总容量, 考点:LRU实现, 难度:综合"
>

仍采用原题 **24 位物理地址、64 KB 数据区、2 路组相联、64 B 块**的物理 Cache，但增加如下实现细节：每行保存 **1 位有效位和 1 位脏位**；2 路精确 LRU **每组用 1 位**记录替换优先级，不考虑校验位及其他电路。

1. 求 Cache 的总行数、组数和每行物理 Tag 位数。
2. 求数据位、Tag 位、有效位与脏位、LRU 位各占多少位，最终求**总存储容量**（以字节表示）。
3. 两个物理**块号**分别为 $4099$ 和 $4611$。它们分别属于哪一组、Tag 为多少？若此组起初为空，它们能否同时驻留而不互相替换？再读入块号 $5123$ 会发生什么？

<Solution>

### 参考答案

1. **1024 行、512 组、9 位 Tag**。
2. 数据 $524288$ 位；Tag $9216$ 位；有效与脏位 $2048$ 位；LRU $512$ 位；合计 **$536064$ 位 $=67008\mathrm B$**。
3. $4099=8\times512+3$；$4611=9\times512+3$，均在第 3 组，Tag 分别为 $8,9$，**可同时驻留**。$5123=10\times512+3$ 是同组第三个块，必须替换现有两路中的一块；被替换哪块由 LRU 状态决定，脏位为 1 时还需写回。

### 详细解析

<Steps>
  <Step>

  **先只按数据区求组织形式。**

  $$
  N_{\rm line}=\frac{64\times1024}{64}=1024,\quad
  N_{\rm set}=\frac{1024}{2}=512,\quad
  T=24-\log_2 512-\log_2 64=9.
  $$


  </Step>
  <Step>

  **按存储字段分别计数，避免混淆 64 KB 和总容量。**

  | 项目 | 位数 |
  | --- | ---: |
  | 数据区 | $1024\times64\times8=524288$ |
  | 标记 Tag | $1024\times9=9216$ |
  | 有效位 + 脏位 | $1024\times2=2048$ |
  | 精确 2 路 LRU | $512\times1=512$ |
  | **总计** | **$536064$** |

  故字节数为 $536064/8=67008\mathrm B$，比 65536B 的数据区多出 **1472B**。**精确二路 LRU 一组 1 位就足够**，不必盲目为每行都加一个 LRU 位。

  </Step>
  <Step>

  **同组并不等于必然立刻冲突。**

  三个块号分别为 $8\cdot512+3$、$9\cdot512+3$、$10\cdot512+3$，所以组号都等于 3，但 Tag 为 8、9、10。前两个正好填满该组的两路，第三个到来才需要根据 LRU 淘汰其中一路。与直接映射只有 1 行的情况相比，这正体现了 2 路组相联减少冲突缺失的作用。

  </Step>
</Steps>

</Solution>

## 2018 年第 44 题

<Question
  id="408-co-large-2018-44"
  type="essay"
  tags="来源:2018考研408, 科目:计算机组成原理, 章节:存储器层次结构, 考点:TLB与Cache, 考点:LRU容量, 难度:综合"
>

某计算机采用**分页虚拟存储管理**，按字节编址，CPU 的存储访问过程如图所示。

<img src="/img/408/past-exams-large-questions/02-计算机组成原理/assets/2018-44-figure-001.svg" alt="2018 年第 44 题：TLB、页表与 2 路组相联 Cache（原图）" />

请回答：

1. 主存**物理地址**有多少位？
2. TLB 采用什么映射方式？TLB 应用 SRAM 还是 DRAM 实现？
3. Cache 是何种映射方式？若使用 LRU 替换和**回写策略**，每行除 Data、Tag、有效位外应有哪些附加状态位？Cache 的**总容量**是多少？有效位的作用是什么？
4. 虚拟地址为 `0008C040H` 时，对应物理地址是多少？是否 Cache 命中？说明理由。若虚拟地址为 `0007C260H`，该地址所在主存块应映射哪一组？

<Solution>

### 参考答案

1. 物理地址 **28 位**。
2. TLB 为**全相联**；通常用 **SRAM/相联存储器**实现（硬件并行标记匹配）。
3. Cache 为 **2 路组相联**。除数据、标记和有效位，还需要**脏位**和**LRU 替换状态**。按题图的**每行 1 位 LRU**统计口径，总容量 **$4464\mathrm{bit}=558\mathrm B$**；按精确 2 路 LRU **每组 1 位**的最小实现，容量是 **$4456\mathrm{bit}=557\mathrm B$**。有效位决定 Tag 匹配的行是否含有效数据。
4. `0008C040H` 对应物理地址 **`0040040H`**，选 Cache **第 2 组**，Tag=`00400H`，但图中该 Tag 对应行**有效位为 0**，故**未命中**；`0007C260H` 对应主存块映射**第 3 组**。

### 详细解析

<Steps>
  <Step>

  **先从图里的两套字段同时确认物理地址宽度。**

  图示物理页框号为 **16 位**、页内偏移为 **12 位**，所以物理地址宽度为 $16+12=28$ 位。另一方面 Cache 地址字段为 **Tag 20 位 + Set 3 位 + Offset 5 位**，同样是 $28$ 位。两条独立信息吻合，说明字段读法正确。

  </Step>
  <Step>

  **识别 TLB 和 Cache 的映射结构。**

  TLB 中多个标记与输入虚页号作并行比较，任一有效匹配项可以提供页框号，所以是**全相联**；容量通常较小、要求高速，实际使用 SRAM 及关联比较逻辑，而非大容量 DRAM。

  Cache 则是 **8 组 × 每组 2 路 = 16 行**，每块 $2^5=32\mathrm B$，缓存**数据区**为 $16\times32=512\mathrm B$。组号来源于地址位 $[7:5]$，Tag 来源于物理地址位 $[27:8]$。

  </Step>
  <Step>

  **总容量先明示 LRU 计数约定，再加总所有存储字段。**

  每行数据是 $32\times8=256$ 位，Tag 占 20 位，另外有 1 位 Valid、1 位 Dirty，共计 $278$ 位/行。

  <Tabs items={['按题图／传统答案口径','按最小精确二路 LRU']} defaultIndex={0}>
    <Tab value="按题图／传统答案口径">

    原题按**每行再计 1 位 LRU**，于是

    $$
    C_{\rm total}=16(256+20+1+1+1)=4464\mathrm{bit}=558\mathrm B.
    $$


    这是本题按原图所要求的主要数值答案。

    </Tab>
    <Tab value="按最小精确二路 LRU">

    标准 **2 路精确 LRU** 的最近访问者只有两个选择，**每组 1 位**即可，而非每行必须各存一位：

    $$
    C_{\rm total}=16(256+20+1+1)+8=4456\mathrm{bit}=557\mathrm B.
    $$


    两者**差 1B**，由替换状态的硬件实现和统计口径造成，不是数据区容量不同。在考试答卷中优先写出原题规定口径，并说明合理替代实现。

    </Tab>
  </Tabs>

  </Step>
  <Step>

  **翻译 `0008C040H` 后再进行物理 Tag 与有效位匹配。**

  4 KB 页内偏移为 12 位：

  $$
  VPN=\texttt{0008CH},\qquad offset=\texttt{040H}.
  $$


  查原图，TLB 对应有效映射的物理页框号是 `0040H`，因此

  $$
  PA=(\texttt{0040H}\ll12)\;|\;\texttt{040H}=\texttt{0040040H}.
  $$


  组号为 $(PA\gg5)\bmod8=2$，物理 Tag 为 $PA\gg8=\texttt{00400H}$。该组有一路的 Tag 虽相同，但**Valid=0**；其余路 Tag 不符合，故发生 Cache miss。

  </Step>
  <Step>

  **计算 `0007C260H` 的组号时，无须先查 TLB。**

  组索引为物理地址位 $[7:5]$，完全包含在虚实一致的页内偏移 $[11:0]$。本地址页内偏移为 `260H`，

  $$
  \mathrm{Set}=(\texttt{260H}\gg5)\mathbin{\&}7=3.
  $$


  所以**只能在第 3 组内查找**。这里题目并未提供完整的物理 Tag 及该组最终状态，不能据此断言 Cache 一定命中。

  </Step>
</Steps>

<Callout type="warn" title="有效位不等于脏位，组号也不等于命中判定">

命中需要 **Valid=1 且 Tag 相同**。脏位只说明是否需要在替换时回写；LRU 只决定满组未命中时的淘汰对象；三者承担不同职责。还要区分「Cache 数据区 512B」与「包含标记、控制位的总容量 558B」。

</Callout>

</Solution>

### 原创强化训练 1 · 2 路 LRU 与脏块回写逐访问跟踪

<Question
  id="408-co-large-2018-44-ext1"
  type="essay"
  tags="来源:原创预测题, 科目:计算机组成原理, 考点:LRU替换, 考点:写回策略, 难度:综合"
>

某 Cache 的一个组只有 **2 路**，开始时两路均无效，采用**精确 LRU** 和 **Write Back + Write Allocate（写分配）**。对映射到这一组、Tag 分别为 `A`、`B`、`C`、`D` 的块，依次执行：

```text
读 A → 读 B → 写 A → 读 C → 读 B → 写 C → 读 D
```

约定读缺失装入干净块；写命中把块置脏；满组缺失总是淘汰 LRU 行，若脏则写回。

1. 逐次列出命中/缺失、被淘汰块、是否产生脏块写回。
2. 全部 7 次访问的命中数、未命中数、命中率各是多少？共发生几次脏块写回？
3. 最后两路分别保存哪些 Tag，哪一行处于脏状态？

<Solution>

### 参考答案

- **命中 2 次、缺失 5 次，命中率 $2/7$。**
- **脏块写回 1 次**，发生在再次读取 `B` 而淘汰已修改的 `A` 时。
- 结束后缓存 **`C`（脏）和 `D`（干净）**；`C` 为 LRU，`D` 为 MRU。

### 详细解析

逐次维护「**谁最近访问过**」与「**谁是脏块**」两种独立信息：

| 次序 | 操作 | 命中？ | 淘汰 | 写回？ | 访问后两路：按 LRU → MRU 排列 |
| ---: | --- | --- | --- | --- | --- |
| 1 | 读 A | 缺失 | 无 | 否 | `A(净)` |
| 2 | 读 B | 缺失 | 无 | 否 | `A(净), B(净)` |
| 3 | 写 A | **命中** | 无 | 否 | `B(净), A(脏)` |
| 4 | 读 C | 缺失 | B | 否 | `A(脏), C(净)` |
| 5 | 读 B | 缺失 | **A** | **是** | `C(净), B(净)` |
| 6 | 写 C | **命中** | 无 | 否 | `B(净), C(脏)` |
| 7 | 读 D | 缺失 | B | 否 | `C(脏), D(净)` |

总共 7 次访问，其中第 3、6 次命中，故 $H=2/7$。第 5 次发生的是**把脏 A 写回下一级存储器**，随后再装入 B；此处通常既有缺失读流量，又有额外的写回流量。

<Callout type="info" title="考点延伸：写策略与写分配是两条独立轴">

Write Back 决定**写命中后何时向下一级写数据**；Write Allocate 决定**写缺失是否先装入块**。不要把「回写」误解为「写缺失一定不装块」，或把「LRU」误解为「优先淘汰干净块」。

</Callout>

</Solution>
</Question>

### 原创强化训练 2 · 从虚页号到物理组号的可判定信息

<Question
  id="408-co-large-2018-44-ext2"
  type="essay"
  tags="来源:原创强化训练, 科目:计算机组成原理, 考点:VIPT索引, 考点:页偏移不变, 难度:拔高"
>

某机使用 **4 KB 页、28 位物理地址**，并用**物理标记 Cache**，缓存数据区为 **32 KB**，块长 **64 B**。现在希望不等待 TLB 翻译，便能从页内偏移并行算出 Cache 组号；系统不采用额外的同义地址处理机制。

1. 如果 Cache 为 **2 路**，求组数、组号与块内偏移位数，以及组号是否完全落在页内偏移中。
2. 若容量和块长保持不变，把相联度提高到 **8 路**，重新计算组数、组号和物理 Tag 的位数，判断是否满足要求。
3. 对虚拟地址 `0007C260H`，采用第 2 问结构时，能否直接确定组号？如果该组某行物理 Tag 恰巧等于目标的 Tag，但有效位为 0，是否命中？

<Solution>

### 参考答案

1. 2 路：$32\mathrm{KB}/(2\times64\mathrm B)=256$ 组，组索引 **8 位**、块偏移 **6 位**，共 **14 位**，超过 4 KB 页偏移的 12 位，**不满足**。
2. 8 路：$64$ 组，索引 **6 位**、块偏移 **6 位**；物理 Tag $28-6-6=16$ 位，**满足**。
3. 可直接用低 12 位得到组号 **$9$**；Tag 虽相等但有效位为 0，**Cache miss**。

### 详细解析

<Steps>
  <Step>

  **计算页内的稳定部分。** $4\mathrm{KB}=2^{12}\mathrm B$，虚实地址仅保证最低 12 位完全相同。若索引 + 块内偏移超过 12 位，就可能需要翻译后的页框位才能确定物理组号。

  </Step>
  <Step>

  **两种路数的对照。**

  | 路数 | 组数 | 索引位 | 偏移位 | 共用低位 | 能否完全页内选组 |
  | ---: | ---: | ---: | ---: | ---: | --- |
  | 2 | 256 | 8 | 6 | 14 | 否 |
  | 8 | 64 | 6 | 6 | 12 | 是 |

  8 路时 Tag 宽度为 $28-(6+6)=16$ 位；增加相联度的作用是**减少组数和索引位**，并不是改变物理地址总长度。

  </Step>
  <Step>

  **算组号并判断命中。** 页内偏移 `260H`：

  $$
  \mathrm{Set}=\left\lfloor\frac{\texttt{260H}}{64}\right\rfloor\bmod64=9.
  $$


  这说明可以直接选中第 9 组，而不说明数据是否已驻留。必须再等待翻译得到物理 Tag，并判断**有效位与 Tag 同时满足**。

  </Step>
</Steps>

</Solution>
</Question>

## 2019 年第 46 题

<Question
  id="408-co-large-2019-46"
  type="essay"
  tags="来源:2019考研408, 科目:计算机组成原理, 章节:存储器层次结构, 考点:跨题取指, 考点:Cache组号, 难度:综合"
>

**承接 2019 年第 45 题**的计算机 M 与阶乘程序。若计算机的**主存地址为 32 位**，采用分页存储管理，页大小为 **4 KB**，回答：

1. 机器级代码第 1 行 `push` 和第 30 行 `ret` 是否处于**同一页**？说明理由。
2. 指令 Cache 有 **64 行**，采用 **4 路组相联**；主存块大小为 **64 B**。32 位主存地址中的**块内地址、Cache 组号、Tag** 分别是哪些位？
3. 读取第 16 行 `call` 指令时，只可能在指令 Cache 的**哪一组**命中？说明理由。

为使本题独立可读，保留前一题相关机器码地址：

```text
第 1 行：00401000H  55              push ebp
第 16 行：00401025H E8 D6 FF FF FF  call f1
第 30 行：0040104AH C3              ret
```

<Solution>

### 参考答案

1. **同一虚拟页**。两条指令首地址分别为 `00401000H` 和 `0040104AH`，按 4 KB 页划分，其虚页号都为 `00401H`。
2. 组数 $64/4=16$。**块内偏移：$[5:0]$（6 位）；Cache 组号：$[9:6]$（4 位）；物理 Tag：$[31:10]$（22 位）。**
3. `call` 指令起始地址为 `00401025H`，其所在主存块**只可能映射到第 0 组**。理由是组索引位 $[9:6]$ 完全位于 4 KB 页内偏移 $[11:0]$，可直接从虚拟地址读取；**确定组号并不保证命中**。

### 详细解析

<Steps>
  <Step>

  **从「承接上一题」找出真实机器指令地址。**

  2019 年第 45 题的 `f1(n)` 为递归阶乘函数，第 1 行 `push` 起于 `00401000H`，第 30 行 `ret` 起于 `0040104AH`，第 16 行 `call` 起于 `00401025H`（机器码 `E8 D6 FF FF FF`，长 5B）。本题只问取指映射，**不是要求重新计算阶乘**；必须使用机器码中的**字节地址**，不能把「第 16 行」直接当作内存偏移量 16。

  </Step>
  <Step>

  **比较页号：右移 12 位，而不是比较整条地址。**

  $4\mathrm{KB}=4096\mathrm B=2^{12}\mathrm B$，页内偏移位数为 12；因此：

  $$
  \begin{aligned}
  \mathrm{VPN}_{push}&=\texttt{00401000H}\gg12=\texttt{00401H},\\
  \mathrm{VPN}_{ret}&=\texttt{0040104AH}\gg12=\texttt{00401H}.
  \end{aligned}
  $$

  或看低 12 位：两地址分别落在同一页面的 `000H` 与 `04AH` 位置。故**同一虚拟页**。如果题目仅给虚拟地址、尚未给出页表，也不应擅自写出它们的具体物理页框号；但同一合法虚页最终映射同一页框。

  </Step>
  <Step>

  **区分「64 行」与「16 组」。**

  Cache 总行数 64、相联度 4，所以有 $64/4=16=2^4$ 组。每块 $64\mathrm B=2^6\mathrm B$，块内偏移 6 位。32 位物理地址的高位 Tag 因此是 $32-4-6=22$ 位：

  | 字段 | 位数 | 物理地址位范围 |
  | --- | ---: | --- |
  | Tag | 22 | $[31:10]$ |
  | 组号 | 4 | $[9:6]$ |
  | 块内偏移 | 6 | $[5:0]$ |

  不要把 64 行看成 64 组，否则会错写组号为 6 位、Tag 为 20 位。

  </Step>
  <Step>

  **利用页内偏移不变的性质，不查页表也能算组号。**

  `call` 指令地址 `00401025H` 的页内偏移为 `025H`。由于 Cache 组号只使用 $[9:6]$，而这些位都在页内偏移范围 $[11:0]$ 中，故

  $$
  \mathrm{Set}=\left(\texttt{025H}\gg6\right)\mathbin{\&}\texttt{FH}=0.
  $$


  也可用块号视角核对：本页从偏移 `000H` 到 `03FH` 是第一页内的第 0 块；`call` 的地址 `025H` 落在其中，所以索引为 0。**「只能在第 0 组中命中」是位置约束，不是命中事实**；Cache 未装入该块或该路有效位为 0 时仍会缺失。

  </Step>
</Steps>

<Callout type="warn" title="可复用的组相联取指判断式">

令页面大小 $P=2^p$、块大小 $B=2^b$、组数 $S=2^s$。当 **$b+s\le p$** 时，组号位全部来自不变的页内偏移；可用虚拟地址先行算出**物理索引对应的组号**。但若要判断是否真正命中，仍需物理 Tag 与有效位等状态。

</Callout>

</Solution>
</Question>

### 原创强化训练 1 · 指令跨页时，单条取指也可能访问两个 Cache 块

<Question
  id="408-co-large-2019-46-ext1"
  type="essay"
  tags="来源:原创预测题, 科目:计算机组成原理, 考点:跨页取指, 考点:Cache地址拆分, 难度:拔高"
>

某机按字节编址，页面为 **4 KB**；物理地址 **32 位**。指令 Cache 有 **128 行**、**8 路组相联**，每块 **32 B**。已知 x86 类指令可采用不等长编码，并有以下机器指令：

- 指令 $I_1$：从虚拟地址 `00401FE0H` 开始，长 **4 B**；
- 指令 $I_2$：从虚拟地址 `00401FFCH` 开始，长 **5 B**；
- 指令 $I_3$：从虚拟地址 `00402010H` 开始，长 **3 B**。

1. 求 Cache 组数，以及块内偏移、组号和物理 Tag 的位数与位范围。
2. $I_1,I_2,I_3$ 各涉及哪些虚拟页面？其中是否有**单条指令跨页**的情况？
3. 在不知物理页框号的前提下，分别列出三条指令涉及的 Cache **组号**。说明为何「指令首地址落在某页」不足以保证整条指令只需翻译该页。

<Solution>

### 参考答案

1. 组数 $128/8=16$；块内偏移 **5 位 $[4:0]$**，组号 **4 位 $[8:5]$**，物理 Tag **23 位 $[31:9]$**。
2. $I_1$ 在 VPN=`00401H`；$I_2$ 的前 4B 位于 VPN=`00401H`，最后 1B 位于 VPN=`00402H`，**跨 2 页**；$I_3$ 在 VPN=`00402H`。
3. $I_1$ 对应**组 15**；$I_2$ 同时涉及**组 15 与组 0**；$I_3$ 涉及**组 0**。

### 详细解析

<Steps>
  <Step>

  **先求地址字段。** 16 组用 4 位索引，32B 块用 5 位偏移，合计 9 位，完全处于 4KB 页的 12 位页内偏移之中。所以本题不用先查 TLB 也能计算组号。

  </Step>
  <Step>

  **按「首地址 + 长度 - 1」求每条指令覆盖的最后一个字节。**

  | 指令 | 占用的字节地址范围 | 虚页号 |
  | --- | --- | --- |
  | $I_1$ | `00401FE0H` 至 `00401FE3H` | `00401H` |
  | $I_2$ | `00401FFCH` 至 `00402000H` | **`00401H` 与 `00402H`** |
  | $I_3$ | `00402010H` 至 `00402012H` | `00402H` |

  **特别注意**：`...1FFCH` 开始、长 5B，最后一个字节正好是 `...2000H`，跨越了 `...1FFFH` 与 `...2000H` 之间的页面边界。因此一次指令读取可能牵涉**两次页号翻译、两次 Cache 块检查**；第二页不驻留时还可能缺页。

  </Step>
  <Step>

  **用所触及每个块的页内偏移单独算组号。**

  $I_1$ 所在块偏移以 `1FE0H` 开始：$\left\lfloor\texttt{1FE0H}/32\right\rfloor\bmod16=15$。$I_2$ 前 4B 属于同一块，组号也为 15；最后 1B 来自下一页 `2000H` 的首块，组号为 0。$I_3$ 的 `2010H` 也位于该新页的首个 32B 块，组号仍为 0。

  如果题目只说「$I_2$ 首地址位于 VPN=`00401H`」，只能判定**第一个字节**的位置，不能据此推断整条变长指令不会跨页。

  </Step>
</Steps>

<Callout type="info" title="命题升级点">

典型 408 题只给指令首地址并问所在页或组；将其扩展为 **变长指令、跨块与跨页** 时，判断依据应改成整条指令覆盖的地址**闭区间**，而不是只检查首字节。

</Callout>

</Solution>

### 原创强化训练 2 · TLB 不命中、Cache 命中与缺页能否并存？

<Question
  id="408-co-large-2019-46-ext2"
  type="essay"
  tags="来源:原创预测题, 科目:计算机组成原理, 考点:多级访存, 考点:TLB与缺页, 难度:综合"
>

某机虚拟地址和物理地址均为 **32 位**，页面大小 **4 KB**，指令 Cache 为 **64 行、4 路组相联、64 B/块**，以**物理地址标记**。CPU 要读取虚拟地址 `00001A3CH`；页表给出虚页 `00001H` 已驻留物理页框 `12345H`。

1. 分别求 VPN、页内偏移、物理地址、Cache 组号和 Cache 物理 Tag。
2. 如果**TLB 未命中**，但页表指出该页**已驻留且允许读取**，是否必然发生缺页异常？假如物理 Cache 此时保存了目标块且对应有效位为 1，则最终数据访问能否在 Cache 命中？
3. 如果 **TLB 已命中**，是否能据此推断 Cache 必定命中？如果页表标记该页**不驻留**，仅观察到 TLB 未命中，应该走哪一步才能分清是普通 TLB miss 还是缺页？

<Solution>

### 参考答案

1. VPN=`00001H`，偏移=`A3CH`，物理地址 **`12345A3CH`**；Cache 组号 **8**，物理 Tag 为 **`48D16H`**（下文核算）。
2. **不会必然缺页**；TLB miss 后查页表并回填 TLB，即可取得有效物理地址，最终**完全可能 Cache 命中**。
3. **TLB 命中也不保证 Cache 命中**；当 TLB miss 时需要查页表或进行硬件页表遍历，检查有效/驻留及权限等状态，必要时才触发缺页或相应保护异常。

### 详细解析

<Steps>
  <Step>

  **独立完成三个层次的地址分解。**

  页内偏移 12 位，故 `00001A3CH` 分成 VPN=`00001H` 与 Offset=`A3CH`。页表映射到页框 `12345H`，物理地址为

  $$
  PA=(\texttt{12345H}\ll12)\;|\;\texttt{A3CH}=\texttt{12345A3CH}.
  $$


  Cache 仍为 16 组，块内偏移 6 位，所以

  $$
  \mathrm{Set}=(PA\gg6)\mathbin{\&}\texttt{FH}=8,\qquad
  \mathrm{Tag}=PA\gg10=\texttt{48D16H}.
  $$


  </Step>
  <Step>

  **将 TLB 状态、页表状态、Cache 状态分别看待。**

  | 检查层级 | 要回答的问题 | 未命中或异常的后续行为 |
  | --- | --- | --- |
  | TLB | 最近访问过该 VPN 的翻译是否缓存？ | 查页表或硬件遍历获取映射 |
  | 页表 | 虚页是否有效、驻留且有权限？ | 非驻留时通常触发缺页并进行处理；权限问题按体系结构报错 |
  | Cache | 目标物理块是否在对应组且 Tag、Valid 均匹配？ | 缺失时从下一级存储层次取块 |

  因而 **TLB miss + 页表命中 + Cache hit** 是完全合法的组合：翻译缓存未命中并不妨碍目标数据块已经保存在 Cache。

  </Step>
  <Step>

  **注意不能使用失效的翻译项规避页表检查。**

  当页表指示页面不驻留时，必须按缺页协议处理，不能仅因为 Cache 某组曾保存过类似 Tag 就直接跳过转换。地址翻译和访问权限判定属于 Cache 命中之前的正确性条件。

  </Step>
</Steps>

<Callout type="warn" title="不要将三种事件混为一谈">

TLB miss 是**翻译缓存未命中**，Cache miss 是**数据缓存未命中**，Page Fault 是**页面转换或驻留相关异常**。它们的定义、后果、时间开销不同；只有结合页表与有效位，才能确定处理路径。

</Callout>

</Solution>
</Question>

## 2020 年第 44 题

<Question
  id="408-co-large-2020-44"
  type="essay"
  tags="来源:2020考研408, 科目:计算机组成原理, 章节:存储器层次结构, 考点:组相联映射, 考点:Cache命中率, 难度:综合"
>

某计算机的**主存地址为 32 位**，按字节编址。指令 Cache 和数据 Cache **均**采用 **8 路组相联**、**直写（Write Through）**策略和 **LRU** 替换算法；主存块为 **64 B**，两种 Cache 的**数据区容量各为 32 KB**。开始时 Cache 均为空。回答：

1. Cache 每行的 **Tag**、**LRU 位**各占几位？是否需要修改位？
2. 执行以下 C 程序，`int` 占 4 B，`k` 在寄存器中；数组 `s` 首地址为 `008000C0H`。访问数组 `s` 时，**数据 Cache 缺失多少次**？

   ```c
   for (k = 0; k < 1024; k++)
       s[k] = 2 * s[k];
   ```

3. CPU **首次**读取主存地址 `00010003H` 处的指令时，说明指令 Cache 的访问流程，包括缺失处理。

<Solution>

### 参考答案

1. **Tag 为 20 位**；若以 **0～7 的 LRU 次序独立标记各行**，则每行 **3 位 LRU 状态**。直写策略无需表示与主存不一致的**脏位/修改位**。注意“3 位/行”取决于题目的 LRU 编码口径。
2. 数据 Cache **缺失 64 次**，全部来自每块第一次读入。
3. 指令地址对应 **Tag=`00010H`、组号 0、块内偏移 `03H`**。第 0 组起初没有有效行，故缺失；从主存调入地址 `00010000H`～`0001003FH` 的 **64 B**，填入第 0 组空路、写标记并置有效位，更新 LRU，再从偏移 `03H` 处取所需指令字节。

### 详细解析

<Steps>
  <Step>

  **先用数据区容量反推行数、组数，再切分 32 位主存地址。**

  $$
  \begin{aligned}
  \text{行数}&=\frac{32\times1024}{64}=512,\\
  \text{组数}&=\frac{512}{8}=64=2^6,\\
  \text{块内偏移}&=\log_2 64=6\text{ 位},\\
  \text{组号}&=\log_2 64=6\text{ 位},\\
  \text{Tag}&=32-6-6=\boxed{20\text{ 位}}.
  \end{aligned}
  $$

  地址从高到低依次是：**Tag `A[31:12]`｜组号 `A[11:6]`｜块内偏移 `A[5:0]`**。特别注意，Cache 数据区的 32 KB **不包含** Tag、有效位等元数据，不能拿 32 KB 直接当“总物理位数”。

  </Step>
  <Step>

  **分清 LRU 状态和脏位，避免把“通常实现”误作唯一实现。**

  8 路组相联若在**每条 Cache 行中记载该行当前的 0～7 次序号**，编码一个次序号需要 $\lceil\log_2 8\rceil=3$ 位。按这种考试常用的行级次序编码，答案就是**每行 3 位**。但是，LRU 的状态由**整组 8 路的相对先后次序**决定，也可以采用其他按组编码方式：例如保存所有 $8!$ 种顺序理论上至少需要 $\lceil\log_2(8!)\rceil=16$ 位/组；树形 *pseudo-LRU* 虽常用 7 位/组，却并非严格 LRU。题目的“每行多少位”隐含了实现口径，作答应说明它。

  直写 Cache 中每次对数据行的写入都同步更新下一级主存，故不存在仅 Cache 拥有的、尚未写回的修改数据，**不必设置脏位**。这**不等于**不需要有效位，也**不等于**写未命中一定分配或一定不分配新行。

  </Step>
  <Step>

  **从“每个元素一次读、一次写”数清访存和缺失。**

  数组占 $1024\times4=4096\text{ B}$；首址 `008000C0H` 满足 $\texttt{C0H}\bmod64=0$，恰好位于主存块边界。每块能容纳 $64/4=16$ 个 `int`，因此数组覆盖

  $$
  \frac{4096}{64}=\boxed{64\text{ 个主存块}}.
  $$


  对每个 `s[k]`，先**读取**旧值，再**写回**新值。每块首次读取产生 1 次强制缺失；同块剩余 15 次读取都命中，写入时该块已经驻留。循环沿地址单调递增，每块仅处理一次，所以即使以后载入的新块发生替换，也无需再访问已淘汰的旧块。

  | 指标 | 数量 | 含义 |
  | --- | ---: | --- |
  | 元素个数 | 1024 | 每个元素读后写 |
  | 数据 Cache 访问总次数 | 2048 | 1024 次读 + 1024 次写 |
  | 涉及主存块数 | 64 | 首地址对齐，16 个元素/块 |
  | Cache 缺失次数 | **64** | 每个新块首次读取缺失 |
  | 若问缺失率 | $64/2048=3.125\%$ | **不是本题要求的“缺失次数”** |

  直写会产生大量**向主存发送的写事务**，但它们不能与 CPU 访问数据 Cache 时发生的**缺失次数**混为一谈。

  </Step>
  <Step>

  **对首次取指作完整地址分解，并执行缺失处理。**

  对地址 `00010003H`：

  $$
  \begin{aligned}
  \text{Tag}&=\texttt{00010003H}\gg12=\texttt{00010H},\\
  \text{组号}&=(\texttt{00010003H}\gg6)\ \&\ 63=0,\\
  \text{偏移}&=\texttt{00010003H}\ \&\ 63=\texttt{03H}.
  \end{aligned}
  $$

  访问第 0 组，比较 8 路的 **Valid** 与 **Tag**；初始为空，因此全部有效位为 0，必然缺失。块首地址通过将偏移清零得到 `00010000H`，取回包含该地址的 64 B 块；由于有空路，无须替换旧块。记录 Tag、置 Valid、更新组内 LRU，最后按块内偏移完成取指。**确定了映射组不代表已经命中**，命中还必须满足有效位为 1 且 Tag 匹配。

  </Step>
</Steps>

<Callout type="warn" title="命中率、写流量和物理容量是不同的三个量">

本题程序是**读—改—写**，不需通过猜测“写不命中是否分配”来计算首次装入次数；而 8 路 LRU 状态位数需要同时报告所假设的实现方式。若题目改为**纯写**、**数组不对齐**或**统一 I/D Cache**，上述缺失计数可能改变。

</Callout>

</Solution>
</Question>

### 原创强化训练 1 · 首址不对齐与读写策略的双重陷阱

<Question
  id="408-co-large-2020-44-ext1"
  type="essay"
  tags="来源:原创预测题, 科目:计算机组成原理, 考点:跨块对齐, 考点:写策略, 难度:拔高"
>

某机数据 Cache **直接映射**，数据区 4 KB、64 B/块，初始为空；`int` 为 4 B，`k` 在寄存器。按顺序执行：

```c
for (int k = 0; k < 1024; ++k)
    a[k] = a[k] + 1;
```

`a` 的首地址为 `008000E0H`，且每个元素必须先读取、再写回。

1. 数组首元素位于块内第几个字节？覆盖多少主存块？总访问次数、缺失次数、缺失率分别是多少？
2. 若仅将首址改为 `008000C0H`，重复计算缺失次数。说明两个结果为什么不同。
3. 假定 **Write Through** 且每次写回通过主存总线传送 4B，**不合并写操作**，每次 Cache 缺失从主存读入 64B；在首址为 `008000E0H` 的情况下，忽略其他读写流量，累计从主存读取及写回主存的数据各有多少字节？

<Solution>

### 参考答案

1. 块内偏移 **32 B**；覆盖 **65 块**；数据 Cache 访问 **2048 次**，缺失 **65 次**，缺失率 $65/2048\approx\boxed{3.174\%}$。
2. 对齐后只覆盖 **64 块**，缺失 **64 次**。
3. 主存读入 $65\times64=\boxed{4160\text{ B}}$；直写发送 $1024\times4=\boxed{4096\text{ B}}$，总数据流量为 **8256 B**（未计地址、命令和其他开销）。

### 详细解析

<Steps>
  <Step>

  **用「首偏移 + 区间长度」统一计算覆盖块数。**

  `E0H` 模 `40H` 余 `20H`，首字节偏移为 $32$。数组长度 $4096$B，故占块数

  $$
  N_{\mathrm{block}}=\left\lceil\frac{32+4096}{64}\right\rceil=\boxed{65}.
  $$


  这比单纯计算 $4096/64=64$ 多 1 块：前一块只有剩余 32B 被数组使用，最后一块也只用到 32B。

  </Step>
  <Step>

  **为什么不是“Cache 只有 64 行，所以后来访问必然反复缺失”？**

  这是一趟**不回头**的连续扫描。同一主存块内所有数组元素连续处理完，才移动到下一块。因此即使后来的块与前面的块映射到相同 Cache 行，被驱逐的旧块也不会再被读取。每个块只发生第一次读入那一次缺失，所以是 65 次，不需要逐组模拟每一次 LRU/替换。

  </Step>
  <Step>

  **把写回流量与 Cache 缺失分开计算。**

  程序执行了 1024 次数据写回。在明确“每次写回 4B、无写合并”的直写模型下，向主存写入 4096B；另一方面 65 次读缺失各取回整块 64B，主存读入 4160B。即使同一个 `int` 的写入命中了 Cache，也仍向下一级发送直写事务；所以**写流量可以很大，却不增加 Cache 缺失次数**。

  </Step>
</Steps>

<Callout type="info" title="通用公式">

长度为 $L$ 字节、块大小为 $B$ 字节、首址块内偏移为 $r$ 的连续区间，覆盖块数为 $\left\lceil(r+L)/B\right\rceil$（其中 $0\le r<B$ 且 $L>0$）。只有首址块对齐时，它才简化为 $\lceil L/B\rceil$。

</Callout>

</Solution>

### 原创强化训练 2 · 组相联 LRU：相同组内的时间先后决定替换

<Question
  id="408-co-large-2020-44-ext2"
  type="essay"
  tags="来源:原创预测题, 科目:计算机组成原理, 考点:LRU替换, 考点:冲突缺失, 难度:综合"
>

某机使用物理地址、**16 KB 数据区、4 路组相联、64 B/块**的 Cache，采用**精确 LRU**，初始为空。依次读取以下地址，每次只访问 1B：

```text
A=00000000H, B=00001000H, C=00002000H,
D=00003000H, A, E=00004000H, B
```

1. Cache 的组数、组号位数、Tag 位数各是多少？上述五个不同主存块映射到哪些组？
2. 写出七次访问的命中/缺失序列，以及每次访问后目标组的 LRU 顺序（从最近到最久）。第 6、7 次分别淘汰谁？
3. 计算命中率。若精确保存 4 路的全部访问先后次序，理论上最少需要多少**位/组**才能区分所有 LRU 排列？为什么不能把常见的 3 位树形伪 LRU 当成精确 LRU？

<Solution>

### 参考答案

1. **64 组、6 位组号、20 位 Tag**；A～E 均映射**第 0 组**。
2. 命中/缺失依次是 **缺、缺、缺、缺、命中、缺、缺**。第 6 次读 E 淘汰 **B**，第 7 次读 B 淘汰 **C**。
3. 命中率 **$1/7\approx14.29\%$**；4 路精确 LRU 共有 $4!=24$ 种顺序状态，信息论下界为 $\lceil\log_2 24\rceil=\boxed{5\text{ 位/组}}$。

### 详细解析

<Steps>
  <Step>

  **先证明存在组内竞争。**

  $16\mathrm{KB}/(4\times64\mathrm B)=64$ 组，物理地址为 32 位，故 $32-6-6=20$ 位 Tag。组号由物理地址位 $[11:6]$ 决定；所有地址都以 `1000H` 为单位相差，低 12 位均为 0，所以五块全部竞争第 0 组的四路空间。

  </Step>
  <Step>

  **每轮把命中或新放入的块移到 MRU 位置。**

  | 次序 | 块 | 命中？ | 访问后的顺序（MRU → LRU） | 淘汰 |
  | --- | --- | --- | --- | --- |
  | 1 | A | 缺失 | A | — |
  | 2 | B | 缺失 | B,A | — |
  | 3 | C | 缺失 | C,B,A | — |
  | 4 | D | 缺失 | D,C,B,A | — |
  | 5 | A | **命中** | A,D,C,B | — |
  | 6 | E | 缺失 | E,A,D,C | **B** |
  | 7 | B | 缺失 | B,E,A,D | **C** |

  一种常见误判是第 6 次淘汰 A，因为 A 是最早装入的块；但 A **刚在第 5 次命中**，因此是最常使用的块。LRU 判断的是**最近访问**，不是首次装入的时间（FIFO）。

  </Step>
  <Step>

  **区分 4 路 LRU 的状态编码与容量。**

  4 路的可能使用次序有 $4!=24$ 种；要精确区分所有顺序，二进制状态空间至少有 24 种，故最少 5 位/组。实际实现可采用每路 2 位排名（合计 8 位/组，带冗余状态），也可以采用其他精确编码。常见 4 路树形伪 LRU 只需 3 位/组，但它并**不能**区分 24 种严格先后排列，因此某些访问序列会选择与精确 LRU 不同的牺牲路。

  </Step>
</Steps>

</Solution>

## 2021 年第 44 题

<Question
  id="408-co-large-2021-44"
  type="essay"
  tags="来源:2021考研408, 科目:计算机组成原理, 章节:存储器层次结构, 考点:TLB组相联, 考点:LRU, 难度:综合"
>

计算机 M 的**物理主存地址为 24 位**，按字节编址；采用分页存储，**虚拟地址为 30 位、页大小为 4 KB**。TLB 有 **8 组、每组 2 路**，使用 LRU 替换。请回答：

1. 虚拟地址的哪几位是**虚页号（VPN）**，哪几位是**页内偏移**？
2. 用 VPN 的高位作 TLB Tag、低位作组号时，完整虚拟地址的哪些位用于这两个字段？
3. TLB 初始为空，按顺序访问虚页号 **10、12、16、7、26、4、12、20**；发生了哪一个**表项替换**？说明具体过程。
4. 若虚拟地址从 30 位增至 **32 位**，其他参数不变，**每条 TLB 表项**增加多少位？

<Solution>

### 参考答案

1. VPN 为 **`VA[29:12]`（18 位）**；页内偏移为 **`VA[11:0]`（12 位）**。
2. TLB Tag 为 **`VA[29:15]`（15 位）**；组号为 **`VA[14:12]`（3 位）**。
3. **虚页号 4** 对应的 TLB 表项被替换；访问共 **7 次 TLB 缺失、1 次命中**。
4. 每项的 Tag 从 15 位变为 17 位，故每条表项**增加 2 位**。整个 16 项 TLB 的 Tag 存储合计增加 $16\times2=32$ 位，而非“整个 TLB 增 2 位”。

### 详细解析

<Steps>
  <Step>

  **先拆虚拟页与物理页，避免从物理位宽反推 VPN。**

  页长 $4\mathrm{KB}=2^{12}$ B。虚拟地址 30 位，因而虚页号宽 $30-12=18$ 位；物理地址 24 位，因而物理页框号（PFN）宽 $24-12=12$ 位。地址转换只改变页号，不改变页内偏移。

  $$
  VA=[\underbrace{VPN}_{18}\mid\underbrace{offset}_{12}],\qquad PA=[\underbrace{PFN}_{12}\mid\underbrace{offset}_{12}].
  $$


  TLB 用虚页号作为查询键，用物理页框号等作为查询结果；它不是缓存数据的 Cache 行。

  </Step>
  <Step>

  **从 VPN 的低位截取组号，而不是使用虚拟地址最低 3 位。**

  $8=2^3$ 组，需要 3 位组号；VPN 低 3 位正好是完整虚拟地址的 `VA[14:12]`，而非 `VA[2:0]`。剩下 18-3=15 位为 TLB Tag，即 `VA[29:15]`。每组两路，允许两个不同 VPN 的表项共存，只有第三个映射到同一组的新 VPN 到来且均已占满时才需替换。

  </Step>
  <Step>

  **逐次模拟 LRU：命中会刷新使用次序。**

  | 访问 | VPN | 组号 `VPN % 8` | 命中/缺失 | 对应组访问后的状态（MRU → LRU） |
  | ---: | ---: | ---: | --- | --- |
  | 1 | 10 | 2 | 缺失 | 组 2：10 |
  | 2 | 12 | 4 | 缺失 | 组 4：12 |
  | 3 | 16 | 0 | 缺失 | 组 0：16 |
  | 4 | 7 | 7 | 缺失 | 组 7：7 |
  | 5 | 26 | 2 | 缺失 | 组 2：26,10 |
  | 6 | 4 | 4 | 缺失 | 组 4：4,12 |
  | 7 | 12 | 4 | **命中** | 组 4：12,4 |
  | 8 | 20 | 4 | 缺失，淘汰 **4** | 组 4：20,12 |

  第 7 次再访问 12 是本题的陷阱：若只记“先后插入”，就会误把 12 当作 LRU 而淘汰；但既然是 **LRU**，每次命中也会更新使用历史。第 8 次到来时组 4 已满，正确的淘汰目标是 **4**。

  </Step>
  <Step>

  **比较扩展前后的“字段长度”，而非只比较整个地址。**

  30 位增到 32 位，页内偏移 12 位不变，VPN 从 18 位变为 20 位；组号仍是低 3 位，因此 Tag 由 15 位变 17 位。物理地址宽度未变，PFN 仍为 12 位，权限/有效位也不随此改变，故每项增长 2 位。因为表项数是 $8\times2=16$，仅 Tag 存储的总增长为 32 位。

  </Step>
</Steps>

<Callout type="warn" title="TLB 未命中 ≠ 缺页异常">

TLB miss 只表示快表中没有可用翻译项；若页表确认页面已驻留且权限允许，仍可获得物理地址并回填 TLB。是否发生缺页由页表驻留状态决定，而不是由 LRU 淘汰的次数直接决定。

</Callout>

</Solution>
</Question>

### 原创强化训练 2 · TLB 位数预算：单项增位与全表增位

<Question
  id="408-co-large-2021-44-ext2"
  type="essay"
  tags="来源:原创预测题, 科目:计算机组成原理, 考点:TLB容量, 考点:地址扩展, 难度:拔高"
>

继续采用真题的 **30 位虚拟地址、24 位物理地址、4 KB 页面、8 组 2 路 TLB**。现明确硬件实现：每项存放 **Tag、PFN、有效位 1 位、只读/可写权限位 1 位**；每组另外使用 **1 位**记录精确 2 路 LRU 状态。暂不计其他元数据。

1. 求 TLB 的表项数、Tag 和 PFN 位数，以及**全部存储位数**。
2. 虚拟地址扩为 32 位，其余配置不变，计算每项和整个 TLB 的新位数以及总共新增的位数。
3. 若新 TLB 为了区分进程地址空间，又额外给**每项添加 8 位 ASID**（地址空间标识符），则总共需多少位？加入 ASID 后，还能仅凭旧进程的 VPN 相同就视为 TLB 命中吗？

<Solution>

### 参考答案

1. **16 项**；Tag **15 位**、PFN **12 位**；单项 $15+12+2=29$ 位，总计 **$16\times29+8=472$ 位**。
2. Tag 变 **17 位**，单项变 **31 位**，总计 **$16\times31+8=504$ 位**，总共增加 **32 位**。
3. 每项再增 8 位，总计 **$504+16\times8=632$ 位**。不能仅按 VPN 认定命中；还须匹配相应地址空间的 **ASID**（或依上下文切换进行 TLB 刷新）。

### 详细解析

<Steps>
  <Step>

  **把字段宽度和条目数量分别列出。**

  VPN 宽 $30-12=18$，TLB 8 组需要 3 位索引，Tag 宽 $18-3=15$；PFN 宽 $24-12=12$。共有 $8\times2=16$ 项，故 TLB 总存储位数是

  $$
  16\times(15+12+1+1)+8\times1=\boxed{472\text{ 位}}.
  $$


  其中最后的 8 位属于**按组计**的 LRU 状态，不能误算成 16 位，也不能遗漏。

  </Step>
  <Step>

  **扩展地址和增加 ASID 是两次不同的硬件变化。**

  虚地址增两位以后，VPN 和 Tag 各增两位；PFN、权限、有效状态及组数都不变。因此每项增两位，合计 $16\times2=32$ 位。若此后再添加 8 位 ASID，则这是**每项**额外 8 位，故新增 $16\times8=128$ 位，总数为 $504+128=632$ 位。

  </Step>
  <Step>

  **ASID 为什么参与匹配。**

  不同进程可以复用同一虚页号，却把它映射到不同物理页框。ASID 用来区分这些相互冲突的翻译上下文，因此查询键应含“相应 ASID + VPN/组号及 Tag”。只有有效位和查询标记全部匹配，才能复用该翻译。倘若体系结构不使用 ASID，则上下文切换时常需刷新相关 TLB 项，防止错用旧进程映射。

  </Step>
</Steps>

</Solution>
</Question>

## 2022 年第 44 题

<Question
  id="408-co-large-2022-44"
  type="essay"
  tags="来源:2022考研408, 科目:计算机组成原理, 章节:存储器层次结构, 考点:磁盘CHS, 考点:DMA周期挪用, 难度:综合"
>

磁盘驱动器有 **4 个双面盘片**，**每盘面 20000 个磁道**，**每磁道 500 个扇区**，**每扇区记录 512 B 数据**；转速 **7200 rpm**，平均寻道时间 **5 ms**。请回答：

1. 一个扇区的地址信息由哪 **3 个字段**组成？这三个字段至少各占多少位？
2. 访问一个扇区的**平均时间**约为多少？
3. 若采用**周期挪用 DMA**，磁盘控制器的数据缓冲寄存器宽度 **64 位**，读取/写入一个扇区时，DMA 控制器向 CPU（更准确地说，向总线仲裁逻辑）提出多少次总线请求？如果 CPU 同时需要访问主存，DMA 能否获得总线使用权？为什么？

<Solution>

### 参考答案

1. 扇区的 **CHS** 地址由**柱面号（Cylinder）**、**磁头号/盘面号（Head）**和**扇区号（Sector）**组成，分别至少为 **15 位、3 位、9 位**，合计 **27 位**。
2. 平均访问时间约 **$9.18\text{ ms}$**。
3. 按题设“每次 DMA 申请只搬一个 64 位数据字”的周期挪用模型，需 **64 次总线请求**。CPU 同时申请主存时，**DMA 通常优先**获取总线，以避免外设缓冲区来不及转移新数据而溢出，CPU 暂停一个或少数存储周期。

### 详细解析

<Steps>
  <Step>

  **把盘片、盘面、磁道与柱面分开数。**

  一个双面盘片有两个可用记录面，所以 4 个双面盘片共有 **8 个盘面**，需要 8 个磁头（按每个盘面一个磁头的题设模型）。同一半径上、不同盘面的磁道共同形成一个**柱面**，故一个柱面号可与 8 个磁头号组合，而柱面数**仍为 20000**，不能误算为 $8\times20000$。

  | CHS 字段 | 可能取值个数 | 最小位宽 |
  | --- | ---: | ---: |
  | 柱面号 C | 20000 | $\lceil\log_2 20000\rceil=\boxed{15}$ |
  | 磁头号 H | 8 | $\lceil\log_2 8\rceil=\boxed{3}$ |
  | 扇区号 S | 500 | $\lceil\log_2 500\rceil=\boxed{9}$ |

  一次定位时需要 `(柱面号, 磁头号, 扇区号)` 三元组。27 位只是数学上足以编码位置的字段下界，不等于一个扇区的实际硬件格式只用 27 位。

  </Step>
  <Step>

  **求三段时间：寻道 + 平均转动等待 + 单扇区传输。**

  $$
  \begin{aligned}
  T_{\mathrm{rev}}&=\frac{60}{7200}\mathrm{s}=8.3333\mathrm{ms},\\
  T_{\mathrm{seek}}&=5\mathrm{ms},\\
  T_{\mathrm{rotation}}&=\frac{T_{\mathrm{rev}}}{2}=4.1667\mathrm{ms},\\
  T_{\mathrm{transfer}}&=\frac{T_{\mathrm{rev}}}{500}=0.016667\mathrm{ms},\\
  T_{\mathrm{avg}}&=5+4.1667+0.016667=\boxed{9.1833\mathrm{ms}}.
  \end{aligned}
  $$

  平均等待半圈来自目标扇区相对于读写头的起始角位置近似均匀随机；而传送一个扇区只经过整圈的 **$1/500$**。不能把等待半圈与传输整圈当成同一个时间。

  </Step>
  <Step>

  **磁盘的数据块与 DMA 请求所对应的数据量不同。**

  每扇区 $512\text{ B}=4096\text{ bit}$，每次 DMA 传一个 **64-bit = 8B** 的缓冲字，故

  $$
  N_{\mathrm{DMA}}=\frac{512\text{ B}}{8\text{ B/次}}=\boxed{64\text{ 次}}.
  $$


  这是题设教学模型下，每 8B 向主存传输就仲裁一次的**周期挪用请求数**；它不是磁盘控制器发出的“读扇区命令次数”，也不是中断次数。若采用能够一次持有总线连续传很多字的突发 DMA，**总线申请次数可能少于 64**，但数据搬运总量仍为 512B。

  </Step>
  <Step>

  **解释 DMA 优先的原因，而不是背诵一句“DMA 权限大”。**

  磁盘控制器把外设来的数据暂存在容量有限的缓冲器中，若未及时写入主存，后续数据可能覆盖尚未转出的内容。DMA 使用周期挪用可以在 CPU 访问主存的同时，临时抢占**某一个主存传输周期**，快速搬走数据；之后让出总线，CPU 接着完成被延迟的存取。这是常见的优先仲裁选择，具体仍取决于机器的总线仲裁设计。

  </Step>
</Steps>

<Callout type="info" title="容量扩展与时间估算不可混算">

整盘用户数据容量（不含格式化与纠错开销）为 $4\times2\times20000\times500\times512=40{,}960{,}000{,}000\text{ B}$；但**随机访问一个扇区**的时间不随总容量线性增大，而主要由平均寻道、旋转等待以及该扇区的实际传送时间决定。

</Callout>

</Solution>

### 原创强化训练 1 · 连续 128 扇区：不能把随机访问延迟重复 128 次

<Question
  id="408-co-large-2022-44-ext1"
  type="essay"
  tags="来源:原创预测题, 科目:计算机组成原理, 考点:顺序磁盘IO, 考点:DMA, 难度:综合"
>

沿用真题磁盘：**7200 rpm、每磁道 500 扇区、每扇区 512B、平均寻道 5ms**。现需从随机磁道、随机起始扇区开始，**连续读取同一磁道上相邻的 128 个扇区**，不跨磁道；忽略扇区间隙、传输协议及额外排队开销。DMA 数据缓冲寄存器为 **64 位**，且每搬运 64 位需一次总线申请。

1. 本次读取的总数据量与磁盘**纯传输时间**各是多少？
2. 平均总访问时间约是多少？能否用真题的单扇区平均时间乘以 128？
3. 这批数据共需要多少次 64 位 DMA 总线搬运？如果接口改成每次请求后**突发连续搬运 8 个 64 位字**，在理想无异常的情况下，总线仲裁申请次数会变成多少？

<Solution>

### 参考答案

1. 总数据量 **$128\times512=65536\text{ B}=64\text{ KiB}$**；纯传输时间约 **$2.1333\text{ ms}$**。
2. 平均总时间 **$5+4.1667+2.1333\approx\boxed{11.30\text{ ms}}$**，不能把单扇区随机访问时间重复 128 次。
3. 64 位数据搬运共 **8192 次**；如果每次申请可突发搬运 8 个数据字，则需要 **1024 次总线申请**。

### 详细解析

<Steps>
  <Step>

  **单次连续传输只需要一次寻道、一次首扇区旋转等待。**

  读取 128 个连续扇区等于读过 $128/500$ 圈，纯传输时长是

  $$
  T_{\mathrm{data}}=\frac{60}{7200}\times\frac{128}{500}\mathrm{s}\approx2.1333\mathrm{ms}.
  $$


  磁头先寻道、再平均等待半圈，使第一个扇区转到磁头下方；随后沿磁道连续读取，不必每个扇区重新寻道或者再等半圈。

  </Step>
  <Step>

  **写出三项之和。**

  $$
  T\approx T_{\mathrm{seek}}+\tfrac12T_{\mathrm{rev}}+T_{\mathrm{data}}=5+4.1667+2.1333\approx11.30\mathrm{ms}.
  $$


  若误算 $128\times9.18\mathrm{ms}$，意味着每一个相邻扇区都独立经历新的随机寻道和半圈等待，与“同一磁道连续读取”的前提相矛盾。

  </Step>
  <Step>

  **区分 DMA 搬运节拍和一次获得总线的申请次数。**

  $$
  \frac{65536\mathrm B}{8\mathrm{B/字}}=8192\text{ 个 64 位传输字};\qquad\frac{8192}{8}=1024\text{ 次突发申请}.
  $$


  在“周期挪用每次只挪一个字”的模型中，需要 8192 次申请；如果控制器每次仲裁成功后占用总线连传 8 字，则需要 1024 次申请。**数据传送字数没变，减少的是申请次数**；总时长仍会受到实际总线时钟、突发开销及竞争影响。

  </Step>
</Steps>

### 原创强化训练 2 · CHS/LBA 转换与单次 DMA 请求的语义

<Question
  id="408-co-large-2022-44-ext2"
  type="essay"
  tags="来源:原创预测题, 科目:计算机组成原理, 考点:CHS与LBA, 考点:DMA传输, 难度:拔高"
>

为便于计算，假设仍是 **8 个盘面、20000 柱面、每磁道 500 扇区**的理想磁盘，采用**从 0 编号**的 `(C,H,S)`；LBA 也从 0 编号，按照“柱面号优先，其次盘面号，最后扇区号”的顺序连续编号，即

$$
\mathrm{LBA}=C\times(8\times500)+H\times500+S.
$$


DMA 接口一次总线仲裁最多可以连续传送 **4 个 64 位数据字**，每字 8B，假定没有尾部不足 8B 的情况。

1. `LBA=123456` 对应的柱面号 C、盘面号 H、扇区号 S 分别是多少？
2. 最后一个扇区的 CHS 是多少？对应的最大合法 LBA 是多少？
3. 若读取一个 **512B 扇区**，需要多少个 64 位总线数据字？理想情况下至少申请多少次总线使用权？如果使用直写策略的 Cache，是否可以把这里的 DMA 请求次数直接视为 Cache 缺失次数？

<Solution>

### 参考答案

1. **`C=30,H=6,S=456`**。
2. 最后扇区为 **`C=19999,H=7,S=499`**，最大合法 LBA 为 **$8\times20000\times500-1=79{,}999{,}999$**。
3. 需传送 **64 个 64 位数据字**；按每次仲裁可连传 4 字，最少申请 **16 次总线使用权**。DMA 申请次数与 CPU Cache 缺失次数没有一一对应关系。

### 详细解析

<Steps>
  <Step>

  **先除以每柱面的扇区数，再除以每盘面的扇区数。**

  一个柱面包含 $8\times500=4000$ 个扇区。对 `LBA=123456`：

  $$
  C=\left\lfloor\frac{123456}{4000}\right\rfloor=30,\qquad r=123456-30\times4000=3456.
  $$


  余量再按盘面 500 扇区划分：

  $$
  H=\lfloor3456/500\rfloor=6,\qquad S=3456-6\times500=456.
  $$


  反代验证 $30\times4000+6\times500+456=123456$。

  </Step>
  <Step>

  **注意编号从 0 起，使最大地址等于扇区总数减 1。**

  最大的合法字段分别为 $19999,7,499$。因此

  $$
  19999\times4000+7\times500+499=79{,}999{,}999.
  $$


  真正磁盘通常使用 LBA 抽象，现代介质内部布局也未必等于此题的简单 CHS 几何模型；这里完全按照**题目显式给定**的地址映射公式计算。

  </Step>
  <Step>

  **总线请求可以覆盖多个数据字，但不能因此改变主存块的命中定义。**

  $512/8=64$ 个数据字，理想 4 字一突发，$64/4=16$ 次仲裁。Cache 缺失指 CPU 查询数据 Cache 时没有找到所需主存块；DMA 在主存和外设之间搬运数据，触发的总线仲裁次数由其缓冲与突发模式决定。即使 CPU 没有访问相关数据、没有任何 Cache 缺失，DMA 也可产生大量总线传输。因此不能把 16 次 DMA 申请错答成 16 次 Cache 缺失。

  </Step>
</Steps>

</Solution>
</Question>

## 2023 年第 43 题

<Question
  id="408-co-large-2023-43"
  type="essay"
  tags="来源:2023考研408, 科目:计算机组成原理, 章节:存储器层次结构, 考点:Cache组相联, 考点:分页与局部性, 难度:较难"
>

已知计算机 M 字长为 32 位，按字节编址，采用**请求调页**的虚拟存储管理方式，虚拟地址为 32 位，页面大小为 $4\text{ KB}$；数据 Cache 采用 **4 路组相联**，数据区大小为 $8\text{ KB}$，主存块大小为 $32\text{ B}$。执行下面的 C 语言程序段：

```c
for (i = 0; i < 24; i++)
    for (j = 0; j < 64; j++)
        a[i][j] = 10;
```

数组 `a` 按**行优先**存放，虚拟首地址为 `00422000H`，`sizeof(int)=4`。执行前整个数组不在主存，执行中不发生页面置换。

1. 数组分布于多少个页面？对数组的访问触发几次缺页异常？每次缺页时的故障虚拟地址是什么？
2. 不考虑变量 `i` 和 `j`，上述访问是否具有**时间局部性**？为什么？
3. 虚拟地址 $A_{31}\sim A_0$ 中，哪些位作 Cache 块内地址、哪些位作组号？`a[1][0]` 的虚拟地址和对应 Cache 组号是多少？
4. 数组占多少主存块？假定其访问不受其他数据造成的 Cache 冲突影响，计算原循环的 Cache 命中率。若交换内外循环顺序，先遍历列、再遍历行，命中率是多少？

<Solution>

### 参考答案

| 小问 | 结果 |
| --- | --- |
| (1) | **2 页**；**2 次缺页**；故障地址分别为 `00422000H`、`00423000H` |
| (2) | **无明显时间局部性**：数组中每个元素只被写一次；原循环有很强的**空间局部性** |
| (3) | 块内偏移 **$A_4\sim A_0$**（5 位），组号 **$A_{10}\sim A_5$**（6 位）；`a[1][0]` 地址为 **`00422100H`**，组号 **8** |
| (4) | **192 块**；按缺失时**写分配**的考试模型，两种循环次序均为 **$87.5\%$** |

### 解题过程

<Steps>
  <Step>

  **先把二维数组变成连续字节区间，再与页面边界比较。**

  一个数组行占 $64\times4=256\mathrm B$，整个数组共

  $$
  L=24\times64\times4=6144\mathrm B.
  $$


  页大小 $4096\mathrm B$；首地址 `00422000H` 的低 12 位为 0，正好在页边界。第 1 页装下 $4096/256=16$ 行，即 `a[0][0]` 至 `a[15][63]`；下一次写入 `a[16][0]` 时访问新页。首次页地址为

  $$
  \texttt{00422000H}+16\times256=\texttt{00423000H}.
  $$


  剩余 $2048\mathrm B$ 位于第二页，因此恰好跨两页。**缺页异常由首次触及未驻留页的指令引起**，不是由页面中每个元素分别引起；无换出条件下发生 2 次。

  </Step>
  <Step>

  **弄清楚两种局部性在描述什么。**

  - **时间局部性**：短时间内重复访问**同一地址或同一数据**。本题每个 `a[i][j]` 只写一次，因此数组数据本身不体现时间复用。
  - **空间局部性**：访问过某地址后，短时间内访问附近地址。原循环让 `j` 连续增加，每次地址增加 4B，同一个 32B Cache 块的 8 个 `int` 会紧邻访问，因而有显著空间局部性。

  交换循环后的单次步长是 $64\times4=256\mathrm B$，相邻两次数据访问远离，**单凭这个事实并不足以推出必定全缺失**：仍要计算每组的活跃块数量。

  </Step>
  <Step>

  **计算 Cache 结构与目标地址，注意组号在页内偏移之中。**

  $$
  \begin{aligned}
  \text{总 Cache 行数}&=8192/32=256,\\
  \text{组数}&=256/4=64=2^6,\\
  \text{块内偏移位数}&=\log_2 32=5.
  \end{aligned}
  $$


  因而组号占 6 位，对应地址 $[10:5]$，块内偏移是 $[4:0]$。即使 Cache 采用物理标记，4KB 页面以内的低 12 位在虚实地址翻译时保持不变，所以这两段字段可以**直接由虚拟地址求得**；真正判定命中仍需要物理 Tag。

  行优先地址公式：

  $$
  VA(a[i][j])=\texttt{00422000H}+4(64i+j).
  $$


  代入 $i=1,j=0$：

  $$
  VA(a[1][0])=\texttt{00422100H},\qquad
  \mathrm{set}=\left(\left\lfloor\frac{VA}{32}\right\rfloor\bmod64\right)=8.
  $$


  </Step>
  <Step>

  **行优先：按首次触及不同块的次数计算缺失。**

  数组首地址 32B 对齐；每块容纳 $32/4=8$ 个整数，故

  $$
  N_{\rm blocks}=6144/32=192,\qquad N_{\rm accesses}=24\times64=1536.
  $$


  若**写未命中时把相应块分配并装入 Cache**，一个新块第 1 次写缺失，随后本块其余 7 次写命中。扫描方向不再回到旧块，所以即使缓存不能长久留住全部块，也不会增加重访缺失。

  $$
  N_{\rm miss}=192,\quad N_{\rm hit}=1536-192=1344,\quad H=\frac{1344}{1536}=\boxed{87.5\%}.
  $$


  </Step>
  <Step>

  **列优先：用“每组同时驻留几块”判断能否复用。**

  固定列 $j$，逐行扫描时，连续两次访问的地址相差 $256\mathrm B=8$ 个主存块。所以组号每次加 $8$，对 64 取模；访问遍历了组号为

  $$
  g,g+8,g+16,\dots,g+56\pmod{64}
  $$


  的 **8 个组**。24 行分到这 8 组，每组对应 $24/8=3$ 个不同数据块。4 路组相联至少可容纳这 3 个块，因此从同一个 8 列组（即同一 Cache 块所含的 8 个连续列）的第 2 列起，回访每个行块时仍然命中。到下一组 8 列时再各有一次首次缺失。

  共 $64/8=8$ 轮、每轮首次各装 24 个块：

  $$
  N_{\rm miss}=8\times24=192,\qquad H=1-192/1536=\boxed{87.5\%}.
  $$


  <Callout type="warn" title="决定列访问是否抖动的是相联度，不是单纯的步长">

  把本题 4 路改成 2 路、仍为 64 组，并使用 LRU 时，3 个活跃块会在每组交替驱逐，列扫描就可能变成**全部缺失**。这个反例说明：**局部性、工作集大小和冲突映射**需要一起分析。

  </Callout>

  </Step>
</Steps>

### 易错点与边界说明

本题是纯写入程序。**写分配（Write Allocate）**与**写不分配（No Write Allocate）**的策略如果不同，缺失数也不同：在初始 Cache 为空、没有读取数组数据、采取写不分配时，每个写入都可能直接写向下一级，导致 $1536$ 次 Cache 写缺失。真题给出的 $87.5\%$ 是默认“写未命中装块”的分析口径，应说明此前提，不能把它当成所有 Cache 写策略的必然结果。缺页次数和 Cache 缺失次数也不可混淆。

</Solution>

### 原创强化训练 1 · 写分配、相联度与列扫描极端抖动

<Question
  id="408-co-large-2023-43-ext1"
  type="essay"
  tags="来源:原创预测题, 科目:计算机组成原理, 章节:存储器层次结构, 考点:Cache相联冲突, 考点:写分配与LRU, 难度:拔高"
>

沿用真题中的 `int a[24][64]`、每元素 4B、32B 块、数组首地址 `00422000H`，改用数据区 **4KB、2 路组相联、LRU、写分配** 的 Cache；初始为空，没有其他数据访问。依次比较以下两段程序：

```c
// 甲：逐行
for (int i=0; i<24; ++i)
    for (int j=0; j<64; ++j) a[i][j]=10;

// 乙：逐列
for (int j=0; j<64; ++j)
    for (int i=0; i<24; ++i) a[i][j]=10;
```

1. 新 Cache 有多少组？固定列时，相邻两行数据块映射的组号间隔为多少？
2. 甲、乙各有多少次访问、多少次 Cache 缺失？给出命中率。
3. 保持 **64 组**不变，若要使乙也达到 $87.5\%$ 的命中率，至少需改成几路组相联？在给定访问规律下说明最小性。

<Solution>

### 参考答案

1. **64 组**；固定列相邻行的主存块号差 $256/32=8$，组号模 64 后间隔为 **8**。
2. 每段均写 $1536$ 次。甲缺失 **192 次**、命中率 **$87.5\%$**；乙缺失 **1536 次**、命中率 **$0\%$**。
3. 至少改成 **3 路**（组数仍为 64、块大小仍为 32B），即可同时容纳每个被使用组的 3 个活跃行块。

### 解题过程

<Steps>
  <Step>

  **组数与活跃组范围。** $4096/(2\times32)=64$ 组。列固定时行步长 $256\mathrm B$，每增加一行跳过 8 个块，所以组号循环每次加 8；24 行只占 8 个不同组，平均每组有 $24/8=3$ 个块需要轮流访问。

  </Step>
  <Step>

  **甲：顺序访问同一块的 8 个数。** 每个新块只有首次写缺失，此后 7 次命中。共有 $1536/8=192$ 块，故缺失 192、命中 1344，命中率 $7/8$。相联度虽低，旧块被淘汰后也不再需要，因此不产生额外缺失。

  </Step>
  <Step>

  **乙：2 路 LRU 如何产生 3 块循环抖动。** 针对其中任意一个被访问的组，假设其 3 个竞争块记为 $A,B,C$。第 1 列顺序访问 $A,B,C$，其中 $A$ 在 $C$ 装入时被淘汰。第 2 列仍按 $A,B,C$ 的顺序：请求 $A$ 时将最久未使用的 $B$ 淘汰；请求 $B$ 时淘汰 $C$；请求 $C$ 时淘汰 $A$。以后每列都重复这个状态循环，**每次访问都是缺失**。

  因此 $N_{\rm miss}=24\times64=1536$，命中率为 0。这里不存在“跨列仍在 Cache 中”的例外，原因是每次重新轮到某块之前恰有另外 2 个同组块被使用。

  </Step>
  <Step>

  **提升到 3 路的临界条件。** 同一 8 列区间内，每组只需要保存 3 个不同块，3 路可容纳全部 3 个，写入当前块的首次访问失配后不再因本组其他块置换而丢失。少于 3 路则按给定 LRU 顺序抖动，所以最小为 3 路。

  若容量改变时意外也改变组数，竞争分布可能发生变化；这里明确**组数保持 64**，才能将“最小 3 路”作为准确结论。

  </Step>
</Steps>

### 原创强化训练 2 · 非对齐数组同时跨页和跨块

<Question
  id="408-co-large-2023-43-ext2"
  type="essay"

>

一个 `int b[10][10]` 按行优先存储，每个 `int` 为 4B，首地址是 `00422FF0H`；页长 4KB、Cache 块长 32B，Cache 初始为空，整个扫描过程中**无块置换**。整个数组开始时不在主存，发生缺页后按需装页且不换出。

执行如下纯写循环，每个赋值算一次数据 Cache 访问：

```c
for (int i=0; i<10; ++i)
    for (int j=0; j<10; ++j)
        b[i][j]=1;
```

1. 分别给出第 1 次、第 2 次缺页的访问元素及其虚拟地址，求总缺页数。
2. 数组涉及多少个主存块？在**写分配**下缺失多少次、命中率多少？
3. 若改为**写不分配**，且全程没有其他操作把这些块载入 Cache，命中率是多少？说明为何写策略没有改变第 1 问的缺页次数。

<Solution>

### 参考答案

1. `b[0][0]` 在 `00422FF0H` 首次触及第 1 页；`b[0][4]` 在 `00423000H` 首次触及第 2 页；共 **2 次缺页**。
2. 占 **13 个 32B 块**；写分配时缺失 **13 次**、命中 **87 次**，命中率 **$87\%$**。
3. 写不分配时 **100 次写均缺失，命中率为 0**；缺页仍是 2 次，因为缺页取决于虚拟页是否驻留，并不由写缺失是否将块装入 Cache 决定。

### 解题过程

<Steps>
  <Step>

  **分页：关注页内偏移。** `...FF0H` 距 4KB 页末还剩 `10H`（16B），正好容纳 $16/4=4$ 个整数，因此 `b[0][0]` 到 `b[0][3]` 在第一页，`b[0][4]` 开始属于下一页。数组长 $100\times4=400\mathrm B$，跨界之后还剩 384B，不会触及第三页。

  </Step>
  <Step>

  **Cache：关注的是另一个边界。** 起始地址对 32B 的余数为 16B，总覆盖区间为 400B。首块只利用尾部 16B，之后覆盖的主存块数

  $$
  N=\left\lceil\frac{16+400}{32}\right\rceil=13.
  $$


  写分配且不发生替换时，按地址递增扫描，每块第一个元素写缺失、随后同块元素写命中：$100-13=87$ 次命中。

  </Step>
  <Step>

  **同样都是“没有”，缺页与写缺失的含义不同。** 若采用写不分配，第一次写缺失并不把该块放入 Cache，后面即使访问同一块的其他字节也依然缺失，故 100 次写均缺失。**页面首次不驻留**仍需操作系统装页，这与 Cache 是否在写缺失时分配缓存块没有关系；题设页不会换出，因此始终仅缺页 2 次。

  </Step>
</Steps>

## 2025 年第 43 题

<Question
  id="408-co-large-2025-43"
  type="essay"
  tags="来源:2025考研408, 科目:计算机组成原理, 章节:存储器层次结构, 考点:VIPT与AMAT, 考点:Cache与缺页率, 难度:较难"
>

计算机 M 字长 32 位，按字节编址。数据 Cache 数据区为 **32KB**，采用 **8 路组相联**、64B 主存块，命中时间为 **2 个时钟周期**，**缺失损失**为 **200 个时钟周期**；分页管理的页面大小为 **4KB**。程序 P 有以下 C 代码：

```c
int x, d[2048], i;
...
for (i = 0; i < 2048; i++)
    d[i] = d[i] / x;
...
```

数组 `d` 的虚拟首地址为 `01800020H`。

1. 主存地址的 Cache 组号和块内地址字段分别占几位？虚拟地址中哪些位可作为 Cache 组索引？
2. `d[100]` 的虚拟地址及所在主存块对应的 Cache 组号是多少？
3. 假设循环代码已经在 Cache 中，`i`、`x` 已在寄存器中，数组 `d` 已在主存但开始时不在数据 Cache。求 `d[0]` 的块内偏移（十六进制）、执行循环对 `d` 的 Cache **缺失率**（保留两位小数）和数组元素的**平均访问时间**。
4. 数组分布于多少页？若执行前数组不在主存，执行期间不换出，访问 `d` 会触发几次缺页？

<Solution>

### 参考答案

1. 组号 **6 位**，块内偏移 **6 位**；可直接用虚拟地址 **$VA_{11}\sim VA_6$** 作 Cache 组索引。
2. `d[100]` 的虚拟地址 **`018001B0H`**，Cache 组号 **6**。
3. `d[0]` 块内偏移 **`20H`**；数组共发生 **129 次 Cache 缺失 / 4096 次 Cache 访问**，缺失率 **$3.15\%$**；平均访问时间 **$8.30$ 个时钟周期/次访问**。
4. 数组跨 **3 个 4KB 页**；无再次换出时 **3 次缺页**。

### 解题过程

<Steps>
  <Step>

  **先求 Cache 的行数、组数及地址字段。**

  $$
  \begin{aligned}
  N_{\rm line}&=\frac{32\times1024}{64}=512,\\
  N_{\rm set}&=\frac{512}{8}=64=2^6,\\
  b_{\rm offset}&=\log_2 64=6,\qquad b_{\rm index}=\log_2 64=6.
  \end{aligned}
  $$


  物理地址中的**低 6 位** $[5:0]$ 是块内地址，紧接着的 $[11:6]$ 是组号。页面 4KB $=2^{12}$B，页内偏移 $[11:0]$ 在页表翻译时保持不变，因此即使尚未获取物理页框号，也可以用相同的虚拟地址位 $VA_{11}\sim VA_6$ 求组号。

  <Callout type="info" title="VIPT 的经典约束">

  如果 Cache 使用**虚拟索引、物理标记（VIPT）**，为了让组号完全来自页内偏移而不需要复杂的别名处理，常用条件为

  $$
  b_{\rm index}+b_{\rm offset}\le b_{\rm pageOffset}.
  $$


  本题 $6+6=12$，恰好满足。**组索引已知不意味着 Tag 命中已知**，Tag 仍须在物理地址转换后比较。

  </Callout>

  </Step>
  <Step>

  **计算 `d[100]`，严格按字节寻址。**

  $$
  100\times\operatorname{sizeof(int)}=100\times4=400=\texttt{190H}.
  $$


  故地址为

  $$
  VA(d[100])=\texttt{01800020H}+\texttt{190H}=\boxed{\texttt{018001B0H}}.
  $$


  组号来自地址低 12 位中 $[11:6]$，可先按 64B 整除：

  $$
  \mathrm{set}=\left\lfloor\frac{\texttt{1B0H}}{\texttt{40H}}\right\rfloor\bmod64=6.
  $$


  <Callout type="warn" title="别把块内偏移与组号弄反">

  `1B0H` 除以 `40H` 商为 6、余数为 `30H`：**商（再对组数取模）**决定组号，**余数**才是该元素的块内字节偏移。

  </Callout>

  </Step>
  <Step>

  **起始非对齐：块数不能仅用数组长度除以块长。**

  `d[0]` 的地址低 6 位是 `20H`，表示起始位置距所属块首 32B。数组数据量

  $$
  L=2048\times4=8192\mathrm B.
  $$


  连续占用的块数为

  $$
  N_{\rm blocks}=\left\lceil\frac{32+8192}{64}\right\rceil=\boxed{129}.
  $$


  为什么这 129 块能各只缺失一次？前后两个“半块”加 127 个满块，分到 64 个组中，因起始块号整除组数的周期关系，每组最多容纳 $\lceil129/64\rceil=3$ 个不同数据块，小于每组的 8 路。循环也只沿地址递增扫描，没有额外数据竞争，故无需因冲突反复调入同一块。

  </Step>
  <Step>

  **分母是 Cache 访问次数，不是循环迭代次数。**

  每次执行 `d[i]=d[i]/x` 必须先读 `d[i]`，再写回结果：

  $$
  N_{\rm read}=2048,\qquad N_{\rm write}=2048,\qquad N_{\rm access}=4096.
  $$


  数组块原先不在 Cache，每块首次**读**发生一次缺失并将块载入，随后写同一元素已命中；无需为此处再讨论纯写情况下的写分配分歧。于是

  $$
  r=\frac{129}{4096}=0.031494140625\approx\boxed{3.15\%}.
  $$


  </Step>
  <Step>

  **AMAT：不能把“缺失损失”误当“缺失时的总时间”。**

  缺失损失 200 周期指命中访问时间**以外的额外停顿**，因此

  $$
  \begin{aligned}
  \mathrm{AMAT}&=T_{\rm hit}+r\times T_{\rm missPenalty}\\
  &=2+\frac{129}{4096}\times200=8.298828125\\
  &\approx\boxed{8.30\text{ 周期/次 Cache 访问}}.
  \end{aligned}
  $$


  如果要问一个数组元素的完整读—改—写序列的**平均 Cache 服务时间之和**，忽略 ALU 除法本身的运算时间，应乘以 2，约为 $16.60$ 周期/元素。两种口径在不同题目中容易混淆，而本题沿用“每次数组 Cache 访问”口径。

  </Step>
  <Step>

  **页数再单独按 4KB 计算。**

  低 12 位页内偏移为 `020H`（32B），正好跨越 8192B 的数组本应占 2 页，却因首地址不是页边界而延伸到第 3 页：

  $$
  N_{\rm pages}=\left\lceil\frac{32+8192}{4096}\right\rceil=\boxed{3}.
  $$


  首次到达的三个虚页地址分别为 `01800000H`、`01801000H`、`01802000H`，每个页只因首次读取一次而产生一处缺页；题目没有再次换出，因此共 3 次。

  </Step>
</Steps>

### 解题技巧

| 问题 | 看哪个计数单位 | 本题结果 |
| --- | --- | --- |
| 数据 Cache 缺失 | 不同 **64B 主存块**的首次读取 | 129 次 |
| Cache 缺失率 | 读 + 写的 **Cache 访问次数** | $129/4096$ |
| 数组平均 Cache 访问时间 | 命中耗时 + 缺失率 × **额外惩罚** | 8.30 周期 |
| 缺页异常 | 不驻留的 **4KB 虚拟页**被首次触及 | 3 次 |

</Solution>

### 原创强化训练 1 · 对齐优化、页边界与每元素服务时间

<Question
  id="408-co-large-2025-43-ext1"
  type="essay"
  tags="来源:原创预测题, 科目:计算机组成原理, 章节:存储器层次结构, 考点:数组对齐优化, 考点:AMAT计算口径, 难度:较难"
>

仍采用原题的 **2048 个 4B 整数、64B Cache 块、4KB 页面、8 路 64 组 Cache、2 周期命中时间和 200 周期额外缺失损失**。每个元素先读后写，数组已经在主存、Cache 起初为空，不发生其他访问造成的冲突。

比较两个版本：甲的首地址为 `01800020H`（原题），乙仅把首地址改为 **`01800000H`**。

1. 甲、乙各占几个 Cache 块、几个虚拟页？甲首次进入第 2 页和第 3 页的元素下标是多少？
2. 两版分别有多少次 Cache 访问和 Cache 缺失？求缺失率及每次 Cache 访问的 AMAT。
3. 仅按读写 `d[i]` 的 Cache 时间计算，每个元素的平均服务时间分别为多少？能否将这个数当作包括**除法指令计算时间**的完整循环迭代时间？

<Solution>

### 参考答案

| 指标 | 甲：`01800020H` | 乙：`01800000H` |
| --- | ---: | ---: |
| 占用 Cache 块 | 129 | 128 |
| 跨越页面 | 3 | 2 |
| 数组 Cache 访问次数 | 4096 | 4096 |
| Cache 缺失次数 | 129 | 128 |
| 缺失率 | $3.15\%$ | $3.13\%$ |
| AMAT（每次访问） | **8.30 周期** | **8.25 周期** |
| 平均每个元素的两次 Cache 访问耗时 | **16.60 周期** | **16.50 周期** |

甲首次访问第 2 页的是 **`d[1016]`**，首次访问第 3 页的是 **`d[2040]`**。上述每元素耗时**仅为数据 Cache 访问部分**，不能代替包含除法、地址计算、循环控制等开销的完整执行时间。

### 解题过程

<Steps>
  <Step>

  **页边界和块边界分别求。** 甲起始偏移 32B，页面大小 4096B：第一页还可放 $(4096-32)/4=1016$ 个 `int`，所以第二页始于 `d[1016]`；第二页随后可容纳 $4096/4=1024$ 个，第三页始于 `d[2040]`，最后还有 8 个数。乙始于页边界，连续 2048 个整数恰占 2 页。

  同理，甲占 $\lceil(32+8192)/64\rceil=129$ 块，乙占 $8192/64=128$ 块。

  </Step>
  <Step>

  **计算两种缺失率和 AMAT。** 总读写数都为 $2\times2048=4096$。甲 $r=129/4096$，乙 $r=128/4096=0.03125$。乙 AMAT 为

  $$
  2+200\times\frac{128}{4096}=2+6.25=8.25\text{ 周期}.
  $$


  甲 AMAT 为 $2+200\times129/4096\approx8.30$ 周期。题目百分数保留两位时，乙 $3.125\%$ 按通常四舍五入规则写为 $3.13\%$；不要提前把百分数舍入后再代入 AMAT，否则会丢精度。

  </Step>
  <Step>

  **区分“每次访存”与“每个元素”的分母。** 每元素读一次、写一次，故两次访问的期望 Cache 服务时间等于 $2\times\mathrm{AMAT}$：甲约 $16.60$ 周期，乙 $16.50$ 周期。虽然少了一个 Cache 块仅节省一次缺失惩罚，但对大循环性能仍然有贡献。真正每迭代时钟数还应计入除法、取指、循环条件判断等开销，题干没有这些数据，因此不能求得完整执行时间。

  </Step>
</Steps>

</Solution>

### 原创强化训练 2 · 直写与写分配独立、读改写改变命中率

<Question
  id="408-co-large-2025-43-ext2"
  type="essay"
  tags="来源:原创预测题, 科目:计算机组成原理, 章节:存储器层次结构, 考点:写分配与写不分配, 考点:读改写, 难度:拔高"
>

某计算机的 Cache **直写**、32KB 数据区、8 路组相联、64B 块，初始为空。一个 64B 边界对齐的 `int q[1024]` 不在 Cache，中间没有其他数据访问、没有替换。分别考虑两种**写未命中**策略：甲为写分配，乙为写不分配。

先执行一次**纯写**循环：

```c
for (i=0; i<1024; ++i) q[i]=1;
```

另考虑一项**独立实验**：从空 Cache 重新开始，执行一次**读—改—写**循环：

```c
for (i=0; i<1024; ++i) q[i]=q[i]+1;
```

1. 纯写实验在甲、乙策略下各有多少次 Cache 访问、缺失及命中？
2. 读—改—写实验在甲、乙策略下各有多少次访问、缺失及命中？指出为什么两者结果相同。
3. `Write Through` 是否必然推出 `Write Allocate`？如果每次写都必须向主存更新，能否断言两种方案产生同样的“主存块读入”次数？

<Solution>

### 参考答案

1. 纯写：每次实验均 **1024 次 Cache 写访问**。**甲**缺失 **64**、命中 **960**，命中率 **93.75%**；**乙**缺失 **1024**、命中 **0**，命中率 **0%**。
2. 读—改—写：每次实验 **2048 次 Cache 访问**，其中 **64 次读缺失**，其余 **1984 次命中**，命中率 **96.875%**；**甲乙相同**。
3. **不能**。直写/回写决定写入是否同步传给下一级；写分配/不分配决定写未命中是否取入块。纯写时甲调入 64 个块，乙可不调入任何块，虽然两者都需要向主存提交写入。

### 解题过程

<Steps>
  <Step>

  **确定块的数量。** 数组总大小 $1024\times4=4096\mathrm B$，起始与 64B 边界对齐，所以恰占 $4096/64=64$ 块，每块包含 $64/4=16$ 个整数。

  </Step>
  <Step>

  **纯写：缓存分配策略直接影响后续命中。** 甲首次写某块时未命中并将整块装入，随后同块的 15 次写命中，故每块恰 1 次缺失、15 次命中。乙写未命中时直接向主存/写缓冲提交数据但不装块，此时没有任何其他访问把块载入 Cache，下一元素写相同块仍未命中，故 1024 次均缺失。

  </Step>
  <Step>

  **读改写：无论写分配策略如何，先读都会装块。** 每块第一个元素先读，此次读缺失，按通常读缺失处理将整块载入 Cache。紧接着写回该元素已经命中；随后本块另外 15 个元素的读与写也均命中。所以整个实验的 2048 次访问中恰有 64 次缺失：

  $$
  H=\frac{2048-64}{2048}=\frac{1984}{2048}=\boxed{96.875\%}.
  $$


  本问没有把处理器的写缓冲或总线传输并行性混入 Cache 命中次数；如果题目要求主存流量，应另按写合并、写穿透及替换时机计算。

  </Step>
</Steps>

</Solution>
</Question>
