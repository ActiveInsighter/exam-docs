**81. 2013 年第 45 题**

某博物馆最多可以容纳 500 人同时参观，只有一个出入口，且该出入口一次仅允许一个人通过。参观者的活动过程如下：

```text
cobegin
参观者进程 i:
{
    ...
    进门；
    ...
    参观；
    ...
    出门；
    ...
}
coend
```

请添加必要的信号量和 P、V（或 `wait()`、`signal()`）操作，实现上述过程中的互斥与同步。要求写出完整过程，并说明信号量的含义和初值。

<ExamSolution>

<ExamAnswer>

设置两个信号量：

- `mutex=1`：控制出入口的互斥使用；
- `empty=500`：表示博物馆还可容纳的人数。

</ExamAnswer>

<ExamExplanation>

出入口一次只能通过一人，因此“进门”和“出门”都必须由同一个互斥信号量 `mutex` 保护。

博物馆最多同时容纳 500 人，因此用计数信号量 `empty` 表示剩余容量。参观者进门前必须先执行 `P(empty)`；离开博物馆后执行 `V(empty)`，归还一个容量名额。

```c
semaphore empty = 500;
semaphore mutex = 1;

visitor() {
    P(empty);          // 申请一个馆内容量名额

    P(mutex);
    进门;
    V(mutex);

    参观;

    P(mutex);
    出门;
    V(mutex);

    V(empty);          // 离馆后归还容量名额
}
```

这里不能只设置 `empty`，因为即使馆内人数没有达到 500，仍可能有两个人同时试图通过唯一出入口；也不能只设置 `mutex`，因为那样无法限制馆内总人数。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

**82. 2013 年第 46 题**

某计算机主存按字节编址，逻辑地址和物理地址都是 32 位，页表项大小为 4 字节。请回答下列问题。

1. 若采用一级页表，逻辑地址格式为：

| 页号 | 页内偏移量 |
| --- | --- |
| 20 位 | 12 位 |

页的大小是多少字节？页表最大占用多少字节？

2. 若采用二级页表，逻辑地址格式为：

| 页目录号 | 页表索引 | 页内偏移量 |
| --- | --- | --- |
| 10 位 | 10 位 | 12 位 |

设逻辑地址为 `LA`，分别给出页目录号和页表索引的表达式。

3. 采用第 1 问中的一级页表。某代码段起始逻辑地址为 `00008000H`，长度为 8KB，被装载到从物理地址 `00900000H` 开始的连续主存空间中。页表从物理地址 `00200000H` 开始连续存放，示意图如下。请计算该代码段对应的两个页表项的物理地址、两个页表项中的页框号，以及代码页面 2 的起始物理地址。

<img src="/img/408/past-exams-large-questions/03-操作系统/assets/2013-46-figure-003.svg" alt="2013 年第 46 题页表与代码页面映射示意图" />

<ExamSolution>

<ExamAnswer>

1. 页大小为 $2^{12}=4096\text{ B}=4\text{ KB}$；一级页表最大占用 $2^{20}\times4\text{ B}=4\text{ MB}$。
2. 页目录号：`((unsigned int)LA >> 22) & 0x3FF`；页表索引：`((unsigned int)LA >> 12) & 0x3FF`。
3. 两个页表项的物理地址分别为 `00200020H`、`00200024H`；页框号分别为 `00900H`、`00901H`；代码页面 2 的起始物理地址为 `00901000H`。

</ExamAnswer>

<ExamExplanation>

### （1）页大小与一级页表大小

页内偏移量为 12 位，因此页大小为

$$
2^{12}\text{ B}=4096\text{ B}=4\text{ KB}.
$$

页号为 20 位，因此虚拟地址空间最多有

$$
2^{20}
$$

个虚拟页。每个页表项占 4 B，所以一级页表最大大小为

$$
2^{20}\times4\text{ B}=2^{22}\text{ B}=4\text{ MB}.
$$

### （2）二级页表地址字段

32 位逻辑地址从高到低依次为：10 位页目录号、10 位页表索引、12 位页内偏移。

因此页目录号可写成

```c
((unsigned int)LA >> 22) & 0x3FF
```

页表索引可写成

```c
((unsigned int)LA >> 12) & 0x3FF
```

其中 `0x3FF` 的低 10 位全为 1，用于保留所需的 10 位字段。原材料中将右移运算符的一处 `>>` 识别成了单个 `>`，这里按地址分解规则修正。

### （3）两个页表项与物理页框

代码段起始逻辑地址为 `00008000H`。页大小为 `1000H`，所以它从虚拟页 8 开始；长度为 8KB，正好占两个页面，即虚拟页 8 和虚拟页 9。

页表基址为 `00200000H`，每个页表项 4 B，因此虚拟页 8 的页表项地址为

$$
\texttt{00200000H}+8\times4
=\texttt{00200020H}.
$$

虚拟页 9 的页表项地址为

$$
\texttt{00200000H}+9\times4
=\texttt{00200024H}.
$$

代码被连续装入从 `00900000H` 开始的物理空间，因此两个物理页分别从

- `00900000H` 开始，对应页框号 `00900H`；
- `00901000H` 开始，对应页框号 `00901H`。

所以代码页面 2 的起始物理地址为

$$
\boxed{\texttt{00901000H}}.
$$

</ExamExplanation>

</ExamSolution>

**83. 2014 年第 46 题**

文件 $F$ 由 200 条记录组成，记录从 1 开始编号。用户打开文件后，欲将内存中的一条记录插入文件 $F$，使其成为第 30 条记录。请回答下列问题，并说明理由。

1. 若文件系统采用连续分配方式，每个磁盘块存放一条记录，且文件 $F$ 存储区域前后均有足够的空闲磁盘空间，完成上述插入操作最少需要访问多少次磁盘块？$F$ 的文件控制块（FCB）中哪些内容会发生改变？
2. 若采用链接分配方式，每个磁盘块存放一条记录和一个链接指针，完成上述插入操作需要访问多少次磁盘块？若每个磁盘块大小为 1KB，其中 4B 存放链接指针，则该文件系统支持的文件最大长度是多少？

<ExamSolution>

<ExamAnswer>

1. 最少访问 59 次磁盘块；FCB 中的文件起始块号和文件长度需要改变。
2. 需要访问 31 次磁盘块；最大文件长度为

$$
2^{32}\times(1024-4)\text{ B}=2^{32}\times1020\text{ B}=4080\text{ GB},
$$

其中按 $1\text{ GB}=2^{30}\text{ B}$ 计算。

</ExamAnswer>

<ExamExplanation>

### （1）连续分配

原文件连续占 200 个磁盘块。要把新记录插入为第 30 条，可以有两种移动方向：

- 将原第 30～200 条记录整体向后移动，需要移动 171 条记录；
- 利用文件前方的空闲空间，将原第 1～29 条记录整体向前移动 1 个块，只需移动 29 条记录。

为了使磁盘访问次数最少，应选择第二种。

移动一条已有记录需要“读出 + 写回”两次磁盘访问，因此移动前 29 条记录需要

$$
29\times2=58
$$

次访问；再把待插入的新记录写入新的第 30 个位置，需要 1 次访问，所以总计

$$
58+1=59
$$

次。

由于文件整体的连续存储区向前扩展了一个块，FCB 中至少需要更新：

- 文件起始块号；
- 文件长度（由 200 条记录变为 201 条记录，对应占用块数也增加 1）。

### （2）链接分配

要在第 29 条记录之后插入新记录，必须沿链从第 1 块开始找到第 29 块，因此需要读取前 29 个磁盘块，共 29 次访问。

找到第 29 块后：

1. 将其原“下一块”指针复制给新块，并把新块写入磁盘：1 次；
2. 修改第 29 块的链接指针，使其指向新块，再写回第 29 块：1 次。

因此共需

$$
29+1+1=31
$$

次磁盘访问。

每个链接指针占 4B，即 32 位，最多可表示 $2^{32}$ 个不同磁盘块。每个 1KB 磁盘块中真正存放文件数据的空间为

$$
1024-4=1020\text{ B}.
$$

所以最大文件长度为

$$
2^{32}\times1020\text{ B}=4080\text{ GB}.
$$

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

**84. 2014 年第 47 题**

系统中有多个生产者进程和多个消费者进程，共享一个能存放 1000 件产品的环形缓冲区，初始为空。

当缓冲区未满时，生产者可以放入一件产品，否则等待；当缓冲区非空时，消费者可以取走一件产品，否则等待。另要求：**一个消费者进程必须连续取出 10 件产品后，其他消费者进程才可以开始取产品。**

请使用信号量 P、V（`wait()`、`signal()`）操作实现进程间的互斥与同步。要求写出完整过程，并说明所用信号量的含义和初值。

<ExamSolution>

<ExamAnswer>

可设置 4 个信号量：

- `empty=1000`：缓冲区空位数；
- `full=0`：缓冲区已有产品数；
- `buffer_mutex=1`：生产者、消费者单次访问缓冲区时的互斥信号量；
- `consumer_mutex=1`：保证一个消费者连续完成 10 次取产品操作后，其他消费者才能开始取产品。

</ExamAnswer>

<ExamExplanation>

原材料的文字说明一度把 `empty` 和 `full` 的初值写反，但其代码及题意表明：缓冲区初始为空，因此应为

```c
semaphore empty = 1000;
semaphore full = 0;
```

完整实现可写为：

```c
semaphore consumer_mutex = 1;
semaphore buffer_mutex   = 1;
semaphore empty          = 1000;
semaphore full           = 0;

Producer() {
    while (true) {
        生产一件产品;

        P(empty);
        P(buffer_mutex);
        将产品放入缓冲区;
        V(buffer_mutex);
        V(full);
    }
}

Consumer() {
    while (true) {
        P(consumer_mutex);          // 独占“连续取 10 件”的资格

        for (int i = 0; i < 10; i++) {
            P(full);
            P(buffer_mutex);
            从缓冲区取出一件产品;
            V(buffer_mutex);
            V(empty);

            消费产品;
        }

        V(consumer_mutex);
    }
}
```

这里 `consumer_mutex` 必须包住整个 10 次循环，而不能只包住一次取产品。这样某个消费者一旦开始这一轮取产品，其他消费者就必须等它连续取满 10 件后才能进入。

即使该消费者在中途因为缓冲区暂时为空而阻塞在 `P(full)`，生产者仍然可以继续运行并向缓冲区中放入产品，因此不会因此形成生产者—消费者之间的死锁。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

**85. 2015 年第 45 题**

A、B 两人通过信箱进行辩论。每个人都从自己的信箱中取出对方提出的问题，将“问题的答案”和“向对方提出的新问题”组成一个新邮件，再放入对方的信箱。

A 的信箱最多存放 $M$ 个邮件，B 的信箱最多存放 $N$ 个邮件。初始时 A 的信箱中有 $x$ 个邮件，且

$$
0<x<M;
$$

B 的信箱中有 $y$ 个邮件，且

$$
0<y<N.
$$

A、B 的操作过程如下：

```text
A {
    while (true) {
        从 A 的信箱中取出一个邮件；
        回答问题并提出一个新问题；
        将新邮件放入 B 的信箱；
    }
}

B {
    while (true) {
        从 B 的信箱中取出一个邮件；
        回答问题并提出一个新问题；
        将新邮件放入 A 的信箱；
    }
}
```

只有当自己的信箱非空时才能取邮件；只有当对方信箱未满时才能放入新邮件，否则等待。请添加必要的信号量和 P、V（或 `wait()`、`signal()`）操作，实现上述过程的同步。要求写出完整过程，并说明信号量的含义和初值。

<ExamSolution>

<ExamAnswer>

可设置：

```c
semaphore A_full  = x;
semaphore A_empty = M - x;
semaphore B_full  = y;
semaphore B_empty = N - y;
semaphore A_mutex = 1;
semaphore B_mutex = 1;
```

其中 `A_full/B_full` 表示对应信箱中的邮件数，`A_empty/B_empty` 表示对应信箱的空位数，`A_mutex/B_mutex` 用于互斥访问对应信箱。

</ExamAnswer>

<ExamExplanation>

对 A 的信箱而言，A 是消费者、B 是生产者；对 B 的信箱而言，B 是消费者、A 是生产者。因此两个信箱分别构成一个有界缓冲区问题。

```c
semaphore A_full  = x;
semaphore A_empty = M - x;
semaphore B_full  = y;
semaphore B_empty = N - y;
semaphore A_mutex = 1;
semaphore B_mutex = 1;

A() {
    while (true) {
        P(A_full);
        P(A_mutex);
        从 A 的信箱中取出一个邮件;
        V(A_mutex);
        V(A_empty);

        回答问题并提出一个新问题;

        P(B_empty);
        P(B_mutex);
        将新邮件放入 B 的信箱;
        V(B_mutex);
        V(B_full);
    }
}

B() {
    while (true) {
        P(B_full);
        P(B_mutex);
        从 B 的信箱中取出一个邮件;
        V(B_mutex);
        V(B_empty);

        回答问题并提出一个新问题;

        P(A_empty);
        P(A_mutex);
        将新邮件放入 A 的信箱;
        V(A_mutex);
        V(A_full);
    }
}
```

以 A 为例：

- `P(A_full)` 保证 A 只能在自己的信箱中确实存在邮件时取信；
- 取出后执行 `V(A_empty)`，表示 A 信箱多出一个空位；
- A 写入 B 信箱前执行 `P(B_empty)`，若 B 信箱已满则等待；
- 写入成功后执行 `V(B_full)`，通知 B 又多了一封可取邮件。

B 的过程完全对称。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

**86. 2015 年第 46 题**

某计算机系统按字节编址，采用二级页表的分页存储管理方式，虚拟地址格式如下：

| 页目录号 | 页表索引 | 页内偏移量 |
| --- | --- | --- |
| 10 位 | 10 位 | 12 位 |

请回答下列问题。

1. 页和页框的大小各为多少字节？进程的虚拟地址空间共有多少页？
2. 假定页目录项和页表项均占 4B，则进程的页目录和所有二级页表最多共占多少页？写出计算过程。
3. 若某指令周期内访问的虚拟地址为 `01000000H` 和 `01112048H`，则进行地址转换时共涉及多少个二级页表？说明理由。

<ExamSolution>

<ExamAnswer>

1. 页和页框大小均为 $2^{12}\text{ B}=4\text{ KB}$；虚拟地址空间共有 $2^{20}$ 页。
2. 页目录占 1 页，全部二级页表最多占 $2^{10}=1024$ 页，共 $1025$ 页。
3. 只涉及 1 个二级页表，因为两个虚拟地址的页目录号都为 4。

</ExamAnswer>

<ExamExplanation>

### （1）页大小与虚拟页数

页内偏移量为 12 位，所以页和页框大小均为

$$
2^{12}\text{ B}=4096\text{ B}=4\text{ KB}.
$$

虚拟页号由 10 位页目录号和 10 位页表索引共同组成，因此虚拟地址空间中的虚拟页数为

$$
2^{10+10}=2^{20}.
$$

### （2）页目录和所有二级页表最多占多少页

页目录有 $2^{10}$ 个目录项，每项 4B，因此页目录大小为

$$
2^{10}\times4\text{ B}=4096\text{ B}=1\text{ 页}.
$$

一个二级页表同样有 $2^{10}$ 个页表项，每项 4B，因此每个二级页表也恰好占 1 页。

最多可能有 $2^{10}$ 个二级页表，所以全部二级页表最多占

$$
2^{10}=1024\text{ 页}.
$$

总计

$$
1+1024=\boxed{1025\text{ 页}}.
$$

### （3）两个地址是否使用同一个二级页表

页目录号取虚拟地址的最高 10 位，即

$$
\left(\text{VA}\gg22\right)\mathbin{\&}\texttt{0x3FF}.
$$

对两个地址分别计算：

$$
\texttt{01000000H}\gg22=4,
$$

$$
\texttt{01112048H}\gg22=4.
$$

两者页目录号相同，因此页目录中的同一个目录项指向同一个二级页表，故共涉及 **1 个二级页表**。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

**87. 2016 年第 46 题**

某进程调度程序采用基于优先数 `priority` 的调度策略：每次选择**优先数最小**的进程运行。进程创建时由用户指定 `nice` 作为静态优先数。

为动态调整优先数，引入运行时间 `cpuTime` 和等待时间 `waitTime`，初值均为 0：

- 进程处于执行态时，`cpuTime` 定时加 1，`waitTime` 置 0；
- 进程处于就绪态时，`cpuTime` 置 0，`waitTime` 定时加 1。

请回答：

1. 若只令 `priority=nice`，为什么可能出现饥饿现象？
2. 使用 `nice`、`cpuTime` 和 `waitTime` 设计一种动态优先数计算方法以避免饥饿，并说明 `waitTime` 的作用。

<ExamSolution>

<ExamAnswer>

1. 静态优先数不随等待时间改变。若就绪队列中不断出现优先数更小的进程，优先数较大的进程可能长期得不到 CPU，从而发生饥饿。
2. 一种可行方法为

$$
\text{priority}=\text{nice}+k_1\cdot\text{cpuTime}-k_2\cdot\text{waitTime},
$$

其中 $k_1>0,\ k_2>0$。`waitTime` 越大，数值优先数越小，使等待时间较长的进程逐步获得更高的调度优先级，从而实现老化并避免饥饿。

</ExamAnswer>

<ExamExplanation>

题目规定“优先数越小，调度优先级越高”。因此动态调整时两个方向要特别注意：

- 一个进程持续占用 CPU 时，`cpuTime` 增大，应让它的 `priority` 数值增大，从而降低它继续运行的优先级；
- 一个进程长期处于就绪队列等待时，`waitTime` 增大，应让它的 `priority` 数值减小，从而提高它被调度的机会。

因此可取

$$
\boxed{
\text{priority}=\text{nice}+k_1\cdot\text{cpuTime}-k_2\cdot\text{waitTime}
},
$$

其中 $k_1,k_2$ 均为正数，用于调节运行时间和等待时间对优先级的影响程度。

`waitTime` 实际上承担了**老化（aging）**作用：等待得越久，进程的数值优先数会越低，最终能够超过原本优先级更高的进程，从而避免无限期等待。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

**88. 2016 年第 47 题**

某磁盘文件系统采用链接分配方式组织文件，簇大小为 4KB。目录文件的每个目录项包括文件名和文件的第一个簇号，其余簇号存放在文件分配表 FAT 中。

目录树以及各文件占用的簇号和顺序如下图，其中 `dir`、`dir1` 是目录，`file1`、`file2` 是用户文件。

<img src="/img/408/past-exams-large-questions/03-操作系统/assets/2016-47-figure-001.svg" alt="2016 年第 47 题目录树与文件簇链示意图" />

请回答：

1. 给出所有目录文件的内容。
2. 若 FAT 的每个表项只存放簇号，占 2B，则 FAT 的最大长度是多少字节？该文件系统支持的单个文件最大长度是多少？
3. 说明 `file1` 的簇号 106、108 分别存放在 FAT 的哪个表项中。
4. 假设只有 FAT 和 `dir` 目录文件已经读入内存，若要把文件 `dir/dir1/file1` 的第 5000 个字节读入内存，需要访问磁盘中的哪几个簇？

<ExamSolution>

<ExamAnswer>

1. `dir` 目录中有 `(dir1, 48)`、`(file2, 200)`；`dir1` 目录中有 `(file1, 100)`。
2. FAT 最大长度为 $128\text{ KB}$；单个文件最大长度为 $256\text{ MB}$。
3. `FAT[100]=106`，`FAT[106]=108`。
4. 需要访问 48 号簇和 106 号簇。

</ExamAnswer>

<ExamExplanation>

### （1）目录文件内容

由目录树可得：

`dir` 目录文件：

| 文件名 | 第一个簇号 |
| --- | ---: |
| `dir1` | 48 |
| `file2` | 200 |

`dir1` 目录文件：

| 文件名 | 第一个簇号 |
| --- | ---: |
| `file1` | 100 |

### （2）FAT 大小与最大文件长度

FAT 表项中的簇号占 2B，即 16 位，因此最多可编号

$$
2^{16}
$$

个簇。

FAT 本身最多包含 $2^{16}$ 个表项，每项 2B，所以最大长度为

$$
2^{16}\times2\text{ B}
=2^{17}\text{ B}
=128\text{ KB}.
$$

一个文件最多可链接 $2^{16}$ 个簇，每簇 4KB，因此最大文件长度为

$$
2^{16}\times4\text{ KB}
=2^{28}\text{ B}
=256\text{ MB}.
$$

### （3）簇号在 FAT 中的位置

`file1` 的簇链为

$$
100\rightarrow106\rightarrow108.
$$

FAT 的第 $i$ 个表项存放“簇 $i$ 的下一簇号”，因此

$$
\boxed{\text{FAT}[100]=106},
$$

$$
\boxed{\text{FAT}[106]=108}.
$$

### （4）读取第 5000 个字节

`dir` 目录文件已经在内存中，因此可以直接从中查到 `dir1` 的第一个簇号为 48，但 `dir1` 的目录内容尚未在内存，所以首先要访问 **48 号簇**，从中找到 `file1` 的首簇号 100。

由于 FAT 已在内存，可以直接通过

$$
100\rightarrow106
$$

得到 `file1` 的第二个簇号，而无需先从磁盘读取 100 号簇来寻找下一簇。

每簇 4KB，即 4096B：

- 第 1～4096 个字节位于 100 号簇；
- 第 4097～8192 个字节位于 106 号簇。

第 5000 个字节位于第二个簇，即 **106 号簇**。

所以实际需要访问的磁盘簇为

$$
\boxed{48,\ 106}.
$$

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

**89. 2017 年第 45 题**

假定计算机 M 采用二级分页虚拟存储管理方式，虚拟地址格式如下：

| 页目录号 | 页表索引 | 页内偏移量 |
| --- | --- | --- |
| 10 位 | 10 位 | 12 位 |

由同一套试题前两题可知，函数 `f1` 的机器指令代码从虚拟地址 `00401020H` 开始，第 1 条指令为

```text
00401020  55  push ebp
```

最后一条 `ret` 指令位于 `0040107FH`。

请回答：

1. 函数 `f1` 的机器指令代码占多少页？
2. 取第 1 条指令 `push ebp` 时，若地址变换过程中需要访问内存中的页目录和页表，则分别访问页目录和对应页表的第几个表项（编号从 0 开始）？
3. M 的 I/O 采用中断控制方式。若进程 P 在调用 `f1` 之前通过 `scanf()` 获取 `n` 的值，则在执行 `scanf()` 的过程中，进程 P 的状态如何变化？CPU 是否会进入内核态？

<ExamSolution>

<ExamAnswer>

1. 占 1 页。
2. 访问页目录第 1 个表项，以及对应二级页表的第 1 个表项。
3. 进程 P 因等待输入由运行态变为阻塞态；输入完成后由中断处理程序唤醒，变为就绪态；以后被调度时再由就绪态变为运行态。CPU 会进入内核态。

</ExamAnswer>

<ExamExplanation>

### （1）代码占多少页

页大小由 12 位页内偏移量决定：

$$
2^{12}\text{ B}=4\text{ KB}.
$$

`f1` 的机器代码地址范围是

```text
00401020H ～ 0040107FH
```

两端地址的高 20 位页号完全相同，均位于以 `00401000H` 为起始地址的同一虚拟页中，因此整个函数机器代码只占

$$
\boxed{1\text{ 页}}.
$$

### （2）页目录号和页表索引

第一条指令地址为

$$
\texttt{00401020H}.
$$

页目录号为最高 10 位：

$$
(\texttt{00401020H}\gg22)\mathbin{\&}\texttt{3FFH}=1.
$$

页表索引为中间 10 位：

$$
(\texttt{00401020H}\gg12)\mathbin{\&}\texttt{3FFH}=1.
$$

因此访问页目录的第 1 个表项，再访问该目录项所指二级页表的第 1 个表项。

### （3）`scanf()` 期间的进程状态和 CPU 状态

进程 P 执行输入操作后，需要等待外设输入完成，因此会发生：

$$
\text{运行态}\rightarrow\text{阻塞态}.
$$

输入完成后，设备发出中断，中断处理程序将等待该输入的进程唤醒：

$$
\text{阻塞态}\rightarrow\text{就绪态}.
$$

当调度程序以后选中 P 时：

$$
\text{就绪态}\rightarrow\text{运行态}.
$$

`scanf()` 最终需要通过操作系统提供的 I/O 服务完成输入，执行系统调用以及处理设备中断时，CPU 都需要执行内核代码，因此 **CPU 会进入内核态**。

原材料中的 `scanf0` 属于识别错误，这里按题面修正为 `scanf()`。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

**90. 2017 年第 46 题**

某进程中有 3 个并发执行的线程 `thread1`、`thread2`、`thread3`，伪代码如下：

```c
typedef struct {
    float a;
    float b;
} cnum;

// 全局变量
cnum x, y, z;

// 计算两个复数之和
cnum add(cnum p, cnum q) {
    cnum s;
    s.a = p.a + q.a;
    s.b = p.b + q.b;
    return s;
}
```

```c
thread1 {
    cnum w;
    w = add(x, y);
    ...
}

thread2 {
    cnum w;
    w = add(y, z);
    ...
}

thread3 {
    cnum w;
    w.a = 1;
    w.b = 2;
    z = add(z, w);
    y = add(y, w);
    ...
}
```

请添加必要的信号量和 P、V（或 `wait()`、`signal()`）操作，要求既保证线程对临界资源的互斥访问，又尽可能提高并发程度。

<ExamSolution>

<ExamAnswer>

冲突关系为：

- `thread1` 与 `thread3` 在变量 `y` 上存在读—写冲突；
- `thread2` 与 `thread3` 在变量 `y`、`z` 上存在读—写冲突；
- `thread1` 与 `thread2` 对 `y` 都只读，应允许二者并发。

可设置 3 个互斥信号量：

```c
semaphore y_mutex1 = 1;  // thread1 与 thread3 关于 y
semaphore y_mutex2 = 1;  // thread2 与 thread3 关于 y
semaphore z_mutex  = 1;  // thread2 与 thread3 关于 z
```

</ExamAnswer>

<ExamExplanation>

如果只给 `y` 设置一个普通互斥信号量，那么 `thread1` 和 `thread2` 即使都只是读取 `y`，也无法同时执行，会损失不必要的并发性。

本题可以针对两个“读者—写者冲突对”分别设置两个信号量：`thread1` 读取 `y` 时只申请 `y_mutex1`，`thread2` 读取 `y` 时只申请 `y_mutex2`；`thread3` 写 `y` 时必须同时取得这两个信号量。这样 `thread1` 与 `thread2` 可以并发读，而 `thread3` 写 `y` 时又能排斥二者。

```c
semaphore y_mutex1 = 1;
semaphore y_mutex2 = 1;
semaphore z_mutex  = 1;

cnum x, y, z;

thread1() {
    cnum w;

    P(y_mutex1);
    w = add(x, y);          // 读 x、y
    V(y_mutex1);

    ...
}

thread2() {
    cnum w;

    P(z_mutex);
    P(y_mutex2);
    w = add(y, z);          // 同时读取 y、z
    V(y_mutex2);
    V(z_mutex);

    ...
}

thread3() {
    cnum w;
    w.a = 1;
    w.b = 2;

    P(z_mutex);
    z = add(z, w);          // 写 z
    V(z_mutex);

    P(y_mutex1);
    P(y_mutex2);
    y = add(y, w);          // 写 y，必须排斥 thread1 和 thread2
    V(y_mutex2);
    V(y_mutex1);

    ...
}
```

各变量的访问关系如下：

| 变量 | `thread1` 与 `thread2` | `thread1` 与 `thread3` | `thread2` 与 `thread3` |
| --- | --- | --- | --- |
| `x` | 仅 `thread1` 访问 | 仅 `thread1` 访问 | 均不访问 |
| `y` | 同时读，可并发 | 读—写互斥 | 读—写互斥 |
| `z` | 仅 `thread2` 访问 | 仅 `thread3` 访问 | 读—写互斥 |

原解析中 `thread3` 把题面给出的 `w.b=2` 错写成 `w.b=1`，这里已按原题修正；原评分表中的线程编号也存在明显错位，这里按三个实际线程重新整理。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>
