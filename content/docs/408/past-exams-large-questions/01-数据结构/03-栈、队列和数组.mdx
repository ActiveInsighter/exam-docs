## 2019 年第 42 题

<ExamQuestion>

**22. 2019 年第 42 题**

请设计一个队列，满足以下要求：

1. 初始时队列为空；
2. 入队时允许增加队列占用的空间；
3. 出队后，出队元素原来占用的空间可以重复使用，即整个队列已经申请的空间只增不减；
4. 入队和出队操作的时间复杂度始终为 $O(1)$。

请回答：

1. 应选择链式存储结构还是顺序存储结构？
2. 画出队列的初始状态，并给出判队空和“当前已分配空间已满”的条件；
3. 画出第一个元素入队后的状态；
4. 给出入队和出队操作的基本过程。

<img src="/img/408/past-exams-large-questions/01-数据结构/assets/2019-42-figure-001.svg" alt="2019 年第 42 题循环链式队列初始状态" />

<img src="/img/408/past-exams-large-questions/01-数据结构/assets/2019-42-figure-002.svg" alt="2019 年第 42 题第一个元素入队后的状态" />

<ExamSolution>

<ExamAnswer>选**动态循环链式队列**：已申请的结点连成一个环，`front` 指向待出队元素槽，`rear` 指向下一次入队要写入的空槽，始终保留一个空槽以区分空、满。初始申请一个自环空结点并令 `front=rear`。队空条件 `front==rear`；需要扩充结点的条件 `rear->next==front`。扩容时只在 `rear` 后插入一个结点；入队写入 `rear` 再后移 `rear`，出队取出 `front` 再后移 `front`，**出队不释放结点**。不计单次内存分配器内部开销，指针操作均为最坏 $O(1)$。</ExamAnswer>

<ExamExplanation>

### 一、明确三个容易混淆的量

设环上**总已分配结点数**为 $C$（包含一个保留的空槽），队列当前元素个数为 $q$。采用本题的指针约定：

- `front` 指向第一个**有效元素**的位置；如果队空，`front` 与 `rear` 重合。
- `rear` 指向**下一次写入**的位置（不是最后一个有效元素）。
- 环中从 `front` 沿 `next` 到 `rear`（不含 `rear`）的结点是有效元素，其他是已分配的可复用槽。保持 $0\le q\le C-1$。

**逻辑队空**：`front == rear`。**当前分配空间无富余槽**：`rear->next == front`。后者并非“全局入队失败”，只说明当前环的 $C-1$ 个可用数据槽已被占用，下一次入队需要增长环。它们不能互换：当 $C=1$ 且为空时，两个条件**同时成立**，无需误判为有元素。

如果 `rear` 改成“最后有效元素”指针，判定条件与算法都要相应修改，绝不能直接套这套公式。

### 二、初始化、第一次入队与图解

题面所给两张 SVG 分别表示初始单结点自环和第一次插入后的状态。

```text
初始（1 个空槽）：
    front,rear ──► [空] ──┐
                   ▲───────┘

Enqueue(7) 后（2 个已申请槽、1 个有效元素）：
    front ──► [ 7 ] ──► [ 空 ] ──┐
               ▲         ▲       │
               └─────────┘     rear 指向 [空]
```

严格过程：初始 `rear->next == front`，先在 `rear` 后分配结点 `new`，并令 `new->next=front`；再 `rear->data=7` 和 `rear=rear->next`。这样最后一个空槽仍然存在。**环始终保持闭合，已申请空间只增不减。**

### 三、可运行的 C 实现

```c
#include <stdlib.h>

typedef struct QNode {
    int data;
    struct QNode *next;
} QNode;

typedef struct {
    QNode *front;  // 指向待出队数据槽
    QNode *rear;   // 指向下次入队写入槽
} LoopQueue;

int InitQueue(LoopQueue *q) {
    if (q == NULL) return 0;
    QNode *p = malloc(sizeof(*p));
    if (p == NULL) { q->front = q->rear = NULL; return 0; }
    p->next = p;               // 单结点自环
    q->front = q->rear = p;
    return 1;
}

int EnQueue(LoopQueue *q, int x) {
    if (q == NULL || q->rear == NULL) return 0;
    if (q->rear->next == q->front) {
        QNode *p = malloc(sizeof(*p));
        if (p == NULL) return 0;  // 扩容失败：队列状态保持原样
        p->next = q->rear->next;
        q->rear->next = p;        // O(1) 插入新槽
    }
    q->rear->data = x;
    q->rear = q->rear->next;
    return 1;
}

int DeQueue(LoopQueue *q, int *value) {
    if (q == NULL || value == NULL || q->front == NULL ||
        q->front == q->rear) return 0;
    *value = q->front->data;
    q->front = q->front->next;  // 不调用 free
    return 1;
}

// 使用结束后显式销毁；“已申请空间只增不减”约束的是队列运行期间
void DestroyQueue(LoopQueue *q) {
    if (q == NULL || q->front == NULL) return;
    QNode *first = q->front;
    QNode *p = first->next;
    while (p != first) {
        QNode *next = p->next;
        free(p);
        p = next;
    }
    free(first);
    q->front = q->rear = NULL;
}
```

### 四、证明、复杂度和边界

归纳不变量：队列有效区是沿环从 `front` 至 `rear` 的前缀，`rear` 始终是空槽。队空时有效区长度为零；入队在当前空槽写入，若已无额外空槽便先扩容，随后后移 `rear`，故不变量保持；出队直接前移 `front`，有效区恰删去首元素，其槽变为环内可复用空间。有效区的前后顺序等于入队顺序，因此满足 FIFO。

所有操作仅改变常数个指针，不需要搬运队列元素；每次入队至多申请一个结点，故算法层面的最坏操作时间为 $O(1)$。这里与**操作系统内存分配器可能产生的实际延迟**是两个不同的抽象层次，考试通常认为一次结点申请为 $O(1)$。空间上，设运行期间最大同时存放 $q_{\max}$ 个元素，最多申请 $q_{\max}+1$ 个结点，随后出队不回收、再入队直接重用。

**失分点**：①把 `rear` 误定义为“最后数据结点”；②入队前没有检查扩容；③出队 `free(front)` 破坏循环链；④空队列误用 `front->next==rear` 作为判空；⑤忘记“第一个元素入队”先扩容。

</ExamExplanation>

</ExamSolution>

<span className="inline-block rounded border px-2 py-0.5 text-xs text-fd-muted-foreground">原创</span>

采用 2019 年第 42 题的循环链表队列：`front` 指向队头数据槽，`rear` 指向下一入队空槽，初始环只有一个空结点。依次执行：

```text
EnQueue(1), EnQueue(2), DeQueue(),
EnQueue(3), DeQueue(), DeQueue(),
EnQueue(4), EnQueue(5)
```

1. 每次出队返回什么值？末尾队列有哪些元素？整个过程中分配过多少个结点（含初始空结点）？
2. 若加入 `ClearQueue()` 操作，将队列逻辑清空但**不释放任何结点**，要求最坏 $O(1)$，应如何实现？
3. 证明入队不会因为环中已有空闲结点而无谓地继续申请新结点；并说明是否能简单靠 `rear == front` 判断当前环容量已经用完。

<ExamSolution>

<ExamAnswer>三次出队依次返回 $1,2,3$；最终队列逻辑元素为 $4,5$。总共只需要 **3 个结点**：初始一个保留槽，两次入队扩容各增一个；其后结点循环复用。清空操作只要令 `front=rear`（原来的 `rear` 仍指向空槽），耗时 $O(1)$，不必遍历。`front==rear` 判断的是**空队列**而非容量耗尽。</ExamAnswer>

<ExamExplanation>

### 一、跟踪“逻辑元素数”与“物理环槽数”

记 $q$ 为有效元素数，$C$ 为已申请槽数（含一个保留槽）。始终有 $C\ge q+1$。只有入队前 `rear->next == front` 才增加一个槽；出队只移动 `front`，不改变 $C$。

| 操作 | 操作后的逻辑队列 | $q$ | $C$ | 本步新分配 |
| --- | --- | ---: | ---: | ---: |
| 初始化 | 空 | 0 | 1 | 1 |
| 入 1 | `1` | 1 | 2 | 1 |
| 入 2 | `1,2` | 2 | 3 | 1 |
| 出（得 1） | `2` | 1 | 3 | 0 |
| 入 3 | `2,3` | 2 | 3 | 0 |
| 出（得 2） | `3` | 1 | 3 | 0 |
| 出（得 3） | 空 | 0 | 3 | 0 |
| 入 4 | `4` | 1 | 3 | 0 |
| 入 5 | `4,5` | 2 | 3 | 0 |

第二次入队后到达过容量峰值 $q_{\max}=2$，所以本例 $C=q_{\max}+1=3$。如果以后队列长度首次达到 3，下一次入队才会分配第 4 个结点。

### 二、清空与反例

```c
void ClearQueue(LoopQueue *q) {
    if (q != NULL && q->rear != NULL)
        q->front = q->rear;
}
```

这里复用原题 `LoopQueue` 结构定义。`rear` 原来始终指向合法空槽，把 `front` 移到该位置后，逻辑有效区变为空；虽然旧槽里仍保存历史 `data` 值，但不会被当作元素。之后入队再沿环重写即可。**只改指针，$O(1)$，分配量不变。**

若误以 `rear==front` 表示“空间用完”，刚初始化就会把空队列误认为已满；如果按照这个错误条件扩容，反而丧失“一次分配、多次复用”的优点。

### 三、为什么复用是完整的

`rear` 沿单向环移动，`front` 也沿同一方向移动。在有效区和 `rear` 空槽之间，凡是已经出队但未被再次占用的结点都构成可利用槽；直到 `rear` 紧邻 `front` 才说明环中的有效元素达到 $C-1$。因此增长次数只与**历史最高并发队列长度**相关，不与总入队次数相关：

$$
C_{\mathrm{final}}=1+\max_{t}q(t).
$$

该等式假设整个运行过程从一个初始空槽开始、没有手工增加或释放槽，而且仅由本题所定义的入队操作扩容。

## 2026 年第 42 题

<ExamQuestion>

**36. 2026 年第 42 题**

{/* 原整理文件本题题面存在 OCR 漏项/错项；此处已按公开真题题面交叉核对修正。 */}

栈的基本操作有入栈和出栈。将序列

$$
1,2,3,\ldots,n
$$

依次入栈，回答下列问题：

1. 当 $n=9$ 时，可以得到出栈序列

   $$
   \{2,3,1,6,4,7,5,9,8\}
   $$

   吗？可以得到出栈序列

   $$
   \{2,3,1,5,6,7,4,9,8\}
   $$

   吗？
2. 假设 $1,2,\ldots,n$ 组成任意出栈序列 $P_1,P_2,\ldots,P_n$。若其中存在 $P_i,P_j,P_k$，且 $i<j<k$，使该出栈序列不能由栈得到，则这三个元素满足怎样的大小关系？
3. 若 $n=4$，则以 $2$ 开头的合法出栈序列共有多少个？
4. 若 $n=k-1$ 时合法出栈序列总数为 $M$。当 $n=k$ 时，以 $1$ 开头的合法出栈序列有多少个？以 $2$ 开头的有多少个？总数是多少？

<ExamSolution>

<ExamAnswer>（1）第一个序列**不合法**，第二个**合法**；（2）禁形是存在 $i<j<k$ 满足 $P_j<P_k<P_i$（312 模式）；（3）$n=4$ 且首元素为 2 的合法序列有 $5$ 个；（4）若 $C_{k-1}=M$，以 1 开头为 $M$ 个，以 2 开头也为 $M$ 个，总数为 $C_k=\dfrac{2(2k-1)}{k+1}M$。</ExamAnswer>

<ExamExplanation>

### 一、最可靠的判定法：需要谁，就压到谁

顺序入栈 $1,2,\ldots,n$ 且每个元素恰好入栈、出栈一次。对于要求的下一个出栈元素 $x$，**没有决策自由**：

1. 若栈顶恰是 $x$，弹出；
2. 否则只可将尚未入栈的元素按递增顺序压入，直至 $x$ 到栈顶，再弹出；
3. 如果 $x$ 已压入栈内却不在栈顶，该输出序列不可能实现。

这就是判断出栈序列的线性时间模拟，不必枚举所有入栈/出栈操作。

对第一序列，输出 `2,3,1` 后栈空；要输出 `6`，必须压入 `4,5,6` 再弹出 `6`。接下来想输出 `4`，而此时栈顶是 `5`，故失败。在原序列中可直接找到 $P_i=6,P_j=4,P_k=5$，满足 $4<5<6$。

对第二序列，以下操作可成功得到：

```text
+1,+2,-2,+3,-3,-1,
+4,+5,-5,+6,-6,+7,-7,-4,
+8,+9,-9,-8
```

其中 `+x` 表示入栈，`-x` 表示出栈。特别注意输出 `7` 后栈顶就是 `4`，所以合法。

### 二、为何禁形一定且充分导致非法

若 $P_i>P_k>P_j$，且 $i<j<k$，为了先弹出较大的 $P_i$，较小的 $P_j$、$P_k$ 必然已经入栈，并且 $P_j$ 位于 $P_k$ **下方**。但目标又要求先输出 $P_j$、后输出 $P_k$，与 LIFO 冲突。

反向也成立：若上述模拟首次因“目标元素已经压栈却被别的元素挡住”而失败，设目标为 $P_j$，阻挡它的栈顶元素为 $P_k$（该元素只能在后续才会输出），则它们有 $P_j<P_k$，且为使这两个元素都已入栈，必有之前某个已经输出的更大元素 $P_i>P_k$。于是存在 312 模式。注意这里说的是**三个元素在出栈排列中按位置 $i<j<k$ 出现**，不是值的原始大小顺序。

### 三、$n=4$ 时首元素为 2 的全部情形

第一个弹出的元素是 2，开始必须是“压 1、压 2、弹 2”，剩余待输出元素是 1、3、4。逐一枚举合法结果：

```text
2134, 2143, 2314, 2341, 2431
```

共 $5$ 个。`2413` 不合法：在输出 4 后，3 压在 1 上方，不能先输出 1。对照样例比只写数目更能验证理解。

### 四、卡特兰数及“首元素为 1 或 2”均为 M 的原因

令 $C_n$ 表示连续递增入栈的 $n$ 个互异元素可产生的出栈序列数：

$$
C_n=\sum_{i=0}^{n-1}C_iC_{n-1-i}
=\frac{1}{n+1}\binom{2n}{n},\qquad C_0=1.
$$

可把入栈视为上行一步、出栈视为下行一步；任意前缀不能出栈多于入栈，因而是长度 $2n$ 的 Dyck 路径。这与合法出栈排列一一对应。

以 1 开头时，先压 1 弹 1，剩余 $k-1$ 个数可任意组成一个合法栈排列，所以有 $C_{k-1}=M$ 个。

以 2 开头时，先压 1、2 弹 2，随后栈底保留 1、还没入栈的有 3 到 $k$。把 1 当作最小元素重新编号，剩余 $k-1$ 个元素也遵从递增入栈原则，依旧有 $M$ 个（此时“第一个输出”不再固定）。

利用二项式系数化简：

$$
\frac{C_k}{C_{k-1}}
=\frac{(2k)!}{(k+1)!k!}\cdot\frac{k!(k-1)!}{(2k-2)!}
=\frac{2(2k-1)}{k+1}.
$$

因此 $C_k=\frac{2(2k-1)}{k+1}M$。

### 五、可复用的 C 判题函数（$O(n)$）

```c
#include <stdlib.h>

int LegalPop(const int P[], int n) {
    if (P == NULL || n < 0) return 0;
    if (n == 0) return 1;
    int *st = malloc((size_t)n * sizeof(*st));
    if (st == NULL) return 0;
    int top = -1, next = 1, ok = 1;
    for (int i = 0; i < n; ++i) {
        while ((top < 0 || st[top] != P[i]) && next <= n)
            st[++top] = next++;
        if (top < 0 || st[top] != P[i]) { ok = 0; break; }
        --top;
    }
    free(st);
    return ok;
}
```

`while` 中每个数最多入栈一次，每个位置最多弹出一次，因此即使有嵌套循环，总操作数也是 $O(n)$，不是 $O(n^2)$；辅助栈空间为 $O(n)$。**考场技巧**：判定题优先模拟；计数题才使用卡特兰数；禁形结论用于快速找到不合法的三元证据。

按照 $1,2,3,4,5$ 的顺序将每个整数恰好压栈一次、弹出一次。要求出栈序列的前两个元素恰为 $2,4$。

1. 写出所有可能的完整出栈序列并证明没有遗漏。
2. 给出 $O(n)$ 时间、$O(n)$ 辅助空间的通用程序，以检验任意长度为 $n$ 的候选出栈序列是否合法；输入允许有越界、重复值。
3. 如果在完成前缀 `2,4` 后，下一输出元素必须是 1，是否存在合法序列？指出栈顶元素。

<ExamSolution>

<ExamAnswer>合法序列只有 `24315`、`24351`、`24531`，共 **3** 个；下一输出不能是 1，因为弹出 4 后栈为自底向上的 `[1,3]`，栈顶是 3。通用合法性判定使用“遇到目标元素先将尚未入栈的元素一直压到该元素，再检查栈顶并弹出”的贪心模拟即可。</ExamAnswer>

<ExamExplanation>

### 一、从前缀恢复唯一的状态

第一位是 2：必须 `push(1),push(2),pop(2)`。第二位是 4：必须 `push(3),push(4),pop(4)`。此时栈中尚有 `[1,3]`（栈顶为 3），唯一未入栈的整数是 5。

余下三元素是 1、3、5：

- 先弹 3，再弹 1，最后压 5、弹 5：`24315`；
- 先弹 3，再压 5、弹 5，最后弹 1：`24351`；
- 先压 5、弹 5，最后依次弹 3、弹 1：`24531`。

由于 1 埋在 3 之下，不可能先弹 1；而尚未入栈的 5 若不先弹出就会压住 3，所有合法路径已被上述三种选择覆盖。可先画一个只有 3 个终点的操作分支树核对结果。

### 二、线性模拟与异常输入

沿用 2026 年真题里的 `LegalPop(P,n)` 函数：无论 `P[i]` 是正常整数、重复整数、零或大于 $n$ 的整数，只要目标不在可合法弹出的栈顶就返回 0；**无需**另写 $O(n)$ 的出现次数统计数组。若担心 `n=0` 应视为空排列合法，函数已经相应处理。

模拟过程中，尚未入栈的元素只会从 `next` 增加到 $n$；每个整数压栈最多一次、弹栈最多一次，所以总时间 $\Theta(n)$，即使代码含 `while` 也不能误算成 $O(n^2)$。一个大小为 $n$ 的数组模拟栈即 $O(n)$ 额外空间。

### 三、辨析“枚举所有序列”和“检查一个序列”

枚举所有合法出栈序列需要输出 $C_n$ 个结果，运行时间至少与输出规模同阶；而检查**一个已给候选序列**只需 $O(n)$。所以不能把线性判定复杂度拿来描述全部枚举。$n=5$ 时总体合法排列共有

$$
C_5=\frac{1}{6}\binom{10}{5}=42,
$$

只有其中 3 个满足指定前缀 `2,4`。
