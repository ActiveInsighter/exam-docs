## 2019 年第 42 题

<ExamQuestion>

**22. 2019 年第 42 题**

请设计一个队列，满足以下要求：

1. 初始时队列为空；
2. 入队时允许增加队列占用的空间；
3. 出队后，出队元素原来占用的空间可以重复使用，即整个队列已经申请的空间只增不减；
4. 入队和出队操作的时间复杂度始终为 $O(1)$。

请回答：

1. 应选择链式存储结构还是顺序存储结构？
2. 画出队列的初始状态，并给出判队空和“当前已分配空间已满”的条件；
3. 画出第一个元素入队后的状态；
4. 给出入队和出队操作的基本过程。

<img src="/img/408/past-exams-large-questions/01-数据结构/assets/2019-42-figure-001.svg" alt="2019 年第 42 题循环链式队列初始状态" />

<img src="/img/408/past-exams-large-questions/01-数据结构/assets/2019-42-figure-002.svg" alt="2019 年第 42 题第一个元素入队后的状态" />

<ExamSolution>

<ExamAnswer>

1. **存储结构：** 选循环单链表，保留已经申请的所有结点，不释放出队结点，空闲结点自然随环循环复用。
2. **指针约定及判定：** `front` 指向队头元素所在结点，`rear` 指向下一次可写入的空闲结点（始终保留一个空位）。队空：`front==rear`；现有结点已没有足够空位接纳下一元素、需要扩容：`rear->next==front`。
3. **首次入队：** 初始仅一个自环的空结点，先在 `rear` 后插入新结点，再在原 `rear` 处写入数据，令 `rear=rear->next`。
4. **操作：** 入队时必要时只增加一个结点，写 `rear->data` 并前移 `rear`；出队时若非空，取 `front->data` 并前移 `front`，不 `free`。在常规链表操作模型下，每次操作 $O(1)$。

</ExamAnswer>

<ExamExplanation>

1. **先分清“已申请结点数”和“当前元素数”。** 本设计中队列始终以 `front` 为队头数据位置、以 `rear` 为**下一处空位置**；`front==rear` 表示没有待出队的数据。若环上共有 $m$ 个已申请的结点，则最多同时保存 $m-1$ 个元素；多出来的一格用来避免“头尾指针相等时究竟是空还是满”的歧义。`rear->next==front` 表示环上仅剩 `rear` 这一格空位，**下一次入队应扩容**。这里的“满”不是拒绝入队，而是“以现有存储量入队就会覆盖队头”。
2. **初始状态与题图。** 先申请一个结点 $N_0$，令 `front=rear=N0`、`N0->next=N0`。此时队空，也满足扩容条件 `rear->next==front`；因此第一次入队一定先申请第二个结点 $N_1$，并把它插在 $N_0$ 后，使 $N_0\to N_1\to N_0$ 成环。随后把数据写入 $N_0$，将 `rear` 移到 $N_1$，`front` 不动。原题两幅 SVG 分别展示了这些位置关系。
3. **操作的完整 C 实现。** 使用一个始终存在的“保留空位”；整个环不需要另外维护尾结点，插入新结点只需 `rear` 指针即可定位。

```c
#include <stdlib.h>

typedef struct QNode {
    int data;
    struct QNode *next;
} QNode;

typedef struct {
    QNode *front;   /* 队头元素位置；队空时等于 rear */
    QNode *rear;    /* 下一个写入位置 */
} CircleQueue;

int InitQueue(CircleQueue *q) {
    QNode *p = (QNode *)malloc(sizeof(QNode));
    if (p == NULL) return 0;
    p->next = p;
    q->front = q->rear = p;
    return 1;
}

int QueueEmpty(const CircleQueue *q) {
    return q->front == q->rear;
}

int EnQueue(CircleQueue *q, int x) {
    if (q->rear->next == q->front) {
        QNode *p = (QNode *)malloc(sizeof(QNode));
        if (p == NULL) return 0;        /* 分配失败，状态未改变 */
        p->next = q->rear->next;
        q->rear->next = p;               /* 接在 rear 后的环形空位 */
    }
    q->rear->data = x;
    q->rear = q->rear->next;
    return 1;
}

int DeQueue(CircleQueue *q, int *out) {
    if (QueueEmpty(q)) return 0;
    *out = q->front->data;
    q->front = q->front->next;           /* 不释放刚才读出的结点 */
    return 1;
}

/* 全部结束使用时才统一释放历史申请的空间 */
void DestroyQueue(CircleQueue *q) {
    if (q->front == NULL) return;
    QNode *first = q->front;
    QNode *p = first->next;
    while (p != first) {
        QNode *next = p->next;
        free(p);
        p = next;
    }
    free(first);
    q->front = q->rear = NULL;
}
```

4. **入队、出队位置不变量。** 若当前从 `front` 沿着 `next` 到达 `rear` 前有 $s$ 个数据结点，这 $s$ 个结点正好按 FIFO 顺序排队；从 `rear` 向后走到 `front` 之前的是可复用的空闲结点。入队把旧 `rear` 变为数据结点，使 `rear` 前进一格；必要时先扩大环，避免 `rear` 与 `front` 意外相遇。出队只是把原 `front` 变为空闲结点并令 `front` 后移，没有破坏物理上的环，故后续空间可以复用。
5. **严谨讨论 $O(1)$ 和分配行为。** 每次入队至多进行一次单结点 `malloc`、至多常数次连接操作；每次出队只做常数次指针操作。按考试中的链式存储抽象模型，“分配一个结点”记为 $O(1)$，故每次为 $O(1)$。这与连续动态数组扩容时可能要复制 $O(n)$ 个元素不同。现实通用分配器的最坏实际耗时不保证严格常数，但不影响题目的算法复杂度结论。`DestroyQueue` 是整个队列生命周期末尾的释放操作，耗时与历史分配结点数成正比，不算作一次入队/出队。
6. **特别易错：** ①若把 `rear` 定义为尾元素所在结点，则空/满条件和代码必须整体改变，不能混用两种约定；②仅说“链式队列”还不足以保证出队空间被复用，必须说明不释放已申请结点并维护空闲环；③在 `rear->next==front` 时不扩容而直接写入，会覆盖尚未出队的元素；④不能对空队列直接 `DeQueue` 解引用数据。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

<ExamQuestion>

采用原题的循环单链表队列约定：`front` 指向队头，`rear` 指向下一空位置；初始有唯一结点 $N_0$，且 `front=rear=N0`。新增结点依次编号 $N_1,N_2,\ldots$，每次扩容恰好插入一个结点。

依次执行：`EnQueue(10)`、`EnQueue(20)`、`DeQueue()`、`EnQueue(30)`、`DeQueue()`、`DeQueue()`、`EnQueue(40)`。

1. 每一步写出 `front`、`rear`、当前队列内的元素和累计申请结点数；
2. 给出三次出队的返回值和最终指针位置；
3. 说明最后一次入队为什么不需要再次申请结点。

<ExamSolution>

<ExamAnswer>

1. 累计申请结点数从 $1$ 依次变为 $2,3,3,3,3,3,3$；过程见表。
2. 三次出队结果依次为 $10,20,30$；最终 `front=N0`、`rear=N1`，队列内容为 $[40]$。
3. 最后入队时 `rear=N0` 且 `rear->next=N1`，而 `front=N0`，不满足扩容条件，可重用 $N_0$。

</ExamAnswer>

<ExamExplanation>

1. **初始化：** 环为 `N0 -> N0`，队空。依次执行后，环保持 `N0 -> N1 -> N2 -> N0`（扩容次数只有前两次）。

| 操作 | `front` | `rear` | 逻辑队列（队头在左） | 累计已申请结点 |
|---|---|---|---|---:|
| 初始化 | $N_0$ | $N_0$ | $[]$ | 1 |
| 入队 10 | $N_0$ | $N_1$ | $[10]$ | 2 |
| 入队 20 | $N_0$ | $N_2$ | $[10,20]$ | 3 |
| 出队 10 | $N_1$ | $N_2$ | $[20]$ | 3 |
| 入队 30 | $N_1$ | $N_0$ | $[20,30]$ | 3 |
| 出队 20 | $N_2$ | $N_0$ | $[30]$ | 3 |
| 出队 30 | $N_0$ | $N_0$ | $[]$ | 3 |
| 入队 40 | $N_0$ | $N_1$ | $[40]$ | 3 |

2. **关键环节是“旧结点复用”。** 出队两个元素后，旧 `N0`、`N1` 均未释放，仍在环中。最后一次入队 $40$ 时，`front=rear=N0`，`rear->next=N1`，因此队空但**并不满**（已申请了三个结点）；直接向 $N_0$ 写入 $40$，前移 `rear` 即可，不需要 `malloc`。
3. **判空不等于判满。** 对初始单结点队列，两者条件可以同时成立；对已经扩展到三个结点的空队列，`front==rear` 成立，而 `rear->next==front` 不成立。把“空队列一定要扩容”当成普遍规则，会错误增加结点数。每次的出队值来自 `front` 处的逻辑数据，不应从 `rear` 处读取。

</ExamExplanation>

<ExamQuestion>

系统需要维护两个独立的 FIFO 队列 `Q1`、`Q2`，要求它们**共享一个空闲结点池**：从任一队列出队后，结点不释放到操作系统，而是放回公共空闲链表，另一队列入队时可以复用；如果结点池为空才向操作系统申请新结点。

1. 为每个队列及公共结点池设计所需指针与不变量；
2. 给出入队、出队的 C 实现，保证各操作最多修改常数个指针；
3. 说明与原题的循环复用方案相比，何时更适用，以及时间和累计内存复杂度。

<ExamSolution>

<ExamAnswer>

1. 每个队列保存 `first,last`，空队列时两者均为 `NULL`；公共池用 `freeList` 指向单链表表头。
2. 入队从 `freeList` 弹出结点或申请一个结点后尾插；出队从队首摘除结点，将其头插回 `freeList`。
3. 入队和出队均 $O(1)$（单结点分配视为 $O(1)$），适合多个队列共享历史申请量；累计空间为 $O(H)$，其中 $H$ 是历史上同时占用结点数的最大值（不计池元数据）。

</ExamAnswer>

<ExamExplanation>

1. **数据结构与不变量。** 三条单链表：`Q1`、`Q2` 和 `freeList`。每个物理结点在任何时刻恰好属于其中一条链，不能重复挂接。队列的 `first` 指向待出队结点、`last` 指向最后一个待出队结点，尾结点的 `next` 设为 `NULL`；空队列两指针均为 `NULL`。空闲链表不关心结点中陈旧的 `data` 值。
2. **独立于具体队列的实现。**

```c
#include <stdlib.h>

typedef struct PoolNode {
    int data;
    struct PoolNode *next;
} PoolNode;

typedef struct {
    PoolNode *first, *last;
} PoolQueue;

typedef struct {
    PoolNode *freeList;
} NodePool;

int PoolEnqueue(NodePool *pool, PoolQueue *q, int value) {
    PoolNode *p;
    if (pool->freeList != NULL) {
        p = pool->freeList;
        pool->freeList = p->next;
    } else {
        p = (PoolNode *)malloc(sizeof(PoolNode));
        if (p == NULL) return 0;
    }
    p->data = value;
    p->next = NULL;
    if (q->last != NULL) q->last->next = p;
    else q->first = p;
    q->last = p;
    return 1;
}

int PoolDequeue(NodePool *pool, PoolQueue *q, int *out) {
    if (q->first == NULL) return 0;
    PoolNode *p = q->first;
    *out = p->data;
    q->first = p->next;
    if (q->first == NULL) q->last = NULL;
    p->next = pool->freeList;
    pool->freeList = p;
    return 1;
}
```

3. **共享的意义。** 假设先在 `Q1` 中积累 $100$ 个元素，随后全部出队，此时公共池有 $100$ 个结点；即使 `Q2` 从未申请过结点，接下来的 $100$ 次入队也可以直接取池里的结点，无需再申请。若两个队列各自维护一个独立的循环结点集合，就不能直接实现跨队列复用。
4. **效率与内存统计。** 每次入队最多从池头弹出一个结点或申请一个结点，尾插为常数指针操作；出队与池头插也是常数操作，故每次 $O(1)$。若历史上两个队列实际元素数之和的峰值为 $H$，从空池起步、没有特殊额外备用结点时，一共至多向系统申请 $H$ 个结点。出队只在池与队列之间搬移结点，累计申请量不减。真正结束系统时还应遍历三个链表统一释放，销毁过程为 $O(H)$。

</ExamExplanation>

</ExamSolution>

## 2026 年第 42 题

<ExamQuestion>

**36. 2026 年第 42 题**

{/* 原整理文件本题题面存在 OCR 漏项/错项；此处已按公开真题题面交叉核对修正。 */}

栈的基本操作有入栈和出栈。将序列

$$
1,2,3,\ldots,n
$$

依次入栈，回答下列问题：

1. 当 $n=9$ 时，可以得到出栈序列

   $$
   \{2,3,1,6,4,7,5,9,8\}
   $$

   吗？可以得到出栈序列

   $$
   \{2,3,1,5,6,7,4,9,8\}
   $$

   吗？
2. 假设 $1,2,\ldots,n$ 组成任意出栈序列 $P_1,P_2,\ldots,P_n$。若其中存在 $P_i,P_j,P_k$，且 $i<j<k$，使该出栈序列不能由栈得到，则这三个元素满足怎样的大小关系？
3. 若 $n=4$，则以 $2$ 开头的合法出栈序列共有多少个？
4. 若 $n=k-1$ 时合法出栈序列总数为 $M$。当 $n=k$ 时，以 $1$ 开头的合法出栈序列有多少个？以 $2$ 开头的有多少个？总数是多少？

<ExamSolution>

<ExamAnswer>

1. **可行性：** 出栈序列 $(2,3,1,6,4,7,5,9,8)$ 不可实现；$(2,3,1,5,6,7,4,9,8)$ 可以实现。
2. **禁形关系：** 若按输出顺序存在 $i<j<k$ 使 $P_j<P_k<P_i$，则该输出序列不合法；这称为“$312$ 型禁形”。反过来，升序输入的单栈出栈排列只要不存在这种禁形，就一定合法。
3. **计数：** 当 $n=4$ 时，首元素为 $2$ 的合法出栈序列共有 $5$ 个。
4. **一般结果：** 当 $k\ge2$ 且 $C_{k-1}=M$ 时，首项为 $1$ 的有 $M$ 个，首项为 $2$ 的有 $M$ 个；总数为

$$
C_k=\frac{2(2k-1)}{k+1}M.
$$

</ExamAnswer>

<ExamExplanation>

1. **首先牢记栈的 LIFO 约束。** 输入 $1,2,\ldots,n$ 的压栈次序固定，操作可以在任意合法时刻交错，但一次只能弹出当前栈顶。考察指定出栈顺序时，可采用唯一有效的**贪心模拟**：若下一待输出值还未入栈，就一直压栈到该值；之后只有栈顶等于该值才可弹出。不能跳过压栈顺序，也不能越过栈顶取更深层元素。
2. **第一组为何不可能？** 要输出 $2,3,1$，过程必为 `push1,push2,pop2,push3,pop3,pop1`，此时栈空。下一目标为 $6$，必须顺序压入 $4,5,6$ 再弹出 $6$，栈自底向顶还剩 $4,5$。下一个目标为 $4$，然而当前栈顶是 $5$，无法直接弹出 $4$，故不合法。它含有禁形 $(6,4,5)$，满足 $4<5<6$ 且输出顺序为 $6,4,5$。
3. **第二组为何可以？** 一条完整合法操作记录为：

```text
压1、压2、弹2；压3、弹3、弹1；
压4、压5、弹5；压6、弹6；压7、弹7、弹4；
压8、压9、弹9、弹8。
```

   输出恰为 $2,3,1,5,6,7,4,9,8$，因此可实现。请注意“找出一条合法操作过程”就足以证明**可以**；而要证明**不可以**，需指出某个时刻必须越过栈顶（或给出禁形）。
4. **$312$ 禁形的必要性。** 若出栈序列中依次出现 $P_i,P_j,P_k$，其中 $i<j<k$ 且 $P_i>P_k>P_j$，因为输出 $P_i$ 时更小的 $P_j,P_k$ 已经按升序压入过栈，且 $P_j$ 被压入得更早、位置更深，所以无法在 $P_k$ 之前弹出 $P_j$。故出现这种三元组就不合法。**充分性**可由贪心模拟反证：若模拟首次被卡在“待弹 $x$ 被较大的栈顶 $y$ 挡住”且 $x<y$，那么曾有更早输出的 $z>y$ 使 $y$ 被压栈却未弹出，此时 $(z,x,y)$ 构成 $312$ 禁形。故无禁形时模拟必能完成。
5. **$n=4$、首项为 $2$ 的枚举。** 首先必须 `push1,push2,pop2`，栈里剩 $1$，未压的数为 $3,4$。依照后续操作的可行性，五种合法出栈序列为

$$
2134,\quad2143,\quad2314,\quad2341,\quad2431.
$$

   对应数量是 $5=C_3$。枚举法适合小规模，切忌写出一个排列就默认它可实现；比如 $2413$ 不合法，因为输出 $4$ 后栈顶为 $3$，不能越过它弹 $1$。
6. **卡特兰数与完整计数。** 合法出栈序列数目等于合法的压栈/出栈括号路径数：用一次入栈记为左括号、一次出栈记为右括号，共有 $n$ 对括号，任意前缀出栈次数不能超过入栈次数。它恰是卡特兰数

$$
C_n=\frac{1}{n+1}\binom{2n}{n},\qquad C_0=1.
$$

   首项为 $1$ 时，先 `push1,pop1`，剩余 $2\sim k$ 构成规模 $k-1$ 的同构问题，故有 $C_{k-1}=M$ 种。首项为 $2$ 时，强制前缀为 `push1,push2,pop2`，栈里还留着最底层的 $1$；其余阶段可视为一个“先压入 1，再与 3..k 交错操作”的规模 $k-1$ 的合法栈操作序列，同样有 $M$ 种。注意该断言只针对**首项恰为 $1$ 或 $2$**，不可推成所有首项数目都相等。
7. **推导相邻卡特兰数的比值。** 由组合数公式，

$$
\frac{C_k}{C_{k-1}}
=\frac{\frac1{k+1}\binom{2k}{k}}{\frac1k\binom{2k-2}{k-1}}
=\frac{k}{k+1}\cdot\frac{(2k)(2k-1)}{k^2}
=\frac{2(2k-1)}{k+1},
$$

   所以

$$
\boxed{C_k=\frac{2(2k-1)}{k+1}M}.
$$

   例如 $k=4$ 时 $M=C_3=5$，得到 $C_4=14$。这里的 $M$ 是**规模 $k-1$ 的全部合法序列数**，不是任意固定首元素的序列数。
8. **考试避坑。** 判定用栈模拟最可靠；“含 $312$ 禁形”指三个位置按出现先后构成 $P_i$ 大、$P_j$ 小、$P_k$ 中的关系，不能误写为按输入位置比较；计数时辨别题目是“以某个元素开头”还是“全部合法序列”，以及栈的输入顺序是否固定。

</ExamExplanation>

<ExamQuestion>

输入序列固定为 $1,2,\ldots,n$，只允许通过一个初始为空的栈，按顺序入栈并在任意时刻合法出栈。现给出长度为 $n$ 的一个排列 $P$。

1. 设计 $O(n)$ 时间判断 $P$ 是否为合法出栈序列的算法；
2. 用 C 语言给出代码，说明栈顶元素不匹配时为何可立即判失败；
3. 判断 $n=8$ 时的两组序列：$P=(3,2,1,6,5,4,8,7)$ 与 $Q=(3,1,2,6,5,4,8,7)$，分析复杂度。

<ExamSolution>

<ExamAnswer>

1. 从 $1$ 依序压栈，若目标元素尚未入栈，就压到该元素入栈为止；随后检查栈顶是否为目标元素，相等则弹出，否则失败。
2. 当某目标在栈中却不是栈顶时，只继续压新元素会使障碍更深，不能改变失败事实。
3. $P$ 合法；$Q$ 不合法（开头三个元素 $3,1,2$ 构成 $312$）。时间 $O(n)$、辅助栈空间 $O(n)$。

</ExamAnswer>

<ExamExplanation>

1. **单调推进的模拟状态。** `next` 是下一个尚未入栈的输入值，初始为 $1$；数组 `stack[0..top]` 记录当前栈。输出位置从左到右处理：①一直压栈直到目标已被压入；②若栈顶等于目标，弹出；③否则返回失败。每个元素至多一次入栈、一次出栈，因此不会因为 `while` 嵌套而达到 $O(n^2)$。
2. **代码。** 假设输入是 $1\sim n$ 的排列；也用范围和栈顶比较避免无效输出造成越界。

```c
#include <stdlib.h>

int IsStackPermutation(const int P[], int n) {
    if (P == NULL || n < 0) return 0;
    int *s = (int *)malloc((size_t)(n > 0 ? n : 1) * sizeof(int));
    if (s == NULL) return 0;
    int top = -1, next = 1;
    for (int i = 0; i < n; ++i) {
        int want = P[i];
        if (want < 1 || want > n) { free(s); return 0; }
        while (next <= want) s[++top] = next++;
        if (top < 0 || s[top] != want) {
            free(s);
            return 0;
        }
        --top;
    }
    free(s);
    return 1;
}
```

3. **样例跟踪。** 对 $P$：压入 $1,2,3$ 后连续弹出 $3,2,1$；压 $4,5,6$ 后弹 $6,5,4$；压 $7,8$ 后弹 $8,7$，全部合法。对 $Q$：先压 $1,2,3$、弹出 $3$ 后，栈顶仍为 $2$，下一个目标却是 $1$，不能越过 $2$，所以立即判失败。两者只差一个局部顺序，说明“元素相同、长度相同”远不足以保证合法。
4. **正确性与效率。** 每个目标的输入在尚未压栈时必须先压至该值，否则永不可能输出；一旦目标已在栈内，若不位于顶端，则既不能跳过上方元素出栈，也不能通过压入更大值改善局面，故算法的失败判定必要且充分。总共最多 $n$ 次压栈及 $n$ 次弹栈，故时间 $O(n)$、空间 $O(n)$；若只要求判断一个固定排列而非全部计数，用显式栈模拟通常比三重循环搜索禁形更直接。

</ExamExplanation>

</ExamSolution>

<ExamQuestion>

输入 $1,2,\ldots,n$ 依序进栈。设 $T(n,r)$ 表示合法出栈序列中**第一个出栈元素恰为 $r$** 的序列数，$1\le r\le n$。

1. 证明首个出栈元素若为 $r$，必须先进行哪一段入栈、出栈操作；
2. 在 $n=5$ 时，计算 $T(5,1),T(5,2),T(5,3),T(5,4),T(5,5)$，并核对它们的和；
3. 求 $T(n,r)$ 的一般公式，并以 $T(5,4)$ 为例列出对应的全部序列。

<ExamSolution>

<ExamAnswer>

1. 必须先执行 `push1,...,pushr,popr`，剩余栈高为 $r-1$，另有 $n-r$ 个元素未入栈。
2. 当 $n=5$ 时依次是 $14,14,9,4,1$，总数 $42=C_5$。
3. 公式为

$$
\boxed{T(n,r)=\binom{2n-r-1}{n-1}-\binom{2n-r-1}{n}
=\frac{r}{2n-r}\binom{2n-r}{n}}.
$$

   $T(5,4)=4$，合法序列为 $45321,43521,43251,43215$。

</ExamAnswer>

<ExamExplanation>

1. **固定第一个输出。** 首个弹出的若是 $r$，必然已将 $1,2,\ldots,r$ 全部依次压入，然后弹出 $r$。此时栈内由底到顶是 $1,\ldots,r-1$，高度 $h=r-1$；还剩 $u=n-r$ 次压栈及 $d=n-1$ 次弹栈。后续合法序列与“从栈高 $h$ 出发，做 $u$ 次上升、$d$ 次下降且中途不低于 $0$ 的路径”一一对应。
2. **反射原理计数。** 忽略非负限制，从 $h$ 出发的操作排列有 $\binom{u+d}{u}=\binom{2n-r-1}{n-r}$ 种；首次跌至 $-1$ 的非法路径可通过反射对应到 $\binom{2n-r-1}{n}$ 种序列。因此

$$
T(n,r)=\binom{2n-r-1}{n-r}-\binom{2n-r-1}{n}.
$$

   由于 $\binom{2n-r-1}{n-r}=\binom{2n-r-1}{n-1}$，再利用帕斯卡恒等式整理，就得到答案里的两种等价表达式。约定下标超出范围的组合数为 $0$，因而 $r=n$ 时也成立。
3. **计算 $n=5$。**

| 首元素 $r$ | $T(5,r)$ | 说明 |
|---|---:|---|
| 1 | 14 | 剩余 $4$ 个元素自由合法进出，$C_4=14$ |
| 2 | 14 | 强制首部为 `push1,push2,pop2`，剩余计数也是 $C_4$ |
| 3 | 9 | $\binom{6}{4}-\binom{6}{5}=15-6=9$ |
| 4 | 4 | $\binom{5}{4}-\binom{5}{5}=5-1=4$ |
| 5 | 1 | 所有元素先压栈，再逆序弹出，唯一序列 $54321$ |

   求和为 $14+14+9+4+1=42=C_5=\frac{1}{6}\binom{10}{5}$，与卡特兰总数相符。
4. **列出 $T(5,4)$ 的全部序列。** 首次弹出 $4$ 后栈中为 $1,2,3$，只剩元素 $5$ 尚未压入；可在弹出 $3,2,1$ 的任意“前缀长度”后压入并立即弹出 $5$，共四种：

$$
45321,\quad43521,\quad43251,\quad43215.
$$

5. **知识串联。** 原题只问首项为 $1$ 和 $2$ 的特殊计数，两者均等于 $C_{n-1}$；此题进一步研究任意首项 $r$，得到“卡特兰三角形/投票问题”的表达。记忆 $C_n$ 公式之前，更重要的是识别**合法前缀出栈次数不能超过已入栈次数**的路径约束。

</ExamExplanation>

</ExamSolution>
