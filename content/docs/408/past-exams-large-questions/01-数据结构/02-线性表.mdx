## 2009 年第 42 题

<ExamQuestion>

**2. 2009 年第 42 题**

已知一个带头结点的单链表，结点结构为 `| data | link |`。只给出头指针 `list`。

在不改变链表的前提下，设计一个尽可能高效的算法，查找链表中**倒数第 $k$ 个结点**（$k$ 为正整数）。若查找成功，则输出该结点 `data` 域的值并返回 1；否则返回 0。

要求：

1. 描述算法的基本设计思想；
2. 描述算法的详细实现步骤；
3. 用 C、C++ 或 Java 描述算法，并在关键位置给出注释。

<ExamSolution>

<ExamAnswer>利用“固定间距双指针”：快指针先走 $k-1$ 步，再让快慢指针同步移动，直至快指针到达尾结点。成功时输出慢指针数据并返回 `1`，否则返回 `0`。最坏时间 $O(n)$，辅助空间 $O(1)$，链表保持不变。</ExamAnswer>

<ExamExplanation>

### 一、先读懂题意：什么是“倒数第 $k$ 个结点”

设数据结点依次为 $x_1\to x_2\to\cdots\to x_n$。倒数第 $k$ 个就是顺数第 $n-k+1$ 个，存在的充要条件是 $1\le k\le n$。例如 `head → 10 → 20 → 30 → 40 → NULL`，$k=2$ 时输出 `30`；$k=4$ 时输出 `10`；$k=5$ 时查找失败。

**头结点与首元结点不同**：本题 `list` 指向*不存放有效数据*的头结点，`list->link` 才是第一个数据结点。这里的“倒数第 $k$ 个”只统计数据结点，不能把头结点算进去。

### 二、方法选择与解题突破口

常规方法是先遍历一次得到长度 $n$，再从头走 $n-k+1$ 个数据结点：$O(n)$ 时间，但需要两趟。题目要求“尽可能高效”，可以利用**相对位置不变量**，只做单向的一趟扫描。

定义 $p$ 为快指针，$q$ 为慢指针，两者最初均指向首元结点。让 $p$ 领先 $q$ **恰好 $k-1$ 条 `link` 边**。以后两者每次各走一步，这个距离始终不变。当 $p$ 到达第 $n$ 个数据结点时，$q$ 的下标满足

$$
\operatorname{pos}(q)=n-(k-1)=n-k+1,
$$

因此 $q$ 正是目标结点。关键停止条件是 **`p->link == NULL`（$p$ 在尾结点）**，而非 `p == NULL`（指针已经越过尾结点）。

### 三、可直接上考场的 C 语言实现

```c
#include <stdio.h>

typedef struct LNode {
    int data;
    struct LNode *link;
} LNode;

int FindKthFromEnd(const LNode *list, int k) {
    if (list == NULL || k <= 0) return 0;

    const LNode *p = list->link;  // 第一数据结点，不是头结点
    const LNode *q = list->link;

    // 先让 p 领先 k-1 个结点；若链表不够长，直接失败
    for (int i = 1; i < k; ++i) {
        if (p == NULL) return 0;
        p = p->link;
    }
    if (p == NULL) return 0;     // 空表或 k > n

    // 维护“p 比 q 领先 k-1 个结点”的不变量
    while (p->link != NULL) {
        p = p->link;
        q = q->link;
    }
    printf("%d\n", q->data);
    return 1;
}
```

`const LNode *` 表明算法不需要修改结点；若考试统一使用 `LNode *`，去掉 `const` 也不影响原理。输出位置按题意放在成功分支，不能只返回数据值，因为数据可能等于 `0`。

### 四、手工跟踪与正确性说明

以 `10 → 20 → 30 → 40` 和 $k=2$ 为例：初始 `p=q=10`；快指针先走到 `20`；然后 `(p,q)` 依次是 `(30,20)`、`(40,30)`；`p->link` 为空，故输出 `30`。

循环不变量为：在同步移动阶段，$p,q$ 都指向数据结点，且 $\operatorname{pos}(p)-\operatorname{pos}(q)=k-1$。开始成立；每次同步移动两个下标都加 $1$，所以保持；结束时 $\operatorname{pos}(p)=n$，因此 $\operatorname{pos}(q)=n-k+1$，算法正确。

### 五、复杂度、边界与高频失分点

- **时间**：快指针至多行进 $n-1$ 步，慢指针至多行进 $n-k$ 步，故 $O(n)$；对只有头指针、无随机访问能力的单链表，最坏情况下必须查看尾部才能确认目标位置，因此数量级已最优。
- **空间**：仅两个指针、一个循环变量，$O(1)$；且无结点移动，满足“不改变链表”。
- **边界**：空表、`list==NULL`、$k\le0$、$k>n$ 均失败；$k=1$ 找尾结点，$k=n$ 找首元结点。
- **辨析**：若考题改为**删除**倒数第 $k$ 个，最好让慢指针停在目标的**前驱**，这时应把头结点一起利用，先让快指针从头结点走 $k$ 步。见后面的原创第 127 题。

</ExamExplanation>

## 2010 年第 42 题

<ExamQuestion>

**4. 2010 年第 42 题**

设有 $n$ 个整数（$n>1$）存放在一维数组 $R$ 中。设计一个在时间和空间两方面都尽可能高效的算法，将 $R$ 中的序列循环左移 $p$ 个位置，其中 $0<p<n$。

即把

$$
\langle x_0,x_1,\ldots,x_{n-1}\rangle
$$

变换为

$$
\langle x_p,x_{p+1},\ldots,x_{n-1},x_0,x_1,\ldots,x_{p-1}\rangle.
$$

要求：

1. 给出算法的基本设计思想；
2. 用 C、C++ 或 Java 描述算法；
3. 说明时间复杂度和空间复杂度。

<ExamSolution>

<ExamAnswer>将原数组拆成前缀 $a=R[0\ldots p-1]$ 与后缀 $b=R[p\ldots n-1]$，分别逆置 $a$、$b$，最后逆置整个数组，得到 $ba$。总时间 $O(n)$，额外空间 $O(1)$。</ExamAnswer>

<ExamExplanation>

### 一、考点定位：循环移动不是普通移位

**循环左移 $p$ 位**表示前 $p$ 个元素移到末尾，元素个数与相对次序不变。对 $n=8,p=3$：

```text
原数组: a b c d e f g h
目标  : d e f g h a b c
```

要注意 **数组下标从 $0$ 开始**；旋转后，原位置 $i$ 的元素会到达 $(i-p+n)\bmod n$ 位置。直接按该公式为每个元素赋值会造成覆盖，除非额外开数组或精心安排循环置换。

### 二、三次逆置为什么有效

记前缀为 $a$，后缀为 $b$。用 $\operatorname{rev}$ 表示序列逆置，有

$$
\operatorname{rev}\bigl(\operatorname{rev}(a)\operatorname{rev}(b)\bigr)=ba.
$$

原因是逆置拼接串满足 $\operatorname{rev}(XY)=\operatorname{rev}(Y)\operatorname{rev}(X)$，且逆置两次恢复原序列。所以三次逆置必须依次操作这三个区间：

1. $R[0\ldots p-1]$；
2. $R[p\ldots n-1]$；
3. $R[0\ldots n-1]$。

上述样例执行结果：

```text
a b c | d e f g h    原数组
c b a | d e f g h    逆置前缀
c b a | h g f e d    逆置后缀
d e f g h a b c      整体逆置
```

### 三、规范实现

```c
#include <stddef.h>

static void Reverse(int R[], int left, int right) {
    while (left < right) {
        int tmp = R[left];
        R[left] = R[right];
        R[right] = tmp;
        ++left;
        --right;
    }
}

void LeftRotate(int R[], int n, int p) {
    if (R == NULL || n <= 1) return;
    p %= n;                       // 允许推广到 p >= n 的场景
    if (p < 0) p += n;            // 可兼容有符号输入
    if (p == 0) return;

    Reverse(R, 0, p - 1);
    Reverse(R, p, n - 1);
    Reverse(R, 0, n - 1);
}
```

题目保证 $0<p<n$，因此取模和处理负数是为了增强代码鲁棒性，不是原题必需。逆置中 `left < right` 用于防止中间位置重复交换；若区间长度为 $1$，循环自动跳过。

### 四、效率与最优性

逆置长度为 $t$ 的区间，需要 $\lfloor t/2\rfloor$ 次交换，因此总交换次数是

$$
\left\lfloor\frac p2\right\rfloor
+\left\lfloor\frac{n-p}{2}\right\rfloor
+\left\lfloor\frac n2\right\rfloor\le n.
$$

由此 $T(n)=O(n)$。只使用左右边界与一个临时变量，$S(n)=O(1)$。在元素互异、$0<p<n$ 时，全部 $n$ 个位置的值都改变，因此最坏情况下处理量至少是 $\Omega(n)$，时间量级已最优。

### 五、其他思路与易错点

| 方法 | 时间 | 额外空间 | 主要注意点 |
| --- | --- | --- | --- |
| 辅助数组保存前缀 | $O(n)$ | $O(p)$ | 操作简单，但空间不最优 |
| 每次左移一位、重复 $p$ 次 | $O(np)$ | $O(1)$ | 当 $p$ 很大时效率低 |
| 三次逆置 | $O(n)$ | $O(1)$ | 逆置区间端点最容易写错 |
| 按 $\gcd(n,p)$ 条环交换 | $O(n)$ | $O(1)$ | 需证明每个下标恰好访问一次 |

**考场模板**：当题目要求把连续的 `AB` 变为 `BA`，优先考虑“两段分别逆置，再整体逆置”。变成“循环右移 $p$ 位”时，也可以转为左移 $n-(p\bmod n)$ 位；见原创第 128 题。

</ExamExplanation>

## 2011 年第 42 题

<ExamQuestion>

**6. 2011 年第 42 题**

长度为 $L$（$L\ge1$）的升序序列 $S$ 中，第

$$
\left\lceil\frac{L}{2}\right\rceil
$$

个位置上的数称为 $S$ 的中位数。例如，$S_1=(11,13,15,17,19)$ 的中位数是 15。

两个序列的中位数，定义为将它们全部元素合并并按升序排列后所得序列的中位数。例如，若 $S_2=(2,4,6,8,20)$，则 $S_1$ 与 $S_2$ 的中位数为 11。

现有两个**等长升序序列** $A$、$B$，设计一个在时间和空间两方面都尽可能高效的算法，求它们的中位数。

<ExamSolution>

<ExamAnswer>对两个等长有序区间分别取**下中位数**，比较后等量舍弃不可能的两端，每轮保留两个相同长度的区间，最终各剩一个数时返回较小者。时间复杂度 $O(\log n)$，额外空间 $O(1)$。</ExamAnswer>

<ExamExplanation>

### 一、首先确定中位数口径

本题定义长度为 $L$ 的升序数组的中位数为第 $\lceil L/2\rceil$ 个元素（位置从 $1$ 计数）。**当总长度为偶数时，取中间两个数中较小的一个，而不是平均数。** 两个数组各长 $n$，合并长度为 $2n$，所求就是第 $n$ 小的元素。

例如 $A=(1,3,5,7)$，$B=(2,4,6,8)$，合并后第 $4$ 小为 $4$，不是 $4.5$。

### 二、剪枝依据：有序性 + 成对删去

用 $[s_1,d_1]$、$[s_2,d_2]$ 表示两个当前候选区间，始终维持其长度均为 $L$。取下中位位置

$$
m_1=\left\lfloor\frac{s_1+d_1}{2}\right\rfloor,
\qquad m_2=\left\lfloor\frac{s_2+d_2}{2}\right\rfloor,
$$

记 $a=A[m_1]$、$b=B[m_2]$：

- **$a=b$**：该值的合并秩已跨过目标秩，可直接返回。重复元素不影响结论。
- **$a<b$**：舍弃 $A$ 左端过小的一段与 $B$ 右端过大的一段。
- **$a>b$**：对称地舍弃 $A$ 右端与 $B$ 左端。

这里必须**等量**舍弃，且区分当前区间奇偶长度：

| 条件 | 长度 $L$ 为奇数 | 长度 $L$ 为偶数 |
| --- | --- | --- |
| $a<b$ | 保留 $A[m_1\ldots d_1]$、$B[s_2\ldots m_2]$ | 保留 $A[m_1+1\ldots d_1]$、$B[s_2\ldots m_2]$ |
| $a>b$ | 保留 $A[s_1\ldots m_1]$、$B[m_2\ldots d_2]$ | 保留 $A[s_1\ldots m_1]$、$B[m_2+1\ldots d_2]$ |

**为什么偶数时要 `+1`？** 例如 $L=4$，$m_1=s_1+1$ 是靠左的中间元素，如果 $a<b$，想要两个新区间各留 $2$ 个，就必须从 `m1+1` 开始保留 $A$ 的右半区；若仍从 `m1` 开始就会保留 $3$ 个，破坏等长不变量。

### 三、按长度判断奇偶的推荐 C 实现

```c
int MedianOfTwoEqualSorted(const int A[], const int B[], int n) {
    // 前提：n >= 1，两数组各自按非降序排列
    int s1 = 0, d1 = n - 1;
    int s2 = 0, d2 = n - 1;

    while (s1 < d1) {
        int m1 = s1 + (d1 - s1) / 2;
        int m2 = s2 + (d2 - s2) / 2;
        int len = d1 - s1 + 1;      // 两区间始终等长
        if (A[m1] == B[m2]) return A[m1];

        if (A[m1] < B[m2]) {
            s1 = (len % 2 == 1) ? m1 : m1 + 1;
            d2 = m2;
        } else {
            d1 = m1;
            s2 = (len % 2 == 1) ? m2 : m2 + 1;
        }
    }
    return (A[s1] < B[s2]) ? A[s1] : B[s2];
}
```

指针、下标和区间长度的写法是**等价的**；比较下标奇偶来推断当前长度虽然也可行，却不如直接计算 `len` 容易检查正确性。

### 四、跟踪典型样例

$A=(11,13,15,17,19)$、$B=(2,4,6,8,20)$。

1. 初始长度 $L=5$，中位数 $15>6$：保留 $A=(11,13,15)$、$B=(6,8,20)$。
2. 长度 $L=3$，中位数 $13>8$：保留 $A=(11,13)$、$B=(8,20)$。
3. 长度 $L=2$，下中位数 $11>8$：保留 $A=(11)$、$B=(20)$。
4. 返回 $\min(11,20)=11$。

此例中的保留区间只是候选，不表示所有被删掉的值都不在原合并序列里；关键是**删去的两端不会改变目标中位数的值**。

### 五、正确性、复杂度及常见陷阱

每步依据两数组内部的有序关系，同时剔除数量相等的低端与高端元素，保证新问题对应原问题的同一个下中位数，且两个候选区间仍然等长。长度从 $L$ 降到 $\lceil L/2\rceil$ 或 $\lfloor L/2\rfloor$，故

$$
T(n)=T(\lceil n/2\rceil)+O(1)=O(\log n),\qquad S(n)=O(1).
$$

易错点：①把偶数长度中位数算成均值；②比较后只缩小一个数组；③偶数长度丢错一位；④循环结束后取两剩余元素中的大者；⑤把两数组合并排序，得到较慢的 $O(n)$ 或 $O(n\log n)$ 做法。若两数组**不等长**，这个“等长同步舍弃”模板不能直接照搬，见原创第 129 题。

</ExamExplanation>

## 2012 年第 42 题

<ExamQuestion>

**8. 2012 年第 42 题**

假定采用带头结点的单链表保存单词。当两个单词有相同后缀时，可以共享相同的后缀存储空间。例如 `loading` 与 `being` 的存储映像如下图所示。

<img src="/img/408/past-exams-large-questions/01-数据结构/assets/2012-42-figure-001.svg" alt="2012 年第 42 题共享后缀示意" />

设 `str1`、`str2` 分别指向两个单词所在单链表的头结点，结点结构为 `| data | next |`。设计一个时间上尽可能高效的算法，找出两个链表**公共后缀的起始结点**（图中字符 `i` 所在的结点 $p$）。

要求：

1. 给出算法的基本设计思想；
2. 用 C、C++ 或 Java 描述算法；
3. 说明时间复杂度。

<ExamSolution>

<ExamAnswer>先分别求两链表数据结点数，让较长链表的指针先前进长度差，再同时沿 `next` 前进。第一个满足 `p == q` 的结点就是公共后缀首结点；若均走到 `NULL`，则无公共后缀。时间 $O(m+n)$，空间 $O(1)$。</ExamAnswer>

<ExamExplanation>

### 一、题干关键词：共享结点，不只是字符相同

这道题的两个单词可能拥有共同后缀，是因为它们从某个结点开始，**后续结点在内存中是同一批结点**。必须比较**指针地址** `p == q`，而不是比较 `p->data == q->data`。

例如两个链表各自独立存放 `i → n → g`，虽然字符完全相同，但它们的结点地址不同，按本题定义仍然**没有共享后缀**。

单链表没有多个后继指针；若某一结点相同，其 `next` 也必相同，故两个无环链表一旦相交就会一直共享到尾部，不可能“交叉后又分离”。若有公共结点，两链表尾结点必为同一结点，但**尾结点相同只能判断相交，不能直接定位首次相交点**。

### 二、尾部对齐的设计思路

分别计算链表数据结点数 $m,n$。若 $m>n$，第一表先走 $m-n$ 步；若 $n>m$，第二表先走 $n-m$ 步。这样两指针距离终点 `NULL` 的剩余边数相同。此后同步移动，第一次相等便是公共后缀的起点。

为什么不能简单“两个头部一起走”？例如链表一有 $7$ 个结点、链表二有 $4$ 个结点，公共后缀长 $2$，那么第一个公共结点分别位于第 $6$ 和第 $3$ 个数据位置；从首元同时走并不能同步进入公共部分。

### 三、代码：注意头结点、空链表与指针相等

```c
#include <stddef.h>

typedef struct Node {
    char data;
    struct Node *next;
} Node;

static int LengthOfDataNodes(const Node *head) {
    int n = 0;
    if (head == NULL) return 0;
    for (const Node *p = head->next; p != NULL; p = p->next) ++n;
    return n;
}

const Node *FindCommonSuffix(const Node *str1, const Node *str2) {
    if (str1 == NULL || str2 == NULL) return NULL;
    int m = LengthOfDataNodes(str1);
    int n = LengthOfDataNodes(str2);
    const Node *p = str1->next;
    const Node *q = str2->next;

    while (m > n) { p = p->next; --m; }
    while (n > m) { q = q->next; --n; }

    while (p != q) {
        p = p->next;
        q = q->next;
    }
    return p;                     // 首个共享结点，或 NULL
}
```

**使用 `const Node *` 仅限制修改，不改变指针身份比较。** 题目保证链表无环；若存在环，简单求长度的循环可能无法终止，须先进行判环并设计另一套相交算法。

### 四、正确性与复杂度

对齐完成后，若公共后缀长 $c>0$，两指针各距公共起点的前缀长度都是 $\min(m,n)-c$。同步推进时，会在同一轮第一次到达那个公共起点。此前各自位于未共享前缀，地址必不相等；因此返回的确实是**第一个**共享结点。如果两链表不相交，推进至表尾后两个指针同为 `NULL`，循环结束返回空指针。

计算长度用 $m+n$ 次量级的访问，对齐和同步访问不超过 $m+n$ 次，故总时间 $O(m+n)$；额外空间 $O(1)$，没有修改原链表，也不需要哈希表或栈。

### 五、考场迁移

- **逆序比较字符**不是单链表擅长的操作，因为单链表没有前驱指针；本题本质是两条单链表的**首次相交点**。
- 若允许 $O(m)$ 辅助空间，可用哈希集合记录第一链表的结点地址，再扫描第二链表；但不如长度对齐节省空间。
- 若题目禁止先求长度，仍可用**指针换头法**求交点，时间 $O(m+n)$、空间 $O(1)$，见原创第 130 题。

## 2013 年第 41 题

<ExamQuestion>

**9. 2013 年第 41 题**

已知整数序列

$$
A=(a_0,a_1,\ldots,a_{n-1}),
$$

其中

$$
0\le a_i<n\qquad(0\le i<n).
$$

若存在

$$
a_{p_1}=a_{p_2}=\cdots=a_{p_m}=x,
$$

且

$$
m>\frac n2,
$$

则称 $x$ 为 $A$ 的**主元素**。

例如

$$
A=(0,5,5,3,5,7,5,5)
$$

的主元素为 5；而

$$
A=(0,5,5,3,5,1,5,7)
$$

没有主元素。

设计一个尽可能高效的算法：若主元素存在则输出该元素，否则输出 $-1$。

<ExamSolution>

<ExamAnswer>采用 Boyer–Moore 多数投票算法：第一趟通过“不同值两两抵消”得到唯一可能的主元素候选；第二趟统计该候选的实际出现次数，若严格大于 $n/2$ 则输出，否则输出 $-1$。时间 $O(n)$，额外空间 $O(1)$。</ExamAnswer>

<ExamExplanation>

### 一、概念辨析：什么是主元素

主元素（majority element）必须满足

$$
\operatorname{freq}(x)>\frac n2.
$$

因此主元素至多**一个**，`>= n/2` 不算，等于 $n/2$ 不算。这里的数值范围 $0\le a_i<n$ 可以用于“计数数组法”，但那要 $O(n)$ 辅助空间；更优的算法实际上不依赖于元素的取值范围。

### 二、“投票抵消”为什么能留下主元素

维护当前候选 `candidate` 及**尚未抵消的相同候选个数** `count`。从左到右遍历：

1. `count == 0` 时，把当前元素选作新候选，计数置 $1$；
2. 当前元素等于候选时计数加 $1$；
3. 否则计数减 $1$，表示找到了一个**不同值配对抵消**。

如果真实主元素 $x$ 出现 $f>n/2$ 次，任意消去一个 $x$ 和一个非 $x$ 的配对后，剩余的 $x$ 仍比所有非 $x$ 元素的总数多。不断抵消不可能消尽全部 $x$，所以最后的非零候选一定可以是 $x$（若主元素存在，则最终候选必为 $x$）。

**但“能留下候选”不代表“真的有主元素”**：序列 `(1,2,3,4)` 经过抵消仍可能在变量中保存某个候选，其出现次数只有 $1$。所以**第二趟验证不可省略**。

### 三、标准实现：在下一次循环开始时重选候选

```c
int MajorityElement(const int A[], int n) {
    if (A == NULL || n <= 0) return -1;

    int candidate = 0;
    int count = 0;
    // 第一趟：不同元素成对抵消
    for (int i = 0; i < n; ++i) {
        if (count == 0) {
            candidate = A[i];
            count = 1;
        } else if (A[i] == candidate) {
            ++count;
        } else {
            --count;
        }
    }

    // 第二趟：验证候选出现次数是否严格大于 n/2
    int freq = 0;
    for (int i = 0; i < n; ++i) {
        if (A[i] == candidate) ++freq;
    }
    return (freq > n / 2) ? candidate : -1;
}
```

这里用 `n/2` 的整数除法恰好符合“严格超过一半”的判定。候选默认赋值 `0` 只是 C 语言初始化要求，在第一个有效元素处理时一定会重设，**不会把 0 当作默认正确答案**。

### 四、逐步模拟与不变量

以 $A=(0,5,5,3,5,7,5,5)$ 为例：

| 已扫描元素 | 候选 | count | 说明 |
| --- | ---: | ---: | --- |
| 0 | 0 | 1 | 建立候选 |
| 5 | 0 | 0 | 0 与 5 抵消 |
| 5 | 5 | 1 | 建立新候选 |
| 3 | 5 | 0 | 5 与 3 抵消 |
| 5 | 5 | 1 | 建立候选 |
| 7 | 5 | 0 | 抵消 |
| 5 | 5 | 1 | 建立候选 |
| 5 | 5 | 2 | 同值累加 |

第二趟统计得 `freq=5`，由于 $5>8/2$，输出 $5$。

算法维护的逻辑不变量是：**已处理部分可分成若干“不同值配对”和 `count` 个同为 `candidate` 的未配对元素**。该不变量保证有主元素时第一趟不丢失它。

### 五、复杂度、易错点及推广

时间为两趟扫描 $O(n)+O(n)=O(n)$，只维护常数个整数，空间为 $O(1)$。任何算法至少需要读取输入才能在最坏情况下判断主元素，故 $\Omega(n)$ 时间下界也成立。

常见错误：①把阈值写成 `>= n/2`；②只做投票不验证；③把投票阶段的 `count` 误当作主元素真实出现次数；④直接排序，得到 $O(n\log n)$ 时间；⑤开大小为 $n$ 的计数数组，不满足辅助空间最优；⑥候选值使用 `-1` 作特殊标志，可能在允许负数的变式中冲突。

**变式规律**：若阈值改为“出现次数严格超过 $n/3$”，候选就可能有两个，需要两个候选槽并进行三元抵消；见原创第 131 题。

</ExamExplanation>

</ExamSolution>

<ExamQuestion>

**13. 2015 年第 41 题**

用单链表保存 $m$ 个整数，结点含 `data` 域和指针域，并满足

$$
|data|\le n,
$$

其中 $n$ 为正整数。

现要求设计一个时间复杂度尽可能高效的算法：对于链表中 `data` 的**绝对值相等**的结点，仅保留第一次出现的结点，删除其余绝对值相等的结点。

例如：

<img src="/img/408/past-exams-large-questions/01-数据结构/assets/2015-41-figure-001.svg" alt="2015 年第 41 题原单链表示意图" />

处理后为：

<img src="/img/408/past-exams-large-questions/01-数据结构/assets/2015-41-figure-002.svg" alt="2015 年第 41 题删除重复绝对值后的链表" />

要求：

1. 给出算法的基本设计思想；
2. 给出单链表结点的数据类型定义；
3. 用 C 或 C++ 描述算法；
4. 说明时间复杂度和空间复杂度。

<ExamSolution>

<ExamAnswer>按**绝对值而不是原数值**判重，使用直接寻址表 `seen[0..n]`：首遇某绝对值时保留结点并置位，后续遇到同一绝对值时利用前驱指针断链并释放结点。链表扫描耗时 $O(m)$，标记数组初始化 $O(n)$，因此**严格总时间 $O(m+n)$**、额外空间 $O(n)$；若将表初始化成本另计，链表处理阶段为 $O(m)$。</ExamAnswer>

<ExamExplanation>

### 一、审题与知识点：为什么能用直接寻址

已知 $m$ 个**数据结点**，且 $|data|\le n$，因此可能出现的绝对值只在 $\{0,1,\ldots,n\}$，共 $n+1$ 种。这是典型的“**值域已知且有限 → 直接寻址/位图标记**”信号：以绝对值作为数组下标，不必用链表两两比较。

- `7` 与 `-7` 的绝对值相同，只能保留**先出现**的那个；`0` 也有合法下标 `seen[0]`。
- 链表结点**相对次序不可改变**；只删除重复结点，不能先排序（排序会改变原次序，也可能破坏“第一次”要求）。
- 带头结点时 `head` 不参与去重，`head->next` 才是第一个数据结点。若题面结点成员名为 `link`，全程必须统一用 `link`。

例：`head → 3 → -2 → -3 → 0 → 2 → 3 → NULL`，扫描的绝对值为 `3,2,3,0,2,3`，结果是 `3 → -2 → 0`，保留的是值 `-2`，不能改写为 `2`。

### 二、双指针断链：删除结点时不能错误前移 `pre`

始终维持：`pre` 指向**当前待检查结点 `p` 的前驱**。若 `p` 首次出现，则记录绝对值、同时前移 `pre,p`；若重复，则令 `pre->link=p->link`，释放 `p`，**`pre` 不动**，`p` 改指向 `pre->link`。因为原前驱没有被删除，下一待检查结点仍然在它后面。

循环不变量是：`pre` 之前的已处理数据结点按原次序保留，且所有已保留结点的绝对值互异；`seen[v]` 等价于绝对值 $v$ 曾在已处理前缀中出现过。初始只含空前缀；两种分支都保持该条件；遍历结束便得到正确答案。

### 三、C 代码（考虑空链表与分配失败）

```c
#include <stddef.h>
#include <stdlib.h>

typedef struct LNode {
    int data;
    struct LNode *link;
} LNode;

// 成功返回 1；参数或内存分配不合法时返回 0
int DeleteSameAbs(LNode *head, int n) {
    if (head == NULL || n < 0) return 0;
    size_t slots = (size_t)n + 1;   // 先转 size_t，避免 int 的 n+1 溢出
    unsigned char *seen = calloc(slots, sizeof(*seen));
    if (seen == NULL) return 0;

    LNode *pre = head, *p = head->link;
    while (p != NULL) {
        // 转成长整型后取负，避免出现 abs(INT_MIN) 的未定义行为
        long long value = p->data;
        size_t key = (size_t)(value < 0 ? -value : value);
        // 题目保证 key <= n；若用于通用库可额外检查 key < slots
        if (seen[key] == 0) {
            seen[key] = 1;
            pre = p;
            p = p->link;
        } else {
            LNode *dead = p;
            p = p->link;           // 在 free 前取出后继
            pre->link = p;
            free(dead);           // 仅在链表结点由动态分配时释放
        }
    }
    free(seen);
    return 1;
}
```

若试卷中结点不是通过 `malloc` / `new` 动态申请的，不能机械调用 `free`，应按题目存储约定回收；普通链表大题默认数据结点可释放。`n` 是数据**绝对值上界**，不是链表长度，数组长度必须是 `n+1`。

### 四、复杂度应区分“遍历”与“初始化”

设 $m$ 为链表数据结点数。每个结点仅检查一次，删除也只改常数条指针，处理耗时 $\Theta(m)$；`calloc(n+1,...)` 将 $n+1$ 个槽清零需要 $\Theta(n)$。因此完整实现为

$$
T(m,n)=\Theta(m+n),\qquad S(m,n)=\Theta(n).
$$

不少参考答案将数组预处理视为已完成，因而写“扫描 $O(m)$”；严谨答题应明确是否将**数组初始化**计入复杂度。若 $n$ 相对 $m$ 很大，可改用哈希集合，在通常的平均条件下达 $O(m)$ 时间、$O(m)$ 空间，但须说明哈希碰撞与最坏情形；简单的双重扫描不用辅助表，则为 $O(m^2)$ 时间、$O(1)$ 空间。

### 五、考场得分点与变式

1. **值域信息**给了 $n$：下标范围是 $0$ 到 $n$，不能只申请 `n` 项。
2. 删除时**先记后继，再释放结点**；避免 `free(p)` 后读取 `p->link` 的悬垂指针错误。
3. 碰到重复结点时，不前移 `pre`，否则可能漏删连续重复数据。
4. 对 `-5,5`，保留 `-5` 而不是“统一保留正数”。
5. 如果输入已按**绝对值非递减**排列，甚至不必申请 `seen`，一次相邻比较即可用 $O(1)$ 空间完成（原创第 132 题）。

## 2018 年第 41 题

<ExamQuestion>

**19. 2018 年第 41 题**

给定一个含 $n\;(n\ge1)$ 个整数的数组，请设计一个在时间上尽可能高效的算法，找出数组中**未出现的最小正整数**。

例如：

- 数组 $\{-5,3,2,3\}$ 中未出现的最小正整数为 $1$；
- 数组 $\{1,2,3\}$ 中未出现的最小正整数为 $4$。

要求：

1. 给出算法的基本设计思想；
2. 用 C 或 C++ 描述算法；
3. 说明时间复杂度和空间复杂度。

<ExamSolution>

<ExamAnswer>利用答案一定属于 $\{1,2,\ldots,n+1\}$ 的界限，建立 `seen[1..n]`（实际 C 下标 `0..n-1`），只对 $1\le A[i]\le n$ 的数做标记，再从 $1$ 起寻找第一个缺失值；若 $1$ 至 $n$ 均出现，返回 $n+1$。时间 $O(n)$，额外空间 $O(n)$。若允许修改原数组，可进一步做到 $O(n)$ 时间、$O(1)$ 空间（原创第 133 题）。</ExamAnswer>

<ExamExplanation>

### 一、关键突破：无限整数值域缩小为 $n+1$ 个候选

题目要找的是**最小未出现的正整数**，而不是数组的最小正元素，也不是连续整数序列的第一个空洞。对于长度为 $n$ 的数组，最多包含 $n$ 个不同正整数，因此在 $1,2,\ldots,n+1$ 中至少缺一个；若 $1$ 到 $n$ 都出现，答案就恰为 $n+1$。

所以所有**非正数、大于 $n$ 的整数**均不影响最小缺失值；重复出现的合法值仅标记一次。例如 `A=[2,2,1,-4,100]`，$n=5$，标记 `1,2`，故答案 $3$；数组中存在 `100` 并不要求开一个 101 大小的表。

### 二、算法设计与 C 代码

用下标 `x-1` 表示正整数 `x` 是否出现。注意**必须先判定上下界再作下标运算**，避免访问 `seen[-1]` 或 `seen[n]`。

```c
#include <stdlib.h>

// n >= 1 为题目保证；-1 表示内存分配失败而不是数学答案
int FindMissMin(const int A[], int n) {
    if (A == NULL || n <= 0) return -1;
    unsigned char *seen = calloc((size_t)n, sizeof(*seen));
    if (seen == NULL) return -1;

    for (int i = 0; i < n; ++i) {
        int x = A[i];
        if (x >= 1 && x <= n) seen[x - 1] = 1;
    }

    for (int i = 0; i < n; ++i) {
        if (!seen[i]) {
            free(seen);
            return i + 1;
        }
    }
    free(seen);
    return n + 1;  // 题目数据规模需使 n+1 可表示为 int
}
```

正确性可分两步理解：扫描阶段对每个 $x\in[1,n]$，`seen[x-1]` 最终为 1 当且仅当原数组中出现过 $x$；查询阶段从小到大找首个未标记值，必为最小缺失正整数。若无缺失，则 $n+1$ 必不存在于一个恰包含 $1$ 到 $n$ 的长度 $n$ 数组中。

### 三、手工验证与复杂度

| 输入 | 标记结果（有效正整数） | 输出 |
| --- | --- | ---: |
| `[-5,3,2,3]` | `2,3` | `1` |
| `[1,2,3]` | `1,2,3` | `4` |
| `[1,1,2,4]` | `1,2,4` | `3` |
| `[100,0,-1]` | 无 | `1` |
| `[2]` | 无（仅合法区间 1） | `1` |

初始化、标记和查找各自至多遍历 $n$ 次，合起来仍为 $\Theta(n)$；申请 $n$ 个标记字节，辅助空间 $\Theta(n)$。在**必须检查输入所有位置**的模型下，最坏时间下界是 $\Omega(n)$，故时间量级已经最优；空间不是本题要求唯一最优的指标。

### 四、易错点与关联模型

- `x > 0` 还不够，必须 `x <= n`；否则将数组较大数当作下标引发越界。
- `seen[x]` 与 `seen[x-1]` 容易混淆；题目正整数从 1 开始，C 下标从 0 开始。
- **缺失最小正整数**与“最小未出现的非负数”差一个起点：后者候选从 0 开始。
- 若数组可修改，可以用“数值 $x$ 放到下标 $x-1$”的循环置换法避免辅助表；但不能无条件交换，遇到重复值应停止，否则可能死循环。详见原创第 133 题。

</ExamExplanation>

<ExamQuestion>

**21. 2019 年第 41 题**

设线性表

$$
L=(a_1,a_2,a_3,\ldots,a_{n-1},a_n)
$$

采用带头结点的单链表保存，结点定义如下：

```c
typedef struct node {
    int data;
    struct node *next;
} NODE;
```

请设计一个额外空间复杂度为 $O(1)$、时间上尽可能高效的算法，重新排列 $L$ 中的各结点，使其变为

$$
L'=(a_1,a_n,a_2,a_{n-1},a_3,a_{n-2},\ldots).
$$

要求：

1. 给出算法的基本设计思想；
2. 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释；
3. 说明算法的时间复杂度。

<ExamSolution>

<ExamAnswer>用快慢指针把链表分为前后两段，将后半段**原地逆置**，再依次取前半段一个结点、后半段一个结点交替链接，得到 $a_1,a_n,a_2,a_{n-1},\ldots$。时间 $\Theta(n)$，辅助空间 $\Theta(1)$；不新增数据结点，不改变结点数据。</ExamAnswer>

<ExamExplanation>

### 一、题型识别：单链表“首尾交替”不能直接两端取数

单链表只有后继指针，没有前驱指针，不能像数组那样在 $O(1)$ 时间访问末尾前面的元素。若每取一个尾部结点都从头查找，则总体可能为 $\Theta(n^2)$。本题要求 $O(1)$ 额外空间，因此不能先把所有结点地址压栈。

核心通法是**快慢指针找中点 → 后半段原地逆置 → 双链交织**。如果 $n=6$，链表为 `1→2→3→4→5→6`，拆分为 `1→2→3` 和 `4→5→6`，逆置后半为 `6→5→4`，交织后得到 `1→6→2→5→3→4`。

### 二、奇偶长度的断链位置（最常考失分处）

`slow=fast=head->next`，迭代条件是 `fast->next != NULL && fast->next->next != NULL`，每轮 `slow` 前进 1、`fast` 前进 2。结束后 `slow` 在前半段的末结点：

- $n=2r$ 时，前半段有 $r$ 个，后半段有 $r$ 个；
- $n=2r+1$ 时，前半段有 $r+1$ 个，后半段有 $r$ 个。

奇数长度应让**中间结点留在前半段**，否则合并时可能访问不存在的前段结点。断链 `slow->next=NULL` 是必要的，否则旧链接与新链接可能形成环。

### 三、完整 C 实现（按题目 NODE 定义）

```c
#include <stddef.h>

typedef struct node {
    int data;
    struct node *next;
} NODE;

void Rearrange(NODE *head) {
    if (head == NULL || head->next == NULL ||
        head->next->next == NULL) return;  // 0 或 1 个数据结点

    NODE *slow = head->next, *fast = head->next;
    while (fast->next != NULL && fast->next->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }

    NODE *second = slow->next;
    slow->next = NULL;             // 前半段与后半段彻底断开

    NODE *prev = NULL;
    while (second != NULL) {      // 逆置后半段
        NODE *next = second->next;
        second->next = prev;
        prev = second;
        second = next;
    }
    second = prev;

    NODE *first = head->next;
    while (second != NULL) {      // 前半段长度 >= 后半段
        NODE *a = first->next, *b = second->next;
        first->next = second;
        second->next = a;
        first = a;
        second = b;
    }
}
```

交织阶段每轮**先保存两个后继**，再修改指针。不允许“先改 `first->next`，后用它取得原后继”，那会把原链断掉或造成重复链接。

### 四、正确性证明与边界验证

逆置结束时，后半段从前向后正好是 $a_n,a_{n-1},\ldots$；前半段仍是 $a_1,a_2,\ldots$。因此第 $t$ 轮交织严格生成 $a_t,a_{n-t+1}$。两段结点数相等或前半段恰好多 1 个，故不会在 `second!=NULL` 时找不到 `first`，全部结点出现恰好一次。

| 输入长度 | 原链（示意） | 新链 |
| --- | --- | --- |
| 0 或 1 | 空 / `1` | 原样不变 |
| 2 | `1→2` | `1→2` |
| 3 | `1→2→3` | `1→3→2` |
| 4 | `1→2→3→4` | `1→4→2→3` |
| 5 | `1→2→3→4→5` | `1→5→2→4→3` |

快慢指针、原地逆置与交织均只走常数趟、每趟最多 $n$ 步，所以 $T(n)=\Theta(n)$，只用有限个指针，$S(n)=\Theta(1)$。在至少需要重新链接大多数结点的最坏情形，时间量级无法低于线性。

### 五、考法迁移

此类题常与**回文链表检测**（找到中点、逆置后半、对比两个半段）、**链表折叠与还原**（原创第 134 题）、**奇偶位置分组**混考。尤其要区分“按结点位置重排”和“对 `data` 排序”：本题不要求改变或比较数据值，真正操作的是结点链接。

## 2020 年第 41 题

<ExamQuestion>

**23. 2020 年第 41 题**

定义整数三元组 $(a,b,c)$ 的距离为

$$
D(a,b,c)=|a-b|+|b-c|+|c-a|.
$$

给定 3 个非空整数集合 $S_1,S_2,S_3$，各集合中的元素已按升序分别存放在 3 个数组中。请设计一个尽可能高效的算法，计算并输出所有可能三元组

$$
(a,b,c),\qquad a\in S_1,\ b\in S_2,\ c\in S_3
$$

中的最小距离。

例如：

$$
S_1=\{-1,0,9\},
$$

$$
S_2=\{-25,-10,10,11\},
$$

$$
S_3=\{2,9,17,30,41\},
$$

则最小距离为 $2$，相应的三元组可以取 $(9,10,9)$。

要求：

1. 给出算法的基本设计思想；
2. 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释；
3. 说明算法的时间复杂度和空间复杂度。

<ExamSolution>

<ExamAnswer>利用恒等式 $D(a,b,c)=2(\max\{a,b,c\}-\min\{a,b,c\})$；三个有序数组各设一指针，计算当前三元组距离，更新答案后仅推进**当前值最小**的指针。到任一数组耗尽为止。总时间 $O(n_1+n_2+n_3)$，额外空间 $O(1)$。</ExamAnswer>

<ExamExplanation>

### 一、化简距离表达式：先推公式再设计指针

令三个数排序为 $x\le y\le z$，则

$$
D(x,y,z)=|x-y|+|y-z|+|z-x|
=(y-x)+(z-y)+(z-x)=2(z-x).
$$

因此中间值不直接影响目标函数，我们真正要最小化的是三个数组各取一个数时的**最大值与最小值之差**。这是“有序多数组合 + 极差最小”的典型模型。

示例 $(-1,0,9)$、$(-25,-10,10,11)$、$(2,9,17,30,41)$：选择 $(9,10,9)$ 时，极差为 $10-9=1$，距离为 $2$；不能输出 1（漏乘系数 2）。

### 二、为什么只推进最小值：贪心的安全性

当前指针所指三元组最小值为 $x$、最大值为 $z$，当前极差是 $z-x$。若保持 $x$ 的指针不动，而仅推进其他数组的指针，由于每个数组升序，**其余值不会变小**，整体最大值至少仍为 $z$，整体最小值至多仍为 $x$，所以极差不可能低于 $z-x$。

换句话说：不前进当前最小值所在数组，就不可能得到比“当前极差”更优的候选；而当前答案已记录，因此我们可安全地跳过这些状态。即使最小值有并列，也可任选一个最小值指针推进；有相等元素时极差可能暂时不降，但不会漏掉最优解。

### 三、推荐代码：避免减法与取绝对值溢出

原题数据类型是 `int`，但 `abs(a-b)` 可能因**先做了有符号整数减法**而溢出。更稳健的实现先转为 `long long`，用极差计算，返回 64 位距离；若试卷保证所有结果在 `int` 范围，最终再转为 `int`。

```c
#include <limits.h>
#include <stddef.h>

long long Min3Distance(const int A[], int n1,
                       const int B[], int n2,
                       const int C[], int n3) {
    if (A == NULL || B == NULL || C == NULL ||
        n1 <= 0 || n2 <= 0 || n3 <= 0) return -1;

    int i = 0, j = 0, k = 0;
    long long best = LLONG_MAX;
    while (i < n1 && j < n2 && k < n3) {
        long long a = A[i], b = B[j], c = C[k];
        long long lo = a < b ? (a < c ? a : c)
                             : (b < c ? b : c);
        long long hi = a > b ? (a > c ? a : c)
                             : (b > c ? b : c);
        long long d = 2LL * (hi - lo);  // int 输入三数的极差最多为 2^32-1
        if (d < best) best = d;
        if (best == 0) break;

        if (a <= b && a <= c) ++i;
        else if (b <= a && b <= c) ++j;
        else ++k;
    }
    return best;
}
```

当返回 `-1` 时表示非法输入（正常距离非负）。更宽泛的变式若输入本身是 64 位整数，`hi-lo` 还可能溢出，须使用能覆盖差值范围的更宽类型或明确输入约束。

### 四、样例追踪与边界

取 `S1=[1,7]`,`S2=[4,8]`,`S3=[5,6]`：

| 三元组 | 极差 | 距离 $D$ | 下一步 |
| --- | ---: | ---: | --- |
| $(1,4,5)$ | 4 | 8 | 移动 $S_1$（1 最小） |
| $(7,4,5)$ | 3 | 6 | 移动 $S_2$（4 最小） |
| $(7,8,5)$ | 3 | 6 | 移动 $S_3$（5 最小） |
| $(7,8,6)$ | 2 | 4 | 移动 $S_3$，结束 |

故最小距离为 $4$。如果三数组存在共同数值，则能组成 $(t,t,t)$，答案直接为 $0$，已是绝对下界，可提前结束。如果有某个数组只有一个数，指针仍适用；任意数组一旦耗尽，便不可能再从三个集合各取一个数，循环应立即停止。

每轮恰有一个指针增加 1，因此总轮数至多 $n_1+n_2+n_3-2$，时间 $O(n_1+n_2+n_3)$，额外空间 $O(1)$，远优于三重循环 $O(n_1n_2n_3)$。

### 五、迁移：最小覆盖区间与多路归并

若从 **$k$ 个**已排序数组中各取一个数，最小化 `max-min`，仍可“推进当前最小值”；但逐轮找最小值要 $O(k)$，可用**小根堆存当前每路最小值 + 维护当前最大值**做到 $O(N\log k)$，其中 $N$ 为所有数组元素总数。原创第 135 题给出完整模型与堆实现。

</ExamExplanation>

## 2025 年第 41 题

<ExamQuestion>

**33. 2025 年第 41 题**

设有两个长度均为 $n$ 的一维整型数组 `A` 和 `res`。对数组 `A` 中的每个元素 `A[i]`，需要计算

$$
\max_{i\le j\le n-1}\{A[i]\cdot A[j]\},
$$

并将结果保存到 `res[i]` 中。

例如，若

$$
A=\{1,4,-9,6\},
$$

则

$$
res=\{6,24,81,36\}.
$$

请设计时间和空间上尽可能高效的算法

```c
void calMulMax(int A[], int res[], int n);
```

要求：

1. 给出算法的基本设计思想；
2. 使用 C 或 C++ 描述算法；
3. 说明时间复杂度和额外空间复杂度。

<ExamSolution>

<ExamAnswer>从右往左维护后缀**最大元素** `mx` 和**最小元素** `mn`，对每个 $i$ 计算 $res[i]=\max\{A[i]\cdot mx,A[i]\cdot mn\}$，并在计算前将 `A[i]` 纳入后缀。时间 $\Theta(n)$、除输出数组外额外空间 $\Theta(1)$。必须同时维护两种极值，因为负数乘积可能反而最大。</ExamAnswer>

<ExamExplanation>

### 一、读懂量词：下标 $j$ 可以等于 $i$

原目标是

$$
res[i]=\max_{i\le j\le n-1}\{A[i]A[j]\}.
$$

这里的后缀**包含 `A[i]` 本身**；例如末位 $res[n-1]=A[n-1]^2$，不能因为“只有一个元素”而设为 0，也不能误解成 $j>i$。如果直接对所有 $i$ 各自扫描右侧，总共需要 $1+2+\cdots+n=\Theta(n^2)$ 次比较。

### 二、符号决定应取后缀最大还是最小

设后缀 $A[i\ldots n-1]$ 的最大值、最小值分别为 $M_i,m_i$。当 $A[i]\ge0$，乘法随 $A[j]$ 增大而不下降，所以最优选 $M_i$；当 $A[i]<0$，乘法随 $A[j]$ 增大而不增，所以最优选 $m_i$。把两种情况统一为：

$$
\boxed{res[i]=\max\{A[i]M_i,\ A[i]m_i\}}.
$$

同时有后缀递推 $M_i=\max(A[i],M_{i+1})$、$m_i=\min(A[i],m_{i+1})$，所以从右往左一扫即可解决全部位置。这体现的是**后缀状态复用 / 动态维护极值**，不需要建立整张后缀表。

### 三、符合原题接口的代码（注明整数范围）

```c
#include <stddef.h>

void calMulMax(int A[], int res[], int n) {
    if (A == NULL || res == NULL || n <= 0) return;

    int mx = A[n - 1], mn = A[n - 1];
    for (int i = n - 1; i >= 0; --i) {
        if (A[i] > mx) mx = A[i];
        if (A[i] < mn) mn = A[i];

        // 先提升到 long long，避免中间乘法在 int 上溢出
        long long p = (long long)A[i] * mx;
        long long q = (long long)A[i] * mn;
        long long ans = (p > q) ? p : q;
        res[i] = (int)ans; // 原题以结果可由 int 表示为前提
    }
}
```

**重要边界**：上面保留了试卷给定的 `int res[]` 接口，因此隐含“每个最大乘积可用 `int` 表示”。如果题目允许任意 32 位整数且不保证乘积落在 `int` 范围，应把 `res` 改成 `long long res[]`，直接写入 `ans`；否则最后强制转换可能截断，不能仅靠长整型**中间变量**彻底规避结果溢出。

### 四、样例完整推导及循环不变量

输入 $A=[1,4,-9,6]$，由右向左：

| $i$ | $A[i]$ | 维护后的 $m_i$ | 维护后的 $M_i$ | 最大乘积 |
| --- | ---: | ---: | ---: | ---: |
| 3 | 6 | 6 | 6 | 36 |
| 2 | -9 | -9 | 6 | 81 |
| 1 | 4 | -9 | 6 | 24 |
| 0 | 1 | -9 | 6 | 6 |

所以 `res=[6,24,81,36]`，且 `i=2` 的最优方案是 $(-9)\times(-9)$，即 $j=i$，不能只盯着后缀最大元素 6。

循环不变量：处理完下标 $i$ 的极值更新之后，`mn,mx` 恰是 $A[i\ldots n-1]$ 的最小值与最大值。由右端单元素后缀作为起点，不变量成立；每向左扩展一个元素时对两个极值取 `min/max`，保持不变量；因此 `res[i]` 被准确计算。扫描只有 $n$ 轮，每轮常数操作，时间 $\Theta(n)$，只用 `mx,mn,p,q` 等有限变量，额外空间 $\Theta(1)$（输出数组不计）。

### 五、考点迁移与常见错误

- **只维护 `mx`**：对负数 $A[i]$ 会错过“负负得正”的最大值。
- **先算乘积再更新极值**：相当于只允许 $j>i$，末位必错。
- **只判断乘数正负，不给出统一公式**：可以做对，但无法体现最优算法的通用后缀模板。
- **输入输出数组别名**：若 `A` 与 `res` 恰好是同一块数组，当前从右向左、先读取更新极值再写 `res[i]` 的实现仍是正确的，因为后续只依赖已缓存的极值；但如果两个数组只是**部分交叠且错位**，可能覆盖尚未读取的输入，不能默认安全。
- **再问“是哪一个 $j$ 取得最大值、相等时取最小下标”**：仅保留极值数值不够，还须维护后缀极值的下标，并专门处理 $A[i]=0$ 的并列情况（原创第 136 题）。

### 原创第 127 题 · 单链表倒数结点的删除与边界处理

<ExamQuestion>

**127. 原创变式：删除单链表倒数第 $k$ 个结点**

设不带数据的头结点指针为 `head`，单链表无环，含 $n$ 个数据结点。设计函数 `DeleteKthFromEnd(Node *head, int k)`：当 $1\le k\le n$ 时，删除倒数第 $k$ 个数据结点并释放其空间，返回 `1`；其余情形返回 `0` 且不得修改原链表。要求单趟扫描、时间 $O(n)$、额外空间 $O(1)$，并说明为什么与查找题的指针起点不同。

<ExamSolution>

<ExamAnswer>使快慢指针**均从头结点出发**，快指针先走 $k$ 步，再让两个指针同时走到快指针指向尾结点；此时慢指针正好是待删除结点的前驱。删除后返回 `1`；若先行不足 $k$ 步则返回 `0`。</ExamAnswer>

<ExamExplanation>

### 模型变化：为什么要找“前驱”而不是目标

在普通单链表中，要删除结点 `t`，必须修改前驱的 `next` 指针为 `t->next`；仅有 `t` 的地址一般无法直接修改其前驱的后继指针，尤其不能通过“复制后继数据”的技巧删除尾结点。因此本题慢指针应落在**目标前一个结点**。

从头结点（视为位置 $0$）出发，快指针先走 $k$ 步。设尾结点位置为 $n$，当快指针走到位置 $n$，慢指针处于 $n-k$，它的 `next` 正是位置 $n-k+1$ 的倒数第 $k$ 个结点。

### C 语言实现

```c
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *next;
} Node;

int DeleteKthFromEnd(Node *head, int k) {
    if (head == NULL || k <= 0) return 0;
    Node *fast = head, *slow = head;

    // 快指针走 k 条边；走不到表示 k > n
    for (int i = 0; i < k; ++i) {
        if (fast->next == NULL) return 0;
        fast = fast->next;
    }
    while (fast->next != NULL) {
        fast = fast->next;
        slow = slow->next;
    }

    Node *victim = slow->next;   // 一定非空
    slow->next = victim->next;   // 先断链，再释放
    free(victim);
    return 1;
}
```

### 验证和技巧

对 `head → 4 → 7 → 9 → NULL`：$k=1$ 删除 `9`，$k=3$ 删除 `4`，$k=4$ 返回 `0` 且结构不变。$k=n$ 时慢指针保持在**头结点**，无需特判删除第一个数据结点。

查找题使用“从首元结点、领先 $k-1$ 步”，删除题使用“从头结点、领先 $k$ 步”。这两个模板本质一致：让慢指针最终落在**你真正需要操作的位置**。时间 $O(n)$、空间 $O(1)$；如果题目还维护**尾指针**，删除最后一个结点时须同步更新尾指针，否则尾指针悬空。

### 原创第 128 题 · 指定区间的循环右移

<ExamQuestion>

**128. 原创变式：将任意子数组原地循环右移**

给定整数数组 `R[0..n-1]` 及合法下标 $0\le l\le r<n$，整数 $k$ 可以大于区间长度。只允许在 $R[l\ldots r]$ 上操作，将该区间内元素循环**右移** $k$ 位，其余元素保持不变。要求最坏时间 $O(r-l+1)$、额外空间 $O(1)$。给出正确性解释及 $k=0$、区间长度为 $1$ 的处理。

<ExamSolution>

<ExamAnswer>令区间长度 $L=r-l+1$，实际右移量 $t=k\bmod L$。依次逆置**整个区间、右移后的前 $t$ 个位置、剩余 $L-t$ 个位置**，即 `Reverse(l,r)`、`Reverse(l,l+t-1)`、`Reverse(l+t,r)`。</ExamAnswer>

<ExamExplanation>

### 模型迁移

原区间写成 $AB$，其中 $B$ 为后 $t$ 个元素、$A$ 为其余前缀，右移后应为 $BA$。利用

$$
AB\xrightarrow{\text{整体逆置}}B^{-1}A^{-1}
\xrightarrow{\text{分别逆置}}BA.
$$

与原题“先各段、后整体”只是逆置顺序相反；两者均为三次区间逆置。

```c
static void Rev(int a[], int l, int r) {
    while (l < r) {
        int x = a[l]; a[l] = a[r]; a[r] = x;
        ++l; --r;
    }
}

void RotateRangeRight(int R[], int n, int l, int r, int k) {
    if (R == NULL || n <= 0 || l < 0 || r >= n || l > r)
        return;
    int L = r - l + 1;
    int t = k % L;
    if (t < 0) t += L;        // 约定负 k 表示反向旋转
    if (t == 0) return;
    Rev(R, l, r);
    Rev(R, l, l + t - 1);
    Rev(R, l + t, r);
}
```

### 跟踪样例与考点总结

`R=[9,1,2,3,4,5,8]`、$l=1,r=5,k=2$，待处理区间 `(1,2,3,4,5)`，右移后变为 `(4,5,1,2,3)`，整个数组为 `[9,4,5,1,2,3,8]`。前缀元素 `9` 与尾部 `8` 未受影响。

由于三次逆置的区间总长度为 $2L$，时间 $O(L)$、额外空间 $O(1)$。若 $t=0$ 或 $L=1$，无需交换。**尤其注意**：区间的左右边界不是 `0` 与 `n-1`；将原题模板生搬到整个数组会破坏区间外元素。

### 原创第 129 题 · 不等长双有序数组的下中位数

<ExamQuestion>

**129. 原创变式：两个不等长升序序列合并后的中位数**

给定两个非降序数组 $A$、$B$，长度分别为 $m$、$n$，允许其中一个为空，但要求 $m+n>0$。不实际合并数组，求总共 $m+n$ 个元素按非降序排列后的第 $\lceil(m+n)/2\rceil$ 小元素。写出 $O(\log(m+n))$ 时间、$O(1)$ 额外空间的算法，并解释为何不能直接对不等长数组套用真题的“成对区间等长收缩”代码。

<ExamSolution>

<ExamAnswer>将问题统一为“找第 $k$ 小”：$k=\lfloor(m+n+1)/2\rfloor$。每轮查看两数组当前尚未删除部分各自最多前 $\lfloor k/2\rfloor$ 个元素的末尾值，删除其中较小端对应的一批元素，并同步减少 $k$；直至 $k=1$ 或某数组耗尽。</ExamAnswer>

<ExamExplanation>

### 一、核心思路：按秩排除，而非硬凑相等长度

设当前待求是两个剩余有序后缀合并的第 $k$ 小元素，首下标为 `i,j`。令

$$
a=\min(\lfloor k/2\rfloor,m-i),\quad
b=\min(\lfloor k/2\rfloor,n-j).
$$

若 `A[i+a-1] <= B[j+b-1]`，则前 $a$ 个 `A` 元素都不可能是当前第 $k$ 小：这些元素之前最多有 $a+b-1<k$ 个元素（来自两数组被观察到的前缀），因此可删除它们，并将 $k$ 改成 $k-a$；否则对称删除 `B` 的前 $b$ 个。若某数组已空，直接从另一数组定位；若 $k=1$，返回两个首元素的较小者。

### 二、完整 C 实现

```c
int KthSorted(const int A[], int m, const int B[], int n, int k) {
    int i = 0, j = 0;                    // 尚未排除部分的首下标
    for (;;) {
        if (i == m) return B[j + k - 1];
        if (j == n) return A[i + k - 1];
        if (k == 1) return A[i] < B[j] ? A[i] : B[j];

        int half = k / 2;
        int a = (m - i < half) ? m - i : half;
        int b = (n - j < half) ? n - j : half;
        if (A[i + a - 1] <= B[j + b - 1]) {
            i += a; k -= a;
        } else {
            j += b; k -= b;
        }
    }
}

int LowerMedian(const int A[], int m, const int B[], int n) {
    // 前提：m,n >= 0 且 m+n > 0；若长度为 0，相应指针可为空
    return KthSorted(A, m, B, n, (m + n + 1) / 2);
}
```

### 三、实例与复杂度

$A=(1,4,9)$、$B=(2,3,5,6,8,10)$，总长度为 $9$，目标是第 $5$ 小（答案为 $5$）。第一次 $k=5$，观察 `A[1]=4` 和 `B[1]=3`，删掉 $B$ 前两项 `(2,3)`，$k=3$；继续按较小边排除，最终得到 $5$。

每轮排除所考察两批中的一批；若有一批受剩余数组长度限制，常很快耗尽并结束，否则 $k$ 至少下降约一半，因此时间 $O(\log(m+n))$，额外空间 $O(1)$。元素允许相等，因为分支使用 `<=`；$m=0$ 或 $n=0$ 由耗尽分支直接返回。

**区别于原题**：原题依赖两个候选区间的长度始终相等；不等长时若仍同时去掉一半，目标排名会错位。统一维护 $k$ 的“第 $k$ 小”模型更稳健，也可推广到寻找上中位数、分位数和任意秩统计量。

### 原创第 130 题 · 双链表指针换头法

<ExamQuestion>

**130. 原创变式：不预先求长度求两个单链表的交点**

设两个**无头结点**、无环单链表的首结点指针为 `a`、`b`，它们可能共享某条非空尾部，也可能完全不相交。设计一个不用显式计算链表长度、不使用辅助数组或集合的算法，返回第一个公共结点的地址，无交点返回 `NULL`。时间 $O(m+n)$，额外空间 $O(1)$，并给出保证终止的证明。

<ExamSolution>

<ExamAnswer>设置两个指针 `p=a,q=b`；每轮当某指针为 `NULL` 时将它切换到另一条链表的首结点，否则让其后移。两个指针分别遍历路径 `A→B` 和 `B→A`，总走过的长度相同，最终在第一个共享结点相遇，或同时为 `NULL`。</ExamAnswer>

<ExamExplanation>

### 一、算法与代码

```c
#include <stddef.h>

typedef struct Node {
    int data;
    struct Node *next;
} Node;

Node *IntersectionNoLength(Node *a, Node *b) {
    Node *p = a, *q = b;
    while (p != q) {
        p = (p == NULL) ? b : p->next;
        q = (q == NULL) ? a : q->next;
    }
    return p;                   // 可能是第一个公共结点或 NULL
}
```

### 二、为什么“换头”能够对齐尾部

记第一条链表独占前缀长 $u$，第二条独占前缀长 $v$，共享后缀长 $c$，故 $m=u+c$、$n=v+c$。指针 `p` 行进路径为第一条完整链表（$u+c$），再走第二条独占前缀（$v$）；`q` 行进路径为第二条完整链表（$v+c$），再走第一条独占前缀（$u$），两条路径都在第

$$
u+v+c=m+n-c
$$

次移动后到达同一个共享起始结点。因此不需要提前知道 $m-n$，**换头自动抵消长度差**。

若不存在共享后缀，则两指针依次扫描完两链表后同步变成 `NULL`，共不超过 $m+n$ 次后终止。即使 `a` 或 `b` 原本是 `NULL`，也能终止；若 `a==b`，循环一次也不用走。

### 三、失分警示与模型边界

要比较 `p != q`（**结点地址**），不是 `p->data != q->data`；一定要使用三元表达式先判断空指针，否则解引用 `NULL` 会崩溃。算法要求**无环**，有环时指针可能无限循环。时间 $O(m+n)$、空间 $O(1)$，不修改链表，且与原 2012 年真题的“求长度再尾部对齐”方法具有相同的渐近复杂度。

</ExamExplanation>

### 原创第 131 题 · 超过三分之一的高频元素

<ExamQuestion>

**131. 原创变式：求所有出现次数严格超过 $n/3$ 的元素**

设数组 $A$ 长度为 $n\ge1$，元素可为任意整数且可能重复。要求输出所有满足 $\operatorname{freq}(x)>n/3$ 的**不同元素**；若不存在则输出空结果。设计 $O(n)$ 时间、$O(1)$ 额外空间的算法，写出 C 代码和正确性说明。不得排序、开与 $n$ 成比例的辅助数组或使用哈希表。

<ExamSolution>

<ExamAnswer>满足出现次数大于 $n/3$ 的元素最多两个。维护两个候选和两个计数器：遇到匹配候选则加一，有空槽则填入，否则三个互异元素一起抵消（两个计数器同时减一）。最终必须重新扫描核实两个候选的实际次数。</ExamAnswer>

<ExamExplanation>

### 一、从“过半数”迁移到“超过三分之一”

若存在三个不同值，每个都出现**严格**超过 $n/3$ 次，则出现总次数超过 $n$，矛盾。因此符合条件的元素最多两个。把 Boyer–Moore 的“两个不同值抵消”推广为**三个不同值一组抵消**：删掉三个不同值，任何超过 $n/3$ 的真实高频元素仍不会被全部消去。

### 二、代码（返回找到的不同高频元素数目）

```c
// 将最终结果依次放到 out[0], out[1]；out 至少有两个槽位
int MoreThanThird(const int A[], int n, int out[2]) {
    if (A == NULL || out == NULL || n <= 0) return 0;
    int x = 0, y = 0, cx = 0, cy = 0;

    for (int i = 0; i < n; ++i) {
        int v = A[i];
        if (cx > 0 && v == x) ++cx;
        else if (cy > 0 && v == y) ++cy;
        else if (cx == 0) { x = v; cx = 1; }
        else if (cy == 0) { y = v; cy = 1; }
        else { --cx; --cy; }      // 三个不同元素同时抵消
    }

    // 投票剩余计数不是真实频率，重新验证
    int fx = 0, fy = 0;
    for (int i = 0; i < n; ++i) {
        if (cx > 0 && A[i] == x) ++fx;
        if (cy > 0 && A[i] == y) ++fy;
    }

    int count = 0;
    if (cx > 0 && fx > n / 3) out[count++] = x;
    if (cy > 0 && fy > n / 3 && (cx == 0 || x != y))
        out[count++] = y;
    return count;
}
```

两个候选槽在**都有效时必为不同元素**，而检查次数阶段又防御性地判断 `x != y`，避免重复输出。数组中的数据允许为 `0`、负数，因此不能靠 `-1` 之类哨兵代表“候选为空”，应以 `cx,cy` 是否为零判断。

### 三、例子、正确性与边界

- `A=(1,2,1,3,2,1,2,2)`，$n=8$，阈值 $n/3=8/3$；`1` 出现 $3$ 次、`2` 出现 $4$ 次，二者都要输出。
- `A=(1,2,3,4,5,6)`，$n=6$，任何元素频次均不超过 $2$，输出空集。
- `A=(7)`，$n=1$，`7` 的频率 $1>1/3$，正确输出一个元素。

每一次三元抵消都从扫描前缀中删去三个**值互异**的元素，使某个真实频率超过 $n/3$ 的值不可能完全从候选结构中消失；再次扫描便能筛除伪候选。两趟扫描分别 $O(n)$，四个计数变量加两个候选变量只占 $O(1)$ 空间。

**知识拓展**：阈值改成严格超过 $n/k$，可能的高频值最多 $k-1$ 个，可使用 $k-1$ 个候选槽（Misra–Gries 思想）；若 $k$ 固定，空间仍是 $O(1)$；若 $k$ 随输入增长，空间则为 $O(k)$，不可直接写为常数。

### 原创第 132 题 · 已按绝对值排序的单链表去重

<ExamQuestion>

**132. 原创变式：只用常数辅助空间删除绝对值重复结点**

带头结点单链表的元素已按**绝对值非递减**排列（原 `data` 不一定非递减），例如 `-1 → 1 → -2 → 2 → 2 → -5 → 5`。删除绝对值重复的结点，只保留原链表中每种绝对值**第一次出现**的结点。要求不修改保留结点的数据、原地操作，时间 $O(m)$、额外空间 $O(1)$。请写出 C 算法并说明为什么不需要散列表。

<ExamSolution>

<ExamAnswer>由于绝对值有序，相同绝对值的结点一定连续。设置 `pre` 指向最近一个已保留结点，`p` 指向待判断结点。若二者绝对值相同就删除 `p`，否则保留 `p` 并同步前进，扫描一次即完成。$T(m)=O(m)$、$S(m)=O(1)$。</ExamAnswer>

<ExamExplanation>

### 一、模型变化及解决关键

与 2015 年真题相比，虽然不再给出绝对值范围 $n$，但新增了更强的**绝对值有序**条件：所有绝对值相同的结点构成连续区间（等价于已按关键字分组）。因此只需要记住**最后一个保留结点的关键字**，无需对全表记录“见过哪些值”。

例如输入 `-1 → 1 → -2 → 2 → 2 → -5 → 5`，将各元素取绝对值后为 `1,1,2,2,2,5,5`，结果是 `-1 → -2 → -5`。这里的“保留第一次”指**结点位置**，不能把 `-1` 修改为 `1`。

### 二、代码与正确性

```c
#include <stdlib.h>

typedef struct LNode {
    int data;
    struct LNode *next;
} LNode;

static long long AbsKey(int x) {
    long long y = x;               // 避免 abs(INT_MIN) 问题
    return y < 0 ? -y : y;
}

void UniqueAbsSorted(LNode *head) {
    if (head == NULL || head->next == NULL) return;
    LNode *pre = head->next, *p = pre->next;
    while (p != NULL) {
        if (AbsKey(p->data) == AbsKey(pre->data)) {
            LNode *dead = p;
            p = p->next;
            pre->next = p;
            free(dead);
        } else {
            pre = p;
            p = p->next;
        }
    }
}
```

**不变量**：进入循环时，`pre` 是已扫描区域最后保留的结点，它前面的保留结点绝对值严格递增；`p` 是第一个未处理结点。因为排序条件保证“相同键连续”，若 `p` 与 `pre` 绝对值不同，后续再也不会出现此前已经保留的绝对值，故可安全保留 `p`；相同时删除 `p` 不影响后续次序。由此归纳得到算法正确。

### 三、复杂度、边界与辨析

每个结点最多被访问一次，删除时仅改一次指针，故 $T(m)=\Theta(m)$；只使用两个扫描指针与一个临时指针，$S(m)=\Theta(1)$。空链表或只有一个数据结点时直接返回；连续三个以上重复值也能全部删除，因为重复分支不会移动 `pre`。

**注意**：如果题目仅保证 `data` 数值有序，而没有保证 `|data|` 有序，则 `-5,-3,3,5` 的绝对值为 `5,3,3,5`，相同绝对值未必全部相邻，本算法不能保证正确。解题时必须确认排序关键字与判重关键字完全一致。

### 原创第 133 题 · 原地寻找缺失的最小正整数

<ExamQuestion>

**133. 原创变式：允许修改原数组，空间复杂度必须为 $O(1)$**

给定长度为 $n\ge1$ 的整数数组 `A`，可直接交换数组内的元素，但不允许另外申请与 $n$ 成比例的内存。设计 $O(n)$ 时间、$O(1)$ 额外空间算法，返回未出现的最小正整数。数组可能含负数、零、大整数和重复数。请给出终止性与复杂度证明。

<ExamSolution>

<ExamAnswer>将值 $x\in[1,n]$ 尽可能放到下标 $x-1$ 的“正确位置”；对于每个 `i`，只要 `A[i]` 仍为合法值，且目标位置上的值不同，就交换两处。完成后第一个不满足 `A[i]==i+1` 的位置对应最小缺失正整数；若全都满足则返回 $n+1$。$T(n)=O(n)$、$S(n)=O(1)$。</ExamAnswer>

<ExamExplanation>

### 一、以原数组充当直接寻址表

2018 年原题采用辅助 `seen` 数组；现在题目允许修改输入，因此可使用**下标归位 / 原地哈希**：正整数 $x$ 的“家”是数组下标 $x-1$。只有 $1\le x\le n$ 时才有合法的家，其他数可以留在原处，不会影响结果。

示例 `A=[3,4,-1,1]`：把 `3` 放入下标 `2` 得 `[-1,4,3,1]`；把 `4` 放入下标 `3` 得 `[-1,1,3,4]`；把 `1` 放入下标 `0` 得 `[1,-1,3,4]`。此时 `A[1] != 2`，故答案为 $2$。

### 二、代码：同值停止条件不可缺少

```c
#include <stddef.h>

int FirstMissingPositiveInPlace(int A[], int n) {
    if (A == NULL || n <= 0) return 1;
    for (int i = 0; i < n; ++i) {
        while (A[i] >= 1 && A[i] <= n &&
               A[A[i] - 1] != A[i]) {
            int j = A[i] - 1;
            int t = A[j];
            A[j] = A[i];
            A[i] = t;
        }
    }
    for (int i = 0; i < n; ++i) {
        if (A[i] != i + 1) return i + 1;
    }
    return n + 1;
}
```

`A[A[i]-1] != A[i]` 专门防止重复值造成死循环，例如 `[1,1]` 中第二个 1 的目标位置已是 1，若继续交换，只会把两个相等的数无限交换。

### 三、为什么内层 `while` 不会导致 $O(n^2)$

每执行一次交换，至少把一个**此前未在正确位置**的合法值 $x$ 放入 `A[x-1]`，而该正确位置以后不会被移动出去（目标位置已经是 $x$ 时交换被阻止）。因此整个算法最多执行 $n$ 次有效交换，尽管外层有 $n$ 轮、内部有 `while`，总交换量依然 $O(n)$。最后扫描一次又是 $O(n)$，所以时间 $\Theta(n)$，除临时变量外不分配空间，额外空间 $\Theta(1)$。

### 四、正确性与使用条件

归位结束后，对于每个 $k\in[1,n]$，只要原数组中出现过 $k$，数组位置 `A[k-1]` 就必为 $k$：首次尝试搬运 $k$ 时会将它放到目标位，之后目标位不再变化。于是第一个不满足 `A[i]=i+1` 的下标必对应缺失的最小正数。

边界：`[1,2,3]` 输出 4；`[2,2]` 输出 1；`[-1,0,100]` 输出 1；`[2,1]` 归位后输出 3。本算法**破坏原数组的初始顺序**，若题目要求不改变输入，应回到原题的辅助标记方案；并且此方法依赖元素是整数，不能直接推广到任意比较关键字。

</ExamExplanation>

### 原创第 134 题 · 恢复折叠的链表

<ExamQuestion>

**134. 原创变式：已按首尾交替规则折叠的链表如何原地恢复？**

一个带头结点的单链表，原次序为 $a_1,a_2,\ldots,a_n$，经 2019 年第 41 题的操作后变为 $a_1,a_n,a_2,a_{n-1},a_3,a_{n-2},\ldots$。现在**只提供折叠后的链表**，要求在不知道 $n$ 奇偶性的前提下，恢复原结点次序，时间 $O(n)$、额外空间 $O(1)$，不得交换结点数据、不得新建数据结点。给出 C 代码和正确性分析。

<ExamSolution>

<ExamAnswer>把折叠链表按**位置奇偶**交替拆分为两条链：奇数位依次为 $a_1,a_2,\ldots$，偶数位依次为 $a_n,a_{n-1},\ldots$。原地逆置偶数位链表，再把它接到奇数位链表尾部，即恢复 $a_1\to a_2\to\cdots\to a_n$。时间 $O(n)$，辅助空间 $O(1)$。</ExamAnswer>

<ExamExplanation>

### 一、逆向分析“交织”结构

例如折叠前是 `1→2→3→4→5→6→7`，折叠后 `1→7→2→6→3→5→4`。按新链表的**第 1、3、5、7 个位置**取出的是 `1→2→3→4`；按**第 2、4、6 个位置**取出的是 `7→6→5`。将后者逆置为 `5→6→7` 再接在第一条链末尾，正好复原。

偶数长度如 `1→6→2→5→3→4` 也一样，奇数位与偶数位各 3 个；奇数长度时奇数位比偶数位多 1 个。故拆分规则不依赖 $n$ 的已知值。

### 二、只改链接的 C 实现

```c
#include <stddef.h>

typedef struct Node {
    int data;
    struct Node *next;
} Node;

void Unfold(Node *head) {
    if (head == NULL || head->next == NULL) return;

    Node *oddHead = NULL, *oddTail = NULL;
    Node *evenHead = NULL, *evenTail = NULL;
    Node *cur = head->next;
    int odd = 1;

    while (cur != NULL) {
        Node *next = cur->next;
        cur->next = NULL;                 // 先断开，避免旧链接成环
        if (odd) {
            if (oddTail != NULL) oddTail->next = cur;
            else oddHead = cur;
            oddTail = cur;
        } else {
            if (evenTail != NULL) evenTail->next = cur;
            else evenHead = cur;
            evenTail = cur;
        }
        odd = !odd;
        cur = next;
    }

    Node *prev = NULL;
    cur = evenHead;
    while (cur != NULL) {
        Node *next = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next;
    }
    head->next = oddHead;
    if (oddTail != NULL) oddTail->next = prev;
}
```

### 三、证明及复杂度

折叠定义保证位置奇数链保留原链前 $\lceil n/2\rceil$ 个结点的升序，位置偶数链保留后 $\lfloor n/2\rfloor$ 个结点的逆序；逆置偶数链后，正好成为剩余原结点的正序。因此两段顺次拼接恢复原链。每个结点只经过一次拆分和（若属于偶数位）一次逆置；时间 $\Theta(n)$、指针额外空间 $\Theta(1)$。零个、一个或两个数据结点时也能正确处理。

**高频陷阱**：按 `data` 值的奇偶分链是错误的，这里要按**原折叠链表中的位置奇偶**分组。由于必须修改 `next` 链接，拆分前应先保存 `cur->next`，不能边走边丢失剩余链。

### 原创第 135 题 · K 路最短覆盖区间

<ExamQuestion>

**135. 原创变式：从 $k$ 个有序数组中各取一个值，使极差最小**

给定 $k\ge2$ 个非空、各自按非递减顺序排列的整数数组 $S_0,\ldots,S_{k-1}$，总元素数为 $N$，要求从每个数组各选一个元素，使得这 $k$ 个数的最大值与最小值之差最小。输出包含这些元素的最短闭区间 `[L,R]`；如区间长度并列，优先选择较小的 `L`。设计时间 $O(N\log k)$、额外空间 $O(k)$ 的算法并解释终止条件。可使用 C++17 标准库。

<ExamSolution>

<ExamAnswer>在每个数组的当前元素中维护**最小堆**以及这 $k$ 个当前值的最大值 `currentMax`。每轮由堆顶得到最小值 `currentMin`，用区间 `[currentMin,currentMax]` 更新最优解，再**只推进堆顶所属数组**并重新入堆；某路耗尽则终止。时间 $O(N\log k)$，堆占 $O(k)$ 空间。</ExamAnswer>

<ExamExplanation>

### 一、由三指针推广到 k 路归并

2020 年真题最小化三个数的极差；对于任意 $k$，同样有关键贪心：若当前最小值所在数组的元素保持不变，其他数组的指针只会向右移、取值只会增大，就不可能**严格改善**当前最大值与最小值之差。于是每轮只需推进最小值所在数组。

当 $k$ 是输入参数时，逐轮扫描 $k$ 个当前元素寻找最小值要 $O(kN)$；**小根堆**把“找最小 + 更换一个候选”变为 $O(\log k)$。另单独记录 `currentMax`，它只可能不变或增大：替换的是旧的最小值，新增候选又不小于旧最小值，故原有最大值不会因移除堆顶而失去有效代表（若所有值相等，新值也不会更小）。

### 二、可直接运行的 C++17 实现

```cpp
#include <vector>
#include <queue>
#include <tuple>
#include <utility>
#include <climits>
#include <functional>
using namespace std;

// 输入 k 条非空有序数组，返回最小宽度的 [L,R]
pair<int,int> MinCoverRange(const vector<vector<int>>& a) {
    using Item = tuple<int,int,int>;       // 值、数组编号、数组内下标
    priority_queue<Item, vector<Item>, greater<Item>> pq;
    int k = (int)a.size();
    int currentMax = INT_MIN;

    for (int t = 0; t < k; ++t) {
        pq.emplace(a[t][0], t, 0);         // 前提：各路均非空
        if (a[t][0] > currentMax) currentMax = a[t][0];
    }

    long long bestWidth = LLONG_MAX;
    int bestL = 0, bestR = 0;
    while ((int)pq.size() == k) {
        auto [v, t, j] = pq.top();
        pq.pop();                          // 当前所有值的最小值
        long long width = (long long)currentMax - v;
        if (width < bestWidth ||
            (width == bestWidth && v < bestL)) {
            bestWidth = width;
            bestL = v;
            bestR = currentMax;
        }
        if (j + 1 == (int)a[t].size()) break; // 该路不能再提供元素
        int next = a[t][j + 1];
        pq.emplace(next, t, j + 1);
        if (next > currentMax) currentMax = next;
    }
    return {bestL, bestR};
}
```

为使函数具备完整的输入校验，可在封装接口处先检查 `k>=2` 和每个数组非空；代码直接以题面保证为前提。输入 `int` 时区间宽度可能达 $2^{32}-1$，所以 `width` 要用 `long long`，不能先在 `int` 中相减。`greater<tuple<...>>` 按值、数组序号、下标字典序比较，合法处理重复元素。

### 三、例子与贪心正确性

`S0=[4,10,15,24,26]`、`S1=[0,9,12,20]`、`S2=[5,18,22,30]`。最优区间可取 `[20,24]`，分别从三路选 `24,20,22`，宽度 $4$。另如 `[15,20]` 的宽度为 5，比最优差。由于每次更新答案都基于**每路恰好一个当前元素**，输出的区间一定包含所有 $k$ 类别。

正确性核心是“固定当前最小值时，推进其他路不会产生更小极差；所以如果想得到可能的改进，必须推进某个当前最小值”。反复应用直到某一路耗尽，所有可能改进的必要转移均被检查，保留最短长度和并列最小起点，故答案正确。

### 四、复杂度与进一步考法

初始建堆有 $k$ 次插入，$O(k\log k)$；后续每轮弹出与插入各最多一次，至多处理 $N$ 个元素，因此总时间 $O(N\log k)$，堆内只保持每路一个候选，额外空间 $O(k)$。当 $k=3$ 为常数时退化为 $O(N)$，与 2020 年原题的三指针算法一致。若问题改为使 $k$ 数之和最小，就不能套用此极差贪心，必须重新分析目标函数。

### 原创第 136 题 · 最大后缀乘积及最早下标

<ExamQuestion>

**136. 原创变式：不仅求最大乘积，还要返回最早达到该乘积的位置**

给定由 32 位有符号整数组成的数组 `A[0..n-1]`。对每个 $i$，求

$$
P[i]=\max_{i\le j<n}\{A[i]A[j]\},\qquad
J[i]=\min\{j\mid i\le j<n,\ A[i]A[j]=P[i]\}.
$$

要求乘积使用 64 位有符号整数保存，时间 $O(n)$、除 `P,J` 输出数组外额外空间 $O(1)$，并处理负数、零、重复极值和“并列取最小下标”。

<ExamSolution>

<ExamAnswer>从右向左维护后缀最大值及其最早下标、后缀最小值及其最早下标。若 `A[i]>0`，选择后缀最大值最早下标；若 `A[i]<0`，选择后缀最小值最早下标；若 `A[i]==0`，所有乘积都是零，最早合法下标就是 `i`。使用 `long long` 保存乘积，$T(n)=O(n)$、$S(n)=O(1)$。</ExamAnswer>

<ExamExplanation>

### 一、比 2025 真题多出的考点：最优值与见证位置

原题只维护后缀最大、最小**数值**；本题还需返回最优 $j$，故必须同时保存极值对应的**最小合法下标**。由于扫描方向从右向左，遇到与当前极值相等的值时应把下标更新为更靠左的 `i`，而不是保留旧的较大下标。

尤其注意 $A[i]=0$：无论后缀中是否有正数或负数，所有乘积都是 0，最早的 $j$ 就是 $i$；不能简单选择后缀 `maxIndex` 或 `minIndex`，否则答案可能不是最早下标。

### 二、实现：一趟逆向扫描

```c
#include <stddef.h>

void SuffixProductArgmax(const int A[], long long P[], int J[], int n) {
    if (A == NULL || P == NULL || J == NULL || n <= 0) return;
    int mx = A[n - 1], mn = A[n - 1];
    int maxIndex = n - 1, minIndex = n - 1;

    for (int i = n - 1; i >= 0; --i) {
        // 相等时也更新下标：i 比旧记录更早
        if (A[i] >= mx) { mx = A[i]; maxIndex = i; }
        if (A[i] <= mn) { mn = A[i]; minIndex = i; }

        int j;
        if (A[i] > 0) j = maxIndex;
        else if (A[i] < 0) j = minIndex;
        else j = i;                     // 零的乘积全相同，取最早下标

        J[i] = j;
        P[i] = (long long)A[i] * A[j];  // 乘法前提升到 64 位
    }
}
```

对于 32 位 `int`，两个任意输入值的乘积不会超过有符号 64 位整数的表示范围，所以 `long long` 足够（按常见至少 64 位实现）；若把输入扩大为 64 位，需重新考虑乘法溢出。

### 三、案例及并列规则

- `A=[1,4,-9,6]`，得 `P=[6,24,81,36]`，`J=[3,3,2,3]`。
- `A=[2,3,3]`，`P=[6,9,9]`，`J=[1,1,2]`：对 `i=0`，两次出现 3，必须选较早的下标 1。
- `A=[0,5,-7]`，对 `i=0`，最大乘积是 0，**最早**下标为 0，而不是 1 或 2。
- `A=[-2,-2,3]`，对 `i=0`，后缀最小值 -2 在下标 0、1 均出现，最早下标为 0，乘积为 4。

### 四、正确性、不变量与复杂度

更新极值后 `mx,mn` 分别代表 $A[i..n-1]$ 的最大值和最小值，`maxIndex,minIndex` 是后缀内达到相应极值的**最早位置**。因此对正系数选 `maxIndex`、负系数选 `minIndex`，都能同时最大化乘积并满足并列取早；系数为零时直接选 `i`。每轮常数次比较与一次乘法，时间 $\Theta(n)$，除两个输出数组外只维护四个极值相关变量及循环临时量，辅助空间 $\Theta(1)$。
