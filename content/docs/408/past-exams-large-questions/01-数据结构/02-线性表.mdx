## 2009 年第 42 题

<Question
  id="408-ds-large-2009-42"
  type="essay"
  tags="来源:2009考研408, 考点:单链表双指针"
>

已知一个**带头结点**的单链表，结点结构为 `| data | link |`。只给出头指针 `list`。

在**不改变链表**的前提下，设计一个尽可能高效的算法，查找链表中**倒数第 $k$ 个结点**（$k$ 为正整数）。若查找成功，则输出该结点 `data` 域的值并返回 1；否则返回 0。

要求：

1. 描述算法的基本设计思想。
2. 描述算法的详细实现步骤。
3. 用 C、C++ 或 Java 描述算法，并在关键位置给出注释。

<Solution>

### 答案速览

**快慢双指针，一趟扫描**：`fast` 先走 $k-1$ 步，然后 `fast`、`slow` 同步后移；`fast` 停在表尾时，`slow` 正好是倒数第 $k$ 个结点。时间 $O(n)$，额外空间 $O(1)$，不修改链表。

### 图解：用「固定间距」代替「先求表长」

<AlgoFigure src="/img/408/past-exams-large-questions/01-数据结构/solutions/2009-42-1" w={740} h={392} alt="2009-42 快慢指针三阶段：初始化、fast 先走 k−1 步、同步前进到表尾" caption="以 7 个数据结点、k = 3 为例：两指针始终相差 k−1 条 link，fast 落在表尾时 slow 落在倒数第 k 个" />

把表长记为 $n$。倒数第 $k$ 个结点就是正数第 $n-k+1$ 个，它与表尾**相距 $k-1$ 条边**。所以只要让两个指针保持 $k-1$ 条边的间距一起往后走，前面的指针到达表尾的那一刻，后面的指针就站在目标上——不需要知道 $n$，也不需要第二趟扫描。

### 设计思想与步骤

<Steps>
  <Step>

  ### ① 两指针从首元结点出发

  头结点不存数据，计数必须从 `list->link` 开始：`fast = slow = list->link`。

  </Step>
  <Step>

  ### ② fast 先走 $k-1$ 步，顺便判越界

  每走一步之前检查 `fast` 是否已为空。若先行阶段就遇到 `NULL`，说明表长不足 $k$（含空表），返回 0。

  </Step>
  <Step>

  ### ③ 同步后移直到 fast 指向最后一个结点

  循环条件写 `fast->link != NULL`。每轮两指针各走一步，间距不变；退出时输出 `slow->data` 并返回 1。

  </Step>
</Steps>

### C 语言实现

```c title="2009-42：带头结点单链表的倒数第 k 个结点" lineNumbers
#include <stdio.h>

typedef struct LNode {
    int data;
    struct LNode *link;
} LNode;

int FindKthFromEnd(const LNode *list, int k) {
    if (list == NULL || k <= 0) return 0;

    const LNode *fast = list->link;   // 跳过头结点
    const LNode *slow = list->link;

    for (int i = 1; i < k; ++i) {     // fast 先走 k-1 步
        if (fast == NULL) return 0;
        fast = fast->link;
    }
    if (fast == NULL) return 0;       // 空表或 k 超过表长

    while (fast->link != NULL) {      // 间距保持 k-1
        fast = fast->link;
        slow = slow->link;
    }
    printf("%d\n", slow->data);
    return 1;
}
```

### 正确性与复杂度

- **循环不变量**：同步阶段 `fast` 总比 `slow` 多走 $k-1$ 条边。退出时 `fast` 是第 $n$ 个结点，于是 `slow` 是第 $n-(k-1)=n-k+1$ 个，即倒数第 $k$ 个。
- **失败情形**：$k>n$ 时先行阶段必遇 `NULL`，返回 0；不会解引用空指针。
- **复杂度**：先行 $k-1$ 步 + 同步 $n-k$ 步，合计恰好遍历一遍，时间 $O(n)$；只用两个指针和一个计数器，空间 $O(1)$。

| 边界 | 结果 | 原因 |
| --- | --- | --- |
| 空表（只有头结点） | 返回 0 | 首元结点为 `NULL` |
| $k=1$ | 输出最后一个结点 | 两指针起点重合，直接同步到表尾 |
| $k=n$ | 输出首元结点 | 先行后 `fast` 已在表尾，`slow` 不动 |
| $k>n$ | 返回 0 | 无法建立 $k-1$ 的间距 |

<Callout type="warn" title="易错点">

- 头结点不是第 1 个数据结点，起点必须是 `list->link`。
- 「间距 $k-1$、`fast` 停在末结点」与「间距 $k$、`fast` 停在 `NULL`」是两套口径，**终止条件不能混用**。
- 题目要求「输出 `data` 并返回 1/0」，只返回结点指针不完全符合题意。

</Callout>

</Solution>
</Question>

### 原创强化训练 1 · 删除倒数第 $k$ 个结点

<Question
  id="408-ds-large-2009-42-ext1"
  type="essay"
  tags="来源:原创强化训练, 考点:虚拟头结点"
>

给定一个**不带头结点**的单链表 `head`，`next` 指向后继，结点均由动态内存分配。给定整数 $k$，删除倒数第 $k$ 个结点，返回删除后的新表头。若 $k\le0$ 或 $k$ 超过表长，链表应保持不变。

1. 要求单向扫描，时间 $O(n)$，额外空间 $O(1)$。
2. 说明删除首元结点时，为什么不需要单独编写删除分支。
3. 写出 C 语言实现，处理空链表、越界和释放结点。

<Solution>

### 参考答案

在栈上构造一个**临时哑结点** `dummy`，令其 `next=head`。快、慢指针都从 `dummy` 出发，先让 `fast` 前进 $k$ 条边；再让二者同步移动到 `fast->next==NULL`。这时 `slow` 就是待删结点的**前驱**。删除 `slow->next`，返回 `dummy.next`。

```c title="删除倒数第 k 个结点" lineNumbers
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *next;
} Node;

Node *DeleteKthFromEnd(Node *head, int k) {
    if (k <= 0) return head;

    Node dummy = {0, head};
    Node *fast = &dummy, *slow = &dummy;

    for (int i = 0; i < k; ++i) {
        if (fast->next == NULL) return head; // 长度不足
        fast = fast->next;
    }

    while (fast->next != NULL) {
        fast = fast->next;
        slow = slow->next;
    }

    Node *victim = slow->next;
    slow->next = victim->next;
    free(victim);                       // 题设：结点归调用方所有
    return dummy.next;
}
```

### 为什么正确

删除需要的是**前驱**而非目标结点本身。由于 `fast` 领先 `slow` 恰好 $k$ 条边，快指针停在尾结点时，慢指针刚好位于倒数第 $k$ 个结点的前一位置。

例如 $1\to2\to3\to4$，$k=4$：先行后 `fast` 已在结点 4，`slow` 仍在 `dummy`，所以 `slow->next` 就是原首元结点 1。删除后通过 `dummy.next` 得到新的表头 2，**无需额外判断删除的是不是第一个结点**。

<Callout type="idea" title="迁移技巧">

题目从「查找结点」变成「删除结点」时，优先思考**能否使慢指针落在待删结点的前驱**。临时哑结点可以统一处理「删除首元」和「删除普通结点」。

</Callout>

复杂度：时间 $O(n)$，额外空间 $O(1)$。如果结点由内存池统一管理，须将 `free` 改为对应的释放方式。

</Solution>
</Question>

### 原创强化训练 2 · 含环链表上的倒数定位

<Question
  id="408-ds-large-2009-42-ext2"
  type="essay"
  tags="来源:原创预测训练, 考点:Floyd判环"
>

某程序接收到一个**带头结点**的单链表 `list`，由于指针可能被错误连接，数据结点部分**可能含环**。定义：仅当数据结点形成一个以 `NULL` 结尾的有限链时，才存在「倒数第 $k$ 个结点」。

设计函数 `int SafeFind(const LNode *list, int k)`，规定：

- 有环时返回 `-1`，且不输出数据；
- 无环而 $k$ 合法时输出该结点的 `data`，返回 `1`；
- 其他情况返回 `0`。

要求不改变任何指针，时间 $O(n)$、额外空间 $O(1)$。阐述算法的两层循环不变量。

<Solution>

### 参考答案

**先用 Floyd 快慢指针判环，再在确认无环后执行原题的固定间距扫描**。总时间依旧为线性阶，因为只做常数次扫描；不必创建访问标记表。

```c title="判环 + 倒数定位" lineNumbers
// 使用原题的 LNode 定义与 FindKthFromEnd 函数
int SafeFind(const LNode *list, int k) {
    if (list == NULL || k <= 0) return 0;

    const LNode *slow = list->link;
    const LNode *fast = list->link;

    while (fast != NULL && fast->link != NULL) {
        slow = slow->link;
        fast = fast->link->link;
        if (slow == fast) return -1; // 环内必会相遇
    }

    return FindKthFromEnd(list, k); // 已确认链表以 NULL 结束
}
```

### 关键推导

1. **判环不变量**：每轮慢指针走一条边、快指针走两条边。若二者进入同一个环，快指针相对慢指针每轮前进 1 个环位置，至多再经过一个环长便相遇；无环时快指针必先到 `NULL`。
2. **倒数定位不变量**：无环条件成立后，方可谈尾结点；用原题「快指针领先 $k-1$ 条边」的做法，终止时慢指针指向目标。

时间 $O(n)$，空间 $O(1)$；`n` 表示无环时的链长，或有环时首次进入环前的结点数加环长。

<Callout type="warn" title="命题陷阱">

「有环」时不存在通常意义上的尾结点，因此不能直接执行 `while (fast->link != NULL)`：该循环可能永不结束。**判环是倒数定位的前置条件**，不是可以省略的额外功能。

</Callout>

</Solution>
</Question>

## 2010 年第 42 题

<Question
  id="408-ds-large-2010-42"
  type="essay"
  tags="来源:2010考研408, 考点:循环移位"
>

设有 $n$ 个整数（$n>1$）存放在一维数组 $R$ 中。设计一个在时间和空间两方面都尽可能高效的算法，将 $R$ 中的序列**循环左移 $p$ 个位置**，其中 $0<p<n$。

即把

$$
\langle x_0,x_1,\ldots,x_{n-1}\rangle
$$

变换为

$$
\langle x_p,x_{p+1},\ldots,x_{n-1},x_0,x_1,\ldots,x_{p-1}\rangle.
$$

要求：

1. 给出算法的基本设计思想。
2. 用 C、C++ 或 Java 描述算法。
3. 说明时间复杂度和空间复杂度。

<Solution>

### 答案速览

把 $R$ 看成两段：$X=R[0..p-1]$、$Y=R[p..n-1]$。**先分别逆置 $X$、$Y$，再逆置整个数组**，就由 $XY$ 得到 $YX$，即循环左移 $p$ 位。时间 $O(n)$，额外空间 $O(1)$。

$$
XY\ \xrightarrow{\text{分别逆置}}\ X^{R}Y^{R}\ \xrightarrow{\text{整体逆置}}\ (X^{R}Y^{R})^{R}=YX .
$$

### 图解：三次逆置

<AlgoFigure src="/img/408/past-exams-large-questions/01-数据结构/solutions/2010-42-1" w={680} h={418} alt="2010-42 abcdefgh 循环左移 3 位的三次逆置过程" caption="颜色跟随元素：蓝色是 X 段、橙色是 Y 段。每一行下方的弧线表示下一步要交换的位置对" />

看图中颜色的走向最直观：

1. 逆置前段后，蓝色段内部倒序，`abc` 变 `cba`；
2. 逆置后段后，橙色段内部倒序，`defgh` 变 `hgfed`；
3. 整体逆置一次做了两件事——**两段交换位置**（橙色到前面），同时**各段内部再倒一次序**，恰好恢复成原来的顺序。

所以「整体逆置」负责搬家，「先各自逆置」负责抵消搬家时附带的段内倒序。

### 设计思想

<Steps>
  <Step>

  ### 写一个区间逆置函数

  `Reverse(R, left, right)`：左右下标相向移动，交换 `R[left]` 与 `R[right]`，直到相遇。逆置长度为 $L$ 的区间只需 $\lfloor L/2\rfloor$ 次交换。

  </Step>
  <Step>

  ### 依次调用三次

  `Reverse(R, 0, p-1)`、`Reverse(R, p, n-1)`、`Reverse(R, 0, n-1)`。若位移量可能超出范围，先 `p %= n`。

  </Step>
</Steps>

```c title="2010-42：三次逆置实现循环左移" lineNumbers
#include <stddef.h>

static void Reverse(int R[], int left, int right) {
    while (left < right) {
        int t = R[left];
        R[left] = R[right];
        R[right] = t;
        ++left;
        --right;
    }
}

void LeftRotate(int R[], int n, int p) {
    if (R == NULL || n <= 1 || p < 0) return;
    p %= n;
    if (p == 0) return;

    Reverse(R, 0, p - 1);     // X -> X^R
    Reverse(R, p, n - 1);     // Y -> Y^R
    Reverse(R, 0, n - 1);     // (X^R Y^R)^R = Y X
}
```

### 正确性与复杂度

- **位置映射**：设 $x_i$ 位于 $X$（$i<p$）。第一次逆置把它放到 $p-1-i$，整体逆置再放到 $n-1-(p-1-i)=n-p+i$，正是左移 $p$ 位后的位置 $(i-p)\bmod n$。$Y$ 段同理落到 $i-p$。
- **时间**：三次逆置共交换 $\lfloor p/2\rfloor+\lfloor (n-p)/2\rfloor+\lfloor n/2\rfloor\le n$ 次，$O(n)$。
- **空间**：只用一个临时变量和两个下标，$O(1)$。每个元素都可能要换位置，$O(n)$ 已是最优量级。

<Callout type="warn" title="常见失分点">

- 两段的边界是 `[0, p-1]` 与 `[p, n-1]`，写成 `[p+1, n-1]` 会错位。
- 借一个长度为 $p$ 的辅助数组也能做，但空间是 $O(p)$，不满足「空间尽可能高效」。
- 「先整体逆置，再分别逆置 `[0, n-p-1]`、`[n-p, n-1]`」同样正确，但区间端点不同，不要和本法混写。

</Callout>

</Solution>
</Question>

### 原创强化训练 1 · 子区间循环位移

<Question
  id="408-ds-large-2010-42-ext1"
  type="essay"
  tags="来源:原创强化训练, 考点:区间逆置"
>

整数数组 `A[0..n-1]` 中，只有闭区间 `[l,r]`（$0\le l\le r<n$）允许改变，区间外元素必须保持原来的**位置和值**。给定整数位移量 $p$，约定 $p>0$ 表示区间循环左移，$p<0$ 表示区间循环右移。

1. 设计时间 $O(r-l+1)$、额外空间 $O(1)$ 的原地算法。
2. 说明当 $p$ 为负数或位移量绝对值大于区间长度时如何处理。
3. 对 `A=[0,1,2,3,4,5,6,7,8]`、`l=2,r=7,p=2` 给出结果。

<Solution>

### 参考答案

令区间长度 $m=r-l+1$，将位移规范化为

$$
s=((p\bmod m)+m)\bmod m,\qquad 0\le s<m.
$$

对 `[l,l+s-1]`、`[l+s,r]` 分别逆置，再整体逆置 `[l,r]`。

```c title="循环移动任意子区间"
void RotateRange(int A[], int n, int l, int r, long long p) {
    if (A == NULL || n <= 0 || l < 0 || r >= n || l > r)
        return;
    int m = r - l + 1;
    int s = (int)((p % m + m) % m);
    if (s == 0) return;

    Reverse(A, l, l + s - 1);  // 复用原题逆置函数
    Reverse(A, l + s, r);
    Reverse(A, l, r);
}
```

### 结果与证明

原区间是 `[2,3,4,5,6,7]`，左移 2 位得到 `[4,5,6,7,2,3]`，因此整个数组为：

```text
[0,1,4,5,6,7,2,3,8]
```

区间之外的所有交换均不会触及，故外部位置保持不变。位移量归一化后可直接复用原题的三次逆置证明。三个反转只访问长度为 $m$ 的区间，时间 $O(m)$，额外空间 $O(1)$。

<Callout type="idea" title="拓展迁移">

「旋转整个数组」本质上是「旋转指定区间」的特殊情形；处理负数位移量时不要直接把负数当成 C 语言非负余数。

</Callout>

</Solution>
</Question>

### 原创预测训练 2 · 多次位移的惰性合并

<Question
  id="408-ds-large-2010-42-ext2"
  type="essay"
  tags="来源:原创预测训练, 考点:模运算"
>

长度为 $n$（$n\ge1$）的数组依次接收 $q$ 条操作，每条给出一个可能很大的有符号整数 $p_i$：正数表示**循环左移**，负数表示**循环右移**。**仅在全部操作完成后需要输出最终数组**，不要求中间状态。

1. 证明全部操作可以合并为一次循环位移。
2. 设计总时间 $O(n+q)$、额外空间 $O(1)$ 的算法，不允许因为累计求和而产生有符号整数溢出。
3. 若初始数组为 `abcdefgh`、位移依次为 $3,-2,11$，给出最终数组。

<Solution>

### 参考答案

循环位移在模 $n$ 意义下可加：

$$
s\equiv\sum_{i=1}^q p_i\pmod n,\qquad 0\le s<n.
$$

只维护累计偏移量的模 $n$ 结果，在所有操作结束后调用原题的三次逆置法一次。

```c title="多次位移一次执行"
#include <stddef.h>

// 参数 shift[0..q-1] 保存每次位移指令
void BatchRotate(int A[], int n, const long long shift[], int q) {
    if (A == NULL || n <= 0 || q < 0 ||
        (q > 0 && shift == NULL)) return;

    long long s = 0;
    for (int i = 0; i < q; ++i) {
        // 先将每个大整数缩小到 [0,n-1]，避免累计溢出
        long long x = shift[i] % n;
        if (x < 0) x += n;
        s = (s + x) % n; // s+x <= 2n-2，n 为 int，long long 安全
    }
    LeftRotate(A, n, (int)s);  // 原题函数
}
```

### 解题过程

每次左移 $p_i$ 都把原下标 $j$ 变为 $(j-p_i)\bmod n$，相继执行时得到 $(j-\sum p_i)\bmod n$，所以位移可交换、可结合。代码将每个 `p_i` 先取模，再在 `long long` 中累加，避免直接求和可能溢出。

样例累计位移为 $3-2+11=12$，对长度 $8$ 取模得到 $4$，故最终为 `efghabcd`。

- 扫描 $q$ 个指令耗时 $O(q)$。
- 最终一次逆置耗时 $O(n)$。
- 只保存偏移量和常数个临时变量，额外空间 $O(1)$。

<Callout type="warn" title="适用前提">

惰性合并要求**不需要读取或输出中间每一步的实际数组**。若每条操作后都必须输出整个数组，就不能声称总时间仍为 $O(n+q)$。

</Callout>

</Solution>

## 2011 年第 42 题

<Question
  id="408-ds-large-2011-42"
  type="essay"
  tags="来源:2011考研408, 考点:有序序列中位数"
>

长度为 $L$（$L\ge1$）的升序序列 $S$ 中，第

$$
\left\lceil\frac{L}{2}\right\rceil
$$

个位置上的数称为 $S$ 的中位数。例如，$S_1=(11,13,15,17,19)$ 的中位数是 15。

两个序列的中位数，定义为将它们全部元素合并并按升序排列后所得序列的中位数。例如，若 $S_2=(2,4,6,8,20)$，则 $S_1$ 与 $S_2$ 的中位数为 11。

现有两个**等长升序序列** $A$、$B$，设计一个在时间和空间两方面都尽可能高效的算法，求它们的中位数。

<Solution>

### 答案速览

两序列各长 $n$，合并后共 $2n$ 个数。按题目定义，所求是第 $\lceil 2n/2\rceil=n$ 小的数（**下中位数**，不取平均）。

**折半舍弃**：比较两个候选区间的中位数 $a=A[m_1]$、$b=B[m_2]$——

- $a=b$：直接返回；
- $a<b$：舍弃 $A$ 的较小一半、$B$ 的较大一半；
- $a>b$：舍弃 $B$ 的较小一半、$A$ 的较大一半。

两边**舍弃的个数必须相等**，区间始终等长；各剩 1 个元素时取较小者。时间 $O(\log n)$，空间 $O(1)$。

### 图解：每轮两边各砍掉同样多

<AlgoFigure src="/img/408/past-exams-large-questions/01-数据结构/solutions/2011-42-1" w={760} h={440} alt="2011-42 两个等长有序序列求下中位数的折半过程，共 4 轮" caption="A = (1,3,5,7,9)，B = (2,4,6,8,10)。虚线框是当前候选区间，灰色是已舍弃的元素" />

为什么能这样砍？设 $a<b$，答案一定夹在 $a$ 与 $b$ 之间：

- $A$ 中排在 $m_1$ 左边的数都不超过 $a$，它们**偏小**，不可能是第 $n$ 小；
- $B$ 中排在 $m_2$ 右边的数都不小于 $b$，它们**偏大**，同样不可能是第 $n$ 小。

从「偏小」和「偏大」两头各删掉**同样多个**数，目标在剩余数中的相对位置不变——它仍是剩余部分的下中位数。问题规模减半，递推下去即可。

### 奇偶长度的处理

设当前两区间长度都是 $t$，以 $a<b$ 为例：

| $t$ | $A$ 保留 | $B$ 保留 | 新长度 |
| --- | --- | --- | --- |
| 奇数 | `[m1, r1]`（含中点） | `[l2, m2]`（含中点） | $\lceil t/2\rceil$ |
| 偶数 | `[m1+1, r1]`（去中点） | `[l2, m2]`（含中点） | $t/2$ |

偶数长时下中位数偏左，$A$ 若保留中点就会比 $B$ 多一个，等长被破坏——这正是图中第 3 轮「一边含中点、一边去中点」的原因。$a>b$ 时把 $A$、$B$ 的角色互换。

### C 语言实现

```c title="2011-42：两等长升序数组的下中位数" lineNumbers
int LowerMedian(const int A[], const int B[], int n) {
    // 前提：n >= 1，A、B 均非降序
    int l1 = 0, r1 = n - 1;
    int l2 = 0, r2 = n - 1;

    while (l1 < r1) {                 // 两区间始终等长
        int t  = r1 - l1 + 1;
        int m1 = l1 + (t - 1) / 2;    // 下中位数下标
        int m2 = l2 + (t - 1) / 2;

        if (A[m1] == B[m2]) return A[m1];

        if (A[m1] < B[m2]) {          // 舍 A 左半、B 右半
            l1 = (t & 1) ? m1 : m1 + 1;
            r2 = m2;
        } else {                      // 舍 A 右半、B 左半
            r1 = m1;
            l2 = (t & 1) ? m2 : m2 + 1;
        }
    }
    return A[l1] < B[l2] ? A[l1] : B[l2];
}
```

### 正确性与复杂度

- **不变量**：每轮结束后两区间等长，且原问题的答案仍是两区间合并后的下中位数（前后各删同样多个不可能的候选）。
- **终止**：长度为 1 时，两个元素的下中位数就是较小者。
- **复杂度**：区间长度每轮约减半，$T(n)=T(\lceil n/2\rceil)+O(1)=O(\log n)$；只用若干下标，空间 $O(1)$。

<Tabs items={['对照：线性归并法', '易错点']} defaultIndex={0}>
  <Tab value="对照：线性归并法">

  不开辅助数组，用两个下标做「模拟归并」，数到第 $n$ 个即可：

  ```c
  int LowerMedianLinear(const int A[], const int B[], int n) {
      int i = 0, j = 0, ans = 0;
      for (int cnt = 0; cnt < n; ++cnt) {
          if (A[i] <= B[j]) ans = A[i++];   // 只取 n 个，不会越界到两表都尽
          else ans = B[j++];
      }
      return ans;
  }
  ```

  时间 $O(n)$、空间 $O(1)$，写起来稳妥，能拿到大部分分数；但「时间尽可能高效」的满分答案是 $O(\log n)$ 的折半法。（两表各 $n$ 个，只取 $n$ 个时任何一表都不会先被取空。）

  </Tab>
  <Tab value="易错点">

  - 求的是**第 $n$ 小**，不是两个中位数的平均值。
  - 舍弃时两边个数必须相等，否则目标的名次会漂移；奇偶长度要分支处理。
  - 存在重复值时 `A[m1] == B[m2]` 直接返回是正确的。
  - $n=1$ 时循环不执行，直接返回两元素较小者。

  </Tab>
</Tabs>

</Solution>

### 原创强化训练 1 · 不等长数组的第 $k$ 小

<Question
  id="408-ds-large-2011-42-ext1"
  type="essay"
  tags="来源:原创强化训练, 考点:有序数组第k小"
>

给定两个分别非降序排列的数组 `A[0..m-1]` 和 `B[0..n-1]`，**长度允许不等，也允许一个数组为空**，但 $m+n\ge1$。给定 $1\le k\le m+n$，求将两个数组合并并排序后的**第 $k$ 小元素**，重复元素按出现次数计入排名。

1. 不允许构造完整合并数组。
2. 设计最坏时间 $O(\log k)$、额外空间 $O(1)$ 的迭代算法。
3. 在 `A=[1,2,2,7,9,11]`、`B=[2,2,3,4,8,10]` 上分别求第 6 小和第 7 小，并解释为什么相等元素不影响算法正确性。

<Solution>

### 参考答案

**每次用两个数组当前的第 $\lfloor k/2\rfloor$ 个候选值比较，安全删除其中一个数组的前缀，同时减小目标排名 $k$**。若数组某侧剩余不足 $\lfloor k/2\rfloor$ 个元素，则用该侧剩余长度作为比较步长。

```c title="两个有序数组第 k 小（迭代版）" lineNumbers
int KthOfTwoSorted(const int A[], int m,
                   const int B[], int n, int k) {
    // 前提：m,n >= 0；m+n >= 1；1 <= k <= m+n
    int i = 0, j = 0;

    while (1) {
        if (i == m) return B[j + k - 1];
        if (j == n) return A[i + k - 1];
        if (k == 1) return A[i] < B[j] ? A[i] : B[j];

        int half = k / 2;
        int pa = half < m - i ? half : m - i;
        int pb = half < n - j ? half : n - j;

        if (A[i + pa - 1] <= B[j + pb - 1]) {
            i += pa;
            k -= pa;
        } else {
            j += pb;
            k -= pb;
        }
    }
}
```

### 核心正确性证明

设比较端点为 $a=A[i+p_a-1]$、$b=B[j+p_b-1]$。若 $a\le b$，则当前 A 的前 $p_a$ 个元素都不大于 $a$。对其中任一元素而言，排在其前面或与其相等、且被纳入稳定排序前缀的候选元素至多与 A 的前 $p_a$ 个及 B 的前 $p_b-1$ 个有关，合计少于 $k$ 个，因为 $p_a,p_b\le\lfloor k/2\rfloor$。因此这一段 A 的前缀绝不包含当前第 $k$ 小的最终候选位置，可以删除并将 $k$ 减少 $p_a$。$a>b$ 时对称处理 B。

相等元素只会造成两种合法的删除方向之一；由于保留的是**多重序列的排名**，并不会漏算重复出现的值。

- 样例第 6 小为 **3**，第 7 小为 **4**。
- 每轮在未耗尽数组时删除正数量的前缀，目标规模大致减半，最坏 $O(\log k)$ 轮；常数个下标，空间 $O(1)$。

<Callout type="idea" title="与原题关系">

原题是本题的特例：令 $m=n$ 且 $k=n$，即可求题目定义的两个等长升序数组的中位数。**从「中位数」抽象到「第 $k$ 小」通常更便于推广。**

</Callout>

</Solution>

### 原创预测训练 2 · 循环有序数组与中位数

<Question
  id="408-ds-large-2011-42-ext2"
  type="essay"
  tags="来源:原创预测训练, 考点:旋转数组二分"
>

给定两个长度均为 $n\ge1$ 的数组 `A`、`B`。每个数组最初分别是**严格递增**的整数序列，随后各自循环左移了未知次数，因此目前数组不一定整体有序，但都属于某个严格递增序列的旋转形式。

1. 在不修改原数组的前提下，设计最坏时间 $O(\log n)$、额外空间 $O(1)$ 的算法，求两个数组全部 $2n$ 个元素的**下中位数**。
2. 解释为什么对每个数组先找旋转断点、再进行逻辑下标访问，就能复用原题算法。
3. 对 `A=[5,7,1,3]`、`B=[4,6,8,2]` 求结果。若允许数组内部大量重复，说明同样的断点搜索算法为何不能保证最坏 $O(\log n)$。

<Solution>

### 参考答案

对严格递增旋转数组，最小元素所在下标即为**逻辑有序序列的起点** `pivot`。先用二分法分别求出两个 `pivot`，再用

$$
\mathrm{Get}(X,p,i)=X[(p+i)\bmod n]
$$

按逻辑升序下标读取元素。随后完全复用原题的**等长区间折半**过程。

```c title="旋转有序数组的下中位数" lineNumbers
// 前提：X 是长度 n>=1 的严格递增数组的循环旋转
static int FindPivot(const int X[], int n) {
    int l = 0, r = n - 1;
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (X[mid] > X[r]) l = mid + 1;
        else r = mid; // 严格递增保证此处不会出现等值歧义
    }
    return l;
}

static int Get(const int X[], int n, int pivot, int i) {
    // i、pivot 均在 [0,n-1]：避免直接 int 加法溢出
    int remaining = n - pivot;
    return X[i < remaining ? pivot + i : i - remaining];
}

int LowerMedianRotated(const int A[], const int B[], int n) {
    int pa = FindPivot(A, n), pb = FindPivot(B, n);
    int l1 = 0, r1 = n - 1, l2 = 0, r2 = n - 1;

    while (l1 < r1) {
        int t = r1 - l1 + 1;
        int m1 = l1 + (t - 1) / 2;
        int m2 = l2 + (t - 1) / 2;
        int a = Get(A, n, pa, m1);
        int b = Get(B, n, pb, m2);

        if (a == b) return a;
        if (a < b) {
            l1 = (t & 1) ? m1 : m1 + 1;
            r2 = m2;
        } else {
            r1 = m1;
            l2 = (t & 1) ? m2 : m2 + 1;
        }
    }
    int a = Get(A, n, pa, l1);
    int b = Get(B, n, pb, l2);
    return a < b ? a : b;
}
```

### 为什么正确

1. 若 `X[mid] > X[r]`，严格递增的后缀断点必在 `mid` 右侧；否则最小值在 `[l,mid]`。因此可二分出最小值位置。
2. 从最小值开始按模 $n$ 访问，得到原本的严格递增顺序；这仅改变**访问方式**，并未修改数组。
3. 在两个逻辑有序数组上应用 2011 年真题的折半不变量，因此最终所得仍是第 $n$ 小元素。

样例对应的逻辑升序序列分别为 `[1,3,5,7]` 与 `[2,4,6,8]`，合并下中位数为 **4**。

两个断点搜索各 $O(\log n)$，求下中位数再 $O(\log n)$，总时间 $O(\log n)$，额外空间 $O(1)$。

<Callout type="warn" title="边界：重复值会破坏严格折半">

若内部元素允许大量重复，遇到 `X[mid]==X[r]` 时不能确定断点在哪一侧，通常只能缩小一个端点，最坏可能退化为 $O(n)$。因此本题的**严格递增条件是时间上界的重要前提**。

</Callout>

</Solution>
</Question>

## 2012 年第 42 题

<Question
  id="408-ds-large-2012-42"
  type="essay"
  tags="来源:2012考研408, 考点:单链表相交"
>

假定采用**带头结点**的单链表保存单词。当两个单词有相同后缀时，可以共享相同的后缀存储空间。例如 `loading` 与 `being` 的存储映像如下图所示。

<img src="/img/408/past-exams-large-questions/01-数据结构/assets/2012-42-figure-001.svg" alt="2012 年第 42 题共享后缀示意" />

设 `str1`、`str2` 分别指向两个单词所在单链表的头结点，结点结构为 `| data | next |`。设计一个时间上尽可能高效的算法，找出两个链表**公共后缀的起始结点**（图中字符 `i` 所在的结点 $p$）。

要求：

1. 给出算法的基本设计思想。
2. 用 C、C++ 或 Java 描述算法。
3. 说明时间复杂度。

<Solution>

### 答案速览

1. 分别求两条链的数据结点数 $m$、$n$；
2. 较长链的指针先走 $|m-n|$ 步；
3. 两指针同步后移，**第一次 `p == q`（地址相同）** 的结点就是公共后缀的起点；若同时走到 `NULL`，则没有公共后缀。

时间 $O(m+n)$，额外空间 $O(1)$。

### 图解：先对齐剩余长度，再同步走

<AlgoFigure src="/img/408/past-exams-large-questions/01-数据结构/solutions/2012-42-1" w={720} h={492} alt="2012-42 loading 与 being 共享后缀 ing：先让长链先走 2 步，再同步后移直到 p == q" caption="青色结点被两条链共享。p 先走 m − n 步后，p、q 到表尾的剩余结点数相同，同步走必在 i 处相遇" />

关键观察：两条无环单链表一旦在某结点汇合，之后只能沿唯一的 `next` 一起走到表尾，所以公共部分一定是**尾部**。设公共后缀长 $c$，两链独有部分长 $m-c$、$n-c$。让长链先走 $m-n$ 步，就把两段「独有部分」的长度差抵消了——此后两个指针离汇合点的距离相同，同步前进必然**同时**到达汇合点。

### 设计步骤

<Steps>
  <Step>

  ### ① 求长度

  从 `str1->next`、`str2->next` 开始分别计数，**头结点不计入**。

  </Step>
  <Step>

  ### ② 长链先走

  `p = str1->next`，`q = str2->next`；若 $m>n$ 则 `p` 先走 $m-n$ 步，反之 `q` 先走 $n-m$ 步。

  </Step>
  <Step>

  ### ③ 同步比较地址

  `while (p != q) { p = p->next; q = q->next; }`，返回 `p`。相交时停在起点；不相交时两者同时变成 `NULL`，返回 `NULL`。

  </Step>
</Steps>

```c title="2012-42：公共后缀的起始结点" lineNumbers
#include <stddef.h>

typedef struct Node {
    char data;
    struct Node *next;
} Node;

static size_t ListLength(const Node *head) {
    size_t len = 0;
    for (const Node *p = head->next; p != NULL; p = p->next) ++len;
    return len;
}

Node *CommonSuffix(Node *str1, Node *str2) {
    if (str1 == NULL || str2 == NULL) return NULL;

    size_t m = ListLength(str1), n = ListLength(str2);
    Node *p = str1->next, *q = str2->next;

    while (m > n) { p = p->next; --m; }   // 长链先走 |m-n| 步
    while (n > m) { q = q->next; --n; }

    while (p != q) {                      // 比较地址，不比较字符
        p = p->next;
        q = q->next;
    }
    return p;                             // 相交：起点；不相交：NULL
}
```

### 正确性与复杂度

- 对齐后两指针到表尾的剩余结点数相等，因此到公共起点 $s$ 的步数也相等：**到达 $s$ 之前不会相等**（否则会有更早的公共结点），到达 $s$ 时必然相等。
- 不相交时所有非空结点地址各不相同，两指针同时到 `NULL`，循环正常结束。
- 求长 $m+n$ 次 + 对齐 $|m-n|$ 次 + 同步至多 $\min(m,n)$ 次，合计 $O(m+n)$；空间 $O(1)$。

<Tabs items={['另一种写法：换头法', '易错点']} defaultIndex={0}>
  <Tab value="另一种写法：换头法">

  不显式求长：两指针走到 `NULL` 时跳到**对方**链表的首元结点。两条路径长度都是 $m+n$，长度差自然被抵消。

  ```c
  Node *CommonSuffixSwitch(Node *str1, Node *str2) {
      Node *a = str1->next, *b = str2->next;
      Node *p = a, *q = b;
      while (p != q) {
          p = (p == NULL) ? b : p->next;
          q = (q == NULL) ? a : q->next;
      }
      return p;
  }
  ```

  复杂度同样是 $O(m+n)$、$O(1)$；循环条件必须是 `p != q`，不能写成 `p && q`。

  </Tab>
  <Tab value="易错点">

  - 「共享」指**同一个结点**，必须比较 `p == q`；写 `p->data == q->data` 会把 `loading` 与 `being` 中不同位置的相同字母误判为公共。
  - 两链可能从首元结点起就完全重合，此时直接返回首元结点。
  - 释放这种结构时公共后缀只能释放一次。
  - 算法前提是两链均无环。

  </Tab>
</Tabs>

</Solution>
</Question>

### 原创强化训练 1 · 无长度计数器的首个交点

<Question
  id="408-ds-large-2012-42-ext1"
  type="essay"
  tags="来源:原创强化训练, 考点:双指针换头"
>

给定两条**不带头结点、无环**的单链表 `a`、`b`，可能共享尾部结点。禁止遍历求长度，也不允许使用长度计数器或辅助集合。要求在时间 $O(m+n)$、额外空间 $O(1)$ 内返回第一个共有结点。

1. 给出 C 语言函数。
2. 证明两个指针交换起点后，为什么可以消除链长差。
3. 当两表完全不相交或其中一表为空时，解释算法能否正常退出。

<Solution>

### 参考答案

令 `p` 从 `a` 出发，走到空后转到 `b`；`q` 从 `b` 出发，走到空后转到 `a`。首次满足 `p == q` 时退出，并返回该结点（可能为 `NULL`）。

```c title="两条路径交换起点"
Node *FirstIntersection(Node *a, Node *b) {
    Node *p = a, *q = b;
    while (p != q) {
        p = (p == NULL) ? b : p->next;
        q = (q == NULL) ? a : q->next;
    }
    return p;
}
```

此处 `Node` 沿用 2012 年真题的结点结构。

### 路径长度证明

令两链独有的前缀长度分别为 $u,v$，公共后缀长度为 $c$，则 $m=u+c$，$n=v+c$。若有公共结点，则：

- `p` 沿第一链走到公共起点所花的距离是 $u$；在一次换头以后，经过对方独有前缀最终到达公共起点。两条游标因走完 A、B 两段长度相同，最迟在累计 $m+n-c+1$ 次指针更新时相遇（包含指针经过 `NULL` 后切换起点的那一步）。
- `q` 沿 B→A 方向行走，同样最迟在该时刻到达公共起点。

更容易记忆的事实是：**两指针分别经历 A→B、B→A 两段等长路径**。若确实相交，相遇位置是公共尾部第一个结点；若不相交，在最多 $m+n+1$ 次指针更新后，两指针都成为 `NULL`，同样退出。

<Callout type="idea" title="常见误解">

「两个指针一轮中必然分别在两个链表」不是不变量。真正有用的是：**走过 A、B 两条完整路径时累计距离相等**。代码也不能写成每轮 `p = p->next`、`q = q->next` 而不给空指针换头。

</Callout>

时间 $O(m+n)$；额外空间 $O(1)$。输入任一表为空时，在有限次移动后两指针均为 `NULL`。

</Solution>
</Question>

### 原创预测训练 2 · 三条单链表的公共后缀

<Question
  id="408-ds-large-2012-42-ext2"
  type="essay"
  tags="来源:原创预测训练, 考点:多链表求交"
>

现有三条**带头结点、无环**的单链表 `A`、`B`、`C`，其中一些结点可能被多条链共同使用；共有结点指的是**指针地址相同**。

1. 求三条链**同时共有**的后缀中第一个结点，设计最坏时间 $O(|A|+|B|+|C|)$、额外空间 $O(1)$ 的算法。
2. 说明能否先求 A、B 的公共首结点，再与 C 求交。
3. 论证「A 与 B 相交、B 与 C 相交，但三者没有共同结点」在此题设下是否可能。

<Solution>

### 参考答案

**可以分两步求交**。先求 A、B 的首个公共结点 `p`。若 `p==NULL`，三者不可能有公共结点；否则以 `p` 为首元结点的**共享后缀**与 C 再求交，第二次结果就是三条链的公共起点。

```c title="复用真题的 CommonSuffix"
Node *CommonSuffix3(Node *A, Node *B, Node *C) {
    if (A == NULL || B == NULL || C == NULL) return NULL;

    Node *p = CommonSuffix(A, B);
    if (p == NULL) return NULL;

    Node temporary = {0, p};  // 栈上临时头结点，不复制任何数据结点
    return CommonSuffix(&temporary, C);
}
```

### 为什么分两步有效

单链表每个结点只有一个后继，因此若 A、B 在 `p` 相交，**从 `p` 开始的整个尾部**必然都同时属于 A 与 B。这时再将该尾部视为一条链，与 C 求其首个公共结点 `q`：从 `q` 开始的结点同时属于 A、B、C，而在 `q` 之前不可能有三者的共同结点。

若三表两两相交，它们的**尾结点地址必须一致**：A 与 B 相交使尾结点相同；B 与 C 相交也使尾结点相同。于是三条链至少共同拥有同一个尾结点，因此「两两有交点却没有三者公共结点」**不可能发生**。

时间：第一次求交不超过 $O(|A|+|B|)$，第二次不超过 $O(|A|+|C|)$；合并后 $O(|A|+|B|+|C|)$，额外空间 $O(1)$。

<Callout type="warn" title="限制条件不能遗漏">

无环是这个结论的关键前提。题目如果允许环，链表的后继结构可以在不同位置进入环，所谓「共同尾结点」不再存在，不能原样套用该证明。

</Callout>

</Solution>
</Question>

## 2013 年第 41 题

<Question
  id="408-ds-large-2013-41"
  type="essay"
  tags="来源:2013考研408, 考点:主元素与投票算法"
>

已知整数序列

$$
A=(a_0,a_1,\ldots,a_{n-1}),
$$

其中

$$
0\le a_i<n\qquad(0\le i<n).
$$

若存在

$$
a_{p_1}=a_{p_2}=\cdots=a_{p_m}=x,
$$

且

$$
m>\frac n2,
$$

则称 $x$ 为 $A$ 的**主元素**。

例如，$A=(0,5,5,3,5,7,5,5)$ 的主元素为 5；而 $A=(0,5,5,3,5,1,5,7)$ 没有主元素。

设计一个尽可能高效的算法：若主元素存在则输出该元素，否则输出 $-1$。

<Solution>

### 答案速览

**Boyer–Moore 多数投票，两趟扫描**：

1. 第一趟用 `candidate`、`count` 做「异值两两抵消」，得到唯一可能的主元素候选；
2. 第二趟统计候选的真实出现次数，**严格大于 $n/2$** 才输出，否则输出 $-1$。

时间 $O(n)$，额外空间 $O(1)$，不修改数组，也不依赖 $0\le a_i<n$ 的值域。

### 图解：抵消 + 验证

<AlgoFigure src="/img/408/past-exams-large-questions/01-数据结构/solutions/2013-41-1" w={740} h={430} alt="2013-41 多数投票：第一趟抵消后剩下候选 5，第二趟验证次数" caption="上：红色弧线是被抵消的一对不同值，柱高是 count；下：两个样例的验证结果" />

把序列想象成「不同的值两两同归于尽」：

- 图中 `0` 与 `5`、`5` 与 `3`、`5` 与 `7` 各抵消一对，最后剩下两个 `5`；
- 主元素出现次数超过一半，**就算它每次都被拿去抵消，也一定有剩余**；所以如果主元素存在，它必然是最后的幸存者。

但幸存者不一定是主元素（例 2 中 `5` 只出现 4 次），所以第二趟验证不可省略。

### 设计步骤

<Steps>
  <Step>

  ### 第一趟：选出候选

  - `count == 0`：当前元素成为新候选，`count = 1`；
  - 当前元素等于候选：`count++`；
  - 否则：`count--`（抵消一对异值）。

  </Step>
  <Step>

  ### 第二趟：验证次数

  重新扫描统计 `freq`。只有 `freq > n / 2` 才输出 `candidate`，否则输出 $-1$。

  </Step>
</Steps>

```c title="2013-41：两趟扫描求主元素" lineNumbers
int MajorityElement(const int A[], int n) {
    if (A == NULL || n <= 0) return -1;

    int candidate = 0, count = 0;
    for (int i = 0; i < n; ++i) {          // 第一趟：抵消
        if (count == 0) { candidate = A[i]; count = 1; }
        else if (A[i] == candidate) ++count;
        else --count;
    }

    int freq = 0;                           // 第二趟：验证
    for (int i = 0; i < n; ++i)
        if (A[i] == candidate) ++freq;

    return (freq > n / 2) ? candidate : -1;
}
```

### 为什么抵消不会把主元素弄丢

设当前剩余 $t$ 个数，主元素 $x$ 有 $r>t/2$ 个。删去一对不同的值后：

- 这对含 $x$：剩 $r-1$ 个、总数 $t-2$，仍有 $r-1>(t-2)/2$；
- 这对不含 $x$：剩 $r$ 个、总数 $t-2$，更加超过一半。

所以抵消前后「$x$ 占多数」始终成立，第一趟的候选必等于 $x$。若主元素不存在，第二趟会把伪候选过滤掉。两趟各 $n$ 次，时间 $O(n)$；只用 3 个变量，空间 $O(1)$。

<Tabs items={['对照：计数数组法', '易错点']} defaultIndex={0}>
  <Tab value="对照：计数数组法">

  利用 $0\le a_i<n$，开 `cnt[0..n-1]` 统计次数，再找是否有 `cnt[x] > n/2`。时间 $O(n)$，但空间 $O(n)$，不如投票法。考场上写它可拿大部分分。

  </Tab>
  <Tab value="易错点">

  - **主元素 ≠ 众数**：众数只要求最多，主元素要求超过一半。
  - 不验证就输出候选是常见错误：`[1, 2, 3]` 第一趟会剩下候选 3。
  - 阈值是 `freq > n/2`，不是 `>=`；验证的是真实次数，不是第一趟剩下的 `count`。

  </Tab>
</Tabs>

</Solution>
</Question>

### 原创强化训练 1 · 频次超过三分之一的全部元素

<Question
  id="408-ds-large-2013-41-ext1"
  type="essay"
  tags="来源:原创强化训练, 考点:广义多数投票"
>

设长度为 $n\ge1$ 的整数数组中，凡出现次数**严格大于 $n/3$** 的值，都称为「三级高频元素」。数值范围不受限制，可包含负数。

1. 证明符合条件的不同元素**最多有两个**。
2. 用 C 语言设计 $O(n)$ 时间、$O(1)$ 额外空间的算法，输出全部三级高频元素（输出顺序不限）。
3. 对 `A=[1,2,1,3,2,1,2,4]` 给出结果。解释为何仍需要二次验证。

<Solution>

### 参考答案

**最多两个不同的答案**。维护两个候选值、两个净票数；若当前元素与两个候选都不同，而且两票槽均非空，则抵消三种不同元素各一个。第一趟得到至多两个候选，第二趟重新计数，按 `freq>n/3` 验证。

### 为什么最多两个

假定存在三个不同值，其频数都严格大于 $n/3$，那么这三个值的出现次数之和严格大于 $n$，与全数组只有 $n$ 个元素矛盾。

这提示我们：候选槽无需超过两个，也不能只保留一个。

```c title="输出全部频次 > n/3 的元素" lineNumbers
// out 至少有两个 int 单元；返回实际写入的元素个数
int MoreThanThird(const int A[], int n, int out[2]) {
    if (A == NULL || out == NULL || n <= 0) return 0;
    int v1 = 0, v2 = 0, c1 = 0, c2 = 0;

    // 第一趟：两候选 / 三种不同值共同抵消
    for (int i = 0; i < n; ++i) {
        int x = A[i];
        if (c1 > 0 && x == v1) ++c1;
        else if (c2 > 0 && x == v2) ++c2;
        else if (c1 == 0) { v1 = x; c1 = 1; }
        else if (c2 == 0) { v2 = x; c2 = 1; }
        else { --c1; --c2; }
    }

    // 第二趟：只给仍有效的候选统计真实频数
    int f1 = 0, f2 = 0;
    for (int i = 0; i < n; ++i) {
        if (c1 > 0 && A[i] == v1) ++f1;
        else if (c2 > 0 && A[i] == v2) ++f2;
    }

    int ans = 0;
    if (c1 > 0 && f1 > n / 3) out[ans++] = v1;
    if (c2 > 0 && f2 > n / 3) out[ans++] = v2;
    return ans;
}
```

### 正确性分析

抵消操作相当于从尚未淘汰的元素中删除三个互不相同的值。设某值原本出现 $r>n/3$ 次，每次三元抵消至多删去它一次，而总长度减三；它仍保持「超过剩余长度三分之一」的性质。因此，真正满足条件的数不可能因抵消而完全消失；第一次扫描结束时必占据某个候选槽。

**第二趟为什么需要**：比如 `[1,2,3,4]` 的残留候选可能根本不满足频次严格大于 $4/3$；与普通多数投票一样，抵消只保证**不漏真答案**，不能保证剩余值都是真答案。

样例中 1 和 2 各出现 3 次，$3>8/3$，最终输出 **1、2**。两趟均 $O(n)$，只占用常数个候选和计数器，额外空间 $O(1)$。

<Callout type="warn" title="容易写错的比较顺序">

必须**先判断是否匹配已占用候选槽，再尝试填空位**。否则当一个槽空、另一个槽恰好包含当前值时，可能产生重复候选；第二趟还必须避免把相同候选的频数重复计算。

</Callout>

</Solution>
</Question>

### 原创预测训练 2 · 可分块处理的主元素判定

<Question
  id="408-ds-large-2013-41-ext2"
  type="essay"
  tags="来源:原创预测训练, 考点:投票状态合并"
>

长整数序列被拆成相邻的 $t$ 个**非空连续块**。每一块可以独立顺序读取，但不能把所有数据重新存进一个大数组。每块均可输出一对摘要 `(candidate, votes)`：按普通多数投票规则做异值配对抵消后，剩余 `votes` 个相同候选（可以为 0）。已知所有块的总元素数为 $N$，仍允许第二遍从原始块读取全部元素。

1. 设计两个摘要 `(c1,v1)`、`(c2,v2)` 的合并规则，使合并后仍得到一个合法的**主元素候选摘要**。
2. 证明若全局存在出现次数严格超过 $N/2$ 的值，则合并所有块的摘要后，它一定仍是候选。
3. 编写合并两个摘要的 C 函数，并说明最终验证与总时间复杂度。对块 `A=[5,2,5,3]`、`B=[5,4,5,5]` 给出结果。

<Solution>

### 参考答案

将每块的状态视为其「剩余若干同值元素」的压缩表示：

- 任一摘要票数为 0，则直接返回另一摘要。
- 若两摘要候选相同，则票数相加。
- 若候选不同，则两边的票数相互抵消，只保留票数较大一边及其差值；相等时返回零票状态。

合并所有块后得到一个**可能的全局主元素候选**，还必须完整读取所有块进行第二趟验证，检查真实频数是否严格大于 $N/2$。

```c title="投票摘要的两两合并" lineNumbers
typedef struct VoteState {
    int candidate;
    long long votes;  // 0 表示没有有效候选
} VoteState;

VoteState MergeVote(VoteState a, VoteState b) {
    if (a.votes == 0) return b;
    if (b.votes == 0) return a;
    if (a.candidate == b.candidate)
        return (VoteState){a.candidate, a.votes + b.votes};
    if (a.votes > b.votes)
        return (VoteState){a.candidate, a.votes - b.votes};
    if (b.votes > a.votes)
        return (VoteState){b.candidate, b.votes - a.votes};
    return (VoteState){0, 0};
}
```

### 推导过程

1. **局部摘要含义**：一块序列经过若干次异值配对删除后，剩余的都是同一个候选值。原块中删去的都是「不同值配对」，不会抹掉任何真实超过半数的主元素。
2. **块摘要再合并**：拼接剩余元素以后继续做异值配对删除，等价于对原序列执行了更多合法的抵消操作。若全局真主元素存在，按原题证明它始终占剩余元素的多数，因此不可能被彻底删除。
3. **第二趟验证**：若全局没有主元素，合并结果仍可能给出一个候选；必须统计全局真实次数，再决定是否输出。

样例拼接后 `5` 一共出现 5 次，$N=8$，满足 $5>4$，所以答案是 **5**。

若所有块总长为 $N$：局部投票总计 $O(N)$，合并 $t$ 个状态 $O(t)$，全局核验再 $O(N)$；因每块非空，$t\le N$，故总时间 **$O(N)$**。若每块的摘要可边生成边合并且允许第二遍读原块，最终仅保存一个合并摘要和计数，**额外空间 $O(1)$**；若先收集全部 $t$ 个摘要再合并，则额外空间为 $O(t)$。

<Callout type="idea" title="为什么这一题有预测价值">

它考查的不是死记投票模板，而是**证明「不同值抵消」这一操作在分块处理后仍保留真正的主元素**。注意合并结果本身不是最终答案，仍要完成跨全部块的第二遍频数验证。

</Callout>

</Solution>
</Question>

## 2015 年第 41 题

<Question
  id="408-ds-large-2015-41"
  type="essay"
  tags="来源:2015考研408, 考点:链表去重"
>

用单链表保存 $m$ 个整数，结点含 `data` 域和指针域，并满足

$$
|data|\le n,
$$

其中 $n$ 为正整数。

现要求设计一个时间复杂度尽可能高效的算法：对于链表中 `data` 的**绝对值相等**的结点，仅保留第一次出现的结点，删除其余绝对值相等的结点。

例如：

<img src="/img/408/past-exams-large-questions/01-数据结构/assets/2015-41-figure-001.svg" alt="2015 年第 41 题原单链表示意图" />

处理后为：

<img src="/img/408/past-exams-large-questions/01-数据结构/assets/2015-41-figure-002.svg" alt="2015 年第 41 题删除重复绝对值后的链表" />

要求：

1. 给出算法的基本设计思想。
2. 给出单链表结点的数据类型定义。
3. 用 C 或 C++ 描述算法。
4. 说明时间复杂度和空间复杂度。

<Solution>

### 答案速览

**用空间换时间**：开一个标记数组 `seen[0..n]`（因为 $|data|\le n$），从前往后扫描链表：

- `seen[|data|] == 0`：第一次出现，**保留**该结点并置 1；
- `seen[|data|] == 1`：重复出现，**摘链删除**。

只扫描一遍链表，时间 $O(m)$（计入数组清零则为 $O(m+n)$），额外空间 $O(n)$。

### 图解：标记表 + 摘链

<AlgoFigure src="/img/408/past-exams-large-questions/01-数据结构/solutions/2015-41-1" w={740} h={408} alt="2015-41 链表 21,-15,-15,-7,15 按绝对值去重：标记数组与 pre/cur 摘链操作" caption="上：每个结点按 |data| 指向 seen 的槽位，首次出现置 1（保留），再次出现（红色）删除；下：删除时只改 pre->link，pre 不移动" />

以原题链表 `21 → −15 → −15 → −7 → 15` 为例：

| 当前结点 | $\lvert data\rvert$ | `seen` 状态 | 操作 |
| ---: | ---: | --- | --- |
| 21 | 21 | 未标记 | 保留，`seen[21]=1` |
| −15 | 15 | 未标记 | 保留，`seen[15]=1` |
| −15 | 15 | 已标记 | **删除** |
| −7 | 7 | 未标记 | 保留，`seen[7]=1` |
| 15 | 15 | 已标记 | **删除** |

结果为 `21 → −15 → −7`，保留的是**最先出现**的那个结点，与正负无关。

### 设计步骤

<Steps>
  <Step>

  ### ① 申请并清零 `seen[0..n]`

  共 $n+1$ 个槽位，下标就是绝对值；`3` 与 `-3` 映射到同一槽，`0` 单独占槽 0。

  </Step>
  <Step>

  ### ② 双指针扫描：`pre` 指已保留部分的尾，`cur` 指待处理结点

  - 保留：标记后 `pre = cur; cur = cur->link;`
  - 删除：`pre->link = cur->link; free(cur); cur = pre->link;` —— **`pre` 不动**，这样连续多个重复结点也能删净。

  </Step>
  <Step>

  ### ③ 扫描结束释放 `seen`

  </Step>
</Steps>

### 数据类型与代码

```c title="2015-41：按绝对值保留首次出现的结点（带头结点）" lineNumbers
#include <stdlib.h>

typedef struct LNode {
    int data;
    struct LNode *link;
} LNode;

// 成功返回 1；参数非法或申请失败返回 0
int DeleteEqualAbsolute(LNode *head, int n) {
    if (head == NULL || n <= 0) return 0;

    unsigned char *seen = (unsigned char *)calloc((size_t)n + 1, 1);
    if (seen == NULL) return 0;

    LNode *pre = head, *cur = head->link;
    while (cur != NULL) {
        int key = cur->data < 0 ? -cur->data : cur->data;
        if (seen[key] == 0) {           // 首次出现：保留
            seen[key] = 1;
            pre = cur;
            cur = cur->link;
        } else {                        // 重复：摘链删除，pre 不动
            pre->link = cur->link;
            free(cur);
            cur = pre->link;
        }
    }
    free(seen);
    return 1;
}
```

### 正确性与复杂度

- **不变量**：`pre` 之前（含 `pre`）的已保留结点中，每种绝对值恰出现一次，且都是原链表中首次出现的那个结点；`seen[x]==1` 当且仅当绝对值 $x$ 已被保留。每轮处理一个结点后不变量仍成立。
- **时间**：每个结点只访问一次，$O(m)$；`calloc` 清零 $n+1$ 字节是 $O(n)$，严格写为 $O(m+n)$。
- **空间**：`seen` 占 $O(n)$。

<Callout type="warn" title="易错点">

- 数组大小是 $n+1$、下标用 `seen[|data|]`；写成 `seen[|data|-1]` 会让 0 越界。
- 删除分支里 `pre` 不能后移，否则 `[2, -2, -2]` 这类连续重复会漏删。
- 题目要保留原结点并保持顺序，不能排序后去重。
- 若题目未说明带头结点，需先声明假设；不带头结点时首元结点总会被保留，从第二个结点开始同样处理即可。

</Callout>

</Solution>

### 原创强化训练 1 · 只保留绝对值最后一次出现的结点

<Question
  id="408-ds-large-2015-41-ext1"
  type="essay"
  tags="来源:原创强化训练, 考点:频次数组与摘链"
>

仍有一个带头结点的单链表，数据满足 $|data|\le n$。现要求每种绝对值只保留**最后一次出现的原结点**，其他结点全部删除，且保留下来的结点必须维持在原链表中的相对顺序。

1. 不允许新建数据结点，也不允许通过改变 `data` 域来伪装保留结点。
2. **禁止逆置链表**，改用两次正向扫描求解。
3. 给出 C 代码，分析时间、空间，并对 `[-2,3,2,-3,4,2]` 写出最终序列。

<Solution>

### 参考答案

使用**频次数组** `freq[0..n]`：第一趟统计每个绝对值在链表中的总出现次数；第二趟按原顺序扫描，每遇到某类就先 `freq[key]--`。如果减后还大于 0，说明后面仍有该类结点，当前不是最后一次，应删除；如果减后为 0，说明这是最后一次，必须保留。

```c title="禁止逆置时的保留最后一次出现" lineNumbers
#include <stdlib.h>

int KeepLastAbsolute(LNode *head, int n) {
    if (head == NULL || n <= 0) return 0;
    if (head->link == NULL) return 1;

    // calloc 对 n+1 个 int 元素做初始化
    size_t *freq = (size_t *)calloc((size_t)n + 1, sizeof(size_t));
    if (freq == NULL) return 0;

    for (LNode *p = head->link; p != NULL; p = p->link) {
        int x = p->data;
        int key = x < 0 ? -x : x;
        ++freq[key];
    }

    LNode *pre = head;
    LNode *cur = head->link;
    while (cur != NULL) {
        int x = cur->data;
        int key = x < 0 ? -x : x;
        --freq[key];
        if (freq[key] == 0) {
            pre = cur;       // 该类最后一次出现，保留
            cur = cur->link;
        } else {
            LNode *victim = cur;
            pre->link = cur->link;
            cur = pre->link;
            free(victim);
        }
    }

    free(freq);
    return 1;
}
```

### 为什么不会误删最后一个

第一趟结束后 `freq[x]` 等于绝对值为 $x$ 的**全部原结点个数**。第二趟扫描到某个类别 $x$ 时，每处理一个都减 1，因此减后值就是**该结点之后尚未扫描到的同类结点数量**。只有它大于 0 时才能安全删除当前结点；减至 0 的时刻，当前结点恰好是原链表中这一类别的最后一次出现。

样例绝对值 2 出现 3 次、3 出现 2 次、4 出现 1 次。最终保留的是原链表中的第 4、5、6 个结点，结果为 **`[-3,4,2]`**。

两趟正向扫描用时 $O(m)$，频次数组初始化花费 $O(n)$，总时间 **$O(m+n)$**，空间 **$O(n)$**；直接摘链保留原结点次序。

<Callout type="idea" title="和原题的对比">

**保留第一次**：记录「是否见过」，遇到第一次保留；**保留最后一次**：记录「后面是否还剩」，剩余为 0 才保留。算法框架相同，维护的信息不同。

</Callout>

</Solution>

### 原创预测训练 2 · 无已知值域且禁止辅助存储

<Question
  id="408-ds-large-2015-41-ext2"
  type="essay"
  tags="来源:原创预测训练, 考点:常数空间去重"
>

一个带头结点的单链表保存 $m$ 个整数，现**不再提供绝对值上界**，并禁止创建任何数组、散列表、排序结构或新数据结点。允许修改 `link` 指针并删除重复结点。即使输入包含 `INT_MIN`，也必须保证绝对值比较不会触发有符号整数溢出。

1. 设计额外空间 $O(1)$ 的算法，只保留每种绝对值第一次出现的原结点。
2. 解释外层当前结点、内层前驱指针和内层当前指针各自的职责，并写出 C 语言实现。
3. 给出最坏时间复杂度及达到该界的输入情形。

<Solution>

### 参考答案

由于不能使用任何「某绝对值是否出现过」的辅助结构，只能做**原地嵌套扫描**：外层指针 `cur` 始终指向已经决定保留的某个类别的第一次出现结点；内层从 `cur->link` 向后搜索，把与 `cur` 绝对值相同的后续结点逐个删除。外层再继续访问剩余链表的下一个结点。

```c title="无值域限制、常数空间的链表去重" lineNumbers
#include <stdint.h>
#include <stdlib.h>

static uintmax_t AbsUnsigned(int x) {
    // 先转换到无符号类型，再用模运算取幅值，INT_MIN 同样安全
    return x < 0 ? (uintmax_t)0 - (uintmax_t)x : (uintmax_t)x;
}

void DedupAbsNoExtra(LNode *head) {
    if (head == NULL) return;

    for (LNode *cur = head->link; cur != NULL; cur = cur->link) {
        LNode *pre = cur;
        LNode *p = cur->link;
        while (p != NULL) {
            if (AbsUnsigned(p->data) == AbsUnsigned(cur->data)) {
                LNode *victim = p;
                pre->link = p->link;  // 摘掉重复结点
                p = pre->link;        // pre 保持不动
                free(victim);
            } else {
                pre = p;
                p = p->link;
            }
        }
    }
}
```

### 指针职责与正确性

- `cur`：外层保留下来的**该类别最早结点**，整个内层扫描期间不移动、不删除。
- `pre`：内层当前结点 `p` 的**直接前驱**，用于修改指针以摘除 `p`。
- `p`：内层当前被检查的结点。如果保留就与 `pre` 同时前进；如果删除则只让 `p` 改指 `pre->link`，**`pre` 保持不动**。

所有内层扫描结束时，`cur` 之后都不再存在相同绝对值的结点。因此每个类别第一次遇到的原结点必然留下来，后续同类别的结点必然已经被更早的外层循环清除。

### 复杂度与反例分析

当 $m$ 个元素的绝对值全部不同时，内层扫描长度依次为 $m-1,m-2,\ldots,1,0$，比较次数为

$$
\sum_{i=0}^{m-1}i=\frac{m(m-1)}2=\Theta(m^2).
$$

因此最坏时间是 **$\Theta(m^2)$**，额外空间是 **$O(1)$**。

<Callout type="warn" title="关于 INT_MIN">

`-INT_MIN` 对普通有符号 `int` 不安全。代码采用 `uintmax_t`：**先转换为无符号类型，再计算无符号差**，结果在模 $2^w$ 的运算中恰好是原负数的非负幅值。这样不会发生有符号溢出，并且不要求目标平台的 `int` 必须比 `int64_t` 窄。不要先执行 `abs(x)` 再强制类型转换，否则溢出风险已经产生。

</Callout>

</Solution>
</Question>

## 2018 年第 41 题

<Question
  id="408-ds-large-2018-41"
  type="essay"
  tags="来源:2018考研408, 考点:最小缺失正整数"
>

给定一个含 $n$（$n\ge 1$）个整数的数组，请设计一个在**时间上尽可能高效**的算法，找出数组中**未出现的最小正整数**。

例如：

- 数组 $\{-5,3,2,3\}$ 中未出现的最小正整数为 $1$；
- 数组 $\{1,2,3\}$ 中未出现的最小正整数为 $4$。

要求：

1. 给出算法的基本设计思想。
2. 用 C 或 C++ 描述算法。
3. 说明时间复杂度和空间复杂度。

<Solution>

### 答案速览

**答案一定在 $1\sim n+1$ 之间**，因此只需一个长度为 $n$ 的标记数组 `seen`：扫描 $A$，把落在 $[1,n]$ 的数 $x$ 记到 `seen[x-1]`；再从左到右找第一个未标记的位置 $i$，答案为 $i+1$；全被标记则答案为 $n+1$。

时间 $O(n)$，额外空间 $O(n)$，不修改原数组。

### 图解：只关心 1 ~ n

<AlgoFigure src="/img/408/past-exams-large-questions/01-数据结构/solutions/2018-41-1" w={720} h={410} alt="2018-41 两个样例：数组值映射到 seen 标记表，第一个空位即答案" caption="蓝色是落在 [1, n] 内的有效值，箭头指向它在 seen 中的槽位；绿色是第一个空位" />

**为什么范围只到 $n+1$？** $n$ 个整数至多覆盖 $n$ 个不同的正整数。

- 若 $1,2,\ldots,n$ 有缺口，答案就是最小的缺口，它不超过 $n$；
- 若 $1\sim n$ 全部出现，数组已经没有空间再放别的数，答案是 $n+1$。

所以负数、0、以及大于 $n$ 的数**对答案毫无影响**，可以直接忽略——这样就把无限的值域压缩成了 $n$ 个槽位。

### 设计步骤

<Steps>
  <Step>

  ### ① 申请 `seen[0..n-1]` 并清零

  </Step>
  <Step>

  ### ② 扫描 A：只登记 $1\le A[i]\le n$

  执行 `seen[A[i]-1] = 1`；重复值反复写同一槽，无影响。

  </Step>
  <Step>

  ### ③ 从小到大找第一个 0

  第一个 `seen[i]==0` 对应答案 $i+1$；找不到则答案为 $n+1$。

  </Step>
</Steps>

```c title="2018-41：标记数组法" lineNumbers
#include <stdlib.h>

int FindMissMin(const int A[], int n) {
    unsigned char *seen = (unsigned char *)calloc((size_t)n, 1);
    if (seen == NULL) return -1;               // 申请失败

    for (int i = 0; i < n; ++i)
        if (A[i] >= 1 && A[i] <= n)            // 越界值直接忽略
            seen[A[i] - 1] = 1;

    int ans = n + 1;                           // 默认 1~n 全出现
    for (int i = 0; i < n; ++i)
        if (seen[i] == 0) { ans = i + 1; break; }

    free(seen);
    return ans;
}
```

### 正确性与复杂度

- **不变量**：扫描完前 $t$ 个元素后，对 $1\le x\le n$，`seen[x-1]==1` 当且仅当 $x$ 在这 $t$ 个元素中出现过。扫描完成后第一个 0 即最小的未出现正整数。
- **时间**：清零、登记、查找各 $O(n)$，合计 $O(n)$。
- **空间**：`seen` 为 $O(n)$。题目只要求时间高效，此解已满足。

| 输入 | `seen`（对应 1~n） | 答案 |
| --- | --- | ---: |
| $\{-5,3,2,3\}$ | `0 1 1 0` | 1 |
| $\{1,2,3\}$ | `1 1 1` | 4 |
| $\{2,2,4,4\}$ | `0 1 0 1` | 1 |

<Callout type="warn" title="易错点">

- 登记前必须判断 $1\le A[i]\le n$，否则负数或大数会越界写。
- 答案不是「数组最小正数」或「最小值 + 1」。
- 若题目改为额外空间 $O(1)$ 且允许改数组，可用「把 $x$ 交换到下标 $x-1$」的原地置换法，时间仍是 $O(n)$。

</Callout>

### 原创强化训练 1 · 原地求最小缺失正整数

<Question
  id="408-ds-large-2018-41-ext1"
  type="essay"
  tags="来源:原创强化训练, 考点:原地下标置换"
>

数组 `A[0..n-1]` 包含正数、$0$、负数和重复值，**允许改变数组内容**。请在 $O(n)$ 时间和 $O(1)$ 额外空间内求未出现的最小正整数。

1. 给出值域 $[1,n]$ 的「值—位置」映射，以及交换规则。
2. 用 C 实现，特别说明为何重复值不会引发死循环。
3. 对 `A=[3,4,-1,1]` 与 `A=[1,1]` 给出答案，并证明嵌套 `while` 仍为线性总时间。

<Solution>

### 参考答案

把有效值 $x\in[1,n]$ 尽可能置于**下标 $x-1$** 处；当 `A[i]` 已在正确位置、超出值域，或目标位置已经存着相同值时，结束当前位置的交换。最后从左向右找第一个 `A[i]!=i+1`，返回 $i+1$；若没有这样的下标，返回 $n+1$。

```c title="原地置换：线性时间、常数空间" lineNumbers
#include <stddef.h>

long long FirstMissingPositiveInPlace(int A[], int n) {
    if (n <= 0) return 1;
    if (A == NULL) return -1;

    for (int i = 0; i < n; ++i) {
        while (A[i] >= 1 && A[i] <= n &&
               A[A[i] - 1] != A[i]) {
            int pos = A[i] - 1;
            int temp = A[pos];
            A[pos] = A[i];
            A[i] = temp;
        }
    }
    for (int i = 0; i < n; ++i)
        if (A[i] != i + 1) return (long long)i + 1;
    return (long long)n + 1;
}
```

### 为什么算法正确

对于每个有效正整数 $x$，位置 $x-1$ 是它的**唯一目标槽**。每次允许交换时，`A[i]` 被放入它的正确槽；即使换进来的元素还未归位，也会继续处理。因此扫描结束后，只要 $x$ 出现过，其目标位置必然被某个 $x$ 占据。数组中缺少 $x$ 当且仅当该目标位置不等于 $x$。

重复值如 `[1,1]`，当第二个 `1` 想进入 `A[0]` 时，发现 `A[0]` 已为 `1`，不再交换，从而**不会在两个相同值之间来回交换**。

对 `[3,4,-1,1]`，完成置换可得到 `[1,-1,3,4]`，第一个不匹配位置是下标 1，答案 **2**；对 `[1,1]`，答案也是 **2**。

### 为什么不是 $O(n^2)$

虽然 `while` 嵌套在 `for` 中，但每次真正交换都至少让一个有效值首次归位，而已归位的目标槽不会再被换走。全程有效交换不超过 $n$ 次；加上外层 $n$ 次检查、最后 $n$ 次扫描，总时间 **$O(n)$**，额外空间 **$O(1)$**。

<Callout type="idea" title="方法选择">

**不可修改输入**：用原题的 $O(n)$ 标记表；**允许修改输入且要求常数空间**：用值—下标对应关系，原地置换。不要把这两种约束混为一谈。

</Callout>

</Solution>

### 原创预测训练 2 · 区间缺失数量与第 $k$ 个缺失值

<Question
  id="408-ds-large-2018-41-ext2"
  type="essay"
  tags="来源:原创预测训练, 考点:范围标记与秩"
>

给定长度为 $n$ 的只读数组 `A`、整数 $m$（$1\le m\le n$）以及正整数 $k$。在区间 $[1,m]$ 内，分别求：

1. **没有在 `A` 中出现过的整数总数**；
2. **最小的缺失整数**；
3. **按从小到大排列的第 $k$ 个缺失整数**。

若第二项或第三项无对应值，输出 $-1$。重复值和区间外数据不计入有效出现的不同整数。要求不改变 `A`，时间 $O(n+m)$、额外空间 $O(m)$，并对 `A=[2,2,4,-3,10]`、$m=4,k=2$ 给出结果。

<Solution>

### 参考答案

使用 `seen[x-1]` 记录 $1\le x\le m$ 是否出现；遍历输入完成标记后，按 $1,2,\ldots,m$ 顺序扫描零标记，累计缺失个数。遇到第一个缺失数就记录最小值，遇到第 $k$ 个缺失数就记录第 $k$ 缺失值。

```c title="统计全部缺失、最小缺失及第 k 缺失" lineNumbers
#include <stdlib.h>

/* 成功返回 1；参数非法或分配失败返回 0。
   missing、smallest、kth 为三个输出参数。 */
int MissingStats(const int A[], int n, int m, int k,
                 int *missing, int *smallest, int *kth) {
    if (A == NULL || n <= 0 || m < 1 || m > n || k <= 0 ||
        missing == NULL || smallest == NULL || kth == NULL)
        return 0;

    unsigned char *seen = calloc((size_t)m, sizeof *seen);
    if (seen == NULL) return 0;

    for (int i = 0; i < n; ++i)
        if (A[i] >= 1 && A[i] <= m)
            seen[A[i] - 1] = 1;

    int count = 0, first = -1, kthMissing = -1;
    for (int i = 0; i < m; ++i) {
        int x = i + 1;
        if (seen[i] == 0) {
            ++count;
            if (first == -1) first = x;
            if (count == k) kthMissing = x;
        }
    }
    free(seen);
    *missing = count;
    *smallest = first;
    *kth = kthMissing;
    return 1;
}
```

### 推导与答案

样例在 $[1,4]$ 内出现过的**不同数值**只有 $2$ 和 $4$。因此未出现的数是 $\{1,3\}$：总数 **2**，最小缺失数 **1**，第 $2$ 个缺失数 **3**。

扫描不变量是：处理完 $[1,x]$ 后，`count` 恰为其中未出现数的个数。将其从 0 开始逐个累加，就能同时回答**个数查询与顺序秩查询**，无需再次排序。初始化标记需 $O(m)$，遍历输入需 $O(n)$，扫描标记表需 $O(m)$，总时间 $O(n+m)$，辅助空间 $O(m)$。

<Callout type="warn" title="为什么不能直接减去出现次数">

样例中 `2` 出现两次，但区间 $[1,4]$ 中不同的已出现元素只有 $\{2,4\}$ 两个。直接计算「$m$ 减去落入区间的输入元素个数」会把重复的 `2` 多算一次，从而低估缺失数。**先去重再计数**才是关键。

</Callout>

</Solution>
</Question>

## 2019 年第 41 题

<Question
  id="408-ds-large-2019-41"
  type="essay"
  tags="来源:2019考研408, 考点:链表重排"
>

设线性表

$$
L=(a_1,a_2,a_3,\ldots,a_{n-1},a_n)
$$

采用**带头结点的单链表**保存，结点定义如下：

```c
typedef struct node {
    int data;
    struct node *next;
} NODE;
```

请设计一个额外空间复杂度为 $O(1)$、时间上尽可能高效的算法，**重新排列原有结点**，使其变为

$$
L'=(a_1,a_n,a_2,a_{n-1},a_3,a_{n-2},\ldots).
$$

要求：

1. 给出算法的基本设计思想。
2. 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
3. 说明算法的时间复杂度。

<Solution>

### 答案速览

目标序列 $a_1,a_n,a_2,a_{n-1},\ldots$ 就是「前半段」与「**逆序的**后半段」交替合并。三步完成：

1. **快慢指针找中点**，把链表断成前后两段；
2. **原地逆置后半段**；
3. **两段交替合并**。

只改 `next` 指针，时间 $O(n)$，额外空间 $O(1)$。

### 图解：分段 → 逆置 → 交织

<AlgoFigure src="/img/408/past-exams-large-questions/01-数据结构/solutions/2019-41-1" w={740} h={500} alt="2019-41 链表重排三步：快慢指针找中点、逆置后半段、交替合并" caption="以 n = 7 为例。蓝色为前半段，橙色为后半段；逆置后，原来要「从尾部取」的结点变成了「从头部取」" />

难点在于单链表无法从尾部往前走：如果每次都去找当前尾结点，总时间会退化为 $O(n^2)$。**把后半段逆置后，「取尾」就变成了「取头」**，于是两段都只需从头往后取，一趟即可完成。

### 设计步骤

<Steps>
  <Step>

  ### ① 找中点并断开

  `slow`、`fast` 从首元结点出发，`fast` 每次 2 步、`slow` 每次 1 步，循环条件 `fast->next && fast->next->next`。退出时 `slow` 是前半段最后一个结点：前半段 $\lceil n/2\rceil$ 个、后半段 $\lfloor n/2\rfloor$ 个。令 `second = slow->next; slow->next = NULL;`。

  </Step>
  <Step>

  ### ② 逆置后半段

  三指针 `prev / cur / next` 头插式逆置，结束后 `second = prev`（原尾结点 $a_n$）。

  </Step>
  <Step>

  ### ③ 交替合并

  每轮先保存 `next1 = first->next`、`next2 = second->next`，再令 `first->next = second; second->next = next1;`，然后两指针分别后移。后半段取完即结束；$n$ 为奇数时中点 $a_{\lceil n/2\rceil}$ 自然留在末尾。

  </Step>
</Steps>

```c title="2019-41：找中点、逆置后半、交替合并" lineNumbers
typedef struct node {
    int data;
    struct node *next;
} NODE;

void Rearrange(NODE *head) {
    if (head == NULL || head->next == NULL || head->next->next == NULL) return;

    // ① 快慢指针：slow 停在前半段末尾
    NODE *slow = head->next, *fast = head->next;
    while (fast->next != NULL && fast->next->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }
    NODE *second = slow->next;
    slow->next = NULL;                     // 断开两段

    // ② 原地逆置后半段
    NODE *prev = NULL, *cur = second;
    while (cur != NULL) {
        NODE *next = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next;
    }
    second = prev;

    // ③ 交替合并
    NODE *first = head->next;
    while (second != NULL) {
        NODE *next1 = first->next;         // 先保存后继
        NODE *next2 = second->next;
        first->next = second;
        second->next = next1;
        first = next1;
        second = next2;
    }
}
```

### 正确性与复杂度

| $n$ | 前半段 | 后半段逆置后 | 合并结果 |
| --- | --- | --- | --- |
| 6 | $a_1a_2a_3$ | $a_6a_5a_4$ | $a_1a_6a_2a_5a_3a_4$ |
| 7 | $a_1a_2a_3a_4$ | $a_7a_6a_5$ | $a_1a_7a_2a_6a_3a_5a_4$ |

- 前半段长度 $\ge$ 后半段长度，所以合并时 `first` 不会先变成 `NULL`。
- 合并第 $t$ 轮后，结果前缀恰为 $a_1,a_n,\ldots,a_t,a_{n-t+1}$，每个结点只被链接一次。
- 三步各一趟，时间 $O(n)$；只用常数个指针，空间 $O(1)$。

<Callout type="warn" title="易错点">

1. 忘记 `slow->next = NULL`，前半段尾仍连着后半段，合并后会成环。
2. 改指针前没保存后继，剩余链表丢失。
3. 每次去找尾结点，时间变成 $O(n^2)$。
4. 用递归逆置不满足 $O(1)$ 空间（递归栈是 $O(n)$）。
5. 交换 `data` 不算「重新排列结点」。

</Callout>

</Solution>
</Question>

### 原创强化训练 1 · 从尾部开始交织重排

<Question
  id="408-ds-large-2019-41-ext1"
  type="essay"
  tags="来源:原创强化训练, 考点:链表奇偶划分"
>

给定**不带头结点**的单链表 `head`，依次存放原有结点 $a_1,a_2,\ldots,a_n$（$n\ge1$）。现要求**只通过调整指针**，将结点改排为

$$
(a_n,a_1,a_{n-1},a_2,a_{n-2},a_3,\ldots).
$$

1. 设计时间 $O(n)$、空间 $O(1)$ 的算法，并返回新表头。
2. 比较本题和 2019 年真题在**奇数长度时中点归属**上的区别。
3. 分别给出 $n=5$ 和 $n=6$ 的结果。

<Solution>

### 参考答案

本题要**先输出右半段**，因此应把链表分成长度 $\lfloor n/2\rfloor$ 的左段和长度 $\lceil n/2\rceil$ 的右段。若 $n$ 为奇数，中点必须归入**右段**。逆置右段后，按「右一个、左一个」合并，右段可能剩下的中点最后输出。

```c title="尾部优先的交织重排" lineNumbers
#include <stddef.h>

typedef struct node {
    int data;
    struct node *next;
} NODE;

NODE *ReorderFromTail(NODE *head) {
    if (head == NULL || head->next == NULL) return head;

    // 找到左半段末结点（奇数长度时中点归右段）
    NODE dummy = {0, head};
    NODE *slow = &dummy, *fast = head;
    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }
    NODE *right = slow->next;
    slow->next = NULL;
    NODE *left = dummy.next;

    // 逆置右段
    NODE *rev = NULL;
    while (right != NULL) {
        NODE *next = right->next;
        right->next = rev;
        rev = right;
        right = next;
    }

    // 从右段开始，依次交织；输出哑结点在栈上
    NODE out = {0, NULL}, *tail = &out;
    while (rev != NULL) {
        NODE *nextRight = rev->next;
        tail->next = rev;
        tail = rev;
        rev = nextRight;

        if (left != NULL) {
            NODE *nextLeft = left->next;
            tail->next = left;
            tail = left;
            left = nextLeft;
        }
    }
    tail->next = NULL;
    return out.next;
}
```

### 中点为什么必须归右段

以 $n=5$ 为例：分割成左段 $a_1,a_2$ 和右段 $a_3,a_4,a_5$，逆转右段得 $a_5,a_4,a_3$，交织得

$$
a_5,a_1,a_4,a_2,a_3.
$$

当 $n=6$ 时左右各 3 个结点，结果为

$$
a_6,a_1,a_5,a_2,a_4,a_3.
$$

**核心区别**：原真题以 $a_1$ 起头，左段需要不少于右段；本题以 $a_n$ 起头，右段需要不少于左段。时间 $O(n)$，空间 $O(1)$。

</Solution>
</Question>

### 原创预测训练 2 · 原地判断回文并恢复原链

<Question
  id="408-ds-large-2019-41-ext2"
  type="essay"
  tags="来源:原创预测训练, 考点:链表回文与恢复"
>

给定不带头结点的单链表 `head`，其数据域为整数，要求判断结点序列是否回文（如 $1\to2\to3\to2\to1$）。

要求：

1. 时间 $O(n)$、额外空间 $O(1)$。
2. 无论最终判断为真还是为假，都**必须恢复所有结点原来的位置和指针链接**。
3. 说明为何奇数长度可跳过中间结点、偶数长度应比较全部成对位置，并给出 C 代码。

<Solution>

### 参考答案

**找前半段末结点 → 逆置后半段 → 从两端向中间逐项比较 → 再次逆置后半段并接回**。比较结果保存在变量中，但不能在发现不相等时直接退出函数，因为必须先恢复链表。

```c title="判断回文并保证链表恢复" lineNumbers
#include <stdbool.h>
#include <stddef.h>

typedef struct node {
    int data;
    struct node *next;
} NODE;

static NODE *ReversePart(NODE *cur) {
    NODE *prev = NULL;
    while (cur != NULL) {
        NODE *next = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next;
    }
    return prev;
}

bool IsPalindromeRestore(NODE *head) {
    if (head == NULL || head->next == NULL) return true;

    NODE *slow = head, *fast = head;
    while (fast->next != NULL && fast->next->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }

    NODE *second = ReversePart(slow->next);
    NODE *p = head, *q = second;
    bool same = true;
    while (q != NULL) {
        if (p->data != q->data) {
            same = false;
            break; // 仅退出比较循环，后面仍需恢复
        }
        p = p->next;
        q = q->next;
    }

    slow->next = ReversePart(second); // 无论结果如何，都执行
    return same;
}
```

### 奇偶边界与正确性

| 序列 | 前半段末结点 | 逆置后半段 | 结论 |
| --- | --- | --- | --- |
| $[1,2,3,2,1]$ | 数据 $3$ | $[1,2]$ | 是回文，中心 $3$ 不比较 |
| $[1,2,2,1]$ | 第 1 个数据 $2$ | $[1,2]$ | 是回文，两对均比较 |
| $[1,2,3,4]$ | 数据 $2$ | $[4,3]$ | 不是回文，但仍恢复 |

当 $n=2r+1$ 时，比较的是前 $r$ 个元素与后 $r$ 个元素的逆序；中间结点不影响回文性。当 $n=2r$ 时，两段长度均为 $r$，需要完整比较 $r$ 对。逆置第二次是第一次的逆操作，且 `slow->next` 重新指向后半段原首结点，因此**结点身份、数据和相邻关系均复原**。

找中点、两次逆置和比较总时间 **$O(n)$**，额外空间 **$O(1)$**。在发生不相等时，代码仅跳出 `while`，**不提前 `return false`**。

<Callout type="idea" title="核心迁移点">

2019 年真题利用「逆置后半段」实现重排；本题利用同一操作实现**对称比较**。算法套路一样，但多了对链表完整恢复的约束，因而所有退出路径必须经过恢复步骤。

</Callout>

</Solution>
</Question>

## 2020 年第 41 题

<Question
  id="408-ds-large-2020-41"
  type="essay"
  tags="来源:2020考研408, 考点:三指针贪心"
>

定义整数三元组 $(a,b,c)$ 的距离为

$$
D(a,b,c)=|a-b|+|b-c|+|c-a|.
$$

给定 3 个非空整数集合 $S_1,S_2,S_3$，各集合中的元素已按升序分别存放在 3 个数组中。请设计一个尽可能高效的算法，计算并输出所有可能三元组

$$
(a,b,c),\qquad a\in S_1,\ b\in S_2,\ c\in S_3
$$

中的最小距离。例如：

$$
S_1=\{-1,0,9\},\quad
S_2=\{-25,-10,10,11\},\quad
S_3=\{2,9,17,30,41\},
$$

则最小距离为 $2$，三元组可以取 $(9,10,9)$。

要求：

1. 给出算法的基本设计思想。
2. 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
3. 说明算法的时间复杂度和空间复杂度。

<Solution>

### 答案速览

1. **化简目标**：把三数排成 $x\le y\le z$，则 $D=2(z-x)$，即**两倍极差**；
2. **三指针贪心**：`i, j, k` 分别指向三个数组开头，每轮算一次 $D$ 更新最小值，然后**只把当前最小值所在数组的指针后移一位**；任一数组走完即结束。

设三数组长 $n_1,n_2,n_3$，时间 $O(n_1+n_2+n_3)$，额外空间 $O(1)$。样例最小距离为 $2$，对应 $(9,10,9)$。

### 图解：数轴上的极差

<AlgoFigure src="/img/408/past-exams-large-questions/01-数据结构/solutions/2020-41-1" w={740} h={556} alt="2020-41 三元组距离等于两倍极差，以及三指针逐轮推进最小值的数轴示意" caption="上：中间值 y 的贡献相互抵消，D 只由最小值和最大值决定；下：样例的 6 轮迭代，紫色条为极差，每轮推进最左边那个点" />

**为什么只推进最小值？** 设当前三个数中最小的是 $a$、最大的是 $M$。如果不动 $a$ 而推进另外两个指针，因为数组升序，新选的数只会变大：最小值仍是 $a$，最大值不会小于 $M$，极差**不可能变小**。想得到更小的极差，唯一的希望是让最小值变大——也就是推进最小值所在的指针。这样每一步都安全地排除了「以当前 $a$ 为最小值」的所有组合。

### 算法步骤

<Steps>
  <Step>

  ### 初始化

  `i = j = k = 0`，`best` 设为极大值。

  </Step>
  <Step>

  ### 循环（三个下标都未越界时）

  取 `a = A[i], b = B[j], c = C[k]`，计算 $D=2(\max-\min)$，更新 `best`；若 `best == 0` 可提前结束。然后让最小者所在数组的下标加 1。

  </Step>
</Steps>

```c title="2020-41：三个升序数组的最小三元组距离" lineNumbers
#include <limits.h>

long long Min3Distance(const int A[], int n1,
                       const int B[], int n2,
                       const int C[], int n3) {
    int i = 0, j = 0, k = 0;
    long long best = LLONG_MAX;

    while (i < n1 && j < n2 && k < n3) {
        long long a = A[i], b = B[j], c = C[k];   // 先扩宽，防溢出
        long long lo = a, hi = a;
        if (b < lo) lo = b;
        if (c < lo) lo = c;
        if (b > hi) hi = b;
        if (c > hi) hi = c;

        long long d = 2 * (hi - lo);
        if (d < best) best = d;
        if (best == 0) break;

        if (a == lo) ++i;                          // 只推进最小者
        else if (b == lo) ++j;
        else ++k;
    }
    return best;
}
```

### 正确性与复杂度

- **安全排除**：每次被推进掉的元素 $a$，它与另外两个数组「当前及之后」元素组成的组合，极差都不小于本轮已记录的值，所以不会漏掉最优解。
- **时间**：每轮恰有一个下标加 1，至多 $n_1+n_2+n_3$ 轮，远优于暴力枚举的 $O(n_1n_2n_3)$。
- **空间**：常数个变量，$O(1)$。

<Callout type="warn" title="易错点">

- 每轮只推进**一个**指针，不是三个一起走。
- 有并列最小值时推进任意一个都正确。
- 差值和两倍运算要在 `long long` 上做，避免 `int` 溢出。
- 越界判断要在读取 `A[i]` 等之前完成。

</Callout>

</Solution>
</Question>

### 原创强化训练 1 · 四数组极差与多数组推广

<Question
  id="408-ds-large-2020-41-ext1"
  type="essay"
  tags="来源:原创强化训练, 考点:多路贪心与最小堆"
>

给定 **4 个非空升序数组** $S_1,S_2,S_3,S_4$，分别选取一个元素组成四元组 $(a,b,c,d)$，使极差

$$
R(a,b,c,d)=\max\{a,b,c,d\}-\min\{a,b,c,d\}
$$

尽可能小。例如：

$$
S_1=\{1,8\},\quad S_2=\{4,10\},\quad
S_3=\{6,9\},\quad S_4=\{7,11\}.
$$

1. 将真题三指针思想推广为四指针算法，写出 C 实现。
2. 证明其正确性并给出例子的最小极差。
3. 若进一步推广到 $k$ 个升序数组、总元素数为 $N$，说明**线性扫描法**和**最小堆法**的复杂度差异。

<Solution>

### 参考答案

四数组各设一个下标；每轮求四个当前元素的最大值、最小值，更新最佳极差后，**只推进当前最小值所属的下标**。示例最小极差为 **3**（如四元组 $(8,10,9,7)$）。四数组版本时间 $O(N)$，额外空间 $O(1)$。

```c title="四数组最小极差" lineNumbers
#include <limits.h>

/* S[0..3] 是四个数组起点；len[t] > 0；各数组非降序 */
long long MinRange4(const int *S[4], const int len[4]) {
    int p[4] = {0, 0, 0, 0};
    long long best = LLONG_MAX;

    while (1) {
        for (int t = 0; t < 4; ++t)
            if (p[t] == len[t]) return best;

        long long lo = S[0][p[0]], hi = lo;
        int minId = 0;
        for (int t = 1; t < 4; ++t) {
            long long x = S[t][p[t]];
            if (x < lo) { lo = x; minId = t; }
            if (x > hi) hi = x;
        }
        if (hi - lo < best) best = hi - lo;
        if (best == 0) return 0;
        ++p[minId];
    }
}
```

### 证明与实例

固定当前最小值 $m$ 时，只推进其他数组指针，仍然包含 $m$，而当前最大值只可能增大、不可能缩小。因此任何能改善当前极差的候选都必须推进一个最小值指针，与三数组结论一致。

示例中，关键过程是：

| 当前四元组 | 极差 | 应推进的数组 |
| --- | ---: | --- |
| $(1,4,6,7)$ | 6 | $S_1$ |
| $(8,4,6,7)$ | 4 | $S_2$ |
| $(8,10,6,7)$ | 4 | $S_3$ |
| $(8,10,9,7)$ | **3** | $S_4$ |

继续扫描不会得到更小的极差，因此答案是 **3**。

### 进一步推广到 $k$ 个数组

<Tabs items={['每轮线性扫描', '最小堆优化']} defaultIndex={0}>
  <Tab value="每轮线性扫描">

  保留 $k$ 个当前指针。每轮遍历这 $k$ 个值找最大、最小并推进最小者，单轮 $O(k)$。每次必有一个数组下标加 1，总迭代次数不超过 $N$，因此总时间为 **$O(Nk)$**，额外空间 **$O(k)$**（保存指针）。当 $k=4$ 固定时，时间就是 $O(N)$，下标数组也是常量规模。

  </Tab>
  <Tab value="最小堆优化">

  堆中为每个数组保留一个当前元素，键为数值，同时维护当前所有候选中的最大值 `maxValue`：

  1. 初始化将 $k$ 个数组首元素入最小堆，记录最大值。
  2. 堆顶即当前**最小元素**，用 `maxValue - heap.top` 更新答案。
  3. 弹出堆顶，将它所属数组的下一个元素入堆；插入时更新 `maxValue`。若该数组耗尽，则结束，因为不可能再从每个数组各选一个元素。

  初始化建堆 $O(k)$，之后最多 $O(N)$ 次堆更新，每次 $O(\log k)$，总时间 **$O(N\log k)$**，堆与数组下标占 **$O(k)$** 额外空间。适合 $k$ 很大、无法承受每轮扫描全部数组的情形。

  </Tab>
</Tabs>

<Callout type="idea" title="为什么推广成立">

三个、四个、$k$ 个数组本质都在求**每个序列各取一个数时的最小极差**。贪心安全性来自有序性和「当前最小值必须改变才可能缩小区间」，与数组个数无关。

</Callout>

</Solution>

### 原创预测训练 2 · 无序数组的最小距离与排序前提

<Question
  id="408-ds-large-2020-41-ext2"
  type="essay"
  tags="来源:原创预测训练, 考点:堆排序与三指针"
>

给定 3 个非空的**无序**整数数组 `A`、`B`、`C`，允许原地修改各数组，仍求真题中的最小距离

$$
D(a,b,c)=|a-b|+|b-c|+|c-a|.
$$

1. 用一个**具体反例**说明直接应用「推进当前最小者」的三指针贪心可能失败。
2. 设计并实现最坏时间 $O(N\log N)$、额外空间 $O(1)$ 的算法，其中 $N=n_1+n_2+n_3$。
3. 比较「排序后线性扫描」与直接三重枚举的复杂度；对 `A=[9,-1,0]`、`B=[10,-25,-10,11]`、`C=[41,9,2,17,30]` 给出结果。

<Solution>

### 参考答案

**不能直接贪心。应先分别使用原地堆排序将三个数组变成非降序，再调用 2020 年真题的三指针算法**。排序最坏时间 $O(N\log N)$，三指针扫描 $O(N)$，总时间 **$O(N\log N)$**，额外空间 **$O(1)$**。

### 为什么无序时会失败

例如 `A=[1,100,6]`、`B=[5]`、`C=[8]`。初始组合 $(1,5,8)$ 的距离为 $14$，最小者是 $1$；向右推进 A 后，组合变为 $(100,5,8)$，而最小者变成 B 的唯一元素 $5$。继续推进 B 就会耗尽，整个扫描无法再访问 A 后面的 $6$，因此会**漏掉更优组合 $(6,5,8)$，其距离仅为 $6$**。

错误原因是：无序数组向右推进后，选值不保证不减；当前最小者之外的指针变化也可能带来更优结果。真题的贪心证明依赖**每个输入数组已经按升序排列**，不是无条件成立。

### 实现：原地堆排序 + 真题三指针

```c title="无序数组：先堆排序再求最小距离" lineNumbers
#include <limits.h>
#include <stddef.h>

static void SiftDown(int A[], int root, int last) {
    while (last >= 1 && root <= (last - 1) / 2) {
        int child = 2 * root + 1;
        if (child < last && A[child + 1] > A[child]) ++child;
        if (A[root] >= A[child]) break;
        int tmp = A[root]; A[root] = A[child]; A[child] = tmp;
        root = child;
    }
}

static void HeapSort(int A[], int n) {
    for (int i = n / 2; i > 0;) {
        --i;
        SiftDown(A, i, n - 1);
    }
    for (int end = n - 1; end > 0; --end) {
        int tmp = A[0]; A[0] = A[end]; A[end] = tmp;
        SiftDown(A, 0, end - 1);
    }
}

/* Min3Distance 为紧邻上方 2020 年真题给出的完整函数 */
long long MinDistanceUnsorted(int A[], int n1,
                              int B[], int n2,
                              int C[], int n3) {
    if (A == NULL || B == NULL || C == NULL ||
        n1 <= 0 || n2 <= 0 || n3 <= 0) return -1;

    HeapSort(A, n1);
    HeapSort(B, n2);
    HeapSort(C, n3);
    return Min3Distance(A, n1, B, n2, C, n3);
}
```

### 正确性与效率

1. **堆排序不会改变各数组的候选值集合**，仅改变它们在数组中的排列。所有可能的三元组及其最小距离因此不变。
2. 排序完成后，每个数组都满足非降序条件，真题「只推进当前最小者」的贪心证明重新成立。
3. 分别排序的最坏工作量为

   $$
   O(n_1\log n_1+n_2\log n_2+n_3\log n_3)\subseteq O(N\log N).
   $$

   然后三指针总共最多移动 $O(N)$ 次；堆排序与扫描都只需要常数个辅助变量，所以总额外空间 $O(1)$。

样例排序后回到真题的三个升序序列，最小距离为 **$2$**，例如 $(9,10,9)$。

| 方法 | 最坏时间 | 额外空间 | 前提 |
| --- | --- | --- | --- |
| 三重枚举 | $O(n_1n_2n_3)$ | $O(1)$ | 无需排序 |
| 原地堆排序 + 三指针 | $O(N\log N)$ | $O(1)$ | 允许改变数组内顺序 |
| 已有序时直接三指针 | $O(N)$ | $O(1)$ | 各数组本来有序 |

<Callout type="warn" title="别混淆复杂度与前提">

- 这里选择**堆排序**，是为了给出严格的最坏时间 $O(N\log N)$ 与额外空间 $O(1)$；递归归并排序通常需要线性辅助数组。
- 「三指针只推进最小者」不是无需条件的贪心模板，必须明确**数组排序产生的单调性**。
- 若要求不修改无序输入数组，不能再直接采用本题的原地排序版本；需要复制数据或改用其他算法并重新分析空间。

</Callout>

</Solution>

## 2025 年第 41 题

<Question
  id="408-ds-large-2025-41"
  type="essay"
  tags="来源:2025考研408, 考点:后缀最值, 考点:线性扫描"
>

设有两个长度均为 $n$ 的一维整型数组 `A` 和 `res`。对数组 `A` 中的每个元素 `A[i]`，需要计算

$$
\max_{i\le j\le n-1}\{A[i]\cdot A[j]\},
$$

并将结果保存到 `res[i]` 中。

例如，若

$$
A=\{1,4,-9,6\},
$$

则

$$
res=\{6,24,81,36\}.
$$

请设计时间和空间上尽可能高效的算法：

```c
void calMulMax(int A[], int res[], int n);
```

要求：

1. 给出算法的基本设计思想。
2. 使用 C 或 C++ 描述算法。
3. 说明时间复杂度和额外空间复杂度。

<Solution>

### 答案速览

`res[i]` 只能从后缀 `A[i..n-1]` 中选另一个因子（允许 $j=i$）。固定 $x=A[i]$ 时，$x\cdot y$ 是 $y$ 的一次函数，最大值必在后缀的**最大值 `hi` 或最小值 `lo`** 处取得：

$$
res[i]=\max\bigl(A[i]\cdot hi_i,\ A[i]\cdot lo_i\bigr).
$$

**从右往左扫描**，先把 `A[i]` 并入 `hi`、`lo`，再计算 `res[i]`。时间 $O(n)$，额外空间 $O(1)$（不计输出数组）。样例结果 $res=\{6,24,81,36\}$。

### 图解：逆序扫描维护后缀极值

<AlgoFigure src="/img/408/past-exams-large-questions/01-数据结构/solutions/2025-41-1" w={740} h={400} alt="2025-41 A = {1,4,-9,6} 从右往左维护后缀最大值与最小值并计算 res" caption="左：每一行是一次迭代，蓝格为当前 A[i]，括号为合法后缀；右：x > 0 时最大值在 hi 端，x < 0 时在 lo 端" />

- $A[i]>0$：乘以最大值最好；
- $A[i]<0$：乘以最小值（最负的数）最好，例如 $-9\times(-9)=81$；
- $A[i]=0$：结果为 0。

统一取两个乘积的较大者，就不用分情况讨论。注意 `res[2] = 81` 来自 $j=i=2$（自己乘自己），这正是「**先并入、后计算**」的原因。

### 设计步骤

<Steps>
  <Step>

  ### 初始化

  `hi = lo = A[n-1]`。

  </Step>
  <Step>

  ### i 从 n−1 递减到 0

  先更新 `hi = max(hi, A[i])`、`lo = min(lo, A[i])`，此时它们就是 `A[i..n-1]` 的极值；再令 `res[i] = max(A[i]*hi, A[i]*lo)`。

  </Step>
</Steps>

```c title="2025-41：一次逆序扫描" lineNumbers
void calMulMax(int A[], int res[], int n) {
    if (A == NULL || res == NULL || n <= 0) return;
    int hi = A[n - 1], lo = A[n - 1];

    for (int i = n - 1; i >= 0; --i) {
        int x = A[i];
        if (x > hi) hi = x;          // 先把 A[i] 并入后缀
        if (x < lo) lo = x;

        int a = x * hi, b = x * lo;  // 再计算（允许 j = i）
        res[i] = a > b ? a : b;
    }
}
```

### 正确性与复杂度

- **不变量**：处理完下标 $i$ 的更新后，`hi`、`lo` 分别是 `A[i..n-1]` 的最大、最小值（由 $hi_i=\max(A[i],hi_{i+1})$ 递推）。
- **取值正确**：一次函数在闭区间上的最大值在端点取得，后缀中所有数都在 $[lo,hi]$ 内，所以两个候选乘积的较大者就是所求。
- **复杂度**：每个元素常数次比较与乘法，时间 $O(n)$；除输出外只有两个变量，空间 $O(1)$。

| $i$ | $A[i]$ | $lo$ | $hi$ | 两个乘积 | $res[i]$ |
| ---: | ---: | ---: | ---: | --- | ---: |
| 3 | 6 | 6 | 6 | 36, 36 | 36 |
| 2 | −9 | −9 | 6 | −54, **81** | 81 |
| 1 | 4 | −9 | 6 | **24**, −36 | 24 |
| 0 | 1 | −9 | 6 | **6**, −9 | 6 |

<Callout type="warn" title="易错点">

- **先更新、后计算**；反过来就只考虑了 $j>i$。
- 只维护最大值会漏掉「负负得正」。
- 若数据可能接近 `int` 边界，应把 `x`、`hi`、`lo` 和 `res` 改为 `long long` 再相乘。

</Callout>

</Solution>
</Question>

### 原创强化训练 1 · 严格向右并返回最左最优下标

<Question
  id="408-ds-large-2025-41-ext1"
  type="essay"
  tags="来源:原创强化训练, 考点:严格后缀, 考点:最优下标"
>

给定整数数组 `A[0..n-1]`，对每个位置 $i$，必须选择**严格位于其右侧**的位置 $j>i$，使乘积 $A[i]A[j]$ 最大。若有多个最优 $j$，必须选**最小的下标**。

将最大乘积写入 `long long best[]`，对应下标写入 `int pos[]`。若不存在合法 $j$，规定 `best[i]=LLONG_MIN`、`pos[i]=-1`。

1. 设计 $O(n)$ 时间、$O(1)$ 额外空间的算法（不计输出数组）。
2. 用 C 实现，强调**先查询、后更新**以及并列时的下标维护。
3. 对 `A={0,2,-3,-3,2}` 求两个输出数组，并解释 `A[i]=0` 的特殊性。

<Solution>

### 参考答案

从右往左扫描，处理位置 $i$ 时缓存区间 `A[i+1..n-1]` 的最大、最小元素及其**最左出现下标**。先用该严格后缀回答查询，再把 `A[i]` 加入缓存。正数选择后缀最大值、负数选择后缀最小值、零选择最小合法下标 $i+1$。

结果为：

$$
\boxed{best=\{0,4,9,-6,\mathrm{LLONG\_MIN}\}},
$$

$$
\boxed{pos=\{1,4,3,4,-1\}}.
$$

```c title="严格后缀 + 最左最优下标" lineNumbers
#include <limits.h>
#include <stddef.h>

void MaxProductRight(const int A[], int n,
                     long long best[], int pos[]) {
    if (A == NULL || best == NULL || pos == NULL || n <= 0) return;

    best[n - 1] = LLONG_MIN;
    pos[n - 1] = -1;                  // 末元素右边没有候选
    long long hi = A[n - 1], lo = A[n - 1];
    int hiPos = n - 1, loPos = n - 1;

    for (int i = n - 2; i >= 0; --i) {
        long long x = A[i];
        if (x > 0) {
            best[i] = x * hi;
            pos[i] = hiPos;
        } else if (x < 0) {
            best[i] = x * lo;
            pos[i] = loPos;
        } else {
            best[i] = 0;
            pos[i] = i + 1;          // 全部右侧位置并列最优
        }

        // 只有回答了本轮查询后，才允许将 A[i] 加入后缀。
        if (x >= hi) { hi = x; hiPos = i; }
        if (x <= lo) { lo = x; loPos = i; }
    }
}
```

### 解题关键

1. **严格右侧**：更新必须放在计算后面。否则遇到 $-3$ 时可能错误使用 $(-3)\times(-3)$ 的「自己乘自己」。
2. **最左下标**：逆序遍历遇到与缓存极值相同的新值，其下标一定更小，因此更新时使用 `>=`、`<=` 而不是严格不等号。
3. **零的特例**：任意右侧元素与零相乘均为零，最小合法下标必是 $i+1$；不能按最大值下标或最小值下标确定它。
4. **正确性**：查询时极值缓存恰好对应严格右后缀，再由乘法单调性确定最优值和最左位置；更新后保持下一轮所需不变量。

时间 $O(n)$，额外空间 $O(1)$；`best`、`pos` 为题目要求的输出数组，不计辅助空间。

</Solution>

### 原创预测训练 2 · 固定长度右侧窗口上的最大乘积

<Question
  id="408-ds-large-2025-41-ext2"
  type="essay"
  tags="来源:原创预测训练, 考点:单调队列, 考点:滑动窗口"
>

原题扩展为**有限窗口查询**：给定整数 $w$（$0\le w<n$），对每个 $i$ 仅可选

$$
i\le j\le\min(n-1,i+w).
$$

求最大乘积 `best[i]`，并在并列时记录最小的可选下标 `pos[i]`。输入数组不得修改，输出数组 `best` 使用 `long long`。

1. 设计总时间 $O(n)$、额外空间 $O(w+1)$ 的算法（不计输出数组）。
2. 说明为什么需要同时维护当前窗口的最大值、最小值，以及如何保证**相等元素优先最左下标**。
3. 对 `A={1,4,-9,6}`、$w=2$ 写出 `best`、`pos`。

<Solution>

### 参考答案

采用两条**单调双端队列**，分别保存窗口内的最大值候选和最小值候选的下标。按窗口左端点 $i$ 从左到右移动，并将右端扩展到 $\min(n-1,i+w)$。最大队列中的值单调不增，最小队列中的值单调不减；新元素入队时，仅剔除**严格劣于**新元素的队尾，保留相等元素的更早下标。

样例输出：

$$
\boxed{best=\{4,24,81,36\},\quad pos=\{1,3,2,3\}}.
$$

### 核心算法

用容量为 $w+1$ 的循环数组分别实现两个双端队列：

<Steps>
  <Step>

  ### 窗口左端点从 $i-1$ 变为 $i$

  先从两条队列的**队首**移除所有下标小于 $i$ 的旧元素。这一步放在添加新右端元素**之前**，可以确保固定容量 $w+1$ 不会溢出。

  </Step>
  <Step>

  ### 逐个插入刚进入窗口的右端元素

  - 最大值队列：队尾的值若**小于**新值就移除，再插入新下标。
  - 最小值队列：队尾的值若**大于**新值就移除，再插入新下标。

  对于相等值不移除旧下标，以便队首仍是该极值最靠左的合法位置。

  </Step>
  <Step>

  ### 回答查询

  对 $x=A[i]$：$x>0$ 时取最大值队首，$x<0$ 时取最小值队首，$x=0$ 时直接取 `pos[i]=i`。把乘积保存到 `long long best[i]`。

  </Step>
</Steps>

```c title="O(n) 时间、O(w+1) 额外空间的完整实现" lineNumbers
#include <stdlib.h>

typedef struct {
    int *a;
    int head, size, cap;
} Deque;

static int dqFront(const Deque *d) { return d->a[d->head]; }
static int dqBack(const Deque *d) {
    return d->a[(d->head + d->size - 1) % d->cap];
}
static void popFront(Deque *d) {
    d->head = (d->head + 1) % d->cap;
    --d->size;
}
static void popBack(Deque *d) { --d->size; }
static void pushBack(Deque *d, int v) {
    d->a[(d->head + d->size) % d->cap] = v;
    ++d->size;
}

int WindowMaxProduct(const int A[], int n, int w,
                     long long best[], int pos[]) {
    if (!A || !best || !pos || n <= 0 || w < 0 || w >= n)
        return 0;

    int cap = w + 1;
    Deque mx = {0}, mn = {0};
    mx.a = (int *)malloc((size_t)cap * sizeof(int));
    mn.a = (int *)malloc((size_t)cap * sizeof(int));
    if (!mx.a || !mn.a) {
        free(mx.a); free(mn.a);
        return 0;
    }
    mx.cap = mn.cap = cap;
    mx.head = mx.size = mn.head = mn.size = 0;

    int nextRight = 0;
    for (int i = 0; i < n; ++i) {
        // 先剔除左端过期元素，保证队列最多容纳 w+1 项。
        while (mx.size && dqFront(&mx) < i) popFront(&mx);
        while (mn.size && dqFront(&mn) < i) popFront(&mn);

        int r = (w > n - 1 - i) ? n - 1 : i + w;
        while (nextRight <= r) {
            int t = nextRight++;
            while (mx.size && A[dqBack(&mx)] < A[t]) popBack(&mx);
            pushBack(&mx, t);
            while (mn.size && A[dqBack(&mn)] > A[t]) popBack(&mn);
            pushBack(&mn, t);
        }

        int j = (A[i] > 0) ? dqFront(&mx)
              : (A[i] < 0) ? dqFront(&mn) : i;
        pos[i] = j;
        best[i] = (long long)A[i] * A[j];
    }
    free(mx.a); free(mn.a);
    return 1;
}
```

### 正确性与复杂度

队列始终保存窗口内**未被后来的更优元素支配**的候选下标，队首为该窗口对应的最值；被移除的较差值，即使还在窗口中，也无法在支配它的更新元素离开窗口**之前**成为最优（后来的元素离开时，旧元素已经更早离开）。严格比较保证并列最大或最小值时，保留先出现的左端下标。

每个下标只被压入一次，最多从队首或队尾移除一次，因此虽然内部有 `while`，总的双端队列操作次数是 $O(n)$；两条队列最多各存 $w+1$ 个下标，额外空间 $O(w+1)$。

原题是窗口右端始终等于 $n-1$ 的**后缀最值**；本题把范围变为移动窗口，因此静态两个极值不足以删除过期元素，需要将「后缀扫描」升级为「单调队列维护窗口极值」。
