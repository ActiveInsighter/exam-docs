## 2009 年第 42 题

<Question
  id="408-ds-large-2009-42"
  type="essay"
  tags="来源:2009考研408, 科目:数据结构, 章节:线性表, 考点:单链表双指针, 难度:中等"
>

已知一个**带头结点**的单链表，结点结构为 `| data | link |`。只给出头指针 `list`。

在**不改变链表**的前提下，设计一个尽可能高效的算法，查找链表中**倒数第 $k$ 个结点**（$k$ 为正整数）。若查找成功，则输出该结点 `data` 域的值并返回 1；否则返回 0。

要求：

1. 描述算法的基本设计思想。
2. 描述算法的详细实现步骤。
3. 用 C、C++ 或 Java 描述算法，并在关键位置给出注释。

<Solution>

### 参考答案

**采用快慢双指针，一次单向扫描，时间 $O(n)$，额外空间 $O(1)$。**

- `fast` 和 `slow` 都从**首元结点** `list->link` 出发。
- 先令 `fast` 向前移动 $k-1$ 步。如果还没有建立间距就走到 `NULL`，则 $k$ 大于表长，返回 0。
- 再让两指针同步后移，直至 `fast` 指向最后一个数据结点。此时 `slow` 即为倒数第 $k$ 个结点，输出其值并返回 1。

### 解题过程

<Steps>
  <Step>

  ### 第一步：确定间距不变量

  链表长度为 $n$，倒数第 $k$ 个数据结点按正向编号为第 $n-k+1$ 个。不能随机访问，最自然的做法是维持两个游标相差 $k-1$ 条 `link` 边。

  **循环不变量：**同步移动阶段，`fast` 始终比 `slow` 领先 $k-1$ 条边。因此当 `fast` 走到第 $n$ 个数据结点时，`slow` 恰在第 $n-(k-1)$ 个数据结点。

  </Step>
  <Step>

  ### 第二步：先检查是否有足够的结点

  先从 `list->link` 出发，移动 `fast` 共 $k-1$ 次。移动前可允许 `fast==NULL`，但绝不能对空指针取 `fast->link`。先行结束后还须再检查一次 `fast`。

  </Step>
  <Step>

  ### 第三步：保持固定间距，定位目标

  在 `fast->link != NULL` 时，让 `fast` 和 `slow` 各前进一步。由于两者移动步数完全相同，间距不变量不变。

  </Step>
</Steps>

```c title="2009-42：带头结点单链表的倒数第 k 个结点" lineNumbers
#include <stdio.h>

typedef struct LNode {
    int data;
    struct LNode *link;
} LNode;

int FindKthFromEnd(const LNode *list, int k) {
    if (list == NULL || k <= 0) return 0;

    const LNode *fast = list->link;
    const LNode *slow = list->link;  // 跳过头结点

    // 先建立 k-1 条 link 的间距
    for (int i = 1; i < k; ++i) {
        if (fast == NULL) return 0;
        fast = fast->link;
    }
    if (fast == NULL) return 0;   // 空表或 k 超过表长

    // 维持 fast 到 slow 的相对距离
    while (fast->link != NULL) {
        fast = fast->link;
        slow = slow->link;
    }

    printf("%d\n", slow->data);
    return 1;
}
```

### 正确性证明

初始化成功后，`fast` 位于第 $k$ 个数据结点，`slow` 位于第 1 个数据结点。同步扫描的每轮均保持两者之间恰有 $k-1$ 条边。最终 `fast` 到达第 $n$ 个结点，因此 `slow` 的正向序号为 $n-k+1$，正是倒数第 $k$ 个结点。若 $k>n$，初始化阶段必会遇到空指针并返回 0；所以算法对成功、失败两种情况都正确。

### 复杂度分析

先行扫描至多 $k-1$ 步，同步阶段至多 $n-k$ 轮；虽然有两个指针，**没有从头再次扫描**，总操作数为 $O(n)$。只需两个指针和计数器，额外空间 $O(1)$。

| 情况 | 应得结果 | 关键原因 |
| --- | --- | --- |
| 空链表（只有头结点） | 0 | 首元结点为 `NULL` |
| $k=1$ | 输出最后一个数据结点 | 两指针初始重合 |
| $k=n$ | 输出第一个数据结点 | 快指针先行后已到表尾 |
| $k>n$ | 0 | 无法建立完整间距 |

<Callout type="warn" title="易错点">

- **带头结点**不代表头结点也是第 1 个数据结点；计数必须从 `list->link` 开始。
- 这里使用的是「领先 $k-1$ 条边，快指针停在末结点」的口径。另一种写法可以使两指针相差 $k$ 条边，让快指针最终为 `NULL`。**两种终止条件不可混用**。
- 题干要求**打印数据并返回 1/0**，不能只返回找到的结点指针。

</Callout>

</Solution>
</Question>

### 原创强化训练 1 · 删除倒数第 $k$ 个结点

<Question
  id="408-ds-large-2009-42-ext1"
  type="essay"
  tags="来源:原创强化训练, 科目:数据结构, 章节:线性表, 考点:虚拟头结点, 难度:较难"
>

给定一个**不带头结点**的单链表 `head`，`next` 指向后继，结点均由动态内存分配。给定整数 $k$，删除倒数第 $k$ 个结点，返回删除后的新表头。若 $k\le0$ 或 $k$ 超过表长，链表应保持不变。

1. 要求单向扫描，时间 $O(n)$，额外空间 $O(1)$。
2. 说明删除首元结点时，为什么不需要单独编写删除分支。
3. 写出 C 语言实现，处理空链表、越界和释放结点。

<Solution>

### 参考答案

在栈上构造一个**临时哑结点** `dummy`，令其 `next=head`。快、慢指针都从 `dummy` 出发，先让 `fast` 前进 $k$ 条边；再让二者同步移动到 `fast->next==NULL`。这时 `slow` 就是待删结点的**前驱**。删除 `slow->next`，返回 `dummy.next`。

```c title="删除倒数第 k 个结点" lineNumbers
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *next;
} Node;

Node *DeleteKthFromEnd(Node *head, int k) {
    if (k <= 0) return head;

    Node dummy = {0, head};
    Node *fast = &dummy, *slow = &dummy;

    for (int i = 0; i < k; ++i) {
        if (fast->next == NULL) return head; // 长度不足
        fast = fast->next;
    }

    while (fast->next != NULL) {
        fast = fast->next;
        slow = slow->next;
    }

    Node *victim = slow->next;
    slow->next = victim->next;
    free(victim);                       // 题设：结点归调用方所有
    return dummy.next;
}
```

### 为什么正确

删除需要的是**前驱**而非目标结点本身。由于 `fast` 领先 `slow` 恰好 $k$ 条边，快指针停在尾结点时，慢指针刚好位于倒数第 $k$ 个结点的前一位置。

例如 $1\to2\to3\to4$，$k=4$：先行后 `fast` 已在结点 4，`slow` 仍在 `dummy`，所以 `slow->next` 就是原首元结点 1。删除后通过 `dummy.next` 得到新的表头 2，**无需额外判断删除的是不是第一个结点**。

<Callout type="idea" title="迁移技巧">

题目从「查找结点」变成「删除结点」时，优先思考**能否使慢指针落在待删结点的前驱**。临时哑结点可以统一处理「删除首元」和「删除普通结点」。

</Callout>

复杂度：时间 $O(n)$，额外空间 $O(1)$。如果结点由内存池统一管理，须将 `free` 改为对应的释放方式。

</Solution>
</Question>

### 原创强化训练 2 · 含环链表上的倒数定位

<Question
  id="408-ds-large-2009-42-ext2"
  type="essay"
  tags="来源:原创预测训练, 科目:数据结构, 章节:线性表, 考点:Floyd判环, 难度:较难"
>

某程序接收到一个**带头结点**的单链表 `list`，由于指针可能被错误连接，数据结点部分**可能含环**。定义：仅当数据结点形成一个以 `NULL` 结尾的有限链时，才存在「倒数第 $k$ 个结点」。

设计函数 `int SafeFind(const LNode *list, int k)`，规定：

- 有环时返回 `-1`，且不输出数据；
- 无环而 $k$ 合法时输出该结点的 `data`，返回 `1`；
- 其他情况返回 `0`。

要求不改变任何指针，时间 $O(n)$、额外空间 $O(1)$。阐述算法的两层循环不变量。

<Solution>

### 参考答案

**先用 Floyd 快慢指针判环，再在确认无环后执行原题的固定间距扫描。**总时间依旧为线性阶，因为只做常数次扫描；不必创建访问标记表。

```c title="判环 + 倒数定位" lineNumbers
// 使用原题的 LNode 定义与 FindKthFromEnd 函数
int SafeFind(const LNode *list, int k) {
    if (list == NULL || k <= 0) return 0;

    const LNode *slow = list->link;
    const LNode *fast = list->link;

    while (fast != NULL && fast->link != NULL) {
        slow = slow->link;
        fast = fast->link->link;
        if (slow == fast) return -1; // 环内必会相遇
    }

    return FindKthFromEnd(list, k); // 已确认链表以 NULL 结束
}
```

### 关键推导

1. **判环不变量：**每轮慢指针走一条边、快指针走两条边。若二者进入同一个环，快指针相对慢指针每轮前进 1 个环位置，至多再经过一个环长便相遇；无环时快指针必先到 `NULL`。
2. **倒数定位不变量：**无环条件成立后，方可谈尾结点；用原题「快指针领先 $k-1$ 条边」的做法，终止时慢指针指向目标。

时间 $O(n)$，空间 $O(1)$；`n` 表示无环时的链长，或有环时首次进入环前的结点数加环长。

<Callout type="warn" title="命题陷阱">

「有环」时不存在通常意义上的尾结点，因此不能直接执行 `while (fast->link != NULL)`：该循环可能永不结束。**判环是倒数定位的前置条件**，不是可以省略的额外功能。

</Callout>

</Solution>
</Question>

## 2010 年第 42 题

<Question
  id="408-ds-large-2010-42"
  type="essay"
  tags="来源:2010考研408, 科目:数据结构, 章节:线性表, 考点:循环移位, 难度:中等"
>

设有 $n$ 个整数（$n>1$）存放在一维数组 $R$ 中。设计一个在时间和空间两方面都尽可能高效的算法，将 $R$ 中的序列**循环左移 $p$ 个位置**，其中 $0<p<n$。

即把

$$
\langle x_0,x_1,\ldots,x_{n-1}\rangle
$$

变换为

$$
\langle x_p,x_{p+1},\ldots,x_{n-1},x_0,x_1,\ldots,x_{p-1}\rangle.
$$

要求：

1. 给出算法的基本设计思想。
2. 用 C、C++ 或 Java 描述算法。
3. 说明时间复杂度和空间复杂度。

<Solution>

### 参考答案

**把数组分成 $X=R[0\ldots p-1]$ 和 $Y=R[p\ldots n-1]$，分别逆置 $X$、$Y$，然后逆置整个数组。**这样由 $XY$ 得到 $YX$，总时间 $O(n)$，额外空间 $O(1)$。

### 核心思路：三次逆置

设上标 $R$ 表示反转，则

$$
XY\xrightarrow{\text{各自逆置}}X^RY^R
\xrightarrow{\text{整体逆置}}(X^RY^R)^R=YX.
$$

<Steps>
  <Step>

  ### 逆置前 $p$ 个元素

  令区间 `[0,p-1]` 的元素顺序反转。

  </Step>
  <Step>

  ### 逆置后 $n-p$ 个元素

  令区间 `[p,n-1]` 的元素顺序反转。

  </Step>
  <Step>

  ### 整体逆置

  逆置 `[0,n-1]`，两段的相对位置互换，段内顺序恢复为原来顺序。

  </Step>
</Steps>

```c title="三次逆置：最推荐的考场实现" lineNumbers
#include <stddef.h>

static void Reverse(int R[], int left, int right) {
    while (left < right) {
        int t = R[left];
        R[left] = R[right];
        R[right] = t;
        ++left;
        --right;
    }
}

void LeftRotate(int R[], int n, int p) {
    if (R == NULL || n <= 1 || p < 0) return;
    p %= n;
    if (p == 0) return;

    Reverse(R, 0, p - 1);
    Reverse(R, p, n - 1);
    Reverse(R, 0, n - 1);
}
```

### 过程演示

令初始数组为 `abcdefgh`，左移 $3$ 位：

| 步骤 | 当前数组 | 说明 |
| --- | --- | --- |
| 初始 | `abcdefgh` | $X=abc$，$Y=defgh$ |
| 逆置前段 | `cbadefgh` | $X^RY$ |
| 逆置后段 | `cbahgfed` | $X^RY^R$ |
| 整体逆置 | `defghabc` | $YX$ |

### 正确性、最优性与易错点

- **正确性：**把初始元素位置记作 $i$，左移后应到达 $(i-p+n)\bmod n$，三次逆置恰好实现了这一映射。
- **复杂度：**三段逆置各只需线性数量交换，总时间 $O(n)$；只使用一个临时变量及两个区间下标，额外空间 $O(1)$。
- **最优性：**一般情形下需改变线性数量的元素位置，因此 $O(n)$ 已是渐近最优时间量级。

<Callout type="warn" title="常见失分点">

区间必须是 `[0,p-1]` 和 `[p,n-1]`；不能错误写成 `[p+1,n-1]`。如果允许任意大的位移量，先使用 `p %= n` 规范化；否则可能越界。先分别逆置两个区间再整体逆置，或者先整体逆置再分别逆置合适区间，均可实现，只要完整论证分段位置。

</Callout>

</Solution>
</Question>

### 原创强化训练 1 · 子区间循环位移

<Question
  id="408-ds-large-2010-42-ext1"
  type="essay"
  tags="来源:原创强化训练, 科目:数据结构, 章节:线性表, 考点:区间逆置, 难度:中等"
>

整数数组 `A[0..n-1]` 中，只有闭区间 `[l,r]`（$0\le l\le r<n$）允许改变，区间外元素必须保持原来的**位置和值**。给定整数位移量 $p$，约定 $p>0$ 表示区间循环左移，$p<0$ 表示区间循环右移。

1. 设计时间 $O(r-l+1)$、额外空间 $O(1)$ 的原地算法。
2. 说明当 $p$ 为负数或位移量绝对值大于区间长度时如何处理。
3. 对 `A=[0,1,2,3,4,5,6,7,8]`、`l=2,r=7,p=2` 给出结果。

<Solution>

### 参考答案

令区间长度 $m=r-l+1$，将位移规范化为

$$
s=((p\bmod m)+m)\bmod m,\qquad 0\le s<m.
$$

对 `[l,l+s-1]`、`[l+s,r]` 分别逆置，再整体逆置 `[l,r]`。

```c title="循环移动任意子区间"
void RotateRange(int A[], int n, int l, int r, long long p) {
    if (A == NULL || n <= 0 || l < 0 || r >= n || l > r)
        return;
    int m = r - l + 1;
    int s = (int)((p % m + m) % m);
    if (s == 0) return;

    Reverse(A, l, l + s - 1);  // 复用原题逆置函数
    Reverse(A, l + s, r);
    Reverse(A, l, r);
}
```

### 结果与证明

原区间是 `[2,3,4,5,6,7]`，左移 2 位得到 `[4,5,6,7,2,3]`，因此整个数组为：

```text
[0,1,4,5,6,7,2,3,8]
```

区间之外的所有交换均不会触及，故外部位置保持不变。位移量归一化后可直接复用原题的三次逆置证明。三个反转只访问长度为 $m$ 的区间，时间 $O(m)$，额外空间 $O(1)$。

<Callout type="idea" title="拓展迁移">

「旋转整个数组」本质上是「旋转指定区间」的特殊情形；处理负数位移量时不要直接把负数当成 C 语言非负余数。

</Callout>

</Solution>
</Question>

### 原创预测训练 2 · 多次位移的惰性合并

<Question
  id="408-ds-large-2010-42-ext2"
  type="essay"
  tags="来源:原创预测训练, 科目:数据结构, 章节:线性表, 考点:模运算, 难度:较难"
>

长度为 $n$（$n\ge1$）的数组依次接收 $q$ 条操作，每条给出一个可能很大的有符号整数 $p_i$：正数表示**循环左移**，负数表示**循环右移**。**仅在全部操作完成后需要输出最终数组**，不要求中间状态。

1. 证明全部操作可以合并为一次循环位移。
2. 设计总时间 $O(n+q)$、额外空间 $O(1)$ 的算法，不允许因为累计求和而产生有符号整数溢出。
3. 若初始数组为 `abcdefgh`、位移依次为 $3,-2,11$，给出最终数组。

<Solution>

### 参考答案

循环位移在模 $n$ 意义下可加：

$$
s\equiv\sum_{i=1}^q p_i\pmod n,\qquad 0\le s<n.
$$

只维护累计偏移量的模 $n$ 结果，在所有操作结束后调用原题的三次逆置法一次。

```c title="多次位移一次执行"
#include <stddef.h>

// 参数 shift[0..q-1] 保存每次位移指令
void BatchRotate(int A[], int n, const long long shift[], int q) {
    if (A == NULL || n <= 0 || q < 0 ||
        (q > 0 && shift == NULL)) return;

    long long s = 0;
    for (int i = 0; i < q; ++i) {
        // 先将每个大整数缩小到 [0,n-1]，避免累计溢出
        long long x = shift[i] % n;
        if (x < 0) x += n;
        s = (s + x) % n; // s+x <= 2n-2，n 为 int，long long 安全
    }
    LeftRotate(A, n, (int)s);  // 原题函数
}
```

### 解题过程

每次左移 $p_i$ 都把原下标 $j$ 变为 $(j-p_i)\bmod n$，相继执行时得到 $(j-\sum p_i)\bmod n$，所以位移可交换、可结合。代码将每个 `p_i` 先取模，再在 `long long` 中累加，避免直接求和可能溢出。

样例累计位移为 $3-2+11=12$，对长度 $8$ 取模得到 $4$，故最终为 `efghabcd`。

- 扫描 $q$ 个指令耗时 $O(q)$。
- 最终一次逆置耗时 $O(n)$。
- 只保存偏移量和常数个临时变量，额外空间 $O(1)$。

<Callout type="warn" title="适用前提">

惰性合并要求**不需要读取或输出中间每一步的实际数组**。若每条操作后都必须输出整个数组，就不能声称总时间仍为 $O(n+q)$。

</Callout>

</Solution>
</Question>

## 2011 年第 42 题

<Question
  id="408-ds-large-2011-42"
  type="essay"
  tags="来源:2011考研408, 科目:数据结构, 章节:线性表, 考点:有序序列中位数, 难度:较难"
>

长度为 $L$（$L\ge1$）的升序序列 $S$ 中，第

$$
\left\lceil\frac{L}{2}\right\rceil
$$

个位置上的数称为 $S$ 的中位数。例如，$S_1=(11,13,15,17,19)$ 的中位数是 15。

两个序列的中位数，定义为将它们全部元素合并并按升序排列后所得序列的中位数。例如，若 $S_2=(2,4,6,8,20)$，则 $S_1$ 与 $S_2$ 的中位数为 11。

现有两个**等长升序序列** $A$、$B$，设计一个在时间和空间两方面都尽可能高效的算法，求它们的中位数。

<Solution>

### 参考答案

设两个序列长度均为 $n$，则合并后共 $2n$ 个元素。**根据题目定义，所求是第 $n$ 小元素（下中位数），不是中间两个元素的平均数。**

维护两个**长度始终相同**的候选区间，比较各自的下中位数，每次从一个区间的低端、另一个区间的高端**等量删除**不可能成为目标的候选。最终两个区间均只剩一个元素时，取二者较小者。时间 $O(\log n)$，额外空间 $O(1)$。

### 推导与方法

<Steps>
  <Step>

  ### 第一步：先锁定「第几小」

  题目对长度 $L$ 的序列取第 $\lceil L/2\rceil$ 个元素。因此两个等长序列合并后，目标的升序排名为

  $$
  \left\lceil\frac{2n}{2}\right\rceil=n.
  $$

  例如 `[1,3]` 与 `[2,4]` 合并成 `[1,2,3,4]`，答案是第 2 小的 **2**，而不是 2.5。

  </Step>
  <Step>

  ### 第二步：比较两个候选区间的下中位数

  设当前候选子区间长度均为 $t$，下中位数分别是 $a=A[m_1]$、$b=B[m_2]$。

  - 若 $a=b$，直接返回该值。
  - 若 $a<b$，等量剔除**A 的低端**和**B 的高端**。
  - 若 $a>b$，对称地剔除**B 的低端**和**A 的高端**。

  这相当于每次从候选集合同时移除相同数量的「偏小」和「偏大」元素，因此目标在新的候选集合中仍然是**下中位数**。

  </Step>
  <Step>

  ### 第三步：区分奇偶，确保两个区间仍等长

  设两区间原长度均为 $t$。假定 $a<b$：

  | $t$ | 保留 $A$ 的区间 | 保留 $B$ 的区间 | 新长度 |
  | --- | --- | --- | --- |
  | 奇数 $2r+1$ | `[m1,r1]` | `[l2,m2]` | $r+1$ |
  | 偶数 $2r$ | `[m1+1,r1]` | `[l2,m2]` | $r$ |

  若 $a>b$，交换 A、B 的处理方向即可。**奇数长度时保留两个中点，偶数长度时须让两区间同时减半。**

  </Step>
</Steps>

### C 语言实现

```c title="两等长升序数组的下中位数" lineNumbers
int LowerMedian(const int A[], const int B[], int n) {
    // 前提：n >= 1；A、B 均非降序
    int l1 = 0, r1 = n - 1;
    int l2 = 0, r2 = n - 1;

    while (l1 < r1) {
        int t = r1 - l1 + 1;
        int m1 = l1 + (t - 1) / 2;
        int m2 = l2 + (t - 1) / 2;

        if (A[m1] == B[m2]) return A[m1];

        if (A[m1] < B[m2]) {
            l1 = (t & 1) ? m1 : m1 + 1;
            r2 = m2;
        } else {
            r1 = m1;
            l2 = (t & 1) ? m2 : m2 + 1;
        }
    }
    return A[l1] < B[l2] ? A[l1] : B[l2];
}
```

### 样例跟踪

对 `A=[1,3,5,7,9]`、`B=[2,4,6,8,10]`：

| 轮次 | A 当前区间 | B 当前区间 | 中点比较 |
| --- | --- | --- | --- |
| 1 | `[1,3,5,7,9]` | `[2,4,6,8,10]` | $5<6$ |
| 2 | `[5,7,9]` | `[2,4,6]` | $7>4$ |
| 3 | `[5,7]` | `[4,6]` | $5>4$ |
| 4 | `[5]` | `[6]` | 返回 $\min(5,6)=5$ |

### 正确性说明与效率

<Tabs items={['折半不变量证明', '线性归并法对照']} defaultIndex={0}>
  <Tab value="折半不变量证明">

  每轮两侧保留的区间等长，目标始终是这些候选元素的下中位数。当 $a<b$ 时，A 的低端与 B 的高端可以等量配对剔除：被删的偏小元素不可能位于新候选集的右中位位置，被删的偏大元素也不可能位于左中位位置；对称情况同理。若 $a=b$，该值恰好位于两段数据的中间秩，可直接返回。

  当剩余长度为 1 时，两个候选元素的下中位数就是二者较小者，因此算法结束并得到正确答案。

  每轮区间长度至少近似减半，故 $T(n)=T(\lceil n/2\rceil)+O(1)=O(\log n)$；只用 6 个下标及比较变量，额外空间 $O(1)$。

  </Tab>
  <Tab value="线性归并法对照">

  不使用额外合并数组也可以得到正确答案：维护 `i,j` 两个下标，每次取两序列的较小者，连续取出 $n$ 个元素，第 $n$ 个即为目标。

  ```c
  int LowerMedianLinear(const int A[], const int B[], int n) {
      int i = 0, j = 0, ans = 0;
      for (int count = 0; count < n; ++count) {
          if (i == n) ans = B[j++];
          else if (j == n) ans = A[i++];
          else if (A[i] <= B[j]) ans = A[i++];
          else ans = B[j++];
      }
      return ans;
  }
  ```

  线性归并算法时间 $O(n)$、空间 $O(1)$，容易编写，也适用于顺序流读取；但对能够随机访问的两个等长有序数组，**对数时间的折半算法更优**。

  </Tab>
</Tabs>

<Callout type="warn" title="高频失分点">

- 题目定义的是**下中位数**，不能求两个序列各自中位数的平均值。
- 两个候选区间需要始终保持等长，奇偶长度必须分支处理。
- 含重复值时比较可直接使用 `==` 返回；不能假定元素互不相同。
- 当 $n=1$ 时循环不会执行，应返回两个唯一元素中较小者。

</Callout>

### 原创强化训练 1 · 不等长数组的第 $k$ 小

<Question
  id="408-ds-large-2011-42-ext1"
  type="essay"
  tags="来源:原创强化训练, 科目:数据结构, 章节:线性表, 考点:有序数组第k小, 难度:较难"
>

给定两个分别非降序排列的数组 `A[0..m-1]` 和 `B[0..n-1]`，**长度允许不等，也允许一个数组为空**，但 $m+n\ge1$。给定 $1\le k\le m+n$，求将两个数组合并并排序后的**第 $k$ 小元素**，重复元素按出现次数计入排名。

1. 不允许构造完整合并数组。
2. 设计最坏时间 $O(\log k)$、额外空间 $O(1)$ 的迭代算法。
3. 在 `A=[1,2,2,7,9,11]`、`B=[2,2,3,4,8,10]` 上分别求第 6 小和第 7 小，并解释为什么相等元素不影响算法正确性。

<Solution>

### 参考答案

**每次用两个数组当前的第 $\lfloor k/2\rfloor$ 个候选值比较，安全删除其中一个数组的前缀，同时减小目标排名 $k$。**若数组某侧剩余不足 $\lfloor k/2\rfloor$ 个元素，则用该侧剩余长度作为比较步长。

```c title="两个有序数组第 k 小（迭代版）" lineNumbers
int KthOfTwoSorted(const int A[], int m,
                   const int B[], int n, int k) {
    // 前提：m,n >= 0；m+n >= 1；1 <= k <= m+n
    int i = 0, j = 0;

    while (1) {
        if (i == m) return B[j + k - 1];
        if (j == n) return A[i + k - 1];
        if (k == 1) return A[i] < B[j] ? A[i] : B[j];

        int half = k / 2;
        int pa = half < m - i ? half : m - i;
        int pb = half < n - j ? half : n - j;

        if (A[i + pa - 1] <= B[j + pb - 1]) {
            i += pa;
            k -= pa;
        } else {
            j += pb;
            k -= pb;
        }
    }
}
```

### 核心正确性证明

设比较端点为 $a=A[i+p_a-1]$、$b=B[j+p_b-1]$。若 $a\le b$，则当前 A 的前 $p_a$ 个元素都不大于 $a$。对其中任一元素而言，排在其前面或与其相等、且被纳入稳定排序前缀的候选元素至多与 A 的前 $p_a$ 个及 B 的前 $p_b-1$ 个有关，合计少于 $k$ 个，因为 $p_a,p_b\le\lfloor k/2\rfloor$。因此这一段 A 的前缀绝不包含当前第 $k$ 小的最终候选位置，可以删除并将 $k$ 减少 $p_a$。$a>b$ 时对称处理 B。

相等元素只会造成两种合法的删除方向之一；由于保留的是**多重序列的排名**，并不会漏算重复出现的值。

- 样例第 6 小为 **3**，第 7 小为 **4**。
- 每轮在未耗尽数组时删除正数量的前缀，目标规模大致减半，最坏 $O(\log k)$ 轮；常数个下标，空间 $O(1)$。

<Callout type="idea" title="与原题关系">

原题是本题的特例：令 $m=n$ 且 $k=n$，即可求题目定义的两个等长升序数组的中位数。**从「中位数」抽象到「第 $k$ 小」通常更便于推广。**

</Callout>

</Solution>
</Question>

### 原创预测训练 2 · 循环有序数组与中位数

<Question
  id="408-ds-large-2011-42-ext2"
  type="essay"
  tags="来源:原创预测训练, 科目:数据结构, 章节:线性表, 考点:旋转数组二分, 难度:拔高"
>

给定两个长度均为 $n\ge1$ 的数组 `A`、`B`。每个数组最初分别是**严格递增**的整数序列，随后各自循环左移了未知次数，因此目前数组不一定整体有序，但都属于某个严格递增序列的旋转形式。

1. 在不修改原数组的前提下，设计最坏时间 $O(\log n)$、额外空间 $O(1)$ 的算法，求两个数组全部 $2n$ 个元素的**下中位数**。
2. 解释为什么对每个数组先找旋转断点、再进行逻辑下标访问，就能复用原题算法。
3. 对 `A=[5,7,1,3]`、`B=[4,6,8,2]` 求结果。若允许数组内部大量重复，说明同样的断点搜索算法为何不能保证最坏 $O(\log n)$。

<Solution>

### 参考答案

对严格递增旋转数组，最小元素所在下标即为**逻辑有序序列的起点** `pivot`。先用二分法分别求出两个 `pivot`，再用

$$
\mathrm{Get}(X,p,i)=X[(p+i)\bmod n]
$$

按逻辑升序下标读取元素。随后完全复用原题的**等长区间折半**过程。

```c title="旋转有序数组的下中位数" lineNumbers
// 前提：X 是长度 n>=1 的严格递增数组的循环旋转
static int FindPivot(const int X[], int n) {
    int l = 0, r = n - 1;
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (X[mid] > X[r]) l = mid + 1;
        else r = mid; // 严格递增保证此处不会出现等值歧义
    }
    return l;
}

static int Get(const int X[], int n, int pivot, int i) {
    // i、pivot 均在 [0,n-1]：避免直接 int 加法溢出
    int remaining = n - pivot;
    return X[i < remaining ? pivot + i : i - remaining];
}

int LowerMedianRotated(const int A[], const int B[], int n) {
    int pa = FindPivot(A, n), pb = FindPivot(B, n);
    int l1 = 0, r1 = n - 1, l2 = 0, r2 = n - 1;

    while (l1 < r1) {
        int t = r1 - l1 + 1;
        int m1 = l1 + (t - 1) / 2;
        int m2 = l2 + (t - 1) / 2;
        int a = Get(A, n, pa, m1);
        int b = Get(B, n, pb, m2);

        if (a == b) return a;
        if (a < b) {
            l1 = (t & 1) ? m1 : m1 + 1;
            r2 = m2;
        } else {
            r1 = m1;
            l2 = (t & 1) ? m2 : m2 + 1;
        }
    }
    int a = Get(A, n, pa, l1);
    int b = Get(B, n, pb, l2);
    return a < b ? a : b;
}
```

### 为什么正确

1. 若 `X[mid] > X[r]`，严格递增的后缀断点必在 `mid` 右侧；否则最小值在 `[l,mid]`。因此可二分出最小值位置。
2. 从最小值开始按模 $n$ 访问，得到原本的严格递增顺序；这仅改变**访问方式**，并未修改数组。
3. 在两个逻辑有序数组上应用 2011 年真题的折半不变量，因此最终所得仍是第 $n$ 小元素。

样例对应的逻辑升序序列分别为 `[1,3,5,7]` 与 `[2,4,6,8]`，合并下中位数为 **4**。

两个断点搜索各 $O(\log n)$，求下中位数再 $O(\log n)$，总时间 $O(\log n)$，额外空间 $O(1)$。

<Callout type="warn" title="边界：重复值会破坏严格折半">

若内部元素允许大量重复，遇到 `X[mid]==X[r]` 时不能确定断点在哪一侧，通常只能缩小一个端点，最坏可能退化为 $O(n)$。因此本题的**严格递增条件是时间上界的重要前提**。

</Callout>

</Solution>
</Question>

## 2012 年第 42 题

<Question
  id="408-ds-large-2012-42"
  type="essay"
  tags="来源:2012考研408, 科目:数据结构, 章节:线性表, 考点:单链表相交, 难度:中等"
>

假定采用**带头结点**的单链表保存单词。当两个单词有相同后缀时，可以共享相同的后缀存储空间。例如 `loading` 与 `being` 的存储映像如下图所示。

<img src="/img/408/past-exams-large-questions/01-数据结构/assets/2012-42-figure-001.svg" alt="2012 年第 42 题共享后缀示意" />

设 `str1`、`str2` 分别指向两个单词所在单链表的头结点，结点结构为 `| data | next |`。设计一个时间上尽可能高效的算法，找出两个链表**公共后缀的起始结点**（图中字符 `i` 所在的结点 $p$）。

要求：

1. 给出算法的基本设计思想。
2. 用 C、C++ 或 Java 描述算法。
3. 说明时间复杂度。

<Solution>

### 参考答案

**分别求两条单链表的数据结点数，将较长链表的指针先推进两表长度之差，再让两个指针同步前进。首次出现 `p == q` 的结点就是公共后缀起点；如果最终均为 `NULL`，则不存在公共结点。**

设两表长度分别为 $m,n$，总时间 $O(m+n)$，额外空间 $O(1)$。

<Callout type="info" title="先理解：公共后缀不是字符相同">

图示中「共享」指**物理上是同一个结点**，即两个指针的地址相同，不是两个不同结点恰好存放相同字符。比较应写 `p == q`，**不能写 `p->data == q->data`**。无环单链表一旦在某个结点相交，后续都沿该结点唯一的 `next` 指针前进，故其后必是完全相同的结点链。

</Callout>

### 设计思想：对齐距表尾的剩余长度

<Steps>
  <Step>

  ### 第一步：分别计算两个表的实际长度

  从 `str1->next` 和 `str2->next` 开始，分别统计数据结点数 $m$、$n$。**头结点不计入长度**。

  </Step>
  <Step>

  ### 第二步：让长链先走长度差

  令 `p=str1->next`，`q=str2->next`。若 $m>n$，`p` 先移动 $m-n$ 次；若 $n>m$，`q` 先移动 $n-m$ 次。

  此时两个指针距各自表尾的**剩余结点数相同**。假设公共后缀长为 $c$，两表独有部分分别长 $m-c,n-c$，对齐操作恰好消除独有部分的长度差。

  </Step>
  <Step>

  ### 第三步：同步扫描，首次相同即返回

  让 `p`、`q` 每轮都向后移动一条边。两者第一次指向同一个非空结点时，正好抵达公共后缀起点；若全程不相同，就在同一轮到达 `NULL`。

  </Step>
</Steps>

```c title="2012-42：公共后缀的首结点" lineNumbers
#include <stddef.h>

typedef struct Node {
    char data;
    struct Node *next;
} Node;

static size_t ListLength(const Node *head) {
    size_t len = 0;
    if (head == NULL) return 0;
    for (const Node *p = head->next; p != NULL; p = p->next)
        ++len;
    return len;
}

Node *CommonSuffix(Node *str1, Node *str2) {
    if (str1 == NULL || str2 == NULL) return NULL;

    size_t m = ListLength(str1);
    size_t n = ListLength(str2);
    Node *p = str1->next, *q = str2->next;

    // 长链先走；移动后两个指针距末尾的结点数相等
    while (m > n) { p = p->next; --m; }
    while (n > m) { q = q->next; --n; }

    while (p != q) {
        p = p->next;
        q = q->next;
    }
    return p;  // 相交：公共起点；不相交：二者均为 NULL
}
```

### 正确性证明

设公共后缀包含 $c$ 个结点，其首结点为 $s$。对齐后，两个指针到各自链尾所剩的结点数相等，故它们到 $s$ 的距离也相等：两表从对齐位置起都需前进同样步数才能进入共有的 $c$ 个结点。**进入 $s$ 之前不可能指针相等**，否则会出现更早的公共结点，与「首结点」矛盾；到达 $s$ 时必然相等，所以首次相等者就是所求。

若不存在公共结点，则全部非空结点的指针地址互不相同；两条对齐的链同时到达 `NULL`，循环正常退出并返回 `NULL`。算法对无交点情况也能终止。

### 复杂度分析

- 两次求长共访问 $m+n$ 个结点。
- 对齐阶段至多前移 $|m-n|$ 步；同步阶段至多 $\min(m,n)$ 步。合计 $O(m+n)$。
- 长度计数器、游标等均为常数个，额外空间 $O(1)$。

<Tabs items={['长度差法（真题推荐）', '不显式求长度的换头法']} defaultIndex={0}>
  <Tab value="长度差法（真题推荐）">

  **适用：**给出带头结点的两条无环单链表，要求描述清晰且容易证明。

  核心不变量是：对齐后，两指针始终拥有**相同的剩余长度**；同步扫描到相同地址即返回。主代码直接实现该算法。

  </Tab>
  <Tab value="不显式求长度的换头法">

  **另一种同样满足最优复杂度的算法：**两个指针到达 `NULL` 时交换到对方链表的首元结点。分别走过路径 A→B 和 B→A 后，两条路径长度均为 $m+n$，自然抵消长度差。

  ```c
  Node *CommonSuffixSwitch(Node *str1, Node *str2) {
      if (str1 == NULL || str2 == NULL) return NULL;
      Node *a = str1->next, *b = str2->next;
      Node *p = a, *q = b;
      while (p != q) {
          p = (p == NULL) ? b : p->next;
          q = (q == NULL) ? a : q->next;
      }
      return p;
  }
  ```

  该算法不必预先计数，仍为 $O(m+n)$ 时间、$O(1)$ 额外空间。要注意 `while (p != q)`，不能改成 `while (p && q)`，否则可能提前结束。

  </Tab>
</Tabs>

<Callout type="warn" title="边界与内存所有权">

- 只有一个链表含数据时，不可能存在公共后缀，应返回 `NULL`。
- 两条链可能**从首元结点就共用整个数据链**，此时直接返回首元结点。
- 图示存储结构是**共享结点**；销毁链表时不能把公共后缀分别释放两次，否则会发生重复释放或悬空指针问题。
- 本算法以两表**均无环**为前提，含环时求长度可能无法终止。

</Callout>

</Solution>

### 原创强化训练 1 · 无长度计数器的首个交点

<Question
  id="408-ds-large-2012-42-ext1"
  type="essay"
  tags="来源:原创强化训练, 科目:数据结构, 章节:线性表, 考点:双指针换头, 难度:中等"
>

给定两条**不带头结点、无环**的单链表 `a`、`b`，可能共享尾部结点。禁止遍历求长度，也不允许使用长度计数器或辅助集合。要求在时间 $O(m+n)$、额外空间 $O(1)$ 内返回第一个共有结点。

1. 给出 C 语言函数。
2. 证明两个指针交换起点后，为什么可以消除链长差。
3. 当两表完全不相交或其中一表为空时，解释算法能否正常退出。

<Solution>

### 参考答案

令 `p` 从 `a` 出发，走到空后转到 `b`；`q` 从 `b` 出发，走到空后转到 `a`。首次满足 `p == q` 时退出，并返回该结点（可能为 `NULL`）。

```c title="两条路径交换起点"
Node *FirstIntersection(Node *a, Node *b) {
    Node *p = a, *q = b;
    while (p != q) {
        p = (p == NULL) ? b : p->next;
        q = (q == NULL) ? a : q->next;
    }
    return p;
}
```

此处 `Node` 沿用 2012 年真题的结点结构。

### 路径长度证明

令两链独有的前缀长度分别为 $u,v$，公共后缀长度为 $c$，则 $m=u+c$，$n=v+c$。若有公共结点，则：

- `p` 沿第一链走到公共起点所花的距离是 $u$；在一次换头以后，经过对方独有前缀最终到达公共起点。两条游标因走完 A、B 两段长度相同，最迟在累计 $m+n-c+1$ 次指针更新时相遇（包含指针经过 `NULL` 后切换起点的那一步）。
- `q` 沿 B→A 方向行走，同样最迟在该时刻到达公共起点。

更容易记忆的事实是：**两指针分别经历 A→B、B→A 两段等长路径**。若确实相交，相遇位置是公共尾部第一个结点；若不相交，在最多 $m+n+1$ 次指针更新后，两指针都成为 `NULL`，同样退出。

<Callout type="idea" title="常见误解">

「两个指针一轮中必然分别在两个链表」不是不变量。真正有用的是：**走过 A、B 两条完整路径时累计距离相等**。代码也不能写成每轮 `p = p->next`、`q = q->next` 而不给空指针换头。

</Callout>

时间 $O(m+n)$；额外空间 $O(1)$。输入任一表为空时，在有限次移动后两指针均为 `NULL`。

</Solution>
</Question>

### 原创预测训练 2 · 三条单链表的公共后缀

<Question
  id="408-ds-large-2012-42-ext2"
  type="essay"
  tags="来源:原创预测训练, 科目:数据结构, 章节:线性表, 考点:多链表求交, 难度:较难"
>

现有三条**带头结点、无环**的单链表 `A`、`B`、`C`，其中一些结点可能被多条链共同使用；共有结点指的是**指针地址相同**。

1. 求三条链**同时共有**的后缀中第一个结点，设计最坏时间 $O(|A|+|B|+|C|)$、额外空间 $O(1)$ 的算法。
2. 说明能否先求 A、B 的公共首结点，再与 C 求交。
3. 论证「A 与 B 相交、B 与 C 相交，但三者没有共同结点」在此题设下是否可能。

<Solution>

### 参考答案

**可以分两步求交。**先求 A、B 的首个公共结点 `p`。若 `p==NULL`，三者不可能有公共结点；否则以 `p` 为首元结点的**共享后缀**与 C 再求交，第二次结果就是三条链的公共起点。

```c title="复用真题的 CommonSuffix"
Node *CommonSuffix3(Node *A, Node *B, Node *C) {
    if (A == NULL || B == NULL || C == NULL) return NULL;

    Node *p = CommonSuffix(A, B);
    if (p == NULL) return NULL;

    Node temporary = {0, p};  // 栈上临时头结点，不复制任何数据结点
    return CommonSuffix(&temporary, C);
}
```

### 为什么分两步有效

单链表每个结点只有一个后继，因此若 A、B 在 `p` 相交，**从 `p` 开始的整个尾部**必然都同时属于 A 与 B。这时再将该尾部视为一条链，与 C 求其首个公共结点 `q`：从 `q` 开始的结点同时属于 A、B、C，而在 `q` 之前不可能有三者的共同结点。

若三表两两相交，它们的**尾结点地址必须一致**：A 与 B 相交使尾结点相同；B 与 C 相交也使尾结点相同。于是三条链至少共同拥有同一个尾结点，因此「两两有交点却没有三者公共结点」**不可能发生**。

时间：第一次求交不超过 $O(|A|+|B|)$，第二次不超过 $O(|A|+|C|)$；合并后 $O(|A|+|B|+|C|)$，额外空间 $O(1)$。

<Callout type="warn" title="限制条件不能遗漏">

无环是这个结论的关键前提。题目如果允许环，链表的后继结构可以在不同位置进入环，所谓「共同尾结点」不再存在，不能原样套用该证明。

</Callout>

</Solution>
</Question>

## 2013 年第 41 题

<Question
  id="408-ds-large-2013-41"
  type="essay"
  tags="来源:2013考研408, 科目:数据结构, 章节:线性表, 考点:主元素与投票算法, 难度:中等"
>

已知整数序列

$$
A=(a_0,a_1,\ldots,a_{n-1}),
$$

其中

$$
0\le a_i<n\qquad(0\le i<n).
$$

若存在

$$
a_{p_1}=a_{p_2}=\cdots=a_{p_m}=x,
$$

且

$$
m>\frac n2,
$$

则称 $x$ 为 $A$ 的**主元素**。

例如，$A=(0,5,5,3,5,7,5,5)$ 的主元素为 5；而 $A=(0,5,5,3,5,1,5,7)$ 没有主元素。

设计一个尽可能高效的算法：若主元素存在则输出该元素，否则输出 $-1$。

<Solution>

### 参考答案

使用 **Boyer–Moore 多数投票算法**：第一趟扫描进行不同值的「配对抵消」，只留下唯一可能的主元素候选；第二趟统计候选的实际出现次数，只有满足**严格大于 $n/2$** 才返回候选，否则返回 `-1`。

**总时间 $O(n)$，额外空间 $O(1)$**，不需要改变原数组，也不依赖题目给出的 $0\le a_i<n$ 值域。

### 为什么「主元素」可以用抵消法

**主元素不等于出现次数最多的元素。** 众数只要求频次最高，主元素则必须出现超过半数。由于两个不同的数若都超过 $n/2$，其频数之和将超过 $n$，故主元素至多一个。

考虑消去序列中的一对**不同元素**。如果主元素 $x$ 在消除前有 $r$ 次，总长度为 $t$，且 $r>t/2$，则：

- 若抵消对含 $x$，剩余 $r-1$ 次、总长 $t-2$，仍有 $r-1>(t-2)/2$；
- 若抵消对不含 $x$，剩余 $r$ 次、总长 $t-2$，当然仍超过一半。

因此：**只要真主元素存在，任意消去不同元素的一对都不可能把它彻底淘汰。**

### 两趟扫描的具体操作

<Steps>
  <Step>

  ### 第一趟：构造候选值与净票数

  维护 `candidate`（候选值）和 `count`（尚未被抵消的该值票数）：

  - `count==0`：令当前元素成为新候选，`count=1`；
  - 当前值等于候选：`count++`；
  - 当前值不同于候选：`count--`，相当于抵消一对异值。

  扫描后得到的 `candidate` **可能是真主元素，也可能只是最后留下的候选**。

  </Step>
  <Step>

  ### 第二趟：验证候选在原数组中出现的真实次数

  重新扫描原数组，统计 `freq`。仅当

  $$
  \operatorname{freq}(candidate)>\frac n2
  $$

  才能返回 `candidate`；否则说明原序列无主元素，返回 `-1`。

  </Step>
</Steps>

```c title="2013-41：两趟扫描求主元素" lineNumbers
#include <stddef.h>

int MajorityElement(const int A[], int n) {
    if (A == NULL || n <= 0) return -1;

    int candidate = 0, count = 0;
    for (int i = 0; i < n; ++i) {
        if (count == 0) {
            candidate = A[i];
            count = 1;
        } else if (A[i] == candidate) {
            ++count;
        } else {
            --count;
        }
    }

    // 验证是必要步骤：候选未必超过半数
    int freq = 0;
    for (int i = 0; i < n; ++i)
        if (A[i] == candidate) ++freq;

    return (freq > n / 2) ? candidate : -1;
}
```

### 样例跟踪

令 $A=[0,5,5,3,5,7,5,5]$，净票状态如下：

| 已处理元素 | `candidate` | `count` | 原因 |
| --- | ---: | ---: | --- |
| `0` | 0 | 1 | 初始候选 |
| `0,5` | 0 | 0 | 不同值抵消 |
| `…,5` | 5 | 1 | 重新建立候选 |
| `…,3` | 5 | 0 | 不同值抵消 |
| `…,5` | 5 | 1 | 重新建立候选 |
| `…,7` | 5 | 0 | 不同值抵消 |
| `…,5` | 5 | 1 | 重新建立候选 |
| `…,5` | 5 | 2 | 相同值加票 |

第二趟实际得到 `freq=5`，而 $n/2=4$，因此返回 **5**。

对第二个例子 $[0,5,5,3,5,1,5,7]$，值 5 恰好出现 4 次，**$4>4$ 不成立**，必须返回 `-1`。

### 正确性与复杂度

- **不漏报：**每轮抵消最多移除一对不同的值，真主元素始终在未抵消集合中保有多数地位，因此第一趟的候选一定等于真正存在的主元素。
- **不误报：**若原序列无主元素，第一趟仍可能留下候选；第二趟用严格次数阈值过滤，就不会错误输出。
- **时间：**两趟各 $n$ 次，$O(n)$；若不读某个元素，可能无法判定它是否使候选超过半数，因此线性扫描已经是最优量级。
- **空间：**候选、两个计数器共常数个，$O(1)$。

<Tabs items={['多数投票（推荐）', '按题目值域计数']} defaultIndex={0}>
  <Tab value="多数投票（推荐）">

  **优点：**不改数组、不需要值域限制、额外空间严格 $O(1)$。适合考场「时间和空间都尽可能高效」的要求，必须记住**两趟扫描**。

  </Tab>
  <Tab value="按题目值域计数">

  因题目保证 $0\le A[i]<n$，可建立长度 $n$ 的计数数组 `freq[0..n-1]`，用 `freq[A[i]]++` 记录各数出现次数，再找是否存在 `freq[x]>n/2`。

  **优点：**直观，也可顺便得到所有元素的频数；**不足：**初始化与统计需 $O(n)$ 时间，辅助数组额外占 $O(n)$ 空间，不如投票法节省内存。

  </Tab>
</Tabs>

<Callout type="warn" title="不做验证，投票不等于找主元素">

例如 `[1,2,3]`：第一趟最终可能得到候选 3，但 3 只出现一次，不满足 $1>3/2$。要检查的是候选的**真实出现次数**，而不是第一趟抵消后剩余的净票数。阈值必须写 `freq > n/2`，不能写 `>=`。

</Callout>

</Solution>

### 原创强化训练 1 · 频次超过三分之一的全部元素

<Question
  id="408-ds-large-2013-41-ext1"
  type="essay"
  tags="来源:原创强化训练, 科目:数据结构, 章节:线性表, 考点:广义多数投票, 难度:较难"
>

设长度为 $n\ge1$ 的整数数组中，凡出现次数**严格大于 $n/3$** 的值，都称为「三级高频元素」。数值范围不受限制，可包含负数。

1. 证明符合条件的不同元素**最多有两个**。
2. 用 C 语言设计 $O(n)$ 时间、$O(1)$ 额外空间的算法，输出全部三级高频元素（输出顺序不限）。
3. 对 `A=[1,2,1,3,2,1,2,4]` 给出结果。解释为何仍需要二次验证。

<Solution>

### 参考答案

**最多两个不同的答案**。维护两个候选值、两个净票数；若当前元素与两个候选都不同，而且两票槽均非空，则抵消三种不同元素各一个。第一趟得到至多两个候选，第二趟重新计数，按 `freq>n/3` 验证。

### 为什么最多两个

假定存在三个不同值，其频数都严格大于 $n/3$，那么这三个值的出现次数之和严格大于 $n$，与全数组只有 $n$ 个元素矛盾。

这提示我们：候选槽无需超过两个，也不能只保留一个。

```c title="输出全部频次 > n/3 的元素" lineNumbers
// out 至少有两个 int 单元；返回实际写入的元素个数
int MoreThanThird(const int A[], int n, int out[2]) {
    if (A == NULL || out == NULL || n <= 0) return 0;
    int v1 = 0, v2 = 0, c1 = 0, c2 = 0;

    // 第一趟：两候选 / 三种不同值共同抵消
    for (int i = 0; i < n; ++i) {
        int x = A[i];
        if (c1 > 0 && x == v1) ++c1;
        else if (c2 > 0 && x == v2) ++c2;
        else if (c1 == 0) { v1 = x; c1 = 1; }
        else if (c2 == 0) { v2 = x; c2 = 1; }
        else { --c1; --c2; }
    }

    // 第二趟：只给仍有效的候选统计真实频数
    int f1 = 0, f2 = 0;
    for (int i = 0; i < n; ++i) {
        if (c1 > 0 && A[i] == v1) ++f1;
        else if (c2 > 0 && A[i] == v2) ++f2;
    }

    int ans = 0;
    if (c1 > 0 && f1 > n / 3) out[ans++] = v1;
    if (c2 > 0 && f2 > n / 3) out[ans++] = v2;
    return ans;
}
```

### 正确性分析

抵消操作相当于从尚未淘汰的元素中删除三个互不相同的值。设某值原本出现 $r>n/3$ 次，每次三元抵消至多删去它一次，而总长度减三；它仍保持「超过剩余长度三分之一」的性质。因此，真正满足条件的数不可能因抵消而完全消失；第一次扫描结束时必占据某个候选槽。

**第二趟为什么需要：**比如 `[1,2,3,4]` 的残留候选可能根本不满足频次严格大于 $4/3$；与普通多数投票一样，抵消只保证**不漏真答案**，不能保证剩余值都是真答案。

样例中 1 和 2 各出现 3 次，$3>8/3$，最终输出 **1、2**。两趟均 $O(n)$，只占用常数个候选和计数器，额外空间 $O(1)$。

<Callout type="warn" title="容易写错的比较顺序">

必须**先判断是否匹配已占用候选槽，再尝试填空位**。否则当一个槽空、另一个槽恰好包含当前值时，可能产生重复候选；第二趟还必须避免把相同候选的频数重复计算。

</Callout>

</Solution>

### 原创预测训练 2 · 可分块处理的主元素判定

<Question
  id="408-ds-large-2013-41-ext2"
  type="essay"
  tags="来源:原创预测训练, 科目:数据结构, 章节:线性表, 考点:投票状态合并, 难度:拔高"
>

长整数序列被拆成相邻的 $t$ 个**非空连续块**。每一块可以独立顺序读取，但不能把所有数据重新存进一个大数组。每块均可输出一对摘要 `(candidate, votes)`：按普通多数投票规则做异值配对抵消后，剩余 `votes` 个相同候选（可以为 0）。已知所有块的总元素数为 $N$，仍允许第二遍从原始块读取全部元素。

1. 设计两个摘要 `(c1,v1)`、`(c2,v2)` 的合并规则，使合并后仍得到一个合法的**主元素候选摘要**。
2. 证明若全局存在出现次数严格超过 $N/2$ 的值，则合并所有块的摘要后，它一定仍是候选。
3. 编写合并两个摘要的 C 函数，并说明最终验证与总时间复杂度。对块 `A=[5,2,5,3]`、`B=[5,4,5,5]` 给出结果。

<Solution>

### 参考答案

将每块的状态视为其「剩余若干同值元素」的压缩表示：

- 任一摘要票数为 0，则直接返回另一摘要。
- 若两摘要候选相同，则票数相加。
- 若候选不同，则两边的票数相互抵消，只保留票数较大一边及其差值；相等时返回零票状态。

合并所有块后得到一个**可能的全局主元素候选**，还必须完整读取所有块进行第二趟验证，检查真实频数是否严格大于 $N/2$。

```c title="投票摘要的两两合并" lineNumbers
typedef struct VoteState {
    int candidate;
    long long votes;  // 0 表示没有有效候选
} VoteState;

VoteState MergeVote(VoteState a, VoteState b) {
    if (a.votes == 0) return b;
    if (b.votes == 0) return a;
    if (a.candidate == b.candidate)
        return (VoteState){a.candidate, a.votes + b.votes};
    if (a.votes > b.votes)
        return (VoteState){a.candidate, a.votes - b.votes};
    if (b.votes > a.votes)
        return (VoteState){b.candidate, b.votes - a.votes};
    return (VoteState){0, 0};
}
```

### 推导过程

1. **局部摘要含义：**一块序列经过若干次异值配对删除后，剩余的都是同一个候选值。原块中删去的都是「不同值配对」，不会抹掉任何真实超过半数的主元素。
2. **块摘要再合并：**拼接剩余元素以后继续做异值配对删除，等价于对原序列执行了更多合法的抵消操作。若全局真主元素存在，按原题证明它始终占剩余元素的多数，因此不可能被彻底删除。
3. **第二趟验证：**若全局没有主元素，合并结果仍可能给出一个候选；必须统计全局真实次数，再决定是否输出。

样例拼接后 `5` 一共出现 5 次，$N=8$，满足 $5>4$，所以答案是 **5**。

若所有块总长为 $N$：局部投票总计 $O(N)$，合并 $t$ 个状态 $O(t)$，全局核验再 $O(N)$；因每块非空，$t\le N$，故总时间 **$O(N)$**。若每块的摘要可边生成边合并且允许第二遍读原块，最终仅保存一个合并摘要和计数，**额外空间 $O(1)$**；若先收集全部 $t$ 个摘要再合并，则额外空间为 $O(t)$。

<Callout type="idea" title="为什么这一题有预测价值">

它考查的不是死记投票模板，而是**证明「不同值抵消」这一操作在分块处理后仍保留真正的主元素**。注意合并结果本身不是最终答案，仍要完成跨全部块的第二遍频数验证。

</Callout>

</Solution>

## 2015 年第 41 题

<Question
  id="408-ds-large-2015-41"
  type="essay"
  tags="来源:2015考研408, 科目:数据结构, 章节:线性表, 考点:链表去重, 难度:中等"
>

用单链表保存 $m$ 个整数，结点含 `data` 域和指针域，并满足

$$
|data|\le n,
$$

其中 $n$ 为正整数。

现要求设计一个时间复杂度尽可能高效的算法：对于链表中 `data` 的**绝对值相等**的结点，仅保留第一次出现的结点，删除其余绝对值相等的结点。

例如：

<img src="/img/408/past-exams-large-questions/01-数据结构/assets/2015-41-figure-001.svg" alt="2015 年第 41 题原单链表示意图" />

处理后为：

<img src="/img/408/past-exams-large-questions/01-数据结构/assets/2015-41-figure-002.svg" alt="2015 年第 41 题删除重复绝对值后的链表" />

要求：

1. 给出算法的基本设计思想。
2. 给出单链表结点的数据类型定义。
3. 用 C 或 C++ 描述算法。
4. 说明时间复杂度和空间复杂度。

<Solution>

### 参考答案

**建立按绝对值直接索引的标记表 `seen[0..n]`，从前向后遍历链表；某绝对值第一次出现时将其标记并保留当前结点，再次出现时直接摘链删除。**

- 链表遍历与摘链总计 $O(m)$；如果把标记数组的初始化时间也计入，总运行时间为 $O(m+n)$。
- 额外空间 $O(n)$。
- 保留的是**第一次出现的原结点**，不改变存活结点的原有相对顺序。

### 核心设计与不变量

<Steps>
  <Step>

  ### 第一步：将「按绝对值去重」变为直接寻址

  因为题目保证 $|data|\le n$，所有需要区分的类别只有 $0,1,\ldots,n$。分配并清零 `n+1` 个标记位：

  $$
  seen[x]=\begin{cases}
  1,&\text{绝对值为 }x\text{ 的结点已经保留过};\\
  0,&\text{尚未出现}.
  \end{cases}
  $$

  如 `3` 与 `-3` 都映射到同一个下标 3；`0` 单独占用下标 0。

  </Step>
  <Step>

  ### 第二步：同时维护前驱和待处理结点

  令 `pre` 指向**已保留链表尾部**，`cur` 指向下一个尚未处理的结点。若 `seen[abs(cur->data)]==0`，保留 `cur`、标记该值，再将两个指针一起向后移动。

  若已标记，则先把 `cur` 从链表摘除：

  ```c
  LNode *victim = cur;
  pre->link = cur->link;
  cur = pre->link;
  free(victim);
  ```

  **删除分支里 `pre` 一定不能向后移动。**例如序列 `[2,-2,-2]` 连续出现重复值时，`pre` 必须一直指向第一次出现的 2，才能删净其后的两个结点。

  </Step>
  <Step>

  ### 第三步：扫描结束，释放辅助数组

  标记表随扫描维护「每类绝对值是否已保留一个结点」的信息。当 `cur==NULL`，所有结点都已处理，最后释放标记数组。

  </Step>
</Steps>

### C 语言实现

下面按**带头结点**的常见数据结构教材约定编写；原题给出的单链表未强调是否带头结点，实现时必须先声明假设。结点由动态内存管理，删除时使用 `free`，并约定链表结点的释放所有权归当前程序。

```c title="2015-41：按绝对值保留首次出现的结点" lineNumbers
#include <stdlib.h>

typedef struct LNode {
    int data;
    struct LNode *link;
} LNode;

// 成功返回 1；非法参数或内存分配失败返回 0
int DeleteEqualAbsolute(LNode *head, int n) {
    if (head == NULL || n <= 0) return 0;
    if (head->link == NULL) return 1;

    // 前提：每个数据结点都满足 |data| <= n
    unsigned char *seen = (unsigned char *)calloc((size_t)n + 1, 1);
    if (seen == NULL) return 0; // 尚未更改链表

    LNode *pre = head;
    LNode *cur = head->link;
    while (cur != NULL) {
        int value = cur->data;
        int key = value < 0 ? -value : value;
        if (seen[key] == 0) {
            seen[key] = 1;
            pre = cur;          // 当前结点被保留
            cur = cur->link;
        } else {
            LNode *victim = cur;
            pre->link = cur->link;
            cur = pre->link;    // 删除时前驱保持不动
            free(victim);
        }
    }

    free(seen);
    return 1;
}
```

### 示例演算

以链表 `[-2,3,2,-3,4,2,0,0]` 为例，依次处理：

| 当前值 | 绝对值 | 标记状态 | 操作 | 已保留前缀 |
| ---: | ---: | --- | --- | --- |
| $-2$ | 2 | 未标记 | 保留、标记 2 | `[-2]` |
| 3 | 3 | 未标记 | 保留、标记 3 | `[-2,3]` |
| 2 | 2 | 已标记 | 删除 | `[-2,3]` |
| $-3$ | 3 | 已标记 | 删除 | `[-2,3]` |
| 4 | 4 | 未标记 | 保留、标记 4 | `[-2,3,4]` |
| 2 | 2 | 已标记 | 删除 | `[-2,3,4]` |
| 0 | 0 | 未标记 | 保留、标记 0 | `[-2,3,4,0]` |
| 0 | 0 | 已标记 | 删除 | `[-2,3,4,0]` |

最终得到 `[-2,3,4,0]`。特别注意：**保留的是先出现的 `-2`，并不是按照「正数优先」规则保留后面的 2。**

### 正确性证明

设扫描完原链表前 $i$ 个结点后满足不变量：

1. 已保留前缀中的每种绝对值最多出现一次，且必是原链表中第一次出现的那个原结点。
2. `seen[x]==1` 当且仅当当前已处理前缀里存在绝对值为 $x$ 的元素。
3. `pre` 指向已保留前缀的尾结点，`cur` 指向紧随其后的待处理结点。

初始时已处理前缀为空，标记表全为 0，不变量成立。若 `cur` 对应的类别尚未出现，保留并标记，不变量继续成立；若已出现，删除该结点而保留原先的首个结点，同样成立。每轮恰好处理一个原始结点，所以最终结论成立。

### 时间与空间：把初始化成本说清楚

设链表数据结点数为 $m$，合法绝对值上界为 $n$：

| 过程 | 时间开销 | 说明 |
| --- | --- | --- |
| 分配并清零 `seen[0..n]` | $O(n)$ | `calloc` 初始化 $n+1$ 个字节 |
| 遍历与删除全部 $m$ 个结点 | $O(m)$ | 每个原结点只处理一次 |
| 总时间 | $O(m+n)$ | 严格计入初始化 |
| 额外空间 | $O(n)$ | `seen` 长度为 $n+1$ |

若仅讨论链表扫描，常简写为 $O(m)$；但**不能在 $n\gg m$ 时无条件忽略初始化的 $O(n)$**。如果值域特别大，散列表方案期望可在 $O(m)$ 时间内处理，但需要额外哈希结构，且最坏时间受哈希实现影响。

<Callout type="warn" title="严禁的几个错误">

- **不能使用 `seen[abs(data)-1]`**：绝对值允许为 0，直接寻址应该采用 `seen[abs(data)]`，数组大小应为 $n+1$。
- 不能排序链表或用覆盖数据的方式改变前后关系：题目要求保留第一次出现的**实际结点**。
- 删除后不移动 `pre`，否则会遗漏相邻重复结点。
- `abs(INT_MIN)` 在普通 `int` 上存在溢出风险；本题给出 $|data|\le n$ 且 $n$ 是可表示的正 `int`，合法数据不可能为 `INT_MIN`。若取消值域限制，应改用足够宽的有符号类型后再求绝对值。

</Callout>

</Solution>

### 原创强化训练 1 · 只保留绝对值最后一次出现的结点

<Question
  id="408-ds-large-2015-41-ext1"
  type="essay"
  tags="来源:原创强化训练, 科目:数据结构, 章节:线性表, 考点:频次数组与摘链, 难度:较难"
>

仍有一个带头结点的单链表，数据满足 $|data|\le n$。现要求每种绝对值只保留**最后一次出现的原结点**，其他结点全部删除，且保留下来的结点必须维持在原链表中的相对顺序。

1. 不允许新建数据结点，也不允许通过改变 `data` 域来伪装保留结点。
2. **禁止逆置链表**，改用两次正向扫描求解。
3. 给出 C 代码，分析时间、空间，并对 `[-2,3,2,-3,4,2]` 写出最终序列。

<Solution>

### 参考答案

使用**频次数组** `freq[0..n]`：第一趟统计每个绝对值在链表中的总出现次数；第二趟按原顺序扫描，每遇到某类就先 `freq[key]--`。如果减后还大于 0，说明后面仍有该类结点，当前不是最后一次，应删除；如果减后为 0，说明这是最后一次，必须保留。

```c title="禁止逆置时的保留最后一次出现" lineNumbers
#include <stdlib.h>

int KeepLastAbsolute(LNode *head, int n) {
    if (head == NULL || n <= 0) return 0;
    if (head->link == NULL) return 1;

    // calloc 对 n+1 个 int 元素做初始化
    size_t *freq = (size_t *)calloc((size_t)n + 1, sizeof(size_t));
    if (freq == NULL) return 0;

    for (LNode *p = head->link; p != NULL; p = p->link) {
        int x = p->data;
        int key = x < 0 ? -x : x;
        ++freq[key];
    }

    LNode *pre = head;
    LNode *cur = head->link;
    while (cur != NULL) {
        int x = cur->data;
        int key = x < 0 ? -x : x;
        --freq[key];
        if (freq[key] == 0) {
            pre = cur;       // 该类最后一次出现，保留
            cur = cur->link;
        } else {
            LNode *victim = cur;
            pre->link = cur->link;
            cur = pre->link;
            free(victim);
        }
    }

    free(freq);
    return 1;
}
```

### 为什么不会误删最后一个

第一趟结束后 `freq[x]` 等于绝对值为 $x$ 的**全部原结点个数**。第二趟扫描到某个类别 $x$ 时，每处理一个都减 1，因此减后值就是**该结点之后尚未扫描到的同类结点数量**。只有它大于 0 时才能安全删除当前结点；减至 0 的时刻，当前结点恰好是原链表中这一类别的最后一次出现。

样例绝对值 2 出现 3 次、3 出现 2 次、4 出现 1 次。最终保留的是原链表中的第 4、5、6 个结点，结果为 **`[-3,4,2]`**。

两趟正向扫描用时 $O(m)$，频次数组初始化花费 $O(n)$，总时间 **$O(m+n)$**，空间 **$O(n)$**；直接摘链保留原结点次序。

<Callout type="idea" title="和原题的对比">

**保留第一次：**记录「是否见过」，遇到第一次保留；**保留最后一次：**记录「后面是否还剩」，剩余为 0 才保留。算法框架相同，维护的信息不同。

</Callout>

</Solution>
</Question>

### 原创预测训练 2 · 无已知值域且禁止辅助存储

<Question
  id="408-ds-large-2015-41-ext2"
  type="essay"
  tags="来源:原创预测训练, 科目:数据结构, 章节:线性表, 考点:常数空间去重, 难度:较难"
>

一个带头结点的单链表保存 $m$ 个整数，现**不再提供绝对值上界**，并禁止创建任何数组、散列表、排序结构或新数据结点。允许修改 `link` 指针并删除重复结点。即使输入包含 `INT_MIN`，也必须保证绝对值比较不会触发有符号整数溢出。

1. 设计额外空间 $O(1)$ 的算法，只保留每种绝对值第一次出现的原结点。
2. 解释外层当前结点、内层前驱指针和内层当前指针各自的职责，并写出 C 语言实现。
3. 给出最坏时间复杂度及达到该界的输入情形。

<Solution>

### 参考答案

由于不能使用任何「某绝对值是否出现过」的辅助结构，只能做**原地嵌套扫描**：外层指针 `cur` 始终指向已经决定保留的某个类别的第一次出现结点；内层从 `cur->link` 向后搜索，把与 `cur` 绝对值相同的后续结点逐个删除。外层再继续访问剩余链表的下一个结点。

```c title="无值域限制、常数空间的链表去重" lineNumbers
#include <stdint.h>
#include <stdlib.h>

static uintmax_t AbsUnsigned(int x) {
    // 先转换到无符号类型，再用模运算取幅值，INT_MIN 同样安全
    return x < 0 ? (uintmax_t)0 - (uintmax_t)x : (uintmax_t)x;
}

void DedupAbsNoExtra(LNode *head) {
    if (head == NULL) return;

    for (LNode *cur = head->link; cur != NULL; cur = cur->link) {
        LNode *pre = cur;
        LNode *p = cur->link;
        while (p != NULL) {
            if (AbsUnsigned(p->data) == AbsUnsigned(cur->data)) {
                LNode *victim = p;
                pre->link = p->link;  // 摘掉重复结点
                p = pre->link;        // pre 保持不动
                free(victim);
            } else {
                pre = p;
                p = p->link;
            }
        }
    }
}
```

### 指针职责与正确性

- `cur`：外层保留下来的**该类别最早结点**，整个内层扫描期间不移动、不删除。
- `pre`：内层当前结点 `p` 的**直接前驱**，用于修改指针以摘除 `p`。
- `p`：内层当前被检查的结点。如果保留就与 `pre` 同时前进；如果删除则只让 `p` 改指 `pre->link`，**`pre` 保持不动**。

所有内层扫描结束时，`cur` 之后都不再存在相同绝对值的结点。因此每个类别第一次遇到的原结点必然留下来，后续同类别的结点必然已经被更早的外层循环清除。

### 复杂度与反例分析

当 $m$ 个元素的绝对值全部不同时，内层扫描长度依次为 $m-1,m-2,\ldots,1,0$，比较次数为

$$
\sum_{i=0}^{m-1}i=\frac{m(m-1)}2=\Theta(m^2).
$$

因此最坏时间是 **$\Theta(m^2)$**，额外空间是 **$O(1)$**。

<Callout type="warn" title="关于 INT_MIN">

`-INT_MIN` 对普通有符号 `int` 不安全。代码采用 `uintmax_t`：**先转换为无符号类型，再计算无符号差**，结果在模 $2^w$ 的运算中恰好是原负数的非负幅值。这样不会发生有符号溢出，并且不要求目标平台的 `int` 必须比 `int64_t` 窄。不要先执行 `abs(x)` 再强制类型转换，否则溢出风险已经产生。

</Callout>

</Solution>
</Question>

## 2018 年第 41 题

<Question
  id="408-ds-large-2018-41"
  type="essay"
  tags="来源:2018考研408, 科目:数据结构, 章节:线性表, 考点:最小缺失正整数, 难度:中等"
>

给定一个含 $n$（$n\ge 1$）个整数的数组，请设计一个在**时间上尽可能高效**的算法，找出数组中**未出现的最小正整数**。

例如：

- 数组 $\{-5,3,2,3\}$ 中未出现的最小正整数为 $1$；
- 数组 $\{1,2,3\}$ 中未出现的最小正整数为 $4$。

要求：

1. 给出算法的基本设计思想。
2. 用 C 或 C++ 描述算法。
3. 说明时间复杂度和空间复杂度。

<Solution>

### 参考答案

**建立长度为 $n$ 的出现标记表 `seen[0..n-1]`，仅记录 $1\sim n$ 是否出现。顺序扫描第一个未标记位置 $i$，返回 $i+1$；若全部标记，则返回 $n+1$。**

时间 $O(n)$，额外空间 $O(n)$，**不修改输入数组**。题目只要求时间最优，并不强制辅助空间为 $O(1)$。

### 解题过程

<Steps>
  <Step>

  ### 第一步：证明答案一定落在 $[1,n+1]$

  长度为 $n$ 的数组至多包含 $n$ 个不同的正整数。若 $1,2,\ldots,n$ 有某个数缺失，答案显然是其中最小的缺失数；若这 $n$ 个数全部出现，那么最小缺失正整数只能是 $n+1$。

  因此**无需关心非正数和大于 $n$ 的整数**。这是将无限值域压缩为 $n$ 个标记槽的关键。

  </Step>
  <Step>

  ### 第二步：设计值与下标的映射

  用 `seen[x-1]` 表示正整数 $x$ 是否出现，其中 $1\le x\le n$。先清零，再逐一读取数组元素：

  - 遇到 $x\le0$ 或 $x>n$，直接忽略；
  - 遇到 $1\le x\le n$，设置 `seen[x-1]=1`；
  - 同一正整数出现多次也只会把同一个槽反复设置为 1，不影响正确性。

  </Step>
  <Step>

  ### 第三步：按数值从小到大寻找未标记位置

  标记完毕后，从 `seen[0]` 向右依次查找。第一个值为 0 的位置 $i$ 对应答案 $i+1$；若不存在 0，返回 $n+1$。

  </Step>
</Steps>

```c title="2018-41：标记数组解法" lineNumbers
#include <stdlib.h>

/* 返回值用 long long，避免极端情况下 n+1 的 int 溢出；
   -1 表示非法输入或分配失败。 */
long long FindMissMin(const int A[], int n) {
    if (A == NULL || n <= 0) return -1;

    unsigned char *seen = calloc((size_t)n, sizeof *seen);
    if (seen == NULL) return -1;

    for (int i = 0; i < n; ++i) {
        if (A[i] >= 1 && A[i] <= n)
            seen[A[i] - 1] = 1;
    }

    for (int i = 0; i < n; ++i) {
        if (seen[i] == 0) {
            free(seen);
            return (long long)i + 1;
        }
    }

    free(seen);
    return (long long)n + 1;
}
```

### 实例验证

| 输入 | 标记表（从 $1$ 到 $n$） | 最小缺失正整数 |
| --- | --- | --- |
| $[-5,3,2,3]$ | `[0,1,1,0]` | $1$ |
| $[1,2,3]$ | `[1,1,1]` | $4$ |
| $[2,2,4,4]$ | `[0,1,0,1]` | $1$ |
| $[1]$ | `[1]` | $2$ |

### 正确性与复杂度

**循环不变量：**处理完输入前 $t$ 个元素后，对每个 $1\le x\le n$，有 `seen[x-1]==1` 当且仅当 $x$ 曾出现在已经处理的 $t$ 个元素中。初始 $t=0$ 时全部为 0；处理新元素时只更新对应槽，因此不变量保持。扫描完成后，从左向右遇到的第一个 0 恰是从小到大第一个未出现的正整数。不存在 0 时，所有 $1\sim n$ 均出现，答案为 $n+1$。

初始化表、读取输入、检查标记表分别至多访问 $n$ 个元素，总时间 **$O(n)$**；辅助表有 $n$ 个字节，额外空间 **$O(n)$**。在一般数组访问模型下，最坏情况下需要检查所有输入元素以排除某个关键值，线性时间达到渐近最优。

<Callout type="warn" title="易错点">

- 「未出现的最小正整数」不是数组中的最小正数，也不是「最小数 +1」。
- `seen` 应有 $n$ 个槽，对应 $1\sim n$；访问前**必须检查 $1\le A[i]\le n$**，否则负数或极大值会导致越界。
- `calloc` 的清零工作量是 $O(n)$，并非常数时间。
- 此解法不改变 `A`；若题目改为严格要求额外空间 $O(1)$，可以使用**原地置换**，见下面的强化题。

</Callout>

</Solution>
</Question>

### 原创强化训练 1 · 原地求最小缺失正整数

<Question
  id="408-ds-large-2018-41-ext1"
  type="essay"
  tags="来源:原创强化训练, 科目:数据结构, 章节:线性表, 考点:原地下标置换, 难度:较难"
>

数组 `A[0..n-1]` 包含正数、$0$、负数和重复值，**允许改变数组内容**。请在 $O(n)$ 时间和 $O(1)$ 额外空间内求未出现的最小正整数。

1. 给出值域 $[1,n]$ 的「值—位置」映射，以及交换规则。
2. 用 C 实现，特别说明为何重复值不会引发死循环。
3. 对 `A=[3,4,-1,1]` 与 `A=[1,1]` 给出答案，并证明嵌套 `while` 仍为线性总时间。

<Solution>

### 参考答案

把有效值 $x\in[1,n]$ 尽可能置于**下标 $x-1$** 处；当 `A[i]` 已在正确位置、超出值域，或目标位置已经存着相同值时，结束当前位置的交换。最后从左向右找第一个 `A[i]!=i+1`，返回 $i+1$；若没有这样的下标，返回 $n+1$。

```c title="原地置换：线性时间、常数空间" lineNumbers
#include <stddef.h>

long long FirstMissingPositiveInPlace(int A[], int n) {
    if (n <= 0) return 1;
    if (A == NULL) return -1;

    for (int i = 0; i < n; ++i) {
        while (A[i] >= 1 && A[i] <= n &&
               A[A[i] - 1] != A[i]) {
            int pos = A[i] - 1;
            int temp = A[pos];
            A[pos] = A[i];
            A[i] = temp;
        }
    }
    for (int i = 0; i < n; ++i)
        if (A[i] != i + 1) return (long long)i + 1;
    return (long long)n + 1;
}
```

### 为什么算法正确

对于每个有效正整数 $x$，位置 $x-1$ 是它的**唯一目标槽**。每次允许交换时，`A[i]` 被放入它的正确槽；即使换进来的元素还未归位，也会继续处理。因此扫描结束后，只要 $x$ 出现过，其目标位置必然被某个 $x$ 占据。数组中缺少 $x$ 当且仅当该目标位置不等于 $x$。

重复值如 `[1,1]`，当第二个 `1` 想进入 `A[0]` 时，发现 `A[0]` 已为 `1`，不再交换，从而**不会在两个相同值之间来回交换**。

对 `[3,4,-1,1]`，完成置换可得到 `[1,-1,3,4]`，第一个不匹配位置是下标 1，答案 **2**；对 `[1,1]`，答案也是 **2**。

### 为什么不是 $O(n^2)$

虽然 `while` 嵌套在 `for` 中，但每次真正交换都至少让一个有效值首次归位，而已归位的目标槽不会再被换走。全程有效交换不超过 $n$ 次；加上外层 $n$ 次检查、最后 $n$ 次扫描，总时间 **$O(n)$**，额外空间 **$O(1)$**。

<Callout type="idea" title="方法选择">

**不可修改输入**：用原题的 $O(n)$ 标记表；**允许修改输入且要求常数空间**：用值—下标对应关系，原地置换。不要把这两种约束混为一谈。

</Callout>

</Solution>
</Question>

### 原创预测训练 2 · 区间缺失数量与第 $k$ 个缺失值

<Question
  id="408-ds-large-2018-41-ext2"
  type="essay"
  tags="来源:原创预测训练, 科目:数据结构, 章节:线性表, 考点:范围标记与秩, 难度:较难"
>

给定长度为 $n$ 的只读数组 `A`、整数 $m$（$1\le m\le n$）以及正整数 $k$。在区间 $[1,m]$ 内，分别求：

1. **没有在 `A` 中出现过的整数总数**；
2. **最小的缺失整数**；
3. **按从小到大排列的第 $k$ 个缺失整数**。

若第二项或第三项无对应值，输出 $-1$。重复值和区间外数据不计入有效出现的不同整数。要求不改变 `A`，时间 $O(n+m)$、额外空间 $O(m)$，并对 `A=[2,2,4,-3,10]`、$m=4,k=2$ 给出结果。

<Solution>

### 参考答案

使用 `seen[x-1]` 记录 $1\le x\le m$ 是否出现；遍历输入完成标记后，按 $1,2,\ldots,m$ 顺序扫描零标记，累计缺失个数。遇到第一个缺失数就记录最小值，遇到第 $k$ 个缺失数就记录第 $k$ 缺失值。

```c title="统计全部缺失、最小缺失及第 k 缺失" lineNumbers
#include <stdlib.h>

/* 成功返回 1；参数非法或分配失败返回 0。
   missing、smallest、kth 为三个输出参数。 */
int MissingStats(const int A[], int n, int m, int k,
                 int *missing, int *smallest, int *kth) {
    if (A == NULL || n <= 0 || m < 1 || m > n || k <= 0 ||
        missing == NULL || smallest == NULL || kth == NULL)
        return 0;

    unsigned char *seen = calloc((size_t)m, sizeof *seen);
    if (seen == NULL) return 0;

    for (int i = 0; i < n; ++i)
        if (A[i] >= 1 && A[i] <= m)
            seen[A[i] - 1] = 1;

    int count = 0, first = -1, kthMissing = -1;
    for (int i = 0; i < m; ++i) {
        int x = i + 1;
        if (seen[i] == 0) {
            ++count;
            if (first == -1) first = x;
            if (count == k) kthMissing = x;
        }
    }
    free(seen);
    *missing = count;
    *smallest = first;
    *kth = kthMissing;
    return 1;
}
```

### 推导与答案

样例在 $[1,4]$ 内出现过的**不同数值**只有 $2$ 和 $4$。因此未出现的数是 $\{1,3\}$：总数 **2**，最小缺失数 **1**，第 $2$ 个缺失数 **3**。

扫描不变量是：处理完 $[1,x]$ 后，`count` 恰为其中未出现数的个数。将其从 0 开始逐个累加，就能同时回答**个数查询与顺序秩查询**，无需再次排序。初始化标记需 $O(m)$，遍历输入需 $O(n)$，扫描标记表需 $O(m)$，总时间 $O(n+m)$，辅助空间 $O(m)$。

<Callout type="warn" title="为什么不能直接减去出现次数">

样例中 `2` 出现两次，但区间 $[1,4]$ 中不同的已出现元素只有 $\{2,4\}$ 两个。直接计算「$m$ 减去落入区间的输入元素个数」会把重复的 `2` 多算一次，从而低估缺失数。**先去重再计数**才是关键。

</Callout>

</Solution>
</Question>

## 2019 年第 41 题

<Question
  id="408-ds-large-2019-41"
  type="essay"
  tags="来源:2019考研408, 科目:数据结构, 章节:线性表, 考点:链表重排, 难度:较难"
>

设线性表

$$
L=(a_1,a_2,a_3,\ldots,a_{n-1},a_n)
$$

采用**带头结点的单链表**保存，结点定义如下：

```c
typedef struct node {
    int data;
    struct node *next;
} NODE;
```

请设计一个额外空间复杂度为 $O(1)$、时间上尽可能高效的算法，**重新排列原有结点**，使其变为

$$
L'=(a_1,a_n,a_2,a_{n-1},a_3,a_{n-2},\ldots).
$$

要求：

1. 给出算法的基本设计思想。
2. 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
3. 说明算法的时间复杂度。

<Solution>

### 参考答案

**快慢指针找中点 → 断开链表 → 原地逆置后半段 → 两段交替合并。**这样将“不断从尾部取结点”转化为“从逆序后半段的表头取结点”，总时间 **$O(n)$**、额外空间 **$O(1)$**。只修改 `next`，不修改 `data`，也不创建数据结点。

### 设计思想与关键步骤

<Steps>
  <Step>

  ### 第一步：快慢指针划分前后两段

  快指针每次走两步，慢指针每次走一步。令二者从 `head->next`（首元结点）开始，使用 `fast->next!=NULL && fast->next->next!=NULL` 作循环条件。

  若 $n=2r$，慢指针停在 $a_r$；若 $n=2r+1$，停在 $a_{r+1}$。这样**前半段结点数为 $\lceil n/2\rceil$，后半段为 $\lfloor n/2\rfloor$**。交织时，前半段不会在后半段用尽前被耗尽。

  保存 `second=slow->next`，并设置 `slow->next=NULL` 断开两段。

  </Step>
  <Step>

  ### 第二步：原地逆置后半段

  用 `prev、cur、next` 三指针遍历后半段。每轮先保存 `next=cur->next`，再将 `cur->next=prev`，最后推进。完成后，原尾结点成为逆置后半段的首结点。

  </Step>
  <Step>

  ### 第三步：交替摘取并连接

  令 `first` 指向前半段首结点，`second` 指向已逆置的后半段首结点。每轮先暂存它们的各自后继，再执行

  ```c
  first->next = second;
  second->next = next1;
  ```

  随后分别转到 `next1`、`next2`。奇数长度时前半段多出的中点自然留在结果最后。

  </Step>
</Steps>

```c title="2019-41：分段、逆置、交织" lineNumbers
#include <stddef.h>

typedef struct node {
    int data;
    struct node *next;
} NODE;

void Rearrange(NODE *head) {
    if (head == NULL || head->next == NULL ||
        head->next->next == NULL) return;

    // 1. 慢指针落在前半段末结点
    NODE *slow = head->next, *fast = head->next;
    while (fast->next != NULL && fast->next->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }
    NODE *second = slow->next;
    slow->next = NULL; // 重要：断开前后两段

    // 2. 逆置后半段
    NODE *prev = NULL, *cur = second;
    while (cur != NULL) {
        NODE *next = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next;
    }
    second = prev;

    // 3. 把前段、逆置的后段交替编织起来
    NODE *first = head->next;
    while (second != NULL) {
        NODE *next1 = first->next;  // 改链接之前先保存后继
        NODE *next2 = second->next;
        first->next = second;
        second->next = next1;
        first = next1;
        second = next2;
    }
}
```

### 奇数与偶数长度的逐步验证

| 原链长度 | 前半段 | 后半段逆置后 | 交织结果 |
| --- | --- | --- | --- |
| $n=5$ | $a_1,a_2,a_3$ | $a_5,a_4$ | $a_1,a_5,a_2,a_4,a_3$ |
| $n=6$ | $a_1,a_2,a_3$ | $a_6,a_5,a_4$ | $a_1,a_6,a_2,a_5,a_3,a_4$ |
| $n=2$ | $a_1$ | $a_2$ | $a_1,a_2$ |

### 正确性与复杂度

- **划分不变量：**慢指针跨过的结点数始终对应快指针跨过结点数的一半；循环终止时前后段长度分别为 $\lceil n/2\rceil$ 和 $\lfloor n/2\rfloor$。
- **逆置不变量：**`prev` 永远是已处理的后半段结点组成的逆序链，`cur` 是未处理部分的第一个结点；每个原结点转移一次、不复制。
- **合并不变量：**完成 $t$ 轮后，输出前缀恰为 $a_1,a_n,a_2,a_{n-1},\ldots,a_t,a_{n-t+1}$，余下两链仍各自包含尚未输出的原结点。后半段耗尽后，所有结点恰好出现一次。

找中点、逆置后段、交替合并分别为 $O(n)$，总时间 **$O(n)$**；仅使用若干指针，额外空间 **$O(1)$**。

<Callout type="warn" title="常见错误">

1. **未断开两段**，可能保留原后继链接并形成环。
2. 直接从链表末尾不断查找前驱，导致 $O(n^2)$。
3. 在赋新 `next` 之前没保存旧后继，丢失剩余链。
4. 使用递归反转却写出严格 $O(1)$ 的辅助空间（递归栈也要计入）。
5. 将改变数据域当作重新排列结点；本题强调**原结点链接关系重排**。

</Callout>

</Solution>
</Question>

### 原创强化训练 1 · 从尾部开始交织重排

<Question
  id="408-ds-large-2019-41-ext1"
  type="essay"
  tags="来源:原创强化训练, 科目:数据结构, 章节:线性表, 考点:链表奇偶划分, 难度:较难"
>

给定**不带头结点**的单链表 `head`，依次存放原有结点 $a_1,a_2,\ldots,a_n$（$n\ge1$）。现要求**只通过调整指针**，将结点改排为

$$
(a_n,a_1,a_{n-1},a_2,a_{n-2},a_3,\ldots).
$$

1. 设计时间 $O(n)$、空间 $O(1)$ 的算法，并返回新表头。
2. 比较本题和 2019 年真题在**奇数长度时中点归属**上的区别。
3. 分别给出 $n=5$ 和 $n=6$ 的结果。

<Solution>

### 参考答案

本题要**先输出右半段**，因此应把链表分成长度 $\lfloor n/2\rfloor$ 的左段和长度 $\lceil n/2\rceil$ 的右段。若 $n$ 为奇数，中点必须归入**右段**。逆置右段后，按「右一个、左一个」合并，右段可能剩下的中点最后输出。

```c title="尾部优先的交织重排" lineNumbers
#include <stddef.h>

typedef struct node {
    int data;
    struct node *next;
} NODE;

NODE *ReorderFromTail(NODE *head) {
    if (head == NULL || head->next == NULL) return head;

    // 找到左半段末结点（奇数长度时中点归右段）
    NODE dummy = {0, head};
    NODE *slow = &dummy, *fast = head;
    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }
    NODE *right = slow->next;
    slow->next = NULL;
    NODE *left = dummy.next;

    // 逆置右段
    NODE *rev = NULL;
    while (right != NULL) {
        NODE *next = right->next;
        right->next = rev;
        rev = right;
        right = next;
    }

    // 从右段开始，依次交织；输出哑结点在栈上
    NODE out = {0, NULL}, *tail = &out;
    while (rev != NULL) {
        NODE *nextRight = rev->next;
        tail->next = rev;
        tail = rev;
        rev = nextRight;

        if (left != NULL) {
            NODE *nextLeft = left->next;
            tail->next = left;
            tail = left;
            left = nextLeft;
        }
    }
    tail->next = NULL;
    return out.next;
}
```

### 中点为什么必须归右段

以 $n=5$ 为例：分割成左段 $a_1,a_2$ 和右段 $a_3,a_4,a_5$，逆转右段得 $a_5,a_4,a_3$，交织得

$$
a_5,a_1,a_4,a_2,a_3.
$$

当 $n=6$ 时左右各 3 个结点，结果为

$$
a_6,a_1,a_5,a_2,a_4,a_3.
$$

**核心区别：**原真题以 $a_1$ 起头，左段需要不少于右段；本题以 $a_n$ 起头，右段需要不少于左段。时间 $O(n)$，空间 $O(1)$。

</Solution>
</Question>

### 原创预测训练 2 · 原地判断回文并恢复原链

<Question
  id="408-ds-large-2019-41-ext2"
  type="essay"
  tags="来源:原创预测训练, 科目:数据结构, 章节:线性表, 考点:链表回文与恢复, 难度:较难"
>

给定不带头结点的单链表 `head`，其数据域为整数，要求判断结点序列是否回文（如 $1\to2\to3\to2\to1$）。

要求：

1. 时间 $O(n)$、额外空间 $O(1)$。
2. 无论最终判断为真还是为假，都**必须恢复所有结点原来的位置和指针链接**。
3. 说明为何奇数长度可跳过中间结点、偶数长度应比较全部成对位置，并给出 C 代码。

<Solution>

### 参考答案

**找前半段末结点 → 逆置后半段 → 从两端向中间逐项比较 → 再次逆置后半段并接回**。比较结果保存在变量中，但不能在发现不相等时直接退出函数，因为必须先恢复链表。

```c title="判断回文并保证链表恢复" lineNumbers
#include <stdbool.h>
#include <stddef.h>

typedef struct node {
    int data;
    struct node *next;
} NODE;

static NODE *ReversePart(NODE *cur) {
    NODE *prev = NULL;
    while (cur != NULL) {
        NODE *next = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next;
    }
    return prev;
}

bool IsPalindromeRestore(NODE *head) {
    if (head == NULL || head->next == NULL) return true;

    NODE *slow = head, *fast = head;
    while (fast->next != NULL && fast->next->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }

    NODE *second = ReversePart(slow->next);
    NODE *p = head, *q = second;
    bool same = true;
    while (q != NULL) {
        if (p->data != q->data) {
            same = false;
            break; // 仅退出比较循环，后面仍需恢复
        }
        p = p->next;
        q = q->next;
    }

    slow->next = ReversePart(second); // 无论结果如何，都执行
    return same;
}
```

### 奇偶边界与正确性

| 序列 | 前半段末结点 | 逆置后半段 | 结论 |
| --- | --- | --- | --- |
| $[1,2,3,2,1]$ | 数据 $3$ | $[1,2]$ | 是回文，中心 $3$ 不比较 |
| $[1,2,2,1]$ | 第 1 个数据 $2$ | $[1,2]$ | 是回文，两对均比较 |
| $[1,2,3,4]$ | 数据 $2$ | $[4,3]$ | 不是回文，但仍恢复 |

当 $n=2r+1$ 时，比较的是前 $r$ 个元素与后 $r$ 个元素的逆序；中间结点不影响回文性。当 $n=2r$ 时，两段长度均为 $r$，需要完整比较 $r$ 对。逆置第二次是第一次的逆操作，且 `slow->next` 重新指向后半段原首结点，因此**结点身份、数据和相邻关系均复原**。

找中点、两次逆置和比较总时间 **$O(n)$**，额外空间 **$O(1)$**。在发生不相等时，代码仅跳出 `while`，**不提前 `return false`**。

<Callout type="idea" title="核心迁移点">

2019 年真题利用「逆置后半段」实现重排；本题利用同一操作实现**对称比较**。算法套路一样，但多了对链表完整恢复的约束，因而所有退出路径必须经过恢复步骤。

</Callout>

## 2020 年第 41 题

<Question
  id="408-ds-large-2020-41"
  type="essay"
  tags="来源:2020考研408, 科目:数据结构, 章节:线性表, 考点:三指针贪心, 难度:较难"
>

定义整数三元组 $(a,b,c)$ 的距离为

$$
D(a,b,c)=|a-b|+|b-c|+|c-a|.
$$

给定 3 个非空整数集合 $S_1,S_2,S_3$，各集合中的元素已按升序分别存放在 3 个数组中。请设计一个尽可能高效的算法，计算并输出所有可能三元组

$$
(a,b,c),\qquad a\in S_1,\ b\in S_2,\ c\in S_3
$$

中的最小距离。例如：

$$
S_1=\{-1,0,9\},\quad
S_2=\{-25,-10,10,11\},\quad
S_3=\{2,9,17,30,41\},
$$

则最小距离为 $2$，三元组可以取 $(9,10,9)$。

要求：

1. 给出算法的基本设计思想。
2. 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
3. 说明算法的时间复杂度和空间复杂度。

<Solution>

### 参考答案

**三数组各维护一个指针，每轮计算当前三元组距离，再只推进当前数值最小者所在数组的指针。**某个数组耗尽即结束。设三个数组长度分别为 $n_1,n_2,n_3$，总长度 $N=n_1+n_2+n_3$，时间 **$O(N)$**，额外空间 **$O(1)$**。

### 第一步：把距离变成极差

把 $(a,b,c)$ 按数值重排为 $x\le y\le z$，则

$$
\begin{aligned}
D(a,b,c)
&=(y-x)+(z-y)+(z-x)\\
&=2(z-x)\\
&=2\bigl(\max\{a,b,c\}-\min\{a,b,c\}\bigr).
\end{aligned}
$$

因此最小化三项绝对值之和，等价于最小化三个数的**最大值与最小值之差（极差）**。中间值不会单独进入最终表达式。

### 第二步：证明为什么只能推进当前最小者

假设当前三数组指针指向 $a,b,c$，最小者为 $a$，当前最大者为 $M$。如果保持 $a$ 不变，只推进另外两个指针，由于两数组有序，新选值不会减小，而 $a$ 仍是一个被选元素，因此新三元组的最小值仍为 $a$、最大值至少是 $M$，极差**不可能更小**。

所以，要想找出比当前组合更小的极差，至少需要让当前最小值所在数组的指针向右移动。贪心规则即：**记录当前值，再移动一个最小值指针。**若有多个相同最小值，推进其中任意一个，之后仍按同一规则继续处理。

<Callout type="idea" title="贪心原则并非凭直觉猜测">

这道题的核心不是「三指针」本身，而是一个**必要改进条件**：只移动非最小值的指针，无法缩小当前极差。利用这个条件，才可以安全剪去大量无需枚举的组合。

</Callout>

### 第三步：C 语言实现

```c title="2020-41：三数组最小距离" lineNumbers
#include <limits.h>

/* 题设保证三个数组非空且各自非降序排列 */
long long Min3Distance(const int A[], int n1,
                       const int B[], int n2,
                       const int C[], int n3) {
    int i = 0, j = 0, k = 0;
    long long best = LLONG_MAX;

    while (i < n1 && j < n2 && k < n3) {
        // 在比较和减法前提升为 long long，避免 int 溢出
        long long a = A[i], b = B[j], c = C[k];
        long long lo = a, hi = a;
        if (b < lo) lo = b;
        if (c < lo) lo = c;
        if (b > hi) hi = b;
        if (c > hi) hi = c;

        long long d = 2LL * (hi - lo);
        if (d < best) best = d;
        if (best == 0) break; // 距离的绝对下界

        // 只推进一个当前最小值指针
        if (a <= b && a <= c) ++i;
        else if (b <= a && b <= c) ++j;
        else ++k;
    }
    return best;
}
```

### 示例跟踪

给定三个数组，关键迭代如下：

| 当前 $(a,b,c)$ | 最小值 | 极差 | 距离 $D$ | 下一步 |
| --- | --- | ---: | ---: | --- |
| $(-1,-25,2)$ | $-25$ | 27 | 54 | 推进 $S_2$ |
| $(-1,-10,2)$ | $-10$ | 12 | 24 | 推进 $S_2$ |
| $(-1,10,2)$ | $-1$ | 11 | 22 | 推进 $S_1$ |
| $(0,10,2)$ | $0$ | 10 | 20 | 推进 $S_1$ |
| $(9,10,2)$ | $2$ | 8 | 16 | 推进 $S_3$ |
| $(9,10,9)$ | $9$ | 1 | **2** | 继续或终止 |

因此最小距离是 **$2$**，一个最优三元组是 **$(9,10,9)$**。

### 正确性证明与复杂度

<Steps>
  <Step>

  ### 正确性：不遗漏更优解

  对当前组合，若有更小的极差，必然要舍弃至少一个当前最小值；只推进非最小值不会改进。因此每轮只推进一个最小者是**安全的候选消除策略**。一直推进直到任一数组耗尽，未被访问的组合不会比某一轮已记录的当前组合更优。

  </Step>
  <Step>

  ### 时间上界

  每轮三个下标中恰有一个自增，因此下标总和每轮增加 1，最多进行 $O(n_1+n_2+n_3)$ 轮。每轮只有常数次比较和减法，时间为 **$O(N)$**，远优于三重枚举的 $O(n_1n_2n_3)$。

  </Step>
  <Step>

  ### 空间及整数边界

  只需要 3 个下标、当前极值和最佳答案，额外空间 **$O(1)$**。输入为 `int` 时，`hi-lo` 及其两倍可能超过 32 位，因此应**先提升为 `long long` 再相减、相乘**。

  </Step>
</Steps>

<Callout type="warn" title="容易失分的细节">

- **只推进一个最小者**，不要每轮三个指针全部前进。
- 当前最小者可能有多个相等值，按预定顺序推进其中一个即可。
- 判定数组是否耗尽必须发生在访问 `A[i]`、`B[j]`、`C[k]` 之前。
- `abs(a-b)` 若先在 `int` 上计算差值，可能在 `abs` 调用前已发生溢出。
- 输出的是**最小距离**，不是只输出三元组；最优三元组本身可以不唯一。

</Callout>

</Solution>

### 原创强化训练 1 · 四数组极差与多数组推广

<Question
  id="408-ds-large-2020-41-ext1"
  type="essay"
  tags="来源:原创强化训练, 科目:数据结构, 章节:线性表, 考点:多路贪心与最小堆, 难度:较难"
>

给定 **4 个非空升序数组** $S_1,S_2,S_3,S_4$，分别选取一个元素组成四元组 $(a,b,c,d)$，使极差

$$
R(a,b,c,d)=\max\{a,b,c,d\}-\min\{a,b,c,d\}
$$

尽可能小。例如：

$$
S_1=\{1,8\},\quad S_2=\{4,10\},\quad
S_3=\{6,9\},\quad S_4=\{7,11\}.
$$

1. 将真题三指针思想推广为四指针算法，写出 C 实现。
2. 证明其正确性并给出例子的最小极差。
3. 若进一步推广到 $k$ 个升序数组、总元素数为 $N$，说明**线性扫描法**和**最小堆法**的复杂度差异。

<Solution>

### 参考答案

四数组各设一个下标；每轮求四个当前元素的最大值、最小值，更新最佳极差后，**只推进当前最小值所属的下标**。示例最小极差为 **3**（如四元组 $(8,10,9,7)$）。四数组版本时间 $O(N)$，额外空间 $O(1)$。

```c title="四数组最小极差" lineNumbers
#include <limits.h>

/* S[0..3] 是四个数组起点；len[t] > 0；各数组非降序 */
long long MinRange4(const int *S[4], const int len[4]) {
    int p[4] = {0, 0, 0, 0};
    long long best = LLONG_MAX;

    while (1) {
        for (int t = 0; t < 4; ++t)
            if (p[t] == len[t]) return best;

        long long lo = S[0][p[0]], hi = lo;
        int minId = 0;
        for (int t = 1; t < 4; ++t) {
            long long x = S[t][p[t]];
            if (x < lo) { lo = x; minId = t; }
            if (x > hi) hi = x;
        }
        if (hi - lo < best) best = hi - lo;
        if (best == 0) return 0;
        ++p[minId];
    }
}
```

### 证明与实例

固定当前最小值 $m$ 时，只推进其他数组指针，仍然包含 $m$，而当前最大值只可能增大、不可能缩小。因此任何能改善当前极差的候选都必须推进一个最小值指针，与三数组结论一致。

示例中，关键过程是：

| 当前四元组 | 极差 | 应推进的数组 |
| --- | ---: | --- |
| $(1,4,6,7)$ | 6 | $S_1$ |
| $(8,4,6,7)$ | 4 | $S_2$ |
| $(8,10,6,7)$ | 4 | $S_3$ |
| $(8,10,9,7)$ | **3** | $S_4$ |

继续扫描不会得到更小的极差，因此答案是 **3**。

### 进一步推广到 $k$ 个数组

<Tabs items={['每轮线性扫描', '最小堆优化']} defaultIndex={0}>
  <Tab value="每轮线性扫描">

  保留 $k$ 个当前指针。每轮遍历这 $k$ 个值找最大、最小并推进最小者，单轮 $O(k)$。每次必有一个数组下标加 1，总迭代次数不超过 $N$，因此总时间为 **$O(Nk)$**，额外空间 **$O(k)$**（保存指针）。当 $k=4$ 固定时，时间就是 $O(N)$，下标数组也是常量规模。

  </Tab>
  <Tab value="最小堆优化">

  堆中为每个数组保留一个当前元素，键为数值，同时维护当前所有候选中的最大值 `maxValue`：

  1. 初始化将 $k$ 个数组首元素入最小堆，记录最大值。
  2. 堆顶即当前**最小元素**，用 `maxValue - heap.top` 更新答案。
  3. 弹出堆顶，将它所属数组的下一个元素入堆；插入时更新 `maxValue`。若该数组耗尽，则结束，因为不可能再从每个数组各选一个元素。

  初始化建堆 $O(k)$，之后最多 $O(N)$ 次堆更新，每次 $O(\log k)$，总时间 **$O(N\log k)$**，堆与数组下标占 **$O(k)$** 额外空间。适合 $k$ 很大、无法承受每轮扫描全部数组的情形。

  </Tab>
</Tabs>

<Callout type="idea" title="为什么推广成立">

三个、四个、$k$ 个数组本质都在求**每个序列各取一个数时的最小极差**。贪心安全性来自有序性和「当前最小值必须改变才可能缩小区间」，与数组个数无关。

</Callout>

</Solution>

### 原创预测训练 2 · 无序数组的最小距离与排序前提

<Question
  id="408-ds-large-2020-41-ext2"
  type="essay"
  tags="来源:原创预测训练, 科目:数据结构, 章节:线性表, 考点:堆排序与三指针, 难度:较难"
>

给定 3 个非空的**无序**整数数组 `A`、`B`、`C`，允许原地修改各数组，仍求真题中的最小距离

$$
D(a,b,c)=|a-b|+|b-c|+|c-a|.
$$

1. 用一个**具体反例**说明直接应用「推进当前最小者」的三指针贪心可能失败。
2. 设计并实现最坏时间 $O(N\log N)$、额外空间 $O(1)$ 的算法，其中 $N=n_1+n_2+n_3$。
3. 比较「排序后线性扫描」与直接三重枚举的复杂度；对 `A=[9,-1,0]`、`B=[10,-25,-10,11]`、`C=[41,9,2,17,30]` 给出结果。

<Solution>

### 参考答案

**不能直接贪心。应先分别使用原地堆排序将三个数组变成非降序，再调用 2020 年真题的三指针算法。**排序最坏时间 $O(N\log N)$，三指针扫描 $O(N)$，总时间 **$O(N\log N)$**，额外空间 **$O(1)$**。

### 为什么无序时会失败

例如 `A=[1,100,6]`、`B=[5]`、`C=[8]`。初始组合 $(1,5,8)$ 的距离为 $14$，最小者是 $1$；向右推进 A 后，组合变为 $(100,5,8)$，而最小者变成 B 的唯一元素 $5$。继续推进 B 就会耗尽，整个扫描无法再访问 A 后面的 $6$，因此会**漏掉更优组合 $(6,5,8)$，其距离仅为 $6$**。

错误原因是：无序数组向右推进后，选值不保证不减；当前最小者之外的指针变化也可能带来更优结果。真题的贪心证明依赖**每个输入数组已经按升序排列**，不是无条件成立。

### 实现：原地堆排序 + 真题三指针

```c title="无序数组：先堆排序再求最小距离" lineNumbers
#include <limits.h>
#include <stddef.h>

static void SiftDown(int A[], int root, int last) {
    while (last >= 1 && root <= (last - 1) / 2) {
        int child = 2 * root + 1;
        if (child < last && A[child + 1] > A[child]) ++child;
        if (A[root] >= A[child]) break;
        int tmp = A[root]; A[root] = A[child]; A[child] = tmp;
        root = child;
    }
}

static void HeapSort(int A[], int n) {
    for (int i = n / 2; i > 0;) {
        --i;
        SiftDown(A, i, n - 1);
    }
    for (int end = n - 1; end > 0; --end) {
        int tmp = A[0]; A[0] = A[end]; A[end] = tmp;
        SiftDown(A, 0, end - 1);
    }
}

/* Min3Distance 为紧邻上方 2020 年真题给出的完整函数 */
long long MinDistanceUnsorted(int A[], int n1,
                              int B[], int n2,
                              int C[], int n3) {
    if (A == NULL || B == NULL || C == NULL ||
        n1 <= 0 || n2 <= 0 || n3 <= 0) return -1;

    HeapSort(A, n1);
    HeapSort(B, n2);
    HeapSort(C, n3);
    return Min3Distance(A, n1, B, n2, C, n3);
}
```

### 正确性与效率

1. **堆排序不会改变各数组的候选值集合**，仅改变它们在数组中的排列。所有可能的三元组及其最小距离因此不变。
2. 排序完成后，每个数组都满足非降序条件，真题「只推进当前最小者」的贪心证明重新成立。
3. 分别排序的最坏工作量为

   $$
   O(n_1\log n_1+n_2\log n_2+n_3\log n_3)\subseteq O(N\log N).
   $$

   然后三指针总共最多移动 $O(N)$ 次；堆排序与扫描都只需要常数个辅助变量，所以总额外空间 $O(1)$。

样例排序后回到真题的三个升序序列，最小距离为 **$2$**，例如 $(9,10,9)$。

| 方法 | 最坏时间 | 额外空间 | 前提 |
| --- | --- | --- | --- |
| 三重枚举 | $O(n_1n_2n_3)$ | $O(1)$ | 无需排序 |
| 原地堆排序 + 三指针 | $O(N\log N)$ | $O(1)$ | 允许改变数组内顺序 |
| 已有序时直接三指针 | $O(N)$ | $O(1)$ | 各数组本来有序 |

<Callout type="warn" title="别混淆复杂度与前提">

- 这里选择**堆排序**，是为了给出严格的最坏时间 $O(N\log N)$ 与额外空间 $O(1)$；递归归并排序通常需要线性辅助数组。
- 「三指针只推进最小者」不是无需条件的贪心模板，必须明确**数组排序产生的单调性**。
- 若要求不修改无序输入数组，不能再直接采用本题的原地排序版本；需要复制数据或改用其他算法并重新分析空间。

</Callout>

## 2025 年第 41 题

<Question
  id="408-ds-large-2025-41"
  type="essay"
  tags="来源:2025考研408, 科目:数据结构, 章节:线性表, 考点:后缀最值, 考点:线性扫描, 难度:中等"
>

设有两个长度均为 $n$ 的一维整型数组 `A` 和 `res`。对数组 `A` 中的每个元素 `A[i]`，需要计算

$$
\max_{i\le j\le n-1}\{A[i]\cdot A[j]\},
$$

并将结果保存到 `res[i]` 中。

例如，若

$$
A=\{1,4,-9,6\},
$$

则

$$
res=\{6,24,81,36\}.
$$

请设计时间和空间上尽可能高效的算法：

```c
void calMulMax(int A[], int res[], int n);
```

要求：

1. 给出算法的基本设计思想。
2. 使用 C 或 C++ 描述算法。
3. 说明时间复杂度和额外空间复杂度。

<Solution>

### 参考答案

**从右向左维护后缀最大值 `hi` 和最小值 `lo`；对每个 `i`，先把 `A[i]` 纳入后缀，再计算 `res[i] = max(A[i]*hi, A[i]*lo)`。**总时间 $O(n)$、额外空间 $O(1)$（不计题目要求的输出数组）。

核心原因是：固定 $x=A[i]$ 时，乘积 $xy$ 是关于 $y$ 的一次函数，最大值一定在合法后缀的**最大元素或最小元素**处取得；只看最大值会遗漏负数乘负数的情况。

```c title="2025-41：后缀双端极值，一次逆序扫描" lineNumbers
#include <stddef.h>

/* 按原题 int 接口；前提：所有计算所得乘积均在 int 范围内 */
void calMulMax(int A[], int res[], int n) {
    if (A == NULL || res == NULL || n <= 0) return;
    int hi = A[n - 1], lo = A[n - 1];

    for (int i = n - 1; i >= 0; --i) {
        int x = A[i];               // 先取原值
        if (x > hi) hi = x;          // 将 i 纳入合法后缀
        if (x < lo) lo = x;

        int a = x * hi, b = x * lo;
        res[i] = a > b ? a : b;
    }
}
```

### 解题过程

<Steps>
  <Step>

  ### 第一步：正确理解约束 $i\le j$

  每个 `res[i]` 只能从**以 `i` 为起点的后缀** `A[i..n-1]` 中选择因子，不能使用数组左侧元素。又因为允许 $j=i$，所以 $A[i]$ 可以与自己相乘。

  </Step>
  <Step>

  ### 第二步：把求最大乘积变成两个极值查询

  对固定的 $i$，记

  $$
  M_i=\max_{i\le j<n}A[j],\qquad m_i=\min_{i\le j<n}A[j].
  $$

  那么

  $$
  \boxed{res[i]=\max\bigl(A[i]M_i,\ A[i]m_i\bigr).}
  $$

  - 当 $A[i]>0$，乘以最大值 $M_i$ 最优；
  - 当 $A[i]<0$，乘以最小值 $m_i$ 最优；
  - 当 $A[i]=0$，所有合法乘积都为 $0$。

  统一使用两个乘积取较大者，省去显式的正负分支。

  </Step>
  <Step>

  ### 第三步：利用后缀递推从右往左计算

  $$
  M_i=\max(A[i],M_{i+1}),\quad
  m_i=\min(A[i],m_{i+1}).
  $$

  右向左移动一次即可同时维护两个量；它们都是常数大小的状态，不需要建立完整的后缀数组。

  </Step>
</Steps>

### 手工模拟

对 $A=\{1,4,-9,6\}$：

| $i$ | $A[i]$ | $m_i$ | $M_i$ | 比较两个乘积 | $res[i]$ |
| --- | ---: | ---: | ---: | --- | ---: |
| 3 | 6 | 6 | 6 | $36,36$ | 36 |
| 2 | -9 | -9 | 6 | $-54,81$ | 81 |
| 1 | 4 | -9 | 6 | $-36,24$ | 24 |
| 0 | 1 | -9 | 6 | $-9,6$ | 6 |

故得到 $res=\{6,24,81,36\}$。**`res[2]=81` 来自 $j=i=2$，不是来自右边的 6。**

### 正确性证明与复杂度

**逆序循环不变量：**处理完下标 $i$ 的两次极值更新后，`hi` 与 `lo` 分别是区间 `A[i..n-1]` 的最大值、最小值。

- **初始化：** $i=n-1$ 时后缀只有一个元素，极值成立。
- **保持：**若对 $i+1$ 成立，把 `A[i]` 与旧极值比较后，就得到 $i$ 的后缀极值。
- **结论：**乘积关于另一因子是单调函数，其最大值只能取在后缀两端极值中的一个，故每次写入的 `res[i]` 均正确。

每次迭代只做常数次比较和乘法，共 $n$ 次，因此时间 $O(n)$；除 `res` 这一题目指定的输出外，只保存少量变量，额外空间 $O(1)$。

<Tabs items={['题目给定的 int 接口', '防止整数溢出的 64 位实现']} defaultIndex={0}>
  <Tab value="题目给定的 int 接口">

  若题目隐含保证**每个合法乘积和最终答案**都可由 `int` 表示，可使用上述 `calMulMax`。即使最终最大乘积合法，若某个中间候选乘积越界，依然可能发生有符号整数溢出，所以前提应覆盖两个候选乘积。

  </Tab>
  <Tab value="防止整数溢出的 64 位实现">

  对完整 32 位 `int` 值域，更安全的接口应当让结果数组也采用 `long long`：

  ```c title="乘法前提升到 64 位"
  void calMulMax64(const int A[], long long res[], int n) {
      if (A == NULL || res == NULL || n <= 0) return;
      long long hi = A[n - 1], lo = A[n - 1];
      for (int i = n - 1; i >= 0; --i) {
          long long x = A[i];
          if (x > hi) hi = x;
          if (x < lo) lo = x;
          long long u = x * hi, v = x * lo;
          res[i] = u > v ? u : v;
      }
  }
  ```

  两个 32 位有符号整数的乘积落在 64 位有符号整数可表示范围内；**先扩大类型再乘法**才能避开溢出。

  </Tab>
</Tabs>

<Callout type="warn" title="三个非常关键的细节">

- **先更新、后计算**：因为原题允许 $j=i$。若先计算，只考虑 $j>i$，题意就变了。
- **保留极小值**：负数与更负的数相乘反而更大，只维护最大值不够。
- **逆序处理并不等于前缀扫描**：合法候选集始终是 `A[i..n-1]`，绝不能误用已经离开的右边窗口或左侧元素。

</Callout>

### 原创强化训练 1 · 严格向右并返回最左最优下标

<Question
  id="408-ds-large-2025-41-ext1"
  type="essay"
  tags="来源:原创强化训练, 科目:数据结构, 考点:严格后缀, 考点:最优下标, 难度:较难"
>

给定整数数组 `A[0..n-1]`，对每个位置 $i$，必须选择**严格位于其右侧**的位置 $j>i$，使乘积 $A[i]A[j]$ 最大。若有多个最优 $j$，必须选**最小的下标**。

将最大乘积写入 `long long best[]`，对应下标写入 `int pos[]`。若不存在合法 $j$，规定 `best[i]=LLONG_MIN`、`pos[i]=-1`。

1. 设计 $O(n)$ 时间、$O(1)$ 额外空间的算法（不计输出数组）。
2. 用 C 实现，强调**先查询、后更新**以及并列时的下标维护。
3. 对 `A={0,2,-3,-3,2}` 求两个输出数组，并解释 `A[i]=0` 的特殊性。

<Solution>

### 参考答案

从右往左扫描，处理位置 $i$ 时缓存区间 `A[i+1..n-1]` 的最大、最小元素及其**最左出现下标**。先用该严格后缀回答查询，再把 `A[i]` 加入缓存。正数选择后缀最大值、负数选择后缀最小值、零选择最小合法下标 $i+1$。

结果为：

$$
\boxed{best=\{0,4,9,-6,\mathrm{LLONG\_MIN}\}},
$$

$$
\boxed{pos=\{1,4,3,4,-1\}}.
$$

```c title="严格后缀 + 最左最优下标" lineNumbers
#include <limits.h>
#include <stddef.h>

void MaxProductRight(const int A[], int n,
                     long long best[], int pos[]) {
    if (A == NULL || best == NULL || pos == NULL || n <= 0) return;

    best[n - 1] = LLONG_MIN;
    pos[n - 1] = -1;                  // 末元素右边没有候选
    long long hi = A[n - 1], lo = A[n - 1];
    int hiPos = n - 1, loPos = n - 1;

    for (int i = n - 2; i >= 0; --i) {
        long long x = A[i];
        if (x > 0) {
            best[i] = x * hi;
            pos[i] = hiPos;
        } else if (x < 0) {
            best[i] = x * lo;
            pos[i] = loPos;
        } else {
            best[i] = 0;
            pos[i] = i + 1;          // 全部右侧位置并列最优
        }

        // 只有回答了本轮查询后，才允许将 A[i] 加入后缀。
        if (x >= hi) { hi = x; hiPos = i; }
        if (x <= lo) { lo = x; loPos = i; }
    }
}
```

### 解题关键

1. **严格右侧**：更新必须放在计算后面。否则遇到 $-3$ 时可能错误使用 $(-3)\times(-3)$ 的「自己乘自己」。
2. **最左下标**：逆序遍历遇到与缓存极值相同的新值，其下标一定更小，因此更新时使用 `>=`、`<=` 而不是严格不等号。
3. **零的特例**：任意右侧元素与零相乘均为零，最小合法下标必是 $i+1$；不能按最大值下标或最小值下标确定它。
4. **正确性**：查询时极值缓存恰好对应严格右后缀，再由乘法单调性确定最优值和最左位置；更新后保持下一轮所需不变量。

时间 $O(n)$，额外空间 $O(1)$；`best`、`pos` 为题目要求的输出数组，不计辅助空间。

</Solution>

### 原创预测训练 2 · 固定长度右侧窗口上的最大乘积

<Question
  id="408-ds-large-2025-41-ext2"
  type="essay"
  tags="来源:原创预测训练, 科目:数据结构, 考点:单调队列, 考点:滑动窗口, 难度:拔高"
>

原题扩展为**有限窗口查询**：给定整数 $w$（$0\le w<n$），对每个 $i$ 仅可选

$$
i\le j\le\min(n-1,i+w).
$$

求最大乘积 `best[i]`，并在并列时记录最小的可选下标 `pos[i]`。输入数组不得修改，输出数组 `best` 使用 `long long`。

1. 设计总时间 $O(n)$、额外空间 $O(w+1)$ 的算法（不计输出数组）。
2. 说明为什么需要同时维护当前窗口的最大值、最小值，以及如何保证**相等元素优先最左下标**。
3. 对 `A={1,4,-9,6}`、$w=2$ 写出 `best`、`pos`。

<Solution>

### 参考答案

采用两条**单调双端队列**，分别保存窗口内的最大值候选和最小值候选的下标。按窗口左端点 $i$ 从左到右移动，并将右端扩展到 $\min(n-1,i+w)$。最大队列中的值单调不增，最小队列中的值单调不减；新元素入队时，仅剔除**严格劣于**新元素的队尾，保留相等元素的更早下标。

样例输出：

$$
\boxed{best=\{4,24,81,36\},\quad pos=\{1,3,2,3\}}.
$$

### 核心算法

用容量为 $w+1$ 的循环数组分别实现两个双端队列：

<Steps>
  <Step>

  ### 窗口左端点从 $i-1$ 变为 $i$

  先从两条队列的**队首**移除所有下标小于 $i$ 的旧元素。这一步放在添加新右端元素**之前**，可以确保固定容量 $w+1$ 不会溢出。

  </Step>
  <Step>

  ### 逐个插入刚进入窗口的右端元素

  - 最大值队列：队尾的值若**小于**新值就移除，再插入新下标。
  - 最小值队列：队尾的值若**大于**新值就移除，再插入新下标。

  对于相等值不移除旧下标，以便队首仍是该极值最靠左的合法位置。

  </Step>
  <Step>

  ### 回答查询

  对 $x=A[i]$：$x>0$ 时取最大值队首，$x<0$ 时取最小值队首，$x=0$ 时直接取 `pos[i]=i`。把乘积保存到 `long long best[i]`。

  </Step>
</Steps>

```c title="O(n) 时间、O(w+1) 额外空间的完整实现" lineNumbers
#include <stdlib.h>

typedef struct {
    int *a;
    int head, size, cap;
} Deque;

static int dqFront(const Deque *d) { return d->a[d->head]; }
static int dqBack(const Deque *d) {
    return d->a[(d->head + d->size - 1) % d->cap];
}
static void popFront(Deque *d) {
    d->head = (d->head + 1) % d->cap;
    --d->size;
}
static void popBack(Deque *d) { --d->size; }
static void pushBack(Deque *d, int v) {
    d->a[(d->head + d->size) % d->cap] = v;
    ++d->size;
}

int WindowMaxProduct(const int A[], int n, int w,
                     long long best[], int pos[]) {
    if (!A || !best || !pos || n <= 0 || w < 0 || w >= n)
        return 0;

    int cap = w + 1;
    Deque mx = {0}, mn = {0};
    mx.a = (int *)malloc((size_t)cap * sizeof(int));
    mn.a = (int *)malloc((size_t)cap * sizeof(int));
    if (!mx.a || !mn.a) {
        free(mx.a); free(mn.a);
        return 0;
    }
    mx.cap = mn.cap = cap;
    mx.head = mx.size = mn.head = mn.size = 0;

    int nextRight = 0;
    for (int i = 0; i < n; ++i) {
        // 先剔除左端过期元素，保证队列最多容纳 w+1 项。
        while (mx.size && dqFront(&mx) < i) popFront(&mx);
        while (mn.size && dqFront(&mn) < i) popFront(&mn);

        int r = (w > n - 1 - i) ? n - 1 : i + w;
        while (nextRight <= r) {
            int t = nextRight++;
            while (mx.size && A[dqBack(&mx)] < A[t]) popBack(&mx);
            pushBack(&mx, t);
            while (mn.size && A[dqBack(&mn)] > A[t]) popBack(&mn);
            pushBack(&mn, t);
        }

        int j = (A[i] > 0) ? dqFront(&mx)
              : (A[i] < 0) ? dqFront(&mn) : i;
        pos[i] = j;
        best[i] = (long long)A[i] * A[j];
    }
    free(mx.a); free(mn.a);
    return 1;
}
```

### 正确性与复杂度

队列始终保存窗口内**未被后来的更优元素支配**的候选下标，队首为该窗口对应的最值；被移除的较差值，即使还在窗口中，也无法在支配它的更新元素离开窗口**之前**成为最优（后来的元素离开时，旧元素已经更早离开）。严格比较保证并列最大或最小值时，保留先出现的左端下标。

每个下标只被压入一次，最多从队首或队尾移除一次，因此虽然内部有 `while`，总的双端队列操作次数是 $O(n)$；两条队列最多各存 $w+1$ 个下标，额外空间 $O(w+1)$。

原题是窗口右端始终等于 $n-1$ 的**后缀最值**；本题把范围变为移动窗口，因此静态两个极值不足以删除过期元素，需要将「后缀扫描」升级为「单调队列维护窗口极值」。

</Callout>
