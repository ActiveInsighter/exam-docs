## 2016 年第 43 题

<ExamQuestion>

**16. 2016 年第 43 题**

已知由 $n\;(n\ge 2)$ 个正整数构成的集合

$$
A=\{a_k\mid 0\le k<n\}.
$$

将其划分为两个不相交的子集 $A_1$ 和 $A_2$，元素个数分别为 $n_1$ 和 $n_2$，元素之和分别为 $S_1$ 和 $S_2$。

设计一个尽可能高效的划分算法，使

$$
|n_1-n_2|
$$

最小，并在此基础上使

$$
|S_1-S_2|
$$

最大。

要求：

1. 给出算法的基本设计思想；
2. 用 C 或 C++ 描述算法；
3. 说明时间复杂度和空间复杂度。

<ExamSolution>

<ExamAnswer>令 $|A_1|=\lfloor n/2\rfloor$，把最小的 $\lfloor n/2\rfloor$ 个数放入 $A_1$，其余放入 $A_2$。可用 Quickselect 原地划分，平均时间复杂度 $O(n)$，额外空间复杂度 $O(1)$。</ExamAnswer>

<ExamExplanation>

要使

$$
|n_1-n_2|
$$

最小，两个集合的元素个数必须尽量接近，因此取

$$
n_1=\left\lfloor\frac n2\right\rfloor,
\qquad
n_2=n-n_1.
$$

由于所有元素均为正整数，在元素个数已经确定的前提下，要让两组元素和的差尽可能大，应让一组取得尽可能小的元素，另一组取得尽可能大的元素。因此把最小的 $\lfloor n/2\rfloor$ 个元素放入 $A_1$，其余放入 $A_2$。

没有必要把整个数组完全排序。使用快速排序的 `partition` 思想，不断缩小划分区间，直到下标

$$
k=\left\lfloor\frac n2\right\rfloor
$$

落在最终划分位置即可。此时下标 $0\sim k-1$ 恰有 $k$ 个较小元素，其余元素构成 $A_2$。

```c
int partition(int a[], int low, int high) {
    int pivot = a[low];
    int i = low, j = high;

    while (i < j) {
        while (i < j && a[j] >= pivot) {
            --j;
        }
        a[i] = a[j];

        while (i < j && a[i] <= pivot) {
            ++i;
        }
        a[j] = a[i];
    }

    a[i] = pivot;
    return i;
}

// 使下标 k 左边均为较小的一组，k 及其右边为较大的一组
void quickSelect(int a[], int n, int k) {
    int low = 0, high = n - 1;

    while (low <= high) {
        int p = partition(a, low, high);

        if (p == k) {
            return;
        } else if (p < k) {
            low = p + 1;
        } else {
            high = p - 1;
        }
    }
}

long long divideSet(int a[], int n) {
    int k = n / 2;              // floor(n/2)
    quickSelect(a, n, k);

    long long S1 = 0, S2 = 0;
    for (int i = 0; i < k; ++i) {
        S1 += a[i];
    }
    for (int i = k; i < n; ++i) {
        S2 += a[i];
    }

    return S2 - S1;             // 所有元素为正数，故此划分下 S2 >= S1
}
```

这里把原整理中的递归 Quickselect 改成了迭代形式，从而与“额外空间复杂度 $O(1)$”的结论一致。

- `partition` 的 Quickselect **平均**时间复杂度为 $O(n)$；
- 最坏情况下可退化为 $O(n^2)$；
- 采用原地迭代划分时，额外空间复杂度为 $O(1)$。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

## 2021 年第 42 题

<ExamQuestion>

**26. 2021 年第 42 题**

已知某排序算法如下：

```c
void cmpCountSort(int a[], int b[], int n)
{
    int i, j, *count;
    count = (int *)malloc(sizeof(int) * n);

    for (i = 0; i < n; i++)
        count[i] = 0;

    for (i = 0; i < n - 1; i++)
        for (j = i + 1; j < n; j++)
            if (a[i] < a[j])
                count[j]++;
            else
                count[i]++;

    for (i = 0; i < n; i++)
        b[count[i]] = a[i];

    free(count);
}
```

请回答：

1. 若

```c
int a[] = {25, -10, 25, 10, 11, 19};
int b[6];
```

调用 `cmpCountSort(a, b, 6)` 后，数组 `b` 中的内容是什么？
2. 若 `a` 中含有 $n$ 个元素，则算法执行过程中元素之间的比较次数是多少？
3. 该算法是否稳定？若稳定，说明理由；若不稳定，将其修改为稳定排序算法。

<ExamSolution>

<ExamAnswer>

排序结果为

```text
{-10, 10, 11, 19, 25, 25}
```

元素比较次数为

$$
\frac{n(n-1)}{2}.
$$

原算法不稳定。把判断改为 `if (a[i] <= a[j]) count[j]++; else count[i]++;` 后可保持相等元素的原相对次序。

</ExamAnswer>

<ExamExplanation>

### （1）排序结果

对任意元素 `a[i]`，`count[i]` 最终表示该元素在输出数组中的目标下标。

原算法会得到

```text
b = {-10, 10, 11, 19, 25, 25}
```

即按非递减次序排列。

### （2）比较次数

双重循环使每一对不同位置的元素恰好比较一次，因此比较次数为

$$
(n-1)+(n-2)+\cdots+1
=\frac{n(n-1)}{2}.
$$

### （3）稳定性

原算法**不稳定**。

设 $i<j$ 且

$$
a[i]=a[j].
$$

原条件 `a[i] < a[j]` 为假，于是执行

```c
count[i]++;
```

这会使原本位于前面的 `a[i]` 获得更大的输出下标，排到原本位于后面的 `a[j]` 之后，从而破坏稳定性。

应修改为：

```c
if (a[i] <= a[j])
    count[j]++;
else
    count[i]++;
```

当两个元素相等时，增加后一个元素 `a[j]` 的计数，使后出现的相等元素仍排在后面，因此排序变为稳定排序。

若使用 C++ 动态数组写法 `new int[n]`，释放时相应应使用 `delete[] count`。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

## 2022 年第 42 题

<ExamQuestion>

**28. 2022 年第 42 题**

现有 $n$ 个数保存在一维数组 $M$ 中，其中

$$
n>100000.
$$

需要找出 $M$ 中最小的 10 个数。

请回答：

1. 设计一个完成上述任务的算法，要求平均情况下的比较次数尽可能少，只需描述算法思想，不需要程序实现；
2. 说明算法平均情况下的时间复杂度和空间复杂度。

<ExamSolution>

<ExamAnswer>维护一个只含 10 个元素的大根堆。堆顶始终是当前候选的 10 个最小数中的最大者；扫描其余元素，只有当新元素小于堆顶时才替换堆顶并向下调整。因 10 为常数，平均时间复杂度为 $O(n)$，额外空间复杂度为 $O(1)$。</ExamAnswer>

<ExamExplanation>

### 算法思想

1. 取数组 $M$ 的前 10 个元素，建立一个大小为 10 的**大根堆** $H$；
2. 对 $M$ 中剩余的每个元素 $x$：
   - 先与堆顶 $H[0]$ 比较；
   - 若

$$
x\ge H[0],
$$

则 $x$ 不可能属于当前最小的 10 个数，直接忽略；
   - 若

$$
x<H[0],
$$

则用 $x$ 替换堆顶，再对堆顶执行一次向下调整，恢复大根堆；
3. 全部扫描结束后，堆中的 10 个元素就是整个数组中最小的 10 个数。

之所以使用**大根堆**，是因为只需 $O(1)$ 时间就能取得这 10 个候选值中的最大者，从而快速判断一个新元素是否值得进入候选集合。

### 复杂度

堆大小固定为 10，所以每次堆调整的代价为

$$
O(\log 10)=O(1).
$$

扫描 $n$ 个元素的总时间复杂度为

$$
O(n).
$$

辅助堆只有 10 个元素，因此若以 $n$ 为规模衡量，额外空间复杂度为

$$
O(1).
$$

若把“10”推广为一般的 $k$，则对应复杂度为 $O(n\log k)$ 时间和 $O(k)$ 额外空间。

</ExamExplanation>

</ExamSolution>

</ExamQuestion>

## 2023 年第 42 题

<ExamQuestion>

**30. 2023 年第 42 题**

对含有 $n$ 个记录的文件进行外部排序。采用**置换—选择排序**生成初始归并段时，需要使用一个工作区，工作区中最多保存 $m$ 个记录。

请回答：

1. 若文件中有 19 个记录，其关键字依次为

$$
51,94,37,92,14,63,15,99,48,56,23,60,31,17,43,8,90,166,100,
$$

当 $m=4$ 时，可生成几个初始归并段？各是什么？
2. 对任意 $n$、$m$，其中 $n>m>0$，生成的第一个初始归并段的长度最大值和最小值分别是多少？

<ExamSolution>

<ExamAnswer>

当 $m=4$ 时，共生成 3 个初始归并段：

1. $37,51,63,92,94,99$
2. $14,15,23,31,48,56,60,90,166$
3. $8,17,43,100$

第一个初始归并段长度的最大值为 $n$，最小值为 $m$。

</ExamAnswer>

<ExamExplanation>

### （1）置换—选择过程

初始把前 4 个关键字装入工作区：

$$
51,94,37,92.
$$

每次从当前仍属于本归并段的记录中选择最小者输出，再读入一个新的输入记录：

- 若新记录关键字不小于刚输出的关键字，则它仍可参加当前归并段；
- 若新记录关键字更小，则将它“冻结”，留待下一归并段。

按照这一规则，第一段依次输出

$$
37,51,63,92,94,99.
$$

第一段结束时被冻结的记录进入第二段，继续执行同样过程，可得到

$$
14,15,23,31,48,56,60,90,166.
$$

剩余被冻结记录构成第三段：

$$
8,17,43,100.
$$

因此共生成 3 个初始归并段。

### （2）第一个归并段长度的上下界

工作区初始装入 $m$ 个记录，这 $m$ 个记录最终都必须在第一个归并段中被输出，因此第一个归并段长度不可能小于

$$
m.
$$

若后续读入的每个记录都不小于当前刚输出的记录，则没有任何记录被冻结，整个文件的 $n$ 个记录都可以落入第一个归并段，因此最大长度为

$$
n.
$$

所以第一个初始归并段长度满足

$$
m\le L_1\le n.
$$

</ExamExplanation>

</ExamSolution>

</ExamQuestion>
