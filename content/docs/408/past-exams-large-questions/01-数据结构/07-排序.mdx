# 第 7 章 排序

## 7.2 交换类排序

<Question id="408-3135dc-011" type="essay" tags="来源:2016考研408">

已知由 $n(n\ge2)$ 个正整数构成的集合 $A=\{a_k\mid 0\le k<n\}$，将其划分为两个不相交的子集 $A_1$ 和 $A_2$，元素个数分别是 $n_1$ 和 $n_2$，$A_1$ 和 $A_2$ 中元素之和分别为 $S_1$ 和 $S_2$。设计一个尽可能高效的划分算法，满足 $|n_1-n_2|$ 最小且 $|S_1-S_2|$ 最大。要求：

(1) 给出算法的基本设计思想；  
(2) 根据设计思想，采用C或C++语言描述算法，关键之处给出注释；  
(3) 说明你所设计算法的时间复杂度和空间复杂度。

<Solution>

**【解析】**

(1) 算法思想：先将集合 A 中的元素按照单调递增的顺序进行排序，再把集合 A 分成：$A_1$ 和 $A_2$ 两个集合，集合 $A_1$ 保存前 $\lfloor n/2\rfloor$ 个元素，集合 $A_2$ 保存后 $\lceil n/2\rceil$ 个元素。

本题也可以采用类似快排的拆分思想，不需要对集合 A 进行排序，仅需要让一边的子集中的每个元素小于另一边的子集中的每个元素即可。首先将 A 从枢轴处分为两个子集，之后根据枢轴所处位置（用 $i$ 进行表示）进行以下处理：

① 若 $i=\lfloor n/2\rfloor$，则算法结束；

② 若 $i<\lfloor n/2\rfloor$，则枢轴之前的所有元素划分给 $A_1$，继续划分 $i$ 之后的元素；

③ 若 $i>\lfloor n/2\rfloor$，则枢轴之后的所有元素划分给 $A_2$，继续划分 $i$ 之前的元素。

(2) C 语言代码实现如下：

```c
int setPartition(int a[], int n) {
    int pivotkey, // 划分基准值
    left = 0, left0 = 0, // 左边界、左边界初值
    right = n - 1, right0 = n - 1, // 右边界、右边界初值
    flag = 1, // 标记位
    k = n / 2; // 要划分的集合元素个数
    int sum1 = 0, sum2 = 0; // 两个子集合元素之和
    while (flag) {
        pivotkey = a[left]; // 取第一个元素作为基准值
        // 将小于基准值的元素放到左边，大于等于基准值的元素放到右边
        while (left < right) {
            while (left < right && a[right] >= pivotkey) --right;
            if (left != right) a[left] = a[right];
            while (left < right && a[left] <= pivotkey) ++left;
            if (left != right) a[right] = a[left];
        }
        a[left] = pivotkey; // 将基准值放到中间
        if (left == k - 1) {
            flag = 0; // 标记位设为 0，退出循环
        } else {
            if (left < k - 1) {
                left+=1;
                left0=left
                right = right0; // 右边界回到初值
            } else {
                right-=1;
                right0=right;
                left = left0; // 左边界回到初值
            }
        }
    }
    // 计算两个子集合的元素之和
    for (int i = 0; i < k; ++i) sum1 += a[i];
    for (int i = k; i < n; ++i) sum2 += a[i];
    return sum2 - sum1; // 返回两个子集合元素之和的差值
}
```

{/* 原书代码 left0=left 行末缺少分号，按原文保留；正文枢轴位置与代码分别采用从 1 和从 0 计数的写法。 */}

(3) 因为不是对全部元素进行完整的快速排序，时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。

**【真题溯源】** 这道题在 LeetCode 上没有直接对应的原题，其算法内核是经典的选择问题（快速排序划分）思想。

> **【点评】** 常规题。考查数组操作的算法题。首先考生可以举一个实例数组，排序后发现，将数组均分成两个长度相等的数组，返回中间位置即可解决问题。所以此时考生可以考虑先将数组排序，再处理后续问题，这也是推荐的方法。考场上留给算法题的时间非常有限，本题的暴力解法很直白也容易想到，暴力解法能拿 8 分左右。这里的最优解是快速排序中划分的思想，如果考生能想到，这道算法题还是比较容易拿满分的。

</Solution>

</Question>

## 7.3 选择类排序

<Question id="408-3135dc-019" number={1} type="essay" tags="来源:2022考研408">

现有 $n(n>100000)$ 个数保存在一维数组M中，需要查找M中最小的10个数。请回答下列问题：

(1) 设计一个完成上述查找任务的算法，要求平均情况下的比较次数尽可能少，简述其算法思想（不需要程序实现）。  
(2) 说明你所设计的算法平均情况下的时间复杂度和空间复杂度。

<Solution>

**【解析】**

(1) **【解法一】** 用插入排序的思想求解：① 定义一个含有 10 个元素的辅助数组 $A[10]$，数组 $A$ 的初始元素为数组 $M$ 的前 10 个元素。将数组 $A$ 中的元素按升序排列。② 让数组 $M$ 的第 $11\sim n$ 个元素逐个与数组 $A$ 中的最后一个元素 $A[9]$ 进行比较：当数组 $M$ 的第 $i$ 个元素与 $A[9]$ 进行比较时，若该元素小于 $A[9]$，则删除 $A[9]$，并将数组 $M$ 的第 $i$ 个元素按升序插入数组 $A$ 中；若该元素不小于 $A[9]$，则让第 $i+1$ 个元素继续比较。重复这一过程直到遍历完数组 $M$ 内所有元素为止。③ 最后数组 $A$ 中保存的就是最小的 10 个元素。

**【解法二】** 用堆排序的方法求解：① 先建立一个含有 10 个元素的大根堆，大根堆中初始元素为数组 $M$ 的第 $1\sim10$ 个元素。② 让数组 $M$ 的第 $11\sim n$ 个元素逐个与堆顶元素进行比较：当数组 $M$ 的第 $i$ 个元素与堆顶元素进行比较时，若该元素小于堆顶元素，则删除当前的堆顶元素，将第 $i$ 个元素插入大根堆；若该元素不小于堆顶元素，则让第 $i+1$ 个元素继续比较。重复这一过程直到遍历完数组 $M$ 内所有元素为止。③ 最后大根堆里的 10 个元素就是最小的 10 个元素。

(2) 算法在平均情况下的时间复杂度是 $O(n)$，空间复杂度是 $O(1)$。

**【提示】** 此题是典型的 top-k 问题，关于此类型题有多种解法，考生可在 LeetCode 上动手实践下：[数组中的第 K 个最大元素](https://leetcode.cn/problems/kth-largest-element-in-an-array)

**【点评】** 难题。这道题没有告诉考生要考什么数据结构、要考什么算法，需要考生根据题目要求，自己选择合适的数据结构，自己设计相应的算法，并简要表述出来。这类题目首先需要确定要考查的知识，如果这一步做不好，也许整道题就是 0 分了。这种题灵活性很强，要求考生会灵活运用，符合考研这种国家级选拔性考试要求。这种题 408 已经考过 5 次：2022 年 42 题、2020 年 42 题、2019 年 42 题、2014 年 42 题、2012 年 41 题。而且，自 2023～2025，已经有 3 年没考过这种题，考生需要重视。在竞成的《数据结构考研复习全书》的最后一章，有专门针对这种题的专题练习。

</Solution>

</Question>

## 7.5 各种内部排序算法总结

<Question id="408-3135dc-034" number={1} type="essay" tags="来源:2021考研408">

已知某排序算法如下：

```c
void cmpCountSort(int a[], int b[], int n) {
    int i, j, *count;

    count = (int *)malloc(sizeof(int) * n);

    for (i = 0; i < n; i++) count[i] = 0;

    for (i = 0; i < n - 1; i++)
        for (j = i + 1; j < n; j++)
            if (a[i] < a[j]) count[j]++;
            else count[i]++;

    for (i = 0; i < n; i++) b[count[i]] = a[i];

    free(count);
}
```

请回答下列问题：

(1) 若有 `int a[] = {25, -10, 25, 10, 11, 19}, b[6]`，则调用 `cmpCountSort(a, b, 6)` 后数组b中的内容是什么？  
(2) 若a中含有n个元素，则算法执行过程中，元素之间的比较次数是多少？  
(3) 该算法是稳定的吗？若是，则阐述理由；否则，修改为稳定排序算法。

<Solution>

**【解析】**

(1) `b={-10,10,11,19,25,25}`。题中的算法是一个基于比较的排序算法（采用了计数排序思想）。代入题目给出的数据，跟着代码手工运行推导一遍即可。第 2 和第 3 个 for 循环内容是排序算法的主体。`count[x] = y`，表示数组中有 a 中有 y（`count[x]`）个元素比 `a[x]` 小。y（`count[x]`）越大表示比 `a[x]` 小的元素越多，`a[x]` 在新数组 b 中的排序就越靠后。算法比较结束后最终 count 数组的值为 `{5,0,4,1,2,3}`，根据 count 数组的值可得数组 b 的值。

(2) 元素之间的比较次数是 $\frac{n(n-1)}{2}$。第一个元素会与后面 $n-1$ 个元素逐个比较，共比较 $n-1$ 次；第二个元素会与后面的 $n-2$ 个元素逐个比较，共比较 $n-2$ 次；$\cdots$；第 $n-1$ 个元素会与最后一个元素比较，共比较 1 次。总比较次数为 $(n-1)+(n-2)+\cdots+1=n(n-1)/2$ 次。

(3) 该算法是不稳定的。将程序中的 if 的判断条件改为 “`if(a[i] <= a[j])`”，即可变为稳定的算法。根据第一问中两个 25 就可以看出，根据代码，第一个 25（`a[0]`）是最大的，放到了 `b[5]` 位置，第二个 25（`a[2]`）放在了 `b[4]` 位置，所以是不稳定的。将条件变化之后，`a[0]` 放在了 `b[4]` 位置，`a[2]` 放在了 `b[5]` 位置。

**【点评】** 常规题。这题其实是考查对 C 语言代码的理解，不涉及数据结构的内容，更非数据结构这个科目的主干内容，其实是不适合在 408 中考查的，在 C 语言考试中考这种题比较合适。这也是迄今为止（2009～2025）408 中唯一一次考这种题。单纯从代码中，看不出这段代码的含义，但把题目给出的数据代入到代码中，手工运行一遍即可发现这段代码实现的功能（代码题都是这种解题套路）。处理起来比较费时间。

</Solution>

</Question>

## 7.6 外部排序

<Question id="408-3135dc-038" number={1} type="essay" tags="来源:2023考研408">

（10分）对含有 $n(n>0)$ 个记录的文件进行外部排序，采用置换-选择排序生成初始归并段时需要使用一个工作区，工作区中能保存m个记录，请回答下列问题：

(1) 若文件中有19个记录，其关键字依次是51,94,37,92,14,63,15,99,48,56,23,60,31,17,43,8,90,166,100。当m=4时，可生成几个初始归并段？每个归并段各是什么？  
(2) 对任意 $n\gg m>0$，生成的第一个初始归并段的长度最大值和最小值分别是多少？

<Solution>

**【解析】**

（1）共生成 3 个初始归并段，分别为：① 37，51，63，92，94，99；② 14，15，23，31，48，56，60，90，166；③ 8，17，43，100。具体步骤如下：

① 读取 51，94，37，92 四个记录进入工作区，选择最小元素 37 进入归并段，同时 MINIMAX 更新为 37。

② 读取 14 进入工作区，从工作区 51，94，92，14 中选择大于 MINIMAX 的最小元素 51 进入归并段，同时 MINIMAX 更新为 51。

③ 读取 63 进入工作区，从工作区 94，92，14，63 中选择大于 MINIMAX 的最小元素 63 进入归并段，同时 MINIMAX 更新为 63。

④ 读取 15 进入工作区，从工作区 94，92，14，15 中选择大于 MINIMAX 的最小元素 92 进入归并段，同时 MINIMAX 更新为 92。

⑤ 读取 99 进入工作区，从工作区 94，14，15，99 中选择大于 MINIMAX 的最小元素 94 进入归并段，同时 MINIMAX 更新为 94。

⑥ 读取 48 进入工作区，从工作区 14，15，99，48 中选择大于 MINIMAX 的最小元素 99 进入归并段，同时 MINIMAX 更新为 99。

⑦ 读取 56 进入工作区，从工作区 14，15，48，56 中选择大于 MINIMAX 的最小元素，工作区中不存在这样的元素，**第一个归并段完成。**

⑧ 从工作区四个元素 14，15，48，56 选择最小元素 14，并将 14 放入归并段，同时更新 MINIMAX 的值为 14。

⑨ 读取 23 进入工作区，从工作区 15，48，56，23 中选择大于 MINIMAX 的最小元素 15 进入归并段，同时 MINIMAX 更新为 15。

⑩ 读取 60 进入工作区，从工作区 48，56，23，60 中选择大于 MINIMAX 的最小元素 23 进入归并段，同时 MINIMAX 更新为 23。

⑪ 读取 31 进入工作区，从工作区 48，56，60，31 中选择大于 MINIMAX 的最小元素 31 进入归并段，同时 MINIMAX 更新为 31。

⑫ 读取 17 进入工作区，从工作区 48，56，60，17 中选择大于 MINIMAX 的最小元素 48 进入归并段，同时 MINIMAX 更新为 48。

⑬ 读取 43 进入工作区，从工作区 56，60，17，43 中选择大于 MINIMAX 的最小元素 56 进入归并段，同时 MINIMAX 更新为 56。

⑭ 读取 8 进入工作区，从工作区 60，17，43，8 中选择大于 MINIMAX 的最小元素 60 进入归并段，同时 MINIMAX 更新为 60。

⑮ 读取 90 进入工作区，从工作区 17，43，8，90 中选择大于 MINIMAX 的最小元素 90 进入归并段，同时 MINIMAX 更新为 90。

⑯ 读取 166 进入工作区，从工作区 17，43，8，166 中选择大于 MINIMAX 的最小元素 166 进入归并段，同时 MINIMAX 更新为 166。

⑰ 读取 100 进入工作区，从工作区 17，43，8，100 中选择大于 MINIMAX 的最小元素，工作区中不存在这样的元素，**第二个归并段完成。**

⑱ 因为所有记录已经全在工作区，**按升序序列可得到第三个归并段：8，17，43，100。**

（2）① 当有 $n$ 个记录按升序排序时，新归并段的长度可以达到 $n$，此时第一个初始归并段的长度最大值为 $n$。② 假设工作区大小为 $m$，同时若初始归并段的元素都小于工作区最小的元素，则新的归并段大小只能为 $m$，此时第一个初始归并段的最小值为 $m$。

</Solution>
