## 二、栈：真正理解出栈顺序的约束

### 1. 栈的本质不是逆序，而是局部逆序

栈遵循后进先出（LIFO）。

但是，**后进先出不等于出栈序列一定是入栈序列的逆序。**

假设入栈顺序为 $1,2,3$。

| 出栈序列  | 是否可能 |
| ----- | ---- |
| 1,2,3 | 可以   |
| 1,3,2 | 可以   |
| 2,1,3 | 可以   |
| 2,3,1 | 可以   |
| 3,2,1 | 可以   |
| 3,1,2 | 不可以  |

为什么最后一种不可以？

为了让 3 最先出栈，必须先将 1、2、3 全部压栈。

```text
       栈顶
      ┌───┐
      │ 3 │
      ├───┤
      │ 2 │
      ├───┤
      │ 1 │
      └───┘
       栈底
```

3 出栈后，1 被 2 压住，因此不可能先输出 1。

由此得到栈最重要的规律：

<Callout type="idea" title="出栈序列的核心约束">

**同时留在栈中的元素，其出栈相对顺序必定与入栈相对顺序相反。**

</Callout>

注意关键词是“同时留在栈中”。

### 2. 出栈序列的万能解题方法

任何出栈序列判断题，都可以采用目标驱动模拟法：

1. 查看下一个需要输出的元素。
2. 如果它还未入栈，就依次压入元素，直到它成为栈顶。
3. 如果它是栈顶，立即弹出。
4. 如果它已经在栈中，却不是栈顶，则序列不合法。
5. 如果还要求栈容量，记录模拟过程中的最大栈深。

不需要尝试各种入栈、出栈组合。对互异元素而言，给定目标出栈序列后，满足它的标准操作顺序实际上是确定的。

#### 代表题1：2009年408真题，题库真题第1题

元素依次进入栈：

$$
a,b,c,d,e,f,g
$$

每个元素出栈后立即进入队列，最终出队顺序为：

$$
b,d,c,f,e,a,g
$$

问栈的容量至少是多少？

**第一步：消除无关信息。**

队列先进先出，不改变元素之间的相对顺序，所以最终出队顺序就是栈的出栈顺序。

**第二步：按照目标顺序模拟。**

| 操作       | 栈底 → 栈顶 | 栈深 |
| -------- | ------- | -- |
| a、b 入栈   | a,b     | 2  |
| b 出栈     | a       | 1  |
| c、d 入栈   | a,c,d   | 3  |
| d、c 出栈   | a       | 1  |
| e、f 入栈   | a,e,f   | 3  |
| f、e、a 出栈 | 空       | 0  |
| g 入栈并出栈  | 空       | 0  |

因此最大栈深为 3。

**答案：C，容量至少为3。**

#### 从这道题迁移到其他题型

| 题目要求      | 模拟时关注什么      |
| --------- | ------------ |
| 判断序列是否合法  | 是否需要越过栈顶取元素  |
| 求最小栈容量    | 最大栈深         |
| 限制栈容量     | 是否出现上溢       |
| 不允许连续三次出栈 | 是否连续出现三次 Pop |
| 栈与队列组合    | 队列保持顺序，栈改变顺序 |

题库中的2010年、2018年、2020年、2022年相关真题，以及王道卷六、卷七的模拟题，都可以用这套方法解决。

### 3. 出栈序列计数：不要盲目枚举

这类题比单纯判断合法性更值得深入理解。

#### 代表题2：2013年408真题与竟成模拟五的同源变式

**2013年真题：**

入栈序列为 $1,2,\ldots,n$，出栈序列为 $p_1,p_2,\ldots,p_n$。若 $p_2=3$，则 $p_3$ 可能取值的个数是多少？

竟成模拟五将条件推广为：

$$
p_2=k,\quad k>3
$$

求 $p_3$ 可能取值的个数。

这两道题应该放在一起学习。

当第二个元素 $k$ 出栈时，$1$ 到 $k$ 肯定都已经入过栈。

但此时只出栈了两个元素，其中一个是 $k$，所以在比 $k$ 小的元素中，最多只有一个已经离开了栈。

接下来分两类讨论。

**情况一：第三个出栈元素小于 $k$。**

如果 $k-1$ 没有出栈，那么栈顶就是 $k-1$。

如果 $k-1$ 已经出栈，那么栈顶就是 $k-2$。

因此，小于 $k$ 的候选值只有：

$$
k-2,\quad k-1
$$

更小的元素仍然被压在下面。

**情况二：第三个出栈元素大于 $k$。**

可以通过继续入栈，得到任意一个更大的目标元素：

$$
k+1,k+2,\ldots,n
$$

共有 $n-k$ 种可能。

合并得到：

$$
\boxed{n-k+2}
$$

因此：

- 竟成模拟五的答案为 D。
- 2013年真题令 $k=3$，得到 $n-1$，答案为 C。

**这道题的本质是：根据已经发生的出栈次数，推断还有多少元素可能被压住。**

这里还要特别注意，2013年真题的原解析认为 $p_1$ 只能为 1 或 2，这个说法并不严谨。例如 $4,3,2,1$ 也是合法出栈序列。虽然原题最终答案正确，但不能记住这个错误的中间结论。

### 4. 出栈序列计数的其他重要规律

2011年真题问：$a,b,c,d,e$ 依次入栈，以 $d$ 开头的合法出栈序列有多少种？

当 $d$ 出栈后，栈中剩余 $a,b,c$，它们的相对出栈顺序一定是：

$$
c,b,a
$$

而尚未入栈的 $e$ 可以插入这三个元素形成的四个空隙。

```text
_ c _ b _ a _
```

所以共有4种。

这个方法比逐一枚举更重要：**先确定不可改变的相对顺序，再考虑自由元素可以插入的位置。**

另外，作为基础知识的补充，如果 $n$ 个互异元素依次入栈，栈容量无限制，所有元素最终全部出栈，则合法出栈序列总数为卡特兰数：

$$
C_n=\frac{1}{n+1}\binom{2n}{n}
$$

| 元素个数 | 合法出栈序列数 |
| ---- | ------- |
| 1    | 1       |
| 2    | 2       |
| 3    | 5       |
| 4    | 14      |
| 5    | 42      |
| 6    | 132     |

有额外容量限制或指定出栈位置时，不能直接套用卡特兰数。

### 5. 顺序栈与共享栈：指针含义决定公式

王道卷五、竟成模拟四都考查了共享栈判满，值得重视。

首先理解两种普通顺序栈定义。

假设数组长度为 $n$。

| 比较项  | top 指向栈顶元素     | top 指向下一空位置    |
| ---- | -------------- | -------------- |
| 初始值  | -1             | 0              |
| 判空   | `top == -1`    | `top == 0`     |
| 判满   | `top == n-1`   | `top == n`     |
| 入栈   | `A[++top] = x` | `A[top++] = x` |
| 出栈   | `x = A[top--]` | `x = A[--top]` |
| 元素个数 | `top+1`        | `top`          |

共享栈也是同样的道理。

两个栈分别从数组两端向中间增长：

```text
低地址                     高地址
┌───┬───┬───┬───┬───┬───┐
│ A │ B │   │   │ D │ C │
└───┴───┴───┴───┴───┴───┘
        →       ←
        S1      S2
```

如果两个 top 指向实际栈顶元素，满栈条件为：

$$
top_1+1=top_2
$$

如果两个 top 指向各自下一空位置，满栈条件为：

$$
top_1=top_2+1
$$

两条公式看起来正好相反，其实是因为指针定义不同。

例如数组长度为6，两个栈各占3格：

```text
下标    0   1   2   3   4   5
数组  [ A | B | C | F | E | D ]
                ↑   ↑
```

指向实际栈顶时，两个指针为2和3。

指向下一空位置时，两个指针为3和2。

**考场上不要凭印象背判满条件。画一个只剩最后一个空格的数组，再模拟一次入栈，公式自然就出来了。**

## 三、队列：彻底掌握循环队列与指针问题

### 1. 循环队列的所有公式来自一个距离

普通队列遵循先进先出（FIFO），只允许队尾插入、队头删除。

循环队列的本质是：**把有限长度的数组当作一个可以循环使用的环。**

它解决的是普通顺序队列可能产生的假溢出问题。

设数组长度为 $m$，front 指向队头元素，rear 指向队尾元素的下一位置，并且牺牲一个存储单元区分空满。

例如长度为8的循环队列：

```text
下标    0   1   2   3   4   5   6   7
数组  [ C | D |   |   |   |   | A | B ]
                ↑               ↑
               rear            front
```

实际队列为：

$$
A\rightarrow B\rightarrow C\rightarrow D
$$

队列占用了两段空间：

$$
6,7\quad\text{以及}\quad0,1
$$

队长为：

$$
(8-6)+2=4
$$

从而统一得到：

$$
\boxed{L=(rear-front+m)\bmod m}
$$

这是循环队列最核心的公式。

其他公式都可以从它推出：

| 操作或状态 | 表达式                              |
| ----- | -------------------------------- |
| 队列长度  | `(rear-front+m)%m`               |
| 队空    | `front == rear`                  |
| 队满    | `(rear+1)%m == front`            |
| 入队    | `A[rear]=x; rear=(rear+1)%m;`    |
| 出队    | `x=A[front]; front=(front+1)%m;` |
| 最大容量  | $m-1$                        |

为什么队满时是 rear 的下一位置等于 front？

因为最后一格必须保留，否则 rear 继续移动后就会与 front 重合，无法区分空队列和满队列。

### 2. 真正容易出错的是指针定义改变

#### 代表题3：2011年408真题，题库真题第10题

循环队列存储在数组 $A[0,\ldots,n-1]$ 中，front 和 rear 分别指向实际的队头元素和队尾元素。

初始为空，并且要求第一个入队元素存储在 $A[0]$ 中。

求 front 和 rear 的初始值。

这道题不能直接套用常规的 `front=rear=0`。

因为题目规定 rear 指向实际队尾，所以入队操作应该是：

```c
rear = (rear + 1) % n;
A[rear] = x;
```

第一次入队后，rear 必须等于0，因此：

$$
(rear+1)\bmod n=0
$$

推出：

$$
rear=n-1
$$

而 front 指向第一个实际元素的位置0，所以：

$$
\boxed{front=0,\quad rear=n-1}
$$

答案为 B。

**真正考查的不是循环队列的初始化公式，而是能否根据指针含义反推初始状态。**

2014年真题又改回了 rear 指向队尾下一位置的常规定义，王道卷六、竟成模拟四则考查队长公式。

遇到这些题，先弄清楚三个问题：front 指哪里？rear 指哪里？是否保留空单元？

如果使用额外的计数器 size 或标志位区分空满，那么长度为 $m$ 的数组可以存储 $m$ 个元素，此时不能只依靠两指针是否重合判断空满。

### 3. 双端队列：从操作限制推导输出规律

2010年、2021年真题均考查输出受限的双端队列。

| 类型       | 入队限制 | 出队限制 |
| -------- | ---- | ---- |
| 普通队列     | 一端   | 另一端  |
| 双端队列     | 两端   | 两端   |
| 输入受限双端队列 | 一端   | 两端   |
| 输出受限双端队列 | 两端   | 一端   |

以2010年真题为例，$a,b,c,d,e$ 依次全部入队，然后再出队。

如果只能从左端出队，后续新元素只能插在已有元素的最左侧或最右侧，不能插入中间。

因此最先入队的 $a,b$ 必定相邻。

题目选项 `dbcae` 中，$a,b$ 被 $c$ 隔开，直接排除。

更一般地，如果输入顺序为 $1,2,\ldots,n$，先全部入队再从固定一端出队，那么可以反向检查输出序列：$n$ 必须在两端之一，删除 $n$ 后，$n-1$ 也必须在两端之一，以此类推。

**注意适用条件**：这个整体反向删除方法建立在先全部入队、再全部出队的前提下。如果允许入队和出队交替进行，就需要根据具体操作过程推导，不能机械套用。

### 4. 链式栈与链式队列的高价值结论

王道卷三、卷七、卷八分别考查了这些内容。

| 存储结构      | 核心知识                    |
| --------- | ----------------------- |
| 链栈        | 通常用链表头部作为栈顶             |
| 普通链式队列    | 头部删除、尾部插入               |
| 无头结点的循环链队 | 只设置 rear 也能直接找到队头       |
| 有头结点的链队   | 空队列时 front 与 rear 指向头结点 |
| 无头结点的普通链队 | 空队列时 front 与 rear 均为空指针 |

其中一个很值得掌握的设计是：**不带头结点的循环单链表，只设置尾指针，就可以使入队、出队均为 $O(1)$。**

```text
        队头                队尾
         ↓                   ↓
        [A] ───→ [B] ───→ [C] ← rear
         ↑                   │
         └───────────────────┘
```

因为 `rear->next` 就是队头，所以不需要遍历整个链表。

这也说明了判断链式结构时间复杂度的本质：

> 不是看它有多少个结点，而是看目标结点能否直接定位，以及修改操作需要多少次指针操作。

对于代码选择题，还要特别注意空队列和只有一个结点的边界情况。王道卷八的链队入队题，原答案实际上默认了队列非空；如果队列为空，就不能直接执行 `rear->next=s`。

## 四、栈和队列的应用：表达式是重点

### 1. 中缀、前缀、后缀表达式的本质

不要将它们理解为三种毫无关联的字符串。

它们只是同一运算结构的三种表示方式。

例如：

$$
a+b\times c
$$

对应的表达式树：

```text
          +
         / \
        a   ×
           / \
          b   c
```

| 表达式类型 | 结果          | 对应遍历         |
| ----- | ----------- | ------------ |
| 前缀    | `+ a * b c` | 先序遍历         |
| 中缀    | `a + b * c` | 中序遍历（必要时加括号） |
| 后缀    | `a b c * +` | 后序遍历         |

运算关系没有改变，只是运算符的位置不同。

### 2. 中缀转后缀的最快手算方法

如果题目只问最终表达式，不要求栈的变化过程，可以按照运算优先级分层转换。

例如2024年408真题：

$$
x+y\times(z-u)/v
$$

它的运算结构为：

$$
x+\frac{y\times(z-u)}{v}
$$

先将括号内部转换，再处理乘除，最后处理加法。

| 运算部分                 | 后缀形式                |
| -------------------- | ------------------- |
| $z-u$            | `z u -`             |
| $y\times(z-u)$   | `y z u - *`         |
| $y\times(z-u)/v$ | `y z u - * v /`     |
| 完整表达式                | `x y z u - * v / +` |

答案为 A。

这里要注意乘除同优先级时的左结合性：

$$
a/b\times c=(a/b)\times c
$$

而不是：

$$
a/(b\times c)
$$

### 3. 运算符栈的变化：必须掌握标准算法

如果题目问栈内元素、最大栈深等，就不能只转换最终表达式，而要模拟运算符栈。

| 扫描到的内容 | 操作                                 |
| ------ | ---------------------------------- |
| 操作数    | 直接输出                               |
| 左括号    | 压栈                                 |
| 右括号    | 弹出运算符直到左括号，再丢弃左括号                  |
| 普通运算符  | 对常见左结合运算符，先弹出优先级大于或等于它的栈顶运算符，再将它入栈 |
| 表达式结束  | 弹出剩余运算符                            |

左括号具有隔离作用，比较优先级时不能越过左括号。

#### 代表题4：2012年408真题，题库真题第15题

将以下中缀表达式转换为后缀表达式：

$$
a+b-a\times((c+d)/e-f)+g
$$

问运算符栈中同时保存的元素最多有几个。

这道题其实不需要写出后缀表达式，也不需要记录操作数。

只观察运算符栈即可。

| 扫描到    | 栈底 → 栈顶     | 栈深    |
| ------ | ----------- | ----- |
| 第一个 +  | `+`         | 1     |
| 第一个 -  | `-`         | 1     |
| \*     | `- *`       | 2     |
| (      | `- * (`     | 3     |
| (      | `- * ( (`   | 4     |
| 括号内的 + | `- * ( ( +` | **5** |
| )      | `- * (`     | 3     |
| /      | `- * ( /`   | 4     |
| 括号内的 - | `- * ( -`   | 4     |
| )      | `- *`       | 2     |
| 最后的 +  | `+`         | 1     |

最大栈深为5，答案为 A。

<Callout type="warn" title="运算符栈">

**重要陷阱：左括号也占用运算符栈的空间。**

</Callout>

王道卷五、卷八的两道模拟题，以及2014年真题，都是这个考点的直接变式。

### 4. 操作数栈：完全不同的一套计数方法

运算符栈用于确定运算顺序，操作数栈用于计算结果。

计算后缀表达式时，遇到操作数就入栈；遇到二元运算符，就弹出两个操作数，运算后将结果入栈。

因此，只要求操作数栈的最大深度时：

$$
\text{遇操作数：栈深}+1
$$

$$
\text{遇二元运算符：栈深}-1
$$

完全不需要实际计算。

竟成模拟二考查了容量为3的操作数栈，表达式为：

$$
A-B\times(C-D)+E
$$

对应后缀表达式：

```text
A B C D - * - E +
```

栈深变化：

| 扫描元素 | A | B | C | D     | - | \* | - | E | + |
| ---- | - | - | - | ----- | - | -- | - | - | - |
| 栈深   | 1 | 2 | 3 | **4** | 3 | 2  | 1 | 2 | 1 |

按题目采用的后缀求值模型，最大栈深为4，因此容量为3时会发生上溢。

如果要求计算实际结果，还必须注意：

<Callout type="warn" title="操作数顺序">

**先弹出的是右操作数，后弹出的是左操作数。**

</Callout>

假设先弹出 $a$，再弹出 $b$，运算结果应该是：

$$
b\ \mathrm{op}\ a
$$

而不是：

$$
a\ \mathrm{op}\ b
$$

2018年408真题就是专门考查这一点。

### 5. 栈和队列的典型应用不能只靠背诵

| 应用场景       | 常用结构 | 本质原因       |
| ---------- | ---- | ---------- |
| 函数调用       | 栈    | 后调用的函数先返回  |
| 递归与回溯      | 栈    | 从最近的状态返回   |
| 括号匹配       | 栈    | 最近的左括号优先匹配 |
| 深度优先遍历 DFS | 栈    | 深入后回溯      |
| 广度优先遍历 BFS | 队列   | 按发现顺序处理    |
| 树的层序遍历     | 队列   | 逐层访问       |
| 打印缓冲区      | 队列   | 保持任务先后顺序   |

2017年真题考查了一个常见错误：非递归方式重写递归程序时必须使用栈。

这是错误的。有些递归可以直接转换为循环，未必需要显式栈。

另外，模拟题还考查了栈与队列相互实现的问题。

两个栈可以实现一个队列：第一次转移实现逆序，第二次弹出恢复原来的先进先出顺序。使用常见的惰性转移实现时，出队最坏时间复杂度为 $O(n)$，均摊时间复杂度为 $O(1)$。

一个队列也可以实现一个栈：新元素入队后，将原有元素依次出队并重新入队，使新元素位于队头。

但在只允许普通栈操作、没有额外线性存储空间的标准模型下，一个栈不能模拟任意长度的普通队列。

### 6. 一道值得掌握的思想型真题：2016年火车轨道问题

火车驶入顺序为：

$$
8,4,2,5,3,9,1,6,7
$$

每条轨道只能从一端进入、另一端驶出。要求最后按照1至9的顺序输出，至少需要多少条轨道？

一条轨道就是一个队列。

由于要求最终递增输出，因此同一条轨道里的火车必须按递增顺序进入。

观察：

$$
8,4,2,1
$$

这四个元素在输入中形成严格递减子序列。任意两个如果处于同一轨道，就会违反最终递增输出的要求，所以至少需要四条轨道。

而下面的分配恰好可以做到：

| 轨道 | 入队顺序    |
| -- | ------- |
| 1  | 8,9     |
| 2  | 4,5,6,7 |
| 3  | 2,3     |
| 4  | 1       |

所以答案为4。

这道题不应只记住答案。它背后是一个非常有价值的抽象方法：

**将一个序列划分为最少数量的递增子序列，其最少数量等于最长递减子序列的长度（元素互异时）。**

遇到复杂的实际应用题，优先想清楚数据结构施加了怎样的顺序约束，再求解。

## 五、数组和特殊矩阵：用一个公式解决绝大部分题目

这是本章非常适合实现稳定得分的部分。

题库中2016年、2018年、2020年、2021年真题，以及多道模拟题，都考查了存储位置和地址计算。

### 1. 数组地址计算的统一模型

任何连续存储的数组，都满足：

$$
\boxed{\text{地址}=\text{基地址}+\text{元素偏移量}\times\text{元素大小}}
$$

所以真正需要解决的只有一个问题：

**目标元素前面有多少个元素？**

对于一个具有 $m$ 行、$n$ 列的二维数组，下标从0开始，每个元素占用 $w$ 个存储单元。

按行优先存储：

$$
\operatorname{LOC}(A[i][j]) =B+(in+j)w
$$

按列优先存储：

$$
\operatorname{LOC}(A[i][j]) =B+(jm+i)w
$$

不要混淆行数与列数。按行优先时，跨越一整行需要跳过 $n$ 个元素；按列优先时，跨越一整列需要跳过 $m$ 个元素。

2021年真题给定 $A[0][0]$ 的地址为100，$A[3][3]$ 的地址为220，每个元素占一个存储单元。

对角线上每移动一次，行和列都增加1，地址增加量恒定，因此：

$$
d=\frac{220-100}{3}=40
$$

于是：

$$
\operatorname{LOC}(A[5][5]) =100+5\times40=300
$$

这种等差数列的思想比先求数组列数再计算更加快捷。

### 2. 特殊矩阵压缩存储的万能方法

很多同学会死记上三角、下三角、对称矩阵等一大堆公式。

实际上，只需要记住：

$$
\boxed{k=\text{前面完整行或列的元素数}+\text{当前行或列的偏移量}}
$$

这里的 $k$ 是从0开始的一维数组下标。

下面以一个五阶矩阵为例，● 表示需要存储的位置，· 表示不单独存储的位置。

```text
上三角矩阵              下三角矩阵

● ● ● ● ●              ● · · · ·
· ● ● ● ●              ● ● · · ·
· · ● ● ●              ● ● ● · ·
· · · ● ●              ● ● ● ● ·
· · · · ●              ● ● ● ● ●
```

由此可以直接看出：

| 存储方式  | 各行或列包含的元素数           |
| ----- | -------------------- |
| 上三角按行 | $n,n-1,\ldots,1$ |
| 上三角按列 | $1,2,\ldots,n$   |
| 下三角按行 | $1,2,\ldots,n$   |
| 下三角按列 | $n,n-1,\ldots,1$ |

所有公式都是等差数列求和，根本不需要分别硬背。

#### 代表题5：2020年408真题，题库真题第23题

将一个 $10\times10$ 对称矩阵的上三角部分按列优先存入C语言的一维数组中。

求 $m_{7,2}$ 对应的一维数组下标。

<Steps>

<Step>

### 第一步：确定实际存储的位置。

因为是对称矩阵：

$$
m_{7,2}=m_{2,7}
$$

题目只存上三角，因此需要计算第2行、第7列的元素位置。

</Step>

<Step>

### 第二步：数前面完整的列。

上三角按列存储时，第1列有1个元素，第2列有2个元素。

前6列共有：

$$
1+2+3+4+5+6=21
$$

</Step>

<Step>

### 第三步：数当前列内的偏移。

第7列中的第2行，是该列第2个元素，偏移量为1。

所以：

$$
k=21+1=\boxed{22}
$$

答案为 C。

这道题覆盖了四个重要陷阱：对称性映射、上三角、列优先、数组从0开始。

掌握它之后，其他矩阵压缩题只需要改变计数方向。

</Step>

</Steps>

### 3. 四种三角矩阵映射公式的统一总结

以下统一规定：矩阵的行列下标 $i,j$ 从1开始，一维数组下标 $k$ 从0开始，并且存储主对角线。

| 压缩方式  | 一维数组下标 $k$                  |
| ----- | ------------------------------- |
| 下三角按行 | $\frac{i(i-1)}2+j-1$        |
| 上三角按列 | $\frac{j(j-1)}2+i-1$        |
| 上三角按行 | $\frac{(i-1)(2n-i+2)}2+j-i$ |
| 下三角按列 | $\frac{(j-1)(2n-j+2)}2+i-j$ |

公式可以作为复习时的检验工具，考场上忘记也没有关系。

上三角、下三角共需要保存的主对角线及一侧元素数均为：

$$
\frac{n(n+1)}2
$$

如果未存储区域是某个共同的非零常量，还可能需要额外一个单元保存该常量，具体按照题设判断。

### 4. 三对角矩阵：同样使用计数法

2016年408真题考查了100阶三对角矩阵按行优先压缩存储，求 $m_{30,30}$ 的一维数组下标。

三对角矩阵只保存满足以下条件的带状区域：

$$
|i-j|\leq1
$$

一个五阶三对角矩阵的结构如下：

```text
● ● · · ·
● ● ● · ·
· ● ● ● ·
· · ● ● ●
· · · ● ●
```

第一行和最后一行各保存两个元素，中间每行保存三个元素。

前29行元素数：

$$
2+28\times3=86
$$

第30行保存的是：

$$
m_{30,29},m_{30,30},m_{30,31}
$$

因此 $m_{30,30}$ 的行内偏移量为1。

得到：

$$
k=86+1=\boxed{87}
$$

答案为 B。

在矩阵下标从1开始、一维数组下标从0开始、按行优先存储的条件下，可以进一步得到：

$$
\boxed{k=2i+j-3}
$$

三对角矩阵总存储元素数为：

$$
\boxed{3n-2}
$$

这些公式都能从图形直接推导出来。

### 5. 三维数组压缩：只是多增加一个层偏移

竟成模拟一考查了一个 $10\times10\times10$ 的三维数组，其中每个固定第三维下标的二维矩阵是对称矩阵。

按照题库预期的列优先存储定义，每一层压缩后只有：

$$
\frac{10\times11}{2}=55
$$

个元素，而不是100个元素。

整个位置计算可以分解为：

$$
\text{总偏移量} =\text{层数偏移}\times55+\text{层内偏移量}
$$

这道模拟题看起来比真题复杂很多，但依然没有超出基本的地址计算思想。

**跨越一个完整的存储块时，使用的是压缩后的实际长度，而不是压缩前的逻辑长度。**

## 六、稀疏矩阵：必须理解为什么需要额外信息

2017年、2023年两次真题考查了稀疏矩阵，王道卷四又考查了三元组的存储空间。

这部分知识不难，但是必须理解到位。

### 1. 稀疏矩阵与特殊矩阵压缩的区别

| 特殊矩阵          | 稀疏矩阵            |
| ------------- | --------------- |
| 元素位置具有规律      | 非零元素位置通常没有固定规律  |
| 可以通过公式计算存储位置  | 需要额外记录非零元素位置    |
| 例如对称、三角、三对角矩阵 | 例如仅有少量非零元素的一般矩阵 |

稀疏矩阵常用三元组表、十字链表进行存储。

三元组包括：

$$
(\text{行号},\text{列号},\text{元素值})
$$

### 2. 为什么三元组之外还必须保存行数与列数？

2023年408真题考查了这一问题。

例如某矩阵只有两个非零元素，其三元组表如下：

| 行号 | 列号 | 元素值 |
| -- | -- | --- |
| 1  | 2  | 5   |
| 2  | 3  | 8   |

仅凭这些记录，无法确定原矩阵究竟是一个 $2\times3$ 矩阵、$3\times3$ 矩阵，还是 $100\times100$ 矩阵。

因为全零的行与列不会出现在三元组表中。

所以还必须保存：

$$
\text{原矩阵总行数和总列数}
$$

至于包含非零元素的行数和列数，可以通过扫描三元组表获得，无须额外保存才能还原矩阵。

### 3. 三元组存储空间计算

王道卷四给出一个具有1000个非零元素的稀疏矩阵。

行号和列号各占2B，元素值占4B。

因此，每个三元组占：

$$
2+2+4=8\text{ B}
$$

三元组记录共占：

$$
1000\times8=8000\text{ B}
$$

注意这个答案只计算三元组记录，不包括表头、结构体填充等额外空间。若题目要求完整存储结构的内存开销，则必须另外考虑。

| 常见错误认识               | 正确理解              |
| -------------------- | ----------------- |
| 出栈顺序一定是入栈顺序的逆序       | 只有同时留在栈中的元素才有逆序约束 |

| 三元组只记录元素值            | 还要记录行号和列号         |
| 三元组表可以独立还原矩阵         | 还需要知道原矩阵的总行数和列数   |

## 十、最终总结：考场上只需要抓住五个思维模型

面对第三章的陌生选择题时，不要先回忆教材上的某个公式，而要先识别它属于哪种问题。

**模型一：顺序问题。** 判断哪些元素被压住，哪些元素可以立即取出。

**模型二：指针问题。** 确定指针指向实际元素还是空位置，再画出占用区间。

**模型三：表达式问题。** 区分运算符栈和操作数栈，理解优先级、结合性与操作数顺序。

**模型四：存储位置问题。** 计算目标元素之前实际存储了多少个元素。

**模型五：信息完整性问题。** 判断压缩之后保留的信息，是否足以还原原始数据。

这五个模型几乎贯穿了第三章全部46道选择题。
