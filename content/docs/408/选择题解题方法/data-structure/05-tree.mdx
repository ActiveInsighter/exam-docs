## 二、树的基本性质：所有计数题的根源

### 1. 最重要的公式不是叶结点公式，而是边数公式

对于一棵非空树，设总结点数为 $n$，度为 $i$ 的结点数为 $n_i$，最大度为 $m$。

从结点角度统计：

$$
n=n_0+n_1+n_2+\cdots+n_m
$$

从边的角度统计：

$$
n-1=n_1+2n_2+\cdots+mn_m
$$

为什么边数是 $n-1$？

因为除了根结点，每个结点都恰好有一个双亲，也就恰好对应一条连接双亲的边。

将两式相减，得到：

$$
\boxed{n_0=1+\sum_{i=2}^{m}(i-1)n_i}
$$

展开就是：

$$
n_0=1+n_2+2n_3+3n_4+\cdots
$$

这才是一般树叶结点计数题的通用公式。

#### 代表题：2010年408真题，题库第1题

一棵度为4的树中，有20个度为4的结点、10个度为3的结点、1个度为2的结点、10个度为1的结点，求叶结点数。

直接使用公式：

$$
\begin{aligned} n_0&=1+3\times20+2\times10+1\\ &=82 \end{aligned}
$$

答案：**B，82。**

度为1的结点数量为什么不参与计算？

因为在一条边中插入一个度为1的结点，只会延长路径，不会增加叶结点。真正增加分支数量的是度大于1的结点。

可以这样理解：从只有根结点的一棵树开始，它有一个叶结点；将一个叶结点扩展为拥有 $k$ 个孩子的分支结点，会净增加 $k-1$ 个叶结点。

这就是公式的结构本质。

### 2. 二叉树最重要的计数性质

将一般树公式应用于二叉树：

$$
\boxed{n_0=n_2+1}
$$

以及：

$$
\boxed{n=2n_0+n_1-1}
$$

注意，这两个公式适用于**任何非空二叉树**，而不仅是完全二叉树。

进一步可以推出：

| 已知条件              | 结论                   |
| ----------------- | -------------------- |
| 度为2的结点数为 $k$  | 叶结点数为 $k+1$      |
| 不存在度为1的结点         | $n=2n_0-1$       |
| 不存在度为1的结点         | 总结点数一定是奇数            |
| 二叉链表有 $n$ 个结点 | 孩子指针域共有 $2n$ 个   |
| 二叉链表有 $n$ 个结点 | 非空孩子指针共有 $n-1$ 个 |
| 二叉链表有 $n$ 个结点 | 空孩子指针共有 $n+1$ 个  |

最后一条尤其重要，因为它直接联系到后面的线索二叉树：

$$
2n-(n-1)=n+1
$$

题库中的2018年、2019年相关真题，以及王道卷八、竟成模拟三等题目，都可以用这些关系直接解决。

#### 迁移：所有分支结点的度均为 $k$

对应王道卷六，模拟题第1题。

假设树有 $n$ 个结点，分支结点数为 $b$，则：

$$
kb=n-1
$$

因此：

$$
\boxed{n_0=n-\frac{n-1}{k}}
$$

注意题目必须说明 **所有分支结点的度都为 $k$**，如果只说明树的度为 $k$，就不能直接使用该公式。

## 三、完全二叉树与顺序存储：用编号代替画图

### 1. 不同二叉树的性质必须严格区分

| 性质              | 普通二叉树 | 完全二叉树 | 满二叉树 | 二叉哈夫曼树 |
| --------------- | ----- | ----- | ---- | ------ |
| $n_0=n_2+1$ | ✓     | ✓     | ✓    | ✓      |
| 度为1的结点最多1个      | 不一定   | ✓     | ✓    | ✓      |
| 所有分支结点的度为2      | 不一定   | 不一定   | ✓    | ✓      |
| 结点数一定为奇数        | 不一定   | 不一定   | ✓    | ✓      |
| 叶结点只在最后两层       | 不一定   | ✓     | ✓    | 不一定    |
| 已知总结点数即可确定叶结点数  | 不一定   | ✓     | ✓    | ✓      |

本章很多判断题，本质上就是故意把一种特殊二叉树的性质错误地推广到其他二叉树上。

尤其要注意：**没有度为1的结点，不代表一定是满二叉树，也不代表一定是完全二叉树。**

### 2. 完全二叉树的编号体系

设根结点编号为1，按照层次从左向右编号。

| 所求内容           | 公式                                 |
| -------------- | ---------------------------------- |
| 结点 $i$ 的双亲 | $\lfloor i/2\rfloor$，$i>1$ |
| 左孩子编号          | $2i$                           |
| 右孩子编号          | $2i+1$                         |
| 结点所在层数         | $\lfloor\log_2 i\rfloor+1$     |
| 最后一个分支结点       | $\lfloor n/2\rfloor$           |
| 叶结点数           | $\lceil n/2\rceil$             |
| 树的高度           | $\lfloor\log_2 n\rfloor+1$     |

孩子编号超过总结点数 $n$，则相应孩子不存在。

如果根结点编号从0开始，公式就会变为：

$$
\begin{aligned} \operatorname{parent}(i)&=\left\lfloor\frac{i-1}{2}\right\rfloor\\ \operatorname{left}(i)&=2i+1\\ \operatorname{right}(i)&=2i+2 \end{aligned}
$$

考试时不要混用两种编号体系。

#### 代表题：2009年408真题，题库第3题

一棵完全二叉树的第6层有8个叶结点，求该树最多有多少个结点。

<Steps>

<Step>

#### 第一步：确定树的最大高度

完全二叉树的叶结点只可能位于最后两层。既然第6层存在叶结点，那么整棵树最多有7层。

</Step>

<Step>

#### 第二步：确定第6层的最大分支结点数

第6层最多有：

$$
2^5=32
$$

个结点，其中8个是叶结点，那么其余24个结点可以拥有孩子。

</Step>

<Step>

#### 第三步：将允许存在的孩子全部填满

第7层最多有：

$$
24\times2=48
$$

个结点。

因此：

$$
n_{\max}=2^6-1+48=111
$$

答案：**C，111。**

这类极值题的核心不是记公式，而是先判断哪些位置必须存在、哪些位置允许填满、哪些位置必须为空。

</Step>

</Steps>

### 3. 普通二叉树的层数极值：不要默认前面各层都是满的

#### 代表题：王道卷二，模拟题第3题

一棵普通二叉树有100个结点，根为第1层，第7层最多有多少个结点？

选项：37、48、49、64。

本题考查普通二叉树和完全二叉树的区别。

假设第7层有 $x$ 个结点，为了容纳这些结点，第6层至少需要：

$$
\left\lceil\frac{x}{2}\right\rceil
$$

个结点。继续向上推导，整棵树至少需要：

$$
N_{\min}(x)= \sum_{j=0}^{6} \left\lceil\frac{x}{2^j}\right\rceil
$$

使用选项代入，比直接求解更快。

当 $x=48$ 时：

$$
48+24+12+6+3+2+1=96
$$

没有超过100，而且可以在不增加第7层结点数的情况下补足剩余4个结点。

当 $x=49$ 时：

$$
49+25+13+7+4+2+1=101
$$

超过100，不可能。

答案：**B，48。**

错误解法是认为前6层必须有63个结点，因此第7层只有37个结点。

<Callout type="idea" title="最少祖先法">

**普通二叉树追求某一层的最大容量，应从目标层向上计算最少需要的祖先，而不是从根向下填满所有层。**

</Callout>

### 4. 顺序存储的本质：保留位置，而不是只保存结点

2020年408真题第7题问：任意一棵高度为5且有10个结点的二叉树，采用顺序存储，至少需要多少个存储单元才能保证存下？

虽然只有10个实际结点，但第5层最右端的结点编号可能达到：

$$
2^5-1=31
$$

例如，其最右路径的编号为：

$$
1\to3\to7\to15\to31
$$

因此需要31个存储单元才能覆盖所有可能的树形。

答案：**A，31。**

顺序存储空间取决于**最大结点编号**，而不是实际结点数量。

对于模拟题第12题中的空间比较，也是同一个思想：

设实际有 $n$ 个结点，最大编号为 $k$，数据域为 $d$ 字节，三叉链表的三个指针各占4字节，则：

$$
S_{\text{顺序}}=kd
$$

$$
S_{\text{链式}}=n(d+12)
$$

顺序存储更省空间的条件为：

$$
d(k-n)<12n
$$

其中，$k-n$ 就是顺序存储浪费的空位置数。

## 四、二叉树遍历：掌握递归结构，而不是机械背诵顺序

### 1. 三种遍历真正的区别

| 遍历方式 | 访问顺序      | 根结点的位置   |
| ---- | --------- | -------- |
| 先序遍历 | 根、左、右     | 子树序列的开头  |
| 中序遍历 | 左、根、右     | 左右子树的分界线 |
| 后序遍历 | 左、右、根     | 子树序列的末尾  |
| 层次遍历 | 从上到下、从左到右 | 整个序列的开头  |

最重要的观察是：

**先序和后序能够确定根，中序能够划分左右子树。**

这解释了为什么在结点关键字互异、序列合法的前提下：

| 已知遍历序列  | 能否唯一确定二叉树 |
| ------- | --------- |
| 先序 + 中序 | 能         |
| 后序 + 中序 | 能         |
| 层序 + 中序 | 能         |
| 先序 + 后序 | 一般不能      |
| 仅有先序    | 不能        |
| 仅有中序    | 不能        |

先序与后序不能唯一确定二叉树的最简单反例：

```text
    A          A
   /            \
  B              B
```

两棵树的先序都是 AB，后序都是 BA。

但是中序分别为 BA 和 AB。

也就是说，先序和后序无法区分唯一的孩子究竟是左孩子还是右孩子。

如果额外知道每个非叶结点都有两个孩子，那么先序和后序可以唯一确定二叉树。

### 2. 利用遍历序列的相对顺序推断树形

不需要画出整棵树，有时只需比较结点之间的相对顺序。

假设二叉树的结点身份可以区分：

| 遍历序列关系  | 必然的树形       |
| ------- | ----------- |
| 先序与中序相同 | 右单支树        |
| 后序与中序相同 | 左单支树        |
| 先序与中序互逆 | 左单支树        |
| 后序与中序互逆 | 右单支树        |
| 先序与后序互逆 | 单支树，左右方向不确定 |

其中最重要的是最后一种。

#### 代表题：2011年408真题，题库第9题

某二叉树的先序遍历为：

$$
1,2,3,4
$$

后序遍历为：

$$
4,3,2,1
$$

则中序遍历不可能是：

A. 1,2,3,4

B. 2,3,4,1

C. 3,2,4,1

D. 4,3,2,1

**关键突破：先序和后序完全相反。**

假设存在一个结点同时拥有左右孩子，那么左子树中的结点在先序和后序中都一定出现在右子树结点之前。

它们的相对顺序不可能颠倒。

因此，这棵树不存在度为2的结点，只能是一条单支链：

```text
1
 \
  2
   \
    3
     \
      4
```

图中每条边都可以独立选择左孩子或右孩子。

接下来判断中序序列时，只需要记住一个规律：

**单支树中，根结点只能出现在中序遍历序列的开头或末尾。**

检查C：

$$
3,2,4,1
$$

去掉根结点1，剩下：

$$
3,2,4
$$

这棵子树的根是2，但2既不在开头，也不在末尾，所以不可能。

答案：**C。**

这个方法比根据四个选项分别还原四棵二叉树高效得多。

### 3. 二叉树遍历的几个重要不变量

题库中2017年真题、竟成模拟四、竟成模拟七都涉及这些性质。

| 结论                   | 正确性 |
| -------------------- | --- |
| 先序遍历的最后一个结点一定是叶结点    | 正确  |
| 后序遍历的第一个结点一定是叶结点     | 正确  |
| 中序遍历的最后一个结点一定是叶结点    | 错误  |
| 中序遍历的最后一个结点一定没有右孩子   | 正确  |
| 中序遍历的第一个结点一定没有左孩子    | 正确  |
| 三种深度优先遍历中，叶结点的相对顺序相同 | 正确  |
| 先序和层序的第一个结点相同        | 正确  |

为什么三种深度优先遍历中的叶结点相对顺序相同？

因为先序、中序、后序虽然改变了访问根结点的时机，但始终保持先访问左子树、再访问右子树的顺序。

这个规律能够解决很多不需要知道具体树形的判断题。

### 4. 二叉树形态计数：卡特兰数

含有 $n$ 个结点的不同有序二叉树形态数为：

$$
\boxed{C_n=\frac{1}{n+1}\binom{2n}{n}}
$$

其递推关系是：

$$
C_n=\sum_{i=0}^{n-1}C_iC_{n-1-i}
$$

理解递推比背诵公式更重要：

去掉根结点，将剩余 $n-1$ 个结点分给左右子树。如果左子树有 $i$ 个结点，右子树就有 $n-1-i$ 个结点，分别计算形态数再相乘。

常见数值建议直接记住：

| 结点数 | 0 | 1 | 2 | 3 | 4  | 5  | 6   | 7   |
| --- | - | - | - | - | -- | -- | --- | --- |
| 形态数 | 1 | 1 | 2 | 5 | 14 | 42 | 132 | 429 |

2015年408真题第11题，先序序列为 abcd 的不同二叉树共有多少棵？

因为每一种二叉树形态都可以按照先序依次填入 abcd，所以直接得到：

$$
C_4=14
$$

不必逐一画出14棵二叉树。

#### 特别注意：关键字重复

王道卷二模拟题第15题给出的先序和中序都是 `ooops`。

虽然给出了两种遍历，但由于存在重复关键字，二叉树不再唯一。

前三个 o 可以对应五种二叉树形态，而 p、s 的连接位置由剩余遍历顺序确定，因此共有：

$$

种形态。

### 5. 递归算法复杂度：访问结点数与递归深度是两回事

竟成模拟六第18题：

```c
int maxFunc(TreeNode* root) {
    if (root == NULL)
        return 0;

    return max(maxFunc(root->left),
               maxFunc(root->right)) + 1;
}
```

这是求二叉树高度的算法。

每个结点都被访问一次，每次执行常数数量的操作，所以：

$$
T(n)=\Theta(n)
$$

递归栈空间取决于树的高度：

$$
S(n)=\Theta(h)
$$

即使这是一棵平衡二叉树，高度为 $O(\log n)$，时间复杂度依然是 $O(n)$，而不是 $O(\log n)$。

**时间复杂度看总共处理多少结点，递归栈空间复杂度看同时存在多少层递归。**

## 五、前驱、后继与线索二叉树

### 1. 中序前驱和后继是近年来非常值得重视的考点

不要把中序前驱和后继简单理解成左孩子和右孩子。

真正的定义是：**中序遍历序列中，紧邻当前结点之前和之后的结点。**

对于任意结点 $x$：

| 所求对象 | 条件   | 查找方法                       |
| ---- | ---- | -------------------------- |
| 中序前驱 | 有左子树 | 左子树中最靠右的结点                 |
| 中序前驱 | 无左子树 | 向上寻找第一个使 $x$ 位于其右子树的祖先 |
| 中序后继 | 有右子树 | 右子树中最靠左的结点                 |
| 中序后继 | 无右子树 | 向上寻找第一个使 $x$ 位于其左子树的祖先 |

#### 代表题：2024年408真题，题库第16题

结点 $v$ 有两个孩子，其中序遍历序列为：

$$
\cdots,p,v,q,\cdots
$$

问 $p$、$q$ 分别具有怎样的孩子关系？

由于中序遍历的结构为：

$$
\underbrace{\text{左子树}}_{\text{最后一个是 }p} \quad v\quad \underbrace{\text{右子树}}_{\text{第一个是 }q}
$$

所以 $p$ 必然是左子树最右侧的结点，$q$ 必然是右子树最左侧的结点。

```text
            v
          /   \
         A     B
          \   /
          ... ...
            p q
```

因此：

- $p$ 一定没有右孩子，但可能有左孩子。
- $q$ 一定没有左孩子，但可能有右孩子。

答案：**A。**

这里还有一个很重要的陷阱：如果题目没有说明 $v$ 拥有两个孩子，就不能无条件推出上述结论。

2012年、2022年、2024年真题以及王道卷二模拟题，都要求考生根据遍历顺序分析局部结点关系，而不只是会默写遍历结果。

### 2. 线索二叉树的本质：利用空指针保存遍历信息

普通二叉链表中存在大量空指针。

线索化的目的就是利用这些空指针记录前驱、后继，使得遍历时不必总是依赖递归栈。

| 指针域    | 标志位为0 | 标志位为1  |
| ------ | ----- | ------ |
| lchild | 指向左孩子 | 指向遍历前驱 |
| rchild | 指向右孩子 | 指向遍历后继 |

这里采用常见的线索标志位定义。

最重要的是：

<Callout type="warn" title="线索化的前提">

**只有原本为空的孩子指针才能变成线索，原有的孩子指针不能被覆盖。**

</Callout>

一棵具有 $n$ 个结点的二叉树有 $n+1$ 个原始空孩子指针域，其中遍历序列首、尾结点的相应线索可能为空或指向头结点，具体取决于实现方式。

线索二叉树的题目有一个通用方法：

先写出题目指定的遍历序列，再找到目标结点前后相邻的结点，最后检查相应孩子指针是否为空。

不要根据图中结点的空间位置猜测线索方向。

### 3. 为什么中序线索二叉树最方便？

对应竟成模拟四第20题：

| 线索二叉树类型 | 容易查找    | 一般不能直接高效查找 |
| ------- | ------- | ---------- |
| 先序线索二叉树 | 先序后继    | 先序前驱       |
| 中序线索二叉树 | 中序前驱、后继 | —          |
| 后序线索二叉树 | 后序前驱    | 后序后继       |

前提是采用普通二叉链表，没有额外的双亲指针。

后序遍历访问顺序是左、右、根。因此访问完某个结点后，下一步可能需要进入双亲的右子树，也可能直接访问双亲。

如果不知道双亲是谁，就很难仅依靠局部信息快速确定后序后继。

## 六、树与森林：彻底理解左孩子右兄弟

### 1. 整个考点的核心只有两条规则

将树或森林转换为二叉树：

**左指针指向第一个孩子，右指针指向下一个兄弟。**

例如，原来的树：

```text
        A
      / | \
     B  C  D
       / \
      E   F
```

转换为二叉树：

```text
        A
       /
      B
       \
        C
       / \
      E   D
       \
        F
```

观察这一变化，就能推导出绝大多数考试结论。

| 原树或森林中的性质        | 对应二叉树中的表现                |
| ---------------- | ------------------------ |
| 原结点没有孩子          | 左孩子指针为空                  |
| 原结点没有右兄弟         | 右孩子指针为空                  |
| 原结点为叶结点          | 不一定仍为二叉树的叶结点             |
| 原结点有 $k$ 个孩子 | 从左孩子开始形成长度为 $k$ 的兄弟链 |
| 单棵树的根            | 一定没有右孩子                  |
| 森林中各棵树的根         | 从二叉树根开始形成右孩子链            |

特别容易出错的是：原树中的兄弟关系，转换后会表现为二叉树中的父子关系。

不能将两种结构中的父子关系混为一谈。

### 2. 森林转换后的遍历对应关系

这是必须掌握的结论：

| 树或森林的遍历 | 对应二叉树的遍历 |
| ------- | -------- |
| 先根遍历    | 先序遍历     |
| 后根遍历    | 中序遍历     |

尤其注意：

<Callout type="warn" title="遍历对应关系">

**树的后根遍历，对应的不是二叉树的后序遍历，而是中序遍历。**

</Callout>

原因是原树的所有孩子在转换后二叉树中由左子树及其右兄弟链表示，中序遍历恰好能够先遍历完这些孩子，再访问原来的根。

### 3. 代表题：2021年408真题，题库第25题

某森林对应的二叉树 $T$，其先序遍历为：

$$
a,b,d,c,e,g,f
$$

中序遍历为：

$$
b,d,a,e,g,c,f
$$

求森林中树的数量。

按照通常的方法，需要先还原整棵二叉树。

但本题只问森林中有多少棵树，实际上只需要找到**二叉树最右侧的根结点链**。

先序的第一个结点是 a。

在中序中，以 a 为分界线：

```text
b d | a | e g c f
```

因此右子树的先序是 `c e g f`，根为 c。

再处理中序的右侧：

```text
e g | c | f
```

因此 c 的右孩子是 f。

得到：

```text
a
 \
  c
   \
    f
```

森林中一共有3棵树。

答案：**C。**

本题的核心方法是：**题目只问某个局部性质，就只还原与该性质有关的部分，不必完成整棵树的构造。**

### 4. 树与森林转换的计数公式

设原森林有 $n$ 个结点、$t$ 棵树、$l$ 个叶结点。

森林内部的边数为：

$$
\boxed{E=n-t}
$$

转换成一棵非空二叉树后：

左孩子非空的结点数等于原森林的分支结点数：

$$
n-l
$$

因此左孩子指针为空的结点数为：

$$
\boxed{l}
$$

整个二叉树有 $n-1$ 条边，所以右孩子非空的指针数为：

$$
(n-1)-(n-l)=l-1
$$

右孩子为空的结点数为：

$$
\boxed{n-l+1}
$$

2011年408真题第5题给出一棵有2011个结点、116个叶结点的树，求转换后二叉树中没有右孩子的结点数。

直接得到：

$$
2011-116+1=1896
$$

答案为D。

这个解法比题库解析中构造特殊树形的方法更具有普遍性，也解释了为什么任意满足条件的树都会得到相同结果。

### 5. 卡特兰数在树与森林中的迁移

王道卷一模拟题第23题问：7个结点的树转换为二叉树后，有多少种不同形态？

单棵有序树转换为二叉树，根结点一定没有右孩子。

因此剩余6个结点构成的左子树可以是任意形态的二叉树。

答案：

$$
C_6=132
$$

总结：

| 结构      | $n$ 个结点的形态数 |
| ------- | --------------- |
| 有序二叉树   | $C_n$       |
| 单棵有根有序树 | $C_{n-1}$  |
| 有序森林    | $C_n$       |

## 七、哈夫曼树：掌握贪心合并与带权路径长度

这是本章真题最多的单独知识模块，35道历年真题中有10道属于哈夫曼树及编码。

### 1. 哈夫曼树到底在优化什么？

结点的路径长度是从根到该结点经过的边数。

树的带权路径长度为：

$$
\boxed{\mathrm{WPL}=\sum_{i=1}^{n}w_i l_i}
$$

其中：

$w_i$ 是叶结点权值，$l_i$ 是根到该叶结点的路径长度。

哈夫曼树的目标就是使 WPL 最小。

直观上，出现频率较高的字符，应尽可能获得较短的编码；出现频率较低的字符，则可以获得较长的编码。

构造过程始终重复一个操作：从当前所有候选结点中取出权值最小的两个结点，将它们合并，新结点的权值为二者之和，再放回候选集合。

### 2. 最重要的计算技巧：不画树直接计算 WPL

$$
\boxed{\mathrm{WPL}=\text{所有合并产生的新结点权值之和}}
$$

为什么成立？

因为每合并一次，被合并子树中的每个叶结点在新树中的深度都会增加1。

因此，这次合并对 WPL 的增加量，正好等于被合并子树中所有叶结点的权值之和，也就是新结点的权值。

#### 代表题：2023年408真题，题库第35题

6个字符的频次分别为：

$$
3,4,5,6,8,10
$$

求哈夫曼编码的加权平均长度。

完全不用画树，只需跟踪合并过程。

| 合并过程        | 合并后权值 |
| ----------- | ----- |
| $3+4$   | 7     |
| $5+6$   | 11    |
| $7+8$   | 15    |
| $10+11$ | 21    |
| $15+21$ | 36    |

因此：

$$
\mathrm{WPL}=7+11+15+21+36=90
$$

总频次：

$$
3+4+5+6+8+10=36
$$

加权平均编码长度为：

$$
\boxed{\bar L=\frac{\mathrm{WPL}}{\sum_i w_i}}
$$

代入：

$$
\bar L=\frac{90}{36}=2.5
$$

答案：**B，2.5。**

这一个方法就可以解决2021年、2023年等真题中的 WPL 和平均编码长度计算问题。

### 3. 哈夫曼树的性质与易错结论

设有 $n$ 个字符，构造标准二叉哈夫曼树。

| 结论                | 正误 |
| ----------------- | -- |
| 有 $n$ 个叶结点    | 正确 |
| 有 $n-1$ 个分支结点 | 正确 |
| 共有 $2n-1$ 个结点 | 正确 |
| 不存在度为1的结点         | 正确 |
| 总结点数一定为奇数         | 正确 |
| 一定是完全二叉树          | 错误 |
| 一定是二叉排序树          | 错误 |
| 哈夫曼树一定唯一          | 错误 |
| 最小WPL一定唯一         | 正确 |
| 树的高度一定唯一          | 错误 |
| 频次不同的字符一定处于不同层    | 错误 |
| 权值最大的叶结点一定是根的孩子   | 错误 |

其中，要重点区分：

<Callout type="warn" title="哈夫曼树的唯一性">

**最优目标值唯一，不代表最优解的结构唯一。**

</Callout>

例如，竟成模拟五第31题涉及的权值集合：

$$
1,1,1,2
$$

因为出现相同权值，合并过程可能存在不同选择，可以形成下面两种树形：

```text
       5                 5
      / \               / \
     2   3             2   3
    / \ / \               / \
   1  1 1  2             1   2
                            / \
                           1   1
```

两棵树的 WPL 均为：

$$
2+3+5=10
$$

但最大路径长度分别为2和3。

因此，哈夫曼树的高度可以不同，而最小WPL保持不变。

### 4. 哈夫曼编码的本质：前缀编码

前缀编码要求任何一个字符的编码都不是另一个字符编码的前缀。

例如：

```text
a = 0
b = 10
c = 110
d = 111
```

这是合法的前缀编码。

但如果再加入：

```text
e = 1100
```

就不合法了，因为110已经是1100的前缀。

本质上，一个编码对应编码树中的叶结点。既然某个位置已经是叶结点，它就不可能同时拥有后代。

**所有哈夫曼编码都是前缀编码，但并非所有前缀编码都是哈夫曼编码。**

前缀编码保证能够无歧义译码；哈夫曼编码还要求加权平均编码长度最小。

#### 代表题：王道卷一，模拟题第26题

已知两个字符的编码分别为0和10，要求编码长度不超过4，最多还能编码多少个字符？

编码树中，0已经占据整个左子树，10占据右子树的左分支。

剩余可用空间只有前缀11：

```text
             根
            /  \
           0    1
               / \
              10  11
                 /  \
               110  111
               / \  / \
            1100 ... 1111
```

因此可以增加：

`1100、1101、1110、1111`

共4个编码。

答案：**B。**

进一步推广，如果最长编码长度为 $L$，已有合法前缀编码的长度分别为 $l_1,l_2,\ldots,l_k$，那么最多还能加入：

$$
\boxed{2^L-\sum_{i=1}^{k}2^{L-l_i}}
$$

个字符。

前提是已有编码互不构成前缀，且长度均不超过 $L$。

本题代入：

$$
2^4-2^3-2^2=4
$$

这就是前缀码容量问题的通用方法。

### 5. 多叉哈夫曼树：遇到陌生题也可以从边数推导

2013年408真题第27题考查了三叉哈夫曼树。

对于每个分支结点都拥有 $m$ 个孩子的哈夫曼树，设叶结点数为 $n$，内部结点数为 $b$。

由边数公式：

$$
mb=n+b-1
$$

得到：

$$
\boxed{b=\frac{n-1}{m-1}}
$$

所以叶结点数必须满足：

$$
(n-1)\bmod(m-1)=0
$$

如果不满足条件，就需要补充权值为0的虚拟叶结点。

补充数量：

$$
\boxed{x=(m-1-(n-1)\bmod(m-1))\bmod(m-1)}
$$

例如三叉哈夫曼树的6个叶结点权值分别为：

$$
2,3,4,5,6,7
$$

因为6不满足完整三叉结构的叶结点数量要求，所以补一个0。

每次选择三个最小权值合并：

$$
0+2+3=5
$$

$$
4+5+5=14
$$

$$
6+7+14=27
$$

得到：

$$
\mathrm{WPL}=5+14+27=46
$$

这类看似陌生的多叉题，本质仍然是**树的边数关系加上哈夫曼贪心合并**。

## 八、并查集：关注集合的根，而不是表面连接关系

虽然本题库中并查集没有被单独归入历年真题，但模拟题集中安排了4道题，值得掌握。

### 1. 并查集只维护两种操作

- `Find(x)`：查找元素 $x$ 所属集合的根结点。
- `Union(x,y)`：将两个元素所属的不同集合合并。

并查集使用树来表示集合，同一个集合中的所有元素最终都指向同一个根。

例如：

```text
集合一         集合二

   0             3
  / \           /
 1   2         4
```

执行 `Union(2,4)` 时，并不是简单地将2和4直接连接起来，而是先查找它们所属集合的根0和3，再合并两棵树。

这是并查集最重要的思想。

### 2. 两种优化方式

| 优化方式  | 核心思想                  |
| ----- | --------------------- |
| 按秩合并  | 将秩较小的树接到秩较大的树下面       |
| 按大小合并 | 将结点数较少的树接到较大的树下面      |
| 路径压缩  | 查找根的过程中，将路径上的结点直接连接到根 |

路径压缩示意：

```text
压缩前          压缩后

   A               A
   |             / | \
   B            B  C  D
   |
   C
   |
   D
```

路径压缩能够减少以后查找根结点所需的时间。

同时使用路径压缩与按秩或按大小合并，在常见的操作序列条件下，摊还时间复杂度接近常数：

$$
O(\alpha(n))
$$

其中 $\alpha(n)$ 是反阿克曼函数，增长极其缓慢。

#### 代表题：竟成模拟一，模拟题第33题

初始元素为0至5，各个集合的秩均为1。当两个根的秩相同时，题目给定的程序保留第一个参数所属集合的根。

依次执行：

```c
Union(0, 1);
Union(2, 3);
Union(1, 3);
Union(3, 4);
```

问元素4最终所属集合的根。

| 操作         | 实际参与合并的根 | 合并后的根 |
| ---------- | -------- | ----- |
| Union(0,1) | 0、1      | 0     |
| Union(2,3) | 2、3      | 2     |
| Union(1,3) | 0、2      | 0     |
| Union(3,4) | 0、4      | 0     |

所以：

$$
\operatorname{Find}(4)=0
$$

答案：**A。**

最容易犯的错误是第三步把1和3当成根进行合并。

### 3. 并查集为什么能判断环？

在无向图中，如果一条新边的两个端点已经属于同一个连通分量，说明这两个端点之间原本就存在路径。

再加入这条边，就会产生环。

因此：

$$
\operatorname{Find}(u)=\operatorname{Find}(v)
$$

说明新边会形成环。

这就是 Kruskal 最小生成树算法使用并查集的原因。

并查集可以高效维护连通关系，但不能直接求最短路径，也不能代替 Floyd、Dijkstra 算法。

## 九、题库中值得警惕的解析问题

原题库部分中间推理不够严谨，具体校注如下。

| 题目          | 需要注意的问题                                            |
| ----------- | -------------------------------------------------- |
| 2011年真题第5题  | 仅构造特殊树形不足以证明一般结论，应使用 $n-l+1$ 推导                |
| 2024年真题第16题 | 有右孩子时，中序后继不一定就是右孩子，而是右子树最左结点                       |
| 王道模拟第15题    | `ooops` 的分类计数应为 $2+1+2=5$，原解析的 $3+1+1$ 不正确 |
| 王道模拟第28题    | 哈夫曼树不同层之间的权值关系，原解析给出的限制过强                          |
| 竟成模拟第34题    | 将复杂度的宽松上界当作错误选项，存在数学表述上的歧义                         |

特别说明哈夫曼树的权值关系：对于非负权值的最优哈夫曼树，较浅层结点的权值不会小于较深层结点的权值。若两个结点所在子树互不包含，而较深处的子树权值更大，那么交换两棵子树就能够降低 WPL，与最优性矛盾。若具有祖先关系，则直接由权值求和性质保证。

因此不能简单认为这一性质只适用于祖先与后代。

另外，并查集题中，若更紧的复杂度上界是 $O(m\alpha(n))$，那么数学上它也属于较宽松的 $O(m\log n)$。考试时通常按命题人希望考查的更紧复杂度理解，但应当知道两者的区别。

| 高度为 $h$ 的二叉树最大结点数         | $2^h-1$                           |
| 高度为 $h$ 的 $m$ 叉树最大结点数 | $\frac{m^h-1}{m-1}$，$m>1$     |
| 完全二叉树高度                       | $\lfloor\log_2n\rfloor+1$         |
| 完全二叉树叶结点数                     | $\lceil n/2\rceil$                |
| 二叉树形态数                        | $C_n=\frac{1}{n+1}\binom{2n}{n}$  |
| 单棵有序树形态数                      | $C_{n-1}$                        |
| 中序前驱                          | 有左子树时，找左子树最右结点                        |
| 中序后继                          | 有右子树时，找右子树最左结点                        |
| 树与森林转换                        | 左孩子右兄弟                                |
| 森林中树的数量                       | 转换后二叉树根的右孩子链长度                        |
| 二叉哈夫曼树结点总数                    | $2n-1$，$n$ 为叶结点数              |
| 哈夫曼树WPL                       | 所有合并产生的新权值之和                          |
| 加权平均编码长度                      | $\mathrm{WPL}/\sum_i w_i$         |
| 并查集合并                         | 先找根，再合并                               |

## 十二、解题方法自检

遇到新题时，可用以下六个问题识别解题方向：

1. 这道计数题能不能通过统计边数解决？
2. 题目中的二叉树究竟是普通、完全、满，还是哈夫曼二叉树？
3. 遍历序列中哪些结点是根，哪些结点决定子树边界？
4. 题目只问局部性质时，是否有必要还原整棵树？
5. 能否把树与森林的问题转化为左孩子和右兄弟的关系？
6. 能否通过跟踪合并过程，不画树就得到哈夫曼树或并查集的答案？
