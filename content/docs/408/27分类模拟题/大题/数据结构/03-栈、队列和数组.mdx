## 3.2 队列

<Question id="sim1127-408-jingcheng-2027-06-42" type="essay" points={10} tags="来源:27竞成10套卷, 试卷:第6套·第42题, 科目:数据结构, 章节:栈队列和数组, 考点:双栈实现队列">

利用两个栈 $S_1$ 和 $S_2$ 来模拟一个队列 $Q$，栈 $S_1$ 和 $S_2$ 中存储的元素均为整数。请给出队列 $Q$ 入队（enqueue）、出队（dequeue）和判空操作（queue_empty）的伪代码实现。其中，栈 $S_1$ 和 $S_2$ 只支持以下的 4 种运算操作：

① push(x)：将元素 $x$ 入栈；

② pop()：将栈顶元素出栈；

③ top()：获取栈顶元素；

④ empty()：判断栈是否为空。

<Solution>

### （1）设计思想：一个输入栈，一个输出栈

栈是后进先出（LIFO），队列是先进先出（FIFO）。利用两次次序反转可以得到先进先出的效果：令 $S_1$ 为输入栈，$S_2$ 为输出栈。

- 入队：新元素直接压入 $S_1$。
- 出队：若 $S_2$ 非空，其栈顶一定是最早尚未出队的元素，直接读取并弹出。若 $S_2$ 为空，则将 $S_1$ 中所有元素逐个弹出、压入 $S_2$，使原本位于 $S_1$ 栈底的最早元素变成 $S_2$ 的栈顶，再执行出队。
- 判空：只有两个栈均为空，队列才为空。

**关键不变式：** 队列从队首到队尾的逻辑顺序，等于 $S_2$ 从栈顶到栈底的顺序，接上 $S_1$ 从栈底到栈顶的顺序。必须等 $S_2$ 完全为空才可以把 $S_1$ 中的元素转移过去，否则较新的元素将压在较老的元素上方，破坏 FIFO。

### （2）伪代码实现

题目只允许四种栈操作，以下不依赖 `pop()` 的返回值，并显式区分出队失败与取到某个整数。

```text
initialize:
    S1 = empty stack
    S2 = empty stack

enqueue(x):
    S1.push(x)

queue_empty():
    return S1.empty() AND S2.empty()

dequeue():
    if queue_empty():
        return (false, no_value)
    if S2.empty():
        while NOT S1.empty():
            x = S1.top()
            S1.pop()
            S2.push(x)
    x = S2.top()
    S2.pop()
    return (true, x)
```

如果使用 C/C++，可以实现 `bool dequeue(int &x)`（C 语言可使用 `int *x`），返回是否成功，并通过输出参数提供元素。不能直接用 `-1` 当作失败标记：题干并未限制整数取值，`-1` 也可能是合法入队数据。

### （3）模拟过程

下表栈内容均按**栈底到栈顶**表示，最右侧为栈顶。

| 操作 | 输入栈 $S_1$ | 输出栈 $S_2$ | 出队结果 |
| --- | --- | --- | --- |
| `enqueue(1)` | `[1]` | `[]` | — |
| `enqueue(2)` | `[1,2]` | `[]` | — |
| `enqueue(3)` | `[1,2,3]` | `[]` | — |
| `dequeue()` | `[]` | `[3,2]` | 1 |
| `enqueue(4)` | `[4]` | `[3,2]` | — |
| `dequeue()` | `[4]` | `[3]` | 2 |
| `dequeue()` | `[4]` | `[]` | 3 |
| `dequeue()` | `[]` | `[]` | 4 |

结果为 1、2、3、4，满足先进先出。第三次出队之前即使输入栈中已有 4，也不能提前转移它。

### （4）复杂度补充

入队、判空最坏时间复杂度都是 $O(1)$。若一次出队触发 $m$ 个元素的批量转移，则该次出队最坏为 $O(m)$。但从空队列开始看一串操作，每个元素最多经历一次压入 $S_1$、一次从 $S_1$ 弹出、一次压入 $S_2$、一次从 $S_2$ 弹出，栈顶读取也只有常数次。所以每次队列操作的**摊还时间复杂度为 $O(1)$**。两栈总共存储当前队列中的元素，总存储空间 $O(n)$，除两个栈之外辅助空间 $O(1)$。
