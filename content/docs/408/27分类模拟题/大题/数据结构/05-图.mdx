## 5.2 图的基本存储及基本操作

<Question id="sim1127-wd408-2027-s06-q42" type="essay" tags="来源:27王道八套卷, 试卷:第6套·第42题, 科目:数据结构, 章节:图, 考点:邻接表与有向图入度" points={12}>

假设**无权有向图**采用邻接表存储，顶点以整数 $0,1,\ldots,n-1$ 编号。回答：

1. 给出图 $G$ 的邻接表存储结构定义（C 语言）。
2. 基于此结构设计算法，求给定顶点 $v$ 的**入度**，给出设计思想、C 或 C++ 代码与复杂度。

<Solution>

### （1）邻接表的结构定义

对有向图，一条弧 $\langle u,v\rangle$ 从 $u$ 指向 $v$。普通邻接表中，弧通常挂在**起点** $u$ 的链表中，边表结点记录终点 $v$。因此顶点表记录出边的链表入口，而不是入边入口。

```c
#include <stddef.h>
#define MAXV 100

typedef struct ArcNode {
    int adjvex;               // 弧的终点编号
    struct ArcNode *nextarc;  // 同一起点的下一条出弧
} ArcNode;

typedef struct {
    int data;                 // 顶点编号
    ArcNode *firstarc;
} VNode;

typedef struct {
    VNode vertices[MAXV];
    int n, e;                 // 顶点数和弧数
} ALGraph;
```

假定 $0\le n\le MAXV$，顶点编号与数组下标一致，邻接表已经正确建立。

### （2）算法设计与 C 语言实现

顶点 $v$ 的入度定义为终点等于 $v$ 的有向边数：

$$
d^-(v)=\sum_{u\in V}\#\{\langle u,v\rangle\in E\}.
$$

依次扫描每一个顶点的出边链，每发现一条弧的终点为 $v$，入度计数器加 1。不能只扫描 $v$ 自己的邻接表，因为它记录的是从 $v$ 出发的弧。

```c
int inDegree(const ALGraph *G, int v) {
    if (G == NULL || v < 0 || v >= G->n) return -1;
    int degree = 0;
    for (int u = 0; u < G->n; ++u) {
        const ArcNode *p = G->vertices[u].firstarc;
        while (p != NULL) {
            if (p->adjvex == v) ++degree;
            p = p->nextarc;
        }
    }
    return degree;
}
```

例如有四个顶点，邻接表如下：

```text
0 -> 2
1 -> 2 -> 3
2 -> 3
3 -> NULL
```

求顶点 2 的入度时，扫描顶点 0 的链表加 1，扫描顶点 1 的链表再加 1，扫描其余链表均不加，故入度为 2。其出度则为 1。

### （3）正确性与复杂度

普通有向图邻接表中的每条弧恰好存储一次，扫描所有链表既不会漏弧，也不会重复计数。判断条件又恰好等价于该弧指向 $v$，故计数结果等于入度。允许自环时每条自环对入度贡献 1；允许重边时每条弧分别计数。

外层循环访问 $n$ 个表头，全部内层循环合计访问 $e$ 条弧，故时间复杂度为 $O(n+e)$，辅助空间 $O(1)$（不计图自身的存储）。这里两层循环不能直接相乘，因为不同顶点出边链长度不同，全部长度之和为 $e$。

### （4）相关知识：不同存储方式求度

| 存储方式 | 求单个顶点入度 | 求单个顶点出度 |
| --- | --- | --- |
| 邻接矩阵 | 扫描对应列，$O(n)$ | 扫描对应行，$O(n)$ |
| 普通邻接表 | 扫描所有链，$O(n+e)$ | 扫描本顶点链，$O(d^+(v)+1)$ |
| 逆邻接表 | 扫描本顶点入边链，$O(d^-(v)+1)$ | 扫描所有链，$O(n+e)$ |
| 十字链表 | 沿入边链扫描 | 沿出边链扫描 |

若频繁查询入度，可在构图和插删弧时维护入度数组，使查询为 $O(1)$，代价是额外 $O(n)$ 空间和更新维护。拓扑排序也常先扫描一次所有弧初始化入度数组，而不是对每个顶点反复调用本题函数。

</Solution>

</Question>

## 5.3 图的遍历

<Question id="sim1127-408-jingcheng-2027-09-42" type="essay" points={13} tags="来源:27竞成10套卷, 试卷:第9套·第42题, 科目:数据结构, 章节:图, 考点:邻接矩阵与连通分量计数">

无向图 $G$ 中有 $n$ 个顶点，顶点之间的邻接关系用邻接矩阵 AdjGrid 表示，`AdjGrid[i][j] = 1` 表示存在一条顶点 $i$ 与顶点 $j$ 连接的边，否则不存在该边，且 `AdjGrid[i][j] = AdjGrid[j][i]`。图的结构如下所示：

```c
const int MAX_SIZE = 200;

typedef struct {
    int n;
    int AdjGrid[MAX_SIZE][MAX_SIZE];
} Graph;
```

请给出一个时间上尽可能高效的算法，计算图 M 的连通分量的数量。要求：

(1) 给出算法的基本设计思想。

(2) 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

(3) 说明你的算法的时间复杂度。

<Solution>

### （1）算法思想：每启动一次新的 DFS，就找到一个连通分量

无向图的连通分量是极大的连通子图。从任意顶点出发进行一次 DFS 或 BFS，可以到达且仅能到达与它处在同一连通分量的顶点。利用这一性质：

1. 建立访问标记数组 `visited`，初始所有顶点均未访问；令分量数 `ans=0`。
2. 按编号扫描所有顶点，若顶点已经访问，说明它所属分量已经统计过，直接跳过。
3. 若顶点未访问，说明发现一个新分量，`ans++`，并从该顶点执行 DFS，把该分量的所有顶点标记为已访问。
4. 所有顶点扫描完毕，返回 `ans`。

孤立顶点也构成一个连通分量，不能只遍历具有边的顶点。题干中的「图 M」按上下文理解为给定的图 G。

### （2）C++ 语言实现

沿用题干的 `Graph` 和 `MAX_SIZE` 定义。使用常量引用传递图，避免复制整个邻接矩阵。

```cpp
void dfs(const Graph &G, int u, bool visited[]) {
    visited[u] = true;    // 先标记，再扩展邻点，避免在环上重复递归
    for (int v = 0; v < G.n; ++v) {
        if (G.AdjGrid[u][v] == 1 && !visited[v]) {
            dfs(G, v, visited);
        }
    }
}

int countComponents(const Graph &G) {
    bool visited[MAX_SIZE] = {false};
    int ans = 0;
    for (int u = 0; u < G.n; ++u) {
        if (!visited[u]) {
            ++ans;
            dfs(G, u, visited);
        }
    }
    return ans;
}
```

假定 $0\le G.n\le MAX\_SIZE$，邻接矩阵是有效的对称 0-1 矩阵。空图返回 0，无边的非空图返回 $n$。由于当前结点已经标记，即使矩阵主对角线有自环也不会重复递归。

### （3）实例与正确性

若图有 6 个顶点，边为 $(0,2),(2,3),(1,4)$，顶点 5 孤立，则按编号扫描：

| 外层顶点 | 操作 | DFS 新标记的顶点 | ans |
| --- | --- | --- | ---: |
| 0 | 启动 DFS | 0,2,3 | 1 |
| 1 | 启动 DFS | 1,4 | 2 |
| 2,3,4 | 已访问，跳过 | 无 | 2 |
| 5 | 启动 DFS | 5 | 3 |

每次 DFS 只能沿图中存在的边访问顶点，故不可能跨越不同的连通分量；而同一分量的任意顶点都存在一条从起点出发的路径，DFS 会逐层探索所有未访问的邻点，所以不会漏掉分量内部的顶点。于是每次外层循环启动 DFS 时恰好统计一个未统计过的分量。最终所有顶点均被访问，计数正确。

### （4）复杂度与最优性

每个顶点仅进入 DFS 一次，每次进入都扫描邻接矩阵的一整行，即检查 $n$ 个位置。总检查次数为 $n\times n$，加上初始化和外层扫描的 $O(n)$ 时间，故时间复杂度为 $\boxed{O(n^2)}$。访问数组和最深 $n$ 层递归栈均为 $O(n)$，辅助空间为 $O(n)$，不计邻接矩阵本身。

在仅给定邻接矩阵、没有其他索引的条件下，最坏情况需要检查二次数量级的矩阵元素：例如空图与某个尚未检查的顶点对之间存在一条边的图具有不同分量数，即使利用对称性只检查上三角，也仍有 $n(n-1)/2$ 个候选位置。因此 $O(n^2)$ 在最坏情况下已是渐近最优。若题目改为邻接表，DFS/BFS 复杂度可降为 $O(n+e)$。

**易错点**：一次 DFS 的递归调用次数是访问顶点数，不是分量数；应只在外层遇到未访问顶点并启动新 DFS 时加 1。有向图的强连通分量不能直接用此法统计。

</Solution>

</Question>

## 5.4 图的基本应用

<Question id="sim1127-wd408-2027-s03-q41" type="essay" tags="来源:27王道八套卷, 试卷:第3套·第41题, 科目:数据结构, 章节:图, 考点:拓扑排序、关键路径与最短路径" points={10}>

给定如图所示的带权有向无环图，顶点为 $V_1,\ldots,V_8$，边上的数字表示活动持续时间（也作为计算最短路的边权）。

![8 个顶点的带权有向无环图](/images/27王道8套卷1025/p033-1.svg)

1. 写出图的邻接矩阵（顶点依次为 $V_1,\ldots,V_8$）。
2. 写出**所有**拓扑排序序列。
3. 将图视为 AOE 网络，以 $V_1$ 为源、$V_8$ 为汇，求所有**事件**和**活动**的最早/最晚允许发生时刻，并给出全部关键路径。
4. 以 $V_1$ 为起点，求到各顶点的最短距离及一条对应最短路径。

<Solution>

### （1）邻接矩阵：按箭头方向填写

原图共有 10 条弧，以下列出每个顶点的出边，括号内为权值。

| 起点 | 出边终点及权值 |
| --- | --- |
| $V_1$ | $V_2(2),V_3(3)$ |
| $V_2$ | $V_4(5)$ |
| $V_3$ | $V_4(3),V_5(10)$ |
| $V_4$ | $V_6(4)$ |
| $V_5$ | $V_7(3)$ |
| $V_6$ | $V_5(2),V_8(6)$ |
| $V_7$ | $V_8(1)$ |
| $V_8$ | 无 |

约定矩阵主对角线为 0，无弧为 $\infty$，有弧则填权值（行表示起点、列表示终点）：

$$
A=\begin{bmatrix}
0&2&3&\infty&\infty&\infty&\infty&\infty\\
\infty&0&\infty&5&\infty&\infty&\infty&\infty\\
\infty&\infty&0&3&10&\infty&\infty&\infty\\
\infty&\infty&\infty&0&\infty&4&\infty&\infty\\
\infty&\infty&\infty&\infty&0&\infty&3&\infty\\
\infty&\infty&\infty&\infty&2&0&\infty&6\\
\infty&\infty&\infty&\infty&\infty&\infty&0&1\\
\infty&\infty&\infty&\infty&\infty&\infty&\infty&0
\end{bmatrix}.
$$

矩阵不对称，因为图是有向图。例如原图 $V_6\to V_5$ 权为 2，不能反向填写。若使用其他无边标记，需说明约定。

### （2）枚举全部拓扑序列

拓扑排序每次只能选当前入度为 0 的顶点。按 $V_1$ 到 $V_8$ 顺序，初始入度数组为 $(0,1,1,2,2,1,1,2)$。

| 已选顶点 | 下一步可选顶点 |
| --- | --- |
| 无 | $V_1$ |
| $V_1$ | $V_2,V_3$（任选其一） |
| $V_1,V_2$ 或 $V_1,V_3$ | 尚未选的 $V_3$ 或 $V_2$ |
| $V_1,V_2,V_3$（后两者可互换） | $V_4$ |
| 再选 $V_4$ | $V_6$ |
| 再选 $V_6$ | $V_5$ |
| 再选 $V_5$ | $V_7$ |
| 再选 $V_7$ | $V_8$ |

故恰好两种拓扑序列：

- $V_1,V_2,V_3,V_4,V_6,V_5,V_7,V_8$；
- $V_1,V_3,V_2,V_4,V_6,V_5,V_7,V_8$。

注意拓扑序列的编号不必递增，例如 $V_6$ 必须在 $V_5$ 之前。

### （3）关键路径：先正向求最长工期，再逆向求允许时刻

**第一步：事件最早发生时刻 $ve$。** 事件必须等待全部前驱活动结束，故对所有前驱候选值取最大值：$ve(j)=\max_{i\to j}(ve(i)+w_{ij})$。取第一种拓扑序列依次计算。

| 顶点 | 计算 | ve |
| --- | --- | ---: |
| $V_1$ | 源点，初始化 | 0 |
| $V_2$ | $0+2$ | 2 |
| $V_3$ | $0+3$ | 3 |
| $V_4$ | $\max(2+5,3+3)$ | 7 |
| $V_6$ | $7+4$ | 11 |
| $V_5$ | $\max(3+10,11+2)$ | 13 |
| $V_7$ | $13+3$ | 16 |
| $V_8$ | $\max(11+6,16+1)$ | 17 |

所以工程总工期为 17。

**第二步：事件最晚发生时刻 $vl$。** 从汇点反推，$vl(8)=17$。任何一个后继活动都不能因当前事件推迟而耽误，所以 $vl(i)=\min_{i\to j}(vl(j)-w_{ij})$，按逆拓扑序计算。

| 顶点 | 计算 | vl |
| --- | --- | ---: |
| $V_8$ | 工期 | 17 |
| $V_7$ | $17-1$ | 16 |
| $V_5$ | $16-3$ | 13 |
| $V_6$ | $\min(13-2,17-6)$ | 11 |
| $V_4$ | $11-4$ | 7 |
| $V_3$ | $\min(7-3,13-10)$ | 3 |
| $V_2$ | $7-5$ | 2 |
| $V_1$ | $\min(2-2,3-3)$ | 0 |

**第三步：活动最早和最晚开始时刻。** 对活动 $a=\langle V_i,V_j\rangle$，最早开始 $e(a)=ve(i)$，最晚开始 $l(a)=vl(j)-w_{ij}$，时间余量 $d(a)=l(a)-e(a)$。若问结束时刻，则分别在开始时刻上加活动持续时间。

| 活动 | 权 | 最早开始 | 最晚开始 | 最早结束 | 最晚结束 | 余量 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| $1\to2$ | 2 | 0 | 0 | 2 | 2 | 0 |
| $1\to3$ | 3 | 0 | 0 | 3 | 3 | 0 |
| $2\to4$ | 5 | 2 | 2 | 7 | 7 | 0 |
| $3\to4$ | 3 | 3 | 4 | 6 | 7 | 1 |
| $3\to5$ | 10 | 3 | 3 | 13 | 13 | 0 |
| $4\to6$ | 4 | 7 | 7 | 11 | 11 | 0 |
| $5\to7$ | 3 | 13 | 13 | 16 | 16 | 0 |
| $6\to5$ | 2 | 11 | 11 | 13 | 13 | 0 |
| $6\to8$ | 6 | 11 | 11 | 17 | 17 | 0 |
| $7\to8$ | 1 | 16 | 16 | 17 | 17 | 0 |

仅 $V_3\to V_4$ 不是关键活动，其余 9 条均为关键活动。从源点沿关键活动走到汇点，枚举全部关键路径：

- $V_1\to V_2\to V_4\to V_6\to V_8$，长度 $2+5+4+6=17$；
- $V_1\to V_2\to V_4\to V_6\to V_5\to V_7\to V_8$，长度 $2+5+4+2+3+1=17$；
- $V_1\to V_3\to V_5\to V_7\to V_8$，长度 $3+10+3+1=17$。

虽然本题每个事件的 $ve=vl$，仍不能直接判断所有弧都是关键活动。关键活动要比较弧自身的 $e,l$；例如 $3\to4$ 到达时刻为 6，却必须等另一前驱活动到时刻 7 才能触发事件 4。

### （4）单源最短路径：Dijkstra 松弛过程

所有权值均非负，Dijkstra 每轮确定尚未确定的最小距离顶点，再用其出边松弛其他顶点。初始 $dist(1)=0$，其余为 $\infty$；更新公式为 $dist(v)=\min(dist(v),dist(u)+w_{uv})$。

| 本轮确定的顶点 | d1 | d2 | d3 | d4 | d5 | d6 | d7 | d8 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 初始 | 0 | ∞ | ∞ | ∞ | ∞ | ∞ | ∞ | ∞ |
| 1 | 0 | 2 | 3 | ∞ | ∞ | ∞ | ∞ | ∞ |
| 2 | 0 | 2 | 3 | 7 | ∞ | ∞ | ∞ | ∞ |
| 3 | 0 | 2 | 3 | 6 | 13 | ∞ | ∞ | ∞ |
| 4 | 0 | 2 | 3 | 6 | 13 | 10 | ∞ | ∞ |
| 6 | 0 | 2 | 3 | 6 | 12 | 10 | ∞ | 16 |
| 5 | 0 | 2 | 3 | 6 | 12 | 10 | 15 | 16 |
| 7 | 0 | 2 | 3 | 6 | 12 | 10 | 15 | 16 |
| 8 | 0 | 2 | 3 | 6 | 12 | 10 | 15 | 16 |

| 终点 | 最短距离 | 一条最短路径 |
| --- | ---: | --- |
| $V_1$ | 0 | $V_1$ |
| $V_2$ | 2 | $1\to2$ |
| $V_3$ | 3 | $1\to3$ |
| $V_4$ | 6 | $1\to3\to4$ |
| $V_5$ | 12 | $1\to3\to4\to6\to5$ |
| $V_6$ | 10 | $1\to3\to4\to6$ |
| $V_7$ | 15 | $1\to3\to4\to6\to5\to7$ |
| $V_8$ | 16 | $1\to3\to4\to6\to8$ |

到 $V_8$ 还有一条同长的最短路径 $1\to3\to4\to6\to5\to7\to8$，长度也是 16。题目要求一条，任写其一即可。

### 相关知识与易错点

AOE 网络用最长路径确定最短工程完工时间（必须等全部活动完成）；单源最短路径是在可选路线中寻找最小代价，两者分别对候选值取最大和最小，不能混淆。由于此图还是 DAG，最短路径也能按拓扑序进行一次松弛，邻接表实现时间 $O(n+m)$，不要求非负权；而普通 Dijkstra 必须满足非负权条件，邻接矩阵实现时间 $O(n^2)$。

<Question id="sim1127-408-jingcheng-2027-01-41" type="essay" points={14} tags="来源:27竞成10套卷, 试卷:第1套·第41题, 科目:数据结构, 章节:图, 考点:拓扑序列与删边算法">

### （1）设计思想：把顶点编号转换为序列位置

设 `pos[v]` 是顶点 $v$ 在给定序列 $s$ 中的下标。合法拓扑序列的定义是：每一条有向边 $u\to v$ 都必须满足 $pos[u]<pos[v]$。因此只要扫描所有边，就能判断哪些边违背该序列。

- 若 $pos[u]\ge pos[v]$，该边必须删除（等号对应自环）。
- 若 $pos[u]<pos[v]$，该边可以保留；特别地，若 $pos[v]=pos[u]+1$，记录这一对相邻顶点间存在正向边。

删除全部违背顺序的边之后，剩余的边均从序列前方指向后方，必然无环。序列 $s$ 已经是合法拓扑序列，不必再执行一次拓扑排序。

判断唯一性只需检查 $s$ 中每对相邻顶点 $s[i],s[i+1]$ 是否有直接的正向边。全部存在时，整个序列的顺序被一条覆盖所有顶点的有向链固定；若其中有一对不存在，则交换这一对相邻顶点不会影响它们与其他顶点的相对次序，也不会违反二者之间的边约束，因此得到另一个合法拓扑序列。

### （2）存储结构与算法实现

稀疏图采用边表即可，不必使用 $n\times n$ 的邻接矩阵。以下采用指针保存边数组，按值传递 `Graph` 只复制两个计数及指针，不复制整张图。假定 $s$ 是顶点的一个排列，所有边端点合法。

```cpp
#include <vector>

struct Edge {
    int from, to;
};
struct Graph {
    int n, m;
    const Edge *edges; // 指向已建立的 m 条边
};

int count(Graph G, int s[], int &unique) {
    std::vector<int> pos(G.n);
    std::vector<char> adjacent(G.n, 0);
    for (int i = 0; i < G.n; ++i)
        pos[s[i]] = i;

    int removed = 0;
    for (int i = 0; i < G.m; ++i) {
        int p = pos[G.edges[i].from];
        int q = pos[G.edges[i].to];
        if (p >= q) {
            ++removed;            // 必须删除，包括自环
        } else if (q == p + 1) {
            adjacent[p] = 1;      // 相邻位置间的正向边
        }
    }
    unique = 1;
    for (int i = 0; i + 1 < G.n; ++i) {
        if (!adjacent[i]) {
            unique = 0;
            break;
        }
    }
    return removed;
}
```

算法仅统计需要删除的边并判断删除后的图，不要求实际修改图；若还要求输出删边后的边表，扫描时将满足 $p<q$ 的边写入新边表即可。邻接表实现也可以：外层扫描各顶点，内层逐条访问出边，判断规则完全相同。

### （3）实例推演与正确性

例如 $s=(2,0,1,3)$，原图边为 $2\to0,0\to1,2\to3,3\to0,1\to3$。

| 边 | 起点位置 | 终点位置 | 处理 |
| --- | ---: | ---: | --- |
| $2\to0$ | 0 | 1 | 保留，标记位置 0 |
| $0\to1$ | 1 | 2 | 保留，标记位置 1 |
| $2\to3$ | 0 | 3 | 保留，不标记 |
| $3\to0$ | 3 | 1 | 删除 |
| $1\to3$ | 2 | 3 | 保留，标记位置 2 |

故返回 1，`unique=1`。若原图没有 $0\to1$，则删除数量仍为 1，但 $0,1$ 可互换，`unique=0`。

**最少性证明**：每条逆序边都独立违反拓扑序列定义，因此任何方案均必须删除这些边；删除它们后所有边均正向，已满足定义，所以该方案达到下界。再删除其他边只会使删除数量增大。

**唯一性证明**：相邻顶点之间都有边时，任意拓扑序必须满足 $s[0]\prec s[1]\prec\cdots\prec s[n-1]$，只能是 $s$。若缺少某一相邻正向边，反向边已经删除，交换这两个相邻顶点不会破坏其他边的先后约束，故不唯一。重边不会改变唯一性，每条逆序重边仍需单独计数。空图与单顶点图的拓扑排列均唯一。

### （4）复杂度与考点

位置数组初始化、相邻关系检查均为 $O(n)$，扫描边表为 $O(m)$，故时间复杂度为 $O(n+m)$、辅助空间为 $O(n)$。使用邻接矩阵通常需 $O(n^2)$。本题的关键是利用**指定拓扑序列**，而不是枚举所有拓扑排序；通常也可通过拓扑排序时每一步是否只有一个零入度顶点来判断唯一性，但本题直接检查相邻边更简单。
