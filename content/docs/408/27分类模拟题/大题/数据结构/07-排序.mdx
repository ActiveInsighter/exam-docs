## 7.3 选择类排序

<Question id="sim1127-wd408-2027-s04-q41" type="essay" tags="来源:27王道八套卷, 试卷:第4套·第41题, 科目:数据结构, 章节:排序, 考点:小根堆的删除与插入" points={10}>

集合 $S$ 中已有一批元素，系统每隔 $1\,\mathrm{s}$ 接收一个新元素。每次接收新元素**之前**，必须输出并删除当前 $S$ 中的最小元素。

1. 选择合适的数据结构，设计算法，使每次删除最小元素、接收新元素的操作尽可能高效。
2. 初始 $S=\{59,31,29,18,78,26,48,10,65,35\}$，其后依次接收 $39$、$12$。给出建立结构以及两轮“删除最小值、插入新值”的过程。

<Solution>

### （1）数据结构：小根堆（最小优先队列）

本题反复执行「取当前最小元素并删除，再插入新元素」。无序数组查找最小值需要 $O(n)$，有序数组虽能直接得到最小值，但插入可能搬移 $O(n)$ 个元素。小根堆利用完全二叉树的形状和父结点不大于孩子的性质，使堆顶始终最小，并只需要沿树的一条路径调整。

用从 0 开始的数组存储，父结点为 $(i-1)/2$（向下取整，$i>0$），左右孩子为 $2i+1,2i+2$。自底向上建堆 $O(n)$；删除时取出堆顶、末元素补根并下沉，插入时在尾部增加元素并上浮，两者最坏均为 $O(\log n)$。

```c
static void swap(int *a, int *b) {
    int t = *a; *a = *b; *b = t;
}
static void down(int a[], int n, int i) {
    while (i < n / 2) { // 有左孩子（n 为当前堆大小）
        int c = 2 * i + 1;
        if (c + 1 < n && a[c + 1] < a[c]) ++c;
        if (a[i] <= a[c]) break;
        swap(&a[i], &a[c]);
        i = c;
    }
}
void build(int a[], int n) {
    for (int i = n / 2 - 1; i >= 0; --i)
        down(a, n, i);
}
// 前提：*n > 0
int removeMin(int a[], int *n) {
    int ans = a[0];
    --*n;
    if (*n > 0) {
        a[0] = a[*n];
        down(a, *n, 0);
    }
    return ans;
}
// 前提：数组有剩余容量
void insert(int a[], int *n, int x) {
    int i = (*n)++;
    a[i] = x;
    while (i > 0) {
        int p = (i - 1) / 2;
        if (a[p] <= a[i]) break;
        swap(&a[p], &a[i]);
        i = p;
    }
}
```

每轮先调用 `removeMin` 并输出返回值，等新值到达后调用 `insert`。两次操作加起来仍为 $O(\log n)$，辅助空间 $O(1)$，堆数组自身占 $O(n)$。本题实际出现的元素均不同；若系统允许重复值，可视作多重集合。若要求严格数学集合语义，应额外检查新元素是否已存在。

### （2）建堆过程

为方便画树，下表使用从 1 开始的结点编号（数组仍按层序展示）。10 个元素最后一个非叶结点编号为 5。按 5、4、3、2、1 的顺序向下调整，每次与较小孩子比较。

| 筛选结点 | 交换的值 | 筛选后数组 |
| --- | --- | --- |
| 初始 | — | 59,31,29,18,78,26,48,10,65,35 |
| 5 | 78↔35 | 59,31,29,18,35,26,48,10,65,78 |
| 4 | 18↔10 | 59,31,29,10,35,26,48,18,65,78 |
| 3 | 29↔26 | 59,31,26,10,35,29,48,18,65,78 |
| 2 | 31↔10、31↔18 | 59,10,26,18,35,29,48,31,65,78 |
| 1 | 59↔10、59↔18、59↔31 | 10,18,26,31,35,29,48,59,65,78 |

### （3）第一轮：先输出 10，再接收 39

| 操作 | 当前堆数组 |
| --- | --- |
| 输出 10，末尾 78 补根 | 78,18,26,31,35,29,48,59,65 |
| 78 与 18 交换 | 18,78,26,31,35,29,48,59,65 |
| 78 与 31 交换 | 18,31,26,78,35,29,48,59,65 |
| 78 与 59 交换 | 18,31,26,59,35,29,48,78,65 |
| 插入 39 至尾部 | 18,31,26,59,35,29,48,78,65,39 |

39 的双亲为 35，满足堆序，不需要上浮。

### （4）第二轮：先输出 18，再接收 12

| 操作 | 当前堆数组 |
| --- | --- |
| 输出 18，末尾 39 补根 | 39,31,26,59,35,29,48,78,65 |
| 39 与 26 交换 | 26,31,39,59,35,29,48,78,65 |
| 39 与 29 交换 | 26,31,29,59,35,39,48,78,65 |
| 插入 12 至尾部 | 26,31,29,59,35,39,48,78,65,12 |
| 12 与 35 交换 | 26,31,29,59,12,39,48,78,65,35 |
| 12 与 31 交换 | 26,12,29,59,31,39,48,78,65,35 |
| 12 与 26 交换 | 12,26,29,59,31,39,48,78,65,35 |

两轮的输出为 **10、18**，最终堆顶为 12。若下一轮再输出，才会输出 12。可用树形表示最终堆：

```text

          /    \
        26      29
       /  \    /  \

     / \  /

```

</Solution>

现需对整数序列 $\{18,25,3,7,50,19\}$ 通过堆排序调整为从小到大的序列，据此回答以下问题。

1. 给出构造完成的初始堆以及构造初始堆的时间复杂度。
2. 给出由初始堆到有序序列的完整堆排序过程。
3. 堆是否为二叉排序树？是否为完全二叉树？

<Solution>

### （1）构造初始大根堆

要用原地堆排序得到升序，选择大根堆：根为当前未排序区最大值，每轮将其交换到未排序区末尾，最大值逐个就位。采用从 1 开始的数组下标，最后一个非叶结点为 $\lfloor6/2\rfloor=3$，按 3、2、1 自底向上筛选。下沉时必须选择较大的孩子。

| 筛选位置 | 过程 | 层序数组 |
| --- | --- | --- |
| 初始 | — | 18,25,3,7,50,19 |
| 3 | 3 与唯一孩子 19 交换 | 18,25,19,7,50,3 |
| 2 | 25 与较大孩子 50 交换 | 18,50,19,7,25,3 |
| 1 | 18 与 50 交换，再与 25 交换 | 50,25,19,7,18,3 |

初始堆为：

![初始堆](/images/exams/408-jingcheng-2027/02-42-heap.svg)

每个结点均不小于孩子，且完全二叉树形状不变。自底向上建堆为 $O(n)$，因为高度为 $k$ 的结点数约为 $n/2^{k+1}$，每个至多下沉 $k$ 层，所有下沉代价之和由下式控制：

$$
O\left(n\sum_{k\ge1}\frac{k}{2^k}\right)=O(n).
$$

不能把每个非叶结点的最坏下沉次数都当作 $\log n$ 后直接认为建堆是 $O(n\log n)$（这仅是较松上界）。

### （2）完整堆排序过程

每轮交换堆顶和当前堆最后一个元素，将堆长度减 1，然后只对剩余前缀向下筛选。后缀已排好，不能参与后续比较。

| 轮次 | 交换堆顶与末元素之后 | 筛选过程 | 筛选完成（竖线后已排序） |
| --- | --- | --- | --- |
| 初始 | — | — | 50,25,19,7,18,3 |
| 1 | 3,25,19,7,18,50 | 3↔25，3↔18 | `25,18,19,7,3 ｜ 50` |
| 2 | 3,18,19,7,25,50 | 3↔19 | `19,18,3,7 ｜ 25,50` |
| 3 | 7,18,3,19,25,50 | 7↔18 | `18,7,3 ｜ 19,25,50` |
| 4 | 3,7,18,19,25,50 | 3↔7 | `7,3 ｜ 18,19,25,50` |
| 5 | 3,7,18,19,25,50 | 剩一个元素，不调整 | `3 ｜ 7,18,19,25,50` |

对应题目原图：

![堆排序过程](/images/exams/408-jingcheng-2027/02-42-sort.svg)

最终升序序列为 $\boxed{3,7,18,19,25,50}$。图与上述数组逐轮一致。每轮最多下沉 $O(\log n)$，共 $n-1$ 轮，故堆排序最坏时间复杂度为 $O(n\log n)$；原地迭代筛选的辅助空间为 $O(1)$。堆排序通常不稳定，因为交换堆顶与末元素可能改变相同关键字的相对顺序。

### （3）堆与二叉排序树、完全二叉树的区别

- **堆是完全二叉树**：按层序紧凑存放，最后一层从左向右填充，可直接用数组下标计算孩子位置。
- **堆不一定是二叉排序树**：大根堆只要求父结点不小于孩子，不要求左子树所有关键字小于根且右子树所有关键字大于根。例如初始堆的根为 50、右孩子为 19，已违反普通 BST 右子树关键字大于根的性质。

原题问“堆是否为二叉排序树”，准确表述应为堆一般不是 BST，而非两种性质在逻辑上绝对互斥（例如单结点树同时满足）。对于一般 BST，中序遍历为升序；对一般堆，中序遍历不保证有序，必须通过反复取出极值等操作完成排序。

</Solution>

## 7.6 外部排序

<Question id="sim1127-wd408-2027-s06-q41" type="essay" tags="来源:27王道八套卷, 试卷:第6套·第41题, 科目:数据结构, 章节:排序, 考点:外部排序与四路最佳归并树" points={11}>

外存中有 $n$ 条记录，每条记录恰好占一个磁盘块；内存一次能容纳 $k$ 条记录，且 $n\gg k$。先用内部排序生成初始归并段，再进行 **4 路归并**（假设归并时具备满足缓冲区要求的内存空间）。

1. 每次最多读入 $k$ 条记录进行内部排序，会生成多少个初始归并段？
2. 这种初始归并段的生成方法有什么局限？如何优化？
3. 若已经生成 $8$ 个初始归并段，长度依次为 $12,25,39,61,19,42,33,49$（单位：磁盘块），构造 **4 路最佳归并树**，写出归并顺序及其总磁盘 I/O 次数。约定每次读或写一个磁盘块记为一次 I/O，计入**归并阶段**的读、写，不重复计入初始归并段生成阶段的 I/O。

<Solution>

### （1）确定初始归并段数

外部排序分为两个阶段：先将外存中无序记录分批读入内存，利用内部排序生成有序段，再将各有序段多路归并。内存一次容纳 $k$ 条，若每批尽可能装满，则设 $n=qk+r$，其中 $0\le r<k$。前 $q$ 批各含 $k$ 条，若 $r>0$，还需处理最后不足一批的 $r$ 条。

因此初始归并段数为 $\boxed{\lceil n/k\rceil}$。注意此处向上取整，不能因为最后一段不满就忽略它。

### （2）如何减少初始归并段数

直接分批内部排序的局限在于每个有序段至多包含 $k$ 条记录，段之间没有利用输入原有的顺序关系。段数越多，在固定归并路数下通常需要越多层归并，而外部排序的主要开销是磁盘 I/O。

可以用**置换—选择排序**，在内存中维护最多 $k$ 条待处理记录，通过最小堆或败者树选取当前段中最小的可输出记录：

1. 初始读入 $k$ 条记录，全部标为当前归并段可用。
2. 选出当前可用记录中关键字最小的一条写入当前段，记其关键字为 $last$。
3. 从输入补入一条新记录。若其关键字不小于 $last$，仍可参加当前段的选择；否则标记为下一段的记录（冻结），不能再写入当前段。
4. 当所有剩余记录都被冻结，结束当前段，解除冻结并开始下一段；输入读完后继续输出剩余记录，直至全部输出。

例如内存只容纳 3 条，初始记录为 2、5、8，随后输入 4、7、1。输出 2 后读入 4（可用），输出 4 后读入 7（可用），输出 5 后读入 1（冻结）；继续输出 7、8，当前段得到 2、4、5、7、8，长度为 5，已经超过内存容量 3；下一段再输出 1。

当输入关键字独立、近似随机时，平均段长通常约为 $2k$，但这并非对任意输入的保证。完全逆序输入可能只能生成长度约为 $k$ 的段，完全升序输入则可能只生成一段。置换—选择的关键是**边输出边补入**，不是增大内存。

### （3）四路最佳归并树与 I/O 计算

**第一步：补虚段。** 设严格四叉归并树有 $I$ 个内部结点、$L$ 个叶结点，每个内部结点有 4 个孩子。由边数关系 $4I=I+L-1$ 得 $L=3I+1$，即 $L-1$ 应为 3 的倍数。现有 8 段，需要补两个长度为 0 的虚段，使叶数变为 10。

为什么不能直接取最短四段合并？因为第一次就合并四个真实段，会使最后某次归并的路数不足 4；将不足路数的归并安排在树的较深处，并优先处理较短段，才符合多叉哈夫曼树的最优构造。

**第二步：反复选择当前权值最小的四个结点。** 初始权值按升序排列为 $0,0,12,19,25,33,39,42,49,61$，真实总长度为 280。

| 次数 | 选出的最小权值 | 新段长度 | 当前剩余权值（升序） |
| --- | --- | ---: | --- |
| 1 | 0、0、12、19 | 31 | 25、31、33、39、42、49、61 |
| 2 | 25、31、33、39 | 128 | 42、49、61、128 |
| 3 | 42、49、61、128 | 280 | 280 |

对应的树为：

```text
[280]
├─ 42
├─ 49
├─ 61
└─ [128]
   ├─ 25
   ├─ [31]
   │  ├─ 0
   │  ├─ 0
   │  ├─ 12
   │  └─ 19
   ├─ 33
   └─ 39
```

第一次实际只归并两个真实段，两个虚段不产生 I/O。

**第三步：按读写次数计费。** 每合并长度总和为 $w$ 的若干段，必须读入 $w$ 个磁盘块并写出 $w$ 个磁盘块，故产生 $2w$ 次 I/O。每个内部结点恰好对应一次这样的归并。

$$
WPL=31+128+280=439,\qquad I/O=2\times439=\boxed{878\text{ 次}}.
$$

也可以从叶深度独立核验：长度 12、19 的段参与三次归并，25、33、39 参与两次，42、49、61 参与一次。因此

$$
WPL=3(12+19)+2(25+33+39)+(42+49+61)=439.
$$

最佳归并树本质上是多叉哈夫曼树，最小化各段长度与参与归并次数的乘积之和，而不只是最小化归并轮数。题目明确仅统计归并阶段；若另计初始段生成阶段，还要加上读、写各 280 块，共 560 次，总计 1438 次。按本题要求不加这部分。

</Solution>

</Question>

<Question id="sim1127-408-jingcheng-2027-03-42" type="essay" points={10} tags="来源:27竞成10套卷, 试卷:第3套·第42题, 科目:数据结构, 章节:排序, 考点:败者树构建与多路归并">

已知某计算机将初始文件经过原始内部排序后得到以下四个初始归并段：$\{6,8\}$（归并段 1）；$\{3,9\}$（归并段 2）；$\{1,5\}$（归并段 3）；$\{2,7\}$（归并段 4）。计算机采用败者树进行四路归并，初始败者树由每个归并段的第一个元素参与构建，据此回答以下问题：

(1) 画出初始构建完成的败者树。

(2) 该败者树决出的第二个冠军结点保存的是？

(3) $k$-路平衡归并败者树的树高是多少？

<Solution>

### （1）构造初始败者树

败者树用来加速多路归并时的最小值选择。每个叶子代表一路有序段的当前待输出记录；内部结点保存比较失败的一路的**段号**，胜者继续向上参加比较，最终冠军段号单独保存在 `a[0]` 中。升序归并时关键字较小的一方获胜。

初始各段的候选值如下：

| 归并段号 | 原有序段 | 当前候选值 |
| --- | --- | ---: |
| 1 | 6、8 | 6 |
| 2 | 3、9 | 3 |
| 3 | 1、5 | 1 |
| 4 | 2、7 | 2 |

自底向上比较：

| 比较位置 | 参赛候选 | 胜者（段号） | 败者（存入结点的段号） |
| --- | --- | --- | --- |
| `a[2]` | 6 与 3 | 2 | 1 |
| `a[3]` | 1 与 2 | 3 | 4 |
| `a[1]` | 3 与 1 | 3 | 2 |

所以初始 `a[0..3] = [3,2,1,4]`，第一个冠军是段 3 的记录 1。

```text
          a[0]=3（冠军段号）
               |
            a[1]=2
           /      \
       a[2]=1    a[3]=4
        /   \     /   \
       6     3   1     2  （叶子保存候选关键字）
      段1   段2  段3   段4
```

题目原图展示了初建及下一次调整的对应状态：

![败者树构建及调整过程](/images/exams/408-jingcheng-2027/03-42-loser-tree.svg)

### （2）决出第二个冠军

首先输出第一个冠军关键字 1，仅从段 3 补入下一条记录 5。其余三路候选值不动。因为只有段 3 的叶子改变，左侧子树比赛结果不变，只需重赛段 3 到根的路径。

1. 在 `a[3]` 处，将新值 5 与原败者段 4 的值 2 比较。2 获胜向上，5 失败，故 `a[3]=3`。
2. 在 `a[1]` 处，将段 4 的值 2 与原败者段 2 的值 3 比较。2 获胜，`a[1]` 仍为 2。
3. 冠军段号写入 `a[0]=4`，此时 `a[0..3]=[4,2,1,3]`。

所以第二个冠军结点中保存的**段号为 4**，它对应的记录关键字为 2。考试中必须区分题目问的是结点存储的段号还是输出的记录值。

继续归并时，某段耗尽可用正无穷大作为哨兵，使它不再成为最小值冠军（实现中应保证哨兵大于全部合法关键字，或者另设耗尽标志）。整段输出顺序为 1、2、3、5、6、7、8、9，可用于检验。

### （3）树高与比较次数

$k$ 路平衡归并需要 $k$ 个叶子。当 $k=2^m$ 时，比赛共 $m$ 层；当 $k$ 不是 2 的整数次幂时，可按平衡结构组织或补足到下一次幂，最长比赛路径仍为 $\lceil\log_2 k\rceil$。

按本题规定不计冠军结点和叶结点，故树高为 $\boxed{h=\lceil\log_2 k\rceil}$。若其他教材把完整叶层计入结点层数，则会多 1 层；不要混淆树高按边数还是按层数计算的约定。

一般初建需 $O(k)$ 次比较，每输出一条记录后仅需沿一条路径调整，比较次数至多为 $\lceil\log_2 k\rceil$，而直接扫描 $k$ 个候选需要 $k-1$ 次比较。归并 $N$ 条记录的比较时间复杂度为 $O(k+N\log k)$（$k\ge2$），这正是采用败者树的主要价值。败者树降低的是关键字选择的比较开销，并不会自动改变给定归并方案的磁盘 I/O 次数。
