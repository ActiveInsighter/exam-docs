## 4.2 IPv4

<Question id="sim1127-wd408-2027-s04-q47" type="essay" tags="来源:27王道八套卷, 试卷:第4套·第47题, 科目:计算机网络, 章节:网络层, 考点:VLAN、ARP与NAT综合" points={9}>

局域网拓扑见图。R 是支持 NAT 的路由器，其 E0 为 `192.168.0.1/24`，MAC 为 `00-11-11-11-11-A1`；S 是支持 802.1Q 的交换机，**VLAN10：端口 1、2、5；VLAN20：端口 3、4**；AP 为桥接式无线接入点。H1、H2 分别在端口 1、2，默认网关均为 `192.168.0.1`；AP 接端口 3，DHCP 服务器接端口 4；H3、H4 从 DHCP 获取地址。**本题只讨论 H1 所属 VLAN10 出口上网，不假设图中已经实现 VLAN20 与 VLAN10 间的三层路由。**

![](/images/27王道8套卷1025/p045-1.svg)

1. VLAN10 与 VLAN20 是否同属一个二层广播域？H1 的广播以太网帧能直接传给 H3 吗？
2. H1 在浏览器中输入 `www.s.com`，经 Internet 访问 Web 服务器。说明 DNS 解析需要的条件、H1 ARP 查询的对象、IP 层目的地址与下一跳的关系，以及 H1 初始发出的以太网帧目的 MAC。
3. H1 的私网 IP 报文经 R 做 NAT/PAT 后向 Internet 转发。描述 H1 的二层转发路径、源／目的 IP 在 R 上可能发生的变化，以及 R **外网出口处**的以太网帧目的 MAC 应属于哪个设备。
4. H1 可以 ping 通 `192.168.0.1`，且浏览器已经得到 Web 服务器公网 IP，但 HTTP 请求总超时。假设 R 的接口与默认路由工作正常、NAT 功能已启用，**但尚未验证 NAT 转换／过滤规则**。候选故障为：① NAT/PAT 或过滤规则错误；② H1 默认网关填错；③ DNS 服务器地址错误。选最有针对性的故障项并解释。

<Solution>

### 解题思路

本题应分三层判断：VLAN 决定二层广播范围，路由表决定 IP 数据报的下一跳，NAT 决定经过出口路由器时哪些地址或端口需要转换。这三件事不能混为一谈。

### （1）判断广播域

**不是同一个广播域，不能直接传给 H3。**

交换机 S 按 VLAN 分隔广播域。H1 接端口 1，属于 VLAN10；H3 经 AP 接端口 3，属于 VLAN20。H1 发出广播帧时，S 只向 VLAN10 内除入端口外的端口 2、5 泛洪，不向端口 3、4 转发。因此 H3 收不到该广播。AP 作为二层桥接设备，并不能使两个 VLAN 自动互通。

即使图中的两个 VLAN 使用相同的 IP 网段，也不能改变二层广播范围。跨 VLAN 通信通常需要三层网关，并合理划分不同 IP 子网。

### （2）DNS、路由选择与 ARP

设 Web 服务器公网 IP 为 $W$，H1 的 IP 为 `192.168.0.11`。

1. **域名解析：** 若本机已有有效 DNS 缓存，可以直接获得 $W$；否则需要可用的 DNS 解析服务（例如已配置且可达的递归 DNS 服务器）。DNS 查询本身也要经过正常的 IP 路由和必要的链路层解析。图中 VLAN20 的 DHCP 服务器并不能据此被认定为 H1 的 DNS 服务器。
2. **判断目的地址是否直连：** H1 用 `/24` 掩码判断 $W$ 不属于 `192.168.0.0/24`，于是按路由表选择默认网关 `192.168.0.1` 为下一跳。
3. **获得下一跳 MAC：** 若 ARP 缓存未命中，H1 广播查询 `192.168.0.1` 对应的 MAC，R 的 E0 接口应答 `00-11-11-11-11-A1`。
4. **构造以太网帧：** IP 层仍以 $W$ 为最终目的地址，链路层则以 E0 的 MAC 为本跳目的地址。

| 字段 | H1 发出承载 Web 流量的帧 |
| --- | --- |
| 源 IP | `192.168.0.11` |
| 目的 IP | Web 服务器公网 IP $W$ |
| 源 MAC | `00-11-11-11-11-01` |
| 目的 MAC | **`00-11-11-11-11-A1`** |

若访问的是普通 HTTP，通常先建立 TCP 连接再发 HTTP 请求；HTTPS 通常还需完成 TLS 握手。上述表格针对去往 Web 服务器的流量，而不是 DNS 查询帧或 ARP 广播帧。

### （3）逐跳转发和 NAT/PAT

二层路径为 **H1 → S 的端口 1 → S 的端口 5 → R 的 E0**。交换机依据 VLAN10 的 MAC 转发表转发，不需要改写 IP 源、目的地址。R 收到帧后去掉原链路层封装，检查 IP 首部并查找下一跳。

设 R 用公网地址 $P$、映射端口 $p'$ 代表 H1 的源地址及源端口 $p$。典型出站 PAT 的变化如下：

| 字段 | R 内网入口 | R 外网出口 |
| --- | --- | --- |
| 源 IP | `192.168.0.11` | $P$ |
| 源 TCP 端口 | $p$ | $p'$（可能保持不变） |
| 目的 IP | $W$ | $W$ |
| 目的端口 | Web 服务端口 | 不变 |

此外，路由转发会递减 TTL，并更新相应校验和；NAT 修改地址或端口也需维护有关校验和及映射状态。返回流量由 R 根据映射反向转换。

**若外网出口是以太网，目的 MAC 是外网本链路下一跳设备的 MAC**（通常为上游路由器；若目的主机恰好直连，则是该主机 MAC）。源 MAC 是 R 外网出口接口的 MAC。若外网采用 PPP，则不存在以太网 MAC 字段。原图没有给出外网链路类型及下一跳地址，无法确定具体 MAC 数值。

### （4）故障定位

在三个候选项中，**① NAT/PAT 或过滤规则错误**最值得优先排查。

- ① NAT 已启用不等于转换规则正确；可能没有匹配 H1 的源网段、缺少回程映射或防火墙阻断 TCP 流量，均可造成 HTTP 超时。
- ② 能 ping 通网关只证明 H1 与 `192.168.0.1` 之间的本地连通性，**并不能单独证明默认路由配置正确**。但题干已经给定默认网关为该地址，在该前提下不优先选②。若实际配置未确认，仍需查 H1 路由表。
- ③ 已获得服务器公网 IP，单纯 DNS 配置错误不能解释随后直接向该 IP 发送 HTTP 请求仍超时。

实际排障还可检查远端服务是否监听、TCP SYN 是否收到应答、NAT 会话和过滤日志。题目要求最有针对性的候选项，而不是断言其他故障必然不存在。

### 易错点与题设说明

ARP 解析的是**当前以太网链路的下一跳 IP**，不是永远解析最终目的 IP；IP 目的地址通常跨路由保持，而二层地址逐跳重新封装。原题已明确只分析 VLAN10 的外网访问，不能额外假定 VLAN20 有跨 VLAN 路由。

</Solution>

<Question id="sim1127-wd408-2027-s05-q47" type="essay" tags="来源:27王道八套卷, 试卷:第5套·第47题, 科目:计算机网络, 章节:网络层, 考点:VLSM与路由聚合" points={9}>

某企业内网分配地址块 `160.10.10.0/24`，经核心路由器 R1 和外部路由器 R2 接入 Internet。部门 1、2、3 有计算机 **112、60、29** 台，且每个部门还要为 R1 的 LAN 网关接口预留一个可用 IP，部门 1 包含可被公网访问的 Web 服务器。三个部门采用以太网交换机 S1～S3，R1 与 R2 通过 **PPP** 点到点链路互连。部门 1～3 按地址从低到高分配子网，尽量节约空间；图示 R1 的 WAN1 地址为 `198.10.10.18/30`。

![](/images/27王道8套卷1025/p054-1.svg)

1. 为 3 个部门划分地址块（CIDR），并给出部门 1 一个合理的默认网关 IP。
2. R2 的 WAN2 在同一 `/30` 链路上，可分配什么 IP？写出计算。
3. 为了让 Internet 能把数据送回企业内网，给出 R2 至少需要的**企业网路由**（可作地址聚合；注明直连 WAN 网络），若其他 Internet 路由未在图中给出，不要求臆造。
4. Internet 主机的请求已到 R2，随后经 R1 转发到部门 1 的 Web 服务器。**R2、R1 和其他设备开始时 ARP 缓存均为空**；在该单向转发路径上需要多少次 ARP 地址解析？不统计对端服务器回包。

<Solution>

### 解题思路

VLSM 的核心是先算每个子网所需的可用地址数，再取满足条件的最小二次幂地址块，按照由大到小的顺序在合法边界上分配。常规 IPv4 广播子网需要保留网络地址和广播地址，另外还要计入网关。

### （1）为三个部门分配地址

若部门需要 $m$ 个计算机地址，再加一个网关，则主机位数 $h$ 应满足

$$
2^h-2\ge m+1,\qquad \text{前缀长度}=32-h。
$$

| 部门 | 需要的可用地址 | 最小主机位数 | 分配块大小 | CIDR |
| --- | ---: | ---: | ---: | --- |
| 1 | 113 | 7 | 128 | `160.10.10.0/25` |
| 2 | 61 | 6 | 64 | `160.10.10.128/26` |
| 3 | 30 | 5 | 32 | `160.10.10.192/27` |

例如部门 3 若使用 `/28`，只有 $2^4-2=14$ 个可用地址，远不够；`/27` 恰好提供 30 个。

各子网边界如下（省略前三个字节 `160.10.10`）：

| 部门 | 网络地址 | 可用主机地址 | 广播地址 | 掩码 |
| --- | --- | --- | --- | --- |
| 1 | .0 | .1～.126 | .127 | 255.255.255.128 |
| 2 | .128 | .129～.190 | .191 | 255.255.255.192 |
| 3 | .192 | .193～.222 | .223 | 255.255.255.224 |

部门 1 的默认网关可以设置为 **`160.10.10.1`**，分配给 R1 的 L1 接口；该地址不得重复分配给其他主机。剩余 `.224～.255` 恰好形成一个 `/27` 地址块，留作扩展。即便部门 1 的 Web 服务器另占一个地址，该 `/25` 仍有余量。

### （2）确定 WAN2 的 IP 地址

`/30` 的掩码为 `255.255.255.252`，最后一个字节掩码为二进制 `11111100`。R1 的 WAN1 地址最后一字节为 18，即 `00010010`。

按位与得到 `00010000`，也就是 16。因此该点到点链路的地址块为 `198.10.10.16/30`，范围如下：

| 地址 | 用途 |
| --- | --- |
| `198.10.10.16` | 网络地址 |
| `198.10.10.17` | R2 的 WAN2 |
| `198.10.10.18` | 已分配给 R1 的 WAN1 |
| `198.10.10.19` | 广播地址 |

答案：**WAN2 为 `198.10.10.17/30`**。

### （3）R2 的企业网路由

三个部门的地址均属于企业获配的 `160.10.10.0/24`，而且从 R2 看它们都要经过同一个下一跳 R1。因此不必分别设置三条静态路由，使用一条聚合路由即可。

| 目的网络 | 子网掩码 | 下一跳 | 转发接口 |
| --- | --- | --- | --- |
| `160.10.10.0` | `255.255.255.0` | `198.10.10.18` | WAN2 |
| `198.10.10.16` | `255.255.255.252` | 直连 | WAN2 |

第一条是企业网的汇总路由，第二条是 WAN2 自身的直连路由。未分配的 `.224/27` 也在汇总范围内，R1 应对没有具体有效路由的地址妥善丢弃或配置汇总丢弃路由，避免与默认路由形成循环。题目没有提供 R2 的 Internet 上游接口信息，不需假设具体外网路由。

补充：若明确要求汇总只能精确覆盖已使用地址，不能覆盖未分配块，则不能用单条 `/24`；本题整个 `/24` 已分配给企业，因此允许汇总。

### （4）ARP 解析次数

**1 次。** 沿请求的单向路径逐段判断：

| 转发阶段 | 链路类型 | ARP 次数 | 原因 |
| --- | --- | ---: | --- |
| R2 → R1 | PPP | 0 | 点到点链路无以太网目的 MAC，不需要 ARP |
| R1 → S1 → Web 服务器 | 以太网 | 1 | R1 必须获得服务器 IP 对应的 MAC |

交换机 S1 依据 MAC 地址转发表完成帧转发，不因经过它而额外产生一次 ARP。一次地址解析通常包含 ARP 请求和应答两个报文，本题问的是解析次数，不是报文数。且请求已到 R2，不计外网此前的链路，也不计服务器回包。

### 易错点

VLSM 分配不能只看计算机数量，网关也占可用地址；路由汇总必须考虑下一跳是否一致；PPP 与以太网的封装方式不同，不能机械地按路由器数量统计 ARP。

</Solution>
</Question>

<Question id="sim1127-408-jingcheng-2027-02-47" type="essay" tags="来源:27竞成10套卷, 试卷:第2套·第47题, 科目:计算机网络, 章节:网络层, 考点:VLSM与路由表" points={9}>

某单位的网络拓扑如下图所示。其中 R1～R3 为路由器，L1～L5、X1～X3 为对应的路由器接口。其中 X1～X3 分别连接部门一、部门二和部门三的局域网。部门一有主机 120 台，部门二有主机 60 台，部门三有主机 60 台。路由器接口 L1～L5 的 IP 地址已在下图中进行标注，其网络前缀均为 /30。路由器 R2 通过接口 L3 连接到 Internet。据此回答以下问题。

1. 现计划将 IP 地址段 200.168.9.0/24 提供给部门一、部门二和部门三使用，其中部门二子网分配的 IP 地址为 200.168.9.128/26。请求用合适的分配方案将剩下的地址空间分配给部门一和部门三，并给出地址空间分配方案。
2. 假设网络各部件均正常运行且路由表均已收敛，请给出路由器 R3 的路由表，要求路由表项尽可能少（路由表项应包括目的网络、子网掩码、下一跳、转发接口）。
3. 假设主机 1 的默认网关误设置为 200.168.10.5，网络中无其他配置错误，请问主机 1 能否与主机 2、主机 3 进行双向正常通信？
4. 假设主机 3 的 IP 地址设置为 200.168.9.130，子网掩码误设置为 255.255.255.0，网络中无其他配置错误，请问主机 3 能否与主机 4 和主机 5 进行双向正常通信？

![网络拓扑图](/images/exams/408-jingcheng-2027/02-47-topology.svg)

<Solution>

### （1）VLSM 子网划分

部门一、二、三分别需要 120、60、60 台主机，再为各自网关预留一个地址。普通广播子网至少应满足 $2^h-2\ge m+1$。

- 部门一：`/26` 只有 62 个可用地址，选 `/25`，有 126 个可用地址。
- 部门二、三：`/27` 只有 30 个可用地址，选 `/26`，有 62 个可用地址。

题目固定部门二为 `200.168.9.128/26`，它占用最后一个字节 128～191。合法的 `/25` 边界只有 .0 和 .128，因此部门一只能使用前半个 `/25`；最后的 .192～.255 分给部门三。

| 部门 | CIDR | 掩码 | 可用主机地址（末字节） | 广播（末字节） |
| --- | --- | --- | --- | --- |
| 一 | `200.168.9.0/25` | 255.255.255.128 | 1～126 | 127 |
| 二 | `200.168.9.128/26` | 255.255.255.192 | 129～190 | 191 |
| 三 | `200.168.9.192/26` | 255.255.255.192 | 193～254 | 255 |

三个子网恰好占满 $128+64+64=256$ 个地址，且都能容纳各自网关。

### （2）R3 路由表

从拓扑图读取：X1、X2、X3 分别连接三个部门，L1 的本端地址为 `200.168.10.1/30`，对端 R2 的 L2 地址为 `200.168.10.2/30`。R1 和 Internet 都在 R2 方向，因此非本地目的可以通过默认路由转发给 R2。

| 目的网络 | 子网掩码 | 下一跳 | 转发接口 |
| --- | --- | --- | --- |
| `200.168.9.0` | `255.255.255.128` | 直连 | X1 |
| `200.168.9.128` | `255.255.255.192` | 直连 | X2 |
| `200.168.9.192` | `255.255.255.192` | 直连 | X3 |
| `200.168.10.0` | `255.255.255.252` | 直连 | L1 |
| `0.0.0.0` | `0.0.0.0` | `200.168.10.2` | L1 |

**严格意义上的完整路由表应包含第四条直连 `/30` 路由。** 原参考答案只给三个部门及默认路由，省略了该直连链路；如果评分只要求业务转发相关的简表，可写原有四条，并注明 L1 链路由系统自动产生直连路由。实际递归查找默认路由下一跳时，需要确认该地址通过 L1 直接可达。

虽然部门二、三的地址块相邻且能组成 `/25`，但出接口分别为 X2、X3，不能把它们作为一条具有单一转发接口的等效路由合并。最长前缀匹配保证部门内路由优先于默认路由。

### （3）主机 1 默认网关配置错误

**主机 1 与主机 2 可以双向正常通信；与主机 3 不可以。**

主机 1 和主机 2 都位于部门一，属于同一 `/25`，通信时直接 ARP 查询对方的 MAC，不经过默认网关。默认网关配置错误不影响同网段直接交付。

主机 3 位于部门二。主机 1 判断目的地址不在本子网，需要把帧交给本地网关 R3 的 X1 接口。但它错误地将 `200.168.10.5`（R2 的 L4）设置为默认网关；该地址既不是部门一的直连地址，也不在主机 1 所在二层网络中，正常主机配置下无法作为有效本地下一跳。即使主机 3 发来的某些报文能到主机 1，主机 1 的回程仍失败，故不能双向通信。

### （4）主机 3 子网掩码配置错误

主机 3 为 `200.168.9.130`，正确掩码应为 `/26`，误配 `/24` 后，自身计算得到的网络地址是 `200.168.9.0`。

根据图，主机 5 属于部门二，主机 4 属于部门三。两者的地址与错误的 `/24` 掩码相与，均得到 `200.168.9.0`。因此主机 3 都会尝试在部门二直接进行 ARP。

| 对端 | 主机 3 的判断 | 实际位置 | 双向通信 |
| --- | --- | --- | --- |
| 主机 5 | 同网段、直接交付 | 部门二，与主机 3 同 LAN | **可以** |
| 主机 4 | 同网段、直接交付 | 部门三，隔着 R3 | **不可以** |

主机 5 使用正确 `/26` 时也认为主机 3 是本地地址；而主机 4 所在 LAN 收不到主机 3 发出的 ARP 广播。即使主机 4 可以经 R3 将 IP 报文发给主机 3，主机 3 的回复仍无法直接交付。

以上采用考研常规前提：无代理 ARP、特殊主机路由等额外配置。如果路由器开启代理 ARP，错误掩码在某些情况下可能被掩盖，但题目未给出该条件，不应自行假设。

</Solution>

## 4.4 路由协议

<Question id="sim1127-wd408-2027-s02-q47" type="essay" tags="来源:27王道八套卷, 试卷:第2套·第47题, 科目:计算机网络, 章节:网络层, 考点:RIPv2与路由收敛" points={9}>

某单位通过 R1～R5 互联部门局域网，并由 R3 接入 Internet。路由器使用支持 CIDR/VLSM 的 **RIPv2** 交换路由信息，路由表已收敛。部门 1、部门 2 分别有 18 台和 25 台联网计算机，连接 R1 的 D1、D2，地址块是 `211.72.32.0/26`；还需给各部门的路由器 LAN 接口分配地址。路由器间各点到点网络都是 `/30`，具体 IP 如图。

![](/images/27王道8套卷1025/p025-1.svg)

1. 为部门 1、部门 2 分配适当的 CIDR 子网，并给出 R1 的 D1 和 D2 的 IP 地址。
2. 给出部门 1 主机的子网掩码和默认网关。
3. 给出 R1 与 R4 到**部门 1、部门 2 和 Internet** 的最少路由表项，分别写出目的网络、掩码、下一跳和出接口。Internet 用缺省路由代表；允许对**相邻且具有相同下一跳**的两个部门网络进行路由聚合。
4. R2 停机后网络重新收敛，说明 RIP 的变化处理，并写出 R1 到 Internet 的新路由。

<Solution>

### （1）两个部门的子网划分

地址块 `211.72.32.0/26` 共有 $2^6=64$ 个地址。部门 1 和部门 2 加上各自网关分别需要 19 和 26 个可用地址。

常规 IPv4 子网中，若主机位数为 $h$，可用主机地址数为 $2^h-2$。`/28` 的 14 个可用地址不足，`/27` 的 30 个可用地址均满足要求。因此把 `/26` 的 64 个地址分成两个连续的 32 地址块。

| 部门 | CIDR | 可用地址范围 | 广播地址 | 网关示例 |
| --- | --- | --- | --- | --- |
| 1 | `211.72.32.0/27` | `211.72.32.1～30` | `211.72.32.31` | D1：`211.72.32.1` |
| 2 | `211.72.32.32/27` | `211.72.32.33～62` | `211.72.32.63` | D2：`211.72.32.33` |

两子网可交换分配，网关也可选各自可用范围内的其他不冲突地址。以下以表中方案为准。

### （2）部门 1 的主机设置

`/27` 对应最后一字节掩码 `11100000`，即 224。故子网掩码为 **`255.255.255.224`**，默认网关为 **`211.72.32.1`**，即 R1 的 D1 接口地址。

### （3）根据 RIP 跳数选路

RIP 以跳数为度量，而非物理距离、链路带宽或时延。先在图中找最少经过路由器的路径，再读取**相邻路由器的接口 IP**作为下一跳，而不是抄写自身出接口 IP。

| 起点 | 目标 | 优选路径 | 路径上的路由器间链路数 |
| --- | --- | --- | ---: |
| R1 | R3（Internet 出口） | R1→R2→R3 | 2 |
| R4 | R1（两个部门网关） | R4→R5→R1 | 2 |
| R4 | R3（Internet 出口） | R4→R3 | 1 |

R1 到 R3 的其他路径（如经 R5、R4 或经 R5、R2）至少需要 3 条路由器间链路，故不优先选。R4 到 R1 经 R3、R2 需要 3 条，劣于经 R5 的路径。这里统计的是拓扑中的路由器间链路数，用于比较路径，不等同于特定设备显示的 RIP 路由度量绝对值。

**R1 的相关路由表：**

| 目的网络 | 子网掩码 | 下一跳 | 出接口 |
| --- | --- | --- | --- |
| `211.72.32.0` | `255.255.255.224` | 直连 | D1 |
| `211.72.32.32` | `255.255.255.224` | 直连 | D2 |
| `0.0.0.0` | `0.0.0.0` | `211.72.33.6` | L2 |

R1 的两个 LAN 出接口不同，不能合并为一条普通转发路由。

**R4 的相关路由表：**

| 目的网络 | 子网掩码 | 下一跳 | 出接口 |
| --- | --- | --- | --- |
| `211.72.32.0` | `255.255.255.192` | `211.72.33.22` | L10 |
| `0.0.0.0` | `0.0.0.0` | `211.72.33.17` | L9 |

R4 到两个部门均经 R5 的 L11（`211.72.33.22`），两个连续 `/27` 只在第 27 位不同，前 26 位一致，故可按题意聚合为 `/26`。这是一种等效汇总表达，不意味着 RIPv2 默认必然自动生成该汇总项。表格按题目限定范围列出，不是完整设备路由表。

### （4）R2 停机后的 RIP 更新

R2 停机使 R1、R3、R5 与 R2 之间的链路失效。RIP 可通过接口故障通知或路由超时获知不可达，将失效路由的度量置为 16（无穷大），再通过触发或周期更新通知邻居。邻居根据收到的距离向量重新计算可达路径。水平分割、毒性逆转等措施能减少环路，但不能保证所有故障下立即收敛。

去掉 R2 后，R1 到 Internet 的可达路径为

$$
R1\rightarrow R5\rightarrow R4\rightarrow R3\rightarrow\text{Internet}。
$$

因此 R1 的新默认路由如下：

| 目的网络 | 掩码 | 下一跳 | 出接口 |
| --- | --- | --- | --- |
| `0.0.0.0` | `0.0.0.0` | **`211.72.33.2`** | **L1** |

R5 的对应接口是 L13，地址为 `211.72.33.2`；R1 自己的 L1 为 `211.72.33.1`，不能把本端地址当下一跳。

### 知识补充

RIPv2 能携带子网掩码，支持 VLSM/CIDR；RIP 的最大有效度量为 15 跳，16 表示不可达。默认路由在最长前缀匹配中优先级最低，只有找不到更具体的匹配项时才使用。
