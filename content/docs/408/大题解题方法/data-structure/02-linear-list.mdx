## 二、核心模型一：链表双指针——控制两个指针的相对位置

链表不能像数组一样通过下标直接访问任意元素。因此，解决链表的位置问题，关键在于**建立两个指针之间的位置关系**。

### 1. 2009 年真题：查找倒数第 $k$ 个结点

**题目核心：** 已知带头结点的单链表，不改变链表，查找倒数第 $k$ 个结点。

#### 解题本质：把倒数问题转化为距离问题

假设要求倒数第 3 个结点：

```text
初始状态：
1 → 2 → 3 → 4 → 5 → 6 → 7 → NULL
p
q

p 先走 3 步：
1 → 2 → 3 → 4 → 5 → 6 → 7 → NULL
q           p

随后 p、q 同步移动：
1 → 2 → 3 → 4 → 5 → 6 → 7 → NULL
                q               p
```

当 `p` 到达 `NULL` 时，`q` 恰好指向倒数第 3 个结点。

整个过程中，两个指针始终保持 $k$ 个结点间隔。

#### 必须掌握的代码

以下链表代码统一采用 `next` 表示后继指针，题目如果使用 `link`，替换即可。

```c
int findK(Node *L, int k) {
    Node *p = L->next;
    Node *q = L->next;

    // p 先走 k 步
    for (int i = 0; i < k; i++) {
        if (p == NULL)
            return 0;
        p = p->next;
    }

    // 保持固定距离，同步移动
    while (p != NULL) {
        p = p->next;
        q = q->next;
    }

    printf("%d", q->data);
    return 1;
}
```

时间复杂度为 $O(n)$，辅助空间复杂度为 $O(1)$。

#### 固定间距的位置关系

而是这个位置关系：

$$
\text{快指针到达表尾之后的位置}
\Longrightarrow
\text{慢指针到达倒数第 }k\text{ 个结点}
$$

这类算法叫作**固定间距双指针**。

### 2. 知识迁移：2012 年真题——寻找公共后缀

例如两个单词 `loading` 和 `being` 共享后缀 `ing` 的存储空间：

```text
l → o → a → d ─┐
               ↓
               i → n → g → NULL
               ↑
        b → e ─┘
```

问题是找到两个链表第一个共享的结点。

假设两个链表长度分别为 $m,n$，直接从头同步遍历是不行的，因为两个链表到尾部的距离不同。

解决方法：

- 分别求两个链表的长度。
- 让较长链表的指针先走 $|m-n|$ 步。
- 两个指针同步移动，直到指向同一个结点。

时间复杂度为 $O(m+n)$，辅助空间复杂度为 $O(1)$。

**最重要的易错点：**

```text
p == q
```

才表示两个指针指向同一个结点，而：

```c
p->data == q->data
```

只能说明两个结点的数据相同，不代表共享存储空间。

#### 双指针的本质总结

| 双指针类型 | 控制的关系       | 解决的问题       |
| ----- | ----------- | ----------- |
| 固定间距  | 两指针相隔 $k$ 步 | 倒数第 $k$ 个结点 |
| 尾端对齐  | 两指针距离表尾相等   | 公共后缀、链表相交   |
| 快慢指针  | 一个走一步，一个走两步 | 寻找链表中点、环检测  |

应根据题设设计指针之间的相对位置关系。

## 三、核心模型二：链表反转、拆分与合并

链表反转是一个基础操作，却可以组合解决很多看起来复杂的算法题。

### 1. 必须彻底掌握：单链表原地反转

假设原链表为：

```text
1 → 2 → 3 → 4 → NULL
```

目标是：

```text
4 → 3 → 2 → 1 → NULL
```

反转的本质不是交换数据，而是修改每一个结点的后继指针。

需要三个指针：

| 指针     | 含义         |
| ------ | ---------- |
| `prev` | 已反转部分的首结点  |
| `p`    | 当前待反转结点    |
| `q`    | 暂存下一个待处理结点 |

```c
Node *reverse(Node *p) {
    Node *prev = NULL;
    Node *q;

    while (p != NULL) {
        q = p->next;     // 保存后继
        p->next = prev;  // 反转指向
        prev = p;        // 更新已反转部分
        p = q;           // 继续处理
    }

    return prev;
}
```

反转过程：

```text
初始：
NULL     1 → 2 → 3 → 4 → NULL
prev     p

第一次：
NULL ← 1     2 → 3 → 4 → NULL
       prev  p

第二次：
NULL ← 1 ← 2     3 → 4 → NULL
           prev  p

最终：
NULL ← 1 ← 2 ← 3 ← 4
                   prev
```

最关键的一行是：

```c
q = p->next;
```

如果不提前保存后继，修改 `p->next` 后，就可能丢失尚未处理的链表。

时间复杂度为 $O(n)$，辅助空间复杂度为 $O(1)$。

### 2. 代表性真题：2019 年链表首尾交替重排

**题目要求：**

将带头结点的单链表

$$
L=(a_1,a_2,\ldots,a_{n-1},a_n)
$$

重新排列为：

$$
L=(a_1,a_n,a_2,a_{n-1},a_3,a_{n-2},\ldots)
$$

要求辅助空间复杂度为 $O(1)$，时间尽可能高效。

<Steps>

<Step>

### 分析目标结构

例如：

```text
原链表：1 → 2 → 3 → 4 → 5 → 6

目标：  1 → 6 → 2 → 5 → 3 → 4
```

将目标序列分解：

```text
第一组：1 → 2 → 3
第二组：6 → 5 → 4
```

发现第一组是原链表前半部分，第二组是原链表后半部分的逆序。

所以复杂问题实际上由三个简单操作组成：

```text
原链表
1 → 2 → 3 → 4 → 5 → 6

① 寻找中点并拆分
1 → 2 → 3
4 → 5 → 6

② 反转后半段
1 → 2 → 3
6 → 5 → 4

③ 交替合并
1 → 6 → 2 → 5 → 3 → 4
```

</Step>

<Step>

### 实现重排算法

复用前面的 `reverse` 函数。

```c
void reorder(Node *L) {
    if (L->next == NULL ||
        L->next->next == NULL)
        return;

    Node *slow = L->next;
    Node *fast = L->next;

    // 1. 找到前半段最后一个结点
    while (fast->next != NULL &&
           fast->next->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }

    // 2. 拆分并反转后半段
    Node *q = slow->next;
    slow->next = NULL;
    q = reverse(q);

    // 3. 交替合并
    Node *p = L->next;

    while (q != NULL) {
        Node *pnext = p->next;
        Node *qnext = q->next;

        p->next = q;
        q->next = pnext;

        p = pnext;
        q = qnext;
    }
}
```

时间复杂度：

$$
O(n)+O(n)+O(n)=O(n)
$$

辅助空间复杂度：

$$
O(1)
$$

</Step>

</Steps>

#### 算法分解

不是背诵一个长达几十行的重排算法，而是把复杂操作分解成：

$$
\boxed{\text{找中点}+\text{反转}+\text{合并}}
$$

三种操作可组合解决不同的链表重排问题。

### 3. 知识迁移：王道第 8 套第 42 题——回文链表

题目要求判断字符链表是否中心对称，例如 `xyx`、`xyyx`，尽可能降低时间和空间复杂度。

普通思路是将所有字符压入栈，再反向比较，但需要 $O(n)$ 的辅助空间。

最优思路与 2019 年真题几乎相同：

```text
原链表：a → b → c → b → a

拆分：
a → b → c
b → a

反转后半段：
a → b → c
a → b

逐个比较：
a == a
b == b
```

同样使用快慢指针寻找前半段的末尾，再反转后半段。但最后一步由交替合并变成对应元素比较。

如果沿用上一题的中点定位方式，奇数长度时中间结点留在前半段，只需要遍历后半段进行比较即可。

若需要保持原链表结构，在比较结束后，还应将后半段反转回来并重新连接。即使中途发现不相等，也不能直接返回而忘记恢复。

复杂度为 $O(n)$ 时间、$O(1)$ 辅助空间。

| 题目       | 找中点 | 反转后半段 | 最后操作    |
| -------- | --- | ----- | ------- |
| 2019 年真题 | 需要  | 需要    | 交替合并    |
| 第 8 套模拟题 | 需要  | 需要    | 逐个比较、恢复 |

## 四、核心模型三：空间换时间——利用元素值作为数组下标

这是顺序表和链表大题共同的重要考点。

查重、计数、寻找缺失元素时，若题设给出明确的取值范围，可优先考虑辅助数组。

### 1. 代表性真题：2015 年删除绝对值相同的结点

单链表中保存了 $m$ 个整数，满足：

$$
|data|\leq n
$$

要求绝对值相同的结点只保留第一次出现的结点。

例如，自拟一个链表：

```text
21 → -15 → 15 → -7 → 7 → 15
```

删除后：

```text
21 → -15 → -7
```

#### 解题本质：将查找问题转化为直接寻址问题

暴力算法每处理一个结点，都要查找此前是否出现过相同绝对值的元素，最坏时间复杂度为 $O(m^2)$。

题设给出的取值范围为：

$$
|data|\in[0,n]
$$

因此可以建立长度为 $n+1$ 的辅助数组 `seen`。

规定：

$$
seen[x]=
\begin{cases}
0,&x\text{ 尚未出现}\\
1,&x\text{ 已经出现}
\end{cases}
$$

这样，每次判断某个绝对值是否出现，只需一次数组访问。

#### 参考代码

假设链表带头结点，结点通过动态内存分配创建。

```c
typedef struct Node {
    int data;
    struct Node *next;
} Node;

void removeDuplicate(Node *L, int n) {
    int *seen = calloc(n + 1, sizeof(int));
    if (seen == NULL)
        return;

    Node *p = L;

    while (p->next != NULL) {
        Node *q = p->next;
        int x = abs(q->data);

        if (seen[x] == 0) {
            seen[x] = 1;
            p = q;         // 保留结点
        } else {
            p->next = q->next;
            free(q);       // 删除结点
        }
    }

    free(seen);
}
```

需要使用 `stdlib.h` 中的相关函数。

#### 链表删除的关键细节

观察以下两种情况：

```text
保留结点：
p → q → r
    ↑
    p 向后移动

删除结点：
p → q → r

变成：
p ─────→ r
```

<Callout type="warn" title="链表删除">

**删除结点以后，前驱指针 `p` 不能移动。**

</Callout>

因为下一个结点尚未检查。如果删除后仍然移动 `p`，就可能漏掉连续重复的结点。

#### 复杂度分析

初始化辅助数组需要 $O(n)$ 时间，遍历链表需要 $O(m)$ 时间，因此严格来说：

$$
T(m,n)=O(m+n)
$$

辅助空间复杂度为：

$$
S(m,n)=O(n)
$$

题库参考答案将时间复杂度写为 $O(m)$，没有单独计入辅助数组初始化的开销。在 $m,n$ 相互独立时，写成 $O(m+n)$ 更严谨。

### 2. 知识迁移：2018 年寻找未出现的最小正整数

题目给定一个长度为 $n$ 的整数数组，找出其中未出现的最小正整数。

例如：

$$
A=(-5,3,2,3)
$$

答案为 1。

这道题最重要的并不是辅助数组，而是如何确定辅助数组的范围。

#### 为什么答案一定在 $[1,n+1]$ 中？

因为数组只有 $n$ 个元素。

如果 $1,2,\ldots,n$ 全部出现，那么数组的所有位置都被占满，最小未出现的正整数必然是 $n+1$。

如果其中有数字没有出现，答案必然落在 $[1,n]$ 内。

因此：

$$
\boxed{1\leq ans\leq n+1}
$$

即使原数组出现很大的数字或者负数，也完全没有必要记录它们。

算法只需：

1. 建立长度为 $n+1$ 的标记数组。
2. 遍历原数组，只标记处于 $[1,n]$ 内的元素。
3. 从 1 开始查找第一个未标记的下标，如果全部出现，就返回 $n+1$。

时间复杂度为 $O(n)$，辅助空间复杂度为 $O(n)$。

#### 进阶理解：原数组本身也可以充当标记空间

如果题目进一步要求 $O(1)$ 辅助空间，并且允许修改原数组，可以将值为 $x$ 的元素交换到下标 $x-1$ 的位置。

最终寻找第一个满足：

$$
A[i]\ne i+1
$$

的位置即可。

交换时必须检查目标位置是否已经等于 $x$，否则遇到重复元素可能陷入死循环。

这种方法同样可以达到 $O(n)$ 时间，但不需要额外的标记数组。原真题只要求时间尽可能高效，因此辅助数组法已经满足要求，而且更加容易书写。

### 3. 知识迁移：2013 年主元素问题

题目要求寻找出现次数超过 $n/2$ 的元素。

由于题目给定：

$$
0\leq A[i]<n
$$

因此可以直接使用辅助数组进行计数，达到 $O(n)$ 时间、$O(n)$ 空间。

但如果同时希望将辅助空间降到 $O(1)$，就要掌握一个特殊算法：**摩尔投票法**。

#### 摩尔投票法的本质：不同元素两两抵消

假设存在主元素 $x$，其数量超过全部元素的一半。

那么不断删除两个不同的元素，主元素的数量优势不会消失。

例如：

```text
5, 5, 3, 5, 7, 5, 5

抵消一对 5 和 3：
5, 5, 7, 5, 5

抵消一对 5 和 7：
5, 5, 5
```

最终剩下的候选元素一定是主元素——前提是主元素确实存在。

```c
int majority(int A[], int n) {
    int candidate = 0;
    int count = 0;

    // 第一遍：寻找候选元素
    for (int i = 0; i < n; i++) {
        if (count == 0)
            candidate = A[i];

        if (A[i] == candidate)
            count++;
        else
            count--;
    }

    // 第二遍：验证候选元素
    count = 0;
    for (int i = 0; i < n; i++)
        if (A[i] == candidate)
            count++;

    return count > n / 2 ? candidate : -1;
}
```

<Callout type="warn" title="摩尔投票的候选验证">

最容易忘记的是第二遍验证。

</Callout>

因为算法筛选出的只是候选元素，而原数组不一定真的存在主元素。

时间复杂度为 $O(n)$，辅助空间复杂度为 $O(1)$。

#### 空间换时间模型总结

| 题目要求      | 辅助数组的含义        |
| --------- | -------------- |
| 查找某元素是否出现 | `seen[x]`      |
| 统计元素出现次数  | `count[x]`     |
| 删除重复元素    | `seen[x]`      |
| 查找缺失元素    | 查找未标记下标        |
| 绝对值去重     | `seen[abs(x)]` |

遇到明确的取值范围时，优先判断：**能不能把元素的值直接映射为数组下标？**

## 五、核心模型四：数组原地变换——三次反转与稳定性

### 1. 代表性真题：2010 年循环左移

将长度为 $n$ 的数组循环左移 $p$ 个位置，要求时间和空间都尽可能高效。

例如：

```text
原数组：1 2 3 4 5 6 7
左移 3 位
结果：  4 5 6 7 1 2 3
```

#### 解题本质：交换两个连续区间

设原数组由两部分组成：

$$
XY
$$

其中 $X$ 是前 $p$ 个元素，$Y$ 是剩余元素。

循环左移实际上就是：

$$
XY\longrightarrow YX
$$

通过三次反转可以得到：

$$
XY
\longrightarrow X^RY
\longrightarrow X^RY^R
\longrightarrow YX
$$

其中上标 $R$ 表示逆序。

具体过程：

```text
原数组：    1 2 3 | 4 5 6 7

反转前段：  3 2 1 | 4 5 6 7

反转后段：  3 2 1 | 7 6 5 4

整体反转：  4 5 6 7 | 1 2 3
```

#### 必须掌握的代码

```c
void reverseArray(int A[], int l, int r) {
    while (l < r) {
        int temp = A[l];
        A[l] = A[r];
        A[r] = temp;
        l++;
        r--;
    }
}

void leftRotate(int A[], int n, int p) {
    reverseArray(A, 0, p - 1);
    reverseArray(A, p, n - 1);
    reverseArray(A, 0, n - 1);
}
```

时间复杂度为 $O(n)$，辅助空间复杂度为 $O(1)$。

另一种等价做法是先整体反转，再分别反转前 $n-p$ 个和后 $p$ 个元素，这也是题库参考答案采用的方法。

#### 为什么这道题值得掌握？

因为三次反转并不是循环移位专属算法，而是一个通用的**相邻区间原地交换算法**。

该方法可用于数组分段重排、循环右移及相邻区间交换。

### 2. 王道第 5 套第 42 题：奇偶位置稳定重排

要求将原奇数号元素放在原偶数号元素之前，且保持各自的相对顺序。

```text
原数组：10 20 30 40 50 60 70

结果：  10 30 50 70 20 40 60
```

注意两个限定：

**第一，奇偶性指原来的位置，而不是元素值。**

**第二，保持相对顺序，意味着不能随意交换元素。**

最简单的高效解法是使用辅助数组：

```c
int j = 0;

for (int i = 0; i < n; i += 2)
    B[j++] = A[i];

for (int i = 1; i < n; i += 2)
    B[j++] = A[i];

for (int i = 0; i < n; i++)
    A[i] = B[i];
```

这里假定辅助数组 `B` 已经分配好。

时间复杂度为 $O(n)$，辅助空间复杂度为 $O(n)$。

如果限制 $O(1)$ 辅助空间，一个简单方案是逐个插入原奇数号元素，将中间元素整体后移，但最坏时间为 $O(n^2)$。

还可以利用分治与相邻区间旋转设计更复杂的稳定重排算法，不过不属于本题优先掌握的解法。

**稳定性、时间效率和空间效率需要统筹考虑。** 不应为追求原地操作而破坏稳定性。

## 六、核心模型五：利用有序性，排除不可能的解

有序数组的最大价值，并不是方便遍历，而是可以利用大小关系，一次性排除大量不需要检查的情况。

这一点在 2011 年和 2020 年真题中体现得非常明显。

### 1. 代表性真题：2020 年三元组最小距离

给定三个升序数组，分别选出一个元素 $a,b,c$，使下式最小：

$$
D=|a-b|+|b-c|+|c-a|
$$

暴力算法需要枚举全部三元组。

利用有序性，只需维护三个指针。

<Steps>

<Step>

### 化简目标函数

假设：

$$
a\leq b\leq c
$$

则：

$$
\begin{aligned}
D&=(b-a)+(c-b)+(c-a)\\
&=2(c-a)
\end{aligned}
$$

因此无论三个数的大小关系如何，都有：

$$
\boxed{D=2(\max(a,b,c)-\min(a,b,c))}
$$

也就是说，**中间值并不直接决定距离，最大值和最小值之间的差才是关键。**

</Step>

<Step>

### 确定移动指针

假设当前选中的三个元素为：

$$
(2,5,9)
$$

由于数组升序排列：

| 移动方式    | 可能产生的效果        |
| ------- | -------------- |
| 移动最小值 2 | 最小值可能增大，距离可能缩小 |
| 移动中间值 5 | 最小值不变，最大值不会减小  |
| 移动最大值 9 | 最大值不会减小，距离无法缩小 |

因此，在记录当前距离后，应移动最小元素所在数组的指针。

理由是：只要保留当前最小元素，其他两个数组的后续元素都不会变小，因而无法产生比当前更小的距离。

这就是排除无效解的依据。

</Step>

<Step>

### 实现算法

```cpp
long long minDistance(int A[], int B[], int C[],
                      int m, int n, int t) {
    int i = 0, j = 0, k = 0;
    long long ans = LLONG_MAX;

    while (i < m && j < n && k < t) {
        int low = min(A[i], min(B[j], C[k]));
        int high = max(A[i], max(B[j], C[k]));

        long long d = 2LL * (1LL * high - low);
        ans = min(ans, d);

        if (ans == 0)
            return 0;

        // 移动最小元素所在的指针
        if (A[i] == low)
            i++;
        else if (B[j] == low)
            j++;
        else
            k++;
    }

    return ans;
}
```

这里采用 C++，使用 `std::min`、`std::max` 和 `LLONG_MAX`，需要相应头文件。

三个数组的长度分别为 $m,n,t$，每一个指针都只会向前移动。

因此时间复杂度为：

$$
O(m+n+t)
$$

辅助空间复杂度为 $O(1)$。

相比暴力算法的 $O(mnt)$，效率提升非常明显。

</Step>

</Steps>

#### 这道题应该学到什么？

不要看到三个数组就直接写三层循环。

遇到最优化问题，应该先考虑能否化简目标函数，再利用数据的有序性，证明某些情况不必检查。

### 2. 知识迁移：2011 年两个升序序列的中位数

题目给出两个等长的升序数组，每个数组长度为 $n$，要求寻找合并后的中位数。

特别注意，按照原题定义，中位数是合并后第 $n$ 小的元素，**不是中间两个元素的平均值**。

<Tabs items={['双指针归并', '二分排除']}>

<Tab value="双指针归并">

两个指针分别指向两个数组的首元素，每次选择较小元素，并移动相应指针。

当选出第 $n$ 个元素时停止。

不必真正创建合并数组。

时间复杂度为 $O(n)$，辅助空间复杂度为 $O(1)$。

</Tab>

<Tab value="二分排除">

分别取两个数组的中间元素，比较大小。

如果 $A$ 的中间元素小于 $B$ 的中间元素，可以排除 $A$ 中一部分较小元素，同时排除 $B$ 中相同数量的较大元素。

之所以必须排除相同数量，是为了保持剩余序列所求中位数的对应关系。

具体处理如下，设当前两个区间等长，长度为 $s$，中间位置均取靠左的中位位置。

| 比较结果       | $s$ 为奇数             | $s$ 为偶数            |
| ---------- | ------------------- | ------------------ |
| $A_m<B_m$ | A 保留中点及右侧，B 保留中点及左侧 | A 保留中点右侧，B 保留中点及左侧 |
| $A_m>B_m$  | B 保留中点及右侧，A 保留中点及左侧 | B 保留中点右侧，A 保留中点及左侧 |
| $A_m=B_m$  | 直接返回                | 直接返回               |

直到两个区间各剩一个元素，返回两者中较小者。

每轮问题规模大约减半：

$$
T(n)=T(\lceil n/2\rceil)+O(1)
$$

所以：

$$
T(n)=O(\log n)
$$

采用循环实现时，辅助空间复杂度为 $O(1)$。

这道题建议先熟练掌握双指针归并，再理解二分排除的最优解。不要在还没有理解排除规则之前机械背诵奇偶性判断的代码。

</Tab>

</Tabs>

## 七、核心模型六：滑动窗口——避免重复计算连续区间

### 王道第 3 套第 42 题：乘积小于 $k$ 的连续子数组

给定一个正整数数组，统计乘积严格小于 $k$ 的非空连续子数组数量。

例如：

$$
A=(10,5,2,6),\quad k=100
$$

答案为 8。

#### 1. 为什么可以使用滑动窗口？

最关键的条件是：**所有元素都是正整数。**

因此：

- 向窗口右侧加入元素，乘积不会减小。
- 从窗口左侧删除元素，乘积不会增大。

这就是滑动窗口所依赖的单调性。

如果数组包含负数，这种单调性就可能被破坏。如果包含 0，下面使用除法收缩窗口的代码也不能直接使用。

#### 2. 最核心的计数公式

假设窗口为：

$$
[left,right]
$$

且整个窗口的乘积小于 $k$。

那么所有以 `right` 为右端点、以窗口内任意位置为左端点的子数组都合法。

例如当前窗口为：

```text
[5, 2, 6]
```

以 6 为结尾的合法子数组为：

```text
[6]
[2, 6]
[5, 2, 6]
```

所以新增合法子数组数量为：

$$
\boxed{right-left+1}
$$

#### 3. 完整演算

对于数组 $(10,5,2,6)$：

| 加入元素 | 收缩后的窗口    | 窗口乘积 | 新增数量 | 累计数量 |
| ---- | --------- | ---- | ---- | ---- |
| 10   | $[10]$    | 10   | 1    | 1    |
| 5    | $[10,5]$  | 50   | 2    | 3    |
| 2    | $[5,2]$   | 10   | 2    | 5    |
| 6    | $[5,2,6]$ | 60   | 3    | 8    |

加入 2 时，原窗口乘积为 100，不满足严格小于 100 的条件，所以必须删除左端的 10。

#### 4. 必须掌握的代码模板

```c
long long countSubarrays(int A[], int n, int k) {
    if (k <= 1)
        return 0;

    int left = 0;
    long long product = 1;
    long long ans = 0;

    for (int right = 0; right < n; right++) {
        product *= A[right];

        // 窗口不合法时不断收缩
        while (product >= k) {
            product /= A[left];
            left++;
        }

        // 统计以 right 为结尾的子数组
        ans += right - left + 1;
    }

    return ans;
}
```

#### 5. 为什么两层循环不是 $O(n^2)$？

虽然代码中有 `for` 和 `while` 两层循环，但左指针不会回退。

右指针总共移动 $n$ 次，左指针在整个算法中最多移动 $n$ 次。

因此总操作次数与 $n$ 成线性关系：

$$
T(n)=O(n+n)=O(n)
$$

辅助空间复杂度为 $O(1)$。

这是考研算法复杂度分析中非常重要的知识：**不能只根据循环嵌套层数判断时间复杂度，而应该分析操作实际执行的总次数。**

#### 滑动窗口的通用使用条件

当题目出现连续子数组、连续子串、最长合法区间、最短合法区间或者合法区间计数时，应优先思考滑动窗口。

但必须进一步判断：随着窗口扩大或缩小，合法性是否具有可以利用的单调性质。

## 八、核心模型七：逆序访问——链表与栈的结合

### 王道第 2 套第 42 题：高位在前的单链表加法

两个单链表分别表示两个非负整数，每个结点存储一位数字，最高位在前。

例如：

```text
7 → 2 → 4 → 3
    5 → 6 → 4
```

分别表示 7243 和 564，结果为 7807。

#### 题目的核心矛盾

链表的访问顺序是：

$$
\text{最高位}\longrightarrow\text{最低位}
$$

但加法的计算顺序是：

$$
\text{最低位}\longrightarrow\text{最高位}
$$

访问顺序与计算顺序恰好相反，所以应该想到栈。

将两个链表中的数字分别压栈，然后从栈顶开始取出数字，逐位相加。

每次计算：

$$
sum=x+y+carry
$$

当前结果位为：

$$
digit=sum\bmod 10
$$

新的进位为：

$$
carry=\left\lfloor\frac{sum}{10}\right\rfloor
$$

由于结果是从最低位开始产生的，因此采用头插法建立结果链表，最终得到正确的高位在前的顺序。

核心代码逻辑：

```c
while (!empty(S1) || !empty(S2) || carry != 0) {
    int x = empty(S1) ? 0 : pop(S1);
    int y = empty(S2) ? 0 : pop(S2);

    int sum = x + y + carry;
    carry = sum / 10;

    // 创建新结点并头插到结果链表
    headInsert(&head, sum % 10);
}
```

这段代码是核心逻辑，省略了栈操作与头插函数的具体实现。

设两个链表长度分别为 $m,n$，时间复杂度和辅助空间复杂度均为 $O(m+n)$。

<Callout type="warn" title="循环终止条件">

**最需要注意的是最后的进位不能遗漏。**

</Callout>

例如：

$$
99+1=100
$$

两个栈都为空时，如果进位仍为 1，还必须继续生成一个结点。

本题的三个基础模块为栈的逆序访问、头插法的逆序构造和整数加法的进位处理。

## 十、考场大题的统一解题方法

<Steps>

<Step>

### 明确约束

读完题目后，先判断以下问题：

- 是顺序存储还是链式存储？
- 数据是否有序、是否有明确取值范围？
- 是否允许修改原数据结构？
- 是否要求 $O(1)$ 辅助空间？
- 是否必须保持相对顺序？

这一步决定了哪些算法可以使用，哪些算法不能使用。

</Step>

<Step>

### 消除重复工作

例如：

| 暴力解法的问题      | 优化方向    |
| ------------ | ------- |
| 不断查找链表尾结点    | 反转链表    |
| 反复判断元素是否出现   | 辅助数组    |
| 反复计算连续区间乘积   | 滑动窗口    |
| 枚举所有有序数组组合   | 多指针排除   |
| 循环移位时反复搬动数据  | 三次反转    |
| 为了寻找倒数位置反复遍历 | 固定间距双指针 |

**从暴力解法过渡到高效解法的关键，就是发现重复工作发生在哪里。**

</Step>

<Step>

### 建立算法不变量

算法不变量，是指算法执行过程中始终保持成立的性质。

这是理解算法正确性的关键。

| 算法      | 核心不变量或保持的性质         |
| ------- | ------------------- |
| 固定间距双指针 | 两指针始终相隔 $k$ 步       |
| 链表反转    | `prev` 指向已经正确反转的部分  |
| 辅助数组去重  | 标记数组记录此前保留过的元素      |
| 滑动窗口    | 每轮收缩结束后窗口合法         |
| 摩尔投票    | 消去不同元素不改变真正主元素的数量优势 |
| 有序数组归并  | 已选出的元素是当前全局最小的一批元素  |

</Step>

<Step>

### 规范书写答案

408 算法题通常要求设计思想、代码实现、复杂度分析三个部分。

**算法思想：** 说明利用了题目的什么条件，使用什么数据结构或算法，如何保证得到正确结果。

**代码实现：** 指针含义明确，关键步骤有注释，保证循环终止，处理必要的边界情况。

**复杂度分析：** 不要只写结论，要简单说明依据。例如：

> 快慢指针定位中点、反转后半段及合并链表分别需要线性时间，故总时间复杂度为 $O(n)$。算法仅使用常数个辅助指针，故辅助空间复杂度为 $O(1)$。

如果考场上实在想不出最优算法，优先写出正确的次优算法，不要因为过度追求最优解而整道题空着。但具体能够获得多少分，取决于当年评分标准。

</Step>

</Steps>

### 本章最重要的六句话

- 链表不能随机访问，因此用双指针建立位置关系。

- 复杂算法往往可以分解成几个简单的基础操作。
