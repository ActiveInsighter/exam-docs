<Question id="408-2018-01" type="single" number={1} points={2} tags="来源:2018考研408, 科目:数据结构, 考点:栈">

若栈 $S_1$ 中保存整数，栈 $S_2$ 中保存运算符，函数 $F()$ 依次执行下述各步操作：

(1) 从 $S_1$ 中依次弹出两个操作数 $a$ 和 $b$；

(2) 从 $S_2$ 中弹出一个运算符 op；

(3) 执行相应的运算 $b\ \mathrm{op}\ a$；

(4) 将运算结果压入 $S_1$ 中。

假定 $S_1$ 中的操作数依次是 5,8,3,2（2 在栈顶），$S_2$ 中的运算符依次是 *,−,+（+ 在栈顶）。调用 3 次 $F()$ 后，$S_1$ 栈顶保存的值是（ ）。

<Option>

-15

</Option>

<Option correct>

15

</Option>

<Option>

-20

</Option>

<Option>

20

</Option>

<Solution>

<Question id="408-2018-04" type="single" number={4} points={2} tags="来源:2018考研408, 科目:数据结构, 考点:二叉树性质">

设一棵非空完全二叉树 $T$ 的所有叶结点均位于同一层，且每个非叶结点都有 2 个子结点。若 $T$ 有 $k$ 个叶结点，则 $T$ 的结点总数是（ ）。

<Option correct>

$2k-1$

</Option>

<Option>

$2k$

</Option>

<Option>

$k^2$

</Option>

<Option>

$2^k-1$

</Option>

<Solution>

**【解析】** **【解法一】** 二叉树中度为 2、1、0 的结点分别有 $n_2$、$n_1$、$n_0$ 个，则 $n_0=n_2+1$。该结论挺常见的，需要考生理解记忆。该结论的依据是：二叉树中，分支数 + 1 = 结点数。度为 2 的结点有 2 个分支，度为 1 的结点有 1 个分支，则二叉树中的分支数 = $2\times n_2+n_1$，结点数 = $n_0+n_1+n_2$。代入等式：分支数 + 1 = 结点数，则有 $2\times n_2+n_1+1=n_0+n_1+n_2$，即 $n_0=n_2+1$。本题中 $n_0=k$。因为非叶结点的都有 2 个子结点，则不存在度为 1 的结点，即 $n_1=0$。则 $T$ 的结点总数是 $k-1+k=2k-1$。故选 A。

**【解法二】** 完全二叉树中所有叶结点位于同一层，且每个非叶结点都有两个子结点，所以最后一层是满的，即此树是满二叉树。最后一层（第 $n$ 层）的叶结点个数是 $k=2^{n-1}$，总结点数目是 $2^n-1=2k-1$。故选 A。

**【点评】** 常规题。考查特殊形态的二叉树结点之间的关系。要求考生熟悉基本概念。

</Solution>

</Question>

<Question id="408-2018-13" type="single" number={13} points={2} tags="来源:2018考研408, 科目:计算机组成原理, 考点:补码运算">

假定带符号整数采用补码表示，若 int 型变量 $x$ 和 $y$ 的机器数分别是 FFFF FFDFH 和 0000 0041H，则 $x$、$y$ 的值及 $x-y$ 的机器数分别是（ ）。

<Option>

$x=-65$，$y=41$，$x-y$ 的机器数溢出

</Option>

<Option>

$x=-33$，$y=65$，$x-y$ 的机器数为 FFFF FF9DH

</Option>

<Option correct>

$x=-33$，$y=65$，$x-y$ 的机器数为 FFFF FF9EH

</Option>

<Option>

$x=-65$，$y=41$，$x-y$ 的机器数为 FFFF FF96H

</Option>

<Solution>

**【解析】** ① 将负数补码转换成原码的规则为：符号位不变，将数值位取反再加 1。

$[x]_{补码}=\mathrm{FFFF\ FFDFH}=\mathrm{1\ 111\ 1111\ 1111\ 1111\ 1111\ 1111\ 1101\ 1111B}$，除符号位外，其余各位取反得到 1 000 0000 0000 0000 0000 0000 0010 0000，再加 1 得 $[x]_{原码}=\mathrm{1\ 000\ 0000\ 0000\ 0000\ 0000\ 0000\ 0010\ 0001}=-33$。② 正数的补码和原码相同，$[y]_{补码}=\mathrm{0000\ 0041H}=\mathrm{0000\ 0000\ 0000\ 0000\ 0000\ 0000\ 0100\ 0001B}=65$。③ $[x-y]_{补码}=[x]_{补码}+[-y]_{补码}$。$[-y]_{补码}$ 等于将 $[y]_{补码}$ 连同符号位在内，各位取反，再加 1。则 $[-y]_{补码}=\mathrm{1111\ 1111\ 1111\ 1111\ 1111\ 1111\ 1011\ 1111B}=\mathrm{FFFF\ FFBFH}$。

$[x-y]_{补码}=[x]_{补码}+[-y]_{补码}=\mathrm{FFFF\ FFDFH}+\mathrm{FFFF\ FFBFH}=\mathrm{FFFF\ FF9EH}$。计算过程如下：

| | | |
|---|---|---|
| $[x]_{补码}$ | | FFFFFFDF |

<Question id="408-2018-41" type="essay" number={41} points={13} tags="来源:2018考研408, 科目:数据结构, 考点:数组">

给定一个含 $n(n\geq 1)$ 个整数的数组，请设计一个在时间上尽可能高效的算法，找出数组中未出现的最小正整数。例如，数组 $\{-5,3,2,3\}$ 中未出现的最小正整数是 1；数组 $\{1,2,3\}$ 中未出现的最小正整数是 4。要求：

(1) 给出算法的基本设计思想。

(2) 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

(3) 说明你所设计算法的时间复杂度和空间复杂度。

<Solution>

**【解析】**

(1) 含有 $n$ 个整数的数组中，未出现的最小正整数一定落在区间 $[1,n+1]$ 内：因为 $1\sim n$ 这 $n$ 个正整数若全部出现，则数组恰好被占满，此时答案是 $n+1$；否则 $[1,n]$ 中必有缺席者，最小缺席者即答案。

只需要用一个辅助数组 $S[n+2]$ 记录 $k$ 是否出现过即可。$S[k]=1$ 表示 $k$ 在原数组中出现过，$S[k]=0$ 表示未出现过。遍历完原数组后只需再次遍历 $S$ 查找最小未出现整数即可。

(2) 代码实现如下：

```c
int findMissMin(int A[], int n) {
    int S[n+2] = {0}, i; // 辅助数组，记录A中元素是否出现过
    for (i = 0; i < n; i++) {
        if (A[i] > 0 && A[i] <= n) {
            S[A[i]] = 1;
        }
    }
    for (i = 1; i <= n + 1; i++) { // 从1开始遍历是因为0不是正整数
        if (S[i] == 0) {
            break;
        }
    }
    return i;
}
```

(3) 算法的时间复杂度为 $O(n)$，空间复杂度为 $O(n)$。

**【提示】** 本题暴力解法思路：先对数组元素排序（采用快速排序或者冒泡排序等任意一种），设置一个变量整型 count，初值为 1。再从有序数组第一个非负元素的位置开始遍历，遍历时若数组元素当前值等于 count，则令 count++，最后 count 的值即为所求值。时间复杂度为采用排序算法的时间复杂度。

假定计算机的主频为 500MHz，CPI 为 4。现有设备 A 和 B，其数据传输率分别为 2MBps 和 40MBps，对应 I/O 接口中各有一个 32 位数据缓冲寄存器。请回答下列问题，要求给出计算过程。

(1) 若设备 A 采用定时查询 I/O 方式，每次输入/输出都至少执行 10 条指令。设备 A 最多间隔多长时间查询一次才能不丢失数据？CPU 用于设备 A 输入/输出的时间占 CPU 总时间的百分比至少是多少？

(2) 在中断 I/O 方式下，若每次中断响应和中断处理的总时钟周期数至少为 400，则设备 B 能否采用中断 I/O 方式？为什么？

(3) 若设备 B 采用 DMA 方式，每次 DMA 传送的数据块大小为 1000B，CPU 用于 DMA 预处理和后处理的总时钟周期数为 500，则 CPU 用于设备 B 输入/输出的时间占 CPU 总时间的百分比最大是多少？

<Solution>

**【解析】**

(1) 采用定时查询 I/O 方式：① I/O 接口数据缓冲寄存器为 32 位 = 4B。设备 A 数据传输率 2MB/s，填满 4B 缓冲区的时间 = $\frac{4\mathrm{B}}{2\mathrm{MB/s}}=2\mu\mathrm{s}$。若超过 2μs 未查询，缓冲区数据会被新数据覆盖而丢失，因此最多每隔 2μs 必须查询一次。

② 每秒查询次数 = $\frac{1\mathrm{s}}{2\mu\mathrm{s}}=5\times 10^5$ 次。每次查询至少执行 10 条指令，CPI = 4，每条指令需 4 个时钟周期。每秒用于设备 A 的时钟周期数 = $5\times10^5\times10\times4=2\times10^7$。CPU 主频 500MHz，每秒总时钟周期数 = $500\times10^6$。CPU 用于设备 A 的输入/输出时间占比 = $\frac{2\times10^7}{500\times10^6}=4\%$。

(2) ① I/O 接口数据缓冲寄存器为 32 位 = 4B。设备 B 传输率 40MB/s，准备 4B 数据的时间 = $\frac{4\mathrm{B}}{40\mathrm{MB/s}}=2\mu\mathrm{s}$。每次中断响应和处理至少需要 400 个时钟周期，每个时钟周期 = $\frac{1}{500\mathrm{MHz}}\mathrm{s}$，则每次中断响应和处理耗时 = $400\times\frac{1}{500\mathrm{MHz}}=0.8\mu\mathrm{s}$。

{/* 原书此处将 4B/(40MB/s) 误写为 2μs，正确为 0.1μs；下文使用正确数值。 */}

② 由于 $0.8\mu\mathrm{s}>0.1\mu\mathrm{s}$，即中断处理速度跟不上数据到达速度，缓冲区数据会在中断处理期间被覆盖丢失。因此设备 B 不能采用中断 I/O 方式。

(3) 设备 B 数据传输率为 40MBps，DMA 每次传送 1000B，则每秒 DMA 次数 = $\frac{40\mathrm{MB}}{1000\mathrm{B}}=4\times10^4$ 次。每次 DMA 预处理和后处理共需 500 个时钟周期，则每秒 CPU 用于 DMA 的时钟周期数 = $4\times10^4\times500=2\times10^7$。

CPU 用于设备 B 的输入/输出时间占比 = $\frac{2\times10^7}{500\times10^6}=4\%$。

**【点评】** 概念题。考查定时查询、程序中断、DMA 这 3 种 I/O 方式的计算。本题跟 2009 年 408 第 43 题考法类似，考生可对比练习。

</Solution>

<Question id="408-2018-44" type="essay" points={15} tags="来源:2018考研408, 科目:计算机组成原理, 考点:虚拟存储与Cache">

某计算机采用页式虚拟存储管理方式，按字节编址。CPU 进行存储访问的过程如下图所示。根据下图回答下列问题：

(1) 主存物理地址占多少位？

(2) TLB 采用什么映射方式？TLB 是用 SRAM 还是用 DRAM 实现？

(3) Cache 采用什么映射方式？若 Cache 采用 LRU 替换算法和回写（Write Back）策略，则 Cache 每行中除数据（Data）、Tag 和有效位外，还应有哪些附加位？Cache 的总容量是多少？Cache 中有效位的作用是什么？

(4) 若 CPU 给出的虚拟地址为 0008 C040H，则对应的物理地址是多少？是否在 Cache 中命中？说明理由。若 CPU 给出的虚拟地址为 0007 C260H，则该地址所在主存块映射到的 Cache 组号是多少？

![题 44 图：CPU 进行存储访问的过程](/img/2018-q44.svg)

<Solution>

**【解析】**

(1) 访问 Cache 时使用物理地址，故图中与 Cache 直接相连的结构必为物理地址，观察图中对应地址结构可知，物理地址的位数 = $20+3+5=28$ 位。

(2) ① TLB 采用全相联映射：图中 TLB 每个表项都有独立的比较器，虚页号同时与所有 Tag 并行比较，没有固定的映射规则，这是全相联映射的特征。

② TLB 用 SRAM 实现：TLB 是高速缓存，要求速度快，SRAM 速度快但成本高，适合小容量高速缓存。

(3) ① 图中 Cache 分为左右两列，每组 2 行，用多路选择器输出，所以 Cache 采用二路组相联映射。② 附加位：

- LRU 替换算法需要 1 位 LRU 位（2 路组相联每组 1 位即可记录哪路最近最少使用）；
- 回写策略需要 1 位修改位（脏位），标记该行是否被修改过，替换时决定是否写回主存。

③ Cache 参数：28 位物理地址中 Tag = 20 位，组索引 = 3 位（共 $2^3=8$ 组），块内偏移 = 5 位（每块 $2^5=32\mathrm{B}$），每组 2 路。每行总位数 = 数据（$32\times8=256$ 位）+ Tag（20 位）+ 有效位（1 位）+ 脏位（1 位）+ LRU 位（1 位）= 279 位。

Cache 总容量 = $8\text{组}\times2\text{路}\times279\text{位}=4464\text{位}=558\mathrm{B}$。

{/* 原书按每行一个 LRU 位计算容量；若按每组一位实现，容量会不同。保留原书的每行计算口径。 */}

④ 有效位作用：标识 Cache 行中的数据是否有效。初始时或主存块被换出后有效位置 0，即使 Tag 匹配，若有效位为 0 也不能命中。

(4) ① 虚拟地址 0008C040H：虚页号（高 20 位）= 0008CH，页内偏移（低 12 位）= 040H。查 TLB：Tag = 0008CH，有效位 = 1，实页号 = 0040H，TLB 命中。将实页号和偏移拼接得到物理地址 = 0040040H。

② Cache 命中判断：根据图中给出的物理地址结构，将物理地址 0040040H 拆分为 Tag（20 位）+ 组索引（3 位）+ 块内偏移（5 位）。0040040H = 0000 0000 0100 0000 0000 0100 0000B，则 Tag = 00400H，组号 = 010B = 2，块内偏移 = 00000B。查图中 Cache 第 2 组：左路 Tag = 00400H 但有效位 = 0（无效）；右路 Tag = 01600H（不匹配）。故 Cache 未命中。

③ ▷ 根据图中给出的虚拟地址结构：

| 虚页号（20 位） | 页内偏移（12 位） |
| --- | --- |

虚拟地址 0007C260H 的页内偏移（后 12 位）= 260H = 0010 0110 0000B。

▷ 根据图中给出的物理地址结构：

| Tag 标记（20 位） | 组号（3 位） | 块内偏移（5 位） |
| --- | --- | --- |

Cache 组号是物理地址的第 6～8 位（块内偏移左边 3 位），而页内偏移在虚实地址转换中保持不变，因此直接取页内偏移的第 6～8 位：011B = 3。该地址所在主存块映射到 Cache 第 3 组。

**【拓展】** 在 2022 年 408 第 16 题考查了 Cache 比较器的个数、位数，其原理和本题出现的 TLB 比较器一致。所以，考生应仔细研究分析历年 408 真题，真的会遇到“原题”。以 TLB 为例，下面是关于比较器的个数结论：

- 直接映射：一个块只能映射到一个 TLB 行，故只需要一个比较器；
- 全相联映射：一个块可以映射到多个 TLB 行，为了加快映射速度，一般采用多个比较器，一个 TLB 行对应一个比较器；
- 组相联映射中需要的比较器个数为 TLB 一组中的行数。

**【点评】** 难题。综合考查存储系统中页式虚拟存储、TLB、Cache 三大核心机制，信息量大、计算环节多。命题人要求考生从流程图中提取参数（虚拟地址结构、TLB 全相联、Cache 二路组相联、物理地址结构），然后完成物理地址计算、Cache 命中判断和组号计算。第 (4) 小问问的第二小问尤其巧妙——组索引来自页内偏移（虚拟地址低 12 位），而虚实地址的页内偏移是相同的，直接从虚拟地址 260H 中提取 6～8 位 = 011B = 3 即可。

</Solution>

<Question id="408-2018-45" type="essay" points={8} tags="来源:2018考研408, 科目:操作系统, 考点:页式虚拟存储管理">

请根据题 44 图给出的虚拟存储管理方式，回答下列问题：

![题 44 图](/img/2018-q44.svg)

(1) 某虚拟地址对应的页目录号为 6，在相应的页表中对应的页号为 6，页内偏移量为 8，该虚拟地址的十六进制表示是什么？

(2) 寄存器 PDBR 用于保存当前进程的页目录起始地址，该地址是物理地址还是虚拟地址？进程切换时，PDBR 的内容是否会变化？说明理由。同一进程的线程切换时，PDBR 的内容是否会变化？说明理由。

(3) 为了支持改进型 CLOCK 置换算法，需要在页表项中设置哪些字段？

<Solution>

**【解析】**

(1) 由题 44 图可知：32 位虚拟地址 = 页目录号（10 位）+ 页号（10 位）+ 页内偏移（12 位）。页目录号 = 6 = 00 0000 0110B，虚拟页号 = 6 = 00 0000 0110B，页内偏移量 = 8 = 0000 0000 1000B。

三者拼接得到虚地址 = $\overbrace{0000000110}^{\text{页目录号（10 位）}}\ \overbrace{0000000110}^{\text{页号（10 位）}}\ \overbrace{000000001000}^{\text{页内偏移（12 位）}}\mathrm{B}$ = 0180 6008H。

(2) ① PDBR（页目录基址寄存器）保存当前进程页目录的起始地址，该地址是物理地址。因为页目录寻址是地址翻译的第一步，不能再通过虚拟地址访问（否则会递归依赖），所以 PDBR 中必须是物理地址。

② 进程切换时 PDBR 内容会变化：每个进程拥有独立的地址空间和页目录，切换进程后必须加载新进程的页目录起始地址到 PDBR。

③ 同一进程的线程切换时 PDBR 内容不变化：同一进程内的所有线程共享该进程的地址空间和页目录，线程切换不改变地址空间，无需更新 PDBR。

(3) 改进型 CLOCK 算法同时考虑页面是否被访问和是否被修改，因此页表项中需要设置：

- 访问位（引用位/使用位）：记录页面最近是否被访问过；
- 修改位（脏位）：记录页面是否被修改过（影响换出时是否需要写回磁盘）。

改进型 CLOCK 算法优先淘汰未访问且未修改的页面（访问位 = 0，修改位 = 0）。

**【点评】** 常规题。本题和第 44 题的共用同一背景，综合考查虚拟地址的结构、PDBR 寄存器的工作原理、以及改进型 CLOCK 置换算法。各个小问的考点其实相互独立，难度也不大，单独拿出来都适合作为一个 408 选择题，属于“强行”拼凑在一起，“割裂感”明显。

</Solution>

<Question id="408-2018-46" type="essay" points={7} tags="来源:2018考研408, 科目:操作系统, 考点:索引节点">

某文件系统采用索引节点存放文件的属性和地址信息，簇大小为 4KB。每个文件索引节点占 64B，有 11 个地址项，其中直接地址项 8 个，一级、二级和三级间接地址项各 1 个，每个地址项长度为 4B。请回答下列问题：

(1) 该文件系统能支持的最大文件长度是多少？（给出计算表达式即可）

(2) 文件系统用 1M（$1\mathrm{M}=2^{20}$）个簇存放文件索引节点，用 512M 个簇存放文件数据。若一个图像文件的大小为 5600B，则该文件系统最多能存放多少个图像文件？

(3) 若文件 F1 的大小为 6KB，文件 F2 的大小为 40KB，则该文件系统获取 F1 和 F2 最后一个簇的簇号需要的时间是否相同？为什么？

<Solution>

**【解析】**

(1) 簇大小 4KB，每个地址项 4B，因此每个间接地址块可存放 $4\mathrm{KB}\div4\mathrm{B}=1024$ 个簇号。

- 直接地址：8 个簇 → $8\times4\mathrm{KB}$；
- 一级间接：1024 个簇 → $1024\times4\mathrm{KB}$
- 二级间接：$1024\times1024$ 个簇 → $1024^2\times4\mathrm{KB}$
- 三级间接：$1024\times1024\times1024$ 个簇 → $1024^3\times4\mathrm{KB}$

最大文件长度 = $(8+1024+1024^2+1024^3)\times4\mathrm{KB}=32\mathrm{KB}+4\mathrm{MB}+4\mathrm{GB}+4\mathrm{TB}$。

(2) ① 索引节点区：1M 个簇，每簇 4KB，每个索引节点 64B，每簇可存 $4\mathrm{KB}\div64\mathrm{B}=64$ 个索引节点，总索引节点数 = $1\mathrm{M}\times64=64\mathrm{M}$ 个。

② 数据区：每个图像文件 5600B，每簇 4KB = 4096B，存储一个图像文件需要 $\lceil5600\div4096\rceil=2$ 个簇。512M 个簇最多可存放 $512\mathrm{M}\div2=256\mathrm{M}$ 个图像文件。

最多可存放的文件数受限于索引节点数和数据簇数中的较小值 = $\min(64\mathrm{M},256\mathrm{M})=64\mathrm{M}$ 个。

(3) ① F1 大小 6KB，占 $\lceil6\mathrm{KB}\div4\mathrm{KB}\rceil=2$ 个簇。$2\leq8$，两个簇全部由直接地址项索引。获取最后一个簇（第 2 簇）的簇号：只需读入 F1 的索引节点，从第 2 个直接地址项中即可得到，访问磁盘 1 次（读索引节点）。

② F2 大小 40KB，占 $\lceil40\mathrm{KB}\div4\mathrm{KB}\rceil=10$ 个簇。直接地址项只能覆盖前 8 簇，第 9、10 簇在一级间接索引范围。获取最后一个簇（第 10 簇）的簇号：先读索引节点得到一级间接地址项，再读访问该索引块，取出其中第 2 个地址项，共访问磁盘 2 次。

**【点评】** 常规题。考查索引节点（inode）文件系统的地址结构和容量计算，此类题型是 408 操作系统部分的经典题型，解题套路固定，在此前的 408 真题中也考过很多次，但更多在选择题中考查。

</Solution>
