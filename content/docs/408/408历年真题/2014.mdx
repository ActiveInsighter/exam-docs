<Question id="408-2014-01" type="single" number={1} points={2} tags="来源:2014考研408, 科目:数据结构, 考点:时间复杂度">

下列程序段的时间复杂度是（ ）。

```c
count=0;
for(k = 1; k <= n; k *= 2)
    for(j = 1; j <= n; j++)
        count++;
```

<Option>

$O(\log_2 n)$

</Option>
<Option>

$O(n)$

</Option>
<Option correct>

$O(n\log_2 n)$

</Option>
<Option>

$O(n^2)$

</Option>

<Solution>

**【解析】** 外层循环“`for(k = 1; k <= n; k *= 2)`”的执行是 $\lfloor\log_2 n\rfloor$。内存循环“`for(j = 1; j <= n; j++)`”，每次执行 $n$ 次。时间复杂度是基本语句执行次数的数量级。本题的基本语句是“`count++`”，其执行次数为：$n\lfloor\log_2 n\rfloor$。故时间复杂度为 $O(n\log_2 n)$。故选 C。

{/* 原文外层循环次数少计 1，且“内存循环”疑为“内层循环”，此处保留。 */}

**【点评】** 常规题。常规的考查时间复杂度的题目。

</Solution>

</Question>

<Question id="408-2014-03" type="single" number={3} points={2} tags="来源:2014考研408, 科目:数据结构, 考点:循环队列">

循环队列放在一维数组 $A[0,\cdots,M-1]$ 中，end1 指向队头元素，end2 指向队尾元素的后一个位置。假设队列两端均可进行入队和出队操作，队列中最多能容纳 $M-1$ 个元素。初始时为空。下列判断队空和队满的条件中，正确的是（ ）。

<Option correct>

队空：`end1 == end2`；队满：$\mathrm{end1}=(\mathrm{end2}+1)\bmod M$

</Option>
<Option>

队空：`end1 == end2`；队满：$\mathrm{end2}=(\mathrm{end1}+1)\bmod(M-1)$

</Option>
<Option>

队空：$\mathrm{end2}=(\mathrm{end1}+1)\bmod M$；队满：$\mathrm{end1}=(\mathrm{end2}+1)\bmod M$

</Option>
<Option>

队空：$\mathrm{end1}=(\mathrm{end2}+1)\bmod M$；队满：$\mathrm{end2}=(\mathrm{end1}+1)\bmod(M-1)$

</Option>

<Solution>

</Solution>

</Solution>

<Question id="408-2014-14" type="single" number={14} points={2} tags="来源:2014考研408, 科目:计算机组成原理, 考点:IEEE 754 单精度浮点数">

float 型数据常用 IEEE 754 单精度浮点格式表示。假设两个 float 型变量 $x$ 和 $y$ 分别存放在 32 位寄存器 $f_1$ 和 $f_2$ 中，若 $(f_1)=\text{CC90 0000H}$，$(f_2)=\text{B0C0 0000H}$，则 $x$ 和 $y$ 之间的关系为（ ）。

<Option correct>

$x<y$ 且符号相同

</Option>
<Option>

$x<y$ 且符号不同

</Option>
<Option>

$x>y$ 且符号相同

</Option>
<Option>

$x>y$ 且符号不同

</Option>

<Solution>

**【解析】** IEEE 754 标准规定的 32 位单精度浮点数格式如下图所示。

![IEEE 754 单精度浮点数格式](/img/2014-a14.svg)

IEEE 754 单精度浮点数格式、规格化数的真值为 $(-1)^s\times2^{(E-127)}\times1.M$。其中 $s$、$E$ 和 $M$ 分别表示符号位、阶码和尾数的取值。

$$
x=(f_1)=\text{CC90 0000H}=\underbrace{1}_{1\text{位符号位}}\ \underbrace{1001\ 1001}_{8\text{位阶码}}\ \underbrace{001\ 0000\ 0000\ 0000\ 0000\ 0000}_{23\text{位尾数}}\text{B}
$$

- 符号位 $s=1$，表示负数；
- 阶码 $E=1001\ 1001\text{B}=153$。指数偏移量 = 127，则指数 = 153 − 127 = 26；
- 尾数 $M=001\ 0000\ 0000\ 0000\ 0000\ 0000$。如上图所示，尾数采用隐含 1 的规格化表示，则尾数真值 = $1.M=1.001\ 0000\ 0000\ 0000\ 0000\ 0000=2^0+2^{-3}=1.125$。

故 $x=(f_1)=\text{CC90 0000H}=(-1)^1\times2^{26}\times1.125=-1.125\times2^{26}$。

$$
y=(f_2)=\text{B0C0 0000H}=\underbrace{1}_{1\text{位符号位}}\ \underbrace{0110\ 0001}_{8\text{位阶码}}\ \underbrace{100\ 0000\ 0000\ 0000\ 0000\ 0000}_{23\text{位尾数}}\text{B}
$$

<Option>

</Option>
<Option>

</Option>
<Option>

降低 CPU 平均访存时间

</Option>
<Option correct>

减少指令流水线资源冲突

</Option>

<Solution>

**【解析】** 指令 Cache 与数据 Cache 分离时，在指令流水线中，取指令阶段访问指令 Cache，执行阶段访问数据 Cache。采用两套独立存储、两套独立访问通路，取指令和读写数据可同时并行访问各自 Cache，消除端口争抢，减少流水线资源冲突。

若指令、数据共用同一个 Cache，在指令流水线中，同一时钟周期内取指令和读写数据会争抢唯一的 Cache 访问端口，引发资源冲突、造成流水线停顿。故选 D。

- B 选项：Cache 分离后，指令 Cache 和数据 Cache 各自容量减半，反而可能降低命中率。这是分离式设计的一个代价，而非目的。

②“哈佛架构”的核心设计思想是指令和数据分开存储，并且各自拥有独立的存储器（指令存放在程序存储器中，数据存放在数据存储器）和总线。其优点是可同时取指令、读写数据，并行执行（适合流水线），吞吐率高。缺点是硬件复杂度高、不支持程序自我修改（因为“哈佛架构”程序必须预先固化在指令 ROM 中）和动态加载（指程序运行时，才把代码从外存调入内存执行），难以运行现代通用操作系统。

③“改进型哈佛架构”是上述两种架构的折中方案：在 CPU 内部指令 Cache 和数据 Cache 分离，在 CPU 外部指令和数据统一存储。“改进型哈佛架构”兼顾性能与灵活性，是现代 CPU 的事实标准。目前主流的手机 CPU（例如：高通骁龙、联发科、苹果 A 系列和 M 系列）都是采用“改进型哈佛架构”。

**【点评】** 常规题。本题考查“哈佛架构”的设计思想。

</Solution>

<Question id="408-2014-26" type="single" number={26} points={2} tags="来源:2014考研408, 科目:操作系统, 考点:进程状态转换">

一个进程的读磁盘操作完成后，操作系统针对该进程必做的是（ ）。

<Option correct>

修改进程状态为就绪态

</Option>
<Option>

降低进程优先级

</Option>
<Option>

给进程分配用户内存空间

</Option>
<Option>

增加进程时间片大小

</Option>

<Solution>

**【解析】** A 正确：进程发起读磁盘 I/O 操作后，会从运行态变为阻塞态，等待磁盘 I/O 完成。当磁盘操作完成后，硬件会发出中断，操作系统处理中断时，必须把这个等待 I/O 的进程状态修改为就绪态，等待 CPU 调度。

B 选项：降低进程优先级不是必须操作。某些调度算法（例如，多级反馈队列）可能调整优先级，但这不是普遍要求。

C 选项：读磁盘是把数据加载到已分配的缓冲区或内存，不需要额外分配用户内存空间。内存分配通常在进程创建时完成。

D 选项：时间片调整取决于具体调度策略，不是 I/O 完成后的必做操作。

**【拓展】** ① 处于阻塞态的进程既缺少处理器资源，又缺少其他资源。而处于就绪态的进程只缺少处理器资源。② 操作系统这门课程理论概念多，学起来感觉很抽象，看不见摸不着。408 考生都是为了应试才学，大多只停留在概念阶段。建议考生尽量结合一些具体的例子学习，能加深理解、印象也更深刻。这里将进程读磁盘前后的完整操作拆解如下：

(1) 首先需要明确，为什么进程发起磁盘 I/O 后要进入阻塞态？

CPU 执行一条指令仅纳秒级（$10^{-9}\mathrm{s}$），而机械磁盘寻道、读写耗时毫秒级（$10^{-3}\mathrm{s}$），速度相差百万倍。如果进程发起读盘后不放弃 CPU，CPU 会原地空循环等待磁盘，造成处理器资源完全浪费。所以进程会主动让出 CPU。

(2) 进程读磁盘前后的完整流程：

1. 进程处于运行态：正在 CPU 上执行代码，调用 `read()` 系统调用发起磁盘读请求。
2. 陷入内核态：执行 I/O 相关特权指令，向磁盘控制器下发读写命令。
3. 进程主动放弃 CPU，转为阻塞态。操作系统内核做两件事：(a) 将该进程 PCB（进程控制块）移入 I/O 等待队列，标记状态为阻塞；(b) 调用进程调度程序，从就绪队列挑选另一个就绪进程占用 CPU。
4. 磁盘硬件独立工作：磁盘控制器不依赖 CPU，自行完成磁头寻道、数据读取，全程 CPU 可以运行其他程序。
5. I/O 完成触发中断：磁盘读完数据后发送硬件中断，OS 中断处理程序把该进程从阻塞队列移出，并修改为就绪态，放回就绪队列等待调度。

**【点评】** 难题。结合具体的实例考查进程的状态转换，类似的题是 408 考查的趋势。若平时涉猎不广，只背概念，做此类题就“摇摆不定”、不确定到底选哪个。

</Solution>

<Question id="408-2014-28" type="single" number={28} points={2} tags="来源:2014考研408, 科目:操作系统, 考点:虚实地址转换">

下列措施中，能加快虚实地址转换的是（ ）。

I. 增大快表（TLB）容量

II. 让页表常驻内存

III. 增大交换区（swap）

<Option>

仅 I

</Option>
<Option>

仅 II

</Option>
<Option correct>

仅 I、II

</Option>
<Option>

仅 II、III

</Option>

<Solution>

**【解析】** 虚实地址转换指将虚拟地址转换为物理地址。本题 I、II 正确，III 错误，对应选 C。下面逐条分析。① I 正确√：TLB 中的内容是页表内容的一部分，TLB 容量越大，TLB 中缓存页表的内容越多，在程序具有良好局部性的前提下，TLB 命中率就越高。TLB 命中时，可从 TLB 中直接得到物理地址，无需再访问内存中的页表。TLB 不命中时，必须访问内存中的页表，多一次内存访问延迟。而 TLB 访问速度比内存访问速度快 100 倍左右（经验估计值），故 I 正确。

② II 正确√：页表常驻内存是现代操作系统的设计原则。一旦页表被换出内存，地址转换时需要先从外存读入页表，读写性能下降上万倍（内存访问速度比磁盘 I/O 快上万倍）。所以，让页表常驻内存，是确保地址转换高效性的基本设计，避免了页表访问导致的外存访问开销，故 II 正确。“页表常驻内存”是用内存容量换取访问速度：占用少量物理内存存放页表，换取每次地址转换时的速度提升。

③ III 错误×：交换区（swap）是磁盘上用于页面置换的一块空间。当物理内存不足时，将不常用的页面换出到磁盘交换区，以释放内存。等程序需要这些数据时，再从交换区读回内存。交换区解决的是“内存不够用”的问题，而不是“地址转换速度”的问题。实际上，交换区是以“时间换空间”的思路，因为内存和交换区的数据交互需要磁盘 I/O，所以使用交换区比没有交换区访问更慢。所以增大交换区跟虚实地址转换速度无关。故 III 错误。

**【提示】** “以空间换时间”和“以时间换空间”是计算机科学中的经典设计思想。“以空间换时间”指用额外的、冗余的（基于缓存机制）存储空间来保存数据副本或中间结果，从而减少后续的计算时间或访问时间。通俗地讲，“以空间换时间” = 额外存一份副本，让以后查得更快、算得更少。关键前提是：这部分空间是冗余的，不存也行，只是慢。如果数据本身必须存在，只是换了个存储介质（存到外存还是内存），则不属于“以空间换时间”，而属于存储层次优化。例如，“让页表常驻内存”不是“以空间换时间”：因为页表本身必须存在，只是选择放在内存还是外存，没有增加冗余副本。TLB 才是“以空间换时间”：在 TLB 这个高速缓存中额外存储页表项的副本，与内存中的页表并存。这点非常容易混淆，是典型的易错点。

**【点评】** 常规题。考查虚实地址转换。考的很细致，需要对虚实地址转换过程很熟悉，这也是 408 考试的重难点。

▷ ① 文件 open 打开操作完整流程如下：

<Question id="408-2014-31" type="single" number={31} points={2} tags="来源:2014考研408, 科目:操作系统, 考点:管道通信">

下列关于管道（Pipe）通信的叙述中，正确的是（ ）。

<Option>

一个管道可实现双向数据传输

</Option>
<Option>

管道的容量仅受磁盘容量大小限制

</Option>
<Option correct>

进程对管道进行读操作和写操作都可能被阻塞

</Option>
<Option>

一个管道只能有一个读进程或一个写进程对其操作

</Option>

<Solution>

**【解析】** 管道通信是 408 中的冷门考点。先简要介绍管道通信，再分析题目中的 4 个选项。

管道是 UNIX / Linux 系统中最早、最简单的进程间通信方式，本质是内核开辟的一块内存缓冲区，把一个进程的输出直接作为另一个进程的输入，像水管一样单向传递字节流数据。管道分为两类：匿名管道（Pipe）、命名管道（FIFO）。

**一、匿名管道（也称为普通管道）核心特性如下：**

1. 半双工单向通信
    - 一根管道固定只能一个方向传数据：一端只读、一端只写；如果要双向收发，必须创建两根独立管道。
2. 仅支持有亲缘关系的进程间通信
    - 只能用于父子进程、兄弟进程间通信。创建管道后、父进程调用 `fork()` 生成子进程，子进程复制管道文件描述符，才能共享管道。
3. 数据存在内核缓冲区（内存）
    - 数据不会写入磁盘，管道只是内存缓冲，生命周期随进程；所有进程关闭管道后，缓冲区直接销毁。
4. 阻塞读写机制
    - 管道为空时：执行读操作的进程阻塞，直到有数据写入；
    - 管道缓冲区写满时：执行写操作的进程阻塞，直到数据被读走腾出空间；
    - 极端情况：所有写端关闭，读端读完数据直接返回 0；所有读端关闭，写端写入会触发进程崩溃信号 SIGPIPE。
5. 允许多读多写
    - 系统不限制管道的读写进程数量，但具体实现时一般设计一对一读写。

**二、命名管道**

① 命名管道又称 FIFO 文件，是文件系统中可见的特殊文件，拥有独立路径和文件名称。

② 支持无亲缘关系的任意进程间通信，弥补了匿名管道仅支持有亲缘关系的进程间通信的短板。

③ FIFO 文件在磁盘上只存文件元信息（inode、文件名和路径），不会缓存读写数据流。管道通信的临时数据全程驻留内核缓冲区中，不会落地磁盘。

④ 除去具备磁盘文件实体这一点差异，命名管道的其他通信特性（半双工、内核缓冲、字节流、读写阻塞逻辑）和匿名管道保持一致。

**三、管道通信的优缺点**

- 优点：① 实现简单、系统原生支持，开销小；② 流式字节传输，适合连续数据传递。
- 缺点：① 匿名管道只限亲缘进程间使用；② 半双工，双向通信需要双管道；③ 数据一次性读取：管道数据被读走后，缓冲区就清空，无法重复读取；④ 缓冲区容量有限，大数据传输会频繁阻塞。

再来逐一分析题目中的 4 个选项：

A 错误×：传统匿名管道是半双工的，只能单向传输数据，要实现双向通信需要建立两个管道。

B 错误×：管道是内核缓冲区，存放在内存中，容量受内核缓冲区大小限制，和磁盘容量无关。

C 正确√：管道有阻塞特性：当管道空时，读操作会阻塞；当管道写满时，写操作会阻塞。因此读、写操作都有可能被阻塞。

D 错误×：一个管道可以有多个读进程、多个写进程。只是编程时通常规范为一对一避免数据混乱，并非只能有一个读或一个写进程。

**【点评】** ★ 冷门考点。管道通信在 2009～2026 年这 18 年的 408 考试中仅 2014 年第 31 题考查过一次，属于考查频次低但工程价值高的冷门考点。而且，管道至今仍是操作系统最基础、高频使用的进程间通信手段，大量底层场景仍在大规模使用，管道通信至今仍具有不可替代性。近些年 408 中偏好考这种“在工程实际中具有重要应用但冷门的考点”，需引起考生重视。所以本题解析特意用较大篇幅尽可能全面的介绍“管道通信”，助力考生复习。

</Solution>

<Question id="408-2014-32" type="single" number={32} points={2} tags="来源:2014考研408, 科目:操作系统, 考点:多级页表">

下列选项中，属于多级页表优点的是（ ）。

<Option>

加快地址变换速度

</Option>
<Option>

减少缺页中断次数

</Option>
<Option>

减少页表所占字节数

</Option>
<Option correct>

减少页表所占的连续内存空间

</Option>

<Solution>

**【解析】** 多级页表的核心设计目的是解决单级页表需在内存中连续存放的问题。多级页表将大页表拆分成多个小页表，每个小页表占一个页面大小，高一级页表存放下级页表的物理页框号（下级页表的物理起始地址 = 页框号 × 页面大小），各级页表可以分散存放在内存中，不需要整块连续内存。下面再来逐一分析题目中的 4 个选项：

A 错误×：多级页表虚实地址转换时，需要多次内存访问（访问一级页表 → 二级页表 → … → 物理页），会减慢地址变换速度。加快变换速度的是 TLB（快表），不是多级页表。

**【提示】** ★ 页表项中只存页框号，不存完整物理地址。页框号只是编号，不是完整地址：物理内存被切分为固定大小的页框，从 0 开始顺序编号（0、1、2、… 这类数字），这个数字就是页框号。完整物理地址 = 页框号 × 页面大小 + 页内偏移。

D 正确√：减少页表所占的连续内存空间是多级页表的核心优点。大页表被拆分成多个小页表，每个小页表可以分散存放，大幅降低对连续内存的需求。

<Question id="408-2014-34" type="single" number={34} points={2} tags="来源:2014考研408, 科目:计算机网络, 考点:以太网交换机转发">

某以太网拓扑及交换机当前转发表如下所示，主机 00-e1-d5-00-23-a1 向主机 00-e1-d5-00-23-c1 发送 1 个数据帧，主机 00-e1-d5-00-23-c1 收到该帧后，向主机 00-e1-d5-00-23-a1 发送 1 个确认帧，交换机对这两个帧的转发端口分别是（ ）。

![以太网拓扑](/img/questions/408/computer-network-3-5-q3.svg)

| 目的地址 | 端口 |
| --- | --- |
| 00-e1-d5-00-23-b1 | 2 |

<Option>

$\{3\}$ 和 $\{1\}$

</Option>
<Option correct>

$\{2,3\}$ 和 $\{1\}$

</Option>
<Option>

$\{2,3\}$ 和 $\{1,2\}$

</Option>
<Option>

$\{1,2,3\}$ 和 $\{1\}$

</Option>

<Solution>

**【解析】** **一、知道以太网的转发机制，就会做本题。这里先介绍交换机的转发机制。**

以太网交换机的自学习（Self-Learning）机制是：

① 交换机收到数据帧时，先记录该帧源 MAC 地址与入端口：

- 若转发表无该 MAC 条目，则新增一条“MAC 地址 → 端口”的记录。
- 若转发表已有相同 MAC 条目，则更新该 MAC 地址对应的端口。

② 交换机在转发时，从自身转发表中查找目的 MAC 地址对应的端口：

- 若转发表存在目的 MAC 条目，则直接从条目对应的端口单播转发。
- 若转发表无目的 MAC 条目，则执行泛洪：从除入端口外所有端口转发。

③ 主机收到泛洪帧后，网卡硬件对比本机 MAC 与泛洪帧的目的 MAC 地址：

- 若匹配成功：收下帧，剥离以太网帧首部，根据帧首部 Type 字段所标识的网络层协议（例如：IPv4、IPv6、ARP 等），把数据交给上层协议处理，可回复应答帧。
- 若不匹配：则网卡硬件层直接丢弃该帧，操作系统完全感知不到，无任何响应、不产生新流量。

**二、再分析本题。**

① 当主机 00-e1-d5-00-23-a1 向主机 00-e1-d5-00-23-c1 发送 1 个数据帧时：交换机收到该帧后，记录该帧源 MAC 地址和入端口，由于转发表中没有 00-e1-d5-00-23-a1 这个 MAC 地址，则更新转发表，在转发表中新增一个条目，更新后的转发表如下：

| 目的地址 | 端口 |
| --- | --- |
| 00-e1-d5-00-23-b1 | 2 |
| 00-e1-d5-00-23-a1 | 1 |

由于转发表中没有接收方 00-e1-d5-00-23-c1 的端口号，交换机会执行泛洪：从除入端口 1 外的所有端口转发（即端口 2 和 3）。

② 当主机 00-e1-d5-00-23-c1 向主机 00-e1-d5-00-23-a1 发送确认帧时：交换机收到该帧后，记录该帧源 MAC 地址和入端口，由于转发表中没有 00-e1-d5-00-23-c1 这个 MAC 地址，则更新转发表，在转发表中新增一个条目，更新后的转发表如下：

| 目的地址 | 端口 |
| --- | --- |
| 00-e1-d5-00-23-b1 | 2 |
| 00-e1-d5-00-23-a1 | 1 |
| 00-e1-d5-00-23-c1 | 3 |

转发表中目的地址 00-e1-d5-00-23-a1 对应的端口为 1，故从端口 1 转发该帧。故选 B。

**【提示】** ★ ① 泛洪是交换机基于自身转发表缺失而采取的转发策略，交换机泛洪时不改变帧的地址字段（目的 MAC 地址、源 MAC 地址都不变），只是从多个端口复制转发。交换机不会将泛洪帧的目的 MAC 改为广播地址 FF-FF-FF-FF-FF-FF。这是常见的易错点，不要和广播帧混淆了。

② 主机收到泛洪帧和广播帧的处理方式有所不同。其中，主机收到泛洪帧的处理方式，本题前半部分已经有介绍。主机收到广播帧时，是“无条件接收”：广播帧到达网卡 → 网卡检查目的 MAC = FF-FF-FF-FF-FF-FF → 确认是广播帧 → 根据帧首部 Type 字段所标识的网络层协议（例如：IPv4、IPv6、ARP 等），把数据交给上层协议处理。

**【点评】** 难题。本题细致全面的考查了以太网交换机转发机制。适合作为一个典型例题理解记忆。本题提示部分讲解的 2 个考点，也是常见的易错点，考生需留意。

</Solution>

</Question>

<Question id="408-2014-35" type="single" number={35} points={2} tags="来源:2014考研408, 科目:计算机网络, 考点:信道数据传输速率">

下列因素中，不会影响信道数据传输速率的是（ ）。

<Option>

信噪比

</Option>
<Option>

频率带宽

</Option>
<Option>

调制速率

</Option>
<Option correct>

信号传播速度

</Option>

<Solution>

**【解析】** 先介绍香农定理：$C=W\log_2(1+S/N)$。其中：$C$ 指信道极限数据传输速率（单位为 bit/s），$W$ 指信道带宽，$S$ 指信号功率，$N$ 指噪声功率，$S/N$ 指信噪比。

① 本题信道带宽指频率带宽，指信道能通过的最高频率与最低频率之差（描述信号占有的频率区间宽度），单位为 Hz。根据香农定理，信噪比和频率带宽均会影响信道数据传输速率。

② 调制速率（又称码元速率、波特率），指单位时间内信道传输的码元（调制符号）数量，表示调制信号每秒波形变化次数，单位为波特（Baud）。数据传输速率 = 调制速率 × 单个码元携带比特数，即调制速率会影响信道数据传输速率。

③ 信道数据传输速率和信号传播速度是两个独立的概念，两者没有关系，但极易混淆。故选 D。

- 信道数据传输速率（比特率，bit/s）指单位时间，发送端能往信道里发送多少比特，衡量“发得有多快”。
- 信号传播速度（m/s，接近光速）指比特送入信道后，在介质里的传播速度，只影响“送到对方要多久”。信号传播速度决定传播时延。

例如，把信道比作高速公路：车道宽度 = 频率带宽（决定一次能并排跑多少辆车）；每秒驶入高速公路的车辆数 = 数据传输速率（每秒发多少比特）；汽车在路上的行驶速度 = 信号传播速度。

**【提示】** ★ “信道带宽”源于通信原理，在不同场景下有两种含义，容易混淆：

- 在计网物理层中，信道带宽通常指频率带宽，衡量信道能通过的频率范围，单位是 Hz。例如：双绞线信道带宽 100MHz、2.4G WiFi 信道带宽 20MHz。计网中常考的 2 个公式（香农定理、奈奎斯特定理）中，信道带宽均指频率带宽。
- 在计网非物理层（数据链路层、网络层、传输层、应用层），信道带宽通常表示数据传输速率，单位是 bps 等。例如：宽带套餐（100Mbps）、网卡速率、服务器带宽等场景，信道带宽指数据传输速率。
- 信道带宽指频率带宽（单位 Hz）还是数据传输速率（单位 bps），最重要的区分方式还是单位。例如：在 2014 年 408 第 36 题，题目中说“信道带宽为 100Mbps”。在 2023 年 408 第 34 题，题目中说“信道带宽为 4MHz”。

**【点评】** 概念题。考查计网通信（物理层）相关的基础概念。

<Question id="408-2014-36" type="single" number={36} points={2} tags="来源:2014考研408, 科目:计算机网络, 考点:后退 N 帧协议">

主机甲与主机乙之间使用后退 N 帧协议（GBN）传输数据，甲的发送窗口尺寸为 1000，数据帧长为 1000 字节，信道带宽为 100Mbps，乙每收到一个数据帧立即利用一个短帧（忽略其传输延迟）进行确认，若甲、乙之间的单向传播延迟是 50ms，则甲可以达到的最大平均数据传输速率约为（ ）。

<Option>

10Mbps

</Option>
<Option>

20Mbps

</Option>
<Option correct>

80Mbps

</Option>
<Option>

100Mbps

</Option>

<Solution>

**【解析】** ▷ 第一步，首先明确 2 个概念：① GBN（Go-Back-N，后退 N 帧，N 指发送窗口的大小）协议中，发送方在未收到确认的情况下，最多可以连续发送 N 帧。出错时需要回退并重传出错帧及其之后的帧。

② 一个完整发送周期 = 从发送方开始发送一帧到发送方收到对该帧的确认帧，所经历的时间。

▷ 第二步，数据传输速率 = $\frac{\text{一个发送周期内发送的数据量}}{\text{发送周期}}$。下面分别求一个发送周期内发送的数据量和发送周期时长 $T$。

▷ 第三步，求发送周期 $T$：① 这里信道带宽指数据发送速率 = 100Mbps，数据帧长为 1000B，发送一帧的时间 $T_t=\frac{1000\mathrm{B}}{100\mathrm{Mbps}}=\frac{1000\times8\mathrm{bit}}{100\mathrm{Mbps}}=0.08\mathrm{ms}$。② 单向传播时延 = 50ms，则双向传播时延 RTT = $50\mathrm{ms}\times2=100\mathrm{ms}$。③ 题目已说明“确认帧很短，忽略其发送时延”，则发送周期 $T=T_t+\mathrm{RTT}=0.08\mathrm{ms}+100\mathrm{ms}=100.08\mathrm{ms}$。

▷ 第四步，求发送周期 $T$ 内发送的数据量。发送一帧的时间 $T_t=0.08\mathrm{ms}$，单向传播时延 50ms。以主机甲发送第 1 帧的时间为计时起点（即 $t=0$），一个发送周期内的传输过程如下：

- $t=0$：主机甲开始发送第 1 帧。
- $t=0.08\mathrm{ms}$：第 1 帧发送完成，进入信道向主机乙传播。
- $t=0.08+50=50.08\mathrm{ms}$：第 1 帧到达主机乙，主机乙立刻发确认（忽略此确认帧的发送时延）。
- $t=50.08+50=100.08\mathrm{ms}$：确认帧传回主机甲，本轮发送周期结束。

发送窗口 = 1000，主机甲连续发送 1000 帧的时间 = $0.08\mathrm{ms}\times1000=80\mathrm{ms}$。主机甲只用 80ms 就把 1000 帧全部发完了，之后需要空闲等待到第 100.08ms 才能收到确认、开启下一轮。所以，发送周期 $T$ 内发送的数据量 = $1000\times1000\mathrm{B}=10^6\mathrm{B}$。

▷ 第五步，数据传输速率 =

$$
\frac{\text{一个发送周期内发送的数据量}}{\text{发送周期}}=\frac{1000\times1000\mathrm{B}}{100.08\mathrm{ms}}=\frac{8\times10^6\mathrm{bit}}{0.10008\mathrm{s}}\approx80\mathrm{Mbps}
$$

故选 C。

**【提示】** ① 本题如果问“信道利用率”，解题过程也是一样的。信道利用率 $U$ = 一个发送周期内发送数据的时间 ÷ 发送周期。具体到本题，$U=80\mathrm{ms}\div100.08\mathrm{ms}\approx80\%$。

② ★ 本题题目存在错误，题目中说“乙每收到一个数据帧立即利用一个短帧（忽略其传输延迟）进行确认”，这里应该是“忽略发送时延”。为了保持 408 真题的原貌（竞成收录历年 408 真题时，严格以官方在考试大纲中公布的原文为准），竞成在收录这道 408 真题时，未将该错误进行修正。此处不是竞成的真题卷子搞错了，请各位考生知悉。

**【点评】** 难题。此类题是 408 中常考的重难点之一。考生应仔细揣摩，适合作为一个典型例题理解记忆。很多其他地方的解析，都没将这题讲清楚，竞成在编写这题解析时，进行了大量调研和反复打磨。

</Solution>

<Question id="408-2014-37" type="single" number={37} points={2} tags="来源:2014考研408, 科目:计算机网络, 考点:CDMA 码分多址">

站点 A、B、C 通过 CDMA 共享链路，A、B、C 的码片序列（chipping sequence）分别是 $(1,1,1,1)$、$(1,-1,1,-1)$ 和 $(1,1,-1,-1)$。若 C 从链路上收到的序列是 $(2,0,2,0,0,-2,0,-2,0,2,0,2)$，则 C 收到 A 发送的数据是（ ）。

000

101

<Option>

</Option>
<Option>

111

<Solution>

**【解析】** CDMA 发送和解码规则如下：

- 发送方：每个站点发送数据时，发送 1 则发送自己的码片序列，发送 0 则发送自己码片序列的反码（注意：是每位取相反数）。
- 接收方：先将收到的序列按该站点码片长度分段，要解码某个发送站点的数据，就与对应码片序列做规格化内积（点积除以码片长度）。

解题步骤如下：

① 第一步：分段。因为站点码片序列长度为 4，所以将 C 收到的序列、按码片长度 4 分段，得到 $(2,0,2,0)$、$(0,-2,0,-2)$、$(0,2,0,2)$。

② 第二步：求规格化内积。将上述分段结果与站点 A 的码片序列求规格化内积。

$$
\begin{aligned}
\frac14(2,0,2,0)\cdot(1,1,1,1)&=\frac14\cdot(2+0+2+0)=1\\
\frac14(0,-2,0,-2)\cdot(1,1,1,1)&=\frac14\cdot[0+(-2)+0+(-2)]=-1\\
\frac14(0,2,0,2)\cdot(1,1,1,1)&=\frac14\cdot(0+2+0+2)=1
\end{aligned}
$$

③ 第三步：将结果转换为二进制数据。规格化内积的结果只可能是以下 3 种情况：

- 规格化内积结果为 1 ⇒ 发送的是 1。
- 规格化内积结果为 −1 ⇒ 发送的是 0。
- 规格化内积结果为 0 ⇒ 该站点未发送数据。

**【提示】** 考生可参照本题解析步骤，自行推导 C 收到 B 发送的数据是 110。

<Question id="408-2014-38" type="single" number={38} points={2} tags="来源:2014考研408, 科目:计算机网络, 考点:TCP 拥塞控制">

主机甲和主机乙已建立了 TCP 连接，甲始终以 MSS = 1KB 大小的段发送数据，并一直有数据发送；乙每收到一个数据段都会发出一个接收窗口为 10KB 的确认段。若甲在 $t$ 时刻发生超时时拥塞窗口为 8KB，则从 $t$ 时刻起，不再发生超时的情况下，经过 10 个 RTT 后，甲的发送窗口是（ ）。

<Option correct>

10KB

</Option>
<Option>

12KB

</Option>
<Option>

14KB

</Option>
<Option>

15KB

</Option>

<Solution>

**【解析】** ① 当 TCP 发生超时重传时，TCP 拥塞控制初始化规则如下：

- 将拥塞窗口 cwnd 重置为 1 个 MSS = 1KB。
- 将慢启动门限 ssthresh 更新为超时时刻拥塞窗口的一半，即：$\mathrm{ssthresh}=\frac{\mathrm{cwnd}}{2}=4\mathrm{KB}$。

② 当 cwnd ≤ ssthresh 时，是慢开始阶段：每经过一个 RTT，cwnd 翻倍（cwnd 指数增大）。拥塞窗口 cwnd 变化过程是：

$$
1\mathrm{KB}\xrightarrow{\text{第 1 个 RTT}}2\mathrm{KB}\xrightarrow{\text{第 2 个 RTT}}4\mathrm{KB}
$$

当经过 2 个 RTT 后，cwnd = ssthresh = 4KB，慢开始阶段结束。

③ 当 cwnd > ssthresh 时，进入拥塞避免阶段：每经过一个 RTT，cwnd 加一（cwnd 线性增大）。拥塞窗口 cwnd 变化过程是：

$$
\begin{aligned}
4\mathrm{KB}&\xrightarrow{\text{第 3 个 RTT}}5\mathrm{KB}\xrightarrow{\text{第 4 个 RTT}}6\mathrm{KB}\\
&\xrightarrow{\text{第 5 个 RTT}}7\mathrm{KB}\xrightarrow{\text{第 6 个 RTT}}8\mathrm{KB}\\
&\xrightarrow{\text{第 7 个 RTT}}9\mathrm{KB}\xrightarrow{\text{第 8 个 RTT}}10\mathrm{KB}\\
&\xrightarrow{\text{第 9 个 RTT}}11\mathrm{KB}\xrightarrow{\text{第 10 个 RTT}}12\mathrm{KB}
\end{aligned}
$$

经过 10 个 RTT 后，拥塞窗口 cwnd = 12KB。

④ 拥塞窗口是网络侧的承载上限，接收窗口是接收方的承载上限，发送窗口必须同时满足两个上限、取更小值，即：发送窗口 = min\{拥塞窗口 cwnd, 接收窗口 rwnd\} = min(12KB, 10KB) = 10KB。故选 A。

**【提示】** ① 题目已说明“接收窗口一直为 10KB”，根据发送窗口 = min\{拥塞窗口, 接收窗口\}，可知发送窗口 ≤ 接收窗口（10KB），则发送窗口不超过 10KB，只有 A 选项符合要求。这种解法可节省较多做题时间，无需分析慢开始和拥塞避免过程。猜测这里大概率应该是命题人考虑不周，选项设计欠妥当，导致考生“可钻空子”：设计几个小于 10KB 的选项即可避免。命题的本意应该还是要考 TCP 的拥塞控制过程的。

② 本题错选 B 的同学，挺可惜的，考点应该都会，但做题时“顾头不顾尾”，算了半天算出了拥塞窗口 = 12KB，漏了发送窗口要取拥塞窗口、接收窗口里更小的那个。这种“丢三落四”不是知识掌握的问题，可通过多做题增加熟练度、并总结专属自己的易错点来避免此类问题。

**【点评】** 常规题。TCP 连接的建立与释放、拥塞控制，是 408 中的高频考点。类似的题在 408 中多次考到。

</Solution>

PPPoE（PPP over Ethernet）协议属于工作在数据链路层的封装型 / 隧道型协议：它不是凭空定义了一套全新的通信规则，而是把原本用于点对点链路的 PPP 协议，封装在以太网帧中进行传输。PPPoE 协议设计的初衷就是为了弥补以太网的接入管控短板。

- PPPoE 的价值：它在以太网和 PPP 之间搭建了适配层，在共享的以太网物理链路上，为每个用户虚拟出一条独立的点对点逻辑隧道，既保留了以太网部署成本低的优势，又继承了 PPP 完善的用户管理能力。

<Question id="408-2014-41" type="essay" number={41} points={13} tags="来源:2014考研408, 科目:数据结构, 考点:二叉树的带权路径长度">

二叉树的带权路径长度（WPL）是二叉树中所有叶结点的带权路径长度之和。给定一棵二叉树 T，采用二叉链表存储，其结点结构为：

| left | weight | right |
| --- | --- | --- |

其中叶结点的 weight 域保存该结点的非负权值。设 root 为指向 T 的根结点的指针，请设计求 T 的 WPL 的算法，要求：

(1) 给出算法的基本设计思想。

(2) 使用 C 或 C++ 语言，给出二叉树结点的数据类型定义。

(3) 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

<Solution>

**【解析】**

(1) 算法的基本设计思想：① 二叉树的带权路径长度（WPL）是树中所有叶结点的带权路径长度之和。叶结点的带权路径长度 = 该叶结点的权值 × 根结点到该叶结点的路径长度（路径上的边数），其中叶结点的权值存储在结点结构体的 weight 成员中。

② 求解时，可通过“任意一种二叉树的遍历算法”（本题采用中序遍历）统计每个叶结点的路径长度：遍历时维护一个变量 h，二叉树每向下一层深度 h 加 1，每回溯一层深度 h 减 1（如果用层序遍历算法则不用回溯）；遇到叶结点时，用其权值 weight 与当前深度 h 相乘并累加到总和 WPL 中。遍历完整棵二叉树即可求得 WPL。

(2) 二叉树结点的数据类型定义如下：

```c
typedef struct BiTNode {
    int weight;
    struct BiTNode *left, *right;
} BiTNode, *BiTree;
```

(3) C 语言算法代码实现如下：

```c
void InOrderCalWPL(BiTNode *T,int h,int *wpl) {
    if(T == NULL) {
        return ; // 空结点，递归直接返回
    }
    InOrderCalWPL(T->left,h+1,wpl); //递归遍历左子树，下层深度+1
    if(T->left == NULL && T->right == NULL) {
        *wpl += T->weight * h; // 计算叶结点的带权路径长度
    }
    InOrderCalWPL(T->right, h+1, wpl); //递归遍历右子树，下层深度+1
}

int GetTreeWPL(BiTree root) { //函数调用入口，输入根指针，返回树的WPL
    int wpl = 0; // 初始化wpl为0
    InOrderCalWPL(root,0,&wpl); // 根结点初始深度为0
    return wpl;
}
```

**【注意】** 在子函数 `InOrderCalWPL()` 中，形参 wpl 必须定义成指针，否则就是错的。或者通过引用传参也行。考生若不熟悉 C 语言函数的形参和实参，或者 C++ 中的引用，建议去看下竞成《数据结构考研复习全书》第 1 章【编程基础】部分（在该章 1.5 小节），该章对 408 考试中所需要的前置的编程基础知识进行了补充介绍，助力考生 0 基础入门 408。

<Question id="408-2014-44" type="essay" points={12} tags="来源:2014考研408, 科目:计算机组成原理, 考点:指令系统, 考点:指令流水线">

| 编号 | 地址 | 机器代码 | 汇编代码 | 注释 |

(2) 已知 sll 指令实现左移功能，数组 A 中每个元素占多少位？

(3) 表中 bne 指令的 OFFSET 字段的值是多少？已知 bne 指令采用相对寻址方式，当前 PC 内容为 bne 指令地址，通过分析表中指令地址和 bne 指令内容，推断出 bne 指令的转移目标地址计算公式。

**【解析】**

(1) M 的存储器编址单位是字节。理由：题目规定指令是 32 位定长，即：单条指令占 4 字节。观察表中 6 条指令的地址，相邻指令的地址相差 4（例如：08048104H − 08048100H = 4），说明 1 个地址编号对应 4B ÷ 4 = 1B 存储空间，所以编址单位为字节。

(2) 数组 A 中每个元素占 4B。理由：指令 1 为“`sll R4,R2,2`”，其功能是把循环变量 i（在 R2 中）逻辑左移 2 位（等价于 $i\times4$），将结果存在 R4 中。

指令 2 为“`add R4,R4,R3`”，其功能是把 $i\times4$ 后的结果（在 R4 中）加上数组 A 的首地址（即 A[0]，在 R3 中），即：`A[i]=A[0]+i*4`，将 A[i] 的地址存在 R4 中。

按字节编址，每个数组元素地址对应的偏移量 = $i\times4$，说明每个数组元素占 4 字节 = 32 位。

(3) ① 题目给出的 bne 指令的机器代码为 1446 FFFAH，bne 指令格式为：

| 31～26 | 25～21 | 20～16 | 15～0 |
| --- | --- | --- | --- |
| OP | Rs | Rd | OFFSET |

由 bne 指令格式可知，低 16 位是 OFFSET 的值，所以 OFFSET = FFFAH（补码）= −6。

② 转移目标地址 = $(\mathrm{PC})+4+\mathrm{OFFSET}\times4$。理由：CPU 取 bne 指令时 PC 为指令自身地址，每条指令是 4B，取指结束 PC + 4 指向下一条指令地址；OFFSET 以指令条数为偏移单位，单条指令占 4B，因此偏移量为 $\mathrm{OFFSET}\times4$。

**【提示】** 转移目标地址计算公式推导过程如下：题目给出的表中，编号为 6 这一行对应 bne 指令。① bne 指令地址为 08048114H，按字节编址，指令长度 = 4B，所以 PC 取指后自增 4 指向下一条指令地址。PC + 4 = 08048118H。② bne 采用相对寻址，且目标地址为 `loop(08048100H)`。08048100H − 08048118H = −18H = −24。由于 OFFSET = −6，$-24=(-6)\times4$，说明 OFFSET 是按 4B 偏移的。所以转移目标地址 = $(\mathrm{PC}+4)+\mathrm{OFFSET}\times4$。

<Question id="408-2014-45" type="essay" points={11} tags="来源:2014考研408, 科目:计算机组成原理, 考点:Cache, 考点:虚拟存储器">

假设对于 44 题中的计算机 M 和程序 P 的机器代码，M 采用页式虚拟存储管理；P 开始执行时，(R1) = (R2) = 0，(R6) = 1000，其机器代码已调入主存但不在 Cache 中；数组 A 未调入主存，且所有数组元素在同一页，并存储在磁盘同一个扇区。请回答下列问题并说明理由。

(1) P 执行结束时，R2 的内容是多少？

(2) M 的指令 Cache 和数据 Cache 分离。若指令 Cache 共有 16 行，Cache 和主存交换的块大小为 32 字节，则其数据区的容量是多少？若仅考虑程序段 P 的执行，则指令 Cache 的命中率为多少？

(3) P 在执行过程中，哪条指令的执行可能发生溢出异常？哪条指令的执行可能产生缺页异常？对于数组 A 的访问，需要读磁盘和 TLB 至少各多少次？

<Solution>

**【解析】**

(1) 常量 N 保存在寄存器 R6 中，故 N = (R6) = 1000。当程序 P 执行结束时，跳出 for 循环，此时 i = N = (R6) = 1000。变量 i 保存在寄存器 R2 中，故 R2 的内容是 1000。

(2) ① 由于 Cache 有 16 行，每行的大小为 32B，所以 Cache 数据区容量 = 16 × 32B = 512B。② 由于程序 P 有 6 条指令，总共占 $6\times4\mathrm{B}=24\mathrm{B}<32\mathrm{B}$，所以 P 的所有指令都在同一块主存块中。在 1000 次循环中，每次循环读取 6 条指令。在第一次循环读取第一条指令时，由于程序 P 所在的主存块还没有调入 Cache 中，发生 Cache 缺失，操作系统将程序 P 所在主存块调入 Cache 块中，此后每次读取指令时 Cache 都能命中。Cache 命中率 $=\frac{1000\times6-1}{1000\times6}\approx99.98\%$。

{/* 原书将 Cache 缺失时的主存块调入称为“操作系统”操作；后续提示明确 Cache 缺失由硬件自动处理，保留原文。 */}

(3) ① 编号为 4 的指令执行“`sum += A[i]`”操作，可能会因为 sum 的值过大而发生溢出异常。

② 编号为 3 的指令是访存指令，可能会发生缺页异常。

③ 第一次访问数组 A 时，会先查一次 TLB，由于数组 A 初始未调入主存，所以发生缺页，要从磁盘上读取数组 A，因为数组 A 存储在磁盘的同一扇区中，只需要读 1 次磁盘。

④ 当缺页异常处理完后，CPU 会重新执行触发异常的指令，会查一次 TLB。此后访问 A[1]～A[999] 时，每访问一个数组元素会查一次 TLB，访问 TLB 的总次数 = 1 + 1 + 999 = 1001。

**【提示】** ★ ① 缺页异常处理完后，重新执行被中断的指令，所以必须“再查一次 TLB”。

② Cache 缺失（不命中）处理完后，不需要再访问一次 Cache。因为 Cache 缺失是纯硬件自动处理，此过程对 CPU 来说是透明的（即：CPU 感知不到 Cache 缺失的处理过程）。Cache 缺失的完整处理过程是：CPU 发出一个物理地址 → Cache 缺失 → 硬件读取主存块送入 Cache → 数据交给 CPU（从主存中取或从 Cache 中取）→ 指令继续执行。

③ Cache 缺失后，现代主流通用 CPU 都是将缺失的主存块写入 Cache 的同时，将所需数据送往 CPU。在早期 CPU 设计中，查 Cache 标记发现 Cache 缺失后，先读取主存数据块写入 Cache 块，再从 Cache 块中读取所需数据送往 CPU，这个过程（先查 Cache 标记 → 写入 Cache 块 → 从 Cache 块中取数据送 CPU）属于 Cache 的内部读写，不改变外部访问 Cache 的计数，所以这个过程属于“一次访问 Cache”，不是两次访问 Cache，这点很容易混淆。

**【点评】** 常规题。本题属于计组大题最简单的一类考法之一。

</Solution>

<Question id="408-2014-46" type="essay" points={7} tags="来源:2014考研408, 科目:操作系统, 考点:文件的物理实现">

文件 F 由 200 条记录组成，记录从 1 开始编号。用户打开文件后，欲将内存中的一条记录插入文件 F 中，作为其第 30 条记录。请回答下列问题，并说明理由。

(1) 若文件系统采用连续分配方式，每个磁盘块存放一条记录，文件 F 存储区域前后均有足够的空闲磁盘空间，则完成上述插入操作最少需要访问多少次磁盘块？F 的文件控制块内容会发生哪些改变？

(2) 若文件系统采用链接分配方式，每个磁盘块存放一条记录和一个链接指针，则完成上述插入操作需要访问多少次磁盘块？若每个存储块大小为 1KB，其中 4 字节存放链接指针，则该文件系统支持的文件最大长度是多少？

<Solution>

**【解析】**

(1) 文件采用连续分配，原有 200 条记录占用 200 个连续的磁盘块。要插入作为第 30 条记录，意味着新记录要占据第 30 个逻辑位置，有如下 2 种插入方法：

- 向前扩展：将第 1～29 条（共 29 条）记录各向前移动一个磁盘块，每条记录需要读写各访盘一次，再写入新记录访盘一次，至少访盘 29 + 29 + 1 = 59 次。
- 向后扩展：将第 30～200 条（共 171 条）记录各后移动一个磁盘块，每条记录需要读写各访盘一次，再写入新记录访盘一次，至少访盘 171 + 171 + 1 = 343 次。

① 题目已说明“文件存储区域前后均有足够空闲磁盘空间”，求访问磁盘的最少次数。所以选择向前扩展，访问磁盘 59 次。

② 文件的起始地址（块号）和文件长度会发生改变。具体变化是：文件的起始地址减小一个磁盘块大小，文件长度增加一个磁盘块大小。

(2) ① 链接分配只能顺序访问。要插入到第 30 条位置，必须先找到第 29 个磁盘块，过程如下：

- 依次读取文件 F 的第 1～29 条记录，获取第 29 块的后继指针：此过程需要访问 29 个磁盘块。
- 申请空闲磁盘块，将新记录与第 29 块的后继指针写入该磁盘块：1 次写操作对应一次磁盘块访问。
- 修改第 29 块的链接指针为新分配的磁盘块地址：1 次写操作对应一次磁盘块访问。

此过程共访问 29 + 1 + 1 = 31 次磁盘块。

② 磁盘块的链接指针占 4B，最多可寻址 $2^{32}$ 个磁盘块。每个磁盘块大小为 1KB = 1024B，其中 4B 存放链接指针，则每个磁盘块可分配空间 = 1024 − 4 = 1020B。则该文件系统支持的文件最大长度 = $2^{32}\times1020\mathrm{B}=4080\mathrm{GB}$。

**【点评】** 难题。综合考查文件的物理实现：连续分配和链接分配。第 (2) 问求文件最大长度时，每个磁盘块的可分配空间，要去掉链接指针所占空间，这点容易出错。本题很适合作为一个典型例题理解记忆，考生可反复揣摩，加深理解。

</Solution>

</Question>

<Question id="408-2014-47" type="essay" points={8} tags="来源:2014考研408, 科目:操作系统, 考点:信号量, 考点:生产者消费者问题">

系统中有多个生产者进程和多个消费者进程，共享一个能存放 1000 件产品的环形缓冲区（初始为空）。当缓冲区未满时，生产者进程可以放入其生产的一件产品，否则等待；当缓冲区未空时，消费者进程可以从缓冲区取走一件产品，否则等待。要求一个消费者进程从缓冲区连续取出 10 件产品后，其他消费者进程才可以取产品。请使用信号量 P、V（wait()、signal()）操作实现进程间的互斥与同步，要求写出完整的过程，并说明所用信号量的含义和初值。

<Solution>

**【解析】** 本题改编自经典的生产者－消费者问题。① 定义互斥信号量 mutex_consumer，用于实现在一个消费者进程进入缓冲区，且尚未取出 10 件产品之前，其他消费者进程不可以进入缓冲区取产品；② 定义互斥信号量 mutex_buffer，用于实现对缓冲区的互斥访问；③ 定义信号量 empty 和 full，分别表示缓冲区的空位数和已存放的产品数量。伪代码描述如下：

```c
semaphore mutex_consumer = 1; //实现消费者进程之间的互斥操作
semaphore mutex_buffer = 1; //实现对缓冲区的互斥访问
semaphore empty = 1000; //缓冲区可用空位数量
semaphore full = 0; //缓冲区已存放的产品数量

生产者进程
while(1){
    生产一件产品;
    P(empty); //占用一个缓冲区，如剩余容量不足则等待
    P(mutex_buffer); //（互斥）阻止他人访问缓冲区
    把产品放入缓冲区;
    V(mutex_buffer); //（互斥）允许他人访问缓冲区
    V(full); //（同步）缓冲区的已用容量加1
}

消费者进程
while(1){
    P(mutex_consumer); //申请进入缓冲区取走10件产品
    for(int i = 0; i < 10; i++){ //用这个循环描述连续取走10件
        P(full); // 申请从缓冲区取走一件产品，若缓冲区为空则等待
        P(mutex_buffer); //（互斥）阻止他人访问缓冲区
        从缓冲区取走一件产品;
        V(mutex_buffer); //（互斥）允许他人访问缓冲区
        V(empty); //缓冲区空位+1
    }
    V(mutex_consumer); //从缓冲区连续取走10件产品后，其他消费者可取产品
}
```

**【提示】** ★ ① 上述伪代码实现中，默认生产者和消费者不能同时访问缓冲区（经典的“生产者－消费者”问题也是这样要求的）。但本题官方给出的参考答案中，默认生产者和消费者可以同时访问缓冲区。而且，本题也未明确说明：“生产者和消费者是否可以同时访问缓冲区”，所以，两种写法都可以。而且，更推荐考生我们这里的这种写法。

② 教育部每年都会公布统考科目真题的标准答案，竞成将历年官方公布的 408 评分标准答案（2009～至今），整理在竞成《408 评分标准与官方答案》这本书中，建议考生去看看。

**【点评】** 常规题。本题根据教材上常见的“生产者－消费者”问题改编，主要改编点在于加了约束条件“一个消费者进程从缓冲区连续取走 10 件产品”，考查灵活运用。根据经典例题改编，此类考查方向多、变种很多，且“死记硬背”没有用，需要考生平时多练习（提高熟练度），多见一些题型（开拓视野），多积累总结，增进理解。

</Solution>
