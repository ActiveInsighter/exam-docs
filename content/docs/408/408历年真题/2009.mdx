<Question id="408-2009-01" type="single" number={1} points={2} tags="来源:2009考研408, 科目:数据结构, 考点:队列">

为解决计算机主机与打印机之间速度不匹配问题，通常设置一个打印数据缓冲区，主机将要输出的数据依次写入该缓冲区，而打印机则依次从该缓冲区中取出数据。该缓冲区的逻辑结构应该是（ ）。

<Option>

栈

</Option>
<Option correct>

队列

</Option>
<Option>

树

</Option>
<Option>

</Option>

<Solution>

**【解析】** 数据由主机依次写入缓冲区，而打印机依次从缓冲区中取出数据，先进入的数据也会先被取出，逻辑结构可抽象为“队列”。故选 B。

已知一棵完全二叉树的第 6 层（设根为第 1 层）有 8 个叶结点，则该完全二叉树的结点个数最多是（ ）。

</Option>

</Option>
<Option correct>

</Option>
<Option>

119

</Option>

<Solution>

**【解析】** 根结点为第 1 层的完全二叉树的第 $n$ 层最多有 $2^{n-1}$ 个结点，即第 6 层最多有 $2^{6-1}=32$ 个结点。完全二叉树的叶结点只可能出现在最后两层，题目中给出第 6 层有 8 个叶结点，则第 6 层其余位置均为有两个孩子的非叶结点时，总结点数最多。第 6 层除了 8 个叶结点外，还有 24 个非叶结点，第 7 层有 48 个叶结点，此时总结点数为 $1+2+4+8+16+(8+24)+24\times2=111$ 个。故选 C。

</Option>
<Option>

<Solution>

<Question id="408-2009-12" type="single" number={12} points={2} tags="来源:2009考研408, 科目:计算机组成原理, 考点:补码与符号扩展">

一个 C 语言程序在一台 32 位机器上运行。程序中定义了三个变量 $x$、$y$ 和 $z$，其中 $x$ 和 $z$ 为 int 型，$y$ 为 short 型。当 $x=127$，$y=-9$ 时，执行赋值语句 $z=x+y$ 后，$x$、$y$ 和 $z$ 的值分别是（ ）。

<Option>

$x=0000007\mathrm{FH}$，$y=\mathrm{FFF9H}$，$z=00000076\mathrm{H}$

</Option>
<Option>

$x=0000007\mathrm{FH}$，$y=\mathrm{FFF9H}$，$z=\mathrm{FFFF0076H}$

</Option>
<Option>

$x=0000007\mathrm{FH}$，$y=\mathrm{FFF7H}$，$z=\mathrm{FFFF0076H}$

</Option>
<Option correct>

$x=0000007\mathrm{FH}$，$y=\mathrm{FFF7H}$，$z=00000076\mathrm{H}$

</Option>

<Solution>

**【解析】** $x$ 为 int 型，用 32 位补码表示，机器数为 0000 007FH；$y$ 为 short 型，用 16 位补码表示，机器数为 FFF7H。执行 $z=x+y$ 时，因为 $x$ 与 $y$ 的数据类型不同，需通过符号位扩展将 $y$ 的 short 类型强制转换为 int 型。符号扩展规则为“高位直接补符号位”。$y$ 为负数，所以在 $y$ 的高位填充 1（高共补充 16 个 1），即可将 $y$ 转换为 int 型，其机器数为 FFFF FFF7H。再执行加法 0000 007FH + FFFF FFF7H = 0000 0076H，得到 $z$ 的机器数。

**【提示】** 408 考试时间为 3 小时，包含 40 道选择题、7 道大题，平均一道选择题最好只花 2～3 分钟。本题的快速解题小技巧为：C 语言中数据用补码表示，$y$ 的补码为 FFF7H，故排除 A、B。又因为 $z=127-9>0$ 为正数，排除 C（符号位 0 正 1 负），故选 D。

**【点评】** 常规题。本题考查 C 语言数据类型转换、符号扩展、原码转换为补码。考生应留意此题快速解题的小技巧，节省考场答题时间。

</Solution>

</Question>

<Question id="408-2009-13" type="single" number={13} points={2} tags="来源:2009考研408, 科目:计算机组成原理, 考点:浮点数加减运算">

浮点数加、减运算过程一般包括对阶、尾数运算、规格化、舍入和判溢出等步骤。设浮点数的阶码和尾数均采用补码表示，且位数分别为 5 位和 7 位（均含 2 位符号位）。若有两个数 $X=2^7\times29/32$，$Y=2^5\times5/8$，则用浮点加法计算 $X+Y$ 的最终结果是（ ）。

<Option>

00111 1100010

</Option>
<Option>

00111 0100010

</Option>
<Option>

01000 0010001

</Option>
<Option correct>

发生溢出

</Option>

<Solution>

**【解析】**

① 第一步：规格化。将 $X$、$Y$ 表示为规格化浮点数。$X=2^7\times29/32=29\times2^2$，29 = 11101B，$X$ 规格化形式的表示为 $00.11101\times2^7$。$X$ 的规格化尾数 = 00.11101（高 2 位为符号位）、阶码 = 7 = 00111B（高 2 位为符号位）。$Y=2^5\times5/8=5\times2^2$，5 = 101B，$Y$ 规格化形式的表示为 $00.101\times2^5=00.10100\times2^5$（末尾补 0 不影响大小）。$Y$ 的规格化尾数 = 00.10100（高 2 位为符号位）、阶码 = 5 = 00101B（高 2 位为符号位）。

② 第二步：对阶，小阶向大阶对齐。将 $Y$ 的尾数右移 2 位，使得阶码变为 7。$Y=00.10100\times2^5=00.00101\times2^7$。

③ 第三步：尾数相加。$00.11101+00.00101=01.00010$。尾数相加结果符号位为 01，故右规。

④ 第四步：结果规格化。将尾数右移 1 位，阶码加 1，尾数为 00.10001，阶码为 7 + 1 = 8 = 01000B。阶码加 1 变成 8 之后，其实已经可以判断溢出，超出 3 位阶码（除去 2 位符号位后）的最大表示范围了。

⑤ 第五步：舍入处理。本题中无需舍入。

⑥ 第六步：溢出判断和处理。阶码符号位为 01，说明发生溢出。

**【提示】**

① 快速解题技巧：由阶码 5 位、尾数 7 位（均含 2 位符号位）可知，该浮点数可表示的最大数的尾数均为 1（00.11111），阶码均为 1（00 111），对应真值为 $31\times2^7\div2^5=31\times2^2$。直接通过十进制计算 $X+Y=29\times2^2+5\times2^2=34\times2^2>31\times2^2$，超过最大表示范围，显然溢出，故选 D。

② 原码和补码规格化尾数形式是不一样的，相关总结如下表所示。原码的符号位和数值位完全分开，而补码的符号位和数值位是一体的。

| 编码方式 | 规格化形式 | 正数形式 | 负数形式 |
| --- | --- | --- | --- |
| 原码 | 小数点后第一位必须为 1 | 0.1xxxx | 1.1xxxx |
| 补码 | 符号位与最高数值位必须不同 | 0.1xxxx | 1.0xxxx |
| 补码（双符号位） | 双符号位与最高数值位必须不同 | 00.1xxxx | 11.0xxxx |

**【点评】** 常规题。本题考查浮点数加减运算，只要掌握了浮点数加减运算的流程，难度其实不大。可能部分同学放弃了对该考点的学习，从而无从下手。

</Solution>

<Question id="408-2009-14" type="single" number={14} points={2} tags="来源:2009考研408, 科目:计算机组成原理, 考点:组相联映射">

某计算机的 Cache 共有 16 块，采用 2 路组相联映射方式（每组 2 块）。每个主存块大小为 32B，按字节编址。主存 129 号单元所在主存块应装入到的 Cache 组号是（ ）。

<Option>

0

</Option>
<Option>

1

</Option>
<Option correct>

4

</Option>
<Option>

6

</Option>

<Solution>

**【解析】**

**【解法一】** Cache 一共 16 行，采取二路组相联，所以有 $16\div2=8$ 组。Cache 块大小为 32B，按字节编址，物理地址（二进制）的低 $\log_2 32=5$ 位为块内地址、其高的 $\log_2 8=3$ 位为组号。129 = 100 00001B，可知组号为 100B = 4。故选 C。

**【解法二】** 主存按字节编址，每个主存块大小为 32B，主存单元对应的主存块号 = 主存单元地址 ÷ 块大小。从 0 开始编号，129 号主存单元对应的主存块号 = $\lfloor 129\mathrm{B}\div32\mathrm{B}\rfloor=4$。根据组相联主存块号和 Cache 组号的映射公式：Cache 组号 = 主存块号 % Cache 组数 = 4 % 8 = 4，可得 129 号主存单元对应的 Cache 组号为 4。

**【点评】** 常规题。本题考查组相联映射的地址结构。计算地址结构是基本功，需要熟练掌握。本题解法二，容易因为混清主存单元和主存块号之间的关系而出错（也容易忽略主存块默认从 0 开始编号）。

</Solution>

(1) 算法思想：定义两个指针 $p$ 和 $q$，初始均指向头结点的下一个结点。当 $p$ 指针移动到链表第 $k$ 个结点时，$p$ 和 $q$ 指针开始同步移动。当 $p$ 指针遍历到链表最后一个结点时，$q$ 指针正好指向链表的倒数第 $k$ 个结点。

(2) 算法步骤如下：

- (a) 初始化 `p = list->next, q = list->next, count = 0;`
- (b) `p = p->next, count++`，若 `p->next` 为空，跳转至 (f)；
- (c) 如果 `count < k`，跳转 (b)，否则跳转 (d)；
- (d) `p = p->next, q = q->next;`
- (e) 如果 $p$ 为空，则跳转 (f)，否则跳转 (d)；
- (f) 如果 `count == k`，输出 `q->data`，返回 1，否则返回 0。

(3) 代码实现如下：

```cpp

    ElemType data;
    LinkNode *link;
} LinkNode, *LinkList;
int findK(LinkList L, int k) {
    LinkNode *p = L->link, *q = L->link;
    int count = 0;
    for (; p != NULL; p = p->link) {
        if (count < k) {count++;}
        else {q = q->link;}
    }
    if (count < k) return 0;
    else {
        printf("%d", q->data);
        return 1;
    }
}
```

**【参考答案一】**

| 时钟 | 功能 | 有效控制信号 |
| --- | --- | --- |
| C5 | MAR←(R1) | R1out, MARin |
| C6 | MDR←M(MAR) | MemR, MDRinE |
| C7 | A←(MDR) | MDRout, Ain |
| C8 | AC←(A)+(R0) | R0out, ADD, ACin |

**【参考答案二】**

| 时钟 | 功能 | 有效控制信号 |
| --- | --- | --- |
| C5 | MAR←(R1) | R1out, MARin |
| C6 | MDR←M(MAR), A←(R0) | MemR, MDRinE, Ain, R0out |
| C7 | AC←(A)+(MDR) | MDRout, Add, ACin |
| C8 | MDR←(AC) | ACout, MDRin |
| C9 | M(MAR)←(MDR) | MDRoutE, MemW |

时钟周期 C1～C4 是取指阶段，主要工作是：根据寄存器 PC 中地址，从主存中读取数据（指令），经过 MDR 送至指令寄存器 IR。

- `C1: MAR←(PC)`。指令地址在 PC 中，将 PC 中指令地址送往地址寄存器 MAR。
- `C2: MDR←M(MAR), PC←(PC)+1`。在这一个时钟周期，同时完成了两项工作：① 根据 MAR 中的地址，从主存中读取数据送往 MDA；② PC 自增，指向下一条指令地址。
- `C3: IR←(MDR)`。此时指令已经暂存在 MDR 中，将其送往 IR。

时钟周期 C4 是指令译码阶段，主要工作是：对当前取出的指令进行分析、解码，识别出指令的操作类型、寻址方式、操作数来源／去向，为后续执行阶段生成对应的控制信号，控制 CPU 完成指令要求的操作。加法指令 `ADD (R1),R0` 的第一个操作数，保存在 R1 的内容（地址）所指主存单元中；第二个操作数保存在寄存器 R0 中；两个操作数相加，结果保存在 R1 的内容（地址）所指主存单元中。

- `C5: MAR←(R1)`。((R1)) 是寄存器间接寻址，需要从 R1 中读取目的地址送入 MAR 中。
- `C6: MDR←M(MAR)`。根据 MAR 中的地址，取出操作数送入 MDR 中。这一步完成后，加法运算所需要的两个操作数，存在寄存器 MDR 和 R0 中。这道题答案有多种，将 MDR 中的内容送入暂存寄存器 A，或 R0 中的内容送入暂存寄存器 A，都可以。在节拍安排上，如【参考答案一】所示，若执行 `MDR←M(MAR)` 时，同时将 R0 中的内容送入暂存寄存器 A（`A←(R0)`），并不会发生总线冲突。
- `C7: A←(MDR)`。将 MDR 中的内容送入暂存寄存器 A。
- `C8: AC←(A)+(R0)`。将两个操作数同时送至 ALU 进行加法操作，将运算结果送入累加寄存器 AC 中。
- `C9: MDR←(AC)`。将运算结果从累加寄存器 AC 中送入 MDR。
- `C10: M(MAR)←(MDR)`。将计算结果送至 MAR 内容（其实是 R1）所指的内存单元。

```c

semaphore even = 0;//定义偶数取用的同步信号量

semaphore num_mutex = 1;//定义对临界区访问的互斥信号量

    P1(){
        while(1){
            x = produce(); //生成一个正整数
            P(num_empty); //（同步）申请一个空余位置，empty自减

                V(odd); //（同步）如果是奇数，odd自增，以便等待中的P2使用

        while(1){
            P(odd);//（同步）P1产生奇数后，P2才可取用

        }
    }
}CoEnd
```
