<Question id="408-2021-01" type="single" number={1} points={2} tags="来源:2021考研408, 科目:数据结构, 考点:单循环链表">

已知头指针 `h` 指向一个带头结点的非空单循环链表，结点结构为 `data | next`，其中 `next` 是指向直接后继结点的指针，`p` 是尾指针，`q` 是临时指针。现要删除该链表的第一个元素，正确的语句序列是（ ）。

<Option>

`h->next = h->next->next; q = h->next; free(q);`

</Option>

<Option>

`q = h->next; h->next = h->next->next; free(q);`

</Option>

<Option>

`q = h->next; h->next = q->next; if(p != q) p = h; free(q);`

</Option>

<Option correct>

`q = h->next; h->next = q->next; if(p == q) p = h; free(q);`

</Option>

<Solution>

**【解析】** 本题要考虑的特殊情况是：“当链表中只有一个元素时，即要删除的是尾指针 p 指向的结点时”，画图模拟此场景下链表删除，如右图所示：

![链表删除示意图](/img/2021-a01.svg)

在这种情况下，肯定涉及处理尾指针 p，可快速排除 A 和 B。观察选项 C 和 D，唯一的不同就是判断 p 和 q 的关系：这两个选项中 q 都指向了链表的第一个元素（待删除结点），而 p 是尾指针。在上述情况下：① 当 p 和 q 不相等时，说明链表中元素不止一个，删除第一个元素不影响尾指针 p，故 C 错误；② 当 p 和 q 相等时（尾指针指向第一个元素），说明链表中只有一个元素，将其删除后就只剩下头结点，所以要将尾指针指向头结点，故 D 正确。

**【点评】** 常规题。链表删除是常见基础的考点，本题为了增加难度，增加了“非空单循环”这些限制条件。“非空”则要考虑删除前，除头结点外链表只有一个元素的特殊情况。另外，需要留意的是，如本题所示，通常默认头结点仅作为链表的入口，不属于链表中的元素。

</Solution>

</Question>

<Question id="408-2021-03" type="single" number={3} points={2} tags="来源:2021考研408, 科目:数据结构, 考点:二维数组">

已知二维数组 $A$ 按行优先方式存储，每个元素占用 1 个存储单元。若元素 `A[0][0]` 的存储地址是 100，`A[3][3]` 的存储地址是 220，则元素 `A[5][5]` 的存储地址是（ ）。

<Option>

295

</Option>

<Option correct>

300

</Option>

<Option>

301

</Option>

<Option>

306

</Option>

<Solution>

**【解析】** ① **【解法一】** `A[3][3]` 的存储地址为 220，则 `A[3][0]` 的存储地址为 $220-3=217$。而 `A[0][0]` 的存储地址为 100，从 `A[0][0]` 到 `A[3][0]` 有三行元素，所以一行有 $(217-100)\div3=39$ 个元素。则 `A[5][0]` 的存储地址为 $100+5\times39=295$。`A[5][0]` 和 `A[5][5]` 之间相隔 5 个元素，故 `A[5][5]` 的存储地址为 $295+5=300$。

② **【解法二】** `A[0][0]`、`A[1][1]`、`A[2][2]`、`A[3][3]`、`A[4][4]`、`A[5][5]` 的存储地址为等差数列（因为每个元素之间相隔的元素个数相同），`A[0][0]` 存储地址为 100，`A[3][3]` 存储地址为 220，求得公差为 40，故 `A[5][5]` 的存储地址为 $220+40\times2=300$。

**【点评】** 常规题。为了避免计算出错，这类题可先在草稿纸上，举个例子类比下。

</Solution>

</Question>

<Question id="408-2021-08" type="single" number={8} points={2} tags="来源:2021考研408, 科目:数据结构, 考点:Dijkstra 算法">

使用 Dijkstra 算法求下图中从顶点 1 到其余各顶点的最短路径，将当前找到的从顶点 1 到顶点 2, 3, 4, 5 的最短路径长度保存在数组 dist 中，求出第二条最短路径后，dist 中的内容更新为（ ）。

![题08图](/img/2021-q08.svg)

<Option>

26, 3, 14, 6

</Option>

<Option>

25, 3, 14, 6

</Option>

<Option correct>

21, 3, 14, 6

</Option>

<Option>

15, 3, 14, 6

</Option>

<Solution>

**【解析】** 集合 $S$：指当前最短路径上的顶点集合，初始化为起始顶点，$S=\{1\}$。根据 Dijkstra 算法的计算步骤：

① 从顶点 1 到图中其余各个顶点若有边，则将 dist 初始化为相关边的边权：顶点 1 到顶点 2（$1\to2$）的距离为 26，顶点 1 到顶点 3（$1\to3$）的距离为 3，顶点 1 到顶点 4（$1\to4$）的距离为 $\infty$，顶点 1 到顶点 5（$1\to5$）的距离为 6，得到 dist 的初始值为 $\mathrm{dist}=\{26,3,\infty,6\}$。选择此时 dist 中、未加入集合 $S$ 且最小值 3 对应的顶点 3 加入集合 $S$，$S=\{1,3\}$。

② 经过顶点 3 的中转后，若从顶点 1 到达其他未在集合 $S$ 中的顶点的距离比 dist 中记录的更小，则更新 dist 中对应的值，否则保持不变。由图可知，顶点 1 经过顶点 3 到达顶点 2（$1\to3\to2$）的距离为 $3+22=25<26$，比 dist 里记录的 26 更小，则更新 $\mathrm{dist}=\{25,3,\infty,6\}$。此时 dist 中、未加入集合 $S$ 且最小值 6 对应的顶点为 5，将顶点 5 加入集合 $S$，$S=\{1,3,5\}$。

③ 由图可知，顶点 1 经过顶点 5 到达顶点 4（$1\to5\to4$）的距离为 $6+8=14<\infty$，顶点 1 经过顶点 5 到达顶点 2（$1\to5\to2$）的距离为 $6+15=21<25$，均小于 dist 里记录的值，则更新 $\mathrm{dist}=\{21,3,14,6\}$。故选 C。

**【点评】** 常规题。考查 Dijkstra 算法的执行过程。Dijkstra 算法每次确定一条到达某个顶点的最短路径。本题的难点可能在于有些同学不清楚“求出第二条最短路径后”这句话的含义。

</Solution>

</Question>

在一棵高度为 3 的 3 阶 B 树中，根为第 1 层，若第 2 层中有 4 个关键字，则该树的结点个数最多是（ ）。

<Option correct>

11

</Option>

<Option>

10

</Option>

<Option>

9

</Option>

<Option>

8

</Option>

<Solution>

**【解析】** $m$ 阶 B 树中，每个非根结点的关键字个数 $x$ 的取值范围为 $\lceil m/2\rceil-1\le x\le m-1$。令 $m=3$，则 $1\le x\le2$。B 树中每个结点的孩子数等于该结点关键字的个数加 1。对于本题，要想使得 B 树中总结点个数最多，则每个结点的分支尽可能多。根结点最多有 3 个孩子，则第 2 层最多有 3 个结点。第 2 层有 4 个关键字，则第 2 层其中一个结点有 2 个关键字（3 个孩子），另外 2 个结点各有 1 个关键字（2 个孩子）。则第 3 层共有 $3+2+2=7$ 个结点。则该 B 树最多有 $1+3+7=11$ 个结点。故选 A。

**【提示】** 本题中，根结点的孩子结点个数的取值范围只能是 1、2 或 3。上面已经分析了根结点有 3 个孩子的情况，选择题为了稳妥起见，考生可自行按照上述方法分析：根结点有 1 个孩子（不满足题目要求）或 2 个孩子（共 $1+2+6=9$ 个结点）的情况。

**【解析】** $x=\text{FFFDH}=\text{1111 1111 1111 1101B}$，$y=\text{FFDFH}=\text{1111 1111 1101 1111B}$，$z=\text{7FFCH}=\text{0111 1111 1111 1100B}$。① 若 $x$、$y$ 和 $z$ 均为无符号整数，则 $x>y>z$，故 A 和 B 错误。② 若 $x$、$y$ 和 $z$ 均为带符号整数，补码的最高位是符号位，0 表示正数，1 表示负数，所以 $x$ 和 $y$ 为负数，$z$ 为正数，可得 $z>x$，$z>y$。对于负数，补码转换为原码和原码转换为补码的方法均为“符号位不变，数值位取反再加一”。$x$ 的原码为 1000 0000 0000 0011B，则 $x=-3$；$y$ 的原码为 1000 0000 0010 0001B，则 $y=-33$。所以 $x>y$，可得 $y<x<z$。故选 D。

**【点评】** 常规题。整数的表示和运算，补码、原码、有符号和无符号都考到了，涉及的内容都是 408 必须掌握的，有一定综合性。

```c
typedef struct {             //图的定义
    int numVertices,numEdges; //图中实际的顶点数和边数
    char VerticesList[MAXV];  //顶点表。MAXV为已定义常量
    int Edge[MAXV][MAXV];     //邻接矩阵
} MGraph;
```

请设计算法：`int IsExistEL(MGraph G)`，判断 $G$ 是否存在 EL 路径，若存在，则返回 1，否则返回 0。要求：

(1) 给出算法的基本设计思想。

(2) 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

(3) 说明你所设计算法的时间复杂度和空间复杂度。

<Solution>

**【解析】**

(1) 算法的基本设计思想：在无向图的邻接矩阵中，某行（或列）非零元素个数之和为该行对应顶点的度。遍历邻接矩阵，计算各顶点的度，并统计其中度为奇数的顶点个数 count。遍历结束后，根据题目定义，若 count 为 0 或 2（不大于 2 的偶数，0 也是偶数），则返回 1，否则返回 0。

(2) C 语言代码算法描述如下：

```c
//算法功能：遍历图的邻接矩阵，计算各顶点的度，并统计顶点的度为0或2的顶点个数。
int isExistEL(MGraph G) {
    int degree = 0; //暂存当前正在计算的顶点的度
    int count = 0; //度为奇数的顶点个数
    for (int i = 0; i < G.numVertices; i++) {
        degree = 0; // degree用于记录当前所求顶点的度
        for (int j = 0; j < G.numVertices; j++){
            if (G.Edge[i][j] != 0){ //两个顶点之间存在边
                degree += 1;
            }
        }
        if (degree % 2 == 1) //判断该顶点的度是否为奇数
            count++; //度为奇数的顶点个数加一
    }
    if (count == 0 || count == 2) // 判断度为奇数的顶点个数
        return 1;
    else
        return 0;
}
```

(3) 假定 op1 为 0010 和 0011 时，分别表示带符号整数减法和带符号整数乘法指令，则指令 01B2H 的功能是什么（参考上述指令功能说明的格式进行描述）？若 1，2，3 号通用寄存器当前内容分别为 B052H，0008H，0020H，则分别执行指令 01B2H 和 01B3H 后，3 号通用寄存器内容各是什么？各自结果是否溢出？

(4) 若采用 I 型格式的访存指令中 imm（偏移量）为带符号整数，则地址计算时应对 imm 进行零扩展还是符号扩展？

(5) 无条件转移指令可以采用上述哪种指令格式？

<Solution>

**【解析】**

(1) ① ALU 是算术逻辑单元，其在一个时钟周期内能运算的二进制位数通常与机器字长相同，所以 ALU 宽度是 16 位。② 地址线为 20 位，可表示的地址个数是 $2^{20}$，按字节编址，则一个地址存储 1B 内容，所以可寻址主存空间大小为 $2^{20}\text{B}=1\text{MB}$。③ 指令寄存器存储机器指令，其位数等于指令字长，所以指令寄存器为 16 位。④ 主存地址寄存器（MAR）存放数据地址，其位数等于地址线位数，所以主存地址寄存器为 20 位。⑤ 主存数据寄存器（MDR）存储的是数据本身，其位数等于数据线的位数，所以主存数据寄存器为 8 位。

**【提示】** 通用寄存器位数与机器字长相等。

(2) 根据操作码位数可求出可定义操作的数量。① R 型格式的指令的操作码（图中的 op1）占 4 位，因此最多可定义 $2^4=16$ 种操作。② I 型和 J 型指令操作码（图中的 op2 和 op3）都是占高 6 位（共享 6 位操作码空间），6 位操作码可定义 $2^6=64$ 种操作。但高 6 位操作码中，000000 这个编码已经被 R 型指令占用了，所以 I 型和 J 型格式总共最多可定义 $64-1=63$ 种操作。③ 图中通用寄存器 rs、rt 和 rd 都占 2 位，所以通用寄存器最多有 $2^2=4$ 个。

(3) ① 01B2H = 0000 0001 1011 0010B，前 6 位为 000000，根据题目给出的指令格式可知，这是一条 R 型指令。R 型指令末 4 位 op1 = 0010，说明是带符号整数减法。rs = 01B = 1，rt = 10B = 2，rd = 11B = 3，所以指令 01B2H 的功能是 R[3] ← R[1] − R[2]。该指令执行后，R[3] = B052H − 0008H = B04AH，结果未溢出。

(4) 因为偏移量 imm 为带符号的整数，所以地址计算时应该进行符号扩展。

**【提示】** 符号扩展（复制符号位到高位）适用于带符号整数，零扩展（高位补 0）仅适用于无符号整数。

(5) 可以采用 J 型格式的指令。将 J 型指令的低 10 位（target 字段）送至程序计数器 PC 的低 10 位，即可完成无条件转移。

<Question id="408-2021-44" type="essay" points={8} tags="来源:2021考研408, 科目:计算机组成原理, 考点:TLB, 考点:LRU替换策略">

假设计算机 M 的主存地址为 24 位，按字节编址；采用分页存储管理方式，虚拟地址为 30 位，页大小为 4KB；TLB 采用 2 路组相联方式和 LRU 替换策略，共 8 组。请回答下列问题：

(1) 虚拟地址中哪几位表示虚页号？哪几位表示页内地址？

(2) 已知访问 TLB 时虚页号高位部分用作 TLB 标记，低位部分用作 TLB 组号，M 的虚拟地址中哪几位是 TLB 标记？哪几位是 TLB 组号？

(3) 假设 TLB 初始时为空，访问的虚页号依次为 10,12,16,7,26,4,12 和 20，在此过程中，哪一个虚页号对应的 TLB 表项被替换？说明理由。

(4) 若将 M 中的虚拟地址位数增加到 32 位，则 TLB 表项的位数增加几位？

<Solution>

**【解析】**

(1) 虚拟地址格式为 `虚页号 | 页内地址（页内偏移）`。页大小为 4KB = $2^{12}$B，按字节编址，$\log_2 2^{12}=12$，所以虚拟地址的低 12 位为页内地址，虚拟地址的高 $30-12=18$ 位为虚页号。

(2) 虚页号 = `TLB 标记 | TLB 组号`。TLB 共 8 组，所以虚页号的低 $\log_2 8=3$ 位为 TLB 组号，虚页号高 $18-3=15$ 位为 TLB 标记号。虚拟地址的高 15 位为 TLB 标记，虚拟地址中 TLB 标记的随后 3 位是 TLB 组号。

(3) ① 参照 Cache 组相联映射中 Cache 组号和主存块号之间的映射关系，TLB 中组号与虚页号之间的关系为 TLB 组号 = 虚页号 % TLB 组数。虚页号 10 映射到的 TLB 组号为 10%8 = 2，依此计算，10, 12, 16, 7, 26, 4, 12, 20 映射到的 TLB 组号分别为 2, 4, 0, 7, 2, 4, 4, 4。因为 TLB 为 2 路组相联（一组存放 2 个表项），第 4 组出现的频率大于 2 次，所以只有第 4 组可能存在替换现象。② 访问的虚页号 12, 4, 12, 20 映射到第 4 组。TLB 初始为空，访问虚页号 12, 4 时将对应的表项调入第 4 组，再次访问虚页号 12 时命中。访问虚页号 12 之后，紧接着访问虚页号 20，此时 TLB 第 4 组表项对应的虚页号分别为 12, 4（已被填满）。TLB 采用 LRU（最近最少使用）替换策略，由于 12 刚被访问过，所以虚页号 4 对应的 TLB 表项被替换。

**【提示】** 求解虚页号映射到的 TLB 组号还有一种方法：将题目给出的十进制虚页号转化为二进制，例如：虚页号 10 对应的二进制为 10 = 00 0000 0000 0000 1010B，虚页号的低 3 位为 TLB 组号，则虚页号 10 映射到的 TLB 组号为 010B = 2。这种计算方式比较麻烦费时间，但可能更容易想到。

(4) 虚拟地址由虚页号和页内地址组成，虚拟地址的位数增加而其他参数不变的情况下，只会引发虚页号增加，TLB 表项对应标记 Tag 和物理页号。当虚拟地址增加到 32 位时，每个 TLB 块的 TLB 标记位增加 $32-30=2$ 位，表项位数增加 2 位。

**【点评】** 常规题。第二问的设置欠妥当，居然同一个问题考 2 遍。TLB 采用二路组相联，其解法参照 Cache 组相联方式求解。这个点如果第一次遇到，可能无从下手，但在经典教材中一般都有讲解这种方式，也有类似的练习题。

</Solution>

<Question id="408-2021-45" type="essay" points={7} tags="来源:2021考研408, 科目:操作系统, 考点:信号量, 考点:开关中断">

下表给出了整型信号量 S 的 wait() 和 signal() 操作的功能描述，以及采用开/关中断指令实现信号量操作互斥的两种方法。

**功能描述**

```c
Semaphore S;
wait(S){
  while(S<=0);
  S=S-1;
}

signal(S){
  S=S+1;
}
```

**方法 1**

```text
Semaphore S;
wait(S){
  关中断;
  while(S<=0);
  S=S-1;
  开中断;
}

signal(S){
  关中断;
  S=S+1;
  开中断;
}
```

**方法 2**

```text
Semaphore S;
wait(S){
  关中断;
  while(S<=0){
    开中断;
    关中断;
  }
  S=S-1;
  开中断;
}

signal(S){
  关中断;
  S=S+1;
  开中断;
}
```

请回答下列问题：

(1) 为什么在 wait() 和 signal() 操作中对信号量 S 的访问必须互斥执行？

(2) 分别说明方法 1 和方法 2 是否正确。若不正确，请说明理由。

(3) 用户程序能否使用开/关中断指令实现临界区互斥？为什么？

<Solution>

**【解析】**

(1) 因为信号量 S 是能被多个进程进行读写操作的共享变量，所以访问必须互斥，否则就会出现数据不一致的问题。

(2) ① 方法 1 错误 ×。在 wait() 中，若 $S\leq 0$，会导致在 while 循环陷入死循环。因为关中断后（不再响应中断），当前进程无法被中断，其他进程无法修改信号量 S 的值。

② 方法 2 正确 ✓。方法 2 改进了方法 1 中存在的问题。当信号量 $S\leq 0$ 时，在 wait() 操作的 while 循环中，不断重复依次进行开中断和关中断的操作。开中断时，其他进程执行 signal() 操作时，可以关中断增加信号量 S 的值，使得不满足 while 循环中 $S\leq 0$ 的条件，从而避免 while 语句的死循环。

(3) 不能。因为用户程序运行在用户态，而开 / 关中断指令属于特权指令（只能运行在内核态），用户程序无法使用特权指令。若用户企图调用特权指令，会触发特权指令异常，被操作系统拦截或终止。用户程序需要使用特权指令实现的功能时，必须通过系统调用向操作系统内核申请服务，由操作系统内核代其执行相关操作。

**【点评】** 常规题。考查信号量的基本概念，是送分题。且第 (3) 问是独立的，跟题目背景没关系。
