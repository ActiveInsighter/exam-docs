<Question id="408-2024-01" type="single" number={1} points={2} tags="来源:2024考研408, 科目:数据结构, 考点:单链表">

已知带头结点的非空单链表 $L$ 的头指针为 $h$，结点结构为

| data | next |
| --- | --- |

其中 next 是指向直接后继结点的指针。现有指针 p 和 q，若 p 指向 $L$ 中非首且非尾的任意一个结点，则执行语句序列 “`q = p->next; p->next = q->next; q->next = h->next; h->next = q;`” 的结果是（ ）。

<Option>

在 p 所指结点后插入 q 所指结点

</Option>

<Option>

在 q 所指结点后插入 p 所指结点

</Option>

<Option>

将 p 所指结点移动到 $L$ 的头结点之后

</Option>

<Option correct>

将 q 所指结点移动到 $L$ 的头结点之后

</Option>

<Solution>

**【解析】** “`q = p->next;`” 使 q 指向 p 的后继；“`p->next = q->next;`” 使 p 指向 q 的后继（即 p 的后继的后继）；“`q->next = h->next;`” q 指向头指针 h 的后继；“`h->next = q;`” 将头指针 h 指向 q 结点。该语句序列实现将 p 的后继结点插入到头指针 h 之后。故选 D。

**【点评】** 常规题。本题有点绕，没通常的第一题那么简单。但大部分人做出来应该没问题。

</Solution>

</Question>

<Question id="408-2024-02" type="single" number={2} points={2} tags="来源:2024考研408, 科目:数据结构, 考点:后缀表达式">

<Option correct>

$\texttt{xyzu-*v/+}$

</Option>

<Option>

$\texttt{xyzu-v/*+}$

</Option>

<Option>

$\texttt{+x/*y-zuv}$

</Option>

<Option>

$\texttt{+x*y/-zuv}$

</Option>

<Solution>

| 序号 | 扫描元素 | 操作符栈中元素 | 输出的后缀表达式 | 下一步操作 |
| --- | --- | --- | --- | --- |
| 1 | x | | | 输出 x |
| 2 | + | | x | + 入栈 |
| 3 | y | + | x | 输出 y |
| 4 | * | + | xy | * 入栈 |
| 5 | ( | `+*` | xy | (入栈 |
| 6 | z | `+*(` | xy | 输出 z |
| 7 | − | `+*(` | xyz | − 入栈 |
| 8 | u | `+*(-` | xyz | 输出 u |
| 9 | ) | `+*(-` | xyzu | 输出栈中元素，直到遇到 ( 并出栈 |

<Question id="408-2024-03" type="single" number={3} points={2} tags="来源:2024考研408, 科目:数据结构, 考点:二叉树中序遍历">

若 p，q，v 均为二叉树 $T$ 中的结点，v 有两个孩子结点，$T$ 的中序遍历序列形如：“⋯，p，v，q，⋯”，则下列叙述中，正确的是（ ）。

<Option correct>

p 没有右孩子，q 没有左孩子

</Option>

<Option>

p 没有右孩子，q 有左孩子

</Option>

<Option>

p 有右孩子，q 没有左孩子

</Option>

<Option>

p 有右孩子，q 有左孩子

</Option>

<Solution>

**【解析】** 由 v 有两个孩子结点，T 的中序遍历序列形如：“⋯，p，v，q，⋯” 可知，p 是 v 的左子树中最靠右结点，q 是 v 的右子树中最靠左结点，v 是 p 和 q 的祖先。用反证法，若 p 有右孩子，那中序遍历下 p 的下一个结点是 p 的右孩子，而已知中序遍历下 p 的下一个结点是 v，v 是 p 的祖先结点，互相矛盾，故 p 没有右孩子；同理，若 q 有左孩子，那中序遍历下 q 的前一个结点应该是 q 的左孩子，而已知中序遍历下 q 的前一个结点是 v，v 是 q 的祖先，互相矛盾，故 q 没有左孩子。故选 A。

**【点评】** 常规题。这种题都是这种解答套路。根据选项内容假设推导，用反证法求解。

</Solution>

</Question>

```c
typedef struct {                 // 图的类型定义
    int numVertices, numEdges;  // 图的顶点数和有向边数
    char VerticesList[MAXV];     // 顶点表，MAXV为已定义常量
    int Edge[MAXV][MAXV];        // 邻接矩阵
} MGraph;
```

请设计算法：`int uniquely(MGraph G)`，判定 G 是否存在唯一的拓扑序列，若是则返回 1，否则返回 0。要求如下：

（1）给出算法的基本设计思想。（4 分）

（2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。（9 分）

<Solution>

**【解析】**

（1）算法设计思想：用数组 degree 记录每个顶点的入度，用变量 count 记录入度 0 的顶点个数，变量 index 记录入度为 0 的顶点下标。首先，遍历邻接矩阵，计算每个顶点的入度，再进行 $n$（$n=$ G.numVertices）次迭代，在每次迭代中找到并从图中移除入度为 0 的顶点，并将入度为 0 的顶点的所有邻接点的入度减去 1。在每次迭代过程中，只要图中存在多个入度为 0 的顶点，则说明不存在唯一的拓扑序列，返回 0。若迭代过程中，图中始终不存在多个入度为 0（有且仅有一个）的顶点，则表示存在唯一的拓扑序列，返回 1。

（2）算法实现如下：

```c
int uniquely(MGraph G) { //判定有向图是否存在唯一的拓扑序列
    int n = G.numVertices;
    int degree[n] = {0}; // 图的各顶点入度初始化为0
    for(int i = 0; i < n; i++) { //计算每个顶点的入度
        for(int j = 0; j < n; j++) {
            if(G.Edge[i][j] != 0) //存在顶点i指向顶点j的边，则顶点j的入度加1
                degree[j]++;
        }
    }
    for(int i = 0; i < n; i++) { // 如下过程重复n次
        int count = 0, index = -1; // 每轮迭代开始，将degree和index初始化
        for(int j = 0; j < n; j++) { // 依次遍历每个顶点
            if(degree[j] == 0) { // 统计入度为0的顶点个数
                count++; // 入度为0的顶点个数加1
                index = j; // 记录入度为0的顶点下标
            }
        }
        if(count > 1 || (-1 == index))
            return 0; // 入度为0的顶点不止一个，或不存在入度为0的顶点
        degree[index] = -1; // 将入度为0的顶点标记为从图中移除
        for(int j = 0; j < n; j++) {
            if(G.Edge[index][j] != 0) { 将顶点index的邻接点j的入度减1
                degree[j]--; // 更新入度
            }
        }
    }
    return 1; // 程序执行到此，说明存在唯一的拓扑排序
}
```

<Question id="408-2024-47" type="essay" number={47} points={9} tags="来源:2024考研408, 科目:计算机网络, 考点:自治系统与路由协议">

网络空间是继陆海空天之后的“第五疆域”，网络技术是网络疆域建设与治理的基础。路由算法与协议是网络核心技术之一，对其准确认知、合理选择与应用，对于网络建设十分重要。假设现有互联网中的 4 个自治系统互连拓扑示意图如下图所示。其中，AS1 运行内部网关协议 RIP；AS3 规模较小，自治系统内任意两个主机间通信，经过路由器数量不超过 15 个；AS4 规模较大，自治系统内任意两个主机间通信，经过路由器数量可能超过 20 个。

![4 个自治系统互连拓扑示意图](/img/2024-q47-topology.svg)

请回答下列问题。

（1）若仅有 RIP 和 OSPF 内部网关协议供选择，则 AS4 应该选择哪个协议？（1 分）

（2）若 AS3 中的某主机向本自治系统内另一主机发送 1 个 IP 分组，为确保该 IP 分组能够被正常接收，则该 IP 分组的初始 TTL 值应该至少设置为多少？（1 分）

（3）假设 AS1 中的路由器同一时刻启动，启动后立即构建并交换初始距离向量，之后每隔 30s 交换一次最新的距离向量，则从交换初始距离向量时刻算起，R11～R16 路由器均获得到达网络 210.2.3.0/24 的正确路由，至少需要多长时间？均获得到达网络 210.2.4.0/24 的正确路由，至少需要多长时间？（2 分）

（4）R44 向 R13 通告到达网络 136.5.16.0/20 路由时，由 BGP 协议哪类会话完成？通过哪个 BGP 报文通告？R13 通过 BGP 协议的哪类会话将该网络可达性信息通告给 R14 和 R15？（3 分）

（5）若 R14 和 R15 均收到分别由 R11、R12、R13 通告的到达网络 136.5.16.0/20 的可达信息如下表所示。

| 目的网络 | AS 路径 | 下一跳 |
| --- | --- | --- |
| 136.5.16.0/20 | AS2、AS8、AS19 | R11 |
| 136.5.16.0/20 | AS3、AS7、AS11、AS19 | R12 |
| 136.5.16.0/20 | AS4、AS10、AS19 | R13 |

则在无策略约束情况下，R14 和 R15 更新路由表后，各自路由表中到达网络 136.5.16.0/20 路由的下一跳分别是什么（用路由器名称表示）？（2 分）

<Solution>

**【解析】**

（1）AS4 中路由器可能超过 20 个，而 RIP 限制最大距离为 15 跳，定义距离为 16 表示不可达，不适合大规模网络，因此只能选择 OSPF 协议。

（2）TTL 每经过一个路由器减一，若 TTL 值减少到 0，该分组就会被路由器丢弃。AS3 中任意两个主机间通信经过的路由器数不超过 15 个，为了确保该 IP 分组能被正常接收，因此 TTL 初值至少应该设置为 $15+1=16$。当 TTL 初值等于 16 时，即使最多经过 15 个路由器之后，TTL 最小值为 1，该分组也不会被路由器丢弃。

（3）本题求解过程可以看作无权图求单源最短路径，类似广度优先遍历。注意：“本小问题目假设 AS1 中的路由器同一时刻启动，启动后立即构建并交换初始距离向量”，意思是第 0s 时相邻路由器间开始交换距离向量，并非 30s 后才第一次交换距离向量。

① R11～R16 路由器均获得到达网络 210.2.3.0/24 的正确路由，至少需要 30s。具体过程如下：初始时就交换了一次距离向量，R14 直连网络 210.2.3.0/24，所以先更新 R14 的路由表，因此初始时 R14 将距离向量发送给相邻的 R11 和 R15（即距离为 1 的结点），30s 后 R11 和 R15 将距离向量发送给相邻的 R12，R16，R13。此时所有路由器都有了到 210.2.3.0/24 的路径。② 均获得到达网络 210.2.4.0/24 的正确路由，至少需要多 60s。具体过程如下：R16 直连网络 210.2.4.0/24，初始时 R16 将距离向量发送给相邻的 R13 和 R15，30s 后 R13 和 R15 将距离向量发送给相邻的 R12 和 R14，60s 后 R11 也得到来自相邻的 R12 和 R14 的距离向量。此时所有路由器均有了到 210.2.4.0/24 的路由。

{/* 原书“至少需要多 60s”多了一个“多”，由后面的计算可知为 60s。 */}

（4）① 由 BGP 协议外部会话 eBGP 完成（该知识点在谢希仁计算机网络第 8 版第 169～171 页中有介绍）。eBGP 是在不同自治系统的两个对等端之间的 BGP 连接，而 iBGP 是在同一个 AS 的两个对等端之间的 BGP 连接。② BGP 通过 UPDATE 报文来通告某一路由的信息，以及列出要撤销的路由。③ R13 通过 BGP 协议内部会话 iBGP 通告 R14 和 R15。

（5）由题干网络拓扑图可知，R14 到达 R11、R12、R13 分别经过 1、2、2 跳，到达网络 136.5.16.0/20 经过 R11 的自治系统较少（题目已给出）且跳数也最少，因此选择 R11。由题干网络拓扑图可知，R15 到达 R11、R12、R13 分别经过 2、2、1 跳，到达网络 136.5.16.0/20 经过 R13 的自治系统较少（题目已给出）且跳数也最少，因此选择 R13。
