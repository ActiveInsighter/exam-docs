<Question id="408-2012-01" type="single" number={1} points={2} tags="来源:2012考研408, 科目:数据结构, 考点:时间复杂度">

求整数 $n(n\geq 0)$ 阶乘的算法如下，其时间复杂度是（ ）。

```c
int fact(int n){
    if(n <= 1) return 1;
    return n * fact(n - 1);
}
```

<Option>

$O(\log_2 n)$

</Option>
<Option correct>

$O(n)$

</Option>
<Option>

$O(n\log_2 n)$

</Option>
<Option>

$O(n^2)$

</Option>

<Solution>

**【解析】** 时间复杂度是基本语句执行次数的数量级。本题基本语句是“`n*fact(n-1)`”，该语句会执行 $n-1$ 次。故时间复杂度为 $O(n)$。故选 B。

**【点评】** 常规题。考查时间复杂度的计算。

</Solution>

</Question>

<Question id="408-2012-05" type="single" number={5} points={2} tags="来源:2012考研408, 科目:数据结构, 考点:广度优先遍历">

对有 $n$ 个结点、$e$ 条边且使用邻接表存储的有向图进行广度优先遍历，其算法时间复杂度是（ ）。

<Option>

如右图所示的有向带权图，若采用迪杰斯特拉 (Dijkstra) 算法求从源点 a 到其他各顶点的最短路径，则得到的第一条最短路径的目标顶点是 b，第二条最短路径的目标顶点是 c，后续得到的其余各最短路径的目标顶点依次是（ ）。

<Question id="408-2012-08" type="single" number={8} points={2} tags="来源:2012考研408, 科目:数据结构, 考点:最小生成树">

下列关于最小生成树的叙述中，正确的是（ ）。

Ⅰ. 最小生成树的代价唯一

Ⅱ. 所有权值最小的边一定会出现在所有的最小生成树中

Ⅲ. 使用普里姆 (Prim) 算法从不同顶点开始得到的最小生成树一定相同

Ⅳ. 使用普里姆算法和克鲁斯卡尔 (Kruskal) 算法得到的最小生成树总不相同

<Option correct>

仅 Ⅰ

</Option>
<Option>

仅 Ⅱ

</Option>
<Option>

仅 Ⅰ、Ⅲ

</Option>
<Option>

仅 Ⅱ、Ⅳ

</Option>

<Solution>

**【解析】** ① 选项Ⅰ正确 ✓：最小生成树代价唯一，但最小生成树不唯一（因为可能存在权值相同的边），“最小”指代价最小。② 选项Ⅱ错误 ×：若图中所有权值最小的边构成了环（即权值最小的边有多条），则此时这些权值最小的边并不会全部出现在最小生成树中（最小生成树一定无环）。③ 选项Ⅲ错误 ×：例如，Prim 算法和 Kruskal 算法得到的最小生成树的代价相同，但由于最小生成树不唯一，且两个算法的构造步骤存在区别，因此得到的两棵树不一定完全相同，当只存在一棵最小生成树的时候，不管使用什么算法得到的最小生成树总是相同的树。④ 选项Ⅳ错误 ×：从不同顶点得到的最小生成树可能相同也可能不相同。故选 A。

**【点评】** 常规题。考查最小生成树的常见结论。

<Question id="408-2012-12" type="single" number={12} points={2} tags="来源:2012考研408, 科目:计算机组成原理, 考点:CPU性能">

假定基准程序 A 在某计算机上的运行时间为 100s，其中 90s 为 CPU 时间，其余为 I/O 时间。若 CPU 速度提高 50%，I/O 速度不变，则运行基准程序 A 所耗费的时间是（ ）。

<Option>

55s

</Option>
<Option>

60s

</Option>
<Option>

65s

</Option>
<Option correct>

70s

</Option>

<Solution>

**【解析】** ① 程序 A 原运行总时间为 100s，其中 CPU 时间 90s，I/O 时间为 $100-90=10\text{s}$。② CPU 速度提高 50%，则新的 CPU 速度是原来的 1.5 倍，完成相同 CPU 任务所需时间与速度成反比。则 CPU 提速后，运行程序 A 的 CPU 时间为 $\frac{90}{1.5}=60\text{s}$。③ I/O 速度不变，因此 I/O 时间仍为 10s。总时间为 $60+10=70\text{s}$。故选 D。

**【点评】** 常规题。本题其实是一道小学数学题。考查内容其实和 408 无关。命题人出此题时考虑不周，欠妥当。

<Question id="408-2012-13" type="single" number={13} points={2} tags="来源:2012考研408, 科目:计算机组成原理, 考点:整数类型转换">

假定编译器规定 int 和 short 类型长度分别为 32 位和 16 位，执行下列 C 语言语句：

```c
unsigned short x = 65530;
unsigned int y = x;
```

得到 y 的机器数为（ ）。

<Option>

0000 7FFAH

</Option>
<Option correct>

0000 FFFAH

</Option>
<Option>

FFFF 7FFAH

</Option>
<Option>

FFFF FFFAH

</Option>

<Solution>

**【解析】** $x=65530=65535-5=1111\ 1111\ 1111\ 1010\text{B}=\text{FFFAH}$。低精度无符号数转化为高精度无符号数时，高位全部填充 0。unsigned short 转换成 unsigned int，高位直接补充 16 个 0 即可，故 $y=\text{0000 FFFAH}$。

**【点评】** 常规题。关于低精度整数向高精度整数转换，高位填充规则补充如下：

- 对于有符号数，“高位填充符号位”：若是负数，则高位全部填充 1；若是正数，则高位全部填充 0。
- 无符号数没有符号位，可视为正数，故高位全部填充 0。

另外，65535 是一个特殊的数，考生需要了解。$65535=2^{16}-1=\text{FFFFH}$。若考场现场推导则浪费时间。

</Solution>

<Question id="408-2012-14" type="single" number={14} points={2} tags="来源:2012考研408, 科目:计算机组成原理, 考点:IEEE 754">

float 类型（即 IEEE 754 单精度浮点数格式）能表示的最大正整数是（ ）。

<Option>

$2^{126}-2^{103}$

</Option>
<Option>

$2^{127}-2^{104}$

</Option>
<Option>

$2^{127}-2^{103}$

</Option>
<Option correct>

$2^{128}-2^{104}$

</Option>

<Solution>

**【解析】** IEEE 754 标准规定的 32 位单精度浮点数格式如下图所示。

| 1 位 | 8 位 | 隐藏 | 23 位 |
| --- | --- | --- | --- |
| 符号 | 阶码 | 1. | 尾数 |

IEEE 754 单精度浮点数格式、规格化数的真值为 $(-1)^s\times 2^{(E-127)}\times 1.M$。其中 $s$、$E$ 和 $M$ 分别表示符号位、阶码和尾数的取值。要表示最大的正整数，则：

- 符号位 $s=0$ 表示正数；
- 阶码取最大值 254（因为阶码全为 1 被预留为特殊用途，表示特殊值）；
- 23 位尾数位 $M$ 全为 1（隐含了最高位 1），即 $1.M=1.\underbrace{11\cdots 1}_{23\text{个}1}=2-2^{-23}$。

最大的正整数的二进制形式为

$$
\underbrace{0}_{1\text{位符号位}}\quad\underbrace{1111\ 1110}_{8\text{位阶码}}\quad\underbrace{111\ 1111\ 1111\ 1111\ 1111\ 1111}_{23\text{位尾数}}=\text{7F7F FFFFH}

<Question id="408-2012-19" type="single" number={19} points={2} tags="来源:2012考研408, 科目:计算机组成原理, 考点:总线突发传输">

某同步总线的时钟频率为 100MHz，宽度为 32 位，地址/数据线复用，每传输一个地址或数据占用一个时钟周期。若该总线支持突发 (猝发) 传输方式，则一次“主存写”总线事务传输 128 位数据所需要的时间至少是（ ）。

<Option>

20ns

</Option>
<Option>

40ns

</Option>
<Option correct>

50ns

</Option>
<Option>

80ns

</Option>

<Solution>

**【解析】** 突发（猝发）传输是一种总线/内存优化传输模式，核心是传一次地址，连续传输多笔数据，大幅减少地址/控制信号的开销，提升总线效率。突发传输工作流程如下：

- 地址阶段（仅传 1 次）：主设备（例如：CPU）发送起始地址 + 传输长度，占用 1 个时钟周期。从设备（例如：内存）收到地址后，自动按顺序生成后续数据的地址。
- 数据阶段（连续多笔）：总线不再重复发送地址，仅连续传输数据。每笔数据仅需 1 个时钟周期，地址从设备内部自动递增。

**【提示】** 此题易错点是：地址/数据复用意味着地址和数据不能同时传输，必须分阶段占用总线，所以传地址需要一个时钟周期。容易错选 B。

**【解析】** ① 中断处理：由硬件自动响应，必须保存程序运行的完整现场，以便中断返回后能恢复原程序的执行状态。② 子程序调用：由软件主动发起，现场保存由程序员控制，仅需保存必要的寄存器，甚至可以不保存任何寄存器。

- 程序计数器（PC）：中断处理和子程序调用都需要保存 PC（返回地址），否则无法回到调用点继续执行。
- 程序状态字寄存器（PSW）：中断处理时必须由硬件（中断隐指令）自动保存 PSW，因为中断响应会改变 CPU 的状态，返回时需要恢复原状态。子程序调用不会改变 CPU 的核心状态，PSW 通常不需要保存。
- 通用数据寄存器：两者都可以由软件选择是否保存，不是必须的。
- 通用地址寄存器：和通用数据寄存器一样，属于软件可控制的现场，不是必须保存的。

PSW（程序状态字）包含了 CPU 的运行状态（例如：中断允许位、条件码、特权级等），中断响应时硬件会自动将其压栈保存，而子程序调用时不会自动保存。故选 B。

**【点评】** 难题。子程序调用的概念比较生僻，容易误选。

</Solution>

<Question id="408-2012-41" type="essay" number={41} points={10} tags="来源:2012考研408, 科目:数据结构, 考点:哈夫曼树, 考点:归并排序">

设有 6 个有序表 A、B、C、D、E、F，分别含有 10、35、40、50、60 和 200 个数据元素，各表中元素按升序排列。要求通过 5 次两两合并，将 6 个表最终合并成 1 个升序表，并在最坏情况下比较的总次数达到最小。请回答下列问题：

(1) 给出完整的合并过程，并求出最坏情况下比较的总次数。

(2) 根据你的合并过程，描述 $n(n\geq 2)$ 个不等长升序表的合并策略，并说明理由。

<Solution>

**【解析】**

(1) 合并长度分别为 $m$ 和 $n$ 的有序表，在最坏的情况下，需要比较 $m+n-1$ 次。最坏的情况对应的场景是：一个表中全部元素都比另一个表所有元素大。例如：可以用 $A=\{1,2,3\}$、$B=\{4,5,6,7\}$ 具体做验证。

{/* 原书此处对最坏情况的描述及例子有误，按原文保留。 */}

要让总比较次数最少，采用构建哈夫曼树的思路：每次合并当前元素个数最少的两个表，让元素个数少的表被合并的次数更多，减少元素个数多的表参与合并的次数，从而降低总比较次数。合并过程如下所示：

| 次数 | 合并过程 | 剩余待合并表（括号里数字指表长度） | 本次最坏比较次数 |
| --- | --- | --- | --- |
| 第 1 次 | 表 A 和表 B 合并 → 表 AB | C(40)、AB(45)、D(50)、E(60)、F(200) | $10+35-1=44$ |
| 第 2 次 | 表 C 和表 AB 合并 → 表 ABC | D(50)、E(60)、ABC(85)、F(200) | $40+45-1=84$ |
| 第 3 次 | 表 D 和表 E 合并 → 表 DE | ABC(85)、DE(110)、F(200) | $50+60-1=109$ |
| 第 4 次 | 表 ABC 和表 DE 合并 → 表 ABCDE | ABCDE(195)、F(200) | $85+110-1=194$ |
| 第 5 次 | 表 ABCDE 和表 F 合并 → 表 ABCDEF | 无 | $195+200-1=394$ |

![对应于合并过程的哈夫曼树](/img/2012-q41-solution.svg)

最坏情况下比较的总次数为：$44+84+109+194+394=825$。

(2) 对于 $n(n\geq 2)$ 个不等长有序表，应采用构建哈夫曼树的合并策略：

① 每次从当前待合并的表中，选取长度最小的两个表进行合并；

② 将合并后的新表放回待合并集合中，重复步骤①，直到只剩一个表为止。

假定采用带头结点的单链表保存单词，当两个单词有相同的后缀时，则可共享相同的后缀存储空间。例如，“loading”和“being”的存储映像如下图所示。设 str1 和 str2 分别指向两个单词所在单链表的头结点，链表结点结构为：

| data | next |
| --- | --- |

请设计一个时间上尽可能高效的算法，找出由 str1 和 str2 所指向两个链表共同后缀的起始位置（如图中字符 i 所在结点的位置 $p$）。要求：

(1) 给出算法的基本设计思想。

(2) 根据设计思想，采用 C 或 C++ 或 Java 语言描述算法，关键之处给出注释。

(3) 说明你所设计算法的时间复杂度。

![两个单词共享后缀的存储映像](/img/questions/408/data-structure-p014-01.svg)

<Solution>

**【解析】**

(1) 算法的基本设计思想：① 计算链表长度：分别遍历两个单链表，得到它们的长度 len1 和 len2。② 两个链表尾端对齐：设两个指针 p 和 q 分别指向两个链表的头结点。若 len1 > len2，则 p 先向后移动 len1 − len2 个结点；若 len2 > len1，则 q 先向后移动 len2 − len1 个结点。使得 p 和 q 两个指针到链表尾端的距离相等。③ 同步遍历找公共结点：让 p 和 q 同时向后移动，每次移动一个结点，直到 p 和 q 指向同一个结点，该结点即为共同后缀的起始位置。

(2) 代码实现如下：

```c
// 定义单链表结点结构
typedef struct LinkNode {
    char data;
    struct LinkNode *next;
} LinkNode, *LinkList;
// 求单链表的表长
int getLen(LinkList L) {
    int count = 0;
    for(LinkNode *cur = L->next; cur != NULL; cur = cur->next)
        count++;
    return count;
}
// 查找两个单链表共同后缀起始位置
LinkNode *findCommon(LinkList str1, LinkList str2) {
    int len1 = getLen(str1), len2 = getLen(str2);
    for(LinkNode *p = str1->next; len1 > len2; len1--) // 若str1更长
        p = p->next;
    for(LinkNode *q = str2->next; len1 < len2; len2--) // 若str2更长
        q = q->next;
    while(p != NULL && p != q) { // 同时向后遍历，直到遍历完或指向相同结点
        p = p->next;
        q = q->next;
    }
    return p;
}
```

{/* 原书代码中 p、q 在 for 初始化语句中声明，循环外使用存在作用域问题；按原文保留。 */}

(3) 时间复杂度为 $O(\max(\mathrm{len1},\mathrm{len2}))$。其中，len1 和 len2 分别指两个单链表长度。

假定某计算机的 CPU 主频为 80MHz，CPI 为 4，平均每条指令访存 1.5 次，主存与 Cache 之间交换的块大小为 16B，Cache 的命中率为 99%，存储器总线宽度为 32 位。请回答下列问题：

(2) 假定在 Cache 缺失的情况下访问主存时，存在 0.0005% 的缺页率，则 CPU 平均每秒产生多少次缺页异常？若页面大小为 4KB，每次缺页都需要访问磁盘，访问磁盘时 DMA 传送采用周期挪用方式，磁盘 I/O 接口的数据缓冲寄存器为 32 位，则磁盘 I/O 接口平均每秒发出的 DMA 请求次数至少是多少？

(3) CPU 和 DMA 控制器同时要求使用存储器总线时，哪个优先级更高？为什么？

(4) 为了提高性能，主存采用 4 体交叉存储模式，工作时每 1/4 个存储周期启动一个体。若每个体的存储周期为 50ns，则该主存能提供的最大带宽是多少？

<Solution>

**【解析】**

(1) ① CPU 主频指每秒有多少个时钟周期，CPI 指执行一条指令平均需要多少个时钟周期，MIPS 指每秒执行百万条指令数。CPU 每秒有 80M 个时钟周期，而执行一个指令平均要 4 个时钟周期，故 CPU 平均每秒能执行 $80\mathrm{M}\div 4=20\mathrm{M}$ 条指令，故 MIPS = 20。

② CPU 平均每秒执行 20M 条指令，平均每条指令访存 1.5 次，则 CPU 平均每秒访存 $20\mathrm{M}\times 1.5=30\mathrm{M}$ 次。每次访存先访问 Cache，Cache 命中率为 99%，则 Cache 缺失率为 $1-99\%=1\%$，则平均每秒 Cache 缺失次数为 $30\mathrm{M}\times 1\%=3\times 10^5$ 次。③ 每次 Cache 缺失时，需要从读取 16B 数据写入 Cache，则主存带宽至少为 $3\times 10^5\times 16\mathrm{B}=4.8\mathrm{MB/s}$。

(2) CPU 平均每秒产生的缺页次数为 $3\times 10^5\times 0.0005\%=1.5$ 次。

每页 DMA 请求次数 $=\dfrac{\text{页面大小}}{\text{总线宽度}}=\dfrac{4\mathrm{KB}}{32\mathrm{bit}}=1\mathrm{K}$，每秒 DMA 请求次数 = 每秒缺页次数 × 每页 DMA 请求次数 $=1.5\times 1\mathrm{K}=1.5\times 1024=1536$ 次（注意不是 1500 次，这里 $1\mathrm{K}\ne 1000$）。

(3) DMA 控制器优先级更高。原因：DMA 用于高速外设（例如：磁盘）与主存间的数据传输，若不及时响应，外设数据会丢失（例如：磁盘缓冲区溢出）；而 CPU 访问主存的请求可以等待，不会导致数据永久性丢失。

(4) 每 1/4 个存储周期启动一个体，每个存储体传输 32 位数据，则一个存储周期（50ns）内可传输 $4\times 32\mathrm{bit}=128\mathrm{bit}=16\mathrm{B}$ 数据，带宽 $=\dfrac{16\mathrm{B}}{50\mathrm{ns}}=320\mathrm{MB/s}$。

**【提示】** 需注意单位。K、M 在表示数量、速度时，$1\mathrm{K}=10^3$、$1\mathrm{M}=10^6$。K、M 在表示存储空间大小、文件大小时，$1\mathrm{K}=2^{10}$、$1\mathrm{M}=2^{20}$。

**【点评】** 概念题。① 本题综合考查计组中的基本概念，后一问要用到前一问的结论（后一问在前一问的基础上计算），很容易一步错导致步步错。② 另外，第 (2) 问“假定在 Cache 缺失的情况下访问主存时，存在 0.0005% 的缺页率”，这句话的表述很不严谨，很不妥当：缺页发生在虚实地址转换过程中，Cache 缺失发生在根据物理地址去访问主存的过程中，只可能先发生“缺页”再发生“Cache 缺失”。题目把顺序说反了，会让人感觉莫名其妙。

</Solution>

**【解析】**

(1) **【解法一】** $x=-513$，$[x]_{\text{补}}=1111\ 1101\ 1111\ 1111\mathrm{B}$。指令“`SHR R1`”表示算术右移一位。算术右移，低位移出，高位补符号位（负数补 1，正数补 0），得到 $1111\ 1110\ 1111\ 1111=\mathrm{FEFFH}$。执行指令之后 R1 的内容为 FEFFH。

**【解法二】** $x=-513$，$x/2=-257$，$[-257]_{\text{补}}=1111\ 1110\ 1111\ 1111\mathrm{H}=\mathrm{FEFFH}$。

{/* 解法二二进制补码后缀 H 为原书写法。 */}

**【拓展】** ① 整数 $x$ 算术右移 1 位，正数和负数的运算规则有所不同：

- 若 $x$ 是正整数，则和普通除法一样（向零取整），例如：$x=513$，则 $x/2=256$。
- 若 $x$ 是负整数，则向负无穷取整，例如：$x=-513$，则 $x/2=-257$（不是 −256）。

② 逻辑右移和算术右移不同：逻辑右移无论正负，右边移出丢弃，左边补 0。即：逻辑右移当成无符号数整体右移，和除法无关！算术右移，低位移出，高位补符号位（0 正 1 负）。

(2) 5 段流水线，执行第 1 条指令需要 5 个时钟周期，之后每个时钟周期都会执行完 1 条指令。连续 4 条指令进入该流水线，执行完毕需要 $5+(4-1)=8$ 个时钟周期。

**【拓展】** $m$ 段流水线稳定之后（无阻塞的理想情况下），执行 $n$ 条指令需要 $m+(n-1)$ 个时钟周期。

(3) ① I3 与 I1、I2 存在数据相关。I3 必须等 I2 将数据写入寄存器 R2 后（WB 阶段之后），再从寄存器 R2 中读取操作数，所以 I3 的 ID 段（读寄存器）被阻塞。

② I4 的 IF 段被阻塞，是因为 I3 的 ID 段被阻塞，导致 I3 的后一条指令 I4 无法取指而阻塞。

**【拓展】** ① 传统单周期 CPU，只有一个指令寄存器 IR，用于存当前指令。而流水线 CPU 中，为了实现多指令并行执行，每段流水线之间设有独立的暂存寄存器。以 5 段流水线为例，段间寄存器包括 IF/ID、ID/EX、EX/MEM、MEM/WB，这些寄存器不仅暂存指令，还会传递指令的完整上下文（操作数、控制信号、地址信息等），本质上替代了全局 IR 的作用。流水线段间寄存器完整的数据流如下（此部分内容目前教辅书中都没有，考生需重视）：

- IF 阶段：取指令并计算 PC + 4，将指令和 PC + 4 的值送入 IF/ID 寄存器；
- ID 阶段：从 IF/ID 寄存器取出指令，完成译码、读寄存器堆，生成控制信号，将源操作数、目的寄存器号、控制信号等送入 ID/EX 寄存器；
- EX 阶段：从 ID/EX 寄存器取出数据，ALU 完成运算或地址计算，将结果和控制信号送入 EX/MEM 寄存器；
- MEM 阶段：从 EX/MEM 寄存器取出数据，完成内存读写（RISC 架构只有 load / store 指令能读写内存），将访存结果或 ALU 结果送入 MEM/WB 寄存器；
- WB 阶段：从 MEM/WB 寄存器取出数据并写回寄存器堆，完成指令的最后一步。

② 例如：本题中指令 I3 因数据相关无法进入 ID 阶段，停留在 IF/ID 寄存器中不动。下一个时钟周期，在 IF 阶段若要取指令 I4，则新指令无处可存：因为 IF/ID 寄存器还被 I3 占用。

(4) $x=x*2+a$ 可以通过 1 次加法、1 次算术左移，或两次加法来实现，对应的指令序列如下。

```asm
I1   LOAD R1,[x]
I2   LOAD R2,[a]
I3   SHL R1   //或ADD R1,R1
I4   ADD R1,R2
I5   STORE R2,[x]
```

① I3 和 I1 存在数据相关：I1 的 WB 阶段写回寄存器之后，I3 的 ID 阶段才能取数。

② I4 和 I2、I3 存在数据相关：因为 I3 的 ID 阶段被阻塞，所以 I4 的 IF 阶段被阻塞（原因第 (3) 问解释过）。等到 I2 和 I3 的 WB 阶段都写回寄存器之后，I4 的 ID 阶段才能取数。

③ I5 和 I4 存在数据相关：因为 I4 的 ID 阶段被阻塞，所以 I5 的 IF 阶段被阻塞（原因第 (3) 问解释过）。I4 的 WB 阶段写回寄存器之后，I5 的 ID 阶段才能取数。

(1) ① 文件系统空间最大容量 4TB，磁盘块大小 1KB，对应磁盘块数 $=\dfrac{4\mathrm{TB}}{1\mathrm{KB}}=\dfrac{4\times 2^{40}\mathrm{B}}{2^{10}\mathrm{B}}=2^{32}$ 块。要对 $2^{32}$ 块磁盘使用二进制进行编号，块号至少占 32 位 = 4B。

- 第 0～7 字节（8B）：`<起始块号(6B), 块数(2B)>`，表示连续存储空间。

**【拓展】** ★ TCP 首部中 SYN、ACK、FIN 取值，是 408 中高频考点，这里总结如下：

① 仅在 TCP 连接建立阶段，主动发起连接（第 1 次握手）和被动响应连接（第 2 次握手）这两个报文中，SYN = 1。后续任何阶段 SYN 均为 0（第 3 次握手阶段也是）。

② 在正常 TCP 通信中，除了第一次握手时 SYN 报文中 ACK = 0，所有后续报文的 ACK = 1。

③ 仅在 TCP 主动释放连接（第 1 次挥手和第 3 次挥手）时，FIN = 1。第 2 次和第 4 次挥手，FIN = 0。通俗的说：谁主动关闭连接，谁发的报文 FIN = 1；只做确认而不主动关闭连接，FIN = 0。

④ TCP 连接释放的四次挥手过程中，ACK 位均为 1。也就是说：除了 TCP 连接建立过程中第一次握手时 ACK 位为 0，TCP 连接建立后的所有报文，ACK 位均为 1。
