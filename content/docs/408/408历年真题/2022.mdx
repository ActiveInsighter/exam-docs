<Question id="408-2022-01" type="single" number={1} points={2} tags="来源:2022考研408, 科目:数据结构, 考点:时间复杂度">

下列程序段的时间复杂度是（ ）。

```c
int sum = 0;
for (int i = 1; i < n; i *= 2)
    for (int j = 0; j < i; j++)
        sum++;
```

<Option>

$O(\log_2 n)$

</Option>

<Option correct>

$O(n)$

</Option>

<Option>

$O(n\log_2 n)$

</Option>

<Option>

$O(n^2)$

</Option>

<Solution>

**【解析】** 本题的基本语句是“sum++”，时间复杂度是基本语句执行次数的数量级。本题程序是二层循环，外层循环中 $i$ 的值是多少，内层循环中就要执行多少次运算。令 $m=\lfloor\log_2 n\rfloor$，外层循环中 $i$ 的值分别为 $1,2,4,8,\cdots,2^{m-1},2^m$，则基本语句的执行次数为 $1+2+4+8+\cdots+2^{m-1}=2^m-1\approx 2^{\log_2 n}-1$。因为 $2^{\log_2 n}-1$ 与 $2^{\log_2 n}=n$ 数量级相同，所以时间复杂度为 $O(n)$。

{/* 原书列出的外层 i 值与求和上限不完全一致，保留原文；不影响渐近复杂度。 */}

**【点评】** 易错题。本题是常见的时间复杂度计算题，命题人在此题上精心设计了一些坑，具有迷惑性：① 误认为内层循环次数的数量级是 $O(n)$，从而误选 C；② 误认为外层和内层循环次数的数量级都是 $O(n)$，从而误选 D。

</Solution>

</Question>

<Question id="408-2022-04" type="single" number={4} points={2} tags="来源:2022考研408, 科目:数据结构, 考点:三叉树高度">

若三叉树 T 中有 244 个结点（叶结点的高度为 1），则 T 的高度至少是（ ）。

<Option>

8

</Option>

<Option>

7

</Option>

<Option correct>

6

</Option>

<Option>

5

</Option>

<Solution>

**【解析】** 本题可以用二叉树类比：结点数确定的情况下，完全二叉树高度最小。三叉树也是同理，当含有 244 个结点的三叉树是完全三叉树时，高度最小。高度为 $h$ 的满三叉树的结点数 $=3^0+3^1+3^2+\cdots+3^{h-1}$。当 $h=5$ 时，$3^0+3^1+3^2+3^3+3^4=121$；当 $h=6$ 时，$3^0+3^1+3^2+3^3+3^4+3^5=121+243=364$。而 $121<244<364$，所以当 T 是高度为 6 的完全三叉树时，高度最小。故选 C。

</Solution>

<Question id="408-2022-08" type="single" number={8} points={2} tags="来源:2022考研408, 科目:数据结构, 考点:B 树删除">

在下图所示的 5 阶 B 树 T 中，删除关键字 260 之后需要进行必要的调整，得到新的 B 树 $T_1$。下列选项中，不可能是 $T_1$ 根结点中关键字序列的是（ ）。

<Option>

60, 90, 280

</Option>

<Option>

60, 90, 350

</Option>

<Option>

60, 85, 110, 350

</Option>

<Option correct>

60, 90, 110, 350

</Option>

<Solution>

① A 正确 ✓：删除 260 之后，280 进入根结点，350 进入叶结点。此时，280 的右侧叶结点的关键字序列为 $\{300、350、400、500\}$，该叶结点关键字数目为 4，满足 5 阶 B 树的性质。

<Question id="408-2022-11" type="single" number={11} points={2} tags="来源:2022考研408, 科目:数据结构, 考点:直接插入排序与快速排序">

对数据进行排序时，若采用直接插入排序而不是快速排序，则可能的原因是（ ）。

- I. 大部分元素已有序
- II. 待排序的元素数量很少
- III. 要求空间复杂度为 $O(1)$
- IV. 要求排序算法是稳定的

<Option>

仅 I、II

</Option>

<Option>

仅 III、IV

</Option>

<Option>

仅 I、II、IV

</Option>

<Option correct>

I、II、III、IV

</Option>

<Solution>

**【解析】** ① I 正确 ✓：待排序序列的初始状态会影响比较次数和移动次数。当大部分元素已有序时，使用直接插入排序，每次插入元素的时候基本仅需比较一次，并且不需要移动元素，时间复杂度为 $O(n)$；而快速排序面对这种情况时，最坏的结果为每次选取的基准元素是最大/最小元素，导致每次划分的结果可以近似为：一边的元素数目很少（甚至为空），另一边的数目接近总数；递归接近 $n$ 次，递归树高度近似 $n$，划分次数也近似 $n$，时间复杂度 $O(n^2)$，故直接插入排序的效果比快速排序好。

② II 正确 ✓：直接插入排序适用于元素较少的序列，快速排序适用于元素较多的序列。

③ III 正确 ✓：直接插入排序仅需一个数据元素大小的辅助空间，用于暂存当前轮次待插入的元素，故直接插入排序的空间复杂度为 $O(1)$。快速排序是递归的，需要一个递归栈来实现递归，递归栈的深度等于递归树的高度。最好的情况下，即快速排序的每一趟排序都将元素均匀地分割成长度相近的两个子表，此时的空间复杂度为 $O(\log_2 n)$。最坏的情况下，快速排序的每一趟的划分都有一个子表是空表，此时的空间复杂度为 $O(n)$。

④ IV 正确 ✓：直接插入排序是稳定的，快速排序不稳定。综上，选 D。

**【点评】** 常规题。考查快速排序和直接插入排序的对比。408 考试中多次考过类似题目，在教辅中也有类似的总结。考生应熟练掌握常见算法思想，会手工模拟，对应的算法代码也要会默写。

</Solution>

<Question id="408-2022-16" type="single" number={16} points={2} tags="来源:2022考研408, 科目:计算机组成原理, 考点:Cache 组相联映射">

若计算机主存地址为 32 位，按字节编址，某 Cache 的数据区容量为 32KB，主存块大小为 64B，采用 8 路组相联映射方式，该 Cache 中比较器的个数和位数分别（ ）。

<Option correct>

8，20

</Option>

<Option>

8，23

</Option>

<Option>

64，20

</Option>

<Option>

64，23

</Option>

<Solution>

**【解析】** ① 按字节编址，主存块大小 64B，可知块内地址为 $\log_2 64=6$ 位。由 Cache 数据区容量 32KB，得到 Cache 块总数为 $32\mathrm{KB}\div64\mathrm{B}=512$ 块。题目中采用 8 路组相联映射方式，因此每 8 个 Cache 块为一组，共有 $512\div8=64$ 个 Cache 组，因此组号为 $\log_2 64=6$ 位。已知主存地址为 32 位，由 Cache 的地址结构知，剩下 $32-6-6=20$ 位均为 Tag 位。

② 在组相联映射中，查找同组内的所有 Cache 块中是否有系统要找的块，为了加快查找速度（并行查找），**比较器个数等于每组的路数**。本题中一组有 8 个块（8 路），所以比较器的个数为 8 个。在访问某物理地址时，根据组号找到某一分组后，再用物理地址的高 20 位与 Cache 行的 Tag 位做比较，若两者相同，则选中此 Cache 行。**比较器的位数等于物理地址中标记（tag）字段的位数**，为 20 位。故选 A。

**【总结】** 关于 Cache 中比较器个数，总结如下：① 直接映射中，一个主存块只能映射到一个指定的 Cache 行，查找时只和这个指定的 Cache 行的 Tag 位比较即可，所以只有一个比较器；② 全相联映射中，一个主存块可以映射到 Cache 的任意一行，所以查找时要和 Cache 中的所有行都进行比较，比较器的个数等于 Cache 的行数；③ 组相联映射中，主存块映射到 Cache 指定组中的任意一行，在组内比较，比较器个数等于每组的路数。

**【点评】** 创新题。本题难点在于“Cache 中比较器个数和位数”，可能很多考生此前没见过这个名词，带有一定猜的成分。熟悉 Cache 的同学，或许能分析出来。本题其他考点都是常见考点。根据常见考点推导陌生的名词和概念，近些年 408 常考。

</Solution>

某主机的 IP 地址是 183.80.72.48，子网掩码是 255.255.192.0，则该主机所在网络的网络地址是（ ）。

<Option>

183.80.0.0

</Option>

<Option correct>

183.80.64.0

</Option>

<Option>

183.80.72.0

</Option>

<Option>

183.80.192.0

</Option>

<Solution>

**【解析】** 将主机的 IP 地址、子网掩码分别以二进制形式展开，两者的每一位分别进行“与”运算，就能求出该主机所在网络的网络地址。“与”运算是针对二进制的运算，其规则是：只有当两个二进制操作数都为 1 时，结果才为 1，否则为 0。

**【解法一】** 点分十进制 IP 地址 183.80.72.48，对应的二进制形式为 1011 0111.0101 0000.0100 1000.0011 0000；子网掩码 255.255.192.0 对应的二进制形式为 1111 1111.1111 1111.1100 0000.0000 0000。IP 地址和子网掩码“与”运算结果为 1011 0111.0101 0000.0100 0000.0000 0000（183.80.64.0）。

(5) 控制信号由 CU（控制单元）产生。标志寄存器 FR（反映运算结果状态等）和指令寄存器 IR（从题目给的图中可以看出）的输出信号连接到 CU 的输入端。

<Question id="408-2022-44" type="essay" number={44} points={8} tags="来源:2022考研408, 科目:计算机组成原理, 考点:磁盘, 考点:DMA">

假设某磁盘驱动器中有 4 个双面盘片，每个盘面有 20000 个磁道，每个磁道有 500 个扇区，每个扇区可记录 512 字节的数据，盘片转速为 7200 r/m（转/分），平均寻道时间为 5ms。请回答下列问题：

(1) 每个扇区包含数据及其地址信息，地址信息分为 3 个字段。这 3 个字段的名称各是什么？对于该磁盘，各字段至少占多少位？

(2) 一个扇区的平均访问时间约为多少？

(3) 若采用周期挪用 DMA 方式进行磁盘与主机之间的数据传送，磁盘控制器中的数据缓冲区大小为 64 位，则在一个扇区读写过程中，DMA 控制器向 CPU 发送了多少次总线请求？若 CPU 检测到 DMA 控制器的总线请求信号时也需要访问主存，则 DMA 控制器是否可以获得总线使用权？为什么？

<Solution>

**【解析】**

(1) ① 三个字段分别为：柱面号（或磁道号）、盘面号（或磁头号）、扇区号。

② 由“每个盘面有 20000 个磁道”，可知该磁盘至少有 20000 个柱面，可得柱面号（磁道号）至少为 $\lceil\log_2 20000\rceil=15$ 位；由“有 4 个双面盘片”，可知该磁盘有 $4\times2=8$ 个盘面，盘面号至少为 $\log_2 8=3$ 位；由“每个磁道都 500 个扇区”，可知扇区号至少为 $\lceil\log_2 500\rceil=9$ 位。

(2) 一个扇区的平均访问时间 = 平均寻道时间 + 平均等待（延迟）时间 + 数据传输时间。

① 题目已说明平均寻道时间为 5ms；

② 平均等待（延迟）时间一般默认为磁盘旋转半周所需的时间。由于磁盘转速为 7200 转/分，因此磁盘旋转一周的时间约为 $60\mathrm{s}/7200\approx8.33\times10^{-3}\mathrm{s}=8.33\mathrm{ms}$。可得平均等待时间 = $8.33\mathrm{ms}\div2\approx4.165\mathrm{ms}$；

③ 数据传输时间（盘片转一个扇区时间，每个磁道 500 个扇区）为 $8.33\mathrm{ms}\div500\approx0.017\mathrm{ms}$。

上述三者相加可得：一个扇区的平均访问时间约为 $5\mathrm{ms}+4.165\mathrm{ms}+0.017\mathrm{ms}\approx9.18\mathrm{ms}$。

(3) ① 在一个扇区读写过程中，每当数据缓冲区的数据充满了，DMA 控制器就要向 CPU 发送一次请求。一个扇区的大小是 512B，缓冲大小 64b = 8B，因此读写一个扇区时向 CPU 发送请求次数 = 扇区大小/缓冲大小 = $512\mathrm{B}\div8\mathrm{B}=64$ 次。

② DMA 控制器的总线使用权优先级高于 CPU，故 DMA 可以获得总线使用权。若磁盘读写的时候 DMA 失去了总线控制权，那么数据缓冲区的数据会发生丢失现象，不能在规定的时间内传输数据。

**【提示】** 周期挪用 DMA 方式是指当 I/O 设备发出 DMA 请求时，会挪用或窃取一个或几个存取周期用于 DMA 接口的数据传送，传送结束后 CPU 仍可以继续访问主存。

**【点评】** 常规题。本题考的都是简单的基础概念。第一问可当作结论记忆了解。第二问在 2013 年 408 第 21 题和 2015 年 408 的第 20 题均考过，教辅书中也有介绍。第三问是常见概念。

</Solution>

| T1: | T2: |

<Question id="408-2022-47" type="essay" number={47} points={9} tags="来源:2022考研408, 科目:计算机网络, 考点:冲突域与广播域, 考点:以太网, 考点:DHCP, 考点:802.11">

某网络拓扑如下图所示，R 为路由器，S 为以太网交换机，AP 是 802.11 接入点，路由器的 E0 接口和 DHCP 服务器的 IP 地址配置如下图所示。H1 与 H2 属于同一个广播域，但不属于同一个冲突域；H2 和 H3 属于同一个冲突域；H4 和 H5 已经接入网络，并通过 DHCP 动态获取了 IP 地址。现有路由器、100BaseT 以太网交换机和 100BaseT 集线器 (Hub) 三类设备各若干台。请回答下列问题：

(1) 设备 1 和设备 2 应该分别选择哪类设备？

(2) 若信号传播速度为 $2\times10^8\mathrm{m/s}$，以太网最小帧长为 64B，信号通过设备 2 时会产生额外的 $1.51\mathrm{\mu s}$ 的时间延迟，则 H2 与 H3 之间可以相距的最远距离是多少？

(3) 在 H4 通过 DHCP 动态获取 IP 地址过程中，H4 首先发送了 DHCP 报文 M，M 是哪种 DHCP 报文？路由器 E0 接口能否收到封装 M 的以太网帧？S 向 DHCP 服务器转发的封装 M 的以太网帧的目的 MAC 地址是什么？

(4) 若 H4 向 H5 发送一个 IP 分组 P，则 H5 收到的封装 P 的 802.11 帧的地址 1、地址 2 和地址 3 分别是什么？

![网络拓扑](/img/questions/408/computer-network-3-3-q13.svg)

<Solution>

**【解析】**

(1) 由于路由器能隔离广播域和冲突域，以太网交换机只能隔离冲突域，集线器既不能隔离广播域也不能隔离冲突域。从题目所给条件来看（在题目给出的三类设备中选择），设备 1 选择 100BaseT 以太网交换机，设备 2 选择 100BaseT 集线器。

(2) 100BaseT 表示数据传输速率为 100Mb/s。传播时延 = 信号在信道上的传播时延 + 信号通过 H2 时产生的 $1.51\mathrm{\mu s}$ 延迟。设相距最远两个站点之间的距离为 $L$。争用期是相距最远两个站点之间的信号传播时延 $\tau$ 的两倍。最小帧长 = 争用期 × 数据传输速率，即 $64\mathrm{B}=2\times\tau\times100\mathrm{Mb/s}$。再将传播时延 $\tau$ 的计算公式，代入上式可得：

$$
64\times8=\left(\frac{L}{2\times10^8}+1.51\times10^{-6}\right)\times2\times100\times10^6
$$

求得最远距离 $L=210\mathrm{m}$。

{/* 原书写“信号通过 H2 时产生的延迟”，题干为“信号通过设备 2 时”产生的延迟。原文保留。 */}

(3) ① 在 H4 通过 DHCP 动态获取 IP 地址的过程中，H4 首先发送了 DISCOVER（发现）报文，所以 M 是 DISCOVER（发现）报文。② 路由器的接口 E0 与 H4 在同一个广播域，DISCOVER（发现）报文以广播形式发出，故路由器接口 E0 能收到 M。③ S 向 DHCP 服务器转发的封装 M 的以太网帧是广播帧，所以目的地址是 FF-FF-FF-FF-FF-FF。
