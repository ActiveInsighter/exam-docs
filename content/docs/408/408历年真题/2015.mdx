<Question id="408-2015-01" type="single" number={1} points={2} tags="来源:2015考研408, 科目:数据结构, 考点:栈">

已知程序如下：

```cpp
int S(int n) {
    return (n <= 0) ? 0 : S(n-1)+n;
}
void main() {
    cout << S(1);
}
```

程序运行时使用栈来保存调用过程的信息，自栈底到栈顶保存的信息依次对应的是（ ）。

<Option correct>

main() → S(1) → S(0)

</Option>
<Option>

S(0) → S(1) → main()

</Option>
<Option>

main() → S(0) → S(1)

</Option>
<Option>

S(1) → S(0) → main()

</Option>

<Solution>

**【解析】** 递归函数的调用顺序与执行顺序相反。最先执行 main() 函数，main() 函数里调用了 S(1)，S(1) 里面又递归调用了 S(0)，即 main()、S(1)、S(0) 依次进栈，故选 A。

**【点评】** 常规题。考查栈“后进先出”的特点。

</Solution>

</Question>

<Question id="408-2015-03" type="single" number={3} points={2} tags="来源:2015考研408, 科目:数据结构, 考点:哈夫曼树">

下列选项给出的是从根分别到达两个叶结点路径上的权值序列，能属于同一棵哈夫曼树的是（ ）。

<Option>

24,10,5 和 24,10,7

</Option>
<Option>

24,10,5 和 24,12,7

</Option>
<Option>

24,10,10 和 24,14,11

</Option>
<Option correct>

24,10,5 和 24,14,6

</Option>

<Solution>

**【解析】** 哈夫曼树左右孩子结点的权值之和等于父亲结点的权值。从题目给出的选项可知，这些权值对应的结点，都属于哈夫曼树的前 3 层。① $5+7=12$，所以权值为 5、7 的两个结点的父结点不是同一个结点。$10+10=20$，两个权值为 10 的结点的父结点为 20，与 24 不相等，故 A 错。② 权值为 24 的结点的两个孩子结点权值分别为 10 和 12，故 B 错。③ 分析 C 选项路径可知，权值为 10 的非叶结点的两个孩子结点权值分别为 10 和 0。权值为 14 的结点的两个孩子结点权值分别为 11 和 3。但权值最小的两个结点 0、3 却不是互为兄弟，这不符合哈夫曼树的构建规则，故 C 错。故选 D。

**【点评】** 常规题。考查哈夫曼树的构建过程。分析过程比较费时间。考生也可根据选项构建出对应的树，再判断其是否符合哈夫曼树的性质。

</Solution>

<Question id="408-2015-04" type="single" number={4} points={2} tags="来源:2015考研408, 科目:数据结构, 考点:平衡二叉树">

现有一棵无重复关键字的平衡二叉树（AVL 树），对其进行中序遍历可得到一个降序序列。下列关于该平衡二叉树的叙述中，正确的是（ ）。

<Option>

根结点的度一定为 2

</Option>
<Option>

树中最小元素一定是叶结点

</Option>
<Option>

最后插入的元素一定是叶结点

</Option>
<Option correct>

树中最大元素一定是无左子树

</Option>

<Solution>

**【解析】** 平衡二叉树是一棵特殊的二叉排序树。A 选项明显错误，根结点的度不一定为 2。例如，根结点只有一个比根结点小的右孩子也可以。B 选项错误，D 选项正确：由于此题规定的平衡二叉树中序遍历之后是降序的，即左子树 $>$ 根结点 $>$ 右子树，因此最大结点不一定是叶结点，但一定没有左子树，D 正确。最小结点也不一定是叶结点，例如，只有根节点和左孩子的 AVL 树最小结点为根结点，并不是叶子结点，B 错误。C 选项，最后插入的结点有可能导致平衡二叉树失衡，而重新调整变成非叶结点。故选 D。

**【点评】** 常规题。考查平衡二叉树的特性。这种题只能逐个选项分析判断，比较费时间。

</Solution>

</Question>

<Question id="408-2015-08" type="single" number={8} points={2} tags="来源:2015考研408, 科目:数据结构, 考点:KMP 算法">

已知字符串 $S$ 为“abaabaabacacaabaabcc”，模式串 $t$ 为“abaabc”。采用 KMP 算法进行匹配，第一次出现“失配”（$S[i]\ne t[j]$）时，$i=j=5$，下次开始匹配时，$i,j$ 的值分别是（ ）。

<Option>

$i=1,j=0$

</Option>
<Option>

$i=5,j=0$

</Option>
<Option correct>

$i=5,j=2$

</Option>
<Option>

$i=6,j=2$

</Option>

<Solution>

**【解析】** 失配后，下一次匹配时，$j=next[j]$，$i$ 不变。即求 $next[5]$ 的值。对于模式串“abaabc”来说，即求“abaab”这个字符串最长相同前缀和后缀的长度。而最长公共子串为“ab”，即 $next[5]=2$，故 $i=5,j=2$。故选 C。

<Question id="408-2015-12" type="single" number={12} points={2} tags="来源:2015考研408, 科目:计算机组成原理, 考点:机器语言">

计算机硬件能够直接执行的是（ ）。

I. 机器语言程序

II. 汇编语言程序

III. 硬件描述语言程序

<Option correct>

仅 I

</Option>
<Option>

仅 I、II

</Option>
<Option>

仅 I、III

</Option>
<Option>

I、II、III

</Option>

<Solution>

**【解析】** ① I. 机器语言程序由二进制指令构成，是计算机硬件唯一可以直接识别、直接执行的语言。例如：机器语言程序代码 `6a 27 58 0f 05 48 97 6a 3c 58 0f 05`，实现的功能是：获取当前进程 PID，并以该 PID 作为状态码退出进程。故选 A。

② II. 汇编语言（Assembly Language）是机器语言的符号化表示。它用人类易记的助记符（例如：MOV、ADD）代替二进制机器指令的操作码，用符号地址（例如：LOOP、DATA）代替物理地址，一条汇编指令通常对应一条机器指令。汇编语言是一种与具体 CPU 架构紧密相关的低级程序设计语言，不同处理器架构（例如：x86、ARM、RISC-V 等）拥有完全不同的汇编指令集，彼此互不通用。汇编语言程序不能被计算机硬件直接执行，必须通过“汇编器”翻译成二进制机器码，才能在 CPU 上运行。

② III. 硬件描述语言（HDL, Hardware Description Language）是一种用于描述数字电路结构和行为的专门语言，它不是传统意义上的“编程语言”，而是“描述语言”：描述的是硬件如何连接、如何工作（本质是用文本“画电路”）。目前行业内最主流的两类基础 HDL 分别是 Verilog 和 VHDL。

**【点评】** 概念题。编程语言有很多种，但计算机硬件能直接执行的只有机器语言。这个考点在 408 中多次考到过。本题列举了“硬件描述语言”这个生僻的语言，类似的考法还有：再列举一个在小众专业领域应用广泛，但考生普遍没听说过的语言作为干扰项，比如 COBOL、Tcl 等。

**【拓展】** 掌握基础的汇编语言语法，对备考 408 是非常重要的。因为 408 中的计组大题，经常给一段 C 语言代码，分析其在计算机中的底层执行过程。通常是默认考生已经学过汇编语言。一个完整可上机执行的入门级汇编语言代码实例如下，考生可对比注释学习：

```asm
; 这段程序的功能是：向屏幕输出一行字符串，随后正常退出程序
section .data        ; 段定义伪指令，用于划分程序的不同内存区域。
    ; msg标记这段数据的内存起始地址；db是数据定义伪指令，按字节分配内存；
    ; 'Hello, Assembly!'是字符串；0Ah指换行符\n，作用是打印完字符串后光标换行。
    msg db 'Hello, Assembly!', 0Ah
    ; len是自定义符号名；equ是等值伪指令，在编译阶段给符号len绑定一个固定数值；
    ; $是汇编器内置的“当前地址计数器”，代表执行到这一行时，当前所处的内存偏移地址。
    len equ $ - msg

section .text        ; 代码段，专门存放程序的执行指令
    ; Linux的链接器默认以_start作为程序的入口地址，必须用global声明。
    ; _start等价于C语言的main函数的入口标识。
    global _start

; _start是程序入口标号，_start是整个程序第一条执行指令的地址。
; 操作系统加载程序后，CPU 会从这个地址开始取指令运行。
_start:
    ; --- write 系统调用：输出字符串 ---
    mov rax, 1        ; 把立即数1存入rax寄存器
    ; 把立即数1存入rdi寄存器。1是 Linux 中“标准输出”的文件描述符，表示向屏幕输出。
    mov rdi, 1
    ; 把字符串的首地址msg存入rsi，告诉内核要输出的数据在内存中的位置。
    mov rsi, msg
    mov rdx, len      ; 把字符串长度len存入rdx，告诉内核“要输出多少个字节”。
    ; 内核根据rax中的调用号，读取对应寄存器的参数，
    ; 执行“向标准输出打印字符串”的操作，完成后返回用户态继续执行下一条指令。
    syscall

    ; --- exit 系统调用：程序退出 ---
    ; 把立即数60存入rax。Linux中，系统调用编号60表示exit（程序退出）。
    mov rax, 60
    ; 把立即数0存入rdi。0表示程序正常退出，非0代表程序异常退出，此值会返回给操作系统。
    mov rdi, 0
    ; 触发 exit 系统调用，程序终止运行，控制权交还给操作系统，不会再执行后续代码。
    syscall
```

一、考生可能会有疑问，为什么上述汇编代码中出现了 2 次 syscall？其实，Linux 中 syscall 是用户态程序进入内核态的唯一入口，具体进入内核态执行什么操作，由触发前 rax 寄存器里的系统调用号决定。

二、建议考生在 linux 上动手运行上述代码，运行步骤如下：

① 第一步：先安装汇编器 nasm（安装命令：`sudo yum install nasm`），将上述代码保存到文件 `hbtest.asm` 中。

② 编译运行命令如下：

```bash
# 1. 汇编为目标文件
nasm -f elf64 hbtest.asm -o hbtest.o
# 2. 链接为可执行文件
ld hbtest.o -o hbtest
# 3. 运行
./hbtest
```

③ 上述代码运行后，会在屏幕显示字符串 "Hello, Assembly!"。

</Solution>

<Question id="408-2015-13" type="single" number={13} points={2} tags="来源:2015考研408, 科目:计算机组成原理, 考点:补码">

由 3 个“1”和 5 个“0”组成的 8 位二进制补码，能表示的最小整数是（ ）。

<Option>

$-126$

</Option>
<Option correct>

$-125$

</Option>
<Option>

$-32$

</Option>
<Option>

$-3$

</Option>

<Solution>

**【解析】** ① 要使补码表示的整数最小，首先该数必为负数，因此符号位必须为 1。

适用于无线网络，以实现无线链路共享

</Option>
<Option>

需要根据网络跨距和数据传输速率限定最小帧长

</Option>
<Option>

当信号传播延迟趋近 0 时，信道利用率趋近 100%

</Option>

<Solution>

**【解析】** CSMA/CD 是有线以太网用于解决多个站点共享同一信道时的冲突问题的介质访问控制（MAC）协议。其核心思想是：站点在发送数据前先监听信道，信道空闲才发送；发送过程中继续监听，一旦发现冲突立即停止。可以概括为四个要点：

- 载波监听：发送前检测信道是否空闲
- 多路访问：多个站点共享同一总线信道
- 边发送边监听：发送过程中持续检测是否发生冲突
- 冲突检测：检测到冲突后立即停止发送，发送强化干扰信号（Jam Signal，通常为 32～48bit），通知所有站点。

① A 正确 ✓。CSMA/CD 协议的精髓就是“边发边听”：站点在发送数据的同时持续监听信道，一旦发现电压叠加异常即判定发生冲突，立即停止发送并执行退避重发。这正是“碰撞检测（CD，Collision Detection）”的含义。

② B 错误 ×。CSMA/CD 是为有线总线型以太网设计的，它成立的前提是“发送站在发送期间能够检测到冲突”。而在无线环境中这一前提不复存在：

- 无线信号随距离衰减极快，远端站点的信号到达本站点时可能已微弱到无法辨别是否与本站信号叠加，冲突检测在物理上难以实现；
- 无线网络存在特有的隐蔽站（hidden terminal）与暴露站问题，站点即使监听到信道空闲也不代表接收端处无冲突。

因此无线局域网（IEEE 802.11）改用 CSMA/CA（碰撞避免），通过 RTS/CTS 预约信道和确认重传机制来尽量规避冲突，而不是检测冲突。

③ C 正确 ✓。为了能在一帧发送完毕之前检测到可能发生的冲突，帧的发送时延必须不小于端到端往返传播时延（争用期 $2\tau$），因此最小帧长 = $2\tau\times$ 数据率，其中 $\tau$ 由网络间隔的距离决定。这正是以太网规定最小帧长 64B 的原因。

④ D 正确 ✓。用 $\tau$ 表示传播时延，信道利用率 $U=\frac{\text{一个发送周期内发送数据的时间}t}{\text{发送周期}T}=\frac{t}{t+2\tau}$，当 $\tau\to0$ 时，$U\to1$。即：当传播延迟趋近 0 时，冲突可以瞬间检测到，信道几乎不会因冲突而浪费，利用率趋近 100%。

**【点评】** 概念题。考查 CSMA/CD 协议的基本特点。

void delSameAbs(LinkList L, int n) {

② 暂存器 T 的作用：单总线结构在同一时刻只能传送一个数据，而 ALU 执行双操作数运算时，A、B 两个输入端必须同时获得两个不同的操作数。解决办法是：先把第一个操作数经内总线送入 T 暂存，再把第二个操作数经内总线直接送到 ALU 的 B 端，此时 T 的输出稳定地接在 A 端，两个操作数便同时就绪，ALU 方可正常工作。如果没有 T，ALU 的 A、B 两端将得到同一个数据（都等于总线上当前的数据），双操作数运算无法实现，数据通路无法工作。

(2) 控制信号的编码位数必须能区分对应功能部件的全部操作种类。

由题目可知，ALU 有 7 种操作，所以操作控制信号 ALUop 至少需要 $\lceil\log_2 7\rceil=3$ 位。

移位寄存器有 3 种操作，所以操作控制信号 SRop 至少需要 $\lceil\log_2 3\rceil=2$ 位。

(3) SRout 控制的部件是三态门，用于控制移位器与总线数据通路的连接 / 断开。CPU 采用单内总线结构，同一时刻只允许一个部件向总线发送数据。当该三态门关闭时，SR 输出为高阻态，不占用总线，防止多个器件同时驱动总线造成信号冲突。

(4) 端口 ①、②、③、⑤、⑧ 必须连接控制部件的输出端（这些部件都需要控制信号）。

(5) 有两条连线。

- 第一条：⑥→⑨。将内总线上的数据引到 MUX 的一个数据输入端（⑨），使总线数据可被 MUX 选通；
- 第二条：⑦→④。这条线用于将 MUX 的输出（⑦）接到 ALU 的 B 输入端（④），并由 MUXop 控制。根据题目给出的 CPU 结构图，当实现普通 ALU 操作时，MUXop = 1，数据直接流入 ALU 的 B 端；当需要完成 PC 自增时，MUXop = 0，2 作为加数实现 $(\mathrm{PC})+2\to(\mathrm{PC})$。

> **【注意】** 在程序计数器（PC）自增时，MUX 输入端的控制信号取决于具体的硬件设计和控制逻辑。在有的机器中，也有可能 MUXop = 1 时，实现 PC 自增。考生要结合具体的题目分析，不可死记硬背。

(6) 每条指令的长度为 16 位 = 2B，按字节编址，所以每条指令占用 2B ÷ 1B = 2 个内存单元。当顺序执行时，下条指令地址为 (PC) + 2。把常数 2 固定接在 MUX 的一个输入端上，就为“(PC) + 2”这一高频微操作提供了硬件捷径，无需再从其他寄存器取常数 2，方便计算下一条顺序指令的地址。

> **【点评】** 常规题。以单总线 CPU 数据通路为载体，全面考查数据通路结构的静态分析（可见寄存器、三态门、控制信号位数、端点属性）与动态理解（暂存器 T 的作用、PC + 2 的实现）。本题是非常经典的一道考查数据通路的综合题，很适合作为一个典型例题理解记忆。近些年 408 中此类题型都和本题形似。

<Question id="408-2015-46" type="essay" points={6} tags="来源:2015考研408, 科目:操作系统, 考点:二级页表">

某计算机系统按字节编址，采用二级页表的分页存储管理方式，虚拟地址格式如下所示：

| 页目录号（10 位） | 页表索引（10 位） | 页内偏移量（12 位） |
| --- | --- | --- |

请回答下列问题：

(1) 页和页框的大小各为多少字节？进程的虚拟地址空间大小为多少页？

(2) 若页目录项和页表项均占 4 字节，则进程的页目录和页表共占多少页？要求写出计算过程。

(3) 若某指令周期内访问的虚拟地址为 0100 0000H 和 0111 2048H，则进行地址转换时共访问多少个二级页表？要求说明理由。

<Solution>

**【解析】**

(1) 注意两级页表的地址结构：一级页号（10 位）+ 二级页号（10 位）+ 页内偏移量（12 位）。页内偏移量占 12 位，所以页和页框大小都是 $2^{12}\mathrm{B}=4\mathrm{KB}$。页目录号加上页表共占 20 位，所以虚拟空间大小为 $2^{20}$ 页。也可通过虚拟空间大小除以页大小来计算：$2^{32}\mathrm{B}\div 2^{12}\mathrm{B}=2^{20}$ 页。

(2) ① 页目录：页目录号 10 位，即页目录有 $2^{10}$ 个页目录项，每个页目录项占 4B，则页目录大小 = $2^{10}\times 4\mathrm{B}=4\mathrm{KB}=2^{12}\mathrm{B}$。每页大小为 $2^{12}\mathrm{B}$，则页目录占 $2^{12}\mathrm{B}\div 2^{12}\mathrm{B}=1$ 页。

② 页表：页号位数 = 页目录号位数（10 位）+ 页表索引位数（10 位），每个进程最多有 $2^{20}$ 个页表项，每个页表项 4B，页表总大小 = $2^{20}\times 4\mathrm{B}=4\mathrm{MB}=2^{22}\mathrm{B}$。每页大小为 $2^{12}\mathrm{B}$，则页表占 $2^{22}\mathrm{B}\div 2^{12}\mathrm{B}=2^{10}=1024$ 页。

③ 页目录占 1 页，页表占 1024 页，共占 $1+1024=1025$ 页。

(3) 0100 0000H = 0000 0001 0000 0000 0000 0000 0000 0000B，最高 10 位为 00 0000 0100B = 4。

0111 2048H = 0000 0001 0001 0001 0010 0000 0100 1000B，最高 10 位为 00 0000 0100B = 4。

两个虚拟地址的页目录号相同（均为 4），经页目录的同一个表项指向同一个二级页表，因此地址转换过程中只访问 1 个二级页表。
