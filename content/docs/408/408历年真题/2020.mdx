<Question id="408-2020-01" type="single" number={1} points={2} tags="来源:2020考研408, 科目:数据结构, 考点:对称矩阵">

将一个 $10\times10$ 对称矩阵 $M$ 的上三角部分的元素 $m_{i,j}$（$1\le i\le j\le10$）按列优先存入 C 语言的一维数组 $N$ 中，元素 $m_{7,2}$ 在 $N$ 中的下标是（ ）。

<Option>

15

</Option>

<Option>

16

</Option>

<Option correct>

22

</Option>

<Option>

23

</Option>

<Solution>

**【解析】** ① 因为是对称矩阵，所以 $m_{7,2}=m_{2,7}$。② 因为对称矩阵 $M$ 只存储上三角部分，而 $m_{7,2}$ 位于下三角部分，所以本题等价于求 $m_{2,7}$ 在数组 $N$ 中的下标。③ 按列优先存储上三角部分，第1列有1个元素，第2列有2个元素，…，第6列有6个元素，前6列共有 $1+2+3+4+5+6=21$ 个元素（可动手画图模拟），$m_{2,7}$ 是第7列的第2个元素，所以 $m_{2,7}$ 是数组 $N$ 的 $21+2=23$ 个元素。因为数组下标从0开始，数组中的第23个元素的下标为22。故选 C。

**【点评】** 常规题。综合考查对称矩阵、上三角矩阵、按列优先存储等多个考点。本题极易误选 D：正确求出了 $m_{2,7}$ 是数组中的第23个元素，稍不留神，忘记数组下标从0开始，就会误选 D，非常可惜。408 这种国家级的选拔性考试，一些看似简单且常见的考点，为了增加区分度，命题人常常会精心设计一些“陷阱”来“坑”考生。这要求考生对考纲知识点有更高的熟练度，若考试之前做过类似练习题或对考点很熟练，就会减少出错概率。

</Solution>

</Question>

对空栈 $S$ 进行 Push 和 Pop 操作，入栈序列为 $a,b,c,d,e$，经过 `Push, Push, Pop, Push, Pop, Push, Push, Pop` 操作后得到的出栈序列是（ ）。

</Option>

<Option>

$b,a,e$

</Option>

<Option>

$b,c,a$

</Option>

<Option correct>

$b,c,e$

</Option>

<Solution>

**【解析】** 栈的特点是“后进先出”。题目要求的入栈和出栈过程如下所示：

| 步骤 | 操作 | 栈内元素 | 已出栈元素 |
| --- | --- | --- | --- |
| 第1步 | Push a | a | 无 |
| 第2步 | Push b | a、b | 无 |

| 第4步 | Push c | a、c | b |
| 第5步 | Pop c | a | b、c |
| 第6步 | Push d | a、d | b、c |
| 第7步 | Push e | a、d、e | b、c |
| 第8步 | Pop e | a、d | b、c、e |

经过题目要求的入栈出栈操作后，出栈序列为 b、c、e，故选 D。

<Question id="408-2020-06" type="single" number={6} points={2} tags="来源:2020考研408, 科目:数据结构, 考点:深度优先搜索">

修改递归方式实现的图的深度优先搜索（DFS）算法，将输出（访问）顶点信息的语句移到退出递归前（即执行输出语句后立刻退出递归）。采用修改后的算法遍历有向无环图 $G$，若输出结果中包含 $G$ 中的全部顶点，则输出的顶点序列是 $G$ 的（ ）。

<Option>

拓扑有序序列

</Option>

<Option correct>

逆拓扑有序序列

</Option>

<Option>

广度优先搜索序列

</Option>

<Option>

深度优先搜索序列

</Option>

<Solution>

**【解析】** 按照题目要求，对 DFS 算法进行修改后的代码如下：

```cpp
int visited[G.verNum] = {0}; // visited数组：1表已访问，0表未访问
void DepthFirstSearch(const Graph &G) {
    // 对每个极大连通子图分别调用一次DFS函数
    for (int v = 0; v < G.verNum; ++v) {
        if (visited[v] != 1) // 过滤掉已经访问过的顶点
            DFS(G, v);
    }
}

void DFS(const Graph &G, int v) {
    for(int w = findFstN(G, v); w >= 0; w = findNextN(G,v,w)) {
        // 选取未被访问过的邻居顶点进行访问
        if (visited[w] != 1) DFS(G, w);
    }
    visit(v);          // 访问v顶点(根据实际需要定义visit函数)
    visited[v] = 1;    // 注意：visited是全局变量，不传入DFS作为参数
}
```

![题06图](/img/2020-a06.svg)

上述代码的第15和16行（加粗部分的代码）原来在第10行之后，根据题目要求移动到函数末尾。这里以上图为例进行分析、从顶点 A 开始遍历：

① 根据上述代码，对上图进行遍历，得到的遍历序列为 C,B,A。

② 对上图进行拓扑排序，得到的拓扑序列为 A,B,C。

③ 对上图进行 DFS 遍历，得到的遍历序列为 A,C,B 或 A,B,C。

④ 对上图进行 BFS 遍历，得到的遍历序列为 A,C,B 或 A,B,C。

C,B,A 是逆拓扑序列，故选 B。

**【点评】** 难题。本题有一定创新性和综合性，要求熟悉 BFS、DFS 和拓扑排序。考生可结合具体的例子，画草图模拟，逐个排除各个选项。若单纯的推理分析很有难度，较难分析清楚，也容易出错。而且，这种题也没有通法，考查灵活运用，下次再考一个修改经典算法进行分析的题也是没问题的。

</Solution>

</Question>

<Question id="408-2020-08" type="single" number={8} points={2} tags="来源:2020考研408, 科目:数据结构, 考点:关键路径">

若使用 AOE 网估算工程进度，则下列叙述中正确的是（ ）。

<Option>

关键路径是从源点到汇点边数最多的一条路径

</Option>

<Option correct>

关键路径是从源点到汇点路径长度最长的路径

</Option>

<Option>

增加任一关键活动的时间不会延长工程的工期

</Option>

<Option>

缩短任一关键活动的时间将会缩短工程的工期

</Option>

<Solution>

**【解析】** ① 根据关键路径的定义，关键路径是从源点到汇点所有的路径中，具有最大路径长度的路径，不一定是边数最多的路径。故 A 错误，B 正确。

② 关键活动是关键路径上的边，不管关键路径中有多少条，增加任一关键路径上的任一关键活动的时间都会导致路径长度增加，还可能导致关键路径变化。故 C 错误。

③ 若 AOE 网只存在一条关键路径，则缩短任一关键活动的时间会缩短工期；若关键路径不止一条，缩短其中一个关键活动的时间可能导致该路径不再是关键路径。故 D 错误。

**【点评】** 常规题。考查关键路径的基本概念。关于关键路径相关总结如下（以下内容截取自竞成《数据结构考研复习全书》）：

① 关键路径不一定只有一条，但所有关键路径的长度都是相同的。

② 关键路径长度是从源点到汇点之间最长的路径。所以，若增大某个关键活动，会使关键路径长度变的更大，从而使 AOE 网对应的工程推迟。但是，若减小某个关键活动，则不一定会使关键路径长度变小。因为，某个关键活动变小之后，它不一定再继续满足关键活动的定义了，可能就不是关键活动了。

③ 若 AOE 网中存在多条长度相同的关键路径，只有同时减小当前所有关键路径上边的长度，才能减小关键路径长度，从而使 AOE 网对应的工程提前。

</Solution>

</Question>

<Question id="408-2020-09" type="single" number={9} points={2} tags="来源:2020考研408, 科目:数据结构, 考点:堆">

下列关于大根堆（至少含2个元素）的叙述中，正确的是（ ）。

I. 可以将堆视为一棵完全二叉树

II. 可以采用顺序存储方式保存堆

</Option>

</Option>

<Solution>

III. 通用寄存器

仅 I、III

</Option>

仅 II、III

**【解析】**

**【暴力解】**

(1) 穷举出所有的三元组，求出最小距离。

(2) 代码实现如下：

```c
int findMin(int s1[], int s2[], int s3[], int n1, int n2, int n3) {
    int temp;
    int minDist = INF; //将minDist初始化为最大的int型整数INF
    for (int i = 0; i < n1; i++) {
        for (int j = 0; j < n2; j++) {

                if (temp < minDist) {
                    minDist = temp;
                }
            }
        }
    }
    return minDist;
}
```

(3) 3 层循环，时间复杂度为 $O(n^3)$，空间复杂度为 $O(1)$。

**【最优解】**

(1) 用变量 minDist 记录当前的最小距离。由于 $S_1,S_2,S_3$ 按升序排列，遍历三个数组，计算当前三元组 $(a,b,c)$ 的距离 temp。若 $\mathrm{temp}<\mathrm{minDist}$，则令 minDist = temp。将 $(a,b,c)$ 中最小的数对应下标加一，重复之前步骤直到遍历结束。

(2) 代码实现如下：

```c

    int temp, minDist = INF; //将minDist初始化为最大的int型整数INF
    int i = j = k = 0;
    while (i < n1 && j < n2 && k < n3) {
        temp = abs(s1[i]-s2[j]) + abs(s2[j]-s3[k]) + abs(s1[i]-s3[k]);
        // minDist赋值为minDist和temp中的最小值
        minDist = temp < minDist ? temp : minDist;

            i++;
        } else if (s2[j] == min(s1[i],s2[j],s3[k])) {
            j++;
        } else {
            k++;
        }
    }
    return minDist;
}
```

| --- | --- | --- |

由主存块大小为 64B，可以得出块内地址占 $\log_2 64=6$ 位。由数据区容量为 32KB，可得 Cache 组数为 $32\text{KB}\div64\text{B}\div8=64=2^6$ 组，因此 Cache 组号占 6 位。主存地址的 Tag 位占 $32-6-6=20$ 位。② 由 8 路组相联映射，每组 8 块，LRU 位数为 $\log_2 8=3$ 位。③ 因为采取直写法（全写法），所以不需要附设修改位。

(2) 0080 00C0H = 0000 0000 1000 0000 0000 0000 1100 0000B，该地址的末 6 位为 00 0000B，说明该地址位于一个主存块的起始位置。该程序段执行时，依次顺序访问数组元素：$s[0],s[1],s[2],\cdots,s[1023]$。一个主存块中可存放 $64\text{B}\div4\text{B}=16$ 个数组元素，$s$ 数组有 1024 个元素，共占 $1024\div16=64$ 个主存块。对于存放数组 $s$ 的数据的每个主存块，首次访问时会发生 Cache 缺失，64 个主存块总共缺失了 64 次。

(3) 0001 0003H = 0000 0000 0000 0001 0000 0000 0000 0011B。根据第一小问分析的地址结构，块内地址为：00 0011B，Cache 组号为：0000 00B，主存块标记 Tag 为：0000 0000 0000 0001 0000B。初始时，Cache 为空，访问会发生 Cache 缺失。因为组号为 0，将缺失的主存块存入 Cache 第 0 组中（组内任意一行），并同时修改 LRU 位和有效位，将 Cache 该行标记设置为：0000 0000 0000 0001 0000B，再根据块内地址 00 0011B 读取内容。

**【点评】** 常规题。简单的 Cache 综合题，题目所涉及的考点和考法都是常见的常规考法，在教辅中也有类似的练习题。

</Solution>

<Question id="408-2020-46" type="essay" number={46} points={8} tags="来源:2020考研408, 科目:操作系统, 考点:二级页表">

某 32 位系统采用基于二级页表的请求分页存储管理方式，按字节编址，页目录项和页表项长度均为 4 字节，虚拟地址结构如下所示。

| 页目录号（10 位） | 页号（10 位） | 页内偏移量（12 位） |
| --- | --- | --- |

某 C 程序中数组 $a[1024][1024]$ 的起始虚拟地址为 1080 0000H，数组元素占 4 字节，该程序运行时，其进程的页目录起始物理地址为 0020 1000H，请回答下列问题。

(1) 数组元素 $a[1][2]$ 的虚拟地址是什么？对应的页目录号和页号分别是什么？对应的页目录项的物理地址是什么？若该页目录项中存放的页框号为 00301H，则 $a[1][2]$ 所在页对应的页表项的物理地址是什么？

(2) 数组 $a$ 在虚拟地址空间中所占的区域是否必须连续？在物理地址空间中所占区域是否必须连续？

(3) 已知数组 $a$ 按行优先方式存放，若对数组 $a$ 分别按行遍历和按列遍历，则哪种遍历方式的局部性更好？

<Solution>

**【解析】**

(1) ① 数组的起始虚拟地址是 1080 0000H，即 $a[0][0]$ 的虚拟地址为 1080 0000H。$a[1][2]$ 是数组中的第 $1024+2=1026$ 个元素，每个数组元素占 4B，所以 $a[1][2]$ 的虚拟地址为 1080 0000H + $1026\times4$ = 1080 1008H。

② 1080 1008H = 0001 0000 1000 0000 0001 0000 0000 1000B。根据虚拟地址结构可知，虚拟地址高 10 位是页目录号，即页目录号为 0001 0000 10B = 042H；根据虚拟地址结构可知，虚拟地址页目录号后 10 位是页号，即页号为 00 0000 0001B = 001H。

③ $a[1][2]$ 虚拟地址的页目录号 042H = 66，为页目录表中第 66 项。页目录起始物理地址为 0020 1000H，则第 66 页目录项的物理地址为 00201000H + $66\times4$ = 0020 1108H。

④ 页表项物理地址 = 页框号 × 页框大小 + 页号 × 页表项长度。根据上述公式来计算，由题目给出的虚拟地址结构可知，页内偏移占 12 位，则每个页框大小为 $2^{12}\text{B}=4\text{KB}$。则页框号 00301H = $3\times2^8+1$ 对应的物理地址为 00301H × 4K = $(3\times2^8+1)\times2^{12}=3\times2^{20}+2\times2^{12}$ = 30 1000H。页目录项中存放着对应页表的起始地址，页号为 001H，每个页表项是 4B，则页号为 001H 的页表项的物理地址为 301000H + 001H × 4 = 30 1004H。

{/* 原书第 (1) 问④展开式中的 2×2^12 应为 1×2^12，原式保留，十六进制结果正确。 */}

(2) 数组支持随机存储，其逻辑地址空间必须连续。但实际的实现中，数组 $a$ 占用了多个页面，这些页面在逻辑空间上连续，但在物理空间上不一定连续。此处是由二级页表将这些不连续的页面索引起来，达到逻辑上的连续。

(3) 按行遍历局部性更好。数组按行优先存放，本题中一个页面刚好可以存放数组 $a$ 的一行元素，同一行的元素大多存放在同一个页面中，不同列的元素大多不在同一页，按行遍历缺页中断次数相比按列遍历显著降低，局部性更好。

**【点评】** 常规题。考查二级页表的地址转换，适合作为二级页表地址转换的典型例题理解记忆。建议查阅竞成写的 2021 年第 29 题的解析，对二级页表进行了进一步的拓展总结。限于篇幅，这里不再重复讲述。另外，本题第一问的第 4 小问中，根据页框号和页号，求对应页表项的物理地址，建议考生采用本题所述的解法（页表基址 = 页框号 × 页面大小），网上一些博主及其他教辅中，对该问的解释很“牵强”，都是在凑答案。

</Solution>
