<Question id="408-2025-01" type="single" number={1} points={2} tags="来源:2025考研408, 科目:数据结构, 考点:时间复杂度">

下列程序段的时间复杂度是（ ）。

```c
int count = 0, i, j;
for(i = 1; i*i <= n; i++)
    for(j = 1; j <= i; j++)
        count++;
```

<Option>

$O(\log n)$

</Option>

<Option correct>

$O(n)$

</Option>

<Option>

$O(n\log n)$

</Option>

<Option>

$O(n^2)$

</Option>

<Solution>

**【解析】** 时间复杂度是基本语句执行次数的数量级，本题基本语句为“`count++`”。程序是两层循环，外层循环中 i 的值是多少，内层循环中就要执行多少次运算。外层循环条件为“$i*i\leq n$”，即 $i\leq\sqrt n$，故外层循环执行 $\lfloor\sqrt n\rfloor$ 次。对于每个外层循环的 i，内层循环执行 i 次。基本语句“`count++`”的总执行次数不超过 $1+2+3+\cdots+\sqrt n=\frac{n+\sqrt n}{2}$，故时间复杂度为 $O(n)$，故选 B。

**【点评】** 常规题。考查时间复杂度的计算。本题和 2022 年 408 第 1 题类似。

</Solution>

</Question>

<Question id="408-2025-02" type="single" number={2} points={2} tags="来源:2025考研408, 科目:数据结构, 考点:括号匹配">

已知算法 A 用于检查字符串中各类括号是否匹配，A 执行过程中使用初始为空的栈保存遇到的括号。若栈的容量是 3，则下列选项中，A 不能处理的是（ ）。

<Option>

$(a+[b+(c+d)/e]+f)+g-h$

</Option>

<Option>

$[a*((b+c)/(d-e)+f/g)-h]$

</Option>

<Option>

$[a*(b-(c-d)*e/(f+g))-h]$

</Option>

<Option correct>

$[a-(b+[c*(d+e)-f]+g+h)]$

</Option>

<Solution>

**【解析】** 括号匹配算法的核心逻辑是“遇左括号入栈，遇右括号则弹出栈顶左括号并检查是否匹配”。栈中元素个数等于当前尚未匹配的左括号数，即最大嵌套深度。若遍历过程中需入栈的左括号数量超过栈容量 3，或者右括号无对应左括号匹配，则算法无法处理该字符串。将字符串中字母和运算符全部划掉、只看括号序列：

① A 选项 ⇒ `( [ ( ) ] )`，最深 3 层，可处理；

② B 选项 ⇒ `[ ( ( ) ( ) ) ]`，最深 3 层，可处理；

③ C 选项 ⇒ `[ ( ( ) ( ) ) ]`，最深 3 层，可处理；

④ D 选项 ⇒ `[ ( [ ( ) ] ) ]`，依次出现 `[、(、[、(`。从左到右扫描表达式，遇到第一个“[”时入栈，遇到第一个“(”时入栈，遇到第二个“[”时入栈，此时栈已满。当遇到第二个“(”时，应该将“(”入栈，但栈已满，故无法处理。故选 D。

**【提示】** 常规题。考查栈的应用。408 中经常结合具体的应用场景，考查栈和队列的特性。本题的坑点在于：① 若按照括号匹配的流程逐个字符模拟四个选项，题目选项设置干扰性强，括号种类多、式子长，费时费力且容易出错；② 审题出错，题目问的是哪个选项“不能”处理。③ 按照本题的做法：先去掉非括号字符，只数各选项括号的最大嵌套层数，10 秒即可锁定 D。

</Solution>

</Question>

<Question id="408-2025-04" type="single" number={4} points={2} tags="来源:2025考研408, 科目:数据结构, 考点:二叉树与森林">

下列关于二叉树及森林的叙述中，正确的是（ ）。

<Option>

完全二叉树中不存在度为 1 的结点

</Option>

<Option correct>

任意一个森林都可以转换为一棵二叉树

</Option>

<Option>

二叉树的分支结点个数比叶结点个数少

</Option>

<Option>

表达式树的根中保存的是最先计算的运算符

</Option>

<Solution>

**【解析】** ① A 错误：完全二叉树只可能存在一个度为 1 的结点（最后一个分支结点可能只有左孩子）。

② B 正确：按照森林转换为二叉树的规则：左孩子右兄弟，可以将任意一个森林都可以转换为一棵二叉树。

③ C 错误：根据二叉树性质，非空二叉树的叶结点个数（$n_0$）= 度为 2 的结点个数（$n_2$）+ 1，即 $n_0=n_2+1$。分支结点包括度为 1 的结点（$n_1$）和度为 2 的结点（$n_2$），分支结点总数 = $n_1+n_2=n_1+(n_0-1)$。若 $n_1\geq1$，则分支结点总数 $=n_0+(n_1-1)\geq n_0$，此时分支结点个数 ≥ 叶结点个数。

④ D 错误：链式树（Linked Tree）是一种基于“链式存储结构”实现的树形数据结构。链式树（以表达式树为例）的运算顺序遵循“先计算子树，后计算根结点”的规则：表达式树中，叶结点为操作数，分支结点为运算符，根结点为最后计算的运算符（因需先计算左、右子树的表达式结果，再用根结点的运算符进行最终运算）。例如：表达式“(a+b)*(c−d)”对应的表达式树，根结点为“*”，左子树根为“+”，右子树根为“−”，计算顺序为先算 a+b 和 c−d，最后算两者乘积，根结点“*”是最后计算的运算符，并非最先计算。故选 B。

**【提示】** 本题选项 A 和 C，其实举个特例，画个草图进行分析即可快速解题，无需像本题这样推导分析。

**【点评】** 常规题。二叉树相关考点的综合题。选项 D 可能比较陌生，容易出错。

</Solution>

</Question>

<Question id="408-2025-05" type="single" number={5} points={2} tags="来源:2025考研408, 科目:数据结构, 考点:哈夫曼编码">

设字符集 S 包含 7 个字符，各字符出现的频次分别为 2, 3, 4, 6, 8, 10, 11。现为 S 中的各字符构造哈夫曼编码，编码长度不小于 3 的字符个数是（ ）。

<Option>

2

</Option>

<Option>

3

</Option>

<Option>

4

</Option>

<Option correct>

5

</Option>

<Solution>

**【解析】** 哈夫曼树构建规则：每次从当前所有结点中选取两个频次最小的根结点，以它们为左、右子树构建一棵新二叉树，新树的根结点频次为两子树频次之和；重复此过程，直至所有字符结点都被合并为一棵二叉树。根据题目条件构造的哈夫曼树如下图所示。

![哈夫曼树](/img/2025-q05-huffman.svg)

哈夫曼编码规则：从哈夫曼树的根结点出发，左分支记为“0”，右分支记为“1”，每个字符的编码为从根到该字符结点的路径上的“0/1”序列，编码长度即路径上的分支数。由上图可知，编码长度不小于 3 的结点有 5 个：$\{4,6,8,2,3\}$。故选 D。

<Question id="408-2025-06" type="single" number={6} points={2} tags="来源:2025考研408, 科目:数据结构, 考点:图的性质">

下列关于图的叙述中，正确的是（ ）。

<Option>

有向图必存在入度为 0 的顶点

</Option>

<Option>

有向无环图的拓扑有序序列存在且唯一

</Option>

<Option correct>

各顶点的度均大于等于 2 的无向图必有回路

</Option>

<Option>

可用 BFS 算法求出带权图中每一对顶点间的最短路径

</Option>

<Solution>

**【解析】** ① A 错误 ×：有向图中可能不存在入度为 0 的顶点。例如，如下图所示，由 3 个顶点 A、B、C 构成的有向环（边为 A → B、B → C、C → A），每个顶点的入度均为 1，不存在入度为 0 的顶点。

![选项 A、B 的反例](/img/2025-q06-graphs.svg)

② B 错误 ×：有向无环图的核心性质是“必存在拓扑有序序列”，但序列不一定唯一。例如：如上图所示，由 3 个顶点 A、B、C 组成的图（边为 A → B、A → C），此图有 2 个拓扑序列：“A → B → C”和“A → C → B”。

③ C 正确 ✓：可以用反证法证明：假设结论不成立，即存在一个“所有顶点度 ≥ 2 的无向图 G，且 G 中没有回路（即 G 是无向无环图）”。对于 n 个顶点、m 条边、$k(k\geq1)$ 个连通分量的无向无环图，存在关系 $m=n-k$。而无向图中所有顶点的度之和等于边数的 2 倍，即总度数 = $2m$。若每个顶点度 ≥ 2，则总度数 $\geq2n$，即 $2m\geq2n\Rightarrow m\geq n$；但无环无向图的边数 $m=n-k\leq n-1$（因为 $k\geq1$），与“$m\geq n$”矛盾。所以假设不成立，原命题“各顶点度均大于等于 2 的无向图必有回路”正确，选项 C 正确。

**【提示】** 树是一种特殊的无向无环图，但无向无环图不一定是树。因为树一定是连通的，但无向无环图不一定是连通的。这里可以用树类比辅助分析。

④ D 错误 ×：BFS 算法的核心逻辑是“按距离（边数）递增的顺序遍历顶点”，仅适用于无权图（或所有边权相等的图），此时“边数最少”等价于“路径最短”。但对于带权图（边权不相等），BFS 无法考虑边权差异，例如：顶点 A 到 B 有两条路径（A → B，权值为 5；A → C → B，权值为 3），BFS 会优先选择边数少的“A → B”，但实际最短路径是“A → C → B”。带权图的多源最短路径需用 Floyd 算法等。故选 C。

**【点评】** 难题。四个选项都是对经典结论做了细微篡改，每个选项单看都“像是对的”。选项 A、C、D 均可举反例排除，通过排除法解题更快。

{/* 原书点评中的 A、C、D 应为 A、B、D，保留原文。 */}

</Solution>

<Question id="408-2025-07" type="single" number={7} points={2} tags="来源:2025考研408, 科目:数据结构, 考点:分块查找">

已知查找表中有 400 个元素，查找每个元素的概率相同。采用分块查找法进行查找，且均匀分块。若采用顺序查找法确定元素所在的块，且块内也采用顺序查找法，为使查找效率最高，则每块包含的元素个数应为（ ）。

<Option>

8

</Option>

<Option>

10

</Option>

<Option correct>

20

</Option>

<Option>

25

</Option>

<Solution>

**【解析】** 若将 n 个元素分为 i 块，每块内的元素个数相同，且均为 j 个，即 $j=n/i$。分块查找过程分为如下两步：

- ① 确定块：顺序查找确定待查元素所在的块。若有 i 块，平均查找长度为 $(1+i)/2$。
- ② 块内查找：在块内顺序查找待查元素。若每块有 j 个元素，则块内平均查找长度为 $(1+j)/2$。分块查找的总平均查找长度 $\text{ASL}=(1+i)/2+(1+j)/2$，将 $j=n/i$ 代入可得：

$$
\text{ASL}=\frac{1+i}{2}+\frac{1+j}{2}=\frac{i+2+n/i}{2}
$$

根据数学不等式 $i+n/i\geq2\sqrt n$，当 $i=\sqrt n$ 时成立。当 $i=\sqrt{400}=20$ 时，ASL 最小，故选 C。

**【点评】** 创新题。考查分块查找 ASL 的计算。这是自 2009～2026 以来，408 中首次考查“分块查找”这个考点，考的比较有新意、出其不意。在竞成《数据结构考研复习全书》分块查找章节有该结论及推导过程。但如果此前忽视了这个考点的学习，可能此题不知道该如何下手。

</Solution>

</Question>

<Question id="408-2025-08" type="single" number={8} points={2} tags="来源:2025考研408, 科目:数据结构, 考点:B 树">

给定 7 个不同的关键字，能够构造的不同 4 阶 B 树的个数最多是（ ）。

<Option>

7

</Option>

<Option>

8

</Option>

<Option correct>

9

</Option>

<Option>

10

</Option>

<Solution>

**【解析】** 4 阶 B 树每个结点最多有 $4-1=3$ 个关键字。除根结点外，每个非叶结点至少有 $\lceil4/2\rceil-1=1$ 个关键字（至少 2 个子结点）。设 B 树高度为 h（根结点为第 1 层），对于 7 个关键字构成的 4 阶 B 树可能的高度，下面分类讨论：

① 若高度 $h=1$：即只有一个根结点，一个根结点最多容纳 3 个关键字，无法容纳 7 个关键字，不可能；

② 若高度 $h=2$：根结点最多能有 3 个关键字（对应 4 个孩子结点）、每个子结点最多 3 个关键字，总关键字最多为 $3+4\times3=15$ 个；根结点至少 1 个关键字（对应 2 个子结点），每个子结点至少 1 个关键字，总关键字最少 $1+2\times1=3$ 个。$3<7<15$，所以 $h=2$ 有可能；

③ 若高度 $h=3$：根结点至少 1 个关键字（对应中间层有 2 个子结点），每个中间层结点至少 1 个关键字（对应 2 个孩子结点），每个孩子结点至少 1 个关键字，总关键字最少为 $1+2\times1+2\times2\times1=7$ 个，刚好等于 7 个关键字，因此 $h=3$ 是可能高度，且只有一种情况；

④ 若高度 $h\geq4$：最少需要 $1+2\times1+2\times2\times1+2\times2\times2\times1=15$ 个关键字，超过 7 个，不可能。

综上，由 7 个关键字组成的 4 阶 B 树，高度只可能为 2 或 3，需分别统计两类的结构数量。如下图所示，7 个关键字构成的 4 阶 B 树，高度为 2 的情况可能有 8 种、高度 3 的情况有且只有 1 种，共 $8+1=9$ 种情况。故选 C。

![九种 B 树结构](/img/2025-q08-btrees.svg)

</Solution>

<Question id="408-2025-09" type="single" number={9} points={2} tags="来源:2025考研408, 科目:数据结构, 考点:散列冲突处理">

下列关于散列方法处理冲突的叙述中，正确的是（ ）。

<Option correct>

只要散列表不满，线性探查再散列一定能找到一个空闲位置

</Option>

<Option>

只要散列表不满，二次探查再散列一定能找到一个空闲位置

</Option>

<Option>

线性探查再散列处理的冲突，一定是发生在同义词之间的冲突

</Option>

<Option>

二次探查再散列处理的冲突，一定是发生在非同义词之间的冲突

</Option>

<Solution>

**【解析】** 开放定址法的冲突处理函数为 $H_i=(H(key)+d_i)\%m$。

① A 正确 ✓：根据线性探测法的冲突处理函数，$d_i=1,2,3,4,\cdots,m-1$，线性探测法会顺序查找，直到找到一个空闲位置为止。

② B 错误 ×：根据二次（平方）探测法的冲突处理函数，$d_i=1^2,-1^2,2^2,-2^2,3^2,-3^2,\cdots$，无法遍历所有位置，并不能像线性探查那样可以依次扫描整张表。可能出现这样的情况：表中确实还有空闲单元，但它们恰好不在该关键字的探查序列上，探查在可达位置里打转，最终报告插入失败——尽管散列表并未满。

③ C 错误 ×：线性探查再散列处理的冲突，除了同义词（即哈希值相同的关键字）之间的冲突，还可能因为非同义词争夺同一位置（称为二次聚集或堆积）而产生冲突。

<Question id="408-2025-41" type="essay" number={41} points={13} tags="来源:2025考研408, 科目:数据结构, 考点:数组算法">

设有两个长度均为 $n$ 的一维整型数组 A 和 res，对数组 A 中的每个元素 $A[i]$，计算 $A[i]$ 与 $A[j]$（$0\le i\le j\le n-1$）乘积的最大值，并将其保存到 $res[i]$ 中。例如，若 `A[] = {1,4,-9,6}`，则得到 `res[] = {6,24,81,36}`。现给定数组 A，请设计一个时间和空间上尽可能高效的算法 calMulMax，求 res 中各元素的值。

函数原型为：`void calMulMax(int A[],int res[],int n)`。要求如下：

（1）给出算法的基本设计思想。（4 分）

（2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。（7 分）

（3）说明你所设计算法的时间复杂度和空间复杂度。（2 分）

<Solution>

**【解法一】暴力解**

（1）暴力解法的基本思路是根据题目描述进行模拟：对数组 A 中的每个元素 $A[i]$，通过遍历数组中所有其他元素 $A[j]$（$i\le j<n$），计算 $A[i]$ 与每个 $A[j]$ 的乘积，并记录这些乘积中的最大值，将该最大值存入 $res[i]$。

（2）算法实现如下：

```c
void calMulMax(int A[], int res[], int n) {
    for(int i = 0; i < n; i++){
        int temp = INT_MIN; //INT_MIN是C语言的宏常量：int类型能表示的最小整数
        for(int j = i;j < n; j++){
            if(A[i]*A[j] > temp){
                temp = A[i]*A[j];
            }
        }
        res[i] = temp;
    }
}
```

（3）两层循环，时间复杂度为 $O(n^2)$。没有引入额外的辅助空间，空间复杂度为 $O(1)$。

**【解法二】最优解**

（1）算法的基本设计思想：

从后向前扫描一遍数组 A，对每个 $A[i]$（$0\le i\le n-1$），分别找到从 $A[n-1]$ 到 $A[i]$ 中的最大值 Max 和最小值 Min，然后分以下情况处理：① 若 $A[i]\ge 0$，则 $A[i]$ 与 Max 相乘；② 若 $A[i]<0$，则 $A[i]$ 与 Min 相乘。最终相乘的结果保存在 $res[i]$ 中。

（2）算法实现：

```c
void calMMulMax(int A[],int res[],int n) {
    int i, Max, Min;
    Max = Min = A[n-1];
    for(i = n-1; i >= 0; i--) { // 从后向前扫描数组A
        if(A[i] > Max) Max = A[i];
        else if(A[i] < Min) Min = A[i];
        if(A[i] >= 0) res[i] = A[i] * Max; //根据A[i]的正负性分别处理
        else res[i] = A[i] * Min;
    }
}
```

{/* 原书最优解函数名 calMMulMax 与题目要求 calMulMax 不一致，按原文保留。 */}

（3）算法的时间复杂度为 $O(n)$；空间复杂度为 $O(1)$。

① 主存块大小为 $64\text{B}=2^6\text{B}$，所以块内偏移占 6 位。d[0] 的虚拟地址为 0180 0020H = 0000 0001 1000 0000 0000 0000 0010 0000B，其末 6 位为 10 0000B = 20H，即 d[0] 的块内偏移是 20H。

② 每个 int 元素占 4B，则每个主存块包含 $64\div4=16$ 个 int 元素。数组 d 有 2048 个元素，$2048\div16=128$，又因为上面已经计算出 d[0] 的块内偏移是 20H，存放在块内中间位置，所以需要数组 d 占 $128+1=129$ 个主存块。数组 d 不在 Cache 中，每次 Cache 缺失后会调入一个主存块，因为数组 d 占 129 个主存块，故 Cache 缺失 129 次。for 循环中，每次执行 `d[i] = d[i]/x` 语句会访问 2 次 d[i]（读出计算完成后，再写回），故数组 d 总的访问次数为 $2048\times2=4096$，Cache 缺失率为 $129/4096\approx3.15\%$。

（1）寄存器 R 中的值为 FFFF FFFFH，Q 中的值为 8765 4321H，Y 中的值为 0000 00FFH。图中的控制逻辑包含计数器。ALUop 所控制的 ALU 运算包含两种运算：加法运算和减法运算。

**控制逻辑与 ALU 操作：** 图中控制逻辑包含计数器，用于记录除法迭代（移位）的次数（32 位除法需 32 次迭代）；ALUop 为 ALU 运算控制信号，补码除法试商时需通过 ALUop 控制 ALU 执行加法或减法运算（例如，根据余数与除数的符号关系，决定加除数或减除数以调整余数，进而确定商值）。

① **除数为 0 异常：** 当除数 x = 0x0000 0000（32 位补码表示的 0）时，无论被除数 d[i] 取何值（如题目中 0x8765 4321，或其他任意 32 位补码值），都会触发除数为 0 异常。因为除法运算中“除以 0”是逻辑上不可执行的操作，属于硬性错误。

② **溢出异常：** 仅当被除数为 32 位补码的“最小负整数”（d[i] = 0x80000000，对应十进制 $-2^{31}$），且除数为 −1（x = 0xFFFF FFFF，32 位补码表示的 −1）时，会触发溢出异常。原因是：$-2^{31}\div(-1)=2^{31}$，而 32 位补码正数的最大值为 $2^{31}-1$，$2^{31}$ 超出了 32 位补码的表示范围，导致结果无法正确存储，进而触发溢出。

① **保存异常现场：**

- 首先保存当前正在执行指令的程序计数器（PC）值（记录异常发生的位置，方便后续恢复执行），同时保存通用寄存器的当前值、程序状态字（PSW，记录 CPU 当前的状态，如标志位等），避免异常处理过程中覆盖原有数据。

② **跳转至异常处理程序：**

- 根据“异常向量表”（存储不同异常对应的处理程序入口地址），找到“除法异常”对应的入口地址，将 PC 值更新为该地址，从而跳转到除法异常处理程序；

③ **后续恢复（处理程序执行后）：**

- 异常处理程序完成错误处理（如输出错误信息、终止程序等）后，CPU 会恢复之前保存的现场数据（恢复 PC、通用寄存器、PSW 值），若需继续执行，则从异常发生时的下一条指令开始运行。

<Question id="408-2025-46" type="essay" points={8} tags="来源:2025考研408, 科目:操作系统, 考点:进程虚拟地址空间">

某系统中进程的虚拟地址空间包括内核区、用户栈、运行时堆、可读写数据段、只读代码段等区域，其布局如下图所示，图中阴影部分表示未占用区域。现有 C 语言程序的部分代码如下。

```c
char* ptr;
void main()
{
    int length;
    ptr=(char*)malloc(100);
    scanf("%s",ptr);
    length=strlen(ptr);
    printf("length=%d\n",length);
    free(ptr);
}
```

![进程虚拟地址空间布局](/img/2025-q46-address-space.svg)

请回答下列问题。

（1）上述程序执行时，其进程控制块位于哪个区域？执行 scanf() 等待键盘输入时，该进程处于什么状态？（2 分）

（2）main() 函数的代码位于哪个区域？其直接调用的哪些函数的功能需要通过执行驱动程序实现？（3 分）

（3）变量 ptr 被分配在哪个区域？若变量 length 没有被分配在寄存器中，则会被分配在哪个区域？ptr 指向的字符串位于哪个区域？（3 分）

<Solution>

（1）进程控制块位于内核区。该进程处于阻塞态。

① PCB（进程控制块）是操作系统内核为管理进程而维护的数据结构，存储进程 ID、状态、优先级、寄存器上下文、内存映射等关键信息。由于 PCB 包含内核级敏感数据（例如：页表基址、内核栈指针等），且仅允许操作系统内核访问（用户态程序无权限操作），因此 PCB 必须位于内核区（虚拟地址空间的最高特权区域）。

② scanf() 是标准输入函数，需等待用户通过键盘输入数据。当进程执行 scanf() 时，因无法立即获得输入数据，会通过系统调用陷入内核，主动放弃 CPU 使用权。此时进程进入阻塞态（等待态），其特征是：进程暂停执行，PCB 被移入阻塞队列，等待 I/O 完成（键盘输入就绪）。阻塞态的进程不会被调度，直到事件（输入完成）触发唤醒。

（2）main() 函数的代码位于只读代码段。scanf() 和 printf() 的功能需要通过执行驱动程序实现。

main 函数的代码位于只读代码段（代码段存储程序指令，通常设为只读以避免指令被意外修改）；它直接调用的 scanf() 和 printf() 需执行驱动程序，因为这两个函数涉及与硬件（键盘、显示器）的交互，而硬件的具体操作需通过操作系统内核中的驱动程序（硬件与操作系统的接口）来完成实际控制。

（3）ptr 分配在可读写数据段中。length 会被分配在用户栈中。ptr 指向的字符串位于运行时堆中。

① 题目中 ptr 的定义为 `char* ptr;`（位于 main() 函数外部，属于全局变量），且题目未提及分配在寄存器中。根据虚拟地址空间功能划分：可读写数据段（.data/.bss 段）专门用于存储全局变量和静态变量（非局部变量），这类变量的生命周期与程序运行周期一致，且允许在运行中修改值（例如，`ptr = (char*)malloc(...)` 对指针值的修改）；用户栈仅用于存储函数内的局部变量（例如，main() 内定义的临时变量），而 ptr 是全局变量，不属于局部变量范畴，因此不能存于用户栈。综上，ptr 作为全局指针变量，未分配至寄存器时，被分配在可读写数据区。

② length 是 main() 函数内定义的局部整型变量（`int length`），且题目明确“未被分配在寄存器中”。与 ptr 同理，用户程序的局部变量（非寄存器分配）均存储于用户栈，故 length 被分配在用户栈。

③ ptr 指向的内存由 `malloc(sizeof(char))` 动态分配。根据虚拟地址空间功能划分，malloc 是 C 语言中用于动态内存分配的函数，其分配的内存来自运行时堆（运行时堆专门用于存储程序运行过程中动态申请的内存，例如：malloc/new 分配的空间），需手动通过 free 释放，因此 ptr 指向的字符串位于运行时堆。

{/* 原书解析 malloc(sizeof(char)) 与题目 malloc(100) 不同，按原文保留。 */}

**【点评】** 冷门考点。结合具体的 C 语言代码，考查进程内存空间布局。此考点在此前的 408 真题中从未考过，出题角度比较出其不意。但本题即使不会，其实“连蒙带猜”也能拿到一些分。本题改编自陈海波、夏虞斌等编著的《现代操作系统原理与实现》（机械工业出版社）第 78 页“5.1.2 进程内存空间布局”小节。这本书作者阵容强大，由国内顶尖高校知名教授联合编写，理论结合实际，建议学有余力的考生可看下该教材。

</Solution>

<Question id="408-2025-47" type="essay" points={9} tags="来源:2025考研408, 科目:计算机网络, 考点:传播时延与GBN, 考点:子网划分">

某公司在承建国家重大工程项目时，工程部需要较长时间驻扎在偏远山区，工程部网络需要连接公司总部网络。假设综合考虑方案的技术可行性、安全性与经济成本等因素后，决定租用我国自主建设的天通一号卫星通信链路，连接工程部网络的路由器 R1 和公司总部网络的路由器 R2，如下图所示。S1 和 S2 为千兆以太网交换机；TR1 和 TR2 是卫星信号地面收发设备，实现全双工调制解调。天通一号卫星轨道高度是 36 000km，电磁波信号传播速度为 300 000 km/s。租用的卫星链路为 R1 和 R2 之间提供对称全双工信道，每个方向的数据传输速率为 200 kb/s。

![天通一号卫星通信网络拓扑](/img/2025-q47-topology.svg)

请回答下列问题。

（1）若忽略卫星信号中继以及 TR1 和 TR2 调制解调的时间开销，则 R1 到 R2 之间卫星链路的单向传播时延是多少？主机 H 向总部服务器传输数据时可以达到的最大吞吐量是多少？若忽略各层协议数据包的首部开销以及以太网内的传播时延，则主机 H 向总部服务器上传一个 4000B 大小的工程进度报告文件，至少需要多长时间？（3 分）

（2）现需要基于 GBN 滑动窗口协议为卫星链路设计单向可靠的数据链路层协议 SLP，支持 R1 向 R2 发送数据，SLP 数据帧长为 1500 B，忽略 ACK 帧长度。若要求 SLP 的单向信道利用率不低于 80%，则 SLP 的发送窗口至少为多少？SLP 帧的序号字段至少需要多少位？（3 分）

（3）若公司总部为工程部网络分配的 IP 地址空间是 10.10.10.0/24，工程部进一步将该 IP 地址空间分配给 3 个子网，其中生活区子网可分配 IP 地址数不少于 120 个，作业区子网和管理区子网可分配 IP 地址数均不少于 60 个，且主机 H 已正确配置了 IP 地址，则作业区子网、管理区子网和生活区子网的子网地址分别是什么（给出 CIDR 地址形式）？（3 分）

<Solution>

（1）单向传播时延 = 传播距离 ÷ 信号传播速度 = $2\times\frac{36000\times10^3}{300000\times10^3}=240\text{ms}$。

吞吐量（单位时间内传输的数据量）受链路带宽等因素限制。若链路带宽为 200kb/s（千比特每秒），在理想无拥塞、无差错的情况下，最大吞吐量等于链路带宽 = 200kb/s。

上传文件的最少时间 = 单向传播时延 + 数据传输时间 = $240\times10^{-3}+\frac{4000\times8}{200\times10^3}=400\text{ms}$。

（2）本题分为以下 3 步来计算：

① 计算发送周期。数据帧长 1500B = 12000 bit，数据传输率 = 200kb/s，发送一帧的发送时延 $t=\text{数据帧长}\div\text{数据传输率}=\frac{12000\text{bit}}{200\text{kb/s}}=0.06\text{s}$，往返传播延迟 RTT = $2\times\text{单向传播时延}=0.48\text{s}$。题目已说明“忽略 ACK 帧长度”，则发送周期 $T=\text{发送时延 }t+\text{往返传播延迟 RTT}=0.06\text{s}+0.48\text{s}=0.54\text{s}$。

② 求发送窗口。从发出一帧到收到该帧确认为止，一个完整的发送周期内，若发送窗口允许连续发送 $n$ 帧，则信道实际用于发送数据的时间为 $n\times t$，信道利用率 $U=\frac{n\times t}{T}=\frac{n\times0.06}{0.54}\ge80\%\Rightarrow n\ge7.2$。由于数据帧 n 必须为整数，所以 n 最小为 8。

③ 根据窗口大小确定帧序号比特数 k。帧序号用 k 比特表示时，序号空间大小为 $2^k$。滑动窗口协议中，发送窗口 + 接收窗口 $\le2^k$，接收窗口最少为 1，则发送窗口 $+1\le2^k$。上一步已经求出发送窗口 n 最小为 8，则 $2^k\ge8+1\xRightarrow{k\text{为正整数}}k\ge4$。

**【提示】** ⚠ 本小问改编自 2015 年 408 第 35 题，甚至连最后求出来的发送窗口、帧序号比特数的数值都是一样的。

（3）子网划分时有如下基本要求：① 各子网的 IP 地址范围不能交叉（否则会引发地址冲突）；

② 要遵循掩码规则：从主机号的高位到低位连续借用主机位来扩展网络位；

③ 划分的各子网之间的地址块连续。

生活区要求不少于 120 个，$2^7-2=126>120$，则其主机位至少为 7 位。

作业子网、管理区子网 IP 均不少于 60 个，$2^6-2=62>60$，对应主机位至少为 6 位。

其中一种适合分配为：作业区子网的子网地址为 10.10.10.64/26；管理区子网的子网地址为 10.10.10.0/26；生活区子网的子网地址为 10.10.10.128/25。
