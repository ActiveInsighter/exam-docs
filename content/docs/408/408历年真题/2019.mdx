<Question id="408-2019-01" type="single" number={1} points={2} tags="来源:2019考研408, 科目:数据结构, 考点:时间复杂度">

设 $n$ 是描述问题规模的非负整数，下列程序段的时间复杂度是（ ）。

```c
x = 0;
while(n >= (x+1)*(x+1))
    x = x+1;
```

<Option>

$O(\log_2 n)$

</Option>

<Option correct>

$O(n^{1/2})$

</Option>

<Option>

$O(n)$

</Option>

<Option>

$O(n^2)$

</Option>

<Solution>

**【解析】** 时间复杂度指基本语句执行次数的数量级。本题程序段的基本语句是 `x = x+1`，该基本语句的执行次数受到 while 循环条件 `n >= (x+1)*(x+1)` 的制约，可知基本语句最多执行次数不超过 $n^{1/2}$ 次，故时间复杂度为 $O(n^{1/2})$。故选 B。

**【点评】** 常规题。考查时间复杂度的常规题目。关于“时间复杂度”的定义，很多其他教辅讲的较难理解，考生可能对此不清不楚，建议考生查看竞成《数据结构考研复习全书》中的讲解，更好理解。

</Solution>

</Question>

<Question id="408-2019-03" type="single" number={3} points={2} tags="来源:2019考研408, 科目:数据结构, 考点:哈夫曼树">

对 $n$ 个互不相同的符号进行哈夫曼编码。若生成的哈夫曼树共有 115 个结点，则 $n$ 的值是（ ）。

<Option>

56

</Option>

<Option>

57

</Option>

<Option correct>

58

</Option>

<Option>

60

</Option>

<Solution>

**【解析】** 哈夫曼树中，$n$ 个叶结点保存 $n$ 个要编码的符号。① 根据哈夫曼树的性质，哈夫曼树中非叶子结点的度均为 2（不存在度为 1 的结点）。② 根据二叉树的性质，二叉树中度为 2 的结点数 = 叶子结点数 − 1 = $n-1$（该性质在教辅书中都有证明）。根据上述关系可得，哈夫曼树中的结点总数 = 叶子结点数（$n$）+ 度为 2 的结点数（$n-1$）$=2n-1=115$，可得 $n=58$。

**【点评】** 常规题。考查哈夫曼树的基本性质。

</Solution>

<Question id="408-2019-07" type="single" number={7} points={2} tags="来源:2019考研408, 科目:数据结构, 考点:排序算法">

选择一个排序算法时，除了算法的时空效率，下列因素中还需要考虑的是（ ）。

I. 数据的规模

II. 数据的存储方式

III. 算法的稳定性

IV. 数据的初始状态

<Option>

仅 III

</Option>

<Option>

仅 I、II

</Option>

<Option>

仅 II、III、IV

</Option>

<Option correct>

I、II、III、IV

</Option>

<Solution>

**【解析】** ① I 正确 ✓：选择排序算法跟数据规模有关。若数据规模较小，不同时间复杂度间（例如：$O(n^2)$ 和 $O(n\log_2 n)$）的排序算法性能相差不大；若数据规模过大，内存无法放下所有数据，则选择外部排序算法。

② II 正确 ✓：有些算法依赖顺序存储的随机访问能力，例如：希尔排序、快速排序、堆排序等，只适用于对顺序存储的数据进行排序。

③ III 正确 ✓：若排序时需求是要稳定性，则不能使用不稳定的排序算法。

④ IV 正确 ✓：排序算法的性能跟数据的初始状态有关，若数据初始时基本有序，则快速排序算法时间复杂度退化为 $O(n^2)$。故选 D。

**【点评】** 常规题。考查排序算法的基本概念。

</Solution>

</Question>

<Option>

</Option>

请设计一个空间复杂度为 $O(1)$ 且时间上尽可能高效的算法，重新排列 $L$ 中的各结点，得到线性表 $L'=(a_1,a_n,a_2,a_{n-1},a_3,a_{n-2},\cdots)$。要求：

(1) 给出算法的基本设计思想。

(2) 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

(3) 说明你所设计算法的时间复杂度。

<Solution>

**【解析】**

(1) 观察线性表 $L'=(a_1,a_n,a_2,a_{n-1},a_3,a_{n-2},\cdots)$，可发现 $L'$ 是由 $L_1=(a_1,a_2,a_3,\cdots)$ 和 $L_2=(a_n,a_{n-1},a_{n-2},\cdots)$ 合并而成。$L_1$ 是 $L$ 的前半段，$L_2$ 是 $L$ 后半段的倒置。所以，算法思想是：找到链表的中间结点，再将链表的后半部分原地倒置，之后从头部和中间依次各取一个结点交错插入重排链表。

(2) 代码实现如下：

```c
void change(NODE *L) {
    NODE *p = L, *q = L,*r;
    // 1、用快慢指针法找到中间结点：p每走一步，q走两步
    while (q->next != NULL) {
        p = p->next; // p走一步
        q = q->next;
        if (q->next != NULL) {
            q = q->next; // p每走一步，q走两步
        }
    } // while循环结束时，p指向中间结点，q指向尾结点
    // 2、倒置后半链表
    q=p->next; //结点q设置为后半段的首结点
    p->next=NULL;
    while (q != NULL) {
        r = q->next;
        q->next = p->next;
        p->next = q;
        q = r;
    }
    // 3、从头部和中间依次各取一个结点交错插入重排
    NODE *s = L->next; // s指向首结点
    q = p->next; // q指向当前的中间结点
    p->next = NULL;
    while (q != NULL) { // 交错插入
        r = q->next;
        q->next = s->next;
        s->next = q;
        s = q->next;
        q = r;
    }
}
```

(3) 算法的时间复杂度为 $O(n)$。

<Solution>

**【解析】**

本题属于哲学家进餐问题。有 $n$ 个哲学家、$n$ 只筷子和 $m$ 个碗，要实现对碗和筷子的互斥访问。定义互斥信号量 bowl，其初始值为 $\min(m,n-1)$。若碗的数量 $m$ 大于哲学家数量 $n$，则令 $\mathrm{bowl}=n-1$，确保最多只有 $n-1$ 个哲学家同时进餐，破坏死锁产生的循环等待条件。若碗的数量 $m$ 小于哲学家数量 $n$，则令 $\mathrm{bowl}=m$，防止所有哲学家都拿起一侧的筷子而无限等待另一侧筷子而产生死锁。定义互斥信号量 `chopsticks[n]`，设 `chopsticks[i]` 是哲学家左侧的筷子数，`chopsticks[(i+1)%n]` 是哲学家右侧的筷子数。注意哲学家进餐的桌子是圆桌，因此需要用到取模操作。每两个哲学家之间只有一支筷子，故对 `chopsticks[i]` 赋的初值为 1。哲学家进餐需要同时拿到碗和两侧的筷子，如果哲学家没有拿到碗，即使拿到筷子也无法进餐，所以先对 bowl 执行 P 操作，然后对两侧筷子执行 P 操作，方可进餐。哲学家进餐完毕后，分别对碗和两侧筷子执行 V 操作，三个 V 操作可以颠倒。题干中的 $n$ 位哲学家独立思考、独立就餐、没有协同关系，故无需定义同步信号量。程序具体实现如下：

```c
int amount_bowl = m, amount_chop = n-1;
//实现对碗这一互斥资源的互斥访问
semaphore bowl = min(amount_bowl, amount_chop);
semaphore chopsticks[n];//实现对筷子这一互斥资源的互斥访问
for(int i = 0; i<=amount_chop; i++){
    chopsticks[i] = 1;//每两个哲学家之间的筷子数量是一只
}
CoBegin{
    while(TRUE){//第i个哲学家
        进行思考;
        P(bowl);//（互斥）拿起一个碗
        P(chopsticks[(i+1) MOD n]);//（互斥）拿起右侧筷子
        P(chopsticks[i]);//（互斥）拿起左侧筷子
        开始就餐;
        V(chopsticks[(i+1) MOD n]);//（互斥）放下右侧筷子
        V(chopsticks[i]);//（互斥）放下左侧筷子
        V(bowl);//（互斥）放下一个碗
    }
}CoEnd
```

(1) 设备 1、设备 2 和设备 3 分别应选择路由器、以太网交换机、以太网交换机。同一网络设备间的连接使用以太网交换机，根据 H1～H4 的地址和网络前缀长度可得，H1 与 H2 在同一网络（192.168.1.0/26），H3 与 H4 同在另一网络（192.168.1.64/26）。所以，设备 2 和设备 3 是以太网交换机。连接不同网络应使用路由器，H1 与 H2、H3 与 H4 在不同网络，故设备 1 是路由器。此外，还可根据 R 接口地址 192.168.1.253/30，计算出子网有效地址数量是 2，只有当设备 1 是路由器，IP 地址才够分配，从这个角度也可确定设备 1 是路由器。

(2) 仅设备 1 需配置 IP 地址，IF1 地址为 192.168.1.254，IF2 地址为 192.168.1.1，IF3 地址为 192.168.1.65。根据主机 H1～H4 的默认网关地址，可知设备 1（路由器）的 IF2、IF3 接口地址。而通过 R 配置的接口地址 192.168.1.253/30，根据网络前缀长度可知有效地址数量为 2，因此 IF1 使用唯一剩下的 IP 地址 192.168.1.254。

(3) 地址块 192.168.0.0/16 内地址是私有地址，仅拥有私有地址的主机需要通过地址转换才可访问 Internet，所以 R 需要提供 NAT 服务。

(4) 127 = 0111 1111B，64 = 0100 0000B。所以，IP 地址 192.168.1.127 属于 H3 和 H4 所在网络 192.168.1.64/26（前 26 位网络号相同），并且是子网广播地址。由于设备 1 是路由器，它可以隔绝广播域，故只有主机 H4 能收到该数据报。
