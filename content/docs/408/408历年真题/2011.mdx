<Question id="408-2011-01" type="single" number={1} points={2} tags="来源:2011考研408, 科目:数据结构, 考点:时间复杂度">

设 $n$ 是描述问题规模的非负整数，下面程序片段的时间复杂度是（ ）。

```c
x = 2;
while(x < n/2)
    x = 2 * x;
```

<Option correct>

$O(\log_2 n)$

</Option>
<Option>

$O(n)$

</Option>
<Option>

$O(n\log_2 n)$

</Option>
<Option>

$O(n^2)$

</Option>

<Solution>

**【解析】** 时间复杂度是基本语句执行次数的数量级。本题的基本语句为“`x=2*x`”。若该语句执行第 $t+1$ 次时跳出循环，即 $t$ 取满足条件 $2^{t+1}<n/2$ 的最大值，则 $t=\lceil\log_2 n/2\rceil-1$。该等式与 $\log_2 n$ 同数量级，所以该程序段的时间复杂度为 $O(\log_2 n)$。故选 A。

**【点评】** 常规题。考查时间复杂度计算的常规题目。

</Solution>

</Question>


<Question id="408-2011-02" type="single" number={2} points={2} tags="来源:2011考研408, 科目:数据结构, 考点:栈">

元素 $a,b,c,d,e$ 依次进入初始为空的栈中，若元素进栈后可停留、可出栈，直到所有元素都出栈，则在所有可能的出栈序列中，以元素 $d$ 开头的序列个数是（ ）。

<Option>

3

</Option>
<Option correct>

4

</Option>
<Option>

5

</Option>
<Option>

6

</Option>

<Solution>

**【解析】** 入栈顺序为 $a,b,c,d,e$，由于第一个出栈元素为 $d$，根据栈后进先出的特点，则说明 $a,b,c$ 已入栈。当 $d$ 出栈后，下一个出栈的元素只能是 $e$ 或 $c$，再分类讨论：① 若下一个出栈元素是 $e$，则出栈序列为 $decba$；② 若下一个出栈元素是 $c$，则再次出栈元素只能是 $e$ 或 $b$：

- 若出栈元素为 $e$，则出栈序列为 $dceba$；
- 若出栈元素为 $b$，则出栈序列为 $dcbea$ 或 $dcbae$；

共有 4 种出栈序列。故选 B。

**【点评】** 常规题。考查出栈入栈操作（后进先出），注意分类讨论不要漏。另外，本题也等价于“将 $e$ 插入到序列 $c,b,a$ 中，共 $\_c\_b\_a\_$ 有 4 个位置可以插入”。

</Solution>

</Question>


<Question id="408-2011-03" type="single" number={3} points={2} tags="来源:2011考研408, 科目:数据结构, 考点:循环队列">

已知循环队列存储在一维数组 $A[0,\cdots,n-1]$ 中，且队列非空时 front 和 rear 分别指向队头元素和队尾元素。若初始时队列为空，且要求第 1 个进入队列的元素存储在 $A[0]$ 处，则初始时 front 和 rear 的值分别是（ ）。

<Option>

$0,0$

</Option>
<Option correct>

$0,n-1$

</Option>
<Option>

$n-1,0$

</Option>
<Option>

$n-1,n-1$

</Option>

<Solution>

**【解析】** 队列的进出规则为尾（rear）入头（front）出。① 队列非空时 rear 指向队尾元素。要求第 1 个入队元素存在 $A[0]$ 处，即 `(rear + 1) % n = 0`，解得 $rear=n-1$。② 队列非空时 front 指向队头元素。要求第 1 个入队元素存在 $A[0]$ 处，而入队操作不影响 front 的值，说明 front 初始为 0。故选 B。

**【点评】** 常规题。考查循环队列，比较“绕”，初学者容易出错。

</Solution>

</Question>


<Question id="408-2011-04" type="single" number={4} points={2} tags="来源:2011考研408, 科目:数据结构, 考点:完全二叉树">

若一棵完全二叉树有 768 个结点，则该二叉树中叶结点的个数是（ ）。

<Option>

257

</Option>
<Option>

258

</Option>
<Option correct>

384

</Option>
<Option>

385

</Option>

<Solution>

**【解析】** 
**【解法一】** 从根结点开始，按从上到下（逐层）、从左往右的顺序，给完全二叉树中的每个结点编号。则完全二叉树父结点和孩子结点之间的编号有如下关系：若孩子结点编号为 $x$，则其父亲结点编号为 $\lfloor x/2\rfloor$。根据上述关系，对含有 768 个结点的完全二叉树进行编号，根结点编号为 1，编号为 768 的结点的父结点编号为 $\lfloor768/2\rfloor=384$。根据完全二叉树的性质，编号从 1～384 的这些结点都是有孩子的，故叶结点个数为 $768-384=384$。故选 C。

**【解法二】** 设二叉树中度为 0、1、2 的结点数分别为 $n_0,n_1,n_2$，二叉树结点总数为 $n$。① 根据二叉树的性质，$n_0=n_2+1,n=2n_2+n_1+1$。② 该完全二叉树有 768 个结点，即 $n=2n_2+n_1+1=768$，则 $2n_2+n_1=767$。767 是奇数，$2n_2$ 是偶数，则 $n_1$ 只能是奇数。③ 又因为在完全二叉树中，度为 1 的结点数只能是 0 或 1，即：$n_1=0$ 或 1。因为 $n_1$ 是奇数，故 $n_1=1$。则 $n_2=(767-1)\div2=383$，$n_0=n_2+1=384$，即叶结点个数为 384。故选 C。

**【点评】** 常规题。考查完全二叉树的特性。解法二比较绕，建议使用解法一。

</Solution>

</Question>


<Question id="408-2011-05" type="single" number={5} points={2} tags="来源:2011考研408, 科目:数据结构, 考点:二叉树遍历">

若一棵二叉树的前序遍历序列和后序遍历序列分别为 1,2,3,4 和 4,3,2,1，则该二叉树的中序遍历序列不会是（ ）。

<Option>

1,2,3,4

</Option>
<Option>

2,3,4,1

</Option>
<Option correct>

3,2,4,1

</Option>
<Option>

4,3,2,1

</Option>

<Solution>

**【解析】** 
**【解法一】** 根据二叉树的中序遍历和任何一种其他遍历，可唯一确定一颗二叉树。可根据前序遍历和每个选项的中序遍历确定 4 棵二叉树，再逐一排查哪一棵二叉树的后序遍历与题设不符即可。选项 ABD 对应的二叉树如下图所示。故选 C。

![选项 ABD 对应的二叉树](/img/2011-q05-solution.svg)

**【解法二】** 先序遍历和后序遍历对子树结点的遍历顺序不变，即先遍历左子树结点，再遍历右子树结点。本题所给先序和后序序列完全相反，没有任何两个结点相对位置不变，可知二叉树中无度为 2 的结点，由此可知二叉树的深度为 4。通过先序遍历序列可知，1 为根结点。根据 2 的位置可以分为如下 2 种情况展开讨论：① 2 为 1 的左孩子结点，中序遍历时，先遍历结点 2 及 2 的孩子结点；② 2 为 1 的右孩子结点，中序遍历时，先遍历 1，再遍历 2 及 2 的孩子结点；对于以 2 为根结点的子树来说，也是同理。选项 ABD 都有可能。故选 C。

**【点评】** 常规题。考查二叉树的 3 种遍历算法，建议采用【解法一】通过排除法解题。【解法二】考虑的情况较多，容易漏，反而不如【解法一】稳当。此题难度不大，但做起来费时间。

</Solution>

</Question>

<Question id="408-2011-13" type="single" number={13} points={2} tags="来源:2011考研408, 科目:计算机组成原理, 考点:IEEE 754 浮点数">

float 型数据通常用 IEEE 754 单精度浮点数格式表示。若编译器将 float 型变量 $x$ 分配到一个 32 位浮点寄存器 FR1 中，且 $x=-8.25$，则 FR1 的内容是（ ）。

<Option correct>

C104 0000H

</Option>
<Option>

C242 0000H

</Option>
<Option>

C184 0000H

</Option>
<Option>

C1C2 0000H

</Option>

<Solution>

**【解析】** ① 第 1 步：转换成二进制。IEEE 754 表示 32 位单精度浮点数格式如下图所示。

| 1 位 | 8 位 | 隐藏 | 23 位 |
| --- | --- | --- | --- |
| 符号 | 阶码 | 1. | 尾数 |

$x=-8.25$，先处理数值部分 8.25。$8=1000\mathrm{B}$，$0.25=2^{-2}=0.01$，则 $8.25=1000.01\mathrm{B}$。

② 第 2 步：规格化。$8.25=1000.01\mathrm{B}$ 的规格化表示形式为 $1.00001\times2^3\mathrm{B}$。

- 指数为 3，加上偏移量 127：$3+127=130=10000010\mathrm{B}$。
- 尾数为 00001（尾数最高位的“1”被隐藏），后面补 18 个 0 凑够 23 位，即：00001000000000000000000。

③ 第 3 步：确定符号位。$x$ 为负数，符号位为 1。

④ 第 4 步：将符号位 1，指数位 1000 0010，尾数位 00001000000000000000000，组合成 32 位。

$$
\underbrace{1}_{\text{符号位}}\ ;\ \underbrace{10000010}_{\text{阶码（指数位）}}\ ;\ \underbrace{00001000000000000000000}_{\text{尾数位}}=1100\ 0001\ 0000\ 0100\ 0000\ 0000\ 0000\ 0000=\mathrm{C104\ 0000H}
$$

故选 A。

**【点评】** 高频考点。考查 IEEE 754 标准，此类题虽然计算量比较大，但解题套路固定。

</Solution>

</Question>


<Question id="408-2011-14" type="single" number={14} points={2} tags="来源:2011考研408, 科目:计算机组成原理, 考点:存储器">

下列各类存储器中，不采用随机存取方式的是（ ）。

<Option>

EPROM

</Option>
<Option correct>

CDROM

</Option>
<Option>

DRAM

</Option>
<Option>

SRAM

</Option>

<Solution>

**【解析】** 随机存取（Random Access）指可直接访问任意地址单元，访问时间与数据位置无关。

① A 选项：EPROM（Erasable Programmable Read-Only Memory），即可擦除可编程只读存储器，属于半导体存储器，支持随机存取。

② B 选项：CDROM（Compact Disc Read-Only Memory），即只读光盘，是一种基于光学存储技术的只读光盘，用户只能读取数据，无法写入、修改或擦除。断电后数据永久保存（非易失性），是早期计算机中最主流的大容量外部存储介质之一（如今已逐步被淘汰）。采用直接存取（半随机）+ 顺序读取的混合方式，不支持真正的随机存取。

③ C 选项：DRAM（Dynamic Random Access Memory），即动态随机存取存储器，断电数据丢失，需要定期刷新。是典型的半导体随机存取存储器（RAM），也是计算机主存（内存条）的主流类型之一。如今笔记本电脑常见的 DDR4 和 DDR5 内存条，都属于 DRAM 的衍生技术。

④ D 选项：SRAM（Static Random Access Memory），即静态随机存取存储器，是一种易失性、高速、随机存取的半导体存储器，是计算机中高速缓存（Cache）的核心载体。故选 B。

**【点评】** 概念题。考查常见的存储器和随机存取的概念。CDROM 较为冷门考点，容易出错。

</Solution>

</Question>


<Question id="408-2011-15" type="single" number={15} points={2} tags="来源:2011考研408, 科目:计算机组成原理, 考点:MAR 位数">

</Option>

- **无连接：** IP 协议在发送数据报前，不需要和对方建立连接。每个 IP 数据报独立路由，不同报文可能走不同路径到达目标。

- **数据报服务：** IP 层以数据报（分组）为单位传输，每个数据报都包含完整的源/目的 IP 地址，独立寻址。

OSI 参考模型中网络层既提供面向连接的服务，也提供无连接的服务。故选 A。

**【点评】** 概念题。考查 TCP/IP 参考模型的基本概念。

</Solution>

$$

- 若 $A_m=B_m$，则 $A_m$ 即为所求中位数。
- 若 $A_m<B_m$，则 $A_0\sim A_{m-1}<A_m<B_m<B_{m+1}\sim B_{n-1}$。$A_0\sim A_{m-1}$ 是 $S$ 中最小的部分（$S$ 中最靠前 $\lfloor n/2\rfloor$ 个元素），$B_{m+1}\sim B_{n-1}$ 是 $S$ 中最大的部分（$S$ 中最靠后的 $\lfloor n/2\rfloor$ 个元素），而中位数位于 $S$ 中第 $\lceil 2n/2\rceil=n$ 个位置，故中位数位于序列 $A_{m+1}\sim A_{n-1},B_0\sim B_{m-1}$（长度为 $n$）中。而 $A_{m+1}\sim A_{n-1}$ 和 $B_0\sim B_{m-1}$ 都是升序序列，将问题转化为求跟原来等价但规模更小的同类问题。
- 若 $A_m>B_m$，则 $B_0\sim B_{m-1}<B_m<A_m<A_{m+1}\sim A_{n-1}$。同理，则中位数位于序列 $A_0\sim A_{m-1},B_{m+1}\sim B_{n-1}$（长度为 $n$）中。

重复此过程，直到两个序列中位数相等或两个序列中都只含一个元素时为止，较小者即为所求中位数。

(2) 代码实现如下：

```c
int middle(int A[], int B[], int n) {
    int start1 = 0, end1 = n-1, start2 = 0, end2 = n-1, m1, m2;
    while (start1 != end1 || start2 != end2) {
        m1 = (start1 + end1)/2, m2 = (start2 + end2)/2;
        if (A[m1] == B[m2])
            return A[m1];
        if (A[m1] < B[m2]) {
            if ((start1 + end1) % 2 == 0) { // 说明序列长度n为奇数
                start1 = m1;
                end2 = m2;
            } else { // 说明序列长度n为偶数
                start1 = m1 + 1;
                end2 = m2;
            }
        }
        if (A[m1] > B[m2]) {
            if ((start1 + end1) % 2 == 0) { // 说明序列长度n为奇数
                end1 = m1;
                start2 = m2;
            } else { // 说明序列长度n为偶数
                end1 = m1;
                start2 = m2 + 1;
            }
        }
    }
    return A[start1] < B[start2] ? A[start1] : B[start2];
}
```

(3) 时间复杂度为 $O(\log_2 n)$，空间复杂度 $O(1)$。

**【真题溯源】** LeetCode 上有道类似的题（hard 难度），建议考生动手练习：[https://leetcode.cn/problems/median-of-two-sorted-arrays](https://leetcode.cn/problems/median-of-two-sorted-arrays)

**【提示】** 本题还有一种容易想到的暴力解思路，该思路跟二路归并排序算法思想一致：设两个等长升序序列为 A 和 B，长度均为 $n$。将 A、B 合并，合并后的序列长度为 $2n$，根据题目定义，中位数是第 $\lceil 2n/2\rceil=n$ 个位置的元素（即从小到大排序后的第 $n$ 小元素）。

<Question id="408-2011-43" type="essay" number={43} points={11} tags="来源:2011考研408, 科目:计算机组成原理, 考点:整数运算, 考点:溢出">

假定在一个 8 位字长的计算机中运行如下类 C 程序段：

```c
unsigned int x = 134;
unsigned int y = 246;
int m = x;
int n = y;
unsigned int z1 = x - y;
unsigned int z2 = x + y;
int k1 = m - n;
```

若编译器编译时将 8 个 8 位寄存器 R1～R8 分别分配给变量 $x$、$y$、$m$、$n$、$z1$、$z2$、$k1$ 和 $k2$。请回答下列问题。（提示：带符号整数用补码表示）

(1) 执行上述程序段后，寄存器 R1、R5 和 R6 的内容分别是什么（用十六进制表示）？

(2) 执行上述程序段后，变量 $m$ 和 $k1$ 的值分别是多少（用十进制表示）？

(3) 上述程序段涉及带符号整数加/减、无符号整数加/减运算，这四种运算能否利用同一个加法器辅助电路实现？简述理由。

(4) 计算机内部如何判断带符号整数加/减运算的结果是否发生溢出？上述程序段中，哪些带符号整数运算语句的执行结果会发生溢出？

<Solution>

**【解析】**

(1) ① 无符号整数 $x=134=10000110\text{B}=86\text{H}$，R1 中存放无符号整数 $x$ 的机器数，故 R1 的内容为 86H。

② 关于无符号数减法，这里用 2 种方法求解：

- 人类视角：$n$ 位无符号数减法计算公式为 $x-y=(x+(2^n-y))\bmod 2^n$。$x-y=(134+(2^8-246))\bmod 2^8=144\%256=144=10010000\text{B}=90\text{H}$，
- 计算机底层实现：计算机硬件只有加法器，没有减法器，用加法器实现所有减法。$x-y=[x-y]_{\text{补}}=[x]_{\text{补}}+[-y]_{\text{补}}$。无符号整数 $y=[y]_{\text{补}}=246=11110110\text{B}$。$[-y]_{\text{补}}$ 可由 $[y]_{\text{补}}$（1111 0110B）连同符号位在内，按位取反，末位加 1 而得。所以 $[-y]_{\text{补}}=00001010$。则 $x-y=1000\ 0110\text{B}+0000\ 1010\text{B}=1001\ 0000\text{B}=90\text{H}$。

R5 中存放无符号数 $x-y$ 的运算结果，故 R5 的内容为 90H。

③ $n$ 位无符号数加法计算公式为 $x+y=(x+y)\bmod 2^n$。在计算机底层中计算规则为：二进制位逐位相加，溢出进位直接舍弃。$x+y=1000\ 0110\text{B}+1111\ 0110\text{B}=(1)0111\ 1100\text{B}=7\text{CH}$（舍弃高位的进位 1），故 R6 的内容为 7CH。

(2) 有符号整数和无符号整数相互转换时，机器数不变，仅改变翻译（解释）方式。① $m$ 的机器数与 $x$ 的机器数相同，均为 86H = 1000 0110B（此为带符号整数的补码），转换成原码为 1111 1010B（除符号位外，各位取反，末位加 1），故 $m=-122$。② $k1$ 的机器数与 $z1$ 的机器数相同，均为 1001 0000B（此为带符号整数的补码），转换成原码为 1111 0000B（除符号位外，各位取反，末位加 1），故 $k1=-112$。

(3) 能。理由如下：① 编码基础：计算机中带符号整数采用补码表示，无符号整数本质就是正数的补码形式（原码）。② 减法统一变加法：无论有符号还是无符号减法，都可以统一转换为加法运算：$A-B=A+[-B]_{\text{补}}=A+(\sim B+1)$。$[-B]_{\text{补}}$ 可由 $[B]_{\text{补}}$ 连同符号位在内，按位取反，末位加 1 而得（即：$\sim B+1$）。③ 共用加法器硬件：以 $n$ 位逐位进位加法器为核心，配合取反控制电路即可实现。

- 加法：在输入端 $A$ 和 $B$，直接相加。
- 减法：对 B 按位取反，通过将“最低位进位输入端置 1”来实现“+1”操作。

④ 带符号整数加/减、无符号整数加/减运算，这四种运算共用加法器得到运算结果，仅溢出/进位标志的判断逻辑不同。运算主体电路完全复用，无需两套独立加法器。

- 无符号数：用进位标志 CF 判断溢出；
- 带符号数：用溢出标志 OF 判断溢出；

所以，现代 CPU 的 ALU 通常只设计一个加法器核心，配合少量控制逻辑，即可处理所有整数加减运算。

(4) 带符号整数加/减运算的溢出判断规则为：加法器完成加法操作时，若最高位的进位（符号位向外的进位）和次高位的进位（数值最高位向符号位的进位）不同，则发生溢出，否则不溢出。执行 $k2=m+n$ 时会发生溢出。因为 $1000\ 0110\text{B}+1111\ 0110\text{B}=(1)\ 0\ 111\ 1100\text{B}$，最高位的进位为 1（括号中的 1），次高位进位为 0，故发生溢出。

<Question id="408-2011-46" type="essay" number={46} points={7} tags="来源:2011考研408, 科目:操作系统, 考点:文件分配, 考点:FCB">

某文件系统为一级目录结构，文件的数据一次性写入磁盘，已写入的文件不可修改，但可多次创建新文件。请回答如下问题：

(1) 在连续、链式、索引三种文件的数据块组织方式中，哪种更合适？要求说明理由。为定位文件数据块，需要 FCB 中设计哪些相关描述字段？

(2) 为快速找到文件，对于 FCB，是集中存储好，还是与对应的文件数据块连续存储好？要求说明理由。

<Solution>

**【解析】**

(1) ① 连续结构更合适。理由如下：

- 因为文件的数据是一次性写入的，不需要修改，所以连续分配带来的磁盘碎片问题在这里完全不存在。
- 连续分配时数据块在磁盘上物理连续分布，支持随机访问，读取效率更高，节省了其他不必要的空间开销。相比链式分配，连续分配无需额外维护块指针，连续分配的访问效率也显著高于链式分配；相比索引结构，无需额外的索引块存储，结构更简单。

② 为定位文件数据块，需在 FCB 中加入：$\langle\text{起始块号，结束块号}\rangle$ 或 $\langle\text{起始块号，块数}\rangle$。

(2) 为了快速找到文件，将所有文件的 FCB 集中存储在磁盘的固定区域（例如：目录区）更好。理由如下：

- 定位速度快：查找文件时，只需读取 FCB 集中存储的区域，通过文件名匹配即可找到对应的 FCB，无需遍历文件数据块，显著提高查找速率。
- 目录结构简单：一级目录结构下，集中存储 FCB 可以直接按文件名索引，避免了与文件数据块连续存储时，需要额外扫描数据块来查找 FCB 的低效问题。
- 不破坏文件数据连续性：如果 FCB 与数据块连续存储，会破坏文件数据的物理连续性，影响文件数据的顺序读取效率；集中存储则完全不影响文件数据块的连续访问。

文件常见的几种物理分配方式总结如下。

| 分配方式 | 优点 | 缺点 |
| --- | --- | --- |
| 连续分配 | 顺序/随机访问快，结构简单，无额外开销 | 仅适合固定大小文件，动态文件易产生碎片 |
| 链式分配 | 无外部碎片，支持动态文件扩展 | 随机访问慢，需遍历链表，指针占空间 |
| 索引分配 | 支持随机访问，无碎片 | 索引块占额外空间，小文件开销大 |

**【点评】** 概念题。考查文件物理分配方式、FCB 存储方式，有一定灵活性。

</Solution>

**【解析】**

(1) ① 因为题目给出的是该主机进行 Web 请求的以太网帧，所以 Web 服务器的 IP 地址就是此以太网帧中 IP 分组目的地址。根据图 (c) 以太网帧结构：目的 MAC 地址（6B）+ 源 MAC 地址（6B）+ 类型（2B）+ 数据（IP 分组）。所以 IP 分组从第 $6+6+2=14$ 字节开始。根据图 (d) IP 分组头结构，目的 IP 地址之前有 16 字节。所以目的 IP 地址是从第 $14+16=30$ 字节开始的连续 4 个字节，即 40 aa 62 20H，转化成点分十进制为 64.170.98.32。即 Web 服务器的 IP 地址的 IP 地址是 64.170.98.32。

② 主机发送跨网段 IP 分组时，以太网帧的目的 MAC 地址是默认网关的 MAC 地址。根据图 (c) 以太网帧结构，该帧的目的 MAC 地址是前 6 字节，故该主机的默认网关的 MAC 地址是 00-21-27-21-51-ee。

**【提示】** 题目给出的以太网帧前 80B 的格式叫 hexdump 格式，是网络抓包、逆向工程、底层调试中最常用的数据查看方式。如下表所示，hexdump 格式由 3 部分组成：

- 偏移地址（Offset）：通常用 4 位或 8 位的十六进制数表示。标记该行数据在整个文件/数据块中的起始字节位置。每一行默认 16 字节。
- 十六进制数据区：每行固定 16 个字节，每字节用 2 位十六进制表示，中间用空格分隔；常按 8 字节分两组，便于阅读。
- ASCII 字符区：十六进制数据区的每个字节，直接对应 ASCII 区同一位置的字符，不可打印字符用点替代。作用是快速识别数据中的文本内容，方便定位关键信息。

| 偏移地址 | 十六进制数据区 | ASCII 字符区 |
| --- | --- | --- |
| `0000` | `00 21 27 21 51 ee` \| `00 15 c5 c1 5e 28` \| `08 00` \| `45 00` | `.!'!Q... ..^(..E.` |
| `0010` | `01 ef 11 3b 40 00 80 06 ba 9d 0a 02 80 64` \| `40 aa` | `...;@... .....d@.` |
| `0020` | `62 20` \| `04 ff` \| `00 50` \| `e0 e2 00 fa` \| `7b f9 f8 05` \| `50 18` | `b ...P.. ..{...P.` |
| `0030` | `fa f0 1a c4 00 00 47 45 54 20 2f 72 66 63 2e 68` | `......GE T /rfc.h` |
| `0040` | `74 6d 6c 20 48 54 54 50 2f 31 2e 31 0d 0a 41 63` | `tml HTTP /1.1..Ac` |

(2) 主机使用 ARP 协议（地址解析协议））确定目的 MAC 地址。ARP 请求是广播报文，因此封装 ARP 协议请求报文的以太网帧目的 MAC 地址是 FF-FF-FF-FF-FF-FF。

(3) 题目中说明 HTTP/1.1 协议以非流水线的持续连接方式工作。

- 持续连接指在同一个 TCP 连接上，可以进行多次 HTTP 请求与响应，传输多个对象，TCP 连接不会在每次请求响应后立即释放。
- 非流水线指客户端仅在收到前一个 HTTP 响应之后，才能发送下一个 HTTP 请求。

由图 (b) 图中“`tml HTTP`”可知，主机当前请求的是 rfc.html 文档，需要一个 RTT。rfc.html 引用了 5 个 JPEG 小图像，请求每个 JPEG 均需要一个 RTT。所以，浏览器总共需要 $1+5=6$ 个 RTT 才能接收到全部内容。

**【提示】** ① 本题的易错点是：发出图 (b) 所示的 Web 请求时，TCP 连接已经建立，不需要考虑 TCP 连接建立的时间（需要 1 个 RTT）。至少有如下 2 种方法能判断 TCP 连接已经建立：

- 图 (b) 最后一行的 ASCII 部分，出现了 `tml HTTP /1.1..Ac`，说明这是一个携带完整 HTTP 请求的报文。只要以太网帧中携带了应用层数据（例如：HTTP、FTP 等），就说明 TCP 连接已经建立完成。
- 分析图 (b) 的十六进制数据区，依次是以太网帧首部（14B）、IP 分组首部（20B）、TCP 首部。TCP 首部报文段格式如下图所示，TCP 首部的第 13B 以后的连续 12 位是保留字段和控制位，即 $018\text{H}=\overbrace{0000\ 00}^{\text{保留字段}}\ 01\ 10\ \overbrace{0}^{\text{SYN}}\ 0$，可知 SYN = 0，则说明 TCP 连接已建立。

![TCP 报文段格式](/img/2011-q47-tcp-header.svg)

② 仅在 TCP 连接建立阶段，主动发起连接（第 1 次握手）和被动响应连接（第 2 次握手）这两个报文中，SYN = 1。后续任何阶段 SYN 均为 0（第 3 次握手阶段也是）。

(4) 路由器 R 转发 IP 分组时，需要修改 IP 分组首部中的字段有：

- 生存时间（TTL）：每经过一个路由器，TTL 减 1。
- 头部校验和：因为 TTL 改变，需要重新计算 IP 分组首部校验和。
- 源 IP 地址：NAT 场景下，私有 IP 地址 10.2.128.100 会被转换为路由器 R 的公网 IP 地址 101.12.123.15。

**【提示】** 若 IP 分组超过链路 MTU（1500B），则需要分片，就会导致总长度、标志位、片偏移字段会被修改。在本题中 Web 请求的 IP 分组总长度为 $01\text{efH}=495<1500$，故无需分片。

**【点评】** 难题。① 本题综合性强，对跨考生非常不友好。图 (b) 中 hexdump 格式数据，若此前没见过，很可能无从下手。但这些在 408 考试中作为常识性的内容出现。建议考生自己动手，用 Wireshark 做网络抓包实验，亲自体验下。

② 在竞成《计算机网络考研复习全书》附录 3 中，列举了一些计网的常识性实验（包含 Wireshark 网络抓包等），帮助大家对抽象的协议、名词概念，有具体的认识。

③ 本题第 (1) 需要分析十六进制数据格式，难度大；第 (3) 问有陷阱，容易将 TCP 建立的 1 个 RTT 算进去，从而误算成 7 个 RTT。但第 (2)、(4) 问是简单的概念题，容易猜出来。故本题还是比较容易得一半分的。
