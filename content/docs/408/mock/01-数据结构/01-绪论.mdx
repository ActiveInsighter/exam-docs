## 1.2 算法和算法评价

### 1.2.1 算法的基本概念

<Question id="mock-ds-01-wd1-q01" type="single" points={2} tags="来源:王道·卷一, 考点:算法基本特征">

在下列选项中，不属于算法的主要特征的是（ ）。

<Option>有穷性</Option>
<Option>可行性</Option>
<Option>确定性</Option>
<Option correct>可读性</Option>

<Solution>

**核心结论**：可读性有助于理解、维护和交流算法，但不是判断一套步骤是否构成算法的必要条件。

**逐项判断：**

| 选项 | 判断 | 原因 |
| --- | --- | --- |
| A 有穷性 | 是算法特征 | 执行有限步后应结束。 |
| B 可行性 | 是算法特征 | 每一步应能由基本操作在有限时间内完成。 |
| C 确定性 | 是算法特征 | 给定状态和输入，每一步的含义应明确。 |
| D 可读性 | 不是必要特征 | 算法即使写得难懂，也不因此失去算法的基本属性。 |

还要掌握**输入、输出**：算法可以有零个输入，但应至少产生一个输出。判断此类题目时，先区分“算法的定义性特征”和“评价算法优劣的指标”。

<Callout type="idea" title="记忆方法">

**有穷、确定、可行、输入、输出**是基础；可读性、健壮性、可维护性等通常用于质量评价。

</Callout>

</Solution>
</Question>

### 1.2.2 算法效率的度量

<Question id="mock-ds-01-wd1-q02" type="single" points={2} tags="来源:王道·卷一, 考点:循环求和">

设 $n$ 是描述问题规模的正整数，则下列程序段的时间复杂度是（ ）。

```c
for (i = 1; i <= n; i++) {
    for (j = 2 * i; j <= n; j++) {
        y += i * j;
    }
}
```

<Option>$O(n)$</Option>
<Option correct>$O(n^2)$</Option>
<Option>$O(n\log_2 n)$</Option>
<Option>$O(\log_2 n)$</Option>

<Solution>

**核心结论**：内层循环只在 $i\le \lfloor n/2\rfloor$ 时执行，总次数为 $\Theta(n^2)$。

<Steps>
<Step>
### 确定有效的外层范围

内层从 $j=2i$ 开始，只有 $2i\le n$ 才会执行，因此有效的外层循环次数是 $m=\lfloor n/2\rfloor$。

</Step>
<Step>
### 累加内层次数

固定 $i$ 时，内层执行 $n-2i+1$ 次。于是

$$
\begin{aligned}
T(n)
&=\sum_{i=1}^{m}(n-2i+1)\\
&=m(n+1)-m(m+1)\\
&=m(n-m)=\Theta(n^2).
\end{aligned}
$$
</Step>
<Step>
### 对照选项

B 给出正确的增长量级。A、C、D 均不足以作为其渐近上界。

</Step>
</Steps>

<Callout type="warn" title="易错点">

不要看到内层初值为 $2i$ 就误判成 $\log n$。只有变量按倍数更新（如 `j *= 2`）时才可能出现对数级循环；这里更新是 `j++`。

</Callout>

</Solution>
</Question>

<Question id="mock-ds-01-wd2-q01" type="single" points={2} tags="来源:王道·卷二, 考点:递归树复杂度">

设二叉树共有 $n$ 个结点，则下列程序段的时间复杂度是（ ）。

```c
int maxFunc(TreeNode* root) {
    if (root == NULL) return 0;
    return max(maxFunc(root->left), maxFunc(root->right)) + 1;
}
```

<Option>$O(\log_2 n)$</Option>
<Option correct>$O(n)$</Option>
<Option>$O(n\log_2 n)$</Option>
<Option>$O(2^n)$</Option>

<Solution>

**核心结论**：该函数计算二叉树的高度。每个非空结点恰好被处理一次，所以时间复杂度为 $\Theta(n)$。

**按照结点数建立递推**：设左右子树规模为 $n_L,n_R$，满足 $n_L+n_R=n-1$，则

$$
T(n)=T(n_L)+T(n_R)+\Theta(1).
$$
把递归开销按每个结点汇总，共有 $n$ 个非空结点，另外的空指针调用数量也为 $O(n)$，故 $T(n)=\Theta(n)$。

**排除错误选项：**

- A：混淆了**平衡树的高度**和**遍历整棵树的工作量**。
- C：没有额外的逐层扫描，不能平白乘以 $\log n$。
- D：两条递归分支访问的是**互不重叠的左右子树**，不是对相同问题重复指数次计算。

<Callout type="idea" title="区分时间与空间">

时间复杂度为 $\Theta(n)$；递归栈的额外空间复杂度为 $\Theta(h)$，其中 $h$ 为树高。平衡树通常为 $O(\log n)$，退化为链时可达 $O(n)$。

</Callout>

</Solution>
</Question>

<Question id="mock-ds-01-wd3-q01" type="single" points={2} tags="来源:王道·卷三, 考点:倍增循环">

设 $n$ 是描述问题规模的正整数，则如下程序片段的时间复杂度是（ ）。

```c
i = 2;
while (i < n / 3)
    i = i * 3;
```

<Option correct>$O(\log_2 n)$</Option>
<Option>$O(n)$</Option>
<Option>$O(\sqrt[3]{n})$</Option>
<Option>$O(n^3)$</Option>

<Solution>

**核心结论**：循环变量每轮乘以 3，循环次数为 $\Theta(\log n)$，对数底数不同不影响渐近阶。

设执行 $k$ 轮后 $i_k=2\cdot3^k$。对于足够大的 $n$，退出条件为

$$
2\cdot3^k\ge \frac n3
\quad\Longrightarrow\quad
k\ge \log_3\frac n6.
$$
首次满足退出条件的 $k$ 约为 $\lceil\log_3(n/6)\rceil$，因此 $T(n)=\Theta(\log_3 n)=\Theta(\log_2 n)$。

B、C、D 均明显高于其实际的紧确增长阶。严格地说它们也能作为宽松的 $O$ 上界；本题按选择题惯例取**最紧的量级** A。

<Callout type="warn" title="判断技巧">

先写出循环后的变量表达式，再反解轮数。`i *= c`（$c>1$）常对应 $\log n$；`i *= i` 则是更快的增长，需要另行分析。

</Callout>

</Solution>
</Question>

<Question id="mock-ds-01-wd4-q01" type="single" points={2} tags="来源:王道·卷四, 考点:整数除法循环">

设 $n$ 是描述问题规模的正整数，则下列程序段的时间复杂度是（ ）。

```c
i = n * n;
while (i != 1)
    i = i / 2;
```

<Option correct>$O(\log_2 n)$</Option>
<Option>$O(n)$</Option>
<Option>$O(\sqrt n)$</Option>
<Option>$O(n^2)$</Option>

<Solution>

**核心结论**：按照题意使用正整数除法，$i$ 每轮减半直至 1，迭代次数为 $\Theta(\log n)$。

当 $n\ge2$ 时，第 $k$ 轮后的值为 $\lfloor n^2/2^k\rfloor$。首次达到 1 的次数为

$$
k=\lfloor\log_2(n^2)\rfloor
=\Theta(\log n).
$$
$n=1$ 时循环不执行。故应选 A（最紧的渐近阶）。

- B、C、D：把循环误认为按线性或多项式次数收缩。
- **容易忽视的边界**：C 语言中的正整数 `/ 2` 会向下取整；正数从大于 1 连续除以 2，必经过 1，不会跳到 0 才结束。

<Callout type="info" title="实现层面的前提">

这里按算法分析的常见抽象模型理解 `i = n*n`；若在固定宽度 C 整数中发生乘法溢出，原程序的行为就不再由此分析保证。

</Callout>

</Solution>
</Question>

<Question id="mock-ds-01-jc1-q01" type="single" points={2} tags="来源:竟成·模拟一, 考点:双指针摊还分析">

下列 C 语言函数的时间复杂度是（）。

```c
int getK(int k) {
    int cnt = 0, left = 0;
    for (int right = 0; right < n; right++) {
        if (nums[right] == 1) cnt++;
        while (left <= right && cnt >= k) {
            if (nums[left] == 1) cnt--;
            left++;
        }
    }
}
```

<Option>$O(\log_2 n)$</Option>
<Option correct>$O(n)$</Option>
<Option>$O(n\log_2 n)$</Option>
<Option>$O(n^2)$</Option>

<Solution>

**核心结论**：嵌套 `while` 不代表二重循环必为平方级；这里 `left`、`right` 各自至多向前移动 $n$ 次，因此总时间为 $\Theta(n)$。

<Tabs items={['指针计数法', '摊还分析法']}>
<Tab value="指针计数法">
- `right` 从 0 到 $n-1$，移动 $n$ 次。
- `left` 只做 `left++`，不可能回退；由 `left <= right` 可知它在整个算法中至多前进 $n$ 次。
- 每次移动执行常数工作，合计不超过 $O(2n)$。

</Tab>
<Tab value="摊还分析法">
给每个数组下标分配两枚“访问代币”：一枚用于被 `right` 扫描，一枚用于被 `left` 扫描。任一元素在每个方向都只会被处理一次，因此总代价为 $O(n)$。又因为外层无论输入如何都遍历 $n$ 次，故为 $\Theta(n)$。

</Tab>
</Tabs>

A、C 不符合实际访问次数；D 是机械地将两层循环上界相乘，没有考虑指针单调性。

<Callout type="warn" title="题面代码细节">

原函数依赖外部的 `n`、`nums`，并且声明返回 `int` 却未给出 `return`；这些是代码完整性问题，不影响该循环结构的时间复杂度分析。

</Callout>

</Solution>
</Question>

<Question id="mock-ds-01-jc2-q01" type="single" points={2} tags="来源:竟成·模拟二, 考点:递归空间复杂度">

C 语言函数 `f1`、`f2` 是求解斐波那契数的两种方式，则 `f1`、`f2` 的空间复杂度分别为（）。

```c
int f1(int n) {
    if (n == 1) return 1;
    if (n == 0) return 0;
    return f1(n - 1) + f1(n - 2);
}
int f2(int n) {
    int dp[n + 2], i;
    dp[0] = 0; dp[1] = 1;
    for (i = 2; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    return dp[n];
}
```

<Option>$O(n)$、$O(1)$</Option>
<Option>$O(2^n)$、$O(1)$</Option>
<Option correct>$O(n)$、$O(n)$</Option>
<Option>$O(2^n)$、$O(n)$</Option>

<Solution>

**核心结论：**`f1` 的空间主要是递归调用栈，`f2` 的空间主要是动态长度数组，两者都是 $\Theta(n)$。

| 函数 | 占用空间的原因 | 最大同时占用 |
| --- | --- | --- |
| `f1` | 最深路径依次计算 `f1(n)`,`f1(n-1)`,… | $\Theta(n)$ 个栈帧 |
| `f2` | 局部数组 `dp[n+2]` | $\Theta(n)$ 个整数单元 |

**为什么 `f1` 的空间不是指数级**？虽然 `f1(n-1)` 和 `f1(n-2)` 引发了大量重复计算，但它们在常规单线程递归执行中并非同时完整驻留调用栈。**空间看最大递归深度，时间看累计调用次数。**

A 错把数组空间当常数；B、D 错把递归树的结点总数当最大栈深度。

<Callout type="idea" title="进一步优化">

`f2` 只需要前两项，可用两个变量滚动更新，把辅助空间优化到 $O(1)$；但**题中原代码**确实分配了 $O(n)$ 的数组，不可按优化后的版本作答。

</Callout>

</Solution>
</Question>

<Question id="mock-ds-01-jc5-q01" type="single" points={2} tags="来源:竟成·模拟五, 考点:平方增长循环">

下列程序段的时间复杂度可能是（）。

```c
int sum = 0;
for (int i = 2; i <= n; i *= i)
    for (int j = 1; j <= i; j++)
        sum++;
```

<Option>$O(\log_2 n)$</Option>
<Option correct>$O(n)$</Option>
<Option>$O(n\log_2 n)$</Option>
<Option>$O(n^2)$</Option>

<Solution>

**按常规命题意图选择 B**：这段程序总工作量具有 $O(n)$ 的线性上界，并且该上界是四个选项中的最紧者。

外层取值为
$$
2,\;4,\;16,\;256,\;\ldots,\;2^{2^t}.
$$
设最后一项为 $M\le n$，则内层执行次数之和为

$$
T(n)=2+4+16+\cdots+M.
$$
前面的项增长迅速，且可由几何级数上界控制：
$$
M\le T(n)<2M\le2n,
$$
因此 $T(n)=O(n)$。在 $n=M$（恰好为该序列某项）时，还有 $T(n)=\Theta(n)$。

<Callout type="warn" title="本题原表述有歧义">

严格说，**不能对所有 $n$ 宣称 $T(n)=\Theta(n)$**：例如 $n$ 位于两个相邻平方项之间、远大于上一项时，$T(n)$ 可能远小于 $n$。而且 C、D 也都是宽松的 $O$ 上界。将选项理解为“最紧的常用 $O$ 上界”才有唯一答案 B。

此外，真实 C 代码的 `int i` 在不断平方时可能溢出；复杂度结论默认忽略整数溢出。

</Callout>

</Solution>
</Question>

<Question id="mock-ds-01-jc7-q01" type="single" points={2} tags="来源:竟成·模拟七, 考点:分治递归空间">

假设下列程序段的所有输入都是合法的，则下列程序段的空间复杂度是（）。

```c
int fun(int *arr, int m, int n) {
    if (m == n)
        return 1;
    else {
        int mid = (m + n) / 2;
        return fun(arr, m, mid) + fun(arr, mid + 1, n);
    }
}
```

<Option correct>$O(\log_2 n)$</Option>
<Option>$O(n)$</Option>
<Option>$O(n\log_2 n)$</Option>
<Option>$O(2^n)$</Option>

<Solution>

**核心结论**：每层将区间一分为二，最大递归深度为 $\Theta(\log L)$，其中区间长度 $L=n-m+1$；每层只用常数额外空间。

递归栈空间可以写成：
$$
S(L)=S(\lceil L/2\rceil)+O(1),
\qquad S(1)=O(1).
$$
因此 $S(L)=\Theta(\log L)$。当题目默认 $m$、$n$ 为常见数组合法边界且 $0\le m\le n$ 时，写为 $O(\log n)$，选 A。

**为什么不是 $O(n)$**？左递归与右递归顺序求值。左子树结束并返回后，其深层栈帧已释放，才会展开右子树；需要统计的是**峰值同时驻留**而非总调用次数。

B、C、D 误将调用总量或树的节点总数与空间开销混淆。

<Callout type="info" title="符号精度">

严格的空间界是 $O(\log(n-m+1)+1)$，这样也覆盖只有一个元素的区间。将区间右端点 $n$ 直接代替长度是题目惯用的简化写法。

</Callout>

</Solution>
</Question>
