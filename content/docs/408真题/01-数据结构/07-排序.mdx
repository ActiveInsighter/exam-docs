# 第 7 章 排序


## 7.1 插入类排序

<ExamQuestion>

1. 【2012】对同一待排序序列，分别进行折半插入排序和直接插入排序，两者之间可能的不同之处是（ ）。

<ExamChoices>
<ExamOption>A. 排序总趟数</ExamOption>
<ExamOption>B. 元素的移动次数</ExamOption>
<ExamOption>C. 使用辅助空间的数量</ExamOption>
<ExamOption>D. 元素之间的比较次数</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>D</ExamAnswer>

<ExamExplanation>
折半插入排序与直接插入排序的区别仅在于**寻找插入位置的方法不同**。

- 两者都需要进行 $\displaystyle n-1$ 趟插入，排序总趟数相同；
- 找到插入位置后，元素后移的范围相同，因此移动次数相同；
- 两者都只需要常数个辅助单元，空间复杂度均为 $\displaystyle O(1)$；
- 折半插入排序利用折半查找确定插入位置，比较次数约为 $\displaystyle O(n\log n)$，而直接插入排序最坏情况下的比较次数为 $\displaystyle O(n^2)$。

因此可能不同的是元素之间的比较次数。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

2. 【2014】用希尔排序方法对一个数据序列进行排序时，若第1趟排序结果为 `{9、1、4、13、7、8、20、23、15}`，则该趟排序采用的增量（间隔）可能是（ ）。

<ExamChoices>
<ExamOption>A. 2</ExamOption>
<ExamOption>B. 3</ExamOption>
<ExamOption>C. 4</ExamOption>
<ExamOption>D. 5</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>B</ExamAnswer>

<ExamExplanation>
希尔排序完成某一增量 $\displaystyle d$ 的一趟排序后，各个相距 $\displaystyle d$ 的子序列都应当有序。

当 $\displaystyle d=3$ 时，各组分别为：

- 下标 $\displaystyle 1,4,7$：$\displaystyle 9,13,20$，有序；
- 下标 $\displaystyle 2,5,8$：$\displaystyle 1,7,23$，有序；
- 下标 $\displaystyle 3,6,9$：$\displaystyle 4,8,15$，有序。

因此该趟采用的增量可能是 $\displaystyle 3$。

其余增量均可找到组内逆序，例如 $\displaystyle d=2$ 时子序列 $\displaystyle 9,4,7,20,15$ 并非有序。
</ExamExplanation>

</ExamSolution>

## 7.2 交换类排序

<ExamQuestion>

1. 【2010】采用递归方式对顺序表进行快速排序。下列关于递归次数的叙述中，正确的是（ ）。

<ExamChoices>
<ExamOption>A. 递归次数与初始数据的排列次序无关</ExamOption>
<ExamOption>B. 每次划分后，先处理较长的分区可以减少递归次数</ExamOption>
<ExamOption>C. 每次划分后，先处理较短的分区可以减少递归次数</ExamOption>
<ExamOption>D. 递归次数与每次划分后得到的分区的处理顺序无关</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>D</ExamAnswer>

<ExamExplanation>
快速排序每次划分后，对左右两个子区间分别递归。递归调用次数由每次划分产生的子区间结构决定，与先递归处理左区间还是右区间无关。

初始序列的排列次序会影响枢轴最终位置，从而影响递归树的形态和递归深度，因此A错误。先处理较长或较短分区只会改变递归执行顺序，在普通递归实现中不会改变递归调用总次数，因此B、C错误。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>

2. 【2011】为实现快速排序算法，待排序序列宜采用的存储方式是（ ）。

<ExamChoices>
<ExamOption>A. 顺序存储</ExamOption>
<ExamOption>B. 散列存储</ExamOption>
<ExamOption>C. 链式存储</ExamOption>
<ExamOption>D. 索引存储</ExamOption>
</ExamChoices>

<ExamSolution>

<ExamAnswer>A</ExamAnswer>

<ExamExplanation>
快速排序的划分过程需要从区间两端向中间扫描，并频繁交换元素。顺序存储支持按下标随机访问，能够在 $\displaystyle O(1)$ 时间内访问任意位置的元素，最适合实现快速排序。

链式存储不便于从区间尾部向前扫描，也不能按下标随机访问，因此不适合快速排序。
</ExamExplanation>

</ExamSolution>

3. 【2014】下列选项中，不可能是快速排序第2趟排序结果的是（ ）。

<ExamChoices>

</ExamChoices>

<ExamSolution>

<ExamAnswer>C</ExamAnswer>

<ExamExplanation>
快速排序一次划分后，枢轴元素会到达最终位置，即枢轴左侧元素都不大于枢轴，右侧元素都不小于枢轴。第二趟还会对第一趟产生的子区间继续划分，因此结果中应能找到符合相应划分层次的枢轴位置。

对C：$\displaystyle 3,2,5,4,7,6,9$ 中只有 $\displaystyle 9$ 满足“左边全部小于它、右边全部大于它”，可以作为第一趟枢轴。但若第一趟枢轴为 $\displaystyle 9$，第二趟必须对其左侧的六个元素完成一次划分，而序列 $\displaystyle 3,2,5,4,7,6$ 中不存在任何一个已经到达最终位置的枢轴，因此不可能是第二趟结果。

其余选项均可构造相应的两趟划分过程。
</ExamExplanation>

</ExamSolution>

7. 【2016】已知由 $\displaystyle n(n\ge2)$ 个正整数构成的集合 $\displaystyle A=\{a_k\mid 0\le k<n\}$，将其划分为两个不相交的子集 $\displaystyle A_1$ 和 $\displaystyle A_2$，元素个数分别是 $\displaystyle n_1$ 和 $\displaystyle n_2$，$\displaystyle A_1$ 和 $\displaystyle A_2$ 中元素之和分别为 $\displaystyle S_1$ 和 $\displaystyle S_2$。设计一个尽可能高效的划分算法，满足 $\displaystyle |n_1-n_2|$ 最小且 $\displaystyle |S_1-S_2|$ 最大。要求：

(1) 给出算法的基本设计思想；  
(2) 根据设计思想，采用C或C++语言描述算法，关键之处给出注释；  
(3) 说明你所设计算法的时间复杂度和空间复杂度。

<ExamSolution>

<ExamAnswer>令 $\displaystyle k=\lfloor n/2\rfloor$。将集合中较小的 $\displaystyle k$ 个元素划入 $\displaystyle A_1$，其余较大的 $\displaystyle n-k$ 个元素划入 $\displaystyle A_2$。</ExamAnswer>

<ExamExplanation>
（1）基本设计思想

要使 $\displaystyle |n_1-n_2|$ 最小：

- 当 $\displaystyle n$ 为偶数时，两组元素数均为 $\displaystyle \dfrac n2$；
- 当 $\displaystyle n$ 为奇数时，两组元素数分别为 $\displaystyle \lfloor n/2\rfloor$ 和 $\displaystyle \lceil n/2\rceil$。

在元素个数已经确定的条件下，要使两组元素和之差最大，应把较小的一半放入一组，把较大的一半放入另一组。

由于所有元素均为正整数，当 $\displaystyle n$ 为奇数时，应让元素较多的一组取得较大的 $\displaystyle \lceil n/2\rceil$ 个元素，这样可以进一步增大两组元素和之差。

不必将全部元素完全排序，只需利用快速选择算法，使数组中下标 $\displaystyle 0\sim k-1$ 的元素为较小的 $\displaystyle k$ 个元素，其余为较大的 $\displaystyle n-k$ 个元素。

（2）C语言描述

```c
#include <stdlib.h>

static void swap(int *x, int *y) {
    int t = *x;
    *x = *y;
    *y = t;
}

/* 随机化Lomuto划分，返回枢轴最终下标 */
static int partition(int a[], int left, int right) {
    int r = left + rand() % (right - left + 1);
    swap(&a[r], &a[right]);

    int pivot = a[right];
    int i = left;
    for (int j = left; j < right; ++j) {
        if (a[j] < pivot) {
            swap(&a[i], &a[j]);
            ++i;
        }
    }
    swap(&a[i], &a[right]);
    return i;
}

/* 使下标k处为按非降序排列后应处于该位置的元素 */
static void quickSelect(int a[], int left, int right, int k) {
    while (left < right) {
        int p = partition(a, left, right);
        if (p == k)
            return;
        if (p < k)
            left = p + 1;
        else
            right = p - 1;
    }
}

/* 划分后：a[0..k-1]属于A1，a[k..n-1]属于A2 */
void divideSet(int a[], int n, long long *S1, long long *S2) {
    int k = n / 2;               // A1取较小的floor(n/2)个元素
    quickSelect(a, 0, n - 1, k);

    *S1 = 0;
    *S2 = 0;
    for (int i = 0; i < k; ++i)
        *S1 += a[i];
    for (int i = k; i < n; ++i)
        *S2 += a[i];
}
```

若有相同关键字，快速选择得到的两个区域中可能任取若干相同元素，但不会影响两组元素个数和最大和差。

（3）复杂度

采用随机化快速选择：

- 期望时间复杂度为 $\displaystyle O(n)$；
- 最坏时间复杂度为 $\displaystyle O(n^2)$；
- 上述迭代实现的辅助空间复杂度为 $\displaystyle O(1)$。
</ExamExplanation>

</ExamSolution>

10. 【2021】已知某排序算法如下：

```c
void cmpCountSort(int a[], int b[], int n) {
    int i, j, *count;

    count = (int *)malloc(sizeof(int) * n);

    for (i = 0; i < n; i++) count[i] = 0;

    for (i = 0; i < n - 1; i++)
        for (j = i + 1; j < n; j++)
            if (a[i] < a[j]) count[j]++;
            else count[i]++;

    for (i = 0; i < n; i++) b[count[i]] = a[i];

    free(count);
}
```

请回答下列问题：

(1) 若有 `int a[] = {25, -10, 25, 10, 11, 19}, b[6]`，则调用 `cmpCountSort(a, b, 6)` 后数组b中的内容是什么？  
(2) 若a中含有n个元素，则算法执行过程中，元素之间的比较次数是多少？  
(3) 该算法是稳定的吗？若是，则阐述理由；否则，修改为稳定排序算法。

<ExamSolution>

<ExamAnswer>
(1) `b = {-10, 10, 11, 19, 25, 25}`。  
(2) 比较次数为 $\displaystyle \dfrac{n(n-1)}2$。  
(3) 原算法不稳定。将判断条件改为 `if (a[i] <= a[j]) count[j]++; else count[i]++;` 后可实现稳定排序。
</ExamAnswer>

<ExamExplanation>
`count[i]` 统计元素 `a[i]` 在最终升序序列中应处的位置。对于任意一对元素，较大者的计数增加1。

对输入中的两个 $\displaystyle 25$ 标记为 $\displaystyle 25_a$ 和 $\displaystyle 25_b$，其中 $\displaystyle 25_a$ 在前。原程序比较这两个相等元素时，条件 `a[i] < a[j]` 为假，因此令前面的 $\displaystyle 25_a$ 的计数增加，最终两个相等元素的顺序变为

$\displaystyle 25_b,25_a$，故算法不稳定。虽然只观察数值时数组仍为

`{-10, 10, 11, 19, 25, 25}`，但两个相等记录的相对次序已经改变。

双重循环对每一对元素恰比较一次，因此比较次数为

$\displaystyle \binom n2=\dfrac{n(n-1)}2$。

稳定版本的核心代码为：

```c
for (i = 0; i < n - 1; ++i) {
    for (j = i + 1; j < n; ++j) {
        if (a[i] <= a[j])
            count[j]++;   // 相等时让后出现的元素排在后面
        else
            count[i]++;
    }
}
```

当 `a[i] == a[j]` 且 `i < j` 时，增加后者的计数，使原来靠前的相等元素仍排在前面，从而保证稳定性。
</ExamExplanation>

</ExamSolution>

</ExamQuestion>
