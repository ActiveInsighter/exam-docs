## 6.1 网络应用模型

### 6.1.1 客户/服务器模型

1. **【竟成·模拟七-40】** 下列关于网络应用模型的叙述中，错误的是（）。

<div className="choice-options">
<div className="choice-option-row">A. DNS、FTP均基于C/S模式进行设计</div>
<div className="choice-option-row">B. C/S模型中，用户之间必须通过服务器进行通信</div>
<div className="choice-option-row">C. P2P模型中，每个节点既可以充当客户端又可以充当服务器</div>
<div className="choice-option-row">D. P2P模型相较于C/S模型更加安全和稳定</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** D

**解析：** A 正确。DNS 由客户程序向域名服务器发起查询，FTP 由 FTP 客户端向 FTP 服务器请求服务，二者均采用客户/服务器模型。

B 正确。在典型 C/S 模型中，客户之间通常不直接通信，而是分别与服务器交互，由服务器集中提供资源和服务。

C 正确。P2P 模型中的对等方既可以请求资源，也可以向其他节点提供资源，因此一个节点可同时充当客户端和服务器。

D 错误。P2P 模型去中心化、可扩展性较好，但节点动态加入和退出，管理与安全控制更加困难，其安全性和稳定性通常不如集中管理的 C/S 模型。

因此选择 D。

</details>

### 6.2.3 域名解析过程

3. **【竟成·模拟六-40】** 假设所有的域名服务器均采用递归方式进行域名查询，当主机想要解析域名www.aaa.bbb.com时，本地域名服务器发送的DNS查询的最少和最多次数为（）。

<div className="choice-options">
<div className="choice-option-row">A. 0，1 &emsp;&emsp; B. 0，4 &emsp;&emsp; C. 1，1 &emsp;&emsp; D. 1，4</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** A

**解析：** 若本地域名服务器的高速缓存中已经保存了该域名的有效解析结果，则它可直接向主机返回答案，不需要向其他域名服务器发送查询，因此最少次数为 $\displaystyle 0$。

若本地域名服务器没有缓存结果，由于题目规定所有域名服务器均采用递归查询，本地域名服务器只需向上级域名服务器（通常是根域名服务器）发送一次递归查询。后续对顶级域名服务器、权限域名服务器的查询由接到请求的域名服务器继续完成，而不是由本地域名服务器逐个发送。

因而本地域名服务器最多只发送 $\displaystyle 1$ 次 DNS 查询，选择 A。

</details>

## 6.3 文件传输协议

### 6.3.1 FTP的工作原理

4. **【王道·卷七-Q40】** 某同学利用校园网访问因特网，在从该同学打开计算机电源到使用命令ftp连通到文件服务器202.38.70.25的过程中，（  ）协议可能未用到。

<div className="choice-options">
<div className="choice-option-row">A. IP &emsp;&emsp; B. ICMP &emsp;&emsp; C. ARP &emsp;&emsp; D. DHCP</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** B

**解析：** IP 是主机在互联网中传送分组的基础协议，连接远程 FTP 服务器必须使用，A 不选。

主机通常需要通过 ARP 获得默认网关或同一局域网目标的 MAC 地址，因此 ARP 通常会被使用，C 不选。

主机开机接入校园网时，可能通过 DHCP 自动获取 IP 地址、子网掩码、默认网关等网络参数，因此 DHCP 也可能被使用，D 不选。

ICMP 主要用于差错报告和网络探测。若整个连接过程正常，且用户没有执行 `ping` 等诊断操作，则可以完全不产生 ICMP 报文。因此“可能未用到”的是 ICMP，选择 B。

</details>

<div className="choice-options">

<summary>查看答案与解析</summary>

**答案：** C

**解析：** A 正确。FTP 由客户端向 FTP 服务器发起文件传输请求，采用 C/S 模型。

### 6.5.2 超文本传输协议

6. **【王道·卷五-Q40】** 在下列关于客户端/服务器模型的描述中，错误的是（  ）。
I. 客户端和服务器必须都事先知道对方的地址，以提供请求和服务
II. HTTP基于客户端/服务器模型，客户端和服务器端的默认端口号都是80
III. 浏览器显示的内容来自服务器
IV. 客户端是请求方，即使连接建立后，服务器端也不能主动发送数据

<div className="choice-options">
<div className="choice-option-row">A. I和IV &emsp;&emsp; B. II和IV &emsp;&emsp; C. I、II和IV &emsp;&emsp; D. 只有IV</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** C

**解析：** I 错误。客户端在发起连接前必须知道服务器的地址和服务端口，但服务器无须预先知道某个具体客户端的地址；客户端连接到达后，服务器即可从连接信息中获知对端地址。

II 错误。HTTP 服务器的默认端口是 80，而客户端通常使用操作系统临时分配的动态端口，并非固定使用 80 号端口。

III 正确。浏览器作为客户端，请求服务器上的网页及相关对象，并将服务器返回的内容进行解释和显示。

IV 错误。客户端通常负责主动建立连接和发起请求，但连接建立后，服务器能够向客户端发送响应数据；在支持相应机制的协议版本或应用中，服务器还可主动推送数据。因此“服务器端不能主动发送数据”的绝对表述错误。

所以错误的是 I、II、IV，选择 C。

</details>

8. **【竟成·模拟三-40】** 假设主机H采用非流水线式的HTTP/1.1协议进行工作，一次请求-响应的时间为RTT，主机请求访问web服务器的jingcheng408.html文件，文件的大小为1MSS，同时文件引用了4个JPEG图像，图像的大小为0.5MSS，从H发出TCP连接请求到收到所有的文件为止，需要时间为（）。

<div className="choice-options">
<div className="choice-option-row">A. 5RTT &emsp;&emsp; B. 6RTT &emsp;&emsp; C. 3RTT &emsp;&emsp; D. 4RTT</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** B

**解析：** HTTP/1.1 默认使用持续连接，但题目明确采用非流水线方式，即只有收到前一个对象的响应后，才能发送下一个对象的请求。

从发送 TCP 连接请求到完成三次握手需要 $\displaystyle 1\mathrm{RTT}$。随后：

1. 请求并收到 HTML 基础文件需要 $\displaystyle 1\mathrm{RTT}$。
2. HTML 中引用 4 个 JPEG 图像，非流水线方式下必须依次请求，每个图像各需 $\displaystyle 1\mathrm{RTT}$，共 $\displaystyle 4\mathrm{RTT}$。

文件均不超过 $\displaystyle 1\mathrm{MSS}$，题目以一次请求—响应为一个 RTT，故忽略额外的数据传输时间。总时间为：

$$
\displaystyle
1+1+4=6\mathrm{RTT}
$$

因此选择 B。

</details>

9. **【竟成·模拟四-40】** 某浏览器发出的HTTP请求如下，下列叙述中错误的是（）。

```
POST /index.htm HTTP/1.1
Host: www.test.edu.cn
Connection: keep-alive
Cookie: 123456
```

<div className="choice-options">
<div className="choice-option-row">A. HTTP本身有连接 &emsp;&emsp; B. 该浏览器期望建立持续连接</div>
<div className="choice-option-row">C. 服务器可以识别该浏览器用户身份 &emsp;&emsp; D. 该浏览器期望给服务器添加信息</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** A

**解析：** A 错误。HTTP 是应用层协议，其报文传输依赖下层 TCP 连接；连接由 TCP 建立和维护，不能说 HTTP 协议本身建立了传输连接。

B 正确。`Connection: keep-alive` 表示浏览器希望保持底层 TCP 连接，以便后续继续发送 HTTP 请求，避免频繁建立新连接。

C 正确。请求中带有 `Cookie: 123456`，服务器可据此识别或关联该浏览器的会话与用户状态。

D 正确。`POST` 方法通常用于向服务器提交数据、增加信息或触发服务器端处理，与仅获取资源的 `GET` 方法不同。

因此选择 A。

</details>
