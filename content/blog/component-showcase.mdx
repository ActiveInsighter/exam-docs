## 按钮：按压、涟漪与动画图标

站内的按钮都建在 Animate UI 之上，不再自己维护点击动效：

- **`Button`**（`components/ui/button.tsx`）：shadcn 的按钮加上 Animate UI 的按压反馈。
- **`RippleButton`**（`components/ui/ripple-button.tsx`）：同一套 variant，涟漪从**点击的位置**扩散。题目选项使用它；提交、自评和「查看解答」使用普通按压反馈。
- **动画图标**（`components/animate-ui/icons/`）：来自 Animate UI 图标库，指到按钮上或状态变化时播放。

## 模态弹窗 Modal

`components/ui/modal.tsx` 建在 Animate UI 的 Base UI Drawer 之上，写法与 shadcn 组件一致。无论屏幕宽窄都是**底部抽屉**：每次打开（包括第一次）都从底部弹出，向下收回；宽屏上居中并按 `size` 限制最大宽度。顶栏固定，返回、标签、工具栏与关闭按钮使用半透明胶囊，正文独立滚动。宽屏上弹窗悬浮在底边之上，四角圆润；向下拖动（手机上拖整个抽屉，鼠标拖顶栏）可以关闭，遮罩随手指变浅。系统开启「减少动态效果」时使用淡入淡出。用法与全部属性见 `docs/modal-component.md`。

### 多级弹窗

在弹窗内容里再渲染一个 `<Modal>`，会进入同一面板的下一页。原页先淡出，新页从右侧轻移进入；返回方向相反，面板和遮罩保持共用。左上角的「返回」、Esc 和点击遮罩逐页返回；右上角关闭按钮或向下拖动关闭整个面板。原页保留输入、选择和滚动位置，返回后焦点回到打开子页的按钮。

### 学习卡片

`components/ui/study-card.tsx` 在 Modal 之上封装了一副可翻看的学习卡片：顶栏右侧的工具栏里是调用方的按钮和翻页器；宽屏左右分栏（`ratio` 控制左栏占比，只有一栏时自动占满），手机合并为一列；`tint` 给左栏铺一层柔和的彩色底。切换时当前内容先淡出，下一张从另一侧接入，标题同向切换，页码滚动；两栏本身和底色不动。快速反向时动画接续到最新目标。它只管布局与动效，内容通过 `StudyCardAside`、`StudyCardMain`、`StudyCardHero`、`StudyCardSection` 填入。题目解答就直接用它。

## 题目组件

题目组件已全局注册，博客里同样可以直接使用。选项使用 Animate UI 涟漪按钮，圆波从点击位置扩散后消退；选中和判分状态由边框、字母标记及提示保留。选项字母用 Computer Modern 数学斜体排版（与公式里的变量同一字体），作答记录保存在浏览器本地。

点击「查看解答」打开题目与解析的学习卡片：左栏是题目，铺着题型对应的彩色底，右栏是答案与解析；工具栏的翻页器可在本页所有题目之间前后切换（也可以用 ←/→ 或左右滑动）。工具栏里的「收藏与标签」在同一面板中从右侧推入，返回即回到解答。

<Question id="blog-showcase-single" type="single" tags="来源:408 统考 2019">

设栈 S 和队列 Q 的初始状态均为空，元素 a、b、c、d 依次进栈 S，出栈后立即进入队列 Q。若出队顺序为 b、d、c、a，则栈 S 的容量至少应该是（ ）。

<Option>1</Option>
<Option>2</Option>
<Option correct>3</Option>
<Option>4</Option>

<Solution>

b 出栈时栈内为 a；随后 c、d 进栈，d 出栈前栈内为 a、c、d，共 3 个元素，所以容量至少为 3。

</Solution>

### 公式选项

<Question id="blog-showcase-math-choice" type="single" tags="考点:极限">

极限 $\displaystyle\lim_{x\to 0}\frac{\sin 3x}{x}$ 的值为（ ）。

<Option>$0$</Option>
<Option>$1$</Option>
<Option correct>$3$</Option>
<Option>$\dfrac{1}{3}$</Option>

<Solution>

由重要极限 $\displaystyle\lim_{t\to 0}\frac{\sin t}{t}=1$，令 $t=3x$：

$$
\lim_{x\to 0}\frac{\sin 3x}{x}=3\lim_{x\to 0}\frac{\sin 3x}{3x}=3.
$$

</Solution>

</Question>

### 填空

文字空唤起系统键盘；数学空从底部弹出屏幕数学键盘，按数值等价判分（`1/2` 与 `0.5` 都算对）。

<Question id="blog-showcase-blank" type="blank">

TCP 位于 OSI 参考模型的 <Blank answer="传输层" aliases={["运输层"]} />；$\displaystyle\int_0^1 x\,dx=$ <Blank answer="1/2" kind="math" />。

<Solution>

TCP 是传输层协议。$\displaystyle\int_0^1 x\,dx=\left.\frac{x^2}{2}\right|_0^1=\frac{1}{2}$。

</Solution>

</Question>

### 解答

<Question id="blog-showcase-essay" type="essay" points={10}>

简述进程与线程的主要区别。

<Solution>

1. 进程是资源分配的基本单位，线程是 CPU 调度的基本单位。
2. 同一进程的线程共享进程的地址空间和资源，线程只拥有少量私有数据（栈、寄存器）。
3. 线程切换开销比进程切换小。

</Solution>

</Question>
